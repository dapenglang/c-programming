# 第 6 章 练习 15　二级指针遍历指针数组

**对应章节**：6 内存数据深度操控方法（6.6 指向指针的指针——用二级指针遍历指针数组）

**场景来源**：综合实验 B10《基于编辑距离的文本相似度计算系统》（人工智能学院）——本练习是该实验中"词条名称表输出"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本相似度系统的样本库里有一批词条名称，比如若干条待比对的关键词。为了既能灵活调整顺序、又不用搬动字符串内容，系统把每条名称单独存成一个字符数组，再用一个**指针数组**（`char *p[10]`）逐条指向它们——指针数组的每个元素都是一个"字符串首地址"。要把这张名称表按编号打印出来，就要遍历这个指针数组：外层走进指针数组取下一条地址，内层顺着地址打印整条字符串。函数接收指针数组时，形参会进一步变成"指向指针的指针"。本练习实现这个把名称表格式化输出的函数。

## 二、任务要求

编写一个完整程序 `print_table.c`：

1. 主函数读入词条数 `n`（题目保证 $1 \le n \le 10$），再读入 `n` 个不含空格的字符串（长度 < 50），存入二维字符数组 `char buf[10][50]`；
2. 建立**指针数组** `char *names[10]`，令 `names[i]` 指向 `buf[i]`（即保存第 i 条字符串的首地址）；
3. 编写函数，其原型为 `void print_table(char **names, int n);`，用**二级指针**遍历该指针数组，按编号从 1 开始逐行输出；
4. 主函数调用 `print_table(names, n)` 完成输出。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；接下来 `n` 行，每行一个不含空格的字符串。

**输出**：`n` 行，每行格式为 `<编号> <字符串>`，编号从 1 开始，编号与字符串之间用一个空格分隔。

## 四、样例

**样例 1**

输入：
```
3
alpha
beta
gamma
```
输出：
```
1 alpha
2 beta
3 gamma
```

**样例 2**

输入：
```
2
ICE-01
ICE-02
```
输出：
```
1 ICE-01
2 ICE-02
```

## 五、提示

- `names` 是一个指针数组，作为实参传给函数时，退化为指向其首元素的指针，类型是 `char **`；
- 函数里 `names[i]` 就是一个 `char *`（第 i 条字符串的首地址），`printf("%s", names[i])` 即可打印整条字符串；用 `*(names + i)` 与 `names[i]` 等价；
- 指针数组本身只存"地址"，字符串本体仍在 `buf` 里，所以指针数组可以随意重排而字符串原地不动。

**完成本练习后你将具备的能力**：搞清"指针数组 `char *p[]`"与"二级指针 `char **`"是同一件事的两种写法，能用二级指针遍历名称表——这是本章 6.6 节与后面字符串排序的基础。
