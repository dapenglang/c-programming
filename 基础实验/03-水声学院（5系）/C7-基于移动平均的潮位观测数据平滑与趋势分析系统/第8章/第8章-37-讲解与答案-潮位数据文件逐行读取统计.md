## 二、预备知识：从文件读数与"边读边统计"

### 1. 问题是怎么来的

前面的练习数据都是从**键盘**敲进去的——数据量一小（几十个数）就敲不动了。工程上真实数据都躺在**文件**里：潮位站的记录文件、声速剖面文件、噪声时序文件……程序第一步永远是"把文件读进来"。而仪器有失灵的时候，失灵那几小时的记录不是数值，而是约定的**缺失标记 −9999**，读入时必须把它认出来、剔掉，否则平均值和极值全被污染。

### 2. 读文件四步曲

**第一步：打开**

```c
FILE *fp = fopen("tide.txt", "r");
```

模式 `"r"`（read）：文件必须**已经存在**，不存在则打开失败。这与 `"w"`（不存在就新建）正好相反。

**第二步：判断是否成功**

```c
if (fp == NULL) {
    printf("打开文件 tide.txt 失败\n");
    return 1;
}
```

读文件最常见的失败原因是**文件不存在或放错了目录**——比如程序在 `D:/code` 下运行，而 `tide.txt` 放在了桌面上。

**第三步：读到文件末尾**

关键问题：文件有多少行？**事先不知道**。所以不能用 `for (i = 0; i < n; i++)`，而要用"读返回值"的循环：

```c
while (fscanf(fp, "%lf", &h) == 1) {   /* 成功读到 1 个字段才进循环 */
    /* 处理 h */
}
```

`fscanf` 与 `scanf` 的返回值含义相同：**成功读入的字段个数**。这里格式串里只有 `%lf` 一个字段，所以成功时返回 1；读到文件末尾（或遇到读不出的内容）时返回 `EOF`（−1），循环结束。**用返回值控制循环，是"读到末尾"的标准姿势。**

"逐行读"的另一种等价写法是 `fgets`：先把一整行（含换行符）读进字符数组，再用 `sscanf` 从这个字符串里提取数值：

```c
char line[100];
while (fgets(line, sizeof(line), fp) != NULL) {  /* 读到一行 */
    sscanf(line, "%lf", &h);                     /* 从行内提取数值 */
    /* 处理 h */
}
```

`fgets` 返回 `NULL` 表示读到末尾。两种写法本题都能通过，`fscanf` 更简洁，`fgets` 在"一行里有多个字段、还要判断格式"的场合更稳——C7 后续模块里你会再次见到它。

**第四步：关闭**

```c
fclose(fp);
```

### 3. 边读边统计的"三件套"

读入循环里同时做三件事（不需要数组，来一个处理一个）：

- **计数**：`total++`（每行都算），有效值再 `valid++`；
- **求和**：`sum += h`（只对有效值）；
- **极值（打擂台）**：`if (h > hmax) hmax = h; if (h < hmin) hmin = h;`（只对有效值）。

平均潮位的公式（用 LaTeX 写出）：

$$
\bar{h} = \frac{1}{N_{\text{valid}}}\sum_{h_i \ne \text{MISS}} h_i
$$

其中 `MISS = -9999` 为缺失标记，$N_{\text{valid}}$ 是有效记录数。**分母必须用有效数，且不能为 0**。

极值初值的坑：不要写 `hmax = 0; hmin = 0;` 再打擂台——如果数据里有负值（工程里完全可能），0 永远"赢"，极值就错了。**安全做法：用第一个有效值做初值。**

### 4. 用本例走一遍

样例 1 的文件共 6 行，逐行过一遍循环：

| 行 | 读到的 $h$ | 是缺失？ | total | valid | sum | hmax | hmin |
|---|---|---|---|---|---|---|---|
| 1 | 2.35 | 否 | 1 | 1 | 2.35 | 2.35 | 2.35（首值作初值） |
| 2 | −9999 | **是** | 2 | 1 | 2.35 | 2.35 | 2.35（跳过） |
| 3 | 3.10 | 否 | 3 | 2 | 5.45 | 3.10 | 2.35 |
| 4 | 3.85 | 否 | 4 | 3 | 9.30 | 3.85 | 2.35 |
| 5 | 3.42 | 否 | 5 | 4 | 12.72 | 3.85 | 2.35 |
| 6 | 2.90 | 否 | 6 | 5 | 15.62 | 3.85 | 2.35 |

最后：$\bar{h} = \dfrac{15.62}{5} = 3.124$。第 2 行的 −9999 被正确地"只计数、不统计"——这正是 M2 有效性检查的雏形。

> **这个思想在综合实验中反复出现**：C7 的潮位读入、C6 的深度时序读入、C9 的噪声级读入，全是"文件 → 循环读 → 边读边统计"同一个骨架。学会了这一题，三类实验的数据入口模块就都打通了。

## 三、解题思路

1. **打开**：`fopen("tide.txt", "r")`，判 `NULL`；
2. **读循环**：`while (fscanf(fp, "%lf", &h) == 1)`，每轮 `total++`；
3. **有效性检查**：`h != -9999` 才 `valid++`、`sum += h`、更新极值；第一个有效值用于初始化 `hmax/hmin`（用标志变量或 `valid == 1` 判断）；
4. **算平均**：`mean = sum / valid`；
5. **输出 5 行统计结果到屏幕**，`fclose(fp)`。

## 四、参考代码

```c
#include <stdio.h>

#define MISS -9999.0            /* 缺失标记 */

int main(void)
{
    FILE *fp;                   /* 输入文件指针 */
    double h;                   /* 当前读到的潮位 */
    double hmax, hmin, sum, mean;
    int total = 0, valid = 0;

    fp = fopen("tide.txt", "r");        /* 第一步：以只读方式打开文件 */
    if (fp == NULL) {                   /* 第二步：判断是否成功 */
        printf("打开文件 tide.txt 失败\n");
        return 1;
    }

    hmax = 0; hmin = 0; sum = 0.0;
    while (fscanf(fp, "%lf", &h) == 1) {    /* 第三步：读到文件末尾 */
        total++;                            /* 总记录数（含缺失行） */
        if (h == MISS) continue;            /* 缺失标记：只计数，不统计 */
        if (valid == 0) {                   /* 第一个有效值作极值初值 */
            hmax = h;
            hmin = h;
        }
        valid++;
        sum += h;
        if (h > hmax) hmax = h;
        if (h < hmin) hmin = h;
    }

    fclose(fp);                             /* 第四步：关闭文件 */

    mean = sum / valid;                     /* 题目保证 valid >= 1 */
    printf("总记录数: %d\n", total);
    printf("有效记录数: %d\n", valid);
    printf("最高潮位: %.2f\n", hmax);
    printf("最低潮位: %.2f\n", hmin);
    printf("平均潮位: %.3f\n", mean);
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：不检查 `fopen` 返回值**

```c
FILE *fp = fopen("tide.txt", "r");
fscanf(fp, "%lf", &h);         /* 错：文件不存在时 fp 为 NULL，程序崩溃 */
```

**错误 2：用 `while (!feof(fp))` 判断文件末尾**

```c
while (!feof(fp)) {                      /* 错：feof 在"读完最后一次之后"才置位 */
    fscanf(fp, "%lf", &h);               /* 最后一行会被多处理一次 */
    total++;
}
```

`feof(fp)` 只有在**已经读过末尾**之后才变真，所以这种写法会把最后一行读两次（第二次 `h` 保持旧值）。**正确姿势是用 `fscanf` 的返回值控制循环**：

```c
while (fscanf(fp, "%lf", &h) == 1) { total++; ... }
```

**错误 3：缺失标记混入统计**

```c
if (h == MISS) continue;   /* 对：先剔除再统计 */
sum += h;                  /* 若漏掉这句判断，-9999 会把 sum 和极值全部拉偏 */
```

少这一句，样例 1 的平均值会变成 $(15.62-9999)/6 \approx -1663.90$，最高/最低潮位也会被 −9999 污染——一眼就能看出结果不对。

**错误 4：极值初始化为 0**

```c
hmax = 0; hmin = 0;                  /* 潮位恒正时侥幸正确，但不是通用写法 */
if (valid == 0) { hmax = h; hmin = h; }   /* 对：用第一个有效值作初值 */
```

**错误 5：模式用错（读文件却用 `"w"`）**

```c
FILE *fp = fopen("tide.txt", "w");   /* 错：刚打开就把文件清空了，数据全没！ */
FILE *fp = fopen("tide.txt", "r");   /* 对：读文件用 "r" */
```

这是**最危险**的错误：`"w"` 打开的瞬间文件就被清空。处理观测数据时误用 `"w"`，原始数据直接丢失。**记牢：读用 `"r"`，写用 `"w"`。**
