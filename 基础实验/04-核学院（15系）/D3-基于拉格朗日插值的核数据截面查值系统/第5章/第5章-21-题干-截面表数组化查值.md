# 第 5 章 练习 21　截面表数组化查值

**所属综合实验**：D3（D3-基于拉格朗日插值的核数据截面查值系统）

**对应章节**：5 数组与批量数据处理（5.1 一维数组的定义与初始化、5.2 数组元素的访问、5.3 数组与循环配合、5.4 一维数组的查值与插值）

**场景来源**：综合实验 D3《基于拉格朗日插值的核数据截面查值系统》（核学院）——本练习是该实验中"把能量-截面表存入数组并按能量查值"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

中子与原子核反应的**截面**（单位 barn，\(1\ \text{barn}=10^{-28}\ \text{m}^2\)）是反应堆物理最重要的物理量之一：它描述"中子撞上核发生反应的概率"。截面随中子能量剧烈变化，从热中子（0.025 eV）到快中子（MeV）相差几个数量级。

国际核数据库（ENDF、IAEA）用**能量-截面数据表**的形式给出这些数值。模拟程序（实验 D3）要能回答："能量为某个值的中子，截面是多少？"——做法是把表格存进**数组**，再用**循环**找到所在区间做**线性插值**。本练习实现这个最小的查值内核。

## 二、任务要求

编写一个完整程序 `sigma_table.c`：

1. 程序中用**数组**存放下表 6 组能量与截面数据（能量单位 eV，截面单位 barn）；
2. 从键盘读入一个中子能量 `E`（eV，double，题目保证 \(0.025 \le E \le 10^{6}\)）；
3. 用**循环**找到 `E` 所在的区间，用线性插值计算该能量对应的截面 `sigma`；若 `E` 恰好等于表中某个能量值，则直接取对应截面；
4. 输出截面值，保留 **2 位小数**，格式 `sigma = 结果`。

下表为简化的仿真数据（用于教学，非真实核数据；真实数据可在 ENDF/IAEA 库中按相同字段读取）：

| 能量 E（eV） | 截面 σ（barn） |
|---|---|
| 0.025 | 587.0 |
| 1.0 | 250.0 |
| 100.0 | 60.0 |
| 1.0×10⁴ | 20.0 |
| 1.0×10⁵ | 12.0 |
| 1.0×10⁶ | 8.0 |

## 三、输入输出格式

**输入**：一行，一个实数，表示中子能量 `E`（eV）。

**输出**：一行，按格式 `sigma = 结果` 输出截面，保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
0.5
```
输出：
```
sigma = 422.82
```

**样例 2**

输入：
```
10
```
输出：
```
sigma = 232.73
```

## 五、提示

线性插值公式：若 `E` 落在第 `i` 与第 `i+1` 个数据点之间（\(E_i \le E \le E_{i+1}\)），则

$$
\sigma = \sigma_i + \dfrac{(\sigma_{i+1}-\sigma_i)\,(E - E_i)}{E_{i+1} - E_i}
$$

程序的结构是"**一次循环扫描找区间 + 一次插值计算**"：

```c
for (i = 0; i < N - 1; i++) {
    if (E >= en[i] && E <= en[i + 1]) {
        /* 在 en[i] 与 en[i+1] 之间插值，算完可以 break */
    }
}
```

注意数据点个数 `N` 是常量 6，数组下标从 0 到 5。数组元素用 `en[i]`、`sig[i]` 访问。

**完成本练习后你将具备的能力**：定义数组并用初始化列表赋初值、用循环遍历数组、在循环中做条件判断找区间、把表格插值公式翻译成数组下标形式的代码——这些是实验 D3 中"截面查值模块"的地基。
