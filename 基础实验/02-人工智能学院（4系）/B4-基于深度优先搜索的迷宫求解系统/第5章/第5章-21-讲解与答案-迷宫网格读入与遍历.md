## 二、预备知识：二维数组与字符网格的基本原理（零基础阅读）

### 1. 问题是怎么来的

迷宫是"二维"的：有行、有列。用一维数组只能表示一排格子，表示不了整张图。**二维数组**就是"数组的数组"：每个元素本身又是一个数组，于是要两个下标才能定位一个格子。

```c
char grid[10][10];   /* 10 行，每行 10 个字符 */
```

`grid[i][j]` 表示"第 $i$ 行、第 $j$ 列"那个格子里的字符。可以把它想象成一张表格：第一个下标选行，第二个下标选列，和 Excel 的行号列号一个道理。

### 2. 字符是怎么存的

每个格子里放的是一个**字符**。C 语言里字符常量用单引号括起来，如 `'S'`、`'.'`、`'#'`。判断两个字符是否相同，直接用 `==`：

```c
if (grid[i][j] == 'S') { ... }   /* 这一格是起点 */
```

**注意别把 `'S'` 写成 `"S"`**：单引号是字符，双引号是字符串，二者类型不同，比较结果永远不对。

### 3. 二维网格在内存里是怎么排的

`char grid[10][10]` 在内存里其实是**连续**的 100 个字符，按行排列：

```
内存：grid[0][0] grid[0][1] ... grid[0][9] grid[1][0] ... grid[9][9]
```

也就是说，"第 $i$ 行第 $j$ 列"实际是第 $i \times 10 + j$ 个字符——这正是第 2 章练习 23 讲过的"二维拉直"公式，只是这里由编译器自动完成，我们只管用两个下标访问。

### 4. 用本例走一遍

**例 1**：$3 \times 3$ 网格 `S..` / `.#.` / `..G`。

- $(0,0)$ 是 `S`，记起点 $(0,0)$；
- $(1,1)$ 是 `#`，`wall` 加一；
- $(2,2)$ 是 `G`，记终点 $(2,2)$；
- 其余 5 个是 `.`，`road` 加五。

结果：`S at (0,0)`、`G at (2,2)`、`road = 6, wall = 1`。校验 $6 + 1 + 1(\text{S}) + 1(\text{G}) = 9 = 3 \times 3$ ✓。

**例 2**：$2 \times 4$ 网格 `S..G` / `####`。

- 第一行：`S` 在 $(0,0)$，`G` 在 $(0,3)$，两个 `.`；
- 第二行：4 个 `#`。

结果：`road = 2, wall = 4`，校验 $2+4+1+1 = 8 = 2 \times 4$ ✓。

### 5. 编程时怎么用它

读入的常见做法是先读一个临时字符串，再逐字符搬到网格里：

```c
char line[16];
for (i = 0; i < r; i++) {
    scanf("%s", line);              /* 读一行 */
    for (j = 0; j < c; j++)
        grid[i][j] = line[j];       /* 逐字符搬入 */
}
```

遍历时再用双重循环，一边看字符、一边统计。**注意循环上界是给定的 $r, c$，不是数组声明的 10**——声明 10 只是留足空间，实际只用 $r$ 行 $c$ 列。

> **这个思想在综合实验中反复出现**：B4 迷宫网格、B1 灰度图像（二维像素矩阵）、B5 邻接矩阵、B8 系数矩阵，全都是"二维数组存二维数据"同一个套路。

## 三、解题思路

1. **定义网格**：`char grid[10][10];`，另备临时字符串 `char line[16];`；
2. **读入尺寸**：`scanf("%d %d", &r, &c);`；
3. **读入网格**：外层循环逐行读字符串，内层循环逐字符搬到 `grid`；
4. **遍历统计**：双重循环里按字符分类，记住 S、G 坐标，累加 `road`、`wall`；
5. **输出**：三条 `printf` 输出坐标与计数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    char grid[10][10];      /* 二维字符网格，最多 10×10 */
    char line[16];          /* 临时存放读入的一行 */
    int r, c;               /* 行数、列数 */
    int i, j;
    int sr = -1, sc = -1;   /* 起点坐标，-1 表示尚未找到 */
    int gr = -1, gc = -1;   /* 终点坐标 */
    int road = 0, wall = 0; /* 通路数、墙数 */

    /* 读入尺寸 */
    scanf("%d %d", &r, &c);

    /* 逐行读入并逐字符存入二维数组 */
    for (i = 0; i < r; i++) {
        scanf("%s", line);
        for (j = 0; j < c; j++)
            grid[i][j] = line[j];
    }

    /* 遍历网格，分类统计 */
    for (i = 0; i < r; i++) {
        for (j = 0; j < c; j++) {
            char ch = grid[i][j];
            if (ch == 'S') { sr = i; sc = j; }        /* 起点 */
            else if (ch == 'G') { gr = i; gc = j; }   /* 终点 */
            else if (ch == '.') road++;               /* 通路 */
            else if (ch == '#') wall++;               /* 墙 */
        }
    }

    /* 输出结果 */
    printf("S at (%d,%d)\n", sr, sc);
    printf("G at (%d,%d)\n", gr, gc);
    printf("road = %d, wall = %d\n", road, wall);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3 3 / `S..` / `.#.` / `..G` | S(0,0)、G(2,2)、road=6、wall=1 | `S at (0,0)` / `G at (2,2)` / `road = 6, wall = 1` ✓ |
| 2 4 / `S..G` / `####` | S(0,0)、G(0,3)、road=2、wall=4 | `S at (0,0)` / `G at (0,3)` / `road = 2, wall = 4` ✓ |
| 2 2 / `S#` / `#G` | S(0,0)、G(1,1)、road=0、wall=2 | `S at (0,0)` / `G at (1,1)` / `road = 0, wall = 2` ✓ |
| 1 5 / `S...G` | S(0,0)、G(0,4)、road=3、wall=0 | `S at (0,0)` / `G at (0,4)` / `road = 3, wall = 0` ✓ |

每组都满足"格子总数 = S + G + road + wall"，说明遍历无遗漏。

## 六、常见错误与讲解

**错误 1：混淆字符与字符串的引号（最典型）**

```c
if (grid[i][j] == "S")   /* 错：单引号才是字符 */
if (grid[i][j] == 'S')   /* 对 */
```

**错误 2：循环上界写成数组声明大小**

```c
for (i = 0; i < 10; i++)      /* 错：实际只有 r 行，会读到垃圾数据 */
for (i = 0; i < r; i++)       /* 对：用实际行数 */
```

**错误 3：读入时用 scanf("%s") 但行内有空格分隔**

```c
scanf("%s", line);    /* 对：迷宫行内无空格，%s 可以读整行 */
```

迷宫字符是连续的，`%s` 正好一次读一行；但如果输入里有空格分隔就会断掉，那时要用 `%c` 逐个读。

**错误 4：找不到 S 或 G 时输出垃圾坐标**

```c
int sr, sc;                  /* 错：未初始化 */
int sr = -1, sc = -1;        /* 对：初值 -1，便于发现"没找到" */
```
