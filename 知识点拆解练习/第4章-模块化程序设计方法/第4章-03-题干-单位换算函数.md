# 第 4 章 练习 03　单位换算函数

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明、调用与参数传递）

**场景来源**：综合实验 C7《基于冲量-动量反演的冰阻力与碰撞事件辨识系统》（水声学院）——本练习是该实验中"航速与阻力单位换算"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰区航行实测数据里，船速常用 km/h 记录，冰阻力常用 kN 记录；而物理公式要求国际单位：速度用 m/s、力用 N。要计算阻力功率（$P = Fv$），必须先把这两类量统一换算。实验 C7（以及 C1 声速剖面、C6 碰撞模拟）里到处都要做单位换算，如果每处都手写"÷3.6"和"×1000"，既容易写错，也不便统一修改。本练习把这两件事各封装成一个函数，让主程序只管调用。

## 二、任务要求

编写一个完整程序 `unit_convert.c`：

1. 必须定义两个函数，**函数原型分别为**
   ```c
   double kmh_to_ms(double v);   /* 千米每小时 → 米每秒 */
   double kn_to_n(double f);     /* 千牛 → 牛 */
   ```
2. 主函数依次读入航速 `v`（km/h）与冰阻力 `F`（kN）；
3. 调用上述两个函数完成换算，并进一步用换算后的国际单位计算阻力功率
   $$
   P = F \times v
   $$
   （此处 $F$ 单位 N，$v$ 单位 m/s，$P$ 单位 W）；
4. 按格式输出换算后的速度、力与功率，各保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，两个实数 v、F，用空格分隔（v 单位 km/h，F 单位 kN）。

**输出**：三行，依次为 `v = <速度> m/s`、`F = <力> N`、`P = <功率> W`，每个结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
18 3.6
```
输出：
```
v = 5.0000 m/s
F = 3600.0000 N
P = 18000.0000 W
```

**样例 2**

输入：
```
36 1.25
```
输出：
```
v = 10.0000 m/s
F = 1250.0000 N
P = 12500.0000 W
```

## 五、提示

换算关系：

$$
1\ \text{km/h} = \frac{1000\ \text{m}}{3600\ \text{s}} = \frac{1}{3.6}\ \text{m/s},\qquad
1\ \text{kN} = 1000\ \text{N}
$$

即速度换算除以 $3.6$，力换算乘以 $1000$。**同一处换算逻辑，全程序只写一次**——这正是封装函数的意义。注意功率计算必须使用换算后的量，否则单位混杂会得到错误的物理结果。

**完成本练习后你将具备的能力**：定义和调用多个函数、把公共计算封装复用、在一个程序里组织"调用 A 和 B，再拿结果参与运算"的流程，以及数值计算的单位一致性意识——这是实验 C7 数据预处理模块的通用写法。
