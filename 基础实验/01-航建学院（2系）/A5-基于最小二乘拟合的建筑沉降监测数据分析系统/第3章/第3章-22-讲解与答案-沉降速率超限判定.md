## 二、预备知识：选择结构（if/else）的基本原理（零基础阅读）

### 1. 问题是怎么来的

前面几题的程序都是"一条道走到黑"：读数据、算结果、输出，中间没有任何岔路。但真实工程判断总要分情况：沉降速率超了没有？超过就报警，没超就不报警。程序必须能在某个位置**根据条件的真假走不同的路**，这就是选择结构。

### 2. 条件是怎么表达的

C 语言里，任何"能判断真假的话"都写成一个**关系表达式**，它的值只有两种：真（非 0）或假（0）。常用的关系运算符有：

| 运算符 | 含义 |
|---|---|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | 等于（**两个等号**） |
| `!=` | 不等于 |

本题的判定条件写成 C 语句就是 `v > LIMIT`——注意这里没有等号，因为规范规定"等于控制值不算超限"。

### 3. 用本例走一遍

以样例 1 第 5 个数据 $v = 0.15$、控制值 $0.15$ 为例：

- 判断 `0.15 > 0.15`，结果为假（0.15 并不大于 0.15）；
- 于是走 `else` 分支，输出 `normal: 正常`；
- 计数变量不增加。

再取第 4 个数据 $v = 0.20$：

- 判断 `0.20 > 0.15`，结果为真；
- 走 `if` 分支，输出 `warning: 超限`；
- `cnt` 自增 1。

走完全部 5 个数据，超限的是第 2、4 段，共 2 段。

### 4. 编程时怎么用它

`if`/`else` 的骨架是：

```c
if (条件) {
    条件为真时执行的语句;
} else {
    条件为假时执行的语句;
}
```

有两个容易出错的地方：

1. **判断相等用 `==`，不是 `=`**。`=` 是赋值（把右边的值存进左边的变量），`==` 才是比较。写错不会报错，但逻辑完全错；
2. **花括号 `{}` 不能省**（当分支里有多条语句时）。本题 `if` 分支里既有 `printf` 又有 `cnt++`，必须用花括号包起来，否则只有第一条语句属于该分支。

## 三、解题思路

1. **定义常量**：`const double LIMIT = 0.15;`；
2. **读入 n**：`scanf("%d", &n)`；
3. **准备计数器**：`int cnt = 0;`；
4. **循环 n 次**：每轮读入一个速率 `v`，先输出"第 i 段 v=数值 "，再用 `if`/`else` 输出结论；若超限则 `cnt++`；
5. **循环后输出** `exceed = cnt`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double LIMIT = 0.15;   /* 沉降速率控制值，mm/天（规范值） */
    int n;                       /* 时段数量 */
    int i;                       /* 循环变量 */
    int cnt = 0;                 /* 超限段数计数器，初值 0 */
    double v;                    /* 当前时段的沉降速率，mm/天 */

    /* 读入时段数量 */
    scanf("%d", &n);

    /* 逐段读入速率并判断 */
    for (i = 1; i <= n; i++) {
        scanf("%lf", &v);                       /* 读入第 i 段速率 */
        printf("第%d段 v=%.3f ", i, v);          /* 先输出段号与数值 */
        if (v > LIMIT) {                        /* 严格大于控制值才算超限 */
            printf("warning: 超限\n");
            cnt++;                              /* 超限计数加 1 */
        } else {
            printf("normal: 正常\n");
        }
    }

    /* 输出超限段数 */
    printf("exceed = %d\n", cnt);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 5 / 0.12 0.16 0.09 0.20 0.15 | 0.16、0.20 超限；0.12、0.09、0.15 正常（0.15 不算超限） | 前 5 行判定如上，末行 `exceed = 2` ✓ |
| 4 / 0.05 0.30 0.18 0.10 | 0.30、0.18 超限；0.05、0.10 正常 | `exceed = 2` ✓ |
| 3 / 0.10 0.10 0.10 | 全部正常 | `exceed = 0` ✓ |
| 2 / 0.20 0.25 | 两段都超限 | `exceed = 2` ✓ |

## 六、常见错误与讲解

**错误 1：把 `==` 写成 `=`**

```c
if (v = LIMIT) { ... }    /* 错：这是赋值，v 被改成 LIMIT，条件恒为真 */
if (v == LIMIT) { ... }   /* 对：比较是否相等 */
```

本题用的是 `>`，但同一个错误在第 5 章的查找、第 7 章的链表遍历里都会出现，务必从现在分清 `=` 与 `==`。

**错误 2：花括号漏写**

```c
if (v > LIMIT)
    printf("warning: 超限\n");
    cnt++;                 /* 错：这行永远执行，cnt 变成段数 n */
```

不加花括号时，`if` 只管到它后面的第一条语句。`cnt++` 被排除在分支之外，无论是否超限都会加 1，计数结果全错。**只要分支里不止一条语句，就一定要加 `{}`。**

**错误 3：把"等于控制值"也当成超限**

```c
if (v >= LIMIT) { ... }    /* 错：0.15 会被判为超限 */
if (v > LIMIT)  { ... }    /* 对：规范要求严格超过才报警 */
```

题目样例 1 里的 0.15 正是用来检验这一点的：正确程序应输出"正常"。

**错误 4：计数器初值放在循环里**

```c
for (i = 1; i <= n; i++) {
    int cnt = 0;           /* 错：每轮都被清零，最后只剩 0 或 1 */
    ...
}
```

计数器必须在循环**外面**声明并赋初值。

## 七、与综合实验的衔接

- 实验 **A5（建筑沉降监测数据分析）**中，本练习对应"超限报警"模块：拿到各期观测数据、算出相邻期沉降速率后，逐段与本练习的判定逻辑比对，把超限段号打印出来供工程人员复核；
