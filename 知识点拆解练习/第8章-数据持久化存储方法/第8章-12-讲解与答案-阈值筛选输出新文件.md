## 二、预备知识：筛选型数据流的基本原理（零基础阅读）

### 1. 为什么这样组织数据流

筛选任务的本质是一条**单向流水线**：数据从源文件流出来，经过一道"闸门"（判断），合格的流进结果文件，不合格的丢弃。与练习 11 对比，骨架一模一样——都是"读 → 处理 → 写"，唯一区别是"处理"这一步从**格式转换**换成了**条件筛选**：

```
resistance.txt --fscanf--> id, f --if (f > F0)--> fprintf --> resistance_high.txt
   （全部记录）              （一条记录）     （闸门）              （合格记录）
```

这种"闸门"式结构的好处是：不管文件有 5 行还是 50 万行，代码一行都不用改；想改筛选条件（比如改成"小于阈值"或"落在某区间"），只动 if 里那一行。

### 2. 各环节的职责

- **fscanf（读入环节）**：每次从文件取一条记录放进变量 `id`、`f`。它的返回值是"成功赋值的项数"——正常读到一条完整记录返回 2；文件读完再读，返回 EOF。所以 `while (fscanf(...) == 2)` 是处理**行数未知**文件的标准写法：程序自己知道什么时候该停，不需要用户告诉它有多少行；
- **if（判断环节）**：阈值 `F0` 来自键盘，是程序运行时才确定的量，所以筛选条件不能写死在代码里；
- **fprintf（写出环节）**：只把合格记录写入新文件，同时计数器 `n` 加一。

### 3. 两个文件指针的生命周期

`fin` 从打开到所有记录读完即关闭；`fout` 从打开到筛选结束关闭。它们同时活跃、各管一头。与练习 11 一样：每个 fopen 后必须检查 NULL，退出前必须 fclose。特别提醒——若源文件打开失败就 return，此时 `fout` 还没打开，不需要也无法关闭；若目标文件打开失败，则要先 `fclose(fin)` 再返回。

### 4. fscanf 与 fgets 两种读法怎么选

练习 11 用 `fgets + sscanf`（先拿整行再拆），本题用 `fscanf` 直接按格式取字段。经验法则：**字段类型规整、分隔符统一**时用 fscanf 最省事；**行的结构复杂、需要整行判断**（如空行、注释行）时用 fgets。本题数据规整，fscanf 正合适。

## 三、解题思路

1. **开文件**：fin 以 "r" 打开 resistance.txt，fout 以 "w" 打开 resistance_high.txt，逐一检查返回值；
2. **读阈值**：`scanf("%lf", &F0)` 从键盘读入；
3. **循环筛选**：`while (fscanf(fin, "%d %lf", &id, &f) == 2)`，循环体内 `if (f > F0)` 则写出并计数；总记录数每轮无条件加一；
4. **收尾与摘要**：关闭两个文件，按格式输出总记录数、筛出数与阈值。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fin, *fout;        /* 源文件、结果文件指针 */
    int id;                  /* 样本序号 */
    double f;                /* 阻力值，kN */
    double F0;               /* 阈值，kN */
    int total = 0, n = 0;    /* 总记录数、超阈值记录数 */

    fin = fopen("resistance.txt", "r");
    if (fin == NULL) {
        printf("错误：无法打开 resistance.txt\n");
        return 1;
    }
    fout = fopen("resistance_high.txt", "w");
    if (fout == NULL) {
        printf("错误：无法创建 resistance_high.txt\n");
        fclose(fin);
        return 1;
    }

    printf("请输入阈值(kN)：");
    scanf("%lf", &F0);

    /* 逐条读入，返回值为 2 说明成功读到一条完整记录 */
    while (fscanf(fin, "%d %lf", &id, &f) == 2) {
        total++;
        if (f > F0) {                       /* 闸门：只放行超阈值记录 */
            fprintf(fout, "%d %.1f\n", id, f);
            n++;
        }
    }

    fclose(fin);
    fclose(fout);
    printf("共 %d 条记录，其中 %d 条超过阈值 %.1f\n", total, n, F0);

    return 0;
}
```

## 五、运行验证

**文件内容前后变化**（阈值输入 25.0）：

| resistance.txt（源，不变） | resistance_high.txt（新生成） |
|---|---|
| `1 23.5` | `2 25.1` |
| `2 25.1` | `4 27.6` |
| `3 19.8` | |
| `4 27.6` | |
| `5 22.4` | |

逐条核对判断过程：23.5 > 25.0 否；25.1 > 25.0 **是**，写入；19.8 否；27.6 **是**，写入；22.4 否。筛出 2 条，与文件内容一致。

**屏幕输出**：

```
请输入阈值(kN)：
25.0
共 5 条记录，其中 2 条超过阈值 25.0
```

边界验证：若输入阈值 22.4，则严格大于 22.4 的是 23.5、25.1、27.6 共 3 条，输出为"共 5 条记录，其中 3 条超过阈值 22.4"；恰好等于 22.4 的样本 5 不入选，检验了"严格大于"的约定。

## 六、常见错误与讲解

**错误 1：循环条件写错导致死循环或漏读**

```c
while (!feof(fin)) { fscanf(fin, "%d %lf", &id, &f); ... }   /* 不好：feof 要在读失败之后才置位，常导致最后一条被读两次 */
while (fscanf(fin, "%d %lf", &id, &f) == 2) { ... }          /* 对：以读入是否成功为判据 */
```

**错误 2：格式串与数据不匹配**

```c
fscanf(fin, "%d, %lf", &id, &f);   /* 错：数据是空格分隔的，格式串里多写了一个逗号 */
fscanf(fin, "%d %lf", &id, &f);    /* 对：格式串中的空格可匹配任意空白 */
```

格式串与文件实际格式不一致时，fscanf 返回值会小于 2，循环提前结束——表现为"只读到第一条"或"一条都读不到"。

**错误 3：筛选条件用了 >=**

题目约定"严格大于阈值"，写成 `f >= F0` 会把恰好等于阈值的记录也放进去。样例中特意安排了 25.1 与 25.0 这样接近的数值来检验这一点。

**错误 4：屏幕摘要格式串写错**

```c
printf("共 %d 条记录，其中 %d 条超过阈值 %.1f\n", total, n);          /* 错：少传 F0 */
printf("共 %d 条记录，其中 %d 条超过阈值 %.1f\n", total, n, F0);      /* 对：三个占位符三个实参 */
```

占位符与实参必须一一对应，否则输出乱值。
