# 题目 A9：基于贪心枚举的矩形板材下料优化系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套矩形板材下料排样优化工具。系统读入标准板材尺寸与待切割零件清单后，把每张板材离散成 10 mm 网格的二维字符占用矩阵，按"面积从大到小"的贪心次序逐件在板材上扫描寻找可放置位置（支持旋转），放置成功则标记占用矩阵；全部排完后统计材料利用率与废料面积并绘制排样字符图；进一步对"面积降序/长边降序/短边降序"等多种排序规则分别完整排样，比较利用率取最优方案，输出优化报告。

**解决什么重要问题**：钢结构与木作加工中，板材（钢板、木工板、石膏板）按标准尺寸采购，而零件尺寸五花八门——下料方案直接决定材料利用率，大型加工厂板材成本占材料费 30% 以上，利用率每提高 5% 就是数万元节约；排样不合理还会导致切割路径混乱、工时浪费。矩形排样是经典组合优化问题，精确求解困难，但工程上"大件先放、逐件扫描"的贪心启发式简单有效，本系统让学生亲手实现并对比不同贪心规则的优劣，理解"近似算法 + 评价函数"这一工程优化的基本范式。

**支撑哪些关键应用**：① 钢结构加工厂钢板套料（与 FastCAM 等套料软件同思路）；② 板式家具生产的开料清单优化；③ 玻璃、石材、皮革裁剪排样；④ 后续"运筹学""算法设计"课程中贪心策略与启发式方法的第一课，也是工程管理专业"施工下料与成本控制"的计算基础。

**与专业培养的关联**：土木与工程管理学生毕业后大量接触材料加工与损耗控制。本题目把课程 5.5 节排序、二维数组、枚举循环组合成一个看得见、画得出的优化问题，字符排样图让算法效果直观可见，训练"贪心策略 + 结果量化评价"的优化思维。

## 二、题目任务与专业关联

本题目面向土木工程与工程管理方向学生，模拟"加工厂套料排样"场景。系统功能概述：① 读入板材与零件清单；② 零件按面积排序；③ 用二维字符数组表示板材占用网格；④ 逐件扫描尝试放置（含旋转）；⑤ 贪心排样全部零件；⑥ 统计利用率与余料；⑦ 多排序规则枚举对比取最优；⑧ 排样字符图与报告输出。先导知识铺垫：放置可行性判定——零件以左上角对齐网格点 (r,c) 放置，当且仅当其覆盖的所有网格单元均为空闲；扫描次序为"从上到下、从左到右"取第一个可行位置（首次适应策略），整页讲清，无需任何优化理论。

## 三、数据来源与格式

**数据文件 1：板材清单**（`stock.txt`）

```
板材编号,长mm,宽mm,张数
1,2440,1220,3
2,3000,1500,1
```

**数据文件 2：零件清单**（`parts.txt`）

```
零件编号,名称,长mm,宽mm,数量
101,底板,1200,600,2
102,侧板,800,400,4
103,横撑,1150,150,6
104,加强肋,500,300,5
105,垫块,220,180,8
```

字段含义：板材长 1000~3200 mm、宽 800~1600 mm（市售标准板）；零件长 100~2500 mm、宽 100~1200 mm，长≥宽；数量 1~20 件；所有尺寸均为 10 mm 的整数倍（与网格对应）。

**仿真数据生成规则**：
- 零件 10~16 种（可展开为 30~40 个单件），尺寸按"大件~中件~小件"三档生成：大件 900~1500×400~700、中件 400~800×200~400、小件 150~350×100~300，均取 10 mm 倍数；
- 设计使总面积约为单张板材面积的 1.6~2.2 倍（必然需要多张板材并产生余料对比）；
- 异常注入：在 `parts.txt` 中故意写 `106,误录件,1500,1800,1`（零件宽大于板材宽，无法放置）、`107,超长件,3200,200,1`（零件长超过最大板长），以及一行数量写成 `0` 的记录，用于训练读入校验与"放不下零件"的处理；
- 板材按 `stock.txt` 顺序逐张启用，当前张放不下自动开新张。

**真实数据集**：无必需公开数据集；板材规格参照《人造板尺寸》GB/T 15102（1220×2440 mm 等）与钢板定尺规格，报告中注明。

## 四、数据结构设计

```c
#define GRID_STEP 10           /* 网格步长 mm */
#define MAX_COLS  320          /* 网格最大列数 3200/10 */
#define MAX_ROWS  160          /* 网格最大行数 1600/10 */
#define MAX_PART  50           /* 零件记录数上限 */
#define MAX_PIECE 60           /* 展开后单件总数上限 */
#define MAX_SHEET 8            /* 板材张数上限 */

/* 板材 */
struct Sheet {
    int    len, wid;           /* 长宽 mm，1000~3200 / 800~1600 */
    char   used;               /* 是否启用 */
};

/* 零件记录 */
struct Part {
    int    id;                 /* 零件编号 */
    char   name[16];           /* 名称，≤15 字符 */
    int    len, wid;           /* 长宽 mm，10 的倍数 */
    int    qty;                /* 数量 0~20，0 视为非法 */
    int    valid;              /* 校验标志 */
};

/* 展开后的单个零件实例 */
struct Piece {
    int    partId;             /* 来源零件编号 */
    int    len, wid;           /* 放置方向下的长宽 mm */
    int    sheetNo;            /* 放置在板材编号，0=未放下 */
    int    row, col;           /* 放置位置网格坐标，未放为 -1 */
    int    rotated;            /* 是否旋转 1/0 */
};

/* 全局数据 */
struct Sheet  g_stock[MAX_SHEET];
struct Part   g_part[MAX_PART];
struct Piece  g_piece[MAX_PIECE];
char   g_grid[MAX_ROWS][MAX_COLS]; /* 当前板材占用矩阵 '.'空 'X'占用 */
int    g_sheetCnt, g_partCnt, g_pieceCnt;
```

统计结果全局变量：`g_usedArea`（已用面积 mm²）、`g_wasteArea`（废料面积）、`g_fitCnt`（已放置件数）、`g_unfitCnt`（未放下件数）、`g_util`（利用率 %）。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 板材与零件清单读入模块**（源文件 `DataIO.c`）

- 功能简介：分别读入 `stock.txt` 与 `parts.txt`；校验尺寸为 10 的倍数、范围合法、数量大于 0（对注入的非法行打印警告并标记 valid=0）；把零件按数量展开成单件实例数组 `g_piece[]`；输出板材总面积与零件总面积对比。
- 输入：两个清单文本文件。
- 输出：`g_stock[]`、`g_part[]`、`g_piece[]`；屏幕读入摘要。

**M2 零件面积排序模块**（源文件 `SortPart.c`）

- 功能简介：计算每个单件实例的面积，按选定排序规则（1 面积降序 / 2 长边降序 / 3 短边降序，交互选择）用选择排序重排 `g_piece[]`；打印排序后前 10 件清单供确认。
- 输入：`g_piece[]`、规则号。
- 输出：重排后的 `g_piece[]`；屏幕排序清单。

### 第二部分：算法实现（5 个模块）

**M3 板材占用矩阵模块**（源文件 `Grid.c`）

- 功能简介：实现网格初始化 `void gridInit(int sheetNo)`（把当前板材网格全部置 '.'）与占用查询 `int gridFree(int r, int c, int h, int w)`（检查目标区域是否全部空闲，越界返回 0）、占位 `void gridFill(int r, int c, int h, int w)`（置 'X'）；提供打印网格占用率的调试函数。
- 输入：板材尺寸、位置与零件尺寸。
- 输出：`g_grid[][]` 状态维护；查询结果。

**M4 单件放置尝试模块**（源文件 `Place.c`）

- 功能简介：实现 `int tryPlace(struct Piece *p)`：对零件按不旋转、旋转两种方向，在网格上从左到右、从上到下扫描首个可行位置（调用 M3 的 gridFree），成功则 gridFill 并记录 sheetNo/row/col/rotated；返回成功与否；当前张全放不下返回"需开新板"信号。
- 输入：单件指针、当前板材网格。
- 输出：放置结果与位置信息（写回 Piece）。

**M5 贪心排样主流程模块**（源文件 `Nest.c`）

- 功能简介：按排序后的次序对全部单件执行"当前板 tryPlace，失败则初始化下一张板继续，直到放完或板材用尽"；未放下的件记 sheetNo=0；全程累计已用面积；打印逐件放置流水与启用的板材张数。
- 输入：`g_piece[]`、`g_stock[]`。
- 输出：各件位置信息、`g_fitCnt`/`g_unfitCnt`、当前方案 `g_util`；屏幕排样流水。

**M6 余料统计模块**（源文件 `Remnant.c`）

- 功能简介：对每张已启用板材统计占用单元数换算废料面积，输出"板材号-利用率-最大余料矩形（最大空行×空列的粗估）"表；汇总全方案总利用率 g_util、总废料面积与未放置清单。
- 输入：`g_grid[][]`、`g_piece[]`。
- 输出：屏幕余料统计表与汇总。

**M7 多顺序枚举对比模块**（源文件 `Compare.c`）

- 功能简介：依次按 3 种排序规则完整重跑"排序→排样→统计"（复用 M2、M5、M6，每次排样前备份并恢复 g_piece[] 原始顺序），把三种方案的总利用率、板材张数、未放置数汇成对比表，指出最优规则并把最优方案的位置数据留作最终输出。
- 输入：`g_part[]`（原始清单）。
- 输出：屏幕三方案对比表与最优方案标记。

### 第三部分：数据输出（3 个模块）

**M8 排样图字符画模块**（源文件 `CharPlot.c`）

- 功能简介：对最优方案的每张启用板材按网格打印排样图：不同零件实例分别用字母 A~Z 标注（同零件同字母），空格表示余料；图形过宽时隔行抽样打印；图例列出字母-零件对照。
- 输入：最优方案 `g_piece[]`、板材尺寸。
- 输出：屏幕排样字符图。

**M9 优化报告输出模块**（源文件 `Report.c`）

- 功能简介：把零件清单、三方案对比、最优方案的逐件下料位置表（零件、板材号、左上角坐标 mm、是否旋转）与利用率和余料汇总写入 `nest_report.txt`。
- 输入：全部全局数据。
- 输出：`nest_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读清单 / 排序选择 / 单件放置测试 / 完整排样 / 余料统计 / 多规则对比 / 排样图 / 输出报告 / 退出），`do-while + switch` 调度；状态约束：未读清单与排序不得排样。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1~M9；状态约束：M3~M6 前必须完成 M1 与 M2；M7 内部循环调用 M2、M5、M6；M8、M9 输出 M7 留下的最优方案。

**数据流**：

```
stock.txt ─┐
           ├─► M1 读入展开 ─► g_piece[] ─► M2 排序（规则可选）
parts.txt ─┘                                      │
                                                  ▼
             M3 占用矩阵 g_grid ◄── 扫描 ── M4 单件放置尝试
                       │                      │
                       ▼                      ▼
             M5 贪心主循环（换板逻辑） ─► 位置信息 + g_util
                       │
             M6 余料统计 ◄── g_grid
                       │
             M7 三规则枚举对比 ─► 最优方案
                       │
             M8 排样字符图      M9 报告 nest_report.txt
```

模块间通过全局零件实例数组与占用矩阵交换数据，`gridFree/gridFill/tryPlace` 三个接口编码前书面约定。

## 十、选做扩展

1. 规则库扩充：增加"最长边优先且优先贴左上角""面积降序但先填右上角"两种变体策略，扩充对比表到 5 种方案（在同一放置框架上改扫描次序）；
2. 余料二次利用：对未放下的小件，在各板材余料区域重新扫描放置一轮，输出二次排样后利用率提升幅度（复用 tryPlace 于余料区域）；
3. 利用率随板材规格的敏感性：对同批零件分别用 1220×2440 与 1500×3000 板材完整排样，输出两种采购规格的利用率与费用对比表（多清单循环 + 已有模块组合）。
