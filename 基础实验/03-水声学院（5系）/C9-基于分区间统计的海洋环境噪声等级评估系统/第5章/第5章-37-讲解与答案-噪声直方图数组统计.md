## 二、预备知识：分区间频数统计的基本原理（零基础阅读）

### 1. 问题是怎么来的

水听器记下 12 个噪声级：

```
63.5  71.2  68.9  84.3  92.6  75.8  66.4  88.1  79.5  95.3  72.7  61.8
```

光看这串数很难说出"噪声整体偏大还是偏小"。把 [60, 100] 切成 4 个 10 dB 宽的区间，数一数每个区间落了几个样本，分布就一目了然——这就是**直方图**。综合实验 C9 用它做噪声等级评估的第一步（M3），后续的累积分布（M4）、95% 分位数（M5）都建立在这张频数表上。

### 2. 公式推导

**频数**：第 $k$ 个区间 $[a_k, a_{k+1})$ 的频数定义为

$$f_k = \#\{\, i \mid a_k \le x_i < a_{k+1} \,\}, \qquad k = 0, 1, 2, 3$$

最后一个区间 $[90, 100]$ 右端**闭合**（100.0 也要被统计）。约定 $f_0 + f_1 + f_2 + f_3 = n$（所有样本都落进区间时）。

**占比**（经验频率）：

$$p_k = \frac{f_k}{n} \times 100\%$$

四项占比之和应为 100%（四舍五入后可能差 0.1%，属正常现象）。

**区间归属判定的 else-if 链**：把条件按从小到大排成链

$$x < 70 \Rightarrow k=0;\quad \text{否则 } x < 80 \Rightarrow k=1;\quad \text{否则 } x < 90 \Rightarrow k=2;\quad \text{否则 } k=3$$

因为 `else` 保证"前面的没成立才到这里"，所以走到第 2 个分支时自动有 $x \ge 70$——每个区间只写一个上界就够，不会重复计数，也不会漏。

### 3. 代入本例

样例 1 的 12 个样本逐个归箱：

| 区间 | 落入的样本 | 频数 | 占比 |
|---|---|---|---|
| [60,70) | 63.5, 68.9, 66.4, 61.8 | 4 | 4/12 = 33.3% |
| [70,80) | 71.2, 75.8, 79.5, 72.7 | 4 | 33.3% |
| [80,90) | 84.3, 88.1 | 2 | 16.7% |
| [90,100] | 92.6, 95.3 | 2 | 16.7% |

合计 4+4+2+2 = 12 = n ✓。边界检查：79.5 < 80 → 区间 1（不是 2）；100.0 若出现则 ≥ 90 → 区间 3（样例 2 验证）。

占比按 IEEE-754 double 复算：4/12 = 0.3333… → `%.1f` 输出 `33.3`；2/12 = 0.1666… → `16.7`；0/12 → `0.0`；2/3 → `66.7`。

### 4. 编程翻译

| 数学动作 | C 语言翻译 |
|---|---|
| 4 个计数器 $f_0 \sim f_3$ | `int freq[4] = {0,0,0,0};`（数组当计数器） |
| 归类判定 | `if / else if / else` 链，`freq[k]++` |
| 非法样本 | `if (x < 60 || x > 100) { 警告; continue; }` |
| $p_k$ | `(double)freq[k] / n * 100` |

**"数组当计数器"是关键思想**：4 个区间如果用 `f0, f1, f2, f3` 四个变量，归类就要写 4 段几乎一样的代码；用 `freq[4]` 后，判定分支里只改下标，将来扩到 8 个区间只需把数组开大、分支拉长，骨架不变。

## 三、解题思路

1. **读入**：`n` 与 `n` 个噪声级进 `ns[]`；
2. **清零计数器**：`freq` 初始化为 0（局部数组不清零会读到垃圾值）；
3. **一遍循环归箱**：先查范围（越界则警告并 `continue`），再走 else-if 链 `freq[k]++`；
4. **输出**：4 行频数与占比，占比用 `(double)freq[k] / n * 100`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double ns[200];                 /* 噪声级序列(dB) */
    int freq[4] = {0, 0, 0, 0};     /* 分箱计数器数组 */
    int n, i, k;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf", &ns[i]);
    }

    for (i = 0; i < n; i++) {                       /* 一遍循环归箱 */
        if (ns[i] < 60.0 || ns[i] > 100.0) {        /* 范围检查 */
            printf("警告：样本 %.2f 超出统计范围\n", ns[i]);
            continue;                               /* 跳过该样本 */
        }
        if (ns[i] < 70.0) {
            freq[0]++;              /* 60 ≤ x < 70 */
        } else if (ns[i] < 80.0) {
            freq[1]++;              /* 70 ≤ x < 80 */
        } else if (ns[i] < 90.0) {
            freq[2]++;              /* 80 ≤ x < 90 */
        } else {
            freq[3]++;              /* 90 ≤ x ≤ 100 */
        }
    }

    for (k = 0; k < 4; k++) {                       /* 输出频数表 */
        if (k < 3) {
            printf("[%d,%d) : %d 个  %.1f%%\n",
                   60 + 10 * k, 70 + 10 * k, freq[k],
                   (double)freq[k] / n * 100);
        } else {
            printf("[%d,%d] : %d 个  %.1f%%\n",
                   90, 100, freq[k],
                   (double)freq[k] / n * 100);
        }
    }
    return 0;
}
```

## 五、运行验证

**第一次运行**（样例 1）：

输入：
```
12
63.5 71.2 68.9 84.3 92.6 75.8 66.4 88.1 79.5 95.3 72.7 61.8
```
输出：
```
[60,70) : 4 个  33.3%
[70,80) : 4 个  33.3%
[80,90) : 2 个  16.7%
[90,100] : 2 个  16.7%
```

数值核对（按 IEEE-754 double 与 `printf("%.1f")` 舍入复算）：4/12×100 = 33.333… → `33.3`；2/12×100 = 16.666… → `16.7`。✓

**第二次运行**（样例 2，边界值）：

输入：
```
3
99.9 60.0 100.0
```
输出：
```
[60,70) : 1 个  33.3%
[70,80) : 0 个  0.0%
[80,90) : 0 个  0.0%
[90,100] : 2 个  66.7%
```
✓ 60.0 走到第一个分支（`< 70` 成立）进区间 0；100.0 前三个分支都不成立，进 `else`（区间 3）。

**反例验证**：追加输入一个 `55.0`，程序打印 `警告：样本 55.00 超出统计范围`，且不进入任何区间——范围检查与 `continue` 生效。

## 六、常见错误与讲解

**错误 1：计数器数组没清零**

```c
int freq[4];            /* 局部数组初值是内存垃圾！ */
...
printf("%d", freq[0]);  /* 输出可能是 -858993460（VS 调试态）之类的随机值 */
```

写 `int freq[4] = {0};`（只需给第一个元素 0，其余自动补 0）或用循环清零。

**错误 2：整数除法把占比算成 0**

```c
printf("%.1f%%", freq[k] / n * 100);       /* 错：freq[k]/n 是整数除法，4/12 = 0 */
printf("%.1f%%", (double)freq[k] / n * 100); /* 对：先转 double 再除 */
```

**错误 3：区间端点写重叠或开闭搞错**

```c
if (x >= 60 && x <= 70) freq[0]++;      /* 70.0 同时满足区间 0 和区间 1 的条件 */
if (x >= 70 && x <= 80) freq[1]++;      /* 若用独立 if，70.0 会被计两次！ */
```

四个**独立 if** 遇到恰好落在端点的样本会重复计数。用 **else-if 链**天然互斥，一个样本只进一个分支。

**错误 4：忘了处理越界样本，直接掉进所有分支之外**

```c
if (x < 70) freq[0]++;
else if (x < 80) freq[1]++;
else if (x < 90) freq[2]++;
else freq[3]++;        /* x = 55 也会走到这里！被计入 [90,100] */
```

所以范围检查必须**放在归箱之前**（或把第一个分支写成 `x >= 60 && x < 70`）。

## 七、与综合实验的衔接

- 实验 **C9（基于分区间统计的海洋环境噪声等级评估系统）**中，"区间频数统计（M3）→ 累积分布（M4）→ 排序求 95% 分位数（M5）→ 超阈值占比（M6）"是一条流水线：本题完成了 M3 的频数表；累积分布只需在频数表上做一次"前缀和"（`cum[k] = cum[k-1] + freq[k]`）；超阈值占比是把"落入 (阈值, 100]"的频数累加再除以 n——三步都建立在本题的数组分箱骨架上；
- 与其他实验衔接：实验 **C6** 的"阈值跳变判决"是本题"范围检查"的推广（对**差分**序列判阈值）；第 6 章练习 33 用指针返回均值与方差时，同样的 else-if 归类骨架照用。分箱统计是"把连续量离散化"的通用手段，在所有"等级评估/直方图/累积分布"类实验中都会遇到。
