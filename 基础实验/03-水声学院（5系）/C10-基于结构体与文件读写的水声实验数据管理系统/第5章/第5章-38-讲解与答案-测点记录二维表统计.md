## 二、预备知识：二维表行列统计的基本原理（零基础阅读）

### 1. 问题是怎么来的

3 个测站 × 4 个时刻的声速表：

| | 时刻1 | 时刻2 | 时刻3 | 时刻4 |
|---|---|---|---|---|
| 测站1 | 12.4 | 13.1 | 12.8 | 13.6 |
| 测站2 | 11.2 | 12.0 | 11.8 | 12.5 |
| 测站3 | 14.1 | 14.8 | 15.2 | 14.6 |

表格型数据用**二维数组**存：`v[i][j]`，第一个下标是行（测站）、第二个下标是列（时刻）。要对它做两种汇总：**横着算**（每行平均 → 测站水平）和**竖着算**（每列平均 → 时间水平）。综合实验 C10 的统计汇总模块（M8）对"测站 × 时刻"记录做同样的行列统计，只是数据容器升级为结构体数组。

### 2. 公式推导

行均值（第 $i$ 个测站的平均声速）：

$$\bar{v}^{(r)}_i = \frac{1}{n}\sum_{j=0}^{n-1} v_{ij}$$

列均值（第 $j$ 个时刻的平均声速）：

$$\bar{v}^{(c)}_j = \frac{1}{m}\sum_{i=0}^{m-1} v_{ij}$$

最高测站：

$$i^\* = \arg\max_i \bar{v}^{(r)}_i \quad (\text{并列取最小 } i)$$

注意两个公式的**求和方向不同**：行均值固定 $i$、对 $j$ 求和；列均值固定 $j$、对 $i$ 求和。编程上就是把两层循环的外内层对调。

### 3. 代入本例

**按行**（分母 n = 4）：

- 测站 1：12.4+13.1+12.8+13.6 = 51.9，51.9/4 = 12.975 → `12.97`（double 中 51.9/4 的二进制表示略小于 12.975，`%.2f` 舍入为 12.97）；
- 测站 2：11.2+12.0+11.8+12.5 = 47.5，47.5/4 = 11.875 → `11.88`；
- 测站 3：14.1+14.8+15.2+14.6 = 58.7，58.7/4 = 14.675 → `14.68`。

**按列**（分母 m = 3）：

- 时刻 1：(12.4+11.2+14.1)/3 = 37.7/3 = 12.5667 → `12.57`；
- 时刻 2：39.9/3 = 13.3000 → `13.30`；
- 时刻 3：39.8/3 = 13.2667 → `13.27`；
- 时刻 4：40.7/3 = 13.5667 → `13.57`。

**最高测站**：三个行均值 12.97 / 11.88 / 14.68 中最大是测站 3 → `第 3 号`。

以上全部数值已按 IEEE-754 double 与 `printf("%.2f")` 舍入规则用程序复算核对。

### 4. 编程翻译

| 数学动作 | C 语言翻译 |
|---|---|
| 存 $m \times n$ 表 | `double v[10][10];` 两层循环 `scanf("%lf", &v[i][j]);` |
| $\bar v^{(r)}_i$ | 外层 `i`、内层 `j`，`rowsum += v[i][j]`，除以 `n` |
| $\bar v^{(c)}_j$ | 外层 `j`、内层 `i`，`colsum += v[i][j]`，除以 `m` |
| $i^\*$ | 按行循环里对 `rowsum / n` 打擂台 |

> **"循环对调"是二维统计的通用技巧**：同一张表，外内层对调一次，就完成了另一个方向的统计。C10 的"各测站均值、极值汇总"、实验 C7 的"按小时段统计潮位"，都是这个模式的不同皮肤。

## 三、解题思路

1. **读入**：`m`、`n`，两层循环读入 `v[i][j]`；
2. **按行统计 + 打擂台**：外层测站 `i`，内层时刻 `j` 累加 `rowsum`；算出 `rowsum / n` 输出，并与当前最大行均值比较（初值取第 0 行均值，记录 `best` 下标）；
3. **按列统计**：外层时刻 `j`，内层测站 `i` 累加 `colsum`，除以 `m` 输出；
4. **输出最高测站**：`printf("声速最高测站：第 %d 号\n", best + 1);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double v[10][10];       /* 二维数组：v[i][j] = 测站 i 时刻 j 的声速 */
    double rowsum, colsum, maxavg;
    int m, n, i, j, best;

    scanf("%d %d", &m, &n);                 /* 测站数、时刻数 */

    for (i = 0; i < m; i++) {               /* 按行读入二维表 */
        for (j = 0; j < n; j++) {
            scanf("%lf", &v[i][j]);
        }
    }

    /* ① 按行统计：各测站平均声速（同时打擂台找最高测站） */
    printf("各测站平均声速：\n");
    for (i = 0; i < m; i++) {
        rowsum = 0;
        for (j = 0; j < n; j++) {           /* 行不变、列变 → 累加一行 */
            rowsum += v[i][j];
        }
        printf("测站 %d 平均声速 = %.2f m/s\n", i + 1, rowsum / n);
        if (i == 0 || rowsum / n > maxavg) {    /* 打擂台（并列时取先者=小编号） */
            maxavg = rowsum / n;
            best = i;
        }
    }

    /* ② 按列统计：各时刻平均声速（循环方向对调） */
    printf("各时刻平均声速：\n");
    for (j = 0; j < n; j++) {
        colsum = 0;
        for (i = 0; i < m; i++) {           /* 列不变、行变 → 累加一列 */
            colsum += v[i][j];
        }
        printf("时刻 %d 平均声速 = %.2f m/s\n", j + 1, colsum / m);
    }

    printf("声速最高测站：第 %d 号\n", best + 1);
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：行列下标写反**

```c
rowsum += v[j][i];   /* 错：按行统计时行标是外层 i、列标是内层 j */
rowsum += v[i][j];   /* 对 */
```

m ≠ n 时 `v[j][i]` 还会越界访问 `v[j][i]` 中超出 `v[10][10]` 声明范围的组合（本题 m、n ≤ 10 尚在内存里，但读到的是别的行的数据——结果悄悄错掉）。

**错误 2：内层累加器没清零**

```c
for (i = 0; i < m; i++) {
    for (j = 0; j < n; j++) { colsum += v[i][j]; }   /* 错：colsum 在哪清的？ */
}
```

`colsum = 0;` 必须放在**外层循环体内、内层循环之前**——每换一行/列都要重新清零；放在所有循环之前则第二个测站会把第一个的累计带上。

**错误 3：按行/按列分母用错**

```c
printf("%.2f", rowsum / m);   /* 错：行均值分母是列数 n */
printf("%.2f", rowsum / n);   /* 对；列均值分母是行数 m */
```

**错误 4：打擂台初值设为 0 且比较条件写 `>=`**

```c
if (rowsum / n >= maxavg) { ... }   /* 并列时后者胜 → 输出大编号，违背题意 */
```

初值取第 0 行均值、比较用严格 `>`，并列时自然保留先出现的小编号。
