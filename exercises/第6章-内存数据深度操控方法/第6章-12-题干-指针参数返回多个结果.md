# 第 6 章 练习 12　指针参数返回多个结果

**对应章节**：6 内存数据深度操控方法（6.5 指针与函数——指针作参数把多个结果写回调用者）

**场景来源**：综合实验 C7《基于冲量-动量反演的冰阻力与碰撞事件辨识系统》（水声学院）——本练习是该实验中"载荷样本统计量汇总"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

船体某一测点在冰区航行中会采回一条完整的阻力样本序列。做数据辨识前，工程师总要先把这条序列的三个"体检指标"抽出来：平均阻力是多少、最大阻力是多少、最小阻力是多少。麻烦在于，一个函数用 `return` 一次只能交回一个数，而这里需要三个。C 语言的标准做法是：让函数返回类型为 `void`，把三个结果变量**的地址**当参数传进去，函数在内部顺着地址把结果分别写回到调用者的变量里。本练习实现这个"一次回传多个结果"的统计函数。

## 二、任务要求

编写一个完整程序 `multi_result.c`：

1. 主函数读入样本数 `n`（题目保证 $1 \le n \le 50$），再读入 `n` 个阻力值（单位 kN）存入 `double a[50]`；
2. 编写函数，其原型为 `void stat(double *a, int n, double *mean, double *max, double *min);`，它**不通过 `return`**，而是分别把均值、最大值、最小值写入 `*mean`、`*max`、`*min` 所指的变量；
3. 主函数传入 `&mean`、`&mx`、`&mn` 三个变量的地址，调用后按格式输出三个结果，均保留 4 位小数。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（空格分隔）。

**输出**：一行，格式为 `mean = <均值> max = <最大值> min = <最小值>`，每个数保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
5
10 20 30 40 50
```
输出：
```
mean = 30.0000 max = 50.0000 min = 10.0000
```

**样例 2**

输入：
```
3
2.5 8.5 6.0
```
输出：
```
mean = 5.6667 max = 8.5000 min = 2.5000
```

## 五、提示

- 函数里写 `*mean = sum / n;`，就是"往 `mean` 这个地址所指的抽屉里放数据"，等价于在主函数里写 `mean = sum / n;`；
- 求最值时先用首元素 `a[0]` 初始化最大值、最小值，再从第 2 个元素开始比较；
- 均值公式：$\bar{x} = \dfrac{1}{n}\sum_{i=0}^{n-1} x_i$。

**完成本练习后你将具备的能力**：彻底理解"形参是实参的副本、改形参改不了实参"这一值传递限制，学会用指针参数突破它、一次把多个结果写回调用者——这是实验 C7 中"统计量计算模块"的地基。
