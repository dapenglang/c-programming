## 二、预备知识：结构体数组——把"一张表"整整齐齐存下来（零基础阅读）

### 1. 为什么不建两个平行数组

如果不用结构体，就要建两个数组：`int id[100]` 存编号、`double load[100]` 存载荷。它们靠**下标相同**来表示"同一条记录"。这种写法有两个隐患：

- **容易错位**：万一排序时只交换了 `load` 忘了交换 `id`，编号和载荷就对不上了；
- **不便整体传递**：想把"一个测点"传给函数，得同时传两个数组下标。

结构体数组把"一条记录"变成"一个元素"，编号和载荷**永远捆在一起**，从根本上避免了错位：

```c
struct IceLoad { int id; double load; };
struct IceLoad a[100];       /* 最多 100 条记录 */
```

访问第 `i` 条记录的载荷就写 `a[i].load`，编号写 `a[i].id`。可以把它想象成一张"测点台账"，每一行是一个结构体，下标就是行号。

```
下标 i :   a[i].id    a[i].load
   0        101         12.0
   1        102         25.0
   2        103          8.0
   …
```

### 2. 遍历结构体数组 = 逐行处理台账

结构体数组的遍历和普通数组完全一样，只是每次访问的是"元素的某个成员"：

```c
for (i = 0; i < n; i++) {
    sum += a[i].load;                 /* 累加载荷 */
    if (a[i].load >= limit) over++;   /* 条件计数 */
}
```

结构体数组既有数组"能按下标随机访问、长度固定"的优点，又有结构体"把多条属性绑成一体"的优点，是"记录条数已知"时最顺手的容器。

### 3. 最值模板：值和编号要一起记

求最大 / 最小值时，最容易出的错是**只记住了最大值，却忘了它是哪条记录**。正确模板是**用两个变量同步更新**：

```c
max = a[0].load;  maxId = a[0].id;        /* 先拿第 0 条当擂主 */
for (i = 1; i < n; i++) {
    if (a[i].load > max) {                /* 遇到更大的 */
        max   = a[i].load;                /* 值和编号一起换 */
        maxId = a[i].id;
    }
}
```

最小值同理，把 `>` 换成 `<` 即可。**从下标 1 开始比**，因为下标 0 已经当过初始擂主。这样走完一遍，`max`、`maxId`、`min`、`minId` 就都齐了。

### 4. 报表输出的三个注意点

- **格式必须逐字符对齐**：表头、单位 `kN`、括号、等号都是题目规定的一部分，多一个空格就可能与判题不符；
- **小数位数**：载荷与均值用 `%.2f`，编号用 `%d`；
- **阈值在报表里也要显示**：末行的阈值用 `%.2f` 打印，与输入保持一致（如 `>= 20.00 kN`）。

平均值用 `double` 累加后再除，`n ≥ 1` 保证不会除零。

## 三、解题思路

1. **定义结构体与数组**：`struct IceLoad a[100];`；
2. **读入**：循环 `n` 次，读 `a[i].id`、`a[i].load`；再读阈值 `limit`；
3. **初始化**：`sum = 0; over = 0;`，`max = min = a[0].load`，`maxId = minId = a[0].id`；
4. **一次遍历统计**：从 `i = 0` 到 `n-1` 累加、判超阈；从 `i = 1` 起比较更新最值与编号；
5. **算平均**：`mean = sum / n;`；
6. **输出报表**：按六行格式依次打印。

## 四、参考代码

```c
#include <stdio.h>

struct IceLoad {
    int    id;      /* 测点编号 */
    double load;    /* 载荷，kN */
};

int main(void)
{
    struct IceLoad a[100];
    int n, i, maxId, minId, over;
    double limit, sum, mean, max, min;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d %lf", &a[i].id, &a[i].load);
    scanf("%lf", &limit);

    sum = 0.0;
    over = 0;
    max = min = a[0].load;          /* 最值先取第 0 条 */
    maxId = minId = a[0].id;
    for (i = 0; i < n; i++) {
        sum += a[i].load;               /* 累加 */
        if (a[i].load >= limit) over++; /* 超阈计数 */
        if (a[i].load > max) { max = a[i].load; maxId = a[i].id; }
        if (a[i].load < min) { min = a[i].load; minId = a[i].id; }
    }
    mean = sum / n;

    printf("===== 冰场载荷统计报表 =====\n");
    printf("样本数 = %d\n", n);
    printf("最大载荷 = %.2f kN (编号 %d)\n", max, maxId);
    printf("最小载荷 = %.2f kN (编号 %d)\n", min, minId);
    printf("平均载荷 = %.2f kN\n", mean);
    printf("超阈样本数(>= %.2f kN) = %d\n", limit, over);

    return 0;
}
```

## 五、运行验证

以样例 1 的结构体数组（5 条记录）为例，遍历统计结果：

| 记录 | load | sum | 是否 ≥ 20 | 当前 max（编号） | 当前 min（编号） |
|---|---|---|---|---|---|
| 101 | 12.0 | 12.0 | 否 | 12.0 (101) | 12.0 (101) |
| 102 | 25.0 | 37.0 | 是 | 25.0 (102) | 12.0 (101) |
| 103 | 8.0 | 45.0 | 否 | 25.0 (102) | 8.0 (103) |
| 104 | 40.0 | 85.0 | 是 | 40.0 (104) | 8.0 (103) |
| 105 | 15.0 | 100.0 | 否 | 40.0 (104) | 8.0 (103) |

最终 `sum = 100.00`、`mean = 100.00/5 = 20.00`、`max = 40.00` (编号 104)、`min = 8.00` (编号 103)、`over = 2`，输出：

```
===== 冰场载荷统计报表 =====
样本数 = 5
最大载荷 = 40.00 kN (编号 104)
最小载荷 = 8.00 kN (编号 103)
平均载荷 = 20.00 kN
超阈样本数(>= 20.00 kN) = 2
```

与样例 1 一致。样例 2 中三笔载荷 `30.00`、`12.00`、`18.00` 之和为 `60.00`，均值 `20.00`；最大 `30.00` (编号 1)、最小 `12.00` (编号 2)，只有 `30.00` 满足 $\ge 20$ 故 `over = 1`，输出与样例 2 一致。

## 六、常见错误与讲解

**错误 1：求最值时忘记同步记录编号**

```c
if (a[i].load > max) max = a[i].load;   /* 错：maxId 没更新，输出旧编号 */
```
只更新了值没更新编号，报表里的"(编号 …)"就会和最大载荷对不上。**值和编号必须在同一个 `if` 里一起更新**。

**错误 2：最大、最小值的初始值取错**

```c
double max = 0;    /* 错：若所有载荷都小于 0（本场景不会），或忘初始化为 a[0] */
```
用 0 初始化 `max` 在本例碰巧可以，但若数据全为负数就全错。**稳妥写法是拿 `a[0]` 当初始擂主，并从下标 1 开始比较。**

**错误 3：最小值比较写成 `>`**

```c
if (a[i].load > min) { min = a[i].load; }   /* 错：这是求最大 */
if (a[i].load < min) { min = a[i].load; }   /* 对 */
```
求最小值用 `<`。方向写反会得到与最大值相同的结果。

**错误 4：报表格式和样例不一致**

```c
printf("最大载荷=%.2f kN (编号%d)\n", max, maxId);   /* 错：逗号/空格与样例不符 */
printf("最大载荷 = %.2f kN (编号 %d)\n", max, maxId); /* 对 */
```
等号两边、`kN` 前后、括号内的空格都要照抄样例。判题往往逐字符比对，格式错会被判为答案错误。
