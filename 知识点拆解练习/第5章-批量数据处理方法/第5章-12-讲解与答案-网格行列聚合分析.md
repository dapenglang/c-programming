## 二、预备知识：行优先与列优先两种遍历顺序（零基础阅读）

### 1. 同一张表，两种"走法"

练习 11 已经讲过：二维数组在内存里是**一行接一行**排的（行优先存储），元素 `p[i][j]` 的位置是 $i \times n + j$。现在要对同一张表做两件不同的事：

- 求**行和**：把"横着的一行"加起来 → 自然的走法是**固定行、走遍列**；
- 求**列和**：把"竖着的一列"加起来 → 需要**跨过所有行**，把每行的同一个列号挑出来累加。

这两种走法对应两种循环嵌套：**行优先**是外层行 `i`、内层列 `j`（`for(i...) for(j...)`），**列优先**是外层列 `j`、内层行 `i`（`for(j...) for(i...)`）。两段代码访问的是同一批元素，只是**顺序不同**。

### 2. 行和为什么顺理成章

求第 $i$ 行行和时，行号 $i$ 固定，只有列号 $j$ 在变，累加器只需要一个：

$$
\text{rowSum}_i = p[i][0] + p[i][1] + \cdots + p[i][n-1]
$$

这就是"外层行、内层列"，每个 $i$ 各配一个 `rowSum[i]`。

### 3. 列和为什么容易写错

求第 $j$ 列列和时，列号 $j$ 固定、行号 $i$ 在变：

$$
\text{colSum}_j = p[0][j] + p[1][j] + \cdots + p[m-1][j]
$$

列和有两种写法：

- **写法 A（外层列、内层行）**：`for(j...) { for(i...) colSum[j]+=p[i][j]; }`，最直观，但访问顺序与内存的行优先顺序相反，跳着访问；
- **写法 B（行优先一次搞定）**：`for(i...) for(j...) colSum[j]+=p[i][j];`，按内存顺序走一遍，每个元素顺手加进"它所属列"的累加器里。

两种写法结果完全相同。特别注意写法 B 里累加器的下标必须是 `j`（列号），如果手滑写成 `colSum[i]`，就变成"每行和收进了前 $n$ 个格子"，结果全错。

### 4. 累加前必须先清零

无论行和还是列和，累加器在使用前都要置 0，如 `for (j = 0; j < n; j++) colSum[j] = 0.0;`。局部数组若不初始化，里面是**内存残留的随机值**，直接累加会得到奇怪的数。这是初学者第二大坑。

### 5. 输出时怎么控制空格

一行要打印多个数值，若写成 `printf("%.2f ", x)` 会漏出一个行末空格。规范写法是**先打印标签和第一个值，再在循环里给每个后续值前面加空格**：`printf("行和:"); for (i = 0; i < m; i++) printf(" %.2f", rowSum[i]);`。这样输出正好是 `行和: 410.00 426.00 442.00`，格式干净、可判分。

## 三、解题思路

1. **定容量**：`double p[20][20];`，另建 `double rowSum[20], colSum[20];`；
2. **读入网格**：双重循环按行优先读入 `p[i][j]`；
3. **求行和**：外层 `for(i)`，内层 `for(j)` 把本行元素累加进 `rowSum[i]`；
4. **求列和**：先把 `colSum[0..n-1]` 清零，再走一遍网格，把 `p[i][j]` 累加进 `colSum[j]`；
5. **输出两行**：用"标签 + 首个值 + 循环补空格"的方式输出 `rowSum` 和 `colSum`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double p[20][20];              /* 压力网格 */
    double rowSum[20], colSum[20]; /* 行和、列和 */
    int m, n, i, j;

    scanf("%d %d", &m, &n);
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            scanf("%lf", &p[i][j]);

    /* 行和：外层行、内层列，每行各配一个累加器 */
    for (i = 0; i < m; i++) {
        rowSum[i] = 0.0;
        for (j = 0; j < n; j++)
            rowSum[i] += p[i][j];
    }

    /* 列和：先清零，再按行优先把每个元素累加到它所属的列 */
    for (j = 0; j < n; j++)
        colSum[j] = 0.0;
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            colSum[j] += p[i][j];   /* 注意下标是 j（列号） */

    /* 输出行和 */
    printf("行和:");
    for (i = 0; i < m; i++)
        printf(" %.2f", rowSum[i]);
    printf("\n");

    /* 输出列和 */
    printf("列和:");
    for (j = 0; j < n; j++)
        printf(" %.2f", colSum[j]);
    printf("\n");

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：行列下标混淆，列和写成行和**

```c
colSum[i] += p[i][j];    /* 错：把列累加器的下标写成了行号 i */
colSum[j] += p[i][j];    /* 对：累加到第 j 列 */
```

判断方法很直接：**在行优先的双重循环里，行号 $i$ 不用作累加器下标，列号 $j$ 才是**。写完后可用样例 1 手算列和对照。

**错误 2：累加器忘记清零**

```c
double colSum[20];                /* 未初始化 */
for (i=0;i<m;i++) for (j=0;j<n;j++) colSum[j]+=p[i][j];  /* 错：从随机值开始加 */
```

`colSum` 是局部自动数组，初值是不确定的。养成"累加前先 `= 0`"的习惯。

**错误 3：循环边界用了容量 20 而不是实际行列数**

```c
for (i = 0; i < 20; i++) ...      /* 错：多遍历了 20-m 行垃圾单元 */
for (i = 0; i < m; i++) ...       /* 对：上界用实际行数 m */
```

上界一律用 `m`（行）或 `n`（列），不要用容量。

**错误 4：输出格式多空格 / 少空格**

```c
printf("行和: ");
for (i = 0; i < m; i++) printf("%.2f ", rowSum[i]);   /* 错：行末多一个空格 */
printf("行和:");
for (i = 0; i < m; i++) printf(" %.2f", rowSum[i]);   /* 对：空格放在值前面 */
```

严格的在线判题会因为行末空格判错，务必按样例对齐。

## 七、与综合实验的衔接

- 实验 **C9（冰面压力场热点分析系统）**中，"载荷聚合"模块同时需要行和与列和：行和用于绘制沿某一方向的载荷分布曲线，列和用于绘制垂直方向的分布曲线，二者共同决定热点图的着色范围。本练习把练习 11 的"单方向逐行统计"升级为"双方向聚合"，正是该模块的核心算法；
