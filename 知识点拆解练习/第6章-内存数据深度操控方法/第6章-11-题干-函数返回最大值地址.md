# 第 6 章 练习 11　函数返回最大值地址

**对应章节**：6 内存数据深度操控方法（6.3 指针与数组、6.5 指针与函数）

**场景来源**：综合实验 C9《基于二维网格统计的冰压力场分析与可视化系统》（水声学院）——本练习是该实验中"测点压力峰值定位"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区结构表面布有一排压力测点，一次测试会采回一整条测点压力序列。工程上工程师最关心的往往不只是"最大压力是多少"，而是"最大压力出现在第几个测点"——峰值位置直接决定结构的危险截面在哪里。如果查找函数只把峰值这个数值交回来，位置信息就丢了；如果让函数把最大元素所在的**内存地址**交回来，调用者拿到地址后既能用 `*p` 读出峰值，又能用 `p - a` 反推出它相对数组首元素的下标。本练习就来实现这个"返回地址而非返回值"的查找函数。

## 二、任务要求

编写一个完整程序 `max_addr.c`：

1. 主函数中先用 `scanf` 读入测点数 `n`（题目保证 $1 \le n \le 50$），再依次读入 `n` 个压力值（单位 kPa）存入数组 `double a[50]`；
2. 编写函数，其原型为 `double *find_max(double *a, int n);`，用**指针**遍历数组，返回最大元素所在内存单元的**地址**（若最大值出现多次，返回第一个）；
3. 主函数用返回的指针 `p` 输出最大值 `*p`（保留 4 位小数），并用 `p - a` 输出该峰值所在测点的下标（从 0 开始计数）。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（空格分隔）。

**输出**：一行，格式为 `max = <最大值> at index <下标>`，其中最大值保留 4 位小数，下标为整数。

## 四、样例

**样例 1**

输入：
```
5
12.5 30.2 8.4 25.7 21.0
```
输出：
```
max = 30.2000 at index 1
```

**样例 2**

输入：
```
5
5.5 4.2 9.8 7.1 6.3
```
输出：
```
max = 9.8000 at index 2
```

## 五、提示

当 `p` 指向数组的某个元素时：

- `*p` 就是这个元素的值；
- `p - a` 是它与数组首元素 `a` 之间相隔的元素个数，也就是它的下标（指针相减按**元素个数**计，不是字节数）。

在遍历过程中保存"最大元素的地址"而不是"最大值"：先令 `best = a`，再逐个比较，只要 `*p > *best` 就令 `best = p`。循环结束后 `best` 就是最大元素所在地址。

**完成本练习后你将具备的能力**：理解"函数返回指针"的含义、掌握用指针遍历数组并比较元素值、学会用地址之差 `p - a` 求下标——这是实验 C9 中"峰值定位模块"的地基。
