# 第 7 章 练习 09　嵌套结构体测点表

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.2 结构体数组）

**场景来源**：综合实验 C9《冰压力场网格分析系统》（水声学院）——本练习是该实验中"板面-测点两级数据组织"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰压力场分析系统（实验 C9）监测船体外板上多个测点的冰压力。数据天然分成两层：一块外板（板面）上布置若干个**测点**，每个测点有自己的编号与压力值；分析报告常常问"这块板上哪个测点压力最大？"。描述"板面"用一个结构体，而这个结构体的成员之一是"测点数组"——每个数组元素又是一个小结构体。这种"结构体里套结构体（数组）"的组织方式叫**嵌套结构体**，访问时点号连用、逐层深入，是 C9 测点表的标准数据组织形式。

## 二、任务要求

编写一个完整程序 `panel_max.c`：

1. 按下面的框架定义两级结构体（成员名不得改动）：

```c
struct MeasPoint {
    int    no;        /* 测点编号（1~4） */
    double pressure;  /* 冰压力（MPa） */
};

struct Panel {
    int    id;                  /* 板面编号 */
    struct MeasPoint pts[4];    /* 该板面上的 4 个测点 */
};
```

2. `main` 中定义一个 `struct Panel` 变量，读入板面编号与 4 个测点的压力值（测点编号在程序中自动置为 1～4）；
3. 遍历测点数组，找出**压力最大**的测点；
4. 按格式输出板面编号、最大压力测点的编号与压力值。

## 三、输入输出格式

**输入**：一行，5 个数据：板面编号（整数）、4 个测点压力（实数，MPa），以空格分隔。

**输出**：一行，格式为 `板面 ID 压力最大测点：N 号，压力 P MPa`，压力保留 **2 位小数**。

## 四、样例

**样例 1**

输入：
```
2 1.20 0.85 1.56 1.02
```
输出：
```
板面 2 压力最大测点：3 号，压力 1.56 MPa
```

**样例 2**

输入：
```
5 0.90 1.31 1.05 0.77
```
输出：
```
板面 5 压力最大测点：2 号，压力 1.31 MPa
```

## 五、提示

- 两级访问：`panel.pts[i].pressure`——先点号进板面成员 `pts`，再下标选测点，再点号进测点成员；
- 测点编号不必读入：读入循环里写 `panel.pts[i].no = i + 1;` 即可；
- 打擂台求最大：擂台初值取 `pts[0].pressure`，同时记下该测点的编号；
- 若压力相并列，输出编号最小的一个（用严格大于比较即可做到）。

**完成本练习后你将具备的能力**：定义嵌套结构体、用"点号 + 下标 + 点号"逐层访问内层成员、在两级数据组织中完成查找统计——实验 C9 的板面测点表、网格数据组织都建立在嵌套封装上。
