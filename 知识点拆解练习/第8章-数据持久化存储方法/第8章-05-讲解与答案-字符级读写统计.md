## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

程序里的变量"一停就没"，要长期保存的文本必须落盘。本题要处理的是**一篇文章**：一长串字符。既然处理的对象是"字符"，读它时也应当以**字符**为单位——一个字符一个字符地扫过去，才不会漏掉任何一个空格或换行。C 语言里负责"读一个字符"的函数就是 `fgetc`。

### 2. 文件操作的标准四步曲

文件操作永远是同一条流水线：

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题用 `fgetc` 读字符、`fprintf` 写结果；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 它是这次文件访问的"编号牌"，指向系统为该文件建立的记录（文件在哪、当前进行到哪、是读还是写）；记录里的**文件位置指针**标明"现在读到第几个字节"，每读一个字符就自动向前推一格。

**打开失败会怎样？** 文件不存在或无权限时 `fopen` 返回 `NULL`，不判空就用会崩溃，因此打开后**必须**紧跟：

```c
if (fin == NULL) { printf("打不开 text.txt\n"); return 1; }
```

### 3. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理（词频、统计） |
| `fgets` | 读一整行 | `fgets(buf, sizeof(buf), fp);` | 一行里有字符串、需整行处理 |
| `fscanf` | 按格式读 | `fscanf(fp, "%d%lf", &id, &v);` | 纯数字、格式规整的文本 |
| `fprintf` | 按格式写 | `fprintf(fp, "字母 %d\n", n);` | 把数字按人可读格式写进文本 |
| `fread`/`fwrite` | 按字节块读写 | `fread(a, sizeof(double), n, fp);` | 二进制文件、批量存数组 |

本题要"一个字符都不漏地统计"，正是 `fgetc` 的标准用途。**关键细节：`fgetc` 的返回值要用 `int` 接收。** 因为字母的字符码是正数，而文件结束标志 `EOF` 是负数（通常是 -1）；如果用 `char` 接收，某些字符码可能与 `EOF` 混淆，导致漏统计或死循环。记住一句话：**`fgetc` 的返回值存进 `int`**。

### 4. 打开模式的区别

| 模式 | 含义 | 文件已存在时 |
|---|---|---|
| `"r"` | 只读文本 | 从文件头开始读，不存在则失败 |
| `"w"` | 只写文本 | 清空原有内容，从头开始写 |
| `"a"` | 追加文本 | 保留原有内容，从末尾接着写 |
| `"rb"`/`"wb"` | 二进制只读/只写 | 同上，但按二进制方式处理 |

读文本用 `"r"`；结果文件是每轮重新统计，用 `"w"` 生成新结果即可。

### 5. 用本题的数据走一遍文件指针

样例文件内容（`\n` 表示换行）：

```
I c e   l o a d   2 0 2 6 \n
s h i p   3   k n o t s \n
```

打开后位置指针指向第一个字符 `I`。`fgetc` 读 `I` 返回其字符码，`isalpha` 为真，`letters` 加 1、`total` 加 1，指针移到 `c`；接着读 `c`、`e` 仍是字母；读到空格，两个判断都不成立，落入"空格"分支；读到 `2`、`0`、`2`、`6`，`isdigit` 为真，`digits` 累计 4；读到第一行末尾的 `\n`，进入"换行"分支。第二行同理处理。全部 27 个字符读完后，再次调用 `fgetc` 返回 `EOF`，`while` 条件不再成立，循环结束，把六个计数器写入 `stat.txt` 并打印到屏幕，最后 `fclose` 收尾。

要点：**每读一个字符，位置指针就前进一格；`EOF` 不是真实字符，只提示"已到文件末尾"**，这正是 `while ((c = fgetc(fp)) != EOF)` 控制循环的原理。

## 三、解题思路

1. **开两个文件**：输入 `"r"`、输出 `"w"`，逐个判空；
2. **逐字符循环**：`while ((c = fgetc(fin)) != EOF)`，`c` 声明为 `int`；
3. **分类累加**：`total++`，再用 `if / else if` 把字符归入字母、数字、空格、换行、其他之一；
4. **收尾关闭**：`fclose(fin); fclose(fout);`
5. **输出**：六项结果同时打印到屏幕（用 `printf`）并写入文件（用 `fprintf`）。

## 四、参考代码

```c
#include <stdio.h>
#include <ctype.h>          /* 使用 isalpha / isdigit */

int main(void)
{
    FILE *fin, *fout;       /* 输入文件、输出文件 */
    int  c;                 /* 必须用 int 接收 fgetc 的返回值 */
    long total = 0, letters = 0, digits = 0;
    long spaces = 0, newlines = 0, others = 0;

    /* 打开输入文件（只读） */
    fin = fopen("text.txt", "r");
    if (fin == NULL) {
        printf("无法打开文件 text.txt\n");
        return 1;
    }
    /* 打开输出文件（写） */
    fout = fopen("stat.txt", "w");
    if (fout == NULL) {
        printf("无法创建文件 stat.txt\n");
        fclose(fin);
        return 1;
    }

    /* 逐个字符读取并分类计数 */
    while ((c = fgetc(fin)) != EOF) {
        total++;
        if (isalpha(c))        letters++;    /* 字母 */
        else if (isdigit(c))   digits++;     /* 数字 */
        else if (c == ' ')     spaces++;     /* 空格 */
        else if (c == '\n')    newlines++;   /* 换行 */
        else                   others++;     /* 其他 */
    }

    /* 同时输出到屏幕与结果文件：每一行都同步写两处 */
    printf("字符总数 %ld\n", total);   fprintf(fout, "字符总数 %ld\n", total);
    printf("字母 %ld\n",     letters); fprintf(fout, "字母 %ld\n",     letters);
    printf("数字 %ld\n",     digits);  fprintf(fout, "数字 %ld\n",     digits);
    printf("空格 %ld\n",     spaces);  fprintf(fout, "空格 %ld\n",     spaces);
    printf("换行 %ld\n",     newlines);fprintf(fout, "换行 %ld\n",     newlines);
    printf("其他 %ld\n",     others);  fprintf(fout, "其他 %ld\n",     others);

    fclose(fin);
    fclose(fout);

    return 0;
}
```

## 五、运行验证

**样例 1：运行前** `text.txt` 内容（两行，行末各有一个换行）：
```
Ice load 2026
ship 3 knots
```
字符清点：第一行 14 个字符（`Ice`=3 字母、空格、`load`=4 字母、空格、`2026`=4 数字、换行），第二行 13 个字符（`ship`=4 字母、空格、`3`=1 数字、空格、`knots`=5 字母、换行），合计 27。字母 $=3+4+4+5=16$，数字 $=4+1=5$，空格 $=2+2=4$，换行 $=2$，其他 $=27-16-5-4-2=0$。

屏幕输出与 **运行后** `stat.txt` 的内容：
```
字符总数 27
字母 16
数字 5
空格 4
换行 2
其他 0
```
两个文件的内容逐项一致，说明统计与写出都正确。

## 六、常见错误与讲解

**错误 1：`fgetc` 的返回值用 `char` 接收**

```c
char c; while ((c = fgetc(fp)) != EOF) { ... }   /* 危险：可能与 EOF 混淆，漏读或死循环 */
int  c; while ((c = fgetc(fp)) != EOF) { ... }   /* 对：用 int 接收 */
```
`EOF` 是负数，`char` 在某些平台也是有符号的，比较可能出错。**始终用 `int` 接收 `fgetc` 的返回值。**

**错误 2：`fopen` 不判空、忘记 `fclose`**

打开后若不判 `NULL` 就调用 `fgetc`，文件不存在时程序会崩溃；读完不 `fclose(fout)`，结果文件可能为空或内容不全。**打开判空、用完关闭，是文件操作的两条铁律。**

**错误 3：分类时用了多个并列的 `if` 而不是 `else if`**

```c
if (isalpha(c)) letters++;
if (isdigit(c)) digits++;      /* 条件若重叠就会重复计数 */
if (c == ' ')   spaces++;
```
本题各类互斥，`else if` 保证每个字符只归一类。另外要理解：**`EOF` 只在条件判断里出现，永远不会进入循环体**，循环体内处理的一定是真实字符。
