# 第 6 章 练习 22　指针版文本字符统计

**所属综合实验**：B6（B6-基于词频统计的文本热度分析系统）

**对应章节**：6 指针（6.1 指针与地址、6.4 指针与字符串、6.3 指针运算、3.2 选择结构、3.3 循环结构）

**场景来源**：综合实验 B6《基于词频统计的文本热度分析系统》（人工智能学院）——本练习是该实验中"文本预处理统计"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

词频统计的第一步是"清洗文本"：在真正切词之前，系统要先看这段文本里有多少个字母、多少个数字、多少个空格、多少个其他符号。这些统计能帮助判断文本的构成，也用来过滤掉空白符和标点。

文本在 C 语言里就是一个**字符串**——一串连续的字符，最后跟着一个看不见的结束标记。用**指针**沿着字符串一个一个字符地走，是最贴近底层、也最高效的统计方式。B6 系统就用指针来扫过整段文本。

## 二、任务要求

编写一个完整程序 `text_stat.c`：

1. 从键盘读入一行文本（可能含空格，长度不超过 100）；
2. 定义指针 `char *p`，用**指针遍历**结束整个字符串（即用 `*p` 取当前字符、`p++` 前进，直到 `*p == '\0'`）：
   - 统计字母个数 `letters`（`a~z`、`A~Z`）；
   - 统计数字个数 `digits`（`0~9`）；
   - 统计空格个数 `spaces`；
   - 统计其他字符个数 `others`；
3. 输出这四个统计结果。

## 三、输入输出格式

**输入**：一行文本（可含空格，最长 100 个字符）。

**输出**：一行，按格式 `letters = 字母数, digits = 数字数, spaces = 空格数, others = 其他数` 输出。

## 四、样例

**样例 1**

输入：
```
abc 123 x
```
输出：
```
letters = 4, digits = 3, spaces = 2, others = 0
```

**样例 2**

输入：
```
a1 b2!
```
输出：
```
letters = 2, digits = 2, spaces = 1, others = 1
```

## 五、提示

字符串的"结束标记"是字符 `'\0'`（反斜杠零，读作"空字符"），它是字符串末尾的一个特殊字符，用来告诉程序"到这里就结束了"。所以指针遍历的条件是"当前字符不是 `'\0'`"：

```c
char *p = text;                 /* 从文本开头走起 */
while (*p != '\0') {            /* 还没走到结尾 */
    /* 处理 *p */
    p++;                        /* 走到下一个字符 */
}
```

判断字符类别用范围比较：

$$
\text{字母：} ('a' \le c \le 'z')\ \text{或}\ ('A' \le c \le 'Z')
$$

$$
\text{数字：} '0' \le c \le '9'
$$

读入含空格的整行文本，用 `fgets` 或逐个字符读入（`scanf("%s")` 遇空格会停，不适合本题）。

**完成本练习后你将具备的能力**：理解字符串以 `'\0'` 结尾的特性、用指针遍历字符串、用字符范围比较做分类统计——这些是实验 B6 中"文本预处理模块"的地基。
