## 二、预备知识：打擂台求最值的基本原理（零基础阅读）

### 1. 问题是怎么来的

一列数据摆在你面前，人眼扫一遍就知道最大值在哪；但程序只会"一次看一个元素"。要模拟"扫一遍"的过程，需要一个能记住当前战果的机制——这就是**打擂台**。

### 2. 算法是怎么形成的

想象一场擂台赛：擂主先站上台，之后每个挑战者依次上台，**打得过擂主就取而代之，打不过就下台**。全部人上完台，台上站着的就是最强者。翻译成数组语言：

- 擂主 = 两个变量：`max`（当前最大值）和 `pmax`（当前最大值的下标）；
- 初始擂主 = 第一个元素：`max = r[0]; pmax = 0;`——**擂台必须先有人站着**，不能把 `max` 初始化成 0 或 -1，因为阻力恒为正时 `max = 0` 永远不会被打破；
- 挑战 = 循环里逐个比较：`if (r[i] > max) { max = r[i]; pmax = i; }`。

求最小值是同一套逻辑，只是比较方向反过来（`r[i] < min` 时取代）。

### 3. 位置是怎么同步记下来的

"最大值是多少"和"最大值在哪"必须**同时**更新：擂主换人的瞬间，新擂主的下标就是 `i`，所以两条赋值语句要写在同一个 `{ }` 里。存储时下标从 0 计，输出时按工程习惯 +1 变成第几位。

### 4. 相同值怎么处理

`r[i] > max` 用的是**严格大于**：后来者必须"严格更强"才能上位，遇到相等值不动擂主。这恰好实现了题目"重复最值记录最先出现者"的要求——样例 2 全部数据相等，擂主从始至终都是第 1 个元素，所以 max 和 min 都报第 1 位。

### 5. 求和循环与打擂台循环能合并吗

能（都在同一遍遍历中做互不冲突），但建议先分开写、验证正确后再合并。分开写的最大好处是**每一步都容易单独验证**：先打印 sum 检查累加对不对，再加最值逻辑——这是排查程序错误的通用策略。

> 打擂台与累加是数组遍历的两大基本套路：**累加**把所有元素"收拢"成一个数，**打擂台**把所有元素"比"出一个数。练习 04 的方差还要在累加之上再叠一层。

## 三、解题思路

1. 读入 $n$ 与数组——与练习 01 完全相同；
2. 第一遍循环：`sum += r[i]` 求总和；
3. 第二遍循环：从 `i = 1` 开始同时打两个擂台（最大、最小），换擂主时同步记下标；
4. 计算 `avg = sum / n`；
5. 按 `%.2f` 输出四行报表，位置输出 `pmax + 1`、`pmin + 1`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double r[100];      /* 阻力数组，单位 kN */
    double sum = 0.0;   /* 总和累加器，初值必须为 0 */
    double max, min;    /* 擂主：当前最大值、最小值 */
    int pmax, pmin;     /* 擂主所在下标 */
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &r[i]);

    /* 第一遍：累加求和 */
    for (i = 0; i < n; i++)
        sum += r[i];

    /* 第二遍：打擂台。擂主先取第一个元素，从第二个开始挑战 */
    max = r[0];  pmax = 0;
    min = r[0];  pmin = 0;
    for (i = 1; i < n; i++) {
        if (r[i] > max) { max = r[i]; pmax = i; }   /* 换擂主，同步记位置 */
        if (r[i] < min) { min = r[i]; pmin = i; }
    }

    printf("sum = %.2f\n", sum);
    printf("avg = %.2f\n", sum / n);
    printf("max = %.2f (第 %d 位)\n", max, pmax + 1);
    printf("min = %.2f (第 %d 位)\n", min, pmin + 1);

    return 0;
}
```

## 五、运行验证

以样例 1（n=6，数据 15.2 18.7 12.4 20.1 16.8 13.5）手工模拟：

| 循环阶段 | i | r[i] | sum 变化 | max (pmax) | min (pmin) |
|---|---|---|---|---|---|
| 累加后 | — | — | 96.70 | — | — |
| 初始化 | 0 | 15.2 | — | 15.2 (0) | 15.2 (0) |
| 挑战 | 1 | 18.7 | — | 18.7 (1) 换擂 | 15.2 (0) |
| 挑战 | 2 | 12.4 | — | 18.7 (1) | 12.4 (2) 换擂 |
| 挑战 | 3 | 20.1 | — | 20.1 (3) 换擂 | 12.4 (2) |
| 挑战 | 4 | 16.8 | — | 20.1 (3) | 12.4 (2) |
| 挑战 | 5 | 13.5 | — | 20.1 (3) | 12.4 (2) |

求和核算：$15.2+18.7=33.9$，$+12.4=46.3$，$+20.1=66.4$，$+16.8=83.2$，$+13.5=96.7$；均值 $96.7/6=16.116\ldots \approx 16.12$。程序输出与样例 1 完全一致。样例 2（5 个 8.5）中无任何挑战成功，max、min 均保持初始擂主（下标 0），输出 `第 1 位`，与样例吻合。

## 六、常见错误与讲解

**错误 1：擂主初始化为固定数**

```c
max = 0;  min = 100;   /* 错：靠"猜数据范围"初始化，数据全大于 0 时 min 可能报错值 */
max = r[0];  min = r[0];  /* 对：擂台上先站上真实数据 */
```

`max = 0` 在阻力全为正时碰巧能求最大值，但 `min = 100` 遇到全部数据大于 100 时输出 100——用数据本身初始化是唯一稳妥做法。

**错误 2：位置与值分开更新**

```c
if (r[i] > max) { max = r[i]; }        /* 错：换了值忘了换位置 */
if (r[i] > max) { max = r[i]; pmax = i; }   /* 对：值与位置同步 */
```

**错误 3：输出位置忘记 +1**

```c
printf("max = %.2f (第 %d 位)\n", max, pmax);    /* 错：报的是下标 */
printf("max = %.2f (第 %d 位)\n", max, pmax + 1); /* 对：报的是第几位 */
```

**错误 4：比较符号方向写反或用 `>=`**

```c
if (r[i] >= max) { ... }   /* 错：相等也换擂主，重复最值会报"最后出现"而非"最先出现" */
```

严格比较才能满足"最先出现"的要求；同时 `>=` 在全等数据时会把位置推到最后一个，与样例 2 矛盾。

## 七、与综合实验的衔接

- 实验 **C7** 的统计模块中，"总和/均值/峰值/谷值"四件套是每次试验报告的固定栏目，本练习给出的"累加 + 双擂台一遍扫"结构可直接搬入实验代码，稍后加上方差（练习 04）与超阈值计数（第 3 章已练）即构成完整统计报表；
- 同样的"打擂台"骨架换个数组就是新功能：C9 压力场找热点峰值（练习 07 的输入就是它）、C6 碰撞模拟找最大冲击力时刻、D5 剂量场找最高剂量点——**数据换了，擂台不变**。
