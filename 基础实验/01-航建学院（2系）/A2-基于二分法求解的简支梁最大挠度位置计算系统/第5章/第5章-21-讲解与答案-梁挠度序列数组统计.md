## 二、预备知识：一维数组的基本原理（零基础阅读）

### 1. 问题是怎么来的

如果只求一个挠度，定义几个 `double` 变量就够了。但本题要求计算 n+1 个点的挠度，n 最多到 100——难道要定义 101 个变量 `y0, y1, ..., y100`？这不仅写起来荒谬，而且 n 是运行时才读入的，编译器根本不知道要留几个变量。

解决办法是**一维数组**：它是一排**类型相同**的变量，共用同一个名字，用**下标**区分彼此。

```c
double y[101];
```

这一行就开辟了 101 个 `double` 格子，名字分别叫 `y[0]`、`y[1]`、…、`y[100]`。注意两点：**下标从 0 开始**，所以 101 个格子的合法下标是 0～100；数组一旦定义，长度就固定了，读入的 n 必须不超过它。

### 2. 数组与物理坐标的对应

本题要计算梁上等间距的一排点。把梁长 $L$ 分成 $n$ 段，每段长

$$
h = \frac{L}{n}
$$

第 $i$ 个点的坐标是 $x_i = i \cdot h$（$i$ 从 0 到 n）。于是**数组下标 i 与物理坐标 $x_i$ 就建立了对应**：

| 下标 i | 0 | 1 | 2 | … | n |
|---|---|---|---|---|---|
| 坐标 $x_i$ | 0 | h | 2h | … | L |

这正是"数组"在工程计算里最典型的用法：**用下标表示离散化的位置，用元素值表示该位置的物理量**。这个概念在整个综合实验里反复出现——A2 的挠度、A3 的速度、A5 的沉降量，都是"位置/时间序列 + 数组"。

### 3. 挠度公式与手算

挠度公式为

$$
y(x) = \frac{q\,x\,(L^3 - 2Lx^2 + x^3)}{24 E I}
$$

以样例 1 取 $x = 3$（$L=6,\ q=10,\ E=30000,\ I=0.0008$）：

- 括号内：$6^3 - 2\times6\times3^2 + 3^3 = 216 - 108 + 27 = 135$；
- 分子：$10\times3\times135 = 4050$；
- 分母：$24\times30000\times0.0008 = 576$；
- 结果：$y = 4050 / 576 = 7.03125$。

再看 $x=2$：括号内 $216 - 2\times6\times4 + 8 = 216-48+8=176$，分子 $10\times2\times176=3520$，$y=3520/576\approx6.111$；$x=4$ 对称地得同样值 $\approx6.111$。可见 $x=3$ 处最大。程序只需在数组里比大小，就能自动找出这个位置。

### 4. 求最值的"打擂台法"

在一排数里找最大值，标准做法是打擂台：

1. **设擂主**：先假定第 0 个元素是最大的，用 `imax = 0` 记住它的下标；
2. **逐个挑战**：从第 1 个开始，每个元素都和当前擂主 $y[imax]$ 比一比；
3. **胜者登台**：如果挑战者更大，就把 `imax` 改成挑战者的下标。

循环结束后 `imax` 就是最大值的下标，`y[imax]` 就是最大值。条件写 `y[i] > y[imax]`（严格大于）可以保证遇到相等元素时**保留先出现的那一个**，正好满足题目"取第一个"的要求。

## 三、解题思路

1. **定义数组** `double y[101]`；
2. **读入参数** L、q、E、I 和整数 n；
3. **循环赋值**：`i` 从 0 到 n，`x = i*h`，按挠度公式算 `y[i]`；
4. **打擂台求最值下标**：`imax` 从 0 开始，遍历 1～n 更新；
5. **输出** `y[imax]` 和 `imax*h`（坐标 = 下标 × 步长）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double L, q, E, I;          /* 梁长 m、均布荷载 kN/m、弹性模量、惯性矩 */
    int n;                      /* 分段数 */
    int i;
    double h;                   /* 步长，m */
    double y[101];              /* 挠度数组，最多 101 个点 */
    int imax = 0;               /* 最大挠度所在下标，先假定第 0 个 */

    /* 读入参数与分段数 */
    scanf("%lf %lf %lf %lf", &L, &q, &E, &I);
    scanf("%d", &n);

    h = L / n;                  /* 每段长度 */

    /* 逐个计算各点挠度存入数组 */
    for (i = 0; i <= n; i++) {
        double x = i * h;       /* 第 i 个点的坐标 */
        y[i] = q * x * (L*L*L - 2*L*x*x + x*x*x) / (24 * E * I);
    }

    /* 打擂台：找最大挠度的下标 */
    for (i = 1; i <= n; i++) {
        if (y[i] > y[imax]) {
            imax = i;           /* 更新擂主 */
        }
    }

    /* 输出最大挠度与对应坐标 */
    printf("max_y = %.3f\n", y[imax]);
    printf("x_at_max = %.2f\n", imax * h);

    return 0;
}
```

| 8 12 20000 0.0012 / 8 | 对称，x=4 处最大，$y = 12\times4\times(512-256+64)/576=12\times4\times320/576=26.667$ | `max_y = 26.667` `x_at_max = 4.00` ✓ |

## 六、常见错误与讲解

**错误 1：数组越界**

```c
double y[100];
for (i = 0; i <= n; i++) y[i] = ...;   /* n=100 时访问 y[100]，越界！ */
```

n 个分段对应 **n+1** 个点，若 n 最大到 100，数组至少要 101 个元素。定义 `double y[101]` 或更大。数组越界不会报错，但会悄悄破坏别的变量，极难排查。

**错误 2：下标从 1 开始**

```c
for (i = 1; i <= n; i++) ...   /* 错：漏掉 x=0 那个点，且最后一个下标含义错位 */
```

本题需要包含端点 $x=0$ 和 $x=L$，共 n+1 个点，循环必须是 `i` 从 0 到 n。

**错误 3：坐标算错**

```c
double x = i;             /* 错：把下标当坐标，忽略了步长 h */
double x = i * h;         /* 对：坐标 = 下标 × 步长 */
```

当 $h\neq1$ 时（本题一般如此），直接用下标当坐标会得到错误的位置。

**错误 4：最值判断条件写反或写成 >=**

```c
if (y[i] < y[imax]) imax = i;    /* 错：这是在找最小值 */
if (y[i] >= y[imax]) imax = i;   /* 不满足"取第一个"：相等时会取靠后的点 */
```

题目要求取第一个最大值，用严格大于 `>`。
