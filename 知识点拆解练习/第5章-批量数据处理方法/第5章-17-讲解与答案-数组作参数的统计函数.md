## 二、预备知识：数组作函数参数——传什么、为什么还要传长度（零基础阅读）

### 1. 为什么要把数组交给函数

前面各题里，对数组的操作都写在主函数内。若"求均值"这类操作要在多处用到，反复抄写相同的循环显然糟糕。把"对一条数组求某个统计量"封装成函数，让调用者只写一句 `mean(r, n)`，代码就短了、也统一了。这就是 5.4 节：**数组作函数参数**。

### 2. 形参怎么写

函数定义时，接收数组的形参写成**带方括号**的形式：

```c
double sum(double a[], int n)     /* 推荐：方括号留空 */
double sum(double a[100], int n)  /* 也合法，但方括号里的数字其实不起作用 */
```

方括号里写不写长度都一样——它只是告诉编译器"这里收到的是一个数组"，具体多长由实参决定，故**不能靠形参里的数字得知长度**。

### 3. 传的是"首地址"，函数和调用者共享同一块内存

调用 `sum(r, n)` 时，传过去的**不是整条数组的副本**，而是数组 `r` 的**首地址**（数组名即首地址）。函数里的 `a[i]` 与调用者的 `r[i]` 访问**同一块内存**，故传递代价与数组多长无关；也正因如此，函数内若修改 `a[i]`，调用者的 `r[i]` 会跟着变——"传数组进函数"天然就具备"让函数修改并带回结果"的能力。本题四个函数都是**只读**的（不修改元素），但仍要传地址，以便函数"看得见"数据。

### 4. 关键纪律：数值数组必须把长度 `n` 一起传

函数里只有 `a`，它知道从哪里开始，却**不知道到哪里结束**。字符数组能靠末尾的 `'\0'` 判界，但**数值数组没有这种哨兵**——`double` 数组里任何一个值都是合法数据，不可能找一个"特殊值"当结尾。因此函数只能靠调用者额外递进来的 `n` 来知道有效元素是 `a[0]` 到 `a[n-1]`。这就是为什么四个函数的形参都必须带 `int n`。

一句话记住：**传数组，必传长度。**

### 5. 求最值时为什么用 `a[0]` 当初始答案

最大值函数先把答案设为 `a[0]`，再从 `i = 1` 起逐个比较。初值取真实数据而非 0：若数据全为负，取 0 作初值就会错误地返回 0。这条细节练习 02、11 都强调过，封装成函数后依然适用。

### 6. `mean` 里调用 `sum`：函数调用函数

`mean` 不必重写求和循环，直接 `return sum(a, n) / n;`——把求和"外包"给已写好的 `sum`。日后若要改成加权平均，也只改一处。这是模块化设计（第 4 章）在数组场景下的延伸。

## 三、解题思路

1. **`sum`**：`s = 0`，循环 `i` 从 0 到 `n-1` 累加 `a[i]`，返回 `s`；
2. **`mean`**：直接 `return sum(a, n) / n;`；
3. **`maxv`**：`m = a[0]`，循环 `i` 从 1 到 `n-1`，`a[i] > m` 时更新，返回 `m`；
4. **`minv`**：同 `maxv`，比较方向换成 `<`；
5. **主函数**：声明 `double r[100]`，读入 `n` 与 `n` 个数据，依次调用四个函数并按格式输出。

## 四、参考代码

```c
#include <stdio.h>

/* 求和 */
double sum(double a[], int n)
{
    double s = 0.0;
    int i;
    for (i = 0; i < n; i++)
        s += a[i];
    return s;
}

/* 求均值：内部复用 sum */
double mean(double a[], int n)
{
    return sum(a, n) / n;
}

/* 求最大值：初值取 a[0] */
double maxv(double a[], int n)
{
    double m = a[0];
    int i;
    for (i = 1; i < n; i++)
        if (a[i] > m) m = a[i];
    return m;
}

/* 求最小值 */
double minv(double a[], int n)
{
    double m = a[0];
    int i;
    for (i = 1; i < n; i++)
        if (a[i] < m) m = a[i];
    return m;
}

int main(void)
{
    double r[100];              /* 载荷序列，容量 100 */
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &r[i]);

    printf("sum = %.2f\n", sum(r, n));
    printf("mean = %.2f\n", mean(r, n));
    printf("max = %.2f\n", maxv(r, n));
    printf("min = %.2f\n", minv(r, n));

    return 0;
}
```

## 五、运行验证

以样例 1 的 `12.5 13.2 11.8 14.6 13.9` 为例：

| 函数 | 计算过程 | 结果 |
|---|---|---|
| `sum` | $12.5+13.2+11.8+14.6+13.9$ | 66.00 |
| `mean` | $66.0 / 5$ | 13.20 |
| `maxv` | 逐个比较，最大为 14.6 | 14.60 |
| `minv` | 逐个比较，最小为 11.8 | 11.80 |

程序输出：

```
sum = 66.00
mean = 13.20
max = 14.60
min = 11.80
```

与题干样例 1 完全一致。样例 2 手工核对：和 $= 20.0+9.5+15.5+10.0 = 55.0$，均值 $= 13.75$，最大 20.0，最小 9.5，输出 `sum = 55.00`、`mean = 13.75`、`max = 20.00`、`min = 9.50`，同样吻合。

## 六、常见错误与讲解

**错误 1：忘记传长度 `n`**

```c
double sum(double a[])            /* 错：函数内不知道有多少个元素 */
double sum(double a[], int n)     /* 对：长度必须一起传 */
```

如果硬要写 `for (i = 0; i < 100; i++)` 去凑，就会把闲置单元里的垃圾值也加进去，结果必然错。

**错误 2：调用时写了方括号或取地址**

```c
sum(r[], n);      /* 错：调用时数组名不加方括号 */
sum(&r, n);       /* 错：数组名已是首地址，不需要 & */
sum(r, n);        /* 对 */
```

记住规律：**数值型单个元素**作 `scanf` 参数要加 `&`，而**整条数组**作函数实参不加 `&`、不加方括号。

**错误 3：最值初值取 0**

```c
double m = 0;      /* 错：若数据全为负，max 结果恒为 0 */
double m = a[0];   /* 对：初值取真实数据第一个元素 */
```

**错误 4：均值写成整除**

```c
return sum(a, n) / n;      /* 对：sum 返回 double，结果是实数除法 */
int mean = sum(a, n) / n;  /* 错：用 int 接收丢小数 */
```
