# 题目 C10：基于结构体与文件读写的水声实验数据管理系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行水声实验数据管理工具，围绕"一次海上水声实验会在多个测站、多个时刻投放仪器获得大量测点记录，需要用结构体与链表把记录组织起来，支持增删查改、排序检索、统计汇总与文件存取"这一实验数据管理需求展开。系统定义"测点记录"结构体（测站号、时刻、深度、温度、盐度、声速等字段），支持键盘录入校验与文件批量读入，用链表组织记录，实现按测站号查找修改、按条件删除与有序插入，按测点深度或时间排序，对各测站做均值与极值汇总，并把全部记录与汇总结果以文本形式存取，最后在屏幕输出报表。

水声实验的数据量通常很大：一次实验可能布放十几个测站，每个测站按深度层次或时间间隔采样几十到上百条记录（温度、盐度、声速、噪声级等），实验结束后必须把这些记录统一管理——合并不同批次、修正录错的数据、按测站汇总、归档成规范文件供后续分析使用。手工用电子表格管理容易出错，用数据库又超出大一所学；用 C 语言的结构体数组加链表实现一个小型管理系统，恰好覆盖"数据表示—组织结构—文件持久化"三个基本问题。这也是大一课程里最接近真实软件工程的综合练习。

本系统支撑的关键场景包括：① 水声实验测点记录（CTD 温盐深、噪声级）的统一归档管理；② 实验前测站布放计划与实验后数据核对；③ 多批次实验数据的合并与修正；④ 面向声速剖面计算、噪声评估等后续程序的标准数据文件导出。学生在大一阶段就能用 C 语言把"结构体定义—链表操作—文件存取—报表输出"这一完整数据管理链条跑通，为后续《数据结构》《水声学原理》《海洋观测技术》等课程建立直观基础。本题目与水声工程专业"实验数据处理与管理"方向直接相关，训练学生把管理需求转化为"数据定义—结构组织—文件持久化"完整程序工程的能力。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的水声实验数据管理系统：定义测点记录结构体并实现键盘录入与字段校验，实现文本文件批量读入记录，用链表（支持头插与尾插）组织全部记录，实现按测站号查找与修改、按条件删除与按深度有序插入，实现按测点深度或时间排序，对每个测站统计记录数、均值与极值，把全部记录与汇总结果读写到文本文件，并在屏幕输出报表。

专业关联上，本题目复现了实验数据管理业务中"记录建模—链表组织—文件归档"三类真实环节的核心计算。学生在此过程中将重点掌握课程中的结构体、指针与动态链表、文件读写，并综合运用函数、数组、循环与选择结构，第一次完成一个"菜单驱动的增删查改"小系统，理解"一个管理需求如何变成一套程序"。

## 三、数据来源与格式

- **数据文件格式**：测点记录采用纯文本格式，首行为标题说明，其后每行一条记录，字段以逗号分隔。字段依次为：测站号（无空格字符串，如 `S03`）、时刻（单位：小时，自实验起始累计）、深度（单位：米，非负实数）、温度（单位：摄氏度）、盐度（单位：千分之）、声速（单位：米/秒，可由温度盐度经经验公式预填）。

```
# station,time_hr,depth_m,temp_C,sal_psu,sound_mps
S01,2.5,10.0,18.6,31.2,1516.4
S01,2.5,50.0,14.2,31.5,1508.9
S03,4.0,10.0,19.1,30.8,1518.2
S03,4.0,100.0,8.7,32.4,1494.6
S02,6.5,20.0,17.8,31.1,1514.0
```

- **仿真数据生成规则**：
  - 测站号：3～8 个测站，命名 `S01`～`S08`。
  - 时刻：每站一个投放时刻，取值 0～48 小时；同一站所有记录时刻相同（表示一次投放）。
  - 深度：每站按 10～100 m 分层取 10～20 个深度层次。
  - 温度：从表层 15～20 ℃ 随深度每 100 m 下降 3～6 ℃；盐度 30～34 之间随深度缓增；声速按简化经验式 $c = 1449 + 4.6T - 0.055T^2 + 1.4(S - 35) + 0.017z$ 由温度盐度深度换算。
  - **异常值注入方式**：由教师提供的生成程序人为注入三类错误。其一，深度为负数或温度超出 -2～35 ℃ 合理范围；其二，盐度超出 0～40 范围（如 45.0）；其三，字段个数不足（逗号缺失）导致解析错位。校验模块需输出"行号—异常类型—处理动作"清单。

- **真实数据集（如有）**：真实温盐深数据可参考国家海洋科学数据中心与 Argo 实时海洋观测网（https://argo.ucsd.edu/）。学生**无需下载**真实数据文件，课程提供与上述字段含义对应的简化仿真数据表；表中"温度""盐度"对应 CTD 仪器的分层观测值，"声速"对应按经验公式换算的声速剖面值。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_STATION   10      /* 最多测站数 */
#define MAX_NAME_LEN  12      /* 测站号最大长度（含结束符） */
#define MAX_LINE      128     /* 文件读入行缓冲长度 */

/* ===== 测点记录结构体 ===== */
struct Record {
    char  station[MAX_NAME_LEN]; /* 测站号，如 "S03" */
    double time;                 /* 时刻，单位：小时 */
    double depth;                /* 深度，单位：米 */
    double temp;                 /* 温度，单位：摄氏度 */
    double sal;                  /* 盐度，单位：千分之 */
    double sound;                /* 声速，单位：米/秒 */
    struct Record *next;         /* 链表后继指针 */
};

/* ===== 测站统计汇总 ===== */
struct StationStat {
    char   station[MAX_NAME_LEN];/* 测站号 */
    int    count;                /* 该站记录条数 */
    double maxDepth;             /* 最大观测深度 */
    double meanTemp;             /* 平均温度 */
    double minSound;             /* 最小声速（对应声速极小值层） */
    double maxSound;             /* 最大声速 */
};

/* ===== 全局数据区 ===== */
struct Record      *g_head;         /* 记录链表头指针 */
int                 g_recCount;     /* 记录总数 */
struct StationStat  g_stat[MAX_STATION]; /* 测站汇总表 */
int                 g_statCount;    /* 有记录的测站数 */
char                g_fileName[64]; /* 当前数据文件名 */

/* ===== 处理日志（供报表模块使用） ===== */
struct LogItem {
    char  op[24];                /* 操作名，如 "INSERT" */
    char  detail[64];            /* 参数与关键结果摘要 */
};
struct LogItem g_log[MAX_STATION * 4];
int            g_logCount;         /* 已记录日志条数 */
```

辅助说明：测点记录用带后继指针的结构体组织成单链表（课程 7.1/7.2 与指针（6.1/6.2）综合），增删查改全部在链表上完成；测站汇总用结构体数组组织（课程 7.2），文件以文本格式逐行读写（课程 8.3/8.4）。链表节点用 `malloc` 动态分配，属于课程第 6 章指针与第 7 章结构体的综合运用。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据定义与录入（3 个模块）

**M1 测点记录结构体定义模块**（源文件 `RecDef.h`）

- 功能简介：定义 `struct Record` 与 `struct StationStat`，给出各字段含义注释与取值范围约定；提供记录字段合法性判断函数 `int recValid(const struct Record *p)`，检查深度非负、温度在 [-2, 35]、盐度在 [0, 40]、声速在 [1400, 1600]。
- 输入：结构体定义与校验规则。
- 输出：头文件 `RecDef.h` 供全组共用；校验函数返回 0/1 并指明出错字段。

**M2 记录键盘录入与校验模块**（源文件 `RecInput.c`）

- 功能简介：循环提示逐字段录入测站号、时刻、深度、温度、盐度，声速按经验公式 $c = 1449 + 4.6T - 0.055T^2 + 1.4(S - 35) + 0.017z$ 自动换算填充；调用 M1 校验函数把关，不合法字段就地重录；录入完成后插入链表（由用户选择头插/尾插）。
- 输入：键盘逐字段输入。
- 输出：新节点插入 `g_head` 链表；屏幕录入确认。

**M3 文件批量读入记录模块**（源文件 `RecFileIO.c`）

- 功能简介：打开逗号分隔文本文件，跳过首行标题，用 `fgets` 逐行读入缓冲，按逗号切分字段并用 `sscanf` 转换数值，逐条构造记录；对深度、温度、盐度越界或字段缺失的行生成"行号—异常类型—处理动作"清单并跳过；成功记录尾插入链表。
- 输入：文件路径（菜单输入，默认 `survey.txt`）。
- 输出：填充后的链表与 `g_recCount`；屏幕校验清单；返回成功/失败标志。

### 第二部分：链表操作（3 个模块）

**M4 链表建立模块**（源文件 `RecList.c`）

- 功能简介：实现链表基础操作：节点创建 `struct Record *recNew(...)`、头插 `pushFront`、尾插 `pushBack`（尾插需顺带维护尾指针或遍历找尾）、遍历打印与计数；为空链表时各插入操作正确建立首节点。
- 输入：记录数据。
- 输出：维护好的单链表；遍历打印全部记录。

**M5 链表查找与修改模块**（源文件 `RecList.c`）

- 功能简介：实现按测站号查找（返回该站首个节点及数量统计）与按"测站号 + 深度"精确定位记录；定位后用菜单逐字段修改，修改值同样经 M1 校验；支持列出某测站全部记录供选择修改。
- 输入：测站号、深度（或记录序号）、新字段值。
- 输出：修改后的链表；屏幕修改前后对照。

**M6 链表删除与有序插入模块**（源文件 `RecList.c`）

- 功能简介：实现按"测站号 + 深度"删除记录（含释放节点、处理头节点特例）、按"测站号 + 时刻"整站删除；实现有序插入：对指定测站，新记录按深度从小到大插入到链表中正确位置（要求插入前该站记录已有序，否则提示先执行 M7 排序）。
- 输入：删除/插入条件与记录数据。
- 输出：更新后的链表；屏幕操作结果确认。

### 第三部分：排序、统计与输出（4 个模块）

**M7 排序模块**（源文件 `RecSort.c`）

- 功能简介：对整条链表按"测点深度"或按"时刻"排序（菜单选择关键字），采用把节点摘下再按序插入的链表插入排序实现，保持节点动态分配不被破坏；排序后遍历打印前若干条验证。
- 输入：链表头指针、排序关键字。
- 输出：有序链表；屏幕排序结果抽样。

**M8 统计汇总模块**（源文件 `RecStat.c`）

- 功能简介：遍历链表，对每个测站统计记录条数、最大深度、平均温度与最小/最大声速，填入 `g_stat[]` 汇总表；对全部记录计算总条数、测站数与整体平均深度。
- 输入：链表。
- 输出：`g_stat[]`、`g_statCount`；屏幕汇总表。

**M9 结果文件存取模块**（源文件 `RecFileIO.c`）

- 功能简介：把链表全部记录按 M3 的逗号分隔格式写出到 `survey_out.csv`，首行写列名（保证本系统自己的输出可以被 M3 再次读入，实现往返一致）；把测站汇总表写出到 `survey_stat.txt`；提供"另存为"选项更换文件名。
- 输入：链表、`g_stat[]`。
- 输出：`survey_out.csv`、`survey_stat.txt`；屏幕确认信息。

**M10 屏幕报表与主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：以分测站分节的方式在屏幕打印全部记录表（每站一段）与测站汇总表；主菜单用 `do-while + switch` 提供录入、读入、查找修改、删除、有序插入、排序、汇总、存盘、报表共 9 项功能，用状态标记约束"无记录时禁止查找/删除/排序/汇总"。
- 输入：用户菜单选项。
- 输出：屏幕报表；调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环，用状态标记 `g_recCount` 约束流程——无记录时只允许执行 M2 录入与 M3 读入；有记录后可调用 M4～M8 各操作与 M9～M10 输出。删除操作在记录数归零后自动回到"仅可录入/读入"状态。所有插入、修改均经 M1 校验函数把关。

**数据流**：

```
键盘 ─► M2 录入校验 ─┐
                     ├─► M4 链表建立（头插/尾插）─► g_head 链表
survey.txt ─► M3 批量读入 ─┘            │
                            ┌───────────┼─────────────┐
                            ▼           ▼             ▼
                     M5 查找与修改  M6 删除/有序插入  M7 排序
                            └───────────┼─────────────┘
                                        ▼
                                 M8 统计汇总 ─► g_stat[]
                                        │
                         ┌──────────────┴──────────────┐
                         ▼                             ▼
                  M9 文件存取（CSV/报表）      M10 屏幕报表与主控菜单
```

所有模块之间只通过全局链表头指针、汇总数组与函数参数交换数据，函数头部（接口）在编码前由全组书面约定。

## 十、选做扩展

1. **多文件合并**：支持依次读入两个以上数据文件并把记录合并进同一链表，输出合并后"各文件贡献条数"对照表，模拟多批次实验数据汇交场景。
2. **按条件导出子集**：新增"导出满足条件的记录到独立文件"功能（如某测站、某深度范围），供声速剖面计算等后续程序直接使用，体会数据管理的"服务下游"角色。
3. **简易撤销机制**：维护一个最近一次删除记录的备份节点，菜单提供"撤销上次删除"功能（只保留一级），体会栈式备份的最简实现。
