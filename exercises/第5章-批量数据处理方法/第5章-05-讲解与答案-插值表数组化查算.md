## 二、预备知识：数组化查表插值的基本原理（零基础阅读）

本节按**问题来源 → 公式推导 → 代入本例 → 编程翻译**四步展开。

### 1. 问题来源

第 2 章的插值题只给了两档表格，四个数直接写成常量。真实声速表有 5 档：

| 档位 $i$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 深度 dep（m） | 0 | 20 | 50 | 100 | 200 |
| 声速 spd（m/s） | 1450.0 | 1447.0 | 1445.0 | 1452.0 | 1465.0 |

查询深度是任意的（如 35 m），表格只保证档位上的值。要回答"任意深度的声速是多少"，程序要做两件事：**先找区间**（35 落在哪两档之间？），**再插值**（在那一小段上按直线比例取值）。表格一多，"每档写一组常量 + if 链判断"就不可维护了——数据该归数据管，这就是数组。

### 2. 公式推导

**区间定位**：设查询深度为 $d$，找下标 $i$ 使

$$
dep[i] \le d \le dep[i+1], \qquad i = 0, 1, 2, 3
$$

**区间内插值**（第 2 章已推过，此处复述结论）：假设两档之间声速随深度线性变化，则

$$
y = y_0 + \dfrac{(y_1 - y_0)\,(d - x_0)}{x_1 - x_0}
$$

其中 $(x_0, y_0) = (dep[i],\, spd[i])$，$(x_1, y_1) = (dep[i+1],\, spd[i+1])$。它的读法仍是"起点值 + 全程涨幅 × 已走比例"。

### 3. 代入本例

**样例 1：$d = 35$。** 扫描区间：$dep[1] = 20 \le 35 \le 50 = dep[2]$，命中 $i = 1$。代入：

- 已走比例：$(35 - 20)/(50 - 20) = 15/30 = 0.5$；
- 全程涨幅：$1445.0 - 1447.0 = -2.0$（声速随深度下降）；
- 结果：$1447.0 + (-2.0) \times 0.5 = 1446.00$ m/s。

**样例 2：$d = 150$。** 命中区间 $i = 3$（$100 \le 150 \le 200$）：比例 $(150-100)/(200-100) = 0.5$，涨幅 $1465.0 - 1452.0 = 13.0$，结果 $1452.0 + 13.0 \times 0.5 = 1458.50$ m/s。

两个样例恰好都走了 50% 的比例，可以直观体会"半程取一半涨幅"。

### 4. 编程翻译

数据层：两张表用**两个平行数组**存——`dep` 与 `spd` 同下标即同一行。逻辑层两步：

- 找区间：`for (i = 0; i < 4; i++) if (d >= dep[i] && d <= dep[i+1]) break;`——循环结束后 `i` 就是区间左端下标；
- 插值：一行赋值语句把公式直译过去，四个量全部带 `i` 或 `i+1` 的下标。

与第 2 章写死四个常量相比，这里的进步是**结构性**的：档数从 5 改成 20，只需改数组初值和循环上界，算法骨架不动。

> **这个结构在综合实验中反复出现**：A1 风荷载（高度表 + 系数表）、A7 混凝土强度（龄期表 + 强度表）、C1 声速剖面（深度表 + 声速表）、D3 核截面（能量表 + 截面表）——**全部是"两个平行数组 + 找区间 + 插值"**，只是换了表里的数。

## 三、解题思路

1. **建表**：两个 `const double` 数组按题目给定初值初始化；
2. **读入**：`scanf("%lf", &d)`；
3. **找区间**：循环 $i$ 从 0 到 3，闭区间条件命中即 `break`；
4. **插值**：`c = spd[i] + (spd[i+1]-spd[i]) * (d-dep[i]) / (dep[i+1]-dep[i])`；
5. **输出**：`printf("c = %.2f\n", c)`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 平行数组：dep[i] 与 spd[i] 是声速表的同一行（第 i 档） */
    const double dep[5] = {   0.0,   20.0,   50.0,   100.0,  200.0 };
    const double spd[5] = { 1450.0, 1447.0, 1445.0, 1452.0, 1465.0 };

    double d;   /* 查询深度，m */
    double c;   /* 插值得到的声速，m/s */
    int i;

    scanf("%lf", &d);

    /* 第一步：找区间——i 从 0 扫到 3，命中闭区间即停 */
    for (i = 0; i < 4; i++)
        if (d >= dep[i] && d <= dep[i + 1])
            break;

    /* 第二步：在第 i 档与第 i+1 档之间线性插值 */
    c = spd[i] + (spd[i + 1] - spd[i]) * (d - dep[i]) / (dep[i + 1] - dep[i]);

    printf("c = %.2f\n", c);

    return 0;
}
```

## 五、运行验证

| 输入 d | 命中区间 i | dep[i], dep[i+1] | spd[i], spd[i+1] | 计算 | 输出 |
|---|---|---|---|---|---|
| 35 | 1 | 20, 50 | 1447.0, 1445.0 | 1447 + (−2)×15/30 | `c = 1446.00` ✓ |
| 150 | 3 | 100, 200 | 1452.0, 1465.0 | 1452 + 13×50/100 | `c = 1458.50` ✓ |
| 0 | 0 | 0, 20 | 1450.0, 1447.0 | 1450 + (−3)×0/20 | `c = 1450.00`（下端点） |
| 20 | 0 | 0, 20 | 1450.0, 1447.0 | 1450 + (−3)×20/20 | `c = 1447.00`（恰好档位值，公式端点退化） |
| 200 | 3 | 100, 200 | 1452.0, 1465.0 | 1452 + 13×100/100 | `c = 1465.00`（上端点） |

档位值 20 的查询命中区间 $[0, 20]$ 的右端点，插值结果自动等于表格值 1447，验证了闭区间条件无需特判；200 命中最后一档的上端点，同样吻合。

## 六、常见错误与讲解

**错误 1：平行数组下标错位**

```c
c = spd[0] + (spd[1]-spd[0]) * (d - dep[i]) / (dep[i+1] - dep[i]);
/* 错：起点用了 spd[0]，区间却找的是 i，两半截来自不同的行 */
c = spd[i] + (spd[i+1]-spd[i]) * (d - dep[i]) / (dep[i+1] - dep[i]);
/* 对：四个量统一用 i 与 i+1 */
```

平行数组的纪律是**同行的量用同一个下标**。

**错误 2：找区间的循环上界越档**

```c
for (i = 0; i < 5; i++)          /* 错：i = 4 时访问 dep[5]，越界 */
for (i = 0; i < 4; i++)          /* 对：最后一档的上端是 dep[4]，只需扫到 i = 3 */
```

区间由**相邻两档**构成，5 档的表只有 4 个区间。

**错误 3：命中后忘记 break**

```c
for (i = 0; i < 4; i++)
    if (d >= dep[i] && d <= dep[i+1]) ;   /* 错：不 break，i 最终停在 4，插值越界 */
```

缺少 `break` 时循环会一直扫完，`i` 停在 4，随后 `spd[5]` 越界读出垃圾值。

**错误 4：边界条件用开区间**

```c
if (d > dep[i] && d < dep[i+1])   /* 有隐患：d 恰为档位值时全部区间都不命中，i 停在 4 */
if (d >= dep[i] && d <= dep[i+1]) /* 对：闭区间保证档位值也能命中 */
```

## 七、与综合实验的衔接

- 实验 **C1（声速剖面查算与声线跟踪）**中，声线每前进一小步就要按当前深度查一次声速，本练习的"找区间 + 插值"就是这次查算的全部内容；把表换成实验给出的完整剖面（十几档），代码结构不变；
- 实验 **A1（风荷载计算）**的风压高度变化系数查算与此**同构**：`dep` 换成高度表、`spd` 换成系数表即可。练习 09 的二分查找将进一步优化这里的"找区间"——当表很长时，顺序扫描太慢，二分才是正确姿势。数据结构（平行数组）不变、定位算法升级，这正是程序演进的常见路径。
