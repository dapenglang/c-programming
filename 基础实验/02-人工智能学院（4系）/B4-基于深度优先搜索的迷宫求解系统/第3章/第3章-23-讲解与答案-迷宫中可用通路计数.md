## 二、预备知识：计数统计与二维遍历的基本原理（零基础阅读）

### 1. 问题是怎么来的

要数清楚"图里有几个通路、几个墙"，人眼一扫也许能看出来，但程序必须**一个格子一个格子地看**，边看边记账。这种"挨个查看、分类累加"的做法叫**遍历计数**，是所有统计程序的基本模式。

### 2. 两个计数器是怎么工作的

想象手上有两个"计数器"，分别记录通路数和墙数，一开始都归零：

```
road = 0;  wall = 0;
```

然后按行、按列依次取出每个格子，看到是 `.` 就让 `road` 加一，看到是 `#` 就让 `wall` 加一。走完全部格子后，两个计数器里就是各自的总数。因为每个格子**必然属于且仅属于**其中一类，所以有：

$$
road + wall = r \times c
$$

这个等式可以用来验算结果对不对。

### 3. 双重循环是怎么走的

用两层循环，外层管行、内层管列：

```
i = 0: j = 0,1,2      （第 0 行从左到右）
i = 1: j = 0,1,2      （第 1 行从左到右）
```

以 $2 \times 3$ 网格为例，访问顺序是 $(0,0)(0,1)(0,2)(1,0)(1,1)(1,2)$，正好覆盖全部 $2 \times 3 = 6$ 个格子，不重不漏。

### 4. 用本例走一遍

**例 1**：网格两行为 `.#.` 和 `###`。

- 第 0 行：`.`（road=1）、`#`（wall=1）、`.`（road=2）；
- 第 1 行：`#`（wall=2）、`#`（wall=3）、`#`（wall=4）；
- 结果：$road = 2$，$wall = 4$，校验 $2 + 4 = 6 = 2 \times 3$ ✓；
- 比例：$ratio = 2 / 6 = 0.3333\ldots \approx 0.33$。

**例 2**：三行都是 `...`，共 9 个通路。

- $road = 9$，$wall = 0$，校验 $9 + 0 = 9 = 3 \times 3$ ✓；
- 比例：$ratio = 9 / 9 = 1.00$。

### 5. 编程时怎么用它

比例一步要特别小心：**$road$ 和 $r \times c$ 都是整数，直接相除会按整数除法截断**。$2 / 6$ 会得 $0$ 而不是 $0.333$。解决办法是让除法里至少有一个 `double`：

```c
double ratio = road / (double)(r * c);
```

输出用 `%.2f`。

> **这个思想在综合实验中反复出现**：B4 迷宫地形统计、B1 直方图各灰度级计数、B6 词频分档计数，都是"遍历 + 分类计数"同一个套路。

## 三、解题思路

1. **读入尺寸**：`scanf("%d %d", &r, &c);`；
2. **读入网格**：外层循环逐行读字符串到字符数组 `line`（长度够用即可）；
3. **遍历计数**：内层循环逐字符判断，`.` 计入 `road`、`#` 计入 `wall`（本题读入与统计可放在同一组循环里）；
4. **算比例并输出**：`road / (double)(r * c)`，输出三个量。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int r, c;             /* 行数、列数 */
    char line[16];        /* 存放读入的每一行字符串（本题 c 不超过 6） */
    int road = 0, wall = 0;   /* 通路计数、墙计数，初值均为 0 */
    int i, j;
    double ratio;

    /* 读入行数、列数 */
    scanf("%d %d", &r, &c);

    /* 逐行读入并逐字符统计 */
    for (i = 0; i < r; i++) {
        scanf("%s", line);              /* 读入一行 */
        for (j = 0; j < c; j++) {       /* 逐列检查 */
            if (line[j] == '.')
                road++;                 /* 通路 */
            else if (line[j] == '#')
                wall++;                 /* 墙 */
        }
    }

    /* 计算通路比例：强制转成实数，避免整数除法 */
    ratio = road / (double)(r * c);

    /* 输出统计结果与比例 */
    printf("road = %d, wall = %d, ratio = %.2f\n", road, wall, ratio);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2 3 / `.#.` / `###` | road=2, wall=4, ratio=2/6=0.33 | `road = 2, wall = 4, ratio = 0.33` ✓ |
| 3 3 / `...` / `...` / `...` | road=9, wall=0, ratio=9/9=1.00 | `road = 9, wall = 0, ratio = 1.00` ✓ |
| 2 2 / `##` / `##` | road=0, wall=4, ratio=0/4=0.00 | `road = 0, wall = 4, ratio = 0.00` ✓ |
| 1 4 / `.#.#` | road=2, wall=2, ratio=2/4=0.50 | `road = 2, wall = 2, ratio = 0.50` ✓ |

每组都满足 $road + wall = r \times c$，说明统计没有遗漏或重复。

## 六、常见错误与讲解

**错误 1：比例用整数除法（最典型）**

```c
double ratio = road / (r * c);        /* 错：整数除，2/6 得 0 */
double ratio = road / (double)(r*c);  /* 对：分母转实数 */
```

**错误 2：计数器忘记初始化**

```c
int road, wall;      /* 错：起始值随机 */
int road = 0, wall = 0;   /* 对 */
```

**错误 3：内层循环边界用了 r 而不是 c**

```c
for (j = 0; j < r; j++)   /* 错：列数应比较 c */
for (j = 0; j < c; j++)   /* 对 */
```

行列使用不同的上界，写错会导致越界读或漏掉格子。

**错误 4：字符串比较用 `==` 比较整个串**

```c
if (line == ".")     /* 错：比较的是地址，不是内容 */
if (line[j] == '.')  /* 对：比较单个字符用 == */
```

单个字符是基本类型，可以直接用 `==`；整个字符串的比较要等第 8 章学 `strcmp`。
