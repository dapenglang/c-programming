# 第 3 章 练习 03　讲解与参考答案（冰区航行状态判定）

> 配套题干：`第3章-03-题干-冰区航行状态判定.md`

## 一、知识点对照

| 题干要求 | 用到的章节知识点 |
|---|---|
| 冰厚、冰浓度是实数量 | 2.2 数据类型（`double`） |
| 与阈值比较 | 3.4 关系运算符（`>=`） |

## 二、预备知识：多条件逻辑与分支次序的配合

### 1. 问题是怎么来的

工程规程里大量出现"**双因素定级**"：影响结果的量不止一个，每个量都有若干条阈值线，达到任一因素的某条线就取对应的等级。这种规则的数学本质是：对每个等级 $k$ 定义条件

$$
C_k:\quad t \ge T_k \ \text{或}\ c \ge P_k
$$

其中 $T_k$、$P_k$ 分别是冰厚与浓度的第 $k$ 级阈值。判定时**从最高级往低级逐条检查 $C_3, C_2, C_1$**，第一条满足的等级就是结论。

### 2. 为什么必须从高到低检查

等级 2 的条件 $t \ge 0.3$ **不排斥**等级 3 的数据：若 $t = 0.6$，它同时满足 $C_3$ 和 $C_2$。如果链条把 2 级写在最前面，$t = 0.6$ 会被 2 级抢先命中，输出 `level = 2`——**把本该引航的船放进了降速航道**，这是安全事故级的错误。if-else 链"先到先得"的特性决定了：**条件越严格的分支必须放得越靠前**。写完后用极端数据（最大冰厚、最大浓度）验证，是这类题的自检标准动作。

### 3. "或"条件在 C 语言里的写法

$C_3$ 写成 C 表达式就是

```c
t >= 0.5 || c >= 80.0
```

注意不要写成 `0.5 <= t || 80.0 <= c` 之外又画蛇添足的组合，也不要把"或"写成"+"。样例 2 专门考察这一点：冰厚 0.1 完全不达标，仅凭浓度 85 就必须定 3 级——单个因素的达标足以命中。

### 4. 最后的 else 是最低级

0 级的定义是"以上条件均不满足"，恰好就是 else if 链末尾无条件 `else` 的语义，不需要再写任何条件。**规程表中的"其余情况"永远对应 else**，这是把表格翻译成分支结构的固定套路。

## 三、解题思路

1. **读入两个量**：`scanf("%lf %lf", &t, &c)`；
2. **确定变量**：等级 `level` 用 `int`；
3. **从 3 级到 1 级写 if-else 链**：每级条件用 `||` 连接冰厚与浓度两条判据；
4. **else 定 0 级**；
5. **输出** `level = %d`；
6. **用边界数据自检**：$t = 0.5$、$t = 0.3$、$c = 80$、$c = 60$ 等阈值点逐一核对（阈值点取"满足"，因为条件都是 $\ge$）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double t;        /* 冰厚，m */
    double c;        /* 冰浓度，% */
    int level;       /* 航行状态等级 0~3 */

    scanf("%lf %lf", &t, &c);

    if (t >= 0.5 || c >= 80.0)        /* 从最高级开始逐级检查 */
        level = 3;
    else if (t >= 0.3 || c >= 60.0)
        level = 2;
    else if (t >= 0.15 || c >= 30.0)
        level = 1;
    else                              /* 以上均不满足 → 最低级 */
        level = 0;

    printf("level = %d\n", level);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `0.4 50` | 3 级？$0.4<0.5$ 且 $50<80$ 否；2 级？$0.4 \ge 0.3$ 是 → 2 级 | `level = 2` ✓ |
| `0.1 85` | 3 级？$85 \ge 80$ 是 → 3 级（冰厚不达标不影响） | `level = 3` ✓ |
| `0.6 10` | 3 级？$0.6 \ge 0.5$ 是 → 3 级（验证"高条件在前"，若 2 级在前会错判为 2） | `level = 3` ✓ |
| `0.12 20` | 3、2、1 级条件均不满足 → else | `level = 0` ✓ |
| `0.5 80` | $t \ge 0.5$ 与 $c \ge 80$ 同时恰好达标（条件用 $\ge$，取满足） | `level = 3` ✓ |

## 六、常见错误与讲解

**错误 1：分支次序写反（本题最致命）**

```c
if (t >= 0.15 || c >= 30.0) level = 1;   /* 错：低级条件在前 */
else if (t >= 0.5 || c >= 80.0) level = 3;
```

$t = 0.6, c = 10$ 会被 1 级抢走。else if 链的"先到先得"要求**严格条件在前**。自检方法：用最大值输入跑一遍，必须输出最高级。

**错误 2：把"或"写成"与"**

```c
if (t >= 0.5 && c >= 80.0)   /* 错：要求两因素同时达标 */
if (t >= 0.5 || c >= 80.0)   /* 对：任一达标即命中 */
```

样例 2（`0.1 85`）专门暴露这个错误：写成 `&&` 会漏判成 1 级或 2 级。

**错误 3：等级变量与输出格式不匹配**

```c
printf("level = %f\n", level);   /* 错：int 用 %f 输出乱码 */
printf("level = %d\n", level);   /* 对 */
```

**错误 4：条件用 `>` 而不是 `>=`**

规程阈值（0.5、0.3、80……）本身属于更高一级的工况（"达到 0.5 米按 3 级处置"），条件必须是 `>=`。写成 `>` 会让阈值点数据掉级，见验证表第 5 行。

## 七、与综合实验的衔接

- 实验 **C6（碰撞模拟）**用这个等级决定冰块模型的加载参数（3 级工况启用大冲击载荷曲线），实验 **C10（碎冰场统计）**对整片海域逐网格判定等级并统计各级面积占比。学到第 5 章（数组）后，C10 的"逐网格判定"将变成嵌套循环内反复调用这段判断逻辑；学到第 4 章（函数）后，判定代码可封装成 `int ice_level(double t, double c)`，被两个实验共用——**规程翻译成分支的方法不变**；
- "多因素阈值定级"在工程中随处可见：风荷载的设防烈度分级、核设施辐射分区、混凝土耐久性环境等级划分，都是本题骨架换个阈值表而已。
