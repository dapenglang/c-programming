# 第 3 章 练习 23　屏蔽透射率随厚度递减表

**所属综合实验**：D6（D6-基于蒙特卡洛模拟的射线屏蔽透射率计算系统）

**对应章节**：3 程序控制结构（3.1 顺序结构回顾、3.2 选择结构、3.3 循环结构——for 循环、3.4 循环的嵌套、3.5 关系与逻辑运算）

**场景来源**：综合实验 D6《基于蒙特卡洛模拟的射线屏蔽透射率计算系统》（核学院）——本练习是该实验中"屏蔽厚度—透射率关系表生成"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

做屏蔽设计时，工程师关心的不是"某一个厚度下透射率是多少"，而是**一块厚度到底能减多少**——他要看一条完整的"厚度—透射率"曲线，才能挑出既安全、又不过度浪费材料的厚度。

根据上一练习的指数衰减律：

$$
T = e^{-\mu x}
$$

把厚度 $x$ 从 0 开始每隔 0.5 cm 取一个点，一直到 5 cm，再逐个算出对应透射率，就得到一张**屏蔽透射率随厚度递减表**。综合实验 D6 的最终报告里，这张表用来和蒙特卡洛模拟结果逐行对照：理论一列、模拟一列，看模拟是否收敛到理论值。

## 二、任务要求

编写一个完整程序 `trans_table.c`：

1. 程序中用**常量**存放铅的线衰减系数 $\mu = 0.78$（1/cm）；
2. 用**循环**遍历厚度：从 $x = 0$ 开始，每次增加 0.5 cm，直到 $x = 5$（**含 5**，共 11 个厚度点）；
3. 对每个厚度，用指数衰减公式计算透射率 $T$；
4. 按表格格式逐行输出：每行先打印厚度（保留 1 位小数）、再打印透射率（保留 4 位小数）。

## 三、输入输出格式

**输入**：无（厚度由程序内部循环生成）。

**输出**：共 11 行，每行格式为 `x = 厚度, T = 透射率`，厚度保留 1 位小数，透射率保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
（无输入）
```
输出：
```
x = 0.0, T = 1.0000
x = 0.5, T = 0.6769
x = 1.0, T = 0.4584
x = 1.5, T = 0.3104
x = 2.0, T = 0.2101
x = 2.5, T = 0.1423
x = 3.0, T = 0.0963
x = 3.5, T = 0.0652
x = 4.0, T = 0.0442
x = 4.5, T = 0.0299
x = 5.0, T = 0.0202
```

**样例 2**

若把材料换成铁（$\mu = 0.35\ \text{cm}^{-1}$），其余不变，则首三行为：
```
x = 0.0, T = 1.0000
x = 0.5, T = 0.8395
x = 1.0, T = 0.7047
```

## 五、提示

- 循环变量用 `double` 类型（`for (x = 0.0; x <= 5.0; x += 0.5)`），因为厚度是小数；
- 循环条件是 `x <= 5.0`（写作 `<= 5.0 + 1e-9` 也可，防止浮点误差漏掉终点），保证厚度 5.0 被处理；
- 每次循环里做三件事：算透射率、打印、让 x 增加 0.5；
- $\mu$ 用 `const double` 存放，`exp` 需要 `#include <math.h>`；
- 想一想：随着厚度增加，透射率是单调递减的。如果输出**不是**递减的，说明公式或循环写错了。

**完成本练习后你将具备的能力**：用 `for` 循环遍历一串小数、把"重复计算 + 逐行打印"组织成表格输出、理解"循环变量类型要匹配被遍历数据的类型"——这些是实验 D6 中"关系表生成模块"的地基。
