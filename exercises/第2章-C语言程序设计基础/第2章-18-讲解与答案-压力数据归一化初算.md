# 第 2 章 练习 18　讲解与参考答案（压力数据归一化初算）

> 配套题干：`第2章-18-题干-压力数据归一化初算.md`

## 一、知识点对照

| 题干要求 | 用到的章节知识点 |
|---|---|
| 最小值、最大值、测点值都带小数 | 2.2 数据类型（用 `double`，避免整数除法） |
| 归一化公式 $x'=(x-x_{min})/(x_{max}-x_{min})$ | 2.3 运算符（减法、除法、括号与优先级） |
| 读入三个数、输出一个数 | 2.4 标准输入输出（`%lf` 读多个、`%.4f` 控制位数） |

本章之后的内容（选择、循环、函数、数组）本题**一概不用**。

## 二、预备知识：min-max 归一化的基本原理（零基础阅读）

### 1. 问题是怎么来的

不同工况的压力范围差别很大。若直接把原始值放到同一张图上，量纲和量级都不同，无法比较。我们希望找到一个**统一尺度**，把任何范围的数据都映射到 $[0, 1]$ 区间：让最小值对应 0、最大值对应 1。这样"处在数据范围的哪个位置"就被清楚地表达出来。

### 2. 公式是怎么推出来的

"线性映射"意味着用一条直线把 $[x_{min}, x_{max}]$ 映到 $[0, 1]$。设映射为 $x' = a(x - x_{min})$，用端点条件定 $a$：

- 当 $x = x_{max}$ 时要求 $x' = 1$，即 $a(x_{max} - x_{min}) = 1$，得 $a = \dfrac{1}{x_{max} - x_{min}}$。

代回即得

$$
x' = \dfrac{x - x_{min}}{x_{max} - x_{min}}
$$

分子是"当前值离最小值有多远"，分母是"整个范围有多宽"，二者相除就是**相对位置**，恒在 $[0, 1]$ 内。

### 3. 用本例走一遍

样例 1：$x_{min}=0,\ x_{max}=200,\ x=150$：

- 分子：$150 - 0 = 150$；
- 分母：$200 - 0 = 200$；
- 结果：$150 / 200 = 0.75$，说明该测点处在范围的 75% 位置。

样例 2：$x_{min}=50,\ x_{max}=250,\ x=175$：

- 分子：$175 - 50 = 125$；
- 分母：$250 - 50 = 200$；
- 结果：$125 / 200 = 0.625$。

可见归一化只关心"相对位置"，与绝对大小无关。

### 4. 编程时怎么用它

三个输入用 `double` 读入，一行除法算出结果，`printf` 用 `%.4f` 输出。**核心陷阱是整数除法**：若三数都用 `int`，$150/200$ 会被截断成 0，归一化全错。

> **这个思想在综合实验中反复出现**：C9 压力场可视化（压力 → 灰度）、B1 图像二值化（灰度 → 0/1）都用同一个 min-max 公式，只是缩放目标不同。掌握它，两处通用。

## 三、解题思路

1. **确定变量**：`xmin`、`xmax`、`x` 与结果 `x_norm`，全部用 `double`；
2. **读入三个数**：`scanf("%lf %lf %lf", &xmin, &xmax, &x);`；
3. **套公式**：`x_norm = (x - xmin) / (xmax - xmin);`；
4. **输出**：`printf("x_norm = %.4f\n", x_norm);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double xmin;     /* 压力最小值，kPa */
    double xmax;     /* 压力最大值，kPa */
    double x;        /* 当前测点压力值，kPa */
    double x_norm;   /* 归一化结果，0~1 */

    /* 一次读入三个数（题目保证 xmax > xmin 且 xmin <= x <= xmax） */
    scanf("%lf %lf %lf", &xmin, &xmax, &x);

    /* min-max 归一化：相对位置 = (当前值 - 最小值) / (最大值 - 最小值) */
    x_norm = (x - xmin) / (xmax - xmin);

    /* 输出，保留 4 位小数 */
    printf("x_norm = %.4f\n", x_norm);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 0 200 150 | (150 − 0)/(200 − 0) = 150/200 = 0.75 | `x_norm = 0.7500` ✓ |
| 50 250 175 | (175 − 50)/(250 − 50) = 125/200 = 0.625 | `x_norm = 0.6250` ✓ |
| 0 200 0 | (0 − 0)/200 = 0（最小值归一到 0） | `x_norm = 0.0000` ✓ |
| 0 200 200 | (200 − 0)/200 = 1（最大值归一到 1） | `x_norm = 1.0000` ✓ |

端点分别归一到 0 与 1，中间值按比例分配，符合 min-max 归一化的定义。

## 六、常见错误与讲解

**错误 1：整数除法（最典型）**

```c
int xmin = 0, xmax = 200, x = 150;
double x_norm = (x - xmin) / (xmax - xmin);   /* 错：150/200 整数除法 = 0 */
```

即使左边是 `double`，右边也先按整数除法算完再赋值。正确做法：三个输入都用 `double` 读入（本题正是如此），保证实数运算。

**错误 2：分子分母写反**

```c
x_norm = (xmax - xmin) / (x - xmin);   /* 错：这是倒数，结果会远大于 1 */
x_norm = (x - xmin) / (xmax - xmin);   /* 对：当前值离最小值的距离 / 范围宽度 */
```

归一化结果必须在 $[0, 1]$ 内，若大于 1 或为负，说明分子分母弄反了。

**错误 3：读入漏掉 `&`**

```c
scanf("%lf %lf %lf", xmin, xmax, x);         /* 错 */
scanf("%lf %lf %lf", &xmin, &xmax, &x);      /* 对：每个变量都要取地址 */
```

**错误 4：输出精度不符**

```c
printf("x_norm = %.1f\n", x_norm);   /* 不满足"保留 4 位小数" */
printf("x_norm = %.4f\n", x_norm);   /* 对 */
```

- 学到第 5 章（数组）后，可以对整个压力网格批量归一化；学到第 3 章（选择结构）后，可以把归一化值再映射成 0~255 的灰度。**比值型缩放**是所有数据可视化的起点，本练习让你先把它的公式和整数除法陷阱彻底弄清楚。
