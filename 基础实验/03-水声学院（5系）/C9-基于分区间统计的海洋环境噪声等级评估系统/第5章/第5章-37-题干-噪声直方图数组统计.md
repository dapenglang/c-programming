# 第 5 章 练习 37　噪声直方图数组统计

**所属综合实验**：C9（C9-基于分区间统计的海洋环境噪声等级评估系统）

**对应章节**：5 一维数组与统计（5.1 数组的定义与引用、5.2 数组的遍历、5.4 用数组作计数器——频数统计、5.5 数组统计——占比计算）

**场景来源**：综合实验 C9《基于分区间统计的海洋环境噪声等级评估系统》（水声学院）——本练习是该实验中"区间频数统计（直方图）环节"的最小实现。

**建议用时**：40 分钟

## 一、应用场景

水听器在海上连续工作，每隔一段时间记下一个**噪声级**（dB）。想知道噪声"整体分布在哪个水平"，最直观的工具是**直方图**：把噪声级的取值范围切成若干个**区间（bin）**，数一数每个区间里落了多少个样本——这叫**分区间频数统计**。

综合实验 C9 的核心模块就是它（M3）：把噪声级序列分箱统计出频数直方图，供后续计算累积分布、判定噪声等级。本题用**数组作计数器**实现分箱：四个固定区间的频数存进 `freq[4]`，最后输出频数表与各区间的样本占比。

## 二、任务要求

编写一个完整程序 `noise_hist.c`：

1. 从键盘读入样本个数 `n`（**题目保证 1 ≤ n ≤ 200**）；
2. 读入 `n` 个噪声级（double，单位 dB），存入一维数组 `ns[200]`；
3. 按以下 4 个区间分箱统计频数，频数存入数组 `freq[4]`：

| 区间编号 | 区间范围（dB） |
|---|---|
| 0 | 60 ≤ x < 70 |
| 1 | 70 ≤ x < 80 |
| 2 | 80 ≤ x < 90 |
| 3 | 90 ≤ x ≤ 100 |

4. 输出四行频数表（区间范围、频数、该区间占比 = 频数 / n，占比保留 1 位小数、带百分号）；
5. 题目保证所有样本都落在 [60, 100] 内，**但程序仍应对不在此范围的输入打印一条警告**（如 `警告：样本 xx.xx 超出统计范围`），并跳过该样本（不计入任何区间，也不计入占比分母的合理性讨论——本题约定占比分母仍用 n）。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数（空格分隔）。

**输出**：频数表 4 行，格式：

```
[60,70) : 4 个  33.3%
[70,80) : 4 个  33.3%
[80,90) : 2 个  16.7%
[90,100] : 2 个  16.7%
```

（格式：`区间 : 频数 个  占比%`，冒号前后各一个空格，占比保留 1 位小数。）

## 四、样例

**样例 1**

输入：
```
12
63.5 71.2 68.9 84.3 92.6 75.8 66.4 88.1 79.5 95.3 72.7 61.8
```
输出：
```
[60,70) : 4 个  33.3%
[70,80) : 4 个  33.3%
[80,90) : 2 个  16.7%
[90,100] : 2 个  16.7%
```

**样例 2**

输入：
```
3
99.9 60.0 100.0
```
输出：
```
[60,70) : 1 个  33.3%
[70,80) : 0 个  0.0%
[80,90) : 0 个  0.0%
[90,100] : 2 个  66.7%
```

（注意边界归属：60.0 属于区间 0，100.0 属于区间 3——左闭右开，最后一区间右闭。）

## 五、提示

- 用**数组当一组计数器**，避免写 4 段雷同代码：
  ```c
  int freq[4] = {0, 0, 0, 0};     /* 计数器数组必须清零 */
  for (i = 0; i < n; i++) {
      if (ns[i] < 60.0 || ns[i] > 100.0) {
          printf("警告：样本 %.2f 超出统计范围\n", ns[i]);
          continue;               /* 跳过该样本 */
      }
      if (ns[i] < 70.0)      freq[0]++;
      else if (ns[i] < 80.0) freq[1]++;
      else if (ns[i] < 90.0) freq[2]++;
      else                   freq[3]++;
  }
  ```
- `else if` 链的顺序保证了区间**左闭右开**：能走到第二个分支的必然 ≥ 70，不用重复写 `ns[i] >= 70`；
- 占比 = `(double)freq[k] / n * 100`——**先转 double 再除**，否则整数除法会把占比算成 0；
- 想一想：如果把条件写成 `if (ns[i] >= 60 && ns[i] < 70) freq[0]++; if (ns[i] >= 70 && ns[i] < 80) freq[1]++; ...`（四个独立 if 而非 else-if），结果还正确吗？为什么说 else-if 链更安全？

**完成本练习后你将具备的能力**：用数组作计数器完成分箱频数统计、用 else-if 链实现区间归类——这是实验 C9 中"区间频数统计（M3）"与"累积分布（M4）"的地基。
