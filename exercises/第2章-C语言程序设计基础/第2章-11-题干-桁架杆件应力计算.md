# 第 2 章 练习 11　桁架杆件应力计算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 A8《基于高斯消元的静定桁架内力求解系统》（航建学院）——本练习是该实验中"杆件应力校核"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

桁架是由许多细长杆件组成的承力结构。用静力平衡（实验 A8 的高斯消元模块）解出每根杆承受的**轴力 $N$** 后，下一步要判断这根杆"会不会被拉断或压坏"——办法是把轴力除以杆的**横截面积 $A$**，得到**应力 $\sigma$**：

$$
\sigma = \frac{N}{A}
$$

应力单位是帕（Pa）。工程上更常用兆帕（MPa，$1\ \mathrm{MPa} = 10^6\ \mathrm{Pa}$）和平方毫米（$\mathrm{mm^2}$）作为杆件截面积的单位，而轴力常用千牛（kN）。这三套单位必须统一后才能相除，因此本题的核心是**力除以面积并完成 kN→N、mm²→m² 的换算**。

## 二、任务要求

编写一个完整程序 `truss_stress.c`：

1. 用**常量**定义换算系数：`KN_TO_N = 1000.0`（1 kN = 1000 N）、`MM2_TO_M2 = 1.0e-6`（1 mm² = $10^{-6}$ m²）；
2. 从键盘读入两个 double 数：杆件轴力 `N`（单位 **kN**，**拉为正、压为负**）与横截面积 `A`（单位 **mm²**）。**题目保证 A > 0**，因此本程序不需要判断分支；
3. 按公式 $\sigma = \dfrac{N \times 1000}{A}$ 计算应力（单位 MPa），并说明其等价于 $\dfrac{N(\mathrm{N})}{A(\mathrm{m^2})}$ 再换成 MPa；
4. 按规定格式输出应力，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，两个实数，依次为轴力 N（kN）与横截面积 A（mm²），数之间以空格分隔。

**输出**：一行，按格式 `sigma = 结果 MPa` 输出应力，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
120 2000
```
输出：
```
sigma = 60.0000 MPa
```

**样例 2**

输入：
```
-90 1500
```
输出：
```
sigma = -60.0000 MPa
```

## 五、提示

轴力应力公式为

$$
\sigma = \frac{N}{A}
$$

单位换算的巧处：把轴力从 kN 换成 N 需 $\times 1000$，把面积从 mm² 换成 m² 需 $\times 10^{-6}$，合起来是 $\times 10^9$，而 Pa 换成 MPa 又要 $\div 10^6$，两者相抵，最终**只要 $\dfrac{N(\mathrm{kN}) \times 1000}{A(\mathrm{mm^2})}$ 就直接得到 MPa**。这就是工程上"kN 除 mm² 等于 MPa"这句口诀的来历。应力为负表示受压，输出时会带负号。

**完成本练习后你将具备的能力**：理解不同工程单位之间的换算关系、书写"数值 + 单位 + 量纲检验"的计算代码、正确处理带符号的物理量——这是实验 A8 应力校核模块的基础。
