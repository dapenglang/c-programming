## 二、预备知识：流式序列统计的基本原理（零基础阅读）

### 1. 问题是怎么来的

练习 37 只判一对深度，而真实测线有几百个 ping。把整条序列判完后，我们想知道：**一共跳了几次？地形分了几段？**

一个直观的想法是把 $N$ 个深度存进数组，再两两比较。可以，但不必要——注意判决 $i$ 号点只用 $d_i$ 和 $d_{i-1}$ 两个数，**更早的深度再也不用了**。所以只需两个变量：一个存"上一个深度"，一个存"当前深度"，读完一个滚动一次。这种"数据流过去、只留必要信息"的处理方式叫**流式处理**，是处理大序列（内存放不下或无需回看）的标准思路。

### 2. 公式推导

设序列为 $d_1, d_2, \dots, d_N$，阈值 $T$。定义跳变指示：

$$\delta_i = \begin{cases} 1, & |d_i - d_{i-1}| > T \\ 0, & \text{其他} \end{cases}\qquad i = 2, \dots, N$$

跳变次数与段数：

$$k = \sum_{i=2}^{N} \delta_i,\qquad \text{segments} = k + 1$$

**为什么段数是 $k+1$？** 没有跳变时序列本身是一段；每多一次跳变就多切出一段——$k$ 刀切 $k+1$ 块，和"一条线段上切 $k$ 刀"是同一个道理。

**循环不变式**（程序正确性的核心）：进入第 $i$ 轮循环前，`d0` 中恰是 $d_{i-1}$。每轮做三件事：读入 $d_i$ → 比较 `d1 - d0` → 赋值 `d0 = d1`。循环结束时不变式依然成立，所以比较永不遗漏、永不重复。

### 3. 代入本例数值

样例 1：$N = 8$，$T = 0.5$，序列 `150.0 150.2 151.0 151.1 152.6 152.5 150.8 150.9`。

| $i$ | $d_{i-1} \to d_i$ | $\lvert\Delta\rvert$ | $> 0.5$? | $k$ |
|---|---|---|---|---|
| 2 | 150.0→150.2 | 0.2 | 否 | 0 |
| 3 | 150.2→151.0 | 0.8 | **是** | 1 |
| 4 | 151.0→151.1 | 0.1 | 否 | 1 |
| 5 | 151.1→152.6 | 1.5 | **是** | 2 |
| 6 | 152.6→152.5 | 0.1 | 否 | 2 |
| 7 | 152.5→150.8 | 1.7 | **是** | 3 |
| 8 | 150.8→150.9 | 0.1 | 否 | 3 |

共 $7$ 次比较、$k = 3$ 次跳变，段数 $3 + 1 = 4$。（各差分均为一位小数精确值，无舍入歧义，已按 IEEE-754 double 复核。）

样例 2：全部差分 $0.1$，$k = 0$，段数 $1$。

### 4. 通过编程翻译

| 数学 | C 语言 |
|---|---|
| $k \leftarrow 0$ | `int k = 0;` |
| 读 $d_1$（循环外） | `scanf("%lf", &d0);` |
| 第 $i$ 轮读 $d_i$ | `scanf("%lf", &d1);` |
| $\delta_i = 1$ 即 $\|d_i-d_{i-1}\|>T$ | `if (fabs(d1 - d0) > T) k++;` |
| 滚动：$d_{i-1} \leftarrow d_i$ | `d0 = d1;` |
| 输出 $k$ 与 $k+1$ | 两条 `printf` |

## 三、解题思路

1. 读 `n` 与 `T`；
2. 循环外读第一个深度到 `d0`；
3. `for i = 2..n`：读 `d1`，判跳变，滚动 `d0 = d1`；
4. 输出 `k` 与 `k+1`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
    int n, i, k = 0;            /* 点数、循环变量、跳变计数 */
    double T;                   /* 判决阈值 */
    double d0, d1;              /* 上一个深度、当前深度 */

    scanf("%d %lf", &n, &T);

    if (n >= 1) {
        scanf("%lf", &d0);      /* 第一个深度：只作起点，不参与判决 */
        for (i = 2; i <= n; i++) {
            scanf("%lf", &d1);              /* 读当前深度 */
            if (fabs(d1 - d0) > T) {        /* 幅度超过阈值 */
                k++;                        /* 记一次跳变 */
            }
            d0 = d1;                        /* 滚动：当前变上一个 */
        }
    }

    printf("jumps = %d\n", k);
    printf("segments = %d\n", k + 1);
    return 0;
}
```

## 五、运行验证

**样例 1**（`8 0.5` + 序列）：输出 `jumps = 3`、`segments = 4` ✓（逐点核对见第二节表格）

**样例 2**（`5 0.5` + 全平稳序列）：输出 `jumps = 0`、`segments = 1` ✓

**边界验证**：输入 `1 0.5` 与单个深度 `150.0`——循环体一次都不执行，输出 `jumps = 0`、`segments = 1`（单点自成一段，符合 $k+1$）。

## 六、常见错误与讲解

**错误 1：循环起点从 1 开始、比较错位**

```c
scanf("%lf", &d0);              /* d0 = d1 号点 */
for (i = 1; i <= n; i++) {      /* 错：第 1 轮又读了一个点，d1 实为 2 号点，
                                   且循环多跑一次，末尾多读一个不存在的数 */
```

正确姿势是 `for (i = 2; i <= n; i++)`——比较的轮数是 $N-1$，不是 $N$。可用样例 1 核对：错版会尝试读第 9 个数，输入耗尽后得到垃圾值。

**错误 2：忘记滚动（`d0 = d1` 漏写）**

```c
for (i = 2; i <= n; i++) {
    scanf("%lf", &d1);
    if (fabs(d1 - d0) > T) k++;
    /* 漏了 d0 = d1; → 永远在和第 1 个点比较 */
}
```

漏滚动的后果：所有点都与 $d_1$ 比。样例 1 中 `151.0、152.6、150.8` 与 `150.0` 的差都超阈值，$k$ 会虚增。**"比较完必滚动"是流式比较的铁律。**

**错误 3：计数变量未初始化**

```c
int k;              /* 错：k 初值随机，可能从垃圾值开始累加 */
int k = 0;          /* 对 */
```

**错误 4：用了数组**——本题刻意禁用数组。若你写了 `double d[1000];`，请对照提示改写为双变量滚动：数组版先读完再判，两遍扫描；滚动版边读边判，一遍扫描，后者才是本练习要训练的思维。

## 七、与综合实验的衔接

- 实验 **C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》**的第 6～8 模块是一条流水线：第 6 模块对每个差分点做练习 37 的三级判决，第 7 模块在 `step jump` 处切开序列、把每段的起止 ping 号记下来（综合实验中用数组保存，本题只用两个变量演示核心逻辑），第 8 模块对每段求均值与极值。本题的 $k$ 与 $k+1$ 正是第 8 模块"段数"输出的来源；
- 与练习 37 相比，本题的关键跃迁是**从"一对"到"一路"**：把单次判决装进循环、用滚动变量喂给它。将来学到第 5 章数组、第 6 章指针，处理手段会升级，但"相邻比较 + 累计"这个骨架始终不变——C7 的极值检测（练习 39）马上就要复用它。
