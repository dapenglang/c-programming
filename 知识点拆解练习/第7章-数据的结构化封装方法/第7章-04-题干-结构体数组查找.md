# 第 7 章 练习 04　结构体数组查找

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.2 结构体数组）

**场景来源**：综合实验 C6《冰区航行冰块碰撞仿真系统》（水声学院）——本练习是该实验中"按编号定位冰块记录"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

碰撞仿真运行中，调度系统经常需要"点名"：根据传感器报来的冰块编号，立刻调出这块冰的质量与位置，用于碰撞判断。冰块清单以结构体数组存放，编号的排列没有规律，因此采用**顺序查找**——从第 0 个元素开始逐个比对编号，找到就返回该元素的完整记录，找遍全表都没有就报告"未找到"。找到时得到的是一整个结构体：编号、质量、位置坐标一起到手，这正是把数据封装成结构体后查找操作的便利之处。

## 二、任务要求

编写一个完整程序 `ice_find.c`：

1. 按下面的框架定义结构体类型（成员名不得改动）：

```c
struct IceBlock {
    int    id;      /* 冰块编号 */
    double mass;    /* 质量（kg） */
    double x;       /* 位置 x（m） */
    double y;       /* 位置 y（m） */
};
```

2. 定义长度为 10 的结构体数组（题目保证 $1 \le n \le 10$），读入 $n$ 块冰的记录；
3. 读入待查询的编号 `q`，用**顺序查找**在数组中定位；
4. 找到：输出该冰块的完整记录；未找到：输出未找到提示。

## 三、输入输出格式

**输入**：第一行一个整数 $n$（$1 \le n \le 10$）；随后 $n$ 行，每行 4 个数据：编号（整数）、质量（实数，kg）、位置 x、位置 y（实数，m）；最后一行为待查询的编号 `q`（整数）。

**输出**：若找到，输出一行 `找到：编号 号冰块，质量 M kg，位置 (x, y) m`，实数保留 2 位小数；若未找到，输出一行 `未找到编号为 q 的冰块`。

## 四、样例

**样例 1**

输入：
```
4
3 1650.60 12.5 8.4
7 440.16 5.0 3.2
5 1834.00 20.1 15.6
9 917.00 7.7 2.9
5
```
输出：
```
找到：5 号冰块，质量 1834.00 kg，位置 (20.10, 15.60) m
```

**样例 2**

输入：
```
4
3 1650.60 12.5 8.4
7 440.16 5.0 3.2
5 1834.00 20.1 15.6
9 917.00 7.7 2.9
6
```
输出：
```
未找到编号为 6 的冰块
```

## 五、提示

- 顺序查找：`for (i = 0; i < n; i++) if (b[i].id == q) ...`，比较的是成员 `b[i].id`；
- 用一个标志变量（如 `int found = 0;`）记录是否找到，循环结束后再统一输出结果，避免在循环内反复输出；
- 找到后可以 `break` 提前退出循环（编号唯一时）；
- 输出坐标时括号与逗号要按格式书写：`(%.2f, %.2f)`。

**完成本练习后你将具备的能力**：在结构体数组上做顺序查找、用标志变量组织"查找—判定—输出"流程——实验 C6 的冰块点名、实验 C7 的样本回查都是这一模式。
