# 题目 A5：基于最小二乘拟合的建筑沉降监测数据分析系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套建筑沉降监测数据分析工具。系统读入某测点"观测期号-日期-本期沉降量"监测序列后，先按 3σ 准则筛查并剔除异常观测值，再累加得到累计沉降序列、差分得到沉降速率序列；然后对"累计沉降-时间"做最小二乘线性拟合求沉降发展趋势（斜率与截距），计算相关系数评估拟合质量；用拟合直线外推未来 3 期沉降预测值，按累计沉降与速率双阈值输出预警测点名单，并绘制散点与拟合线字符图，全部结果写入报表。

**解决什么重要问题**：高层建筑、桥梁、地铁隧道周边的既有建筑都必须进行定期沉降监测，监测数据直接决定是否停工加固。原始观测数据受仪器、人员、环境影响必然含粗差（如标尺碰动造成的突跳），不剔除会严重扭曲趋势判断；而"沉降是否趋于稳定"需要从离散观测序列中提取趋势——最小二乘拟合正是工程上提取线性趋势的标准手段。拟合斜率持续不收敛、速率超限都是规范规定的预警判据，判错方向的代价是结构安全事故或昂贵的误加固。

**支撑哪些关键应用**：① 深基坑与地铁施工影响区既有建筑的健康监测报告；② 高层建筑沉降观测数据整理与《沉降观测成果表》编制；③ 大坝、桥梁长期变形监测；④ 后续"工程测量学""结构健康监测""误差理论与测量平差"课程中，最小二乘是平差与回归的核心数学工具，本系统是其最简实现。

**与专业培养的关联**：土木工程专业的测量实习与毕业设计都要处理沉降观测数据。本题目把课程 5.5 节"排序与查找"、数组统计、公式计算组合成一个真实监测业务流程，让学生体会"测量数据 → 清洗 → 建模 → 预警"的完整数据链，为后续学习测量平差与数据分析打基础。

## 二、题目任务与专业关联

本题目面向土木工程方向学生，模拟"沉降监测月报数据处理"场景。系统功能概述：① 读入监测序列文件并按 3σ 准则筛查异常；② 累加得累计沉降、差分得速率；③ 最小二乘拟合累计沉降随时间的线性趋势并求相关系数；④ 外推未来 3 期预测值；⑤ 按"累计沉降 30 mm 或速率 2 mm/期"阈值判定预警；⑥ 绘制散点与拟合线字符图并输出报表。先导知识铺垫：最小二乘斜率 a=(nΣxy-ΣxΣy)/(nΣx²-(Σx)²)、截距 b=(Σy-aΣx)/n、相关系数 r=(nΣxy-ΣxΣy)/√([nΣx²-(Σx)²][nΣy²-(Σy)²])，三个公式直接来自高等数学教材，3σ 准则（|观测值-均值|>3×标准差判为异常）一句话讲清，无需任何额外理论。

## 三、数据来源与格式

**数据文件：单测点监测序列**（`point1.txt`，每组另生成 `point2.txt`、`point3.txt` 供对比）

```
期号,观测日期(第n天),本期沉降量mm
1,0,0.00
2,30,1.82
3,60,1.65
4,90,1.48
5,120,1.36
6,150,1.21
```

字段含义：期号 1～24（约每月一期，监测两年）；观测日期为开工以来天数（0～730，每期间隔约 30 天）；本期沉降量 mm，取值 -0.50～4.00（正常主体施工期 1.0～3.0，后期逐渐衰减至 0.2 以下，正值表示下沉）。

**仿真数据生成规则**：
- 生成 18 期数据：前 12 期按 s(k)=3.0·exp(-k/6)+0.3 的衰减规律取两位小数并叠加 ±0.05 mm 观测噪声（用固定小扰动表给出），后 6 期按 0.2 mm 左右趋稳；
- 异常注入：第 7 期写 `7,180,12.50`（标尺碰动粗差）、第 11 期写 `11,300,-9.80`（符号错误的录入异常），两值均远超 3σ，供筛查模块剔除；
- 三个测点文件用不同衰减系数（4/6/8）与不同注入位置生成，形成"一个预警、一个临界、一个稳定"的对比格局。

**真实数据集**：测绘公开教学数据可参考国家地震科学数据中心（https://data.earthquake.cn/ ）的形变观测数据；课程实验以仿真数据为准，学生可另用实习实测数据替换。

## 四、数据结构设计

```c
#define MAX_PERIOD 24      /* 最大观测期数（两年月观测） */

/* 单期监测记录 */
struct Monitor {
    int    no;             /* 期号 1~24 */
    int    day;            /* 观测日期（开工起天数），0~730，递增 */
    double ds;             /* 本期沉降量 mm，正常 -0.5~4.0 */
    int    flag;           /* 异常标记 0 正常 / 1 粗差剔除 */
};

/* 派生序列（均为按下标对应的一维数组） */
double g_cum[MAX_PERIOD];  /* 累计沉降 mm，0~60 */
double g_rate[MAX_PERIOD]; /* 速率 mm/期，-1~4 */

/* 拟合与统计结果 */
struct FitResult {
    double a;              /* 拟合斜率 mm/天，正常 -0.05~0.02 */
    double b;              /* 拟合截距 mm */
    double r;              /* 相关系数，|r|<=1 */
    double mean, sigma;    /* 原始序列均值与标准差 */
    int    nValid;         /* 有效点数 */
};

/* 全局数据 */
struct Monitor g_mon[MAX_PERIOD];
struct FitResult g_fit;
int    g_cnt;              /* 实际读入期数 */
double g_pred[3];          /* 未来 3 期预测值 mm */
```

预警阈值常量：`CUM_LIMIT=30.0`（mm）、`RATE_LIMIT=2.0`（mm/期）。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 监测数据文件读入模块**（源文件 `MonitIO.c`）

- 功能简介：跳过表头逐行读入期号、日期、本期沉降；检查期号连续、日期递增；支持交互指定测点文件名（默认 point1.txt）；输出读入摘要（期数、时间跨度）。
- 输入：测点监测序列文本文件。
- 输出：`g_mon[]`、`g_cnt`；屏幕读入摘要。

**M2 数据有效性筛查模块**（源文件 `Check.c`）

- 功能简介：对本期沉降序列计算均值与标准差，按 |ds-均值|>3σ 标记异常期（flag=1），打印"期号-数值-偏离倍数"异常清单并从后续计算中剔除；无异常时输出"未发现粗差"。
- 输入：`g_mon[]`。
- 输出：各期 `flag`、`g_fit.mean`、`g_fit.sigma`、有效点数；屏幕筛查报告。

### 第二部分：算法实现（5 个模块）

**M3 累计沉降计算模块**（源文件 `Cumulate.c`）

- 功能简介：按期序累加未剔除期的本期沉降得 g_cum；跳过异常期（其累计值沿用上期并打印"含粗差期未计入"）；输出累计序列表。
- 输入：`g_mon[]`（含 flag）。
- 输出：`g_cum[]`；屏幕累计序列表。

**M4 沉降速率计算模块**（源文件 `Rate.c`）

- 功能简介：相邻两有效期差分除以间隔天数得速率（mm/天）并换算 mm/期；打印速率序列；统计最大速率及其期号。
- 输入：`g_mon[]`、`g_cum[]`。
- 输出：`g_rate[]`；屏幕速率表与最大速率。

**M5 最小二乘拟合模块**（源文件 `LeastSq.c`）

- 功能简介：对有效期的 (day, cum) 数据累加 Σx、Σy、Σxy、Σx² 四个和，按公式求斜率 a 与截距 b 存入 `g_fit`；提供对任意 x 求拟合值的函数 `fitY(double x)` 供预测与绘图共用。
- 输入：有效期数据。
- 输出：`g_fit.a`、`g_fit.b`；拟合函数。

**M6 拟合优度计算模块**（源文件 `LeastSq.c`）

- 功能简介：继续累加 Σy² 求相关系数 r，并计算各点残差（观测-拟合值）的最大绝对值与均方根；打印拟合质量结论（|r|>0.9 为趋势明显，0.7～0.9 为一般，<0.7 提示非线性需分段）。
- 输入：`g_fit` 与原始数据。
- 输出：`g_fit.r`；屏幕优度报告。

**M7 趋势预测模块**（源文件 `Predict.c`）

- 功能简介：以最后一期为基准，用 fitY 外推未来 3 期（间隔 30 天）的累计沉降预测值 g_pred，并给出每期预测增量；打印预测表。
- 输入：`g_fit`、末期日期。
- 输出：`g_pred[3]`；屏幕预测表。

**M8 预警判定模块**（源文件 `Alarm.c`）

- 功能简介：对当前测点按双阈值判定：累计沉降 > 30 mm 或速率 > 2 mm/期输出"红色预警"，接近阈值（80%）输出"黄色关注"，否则"稳定"；支持依次对 point1～point3 三个文件循环判定输出预警名单汇总表。
- 输入：`g_cum[]`、`g_rate[]`、阈值常量。
- 输出：屏幕预警结论与多测点汇总表。

### 第三部分：数据输出（3 个模块）

**M9 散点与拟合线字符图模块**（源文件 `CharPlot.c`）

- 功能简介：把时间轴分 40 列、累计沉降分 20 行，用 `o` 画有效观测散点、`x` 画被剔除点、`*` 按拟合直线位置画拟合线，`#` 画预测点；带坐标刻度与图例。
- 输入：`g_mon[]`、`g_cum[]`、`g_fit`、`g_pred`。
- 输出：屏幕字符散点图。

**M10 分析报表输出模块**（源文件 `Report.c`）

- 功能简介：把原始序列与异常标记、累计与速率表、拟合参数、相关系数、预测值、预警结论写入 `settle_report_point1.txt`（文件名随测点变化），供编制监测月报直接引用。
- 输入：全部全局数据。
- 输出：报表文本文件；屏幕确认信息。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1～M10（M10 为报表）；状态约束：M2 后方可计算，M3、M4 依赖筛查标记，M5～M8 依次依赖前一模块结果，M9、M10 汇总全局数据。

**数据流**：

```
point1.txt ─► M1 读入 ─► g_mon[] ─► M2 3σ筛查(flag) ─┐
                                                     ▼
              M3 累加 ─► g_cum[] ─┬─► M5 最小二乘 ─► g_fit(a,b)
                                  │        │
              M4 差分 ─► g_rate[] │        ├─► M6 相关系数
                                  │        └─► M7 预测 g_pred[]
                                  ▼
              M8 预警判定（多测点循环） ─► 预警名单
                                  │
              M9 字符散点图    M10 报表 settle_report_point1.txt
```

模块间通过全局数组与 `g_fit` 结构体交换数据，`fitY(x)` 函数为 M7 与 M9 共用，接口编码前书面约定。

## 十、选做扩展

1. 滑动平均预处理：对本期沉降序列先做窗口为 3 的滑动平均再拟合，输出原始拟合与滤波后拟合的斜率、相关系数对比表（窗口统计与拟合的组合运用）；
2. 分段拟合：以第 12 期为界对前后两段分别调用 M5 拟合，比较两段斜率以量化"沉降趋稳"程度（函数复用 + 数组分段）；
3. 二分查找反查时间：利用单调拟合函数，用课程二分法反查"累计沉降达到 20 mm 的预测日期"（7.6 节二分法在本题数据上的迁移应用）。
