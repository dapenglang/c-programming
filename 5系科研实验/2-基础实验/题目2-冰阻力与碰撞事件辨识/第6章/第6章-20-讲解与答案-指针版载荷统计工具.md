## 二、预备知识：把"多结果返回"与"只读/可写指针"组装起来（零基础阅读）

### 1. 从"一个函数一件事"到"一组函数一件事"

综合题不是把前面的代码堆在一起，而是让每个函数只干一件明确的事，再用 `main` 把它们串起来。本题的四个环节各由一个函数或一段循环承担：

```
   main
    │  scanf 读入 a[]、thr
    ├─▶ stat(a, n, &mean, &mx, &mn)   ── 多结果返回：一次取回三个统计量
    ├─▶ for 遍历 a，a[i] >= thr 计数   ── 只读遍历 + 计数
    ├─▶ sort_asc(a, n, srt)           ── 只读输入 a，写输出 srt
    └─▶ printf 组装报表
```

### 2. 两种"往外送结果"的方式并用

```
   方式一：return 交回一个值（适合"个数、总和"这种单个量）
   ┌─────────────────────────────────────────────┐
   │  int count;   ← 普通返回值                   │
   └─────────────────────────────────────────────┘

   方式二：指针参数写回（适合"多个结果"或"一批数据"）
   ┌─────────────────────────────────────────────┐
   │  double mean, mx, mn;   ← 传 &mean/&mx/&mn   │
   │  double srt[50];        ← 传 srt（首地址）    │
   └─────────────────────────────────────────────┘
```

本题两种方式都用上了：`stat` 用三个指针参数一次带回三样；`sort_asc` 用一个输出指针把排好序的一整批数写进 `srt`。

### 3. `const` 让"只读"与"可写"泾渭分明

```
   void stat(const double *a, ...)      a 只读：统计不碰原数据
   void sort_asc(const double *a, ..., double *out)   a 只读、out 可写
```

把 `a` 声明成 `const double *`，等于向调用者签字保证"我的统计和排序都不会弄脏你的原始样本"。若在函数里手误写 `a[i] = ...`，编译器立即报错——这正是我们希望的：**错误被拦在编译期，而不是悄悄改坏了实验结果。**

### 4. 排序为什么要"另存一份"

原件 `a` 是只读的（对 `sort_asc` 而言），而排序必然要改数据。解决办法：**先把 `a` 拷贝到可写的 `srt`，再在 `srt` 上排序。** 这样既保护了原样本，又拿到了有序序列：

```
   a:   12.5  30.0   8.4  45.2  20.0  30.0    （只读，始终不变）
                    │ 拷贝
                    ▼
   srt: 12.5  30.0   8.4  45.2  20.0  30.0    （可写，就地排序）
   排序后 srt: 8.4  12.5  20.0  30.0  30.0  45.2
```

一句话：**只读输入 + 拷贝 + 就地排序**，是"既要保护原件、又要排序"的标准套路。

## 三、解题思路

1. **定数据**：`double a[50]` 原样本、`double srt[50]` 排序结果、`mean/mx/mn/thr` 若干标量；
2. **统计函数**：`stat` 用三个指针参数写回均值与最值，`*max = *min = a[0];` 打底；
3. **排序函数**：`sort_asc` 先 `out[i] = a[i]` 拷贝，再冒泡，交换用 `double t`；
4. **超阈计数**：在 `main` 里只读遍历，`if (a[i] >= thr) over++;`
5. **报表输出**：逐行 `printf`，占比 `100.0 * over / n`，`%%` 输出百分号；
6. **排序输出**：循环打印 `srt[i]`，用三目运算符控制空格与换行。

## 四、参考代码

```c
#include <stdio.h>

/* 多结果返回：一次算回均值、最大值、最小值 */
void stat(const double *a, int n, double *mean, double *max, double *min)
{
    double s = 0.0;
    int i;
    *max = *min = a[0];                     /* 用首元素打底 */
    for (i = 0; i < n; i++) {
        s += a[i];
        if (a[i] > *max) *max = a[i];
        if (a[i] < *min) *min = a[i];
    }
    *mean = s / n;
}

/* 拷贝一份到 out 并升序排序（原数组 a 只读） */
void sort_asc(const double *a, int n, double *out)
{
    int i, j;
    for (i = 0; i < n; i++) out[i] = a[i];
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - 1 - i; j++)
            if (out[j] > out[j + 1]) {
                double t = out[j]; out[j] = out[j + 1]; out[j + 1] = t;
            }
}

int main(void)
{
    double a[50], srt[50], mean, mx, mn, thr;
    int n, i, over = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%lf", &a[i]);
    scanf("%lf", &thr);

    stat(a, n, &mean, &mx, &mn);        /* 多结果返回 */
    for (i = 0; i < n; i++)             /* 只读遍历：超阈计数 */
        if (a[i] >= thr) over++;
    sort_asc(a, n, srt);                /* 排序到 srt */

    printf("n = %d\nmean = %.4f\nmax = %.4f\nmin = %.4f\n", n, mean, mx, mn);
    printf("over = %d\nratio = %.2f%%\nsorted = ", over, 100.0 * over / n);
    for (i = 0; i < n; i++)
        printf("%.2f%c", srt[i], i == n - 1 ? '\n' : ' ');
    return 0;
}
```

## 五、运行验证

**样例 1**（n=6，样本 12.5 30.0 8.4 45.2 20.0 30.0，thr=20.0）：均值 146.1/6 = 24.35；max 45.2、min 8.4；超阈（≥20）4 个；占比 4/6 = 66.67%；升序 8.40 12.50 20.00 30.00 30.00 45.20。依次对应程序输出的 `mean/max/min/over/ratio/sorted`，逐项一致 ✓

**样例 2**（n=5，样本 5 15 25 35 45，thr=25）：均值 125/5 = 25；max 45、min 5；超阈（≥25）3 个；占比 3/5 = 60.00%；升序 5.00 15.00 25.00 35.00 45.00。与程序输出逐项一致 ✓

> 说明：函数内部指针地址随运行环境而定，报表只输出统计量与排序结果，与具体地址无关，故换机器结果一致。

## 六、常见错误与讲解

**错误 1：统计函数里把结果写进了形参自己（漏 `*`）**

```c
void stat(const double *a, int n, double *mean, ...) {
    mean = sum / n;   /* 错：改的是形参（地址副本），main 的 mean 没变 */
}
*mean = sum / n;      /* 对：顺着地址写回 main 的变量 */
```
现象：函数算得都对，报表里均值却是随机值。

**错误 2：`sort_asc` 直接对只读数组动手**

```c
void sort_asc(const double *a, int n) {
    ... a[j] = a[j+1]; ...   /* 错：编译报错，a 是只读的 */
}
```
正确做法是先拷贝到可写的 `out` 再排序（或干脆把输入声明成非 `const` 并明确会改动它——但那会破坏"原样本不动"的要求）。

**错误 3：占比用了整数除法**

```c
printf("ratio = %.2f%%\n", 100 * over / n);   /* 若误写成这样，100*over/n 仍是整数除法 */
```
`100 * over` 与 `n` 都是整数，若整除不下取整会把 66.67% 算成 66%。**务必写成 `100.0 * over / n`**，让运算落到浮点域。

**错误 4：输出分隔符处理不当**

```c
for (i = 0; i < n; i++) printf("%.2f ", srt[i]);   /* 行末多空格且无换行 */
```
用三目运算符 `i == n - 1 ? '\n' : ' '` 保证"中间空格、末尾换行"，报表才整齐。
