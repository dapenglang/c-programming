# 第 8 章 练习 07　阻力数组二进制回读

**对应章节**：8 数据持久化存储方法（8.3 文件的打开与关闭、8.4 文件的读写——`fread`）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷数组的二进制回读与统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

练习 06 把一批阻力值以二进制存进了 `loads.bin`。实际工作中，程序重启或换一个模块来跑时，第一件事就是把这份数据读回内存继续处理。本练习用 `fread` 把 `loads.bin` 里的数组读回来，并顺手算出这批阻力值的均值、最大值、最小值——这正是实验 C7 载荷统计模块每次启动都要做的动作。

## 二、任务要求

编写一个完整程序 `read_binary.c`：

1. 以二进制读模式打开文件 `loads.bin`，并检查是否成功；
2. 先从文件开头读入记录个数 $n$（一个整数），再一次性读入 $n$ 个 `double` 型阻力值到数组；
3. 计算这批阻力值的均值、最大值、最小值；
4. 输出读入的个数与三个统计量（均保留 2 位小数），关闭文件。

**数据文件格式约定**

- 文件名：`loads.bin`（由练习 06 的程序生成，字节布局必须完全一致）
- 文件为**二进制文件**，开头 1 个整数 $n$，紧接着 $n$ 个 `double`，连续存放，无分隔符、无换行
- 题目保证文件存在且格式正确，$1 \le n \le 100$

## 三、输入输出格式

**输入**：程序不从键盘读数据，输入全部来自文件 `loads.bin`。

**输出**：屏幕输出 4 行，依次为：
```
读入 X 个阻力值
均值 = X
最大值 = X
最小值 = X
```
其中统计量均保留 2 位小数。

## 四、样例

**样例 1**

`loads.bin` 由练习 06 的样例 1 生成，逻辑内容为：整数 `5`，随后 `12.5 18.3 9.75 21.0 15.5`。

屏幕输出：
```
读入 5 个阻力值
均值 = 15.41
最大值 = 21.00
最小值 = 9.75
```

**样例 2**

`loads.bin` 由练习 06 的样例 2 生成，逻辑内容为：整数 `3`，随后 `10.0 20.0 30.0`。

屏幕输出：
```
读入 3 个阻力值
均值 = 20.00
最大值 = 30.00
最小值 = 10.00
```

## 五、提示

- 二进制读用 `fp = fopen("loads.bin", "rb")`，模式串里的 `b` 表示 binary（二进制）；
- `fread` 的参数顺序与 `fwrite` 完全一致：数据起始地址、单个元素字节数、元素个数、文件指针；
- 读整数用 `fread(&n, sizeof(int), 1, fp);`，读数组用 `fread(a, sizeof(double), n, fp);`；
- 数据的**读取顺序必须与写入顺序一致**：先读整数 $n$，再读数组，否则会整体错位；
- 求均值用累加后除以 $n$；求最大最小值时，可先把第一个元素当作当前最值，再遍历比较。

**完成本练习后你将具备的能力**：用 `rb` 模式打开二进制文件、用 `fread` 读回标量与整个数组、验证"写—读"闭环，并对读回的数据做基本统计——这是实验 C7 载荷统计模块初始化阶段的标准动作。
