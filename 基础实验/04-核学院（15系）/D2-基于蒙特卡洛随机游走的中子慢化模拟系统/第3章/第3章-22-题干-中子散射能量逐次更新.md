# 第 3 章 练习 22　中子散射能量逐次更新

**所属综合实验**：D2（D2-基于蒙特卡洛随机游走的中子慢化模拟系统）

**对应章节**：3 程序控制结构（3.2 选择结构、3.3 循环结构——`while` 循环与提前终止判断）

**场景来源**：综合实验 D2《基于蒙特卡洛随机游走的中子慢化模拟系统》（核学院）——本练习是该实验中"多次散射降低中子能量直至热化"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

裂变产生的中子能量高达 MeV 量级（快中子），而反应堆里真正引发下一次裂变的是能量约 0.025 eV 的**热中子**。中子从快变热的过程叫**慢化**，靠的是与轻核（如水中的氢）反复碰撞，**每碰撞一次就损失一部分能量**。

在慢化模拟（实验 D2）中，工程上常用一个简化的"平均能量保留因子" \(\alpha\) 来刻画每次散射的损失：设本次碰撞前能量为 \(E\)，碰撞后近似为

$$
E_{\text{new}} = \alpha \cdot E
$$

（真实的中子散射能量分布是连续的，这里取平均模型做入门。）模拟的任务是：**从中子初始能量出发，反复散射，直到能量降到热中子阈值附近为止**，同时记录碰撞次数——这需要循环和判断配合。

## 二、任务要求

编写一个完整程序 `neutron_scatter.c`：

1. 从键盘读入初始能量 `E0`（eV，double）、平均能量保留因子 `alpha`（\(0<\alpha<1\)，double）；
2. 程序中用**常量**定义热中子阈值 `E_th = 0.025`（eV）和最大碰撞次数上限 `MAXC = 1000`（防止异常输入导致死循环）；
3. 用**循环**让中子逐次散射：每散射一次能量乘 `alpha`，碰撞次数加 1；每当能量降到阈值以下时**提前结束循环**（判断能量是否小于阈值）；
4. 输出最终碰撞次数 `collisions` 与最终能量 `E`（科学计数法保留 4 位小数）。若达到最大次数仍未热化，则正常输出当前状态。

## 三、输入输出格式

**输入**：一行，两个实数，依次为初始能量 `E0`（eV）和保留因子 `alpha`，用空格分隔。

**输出**：两行。
第一行按格式 `collisions = 结果` 输出碰撞次数（整数）。
第二行按格式 `E = 结果` 输出最终能量，科学计数法保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2000000 0.6
```
输出：
```
collisions = 36
E = 2.0629e-02
```

**样例 2**

输入：
```
2000000 0.5
```
输出：
```
collisions = 27
E = 1.4901e-02
```

## 五、提示

逐次散射的关系是

$$
E_{k} = \alpha^{\,k}\, E_0
$$

模拟的终止条件是"能量降到热中子阈值以下"：

$$
E_k < E_{\text{th}} = 0.025\ \text{eV}
$$

注意判断的**时机**：先做一次散射，再检查是否已降到阈值以下；一旦满足就退出循环，**不要把多算的那一次也计入**。用 `while` 循环配 `if ... break;` 或把条件直接写进 `while` 判断都可以，但要保证"碰撞次数"与"能量"始终对应同一次散射。

**完成本练习后你将具备的能力**：书写 `while` 循环、用 `break` 提前终止、把物理终止条件翻译成判断表达式、在循环中同时更新两个相关变量（能量与计数）——这些是实验 D2 中"中子慢化步进模块"的地基。
