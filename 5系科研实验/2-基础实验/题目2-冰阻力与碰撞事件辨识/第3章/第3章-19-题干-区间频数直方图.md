# 第 3 章 练习 19　区间频数直方图

**对应章节**：3 结构化程序设计方法（3.3 循环结构、3.2 选择结构——if-else 多分支、3.4 关系与逻辑运算）

**场景来源**：综合实验 C7《冰区结构载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷分布直方图统计"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

一批冰载荷样本测出来后，光看一堆数字很难判断它们的分布规律：是集中在低载荷，还是有不少高载荷工况？工程上最常用的办法是做**直方图**——把数值范围分成若干区间，统计每个区间里有多少个样本，再用百分比表示各区间所占的比例。这样一眼就能看出载荷的集中程度，为结构设计的安全裕度提供依据。本练习把载荷范围 `[0, 100]` 分成 5 个区间，对一批样本做频数统计。

## 二、任务要求

编写一个完整程序 `histogram.c`：

1. 从键盘先读入一个整数 `n`（样本个数，题目保证 `1 ≤ n ≤ 100`），再依次读入 `n` 个实数（载荷值，double，题目保证 `0 ≤ 值 ≤ 100`，单位 kN）；
2. 把 `[0, 100]` 划分为 5 个区间：`[0,20)`、`[20,40)`、`[40,60)`、`[60,80)`、`[80,100]`（前 4 个区间左闭右开，最后一个含右端点）；
3. 用 **for 循环逐个读入样本，用 if-else 多分支判断它落在哪个区间**，并把对应区间的计数器加 1（**不使用数组**）；
4. 统计完成后，按区间顺序输出每个区间的样本数与占比（百分比保留 1 位小数）。

## 三、输入输出格式

**输入**：第一行为整数 `n`；后续为 `n` 个实数，数与数之间用空白分隔。

**输出**：共 5 行，按区间从低到高的顺序，每行格式如下（示例）：

```
[  0, 20) : 样本数 (百分比%)
```

即先打印区间标记，再打印该区间样本数，最后打印括号内的百分比，保留 1 位小数。

## 四、样例

**样例 1**

输入：
```
8
12 35 67 88 45 20 78 95
```
输出：
```
[  0, 20) : 1 (12.5%)
[ 20, 40) : 2 (25.0%)
[ 40, 60) : 1 (12.5%)
[ 60, 80) : 2 (25.0%)
[ 80,100] : 2 (25.0%)
```

**样例 2**

输入：
```
5
5 25 65 85 45
```
输出：
```
[  0, 20) : 1 (20.0%)
[ 20, 40) : 1 (20.0%)
[ 40, 60) : 1 (20.0%)
[ 60, 80) : 1 (20.0%)
[ 80,100] : 1 (20.0%)
```

## 五、提示

判断样本 $v$ 落在哪个区间，用一串"从小到大"的比较：$v<20$ 落在第 1 区间，否则 $v<40$ 落在第 2 区间，否则 $v<60$ 落在第 3 区间，否则 $v<80$ 落在第 4 区间，否则（$80\le v\le100$）落在第 5 区间。

写成 if-else 链时，**后一个分支不必再判断下界**——前面的条件已排除了更小的值。每个分支把对应计数器加 1，占比为

$$
\text{占比}_i = \frac{\text{第 } i \text{ 区间样本数}}{n} \times 100\%
$$

五个计数器之和应等于 $n$，可用来自查。

**完成本练习后你将具备的能力**：用 if-else 链做多区间归属判断、用多个计数器做分类统计、把计数换算成百分比——这是实验 C7 中一切分布统计与直方图的基础。
