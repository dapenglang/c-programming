# 第 8 章 练习 10　数据文件统计分析

**对应章节**：8 数据持久化存储方法（8.4 文件的读写——`fscanf` 读到文件尾、结合第 3 章循环统计）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"试验数据文件整体统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

载荷辨识的原始数据文件 `loads.txt` 里，一行一个阻力采样值。拿到这样一份文件，第一步往往是先摸清"家底"：一共多少个数据？平均多大？最大、最小是多少？这三个统计量是判断数据质量、发现异常值的起手式。本练习不改动文件，只把它从头读到尾，边读边统计，最后在屏幕上输出行数、均值、最大值、最小值——这是实验 C7 统计模块读取外部数据后的标准动作。

## 二、任务要求

编写一个完整程序 `file_stat.c`：

1. 以只读模式打开数据文件 `loads.txt`，并检查是否成功；
2. 用循环从文件中逐个读入实数，直到文件结束；每读入一个数，就把它累加到总和、计入个数，并与当前最大值、最小值比较更新；
3. 全部读完后计算均值（总和 ÷ 个数）；
4. 在屏幕上输出数据行数、均值、最大值、最小值（统计量保留 2 位小数）；关闭文件。

**数据文件格式约定**

- 文件名：`loads.txt`（程序运行目录下）
- 文件为纯文本文件，**每行一个实数**（冰阻力值，单位 kN）
- 行末有换行；文件可能有多行，题目保证至少 1 行
- 样例数据行：`12.5`

## 三、输入输出格式

**输入**：程序不从键盘读数据，输入全部来自文件 `loads.txt`。

**输出**：屏幕输出 4 行：
```
共 X 行数据
均值 = X
最大值 = X
最小值 = X
```
其中 `X` 为行数（整数），三个统计量均保留 2 位小数。

## 四、样例

**样例 1**

`loads.txt` 的内容：
```
12.5
18.3
9.75
21.0
15.5
```
屏幕输出：
```
共 5 行数据
均值 = 15.41
最大值 = 21.00
最小值 = 9.75
```

**样例 2**

`loads.txt` 的内容：
```
6.0
14.0
10.0
```
屏幕输出：
```
共 3 行数据
均值 = 10.00
最大值 = 14.00
最小值 = 6.00
```

## 五、提示

- 逐个数读取用 `while (fscanf(fp, "%lf", &v) == 1)`：只要还能成功读到 1 个数就继续，读到文件尾时 `fscanf` 返回值不再是 1，循环自然结束；
- 数个数用一个整数 `count`，累加用一个 `double sum`，每读一个就 `count++`、`sum += v`；
- 最值初值有小技巧：用一个标志位判断"是不是第一个数"，把第一个数同时赋给最大值和最小值，之后逐个比较更新；
- 均值在循环结束后再算：`mean = sum / count;`
- 读完一定要 `fclose`，但**不要**用写模式打开，本练习只读不改。

**完成本练习后你将具备的能力**：用 `fscanf` 配合返回值实现"读到文件尾就停"的循环、边读边做累加与最值统计、把文件数据加工成有意义的指标——这是实验 C7 中"读入试验数据并生成统计量"这类模块的完整雏形。
