## 二、预备知识：蒙特卡洛投点法的基本原理（零基础阅读）

### 1. 问题是怎么来的

$\pi$ 是一个无限不循环的数，没法用有限步算术精确算出来。但换个思路：**如果往一个正方形里均匀地撒点，落在内接圆里的比例应该等于圆与正方形的面积比**。我们不需要精确公式，只要撒得足够多，用"数出来的比例"就能反推出 $\pi$。这就是蒙特卡洛方法的精髓——**用随机试验的频率逼近确定的概率（面积比）**。

### 2. 方法是怎么想出来的

取边长为 1 的正方形 $[0,1)\times[0,1)$，它的面积是 1；在它内部画一个以原点为圆心、半径 1 的四分之一圆（即满足 $x^2 + y^2 \le 1$ 的区域），其面积是 $\pi/4$。均匀投点时，点落入四分之一圆的概率就等于面积之比：

$$
P = \frac{\pi/4}{\,1\,} = \frac{\pi}{4}
$$

进行 $n$ 次独立投点，落在圆内的次数设为 $k$，则频率 $k/n$ 会随 $n$ 增大而接近概率 $P$（大数定律）。于是

$$
\frac{k}{n} \approx \frac{\pi}{4}
\quad\Longrightarrow\quad
\pi \approx 4\cdot\frac{k}{n}
$$

误差大致按 $1/\sqrt{n}$ 缩小，所以 $n$ 越大结果越稳。

### 3. 用本例走一遍

取种子 $r_0 = 1$，按第 15 题的递推生成坐标：

- 前两个随机数 $u_1 = 0.513870,\ u_2 = 0.175741$，构成第 1 个点 $(0.513870,\ 0.175741)$。它到原点的平方距离 $= 0.264062 + 0.030885 = 0.294947 \le 1$，**计入圆形内**；
- 接下来 $u_3 = 0.308652,\ u_4 = 0.534534$，构成第 2 个点。平方距离 $= 0.095266 + 0.285727 = 0.380993 \le 1$，**同样计入**。

如此逐个判断到第 $n$ 个点，统计出总数 $k$，最后 $k/n$ 代入公式求 $\pi$。例如 $n = 10000$ 时数得 $k = 7839$，则 $\pi \approx 4 \times 7839 / 10000 = 3.135600$。

### 4. 编程时怎么用它

三个要点：**① 坐标生成顺序**：一个点要连着取两次随机数，先 $x$ 后 $y$，顺序不能错，也不能只用同一个数当两个坐标；**② 判断与计数**：`if (x*x + y*y <= 1.0) inside++;`，注意写成实数比较（含等号）；**③ 比例计算**：`pi = 4.0 * inside / n;`，`4.0` 一定写成小数，否则 `4*inside/n` 会先做整数除法丢小数。循环上仍用 `for (i=1; i<=n; i++)`，一次循环处理一个点。

## 三、解题思路

1. **常量与变量**：随机数参数同第 15 题；另外需要 `inside`（计数，初值 0）、`x`、`y`、`pi`；
2. **读入** `r0`、`n`，令 `r = r0`；
3. **循环投点**：每次循环内递推两次得到 `x`、`y`，判断 `x*x + y*y <= 1.0`，成立则 `inside++`；
4. **估算并输出**：`pi = 4.0 * inside / n;`，先输出 `inside`，再输出 `pi`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const unsigned long long A = 1103515245ULL;   /* 乘子 */
    const unsigned long long C = 12345ULL;        /* 增量 */
    const unsigned long long M = 2147483648ULL;   /* 模数 = 2^31 */

    unsigned long long r0, r;   /* 种子与当前随机整数 */
    int    n;                   /* 投点总数 */
    int    i;                   /* 循环变量 */
    int    inside = 0;          /* 落在四分之一圆内的点数 */
    double x, y;                /* 当前点的坐标 */
    double pi;                  /* 估算结果 */

    scanf("%llu %d", &r0, &n);

    r = r0;                     /* 从种子出发 */

    for (i = 1; i <= n; i++) {
        /* 连续两个随机数构成一个点 (x, y) */
        r = (A * r + C) % M;
        x = (double)r / (double)M;
        r = (A * r + C) % M;
        y = (double)r / (double)M;

        /* 落在四分之一圆内则计数 */
        if (x * x + y * y <= 1.0) {
            inside = inside + 1;
        }
    }

    /* 用面积比例估算 pi */
    pi = 4.0 * inside / n;

    printf("inside = %d\n", inside);
    printf("pi = %.6f\n", pi);

    return 0;
}
```

## 五、运行验证

| 输入 | 内部点数 | 程序输出 |
|---|---|---|
| 1 1000 | 781 | `inside = 781` / `pi = 3.124000` ✓ |
| 1 10000 | 7839 | `inside = 7839` / `pi = 3.135600` ✓ |
| 1 100000 | 78475 | `inside = 78475` / `pi = 3.139000` ✓ |
| 2024 50000 | 39284 | `inside = 39284` / `pi = 3.142720` ✓ |

可以看到：投点数从 1000 增到 100000，估计值从 3.124 逐步逼近真值 3.141593，**点数越多越准**，正符合蒙特卡洛"误差随 $\sqrt{n}$ 减小"的规律。同一组输入输出完全可复现。

## 六、常见错误与讲解

**错误 1：一个点只用一个随机数**

```c
r = (A * r + C) % M;  x = r/M;  y = r/M;   /* 错：x=y，点全在对角线上 */
```

一个二维点需要**两个独立的坐标**，必须连续递推两次。若偷懒用同一个数，所有点都落在直线 $y=x$ 上，统计彻底失效。

**错误 2：比例计算发生整数除法**

```c
pi = 4 * inside / n;       /* 错：4、inside、n 都是 int，先整除再赋给 double，精度全丢 */
pi = 4.0 * inside / n;     /* 对：4.0 使整个表达式按浮点运算 */
```

**错误 3：判断条件用了严格小于**

```c
if (x*x + y*y < 1.0)       /* 边界点被排除，虽影响极小，但本题要求 <= */
if (x*x + y*y <= 1.0)      /* 对：与题目一致 */
```

**错误 4：忘记给计数变量初值**

```c
int inside;                /* 错：未初始化，其值是内存里的随机数，计数从乱数开始 */
int inside = 0;            /* 对：任何累加/计数变量都必须先清零 */
```
