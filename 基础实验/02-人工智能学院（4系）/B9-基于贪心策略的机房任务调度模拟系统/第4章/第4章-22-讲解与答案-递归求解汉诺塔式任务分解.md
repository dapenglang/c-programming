## 二、预备知识：递归的基本原理（零基础阅读）

### 1. 问题是怎么来的

有一类问题的解法特别有规律：**大问题和它的小问题，解法一模一样，只是规模小一点**。比如"把 $n$ 台机器的任务拆开"，拆成两半之后，每个半边的任务仍然是"把若干台机器的任务拆开"——还是同一个问题，只是数小了。

遇到这种"可以自己套自己"的问题，用**递归**来描述最自然：函数在执行过程中再一次调用自己。

### 2. 递归的两根支柱

一根是**终止条件**：总得有个停止的时候，否则会无限调用下去。本题里"规模已经是最小的 1"就是停止条件，此时直接返回 1，不再拆分。

另一根是**递归步骤**：把当前问题化简成更小的同类问题。本题把 $n$ 拆成两半，对每一半再调用 `split`：

$$
\text{split}(n) = \begin{cases}
1, & n = 1 \\[4pt]
\text{split}\!\left(\lfloor n/2 \rfloor\right) + \text{split}\!\left(\lceil n/2 \rceil\right), & n > 1
\end{cases}
$$

这两根支柱缺一不可：没有终止条件会"栈溢出"崩溃，没有正确的递归步骤则永远解决不了问题。

### 3. 递归是怎么一层层执行的

以 `split(4)` 为例，调用过程像一棵倒挂的树：

```
split(4)
├── split(2)
│   ├── split(1) = 1
│   └── split(1) = 1        -> split(2) 返回 2
└── split(2)
    ├── split(1) = 1
    └── split(1) = 1        -> split(2) 返回 2
                          => split(4) 返回 4
```

每一次"往下调"都等待子结果返回，最后再把结果一层层"往上加"。打印语句放在**递归调用之前**，所以先打印大的拆分，再打印小的拆分，与样例输出顺序一致。

### 4. 用本例走一遍

**例 1**：$n = 2$。

- 不是 1，打印 `split 2 -> 1 + 1`；
- 左半 $\lfloor 2/2 \rfloor = 1$，调 `split(1)` 返回 1；
- 右半 $\lceil 2/2 \rceil = 1$，调 `split(1)` 返回 1；
- 返回 $1 + 1 = 2$。

**例 2**：$n = 4$。

- 打印 `split 4 -> 2 + 2`；
- 调 `split(2)`：打印 `split 2 -> 1 + 1`，返回 2；
- 再调 `split(2)`：又打印 `split 2 -> 1 + 1`，返回 2；
- 返回 $2 + 2 = 4$。

结果与样例完全吻合，说明递归结构正确。

### 5. 编程时怎么用它

代码极短，就一个 `if-else`：

```c
int split(int n) {
    if (n == 1) return 1;              /* 终止条件 */
    int a = n / 2;                     /* 左半，向下取整 */
    int b = n - n / 2;                 /* 右半，向上取整 */
    printf("split %d -> %d + %d\n", n, a, b);
    return split(a) + split(b);        /* 递归步骤 */
}
```

关键点：$\lfloor n/2 \rfloor$ 直接写 `n / 2`（整数除法自动向下取整），$\lceil n/2 \rceil$ 写 `n - n / 2`，两者相加正好等于 $n$。

> **这个思想在综合实验中反复出现**：B9 任务分治、B4 迷宫的深度优先搜索（DFS 本身就是递归）、B7 牛顿迭代，都是"自己调用自己、逐步缩小规模"同一个套路。

## 三、解题思路

1. **终止条件**：`n == 1` 直接返回 1；
2. **拆分**：左半 `a = n / 2`，右半 `b = n - n / 2`；
3. **打印**：在递归调用前打印当前拆分信息；
4. **合并**：返回 `split(a) + split(b)`；
5. **main**：读入 `n`，调用 `split(n)` 并输出返回值。

## 四、参考代码

```c
#include <stdio.h>

/* 递归分解任务：返回拆出的最小任务单元个数 */
int split(int n)
{
    int a, b;

    if (n == 1)                 /* 终止条件：已是最小任务 */
        return 1;

    a = n / 2;                  /* 左半：向下取整 */
    b = n - n / 2;              /* 右半：向上取整，a+b 恰为 n */

    printf("split %d -> %d + %d\n", n, a, b);   /* 拆之前先报告 */

    return split(a) + split(b); /* 递归步骤：两个子任务之和 */
}

int main(void)
{
    int n;   /* 任务规模 */

    scanf("%d", &n);            /* 读入规模 */

    printf("units = %d\n", split(n));   /* 输出最小单元个数 */

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2 | 拆 1+1，两叶子各返回 1，合计 2 | `split 2 -> 1 + 1` / `units = 2` ✓ |
| 4 | 拆 2+2，每个 2 再拆 1+1，4 个叶子 | `split 4 -> 2 + 2` / `split 2 -> 1 + 1` / `split 2 -> 1 + 1` / `units = 4` ✓ |
| 1 | 直接返回 1，无拆分行 | `units = 1` ✓ |
| 5 | 拆 2+3；2→1+1，3→1+2→1+1 | `split 5 -> 2 + 3` / `split 2 -> 1 + 1` / `split 3 -> 1 + 2` / `split 2 -> 1 + 1` / `units = 5` ✓ |

无论如何拆分，最终单元个数都等于原始规模 $n$，符合"叶子数 = 规模"的规律。

## 六、常见错误与讲解

**错误 1：忘记终止条件（最典型）**

```c
int split(int n) {
    int a = n / 2;
    return split(a) + split(n - a);   /* 错：n=1 时 a=0，无限递归 */
}
```

没有 `if (n == 1) return 1;`，递归永远不会停，程序会因栈溢出而崩溃。

**错误 2：一半写成 `n/2` 与 `n/2`，丢失一个**

```c
int a = n / 2, b = n / 2;   /* 错：n 为奇数时 a+b = n-1，会漏掉一个 */
int a = n / 2, b = n - n/2; /* 对：a+b = n 恒成立 */
```

$n = 5$ 时 $\lfloor 5/2 \rfloor = 2$，两半都取 2 只得 4，漏了 1 个单元。

**错误 3：打印语句位置错，输出顺序反了**

```c
return split(a) + split(b);
printf("split ...");     /* 错：永远执行不到，且顺序不符题意 */
```

打印必须在**递归调用之前**，才能输出"先大后小"的顺序。

**错误 4：返回类型写成 void**

```c
void split(int n)     /* 错：无法把子结果相加返回 */
int split(int n)      /* 对 */
```
