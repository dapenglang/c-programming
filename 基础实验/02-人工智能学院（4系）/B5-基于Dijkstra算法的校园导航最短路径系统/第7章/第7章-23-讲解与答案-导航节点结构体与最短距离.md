## 二、预备知识：结构体数组成员访问与极值查找的基本原理（零基础阅读）

### 1. 问题是怎么来的：节点名怎么存

导航节点的信息有两类：**名字**（一串字符）和**距离**（一个整数）。第 7 章练习 21 讲过，用结构体把相关数据打包。这里的新问题是：名字是一串字符，怎么塞进结构体？

答案是**用字符数组当成员**：

```c
struct Node {
    char name[16];    /* 最多存 15 个字符的名字，+\0 结束 */
    int  dist;
    int  fixed;
};
```

`char name[16]` 表示"这个成员是一排 16 个字符柜子"。这样整个 `Node` 就是"名字 + 距离 + 状态"三件东西捆在一起。

### 2. 怎么访问结构体里的字符串成员

访问成员还是用点号，只是这个成员本身是个数组：

```c
nd[i].name        /* 第 i 个节点的名字（整个字符串） */
nd[i].name[j]     /* 第 i 个节点名字的第 j 个字符 */
nd[i].dist        /* 第 i 个节点的距离 */
```

读入名字用 `%s`，**不需要取地址符**：

```c
scanf("%s %d", nd[i].name, &nd[i].dist);
/*             ^^^^^^^^^^^ 数组名即地址，不加 & */
/*                          ^^^^^^^^^ dist 是单个变量，要加 & */
```

这是初学者最容易困惑的地方：**同一个 `scanf` 里，字符数组成员不加 `&`，整型成员要加 `&`**。原因在内存层面很清楚——`nd[i].name` 本身就是一个地址（数组首地址），而 `nd[i].dist` 是一个值，要取出它的地址得用 `&`。

### 3. 遍历结构体数组求最值

求"距离最大的节点"，和第 6 章练习 21 求直方图峰值是同一套逻辑：

1. 先把第 0 个节点的距离当成当前最大；
2. 从第 1 个节点往后走，凡是 `nd[i].dist` 比当前最大还大，就更新最大值、记下是哪个节点；
3. 走完全部，得到结果。

用数学写就是：

$$
maxdist = \max_{0 \le i < n} nd[i].dist
$$

### 4. 用本例走一遍

**样例 1**：节点 lib(250)、canteen(120)、gym(480)。

- 初始最大设为 lib 的 250；
- 看 canteen：$120 > 250$？否，不更新；
- 看 gym：$480 > 250$？是，更新最大为 480、最远节点名为 gym。

结果 `farthest: gym 480`，与样例一致。

**样例 2**：节点 gate(0)、dorm(90)。

- 初始最大设为 gate 的 0；
- 看 dorm：$90 > 0$？是，更新为 90、名为 dorm。

结果 `farthest: dorm 90` ✓。

> **这个思想在综合实验中反复出现**：B5 距离表管理、B2 采样序列最值、B9 找最晚截止的任务、B10 找最相似的文本，都是"遍历结构体数组找最值"同一个套路。

## 三、解题思路

1. **定义类型**：`struct Node { char name[16]; int dist; int fixed; };`；
2. **读入**：循环读 `nd[i].name`（用 `%s`，不加 `&`）与 `&nd[i].dist`，`fixed` 本题统一置 1；
3. **求最远**：设下标记 `far = 0`，循环比较 `nd[i].dist` 与 `nd[far].dist`，更大则更新 `far`；
4. **输出**：先输出 `nd[far]` 的名称与距离，再循环输出全部节点。

## 四、参考代码

```c
#include <stdio.h>

/* 导航节点：名称、当前最短距离、是否已确定 */
struct Node {
    char name[16];   /* 节点名称 */
    int  dist;       /* 从起点算起的最短距离 */
    int  fixed;      /* 是否已确定：1 已定，0 未定 */
};

int main(void)
{
    struct Node nd[8];   /* 结构体数组，最多 8 个节点 */
    int n, i;
    int far = 0;         /* 距离最远的节点下标 */

    scanf("%d", &n);     /* 读入节点个数 */

    /* 读入各节点：名称用 %s（字符数组名不加 &），距离用 %d（要加 &） */
    for (i = 0; i < n; i++) {
        scanf("%s %d", nd[i].name, &nd[i].dist);
        nd[i].fixed = 1;                 /* 本题假设距离均已确定 */
    }

    /* 遍历求距离最远的节点 */
    for (i = 1; i < n; i++) {
        if (nd[i].dist > nd[far].dist)
            far = i;                     /* 严格大于才更新，并列取先出现的 */
    }

    /* 输出最远节点 */
    printf("farthest: %s %d\n", nd[far].name, nd[far].dist);

    /* 按读入顺序输出全部节点 */
    for (i = 0; i < n; i++)
        printf("%s: %d\n", nd[i].name, nd[i].dist);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3 / lib 250 / canteen 120 / gym 480 | 最大 480，节点 gym | `farthest: gym 480` + 三行列表 ✓ |
| 2 / gate 0 / dorm 90 | 最大 90，节点 dorm | `farthest: dorm 90` + 两行列表 ✓ |
| 2 / a 300 / b 100 | 最大 300，节点 a | `farthest: a 300` / `a: 300` / `b: 100` ✓ |
| 1 / only 42 | 只有一项，即最远 | `farthest: only 42` / `only: 42` ✓ |

单节点与多节点情形都正确，说明最值查找与输出都无误。

## 六、常见错误与讲解

**错误 1：字符数组成员误加取地址符（最典型）**

```c
scanf("%s", &nd[i].name);   /* 危险：多数情况仍可运行，但语义错误 */
scanf("%s", nd[i].name);    /* 对：数组名本身就是地址 */
```

虽然不少编译器"容忍"这种写法，但应当养成正确习惯：**数组名不加 `&`，普通变量才加 `&`**。

**错误 2：用 `==` 比较两个字符串**

```c
if (nd[i].name == "gym")     /* 错：比较的是地址，永远不成立 */
if (strcmp(nd[i].name, "gym") == 0)   /* 对：第 8 章会学 strcmp */
```

**错误 3：最值初始化位置错**

```c
int far;                    /* 错：未初始化 */
int far = 0;                /* 对：先假定第 0 个最远 */
```

**错误 4：循环从 0 开始比较自己**

```c
for (i = 0; i < n; i++)     /* 能跑，但第一次是自己比自己，白比一次 */
for (i = 1; i < n; i++)     /* 对：从 1 开始 */
```
