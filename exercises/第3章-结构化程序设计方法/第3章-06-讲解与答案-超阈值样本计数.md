## 二、预备知识："循环 + 判断 + 计数"三件套

### 1. 问题是怎么来的

上一题的累加器是"每个样本都贡献一点什么"（贡献它的值）；本题的计数器是"**满足条件的样本才贡献**"（贡献一个 1）。两者唯一区别是：加什么、什么时候加。"什么时候"由一条 if 判断决定——于是得到统计程序的第二种标准骨架：

```c
for (i = 1; i <= n; i = i + 1) {
    scanf("%lf", &f);
    if (条件)
        count = count + 1;
}
```

### 2. 计数器的三要素

与累加器完全平行：

- **初值**：`count = 0`（int 类型，从零开始数）；
- **增加**：循环体内 `count = count + 1`，只在条件成立时执行；
- **使用**：循环结束后才能拿去算占比。

初值忘清零、使用提前，错误模式与累加器一模一样。

### 3. 百分比里的整数除法陷阱

占比的数学公式是 $\text{ratio} = \dfrac{count}{n} \times 100\%$。C 语言里必须写成实数运算。考察写法：

- `count / n`：两边都是 `int`，做**整数除法**，4/8 的结果不是 0.5 而是 0，再乘 100 还是 0——本题最经典的错误输出就是恒为 `0.00%` 或 `100.00%`；
- `count * 100.0 / n`：`100.0` 是实数，乘法先把左边变成实数，随后除法按实数进行，结果正确；
- `(double) count / n`：强制类型转换，第 2 章介绍过，也正确。

**规则：只要表达式里混有 int 变量做除法，先想办法让其中一方变成实数。**

### 4. "严格大于"的边界归属

题目规定"恰好等于阈值不算超标"，对应关系运算符 `>`。写成 `>=` 会把 850.0 这样的临界样本数进去，统计口径就错了。工程上"是否超标"的口径必须与规范条文逐字对应，写代码前把"等于算不算"这一句找出来。

## 三、解题思路

1. **确定变量**：`n`、`i`、`count` 为 `int`；`t`（阈值）、`f`（当前样本）为 `double`；
2. **一行读入 n 与 t**；
3. **计数器清零** `count = 0`；
4. **for 循环**读入 n 个样本，每个样本判断 `f > t` 成立则 `count++`；
5. **循环后**算占比 `ratio = count * 100.0 / n`；
6. **输出** `count = %d, ratio = %.2f%%`（printf 里百分号要写成 `%%`）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i;           /* 样本个数、循环变量 */
    int count = 0;      /* 计数器：初值必须为 0 */
    double t;           /* 阈值，kN */
    double f;           /* 当前样本，kN */
    double ratio;       /* 超标占比，% */

    scanf("%d %lf", &n, &t);

    for (i = 1; i <= n; i = i + 1) {
        scanf("%lf", &f);
        if (f > t)               /* 严格大于：恰好等于不算 */
            count = count + 1;
    }

    ratio = count * 100.0 / n;   /* 先乘 100.0 避开整数除法 */

    printf("count = %d, ratio = %.2f%%\n", count, ratio);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `8 850` + `861.2 843.5 872.9 838.0 855.4 849.9 866.1 850.0` | 大于 850 的有 861.2、872.9、855.4、866.1 共 4 个；$4/8 \times 100 = 50.00$ | `count = 4, ratio = 50.00%` ✓ |
| `5 900` + `861.2 843.5 872.9 838.0 855.4` | 5 个样本均 < 900，count = 0；$0/5 = 0$ | `count = 0, ratio = 0.00%` ✓ |
| `4 850` + `850 850.0 850 850` | 恰好等于阈值，全部不算超标 | `count = 0, ratio = 0.00%` ✓ |
| `3 800` + `810.2 800 799.5` | 大于 800 的只有 810.2；$1/3 \times 100 = 33.33\ldots$ | `count = 1, ratio = 33.33%` ✓ |

第 4 行验证了占比非整除时的四舍五入输出（33.333… 保留 2 位小数为 33.33）。

## 六、常见错误与讲解

**错误 1：整数除法吞掉小数**

```c
ratio = count / n * 100.0;    /* 错：4/8 先得 0，结果恒为 0 */
ratio = count * 100.0 / n;    /* 对：乘法先化实数 */
```

症状：占比永远是 0 或 100。写完先在心里检查除号两边有没有 int。

**错误 2：计数器不清零**

```c
int count;          /* 错：随机初值 */
int count = 0;      /* 对 */
```

**错误 3：if 与赋值的相对位置写错**

```c
count = count + 1;
if (f > t) ;        /* 错：无条件计数，count 最后等于 n */
```

`count = count + 1` 必须写在 if 的**内部**。规范缩进（if 的下一行缩进一层）能直观暴露这类错位。

**错误 4：printf 里百分号只写一个**

```c
printf("ratio = %.2f%\n", ratio);    /* 错：单独的 % 让输出行为未定义 */
printf("ratio = %.2f%%\n", ratio);   /* 对：%% 才输出一个百分号 */
```
