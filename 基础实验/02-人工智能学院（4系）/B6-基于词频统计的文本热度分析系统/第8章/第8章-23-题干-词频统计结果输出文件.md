# 第 8 章 练习 23　词频统计结果输出文件

**所属综合实验**：B6（B6-基于词频统计的文本热度分析系统）

**对应章节**：8 文件（8.1 文件的概念、8.2 打开与关闭、8.3 读写、8.4 文件定位）、5.1 一维数组、3.3 循环结构、3.2 选择结构

**场景来源**：综合实验 B6《基于词频统计的文本热度分析系统》（人工智能学院）——本练习是该实验中"热度榜报告生成"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

词频统计的最后一步是**生成报告**：把词条按热度（词频）从高到低排好，写进一个文件，方便用户查看和留档。报告里通常还有一行"总词数""总词频"之类的汇总信息。

B6 系统的输出环节就是这样的"排序 + 写文件"。本题把词条数组按词频降序排序，再把结果和汇总信息一起写入指定文件。

## 二、任务要求

编写一个完整程序 `word_report.c`：

1. 从键盘读入两个文件名：输入文件名、输出文件名；
2. 输入文件格式：
   - 第一行整数 $n$（词条数，$1 \le n \le 10$）；
   - 随后 $n$ 行，每行一个字符串（单词）和一个整数（词频），空格分隔；
3. 把词条按**词频从高到低**排序（词频相同时按单词字典序升序）；
4. 把排序结果写入输出文件，格式为每行 `排名. 单词 词频`（排名从 1 开始）；
5. 文件末尾写一行汇总 `total words = n, total count = 词频总和`；
6. **检查 `fopen` 返回值**。

## 三、输入输出格式

**输入**：两行，第一行输入文件名，第二行输出文件名。

**输出**：屏幕输出一行 `report written to <输出文件名>`；报告内容写入输出文件。

## 四、样例

**输入文件 `words.txt`**：
```
3
apple 5
banana 12
cherry 5
```

**运行**：
```
words.txt
report.txt
```

**输出文件 `report.txt`**：
```
1. banana 12
2. apple 5
3. cherry 5
total words = 3, total count = 22
```

**屏幕输出**：
```
report written to report.txt
```

## 五、提示

排序用冒泡法，比较规则是"词频大的往前"：

$$
\text{若 } t[j].count < t[j+1].count \Rightarrow \text{交换}
$$

词频相同时按单词字典序升序，用第 8 章学过的 `strcmp`：

$$
t[j].count = t[j+1].count \ \wedge\ \text{strcmp}(t[j].word, t[j+1].word) > 0 \Rightarrow \text{交换}
$$

写文件用 `fprintf(out, "%d. %s %d\n", rank, t[i].word, t[i].count);`，排名 `rank` 从 1 递增。

词频总和用一个累加器在排序后（或排序前）统计即可。

**完成本练习后你将具备的能力**：把排序与文件输出结合起来、用 `strcmp` 处理并列排序、把结构化结果写成格式化报告——这些是实验 B6 中"报告生成模块"的地基。
