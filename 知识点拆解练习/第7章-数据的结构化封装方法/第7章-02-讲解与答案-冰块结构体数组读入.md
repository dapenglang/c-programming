## 二、预备知识：结构体数组的基本原理（零基础阅读）

### 1. 从"一块冰"到"一冰场冰"

练习 01 里 `struct IceBlock b;` 只能装一块冰。要装 10 块，难道定义 `b1、b2、...、b10` 十个变量吗？那又退回了"散装变量"的老路。第 5 章学过：批量同类型数据用**数组**管理。现在批量管理的是"整个结构体"——把数组的元素类型从 `double` 换成 `struct IceBlock` 即可：

```c
struct IceBlock b[10];    /* 数组 b 的每个元素都是一整个结构体 */
```

### 2. 结构体数组在内存里长什么样

数组元素在内存中**连续存放**，而每个元素本身又是一整块（5 个成员连续打包），所以整体布局是"大块套小格"：

```
b[0]                      b[1]                      b[2]
+----+------+------+-----+-------+----+------+------+-----+ ...
| id |length|width |thick| mass  | id |length|width |thick| ...
+----+------+------+-----+-------+----+------+------+-----+ ...
|<---- 一整块 struct IceBlock --->|<---- 一整块 struct IceBlock --->|
```

第 $i$ 块冰从 `b[i]` 这一大格开始，它的编号、长、宽、厚、质量彼此紧挨着——**一块冰的信息永远不会散架**。访问第 $i$ 块冰的某个属性，写法是"下标在前、点号在后"：`b[i].length`。

### 3. 循环是结构体数组的天然搭档

对 10 个平行变量处理 10 块冰要写 10 遍代码；对结构体数组只需把下标交给循环变量：

```c
for (i = 0; i < n; i++)
    scanf("%d%lf%lf%lf", &b[i].id, &b[i].length, &b[i].width, &b[i].thickness);
```

循环体每转一圈，处理的都是"完整的一块冰"。取成员地址的完整写法 `&b[i].length` 读作"数组第 i 个元素里 length 成员的地址"，优先级上 `b[i]` 先结合、`.` 再结合、`&` 最后取址，不需要加括号。

### 4. 两次遍历是常见工作模式

"先全部读入、再统一输出"分成两个循环完成：第一个循环负责**建立**清单（读入 + 算质量），第二个循环负责**使用**清单（输出 + 累加）。实验 C6 的仿真主循环、C7 的统计模块，都是对这样的清单反复遍历。

## 三、解题思路

1. **定类型**：沿用练习 01 的 `struct IceBlock`；
2. **定数组**：`struct IceBlock b[10];`，另设 `int n` 记录实际冰块数；
3. **第一遍循环**：读入每块冰的编号与尺寸，随读随算 `b[i].mass`；
4. **第二遍循环**：按格式输出每行，同时把 `b[i].mass` 累加进 `total`；
5. **收尾**：输出总质量，保留 2 位小数。

## 四、参考代码

```c
#include <stdio.h>

struct IceBlock {              /* 一块冰的完整信息（同练习 01） */
    int    id;
    double length;
    double width;
    double thickness;
    double mass;
};

int main(void)
{
    const double RHO_ICE = 917.0;   /* 海冰密度 kg/m^3 */
    struct IceBlock b[10];          /* 冰块清单：最多 10 块 */
    int n, i;
    double total = 0.0;             /* 总质量累加器 */

    scanf("%d", &n);                /* 冰块数 */

    /* 第一次遍历：建立清单，随读随算质量 */
    for (i = 0; i < n; i++) {
        scanf("%d%lf%lf%lf", &b[i].id, &b[i].length,
              &b[i].width, &b[i].thickness);
        b[i].mass = b[i].length * b[i].width * b[i].thickness * RHO_ICE;
    }

    /* 第二次遍历：输出清单并累加总质量 */
    printf("编号 长(m) 宽(m) 厚(m) 质量(kg)\n");
    for (i = 0; i < n; i++) {
        printf("%d %.2f %.2f %.2f %.2f\n", b[i].id, b[i].length,
               b[i].width, b[i].thickness, b[i].mass);
        total += b[i].mass;
    }
    printf("总质量 = %.2f kg\n", total);

    return 0;
}
```

## 五、运行验证

| 输入要点 | 手算过程 | 程序输出要点 |
|---|---|---|
| 样例 1（3 块冰） | $m_1 = 1.80 \times 917 = 1650.60$，$m_2 = 0.48 \times 917 = 440.16$，$m_3 = 2.5 \times 2.0 \times 0.4 \times 917 = 2.00 \times 917 = 1834.00$ | 三行清单无误；总质量 $1650.60 + 440.16 + 1834.00 = 3924.76$ → `总质量 = 3924.76 kg` ✓ |
| 样例 2（2 块冰） | $m_1 = 4.80 \times 917 = 4401.60$，$m_2 = 0.40 \times 917 = 366.80$ | 总质量 $4401.60 + 366.80 = 4768.40$ → `总质量 = 4768.40 kg` ✓ |
| 边界 n=1 | 单块冰 `8 1.0 1.0 1.0` → $m = 917.00$ | 清单仅 1 行，总质量 917.00，循环边界正确 ✓ |

## 六、常见错误与讲解

**错误 1：下标与点号的顺序写反**

```c
b.length[i] = ...;    /* 错：length 不是数组，编译报错 */
b[i].length = ...;    /* 对：先定位第 i 个元素，再进它的成员 */
```

**错误 2：循环读入时漏了某个成员**

```c
scanf("%d%lf%lf%lf", &b[i].id, &b[i].length, &b[i].width);   /* 错：漏了 thickness */
```

格式串里有 4 个占位符，参数就必须有 4 个地址，少一个会把后面的数据读串行。建议读入后立刻用样例 1 验证第一行输出是否为 `3 2.00 1.50 0.60 1650.60`。

**错误 3：在循环里重复定义数组或变量名冲突**

```c
for (i = 0; i < n; i++) {
    struct IceBlock b[10];   /* 错：数组应定义在循环外、main 开头 */
    ...
}
```

清单是全程共用的，定义一次即可；在循环内定义会让每圈都"重新造一份"，且循环外不可见。

**错误 4：总质量累加忘记清零或清零位置错误**

```c
double total;                /* 错：未初始化，初值是不确定的垃圾值 */
double total = 0.0;          /* 对：累加器必须先清零 */
```

若把 `total = 0.0;` 误写进输出循环体内，则每圈都被清零，最终总质量只等于最后一块冰的质量。

## 七、与综合实验的衔接

实验 C6 的仿真主程序维护的就是一份结构体数组形式的"冰块清单"：每个时间步长内，程序对清单逐元素遍历，更新位置、检测碰撞。实验 C7 的载荷样本、C9 的测点记录同样以结构体数组形式组织。本练习完成的是"批量建立清单"这一环节；练习 03 将在清单上做**排序**——你会发现排序时交换的是"整个结构体"而不是单个成员，这是结构体数组区别于普通数组的关键操作。
