## 二、预备知识：有序表维护的基本原理（零基础阅读）

### 1. 问题是怎么来的

数组元素在内存中**连续存放**：`a[0]` 紧挨着 `a[1]`，中间没有空隙。这带来一个与链式结构（第 7 章才见）截然不同的后果——**在中间插入或删除元素，必须让两边的元素整体搬家**：

- 插入：把插入点之后的元素**统一后移一格**，腾出空位；
- 删除：把删除点之后的元素**统一前移一格**，补上空洞。

顺序不能乱、方向不能反，否则数据连环覆盖丢失。本练习把这两个搬移工序各走一遍。

### 2. 插入：找位置 → 后移 → 落位

设表长 $n$、插入值 $x$，数据升序：

**第一步找位置**：$x$ 应放在"第一个大于 $x$ 的元素"之前。从前往后扫，第一个满足 `a[i] > x` 的下标 `i` 就是插入点 `p`；若扫完都没有（`x` 最大），`p = n`，即插到末尾。

**第二步后移腾位**：把下标 $n-1, n-2, \ldots, p$ 的元素依次挪到下一格。**必须从后往前搬**：

$$
a[i+1] = a[i], \qquad i = n-1,\, n-2,\, \ldots,\, p
$$

为什么方向不能反？若从 `i = p` 开始，`a[p+1] = a[p]` 先执行，`a[p+1]` 的原值（还没搬走！）就被覆盖了——后面每一次搬都在复制已被污染的值，从 `p` 之后全部变成 `a[p]`。**从后往前**保证每个被写入的格子，其原值已经先搬到了更右边。

**第三步落位**：`a[p] = x`，表长变 $n+1$。

用样例 1 走一遍（数组 `2.5 4.0 6.5 8.0 9.5 12.0`，$x = 7.0$）：第一个大于 7.0 的是 `a[3] = 8.0`，故 $p = 3$；后移过程：

| 搬移步 | 操作 | 数组状态 |
|---|---|---|
| i=5 | a[6] = a[5] = 12.0 | 2.5 4.0 6.5 8.0 9.5 12.0 12.0 |
| i=4 | a[5] = a[4] = 9.5 | 2.5 4.0 6.5 8.0 9.5 9.5 12.0 |
| i=3 | a[4] = a[3] = 8.0 | 2.5 4.0 6.5 8.0 8.0 9.5 12.0 |
| 落位 | a[3] = 7.0 | 2.5 4.0 6.5 **7.0** 8.0 9.5 12.0 |

有序性完好，表长 6 变 7。

### 3. 删除：找位置 → 前移 → 缩短

设删除值 $y$，先顺序查找找到下标 `p`，然后把 $p+1$ 到 $n-1$ 的元素**从前往后**各往前挪一格：

$$
a[i-1] = a[i], \qquad i = p+1,\, p+2,\, \ldots,\, n-1
$$

方向与后移**相反**：前移时每个被写入的格子 `a[i-1]`，其数据来源 `a[i]` 尚未被动过，从前往后先读后写，安全；若从后往前，右端的值会提前被同格内容覆盖。搬完表长减 1，末尾那个重复元素不再属于有效区。

### 4. 容量与表长再次强调

长度 100 的数组最多容纳 100 个元素；本题保证插入后 $n+1 \le 99$，不会越界。程序自始至终用变量 `n` 记录**当前有效长度**，插入后 `n++`、删除后 `n--`，一切循环的上界都跟着它走。

## 三、解题思路

1. 读入 $n$、升序数组、`x` 与 `y`；
2. 插入：扫出 `p`（第一个大于 x 的下标，可能为 n）→ 从后往前 `a[i+1] = a[i]` → `a[p] = x` → `n++`；
3. 删除：扫出值等于 y 的下标 `p` → 从前往后 `a[i-1] = a[i]` → `n--`；
4. 输出前 `n` 个元素，`%.2f` 与空格分隔。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double a[100];    /* 冰块质量有序表 */
    double x, y;
    int n, i, p;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &a[i]);
    scanf("%lf %lf", &x, &y);

    /* ---- 插入 x：找位置 → 从后往前腾位 → 落位 ---- */
    p = n;                          /* 默认插到末尾 */
    for (i = 0; i < n; i++)
        if (a[i] > x) { p = i; break; }
    for (i = n - 1; i >= p; i--)    /* 从后往前搬，防止覆盖 */
        a[i + 1] = a[i];
    a[p] = x;
    n++;                            /* 表长加 1 */

    /* ---- 删除 y：找位置 → 从前往后补位 → 表长减 1 ---- */
    for (i = 0; i < n; i++)
        if (a[i] == y) { p = i; break; }
    for (i = p + 1; i < n; i++)     /* 从前往后搬 */
        a[i - 1] = a[i];
    n--;                            /* 表长减 1 */

    printf("%.2f", a[0]);
    for (i = 1; i < n; i++)
        printf(" %.2f", a[i]);
    printf("\n");

    return 0;
}
```

## 五、运行验证

**样例 1**（x=7.0 插入、y=8.0 删除）：

| 阶段 | 操作 | 数组有效区 |
|---|---|---|
| 初始 | 读入 | 2.50 4.00 6.50 8.00 9.50 12.00（n=6） |
| 插入定位 | 第一个 >7.0 的是 a[3]=8.0，p=3 | — |
| 插入搬移 | i=5,4,3 依次后移 | 2.50 4.00 6.50 8.00 8.00 9.50 12.00（临时态） |
| 插入落位 | a[3]=7.0，n=7 | 2.50 4.00 6.50 7.00 8.00 9.50 12.00 |
| 删除定位 | a[4]=8.0，p=4 | — |
| 删除搬移 | i=5,6 前移 | 2.50 4.00 6.50 7.00 9.50 12.00（n=6） |

输出 `2.50 4.00 6.50 7.00 9.50 12.00`，与样例一致。

**样例 2**（x=10.5 插入队尾、y=1.2 删除队头）：插入定位时无元素大于 10.5，p=5，搬移循环一次不执行，直接 `a[5]=10.5`；删除 p=0，前移 5 次后表长 5。输出 `3.40 5.60 7.80 9.90 10.50`，与样例一致——**插入到末尾与删除队头两个边界均正确**。

## 六、常见错误与讲解

**错误 1：后移方向反了（最高发）**

```c
for (i = p; i < n; i++) a[i+1] = a[i];    /* 错：从前往后，p 之后的值全被 a[p] 覆盖 */
for (i = n - 1; i >= p; i--) a[i+1] = a[i];   /* 对：从后往前，先搬走再覆盖 */
```

**错误 2：删除后忘改表长或改错**

```c
/* 删除搬移后忘记 n-- ：输出多出一个末尾重复元素 */
n--;   /* 对：有效长度减 1 */
```

**错误 3：插入定位条件方向性想反**

```c
if (a[i] < x) { p = i; break; }   /* 错：找到的是第一个小于 x 的位置，破坏升序 */
if (a[i] > x) { p = i; break; }   /* 对：第一个大于 x 的元素之前是 x 的家 */
```

**错误 4：插入搬移循环的起点写成 `i = n`**

```c
for (i = n; i >= p; i--) a[i+1] = a[i];   /* 错：i=n 时写 a[n+1]，且 a[n] 本无有效数据，白白越界 */
for (i = n - 1; i >= p; i--) a[i+1] = a[i];   /* 对：最后一个有效元素是 a[n-1] */
```
