# 第 8 章 练习 05　字符级读写统计

**对应章节**：8 数据持久化存储方法（8.4 文件的读写——`fgetc`/`fputc`）

**场景来源**：综合实验 B6《英文文本词频统计系统》（人工智能学院）——本练习是该实验中"文本预处理与字符分类统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

英文文本词频统计的第一步，是把一篇文章当作一串字符整体看一遍：里面有多少字母、多少数字、多少空格、多少换行？这些统计量既用于评估文本规模，也用于后续的分词准备。要做到"一个字符都不漏"，就得按**字符**为单位读取文件——这正是 `fgetc` 的用武之地。本练习读入文本文件 `text.txt`，逐字符分类统计，并把统计结果写到 `stat.txt`。

## 二、任务要求

编写一个完整程序 `char_stat.c`：

1. 以只读模式打开文本文件 `text.txt`，以写模式新建统计结果文件 `stat.txt`，两个文件都要检查是否打开成功；
2. 用 `fgetc` 逐个读取字符，直到文件结束；每读到一个字符，**总数加 1**，并按类别分别计数：字母（`isalpha`）、数字（`isdigit`）、空格（`' '`）、换行（`'\n'`）、其他；
3. 把六项统计结果同时写到屏幕和结果文件 `stat.txt`；
4. 关闭两个文件。

**数据文件格式约定**

- 输入文件名：`text.txt`；输出文件名：`stat.txt`
- 均为纯文本文件，`text.txt` 内容为任意英文文本（可含字母、数字、空格、换行）
- 统计结果文件 `stat.txt` 每行一项，格式为 `名称 数量`
- 样例数据行（`text.txt`）：`Ice load 2026`

## 三、输入输出格式

**输入**：程序不从键盘读数据，输入全部来自文件 `text.txt`。

**输出**：屏幕与文件 `stat.txt` 均输出以下 6 行（顺序固定）：
```
字符总数 X
字母 X
数字 X
空格 X
换行 X
其他 X
```
其中 `X` 为对应的统计数量。

## 四、样例

**样例 1**

`text.txt` 的内容（注意两行末尾各有一个换行）：
```
Ice load 2026
ship 3 knots
```
屏幕输出与 `stat.txt` 的内容均为：
```
字符总数 27
字母 16
数字 5
空格 4
换行 2
其他 0
```

**样例 2**

`text.txt` 的内容：
```
A1 b2
```
屏幕输出与 `stat.txt` 的内容均为：
```
字符总数 6
字母 2
数字 2
空格 1
换行 1
其他 0
```

## 五、提示

- 逐字符读的固定写法：`while ((c = fgetc(fp)) != EOF) { ... }`。`fgetc` 每次返回一个字符，读到文件末尾返回宏 `EOF`（值为 -1），循环结束；
- `c` 必须声明成 `int` 而不是 `char`，否则无法与 `EOF` 正确比较（教材 8.4 有专门说明）；
- 字母、数字判断用标准函数 `isalpha(c)`、`isdigit(c)`，需要 `#include <ctype.h>`；
- 用一个 `long` 或 `int` 变量累计总数，其余五个变量各自累加；注意用 `else if` 保证每个字符只归入一类；
- 写文件用 `fprintf` 一行一项即可，与练习 01 的写法相同。

**完成本练习后你将具备的能力**：用 `fgetc` 逐字符读文件、用 `EOF` 判断文件结束、用 `ctype.h` 的字符分类函数做统计——这是实验 B6 文本词频系统中"文本预处理"环节的核心技能，也是所有"逐字符扫描"类程序的通用模板。
