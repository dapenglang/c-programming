# 第 3 章 练习 37　深度跳变阈值判定

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：3 选择结构（if-else、多分支、关系与逻辑运算符）；3.x 复合条件

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"阈值跳变判决"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

练习 32 已经学会计算相邻两 ping 的深度差分 $\Delta d$。但差分只是一个数——**多大才算"海底跳变"？**这需要一把尺子：**阈值 $T$**。

综合实验 C6 的第 6 模块"阈值跳变判决"用三级标准给每对相邻深度定性：

- $|\Delta d| > 2T$：深度发生**阶跃跳变**（疑似海底断层或跃出/落入其他地形）；
- $T < |\Delta d| \le 2T$：**斜坡缓变**（海底有一定起伏，但连续）；
- $|\Delta d| \le T$：**平稳**（正常海底）。

注意：深度差有正负，但"跳变"只看**变化幅度**，所以判决前先取绝对值。本题读入阈值和一对深度，输出判决结论。

## 二、任务要求

编写一个完整程序 `jump_judge.c`：

1. 从键盘读入三个 double：判决阈值 `T`（m）、上一 ping 深度 `d0`（m）、当前 ping 深度 `d1`（m）；
2. 计算差分 $\Delta d = d_1 - d_0$，并取绝对值 $A = |\Delta d|$（可用 `math.h` 的 `fabs`，或自行用 if 分支处理）；
3. 按三级标准判决并输出对应结论（三选一，只输出一行）：
   - `step jump`（$A > 2T$）；
   - `gentle slope`（$T < A \le 2T$）；
   - `steady`（$A \le T$）；
4. 用**多分支 if-else** 实现，输出格式见样例。

## 三、输入输出格式

**输入**：一行三个实数，用空格分隔：`T d0 d1`。

**输出**：一行判决结论，三种可能：

```
step jump
gentle slope
steady
```

## 四、样例

**样例 1**（阶跃）

输入：
```
0.5 150.0 153.2
```
输出：
```
step jump
```
（$A = 3.2 > 2T = 1.0$）

**样例 2**（斜坡，恰在边界）

输入：
```
0.5 150.0 151.0
```
输出：
```
gentle slope
```
（$A = 1.0$，**不大于** $2T = 1.0$，落入第二档 $T < A \le 2T$）

**样例 3**（平稳）

输入：
```
0.5 150.0 150.4
```
输出：
```
steady
```

## 五、提示

- 判决依据是**绝对值**：$\Delta d = -3.2$ 同样是阶跃（海底变浅的断层）；
- 三档条件写法（自上而下排除）：
  ```c
  if (A > 2 * T)            printf("step jump\n");
  else if (A > T)           printf("gentle slope\n");
  else                      printf("steady\n");
  ```
  自上而下判、命中即出——第二档不需要再写 `A <= 2*T`，因为走到 `else if` 时上档已排除；
- 边界即规则：$A = 2T$ 恰好**不算**阶跃（判据是严格大于 $>$），样例 2 专门检验这一点；
- 想一想：如果把三档写成三个并列 `if`（而不是 `if / else if / else`），样例 2 会不会输出两行？为什么？

**完成本练习后你将具备的能力**：用 if-else 多分支实现三级阈值判决、正确处理边界条件（$>$ 与 $\le$ 的搭配）——这是 C6 实验判决模块对每个差分点做的事。
