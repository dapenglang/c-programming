## 二、预备知识：百分比在程序中的表示与运算（零基础阅读）

### 1. 问题是怎么来的

工程数据里常给出"各部分占总量的百分之几"。比如总阻力 500 kN，其中破冰分量占 40%。这个"40%"在纸上写成带百分号的数，可程序里**没有百分号这种数据类型**——键盘敲进去的 `40` 只是一个普通实数。所以第一步要弄明白：程序里的 `40` 和数学上的 40% 差了一个"除以 100"。

### 2. 换算关系是怎么来的

按定义，$p\%$ 就是 $\dfrac{p}{100}$。若总量是 $R$，占 $p\%$ 的那一部分就是

$$
R_i = R \times \frac{p_i}{100}
$$

例如 500 kN 的 40%：$500 \times \dfrac{40}{100} = 500 \times 0.4 = 200$ kN。

因为三个占比之和是 100%，把它们折算出的三个分量相加，恰好等于总阻力：

$$
R_1 + R_2 + R_3 = R\times\frac{100}{100} = R
$$

这条"守恒"关系正好可以用来验算程序对不对。

### 3. 用本例走一遍

总阻力 500 kN，占比 40、35、25：

- 破冰：$500\times40/100 = 200$ kN；
- 摩擦：$500\times35/100 = 175$ kN；
- 排开：$500\times25/100 = 125$ kN；
- 验算：$200+175+125 = 500$ kN，与总量一致，说明折算正确。

### 4. 编程时要注意什么

（1）**除数要保证是浮点**。写 `R * p / 100` 时，如果 `p` 是 `double`，`100` 是整型常量，C 会自动把 `100` 提升为 `100.0` 再做浮点除法，结果正确。但如果是 `int p = 40;` 再用 `R * p / 100`，`R` 是 double 也能把整个表达式变成浮点，这属于"混合类型运算自动提升"。最稳妥的写法是把 `100.0` 显式写成小数。

（2）**一次读多个数**。`scanf("%lf %lf %lf %lf", &R, &p1, &p2, &p3)` 中每一对 `%lf` 对应一个 `&变量`，顺序不能乱、`&` 不能漏。

## 三、解题思路

1. **备常量与变量**：定义折算基数 `const double BASE = 100.0`；变量 `R, p1, p2, p3` 与三个结果；
2. **读入**：一行读入四个数，用 `%lf`；
3. **折算**：分别算 `R1 = R * p1 / BASE`，`R2`、`R3` 同理；
4. **输出**：三行，各自 `%.4f`；
5. **自检**：心里把三个结果相加，看是否等于 R。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double BASE = 100.0;   /* 百分比折算基数 */

    double R;    /* 输入：总冰阻力，kN */
    double p1;   /* 输入：破冰占比，% */
    double p2;   /* 输入：摩擦占比，% */
    double p3;   /* 输入：排开占比，% */
    double R1, R2, R3;   /* 输出：三个分量阻力，kN */

    /* 一行读入总阻力与三个占比 */
    scanf("%lf %lf %lf %lf", &R, &p1, &p2, &p3);

    /* 按百分比折算各分量：分量 = 总量 * 占比 / 100 */
    R1 = R * p1 / BASE;
    R2 = R * p2 / BASE;
    R3 = R * p3 / BASE;

    /* 分行输出，均保留 4 位小数 */
    printf("R_break = %.4f kN\n", R1);
    printf("R_friction = %.4f kN\n", R2);
    printf("R_displace = %.4f kN\n", R3);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 500 40 35 25 | $500\times40/100=200$；$500\times35/100=175$；$500\times25/100=125$ | `R_break = 200.0000 kN` 等三行 ✓ |
| 320 50 30 20 | $320\times50/100=160$；$320\times30/100=96$；$320\times20/100=64$ | `R_break = 160.0000 kN` 等三行 ✓ |
| 450 30 45 25 | $450\times30/100=135$；$450\times45/100=202.5$；$450\times25/100=112.5$ | `R_break = 135.0000 kN` 等三行 ✓ |

每一行三个结果相加都等于输入的总阻力，与守恒关系一致，说明折算无误。

## 六、常见错误与讲解

**错误 1：把百分号当成运算符敲进程序**

```c
R1 = R * p1 % 100;   /* 错：% 是取余运算符，不是百分号 */
R1 = R * p1 / 100;   /* 对：占比除以 100 才是真实比例 */
```

```c
printf("占比 = %d %\n", p1);    /* 错：单独一个 % 会让后面的格式错乱 */
printf("占比 = %d %%\n", p1);   /* 对：要输出百分号本身须写 %% */
```

**错误 2：整数除法丢失小数**

```c
int p1 = 35;  R1 = 500 * p1 / 100;   /* 危险：若 R 也是整数，500*35/100 = 175 恰好整除还好，*/
                                      /* 但 450*25/100 若中间顺序不同可能截断，规律难以把握 */
double p1 = 35; R1 = 450.0 * p1 / 100.0;  /* 对：全程浮点，结果 112.5 */
```

**错误 3：scanf 漏写 `&` 或数与变量对不上**

```c
scanf("%lf %lf %lf %lf", &R, &p1, &p2);   /* 错：只给了 3 个地址，p3 读不到；参数个数必须与 %lf 个数一致 */
```

**错误 4：只算了一个分量就照抄**

三个分量表达式只是把 `p1` 依次换成 `p2`、`p3`，输出时变量也要一一对应，不要写成 `R1, R1, R1` 或把 `R_friction` 的行打印成 `R1`。

## 七、与综合实验的衔接

- 在实验 **C7（冰阻力与碰撞事件辨识）**中，本练习对应"阻力分量拆解"环节：真实程序会先由冲量-动量反演出总阻力，再用读入的分量比例表把它拆开，分别与破冰强度、摩擦系数等指标比较；
- 到了第 3 章（循环），当要给成百上千个碰撞样本都做一次折算时，就会把这些算式放进循环体；第 4 章会把它们封装成一个 `split_resistance()` 函数。本题先把"一次折算"写对，是最小可用的地基。
