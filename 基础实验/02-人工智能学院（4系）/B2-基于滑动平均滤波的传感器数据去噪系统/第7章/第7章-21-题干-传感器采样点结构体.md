# 第 7 章 练习 21　传感器采样点结构体

**所属综合实验**：B2（B2-基于滑动平均滤波的传感器数据去噪系统）

**对应章节**：7 构造数据类型（7.1 结构体类型的定义、7.2 结构体变量的定义与初始化、7.3 结构体成员的访问、3.4 标准输入输出）

**场景来源**：综合实验 B2《基于滑动平均滤波的传感器数据去噪系统》（人工智能学院）——本练习是该实验中"采样记录管理"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

传感器采集数据时，每一个采样点其实包含**好几条信息**：它是第几个点（序号）、采集的时刻、以及读到的数值。如果只用一个数组存数值，序号和时间就丢了；如果分别用三个数组，又容易对不上号。

更好的办法是把"属于同一个采样点的几条信息**打包**在一起"，当成一个整体来处理。这就是**结构体**：它让程序用"一条记录"的方式管理数据。B2 系统在建立采样序列时，就是用结构体来记录每个采样点的。

## 二、任务要求

编写一个完整程序 `sample_point.c`：

1. 定义结构体类型
   ```c
   struct Sample {
       int    id;      /* 采样序号 */
       double time;    /* 采样时刻，单位：秒 */
       double value;   /* 采样数值（电压，单位：伏） */
   };
   ```
2. 在 `main` 中定义一个该类型的结构体变量 `s`；
3. 从键盘读入三个数：序号 `id`（整数）、时刻 `time`（实数）、数值 `value`（实数）；
4. 把它们分别存入 `s` 的三个成员，然后按规定格式输出。

## 三、输入输出格式

**输入**：一行，三个数——整数 id、实数 time、实数 value，用空格分隔。

**输出**：一行，按格式 `Sample #序号 @时刻s value = 数值V` 输出，时刻保留 3 位小数、数值保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
1 0.001 3.30
```
输出：
```
Sample #1 @0.001s value = 3.30V
```

**样例 2**

输入：
```
5 0.005 2.75
```
输出：
```
Sample #5 @0.005s value = 2.75V
```

## 五、提示

结构体类型定义后，就用它来"声明变量"，写法是 `struct Sample s;`（`struct Sample` 是类型名，`s` 是变量名）。

访问结构体里的成员，用**点号**：

```c
s.id      /* 采样序号 */
s.time    /* 采样时刻 */
s.value   /* 采样数值 */
```

读入时注意取的是成员的地址：

```c
scanf("%d %lf %lf", &s.id, &s.time, &s.value);
```

输出时直接写成员名即可。

**完成本练习后你将具备的能力**：定义结构体类型、定义结构体变量、用点号访问成员、把结构体当整体读写——这些是实验 B2 中"采样记录模块"的地基。
