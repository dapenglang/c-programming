# 第 8 章 练习 21　风压系数表文件读写

**所属综合实验**：A1（A1-基于线性插值的风荷载计算系统）

**对应章节**：8 数据持久化存储方法（8.1 文件的打开与关闭、8.2 文本文件读写、8.3 文件的读写循环）

**场景来源**：综合实验 A1《基于线性插值的风荷载计算系统》（航建学院）——本练习是该实验中"系数表文件加载与结果回写"环节的实现。

**建议用时**：25～30 分钟

## 一、应用场景

风荷载系统 A1 的系数表不应该写死在程序里——规范更新时要能直接换数据文件。合理的做法是：**把系数表存在文本文件里**，程序运行时读入；计算完再**把结果写回另一个文件**保存。

这样，数据与程序分离，换一套规范数据只需换文件。本练习模拟这个流程：从 `wind_in.txt` 读入高度-系数表，把每个高度对应的风压（系数 × 基本风压）算出来，写入 `wind_out.txt`。

风压计算式：

$$
w_k = \mu_z \times w_0
$$

其中 $w_0$ 为基本风压（kN/m²）。

## 二、任务要求

编写一个完整程序 `wind_file.c`：

1. 从文件 `wind_in.txt` 读入：第一行为基本风压 $w_0$，之后每行一个高度 $h$ 和对应系数 $\mu_z$（直到文件结束）；
2. 对每条记录计算风压 $w_k = \mu_z \times w_0$；
3. 把结果写入文件 `wind_out.txt`，每行形如 `h=高度 wk=风压`；
4. **必须检查 fopen 的返回值**：打开失败要给出错误提示并退出。

## 三、输入输出格式

**输入**：文件 `wind_in.txt`。第一行一个实数（基本风压 $w_0$，kN/m²）；随后每行两个实数（高度 m、系数）。

**输出**：文件 `wind_out.txt`。每行 `h=高度m wk=风压kN/m2`，风压保留 3 位小数；同时屏幕输出处理记录条数 `rows=条数`。

## 四、样例

**输入文件 wind_in.txt**：
```
0.55
10 1.00
20 1.23
30 1.42
```
**输出文件 wind_out.txt**：
```
h=10 wk=0.550
h=20 wk=0.677
h=30 wk=0.781
```
**屏幕输出**：
```
rows=3
```

**样例 2**

**输入文件 wind_in.txt**：
```
0.60
15 1.14
40 1.56
```
**输出文件 wind_out.txt**：
```
h=15 wk=0.684
h=40 wk=0.936
```
**屏幕输出**：
```
rows=2
```

## 五、提示

**文件操作四步曲**：打开 `fopen` → 读或写 → 关闭 `fclose` → 检查是否成功。

```c
FILE *fin = fopen("wind_in.txt", "r");   /* "r" 读模式 */
if (fin == NULL) {                       /* 必须检查！ */
    printf("open input failed\n");
    return 1;
}
```

**读写循环**：用 `fscanf` 从文件读，用 `fprintf` 往文件写，用法与 `scanf`/`printf` 相同，只是第一个参数是文件指针：

```c
while (fscanf(fin, "%lf %lf", &h, &mz) == 2) {   /* 读到两个数就继续 */
    fprintf(fout, "h=%.0f wk=%.3f\n", h, mz * w0);
}
```

**结束条件**：`fscanf` 返回**成功读到的项数**，读不到两个数（遇到文件尾）就返回非 2，循环结束。

**完成本练习后你将具备的能力**：用 `fopen`/`fclose` 打开关闭文件；用 `fscanf`/`fprintf` 读写文本文件；用返回值判断读到文件尾；检查文件打开是否成功。
