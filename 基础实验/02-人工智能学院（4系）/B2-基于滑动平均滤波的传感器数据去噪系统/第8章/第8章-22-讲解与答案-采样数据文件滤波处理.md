## 二、预备知识：文件读写与"读—算—写"流程的基本原理（零基础阅读）

### 1. 问题是怎么来的："离线处理"为什么要把数据落盘

键盘输入适合小数据量的交互，但传感器可能一次记录几万个点。把这些数据**先存成文件**，程序再慢慢处理，好处有三：

- **可重复**：同一份原始数据可以用不同参数反复处理，比较效果；
- **可追溯**：原始数据保留不动，结果另存，出问题能回查；
- **可批处理**：一次处理很多文件，不必人工输入。

### 2. 文件操作的回顾：四步曲

第 8 章练习 21 讲过文件操作的骨架：

```
① fopen（打开，判 NULL）  ② fscanf/fprintf（读写）  ③ fclose（关闭）
```

本题用的是**文本模式**：

- `fscanf(fp, "%lf", &x)` 从文件里"读出一个数"，和 `scanf` 用法相同，只是多一个文件指针；
- `fprintf(out, "%.4f\n", y)` 往文件里"写一个数"，和 `printf` 相同，只是多一个文件指针。

### 3. 打开模式的区别（本题为什么读用 r、写用 w）

- 读文件用 `"r"`：文件必须存在，否则返回 `NULL`；
- 写结果用 `"w"`：文件不存在会**新建**，已存在会**清空**。本题的输出文件是"新结果"，用 `"w"` 正好（旧结果本就该被新结果替换）。

**要特别小心**：绝不能用 `"w"` 打开输入文件，否则原始数据会被清空——这是文件程序最危险的低级错误。

### 4. 为什么能把"滤波"和"文件"接起来

滤波需要看到**整个序列**（因为要用到某个点的左右邻居），所以流程必须是"先全部读进数组，再逐个计算，最后逐个写出"：

$$
\underbrace{\text{读入 } a_0 \sim a_{n-1}}_{\text{数组}} \Rightarrow \underbrace{\bar{a}_i = \frac{1}{m}\sum_{k=i-1}^{i+1}a_k}_{\text{逐点滤波}} \Rightarrow \underbrace{\text{写出 } \bar{a}_0 \sim \bar{a}_{n-1}}_{\text{写文件}}
$$

这正好把第 5 章（数组）、第 4 章（函数）、第 8 章（文件）串成一条完整的处理链。

### 5. 用本例走一遍

数据 $a = (10,12,14,16,18)$，$n = 5$。

- $i=0$：窗口 $-1,0,1$，越界一个，取 $(10+12)/2 = 11.0000$；
- $i=1$：窗口 $0,1,2$，取 $(10+12+14)/3 = 12.0000$；
- $i=2$：窗口 $1,2,3$，取 $(12+14+16)/3 = 14.0000$；
- $i=3$：窗口 $2,3,4$，取 $(14+16+18)/3 = 16.0000$；
- $i=4$：窗口 $3,4,5$，越界一个，取 $(16+18)/2 = 17.0000$。

写出的 5 行正是 $11,12,14,16,17$，与样例一致。

> **这个思想在综合实验中反复出现**：B2 离线滤波、B1 图像批处理、B5 读入地图做路径规划、D3 读截面表做插值，全都是"读文件 → 计算 → 写文件"同一个套路。

## 三、解题思路

1. **读文件名**：两条 `scanf`；
2. **打开输入**：`fopen(inName, "r")`，判 `NULL`；
3. **读数据**：先 `fscanf` 读 $n$，再循环读 $n$ 个实数进数组 `a[]`；
4. **打开输出**：`fopen(outName, "w")`，判 `NULL`；
5. **逐点滤波并写出**：循环调用 `smooth`，`fprintf` 写入；
6. **关闭并提示**。

## 四、参考代码

```c
#include <stdio.h>

/* 三点滑动平均：以 i 为中心，越界点自动跳过 */
double smooth(double *a, int n, int i)
{
    double sum = 0.0;
    int m = 0, k;

    for (k = i - 1; k <= i + 1; k++) {
        if (k >= 0 && k < n) {      /* 只累加有效下标 */
            sum += a[k];
            m++;
        }
    }
    return sum / m;
}

int main(void)
{
    char inName[64], outName[64];
    FILE *in, *out;
    double a[50];       /* 原始采样序列 */
    int n, i;
    double y;

    scanf("%s", inName);
    scanf("%s", outName);

    /* 打开输入文件并检查 */
    in = fopen(inName, "r");
    if (in == NULL) {
        printf("cannot open %s\n", inName);
        return 1;
    }

    /* 读入点数与全部采样值 */
    fscanf(in, "%d", &n);
    for (i = 0; i < n; i++)
        fscanf(in, "%lf", &a[i]);
    fclose(in);              /* 数据已全部读入，可关闭输入 */

    /* 打开输出文件并检查 */
    out = fopen(outName, "w");
    if (out == NULL) {
        printf("cannot open %s\n", outName);
        return 1;
    }

    /* 逐点滤波并写出结果 */
    for (i = 0; i < n; i++) {
        y = smooth(a, n, i);
        fprintf(out, "%.4f\n", y);
    }
    fclose(out);

    printf("done: %d points\n", n);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：不检查 fopen（最典型）**

```c
in = fopen(inName, "r");
fscanf(in, "%d", &n);      /* 错：in 可能为 NULL */
```

**错误 2：边界点除法用错**

```c
return sum / 3;            /* 错：i=0 时只有 2 个点，除 3 结果偏小 */
return sum / m;            /* 对：除以实际点数 */
```

**错误 3：读文件后忘记关闭，或关闭时机不当**

```c
for (i = 0; i < n; i++) fscanf(in, "%lf", &a[i]);
/* 读完后及时 fclose(in)，养成好习惯 */
```

**错误 4：把输入文件用 "w" 打开**

```c
in = fopen(inName, "w");   /* 灾难：清空原始数据 */
in = fopen(inName, "r");   /* 对 */
```
