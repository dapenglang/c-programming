## 二、预备知识：if-else 链的执行流程与典型用法

### 1. if-else 链长什么样

多档判断的典型写法是一条 **if-else 链**（也叫阶梯式选择结构）：

```c
if (条件 1)
    语句块 1;
else if (条件 2)
    语句块 2;
else if (条件 3)
    语句块 3;
else
    语句块 4;
```

### 2. 执行流程

程序**从上往下逐个检查条件，检查到第一个成立的条件就执行它对应的语句块，然后整条链直接跳到结尾**——后面的所有条件连看都不再看一眼；如果所有条件都不成立，就执行最后的 `else` 块。

所以整条链**最多只会执行其中一个分支**，这正是"一个人只能落在一个档位"所需要的语义。要注意两个细节：

- **条件顺序就是判断顺序**。因为从上到下"先到先得"，写条件时必须保证排在前面的分支不会"抢走"应该属于后面分支的数据；
- **最后的 `else` 不带条件**，它的含义是"以上全部落空"，天然适合用来兜底处理非法输入。

### 3. 本例的条件怎么写

题目规定区间**左闭右开**：档 2 是 $[15, 20)$。写成 C 条件就是

```c
h >= 15.0 && h < 20.0
```

由于链是从上往下检查的，也可以利用"走到这里说明上一档已经排除"这一事实简化条件——但初学阶段**建议每档都把上下界写全**，条件自明、不依赖顺序，出错概率更小。端点归属最容易错：$h = 20$ 满足档 2 的 $h \ge 15$ 但不满足 $h < 20$，所以自动落进档 3，**只要每档条件写得完整，端点归属就不需要任何特殊处理**。

### 4. 兜底分支的用法

$h < 10$ 或 $h \ge 40$ 都属于超界。它们既不满足任何一档的完整条件，就会一路落到最后的 `else`——在那里输出 `out of range` 即可。**"先判断合法性，非法就拦截"是所有工程计算程序的第一道工序**，本题的 `else` 块就是这道工序的最小实现。

## 三、解题思路

1. **明确分档表**：四档区间互不重叠、合起来恰好覆盖 $[10, 40)$，端点都是左闭右开；
2. **确定变量**：只需一个 `double h`；
3. **写 if-else 链**：按档 1、2、3、4 的顺序从上往下排，每档条件写全上下界，最后用无条件的 `else` 兜住超界情形；
4. **各分支输出**：合法档位输出 `band = 编号, mu_z = 系数`（`%.2f`），超界输出 `out of range`；
5. **核对端点**：用 $h = 10, 20, 40$ 等特殊值手工核对归属是否与题目一致。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double h;                 /* 建筑物计算高度，m */

    scanf("%lf", &h);

    if (h >= 10.0 && h < 15.0)          /* 档 1：[10, 15) */
        printf("band = 1, mu_z = %.2f\n", 1.00);
    else if (h >= 15.0 && h < 20.0)     /* 档 2：[15, 20) */
        printf("band = 2, mu_z = %.2f\n", 1.13);
    else if (h >= 20.0 && h < 30.0)     /* 档 3：[20, 30) */
        printf("band = 3, mu_z = %.2f\n", 1.23);
    else if (h >= 30.0 && h < 40.0)     /* 档 4：[30, 40) */
        printf("band = 4, mu_z = %.2f\n", 1.39);
    else                                /* 超出表格适用范围 */
        printf("out of range\n");

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 16 | $15 \le 16 < 20$ 成立，其余档不成立 → 档 2，系数 1.13 | `band = 2, mu_z = 1.13` ✓ |
| 8 | 四档条件全不满足 → 落到 else | `out of range` ✓ |
| 20 | 档 2 条件中 $20 < 20$ 不成立；档 3 条件 $20 \le 20 < 30$ 成立 → 档 3 | `band = 3, mu_z = 1.23` ✓ |
| 35 | $30 \le 35 < 40$ 成立 → 档 4 | `band = 4, mu_z = 1.39` ✓ |
| 40 | 档 4 条件中 $40 < 40$ 不成立 → else | `out of range` ✓ |

注意 $h = 20$ 与 $h = 40$ 这两个端点：前者归档 3、后者超界，与题目"左闭右开"的规定一致。

## 六、常见错误与讲解

**错误 1：照抄数学写法连写不等式**

```c
if (15.0 <= h < 20.0)     /* 错：先算 15.0<=h 得 0 或 1，再用 0/1 与 20 比较 */
if (h >= 15.0 && h < 20.0)  /* 对：两个关系用 && 连接 */
```

`15.0 <= h < 20.0` 能通过编译（语法合法），但含义完全不对——它永远等价于 `0 < 20.0` 或 `1 < 20.0`，恒为真。这类错误编译器不报错、程序"看起来能跑"，危害极大。

**错误 2：把各分支写成并列的 if，而不是 else if**

```c
if (h >= 10.0 && h < 15.0) printf(...);   /* 两个独立的 if */
if (h >= 15.0 && h < 20.0) printf(...);   /* 会逐个检查，可能都不执行或多选 */
```

并列 if 各查各的，`else` 就无法知道"前面是否已有分支命中"，兜底逻辑随之失效。多档互斥判断必须用 **if / else if / else** 链。

**错误 3：分支顺序颠倒**

如果把"档 1：$h < 15$"简写成只判上界并放在链的最前面，那么 $h = 8$ 也会被它抢走。要么条件写全上下界（推荐），要么保证条件从窄到宽、从下往上依次排列，利用 else if 的短路特性逐步排除。

**错误 4：遗漏 else 兜底分支**

超界输入若没有 `else` 分支，程序会静默地什么都不输出，调用者还以为计算成功了。工程程序对非法输入必须给出明确提示，`else` 块就是干这个的。

## 七、与综合实验的衔接

- 实验 **A1（风荷载计算）**中，完整流程是"输入高度 → 合法性检查 → 档位/区间判断 → 线性插值 → 计算风压"。本练习实现了前两步；把第 2 章练习 01 的插值公式放进合法档位的分支里，就得到了 A1 的一个两档查算版本。学到第 5 章（数组）后，分档表将整体存入数组并用循环自动定位区间，if-else 链会被"循环找区间"取代——但**端点归属规则（左闭右开）和超界拦截思想完全不变**；
- 同样的"分档判断 + 兜底报错"模式还出现在：C1 声速剖面（深度分档）、D3 核数据截面（能量分档）、A7 混凝土龄期分档。判断的物理量不同，代码骨架完全相同。
