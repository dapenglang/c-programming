# 第 2 章 练习 12　阻力功率换算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C7《基于冲量-动量反演的冰阻力与碰撞事件辨识系统》（水声学院）——本练习是该实验中"冰阻力功率换算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

船舶在冰区航行时，船体不断排开前方的碎冰，冰对船体施加一个与航向相反的**冰阻力**。船舶的推进系统要维持航速，就必须持续输出足以克服这份阻力的功率。工程上最基础的估算关系是：**功率等于阻力乘以航速**——阻力越大、航速越高，所需功率就越大。

综合实验 C7 通过冲量-动量反演，从碰撞数据中辨识出作用在船体上的冰阻力；而"这份阻力究竟需要多大的推进功率才能扛住"，正是冰阻力最直接的工程用途之一。本练习就把这一环节单独抽出来，做成一个最小的计算程序。

## 二、任务要求

编写一个完整程序 `ice_power.c`：

1. 从键盘读入**冰阻力 F**（单位：kN）和**航速 v**（单位：m/s），两个量都用 `double` 类型；
2. 用公式计算克服该冰阻力所需的推进功率 **P**（单位：kW）；
3. 按规定格式输出结果，保留 **3 位小数**。

## 三、输入输出格式

**输入**：一行，两个实数，依次为冰阻力 F（kN）和航速 v（m/s），用空格分隔。

**输出**：一行，按格式 `P = 结果 kW` 输出，结果保留 3 位小数。

## 四、样例

**样例 1**

输入：
```
334.5 1.8
```
输出：
```
P = 602.100 kW
```

**样例 2**

输入：
```
785 1.4
```
输出：
```
P = 1099.000 kW
```

## 五、提示

功率、力、速度三者的关系为：

$$
P = F \times v
$$

本题的单位是"自洽"的：阻力用 kN、速度用 m/s，乘积的单位是 $\mathrm{kN \cdot m/s}$，而 $1\ \mathrm{kN \cdot m/s} = 1000\ \mathrm{N \cdot m/s} = 1000\ \mathrm{W} = 1\ \mathrm{kW}$，所以结果直接就是 kW，**不需要再乘或除 1000**。只需把公式原样翻译成一行赋值语句即可。

**完成本练习后你将具备的能力**：正确选择 `double` 类型存放物理量、书写带单位的算术表达式、用 `scanf`/`printf` 一次读写多个数据、理解量纲自洽的含义——这些是冰阻力相关实验里"从阻力到功率"这类派生计算的基本功。
