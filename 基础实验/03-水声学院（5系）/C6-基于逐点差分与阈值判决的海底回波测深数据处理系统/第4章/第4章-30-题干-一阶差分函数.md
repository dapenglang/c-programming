# 第 4 章 练习 30　一阶差分函数

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：4 函数（4.1 函数定义与调用、4.2 参数传递）+ 3 循环与选择

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"一阶差分计算"环节的最小实现。

**建议用时**：40 分钟

## 一、应用场景

测深仪逐点记录海底深度。原始深度序列杂着波浪、气泡等扰动，看不出地形起伏；**一阶差分**（相邻两点之差）把"深度的变化量"暴露出来：差分接近 0 是平地，差分明显为正是下坡（深度增大），差分突然变大则是可能的海底阶跃——综合实验 C6 的 M4 模块用差分为后面的"阈值跳变判决"备料。

一阶差分定义为：

$$\Delta x_i = x_i - x_{i-1}, \qquad i = 2, 3, \ldots, n$$

本题做它的最小实现：把"算一个差分"封装成函数，主函数循环读入深度流、滚动保存前一个值、逐点调用函数输出差分。

## 二、任务要求

编写一个完整程序 `first_diff.c`：

1. 自定义函数 `double firstDiff(double prev, double curr)`：返回差分 `curr - prev`；
2. 主函数从键盘读入深度点数 `n`（**题目保证 2 ≤ n ≤ 500**），循环读入 `n` 个深度值（double，m）；
3. 从第 2 个点开始，每读入一个新深度，调用 `firstDiff` 计算它与前一个深度的差分并打印（保留 2 位小数，正数带 `+` 号）；
4. 共输出 $n-1$ 个差分值。

**知识边界提示**：本题可使用第 2、3 章全部知识与函数；**禁用数组与指针**——用"前值 + 当前值"两个变量滚动即可。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 个实数（空格或换行隔开）。

**输出**：共 $n-1$ 行，每行格式 `第i点差分=%+.2f 样式`，即：

```
第i点差分=+0.30
```

（`%+.2f` 中的 `+` 表示正数也显式输出加号，负数自然输出减号。）

## 四、样例

**样例 1**

输入：
```
5
12.5 12.8 13.4 13.1 15.0
```
输出：
```
第2点差分=+0.30
第3点差分=+0.60
第4点差分=-0.30
第5点差分=+1.90
```

**样例 2**

输入：
```
2
7.25 7.25
```
输出：
```
第2点差分=+0.00
```

## 五、提示

- 差分需要**相邻两个值**，与练习 29 的滑动窗口同理，用两个变量滚动：

  ```c
  double prev = 0.0, curr;
  for (i = 1; i <= n; i++) {
      scanf("%lf", &curr);
      if (i >= 2) {
          printf("第%d点差分=%+.2f\n", i, firstDiff(prev, curr));
      }
      prev = curr;            /* 当前值变前值，为下一点做准备 */
  }
  ```
- `printf` 的 `%+d`、`%+f` 会给**正数也加上 + 号**——水深变化有正有负，带符号输出一眼可辨方向；
- 差分结果是**有符号的**：+ 表示深度增大（往下坡），− 表示深度减小（往上坡）；
- 想一想：差分与练习 29 的移动平均都在"相邻点"上做文章——移动平均是**求和**（抹平变化），差分是**求差**（放大变化），两者互为镜像；
- 浮点比较提醒：差分结果 `-0.00` 有可能出现吗？试试输入 `5.1 5.05`——`-0.05` 正常；而 `5.05 5.1` 的差分是 +0.05。若两个相等的值相减得 `-0.0`，`%+.2f` 会打成 `-0.00`，属正常的浮点行为。

**完成本练习后你将具备的能力**：用"前值滚动"处理相邻点运算、把差分公式封装成函数、用 `%+` 控制带符号输出——这些是实验 C6 中"一阶差分计算"模块的地基。
