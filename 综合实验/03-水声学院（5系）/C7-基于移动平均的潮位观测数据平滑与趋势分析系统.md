# 题目 C7：基于移动平均的潮位观测数据平滑与趋势分析系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行潮位观测数据分析工具，围绕"验潮站逐时潮位序列受波浪与量测噪声污染，需要用移动平均与中值滤波平滑后提取潮汐特征"这一海洋水文常规流程展开。系统从文本文件读入"时刻—潮位"序列，完成有效性检查与缺失插值补齐，分别实现移动平均滤波与中值滤波并对比平滑效果，检测高低潮极值点，统计相邻高潮—低潮的潮差，比较前后半段均值判断潮位总趋势，最后输出结果文件与字符潮位曲线。

潮位观测是海洋工程与水声作业保障的基础数据。潮汐使海面以半日或全日周期涨落，工程上的乘潮作业、水声设备布放深度设定、声速剖面测量时刻选择都必须知道"当前处于涨潮还是落潮、高潮与低潮何时出现、潮差有多大"。但验潮仪原始记录中混有风浪抖动，直接从原始曲线找高潮低潮会找出大量"假极值"，因此需要先用移动平均压噪，再用极值检测提取真正的潮汐特征。移动平均 $\bar{h}_i = \dfrac{1}{N}\sum_{k=i}^{i+N-1} h_k$ 与中值滤波是最经典也最易实现的两种平滑手段。

本系统支撑的关键场景包括：① 验潮站逐时数据的去噪与质量控制；② 潮汐特征值（高低潮时刻、潮差）的自动提取；③ 乘潮水位窗口与水声实验"作业潮位窗"评估；④ 潮位趋势比较（如连续观测中水位整体抬升/下降的判断）。学生在大一阶段就能用 C 语言把"平滑—检测—统计"这一数据处理链条完整跑通，为后续《海洋科学导论》《水声学原理》《海洋水文观测》等课程建立直观基础。本题目与水声工程专业"海洋环境参数获取与处理"方向直接相关，训练学生把观测流程转化为"数据读入—算法实现—数据输出"完整程序工程的能力。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的潮位观测数据平滑与趋势分析系统：从文本文件读入潮位时序，实现数据有效性检查，对缺失值做线性插值补齐，分别用窗口 $N$ 的移动平均滤波与中值滤波处理序列并对比两者差异，用相邻点比较法检测高潮与低潮极值点，统计相邻高低潮之间的潮差，比较序列前后半段均值判断水位总体趋势，最后生成结果文件与字符潮位曲线。

专业关联上，本题目复现了验潮站数据处理中"去噪平滑—特征提取—趋势判断"三类真实业务的核心计算。学生在此过程中将掌握课程中的选择与循环结构、一维与二维数组、函数、指针与文件读写，并第一次直观感受"不同平滑滤波器对同一数据的差异"，理解"一个观测分析流程如何变成一套程序"。

## 三、数据来源与格式

- **数据文件格式**：潮位时序采用纯文本格式，首行为标题说明，其后每行一条记录，字段以空格分隔。字段依次为：时刻 t（单位：小时，自观测起始累计）、潮位 h（单位：米，相对潮位基准面）。验潮仪故障时段的潮位字段填写缺失标记 `NaN`（或 `-1`）。

```
# time_hr   tide_m
0.0         1.24
1.0         1.87
2.0         NaN
3.0         3.05
4.0         3.42
5.0         3.10
6.0         2.36
```

- **仿真数据生成规则**：
  - 时刻：从 0.0 起、步长 1.0 小时递增，总长 72～168 小时（3～7 天）。
  - 真实潮位：按半日潮合成 $h(t) = H_1\sin(\dfrac{2\pi}{T_1}t + \varphi_1) + H_2\sin(\dfrac{2\pi}{T_2}t + \varphi_2)$，其中主分潮周期 $T_1 \approx 12.42$ 小时，幅值 $H_1$ 取 0.8～1.8 m，浅水分潮幅值 $H_2$ 取 0.1～0.3 m，叠加 1.0 m 左右的基准水位。
  - 观测噪声：在真实潮位上加 ±0.05～0.10 m 的扰动，模拟波浪与仪器噪声。
  - 缺失标记：随机注入 2%～6% 的 `NaN`（模拟验潮仪故障）。
  - **异常值注入方式**：由教师提供的生成程序人为注入三类错误。其一，潮位为负数且低于历史最低潮位下限（如 `-0.5`）；其二，潮位超过历史最高潮位上限（判越界）；其三，时刻字段重复或非数字串导致 `fscanf` 错位。校验模块需输出"行号—异常类型—处理动作"清单。

- **真实数据集（如有）**：真实潮位资料可参考国家海洋信息中心《中国海洋观测网》发布的验潮站逐时潮位数据与全球验潮站数据库 UHSLC（https://uhslc.soest.hawaii.edu/）。学生**无需下载**真实数据文件，课程提供与上述字段含义对应的简化仿真数据表；表中"潮位"对应验潮仪相对基准面的瞬时水位读数。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_TIDE     200      /* 最多潮位采样点数 */
#define MISS         -9999.0  /* 缺失点内部标记值 */
#define MAX_EXTREME  30       /* 最多高低潮极值点数 */

/* ===== 潮位采样点 ===== */
struct TidePoint {
    double t;                /* 时刻，单位：小时 */
    double h;                /* 潮位，单位：米；缺失时为 MISS */
    int    valid;            /* 有效标志：1 有效，0 异常/缺失待补 */
};

/* ===== 高低潮极值点 ===== */
struct Extreme {
    int    idx;              /* 在序列中的下标 */
    double t;                /* 极值时刻 */
    double h;                /* 极值潮位 */
    int    type;             /* 类型：1 高潮，-1 低潮 */
};

/* ===== 全局数据区 ===== */
struct TidePoint g_raw[MAX_TIDE];     /* 原始潮位序列 */
struct TidePoint g_fix[MAX_TIDE];     /* 插值补齐后序列 */
double           g_ma[MAX_TIDE];      /* 移动平均结果 */
double           g_med[MAX_TIDE];     /* 中值滤波结果 */
int              g_n;                 /* 实际采样点数 */
int              g_win;               /* 移动平均窗口 N */
struct Extreme   g_ex[MAX_EXTREME];   /* 高低潮点表 */
int              g_exCount;           /* 极值点数 */

/* ===== 处理日志（供报表模块使用） ===== */
struct LogItem {
    char  op[24];            /* 操作名，如 "MA_FILTER" */
    char  detail[64];        /* 参数与关键结果摘要 */
};
struct LogItem g_log[MAX_TIDE / 10 + 8];
int            g_logCount;             /* 已记录日志条数 */
```

辅助说明：潮位序列用结构体数组组织（课程 7.1/7.2），平滑结果用一维 `double` 数组缓冲（课程 5.1），移动平均窗口 `g_win` 由菜单输入并做奇偶校验（建议取奇数使窗口对称）；中值滤波窗口与移动平均同宽，便于公平对比。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入与预处理（3 个模块）

**M1 潮位时序读入模块**（源文件 `TideIO.c`）

- 功能简介：打开潮位时序文本文件，跳过首行标题，用循环 + `fscanf` 逐行读入时刻与潮位，填充全局序列 `g_raw[]` 并记录点数；遇到 `NaN` 或 `-1` 时把潮位置为 `MISS`；文件不存在时给出明确提示。
- 输入：文件路径（菜单输入，默认 `tide_obs.txt`）。
- 输出：填充后的 `g_raw[]` 与 `g_n`；返回成功/失败标志。

**M2 数据有效性检查模块**（源文件 `TideCheck.c`）

- 功能简介：逐条检查潮位是否低于历史最低潮位下限、是否超过历史最高潮位上限、时刻是否单调递增；对异常记录置 `MISS` 并生成"行号—异常类型—处理动作"清单打印。
- 输入：`g_raw[]`、`g_n`、高低潮位上下限配置。
- 输出：屏幕校验报告；修正后的 `g_raw[]`。

**M3 缺失值线性插值补齐模块**（源文件 `TideFix.c`）

- 功能简介：扫描序列找连续 `MISS` 段，对段两端的有效潮位做线性插值 $\hat{h} = h_1 + \dfrac{h_2 - h_1}{t_2 - t_1}(t - t_1)$ 逐点补齐，结果写入 `g_fix[]`；序列首尾缺失用最近有效值外推；统计补齐点数并写入日志。
- 输入：`g_raw[]`、`g_n`。
- 输出：补齐后的 `g_fix[]`；屏幕补齐统计。

### 第二部分：算法实现（4 个模块）

**M4 移动平均滤波模块**（源文件 `TideFilter.c`）

- 功能简介：对 `g_fix[]` 做窗口 $N$ 的滑动平均 $\bar{h}_i = \dfrac{1}{N}\sum_{k=i-(N-1)/2}^{i+(N-1)/2} h_k$（边界不足半窗时缩小窗口），结果存入 `g_ma[]`；窗口 $N$ 由菜单输入，做范围检查。
- 输入：`g_fix[]`、窗口 `g_win`。
- 输出：`g_ma[]`；屏幕滤波前后抽样对比若干行。

**M5 中值滤波对比模块**（源文件 `TideFilter.c`）

- 功能简介：对 `g_fix[]` 做同宽窗口的中值滤波：取窗口内 $N$ 个潮位排序后取中位数，结果存入 `g_med[]`；统计并打印两种滤波结果的最大绝对差值与平均绝对差值，比较两者对尖峰野值的抑制能力。
- 输入：`g_fix[]`、窗口 `g_win`。
- 输出：`g_med[]` 与两滤波差异统计；屏幕对比摘要。

**M6 高低潮极值检测模块**（源文件 `TideExt.c`）

- 功能简介：在平滑序列 `g_ma[]` 上用相邻点比较法检测极值：比左右邻近各若干点都大判为高潮、都小判为低潮；为抗残余噪声，要求极值前后 $K$ 点单调（$K$ 取 2～3），把结果填入 `g_ex[]`。
- 输入：`g_ma[]`、`g_n`、单调宽度 `K`。
- 输出：`g_ex[]`、`g_exCount`；屏幕高低潮清单。

**M7 潮差统计与前后半段趋势比较模块**（源文件 `TideExt.c`）

- 功能简介：对 `g_ex[]` 中相邻的高潮—低潮对计算潮差 $\Delta h = h_{高} - h_{低}$，输出潮差序列及其均值、最大/最小潮差与对应时刻；把序列按点数均分为前后两半，分别求均值并比较差值，给出"水位整体抬升/下降/基本持平"判断。
- 输入：`g_ex[]`、`g_ma[]`、`g_n`。
- 输出：潮差统计表与趋势结论；屏幕打印。

### 第三部分：输出（3 个模块）

**M8 结果文件输出模块**（源文件 `TideIO.c`）

- 功能简介：把原始、插值后与两种滤波结果按"时刻—原始—插值—移动平均—中值"列写出到 `tide_result.csv`，首行写列名；把高低潮点表、潮差统计与趋势结论写出到 `tide_report.txt` 便于核对。
- 输入：`g_fix[]`、`g_ma[]`、`g_med[]`、`g_ex[]`。
- 输出：`tide_result.csv`、`tide_report.txt`；屏幕确认信息。

**M9 屏幕字符潮位曲线模块**（源文件 `TidePlot.c`）

- 功能简介：以横轴为时间（每格若干小时）、纵轴为潮位（每格 0.2 m），用 `*` 绘制原始潮位曲线、用 `o` 绘制移动平均曲线叠加显示；高潮位置标 `H`、低潮位置标 `L`，让平滑效果与潮汐特征"看得见"。
- 输入：`g_fix[]`、`g_ma[]`、`g_ex[]`。
- 输出：屏幕字符潮位曲线。

**M10 主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：主菜单用 `do-while + switch` 调度 M1～M9，用状态标记约束"必须先读入并校验数据才能计算"；提供参数设置子菜单修改平滑窗口 `N` 与单调宽度 `K`，支持对同一数据换参数重跑并观察结果变化。
- 输入：用户菜单选项。
- 输出：调度各模块；屏幕运行状态提示。

## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环，先用状态标记 `g_loaded` 约束流程——未读入数据时只允许执行 M1；读入后依次可调用 M2 校验、M3 插值、M4～M5 滤波、M6～M7 特征与趋势、M8～M9 输出。任何计算模块要求序列中至少有 $2N$ 个有效点，否则提示缩小窗口或先执行 M3。

**数据流**：

```
tide_obs.txt ─► M1 读入 ─► g_raw[] ─► M2 有效性检查 ─► 清洗后序列
                                   │
                M3 线性插值补齐 ─► g_fix[]
                     │
        ┌────────────┴─────────────┐
        ▼                          ▼
  M4 移动平均（窗口N）        M5 中值滤波（同宽）
        │       g_ma[]             │  g_med[]
        │                          │
        └────┬─────────────────────┘
             ▼
     M6 高低潮极值检测 ─► g_ex[]
             │
             ▼
     M7 潮差统计 + 前后半段趋势比较
             │
    ┌────────┼──────────────────┐
    ▼        ▼                  ▼
 M8 结果文件输出        M9 字符潮位曲线 ──► M10 主控菜单调度
```

所有模块之间只通过全局序列数组、极值点表与函数参数交换数据，函数头部（接口）在编码前由全组书面约定。

## 十、选做扩展

1. **窗口敏感性分析**：把平滑窗口取 3、5、9 三档分别重跑 M4～M7，输出"窗口—极值点数—平均潮差"对照表，观察窗口过小（假极值多）与过大（真实高潮被削平）的折中现象。
2. **日不等现象观察**：把高低潮点表按天分组，统计每天的两次高潮幅值差，输出"日期—高潮不等量"表格，观察浅水分潮造成的日不等现象。
3. **双序列对比**：从文件再读入第二组（如次日）潮位数据，重复 M4～M7 并排输出两天的潮差与趋势对比报表，体会潮汐周期性。
