# 第 2 章 练习 15　声速剖面任意深度插值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 C1《基于拉格朗日插值的声速剖面计算系统》（水声学院）——本练习是该实验中"声速剖面线性插值查算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

海水中声波的传播速度称为**声速**，它随深度变化，把"深度—声速"对应关系画出来就是**声速剖面**。声速剖面是水声定位、声呐作用距离估算的基础数据。测量时，温盐深仪（CTD）只能在若干个离散深度上取样，例如 0 m 处测得 1531.0 m/s、50 m 处测得 1524.0 m/s；而实际计算往往需要**任意深度**处的声速。

在两个相邻测点之间，工程上默认声速随深度**均匀变化**，用**线性插值**求出中间深度的值。本练习把"给定相邻两档深度声速、求任意深度声速"这一最小步骤独立实现一遍，为 C1 中处理完整剖面表打基础。

## 二、任务要求

编写一个完整程序 `sound_speed_profile.c`：

1. 用**常量**在程序中存放相邻两档数据：深度 0 m 对应声速 1531.0 m/s，深度 50 m 对应声速 1524.0 m/s；
2. 从键盘读入一个深度 `z`（单位：m，`double` 类型，**题目保证 0 ≤ z ≤ 50**，因此不需要判断分支）；
3. 用线性插值公式计算该深度对应的声速 `c`；
4. 按规定格式输出结果，保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示深度 z（m）。

**输出**：一行，按格式 `c = 结果 m/s` 输出，结果保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
30
```
输出：
```
c = 1526.80 m/s
```

**样例 2**

输入：
```
45
```
输出：
```
c = 1524.70 m/s
```

## 五、提示

线性插值公式：已知两点 $(z_0,\, c_0)$、$(z_1,\, c_1)$，则深度 $z$ 处的声速为

$$
c = c_0 + \dfrac{(c_1 - c_0)\,(z - z_0)}{z_1 - z_0}
$$

本例声速随深度**减小**（$c_1 - c_0 = -7$），代入时符号自带，不必额外处理；只需把公式原样翻译成一行赋值语句。

**完成本练习后你将具备的能力**：独立完成一次"常量表 + 输入 + 插值 + 输出"的完整流程、正确处理递减型数据（负斜率）、把物理表格翻译成程序常量——这是 C1 声速剖面计算系统里"任意深度查声速"模块的地基。
