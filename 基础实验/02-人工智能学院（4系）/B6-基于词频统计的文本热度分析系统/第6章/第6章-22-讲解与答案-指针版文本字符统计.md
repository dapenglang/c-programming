## 二、预备知识：字符串与字符指针的基本原理（零基础阅读）

### 1. 问题是怎么来的：字符串其实就是一串柜子

第 6 章练习 21 讲过，数组是"一排连续的内存柜子"，指针是"写着柜号的纸条"。字符串 `char text[101]` 也是这个道理——它是**一排连续的字符柜子**：

```
柜号:  2000  2001  2002  2003  2004  2005
内容:  [ a ] [ b ] [ c ] [   ] [ 1 ] [ \0 ]
```

只是它多了个约定：**最后一个有效字符后面，一定要放一个特殊字符 `'\0'`**（柜子里存的数字是 0），当作"到此结束"的路标。程序靠找这个路标来判断字符串有没有走完。

### 2. 字符指针：指向字符柜子的纸条

**`char *p` 是一张"指向字符柜子的纸条"。** 写 `p = text;` 就是把字符串开头的柜号抄到纸条上：

```
纸条 p: [ 2000 ]  ----->  2000 号柜放着 'a'
```

- **`*p`**：打开纸条所指的柜子，取出那个字符（一开始是 `'a'`）；
- **`p++`**：把纸条上的柜号加 1（因为一个 `char` 占 1 个字节），走到下一个字符柜。

这个比喻和第 6 章练习 21 完全一样，只是那里每步跨 4 个字节（`int`），这里每步跨 1 个字节（`char`）。

### 3. 为什么用 `*p != '\0'` 作循环条件

字符串有多长事先不知道，不能用固定次数循环。但有一个天然的终止信号：走到 `'\0'` 就说明到头了。于是遍历写成：

```c
while (*p != '\0') {
    /* 此时 *p 是当前字符 */
    p++;
}
```

每一步先看"当前柜子里是路标吗"，不是就处理、然后前进；是就停下。**这套写法不用知道字符串长度**，是 C 语言处理字符串的经典方式。

### 4. 怎么判断字符属于哪一类

字符在内存里其实是数字（ASCII 码）：`'0'～'9'` 是连续的一段，`'a'～'z'`、`'A'～'Z'` 也是各自连续的一段。所以可以用**区间比较**判断类别：

```c
if ((*p >= 'a' && *p <= 'z') || (*p >= 'A' && *p <= 'Z'))  letters++;
else if (*p >= '0' && *p <= '9')  digits++;
else if (*p == ' ')               spaces++;
else                              others++;
```

能这样比较，是因为"连续编号"——`'5'` 确实大于 `'0'` 小于 `'9'`。这一点和上面"数组在内存里连续排布"是同一个底层道理。

### 5. 用本例走一遍

**例 1**：文本 `abc 123 x`。逐字符看：

- `a`、`b`、`c` 是字母 → letters = 3；
- ` ` 是空格 → spaces = 1；
- `1`、`2`、`3` 是数字 → digits = 3；
- ` ` 空格 → spaces = 2；
- `x` 字母 → letters = 4；
- 遇到 `'\0'` 停止。

结果 letters=4、digits=3、spaces=2、others=0，共 9 个字符，校验 $4+3+2+0=9$ ✓。

**例 2**：文本 `a1 b2!`。

- `a`→letters=1；`1`→digits=1；` `→spaces=1；`b`→letters=2；`2`→digits=2；`!`→others=1。

结束。结果 letters=2、digits=2、spaces=1、others=1，共 6 个，校验 $2+2+1+1=6$ ✓。

> **这个思想在综合实验中反复出现**：B6 文本字符统计、B10 相似度比较（逐字符比对）、B1 命令行式参数解析，都是"指针沿字符串走一遍"同一个套路。

## 三、解题思路

1. **读入整行**：用循环逐字符读入直到换行（因为 `scanf("%s")` 遇空格会截断），存进 `char text[101]`，末尾补 `'\0'`；
2. **初始化四个计数器**为 0；
3. **指针遍历**：`p = text;` 后 `while (*p != '\0')` 循环，按类别判断累加；
4. **移动指针**：循环末尾 `p++`；
5. **输出**：一条 `printf` 输出四个统计值。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    char text[101];     /* 存放读入的文本，最多 100 字符 */
    char *p;            /* 遍历用的字符指针 */
    int letters = 0, digits = 0, spaces = 0, others = 0;
    int n = 0;          /* 已读入的字符个数 */
    char ch;

    /* 逐字符读入，遇到换行结束（可含空格） */
    while ((ch = getchar()) != '\n' && ch != EOF && n < 100) {
        text[n++] = ch;
    }
    text[n] = '\0';     /* 补上字符串结束标记 */

    /* 指针从文本开头走起 */
    p = text;
    while (*p != '\0') {                 /* 未到结尾 */
        char c = *p;
        if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z'))
            letters++;                   /* 字母 */
        else if (c >= '0' && c <= '9')
            digits++;                    /* 数字 */
        else if (c == ' ')
            spaces++;                    /* 空格 */
        else
            others++;                    /* 其他符号 */
        p++;                             /* 走到下一个字符 */
    }

    /* 输出四类统计 */
    printf("letters = %d, digits = %d, spaces = %d, others = %d\n",
           letters, digits, spaces, others);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `abc 123 x` | 字母4、数字3、空格2、其他0（共9） | `letters = 4, digits = 3, spaces = 2, others = 0` ✓ |
| `a1 b2!` | 字母2、数字2、空格1、其他1（共6） | `letters = 2, digits = 2, spaces = 1, others = 1` ✓ |
| `ab` | 字母2，其余 0 | `letters = 2, digits = 0, spaces = 0, others = 0` ✓ |
| `   ` | 空格3，其余 0 | `letters = 0, digits = 0, spaces = 3, others = 0` ✓ |

每组四类之和都等于文本长度，说明遍历完整、分类互斥。

## 六、常见错误与讲解

**错误 1：循环条件忘记判 '\0'（最典型）**

```c
while (*p) { ... }        /* 对：'\0' 的值为 0，等价于 *p != '\0'，可以 */
for (i = 0; i < 100; i++) /* 错：会读到未赋值的垃圾字符 */
```

若用固定长度循环，会统计到 `'\0'` 之后的无效字符。

**错误 2：漏掉 `p++`，死循环**

```c
while (*p != '\0') {
    ...
    /* 忘写 p++ —— p 永远指向同一个字符，死循环 */
}
```

**错误 3：用 `=` 代替 `==` 比较字符**

```c
if (*p = ' ')      /* 错：这是赋值，且值为 ' '（非 0）恒为真 */
if (*p == ' ')     /* 对 */
```

**错误 4：用 scanf("%s") 读含空格的文本**

```c
scanf("%s", text);   /* 错：遇空格就停，"abc 123" 只读到 "abc" */
```

本题必须能读到空格，所以用逐字符读入（或 `fgets`）。
