# 第 5 章 练习 18　区间频数直方图统计

**对应章节**：5 批量数据处理方法（5.1 一维数组——计数数组；5.4 数组作函数参数；3.3 循环结构）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）模块 M9——本练习是该实验中"载荷幅值分布直方图"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

想知道冰载荷"都落在什么范围"、有没有集中在某一档，最直观的办法是画**直方图**：把数值范围等分成若干区间，统计每个区间里有多少个数据（频数），再用一排星号表示出来。工程报告里的分布图，本质上就是这样一张频数表。本练习用"**计数数组**"来实现它——数组的每个下标代表一个区间，下标指向的单元存该区间的频数，这是本章一个非常巧妙、也非常常用的技巧。

## 二、任务要求

编写一个完整程序 `histogram.c`：

1. 从键盘读入数据个数 `n`（**题目保证 $1 \le n \le 100$**），再读入 `n` 个实数，每个满足 $0 \le v < 100$（表示载荷幅值，无量纲）；
2. 声明计数数组 `int cnt[5]`，把 $[0,100)$ 等分为 5 个区间：$[0,20)$、$[20,40)$、$[40,60)$、$[60,80)$、$[80,100)$，统计每个区间的数据个数；
3. 按区间顺序输出 5 行，每行格式为"区间标签 + 频数 + 等量星号"：先输出区间标签与频数，再紧跟着打印与频数相同个数的 `*`；
4. 区间归属规则为**左闭右开**：数值等于区间下界者计入该区间（如 `20` 计入 $[20,40)$）。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（空格分隔）。

**输出**：共 5 行。每行格式为

```
[下界,上界): 频数 若干星号
```

其中区间标签的两端按宽度 3 右对齐（便于上下对齐），冒号后依次是一个空格、频数、一个空格、频数个 `*`，行末无多余空格。参考样例：

## 四、样例

**样例 1**

输入：
```
10
3 8 12 27 39 41 58 62 79 91
```
输出：
```
[  0, 20): 3 ***
[ 20, 40): 2 **
[ 40, 60): 2 **
[ 60, 80): 2 **
[ 80,100): 1 *
```

**样例 2**

输入：
```
6
0 19 20 40 79 99
```
输出：
```
[  0, 20): 2 **
[ 20, 40): 1 *
[ 40, 60): 1 *
[ 60, 80): 1 *
[ 80,100): 1 *
```

## 五、提示

1. **计数数组的用法**：`int cnt[5] = {0};` 先全部清零，数组的 5 个单元 `cnt[0]`～`cnt[4]` 分别记 5 个区间的频数；
2. **值 → 区间的换算**：值 $v$ 落在哪个区间，可以用整除求得区间编号

$$
\text{bin} = \left\lfloor \dfrac{v}{20} \right\rfloor \quad (\text{即整数除法 } v/20)
$$

在 C 里写成 `bin = (int)(v / 20.0);`，然后把 `cnt[bin]` 加 1。这样"归入哪个区间"这件事，就变成了"给哪个下标加 1"；
3. **打印星号**：频数是多少就打印多少个 `*`，用一个内层循环控制

$$
\text{for } (j = 0;\ j < cnt[k];\ j++)\ \text{printf("*");}
$$

4. **标签对齐**：区间两端用 `%3d` 输出即可（如 `[  0, 20):`、`[ 80,100):`），保持五行整齐。

**完成本练习后你将具备的能力**：用"下标代表类别"的计数数组完成频数统计、把连续数值映射到离散区间、用循环打印等长星号条形——这是实验 C7 中"载荷分布直方图模块"的地基。
