## 二、预备知识：函数调用的执行过程与返回值的使用（零基础阅读）

### 1. 问题来源：为什么要"封装复用"

速度换算要做的是"除以 3.6"。这个动作在实验 C7 的读数据、算功率、画曲线等多处都会用到。如果每处都写 `v / 3.6`，一旦换算系数要改（例如改用更精确的 $1/3.6=0.277777\ldots$），就得满程序找。把它们分别写成一个函数后，**换算规则只存在于一处**，改一次全局生效。

### 2. 函数调用是怎么执行的

以 `v_ms = kmh_to_ms(v_kmh);` 为例，执行过程是：

1. 取实参 `v_kmh` 的当前值；
2. 复制一份给形参 `v`；
3. 进入 `kmh_to_ms` 函数体，算出 `v / 3.6`；
4. 遇到 `return`，把结果交回调用处，函数结束；
5. 调用处用这个返回值给 `v_ms` 赋值。

一句话：**"传值进去 → 算 → 交结果出来"**。多个函数调用只是这个过程的重复，且**按书写顺序先后执行**：先算完 `kmh_to_ms`，再算 `kn_to_n`，最后用两个结果做乘法。

### 3. 返回值如何参与后续运算

函数的返回值本身就是一个值，可以像普通变量一样放进表达式。`p_w = f_n * v_ms;` 中，`f_n`、`v_ms` 都是前面两次调用的返回值。也可以一步写成：

```c
p_w = kn_to_n(f_kn) * kmh_to_ms(v_kmh);
```

这行更紧凑，含义是"把两个换算函数的返回值相乘"。初学阶段建议**分两步写**，每个中间结果都有名字，便于检查单位是否一致。

### 4. 单位一致性：物理量计算的铁律

$P=Fv$ 只在 $F$ 用 N、$v$ 用 m/s 时，$P$ 才等于 W。如果直接用 `f_kn * v_kmh`，得到的是 kN·km/h 这种混合单位，数值毫无意义。**先换算、后计算**，是本类程序必须遵守的次序。

### 5. 编程翻译

- 速度：`return v / 3.6;`
- 力：`return f * 1000.0;`
- 功率：`p_w = f_n * v_ms;`

注意 `1000.0` 写成浮点，避免"整数 × 浮点"时不必要的类型疑问；`3.6` 本身就是浮点常量，无需改写。

## 三、解题思路

1. **定两个接口**：`kmh_to_ms`、`kn_to_n`，各一个 `double` 形参、返回 `double`；
2. **写原型**：两个原型都放在 `main` 上方；
3. **写定义**：函数体各一行算术表达式并 `return`；
4. **主流程**：读入原始量 → 两次调用得国际单位量 → 相乘得功率 → 三行输出；
5. **校核**：用样例 1 手算 $18/3.6=5$、$3.6\times1000=3600$、$5\times3600=18000$。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明 */
double kmh_to_ms(double v);   /* 千米每小时 -> 米每秒 */
double kn_to_n(double f);     /* 千牛 -> 牛 */

int main(void)
{
    double v_kmh, f_kn;        /* 原始输入：km/h、kN */
    double v_ms, f_n, p_w;     /* 换算后的速度、力与功率 */

    scanf("%lf %lf", &v_kmh, &f_kn);   /* 读入航速与冰阻力 */

    v_ms = kmh_to_ms(v_kmh);           /* 第一次调用：速度换算 */
    f_n  = kn_to_n(f_kn);              /* 第二次调用：力换算 */
    p_w  = f_n * v_ms;                 /* 单位统一后计算功率 */

    printf("v = %.4f m/s\n", v_ms);
    printf("F = %.4f N\n", f_n);
    printf("P = %.4f W\n", p_w);

    return 0;
}

/* 速度换算：除以 3.6 */
double kmh_to_ms(double v)
{
    return v / 3.6;
}

/* 力换算：乘以 1000 */
double kn_to_n(double f)
{
    return f * 1000.0;
}
```

## 五、运行验证

| 输入 v F | 手算过程 | 程序输出 |
|---|---|---|
| 18 3.6 | v = 18/3.6 = 5；F = 3.6×1000 = 3600；P = 3600×5 = 18000 | `v=5.0000`、`F=3600.0000`、`P=18000.0000` ✓ |
| 36 1.25 | v = 36/3.6 = 10；F = 1.25×1000 = 1250；P = 1250×10 = 12500 | `v=10.0000`、`F=1250.0000`、`P=12500.0000` ✓ |
| 7.2 0.5 | v = 7.2/3.6 = 2；F = 0.5×1000 = 500；P = 500×2 = 1000 | `v=2.0000`、`F=500.0000`、`P=1000.0000` ✓ |

三组数据换算与功率结果全部吻合，说明两个函数被正确调用与复用。

## 六、常见错误与讲解

**错误 1：换算方向写反**

```c
return v * 3.6;        /* 错：这是 m/s -> km/h 的方向 */
return f / 1000.0;     /* 错：这是 N -> kN 的方向 */
```

记忆方法：km/h 是"每小时走多少千米"，单位更大，换成 m/s 数值应变小，所以**除以 3.6**；kN 换成 N，单位变小，数值应变大，所以**乘以 1000**。

**错误 2：用未换算的量算功率**

```c
p_w = f_kn * v_kmh;    /* 错：单位混杂，结果无物理意义 */
p_w = f_n * v_ms;      /* 对：先用函数换算，再相乘 */
```

**错误 3：定义了函数却忘了调用，直接输出原始值**

```c
printf("v = %.4f m/s\n", v_kmh);   /* 错：打印的是 km/h 的数，却标 m/s */
```

**错误 4：两个函数只写了一个原型**

```c
double kmh_to_ms(double v);
int main(void) { ... kn_to_n(f_kn); ... }   /* 编译报错：kn_to_n 未声明 */
```

**每个**被调用的函数都要有原型。

## 七、与综合实验的衔接

- 在实验 **C7（冰阻力与碰撞事件辨识系统）**中，"数据预处理模块"就是本练习的放大：读入的多组航速与阻力，先统一成 m/s、N，再进入反演算法。本练习只处理一组，把"单位换算函数化"的结构立了起来；
- 同一对函数在 C1（声速剖面，需把节/马赫换算成 m/s）、C6（碰撞模拟，力单位统一）中可直接复用。**把不变的计算（换算）抽成函数、让变化的数据（一次次的输入）通过参数流入，是模块化设计最朴素也最有效的用法。**
