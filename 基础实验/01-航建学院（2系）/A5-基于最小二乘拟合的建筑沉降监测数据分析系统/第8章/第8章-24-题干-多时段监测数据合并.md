# 第 8 章 练习 24　多时段监测数据合并

**所属综合实验**：A5（A5-基于最小二乘拟合的建筑沉降监测数据分析系统）

**对应章节**：8 数据持久化存储方法（8.1 文件的打开与关闭、8.2 文本文件读写、8.6 多文件读取与合并）

**场景来源**：综合实验 A5《基于最小二乘拟合的建筑沉降监测数据分析系统》（航建学院）——本练习是该实验中"多期观测数据合并"环节的实现。

**建议用时**：25～30 分钟

## 一、应用场景

沉降监测是**多期**的：第 1 期观测记录在 `s1.txt`，第 2 期在 `s2.txt`，第 3 期在 `s3.txt`……每个文件里都是"点号 + 当期沉降量"。要做整体分析，得先把这几期的数据**合并成一张总表** `all.txt`，并在合并时累计各点的沉降量。

这就是 A5 系统的"多期数据整合"环节：读多个输入文件，写到同一个输出文件。本练习实现把 3 期数据合并，并统计合并后每条记录的累计沉降。

## 二、任务要求

编写一个完整程序 `merge_settle.c`：

1. 依次读取 3 个输入文件 `s1.txt`、`s2.txt`、`s3.txt`，每个文件内每行是 `点号 当期沉降量`（mm）；
2. 把三个文件的所有记录**按读取顺序**写入输出文件 `all.txt`，写入时**为每条记录加上时段编号**，格式为 `期号 点号 沉降量`；
3. 统计并输出：合并后的**总记录数**、**累计沉降量之和**（保留 3 位小数）；
4. **必须检查每个文件的 fopen 返回值**；某一期文件打不开时给出提示并跳过（或退出，二者取一，本练习选择**提示并继续处理其余文件**）。

## 三、输入输出格式

**输入**：文件 `s1.txt`、`s2.txt`、`s3.txt`。每行 `点号 沉降量`。

**输出**：文件 `all.txt`，每行 `期号 点号 沉降量`；屏幕输出两行 `total=总记录数`、`sum=累计沉降量之和mm`（保留 3 位小数）。

## 四、样例

**输入文件 s1.txt**：
```
JC01 3.20
JC02 2.10
```
**输入文件 s2.txt**：
```
JC01 4.10
JC02 3.30
```
**输入文件 s3.txt**：
```
JC01 5.00
JC02 4.40
```
**输出文件 all.txt**：
```
1 JC01 3.20
1 JC02 2.10
2 JC01 4.10
2 JC02 3.30
3 JC01 5.00
3 JC02 4.40
```
**屏幕输出**：
```
total=6
sum=22.100
```

## 五、提示

**多文件读取的套路**：把三个文件名放进一个**字符串数组**，用循环统一处理：

```c
char *files[3] = {"s1.txt", "s2.txt", "s3.txt"};
for (k = 0; k < 3; k++) {
    FILE *fin = fopen(files[k], "r");
    if (fin == NULL) { printf("skip %s\n", files[k]); continue; }
    ...
    fclose(fin);
}
```

**期号**就是循环变量 `k + 1`。

**输出文件只打开一次**，放在循环**外面**（因为要往同一个文件持续写）：

```c
FILE *fout = fopen("all.txt", "w");
for (k = 0; ...) { ... fprintf(fout, "%d %s %.2f\n", k+1, name, s); ... }
fclose(fout);
```

**累加**：每读一条就 `sum += s`、`total++`。

**完成本练习后你将具备的能力**：用循环统一处理多个文件；把多个来源的数据写进同一个输出文件；在某文件打开失败时优雅跳过；综合运用文件读写与统计。
