# 第 5 章 练习 21　梁挠度序列数组统计

**所属综合实验**：A2（A2-基于二分法求解的简支梁最大挠度位置计算系统）

**对应章节**：5 批量数据处理（5.1 一维数组的定义与初始化、5.2 数组的输入与遍历、5.3 数组统计——求和/最值/位置）

**场景来源**：综合实验 A2《基于二分法求解的简支梁最大挠度位置计算系统》（航建学院）——本练习是该实验中"挠度序列生成与峰值定位"环节的实现。

**建议用时**：20～30 分钟

## 一、应用场景

一根跨度 $L$ 的简支梁承受均布荷载 $q$ 时，跨内各点的挠度（竖向位移）随位置变化，中间大、两端小。工程师关心两件事：**最大挠度有多大**、**它出现在哪个位置**。为了用二分法精确求解，程序先在梁上等间距取一排计算点，把每个点的挠度算出来存进数组，再在这组数据里找最大值。

挠度按材料力学公式计算：

$$
y(x) = \frac{q\,x\,(L^3 - 2Lx^2 + x^3)}{24 E I}
$$

其中 $x$ 是距左支座的坐标（m），$q$ 为均布荷载（kN/m），$L$ 为梁长（m），$E$ 为弹性模量（kN/m²），$I$ 为截面惯性矩（m⁴），$y$ 为挠度（程序按公式直接计算，本次练习取单位为 m）。

## 二、任务要求

编写一个完整程序 `beam_defl.c`：

1. 从键盘读入梁长 `L`、均布荷载 `q`、弹性模量 `E`、惯性矩 `I`，以及计算点个数 `n`（整数，**题目保证 3 ≤ n ≤ 100**）；
2. 把梁从 $x=0$ 到 $x=L$ **等分为 n 段**（共 n+1 个点，步长 $h = L/n$），用上面的公式逐个计算各点挠度，**存入一维数组**；
3. 遍历数组，求**最大挠度及其出现的坐标 x**（最大值有多个时取**第一个**）；
4. 输出最大挠度和对应位置，挠度保留 **3 位小数**，位置保留 **2 位小数**。

## 三、输入输出格式

**输入**：第一行 4 个实数 L、q、E、I；第二行 1 个整数 n。

**输出**：两行，`max_y = 最大挠度` 与 `x_at_max = 位置m`。

## 四、样例

**样例 1**

输入：
```
6.0 10.0 30000.0 0.0008
6
```
输出：
```
max_y = 7.031
x_at_max = 3.00
```

**样例 2**

输入：
```
8.0 12.0 20000.0 0.0012
8
```
输出：
```
max_y = 26.667
x_at_max = 4.00
```

## 四之补充：样例核算说明

样例 1 中 $L=6$、$q=10$、$E=30000$、$I=0.0008$，取 $n=6$ 时步长 $h=1$ m，各点坐标为 0,1,2,3,4,5,6。由公式计算，$x=3$ 处挠度最大：

$$
y(3) = \frac{10 \times 3 \times (6^3 - 2 \times 6 \times 3^2 + 3^3)}{24 \times 30000 \times 0.0008}
$$

括号内 $6^3 = 216$，$2\times6\times3^2 = 108$，$3^3=27$，故括号内 $= 216 - 108 + 27 = 135$；分子 $= 10\times3\times135 = 4050$；分母 $= 24\times30000\times0.0008 = 576$。因此 $y = 4050/576 = 7.03125 \approx 7.031$。**本题输出挠度公式的原始计算值，单位按米计（不再换算为 mm），题目示例均以此为准。**

## 五、提示

数组用来存放"一排算好的数"。定义与计算模板：

```c
double y[101];              /* 最多 101 个点 */
double h = L / n;           /* 步长 */
for (i = 0; i <= n; i++) {
    double x = i * h;       /* 第 i 个点的坐标 */
    y[i] = q * x * (L*L*L - 2*L*x*x + x*x*x) / (24*E*I);
}
```

求最大值与位置的模板（**先假设第 0 个就是最大，再逐个比较更新**）：

```c
int imax = 0;
for (i = 1; i <= n; i++) {
    if (y[i] > y[imax]) imax = i;   /* 用 > 保证取第一个最大值 */
}
```

**完成本练习后你将具备的能力**：定义一维数组、用循环给数组批量赋值、遍历数组求最值及其下标、理解"下标 i 与物理坐标 x 的换算关系"。
