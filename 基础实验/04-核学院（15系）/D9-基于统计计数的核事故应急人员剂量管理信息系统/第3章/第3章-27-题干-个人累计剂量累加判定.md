# 第 3 章 练习 27　个人累计剂量累加判定

**所属综合实验**：D9（D9-基于统计计数的核事故应急人员剂量管理信息系统）

**对应章节**：3 程序控制结构（3.2 选择结构——if 判断、3.3 循环结构——for 循环、3.5 关系与逻辑运算）

**场景来源**：综合实验 D9《基于统计计数的核事故应急人员剂量管理信息系统》（核学院）——本练习是该实验中"按编号汇总累计剂量并判定是否超限"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

一名应急人员在事故处置期间可能进出污染区多次，每次佩戴的电子个人剂量计都会记下一笔读数。系统要回答的核心问题是：**这个人整个应急期间累计受了多少剂量？有没有超过 20 mSv/年 的限值？**

这就需要把同一人的多笔记录**累加起来**，再与限值比较。国家标准的判定规则如下：

| 累计剂量 $D$（mSv） | 等级 |
|---|---|
| $D < 20$ | 正常 |
| $D \ge 20$ | 超限（需干预） |

综合实验 D9 的人员清单生成正是建立在这一步之上的：先算累计，再判等级，超限者进入"需干预人员清单"。本题实现"读入若干笔读数、累加、判定并输出结论"这一步。

## 二、任务要求

编写一个完整程序 `dose_sum.c`：

1. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 100**）；
2. 用**循环**读入 `n` 笔剂量读数（double，单位 mSv，**题目保证 0 ≤ 每笔 ≤ 30**），把它们**累加**起来得到该人员的累计剂量 `total`；
3. 用 **if 选择结构**把累计剂量与年限值 20 mSv 比较，判定等级；
4. 输出累计剂量（保留 2 位小数）和判定结论。若累计剂量超过 **15 mSv**（尚未超限但已进入关注区），额外出具提示。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各笔剂量读数（mSv），用空格分隔。

**输出**：共两行或三行——
- 第一行：`total = 累计剂量 mSv`（保留 2 位小数）；
- 第二行：`level = normal`（累计 < 20）或 `level = over`（累计 ≥ 20）；
- 第三行（仅当 15 ≤ 累计 < 20 时）：`warning: approaching limit`。

## 四、样例

**样例 1**

输入：
```
3
5.5 7.0 4.0
```
输出：
```
total = 16.50 mSv
level = normal
warning: approaching limit
```

**样例 2**

输入：
```
4
8.0 9.5 6.0 5.0
```
输出：
```
total = 28.50 mSv
level = over
```

**样例 3**

输入：
```
2
1.2 0.8
```
输出：
```
total = 2.00 mSv
level = normal
```

## 五、提示

- **累加**的固定套路：先让累加器归零 `total = 0.0;`，再在循环里 `total = total + x;`（可简写为 `total += x;`）。累加器必须在循环**之前**初始化，否则会得到一个垃圾初值；
- 判定用 `if (total >= 20.0) { ... } else { ... }`；
- 关注提示是**第二个**独立的 `if`：`if (total >= 15.0 && total < 20.0)`——注意用逻辑与 `&&` 同时卡上下界，否则超限人员也会被误提示；
- 循环里只需要一个变量 `x` 暂存读到的每一笔，读完就加进 `total`，不需要保存全部数据（保存全部是第 5 章数组的事）；
- 想一想：为什么限值取 20 mSv？这是 GB 18871-2002 规定的职业照射**年平均有效剂量限值**（连续 5 年平均 20 mSv/年，且任一年不超过 50 mSv）。

**完成本练习后你将具备的能力**：用 for 循环重复读入、用累加器做求和、用 if 与逻辑运算做分级判定——这些是实验 D9 中"剂量汇总与超限判定模块"的地基。
