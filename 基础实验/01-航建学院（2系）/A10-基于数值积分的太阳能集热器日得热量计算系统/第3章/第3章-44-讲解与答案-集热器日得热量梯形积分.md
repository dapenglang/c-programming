## 二、预备知识：梯形积分的基本原理（零基础阅读）

### 1. 问题是怎么来的

集热器的输出功率随时间变化，测得每 0.5 小时一个功率值：

```
0.0  1.2  2.8  3.5  2.6  1.4  0.0   (kW)
```

日得热量是"功率 × 时间"的总和——几何上就是**功率曲线下的面积**。但实测只有 7 个离散点，曲线本身未知，精确积分做不了。工程做法：把相邻两点之间当作直线，每个时段下的面积就是一个**梯形**（上底、下底是两端点的功率值，高是步长 h），把 n 个梯形面积加起来近似总面积——这就是**梯形法则**。综合实验 A10 用它计算日得热量，本题是其最小编程版。

### 2. 公式推导

第 $i$ 个时段 $[t_{i-1}, t_i]$ 上的梯形面积为：

$$S_i = \frac{h \cdot (P_{i-1} + P_i)}{2}$$

总面积（日得热量）：

$$Q = \sum_{i=1}^{n} S_i = \frac{h}{2}\sum_{i=1}^{n} (P_{i-1} + P_i)$$

展开求和观察每个测点的系数：$P_0$ 只出现在 $S_1$ 里、$P_n$ 只出现在 $S_n$ 里（各**1 次**），中间点 $P_i$（$1 \le i \le n-1$）同时出现在 $S_i$ 和 $S_{i+1}$ 里（共**2 次**）。于是：

$$Q = h \cdot \left( \frac{P_0}{2} + P_1 + P_2 + \cdots + P_{n-1} + \frac{P_n}{2} \right) = h \cdot \left( \frac{P_0 + P_n}{2} + \sum_{i=1}^{n-1} P_i \right)$$

**"首尾半权、中间全权"**就是梯形法则的记忆口诀，它比"逐段算梯形再相加"少一半加法。

### 3. 代入本例

样例 1（n=6, h=0.5）：

- 首尾半权：(0.0 + 0.0)/2 = 0；
- 中间全权和：1.2 + 2.8 + 3.5 + 2.6 + 1.4 = 11.5；
- Q = 0.5 × (0 + 11.5) = **5.75 kWh**。

交叉验证（逐段梯形）：0.5×(0+1.2)/2 + 0.5×(1.2+2.8)/2 + 0.5×(2.8+3.5)/2 + 0.5×(3.5+2.6)/2 + 0.5×(2.6+1.4)/2 + 0.5×(1.4+0.0)/2 = 0.30 + 1.00 + 1.575 + 1.525 + 1.00 + 0.35 = 5.75 ✓ 两种算法一致。

样例 2（n=1, h=1.0）：中间点为空（循环跑 0 次），Q = 1.0 × (2.0+4.0)/2 = 3.00 kWh ✓。

以上数值已按 IEEE-754 double 与 `printf("%.2f")` 舍入规则复算核对：11.5×0.5 = 5.75 精确表示，输出 `5.75`。

### 4. 编程翻译

| 数学动作 | C 语言翻译（无数组版） |
|---|---|
| 保存首点 $P_0$ | 读入后存入 `p0`（首点要用两次：开头与结尾） |
| 中间点累加 $\sum P_i$ | 循环读 `pcur`，`Q += pcur` |
| $\frac{P_0 + P_n}{2}$ | 读完全部点后 `Q += (p0 + pcur) / 2.0;` |
| 乘步长 $h$ | 最后 `Q *= h;` |

**无数组的关键**：首点存进 `p0` 单独保管，其余点读一个用一个，永远只需 `p0` 和 `pcur` 两个变量——"流式处理"思想，内存占用与 n 无关。

> **累加器模式是第 3 章的核心套路**：`sum = 0; 循环 { sum += ...; }` 与练习中"累加求和""计数"一脉相承，实验 A10 的积分、C3/C5 等实验的能量/数据汇总全部建立在这个模式上。

## 三、解题思路

1. **读入** `n`、`h`；
2. **读入首点**存 `p0`，`Q = 0`；
3. **循环 n−1 次**读中间点，每次 `Q += pcur`（全权累加）；
4. **读入末点** `pcur`，`Q += (p0 + pcur) / 2.0`（首尾半权合并处理）；
5. `Q *= h;` 输出。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double p0, pcur;        /* 首点、当前读入的点（无需数组） */
    double h, Q;
    int n, i;

    scanf("%d %lf", &n, &h);            /* 时段数、步长(h) */

    scanf("%lf", &p0);                  /* 读入首点 P0，单独保管 */
    Q = 0.0;                            /* 累加器清零 */

    for (i = 1; i <= n - 1; i++) {      /* n-1 个中间点，全权累加 */
        scanf("%lf", &pcur);
        Q += pcur;
    }

    scanf("%lf", &pcur);                /* 读入末点 Pn */
    Q += (p0 + pcur) / 2.0;             /* 首尾各计半权 */

    Q *= h;                             /* 统一乘步长 */

    printf("日得热量 Q = %.2f kWh\n", Q);
    return 0;
}
```

## 五、运行验证

**第一次运行**（样例 1）：

输入：
```
6 0.5
0.0 1.2 2.8 3.5 2.6 1.4 0.0
```
输出：
```
日得热量 Q = 5.75 kWh
```
核对：0.5 × (11.5 + 0) = 5.75，与逐段梯形求和一致。✓

**第二次运行**（样例 2，单时段边界）：

输入：
```
1 1.0
2.0 4.0
```
输出：
```
日得热量 Q = 3.00 kWh
```
✓ 中间点循环 `i ≤ 0` 不执行，Q = 1.0×(2.0+4.0)/2 = 3.00。

**反例验证**：若把末点处理写成 `Q += pcur;`（全权）而首点也全权累加，样例 1 变成 0.5×(0.0+1.2+2.8+3.5+2.6+1.4+0.0) = 0.5×11.5 = 5.75——本例首尾恰为 0 看不出差别！换样例 2 则得 0.5... 不对，得 1.0×(2+4) = 6.00 ≠ 3.00，错误立现。这说明**测试样例要选首尾非零的数据**才能暴露"忘记半权"的 bug。

## 六、常见错误与讲解

**错误 1：首尾忘了半权**

```c
Q += p0;                     /* 错：首点按全权加了 */
...
Q += (p0 + pcur) / 2.0;      /* 又把首点加了半次 → 首点被算了 1.5 次 */
```

首点只存 `p0` 不进累加器，最后统一在 `(p0 + pcur)/2` 里处理一次即可。

**错误 2：读点个数搞错（n 个 vs n+1 个）**

```c
for (i = 0; i < n; i++) { scanf("%lf", &pcur); ... }   /* 只读了 n 个点，少一个 */
```

n 个时段对应 **n+1 个测点**，读完首点后循环 n−1 次再读末点，合计 n+1。数错点数是本题第一大坑。

**错误 3：中间点循环边界写错**

```c
for (i = 1; i <= n; i++)       /* 错：多读一个点，把末点当中间点加了全权 */
for (i = 1; i <= n - 1; i++)   /* 对：中间点恰 n-1 个 */
```

**错误 4：整数 2 参与除法（隐患写法）**

```c
Q += (p0 + pcur) / 2;     /* 本题 p0、pcur 是 double，结果仍正确；但若变量改成 int 就被截断 */
Q += (p0 + pcur) / 2.0;   /* 推荐：明确实数除法 */
```

**错误 5：步长乘错时机**

```c
Q += h * pcur;            /* 对中间点这样写：h*p1 + h*p2 + ... 结果也对但啰嗦 */
Q *= h;                   /* 推荐：先把权和算完，最后乘一次 h，与公式一致 */
```

两者数学等价，但"最后乘一次 h"与公式 $Q = h(\cdots)$ 一一对应，不易出错。

## 七、与综合实验的衔接

- 实验 **A10（基于数值积分的太阳能集热器日得热量计算系统）**中，"日得热量计算"是本题的直接应用：实验读入全天逐时段的功率（或辐照度 × 集热效率）序列，用本题的梯形累加得出日得热量，进而做月度/年度汇总（对日得热量序列再套一层同样的累加器）；"流式处理、不开数组"的写法在数据量大时尤其有价值；
- 与其他实验衔接：实验 **C8** 的"逐层累加传播时间（M6）"是"对层厚/声速做逐段累加"的又一实例；实验 **C6** 的差分序列处理中，"相邻两点线性插值"（M3）与梯形法则共享"把曲线段当直线段"的几何直觉。梯形积分是数值分析的第一课，本练习之后，"复合梯形/加密步长提高精度"等扩展只需在循环上做文章。
