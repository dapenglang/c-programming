## 二、预备知识：`char *names[]` 到底是什么（零基础阅读）

### 1. 三样容易混淆的"方括号"

```
   (1) char buf[10][50];     二维字符数组：10 行、每行 50 个 char，共 500 字节，字符串本体就住在这里。
   (2) char *names[10];      指针数组：10 个元素，每个元素都是一个 char *（地址），共放 10 个地址。
   (3) char (*q)[50];        行指针（第 16 题会专门练）：一个指针，指向"一整行 50 个 char"。
```

本练习要的是 **(2) 指针数组**：它不存字符，只存字符的**地址**。辨析诀窍看优先级——`char *names[10]` 里 `[]` 优先，先说明 `names` 是数组，再说明元素是 `char *`。

### 2. 指针数组的内存图

```
   字符串本体（都在 buf 里）：
      buf[0]: "alpha\0"
      buf[1]: "beta\0"
      buf[2]: "gamma\0"

   指针数组 names（只存地址）：
      names[0] ──→ buf[0]  "alpha"
      names[1] ──→ buf[1]  "beta"
      names[2] ──→ buf[2]  "gamma"

   一句话：names 是"地址的表格"，顺着每一格地址才能找到真正的字符串。
```

### 3. 为什么形参是 `char **`

把 `names` 传给函数时，数组名又退化了：它退化成 `&names[0]`，即"指向第 0 个元素的指针"。而每个元素本身是 `char *`，所以"指向 `char *` 的指针"类型就是 `char **`。于是：

```
   names          →  char **      （指向指针数组首元素）
   names[i]       →  char *       （第 i 条字符串的首地址）
   *names         →  char *       （等价于 names[0]）
   **names        →  char         （等价于 names[0][0]，第一个字符）
```

**访问字符串本身，只需要一层下标** `names[i]`；只有想取到"某条字符串的第 j 个字符"，才写 `names[i][j]`。

打个比方：`buf` 像一排真实的房间（里面住着字符串），`names` 像一张写着房号的通讯录。遍历通讯录时，我们读的是"房号"（`names[i]`），而不是把房间整个搬出来。正因如此，指针数组特别适合"只调整次序、不动原数据"的场景——第 18 题排序换的就是通讯录上的房号。

还要分清一个容易踩的对照：如果直接把二维数组 `buf` 交给函数，它退化成的是"行指针" `char (*)[50]`，一次按 50 字节步进；而指针数组退化成的是 `char **`，一次按"一个地址"步进。**要表达"一批长度不一的字符串、且需要灵活调整顺序"，指针数组才是最自然的选择。**

### 4. 编程翻译

- 建立指针数组：循环里 `names[i] = buf[i];`（务必写，否则 `names[i]` 是野指针）；
- 输出：`printf("%d %s\n", i + 1, names[i]);`；
- 遍历也可写成 `*(names + i)`，与 `names[i]` 完全等价。

## 三、解题思路

1. **定数据**：`buf` 存本体、`names` 存地址，两者一一对应；
2. **定接口**：`void print_table(char **names, int n);`，只读不改；
3. **定遍历**：`for (i = 0; i < n; i++) printf("%d %s\n", i + 1, names[i]);`
4. **定编号**：题目要求从 1 开始，故打印 `i + 1`；
5. **定调用**：`print_table(names, n);`，`names` 自动退化为 `char **`。

## 四、参考代码

```c
#include <stdio.h>

/* 用二级指针遍历指针数组，输出编号名称表 */
void print_table(char **names, int n)
{
    int i;
    for (i = 0; i < n; i++)
        printf("%d %s\n", i + 1, names[i]);   /* names[i] 即第 i 条字符串首地址 */
}

int main(void)
{
    char buf[10][50];        /* 字符串本体 */
    char *names[10];         /* 指针数组：每一项保存一条字符串的首地址 */
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%s", buf[i]); /* buf[i] 本身已是地址，无需再加 & */
        names[i] = buf[i];   /* 关键一步：让指针指向对应字符串 */
    }

    print_table(names, n);   /* names 退化为 char ** */

    return 0;
}
```

## 五、运行验证

| 输入 | 名称表内容 | 程序输出 |
|---|---|---|
| 3 / alpha beta gamma | names[0..2] = "alpha","beta","gamma" | `1 alpha`、`2 beta`、`3 gamma` ✓ |
| 2 / ICE-01 ICE-02 | names[0..1] = "ICE-01","ICE-02" | `1 ICE-01`、`2 ICE-02` ✓ |

> 地址类说明：`names[i]` 保存的是各自字符串的地址，其具体数值由运行环境决定；程序输出的是"编号 + 字符串内容"，不依赖具体地址值，换机器结果一致。

## 六、常见错误与讲解

**错误 1：混淆 `char *names[10]` 与 `char names[10][50]`**

```c
names[i] = buf[i];     /* 对：把地址存进指针数组 */
/* 若误以为 names 是二维数组而写 strcpy(names[i], buf[i]); 则 names[i] 未初始化，strcpy 会写进野地址而崩溃 */
```
记住：**指针数组只装地址，装字符串要用 `=` 赋地址，不能用 `strcpy` 往里搬内容**（除非事先给它分配了内存）。

**错误 2：忘了初始化指针数组**

```c
char *names[10];
print_table(names, n);    /* 错：names 里的地址是随机垃圾，打印或访问会崩溃 */
```
必须逐项 `names[i] = buf[i];`，让每个指针都有明确指向。

**错误 3：函数内想用 `sizeof` 推出元素个数**

```c
void print_table(char **names) {
    int n = sizeof(names) / sizeof(names[0]);   /* 错：names 是指针，n = 1 或 2，随平台 */
}
```
`char **` 的大小是一个指针的大小，推不出原数组长度。**长度必须作为参数传进来。**

**错误 4：输出用错格式符**

```c
printf("%d %d\n", i + 1, names[i]);    /* 错：%d 用来打印整数，字符串要用 %s */
printf("%d %c\n", i + 1, names[i]);    /* 错：%c 只打印一个字符 */
printf("%d %s\n", i + 1, names[i]);    /* 对 */
```
`%s` 会从给定地址开始一直打印到 `'\0'`，正适合打印整条字符串。
