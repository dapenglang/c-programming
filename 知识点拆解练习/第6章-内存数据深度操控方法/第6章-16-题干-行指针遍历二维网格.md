# 第 6 章 练习 16　行指针遍历二维网格

**对应章节**：6 内存数据深度操控方法（6.3 指针与数组——二维数组与行指针、6.5 指针与函数）

**场景来源**：综合实验 C9《基于二维网格统计的冰压力场分析与可视化系统》（水声学院）——本练习是该实验中"压力网格整体扫描"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰压力场的测点按"行 × 列"布置成一张规则网格，数据自然存成二维数组。要对整片网格求和、求平均，函数就得接收这个二维数组。二维数组的元素地址不像一维那样简单——它由"行"和"列"两级构成：网格可以看成"若干行，每行是一排数"。描述"一整行"需要一种特殊的指针，叫作**行指针**：它指向的不是一个数，而是一整行。函数形参写成 `double (*p)[4]`（4 是列数），就能像翻书页一样逐行扫描网格。本练习实现一个用行指针遍历网格求总和的函数。

## 二、任务要求

编写一个完整程序 `grid_row_ptr.c`：

1. 主函数读入网格行数 `rows`（题目保证 $1 \le rows \le 6$），再读入 `rows` 行、每行 **4** 个实数，存入二维数组 `double g[6][4]`；
2. 编写函数，其原型为 `double grid_total(double (*p)[4], int rows);`，用**行指针**逐行、逐列访问网格，返回所有元素之和；
3. 主函数输出总和 `total`（保留 2 位小数）与平均值 `mean`（保留 4 位小数），平均值为总和除以元素总个数 $rows \times 4$。

## 三、输入输出格式

**输入**：第一行一个整数 `rows`；接下来 `rows` 行，每行 4 个实数（空格分隔）。

**输出**：两行，分别为 `total = <总和>` 与 `mean = <平均值>`，总和保留 2 位小数，平均值保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
3
100 110 120 130
90 95 105 115
80 85 95 100
```
输出：
```
total = 1225.00
mean = 102.0833
```

**样例 2**

输入：
```
2
10 20 30 40
50 60 70 80
```
输出：
```
total = 360.00
mean = 45.0000
```

## 五、提示

- 行指针的写法是 `double (*p)[4]`，括号不可少：它表示"`p` 是一个指针，指向含 4 个 `double` 的数组（一整行）"；
- 用 `p[i][j]` 访问第 i 行第 j 列，等价于 `*(*(p + i) + j)`；其中 `p + i` 前进的是"i 整行"；
- 求和用双重循环：外层 `for (i = 0; i < rows; i++)`，内层 `for (j = 0; j < 4; j++)`。

**完成本练习后你将具备的能力**：理解二维数组的"行指针"本质、会用 `p[i][j]` 或 `*(*(p+i)+j)` 访问网格、掌握"二维数组作函数参数时必须给出列数"的规则——这是实验 C9 中"网格统计模块"的地基。
