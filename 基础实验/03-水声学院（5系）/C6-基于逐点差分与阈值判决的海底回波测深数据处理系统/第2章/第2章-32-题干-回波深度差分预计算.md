# 第 2 章 练习 32　回波深度差分预计算

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：2 常量、变量与数据类型；2.x 运算符与表达式；2.x 格式化输入输出（scanf/printf）

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"一阶差分计算模块"的最小实现。

**建议用时**：20 分钟

## 一、应用场景

声呐换能器每发射一次 ping，就测得一个海底深度。要判断海底是"平的"还是"出现了阶跃"，最基础的一步是**逐点差分**：用当前 ping 的深度减去上一 ping 的深度，得到深度变化量 $\Delta d$。

综合实验 C6 的第 4 个模块就是"一阶差分计算模块"——后面所有的阈值判决、跳变识别，都建立在这个最朴素的减法之上。本题模拟其中**一次差分**的计算：只读两个深度，算一个差，打印出来。麻雀虽小，但它就是差分滤波器的"细胞"。

## 二、任务要求

编写一个完整程序 `diff_pre.c`：

1. 定义符号常量 `#define GAIN 100.0`（差分结果将以"每 100 ping 的深度变化量"形式给出）；
2. 从键盘读入两个 double：上一 ping 的海底深度 `d1`（m）、当前 ping 的海底深度 `d2`（m）；
3. 计算一阶差分 $\Delta d = d_2 - d_1$；
4. 计算折算变化量 $\Delta d_{100} = \Delta d \times GAIN$；
5. 按样例格式输出 $\Delta d$（保留 2 位小数）与 $\Delta d_{100}$（保留 1 位小数）。

**注意**：本题只做顺序计算，不允许使用 `if`、循环和函数。

## 三、输入输出格式

**输入**：一行两个实数，用空格分隔：`d1 d2`（单位：m）。

**输出**：两行：

- 第一行：`diff = <Δd> m`（Δd 保留 2 位小数）；
- 第二行：`per 100 pings = <Δd100> m`（保留 1 位小数）。

## 四、样例

**样例 1**

输入：
```
149.85 152.30
```
输出：
```
diff = 2.45 m
per 100 pings = 245.0 m
```

**样例 2**

输入：
```
150.00 149.55
```
输出：
```
diff = -0.45 m
per 100 pings = -45.0 m
```

差分为负表示海底变浅（回波提前到达）。

## 五、提示

- 深度是实数，请用 `double` 与 `scanf("%lf", ...)`，不要用 `int`；
- 差分方向约定为"当前减上一"：$\Delta d = d_2 - d_1$，正号表示海底变深；
- 输出负数时 `printf("%.2f", x)` 会自动带负号，不需要额外处理；
- 想一想：`#define GAIN 100.0` 与直接写 `100.0` 相比，好处是什么？（换算口径改变时只改一处。）

**完成本练习后你将具备的能力**：用两个变量完成"读入—计算—格式化输出"的最小流水线——这正是 C6 实验中差分模块对每对相邻深度反复做的事情。
