# 第 8 章 练习 09　碰撞日志追加写入

**对应章节**：8 数据持久化存储方法（8.3 文件的打开与关闭——`"a"` 追加模式、8.4 文件的读写——`fprintf`）

**场景来源**：综合实验 C6《冰区航行冰块碰撞仿真系统》（水声学院）——本练习是该实验中"碰撞事件日志追加记录"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰块碰撞仿真每发生一次碰撞，就要往日志文件里记一笔：碰撞时刻、参与碰撞的两块冰编号、碰撞力大小。日志的特点是"**只增不改**"——历史记录必须原样保留，新的碰撞一律**追加**到文件末尾。如果用练习 01 的 `"w"` 模式，一打开文件就把历史全冲掉了，这显然不行。正确做法是用追加模式 `"a"`。本练习就实现这一环节：读入若干次新的碰撞事件，把它们接着老记录写到 `collision_log.txt` 末尾。

## 二、任务要求

编写一个完整程序 `append_log.c`：

1. 从键盘读入一个整数 $n$，表示本次要追加的碰撞事件条数（题目保证 $1 \le n \le 100$）；
2. 随后读入 $n$ 组数据，每组一条碰撞事件：碰撞时刻 $t$（实数，s）、冰块编号 A（整数）、冰块编号 B（整数）、碰撞力 F（实数，N）；
3. 以**追加模式**打开日志文件 `collision_log.txt`，并检查是否成功；把每条事件按固定格式追加写入文件，**原有内容必须保留**；
4. 写入完成后输出提示，报告本次追加了多少条；关闭文件。

**数据文件格式约定**

- 文件名：`collision_log.txt`
- 文件为纯文本文件，每行一条碰撞记录，行末换行；记录只追加、不删除
- 每行四个字段：`t=` 时刻、`A=` 冰块编号、`B=` 冰块编号、`F=` 碰撞力，字段之间用**一个空格**分隔
- 时刻保留 2 位小数、碰撞力保留 1 位小数
- 样例数据行：`t=2.00 A=2 B=5 F=560.0`

## 三、输入输出格式

**输入**：第一行一个整数 $n$；随后 $n$ 行，每行 4 个数据：时刻、编号 A、编号 B、碰撞力，以空格分隔。

**输出**：屏幕输出一行 `已追加 X 条碰撞记录`；新记录写入文件 `collision_log.txt` 末尾。

## 四、样例

**样例 1**

运行前，`collision_log.txt` 已有内容：
```
t=0.50 A=3 B=7 F=1250.0
t=1.25 A=1 B=4 F=980.5
```
输入：
```
2
2.00 2 5 560.0
3.10 6 8 1420.0
```
程序运行后，`collision_log.txt` 的内容为：
```
t=0.50 A=3 B=7 F=1250.0
t=1.25 A=1 B=4 F=980.5
t=2.00 A=2 B=5 F=560.0
t=3.10 A=6 B=8 F=1420.0
```
屏幕输出：
```
已追加 2 条碰撞记录
```

**样例 2**

运行前文件内容与样例 1 相同（2 行）。输入：
```
1
4.75 3 9 870.0
```
程序运行后，文件内容为：
```
t=0.50 A=3 B=7 F=1250.0
t=1.25 A=1 B=4 F=980.5
t=4.75 A=3 B=9 F=870.0
```
屏幕输出：
```
已追加 1 条碰撞记录
```

## 五、提示

- 追加模式用 `fp = fopen("collision_log.txt", "a")`，其中的 `a` 表示 append（追加）；
- 与 `"w"` 不同，`"a"` **不会清空**已有内容，且每次写入都自动落在文件末尾，无需手动 `fseek`；
- 写记录仍用 `fprintf`，格式串写成 `"t=%.2f A=%d B=%d F=%.1f\n"`；
- 文件不存在时，`"a"` 会自动新建；打开后同样要判断 `fp == NULL`；
- 若误用 `"w"`，运行一次之后老记录会全部丢失，请务必检查模式串。

**完成本练习后你将具备的能力**：区分 `"w"` 与 `"a"` 两种写模式、用追加模式往日志文件持续记录、用 `fprintf` 按固定格式写事件行——这是实验 C6 中"碰撞事件日志、运行轨迹记录"这类模块的标准写法。
