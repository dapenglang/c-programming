## 二、预备知识：函数封装的基本原理（零基础阅读）

### 1. 问题是怎么来的

声线穿过一层海水，不是垂直"坠"下去，而是斜着走。设掠射角为 $\theta$（声线与水平面的夹角），层厚 $h$，层内声速 $c$：

- 声线在层内的**斜程**：直角三角形中 $\cos\theta = h / L$，解出

$$L = \frac{h}{\cos\theta}$$

- **传播时间** = 斜程 ÷ 声速：

$$t = \frac{h}{c\cos\theta}$$

- **水平跨距**：$\tan\theta = d / h$，解出

$$d = h\tan\theta$$

综合实验 C8 要对**每条声线的每一层**做这两个计算——同一个公式重复几十上百次。重复出现的计算必须"写一次、用无数次"，这就是**函数**存在的理由。

### 2. 公式翻译成函数：三件套

一个自定义函数 = **原型 + 定义 + 调用**：

**① 原型（声明）**——告诉编译器"有这么个函数，长这样"：

```c
double layerTime(double h, double c, double thetaDeg);
```

读法：函数名叫 `layerTime`，收 3 个 double 参数，还回一个 double。原型通常集中写在 `main` 之前。

**② 定义**——函数的"本事"：

```c
double layerTime(double h, double c, double thetaDeg)
{
    double rad = thetaDeg * PI / 180.0;   /* 角度 → 弧度 */
    return h / (c * cos(rad));            /* 算出结果并交还给调用者 */
}
```

`return` 一执行，函数立即结束，把表达式的值交回调用处。

**③ 调用**——像用 `sqrt` 一样用它：

```c
t = layerTime(h, c, thetaDeg);
```

### 3. 参数传值：抄一份给你

调用 `layerTime(h, c, thetaDeg)` 时，C 语言把主函数里这几个变量的**值**抄一份，交给函数里的同名形参。此后函数内部对 `h、c、thetaDeg` 做任何赋值，都只改自己那份"复印件"，主函数里的原变量**分毫不变**——这叫**传值调用**。本题只需要"拿值进来、算结果出去"，传值完全够用（需要"改回去"的场合要等第 6 章指针）。

### 4. 代入本例数值

以样例 1 第 1 层（h=50, c=1500, θ=20°）验证：

$$\theta_{\text{rad}} = 20 \times \frac{\pi}{180} = 0.349066,\quad \cos\theta = 0.939693,\quad \tan\theta = 0.363970$$

$$t = \frac{50}{1500 \times 0.939693} = 0.035473 \text{ s},\qquad d = 50 \times 0.363970 = 18.198512 \text{ m}$$

四层依次代入（θ 分别为 20°、15°、25°、18°），逐层累加得总时间 0.180603 s。可见掠射角越大，同样厚度耗时越长——声线绕了远路。

> **这个思想在综合实验中反复出现**：C8 的 M4/M5 层内距离与时间、M3 任意深度声速插值、C7 的移动平均，全部是"公式 → 函数"的封装。会封装函数，综合实验的代码才能从"一锅粥"变成分工清晰的模块。

## 三、解题思路

1. **写原型**：`layerTime`、`layerSpan` 两个声明放 main 前；
2. **写定义**：各自一行公式，角度转弧度可各自做或抽成小函数；
3. **主函数循环**：读 n；for 循环每圈读 h、c、thetaDeg，调用两函数并打印，同时累加 layerTime 的返回值；
4. **打印总时间**。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

#define PI 3.14159265358979

double layerTime(double h, double c, double thetaDeg);   /* 原型声明 */
double layerSpan(double h, double thetaDeg);

int main(void)
{
    int n, i;
    double h, c, thetaDeg, t, total = 0.0;

    scanf("%d", &n);                    /* 读入层数 */

    for (i = 1; i <= n; i++) {
        scanf("%lf %lf %lf", &h, &c, &thetaDeg);
        t = layerTime(h, c, thetaDeg);          /* 调用函数算时间 */
        printf("第%d层 时间=%.6f 水平跨距=%.6f\n",
               i, t, layerSpan(h, thetaDeg));   /* 嵌套在实参里直接调用 */
        total = total + t;                       /* 累加 */
    }

    printf("总传播时间=%.6f\n", total);
    return 0;
}

/* 层内传播时间 t = h / (c*cos(theta))，theta 为角度制 */
double layerTime(double h, double c, double thetaDeg)
{
    double rad = thetaDeg * PI / 180.0;          /* 角度转弧度 */
    return h / (c * cos(rad));
}

/* 层内水平跨距 d = h*tan(theta)，theta 为角度制 */
double layerSpan(double h, double thetaDeg)
{
    double rad = thetaDeg * PI / 180.0;
    return h * tan(rad);
}
```

## 五、运行验证

**样例 1 运行结果**：

```
第1层 时间=0.035473 水平跨距=18.198512
第2层 时间=0.054488 水平跨距=21.435935
第3层 时间=0.022366 水平跨距=13.989230
第4层 时间=0.068277 水平跨距=32.491970
总传播时间=0.180603
```

**样例 2 运行结果**（θ=0° 自检）：

```
第1层 时间=0.066667 水平跨距=0.000000
总传播时间=0.066667
```

**核对**：样例 1 各层数值已按 IEEE-754 double 与 `%.6f` 舍入规则用程序化复算核对（cos20°=0.9396926…，50/(1500×cos20°)=0.035473…）；样例 2 中 $\cos 0 = 1$、$\tan 0 = 0$，时间退化为 $h/c = 100/1500 = 0.066667$，水平跨距为 0——函数在退化情形下行为正确。另与第 3 章练习 40 对比：同样的 4 层，练习 40（垂直入射）总时间 0.171170 s，本题（斜入射）0.180603 s，斜程更长、时间更久，物理上自洽。

**反例验证**：若函数里忘了角度转弧度、直接 `cos(thetaDeg)`，第 1 层会算出 `cos(20 rad) = 0.408…`，时间变成 0.081…，与正确值明显不同——漏转弧度是三角函数题最常见的错误。

## 六、常见错误与讲解

**错误 1：没写原型或原型与定义不一致**

```c
double layerTime(double h, double c, double thetaDeg);   /* 原型 */
...
double layerTime(double h, double c, double theta)       /* 错：形参名不同没关系，但少写分号/类型不符会报错 */
```

原型放 main 之前，且返回类型、参数个数与类型必须和定义一致。编译器按原型检查每次调用。

**错误 2：角度没转弧度**

```c
return h / (c * cos(thetaDeg));    /* 错：cos 吃弧度，20° 必须先乘 PI/180 */
```

**错误 3：在函数里 scanf/printf"顺便"输入输出**

```c
double layerTime(double h, double c, double thetaDeg)
{
    scanf("%lf %lf %lf", &h, &c, &thetaDeg);   /* 错：函数应只管计算 */
    return h / (c * cos(thetaDeg * PI / 180.0));
}
```

函数的输入靠**参数**、输出靠 **return**，输入输出混进计算函数会让他处无法复用。

**错误 4：以为函数里改形参会改主函数变量**

```c
t = layerTime(h, c, thetaDeg);
/* 函数里 thetaDeg = 0; 并不会把主函数的 thetaDeg 清零 —— 传值只是抄了一份 */
```
