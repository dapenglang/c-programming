## 二、预备知识：文件—内存—文件流水线的基本原理（零基础阅读）

### 1. 为什么中间必须经过数组

排序的本质是**反复交换任意两个元素**：冒泡排序第 1 轮要把最大值送到末尾，最后一轮还要比较最前面两个元素。这意味着数据必须"召之即来"——下标 0 的元素和下标 n−1 的元素要能随时拿出来比较。文件做不到这一点（顺序读文件时，读过的地方要 fseek 才能回去），而数组天生支持 `a[i]` 的随机访问。所以流水线必然是三段式：

```
load_in.txt --fscanf循环--> 数组 a[0..n-1] --冒泡排序--> 有序数组 --fprintf循环--> load_sorted.txt
   （外存，乱序）             （内存，随机访问）          （内存，有序）            （外存，有序）
```

### 2. 各环节的职责

- **读入环节**：第一个 fscanf 读 n，循环 fscanf 读 n 个数。职责单一：把外存数据完整搬到内存，**不掺任何加工**；
- **算法环节**：对数组做冒泡排序，这是第 5 章 5.5 节的原版算法，一个字都不用改——文件的出现没有改变排序算法本身，改变的只是数据"从哪来、到哪去"；
- **写出环节**：把有序数组逐行写入新文件，同样不掺加工；
- **检查环节**：贯穿全程的纪律——两个 fopen 检查 NULL；n 不在 (0, 100] 范围内时报错退出，防止数组越界。**先校验再使用**是流水线各站共同的规矩。

### 3. 文件指针的生命周期

fin 的生命周期覆盖整个读入环节，读完即可 fclose（不等排序）——排序只用内存，与文件无关；fout 的生命周期覆盖写出环节。与练习 11、12 不同的是，本题两个文件的活跃期**先后错开**：先关 fin、再开算、最后用 fout。生命周期"该长则长、该短则短"，尽早关闭不再使用的文件是良好习惯。

## 三、解题思路

1. **开文件并检查**：fin "r"、fout "w"，各自检查，失败路径上关闭已打开的指针；
2. **读入与校验**：fscanf 读 n；若 `n <= 0 || n > 100` 输出错误并退出；循环读入 n 个值到数组；
3. **冒泡排序**：双层循环，相邻比较逆序交换；
4. **写出与报告**：循环 fprintf 写出排序结果，`a[0]`、`a[n-1]` 即最小、最大值；
5. **收尾**：fclose 两个文件，屏幕输出摘要。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fin, *fout;
    double a[100];            /* 阻力序列，最多 100 个 */
    int n, i, j;              /* 循环变量 */
    double t;

    fin = fopen("load_in.txt", "r");
    if (fin == NULL) {
        printf("错误：无法打开 load_in.txt\n");
        return 1;
    }

    fscanf(fin, "%d", &n);
    if (n <= 0 || n > 100) {
        printf("数据个数无效\n");
        fclose(fin);
        return 1;
    }
    for (i = 0; i < n; i++)
        fscanf(fin, "%lf", &a[i]);
    fclose(fin);              /* 读入完毕，fin 的使命结束 */

    /* 冒泡排序：从小到大 */
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }

    fout = fopen("load_sorted.txt", "w");
    if (fout == NULL) {
        printf("错误：无法创建 load_sorted.txt\n");
        return 1;
    }
    for (i = 0; i < n; i++)
        fprintf(fout, "%.1f\n", a[i]);
    fclose(fout);

    printf("读入 %d 个数据，已排序写入 load_sorted.txt\n", n);
    printf("最大 = %.2f kN，最小 = %.2f kN\n", a[n - 1], a[0]);

    return 0;
}
```

## 五、运行验证

**手工模拟排序**（n = 6，序列 23.5 25.1 19.8 27.6 22.4 24.9）：

- 第 1 轮：依次比较相邻元素，27.6 一路右移到末尾 → `23.5 25.1 19.8 22.4 24.9 27.6`；
- 第 2 轮：25.1 冒到倒数第二 → `23.5 19.8 22.4 24.9 25.1 27.6`；
- 第 3 轮：24.9 到位 → `19.8 23.5 22.4 24.9 25.1 27.6`；再比较 23.5 与 19.8、22.4，交换为 `19.8 22.4 23.5 24.9 25.1 27.6`；
- 继续各轮不再发生交换，最终有序：`19.8 22.4 23.5 24.9 25.1 27.6`。

**文件内容前后变化**：`load_in.txt` 保持不变；`load_sorted.txt` 新建，内容与手工模拟结果一致（每行一个数，共 6 行）。

**屏幕输出**：

```
读入 6 个数据，已排序写入 load_sorted.txt
最大 = 27.60 kN，最小 = 19.80 kN
```

## 六、常见错误与讲解

**错误 1：没检查 n 就直接当循环上限**

```c
fscanf(fin, "%d", &n);
double a[n];                      /* 错：变长数组且 n 未经校验 */
for (i = 0; i < n; i++) fscanf(fin, "%lf", &a[i]);
```

若文件首行是 0 或负数，循环一次都不执行，后续 `a[0]`、`a[n-1]` 就是越界访问；若 n 很大则直接越界写内存。**先校验 (0, 100] 再使用**。

**错误 2：数组大小与文件第一行不一致**

定义了 `double a[50]` 却允许 n 到 100，n 取大值时越界。数组容量常量与校验上限必须一致（都用 100），最好用 `#define N 100` 统一。

**错误 3：排序循环边界写错**

```c
for (i = 0; i < n; i++)
    for (j = 0; j < n; j++)          /* 错：j+1 会访问到 a[n]，越界 */
        if (a[j] > a[j + 1]) ...
for (j = 0; j < n - 1 - i; j++)      /* 对：内层止于倒数第二个 */
```

**错误 4：屏幕输出与文件输出精度不一致**

文件里是 `%.1f`（一位小数），屏幕上最大最小值若用 `%.1f` 也可以，但题目要求 2 位小数（`%.2f`）。同一程序对不同输出口可以有不同精度，关键是**与格式约定一致**，不要混写。

## 七、与综合实验的衔接

- 实验 **C7（冰区载荷辨识与统计）**中，"排序整理"是绘制分布图与计算分位数（如 95% 分位载荷）的前提。本题把这条流水线的三段——读入、排序、写出——全部打通，你在实验中只需把数组容量放大、把排序换成更高效的算法（如快速排序），骨架不变；
- 排好序的文件还有一个附赠好处：**有序文件的统计变简单了**——最小值在第一行、最大值在最后一行、中位数在中间。练习 20 的完整流水线将把本题的"排序站"与统计、报表站串成一条更长的线，届时这条"文件—内存—文件"的主干道就是现成的。
