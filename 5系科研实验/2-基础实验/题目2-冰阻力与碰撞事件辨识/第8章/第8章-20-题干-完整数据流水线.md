# 第 8 章 练习 20　完整数据流水线

**对应章节**：8 数据持久化存储方法（8.1 文件概述、8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）；综合运用第 2～7 章全部知识

**场景来源**：综合实验 C7《冰区载荷辨识与统计系统》（水声学院）——本练习是该实验中"数据读入 → 统计辨识 → 报表输出"主流程的完整实现，也是本章乃至全课程的综合题。

**建议用时**：30～40 分钟

## 一、应用场景

实验 C7 的最终交付物是一份**统计报表**：从冰阻力监测文件出发，给出样本总数、平均阻力、最大最小阻力、超阈值样本数，并附上按阻力从大到小排序的完整序列，全部落盘成报表文件，同时在屏幕上呈现。这一个任务把课程全部家底串了起来：变量与运算（第 2 章）、循环与分支（第 3 章）、函数分解（第 4 章）、数组与排序（第 5 章）、指针传参（第 6 章）、结构化组织（第 7 章）、文件读写（第 8 章）。本练习是全课程的"毕业照"。

## 二、任务要求

编写完整程序 `pipeline.c`，按下列模块组织（**必须使用函数分解**）：

1. **读入模块**：以 `"r"` 打开 `load_in.txt`（**检查 fopen 返回值**），第一行为样本个数 n（$1 \le n \le 100$，越界报 `数据个数无效` 并结束），第二行为 n 个阻力值（kN，实数），读入一维 double 数组后关闭文件；
2. **统计模块**：用指针形参一次返回三个统计量——平均阻力、最大阻力、最小阻力；另统计超过阈值 25.0 kN 的样本个数（阈值用 `#define` 常量）；
3. **排序模块**：冒泡排序，把数组按**从大到小**排序；
4. **报表模块**：设计一个接收 `FILE *` 形参的函数 `report(FILE *out, ...)`，负责输出完整报表——先输出五行摘要（样本总数、平均、最大、最小、超阈值数），再输出分隔线 `------ 降序排序结果 ------` 与排序后的全部数值（每行一个，保留 1 位小数）。调用两次：`report(fo, ...)` 写入报表文件 `load_report.txt`，`report(stdout, ...)` 输出到屏幕（stdout 是系统预打开的"标准输出文件"指针）；
5. **收尾**：所有打开的文件全部 fclose。

**数据文件格式约定**：`load_in.txt` 第一行 n（整数），第二行 n 个实数（空格分隔）。样例数据行：第一行 `8`，第二行 `23.5 25.1 19.8 27.6 22.4 24.9 31.2 18.7`。

## 三、输入输出格式

**输入文件**：`load_in.txt`（第一行 n，第二行 n 个实数）。

**输出文件**：`load_report.txt`（五行摘要 + 分隔线 + 降序序列）。

**屏幕输出**：与 `load_report.txt` 内容完全相同（报表函数被调用两次）。

## 四、样例

**输入文件 load_in.txt 的内容**：

```
8
23.5 25.1 19.8 27.6 22.4 24.9 31.2 18.7
```

**程序运行后 load_report.txt 的内容（屏幕输出与之相同）**：

```

样本总数：8
平均阻力：24.15 kN
最大阻力：31.20 kN
最小阻力：18.70 kN
超阈值(>25.0)样本数：3
------ 降序排序结果 ------
31.2
27.6
25.1
24.9
23.5
22.4
19.8
18.7
```

## 五、提示

- 平均阻力 = 全部样本之和除以 n；手算核对：$23.5+25.1+19.8+27.6+22.4+24.9+31.2+18.7 = 193.2$，$193.2/8 = 24.15$；
- 统计模块用指针形参返回多个结果（第 6 章技术）：`void stats(double a[], int n, double *pavg, double *pmax, double *pmin)`；
- 冒泡降序只需把升序写法的比较方向反过来：`if (a[j] < a[j+1])` 时交换；
- `report` 的第一个形参是 `FILE *out`，函数体内所有输出都用 `fprintf(out, ...)`——传 `fo` 就写文件，传 `stdout` 就上屏幕，**一份报表代码两个去处**；
- 阈值统计与排序互不依赖，建议先统计（此时数组还是乱序）再排序。
