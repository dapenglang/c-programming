# 题目 C8：基于分层线性插值的声线传播时间计算系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行声线传播时间计算工具，围绕"海洋中声速随深度变化、声线在分层常梯度介质中传播，需要把水层切分为若干层、逐层用线性插值取声速并累加传播时间与水平跨距"这一水声工程基础模型展开。系统从文本文件读入"深度—声速"分层表，完成有效性检查，对任意深度做线性插值求声速，按初始掠射角用三角函数计算各层内的水平距离与传播时间，逐层累加得到总传播时间与水平位移，对多条声线路径批量计算并按传播时间排序找出最快到达路径，最后输出结果文件与字符声线轨迹图。

声在海水中的传播速度约为 1500 m/s，但并非常数：它随温度、盐度与压力变化，典型深海中表层因温度高声速大、中层因低温出现声速极小值、深层因压力回升。声速的空间变化使声线走弧线而非直线，因此声呐作用距离预报、定位解算、水声通信时延估计都必须计算声线传播时间。工程上最常用的简化就是"分层线性"模型：把海水按深度切成若干层，认为每层内声速随深度线性变化（或层内取平均声速），声线在层内按直线（或折线）处理，用斯涅尔定律决定每层的掠射角，逐层累加时间与水平距离。这正是大一学生用三角函数、循环与排序就能完整复现的经典算法。

本系统支撑的关键场景包括：① 主动声呐回波到达时间的预报与定位误差估计；② 水声通信系统的多径时延结构计算；③ 海洋声速剖面（CTD/XBT 实测）的快速验算；④ 声线弯曲对水声实验布放方案的影响评估。学生在大一阶段就能用 C 语言把"分层插值—三角函数—逐层累加—排序寻优"完整跑通，为后续《水声学原理》《声呐技术》《海洋声场计算》等课程建立直观基础。本题目与水声工程专业"海洋声场计算"方向直接相关，训练学生把物理模型转化为"数据读入—算法实现—数据输出"完整程序工程的能力。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的声线传播时间计算系统：从文本文件读入分层声速剖面表，实现数据有效性检查，对任意深度做线性插值求声速，按给定初始掠射角用斯涅尔定律逐层确定掠射角，用三角函数计算每层内的水平跨距与传播时间，逐层累加得到声线到达指定深度/距离的总传播时间，对一组初始掠射角不同的多条声线批量计算，按总传播时间用选择排序找出最快到达路径，最后生成结果文件与字符声线轨迹图。

专业关联上，本题目复现了声呐工程中"声速剖面插值—声线跟踪—多径到达时间排序"三类真实业务的核心计算。学生在此过程中将掌握课程中的函数、一维数组、选择排序、三角函数库函数与文件读写，并第一次把连续变化的物理量"离散化"为分层数据处理，理解"一个物理模型如何变成一套程序"。

## 三、数据来源与格式

- **数据文件格式**：声速剖面采用纯文本格式，首行为标题说明，其后每行一条分层记录，字段以空格分隔。字段依次为：层底深度 z（单位：米，正实数，自海面向下递增）、该深度处声速 c（单位：米/秒）。声线参数文件 `ray_config.txt` 另给出声源深度、接收深度与一组初始掠射角。

```
# depth_m   sound_speed_mps
0.0         1512.5
50.0        1508.2
100.0       1495.6
200.0       1483.4
500.0       1490.1
1000.0      1502.8
1500.0      1515.3
```

```
# src_depth  rcv_depth  ray_angle_deg(空格分隔多个)
10.0         800.0      -8.0  -4.0  -1.0  1.0  4.0  8.0
```

- **仿真数据生成规则**：
  - 分层深度：非均匀分层，共 10～30 层，表层密（25～50 m 一层）、深层疏（200～500 m 一层），最大深度 1000～3000 m。
  - 声速：在典型深海剖面（表层约 1512 m/s、声速极小值层约 1483 m/s、深层回升至 1515 m/s 以上）基础上加 ±0.5 m/s 扰动。
  - 初始掠射角：取 −15°～+15° 内的若干角度（正值向下），覆盖 6～12 条声线。
  - **异常值注入方式**：由教师提供的生成程序人为注入三类错误。其一，深度为负数或层底深度出现乱序（比上一层还浅）；其二，声速超出海水合理范围（小于 1400 或大于 1600 m/s，判越界）；其三，声速字段非数字串导致 `fscanf` 错位。校验模块需输出"行号—异常类型—处理动作"清单。

- **真实数据集（如有）**：真实声速剖面可参考美国国家海洋数据中心 WOA（World Ocean Atlas，https://www.ncei.noaa.gov/products/world-ocean-atlas）的海洋温度盐度数据按声速经验公式换算。学生**无需下载**真实数据文件，课程提供与上述字段含义对应的简化仿真数据表；表中"声速"对应实测温度盐度经经验公式换算后的分层声速值。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_LAYER   40       /* 最多分层数 */
#define MAX_RAY     16       /* 最多声线条数 */
#define MAX_TRACE   400      /* 每条声线轨迹最多记录点数 */

/* ===== 分层记录 ===== */
struct Layer {
    double z;                /* 层底深度，单位：米 */
    double c;                /* 该深度处声速，单位：米/秒 */
    int    valid;            /* 有效标志：1 有效，0 异常剔除 */
};

/* ===== 声线路径结果 ===== */
struct Ray {
    double ang0;             /* 初始掠射角，单位：度（正向下） */
    double time;             /* 总传播时间，单位：秒 */
    double xrange;           /* 总水平位移，单位：米 */
    int    bounces;          /* 层内反转（越过极小值层）次数 */
    int    nPts;             /* 轨迹记录点数 */
    double traceZ[MAX_TRACE];/* 轨迹深度序列 */
    double traceX[MAX_TRACE];/* 轨迹水平距离序列 */
};

/* ===== 全局数据区 ===== */
struct Layer g_layer[MAX_LAYER];   /* 声速剖面分层表 */
int          g_layerCount;         /* 有效分层数 */
double       g_srcZ;               /* 声源深度，单位：米 */
double       g_rcvZ;               /* 接收深度，单位：米 */
struct Ray   g_ray[MAX_RAY];       /* 声线结果表 */
int          g_rayCount;           /* 声线条数 */

/* ===== 处理日志（供报表模块使用） ===== */
struct LogItem {
    char  op[24];            /* 操作名，如 "RAY_TRACE" */
    char  detail[64];        /* 参数与关键结果摘要 */
};
struct LogItem g_log[MAX_LAYER * 2];
int            g_logCount;         /* 已记录日志条数 */
```

辅助说明：分层表用结构体数组组织（课程 7.1/7.2），每条声线的轨迹用两个平行一维数组缓冲（课程 5.1），声线结果表按传播时间排序（课程 5.3 选择排序）。声速插值与层内计算封装为函数（课程 4.1/4.2），避免主流程膨胀。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入与预处理（2 个模块）

**M1 分层声速剖面读入模块**（源文件 `SvpIO.c`）

- 功能简介：打开声速剖面文本文件，跳过首行标题，用循环 + `fscanf` 逐行读入层底深度与声速，填充 `g_layer[]` 并记录层数；同时读入声线参数文件中的声源深度、接收深度与初始掠射角列表；文件不存在时给出明确提示。
- 输入：文件路径（默认 `svp.txt` 与 `ray_config.txt`）。
- 输出：`g_layer[]`、`g_layerCount`、`g_srcZ`、`g_rcvZ`、`g_ray[]` 初始角度字段；返回成功/失败标志。

**M2 数据有效性检查模块**（源文件 `SvpCheck.c`）

- 功能简介：逐层检查深度是否为负、层底深度是否单调递增、声速是否在 [1400, 1600] m/s 合理范围；对异常记录置 `valid=0` 并生成"行号—异常类型—处理动作"清单；同时检查声源/接收深度是否落在剖面覆盖范围内。
- 输入：`g_layer[]`、`g_layerCount`、`g_srcZ`、`g_rcvZ`。
- 输出：屏幕校验报告；修正后的 `g_layer[]`。

### 第二部分：算法实现（5 个模块）

**M3 任意深度声速线性插值模块**（源文件 `SvpInterp.c`）

- 功能简介：实现函数 `double svpAt(double z)`：定位目标深度所在层（$z_i \le z \le z_{i+1}$），用线性插值 $c(z) = c_i + \dfrac{c_{i+1} - c_i}{z_{i+1} - z_i}(z - z_i)$ 求声速；深度越界时返回 -1.0 并提示。
- 输入：目标深度 z，`g_layer[]`。
- 输出：返回该深度声速；屏幕抽样验证若干深度的插值结果。

**M4 层内水平距离与传播时间计算模块**（源文件 `RayCalc.c`）

- 功能简介：封装两个函数——按斯涅尔定律 $c(z)\cos\theta(z) = c_0\cos\theta_0$ 由层顶声速与当前掠射角求层内掠射角，进而计算层内水平跨距 $\Delta x = \dfrac{\Delta z}{\tan\theta}$ 与传播时间 $\Delta t = \dfrac{\Delta z}{c(z)\sin\theta}$；掠射角接近 0°（水平传播）时做防除零保护，改用层内平均声速直线近似。
- 输入：层内声速（两端值）、入层掠射角、层厚。
- 输出：返回层内 $\Delta x$ 与 $\Delta t$（通过结构体参数带回）；屏幕调试输出。

**M5 逐层累加总传播时间模块**（源文件 `RayCalc.c`）

- 功能简介：对单条声线，从声源深度出发逐层向下（或向极小值层反向）推进：调用 M3 取层界声速、调用 M4 求层内增量，把水平距离与时间累加，同时把层界点的 $(x, z)$ 记入轨迹数组；到达接收深度即得总传播时间与总水平位移；掠射角符号反转（声线上翘回转）时正确换层。
- 输入：初始掠射角、`g_layer[]`、`g_srcZ`、`g_rcvZ`。
- 输出：填充对应 `g_ray[]` 的时间、水平位移、轨迹数组；屏幕进度摘要。

**M6 多条声线路径批量计算模块**（源文件 `RayBatch.c`）

- 功能简介：遍历 `ray_config.txt` 给定的全部初始掠射角，对每条声线调用 M5 计算，填充 `g_ray[]`；打印每条声线的"初始角—到达时间—水平位移"汇总行，统计合法完成的声线条数。
- 输入：`g_ray[]` 初始角度、`g_layer[]`。
- 输出：`g_ray[]` 完整结果；屏幕批量计算汇总。

**M7 路径按传播时间排序模块**（源文件 `RaySort.c`）

- 功能简介：对 `g_ray[]` 按总传播时间用选择排序升序排列，找出最快到达的声线与最慢到达的声线；输出排序后的"名次—初始角—时间—水平位移"表，标注最快路径（多径中最早到达者用于声呐测距）。
- 输入：`g_ray[]`、`g_rayCount`。
- 输出：排序后的 `g_ray[]`；屏幕排序表。

### 第三部分：输出（3 个模块）

**M8 结果文件输出模块**（源文件 `SvpIO.c`）

- 功能简介：把声线排序结果按"名次—初始角—总时间—水平位移—反转次数"列写出到 `ray_result.csv`，首行写列名；把最快声线的轨迹点按"x—z—t"写出到 `ray_trace.txt` 便于核对。
- 输入：`g_ray[]`、`g_rayCount`。
- 输出：`ray_result.csv`、`ray_trace.txt`；屏幕确认信息。

**M9 屏幕报表与字符声线轨迹图模块**（源文件 `RayPlot.c`）

- 功能简介：以横轴为水平距离、纵轴为深度（海面在上），用不同字符（`*`、`o`、`+`、`.`）绘制至多 4 条声线的字符轨迹，叠加声速极小值层虚线；屏幕同时打印声速剖面表与最快路径结论。
- 输入：`g_layer[]`、`g_ray[]`。
- 输出：屏幕字符轨迹图与报表。

**M10 主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：主菜单用 `do-while + switch` 调度 M1～M9，用状态标记约束"必须先读入并校验剖面才能计算"；提供参数设置子菜单修改声源/接收深度并重算，观察到达时间随深度的变化。
- 输入：用户菜单选项。
- 输出：调度各模块；屏幕运行状态提示。

## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环，先用状态标记 `g_loaded` 约束流程——未读入剖面时只允许执行 M1；读入后依次可调用 M2 校验、M3 插值、M4～M5 单线计算、M6 批量计算、M7 排序、M8～M9 输出。任何计算模块要求剖面中至少有 2 个有效层且覆盖声源与接收深度，否则提示先执行 M2。

**数据流**：

```
svp.txt ─► M1 读入 ─► g_layer[] ─► M2 有效性检查 ─► 有效剖面
                                        │
ray_config.txt ─► M1 读入 ─► g_srcZ/g_rcvZ/初始角列表
                                        │
        M3 声速线性插值 svpAt(z) ◄──────┘
             │
             ▼
        M4 层内 Δx/Δt 计算（斯涅尔 + 三角函数）
             │
             ▼
        M5 逐层累加（单线）─► 轨迹数组 traceZ/traceX
             │
             ▼
        M6 多线批量 ─► g_ray[] ─► M7 选择排序（按时间）
                                        │
                     ┌──────────────────┼───────────────┐
                     ▼                  ▼               ▼
              M8 结果文件输出    M9 字符轨迹图     M10 主控菜单调度
```

所有模块之间只通过全局分层表、声线结果表与函数参数交换数据，函数头部（接口）在编码前由全组书面约定。

## 十、选做扩展

1. **接收深度敏感性分析**：把接收深度取 200、500、800、1200 m 四档分别重跑 M5～M7，输出"接收深度—最快时间—最快初始角"对照表，观察声道轴附近传播时间出现极小的现象。
2. **直线近似对比**：在 M4 之外再实现"层内取平均声速直线传播"的简化算法，把两种模型的到达时间与水平位移并排对比，体会分层精度对结果的影响。
3. **等时线表格**：对最快声线按时间等间隔（如每 0.05 s）抽取轨迹点，输出"时刻—深度—水平距离"表并画字符轨迹，观察声线在不同层中的传播快慢。
