## 二、预备知识：层内水平跨距的基本原理（零基础阅读）

### 1. 问题是怎么来的

声波在海水中传播，速度随深度、温度、盐度变化，路径因此弯曲。直接计算弯曲路径很难，工程上把它"化整为零"：把海水按深度切成许多薄层，**每层内近似认为声线走直线**，只是进入下一层时方向折转一下（类似光在不同介质界面的折射）。

于是一个基本几何问题反复出现：声线以掠射角 $\theta$ 穿过厚度为 $H$ 的一层水，它在水平方向前进了多远？这个量叫**层内水平跨距**，记作 $x$。综合实验 C8 的声线追踪模块，就是对每一层算一次 $x$，再累加得到声线落点的水平偏移。

### 2. 公式推导

画一个直角三角形：竖直直角边是层厚 $H$（声线在层内下降的高度），斜边是层内的声线路径，声线与水平面的夹角是掠射角 $\theta$。由三角定义：

$$\tan\theta = \frac{\text{对边}}{\text{邻边}} = \frac{H}{x}$$

解出水平跨距：

$$x = \frac{H}{\tan\theta} = H\cdot\frac{\cos\theta}{\sin\theta}$$

最后一步用了 $\tan\theta = \sin\theta/\cos\theta$。写成"先 $\cos$ 后 $\sin$"的形式，是为了本题刻意练习两个基本三角函数（而不直接用 `tan`）。

**弧度换算**：C 的 `sin`/`cos` 接收的是**弧度**。角度制 $\theta_{deg}$ 换成弧度：

$$\theta_{rad} = \theta_{deg} \times \frac{\pi}{180}$$

### 3. 代入本例数值

样例 1：$H = 120.0$ m，$\theta_{deg} = 32.5°$。

$$\theta_{rad} = 32.5 \times \frac{\pi}{180} \approx 0.567232$$

$$\sin\theta \approx 0.537300,\qquad \cos\theta \approx 0.843391$$

$$x = 120.0 \times \frac{0.843391}{0.537300} \approx 120.0 \times 1.569686 \approx 188.36\ \text{m}$$

样例 2：$\theta_{deg} = 45°$，$\tan 45° = 1$，故 $x = H = 80.00$ m——一个可用心算验证的标尺样例。

（以上数值已用 Python 按 IEEE-754 double 复算：`120.0/tan(32.5°) = 188.3622…`，`%.2f` 输出 `188.36`。）

### 4. 通过编程翻译

| 数学 | C 语言 |
|---|---|
| $\pi$ | `#define PI 3.14159265358979` |
| $\theta_{rad}$ | `th = theta_deg * PI / 180.0;` |
| $\sin\theta,\ \cos\theta$ | `sin(th)`、`cos(th)`（需 `#include <math.h>`） |
| $x = H\cos\theta/\sin\theta$ | `x = H * cos(th) / sin(th);` |
| 输出 | `printf("span = %.2f m\n", x);` |

注意 `H * cos(th) / sin(th)` 从左到右结合，等价于 $(H\cdot\cos\theta)/\sin\theta$，与公式一致。

## 三、解题思路

1. `#define PI`，`#include <math.h>`；
2. 读入 `H` 与 `theta_deg`；
3. 换算弧度 `th`；
4. 按 `x = H * cos(th) / sin(th)` 计算；
5. `printf` 输出。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

#define PI 3.14159265358979

int main(void)
{
    double H, theta_deg;        /* 层厚度（m）、掠射角（角度制） */
    double th, x;               /* 弧度制角度、层内水平跨距 */

    scanf("%lf %lf", &H, &theta_deg);

    th = theta_deg * PI / 180.0;        /* 角度 → 弧度 */
    x = H * cos(th) / sin(th);          /* x = H / tanθ，用 cos/sin 表达 */

    printf("span = %.2f m\n", x);
    return 0;
}
```

## 五、运行验证

**样例 1**（输入 `120.0 32.5`）：

```
span = 188.36 m
```

**样例 2**（输入 `80.0 45.0`）：

```
span = 80.00 m
```

| 输入 | $\theta_{rad}$ | $\cos/\sin$ | $x$ | 核对 |
|---|---|---|---|---|
| 120.0 32.5 | 0.567232 | 1.569686 | 188.36 | $=120/\tan 32.5°$ ✓ |
| 80.0 45.0 | 0.785398 | 1.000000 | 80.00 | $\tan 45°=1$ ✓ |

**物理合理性验证**（输入 `100.0 10.0`）：输出 `span = 567.13 m`——掠射角很小时声线近乎水平，跨距远大于层厚，符合直觉。

## 六、常见错误与讲解

**错误 1：忘了弧度换算（第一大坑）**

```c
th = theta_deg;                      /* 错：把 32.5 当成弧度，结果完全错误 */
th = theta_deg * PI / 180.0;         /* 对 */
```

`sin(30.0)` 是 $\sin$ 约 $1719°$，不是 $\sin 30°$。若程序"编译通过但数值离谱"，先查弧度。

**错误 2：表达式写错**

```c
x = H * cos(th) / sin(th);     /* 对：H·cosθ/sinθ */
x = H / cos(th) * sin(th);     /* 错：分子分母颠倒，等于 H·tanθ */
```

用样例 2（$45°$）可快速自测：错版会输出 `80 * 1 = 80.00`——碰巧也对！所以**必须再用样例 1 验证**：错版输出 `120 * 0.6372 ≈ 76.46`，与 `188.36` 相差甚远。多备一个非对称样例是好习惯。

**错误 3：漏写 `#include <math.h>`**——部分编译器对 `sin/cos` 隐式声明给出警告，返回值按 `int` 处理会得到垃圾数。用数学函数必带 `math.h`。

**错误 4：`PI` 精度不足写错数字**——如 `#define PI 3.14`，样例 1 会输出 `188.32` 等偏差结果。工程上至少取到小数点后 8 位。

## 七、与综合实验的衔接

- 实验 **C8《基于分层线性插值的声线传播时间计算系统》**的第 4 模块对本题做了推广：对每一层，先用第 3 模块的线性插值求出层内声速，再由 Snell 定律折算该层掠射角，最后套用本题公式 $x = H/\tan\theta$ 得到层内水平跨距，第 6 模块再逐层累加跨距与传播时间。本题正是那条流水线上**重复次数最多**的一个算子；
- 学完第 3 章循环（练习 40：逐层传播时间累加）后，把本题的公式装进循环体，就能对整条声线路径逐层计算——那时你会真切体会到"把单层算对"的价值。
