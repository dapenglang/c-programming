## 二、预备知识：函数封装的基本原理（零基础阅读）

### 1. 问题是怎么来的

算采暖负荷的公式 $Q = K A \Delta T$ 在工程里要用很多次：外墙用一次、外窗用一次、屋面用一次，将来还可能加上外门、地面。如果每处都把公式重抄一遍，代码冗长，一旦公式要改（比如加入朝向修正系数），就得逐处修改，极易漏改出错。

程序员的解决办法是**封装**：把这段计算写成一个独立的**函数**，给它起个名字、规定好"要喂给它什么"和"它能吐出什么"，以后需要时就喊它的名字。这就是模块化程序设计。

### 2. 函数的三要素

一个函数由三部分构成，缺一不可：

- **函数名**：`calc_Q`，调用时用；
- **参数表**：`(double K, double A, double dT)`，告诉调用者"我要三个实数才能干活"；
- **返回值类型**：最前面的 `double`，说明"我干完活会交回一个实数"。

写成一行就是**函数原型**：

```c
double calc_Q(double K, double A, double dT);
```

### 3. 形参与实参：一次"送货"的过程

函数定义里的 `K`、`A`、`dT` 叫**形式参数**（形参），它们只是占位符，函数没被调用时里面没有值。主函数调用时写的是**实际参数**（实参），比如：

```c
double q1 = calc_Q(0.45, 120.0, 49.0);
```

这一刻发生了三件事：把实参 0.45 复制给形参 K、120.0 复制给 A、49.0 复制给 dT；函数体执行 `return K*A*dT;` 得到 2646.0；这个值被交回去赋给 `q1`。

**关键理解：参数传递是"赋值复制"，形参改了不影响实参**。这一点到第 6 章（指针参数）会被打破，届时再讲。

### 4. 用本例走一遍

以样例 1 的外墙为例，$K = 0.45$、$A = 120.0$、$\Delta T = 49.0$（室外 $-29\ ^\circ\text{C}$、室内 $20\ ^\circ\text{C}$）：

$$
Q_{\text{wall}} = 0.45 \times 120.0 \times 49.0 = 2646.0\ \text{W}
$$

外窗 $K = 2.80$、$A = 30.0$：$Q = 2.80 \times 30.0 \times 49.0 = 4116.0\ \text{W}$。

屋面 $K = 0.35$、$A = 150.0$：$Q = 0.35 \times 150.0 \times 49.0 = 2572.5\ \text{W}$。

总负荷 $= 2646.0 + 4116.0 + 2572.5 = 9334.5\ \text{W}$。三次调用用的都是同一个函数，只是实参不同。

### 5. 编程时怎么用它

函数定义的语法骨架：

```c
返回值类型 函数名(形参类型 形参名, ...)
{
    语句;
    return 结果;
}
```

注意 `return` 后面跟的类型要和函数名前面的返回值类型一致。本题函数体只有一行 `return K * A * dT;`——虽然简单，但它是"封装一劳永逸"的典范。

## 三、解题思路

1. **声明并定义函数** `calc_Q`，参数 K、A、dT，返回 `K*A*dT`；
2. **主函数读入 6 个围护结构参数和 1 个温差** `dT`；
3. **三次调用**：`q1 = calc_Q(Kw, Aw, dT)` 等，分别得到外墙、外窗、屋面的负荷；
4. **累加总负荷**：`qtotal = q1 + q2 + q3`；
5. **输出**四项，均用 `%.1f`。

## 四、参考代码

```c
#include <stdio.h>

/* 函数声明（原型）：告诉编译器 calc_Q 长什么样 */
double calc_Q(double K, double A, double dT);

int main(void)
{
    double Kw, Aw;      /* 外墙传热系数 W/(m^2*K)、面积 m^2 */
    double Kc, Ac;      /* 外窗传热系数、面积 */
    double Kr, Ar;      /* 屋面传热系数、面积 */
    double dT;          /* 室内外温差，K */
    double q1, q2, q3;  /* 三种围护结构各自的负荷，W */

    /* 读入外墙、外窗、屋面参数，以及温差 */
    scanf("%lf %lf", &Kw, &Aw);
    scanf("%lf %lf", &Kc, &Ac);
    scanf("%lf %lf", &Kr, &Ar);
    scanf("%lf", &dT);

    /* 三次调用同一函数，只是实参不同 */
    q1 = calc_Q(Kw, Aw, dT);    /* 外墙负荷 */
    q2 = calc_Q(Kc, Ac, dT);    /* 外窗负荷 */
    q3 = calc_Q(Kr, Ar, dT);    /* 屋面负荷 */

    /* 输出各项负荷及总负荷 */
    printf("Q_wall = %.1f\n", q1);
    printf("Q_window = %.1f\n", q2);
    printf("Q_roof = %.1f\n", q3);
    printf("Q_total = %.1f\n", q1 + q2 + q3);

    return 0;
}

/* 函数定义：按 Q = K * A * dT 计算围护结构采暖负荷 */
double calc_Q(double K, double A, double dT)
{
    return K * A * dT;
}
```

## 六、常见错误与讲解

**错误 1：忘记函数声明**

```c
int main(void) { ... calc_Q(...) ... }   /* calc_Q 定义在 main 之后 */
double calc_Q(...) { ... }
```

若把函数定义写在 `main` 之后，又没在开头写原型，编译器在 `main` 里不认识 `calc_Q`。正确做法：在 `main` 之前写上原型 `double calc_Q(double K, double A, double dT);`。

**错误 2：形参类型与实参不匹配**

```c
double calc_Q(int K, double A, double dT) ...   /* 错：K 写成 int */
```

传进去 `0.45` 会被截断成 `0`，负荷算成 0。参数类型必须与物理量的实际类型一致。

**错误 3：忘记 return 或写错返回值类型**

```c
double calc_Q(double K, double A, double dT)
{
    printf("%f\n", K*A*dT);      /* 错：只打印没返回，调用处得到随机值 */
}
```

函数既然声明返回 `double`，函数体里就必须有 `return`，且后面跟一个 `double` 值。

**错误 4：把函数定义写在另一个函数体内**

```c
int main(void)
{
    double calc_Q(...) { ... }   /* 错：C 语言不允许函数嵌套定义 */
}
```

函数必须定义在别的函数**外面**，与 `main` 平级。

## 七、与综合实验的衔接

- 实验 **A4（房间冬季采暖负荷计算）**中，本练习对应"围护结构传热负荷"模块。真实系统里围护结构类型更多、每种还要乘朝向修正系数和温差修正系数，但核心仍然是本练习这个 `calc_Q`；
- 本练习的函数只接收参数、返回值，不涉及数组。学到第 6 章（指针）后，`calc_Q` 可以改写成"经指针参数把多个结果一次带回"的形式；学到第 7 章（结构体）后，可以把"传热系数 + 面积 + 负荷"打包成一个结构体传给函数，参数表会大幅缩短。**模块化是把大系统拆小的第一步，函数是其中最基本的积木。**
