# 第 5 章 练习 25　测线剂量率数组与最值定位

**所属综合实验**：D7（D7-基于数值积分的辐射剂量场分布估算系统）

**对应章节**：5 数组与批量数据处理（5.1 一维数组的定义与初始化、5.2 数组元素的引用与遍历、5.4 遍历中的最值与定位）

**场景来源**：综合实验 D7《基于数值积分的辐射剂量场分布估算系统》（核学院）——本练习是该实验中"测线扫描与热点定位"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

辐射场评估常沿着一条**测线**布置若干个测点，逐个测量或逐个计算剂量率，形成一串数据。工程师最关心两件事：整条测线的剂量率**分布**长什么样，以及**最高点（热点）在哪里**。

综合实验 D7 里，程序会沿测线逐点算剂量率（先算到每个点源的平方反比贡献再累加），把结果存进数组，然后找出最大值及其位置——这个位置就是"热点"，是辐射防护中需要重点关注的区域。

本题给定一维测线上各点到一个点源的距离，算出各点剂量率存入数组，再找出最大值及其下标位置。

## 二、任务要求

编写一个完整程序 `line_max.c`：

1. 从键盘读入测点个数 `n`（**题目保证 2 ≤ n ≤ 50**）；
2. 程序中用**常量**存放点源强度 $S$（取 120.0，μSv·m²/h）；
3. 按顺序读入 `n` 个测点到源的距离 `d[i]`（m，**题目保证 d[i] > 0**），对每个测点计算剂量率 $\dot{D}_i = S / d_i^{2}$，存入数组 `D[]`；
4. 遍历数组 `D[]`，找出**最大剂量率**及其对应的**下标**（下标从 0 开始，用于标识"第几个测点"）；
5. 输出最大值（保留 4 位小数）与下标（整数）。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各测点到源的距离（m），用空格分隔。

**输出**：一行，格式为 `Dmax = 最大值, index = 下标`，最大值保留 4 位小数，下标为整数。

## 四、样例

**样例 1**

输入：
```
5
2.0 3.0 1.5 4.0 5.0
```
输出：
```
Dmax = 53.3333, index = 2
```

**样例 2**

输入：
```
4
6.0 4.0 8.0 10.0
```
输出：
```
Dmax = 7.5000, index = 1
```

**样例 3**

输入：
```
3
1.0 2.0 4.0
```
输出：
```
Dmax = 120.0000, index = 0
```

## 五、提示

- 数组声明 `double d[50], D[50];`，下标从 0 开始，恰好 n 个数占 `[0, n-1]`；
- 读入和计算可合用一次循环：
  ```c
  for (i = 0; i < n; i++) {
      scanf("%lf", &d[i]);
      D[i] = S / (d[i] * d[i]);
  }
  ```
- **打擂台找最大值**：先假设第 0 个最大（`Dmax = D[0]; imax = 0;`），再从下标 1 开始逐个比较，若更大就更新；
- 距离越小剂量率越大，所以最大值必然出现在**距离最小**的测点——可以用这个物理直觉核对结果；
- 若有多个测点并列最大，取**先出现**的那个（打擂台用严格大于 `>` 就能保证这一点）。

**完成本练习后你将具备的能力**：定义与遍历一维数组、用数组同时保存"输入量"和"计算量"、用打擂台法找最大值并记录其位置——这些是实验 D7 中"测线热点定位模块"的地基。
