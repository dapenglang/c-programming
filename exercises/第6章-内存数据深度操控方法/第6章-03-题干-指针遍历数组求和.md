# 第 6 章 练习 03　指针遍历数组求和

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用、6.3 指针与数组）

**场景来源**：综合实验 C7《冰区船舶载荷统计与辨识系统》（水声学院）——本练习是该实验中"阻力序列汇总统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区载荷统计系统 C7 的输入是一段冰区航行试验记录：连续 8 个时刻的冰阻力采样值（单位 kN）。系统要给出这一段的**总阻力、平均阻力与峰值阻力**，并统计**超过阈值 15.0 kN 的采样个数**，作为辨识强载荷事件的基础。在第 5 章你已会用下标 `a[i]` 完成这些统计；本练习要求**全程用指针**完成同样的工作——让一个指针从数组首元素出发逐个"走"过去。这是实验 C7 数据处理模块的底层写法，也是理解"数组名就是地址"的关键一步。

## 二、任务要求

编写一个完整程序 `drag_stat.c`：

1. 读入 8 个阻力采样值，存入 `double` 数组；
2. 定义指针 `p` 指向数组首元素，**只用指针**（`p++` 前移、`*p` 取值，不得使用 `a[i]` 下标）遍历数组，求总阻力 `sum`；
3. 继续用指针遍历，求最大值 `max` 与超过 15.0 kN 的采样个数 `cnt`；
4. 按格式输出总阻力、平均阻力（保留 2 位小数）、峰值阻力（保留 2 位小数）与超阈值个数。

## 三、输入输出格式

**输入**：一行，8 个实数（kN），以空格分隔。

**输出**：两行。
第 1 行：`total = 值 kN mean = 值 kN`；
第 2 行：`max = 值 kN above = 个数`。

## 四、样例

**样例 1**

输入：
```
12.4 15.8 13.2 18.6 14.1 16.9 12.8 17.3
```
输出：
```
total = 121.10 kN mean = 15.14 kN
max = 18.60 kN above = 4
```

**样例 2**

输入：
```
10.0 20.0 30.0 40.0 12.0 22.0 32.0 42.0
```
输出：
```
total = 208.00 kN mean = 26.00 kN
max = 42.00 kN above = 6
```

## 五、提示

1. 让指针指向首元素：`double *p = a;`（数组名 `a` 本身就是首元素地址）；数组末元素的"下一位置"是 `a + 8`；
2. 标准扫尾写法：`for (p = a; p < a + 8; p++) { ... *p ... }`——`p` 每次自增 1，**跨过一个 `double` 元素（8 个字节）**，而不是一个字节；
3. 判断超阈值：`if (*p > 15.0) cnt++;`；
4. 内存的抽象示意（地址为示意值，`double` 占 8 字节）：

```
下标        0        1        2      ...      7
地址   0061FEF0 0061FEF8 0061FF00  ...  0061FF28
值        12.4     15.8     13.2    ...     17.3
            ^                                 ^
            p 起点                          p 终点(a+8, 只比较不访问)
```

**完成本练习后你将具备的能力**：理解"数组名 = 首元素地址"、用 `p++` 与 `*p` 完成无下标遍历、掌握 `p < a + n` 的扫尾条件——实验 C7 中所有序列统计模块的底层通用写法。
