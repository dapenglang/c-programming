## 二、预备知识：线性同余法为什么能产生"随机"数

### 1. 问题是怎么来的

蒙特卡洛模拟要反复"掷骰子"——比如决定一个光子是否被吸收，需要 0 到 1 之间的随机数。计算机本质是确定的机器：给它同样的输入和种子，它永远给出同样的输出。那怎么办？

答案是**伪随机数**：用一条精心设计的**确定性递推公式**，产生一串"看起来毫无规律、统计上却像真随机"的数。只要规律足够复杂、周期足够长，用起来和真随机数几乎没差别。最经典、最简单的递推公式就是**线性同余发生器（LCG）**。

### 2. 公式是怎么推出来的

线性同余递推式是：

$$
r_{n+1} = (a\,r_n + c) \bmod m
$$

三个参数的含义：

- $m$：**模数**，所有结果都被限制在 $0 \sim m-1$ 之间（因为取模的结果一定小于 $m$）；
- $a$：**乘数**，把上一个数放大；
- $c$：**增量**，加一点偏移，避免序列落入简单规律；
- $r_0$：**种子**，递推的起点，同一个种子必然产生同一串序列（这正是"可复现"的来源）。

为什么这样能产生看似随机的数？关键在**取模运算**：$(a r_n + c)$ 算出来是一个很大的数，除以 $m$ 取余数后，结果的"高低位信息"被彻底打乱，下一个数跳到哪里完全看不出规律。只要参数选得好（如本题 $a=1103$、$c=12345$、$m=32768$），序列就能均匀地扫过 $0 \sim m-1$ 的所有整数，周期长达 $m$。

"均匀"是伪随机数最重要的性质：把 $r_n / m$ 看成 $[0,1)$ 上的一个点，这些点应当**均匀分布**——落在任意等长小区间里的个数大致相同。均匀分布最直观的一个检验量就是**均值**：

$$
E[u] = \int_0^1 u \, du = \frac{1}{2}
$$

即理论均值应为 **0.5**。样本少时波动大，样本多时会逼近 0.5。

### 3. 用本例走一遍

取种子 $r_0 = 1$，$a = 1103$、$c = 12345$、$m = 32768$，手推前几个：

- $r_1 = (1103 \times 1 + 12345) \bmod 32768 = 13448$，$u_1 = 13448/32768 \approx 0.4104$；
- $r_2 = (1103 \times 13448 + 12345) \bmod 32768 = 14920489 \bmod 32768$。$14920489 = 32768 \times 455 + 100x$，算得余数 $11593$，$u_2 = 11593/32768 \approx 0.3538$；
- 继续推下去，$u$ 值在 $[0,1)$ 内看似杂乱地跳动。

取前 10 个数的均值：$\bar{u} = 0.4872$；取前 1000 个：$\bar{u} = 0.4970$。可见样本越多，均值越贴近理论值 0.5——这就是伪随机数"统计上像真的"的第一个证据。

### 4. 编程时怎么用它

三件事：**读参数**（$a,c,m$ 常量 + 种子）、**循环递推并累加**（`r = (A*r + C) % M; u = (double)r / M; sum += u;`）、**算均值输出**（`sum / n`）。

有两个必须小心的坑：一是**归一化必须先转 double**，否则 `r / m` 是整数除法，结果恒为 0（$r < m$ 时商为 0）；二是**乘法可能溢出**，$a \times r$ 最大约 $1103 \times 32767 \approx 3.6\times 10^7$，虽在 32 位 `int` 范围内，但保险起见用 `long` 更稳妥。

> **这个思想在综合实验中反复出现**：D6 光子抽样、C5 声呐检测概率、B3 蒙特卡洛面积估算，全部依赖"自己写一个可复现的伪随机数发生器"。**综合实验明确要求不用 `rand()`**，因为你必须控制种子、复现整条序列——学会这一条递推式，四处可用。

## 三、解题思路

1. **确定参数**：$a$、$c$、$m$ 是算法常数，用 `const long`；种子 `r = 1` 是变量（初值），用 `long`；
2. **确定变量**：循环次数 `n`（int）、循环变量 `i`（int）、累加和 `sum`（double）、当前归一棵 `u`（double）；
3. **读入 N**：`scanf("%d", &n);`；
4. **循环生成**：`for (i = 0; i < n; i++) { r = (A*r + C) % M; u = (double)r / M; sum += u; }`；
5. **输出均值**：`printf("mean = %.4f\n", sum / n);`，保留 4 位小数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 线性同余发生器参数：结果范围 0 ~ M-1，序列周期为 M */
    const long A = 1103;       /* 乘数 */
    const long C = 12345;      /* 增量 */
    const long M = 32768;      /* 模数 */

    long r = 1;                /* 当前随机数（种子为 1） */
    int  n, i;                 /* 要生成的个数、循环变量 */
    double sum = 0.0;          /* 累加和 */
    double u;                  /* 归一化到 [0,1) 的随机数 */

    scanf("%d", &n);           /* 读入随机数个数 */

    for (i = 0; i < n; i++) {
        r = (A * r + C) % M;       /* 递推：产生下一个整数随机数 */
        u = (double)r / M;         /* 归一化：必须先转 double 再除 */
        sum += u;                  /* 累加，为求均值做准备 */
    }

    printf("mean = %.4f\n", sum / n);   /* 均匀分布理论均值应接近 0.5 */

    return 0;
}
```

| 输入 N | 手算/推算过程 | 程序输出 |
|---|---|---|
| 1 | 只有 $u_1 = 13448/32768 = 0.4104$，均值即 0.4104 | `mean = 0.4104` ✓ |
| 10 | 前 10 个数均值 0.4872（样本少，偏离 0.5 明显） | `mean = 0.4872` ✓ |
| 50 | 前 50 个数均值 0.4963 | `mean = 0.4963` ✓ |
| 1000 | 前 1000 个数均值 0.4970（已很接近 0.5） | `mean = 0.4970` ✓ |
| 10000 | 前 10000 个数均值 0.4995（几乎正中 0.5） | `mean = 0.4995` ✓ |

从 1 个到 10000 个，均值从 0.4104 逐步收敛到 0.5，直观展示了"样本越多、统计量越准"——这正是蒙特卡洛方法的核心信念。

## 六、常见错误与讲解

**错误 1：整数除法导致均值恒为 0**

```c
u = r / M;                /* 错：r < M，整数除法商为 0，u 恒等于 0 */
u = (double)r / M;        /* 对：先把 r 转成 double，再做浮点除法 */
```

这是本题最隐蔽的错误：程序能跑、不报错，但输出恒为 0.0000。**规则：只要希望得到小数结果，参与除法的至少一个操作数要转成浮点。**

**错误 2：取模写成整除或漏掉取模**

```c
r = A * r + C;            /* 错：漏掉 % M，r 迅速增长、溢出错乱 */
r = (A * r + C) / M;      /* 错：整除而非取余，序列不再落在 0~M-1 */
r = (A * r + C) % M;      /* 对：取余把结果限制在范围内 */
```

取模是 LCG 的灵魂——它保证每个新数都落在 $0 \sim m-1$ 内，并产生"打乱"效果。漏掉它，序列立刻失去随机外观。

**错误 3：分母用错或均值算成 sum**

```c
printf("mean = %.4f\n", sum);      /* 错：输出的是总和，不是均值 */
printf("mean = %.4f\n", sum / n);  /* 对：总和除以个数 */
```

**错误 4：使用了 `rand()`**

```c
u = (double)rand() / RAND_MAX;     /* 本题不允许 */
```

综合实验要求随机序列**可复现**（同一种子结果唯一），而 `rand()` 的结果取决于库内部状态、跨平台不一致。必须手写 LCG，才能保证模拟可重复、可对照。**纪律：核学院所有蒙特卡洛题一律手写线性同余递推式。**

## 七、与综合实验的衔接

- 实验 **D6（蒙特卡洛射线屏蔽透射率计算）**中，本练习的 LCG 是光子抽样的"骰子"：每生成一个 $u$，就用来决定"光子这一次走了多长自由程"或"是否发生作用"。LCG 参数的选取直接决定模拟质量——参数差会产生周期性伪影，让模拟结果系统性偏离理论值 $e^{-\mu x}$；
- 与前面两个练习衔接：练习 25 算理论透射率、练习 23 打印理论关系表，本练习提供"掷骰子"的工具。**理论（$e^{-\mu x}$）+ 随机（LCG）合起来，就是完整的蒙特卡洛模拟**——这也是 D6 综合实验的骨架。到了第 5 章，随机序列会被存进数组以便重复使用。
