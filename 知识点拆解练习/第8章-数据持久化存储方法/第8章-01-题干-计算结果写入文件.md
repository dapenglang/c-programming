# 第 8 章 练习 01　计算结果写入文件

**对应章节**：8 数据持久化存储方法（8.1 文件概述、8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷辨识结果落盘保存"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区船舶载荷辨识系统每完成一次试验，都要算出一串"测点编号—冰载荷"的结果数据。如果这些结果只留在程序的变量里，程序一结束就全部消失，第二天根本无法复核。工程上必须把结果**写进文件**保存下来，形成一份可以长期存放、随时翻看的"结果台账"——这正是实验 C7 中"辨识结果导出"环节要做的事。本练习用一个最简单的程序，把一组编号与载荷值按固定格式写入文本文件，先把这个"程序到文件"的通路打通。

## 二、任务要求

编写一个完整程序 `save_result.c`：

1. 从键盘读入一个整数 $n$，表示要保存的结果条数（题目保证 $1 \le n \le 100$）；
2. 随后读入 $n$ 组数据，每组一条记录，含两个字段：测点编号（整数）、冰载荷值（实数，单位 kN）；
3. 把每条记录按固定格式写入文本文件 `load_results.txt`，**每行一条记录**，格式为 `编号 载荷`，两个字段之间用**一个空格**分隔，载荷保留 **2 位小数**；
4. 写入完成后在屏幕上输出一行提示，并报告写入了多少条记录。

**数据文件格式约定**

- 文件名：`load_results.txt`（程序运行目录下）
- 文件为纯文本文件，每行一条记录
- 每行两个字段：第 1 个是整数编号，第 2 个是实数载荷值
- 两个字段之间用一个空格分隔，行末有换行
- 样例数据行：`1 12.50`

## 三、输入输出格式

**输入**：第一行一个整数 $n$；随后 $n$ 行，每行两个数据：编号（整数）、载荷（实数），以空格分隔。

**输出**：不向屏幕输出结果数据，只输出一行提示 `写入完成，共 X 条记录`；结果数据写入文件 `load_results.txt`。

## 四、样例

**样例 1**

输入：
```
3
1 12.5
2 18.3
3 9.75
```
程序运行后，`load_results.txt` 的内容为：
```
1 12.50
2 18.30
3 9.75
```
屏幕输出：
```
写入完成，共 3 条记录
```

**样例 2**

输入：
```
2
10 7.5
11 6.25
```
程序运行后，`load_results.txt` 的内容为：
```
10 7.50
11 6.25
```
屏幕输出：
```
写入完成，共 2 条记录
```

## 五、提示

- 保存数据的文件要用文件指针 `FILE *fp` 来表示，打开函数写成 `fp = fopen("load_results.txt", "w")`；
- 模式 `"w"` 表示"写文本文件"，如果文件不存在会被新建，如果已存在会**先清空再写**；
- `fopen` 有可能失败（例如磁盘写保护），返回 `NULL`，所以打开后要判断 `if (fp == NULL)`；
- 写入用 `fprintf(fp, "%d %.2f\n", id, value);`，它的用法和 `printf` 完全一样，只是多了一个文件指针参数放在最前面；
- 全部写完后必须用 `fclose(fp);` 关闭文件，否则数据可能没有真正落盘。

**完成本练习后你将具备的能力**：定义文件指针、用 `fopen` 以写模式打开文件、检查打开是否成功、用 `fprintf` 把格式化数据写入文本文件、用 `fclose` 关闭文件——这是实验 C7 所有"结果导出"模块的地基。
