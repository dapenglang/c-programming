# 第 3 章 练习 23　迷宫中可用通路计数

**所属综合实验**：B4（B4-基于深度优先搜索的迷宫求解系统）

**对应章节**：3 程序流程控制（3.1 关系与逻辑运算、3.2 选择结构、3.3 循环结构、3.4 标准输入输出）

**场景来源**：综合实验 B4《基于深度优先搜索的迷宫求解系统》（人工智能学院）——本练习是该实验中"地形统计分析"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

迷宫求解系统拿到一张字符网格后，第一件事往往是"看看这张图长什么样"：多少格子是通路（可走）、多少是墙（不可走）、通路占多大比例。这些统计量能帮助判断迷宫是否"通得过去"，也用来校验读入的数据有没有出错。

迷宫用字符表示：`'.'` 表示通路，`'#'` 表示墙。B4 系统在开始搜索前，先做一次地形统计，作为程序的"体检报告"。

## 二、任务要求

编写一个完整程序 `maze_count.c`：

1. 从键盘读入行数 `r`（$1 \le r \le 6$）和列数 `c`（$1 \le c \le 6$）；
2. 接着读入 $r$ 行字符串（每行 `c` 个字符，只含 `.` 或 `#`），表示迷宫网格；
3. 用双重循环遍历所有格子：
   - 统计通路 `.` 的个数 `road`；
   - 统计墙 `#` 的个数 `wall`；
4. 输出统计结果，以及通路占全部格子的比例（保留 **2 位小数**）。

## 三、输入输出格式

**输入**：
第一行，两个整数 r 和 c，用空格分隔；
接下来 r 行，每行一个长度为 c 的字符串（`.` 或 `#`）。

**输出**：一行，按格式 `road = 通路数, wall = 墙数, ratio = 比例` 输出，比例保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
2 3
.#.
###
```
输出：
```
road = 2, wall = 4, ratio = 0.33
```

**样例 2**

输入：
```
3 3
...
```
输出：
```
road = 9, wall = 0, ratio = 1.00
```

## 五、提示

统计的流程用双重循环：

```
for 每一行 i:
    for 每一列 j:
        读入或查看 grid[i][j]
        若为 '.' 则 road 加 1
        否则若为 '#' 则 wall 加 1
```

比例计算：

$$
ratio = \frac{road}{r \times c}
$$

其中 $r \times c$ 是总格子数。**比例一定是实数除法**，分子或分母要有一个是 `double`，否则整数除法会得到 0。建议写成 `road / (double)(r * c)`，然后 `%.2f` 输出。

读入每行字符串可用 `scanf("%s", line)`（第 5 章会讲字符数组）。本题为让你专注循环与判断，允许把每行读进一个字符数组再逐字符查看。

**完成本练习后你将具备的能力**：写双重 for 循环遍历二维网格、在循环里用 if 做分类计数、用实数除法算比例——这些是实验 B4 中"地形统计模块"的地基。
