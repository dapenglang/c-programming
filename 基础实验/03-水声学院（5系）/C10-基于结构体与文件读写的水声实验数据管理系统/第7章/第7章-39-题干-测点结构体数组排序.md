# 第 7 章 练习 39　测点结构体数组排序

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：7 结构体数组（7.2 结构体数组、7.3 结构体作函数参数——整条记录交换）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"按水深排序"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

拿到一批测点记录后，常想知道"从浅到深测点是怎么分布的"——这就需要**按水深排序**。排序时要注意：交换的是**整条记录**（编号、水深、时刻一起换），只换水深字段的话，编号和水深就对不上号了。

结构体赋值（`a = b;`）会自动复制全部成员，这让"整条交换"比零散变量时代省事得多。综合实验 C10 的按深度排序模块（M7）就是这样做的。本题用冒泡排序实现它。

## 二、任务要求

编写一个完整程序 `rec_sort.c`：

1. 定义与练习 38 相同的测点结构体 `struct Rec`（编号 `id[16]`、水深 `depth`、时刻 `tm[8]`）；
2. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 50**）与 `n` 条记录；
3. 按**水深从小到大**（升序）用冒泡排序，交换时**整条记录一起换**（用结构体赋值）；
4. 输出排序后的全部记录，格式与练习 38 相同。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后 `n` 行，每行 `编号 水深 时刻`。

**输出**：排序后逐行输出，格式：

```
S02          12.50   10:00
```

即编号左对齐占 9 列，水深右对齐占 9 列保留 2 位小数，时刻右对齐占 6 列。

## 四、样例

**样例 1**

输入：
```
3
S01 22.0 08:30
S02 12.5 10:00
S03 15.5 09:15
```
输出：
```
S02          12.50   10:00
S03          15.50   09:15
S01          22.00   08:30
```

**样例 2**

输入：
```
4
B3 8.0 11:00
A1 8.0 09:00
C2 5.5 10:30
D4 9.9 08:45
```
输出：
```
C2           5.50   10:30
B3           8.00   11:00
A1           8.00   09:00
D4           9.90   08:45
```

## 五、提示

- 冒泡排序骨架（第 5 章已学）：外层 `n-1` 轮，内层相邻两两比较，比较条件换成 `r[j].depth > r[j+1].depth`；
- 整条交换一行搞定：
  ```c
  struct Rec t = r[j];
  r[j] = r[j + 1];
  r[j + 1] = t;
  ```
  结构体之间的赋值会**逐成员复制**，不用再一个个 `strcpy`/赋值；
- 样例 2 中 `B3` 与 `A1` 水深相同（8.0）：冒泡排序在相等时不交换（比较条件用 `>` 不用 `>=`），所以保持录入顺序——`B3` 在 `A1` 前；
- 想一想：如果比较条件写成 `>=`，相等元素也会被反复交换，排序变慢且不再稳定。

**完成本练习后你将具备的能力**：对结构体数组按键值排序、用结构体赋值整条交换记录——这是实验 C10 中"按深度/时间排序模块"（M7）的直接实现。
