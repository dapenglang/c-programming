## 二、预备知识：文件读取统计的基本原理（零基础阅读）

### 1. 问题是怎么来的

上一次练习学会了"读文件、算一步、写回去"。但统计类问题需要**把文件从头到尾走一遍**，边走边记：有多少条、加起来多少、最大的那条是谁。

这类问题的特点是：**不需要把所有数据都存下来**，只需要几个"统计量"随读随更新。这既省内存，也符合工程上"数据太大装不下"的实际情况。当然，如果后面还要反复用到数据（如最小二乘拟合），就得存进数组；本题只统计，随读随算即可。

### 2. 统计的四件事

在读取循环里，每读到一条记录 `(name, s)` 就更新四个量：

- **计数器 n**：初值 0，每读一条 `n++`；
- **累加器 sum**：初值 0.0，每读一条 `sum += s`；
- **最大值 maxv 及其点名 maxname**：用打擂台法；
- **最小值 minv 及其点名 minname**：同样用打擂台法。

平均沉降量在循环结束后算：

$$
\bar{s} = \frac{\text{sum}}{n}
$$

平均速率：

$$
v = \frac{\bar{s}}{\Delta t}
$$

### 3. 打擂台法保存"点号"——为什么需要 strcpy

前几章的打擂台只记"最大的数是多少"。本题还要记"最大的那个点是哪个"，也就是要把它的**点名（字符串）**保存下来。字符串不能像数字那样直接赋值：

```c
maxname = name;          /* 错：数组名是地址常量，不能被赋值 */
strcpy(maxname, name);   /* 对：把 name 里的字符逐个复制到 maxname */
```

`strcpy(目标, 源)` 是字符串复制函数，需要 `#include <string.h>`。

### 4. 用本例走一遍

文件内容：

```
145
JC01 12.35
JC02 9.80
JC03 15.20
```

循环三次：

| 第几次 | name | s | n | sum | maxv/maxname | minv/minname |
|---|---|---|---|---|---|---|
| 1 | JC01 | 12.35 | 1 | 12.35 | 12.35 / JC01 | 12.35 / JC01 |
| 2 | JC02 | 9.80 | 2 | 22.15 | 12.35 / JC01 | 9.80 / JC02 |
| 3 | JC03 | 15.20 | 3 | 37.35 | 15.20 / JC03 | 9.80 / JC02 |

循环结束：$n=3$，平均 $= 37.35/3 = 12.45$，最大 JC03（15.20），最小 JC02（9.80）。

平均速率 $= 12.45 / 145 = 0.085862\ldots \approx 0.086$（保留 3 位小数）。

> 注意：这里保留 3 位小数得到 0.086；题目输出格式要求 3 位小数，故样例输出写作 `rate=0.086`。请以代码实际 `%.3f` 输出为准。

### 5. 编程时怎么用它

要点：

1. **第一个记录要特殊处理**：打擂台的"设擂主"可以放在循环里用 `if (n == 1)` 判断，或读入第一条后初始化；
2. **字符串复制**用 `strcpy`，目标数组要够大；
3. **循环条件**仍用 `fscanf(...) == 2`（读到点号和沉降量两个项）。

## 三、解题思路

1. **打开文件**，检查是否成功；
2. **读第一行天数** $\Delta t$；
3. **循环读记录**：每条 `n++`、`sum += s`，并用打擂台更新最大/最小及对应点名；
4. **循环后**算平均与速率，输出五行。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>         /* strcpy */

int main(void)
{
    FILE *fin;
    int dt;                 /* 观测天数 */
    char name[16];          /* 当前点号 */
    char maxname[16], minname[16];   /* 最值对应点号 */
    double s;               /* 当前沉降量 */
    double sum = 0.0, maxv = 0.0, minv = 0.0;
    int n = 0;

    fin = fopen("settle_in.txt", "r");
    if (fin == NULL) {
        printf("open failed\n");
        return 1;
    }

    fscanf(fin, "%d", &dt);     /* 第一行：天数 */

    /* 循环读入每条记录并统计 */
    while (fscanf(fin, "%s %lf", name, &s) == 2) {
        n++;
        sum += s;

        if (n == 1) {                       /* 第一条：初始化最值 */
            maxv = minv = s;
            strcpy(maxname, name);
            strcpy(minname, name);
        } else {                            /* 打擂台 */
            if (s > maxv) { maxv = s; strcpy(maxname, name); }
            if (s < minv) { minv = s; strcpy(minname, name); }
        }
    }

    fclose(fin);

    /* 输出统计结果 */
    printf("n=%d\n", n);
    printf("avg=%.3f\n", sum / n);
    printf("max=%s:%.3f\n", maxname, maxv);
    printf("min=%s:%.3f\n", minname, minv);
    printf("rate=%.3f\n", sum / n / dt);

    return 0;
}
```

## 五、运行验证

**样例 1**：文件头 `145`，三条记录 12.35、9.80、15.20。

| 统计量 | 手算 | 程序输出 |
|---|---|---|
| 点数 | 3 | `n=3` ✓ |
| 平均 | 37.35/3 = 12.45 | `avg=12.450` ✓ |
| 最大 | JC03, 15.20 | `max=JC03:15.200` ✓ |
| 最小 | JC02, 9.80 | `min=JC02:9.800` ✓ |
| 速率 | 12.45/145 = 0.08586… | `rate=0.086` ✓ |

**样例 2**：天数 120，记录 5.00、7.00。$n=2$，平均 6.00，最大 JC12=7.00，最小 JC11=5.00，速率 $6/120=0.050$ → `rate=0.050`。

## 六、常见错误与讲解

**错误 1：用 `=` 复制字符串**

```c
strcpy(maxname, name);   /* 对 */
maxname = name;          /* 错：数组不能整体赋值 */
```

字符串复制一律用 `strcpy`（或 `strncpy`），并确保目标数组放得下。

**错误 2：打擂台没初始化**

```c
double maxv;             /* 未初始化，与 s 比较时结果是随机的 */
```

第一条记录要专门用来初始化最值，或用很大的负数/很小的正数兜底。

**错误 3：`fscanf` 读字符串时加了 `&`**

```c
fscanf(fin, "%s %lf", &name, &s);    /* 错：name 是数组，不加 & */
fscanf(fin, "%s %lf", name, &s);     /* 对 */
```

**错误 4：循环结束后又多做一次除法/统计**

```c
while (fscanf(...) == 2) { ... }
sum / n;                 /* 若 n 为 0（文件为空），这里除零 */
```

稳健做法：统计前判断 `n > 0`。本题数据非空，但也应养成习惯。
