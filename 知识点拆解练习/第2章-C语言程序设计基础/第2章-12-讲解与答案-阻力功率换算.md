## 二、预备知识：功率的概念与单位自洽（零基础阅读）

### 1. 问题是怎么来的

船在冰区前进，冰把船往后推（阻力 $F$），船的螺旋桨必须把船往前推。要让船保持速度 $v$ 前进，推进系统就在不停地做"克服阻力"的功。**每秒钟做的功**，就是功率。阻力越大、速度越快，每秒要克服的位移越大，功率自然越大——这便是"阻力功率"这个物理量的来历。

### 2. 公式是怎么来的

功率的定义是单位时间内所做的功。力 $F$ 沿运动方向作用，在时间 $t$ 内物体前进 $s = v t$，做的功为 $W = F s = F v t$；再除以时间 $t$：

$$
P = \frac{W}{t} = \frac{F v t}{t} = F v
$$

这就是 $P = F v$：**功率等于力乘以速度**。它不需要任何额外的推导技巧，是把"功=力×位移"和"位移=速度×时间"两式合并、消掉时间后得到的。

### 3. 单位为什么"不用换算"

把单位和数字分开看：$F$ 的单位是 $\mathrm{kN}$，$v$ 的单位是 $\mathrm{m/s}$，相乘后单位是 $\mathrm{kN \cdot m/s}$。而

$$
1\ \mathrm{kN \cdot m/s} = 1000\ \mathrm{N} \cdot \frac{\mathrm{m}}{\mathrm{s}} = 1000\ \mathrm{W} = 1\ \mathrm{kW}
$$

也就是说，只要输入用 kN、速度用 m/s，输出恰好是 kW，**数字上直接相乘即可**。这种"单位自己凑成结果单位"的现象，叫作**量纲自洽**。理解它，就能避免"多乘或少乘 1000"这类最常见的工程计算错误。

### 4. 编程时怎么用它

程序里只需三个 `double` 变量：`F`、`v`、`P`。读入前两个、乘出第三个、打印出来，全流程三行代码，是"顺序结构一个完整计算流程"的最简样板。

> **这个关系在综合实验中反复出现**：只要某个实验算出了"力"，再用航速/流速/推进速度乘一下，就能得到功率。C7 冰阻力算完之后，本练习就是它顺理成章的下一步。

## 三、解题思路

1. **确定变量**：冰阻力 `F`（kN）、航速 `v`（m/s）、功率 `P`（kW），三者都是实数，统一用 `double`；
2. **读入数据**：用一条 `scanf` 读两个数，格式串写 `"%lf %lf"`，两个变量前都要加 `&`；
3. **套公式**：`P = F * v;`——注意是乘法，不是除法；
4. **输出**：题目要求 3 位小数，格式串用 `"P = %.3f kW\n"`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 单位自洽：阻力用 kN、速度用 m/s，
       乘积 kN·m/s 恰好等于 kW，无需额外换算 */
    double F;   /* 冰阻力，单位 kN */
    double v;   /* 航速，单位 m/s */
    double P;   /* 所需推进功率，单位 kW */

    /* 一次读入阻力与航速 */
    scanf("%lf %lf", &F, &v);

    /* 功率 = 力 × 速度 */
    P = F * v;

    /* 输出，保留 3 位小数 */
    printf("P = %.3f kW\n", P);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 334.5 1.8 | 334.5 × 1.8 = 602.1 kW | `P = 602.100 kW` ✓ |
| 785 1.4 | 785 × 1.4 = 1099.0 kW | `P = 1099.000 kW` ✓ |
| 500 2 | 500 × 2 = 1000.0 kW | `P = 1000.000 kW` ✓ |
| 200 0 | 200 × 0 = 0（航速为零则功率为零） | `P = 0.000 kW` ✓ |

四个例子的结果都与手算一致，说明公式与单位处理正确。

## 六、常见错误与讲解

**错误 1：用 `int` 存物理量（最典型）**

```c
int F, v;                 /* 错：阻力 334.5 会被截断成 334 */
scanf("%d %d", &F, &v);
```

后果：`334.5` 读入后变成 `334`，`1.8` 变成 `1`，功率全错。**本章纪律：凡物理上的实数量（力、速度、功率……）一律用 `double`，读入用 `%lf`。**

**错误 2：忘记取地址符**

```c
scanf("%lf %lf", F, v);    /* 错：程序崩溃或读不进数据 */
scanf("%lf %lf", &F, &v);  /* 对：每个待读变量前都要加 & */
```

**错误 3：格式符用错**

```c
scanf("%lf", &F);          /* 对：double 的输入格式符是 %lf */
printf("P = %d\n", P);     /* 错：double 用 %d 输出得到乱码 */
printf("P = %.3f\n", P);   /* 对：%.3f 保留 3 位小数 */
```

**错误 4：单位多算或少算**

```c
P = F * v * 1000;          /* 错：误以为要换算成瓦，结果大了 1000 倍 */
P = F * v;                 /* 对：kN·m/s 本就是 kW */
```

动手前先默算一遍样例 1（结果应为 602.100），再上机验证，就能及时发现单位错误。

## 七、与综合实验的衔接

- 实验 **C7（冰阻力与碰撞事件辨识）**中，"由辨识出的冰阻力折算推进功率"就是本练习的直接放大：真实工况里阻力由数据反演得到，可能同时给出多个速度工况；学到第 3 章（循环）后可以批量计算多个工况，学到第 4 章（函数）后可以把换算封装成一个函数反复调用；
- 同样的"力 × 速度 = 功率"关系，也出现在 A1 风荷载（风压 × 面积得风力）等实验里。**公式不变，变的是单位和场景**——本练习让你先把"量纲自洽"这件事彻底弄明白，为后续所有带物理量的程序设计打底。
