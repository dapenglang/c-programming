# 第 4 章 练习 08　递归求汉诺塔移动次数

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 B4《基于深度优先搜索的迷宫求解系统》（人工智能学院）——本练习是该实验中"递归分解与递推关系"环节的实现（对应 4.3 递归调用）。

**建议用时**：25 分钟

## 一、应用场景

汉诺塔是理解"递归分解"的经典问题：三根柱子 A、B、C，A 上有从小到大叠放的 $n$ 个盘子，要求每次移动一个盘子、且大盘不能压在小盘上，把它们全部移到 C。最优策略是先把上面 $n-1$ 个搬到 B，把最大的盘子搬到 C，再把那 $n-1$ 个从 B 搬到 C。按这个思路可以推出移动次数的递推关系，再用递归函数求出来。本练习就来实现它。

## 二、任务要求

编写一个完整程序 `hanoi_moves.c`：

1. 必须定义**递归函数**，**函数原型为**
   ```c
   long long hanoi_moves(int n);
   ```
   返回把 $n$ 个盘子从一根柱子搬到另一根柱子所需的最少移动次数；
2. 函数必须同时具备两部分：
   - **基线条件**：当 `n == 1` 时返回 `1`（一个盘子只需搬一次）；
   - **递推关系**：否则返回 `2 * hanoi_moves(n - 1) + 1`；
3. 主函数读入整数 `n`（题目保证 $1 \le n \le 60$），调用 `hanoi_moves`；
4. 按格式输出结果（用 `long long` 与 `%lld`，因为 $2^{60}$ 远超 `int`）。

## 三、输入输出格式

**输入**：一行，一个整数 n（$1 \le n \le 60$）。

**输出**：一行，按格式 `moves(n) = 结果` 输出，例如输入 3 时输出 `moves(3) = 7`。

## 四、样例

**样例 1**

输入：
```
3
```
输出：
```
moves(3) = 7
```

**样例 2**

输入：
```
10
```
输出：
```
moves(10) = 1023
```

## 五、提示

设 $M(n)$ 为搬 $n$ 个盘子的最少次数。按"先搬上面 $n-1$ 个 → 搬最大盘 → 再搬那 $n-1$ 个"三步分解：

$$
M(n) = M(n-1) + 1 + M(n-1) = 2M(n-1) + 1,\qquad M(1) = 1
$$

这个递推还能解出通式 $M(n) = 2^n - 1$，可以用样例 2 校验（$2^{10}-1=1023$）。递归写法与递推关系**一一对应**：`2 * hanoi_moves(n-1) + 1`。

**完成本练习后你将具备的能力**：把一个复杂过程按"分解成同类子问题"的思路写成递归、从问题分析中推出递推关系、用 `long long` 处理指数增长的数——这是实验 B4 中把搜索过程结构化求解的直接训练。
