# 第 8 章 练习 08　文件定位读取记录

**对应章节**：8 数据持久化存储方法（8.4 文件的读写——`fread`、8.5 文件定位——`fseek`/`ftell`/`rewind`）

**场景来源**：综合实验 C9《冰面压力场热点分析系统》（水声学院）——本练习是该实验中"按记录号直接定位读取测点数据"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰面压力场系统把全部测点记录按固定长度写进二进制文件 `pressure.bin`：每条记录都由"测点号 + 压力值"组成。查看某一条记录的数值时，如果从第一条开始一条条读过去，记录一多就很慢。由于每条记录**长度完全相同**，我们其实可以直接"跳到"第 $k$ 条记录所在的位置，只读那一条——这就是文件定位 `fseek` 的用途。本练习实现"输入记录号、直接定位读取"的功能。

## 二、任务要求

编写一个完整程序 `seek_record.c`：

1. 以二进制读模式打开文件 `pressure.bin`，并检查是否成功；
2. 用 `fseek` 把文件位置指针挪到末尾，再用 `ftell` 求出文件总字节数，据此算出记录总数（每条记录占 `sizeof(struct Rec)` 字节）；
3. 从键盘读入一个记录号 $k$（$1 \le k \le$ 记录总数）；用 `fseek` 定位到第 $k$ 条记录，用 `fread` 只读这一条；
4. 输出文件总记录数、单条记录字节数、文件总字节数，以及第 $k$ 条记录的测点号与压力值；关闭文件。

**数据文件格式约定**

- 文件名：`pressure.bin`（由前处理程序按固定长度写入的二进制文件）
- 每条记录对应如下结构体，在内存与文件中都占 `sizeof(struct Rec)` 字节：
  ```c
  struct Rec { int id; double p; };
  ```
- 全部记录首尾相接、无分隔符，可按下标 $0 \sim (n-1)$ 随机访问

**逻辑内容如下表（并非文本，仅示意）：

| 记录序号 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 测点号 id | 1001 | 1002 | 1003 | 1004 |
| 压力值 p (kPa) | 12.50 | 18.30 | 9.75 | 21.00 |

## 三、输入输出格式

**输入**：一行，一个整数 $k$（记录号，从 1 开始计数）。

**输出**：屏幕输出两行：
```
文件共 X 条记录，每块 X 字节，总大小 X 字节
第 X 条记录：编号 = X, 压力 = X kPa
```
其中压力值保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
2
```
输出：
```
文件共 4 条记录，每块 16 字节，总大小 64 字节
第 2 条记录：编号 = 1002, 压力 = 18.30 kPa
```

**样例 2**

输入：
```
4
```
输出：
```
文件共 4 条记录，每块 16 字节，总大小 64 字节
第 4 条记录：编号 = 1004, 压力 = 21.00 kPa
```

## 五、提示

- 记录结构体定义为 `struct Rec { int id; double p; };`，在常见平台上 `sizeof(struct Rec)` 为 16 字节（`int` 4 字节 + 对齐填充 4 字节 + `double` 8 字节），程序中一律用 `sizeof(struct Rec)` 表示，不要手写 16；
- 求文件总大小用 `fseek(fp, 0, SEEK_END);` 把指针移到末尾，再 `size = ftell(fp);`；
- 记录总数 `count = size / sizeof(struct Rec);`
- 定位第 $k$ 条（下标从 0 起是 $k-1$）：`fseek(fp, (long)(k - 1) * sizeof(struct Rec), SEEK_SET);`，其中 `SEEK_SET` 表示"从文件开头算起"；
- 定位后用 `fread(&r, sizeof(struct Rec), 1, fp);` 读回一条记录；
- 用 `fseek` 之前要保证 $k$ 在合法范围内（$1 \le k \le count$），否则会读到文件之外。

**完成本练习后你将具备的能力**：用 `fseek` 在文件中任意跳转、用 `ftell` 测量文件大小与位置、按"记录下标 × 记录长度"计算偏移量——这是实验 C9 中"随机访问固定长度记录"的关键技能，也是数据库"按主键定位"思想的雏形。
