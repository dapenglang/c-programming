# 第 2 章 练习 09　水下声波往返时间计算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 C1《基于拉格朗日插值的声速剖面计算系统》（水声学院）——本练习是该实验中"回声时间估算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

主动声呐发出一个声脉冲，碰到目标后反射回来被接收，这段"去—回"的时间叫**回声时间**。声波走过的总路程是往返两倍的目标距离，除以声速就得到时间：

$$
t = \frac{2h}{c}
$$

关键在声速 $c$：海水中的声速随深度变化，不能当成固定常数。假设该海域实测剖面只有两个点——0 m 处 1450 m/s、200 m 处 1500 m/s——那么要求 100 m 深目标处的回声时间，就得**先插值求该深度的声速，再代入回声时间公式**。实验 C1 的"回声时间估算"环节正是这个两步流程。

## 二、任务要求

编写一个完整程序 `echo_time.c`：

1. 用**常量**存放两个实测档：深度 0 m 声速 1450 m/s，深度 200 m 声速 1500 m/s；
2. 从键盘读入目标深度 `h`（单位：米，double 类型，**题目保证 0 ≤ h ≤ 200**，因此本程序不需要判断分支）；
3. 先用线性插值求出该深度的声速 `c`，再用 $t = 2h/c$ 计算回声时间；
4. 输出声速（保留 2 位小数）与回声时间（保留 6 位小数）。

## 三、输入输出格式

**输入**：一行，一个实数，表示目标深度 h（米）。

**输出**：两行，第一行按 `c = 结果 m/s` 输出声速（保留 2 位小数），第二行按 `t = 结果 s` 输出回声时间（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
100
```
输出：
```
c = 1475.00 m/s
t = 0.135593 s
```

**样例 2**

输入：
```
50
```
输出：
```
c = 1462.50 m/s
t = 0.068376 s
```

## 五、提示

分两步走。先插值求声速，再求往返时间：

$$
c = c_0 + \dfrac{(c_1 - c_0)\,(h - h_0)}{h_1 - h_0}, \qquad t = \frac{2h}{c}
$$

注意 $t$ 的分母是声速 $c$（约 1500），不是深度；算出来的时间是个很小的数，所以要保留 6 位小数才看得出差别。

**完成本练习后你将具备的能力**：把两个公式**串起来**用（一个的输出当另一个的输入）、在同一个程序里用不同精度输出不同物理量——这是实验 C1 中"插值结果再参与物理计算"的基本模式。
