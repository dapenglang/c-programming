# 第 5 章 练习 35　潮位数组排序

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：5 一维数组与排序（5.1 数组的定义与引用、5.2 数组的遍历、5.5 排序——冒泡排序、5.5 数组统计——极值）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"高低潮极值检测与潮差统计环节"的最小实现。

**建议用时**：40 分钟

## 一、应用场景

验潮站每小时记录一次潮位，一天下来得到一串数据。要回答"今天**最高潮位**多少、**最低潮位**多少、**潮差**（最高减最低）多大"，最直观的办法之一是把这串数**从大到小排个序**：排完之后，第 1 个就是最高潮位，最后 1 个就是最低潮位，两者一减就是潮差。

综合实验 C7 在做潮位趋势分析时，需要检测高低潮并统计潮差；排序是理解"极值检测"的另一条路径。本题用**冒泡排序**把潮位序列降序排列，输出排序结果与潮差。

## 二、任务要求

编写一个完整程序 `tide_sort.c`：

1. 从键盘读入观测个数 `n`（**题目保证 2 ≤ n ≤ 50**）；
2. 读入 `n` 个潮位值（double，单位 m），存入一维数组 `tide[50]`；
3. 用**冒泡排序**把数组按**从大到小（降序）**排列——要求写出双重循环，并在内层用"相邻元素比较 + 交换"；
4. 输出三部分：
   - 排序后的潮位序列（每个保留 2 位小数，空格分隔）；
   - 最高潮位 = 排序后第 1 个元素；
   - 最低潮位 = 排序后最后 1 个元素，并输出潮差 = 最高 − 最低（保留 2 位小数）；
5. **禁止**调用任何库函数排序（如 `qsort`），必须手写冒泡排序。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数（空格分隔）。

**输出**：

```
排序后：xx.xx xx.xx ... xx.xx
最高潮位 = xx.xx m
最低潮位 = xx.xx m
潮差 = xx.xx m
```

## 四、样例

**样例 1**

输入：
```
10
3.42 1.85 4.10 2.36 3.75 1.20 4.48 2.05 3.10 0.95
```
输出：
```
排序后：4.48 4.10 3.75 3.42 3.10 2.36 2.05 1.85 1.20 0.95
最高潮位 = 4.48 m
最低潮位 = 0.95 m
潮差 = 3.53 m
```

**样例 2**

输入：
```
3
2.00 2.00 1.50
```
输出：
```
排序后：2.00 2.00 1.50
最高潮位 = 2.00 m
最低潮位 = 1.50 m
潮差 = 0.50 m
```

（存在相等元素时排序结果仍正确——冒泡排序用"大于才交换"，相等元素不交换，顺序稳定。）

## 五、提示

- 冒泡排序（降序版）的骨架：
  ```c
  for (i = 0; i < n - 1; i++) {           /* 共 n-1 趟 */
      for (j = 0; j < n - 1 - i; j++) {   /* 每趟比到"未排好区"的倒数第二个 */
          if (tide[j] < tide[j + 1]) {    /* 前面小 → 交换，让大的往前冒 */
              tmp = tide[j];
              tide[j] = tide[j + 1];
              tide[j + 1] = tmp;
          }
      }
  }
  ```
- 降序和升序只差**一个比较方向**：升序是"前面大就交换"（`tide[j] > tide[j+1]`），降序反过来；
- 排完序，`tide[0]` 是最高潮位，`tide[n-1]` 是最低潮位，不需要再扫描；
- 交换必须借助**临时变量** `tmp` 三步完成，直接写 `tide[j] = tide[j+1]; tide[j+1] = tide[j];` 会把数据覆盖丢失；
- 想一想：第 1 趟结束后，最小值一定"沉"到了末尾吗？为什么内层循环上界是 `n - 1 - i` 而不是 `n - 1`？

**完成本练习后你将具备的能力**：手写冒泡排序完成降序排列、用排序结果直接定位极值——这是实验 C7 中"高低潮检测与潮差统计"环节的地基，也为实验 C8 的"路径按时间排序"打基础。
