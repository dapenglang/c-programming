## 二、预备知识：欧几里得算法的原理与递归实现（零基础阅读）

### 1. 问题来源

求两个正整数的最大公约数，古老的做法是"辗转相除"：用较大数除以较小数取余，再用较小数和这个余数继续相除，直到余数为零；此时最后一次的除数就是最大公约数。例如 $\gcd(48,36)$：

$$
48 \div 36 = 1 \text{ 余 } 12,\quad
36 \div 12 = 3 \text{ 余 } 0 \;\Rightarrow\; \gcd = 12
$$

### 2. 为什么 `gcd(a,b) = gcd(b, a mod b)` 成立

设 $r = a \bmod b$，即 $a = qb + r$（$q$ 是商）。

- 如果某个整数 $d$ 同时整除 $a$ 和 $b$，那么它也整除 $a - qb = r$，所以 $d$ 整除 $b$ 和 $r$；
- 反过来，若 $d$ 同时整除 $b$ 和 $r$，那么它也整除 $qb + r = a$，所以 $d$ 整除 $a$ 和 $b$。

**结论**：$(a,b)$ 的公因子集合与 $(b,r)$ 的公因子集合完全相同，因此它们的最大公约数也相同。于是求 $\gcd(a,b)$ 就等价于求 $\gcd(b, a \bmod b)$——问题形式没变，只是换成了一对更小的数。

### 3. 基线条件：为什么是 `b == 0`

当第二个数为 0 时，$\gcd(a,0)$ 就是 $a$（任何数都能整除 0，而 $a$ 是其中最大的）。所以基线写成 `if (b == 0) return a;`。每做一次递推，第二参数就换成更小的余数，**余数严格递减，最终必然变成 0**，因此递归一定会停。

### 4. 调用栈展开：用 $\gcd(48,36)$ 走一遍

```text
gcd(48, 36)  ── 48 % 36 = 12 ──▶ gcd(36, 12)     ── 挂起，等后面结果
  gcd(36, 12) ── 36 % 12 = 0  ──▶ gcd(12, 0)     ── 挂起
    gcd(12, 0)  命中基线，返回 12                  （最深处）
  gcd(36, 12) 收到 12，直接返回 12
gcd(48, 36) 收到 12，直接返回 12 ──▶ main
```

注意：本题的递归在"返回"阶段不做任何额外计算，只是把最深处的结果**原样传回**。这与阶乘（返回时要补一次乘法）不同，是因为欧几里得的递推关系里因子已经被"剔除"干净了。

### 5. 编程要点

- 递归关系里两个实参**交换位置**：`gcd(b, a % b)`，第一个是原来的除数，第二个是余数；
- `%` 只能用于整数，因此本函数的形参用 `int`；
- 题目限定正整数，免去符号处理。

## 三、解题思路

1. **定接口**：`int gcd(int a, int b)`；
2. **写原型**：放在 `main` 上方；
3. **写基线**：`if (b == 0) return a;`；
4. **写递推**：`return gcd(b, a % b);`；
5. **主流程**：读两个整数 → 调用 → 打印。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：返回 a 与 b 的最大公约数 */
int gcd(int a, int b);

int main(void)
{
    int a, b;
    scanf("%d %d", &a, &b);                 /* 读入两个正整数 */
    printf("gcd = %d\n", gcd(a, b));        /* 辗转相除求最大公约数 */
    return 0;
}

/* 递归函数：欧几里得（辗转相除）算法 */
int gcd(int a, int b)
{
    if (b == 0)                             /* 基线条件：余数为零 */
        return a;
    else                                    /* 递推关系：换成 除数 与 余数 */
        return gcd(b, a % b);
}
```

## 五、运行验证

以 $\gcd(48,36)$ 为例的中间结果：

| 调用 | 取余 | 下一步 |
|---|---|---|
| gcd(48, 36) | 48 % 36 = 12 | gcd(36, 12) |
| gcd(36, 12) | 36 % 12 = 0 | gcd(12, 0) |
| gcd(12, 0) | 命中基线 | 返回 12 |

多组输入的程序输出：

| 输入 a b | 手算过程 | 程序输出 |
|---|---|---|
| 48 36 | 48%36=12，36%12=0 → 12 | `gcd = 12` ✓ |
| 1071 462 | 1071%462=147，462%147=21，147%21=0 → 21 | `gcd = 21` ✓ |
| 100 75 | 100%75=25，75%25=0 → 25 | `gcd = 25` ✓ |
| 7 13 | 7%13=7，13%7=6，7%6=1，1%…=0 → 1 | `gcd = 1` ✓ |

## 六、常见错误与讲解

**错误 1：基线条件位置写错**

```c
if (a == 0) return b;              /* 不是不能改成这样，但要与递推配套；本题统一用 b == 0 */
if (b == 0) return a;              /* 对：与 gcd(b, a % b) 配套，余数为零时停 */
```

**错误 2：递推时参数顺序写反**

```c
return gcd(a % b, b);              /* 错：第二个参数没有变小，很快会陷入死循环或除零 */
return gcd(b, a % b);              /* 对：新的一对是"除数"和"余数" */
```

若第二参数没有朝更小的余数变化，递归就无法保证终止。

**错误 3：用浮点数做取余**

```c
double gcd(double a, double b) { return gcd(b, a % b); }   /* 错：% 不能用于 double，编译报错 */
int gcd(int a, int b)          { ... }                     /* 对：取余只用于整数 */
```

**错误 4：忘记 `return` 导致结果丢失**

```c
if (b == 0) a;                     /* 错：只是求了个值，没有返回 */
if (b == 0) return a;              /* 对 */
```
