# 第 3 章 练习 24　伪随机序列生成与均值检验

**所属综合实验**：D6（D6-基于蒙特卡洛模拟的射线屏蔽透射率计算系统）

**对应章节**：3 程序控制结构（3.1 顺序结构、3.3 循环结构——for 循环、3.5 关系与逻辑运算、3.6 数值方法初步——线性同余法）

**场景来源**：综合实验 D6《基于蒙特卡洛模拟的射线屏蔽透射率计算系统》（核学院）——本练习是该实验中"随机数发生器"环节的最小实现，为后续光子抽样做准备。

**建议用时**：30 分钟

## 一、应用场景

蒙特卡洛方法靠"掷骰子"来模拟物理过程：让每个光子随机地决定"走多远""是否被挡下"。计算机不会真的掷骰子，只能用**伪随机数发生器**造出一串"看起来随机"的数。

综合实验 D6 里，程序必须自己生成 0 到 1 之间的随机数，模拟光子在屏蔽板中走到哪里、是否发生作用。工程上最常用、也最简单的一种发生器叫**线性同余发生器（LCG）**：

$$
r_{n+1} = (a\,r_n + c) \bmod m
$$

选好常数 $a$、$c$、$m$，给定一个种子 $r_0$，就能递推出整串数。本题先用一个小规模例子把发生器跑通，并检查它产生的数**是否均匀**——均匀性用**均值**来粗验：若随机数均匀分布在 $[0,1)$，其均值应接近 $0.5$。

## 二、任务要求

编写一个完整程序 `lcg_test.c`：

1. 用**常量**定义线性同余参数：$a = 1103$、$c = 12345$、$m = 32768$，并用 `long` 型变量 `r` 存放当前随机数，初始种子 `r = 1`；
2. 用**循环**生成 `N` 个随机数（$N$ 由键盘读入，**题目保证 1 ≤ N ≤ 10000**）；
3. 每生成一个数，先按递推式更新 `r`，再把 `r` 归一化到 $[0,1)$：$u = r / m$，累加进总和 `sum`；
4. 循环结束后求平均值 `sum / N`，并按格式输出算子均值（保留 4 位小数）。

## 三、输入输出格式

**输入**：一行，一个整数 N，表示要生成的随机数个数。

**输出**：一行，按格式 `mean = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
10
```
输出：
```
mean = 0.4872
```

**样例 2**

输入：
```
1000
```
输出：
```
mean = 0.4970
```

## 五、提示

- 递推式在 C 里写成一行赋值：`r = (A * r + C) % M;`，注意乘法可能超出 `int` 范围，`r` 建议用 `long`，常量也用 `long` 或足够大的整型；
- 归一化：`u = (double)r / M;`——**必须先强制转换为 double**，否则整数相除结果恒为 0；
- 累加：`sum += u;`；
- 均值检验的道理：$u$ 均匀分布在 $[0,1)$ 时理论均值是 $0.5$。样本少（如 10 个）时波动大，样本多（如 1000 个）时会逼近 0.5——这就是蒙特卡洛法"样本越多越准"的直观体现；
- **不要用 `rand()`、`srand()`**，本练习必须手写线性同余递推式，因为综合实验要求随机序列可复现（给定种子结果唯一）。

**完成本练习后你将具备的能力**：用循环做定次数累加、理解取模运算如何把数限制在固定范围、体会"伪随机数的均匀性"如何用统计量检验——这些是实验 D6 中"随机数发生器"的地基。
