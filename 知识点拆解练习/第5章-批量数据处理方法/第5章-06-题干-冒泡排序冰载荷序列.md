# 第 5 章 练习 06　冒泡排序冰载荷序列

**对应章节**：5 批量数据处理方法（5.5 排序与查找——冒泡排序；5.1 一维数组；3.3 循环结构）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）模块 M8——本练习是该实验中"冰载荷峰值序列升序整理"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰载荷辨识试验记录下 6 个海冰与船体相互作用的事件，每个事件的峰值载荷不同。为了生成载荷谱（统计不同载荷水平的出现规律），第一步是把杂乱的峰值序列**从小到大**排列——排序是数据分析中出现频率最高的预处理操作。冒泡排序是最直观的排序算法：像水中的气泡一样，**每一轮把当前未排序部分的最大值"顶"到末尾**。它的双重循环结构、相邻比较与三步交换，是理解一切排序算法的起点。

## 二、任务要求

编写一个完整程序 `bubble_sort.c`：

1. 读入数据个数 `n`（`int`，**$2 \le n \le 100$**），再读入 $n$ 个冰载荷峰值存入长度为 100 的 `double` 数组（单位：kN）；
2. 用**冒泡排序**将数组按**升序**排列：外层循环控制轮数（$n-1$ 轮），内层循环从数组头开始**相邻两元素比较**，前者大则交换，每轮把未排序部分的最大值移到末尾；
3. 输出排好序的 $n$ 个数，空格分隔（行末不留多余空格），保留 **2 位小数**；
4. 每完成一轮排序，把当前数组状态打印一行（格式见样例），用于观察排序过程。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个实数，以空格分隔。

**输出**：先输出 $n-1$ 行过程行，每行格式为 `第 k 轮: 数值 数值 …`（数值保留 2 位小数，空格分隔）；最后输出一行排序结果，格式为 `排序结果: 数值 数值 …`。

## 四、样例

**样例 1**

输入：
```
6
8.5 3.2 12.7 5.9 10.4 1.8
```
输出：
```
第 1 轮: 3.20 8.50 5.90 10.40 1.80 12.70
第 2 轮: 3.20 5.90 8.50 1.80 10.40 12.70
第 3 轮: 3.20 5.90 1.80 8.50 10.40 12.70
第 4 轮: 3.20 1.80 5.90 8.50 10.40 12.70
第 5 轮: 1.80 3.20 5.90 8.50 10.40 12.70
排序结果: 1.80 3.20 5.90 8.50 10.40 12.70
```

**样例 2**

输入：
```
4
2.0 2.0 2.0 2.0
```
输出：
```
第 1 轮: 2.00 2.00 2.00 2.00
第 2 轮: 2.00 2.00 2.00 2.00
第 3 轮: 2.00 2.00 2.00 2.00
排序结果: 2.00 2.00 2.00 2.00
```

## 五、提示

1. 冒泡排序的骨架是**双重循环**：
$$
\text{外层轮数：} k = 1, 2, \ldots, n-1; \qquad
\text{内层比较：} j = 0, 1, \ldots, n-k-1
$$
第 $k$ 轮中，比较 `a[j]` 与 `a[j+1]`，若 `a[j] > a[j+1]` 则交换——本轮结束后 `a[n-k]` 位置落定，不再参与后续比较；
2. 交换用标准三步：`t = a[j]; a[j] = a[j+1]; a[j+1] = t;`；
3. 内层上界 `n - k - 1` 的来历：每轮落定 1 个，未排序部分逐轮缩短；
4. 过程行在第 $k$ 轮内层循环结束后打印；
5. 升序用 `>`，若把比较写成 `<` 得到的是降序。

**完成本练习后你将具备的能力**：实现标准的双重循环冒泡排序、用"每轮落定一个"理解内层边界的收缩、通过打印中间状态观察算法行为——实验 C7 模块 M8 的载荷谱整理就以此为内核，它也是下一题选择排序的对质参照。
