## 二、预备知识：声压级换算的基本原理（零基础阅读）

### 1. 问题是怎么来的

人耳对声音强弱的感知是"对数式"的：声压大 100 倍，听起来只"响"得多一点点。所以声学里用**级（level）**表示声音强弱——取声压比值的对数再乘 20。不同行业给"比值分母"（基准声压 $p_0$）取了不同的值：水声常用 1 μPa，空气声学常用 20 μPa 或 1 Pa。

同一片噪声场，报数时若不注明基准（"re 1 μPa"等），数值就没有意义——差 120 dB 的两个数可能描述**同一个**噪声场！综合实验 C9 处理观测数据之前，必须先把所有读数统一到同一基准、扣除仪器偏置，否则后面分箱统计会"张冠李戴"。

### 2. 公式推导

声压级的定义（对基准声压 $p_0$）：

$$L = 20\lg\frac{p}{p_0}\ \text{(dB)}$$

把同一物理声压 $p$ 分别对两个基准 $p_{01}$、$p_{02}$ 表达，两式相减：

$$L_1 - L_2 = 20\lg\frac{p}{p_{01}} - 20\lg\frac{p}{p_{02}} = 20\lg\frac{p_{02}}{p_{01}}$$

妙处在于：**物理声压 $p$ 被消掉了**——换算差值只取决于两个基准之比。取 $p_{01}=1\ \mu Pa$：

- 换到 re 1 mPa（$p_{02}=10^3\ \mu Pa$）：$20\lg 10^3 = 60$ dB；
- 换到 re 1 Pa（$p_{02}=10^6\ \mu Pa$）：$20\lg 10^6 = 120$ dB。

于是得到本题的两个换算公式（再叠加校准）：

$$L_c = L - C$$

$$L_{mPa} = L_c - 60,\qquad L_{Pa} = L_c - 120$$

**为什么是减？** 基准声压越大，同样的 $p$ 摊在更大的 $p_0$ 上，比值更小，dB 数更低——基准每放大 10 倍，级就减 20 dB。

### 3. 代入本例数值

样例 1：$L = 142.5$，$C = 1.5$。

$$L_c = 142.5 - 1.5 = 141.00\ \text{dB re 1 μPa}$$

$$L_{mPa} = 141.00 - 60 = 81.00\ \text{dB re 1 mPa}$$

$$L_{Pa} = 141.00 - 120 = 21.00\ \text{dB re 1 Pa}$$

三个数描述的是**同一个**噪声场。样例 2 中 $C=0$，校准不改变读数，$128.0$ 依次变为 $68.00$、$8.00$。

### 4. 通过编程翻译

| 数学 | C 语言 |
|---|---|
| 换算常数 60、120 | `#define C_UMPAMPA 60.0`、`#define C_UMPAPA 120.0` |
| 读入 $L,\ C$ | `scanf("%lf %lf", &L, &Cc);` |
| $L_c = L - C$ | `Lc = L - Cc;` |
| $L_{mPa} = L_c - 60$ | `Lm = Lc - C_UMPAMPA;` |
| $L_{Pa} = L_c - 120$ | `Lp = Lc - C_UMPAPA;` |
| 输出 | 三条 `printf`，均 `%.2f` |

（示例中变量 `Cc` 是为避免与常量名冲突。）

## 三、解题思路

1. 两个 `#define` 封装换算常数；
2. 读入 `L`、`Cc`；
3. 顺序计算 `Lc`、`Lm`、`Lp`；
4. 三行 `printf` 输出，文字部分照抄样例。

## 四、参考代码

```c
#include <stdio.h>

#define C_UMPAMPA 60.0          /* re 1uPa → re 1mPa 的换算常数 */
#define C_UMPAPA  120.0         /* re 1uPa → re 1Pa  的换算常数 */

int main(void)
{
    double L, Cc;               /* 仪器读数（dB re 1uPa）、校准偏置 */
    double Lc, Lm, Lp;          /* 校准后、re 1mPa、re 1Pa */

    scanf("%lf %lf", &L, &Cc);

    Lc = L - Cc;                /* 第一步：扣除校准偏置 */
    Lm = Lc - C_UMPAMPA;        /* 第二步：换算到 re 1mPa */
    Lp = Lc - C_UMPAPA;         /* 第三步：换算到 re 1Pa */

    printf("calibrated = %.2f dB re 1uPa\n", Lc);
    printf("re 1mPa = %.2f dB re 1mPa\n", Lm);
    printf("re 1Pa = %.2f dB re 1Pa\n", Lp);
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：换算方向弄反（加而不是减）**

```c
Lm = Lc + C_UMPAMPA;    /* 错：基准变大级应变小 */
Lm = Lc - C_UMPAMPA;    /* 对 */
```

用物理常识自检：142 dB re 1 μPa 的噪声，换到更大的基准（1 Pa）后只剩 21 dB——如果"换算完更大了"，方向必然反了。

**错误 2：常数硬编码进表达式**

```c
Lm = Lc - 60.0;     /* 能跑，但 60 的来历无处可查，改基准时要在代码里翻找 */
Lm = Lc - C_UMPAMPA;    /* 对：常数有名有姓、集中管理 */
```

**错误 3：变量名与宏名冲突**——`#define C_UMPAMPA 60.0` 后再声明 `double C_UMPAMPA;` 会引发编译错误。宏名全大写、变量名小写，可从根源规避。

**错误 4：输出文字与样例不一致**——`re 1uPa` 写成 `re 1μPa`（非 ASCII 字符）或漏掉空格，在 OJ/自动测评中会被判错。工程输出的"格式即契约"，逐字符照抄。
