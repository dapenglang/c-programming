# 第 5 章 练习 08　顺序查找冰块编号

**对应章节**：5 批量数据处理方法（5.5 排序与查找——顺序查找；5.1 一维数组；3.2 选择结构、3.3 循环结构）

**场景来源**：综合实验 C6《海冰与结构碰撞模拟系统》（水声学院）——本练习是该实验中"冰块编号定位"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

碰撞模拟系统为场景中的每块冰分配一个唯一编号（如 2101、2085），所有冰块的状态记录按编号存放在数组中。当操作员输入一个编号查询某块冰时，系统必须回答"这块冰是第几个记录"。由于冰块编号的分配顺序与大小无关，编号数组**不保证有序**，只能采用最朴素的**顺序查找**：从第 1 个元素开始逐个比对，直到找到目标或扫完全表。顺序查找是查找算法的起点，也是理解下一题"二分查找为什么要求数组有序"的参照。

## 二、任务要求

编写一个完整程序 `ice_search.c`：

1. 读入冰块个数 `n`（`int`，**$1 \le n \le 100$**），再读入 $n$ 个互不相同的冰块编号存入长度为 100 的 `int` 数组（编号为 4 位整数）；
2. 读入一个待查询的编号 `key`（`int`）；
3. 用**顺序查找**在数组中寻找 `key`：找到则输出它的位置（按第几个数据计，从 1 开始）并停止比较；扫完全表未找到则输出未找到信息；
4. 查找过程不修改数组内容。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个整数（互不相同），以空格分隔；第三行一个整数 `key`。

**输出**：一行：
- 找到时输出 `编号 key 是第 p 个冰块`；
- 未找到时输出 `编号 key 未找到`。

## 四、样例

**样例 1**

输入：
```
8
2101 2085 2103 2077 2090 2105 2069 2088
2090
```
输出：
```
编号 2090 是第 5 个冰块
```

**样例 2**

输入：
```
8
2101 2085 2103 2077 2090 2105 2069 2088
2100
```
输出：
```
编号 2100 未找到
```

## 五、提示

1. 顺序查找的框架：遍历下标 $0 \sim n-1$，每次比较 `a[i] == key`，命中即记录位置并 `break`；
2. 用一个标志变量（如 `int found = 0;`）区分"找到"与"未找到"：命中时置 `found = 1`，循环结束后据此分支输出——**不要把输出语句直接写在循环里**，否则未找到的信息难以处理；
3. 整数比较用 `==`，注意不要误写成赋号 `=`（`a[i] = key` 的值恒为真，逻辑全错）；
4. 位置与下标的关系仍是"序号 = 下标 + 1"；
5. 找到后 `break` 可以提前结束循环——虽然对本题正确性非必需（编号互不重复），但这是"找到就停"的标准写法，表很长时显著省时。

**完成本练习后你将具备的能力**：实现带标志变量的顺序查找、掌握"找到即停"与"未找到兜底"两类出口的处理、理解查找算法以"比较次数"计代价的观念——实验 C6 的冰块定位环节与练习 09 的二分查找共同构成查找专题。
