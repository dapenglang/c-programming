## 二、预备知识：选择结构与逻辑运算的组合用法

### 1. 问题是怎么来的

数据合法性检查的典型结构是"**一串互斥的检查项，按优先级排列**"：每一项回答一个"是否违规"的问题，答案非真即假；只要有一项为真，就输出该项的错误并停止，全部为假才放行。这种"流水线式把关"用 **if / else if 链**实现最自然：每个 `if` 条件就是一项检查的"违规判据"，链的最后一个 `else` 就是放行。

### 2. 单项的违规判据怎么写

一项检查往往涉及多个量、多个边界。写法上有两种思路：

- **正向写"合格"条件**，合格才往下走：尺寸合格 = $(0 < a \le 20)$ 且 $(0 < b \le 20)$ 且 $(0 < c \le 20)$；
- **反向写"违规"条件**，违规才拦截：尺寸违规 = $a$ 出界 或 $b$ 出界 或 $c$ 出界。

两种写法逻辑等价，但反向写法（拦截式）通常更短，而且与 if-else 链的"拦截"语义直接对应。C 语言中"或"用 `||`，"与"用 `&&`，注意**它们是成对的双字符符号**，单个 `|`、`&` 是位运算符，含义完全不同。

### 3. 为什么必须"按顺序检查"

本例的密度检查要做除法 $\rho = m/(abc)$。若尺寸检查放在密度之后，当输入 $a = 0$（或负数）时程序会带着非法尺寸直接去除法——除以零，程序立刻崩溃。**"先做便宜的、能排除危险的检查，后做有前提的计算"**，是所有工程程序数据校验的通用原则。本例顺序：尺寸 → 质量 → 密度 → 位置，前三步全部通过后，$abc > 0$ 已有保证，除法才安全。

### 4. 逻辑运算的短路特性帮了忙

`||` 运算从左往右进行，一旦某个子条件为真，后面的子条件**不再求值**。所以 `a <= 0.0 || m / a > 100.0` 这种写法在 $a \le 0$ 时根本不会执行除法。理解短路特性，既能写出更安全的条件，也能看懂别人代码里的这类"保护性写法"。

## 三、解题思路

1. **读入 6 个数**：一个 `scanf` 用 6 个 `%lf` 配 6 个取地址的变量；
2. **第一关尺寸**：用 `||` 串起 6 个出界条件，违规输出 `ERR size`；
3. **第二关质量**：$m \le 0$ 输出 `ERR mass`；
4. **第三关密度**：先算 $\rho = m/(abc)$（此时 $abc > 0$ 已有保证），越出 $[850, 950]$ 输出 `ERR density`；
5. **第四关位置**：$x$、$y$ 任一越界输出 `ERR position`；
6. **全部通过**：最后的 `else` 输出 `OK`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double SIZE_MAX = 20.0;   /* 边长上限，m */
    const double RHO_MIN  = 850.0;  /* 密度下限，kg/m3 */
    const double RHO_MAX  = 950.0;  /* 密度上限，kg/m3 */
    const double X_MAX = 100.0;     /* 计算域 x 上限，m */
    const double Y_MAX = 80.0;      /* 计算域 y 上限，m */

    double a, b, c;                 /* 冰块长、宽、厚，m */
    double m;                       /* 冰块质量，kg */
    double x, y;                    /* 中心坐标，m */
    double rho;                     /* 折算密度，kg/m3 */

    scanf("%lf %lf %lf %lf %lf %lf", &a, &b, &c, &m, &x, &y);

    if (a <= 0.0 || a > SIZE_MAX || b <= 0.0 || b > SIZE_MAX ||
        c <= 0.0 || c > SIZE_MAX)
        printf("ERR size\n");       /* 第一关：尺寸 */
    else if (m <= 0.0)
        printf("ERR mass\n");       /* 第二关：质量 */
    else {
        rho = m / (a * b * c);      /* 走到这里 abc>0 已有保证，除法安全 */
        if (rho < RHO_MIN || rho > RHO_MAX)
            printf("ERR density\n");    /* 第三关：密度 */
        else if (x < 0.0 || x > X_MAX || y < 0.0 || y > Y_MAX)
            printf("ERR position\n");   /* 第四关：位置 */
        else
            printf("OK\n");             /* 全部合格，放行 */
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `3 2 1.5 8250 50 40` | 尺寸、质量合格；$\rho = 8250/9 \approx 916.7 \in [850,950]$；$0 \le 50 \le 100$、$0 \le 40 \le 80$ | `OK` ✓ |
| `3 2 1.5 10000 150 40` | 尺寸、质量合格；$\rho = 10000/9 \approx 1111.1 > 950$ → 第三关拦截（x=150 虽也越界但轮不到它） | `ERR density` ✓ |
| `25 2 1.5 8250 50 40` | $a = 25 > 20$ → 第一关拦截 | `ERR size` ✓ |
| `0 2 1.5 8250 50 40` | $a = 0$ 不满足 $a > 0$ → 第一关拦截（若先算密度将除以零） | `ERR size` ✓ |

第 2 行验证了"先到先停"：密度与位置同时违规时，只报排在前面的那一项。

## 六、常见错误与讲解

**错误 1：检查顺序颠倒导致除以零**

```c
rho = m / (a * b * c);        /* 错：a 可能为 0，先除后查直接崩溃 */
if (a <= 0.0 || a > SIZE_MAX || ...) printf("ERR size\n");
```

必须把尺寸检查放在密度计算**之前**。样例 `0 2 1.5 ...` 就能暴露这个错误。

**错误 2：逻辑"或"写成逻辑"与"**

```c
if (a <= 0.0 && a > SIZE_MAX)   /* 错：a 不可能同时 <=0 又 >20，恒为假 */
if (a <= 0.0 || a > SIZE_MAX)   /* 对："出界"是二者居其一 */
```

"某个量越界"天然是或关系；把"全部合格"反向成"任一违规"时最容易把 `||` 误写成 `&&`。

**错误 3：把范围判断拆丢一半**

```c
if (rho < RHO_MIN) printf("ERR density\n");   /* 错：漏了超上限的情形 */
if (rho < RHO_MIN || rho > RHO_MAX) printf("ERR density\n");  /* 对 */
```

**错误 4：else if 链中混入并列 if**

若把第四关写成与第三关并列的新 `if`（而不是 else if），当密度违规时位置检查仍会执行——虽然本题结果碰巧相同，但"发现即停止"的语义已被破坏，一旦后续分支有计算就会出错。

## 七、与综合实验的衔接

- 实验 **C6（冰块碰撞模拟）**中，冰块数据在进入碰撞主循环前必须通过本练习的整套体检，任何一个 `ERR` 都意味着该冰块被剔除并记录日志。学到第 5 章（数组）后，"一块冰"将扩展成"一批冰"，用循环对每块冰重复执行同样的检查流程；学到第 7 章（结构体）后，6 个分散的变量会被封装成一个冰块结构体，检查代码相应地读 `ice.a`、`ice.m` 等成员——但**检查顺序与逻辑条件本身一字不变**；
- "逐项校验、先到先停"的模式在所有综合实验的输入模块中都会出现（A1 的高度范围、D5 的剂量上限、C1 的深度范围等），本题是这一模式的标准模板。
