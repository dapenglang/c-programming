## 二、预备知识：冒泡排序的指针实现原理（零基础阅读）

### 1. 冒泡排序的算法思想（第 5 章已学，快速回顾）

对 $n$ 个数升序排序：每一趟从头到尾**两两比较相邻元素**，逆序就交换——一趟下来最大值必然"冒泡"到末尾；共做 $n-1$ 趟，第 $i$ 趟只需比较前 $n-i$ 个元素（末尾 $i$ 个已就位）。

以样例 1 第一趟为例（5 个数）：

```
初始        320.5  180.2  455.8  267.4  390.1
比较 320.5,180.2 → 逆序，交换：180.2  320.5  455.8  267.4  390.1
比较 320.5,455.8 → 正序，不动：180.2  320.5  455.8  267.4  390.1
比较 455.8,267.4 → 交换：     180.2  320.5  267.4  455.8  390.1
比较 455.8,390.1 → 交换：     180.2  320.5  267.4  390.1  455.8   ← 最大值就位
```

### 2. 把下标翻译成指针

第 5 章的下标版核心判断是 `a[j] > a[j+1]`。因为 `a[j]` 就是 `*(a + j)`，翻译后：

```c
if (*(a + j) > *(a + j + 1))
    swap(a + j, a + j + 1);      /* 传地址，不是传值 */
```

注意两个细节：比较时用 `*(a + j)` **取值**；交换时用 `a + j` **传地址**（`a + j` 已经是地址，不加 `&`）。这正好是练习 02 与 04 两个知识点的合成应用。

### 3. 函数签名为什么是 `void bubble_sort(double *a, int n)`

主函数调用 `bubble_sort(m, 5)` 时，数组名 `m` 自动退化为首元素地址传给形参 `a`。于是：

- 函数拿到的是**地址**，`*(a + j)` 操作的就是主函数里数组 `m` 的原数据——排序**就地完成**，不需要返回值（`void`）；
- 长度 `n` 必须单独传：函数拿到地址后，**无法从地址本身得知数组有几个元素**，这是指针与数组的重要差异，也是所有数组型函数都带长度参数的原因。

### 4. 内层循环的指针化边界

下标版内层条件是 `j < n - i - 1`（保证 `a[j+1]` 不越界）。指针版写法保持下标循环也可以；若让指针 `q` 自己走，则条件写成 `q < a + n - i - 1`，含义是"右邻 `q + 1` 至多是 `a + n - i - 1`"，仍在有效区间内。两种写法任选其一，本题参考代码采用后者，让你同时见到两种风格。

## 三、解题思路

1. **函数拆分**：`swap` 负责一次交换，`bubble_sort` 负责排序流程，主函数负责输入输出——三段职责分明；
2. **排序函数**：外层 `for (i = 1; i < n; i++)`，内层指针 `q` 从 `a` 走到 `a + n - i - 1`，比较 `*q` 与 `*(q + 1)`；
3. **主函数**：读入 5 个数 → 调用 `bubble_sort(m, 5)` → 用指针或下标遍历输出；
4. **输出格式**：`%.2f`，空格分隔，末尾换行。

## 四、参考代码

```c
#include <stdio.h>

void swap(double *x, double *y);            /* 练习 02 的交换函数 */
void bubble_sort(double *a, int n);         /* 指针版冒泡排序 */

int main(void)
{
    double m[5];        /* 5 个冰载荷值，kN */
    int i;

    for (i = 0; i < 5; i++)
        scanf("%lf", &m[i]);

    bubble_sort(m, 5);  /* 数组名 m 即首元素地址，就地排序 */

    for (i = 0; i < 5; i++)
        printf("%.2f ", m[i]);
    printf("\n");

    return 0;
}

void swap(double *x, double *y)
{
    double t = *x;
    *x = *y;
    *y = t;
}

void bubble_sort(double *a, int n)
{
    int i;
    double *q;

    for (i = 1; i < n; i++)             /* 共 n-1 趟 */
        for (q = a; q < a + n - i; q++) /* q 的右邻不越过未排序区末尾 */
            if (*q > *(q + 1))          /* 前面的数更大则交换 */
                swap(q, q + 1);         /* 传相邻两个元素的地址 */
}
```

## 五、运行验证

样例 1（输入 `320.5 180.2 455.8 267.4 390.1`）：逐趟冒泡后序列为

```
第 1 趟后：180.2 320.5 267.4 390.1 455.8
第 2 趟后：180.2 267.4 320.5 390.1 455.8
第 3 趟后：180.2 267.4 320.5 390.1 455.8（已有序，后两趟无交换）
```

输出 `180.20 267.40 320.50 390.10 455.80`，与样例一致 ✓。

样例 2（输入 `100.0 99.5 100.5 99.0 101.0`）：排序后输出 `99.00 99.50 100.00 100.50 101.00` ✓。两个样例中主函数数组 `m` 的原始顺序均被就地改变，验证了"指针形参可修改主调函数数据"。

## 六、常见错误与讲解

**错误 1：交换时多加取地址符**

```c
swap(&a[j], &a[j+1]);   /* 下标版：对 */
swap(&(a + j), ...);    /* 错：a+j 已经是地址，不能再取地址 */
swap(a + j, a + j + 1); /* 指针版：对 */
```

`&` 只能作用于变量（有内存实体的东西），`a + j` 是算出来的地址值，对它取地址是编译错误。

**错误 2：内层边界写错导致越界**

```c
for (q = a; q < a + n; q++)
    if (*q > *(q + 1))   /* 错：q 到 a+n-1 时，q+1 已指向 a[n]，越界 */
```

比较 `*(q + 1)` 要求 `q + 1` 合法，故 `q` 最远走到 `a + n - 2`，即条件 `q < a + n - i`（`i ≥ 1`）保证右邻不越界。

**错误 3：以为排序函数需要 return 数组**

```c
double *bubble_sort(...) { ...; return a; }   /* 多余：a 就是主函数数组本身 */
```

指针形参已让函数直接改写原数组，`void` 即可；返回地址是练习 06 的主题，此处不必混入。

**错误 4：在排序函数里用 `n` 之外的定长**

```c
for (i = 1; i < 5; i++)   /* 错：写死 5，函数失去通用性 */
for (i = 1; i < n; i++)   /* 对：长度由参数决定 */
```

通用函数必须依赖形参 `n`，这样实验 C7 中长度为 1000 的载荷序列也能直接调用。

## 七、与综合实验的衔接

实验 **C7** 的 M8 模块（冰载荷序列排序）与本练习几乎逐行对应：真实系统中序列长度达数百上千，函数签名 `bubble_sort(double *a, int n)` 无需任何修改即可直接投入使用；排序还服务于分位数统计（如取前 10% 大载荷的均值），那一步只需再配合指针定位 `a + (int)(0.1 * n)`。把"比较—交换—遍历"全部指针化之后，你会发现排序、查找、统计的代码骨架彼此相通——下一题的查找函数只比本题少一个外层循环。
