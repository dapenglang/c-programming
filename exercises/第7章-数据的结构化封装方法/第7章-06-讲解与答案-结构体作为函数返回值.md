## 二、预备知识：函数返回结构体的基本原理（零基础阅读）

### 1. 为什么"一个 return 只能带回一个数"会不够用

第 4 章的函数 `double maxOf(double a[], int n)` 用 `return` 带回一个数。可统计工作天然是"多产出"的：最大、最小、平均三个量同样重要。硬凑单返回值的办法有两个——写三个几乎一样的函数（遍历三遍，浪费）；或者用全局变量传回（破坏模块封装，第 4 章已强调慎用）。结构体给出了优雅的第三条路：**把多个结果本身打包成一种新类型**，让函数返回这个类型。

### 2. 返回结构体时发生了什么

```c
struct Stat analyze(const double a[], int n)
{
    struct Stat s;      /* 局部的结果变量 */
    ...                 /* 填好 s.max、s.min、s.avg */
    return s;           /* 把整个 s 复制回主调函数 */
}
```

`return s;` 的动作与参数值传递方向相反：把函数内局部变量 `s` 的**全部成员复制一份**交给调用处。于是 main 里可以写：

```c
struct Stat r;
r = analyze(f, n);      /* 三个结果一次到手 */
```

这里 `r = ...` 是**同类型结构体之间的整体赋值**——C 语言允许，语义是逐成员复制。与练习 05 相对照：值传递是"调用时复制进去"，返回结构体是"返回时复制出来"，两个方向的整块复制遵循同一套规则。

### 3. 返回的是副本，局部变量随之消亡

函数返回后，局部变量 `s` 的生命周期结束，但这不影响结果——因为 `return` 在函数结束**之前**已经把 s 的副本送了出去，main 里的 `r` 是独立的一份。这与"返回局部变量的地址"（悬空指针，危险）完全不同：**返回结构体是复制值，安全；返回局部变量的地址是复制地址，危险**。当前阶段只做前者。

### 4. 统计量的求法回顾

最大/最小值用"打擂台"法：擂主初值取第一个样本 `a[0]`（不能取 0，阻力可能全为正，也不能想当然取其他数），逐个比较、更大（更小）则换擂主。平均值先累加再除以 n。这些算法第 5 章已练过，本练习的新意只在"三个结果打包返回"。

## 三、解题思路

1. **定结果类型**：`struct Stat { max, min, avg }`——类型按"函数要返回什么"来设计；
2. **写统计函数**：形参 `(const double a[], int n)`，局部 `struct Stat s` 与累加器 `sum`；
3. **一遍循环三件事**：比较更新 `s.max、s.min`，同时 `sum += a[i]`；
4. **收尾**：`s.avg = sum / n; return s;`；
5. **main**：读入 → `r = analyze(f, n);` → 按格式输出 `r.max、r.min、r.avg`。

## 四、参考代码

```c
#include <stdio.h>

struct Stat {                  /* 统计结果打包类型 */
    double max;                /* 最大阻力 kN */
    double min;                /* 最小阻力 kN */
    double avg;                /* 平均阻力 kN */
};

struct Stat analyze(const double a[], int n)   /* 返回整个结构体 */
{
    struct Stat s;
    double sum = 0.0;
    int i;

    s.max = a[0];              /* 擂主初值取第一个样本 */
    s.min = a[0];
    for (i = 0; i < n; i++) {
        if (a[i] > s.max) s.max = a[i];
        if (a[i] < s.min) s.min = a[i];
        sum += a[i];
    }
    s.avg = sum / n;

    return s;                  /* 整块复制回主调函数 */
}

int main(void)
{
    double f[20];
    struct Stat r;             /* 接住返回的统计结果 */
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &f[i]);

    r = analyze(f, n);         /* 一次调用，三个结果 */

    printf("最大阻力 = %.2f kN\n", r.max);
    printf("最小阻力 = %.2f kN\n", r.min);
    printf("平均阻力 = %.2f kN\n", r.avg);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：擂主初值取 0 或想当然的数**

```c
s.max = 0;                 /* 错：若所有样本都为负（理论上有此可能）结果恒为 0 */
s.max = a[0];              /* 对：用第一个样本当擂主 */
```

用 0 当初值在本题的正样本数据上"碰巧"不出错，因此更具迷惑性——好习惯必须从现在养成。

**错误 2：返回类型写漏 struct 前缀或接不住返回值**

```c
Stat analyze(...)           /* 错：C 里类型名是 struct Stat，不能只写 Stat */
double r = analyze(f, n);   /* 错：返回的是结构体，不能赋给 double */
struct Stat r = analyze(f, n);   /* 对 */
```

**错误 3：在函数外使用函数内的局部变量**

```c
analyze(f, n);
printf("%.2f\n", s.max);    /* 错：s 是 analyze 的局部变量，main 里不存在 */
printf("%.2f\n", r.max);    /* 对：必须通过接收返回值的 r 访问 */
```

这正检验了对"返回结构体 = 复制副本"的理解：拿到的是 `r`，`s` 已随函数结束消亡。

**错误 4：忘记 n 作除数时可能整型化或除零**

```c
s.avg = sum / (double)n;    /* 安全写法：强制实数除法 */
s.avg = sum / n;            /* 本题 n 是 int 但 sum 是 double，结果仍为实数，亦可 */
s.avg = sum / n;            /* 若 sum 声明成了 int，小数部分会被丢弃——务必检查类型 */
```

sum 必须声明为 `double`；同时题目保证 $n \ge 1$，暂不需要除零保护。
