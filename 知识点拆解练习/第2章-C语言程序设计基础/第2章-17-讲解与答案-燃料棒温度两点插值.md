## 二、预备知识：线性插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

数值方法求温度场时，只算出了节点上的温度：0.5 m 处 620.0 ℃，1.0 m 处 540.0 ℃。**介于两节点之间（如 0.75 m）的温度是多少？** 最自然的假设是：这段区间内温度随位置**均匀变化**（图象是一条直线），于是按比例取值，这就是线性插值。

### 2. 公式是怎么推出来的

设已知点为 $(x_0, T_0)$、$(x_1, T_1)$，要求 $x$ 处（$x_0 \le x \le x_1$）的值。"均匀变化"意味着**温度变化量与位置变化量成正比**：

$$
\frac{T - T_0}{T_1 - T_0} = \frac{x - x_0}{x_1 - x_0}
$$

解得

$$
T = T_0 + \dfrac{(T_1 - T_0)(x - x_0)}{x_1 - x_0}
$$

读作"起点温度 + 全程温降 × 已走位置比例"。$T_1 - T_0$ 为负表示温度在下降，公式自动带符号。

### 3. 用本例走一遍

取 $x = 0.75$，代入 $(x_0, T_0) = (0.5,\ 620.0)$，$(x_1, T_1) = (1.0,\ 540.0)$：

- 已走比例：$(0.75 - 0.5)/(1.0 - 0.5) = 0.25/0.5 = 0.5$；
- 全程温降：$540.0 - 620.0 = -80.0$ ℃；
- 已降温：$-80.0 \times 0.5 = -40.0$ ℃；
- 结果：$T = 620.0 - 40.0 = 580.0$ ℃。

再取 $x = 0.6$：比例 $= (0.6-0.5)/0.5 = 0.2$，降温 $-80 \times 0.2 = -16$，得 $T = 604.0$ ℃。端点 $x=0.5$ 得 620.0、$x=1.0$ 得 540.0，与节点值一致。

### 4. 编程时怎么用它

四个表格常量 + 一个输入，把公式翻译成一行赋值语句即可。分子 $(T_1-T_0)(x-x_0)$ 与分母 $(x_1-x_0)$ 都要先各自算好。

> **这个思想在综合实验中反复出现**：D4 温度场、C1 声速剖面、A1 风荷载、D3 核截面，都是"表格 + 线性插值"。本题是同一方法在温度场景下的又一次练习，请独立完成、独立验算。

## 三、解题思路

1. **确定常量**：`X0=0.5, X1=1.0, T0=620.0, T1=540.0`，用 `const double`；
2. **确定变量**：位置 `x` 与温度 `T`，用 `double`；
3. **套公式**：`T = T0 + (T1 - T0) * (x - X0) / (X1 - X0);`；
4. **输出**：`printf("T = %.2f C\n", T);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 相邻两节点：轴向位置(m) 与 温度(摄氏度) */
    const double X0 = 0.5;    /* 下节点位置 */
    const double X1 = 1.0;    /* 上节点位置 */
    const double T0 = 620.0;  /* 下节点温度 */
    const double T1 = 540.0;  /* 上节点温度（温度沿轴向递减） */

    double x;    /* 待查位置，m */
    double T;    /* 插值得到的温度，摄氏度 */

    /* 读入位置（题目保证 0.5 <= x <= 1.0） */
    scanf("%lf", &x);

    /* 线性插值：T = T0 + (T1 - T0) * (x - X0) / (X1 - X0) */
    T = T0 + (T1 - T0) * (x - X0) / (X1 - X0);

    /* 输出，保留 2 位小数 */
    printf("T = %.2f C\n", T);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 0.75 | 620 + (−80) × 0.25/0.5 = 620 − 40 = 580.0 | `T = 580.00 C` ✓ |
| 0.6 | 620 + (−80) × 0.1/0.5 = 620 − 16 = 604.0 | `T = 604.00 C` ✓ |
| 0.5 | 620 + (−80) × 0/0.5 = 620.0（下节点） | `T = 620.00 C` ✓ |
| 1.0 | 620 + (−80) × 0.5/0.5 = 540.0（上节点） | `T = 540.00 C` ✓ |

端点值与节点温度完全一致，中间值线性下降，插值正确。

## 六、常见错误与讲解

**错误 1：常量写成整数**

```c
const double T0 = 620, T1 = 540;      /* 错：温度写成整数字面量 */
const double T0 = 620.0, T1 = 540.0;  /* 对：一律带小数点 */
```

**错误 2：忘记取地址符**

```c
scanf("%lf", x);      /* 错：程序崩溃或读不进数据 */
scanf("%lf", &x);     /* 对：scanf 需要变量地址 */
```

**错误 3：输出格式与精度不符**

```c
printf("T = %d C\n", T);       /* 错：double 用 %d 输出乱码 */
printf("T = %.2f C\n", T);     /* 对：保留 2 位小数 */
```

**错误 4：公式括号写错**

```c
T = T0 + (T1 - T0) * x - X0 / (X1 - X0);        /* 错：括号缺失 */
T = T0 + (T1 - T0) * (x - X0) / (X1 - X0);      /* 对：先减、再乘、再除 */
```

本题为负斜率，若结果高于 620 或低于 540，一定超出了合理区间，可据此自查。
