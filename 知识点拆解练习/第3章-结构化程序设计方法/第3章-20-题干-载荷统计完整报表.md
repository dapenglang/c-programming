# 第 3 章 练习 20　载荷统计完整报表

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.2 选择结构、3.3 循环结构、3.4 关系与逻辑运算、3.5 数值求解方法——矩形法数值积分）

**场景来源**：综合实验 C7《冰区结构载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷统计报表输出"环节的实现。

> 本题为第 3 章**综合题**，综合运用 3.1～3.5 全部知识点。

**建议用时**：25 分钟

## 一、应用场景

冰区结构在一次作业过程中会记录一串随时间变化的载荷样本。工程上需要把这些样本整理成一份规范的统计报表，内容包括样本总数、总和、均值、最大值与最小值（及其出现位置）、极差、超阈值样本的比例，以及整段过程的"载荷冲量"。报表是后续安全评估、疲劳分析的原始依据，因此既要算得对，又要输出得规范清楚。本练习把前面几题学到的循环、判断、统计、积分串成一个完整流程。

## 二、任务要求

编写一个完整程序 `load_report.c`：

1. 从键盘读入三个数，用空格分隔：样本个数 `n`（正整数，int）、阈值 `T`（double，单位 kN）、时间间隔 `dt`（double，单位 s）；随后再依次读入 `n` 个载荷样本值（double，单位 kN）；
2. 用 **for 循环**逐个读入样本并用**选择结构**完成统计：求总和、最大值及其位置、最小值及其位置、不小于阈值的样本个数（**不使用数组**）；
3. 用**矩形法**估算载荷冲量：$I \approx \displaystyle\sum_{i=1}^{n} F_i \cdot \Delta t$；
4. 按第三节规定格式输出完整报表，实数保留 4 位小数，百分比保留 1 位小数。

## 三、输入输出格式

**输入**：第一行三个数 `n T dt`；后续为 `n` 个实数（载荷样本），数与数之间用空白分隔。

**输出**：九行固定报表，首行为标题 `==== 载荷统计报表 ====`，其后依次为 `样本数 = ...`、`总和 = ...`、`均值 = ...`、`最大值 = ... (位置 ...)`、`最小值 = ... (位置 ...)`、`极差 = ...`、`超阈值数 = ... (占比 ...%)`、`载荷冲量 = ... kN·s` 八行（各标签与数值之间为一个空格加等号加一个空格）。

其中总和、均值、最大值、最小值、极差、载荷冲量保留 4 位小数；占比保留 1 位小数；"位置"指该样本在输入序列中的序号（从 1 开始）。

## 四、样例

**样例 1**

输入：
```

```
输出：

```
样本数 = 6
总和 = 317.5000
均值 = 52.9167
最大值 = 71.8000 (位置 5)
最小值 = 30.2000 (位置 4)
极差 = 41.6000
超阈值数 = 3 (占比 50.0%)
载荷冲量 = 158.7500 kN·s
```

**样例 2**

输入：
```
4 60 2.0

```

```
样本数 = 4
```

## 五、提示

统计量定义（$F_i$ 为第 $i$ 个样本）：$\text{总和}=\displaystyle\sum_{i=1}^{n}F_i$，$\text{均值}=\frac{1}{n}\displaystyle\sum_{i=1}^{n}F_i$，$\text{极差}=\max_i F_i-\min_i F_i$。"不小于阈值"的样本数记为 $k$，占比为 $k/n\times100\%$。冲量用矩形法近似：

$$
I = \int_0^{T_{end}} F(t)\,\mathrm{d}t \approx \sum_{i=1}^{n} F_i\cdot\Delta t
$$

即"把每个样本看作一小段时间内不变的载荷，乘时间间隔 $dt$ 后全部相加"。注意：**最大值/最小值初值应取第一个读入的样本**（用标志变量判断是否为首个），以免初值设 0 在特殊数据下出错。

**完成本练习后你将具备的能力**：把"循环读入 → 选择判断 → 累加统计 → 数值积分 → 格式化输出"串成一条完整的数据处理链，独立写出结构清晰、结果规范的统计报表程序——这正是实验 C7 统计模块所需要的全部能力。
