# 题目 A3：基于梯形积分的飞行器垂直上升段弹道估算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套飞行器垂直上升段弹道估算工具。系统读入发动机推力-时间曲线表，输入飞行器质量、阻力系数、参考面积等参数后，按定步长 dt 逐时刻推进仿真：由"推力 - 重力 - 空气阻力"计算当前加速度，用梯形法（预估-校正单步积分）由当前速度、高度推算下一时刻速度、高度，直至发动机关机并继续滑行段积分；最后提取关机点特征参数，绘制速度、高度随时间曲线，输出弹道数据报表。

**解决什么重要问题**：火箭与导弹的动力飞行段性能（关机点速度、高度、加速度峰值）决定了能否达到预定弹道，而这些量来自动力学微分方程 dv/dt = a(t,v) 的积分——推力是随时间剧烈变化的曲线（点火爬升、稳定燃烧、关机跌落），空气阻力又与速度平方相关，解析积分几乎不可能，工程上全部依赖数值积分。步长选大了误差大、选小了算得慢，这正是数值方法课程要建立的核心直觉。不解决该问题，飞行器总体方案阶段就无法快速评估"这台发动机能不能把有效载荷送到预定高度"。

**支撑哪些关键应用**：① 探空火箭、运载火箭上升段的方案级弹道预估；② 飞行器总体设计中的推力-质量比权衡分析；③ 飞行仿真软件（如六自由度仿真）的一维简化原型；④ 后续"飞行力学""航天器轨道力学""计算方法"课程中常微分方程数值解法（欧拉法、龙格-库塔法）的直接先导——本系统的单步积分就是这些方法的最简单形态。

**与专业培养的关联**：航空航天工程专业开设"飞行力学""火箭发动机原理"等课程，均以本题目这类质点弹道计算为第一课。学生用课程 3.5 节梯形数值积分亲手复现专业软件内核，理解"仿真 = 循环 + 单步推进 + 状态更新"，为高年级学习完整弹道设计与制导律打下直观基础。

## 二、题目任务与专业关联

本题目面向航空航天工程与工程力学方向学生，模拟"上升段弹道快速估算"场景。系统功能概述：① 读入推力-时间表并对任意时刻线性插值取推力；② 录入飞行器参数；③ 实现加速度函数（含阻力与质量线性消耗）；④ 以 dt=0.05~0.2 s 定步长推进速度与高度；⑤ 提取关机点时刻、速度、高度与最大动压；⑥ 绘制弹道字符曲线并输出报表。先导知识铺垫：教师随题发布一维动力学方程 a=(F(t)-mg-0.5ρv²·Cd·A·sign(v))/m(t)、质量线性消耗模型 m(t)=m0-k·t（k 为推进剂秒耗量），以及梯形单步公式：先以当前加速度预测 v*，再由 v* 算校正加速度，取两者平均推进（预估-校正，半页讲清）。

## 三、数据来源与格式

**数据文件：推力-时间曲线表**（`thrust_curve.txt`）

```
时间s,推力kN
0.0,0.0
0.5,42.0
1.0,55.0
2.0,60.0
5.0,60.0
5.5,58.0
6.0,0.0
```

字段含义：时间 t（s，取值 0~60，间隔 0.1~1.0 s）；推力 F（kN，取值 0~120，发动机工作段 30~120、点火段线性爬升、关机点归 0）。文件按时间递增排列，首行为表头说明。

**仿真数据生成规则**：
- 生成 2~3 条不同发动机曲线：小型探空火箭（工作 6 s，推力 40~60 kN）、中型（工作 15 s，推力 80~120 kN）、双脉冲（0~5 s 与 8~13 s 两段推力，中间为 0）；
- 曲线形态：0~0.5 s 由 0 线性爬升到额定值，工作段加 ±3% 随机小幅波动（用固定规律如 sin 函数模拟，不引入随机数也可），关机前 0.5 s 线性跌落到 0；
- 异常注入：在 `thrust_curve.txt` 中故意把某行时间写成 `3.0` 出现两次（重复时间点）、某行推力写成 `600.0`（超物理范围），用于训练读入模块的重复检测与范围校验。

**真实数据集**：NASA 公开的 sounding rocket 发动机参数页（https://www.nasa.gov/sounding-rockets/ ，仅作参数参考）；课程实验以仿真数据为准。

## 四、数据结构设计

```c
#define MAX_THRUST_ROW 200   /* 推力表最大行数 */
#define MAX_STEP       6000  /* 仿真最大步数（60s/0.01s） */

/* 推力表一行 */
struct ThrustRow {
    double t;                /* 时间 s，0~60，递增 */
    double F;                /* 推力 kN，0~120 */
};

/* 飞行器与大气参数（M2 录入） */
struct Vehicle {
    double m0;               /* 起飞质量 kg，取值 50~3000 */
    double fuelK;            /* 推进剂秒耗量 kg/s，取值 1~50 */
    double cd;               /* 阻力系数，取值 0.2~1.2 */
    double area;             /* 参考面积 m2，取值 0.03~1.5 */
    double dt;               /* 积分步长 s，取值 0.01~0.5 */
};

/* 单时刻弹道状态 */
struct TrajPoint {
    double t;                /* 时刻 s */
    double m;                /* 瞬时质量 kg */
    double F;                /* 当前推力 N */
    double a;                /* 加速度 m/s2 */
    double v;                /* 速度 m/s，垂直向上为正 */
    double h;                /* 高度 m */
};

/* 全局数据 */
struct ThrustRow g_thr[MAX_THRUST_ROW];
int    g_thrCnt;             /* 推力表行数 */
struct Vehicle  g_vh;        /* 飞行器参数 */
struct TrajPoint g_traj[MAX_STEP]; /* 弹道序列 */
int    g_stepCnt;            /* 实际步数 */
int    g_burnoutIdx;         /* 关机点在 g_traj 中的下标 */
```

关键物理常量：`g = 9.8`（m/s²）、`RHO0 = 1.225`（kg/m³，海平面空气密度，本系统取常数简化）。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 推力-时间数据文件读入模块**（源文件 `ThrustIO.c`）

- 功能简介：跳过首行表头后逐行读入"时间,推力"，检查时间递增与推力范围（0~120 kN）；对重复时间点保留前一行并打印警告，对超范围推力（如注入的 600.0）截断到上限并标记；输出读入摘要（行数、工作时段）。
- 输入：`thrust_curve.txt`。
- 输出：`g_thr[]`、`g_thrCnt`；屏幕读入与校验摘要。

**M2 飞行器参数录入模块**（源文件 `ParamInput.c`）

- 功能简介：交互录入起飞质量、秒耗量、阻力系数、参考面积与步长，逐项范围检查不合法重输；显示推力-质量比初值（F0/(m0·g)）供学生判断方案合理性。
- 输入：键盘输入 5 项参数。
- 输出：填充 `g_vh`；屏幕参数回显。

### 第二部分：算法实现（5 个模块）

**M3 加速度函数实现模块**（源文件 `Dynamics.c`）

- 功能简介：实现 `double accel(double t, double v, double m, const struct Vehicle *p)`：调用 M6 取当前推力，按动力学方程计算含重力与速度平方阻力的加速度；提供固定状态下的单点自测打印，便于与手算对照。
- 输入：时刻 t、速度 v、质量 m、参数指针。
- 输出：加速度 a（m/s²）。

**M4 单步梯形积分模块**（源文件 `StepInteg.c`）

- 功能简介：实现预估-校正单步推进 `void stepForward(int i)`：由第 i 点状态用 M3 算 a_i，预测 v* = v_i + a_i·dt、h* = h_i + v_i·dt + 0.5·a_i·dt²；由 v* 再算校正加速度 a*，取 a_avg=(a_i+a*)/2 后更新第 i+1 点的速度与高度（v_{i+1}=v_i+a_avg·dt，h_{i+1}=h_i+v_{i+1}·dt）；质量按 m0-k·t 同步更新；速度由正转负即到达弹道顶点时停止积分。
- 输入：`g_traj[i]` 与 `g_vh`。
- 输出：填充 `g_traj[i+1]`。

**M5 定步长仿真主循环模块**（源文件 `Simulate.c`）

- 功能简介：初始化第 0 点（t=0, v=0, h=0），循环调用 M4 推进直至关机后再滑行 20 s 或速度转负；步数超 MAX_STEP 强制终止并告警；过程中记录每步状态到 `g_traj[]`。
- 输入：`g_thr[]`、`g_vh`。
- 输出：`g_traj[]`、`g_stepCnt`；屏幕进度提示。

**M6 推力插值模块**（源文件 `ThrustIO.c`）

- 功能简介：实现 `double thrustAt(double t)`：在 `g_thr[]` 中定位 t 所在区间做线性插值；t 超出表末返回 0（已关机）；用 5 个典型时刻做插值自测打印。
- 输入：任意时刻 t（s）。
- 输出：推力 F（N）。

**M7 关机点特征提取模块**（源文件 `Feature.c`）

- 功能简介：扫描 `g_traj[]` 找出推力首次降为 0 的下标即关机点，输出关机时刻、关机点速度与高度；另统计全程最大加速度及其时刻、最大动压 0.5ρv² 及其时刻（动压为载荷设计的特征量）。
- 输入：`g_traj[]`。
- 输出：关机点与极值特征；屏幕特征汇总。

### 第三部分：数据输出（3 个模块）

**M8 弹道曲线字符画模块**（源文件 `CharPlot.c`）

- 功能简介：以时间均隔 20~40 个打印点抽样 `g_traj[]`，分别绘制"速度-时间"与"高度-时间"两条字符曲线（`*` 条形按各自最大值归一化），关机点所在行用 `#` 标注并打印数值。
- 输入：`g_traj[]`。
- 输出：屏幕两条字符曲线。

**M9 弹道数据报表模块**（源文件 `Report.c`）

- 功能简介：按可配置间隔（如每 0.5 s 一行）把"时刻、质量、推力、加速度、速度、高度"表写入 `traj_report.txt`，文件头写参数清单，文件尾写 M7 特征汇总。
- 输入：`g_traj[]`、`g_vh`、特征数据。
- 输出：`traj_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读推力表 / 录入参数 / 插值自测 / 加速度自测 / 运行仿真 / 特征提取 / 曲线显示 / 输出报表 / 退出），`do-while + switch` 调度；状态约束：未读推力表与参数不得仿真。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1~M9；状态约束：M3、M5 前必须完成 M1 与 M2；M7、M8、M9 前必须已运行 M5。

**数据流**：

```
thrust_curve.txt ─► M1 读入校验 ─► g_thr[] ─► M6 推力插值函数 ─┐
键盘参数 ───────► M2 录入 ─► g_vh ──────────► M3 加速度函数 ◄──┘
                                                   │
                              M4 单步梯形积分（预校-校正） ─► g_traj[i+1]
                                                   ▲
                              M5 仿真主循环（循环调用 M4）
                                                   │
                              M7 关机点特征 ◄──────┤
                                                   ▼
                              M8 字符曲线      M9 报表 traj_report.txt
```

模块间通过全局弹道数组 `g_traj[]` 与函数参数交换数据，`accel`、`thrustAt`、`stepForward` 三个接口编码前书面约定。

## 十、选做扩展

1. 步长对比实验：dt 取 0.5/0.2/0.05/0.01 s 各跑一遍，输出关机点速度与高度随步长变化的收敛表（只用循环重跑已有模块）；
2. 指数大气阻力：把常数密度改为 ρ=1.225·e^(-h/8500)（pow 函数已在课程运算符章节内），比较两种大气模型下的最大动压差异；
3. 多发动机对比：把 `thrust_curve.txt` 扩为多组曲线文件，循环对同一飞行器分别仿真，输出各方案关机点高度对比排名表（文件遍历 + 结构体数组 + 排序的综合运用）。
