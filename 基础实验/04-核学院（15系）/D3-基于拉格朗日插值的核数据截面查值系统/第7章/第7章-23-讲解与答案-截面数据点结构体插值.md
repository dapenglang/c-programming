## 二、预备知识：结构体数组与插值的结合（零基础阅读）

### 1. 问题是怎么来的

第 5 章用两个平行数组 `en[]`、`sig[]` 存截面表。虽然可行，但"能量和截面一一对应"这个关系只能靠**约定下标相同**来维持，代码里到处写 `en[i]`、`sig[i]` 两个下标，容易看错。

如果换用**结构体数组**，每个元素就是"**一个完整的数据点**"：

```c
struct SigmaPt { double e; double sigma; };   /* 一张“数据点卡”：能量 + 截面 */
struct SigmaPt tab[6];                         /* 一叠数据点卡 */
```

插值时只需针对 `tab[i]` 一张卡操作，取它的两个成员即可。这就是本题相对第 5 章的升级。

### 2. 结构体数组的初始化

初始化列表里，每个元素用一对花括号 `{能量, 截面}` 表示：

```c
struct SigmaPt tab[6] = {
    {0.025, 587.0},   /* tab[0] */
    {1.0,   250.0},   /* tab[1] */
    ...
};
```

**画成图**：

```
  tab[0]          tab[1]          tab[2]
+-------------+ +-------------+ +-------------+
| e   = 0.025 | | e   = 1.0   | | e   = 100.0 |
| sigma= 587  | | sigma= 250  | | sigma= 60   |
+-------------+ +-------------+ +-------------+
   一个元素 = 一个完整数据点，能量与截面永不分离
```

### 3. 插值公式怎么翻译到结构体成员

第 5 章的插值公式：

$$
\sigma = \sigma_i + \dfrac{(\sigma_{i+1}-\sigma_i)\,(E - E_i)}{E_{i+1} - E_i}
$$

把 \(E_i \to tab[i].e\)、\(\sigma_i \to tab[i].sigma\)、\(E_{i+1}\to tab[i+1].e\)、\(\sigma_{i+1}\to tab[i+1].sigma\)：

```c
sigma = tab[i].sigma + (tab[i+1].sigma - tab[i].sigma)
        * (e - tab[i].e) / (tab[i+1].e - tab[i].e);
```

**公式本身没变，只是每个符号都带上了"哪张卡、哪一栏"**。找区间的循环条件也照此翻译：`tab[i].e <= e && e <= tab[i+1].e`。

### 4. 用本例走一遍

**样例 1**：\(E=0.5\)，落在 `tab[0]`（0.025）与 `tab[1]`（1.0）之间。

- 比例 \((0.5-0.025)/(1.0-0.025)=0.487179\)；
- \(\sigma = 587 + (250-587)\times0.487179 = 422.82\) barn。

**样例 2**：\(E=10\)，落在 `tab[1]`（1.0）与 `tab[2]`（100.0）之间。

- 比例 \((10-1)/(100-1)=0.0909091\)；
- \(\sigma = 250 + (60-250)\times0.0909091 = 232.73\) barn。

与第 5 章结果一致，说明结构体数组只是换了个"装表的容器"，算法逻辑不变。

> **这个思想在综合实验中反复出现**：D3 截面数据点（能量+截面）、D4 温度节点（位置+温度）、D1 核素档案（名称+半衰期+活度）。**凡是"成对或多属性"的数据点，都该用结构体——然后用同一套遍历/插值/统计逻辑处理。**

## 三、解题思路

1. **定义类型与数组**：`struct SigmaPt { double e, sigma; };` 与 `struct SigmaPt tab[6] = {...};`；
2. **读入能量** `E`；
3. **遍历找区间**：`for (i = 0; i < N-1; i++) if (tab[i].e <= E && E <= tab[i+1].e) { ... break; }`；
4. **插值**：用结构体成员代入公式；
5. **输出**：`%.2f`。

## 四、参考代码

```c
#include <stdio.h>

/* 截面数据点：能量与截面打包成一张卡片 */
struct SigmaPt {
    double e;      /* 能量，eV */
    double sigma;  /* 截面，barn */
};

int main(void)
{
    const int N = 6;

    /* 结构体数组：6 个数据点的初始化列表 */
    struct SigmaPt tab[N] = {
        {0.025, 587.0},
        {1.0,   250.0},
        {100.0, 60.0},
        {1.0e4, 20.0},
        {1.0e5, 12.0},
        {1.0e6, 8.0}
    };

    double e;       /* 输入能量，eV */
    double sigma;   /* 查得截面，barn */
    int    i;

    scanf("%lf", &e);

    /* 默认取上端点，防止 E 恰为最大值时找不到区间 */
    sigma = tab[N - 1].sigma;

    /* 遍历结构体数组找区间并插值 */
    for (i = 0; i < N - 1; i++) {
        if (tab[i].e <= e && e <= tab[i + 1].e) {
            sigma = tab[i].sigma
                    + (tab[i + 1].sigma - tab[i].sigma)
                      * (e - tab[i].e) / (tab[i + 1].e - tab[i].e);
            break;
        }
    }

    printf("sigma = %.2f\n", sigma);
    return 0;
}
```

## 五、运行验证

|---|---|---|
| 0.5 | 区间 tab[0]-tab[1]，\(587-337\times0.48718=422.82\) | `sigma = 422.82` ✓ |
| 10 | 区间 tab[1]-tab[2]，\(250-190\times0.09091=232.73\) | `sigma = 232.73` ✓ |
| 1000 | 区间 tab[2]-tab[3]，\(60-40\times0.090909=56.36\) | `sigma = 56.36` ✓ |
| 1000000 | 恰为上端点，取 8.0 | `sigma = 8.00` ✓ |

结构体数组插值结果与第 5 章平行数组版本完全一致，证明"数据组织方式改了，算法不变"。

## 六、常见错误与讲解

**错误 1：初始化列表格式写错**

```c
struct SigmaPt tab[6] = {0.025, 587.0, 1.0, 250.0, ...};  /* 错：缺少每组的花括号 */
struct SigmaPt tab[6] = {{0.025, 587.0}, {1.0, 250.0}, ...};  /* 对 */
```

每个结构体元素的初值要用一对 `{}` 括起来，顺序与成员定义一致（先 `e` 后 `sigma`）。

**错误 2：成员访问写成 `tab.e[i]`**

```c
tab.e[i]        /* 错：tab 不是结构体、tab.e 不是数组 */
tab[i].e        /* 对：先取第 i 张卡，再取 e 栏 */
```

**错误 3：忘记处理端点**

与第 5 章相同，若 `E` 恰为表最大值，循环找不到区间，需预置 `sigma = tab[N-1].sigma` 兜底。

**错误 4：插值公式里成员取错行**

```c
(tab[i].sigma - tab[i].sigma)         /* 错：两端取了同一行，差值恒为 0 */
(tab[i + 1].sigma - tab[i].sigma)     /* 对：相邻两行 */
```

务必确认 `i` 与 `i+1` 分别对应区间的左右两端。
