# 第 4 章 练习 17　二分法函数化求解

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.6 非线性方程求解——二分法的函数化封装）

**场景来源**：综合实验 C8《冰区船舶浮力与吃水计算系统》（水声学院）——本练习是该实验中"平衡吃水方程二分求解"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

一个球形冰块漂浮在海面上，要求它的**吃水深度** $d$（浸没部分的高度）。漂浮的平衡条件是"浮力 = 重力"。对半径 $R$ 的球，浸没部分的体积是一个球缺：

$$
V(d) = \frac{\pi d^2 (3R - d)}{3}.
$$

平衡方程为

$$
\rho_w\,V(d) = \rho_i\,V_{\text{总}},\qquad V_{\text{总}} = \frac{4}{3}\pi R^3,
$$

其中冰密度 $\rho_i = 900\ \text{kg/m}^3$、海水密度 $\rho_w = 1025\ \text{kg/m}^3$。这是一个关于 $d$ 的三次方程，工程上常用**二分法**求解：只要区间两端函数值异号，就能不断对分、稳扎稳打地逼近根。本练习要把"方程函数 $f(d)$"与"二分求解器"分开封装。

## 二、任务要求

编写一个完整程序 `bisect_draft.c`：

1. 用常量存放 $\rho_i = 900$、$\rho_w = 1025$ 与 $\pi$；
2. 编写函数 `double f(double d, double R)`：返回平衡方程的残差

   $$
   f(d) = \rho_w\cdot\frac{\pi d^2(3R-d)}{3} - \rho_i\cdot\frac{4}{3}\pi R^3 ;
   $$

3. 编写函数 `double bisect(double R, double eps)`：在区间 $[0,\ 2R]$ 上用二分法求 $f(d)=0$ 的根——每次取中点 `m`，若 $f(a)\cdot f(m) \le 0$ 则把右端点移到 `m`，否则把左端点移到 `m`；直到区间长度 $b-a < \text{eps}$ 停止；每次对分令计数 `k` 加一；函数结束前按格式输出吃水与对分次数，并返回解；
4. `main` 读入半径 `R`，以 `eps = 1e-6` 调用 `bisect`；
5. **接口约定**：`f` 与 `bisect` 均只用参数与返回值通信，不使用全局变量；输出格式为 `draft = 吃水, n = 对分次数`（吃水保留 6 位小数）。

## 三、输入输出格式

**输入**：一行，一个实数 `R`（球半径，单位 m）。

**输出**：一行，格式为 `draft = 吃水深度, n = 对分次数`（吃水保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
1
```
输出：
```
draft = 1.563805, n = 21
```

**样例 2**

输入：
```
1.5
```
输出：
```
draft = 2.345708, n = 22
```

## 五、提示

- 球缺体积公式可通过积分得到：把球沿竖直方向切成薄圆盘，圆盘半径为 $\sqrt{R^2-(R-y)^2}$，从 $y=0$ 积到 $y=d$，即得 $V(d)=\dfrac{\pi d^2(3R-d)}{3}$；
- 区间端点取值：$d=0$ 时 $f=-\rho_i V_{\text{总}}<0$；$d=2R$ 时浮力等于排水力 $\rho_w V_{\text{总}}$，$f=(\rho_w-\rho_i)V_{\text{总}}>0$。**两端异号**是二分法能用的前提；
- 判据可用 `f(a, R) * f(m, R) <= 0` 决定保留哪一半；
- 区间长度每对分一次就减半，故对分次数约为 $\log_2\dfrac{2R}{\text{eps}}$，本题约 21～22 次。

**完成本练习后你将具备的能力**：理解二分法的收敛原理与适用前提、能把"方程"和"求解器"拆成两个函数、会为一个一元方程求根选择合适的方法——这是实验 C8 中"平衡吃水求解模块"的地基。
