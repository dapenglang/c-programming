# 第 4 章 练习 02　梯形面积计算函数

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计——分而治之、4.2 函数的声明、调用与参数传递）

**场景来源**：综合实验 C8《基于数值积分与二分法的碎冰冰块浮力吃水计算系统》（水声学院）——本练习是该实验中"淹没面积梯形积分"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

水声学院在模拟碎冰与结构物作用时，要计算冰块被水淹没部分的面积，进而求浮力与吃水。冰块横截面很不规则，工程上把它近似成一段段梯形，逐块求出面积再累加——这就是数值积分里的"梯形法"。本练习先把最基础的一步抽出来：**给定一个梯形的上底、下底和高，求它的面积**，并把它封装成一个函数。它是后续"多段梯形累加"的积木块。

## 二、任务要求

编写一个完整程序 `trap_area.c`：

1. 必须定义一个函数，**函数原型为**
   ```c
   double trap_area(double a, double b, double h);
   ```
   其中 `a` 为上底、`b` 为下底、`h` 为高，函数返回该梯形面积；
2. 三个形参都由主函数通过**实参**传入，函数内部只做计算并 `return`，不读键盘、不打印；
3. 主函数按顺序读入上底 `a`、下底 `b`、高 `h` 三个实数（单位：米），调用 `trap_area` 求面积；
4. 输出面积，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，三个实数 a、b、h，用空格分隔（单位：米），均非负。

**输出**：一行，按格式 `area = 结果` 输出，保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2.0 3.5 1.2
```
输出：
```
area = 3.3000
```

**样例 2**

输入：
```
1.6 1.6 0.8
```
输出：
```
area = 1.2800
```

## 五、提示

梯形面积公式：

$$
S = \frac{(a + b)\,h}{2}
$$

当 $a=b$ 时梯形退化为矩形，$S = b h$，可用样例 2 校验。函数的三条形参与主函数里三个实参按**位置一一对应**：第一个实参进 `a`，第二个进 `b`，第三个进 `h`，顺序不能错。

**完成本练习后你将具备的能力**：理解形参与实参的位置对应关系、多参数函数的定义与调用、值传递的过程，以及"一个函数只做一件事"的模块化习惯——这是实验 C8 梯形积分和后续所有积分模块的基础单元。
