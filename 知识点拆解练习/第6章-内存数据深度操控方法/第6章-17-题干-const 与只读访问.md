# 第 6 章 练习 17　const 与只读访问

**对应章节**：6 内存数据深度操控方法（6.2 指针变量——用 const 修饰指针，实现只读访问）

**场景来源**：综合实验 C9《基于二维网格统计的冰压力场分析与可视化系统》（水声学院）——本练习是该实验中"压力剖面只读统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

在压力场系统里，同一批测点数据往往要被好几段代码轮流使用：这里算个总和，那里画个图，后面还要再做归一化。为了安全，凡是"只负责读、不负责改"的函数，都应该**明确声明自己不会改动数据**——这样既能防止函数内部手误写坏原始数据，也能让调用者放心地把数据交给它。C 语言用 `const` 给指针加一把"只读锁"：`const double *a` 表示"通过 `a` 只能读、不能写"。本练习编写一个带 `const` 保护的只读求和函数，并验证原始数据在调用后毫发无损。

## 二、任务要求

编写一个完整程序 `const_readonly.c`：

1. 主函数读入测点数 `n`（题目保证 $1 \le n \le 50$），再读入 `n` 个压力值存入 `double a[50]`；
2. 编写函数，其原型为 `double sum_readonly(const double *a, int n);`，其中形参被 `const` 修饰，**只能读取、不能修改**数组元素，函数返回所有元素之和；
3. 主函数输出总和 `sum`（保留 4 位小数），再按原顺序重新输出整个数组（每个保留 2 位小数、空格分隔），用以验证数据未被函数改动。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（空格分隔）。

**输出**：第一行 `sum = <总和>`（保留 4 位小数）；第二行 `n` 个实数值（各保留 2 位小数、空格分隔）。

## 四、样例

**样例 1**

输入：
```
3
101.5 102.3 99.8
```
输出：
```
sum = 303.6000
101.50 102.30 99.80
```

**样例 2**

输入：
```
4
1 2 3 4
```
输出：
```
sum = 10.0000
1.00 2.00 3.00 4.00
```

## 五、提示

- 形参写 `const double *a`，含义是"`a` 指向的内容只读"：函数里写 `a[i] = ...` 或 `*(a + i) = ...` 都会被编译器直接报错拦住；
- 因为不修改，遍历既可用下标 `a[i]`，也可用指针 `*(a + i)`；
- `const` 不改变"指针本身能不能改"：`double * const p` 是"指针自身只读"，`const double *p` 是"所指内容只读"，二者不同（见常见错误）。
- 求和公式：$S = \sum_{i=0}^{n-1} a_i$。

**完成本练习后你将具备的能力**：认识 `const` 修饰指针的几种写法与语义、会用只读指针表达"函数只读不写"的接口契约、能借助编译器提前发现越权修改——这是编写可靠数据处理函数的必备习惯。
