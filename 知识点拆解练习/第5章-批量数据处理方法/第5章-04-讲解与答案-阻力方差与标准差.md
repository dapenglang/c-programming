## 二、预备知识：方差与标准差的基本原理（零基础阅读）

### 1. 问题是怎么来的

平均值只回答"数据整体在哪个水平"，不回答"数据偏离这个水平有多厉害"。两段均值相同的载荷序列，一段平稳、一段剧烈波动，对结构的威胁完全不同。工程上用**偏差** $x_i - \bar{x}$ 度量单个数据的偏离，但 $n$ 个偏差直接相加恒等于 0（正负抵消），必须先取绝对值或平方再平均。取平方的方案就叫**方差**——它保证正负偏差都贡献正数，且放大了大偏差的影响，更符合工程直觉。

### 2. 公式是怎么形成的

总体方差的定义：

$$
\sigma^2 = \frac{1}{n}\sum_{i=0}^{n-1}(x_i - \bar{x})^2
$$

用大白话读就是四步：**① 算出均值 $\bar{x}$；② 每个数据减去均值得偏差；③ 每个偏差自乘（消去正负号）；④ 全部加起来除以 $n$**。标准差是方差的算术平方根：

$$
\sigma = \sqrt{\sigma^2}
$$

开方的目的是把量纲还原回原数据的单位（方差的单位是 kN²，标准差才是 kN），使指标可与原始数据直接比较。

### 3. 为什么必须遍历两遍

观察公式：② 里的 $\bar{x}$ 本身是**全部数据**的平均。当程序还在读第 3 个数据时，$\bar{x}$ 根本不存在，②③ 无从谈起。所以流程天然分两个阶段：

- 第一遍：读完并累加，得到 $\bar{x}$；
- 第二遍：重新从头扫数组，逐个算 $(x_i - \bar{x})^2$ 累加。

**数据必须事先完整存进数组**，第二遍才有东西可扫——这正是"数组 vs 读一个丢一个"的分水岭，也是本题放在第 5 章的根本原因。若用第 3 章的做法（不存数组），第一遍结束数据已全部丢失，题目就做不出来了。

### 4. 代入本例走一遍

样例 1 的数据：14.0, 16.0, 15.0, 17.0, 18.0。

- 第一遍：$\bar{x} = (14+16+15+17+18)/5 = 80/5 = 16.0$；
- 第二遍：偏差为 $-2,\, 0,\, -1,\, 1,\, 2$；平方为 $4,\, 0,\, 1,\, 1,\, 4$；累加得 10；
- 方差 $\sigma^2 = 10/5 = 2.0$；标准差 $\sigma = \sqrt{2} \approx 1.4142$。

### 5. 编程时怎么翻译

两个阶段各是一个普通的累加循环，唯一的新东西是第二遍的累加项是**表达式**而非元素本身：`s2 += (r[i] - avg) * (r[i] - avg);`。开方调用库函数 `sqrt`，它是 `double` 进、`double` 出，写在 `printf` 里即可。

> **一个常见疑问**：有的教材用 $n-1$ 作分母（样本方差）。那是统计学中"用样本估计总体"的修正，本课程与实验 C7 统一采用总体方差（除以 $n$），照公式直译即可，考试与实验以 $n$ 为准。

## 三、解题思路

1. 读入 $n$ 与数组——与练习 01 相同；
2. 第一遍循环累加 `sum`，循环外算 `avg = sum / n`；
3. 第二遍循环累加 `s2 += (r[i]-avg)*(r[i]-avg)`；
4. 循环外算 `var = s2 / n`，`std = sqrt(var)`；
5. 三个量都用 `%.4f` 输出。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>     /* sqrt 需要 */

int main(void)
{
    double r[100];      /* 阻力数组，单位 kN */
    double sum = 0.0;   /* 第一遍累加器 */
    double s2 = 0.0;    /* 第二遍累加器：偏差平方和 */
    double avg, var, std;
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &r[i]);

    /* 第一遍：求和、算均值 */
    for (i = 0; i < n; i++)
        sum += r[i];
    avg = sum / n;

    /* 第二遍：累加偏差平方（均值此时已确定） */
    for (i = 0; i < n; i++)
        s2 += (r[i] - avg) * (r[i] - avg);
    var = s2 / n;

    std = sqrt(var);

    printf("mean = %.4f\n", avg);
    printf("var  = %.4f\n", var);
    printf("std  = %.4f\n", std);

    return 0;
}
```

## 五、运行验证

**样例 1**（14.0 16.0 15.0 17.0 18.0）分步核算：

| 阶段 | 过程 | 结果 |
|---|---|---|
| 第一遍 | 14+16+15+17+18 = 80，80/5 | avg = 16.0000 |
| 第二遍 | 偏差 −2, 0, −1, 1, 2；平方 4+0+1+1+4 = 10；10/5 | var = 2.0000 |
| 开方 | $\sqrt{2}$ | std = 1.4142 |

**样例 2**（12.0 14.0 16.0 18.0）：

| 阶段 | 过程 | 结果 |
|---|---|---|
| 第一遍 | 60/4 | avg = 15.0000 |
| 第二遍 | 偏差 −3, −1, 1, 3；平方 9+1+1+9 = 20；20/4 | var = 5.0000 |
| 开方 | $\sqrt{5}$ | std = 2.2361 |

两样例程序输出与题干完全一致（`%.4f` 下 $\sqrt{2}=1.41421\ldots$ 截为 1.4142，$\sqrt{5}=2.23606\ldots$ 入为 2.2361）。

## 六、常见错误与讲解

**错误 1：一遍循环里边读边算方差**

```c
for (i = 0; i < n; i++) {
    scanf("%lf", &r[i]);
    s2 += (r[i] - avg) * (r[i] - avg);   /* 错：avg 尚未算出，用的是上次的垃圾值 */
}
```

均值未定就引用均值，是最典型的"阶段颠倒"错误。正确顺序永远是：**先算完均值，再开第二遍循环**。

**错误 2：第二遍循环引用了未初始化的累加器**

```c
double s2;          /* 错：没赋初值，累加从随机数开始 */
double s2 = 0.0;    /* 对：累加器必须清零 */
```

**错误 3：忘包含 math.h 或平方写错**

```c
s2 += (r[i] - avg) ^ 2;    /* 错：^ 是位运算异或，不是乘方 */
s2 += (r[i] - avg) * (r[i] - avg);   /* 对 */
/* 且文件开头必须有 #include <math.h>，否则 sqrt 声明缺失 */
```

**错误 4：整数除法吃掉小数**

```c
var = s2 / n;    /* 对：s2 是 double，除法按实数进行 */
```

若把 `s2` 声明成 `int`，`s2 / n` 将做整数除法，样例 1 会算出 2 而不是 2.0000 的问题虽被掩盖，样例 2 的 5.0000 也碰巧正确——但只要数据换一组（如平方和为 21），结果立即错为整数截断。坚持全程 `double`。
