# 题目 C1：基于拉格朗日插值的声速剖面计算系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行声速剖面（Sound Speed Profile，SSP）处理工具。它以海洋调查 CTD（温盐深仪）实测的"深度—声速"离散数据表为输入，用拉格朗日插值把离散测点构造成一条连续、光滑的声速曲线 c(z)，从而支持任意深度声速查询、每 10 m 一层标准剖面表生成、声速梯度与声跃层标注、剖面曲线绘制以及多站位剖面同图对比，最终把标准化剖面写成数据文件。

**解决什么重要问题**：海水中声速由温度、盐度和静压力共同决定，典型在 1450～1560 m/s 之间随深度剧烈变化。声波在不均匀介质中传播会发生折射，声线总是向声速小的一侧弯曲，因此声速剖面是几乎所有水声计算的"第一输入"。实测数据只有有限深度点的离散采样，不经过插值就得不到任意深度的声速，声线追踪、会聚区判断、作用距离预报都会产生显著偏差；剖面错误甚至会把"声影区"误判为可探测区。

**支撑哪些关键应用**：① 声呐作用距离预报与探测盲区分析；② 声线轨迹与声影区/会聚区计算；③ 水声通信链路的时延与多径估计；④ 潜艇利用表面声道隐蔽、反潜方利用深海声道探测；⑤ 多波束测深与高精度定位的声速改正。例如夏季近表层强跃层会形成声影区，使水面舰拖曳声呐的有效作用距离明显缩短，而是否出现跃层完全靠声速剖面判断。

**与专业培养的关联**：水声工程、声学专业的《水声学》《海洋声场计算》等课程均把声速剖面作为基础输入。本题让学生用 C 语言把课程 8.6 的拉格朗日插值直接用于真实海洋观测数据，完整走一遍"离散观测→连续场→声学结论"的建模链路，为后续专业课建立直观认识。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述声速剖面计算系统，完成一条完整的"文件读入→数值插值→剖面分析→结果输出"流水线。具体任务包括：设计站位实测数据文件格式并完成容错读入；对测点按深度排序、剔除重复与越界数据；实现拉格朗日插值函数并支持任意深度声速查询；生成每 10 m 一层的标准剖面表；计算相邻层声速梯度并标注正、负跃层；绘制以深度为纵轴的剖面字符图；对多个站位剖面进行同图对比；把处理结果写成规范数据文件；用菜单调度全部功能。

本题直接对应水声工程专业"把海洋环境参数转化为声学结论"的核心能力：声速剖面是声场计算的输入，学生在此过程中既练熟了文件、数组、函数、结构体等 C 语言要素，也提前认识了本专业最基础的一类数据。

## 三、数据来源与格式

**数据文件格式**：采用纯文本格式，第 1 行为格式标识，第 2 行为站位信息，其后每行一个测点。用 `fscanf(fp, "%s", ...)` 与 `fscanf(fp, "%lf", ...)` 即可逐个读入。

```
PROF
S1 22.50 118.30 6
0     1541.20
5     1540.60
10    1539.85
50    1532.50
500   1523.40
1500  1521.30
```

字段含义：第 1 行 `PROF` 为格式标识（Profile）；第 2 行为站号 `S1`、纬度 `22.50`（度）、经度 `118.30`（度）、测点数 `6`；其后为"深度(m) 声速(m/s)"，共"测点数"行。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 站号 | — | S1～S8 | 顺序编号 |
| 纬度 | 度 | 18.0～40.0 | 在该区间内近似均匀分布 |
| 经度 | 度 | 110.0～125.0 | 在该区间内近似均匀分布 |
| 测点数 | 个 | 30～80 | 浅层密、深层疏 |
| 深度 | m | 0～1500 | 0～100 m 每 5 m 一点，100～500 m 每 25 m 一点，500 m 以上每 50～100 m 一点 |
| 声速 | m/s | 1450～1560 | 典型三层剖面：混合层(0～50 m，约 1540 恒定)→主跃层(50～200 m 线性降至约 1490)→深海层(200 m 以下缓慢回升至约 1521)，叠加 σ=0.3 m/s 高斯噪声 |

**异常值与噪声注入方式**：① 从全部测点中随机选取 5%，声速叠加 ±(5～15) m/s 的粗差；② 随机插入 1～2 个与已有深度完全相同的重复测点；③ 随机令 1 个深度值超出 [0, 6000] 范围。以上异常用于检验 M2 校验模块的排序、剔重与边界检查功能。

**真实数据集（如有）**：
- 世界海洋图集 WOA18（温、盐度月平均，可按经验公式换算声速）：https://www.ncei.noaa.gov/products/world-ocean-atlas
- Argo 全球浮标温盐深剖面：https://argo.ucsd.edu/
- 教师亦可提供南海、东海 2～3 个站位的实测 CTD 转存文件。

## 四、数据结构设计

```c
#define MAX_PTS      256      /* 单站位最大测点数 */
#define MAX_STATIONS 8        /* 最大站位数 */

/* 单个测点：深度-声速 */
typedef struct {
    double depth;                 /* 深度，单位 m，取值 0~6000 */
    double c;                     /* 声速，单位 m/s，取值 1400~1600 */
} ProfilePoint;

/* 一个站位：一次 CTD 观测的完整剖面 */
typedef struct {
    char   name[16];              /* 站号，如 "S1" */
    double lat;                   /* 纬度，度 */
    double lon;                   /* 经度，度 */
    int    n;                     /* 实际测点数 ≤ MAX_PTS */
    ProfilePoint pts[MAX_PTS];    /* 按深度升序排列的测点数组 */
    double grad[MAX_PTS];         /* 相邻层声速梯度，单位 (m/s)/m */
    int    layerType[MAX_PTS];    /* 跃层标注：+1 正跃层 / -1 负跃层 / 0 均匀 */
} Station;

Station g_station;                /* 当前工作站位 */
Station g_all[MAX_STATIONS];      /* 多站位缓冲，供对比模块使用 */
int     g_nStation = 0;           /* 已读入的站位数 */
double  g_gridValues[MAX_PTS];    /* 等间隔剖面表结果 */
int     g_gridCount = 0;          /* 等间隔表的层数 */
```

全局数组放在文件作用域以避免栈溢出；模块之间只通过上述全局结构体与函数参数交换数据。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 深度-声速实测表读入模块**（源文件 `ProfIO.c`）
- 功能简介：打开剖面文本文件，读入格式标识、站号、经纬度与测点数，再循环读入全部"深度-声速"测点填入 `g_station.pts[]`；文件不存在或标识错误时给出明确提示并返回失败标志。
- 输入：文件路径（菜单输入，默认 `ssp_S1.txt`）。
- 输出：填充 `g_station`（name/lat/lon/n/pts）；返回成功/失败标志。

**M2 数据排序与校验模块**（源文件 `ProfCheck.c`）
- 功能简介：检查测点数是否越界、深度与声速是否在合理范围；按深度升序用冒泡排序，剔除深度完全重复的测点并计数；对越界测点做修正或剔除，打印"序号-深度-声速"清单。
- 输入：已读入的 `g_station`。
- 输出：排序去重后的 `g_station`；屏幕校验报告（重复数、越界数）。

### 第二部分：算法实现（4 个模块）

**M3 拉格朗日插值函数模块**（源文件 `Lagrange.c`）
- 功能简介：实现 `double lagrange(double z, ProfilePoint p[], int n)`，用 n 个测点对给定深度 z 求插值声速；为抑制测点较多时的高阶插值振荡，先按深度区间选取 z 附近最近的 4～6 个测点（局部化插值）再套用公式。
- 输入：深度 z、测点数组、测点数。
- 输出：插值声速 c(z)。

**M4 任意深度声速交互查询模块**（源文件 `Query.c`）
- 功能简介：提示用户输入深度并校验其落在剖面测深范围内，调用 M3 返回该深度声速；循环查询直到用户输入 -1 结束，逐条记录查询日志。
- 输入：用户输入的深度值序列。
- 输出：屏幕查询结果；查询日志数组。

**M5 等间隔剖面表生成模块**（源文件 `Grid.c`）
- 功能简介：从最小深度到最大深度按步长 10 m 遍历，对每个深度调用 M3 插值，结果存入 `g_gridValues[]` 并记录层数。
- 输入：`g_station`、步长（默认 10 m）。
- 输出：`g_gridValues[]`；`g_gridCount`。

**M6 声速梯度计算模块**（源文件 `Grad.c`）
- 功能简介：对等间隔表逐层差分求梯度 g_i = (c_{i+1} − c_i)/步长，填入 `grad[]`；按阈值（|g| ≥ 0.02 (m/s)/m）标注正跃层(+1)、负跃层(−1)或均匀(0)。
- 输入：`g_gridValues[]`、层数。
- 输出：`g_station.grad[]`、`g_station.layerType[]`；屏幕跃层统计（正/负跃层起止深度）。

### 第三部分：数据输出（4 个模块）

**M7 声速剖面字符画模块**（源文件 `Plot.c`）
- 功能简介：以深度为纵轴（自上而下加深）、声速为横轴，把剖面点映射到宽 60 列的字符网格上，用 `*` 描点绘制剖面曲线；横轴自动缩放到当前站位的声速范围。
- 输入：`g_station.pts[]` 或 `g_gridValues[]`。
- 输出：屏幕剖面字符画。

**M8 多站位对比模块**（源文件 `Compare.c`）
- 功能简介：把已读入的多个站位（`g_all[]`）剖面按统一深度轴、统一声速轴绘制在同一张字符图上，不同站位用字符 `1`～`8` 区分，并输出各站位在关键深度（0/50/100/500/1000 m）的声速对照表。
- 输入：`g_all[]`、`g_nStation`。
- 输出：屏幕对比字符图与对照表。

**M9 剖面数据文件输出模块**（源文件 `ProfIO.c`）
- 功能简介：把排序后的原始测点、等间隔剖面表与梯度/跃层标注写为结果文件 `ssp_<站号>_out.csv`（列为：深度, 声速, 梯度, 跃层类型）。
- 输入：`g_station`、`g_gridValues[]`。
- 输出：结果 CSV 文件；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读剖面/校验/查询/生成标准表/算梯度/画剖面/多站位对比/输出/退出），用 `do-while + switch` 调度 M1～M9；用状态标记约束"必须先成功读入剖面才能处理"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1～M9，循环直至选择退出；状态标记 `g_loaded` 约束"未成功读入剖面不得进行后续处理"。M2 结束后 `g_station` 即为可用剖面，M3～M9 均以它为输入。

**数据流**：

```
剖面文件 ─► M1 读入 ─► g_station.pts[] (测点数组)
                           │
                           ▼
                    M2 排序 / 剔重 / 越界检查
                           │
        ┌──────────────────┼───────────────────┐
        ▼                  ▼                   ▼
   M3 拉格朗日插值    M5 等间隔剖面表生成   M6 声速梯度计算
        │                  │                   │
        ▼                  ▼                   ▼
   M4 任意深度查询    g_gridValues[]      grad[] / layerType[]
        └──────────────────┼───────────────────┘
                           ▼
        ┌──────────────────┼─────────────────┐
        ▼                  ▼                 ▼
   M7 剖面字符画    M8 多站位对比    M9 剖面数据文件输出
                           │
                           ▼
                     M10 主控菜单调度
```

所有模块仅通过 `g_station`、`g_gridValues` 及函数参数交换数据，函数接口在编码前书面约定。
