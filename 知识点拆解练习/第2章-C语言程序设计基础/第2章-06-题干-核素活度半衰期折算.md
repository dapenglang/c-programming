# 第 2 章 练习 06　核素活度半衰期折算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 D1《基于指数衰减模型的放射性核素活度计算系统》（核学院）——本练习是该实验中"活度计算模块"的最小实现。

**建议用时**：20 分钟

## 一、应用场景

放射性核素会自发衰变，活度随时间按指数规律下降。核工程里描述衰变最常用的参数是**半衰期** $T$：经过一个半衰期，活度恰好减半。

存放放射性废物时要估算：某核素放了 $t$ 天后，活度还剩原来的百分之几？实验 D1 的"活度计算模块"核心就是这个折算。例如 Co-60 半衰期约 5.27 天，衰变 10.54 天（正好两个半衰期）后，活度应降为原来的 $1/4$。本题就把这个"知道半衰期和天数、折算活度比"的过程写成程序。

## 二、任务要求

编写一个完整程序 `decay_ratio.c`：

1. 从键盘读入**半衰期** `T`（单位：天）和**经过的天数** `t`（单位：天），均为 double 类型，**题目保证 T > 0 且 t ≥ 0**，因此本程序不需要判断分支；
2. 按公式 $A/A_0 = 2^{-t/T}$ 计算剩余活度比 `ratio`，再换算成百分数 `percent`；
3. 按规定格式输出活度比与百分数，均保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，两个实数，依次为半衰期 T 与经过天数 t（天），数之间以空格分隔。

**输出**：两行，第一行按 `ratio = 结果` 输出活度比，第二行按 `percent = 结果 %` 输出百分数，结果均保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
8 24
```
输出：
```
ratio = 0.1250
percent = 12.5000 %
```

**样例 2**

输入：
```
5.27 10.54
```
输出：
```
ratio = 0.2500
percent = 25.0000 %
```

## 五、提示

一个半衰期活度减半，$k$ 个半衰期就剩 $2^{-k}$，其中 $k = t/T$：

$$
A/A_0 = 2^{-k} = 2^{-t/T}
$$

C 语言没有"乘方运算符"，求幂要调用**系统数学函数** `pow`，用法为 `pow(2.0, -t / T)`，并在文件开头 `#include <math.h>`。

**完成本练习后你将具备的能力**：理解半衰期与幂运算的关系、正确调用系统数学函数求幂、把指数衰减这一核工程基础模型翻译成代码——这是实验 D1 活度计算链的起点。
