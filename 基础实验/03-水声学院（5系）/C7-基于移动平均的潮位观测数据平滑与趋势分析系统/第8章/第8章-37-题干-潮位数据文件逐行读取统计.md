# 第 8 章 练习 37　潮位数据文件逐行读取统计

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：8 文件（8.1 文件的打开与关闭、8.2 文件的读写——fscanf/fgets、8.3 格式化读写、8.4 错误处理）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"潮位时序读入与数据有效性检查"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

潮位观测站每小时自动记录一次潮位（单位 m）。仪器偶尔会失灵，此时记录的不是数值，而是约定的**缺失标记 −9999**。观测数据以文本文件形式保存在观测站电脑上——分析程序要做的第一件事就是：**从文件里逐行读入数据，剔除缺失值，统计有效记录数、最高潮位、最低潮位与平均潮位**。

综合实验 C7 的 M1（潮位时序读入）与 M2（数据有效性检查）合起来就是这件事。本题模拟这个过程：给定潮位数据文件 `tide.txt`，读入并统计。

## 二、任务要求

编写一个完整程序 `tide_stat.c`：

1. 以**只读**方式打开文件 `tide.txt`（文件与程序在同一目录）；若打开失败（文件不存在），打印提示并返回；
2. 逐行读入潮位值（double，m），**直到文件末尾**；约定：`−9999` 是缺失标记，不计入有效数据；
3. 统计并输出（输出到屏幕）：
   - 总记录数（含缺失标记的行数）；
   - 有效记录数；
   - 最高潮位、最低潮位（保留 2 位小数）；
   - 有效潮位的平均值（保留 3 位小数）；
4. 关闭文件。

## 三、输入输出格式

**输入文件 `tide.txt`**：每行一个数，为一次潮位观测值（有效值或缺失标记 −9999），行数不定（至少 1 行，不超过 1000 行）。

**屏幕输出**（共 5 行）：

```
总记录数: 6
有效记录数: 5
最高潮位: 3.85
最低潮位: 2.35
平均潮位: 3.124
```

` tide.txt` 内容：

## 五、提示

- 读文件同样是四步曲：**打开 → 判断成功 → 读写 → 关闭**，只是打开模式换成 `"r"`；
- "读到文件末尾为止"的标准写法是**用 `fscanf` 的返回值控制循环**——它返回成功读入的字段数，读到末尾（或读不到数）时返回 `EOF`（即 −1）：
  ```c
  while (fscanf(fp, "%lf", &h) == 1) {
      /* 成功读到一个数，处理它 */
  }
  ```
- **"逐行读"的另一种写法**是用 `fgets` 先把一整行读进字符数组，再用 `sscanf` 从字符串里提取数值——本题两种方法都可以，`fscanf` 更简洁；
- 统计三件套：计数（`total++` / `valid++`）、求和（`sum += h`）、维护极值（`if (h > hmax) hmax = h;`）；
- 极值初始化：把**第一个有效值**当作最大、最小的初值，不要想当然初始化为 0——潮位恒为正，但反面（负值数据）在工程里很常见，用首值初始化永远安全；
- 平均值 = 有效数据和 ÷ 有效记录数，注意分母用 `valid`，且要防止除以 0（本题保证至少 1 个有效值）；
- **务必检查 `fopen` 返回值**——读文件时最常见的失败原因是文件不存在或放错了目录。

**完成本练习后你将具备的能力**：用 `"r"` 模式打开文件、用 `fscanf`（或 `fgets`）逐行读到文件末尾、在读入的同时完成计数/求和/极值统计并剔除缺失值——这些是实验 C7 中"数据读入与有效性检查模块"的地基。
