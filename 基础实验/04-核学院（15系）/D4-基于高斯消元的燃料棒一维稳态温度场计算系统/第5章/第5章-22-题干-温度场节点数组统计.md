# 第 5 章 练习 22　温度场节点数组统计

**所属综合实验**：D4（D4-基于高斯消元的燃料棒一维稳态温度场计算系统）

**对应章节**：5 数组与批量数据处理（5.1 一维数组的定义与初始化、5.2 数组元素的访问、5.3 数组与循环配合——求最值与均值）

**场景来源**：综合实验 D4《基于高斯消元的燃料棒一维稳态温度场计算系统》（核学院）——本练习是该实验中"对求得的一维节点温度序列做统计"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

核燃料棒在运行时，芯块中心温度可高达 1700 K 以上，而外表面被冷却剂带走热量、温度低得多。工程上把燃料棒沿径向（或轴向）离散成若干**节点**，每个节点对应一个温度值，得到一维**温度场**。

温度场计算系统（实验 D4）在求出各节点温度后，必须做统计：**最高温度在哪、多少度**（判断是否接近材料熔点），**平均温度**是多少（评估热应力）。这些统计要在**数组**上完成，是判断燃料安全性的关键一步。

## 二、任务要求

编写一个完整程序 `temp_field.c`：

1. 从键盘读入节点个数 `n`（整数，题目保证 \(2 \le n \le 50\)），再读入 `n` 个节点的温度（K，double），存入**一维数组**；
2. 用**循环**遍历数组，求出最高温度 `Tmax` 及其所在节点下标 `imax`、最低温度 `Tmin` 及其所在节点下标 `imin`、平均温度 `Tavg`；
3. 最高/最低温度保留 1 位小数输出，平均温度保留 2 位小数输出，节点下标从 0 开始计数；
4. 按下面规定的四行格式输出。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（温度，K），用空格分隔。

**输出**：四行，格式如下：
```
Tmax = xx.x at node i
Tmin = xx.x at node j
Tavg = xx.xx
```
其中 `i`、`j` 为下标（整数），温度保留 1 位小数；平均温度保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
10
1750 1620 1490 1360 1230 1100 970 840 710 580
```
输出：
```
Tmax = 1750.0 at node 0
Tmin = 580.0 at node 9
Tavg = 1165.00
```

**样例 2**

输入：
```
5
800 1200 1000 900 700
```
输出：
```
Tmax = 1200.0 at node 1
Tmin = 700.0 at node 4
Tavg = 920.00
```

## 五、提示

设数组为 `t[0..n-1]`，求最值的标准做法是"**先假定第 0 个元素是最值，再逐个比较更新**"：

$$
T_{\max} = \max_{0 \le i < n} t[i],\qquad I_{\max} = \arg\max_{0 \le i < n} t[i]
$$

平均值公式为

$$
T_{\text{avg}} = \frac{1}{n}\sum_{i=0}^{n-1} t[i]
$$

求最值时**别忘了一并记住下标**：每当下标 `i` 处的温度超过当前最大值，就把最大值和最大下标一起更新。求平均时先循环累加，最后再除以 `n`（注意除以实数 `n` 还是整数）。

**完成本练习后你将具备的能力**：用初始化/循环读入数组、用"假定最值 + 循环更新"求最值与位置、用循环累加求平均、在循环中同时维护值与其下标——这些是实验 D4 中"温度场结果统计模块"的地基。
