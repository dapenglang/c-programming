# 第 2 章 练习 14　碎冰场面积浓度计算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C10《基于随机模拟的碎冰场生成与碰撞频率估算系统》（水声学院）——本练习是该实验中"碎冰场面积浓度统计"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

碎冰场里并不是"全部是冰"，而是水面漂浮着大小不一的冰块，块与块之间还有开阔水域。工程上用**面积浓度**（area concentration）描述"冰有多密"：它等于**所有冰块的总面积**除以**整个计算域的面积**。浓度越接近 1，说明冰越满、越接近连续冰盖；浓度越小，说明越稀疏。

综合实验 C10 在给定海域内随机生成大量小冰块，并用蒙特卡洛方法估算船舶的碰撞频率；而面积浓度是刻画该碎冰场状态的核心指标之一。本练习把"总面积除以域面积、再折算成百分比"这一最小步骤抽出来，做成一个完整程序。

## 二、任务要求

编写一个完整程序 `ice_concentration.c`：

1. 从键盘读入**冰块总面积** $A_{ice}$ 和**计算域总面积** $A_{domain}$（单位均为 m²，`double` 类型）；
2. 计算面积浓度 $C = \dfrac{A_{ice}}{A_{domain}}$；
3. 输出浓度的小数值（保留 4 位小数）与对应的百分比（保留 2 位小数）。

## 三、输入输出格式

**输入**：一行，两个实数，依次为冰块总面积 $A_{ice}$ 和计算域总面积 $A_{domain}$（m²），用空格分隔。

**输出**：一行，按格式 `C = 小数值 (百分比%)` 输出，小数值保留 4 位小数，百分比保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
3600 10000
```
输出：
```
C = 0.3600 (36.00%)
```

**样例 2**

输入：
```
7250 10000
```
输出：
```
C = 0.7250 (72.50%)
```

## 五、提示

面积浓度的定义为：

$$
C = \dfrac{A_{ice}}{A_{domain}}, \qquad \text{百分比} = C \times 100\%
$$

在 `printf` 中输出百分号要写成 `%%`（两个百分号才会显示一个）。被除数与除数务必都是实数，避免整数除法把浓度算成 0。

**完成本练习后你将具备的能力**：把"比值"型物理量用实数除法算出、把一个比值同时以小数和百分比两种形式输出、正确书写 `printf` 中的转义百分号——这些是碎冰场统计、浓度分析类实验的常用操作。
