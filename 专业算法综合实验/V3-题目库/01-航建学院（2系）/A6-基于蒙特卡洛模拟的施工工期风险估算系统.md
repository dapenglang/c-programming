# 题目 A6：基于蒙特卡洛模拟的施工工期风险估算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套施工工期风险估算工具。系统读入关键线路上的工序清单（每道工序含乐观 a、最可能 m、悲观 b 三个工期估计），用蒙特卡洛方法对每道工序按三角分布随机抽取一个工期样本，沿关键工序链累加得到一次模拟的总工期；重复模拟 N 次（100~100000 次）后，把 N 个总工期样本按区间分桶统计频率、排序后取 P50/P80/P95 分位值，绘制工期分布直方图，并把风险报告写入文件。

**解决什么重要问题**：施工合同几乎都约定工期违约金，而工期受天气、材料供应、人员、地质等不确定因素影响本质上是随机变量——用单一"最可能工期"签合同风险极大。蒙特卡洛模拟通过成千上万次随机试验把"总工期的概率分布"算出来，直接回答业主与项目经理最关心的问题："按期完工的概率有多大？要在 80% 把握下应承诺多少天？"不解决该问题，投标报价与进度计划就只能是拍脑袋。这一"用随机模拟代替解析推导"的思想是现代工程风险分析的基石。

**支撑哪些关键应用**：① 工程投标中工期承诺与违约金条款的风险评估；② 施工组织设计中网络计划的 PERT 分析；③ 造价软件与进度管理软件（如 P6）的风险模块；④ 后续"工程项目管理""运筹学""概率统计"课程中风险分析与随机模拟方法的先导训练。

**与专业培养的关联**：土木工程施工组织是大三核心课，PERT 三点估计与工期概率化是其经典内容。本题目只需课程内的 rand 函数、循环、数组、排序与计数即可完整实现专业级风险分析，让学生体会"简单随机数 + 大量重复 = 概率分布"的计算思维，也为数值仿真类课程建立直觉。

## 二、题目任务与专业关联

本题目面向土木工程（施工管理方向）学生，模拟"投标前工期风险测算"场景。系统功能概述：① 读入工序清单文件；② 封装均匀随机数发生器并做均匀性自检；③ 按三角分布抽样每道工序工期；④ 单次模拟沿关键链累加；⑤ 循环 N 次记录总工期样本；⑥ 分桶统计频率、排序求分位值；⑦ 绘制分布直方图并输出风险报告。先导知识铺垫：三角分布抽样公式（半页）：记 r 为 [0,1) 均匀随机数，F=(m-a)/(b-a)；若 r<F 则 x=a+sqrt(r·(b-a)·(m-a))，否则 x=b-sqrt((1-r)·(b-a)·(b-m))。分位值定义：把 N 个样本升序排序，P80 即第 0.80×N 个样本值。全部知识不超过课程 3.3 循环、5.5 排序与 2.3 运算符。

## 三、数据来源与格式

**数据文件：工序清单**（`tasks.txt`，按关键工序链顺序排列）

```
工序号,工序名,乐观a(天),最可能m(天),悲观b(天)
1,施工准备,5,7,12
2,基坑开挖,10,14,22
3,桩基施工,18,25,40
4,承台及底板,12,16,26
5,主体结构1-5层,30,38,55
6,主体结构6-10层,28,36,52
7,屋面工程,8,10,16
8,外装饰工程,20,28,45
9,机电安装,15,20,32
10,竣工验收,4,5,8
```

字段含义：乐观工期 a 取值 2~40 天（一切顺利时的最短工期）；最可能 m 取值 a<b 且 a<m<b；悲观工期 b 取值 5~60 天（受雨季、材料供应等影响的最长工期）；约束 b-a ≥ 4 且 m 位于区间内。

**仿真数据生成规则**：
- 生成 8~12 道工序：覆盖土建全流程（可参照上表或按教师给的另一项目模板），a 取整数值，m=a+(0.3~0.5)(b-a)，b 按 m 的 1.4~1.8 倍取整；
- 异常注入：在工序 5 故意写 `5,主体结构1-5层,30,55,38`（m 大于 b 的录入颠倒）、工序 7 写 `7,屋面工程,8,10,10`（b-a=0 退化），用于训练读入模块的三点关系校验；
- 工期取整数天，报告输出保留 1 位小数。

**真实数据集**：无必需公开数据集；三点估计的取值可参照《建设工程施工组织设计》教材例题与当地定额工期（如《全国统一建筑安装工程工期定额》），报告中注明来源。

## 四、数据结构设计

```c
#define MAX_TASK 30        /* 最大工序数 */
#define MAX_SIM  100000    /* 最大模拟次数 */
#define MAX_BIN  30        /* 频率分布最大桶数 */

/* 单道工序（三点估计） */
struct Task {
    int    id;             /* 工序号 1~30 */
    char   name[24];       /* 工序名，≤23 字符 */
    int    a;              /* 乐观工期 天，2~40 */
    int    m;              /* 最可能工期 天，a<m<b */
    int    b;              /* 悲观工期 天，5~60 */
    int    valid;          /* 三点关系校验标志 1/0 */
};

/* 全局数据 */
struct Task g_task[MAX_TASK];
int    g_taskCnt;          /* 工序数 */
long   g_simN;             /* 模拟次数 100~100000 */
unsigned int g_seed;       /* 随机种子 */

double g_total[MAX_SIM];   /* 每次模拟的总工期样本（天） */
int    g_bin[MAX_BIN];     /* 各区间频次计数 */
double g_binLow[MAX_BIN];  /* 各桶左端点 天 */
int    g_binCnt;           /* 桶数 */
double g_p50, g_p80, g_p95;/* 分位值 */
```

内存提示：`g_total` 为 100000 个 double，约 0.8 MB，须定义为全局数组避免栈溢出——本身就是"变量存储属性"知识点的活教材。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 工序清单文件读入模块**（源文件 `TaskIO.c`）

- 功能简介：跳过表头逐行读入工序三点估计；校验 a<m<b 与 b-a≥4（对注入的 m>b、b=a 两条异常打印"工序 X 三点估计非法，已跳过"）；交互输入模拟次数 N（100~100000）与随机种子；输出清单摘要。
- 输入：`tasks.txt`、键盘 N 与种子。
- 输出：`g_task[]`、`g_taskCnt`、`g_simN`、`g_seed`；屏幕摘要。

**M2 随机数发生器封装模块**（源文件 `RandUtil.c`）

- 功能简介：封装 `void randInit(unsigned seed)` 与 `double rand01(void)`（返回 [0,1) 均匀随机数，内部 srand/rand 换算）；并提供均匀性自检函数：生成 10000 个随机数按 10 个区间分桶统计，打印各桶频次，偏差超过 15% 时提示检查。
- 输入：种子。
- 输出：随机数接口；屏幕均匀性自检表。

### 第二部分：算法实现（5 个模块）

**M3 三角分布抽样模块**（源文件 `Sample.c`）

- 功能简介：实现 `int sampleTask(const struct Task *p)`：按三角分布抽样公式返回该工序的一个工期样本（整数天）；提供对单道工序抽 1000 次的统计自测，打印样本最值、均值与频率最高的取值，供学生观察抽样分布形态。
- 输入：工序指针、随机数接口。
- 输出：工期样本（天）；自测统计。

**M4 单次模拟工期累加模块**（源文件 `SimOnce.c`）

- 功能简介：实现 `double simulateOnce(void)`：对全部有效工序依次调用 M3 抽样并累加，返回一次模拟的总工期；打印单次模拟的逐工序抽样明细（供调试与演示）。
- 输入：`g_task[]`。
- 输出：总工期样本（天）。

**M5 N 次模拟主循环模块**（源文件 `SimMain.c`）

- 功能简介：调用 randInit 后循环 g_simN 次执行 M4，把每次总工期存入 `g_total[]`；每 10000 次打印进度；统计样本最值与均值。
- 输入：`g_simN`。
- 输出：`g_total[]` 样本数组；屏幕进度与基本统计。

**M6 工期频率统计模块**（源文件 `Histogram.c`）

- 功能简介：取样本[min,max] 均分为 g_binCnt 个区间（桶宽自动取整到 1 天），清零后遍历样本分桶计数 g_bin[]；打印"区间-频次-频率"表。
- 输入：`g_total[]`。
- 输出：`g_bin[]`、`g_binLow[]`、`g_binCnt`；屏幕频率表。

**M7 分位值计算模块**（源文件 `Percentile.c`）

- 功能简介：用冒泡或选择排序把 `g_total[]` 升序排列，取第 0.50/0.80/0.95 位置样本值得 g_p50/g_p80/g_p95；再统计"不超过合同工期（交互输入）的样本比例"即按期完工概率；打印分位表与完工概率。
- 输入：`g_total[]`、合同工期。
- 输出：三个分位值、完工概率；屏幕结果。

### 第三部分：数据输出（3 个模块）

**M8 工期分布直方图字符画模块**（源文件 `CharPlot.c`）

- 功能简介：按 g_bin[] 频次以 `*` 密度画 25 行以内的直方图（按最大频次归一化），在 P50/P80/P95 所在区间行尾标注标记；带横轴刻度说明。
- 输入：分桶数据与分位值。
- 输出：屏幕字符直方图。

**M9 风险报告输出模块**（源文件 `Report.c`）

- 功能简介：把工序清单、模拟参数、样本统计（最值/均值/标准差）、频率表、分位值、合同工期完工概率与结论建议写入 `risk_report.txt`。
- 输入：全部全局数据。
- 输出：`risk_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读工序清单 / 随机数自检 / 单工序抽样自测 / 单次模拟演示 / N 次模拟 / 频率统计 / 分位与概率 / 直方图 / 风险报告 / 退出），`do-while + switch` 调度；状态约束：未读清单与未做模拟不得统计输出。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1~M9；状态约束：M3~M9 前必须完成 M1；M6、M7 前必须已运行 M5；随机种子在 M5 开头一次性初始化保证可复现。

**数据流**：

```
tasks.txt ─► M1 读入校验 ─► g_task[] ─► M3 三角抽样 ─► M4 单次累加
种子 ───────► M2 随机数封装 ──┘              ▲        │
                                              │        ▼
                                   M5 N次主循环 ─► g_total[] 样本
                                                        │
                              M6 分桶 g_bin[]           M7 排序求分位/概率
                                   │                        │
                              M8 直方图          M9 报告 risk_report.txt
```

模块间通过全局样本数组 `g_total[]` 与桶数组交换数据，`rand01`、`sampleTask`、`simulateOnce` 三个接口编码前书面约定。

## 十、选做扩展

1. 模拟次数收敛实验：N 取 1000/5000/20000/100000 各跑一遍，输出 P80 随 N 的变化表，直观体会"样本越多估计越稳"（重复调用已有模块 + 简单汇总表）；
2. 工序重要性排序：逐道工序把 b 增加 5 天重跑模拟，记录 P80 的增量并排序，找出对总工期风险贡献最大的关键工序（循环实验 + 排序）；
3. 缓冲期设计器：给定目标完工概率（如 90%），用排序后的样本数组顺序查找最短工期承诺值，并与 P95 对比（排序与顺序查找的组合运用）。
