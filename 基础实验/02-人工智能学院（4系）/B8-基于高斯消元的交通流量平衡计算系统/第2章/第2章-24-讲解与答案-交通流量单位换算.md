## 二、预备知识：流量单位换算的基本原理（零基础阅读）

### 1. 问题是怎么来的

交通流量描述的是"单位时间内通过多少辆车"。**分母不同，数值就不同**：

- 以"小时"为分母：$1800$ 辆/小时，意思是每小时过 1800 辆车；
- 以"分钟"为分母：$30$ 辆/分钟，意思是每分钟过 30 辆车。

这两个说法描述的是同一个路况——因为 1 小时 = 60 分钟，$30 \times 60 = 1800$。**同一物理量，换一个时间单位，数值就要跟着变**，这就是单位换算要解决的问题。

### 2. 公式是怎么来的

既然 $1$ 小时 $= 60$ 分钟，那么"每小时 $q_{ph}$ 辆"摊到每一分钟，就是把它平均分成 60 份：

$$
q_{pm} = \frac{q_{ph}}{60}
$$

直觉检验：每小时的车分流到每分钟后，数值应该**变小**（因为分母从 1 小时缩小到 1 分钟，对应的时间变短了），所以是**除法**而不是乘法。

反过来，从辆/分钟回到辆/小时则要乘 60：

$$
q_{ph} = q_{pm} \times 60
$$

### 3. 用本例走一遍

**例 1**：$q_{ph} = 1800$ 辆/小时。

$$
q_{pm} = \frac{1800}{60} = 30\ \text{辆/分钟}
$$

**例 2**：$q_{ph} = 900$ 辆/小时。

$$
q_{pm} = \frac{900}{60} = 15\ \text{辆/分钟}
$$

结果 30 与 15 都是整数，但输出时按要求补足两位小数，写成 `30.00`、`15.00`。

### 4. 编程时怎么用它

编程只需一步：`qpm = qph / 60.0;`。两个注意点：

- 分母写成 `60.0`（实数），避免整数除法把 $1800/60$ 的结果以外的情形截断；
- 流量用 `double` 存放，即便输入是整数如 `1800`，`scanf("%lf",...)` 也会把它读成 `1800.0`。

> **这个思想在综合实验中反复出现**：B8 交通流量（辆/小时↔辆/分钟）、B2 采样率换算（Hz↔间隔秒）、B7 迭代收敛（量纲归一并比较），都是"改变分母、数值随之缩放"同一个套路。

## 三、解题思路

1. **确定常量**：每小时的分钟数，定义 `const double MIN_PER_HOUR = 60.0;`；
2. **确定变量**：输入流量 `qph`、输出流量 `qpm` 都用 `double`；
3. **读入**：`scanf("%lf", &qph);`；
4. **换算与输出**：`qpm = qph / MIN_PER_HOUR;`，用一条 `printf` 同时输出换算前后两个值，均用 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double MIN_PER_HOUR = 60.0;   /* 1 小时 = 60 分钟 */

    double qph;   /* 输入：流量，单位 辆/小时 */
    double qpm;   /* 输出：流量，单位 辆/分钟 */

    /* 读入以辆/小时计的流量 */
    scanf("%lf", &qph);

    /* 单位换算：辆/小时 -> 辆/分钟，除以 60 */
    qpm = qph / MIN_PER_HOUR;

    /* 同时输出换算前后的值，均保留 2 位小数 */
    printf("qph = %.2f辆/h, qpm = %.2f辆/min\n", qph, qpm);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 1800 | 1800 / 60 = 30 → 30.00 | `qph = 1800.00辆/h, qpm = 30.00辆/min` ✓ |
| 900 | 900 / 60 = 15 → 15.00 | `qph = 900.00辆/h, qpm = 15.00辆/min` ✓ |
| 60 | 60 / 60 = 1 → 1.00 | `qph = 60.00辆/h, qpm = 1.00辆/min` ✓ |
| 120 | 120 / 60 = 2 → 2.00 | `qph = 120.00辆/h, qpm = 2.00辆/min` ✓ |

$60$ 辆/小时对应 $1$ 辆/分钟，端值关系合理，说明换算正确。

## 六、常见错误与讲解

**错误 1：整数除法（最典型）**

```c
int qph;
qpm = qph / 60;     /* 危险：若两端都是 int，结果被截断 */
qpm = qph / 60.0;   /* 对：分母是实数 */
```

**错误 2：方向搞反，用了乘法**

```c
qpm = qph * 60;     /* 错：1800 × 60 = 108000，数值反而变大了 */
qpm = qph / 60.0;   /* 对：摊到更短的时间单位，数值变小 */
```

**错误 3：scanf 忘记取地址符或格式符不匹配**

```c
scanf("%lf", qph);      /* 错：缺少 &，程序异常 */
scanf("%d", &qph);      /* 错：qph 是 double，应用 %lf */
scanf("%lf", &qph);     /* 对 */
```

**错误 4：输出小数位数不符合要求**

```c
printf("qpm = %f\n", qpm);        /* 对但默认 6 位小数 */
printf("qpm = %.2f辆/min\n", qpm); /* 对：保留 2 位小数 */
```

题目明确要求保留 2 位小数，用 `%.2f`。注意中文字符"辆"可以直接写在格式串里。
