## 二、预备知识：残差符号为什么能指明"往哪边调"（零基础阅读）

### 1. 问题是怎么来的

求方程 $f(R) = 0$ 的根（这里是临界半径），人脑的困难在于：$R$ 是连续变化的，不可能一个个试遍。但有一个信息是**容易得到**的——**任意取一个 $R$，算出 $f(R)$ 是正还是负**。

如果知道了"$f$ 的正负"和"$R$ 该往哪边调"之间的对应关系，就能像玩"猜数字"游戏一样逐步逼近答案。**本题要建立的，正是这个"符号 → 方向"的对应表。**

### 2. 为什么 $f$ 随 $R$ 单调递增

先看 $f(R)$ 的两项：

- $B_m^2 = (k-1)/L^2$：只与材料有关，**与 $R$ 无关**，是一个常数；记作 $C$；
- $B_g^2 = (\pi/R)^2$：$R$ 在分母上，**随 $R$ 增大而减小**（练习 29 第 3 章已用表格证实）。

于是

$$
f(R) = C - B_g^2(R)
$$

"常数 减去 一个递减的量"，结果一定**随 $R$ 增大而增大**——$f$ 是 $R$ 的单调递增函数。这是本题全部推理的基石。

### 3. 方向判据表

有了单调递增这个事实，符号与方向的对应关系就唯一确定了：

| 残差 $f(R)$ | 含义 | 半径的相对位置 | 该往哪边调 |
|---|---|---|---|
| $f > 0$ | $B_m^2 > B_g^2$，几何曲率还不够大 | $R$ 已越过根，**偏大** | **减小** $R$ |
| $f = 0$ | $B_m^2 = B_g^2$ | 正好是根 | 不用调 |
| $f < 0$ | $B_m^2 < B_g^2$，几何曲率过大 | $R$ 还没到根，**偏小** | **增大** $R$ |

记忆口诀：**"$R$ 大 → $f$ 大"**。所以看到 $f$ 为正，就知道 $R$ 给大了。

**这个对应关系的用途**：把"求根"从"瞎猜"变成"有方向的搜索"。二分法（练习 24 第 4 章）做的正是——每算一次 $f$，就砍掉一半不可能的区间。

### 4. 用本例走一遍

样例 1：$k = 1.20$、$L = 5.0$、$R = 30.0$。

- 材料曲率（与 $R$ 无关）：$B_m^2 = (1.20-1)/5^2 = 0.20/25 = 0.008000$；
- 几何曲率：$B_g^2 = (\pi/30)^2 = (0.10472)^2 = 0.010966$；
- 残差：$f = 0.008000 - 0.010966 = -0.002966$。

$f < 0$ → 半径偏小 → 输出 `R too small` 与 `increase R`。

**物理核对**：$R$ 只有 30 cm，堆太小，中子泄漏太厉害（几何曲率大），达不到临界——所以该把堆做大。**结论与物理直觉一致。**

再看样例 2：$R = 120$ cm。

- $B_g^2 = (\pi/120)^2 = (0.0261799)^2 = 0.000685$；
- $f = 0.008000 - 0.000685 = 0.007315 > 0$ → 半径偏大 → `R too large`、`decrease R`。

**物理核对**：堆做太大，泄漏太少、曲率过低，属于"过临界"状态，可以缩小。**两例一负一正，恰好把方向判据的两支都验证到了。**

顺带可以得到一个很有用的估计：真正的临界半径应该介于 30 与 120 之间，而且 $f = 0$ 的位置靠近小半径那端（因为 $R=60$ 时 $f$ 已经是 +0.005258 的正数了）——**答案是 30～60 cm 之间某处，这正是二分法接下来要精确定位的区间。**

> **这个思想在综合实验中反复出现**：D10 的临界半径二分法、D6 的最优屏蔽厚度搜索、A7 的配比寻优，全部是"由目标函数符号确定调整方向"。**"符号即方向"是数值求根最朴素也最有用的思想。**

## 三、解题思路

1. **定义常量**：`const double PI = 3.14159265358979;`；
2. **读参数**：`scanf("%lf %lf %lf", &k, &L, &R);`；
3. **算三个量**：
   ```c
   Bm2 = (k - 1.0) / (L * L);
   Bg2 = (PI / R) * (PI / R);
   f   = Bm2 - Bg2;
   ```
4. **输出残差**：`printf("f = %.6f\n", f);`（`%.6f` 会自动带出负号）；
5. **三分支判定**：
   ```c
   if (f > 0.0)       { printf("R too large\n"); printf("decrease R\n"); }
   else if (f < 0.0)  { printf("R too small\n"); printf("increase R\n"); }
   else                 printf("critical\n");
   ```

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double PI = 3.14159265358979;     /* 圆周率，常量 */

    double k, L;        /* 增殖因子、扩散长度（cm） */
    double R;           /* 待检验的半径，cm */
    double Bm2, Bg2;    /* 材料曲率、几何曲率，cm^-2 */
    double f;           /* 残差 f = Bm2 - Bg2 */

    /* 读入 k、L、R */
    scanf("%lf %lf %lf", &k, &L, &R);

    /* 材料曲率：只与材料有关，与 R 无关 */
    Bm2 = (k - 1.0) / (L * L);

    /* 几何曲率：Bg2 = (PI/R)^2，平方用乘法 */
    Bg2 = (PI / R) * (PI / R);

    /* 残差：Bm2 固定，Bg2 随 R 递增而递减，故 f 随 R 递增 */
    f = Bm2 - Bg2;

    printf("f = %.6f\n", f);        /* 输出残差（自动带正负号） */

    /* 符号即方向：f > 0 说明 R 已越过根（偏大）；f < 0 说明 R 偏小 */
    if (f > 0.0) {
        printf("R too large\n");
        printf("decrease R\n");     /* 减小半径 */
    } else if (f < 0.0) {
        printf("R too small\n");
        printf("increase R\n");     /* 增大半径 */
    } else {
        printf("critical\n");       /* 恰好临界 */
    }

    return 0;
}
```

## 五、运行验证

| 输入 (k, L, R) | Bm2 | Bg2 | f = Bm2 − Bg2 | 程序输出 |
|---|---|---|---|---|
| 1.20 5.0 30.0 | 0.008000 | 0.010966 | −0.002966 | `f = -0.002966` / `R too small` / `increase R` ✓ |
| 1.20 5.0 120.0 | 0.008000 | 0.000685 | +0.007315 | `f = 0.007315` / `R too large` / `decrease R` ✓ |
| 1.20 5.0 60.0 | 0.008000 | 0.002742 | +0.005258 | `f = 0.005258` / `R too large` / `decrease R` ✓ |
| 1.20 5.0 50.0 | 0.008000 | 0.003948 | +0.004052 | `f = 0.004052` / `R too large` / `decrease R` ✓ |

**符号规律校验**：$R$ 从 30 增到 120，$f$ 从 $-0.002966$ 单调增到 $+0.007315$，**四行的结论依次是"偏小、偏大、偏大、偏大"**，与"$f$ 随 $R$ 递增"完全吻合。

**缩小临界区间**：由表中数据可知 $f(30) < 0$ 而 $f(50) > 0$，**临界半径必在 30 ～ 50 cm 之间**。这正是二分法第一步要用的区间（真值约 35.12 cm，练习 24 第 4 章会精确求出）。

## 六、常见错误与讲解

**错误 1：把残差的定义写反**

```c
f = Bg2 - Bm2;      /* 错：与约定相反，所有结论都会颠倒 */
f = Bm2 - Bg2;      /* 对：与题干定义一致 */
```

若定义反了，"$f>0$ 表示偏大"就会变成"$f>0$ 表示偏小"，**整个方向判据全错**。写代码前先在心里固定定义，并用手算样例 1 核对符号。

**错误 2：用 `^` 表示平方**

```c
Bg2 = (PI / R) ^ 2;            /* 错：^ 是位异或 */
Bg2 = (PI / R) * (PI / R);     /* 对 */
```

**错误 3：三分支写成两个平行的 if**

```c
if (f > 0.0)  printf("R too large\n");
if (f < 0.0)  printf("R too small\n");
/* 漏了 f == 0 的情况：此时什么都不打印，缺少“critical”输出 */
```

**建议用 `if / else if / else` 链**，让 `else` 兜住 $f = 0$（以及理论上可能出现的浮点零），避免漏分支。

**错误 4：方向判据记反**

```c
if (f > 0.0) printf("increase R\n");   /* 错：f>0 是半径偏大，应“减小” */
if (f > 0.0) printf("decrease R\n");   /* 对 */
```

记不住时用物理图像推：**堆太大 → 中子泄漏少 → 几何曲率小 → $B_g^2 < B_m^2$ → $f > 0$**，所以 $f > 0$ 对应"太大"。**让结论接受物理直觉的检查，比死记更可靠。**

## 七、与综合实验的衔接

- 实验 **D10（反应堆临界尺寸估算系统）**中，本练习是"二分法方向判据"的直接前身：真实求解器会先算 $f$ 在区间两端 $[R_{\min}, R_{\max}]$ 的符号，确认**异号**（即中间有根），然后在每次折半时用本练习的判据决定保留哪一半。**没有这个符号判据，二分法根本无法进行**；
- 与前面练习的衔接：练习 29（第 2 章）算 $B_m^2$（一个点），练习 29（第 3 章）算 $B_g^2$ 随半径递减的表（一串点），本练习把两者相减得到残差并作出方向判断——**这三题合起来就是完整的临界方程 $f(R) = 0$ 的"体检"**。后续练习 23、24（第 4 章）把这三个计算封装成函数并用二分法自动求根；练习 31（第 5 章）对不同 $k$ 做参数扫描；练习 29（第 7 章）用结构体组织材料参数；练习 28（第 8 章）把扫描结果写成文件。**从"判断一个点"到"自动找到根"，就是本练习到二分法的跃迁。**
