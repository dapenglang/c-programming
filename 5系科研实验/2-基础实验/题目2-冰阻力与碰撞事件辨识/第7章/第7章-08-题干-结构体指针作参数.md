# 第 7 章 练习 08　结构体指针作参数

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.4 结构体指针变量）

**场景来源**：综合实验 C7《冰载荷样本统计与载荷辨识系统》（水声学院）——本练习是该实验中"载荷样本单位批量换算（kN 转 N）"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

载荷辨识系统（实验 C7）采到的阻力样本以 kN 记录，而送入力学分析模块前必须统一换算成国际单位 N。样本存放在结构体数组中，换算要**成批、就地**完成：不是复制一份新数组，而是把原数组里每个样本的 force 成员原地改写。按练习 07 的结论——"修改原数据必须走指针"——批量修改的标准写法是：把数组首地址（结构体指针）作为参数传给换算函数，函数内用一个移动的结构体指针逐元素改写。这正是实验 C7 数据预处理模块的实现方式。

## 二、任务要求

编写一个完整程序 `unit_conv.c`：

1. 按下面的框架定义结构体类型（成员名不得改动）：

```c
struct Sample {
    int    no;      /* 样本编号 */
    double force;   /* 撞击阻力（输入为 kN，换算后为 N） */
};
```

2. 编写函数 `void toNewton(struct Sample *arr, int n);`：形参为结构体指针与个数，**函数内用移动指针 `p`（从 `arr` 走到 `arr + n`）把每个元素的 force 乘以 1000.0**，就地改写数组；
3. `main` 中读入 $n$（$1 \le n \le 10$）与 $n$ 条样本，调用 `toNewton` 后遍历输出换算结果；
4. 输出格式见样例。

## 三、输入输出格式

**输入**：第一行一个整数 $n$（$1 \le n \le 10$）；随后 $n$ 行，每行 2 个数据：样本编号（整数）、阻力（实数，kN），以空格分隔。

**输出**：$n$ 行，每行按 `编号 号：阻力 N` 输出，阻力保留 **2 位小数**（此时单位已是 N）。

## 四、样例

**样例 1**

输入：
```
3
1 12.5
2 8.3
3 15.2
```
输出：
```
1 号：12500.00 N
2 号：8300.00 N
3 号：15200.00 N
```

**样例 2**

输入：
```
4
5 9.9
6 7.25
7 11.2
8 3.6
```
输出：
```
5 号：9900.00 N
6 号：7250.00 N
7 号：11200.00 N
8 号：3600.00 N
```

## 五、提示

- 数组名本身就是首地址，调用直接写 `toNewton(a, n);`，**不加 `&`**；
- 移动指针写法：`struct Sample *p; for (p = arr; p < arr + n; p++) p->force *= 1000.0;`；
- `p < arr + n` 是循环条件——`arr + n` 是"末元素之后"的位置，指针比较在第 6 章学过；
- 换算后 main 里再输出，验证数组确实被函数改动了。

**完成本练习后你将具备的能力**：把结构体指针（数组地址）传给函数、用移动指针遍历并就地修改结构体数组——实验 C6/C7 中所有"批量改写数据"的模块都采用这一模式。
