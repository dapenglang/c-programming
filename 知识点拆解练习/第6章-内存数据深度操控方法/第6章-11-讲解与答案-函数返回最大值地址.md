## 二、预备知识：函数返回指针——"返回地址"比"返回值"更有用（零基础阅读）

### 1. 问题来源：一个 `return` 装不下两个答案

C 语言的函数就像一台自动售货机：投进参数，吐出一个返回值。**它一次只能吐出一样东西**（`return` 后面只能跟一个表达式）。可是"找最大值"这件事天然带着两个答案——最大值是多少、它在哪个位置。只返回数值，位置就丢了；只返回位置，还得让调用者自己再去取值。怎么办？

### 2. 关键认识：地址是一张"名片"，拿着它就能找到数据

内存可以想成一排带门牌号的抽屉，每个抽屉放一个数据。所谓"指针"，就是某个抽屉的**门牌号（地址）**。"返回地址"的美妙之处在于：地址本身就携带了位置信息，而顺着地址一解引用，又能拿到那里的数值——**一个地址，两个答案**。

```
main 中的数组 a（连续存放）：
            a[0]      a[1]      a[2]      a[3]      a[4]
   值：     12.5      30.2       8.4      25.7      21.0
   地址： 0x1000    0x1008    0x1010    0x1018    0x1020
                     ^
                     └── best 最终指向这里（a[1] 的地址 0x1008）
                         find_max 把这个地址 return 给 main

   main 拿到 p = 0x1008 后：
       *p    = 30.2                      ← 顺着地址取到"值"
       p - a = (0x1008-0x1000)/8 = 1     ← 地址差除以元素大小 = "下标"
```

### 3. 为什么这里返回地址是安全的

一个函数执行完，它内部定义的**普通局部变量**（自动变量）就随函数"退场"而销毁，它们占的内存被收回。此时如果把这些局部变量的地址返回出去，调用者拿到的就是一个"已经不存在的抽屉的门牌号"，再用它就出事了。

本题不踩这个坑：数组 `a` 是**在 `main` 里**定义的，`main` 一直活着，直到程序结束；`find_max` 只是照着 `a` 的地址去里面找，并返回 `a` 中某个元素的地址——这个地址指向的内存始终有效。**规则记牢：可以返回"调用者传进来的内存"的地址，绝不能返回"函数自己的局部变量"的地址。**

### 4. 编程翻译

- 形参写成 `double *a`，调用时把数组名 `a` 传进去（数组名就是首元素地址）；
- 遍历用 `for (p = a; p < a + n; p++)`，指针一路向前；
- 判优存取元素值：`if (*p > *best) best = p;`（比较的是 `*` 取出来的值！）；
- 返回 `best`（地址），而不是 `*best`（值）。

## 三、解题思路

1. **定接口**：函数返回类型写 `double *`，参数是数组首地址 `double *a` 与长度 `int n`；
2. **定初值**：把 `best` 先指向首元素 `a`，这样数组里任意一个元素都能和它比较；
3. **遍历**：用移动指针 `p` 从 `a` 走到 `a + n`（左闭右开，正好覆盖 n 个元素）；
4. **比较**：只比较元素值 `*p` 与 `*best`，谁大就把 `best` 改成谁的地址；
5. **回传**：`return best;`，主函数用 `*p` 输出值、用 `p - a` 输出下标。

## 四、参考代码

```c
#include <stdio.h>

/* 返回最大元素所在单元的地址；若最大值出现多次，返回第一个 */
double *find_max(double *a, int n)
{
    double *best = a;              /* 先假定首元素最大，记录它的地址 */
    double *p;                     /* 遍历用指针 */

    for (p = a; p < a + n; p++)    /* 用指针遍历 [a, a+n) */
        if (*p > *best)            /* 比较元素值，不是比较地址 */
            best = p;              /* 记下更大元素所在的地址 */

    return best;                   /* 返回地址，不是返回值 */
}

int main(void)
{
    double a[50];                  /* 测点压力序列，kPa */
    int n, i;
    double *p;                     /* 用来接住 find_max 返回的地址 */

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &a[i]);

    p = find_max(a, n);            /* 数组名 a 传进去，就是首元素地址 */

    printf("max = %.4f at index %d\n", *p, (int)(p - a));

    return 0;
}
```

## 五、运行验证

| 输入序列 | 手算过程 | 程序输出 |
|---|---|---|
| 12.5 30.2 8.4 25.7 21.0 | 最大值 30.2 在第 2 个位置（下标 1） | `max = 30.2000 at index 1` ✓ |
| 5.5 4.2 9.8 7.1 6.3 | 最大值 9.8 在下标 2 | `max = 9.8000 at index 2` ✓ |

> 地址类说明：程序内部 `p` 与 `a` 都是运行时才确定的地址，输出只展示 `*p`（峰值）与相对关系 `p - a`（下标），**不依赖具体地址数值**，因此换一台机器运行结果完全一致。

## 六、常见错误与讲解

**错误 1：返回局部数组的地址（最严重）**

```c
double *bad(double n) {
    double t[3];          /* 局部数组，函数一返回就被销毁 */
    ...;
    return t;             /* 错：返回已失效内存的地址 */
}
```
调用者拿到一个"门牌号已经不存在的抽屉"，稍后访问就是未定义行为（常见表现为输出乱码或程序崩溃）。**要返回数组，必须让数组定义在调用者一侧，函数只接收它的地址、返回它内部的地址。**

**错误 2：把"值"当成"地址"返回**

```c
return *best;   /* 错：返回的是 30.2 这个数值，main 拿不到下标 */
return best;    /* 对：返回 a[1] 的地址，值和位置都在手里 */
```
类型上也能看出问题：函数声明返回 `double *`，`*best` 是 `double`，会被编译器警告类型不匹配。

**错误 3：比较地址而不是比较值**

```c
if (p > best)        /* 错：比的是门牌号大小，与数据大小无关 */
if (*p > *best)      /* 对：加 * 才是取值比较 */
```
数组元素地址一定是递增的，`p > best` 恒为真，结果是最后一个元素被误判为最大。

**错误 4：下标算错**

```c
int idx = a - p;             /* 错：方向反了，得到负数 */
int idx = (p - a) * 8;       /* 错：指针减法已按元素个数计，不能再乘字节数 */
int idx = (int)(p - a);      /* 对：相隔几个元素就是下标 */
```
