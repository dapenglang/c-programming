## 二、预备知识：分支判断与区间的筛选顺序（零基础阅读）

### 1. 问题是怎么来的

"给一个数，看它落在哪一段"是程序里最常见的判断。灰度分档就是典型：有 256 个可能取值，要归到 3 个档里。程序不能同时写三个平级的判断——必须**一个一个问**，问到了就停。

### 2. 用本例走一遍

设三档边界：暗档上界 84，中档上界 169。程序的判断流程是：

- 第一步问："$g \le 84$ 吗？"若是，落暗档，结束；
- 若不是（此时已知 $g > 84$），第二步问："$g \le 169$ 吗？"若是，落中档，结束；
- 若还不是，说明 $g > 169$，落亮档。

**为什么第二个条件只写 $g \le 169$ 就够？** 因为走到第二步时，程序已经"知道"$g$ 不满足 $g \le 84$ 了。两个条件叠加，实际范围就是 $85 \le g \le 169$。这叫**筛选法**：每一步都把前面排掉的部分排除掉，不用重复写下限。

用数学语言写全，三档是：

$$
g \in [0,84] \Rightarrow \text{Dark};\quad g \in [85,169] \Rightarrow \text{Medium};\quad g \in [170,255] \Rightarrow \text{Bright}
$$

### 3. 编程时怎么用它

C 语言里用 `if-else if-else`：

```c
if (g <= 84)
    printf("Dark\n");
else if (g <= 169)
    printf("Medium\n");
else
    printf("Bright\n");
```

`else if` 天然表达了"否则再判断"，所以不必写 `85 <= g && g <= 169`。

> **这个思想在综合实验中反复出现**：B1 灰度分档、B3 投点区域判定、B9 任务优先级分级，都是"给一个数找它所在的区间"同一个套路。

## 三、解题思路

1. **读入**：一个整数 `g`，用 `scanf("%d", &g);`；
2. **第一档**：`if (g <= 84)` 输出 `Dark`；
3. **第二档**：`else if (g <= 169)` 输出 `Medium`（此时 $g>84$ 已自动排除）；
4. **第三档**：`else` 输出 `Bright`（此时 $g>169$ 必然成立）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int g;   /* 输入：像素灰度值，0~255 */

    /* 读入灰度值 */
    scanf("%d", &g);

    /* 按筛选顺序分三档：暗 / 中 / 亮 */
    if (g <= 84)              /* 0~84：暗 */
        printf("Dark\n");
    else if (g <= 169)        /* 此处 g 已 > 84，故表示 85~169：中 */
        printf("Medium\n");
    else                      /* 此处 g 已 > 169，故表示 170~255：亮 */
        printf("Bright\n");

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 50 | 50 ≤ 84，第一档 | `Dark` ✓ |
| 200 | 不 ≤ 84，不 ≤ 169，故亮档 | `Bright` ✓ |
| 84 | 84 ≤ 84，第一档（边界归暗） | `Dark` ✓ |
| 169 | 不 ≤ 84，但 ≤ 169，第二档（边界归中） | `Medium` ✓ |

边界值 84 归暗档、169 归中档，与题干区间定义一致。

## 六、常见错误与讲解

**错误 1：把 else if 写成独立的 if（最典型）**

```c
if (g <= 84)  printf("Dark\n");
if (g <= 169) printf("Medium\n");   /* 错：会重复输出，169 以内同时落两档 */
if (g > 169)  printf("Bright\n");
```

三个平级 `if` 会依次判断，$g = 50$ 时前两个都真，**同时输出 `Dark` 和 `Medium`**。必须用 `else if` 保证"只进一支"。

**错误 2：第二个条件写成完整区间但运算符写错**

```c
else if (85 <= g <= 169)   /* 错：C 语言不支持连写比较 */
else if (g > 84 && g <= 169)  /* 对，但用 else if 时本可省去 g > 84 */
else if (g <= 169)            /* 最简：正确 */
```

C 语言里 `85 <= g <= 169` 会先算 `85 <= g` 得 0 或 1，再拿这个结果与 169 比，永远为真，是隐蔽错误。

**错误 3：判断顺序颠倒，先判大区间**

```c
if (g <= 169) printf("Medium\n");   /* 错：暗档也被吞进中档 */
else if (g <= 84) printf("Dark\n"); /* 这行永远执行不到 */
```

筛选法要求"先从最窄/最极端的一端筛"，顺序颠倒会吞掉下面的分支。

**错误 4：用了赋值号 `=` 代替比较号 `==`**

```c
if (g = 84)      /* 错：这是赋值，表达式值为 84（非 0）恒为真 */
if (g <= 84)     /* 对 */
```

本题用的是 `<=`，不易犯错；但一旦需要判"等于"，务必写 `==`。
