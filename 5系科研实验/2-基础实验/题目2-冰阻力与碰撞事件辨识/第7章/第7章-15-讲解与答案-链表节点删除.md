## 二、预备知识：删除一个节点要做哪些事（零基础阅读）

### 1. 删除的本质：让前驱"绕过"目标

数组里删除一个元素，必须把它后面的元素统统前移一格；链表的思路完全不同——节点之间靠指针相连，只要让目标节点的**前一个节点**不再指向它、而是直接指向它的**后一个节点**，它就自然"脱离"了链。用图表示，删除中间节点 B：

```
改接前：  head ──► [A|●] ──► [B|●] ──► [C|NULL]
                     prev      cur

执行：    prev->next = cur->next;   /* 让 A 越过 B 指向 C */

改接后：  head ──► [A|●] ─────────► [C|NULL]
                     prev            （B 已脱离链条）

再执行：  free(cur);                /* 归还 B 占用的内存 */
```

一句话概括：**"改一根指针 + 释放一块内存"**。改指针负责把它摘下链，`free` 负责回收它的空间。两步都做才算彻底删除。

### 2. 为什么需要 prev 指针

要改的是"前驱的 `next`"，所以必须同时握着**目标节点 `cur`** 和**它的前驱 `prev`**。查找时让两个指针一前一后地同步前进：

```
初始：  prev = NULL , cur = head
        head ──► [A] ──► [B] ──► [C] ──► NULL ,  cur=A
前进一步：prev = cur; cur = cur->next;   /* prev 到 A，cur 到 B */
```

循环条件是"`cur` 还没到头、且 `cur->id != target`"，一旦停下来，要么找到了（`cur != NULL`），要么走到链尾没找到（`cur == NULL`）。

### 3. 头节点的特殊之处

如果目标恰好是**链头**，`prev` 就是 `NULL`——因为链头前面没有节点。这时不能写 `prev->next`（对空指针解引用会崩溃），而要**直接更新 `head`**：

```
删除头节点 A：
改接前：  head ──► [A|●] ──► [B|NULL]
                     cur , prev=NULL

执行：    head = cur->next;    /* head 直接跳到 B */
改接后：  head ──► [B|NULL]    然后 free(A)
```

所以删除代码用一个 `if (prev == NULL)` 把"删头"和"删中间 / 尾"分成两条路：

```c
if (prev == NULL)  head = cur->next;      /* 删头 */
else               prev->next = cur->next; /* 删中间或尾 */
free(cur);
```

### 4. 没找到怎么办

如果遍历到 `cur == NULL` 也没匹配上，说明链上没有这个编号，此时**什么也不该动**，只提示 `not found`。`malloc` 检查与 `free` 归还内存的纪律同前几题。

## 三、解题思路

1. **建链**：尾插法建立链表；
2. **查找**：`prev = NULL; cur = head;`，循环前进直到 `cur == NULL` 或 `cur->id == target`；
3. **分类删除**：若 `cur != NULL`，按 `prev` 是否为空走"删头"或"删中间"分支，再 `free(cur)`；
4. **处理未找到**：若 `cur == NULL`，输出 `not found` 并直接返回；
5. **输出剩余链**：遍历输出并计数；
6. **释放剩余节点**。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

struct IceLoad {
    int    id;
    double load;
    struct IceLoad *next;
};

int main(void)
{
    int n, i, id, target, count;
    double load;
    struct IceLoad *head = NULL, *tail = NULL, *p;
    struct IceLoad *cur, *prev;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {             /* 尾插建链 */
        scanf("%d %lf", &id, &load);
        p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
        if (p == NULL) { printf("malloc failed\n"); return 1; }
        p->id = id; p->load = load; p->next = NULL;
        if (head == NULL) head = tail = p;
        else { tail->next = p; tail = p; }
    }
    scanf("%d", &target);

    prev = NULL;                          /* 双指针查找目标 */
    cur = head;
    while (cur != NULL && cur->id != target) {
        prev = cur;
        cur = cur->next;
    }

    if (cur == NULL) {                    /* 没找到 */
        printf("not found\n");
        return 0;
    }
    if (prev == NULL) head = cur->next;   /* 删头节点 */
    else              prev->next = cur->next; /* 删中间或尾 */
    free(cur);                            /* 释放被删节点 */

    count = 0;                            /* 输出剩余链表 */
    p = head;
    while (p != NULL) {
        printf("%d %.2f\n", p->id, p->load);
        count++;
        p = p->next;
    }
    printf("count = %d\n", count);

    while (head != NULL) { p = head; head = head->next; free(p); }
    return 0;
}
```

## 五、运行验证

样例 1（删除中间节点 `102`）：链表 `101 → 102 → 103 → 104`，查找停下时 `prev` 指向 `101`、`cur` 指向 `102`，执行 `prev->next = cur->next` 后 `101` 直接指向 `103`：

```
删除前： [101] ──► [102] ──► [103] ──► [104] ──► NULL
删除后： [101] ─────────────► [103] ──► [104] ──► NULL
```

输出：

```
101 10.00
103 30.00
104 40.00
count = 3
```

与样例 1 一致。样例 2（删除链头 `201`）：查找停下时 `prev == NULL`、`cur` 指向 `201`，执行 `head = cur->next` 后：

```
删除前： head ──► [201] ──► [202] ──► [203] ──► NULL
删除后： head ─────────────► [202] ──► [203] ──► NULL
```

输出 `202 6.00`、`203 7.00`、`count = 2`，与样例 2 一致。补一个未找到的例子：输入编号 `999`，查找循环走到 `cur == NULL` 仍未匹配，输出 `not found`，链表不变。

## 六、常见错误与讲解

**错误 1：删除头节点时仍写 `prev->next`，空指针崩溃**

```c
prev->next = cur->next;   /* 错：prev 为 NULL 时崩溃 */
if (prev == NULL) head = cur->next;      /* 对：删头单独处理 */
else              prev->next = cur->next;
```
头节点没有前驱，`prev` 是 `NULL`。**凡是"删除"都要问一句：删的是不是头？** 这是链表删除最常见的故障点。

**错误 2：改接顺序写反，丢失后半条链**

```c
cur->next = prev;      /* 错：不是删除，是把链倒过来，还把后半段丢了 */
```
删除是让**前驱**越过当前节点（`prev->next = cur->next`），不是改当前节点的 `next`。改错对象，链会瞬间断裂或成环。

**错误 3：只改指针不 free，内存泄漏**

摘下的节点已经不在链上，但它的内存还在——若只写了 `prev->next = cur->next;` 而**忘了 `free(cur);`**，被删节点就一直占着内存。改指针负责"摘下链"，`free` 负责"还内存"，两步都要做。

**错误 4：没找到时误改链表**

```c
prev->next = cur->next;   /* cur 为 NULL 时执行，崩溃或破坏链 */
free(cur);
```
查找失败（`cur == NULL`）时必须先判断并返回，绝不能对空指针做改接。参考代码用一个 `if (cur == NULL)` 提前拦截。
