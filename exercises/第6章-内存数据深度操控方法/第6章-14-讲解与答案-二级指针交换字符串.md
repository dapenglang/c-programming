## 二、预备知识：指针本身也是变量，也有自己的地址（零基础阅读）

### 1. 第一层：一级指针里装的是"别人的地址"

```c
char a[50] = "alpha";
char *s1 = a;      /* s1 里装的是 a 的首字符地址 */
```

`s1` 是一个**一级指针变量**。它的"值"是地址（指向 `a`），它的"类型"是 `char *`。要记住：`s1` 这个名字代表的内容是**地址**，不是字符。想拿字符，得解引用：`*s1` 是 `'a'`。

### 2. 第二层：指针变量自己被放在哪儿？

指针变量 `s1` 既然是变量，它自己也得待在内存的某个抽屉里，也有自己的门牌号。对 `s1` 取地址，就得到它的门牌号：`&s1`，类型是 `char **`（指向指针的指针，也就是"二级指针"）。

```
   名字         抽屉里的内容           类型
 ─────────────────────────────────────────────────
   a[]         'a''l''p''h''a'\0      char[50]     ← 字符串本体
   0x3000 ──┐
            ▼
   s1          0x3000                 char *       ← 一级指针，指向 a
   （s1 自己住在 0x4000）
 ─────────────────────────────────────────────────
   b[]         'b''e''t''a'\0         char[50]
   0x5000 ──┐
            ▼
   s2          0x5000                 char *
   （s2 自己住在 0x4008）
 ─────────────────────────────────────────────────
   &s1 = 0x4000   →  形参 pa（char **，指向 s1）
   &s2 = 0x4008   →  形参 pb（char **，指向 s2）
```

### 3. 解引用"层数"要数清楚

- `pa`：二级指针，值是 `0x4000`；
- `*pa`：一次解引用 → 得到 `s1` 这个一级指针，值是 `0x3000`；
- `**pa`：两次解引用 → 得到字符 `'a'`。

一句话记法：**几个 `*` 就往下走几层**。本练习要修改的是"一级指针 `s1` 里装的地址"，所以操作在 `*pa` 这一层上完成，只需要一个 `*`。

### 4. 交换"指向"的两行半代码

```
   交换前： s1 → a("alpha")      s2 → b("beta")
   目标：   s1 → b("beta")       s2 → a("alpha")

   char *t = *pa;   /* t 暂存 s1 的值(0x3000) */
   *pa = *pb;       /* s1 改成 0x5000，指向 b */
   *pb = t;         /* s2 改成 0x3000，指向 a */
```

注意：字符串本体 `a`、`b` 一个字都没动，动的只是两个指针里的门牌号。这就是"交换指针"比"交换内容"快得多的原因——**搬三样东西 vs 搬整段文本**。

## 三、解题思路

1. **定数据**：字符数组 `a`、`b` 存内容，一级指针 `s1 = a`、`s2 = b` 指向它们；
2. **定接口**：`void swap_str(char **pa, char **pb);`，形参是"指针的地址"；
3. **定写法**：函数体三行，`t` 暂存 `*pa`，再两次赋值；
4. **定调用**：`swap_str(&s1, &s2);` 传指针的地址；
5. **定输出**：`printf("s1 = %s\n", s1);` 直接打印指针所指数组。

## 四、参考代码

```c
#include <stdio.h>

/* 交换两个字符指针所保存的地址：只换"指向"，不动"内容" */
void swap_str(char **pa, char **pb)
{
    char *t = *pa;    /* t 暂存 s1 原来的地址 */
    *pa = *pb;        /* 让 s1 指向 s2 原来指向的字符串 */
    *pb = t;          /* 让 s2 指向 s1 原来指向的字符串 */
}

int main(void)
{
    char a[50], b[50];       /* 两份文本的"本体" */
    char *s1 = a, *s2 = b;   /* 两个一级指针，分别指向它们 */

    scanf("%s", a);          /* 读入第一份 */
    scanf("%s", b);          /* 读入第二份 */

    swap_str(&s1, &s2);      /* 传"指针的地址"，即二级指针 */

    printf("s1 = %s\n", s1);
    printf("s2 = %s\n", s2);

    return 0;
}
```

## 五、运行验证

| 输入 | 交换后 s1 指向 | 交换后 s2 指向 | 程序输出 |
|---|---|---|---|
| alpha / beta | b = "beta" | a = "alpha" | `s1 = beta`、`s2 = alpha` ✓ |
| ICE-01 / ICE-02 | 第二份 "ICE-02" | 第一份 "ICE-01" | `s1 = ICE-02`、`s2 = ICE-01` ✓ |

> 验证要点：字符数组 `a`、`b` 的内容顺序始终没变；变的是 `s1`、`s2` 里保存的地址（`s1` 由 `a` 的地址变成 `b` 的地址，`s2` 相反）。程序内部地址由运行时决定，输出只反映"谁指向谁"，与具体地址数值无关。

## 六、常见错误与讲解

**错误 1：只写一层 `*`，改的成了形参自己**

```c
void swap_str(char **pa, char **pb) {
    char *t = pa;  pa = pb;  pb = t;   /* 错：换的是形参 pa、pb（地址的副本） */
}
```
形参 `pa`、`pb` 也是值传递得到的副本，交换它们对调用者的 `s1`、`s2` 毫无影响。必须写成 `*pa`、`*pb`，才是"顺着地址改到 `s1`、`s2` 本人"。

**错误 2：传参时漏写 `&`**

```c
swap_str(s1, s2);      /* 错：传的是一级指针 char *，形参却要 char ** */
swap_str(&s1, &s2);    /* 对：传指针变量的地址 */
```
前者编译会给出"实参与形参类型不兼容"的警告或错误，正是类型在提醒你：**要改谁，就传谁的地址。**

**错误 3：理解成"交换内容"，改用 `strcpy` 大搬家**

```c
strcpy(a, b); ...      /* 这是把字符串内容搬来搬去，本题不需要，而且更慢 */
```
本题要求利用指针的特性——**交换指向**。交换指针只改动两个地址，字符串一点没搬。

**错误 4：冒险去改字符串字面量的内容**

如果写成 `char *s1 = "alpha";`（指向只读的字面量），虽然本题只交换指针不会出事，但一旦有人试图 `s1[0] = 'A'` 就会崩溃。为稳妥，**用可读写的字符数组装内容，再用指针指向它**（如参考代码那样）。

## 七、与综合实验的衔接

- 在实验 **B10（文本相似度）**中，系统常维护一张"待比对文本表"，表里的每一项就是一个字符指针；需要调整比对顺序时，用二级指针交换指针即可，代价极小；
- 二级指针是本章 6.6 节的核心，也是第 18 题（指针版字符串排序）的关键零件——**排序字符串数组时，交换的就是指针而不是整段内容**。掌握本题的两层访问，后面的指针数组、指针排序都会迎刃而解。
