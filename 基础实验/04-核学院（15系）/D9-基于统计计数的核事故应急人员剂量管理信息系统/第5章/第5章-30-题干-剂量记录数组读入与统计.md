# 第 5 章 练习 30　剂量记录数组读入与统计

**所属综合实验**：D9（D9-基于统计计数的核事故应急人员剂量管理信息系统）

**对应章节**：5 数组（5.1 一维数组的定义与引用、5.2 数组的遍历、5.3 数组作为函数参数、5.4 排序与查找的数组实现）

**场景来源**：综合实验 D9《基于统计计数的核事故应急人员剂量管理信息系统》（核学院）——本练习是该实验中"剂量记录批量存储与统计指标计算"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

应急期间，监测组每汇报一批人员剂量，系统就要给出这一批的统计指标：**平均受了多少剂量、最高的那个是多少、最低的是多少、有几个人超过了限值**。指标要稳定、要能重复核查，就不能像前几个练习那样"读一个、算一个、丢掉一个"——**必须先把整批数据存下来**。

存放这一批数据的地方就是一维数组。综合实验 D9 的人员剂量表在内存中就是一个数组，所有统计（均值、最大值、超限人数）都在它之上完成。本题实现"读入一批剂量值 → 求均值 → 找最值 → 统计超限人数"这一组基本统计。

## 二、任务要求

编写一个完整程序 `dose_stats.c`：

1. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 60**）；
2. 把 `n` 个剂量值（double，单位 mSv，**题目保证 0 ≤ 每值 ≤ 80**）读入一维数组 `d[60]`；
3. **用一个循环**遍历数组，同时求出：**总和**、**最大值**、**最小值**；
4. 由总和算出**平均值**，再次遍历（或复用第一遍）**统计累计剂量达到 20 mSv 的人数** `over`；
5. 按规定格式输出平均值、最大值、最小值、超限人数。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各人的累计剂量（mSv），用空格分隔。

**输出**：四行，依次为
```
mean = 平均值
max = 最大值
min = 最小值
over = 超限人数
```
平均值、最大值、最小值均保留 2 位小数；超限人数为整数。

## 四、样例

**样例 1**

输入：
```
5
3.50 21.00 8.50 25.00 7.00
```
输出：
```
mean = 13.00
max = 25.00
min = 3.50
over = 2
```

**样例 2**

输入：
```
4
10.0 10.0 20.0 40.0
```
输出：
```
mean = 20.00
max = 40.00
min = 10.00
over = 2
```

**样例 3**

输入：
```
1
18.5
```
输出：
```
mean = 18.50
max = 18.50
min = 18.50
over = 0
```

## 五、提示

- 求最值的经典套路：**把数组第一个元素既当作当前最大值、又当作当前最小值**，然后从第二个元素开始逐个比较更新：
  ```c
  mx = d[0];  mn = d[0];
  for (i = 1; i < n; i++) {
      if (d[i] > mx) mx = d[i];
      if (d[i] < mn) mn = d[i];
  }
  ```
  **不要**把初值写成 0（全正数据下最小值会错）或写成某个很大的数（虽然可行但不推荐，理由见讲解）；
- 求和用一个累加器 `sum`，与练习 27（第 3 章）的做法完全相同；
- 平均值 `mean = sum / n`——`n` 是 `int`，`sum` 是 `double`，除法会自动按浮点进行，结果不会截断；
- 超限人数用计数器（练习 28 第 3 章的套路），条件是 `d[i] >= 20.0`；
- 本题**不使用函数**（数组作函数参数留到综合实验里用），全部在 `main` 内完成。

**完成本练习后你将具备的能力**：定义并使用一维数组、用循环遍历数组、在一遍遍历中同时求多个统计量、区分"遍历一遍就能得"（和、最值）与"需要遍历后才知道"（均值）两类计算——这些是实验 D9 中"剂量数据统计模块"的地基。
