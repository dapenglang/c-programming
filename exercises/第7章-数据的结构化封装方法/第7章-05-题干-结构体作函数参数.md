# 第 7 章 练习 05　结构体作函数参数

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.3 结构体变量作为函数参数）

**场景来源**：综合实验 C8《冰块浮力与平衡吃水计算系统》（水声学院）——本练习是该实验中"单块冰重力与浮力计算"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰块浮力计算系统（实验 C8）的核心问题是：一块完全淹没在海冰中的冰，受到的重力与浮力各是多少？会不会继续下沉？计算重力需要冰块的质量，计算浮力需要冰块的体积——这些属性都封装在同一个 `struct IceBlock` 里。按第 4 章的模块化思想，"算体积""算重力""算浮力"应当各封装成一个函数；而函数要一次性拿到一块冰的全部数据，最直接的办法就是**把整个结构体作为参数传进去**。本练习实现这一环节，并体会结构体参数"值传递、整块复制"的运行方式。

## 二、任务要求

编写一个完整程序 `ice_buoy.c`：

1. 定义结构体类型（成员名不得改动）：

```c
struct IceBlock {
    int    id;         /* 冰块编号 */
    double length;     /* 长（m） */
    double width;      /* 宽（m） */
    double thickness;  /* 厚（m） */
    double mass;       /* 质量（kg） */
};
```

2. 编写三个函数，**形参均为 struct IceBlock 类型的普通变量（值传递）**：
   - `double iceVolume(struct IceBlock b);` —— 返回体积（m³）；
   - `double iceGravity(struct IceBlock b);` —— 返回重力（N），$G = m g$，$g = 9.8\ \mathrm{m/s^2}$；
   - `double iceBuoyancy(struct IceBlock b);` —— 返回完全淹没时的浮力（N），$F = \rho_{sea} g V$，$\rho_{sea} = 1025\ \mathrm{kg/m^3}$；
3. `main` 中读入一块冰的数据，调用三个函数计算；
4. 按格式输出重力、浮力与净浮力（浮力减重力，单位 kN）。

## 三、输入输出格式

**输入**：一行，5 个数据：编号（整数）、长、宽、厚（m）、质量（kg），以空格分隔。

**输出**：三行，分别为 `重力 = X kN`、`浮力 = X kN`、`净浮力 = X kN`，均保留 **2 位小数**（净浮力 = 浮力 − 重力）。

## 四、样例

**样例 1**

输入：
```
3 2.0 1.5 0.6 1650.60
```
输出：
```
重力 = 16.18 kN
浮力 = 18.08 kN
净浮力 = 1.91 kN
```

**样例 2**

输入：
```
7 1.2 0.8 0.5 440.16
```
输出：
```
重力 = 4.31 kN
浮力 = 4.82 kN
净浮力 = 0.51 kN
```

## 五、提示

- 海水密度 1025.0 与重力加速度 9.8 定义为 `const double`；
- 浮力函数内部可再调用体积函数（嵌套调用，第 4 章知识）；
- 注意单位：函数内部用 N 计算，输出时除以 1000.0 化为 kN；
- 形参 `struct IceBlock b` 是实参的一份**副本**，函数内改 `b.mass` 不影响主调函数中的冰块——本题只读不写，正合适。

**完成本练习后你将具备的能力**：把结构体整体作为函数参数传递、理解"整块复制"的值传递语义、用多个小函数分工完成对同一个对象的计算——实验 C8 的浮力模块即由此搭建。
