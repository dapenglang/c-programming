# 第 4 章 练习 13　内部函数与模块化组织

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.4 变量的存储属性，4.5 内部函数与外部函数）

**场景来源**：综合实验 C7《冰载荷辨识系统》（水声学院）——本练习是该实验中"冰载荷应力计算模块划分"环节的实现。

**建议用时**：28 分钟

## 一、应用场景

冰载荷辨识系统需要由实测的力与接触面积算出**接触应力**，再与许用应力比较，判断构件是否安全。这一过程包含三步互相独立的小计算：单位换算（kN→N）、应力计算（$\sigma = F/A$）、安全判定。工程上的做法是把每一步都写成一个**小函数**，再让主程序按顺序调用它们。由于这些函数**只服务于本文件内部**，不希望被其他源文件使用，因此用 `static` 修饰，把它们做成**内部函数**——这就是模块化组织最基本的手段。

## 二、任务要求

编写一个完整程序 `ice_stress.c`：

1. 编写三个**内部函数**（都用 `static` 修饰）：
   - `static double kn_to_n(double kn)`：把力从 kN 换算成 N（1 kN = 1000 N），返回换算结果；
   - `static double calc_stress(double f_n, double area)`：由力（N）与面积（mm²）求应力，返回应力值（MPa）；因 $1\ \text{N/mm}^2 = 1\ \text{MPa}$，故直接返回 `f_n / area`；
   - `static int check_safe(double sigma, double allow)`：若 $\sigma \le \sigma_{\text{allow}}$ 返回 1（安全），否则返回 0；
2. `main` 读入三个实数：力 `f_kn`（kN）、面积 `area`（mm²）、许用应力 `allow`（MPa），依次调用上述三个函数完成计算与判定；
3. **接口约定**：三个函数均只做单一计算、只用参数与返回值通信，**不得使用任何全局变量**；
4. 按格式输出换算后的力、应力与安全结论。

## 三、输入输出格式

**输入**：一行，三个实数 `f_kn area allow`，用空格分隔。

**输出**：三行——第一行 `force = 换算后的力 N`（保留 1 位小数）；第二行 `stress = 应力 MPa`（保留 3 位小数）；第三行 `safe` 或 `over`。

## 四、样例

**样例 1**

输入：
```
12.5 250 60
```
输出：
```
force = 12500.0 N
stress = 50.000 MPa
safe
```

**样例 2**

输入：
```
20 250 60
```
输出：
```
force = 20000.0 N
stress = 80.000 MPa
over
```

## 五、提示

- 应力公式：$\sigma = \dfrac{F}{A}$，其中力 $F$ 用 N、面积 $A$ 用 mm²，得到的单位就是 MPa；
- 单位换算：$1\ \text{kN} = 1000\ \text{N}$，所以 `kn_to_n(12.5)` 应返回 12500.0；
- 判定用 `return (sigma <= allow) ? 1 : 0;`，注意是"小于等于"才算安全；
- `static` 加在函数定义名前，表示该函数**只在本源文件内可见**；它不影响函数的功能，只影响"谁能调用它"，是模块化时"对外隐藏内部细节"的惯用手法。

**完成本练习后你将具备的能力**：会把一个计算流程拆成职责单一的若干函数、理解内部函数（`static` 函数）与外部函数的区别、能用"函数调用链"组织程序结构——这是实验 C7 中"冰载荷计算模块"的地基。
