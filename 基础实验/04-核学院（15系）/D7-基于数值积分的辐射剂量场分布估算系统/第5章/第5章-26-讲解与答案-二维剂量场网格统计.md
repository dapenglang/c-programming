## 二、预备知识：二维数组与"行列遍历"

### 1. 问题是怎么来的

上一练习处理的是一条**线**上的数据——一维数组就够。但辐射场是**一片**区域：沿 x 方向分几列、沿 y 方向分几行，每个交点有一个剂量率。这种"有行有列"的数据，用一维数组硬塞会很不自然（要把二维摊平成一维，下标换算容易出错）。

二维数组就是为"表格/矩阵"而生的：

```c
double D[10][10];     /* 最多 10 行 10 列的剂量率表 */
```

`D[i][j]` 表示**第 i 行、第 j 列**的格点。想象一张网格纸：`i` 是第几行（从上往下数），`j` 是第几列（从左往右数）。

### 2. 为什么要"两层循环"，以及它的顺序

要访问**每一个**格点，需要一个组合：让行号走遍所有值，同时让列号也走遍所有值。这就是**嵌套循环**：

```c
for (i = 0; i < m; i++) {          /* 外层：逐行 */
    for (j = 0; j < n; j++) {      /* 内层：逐列 */
        /* 这里处理 D[i][j] */
    }
}
```

执行过程像"看书"：**先定住一行，从左到右读完整行，再换到下一行**。外层每转一圈，内层要转完整的 `n` 圈，所以内层循环体总共执行 $m \times n$ 次——正好覆盖全部格点。

为什么外层放行、内层放列？因为 C 语言的二维数组在内存里是**按行连续存放**的：`D[0][0], D[0][1], ..., D[0][n-1], D[1][0], ...`。按"行优先"顺序遍历，存取地址是连续递增的，效率最高，也是所有人的习惯写法。

### 3. 用本例走一遍

样例 2 的网格：

| | 列0 | 列1 |
|---|---|---|
| **行0** | 10.0 | 20.0 |
| **行1** | 5.0 | 15.0 |
| **行2** | 30.0 | 25.0 |

- **全场求和**：$10+20+5+15+30+25 = 105$，格点总数 $m \times n = 3 \times 2 = 6$，平均 $105 / 6 = 17.5$；
- **行 0 最大值**：$\max(10, 20) = 20$；
- **行 1 最大值**：$\max(5, 15) = 15$；
- **行 2 最大值**：$\max(30, 25) = 30$。

输出 4 行：平均值 + 三行最大值。

**注意平均值分母**：是格点**总数** $m \times n = 6$，不是 $m + n = 5$。把总数写成 `m+n` 是二维统计里最常见的错。

### 4. 编程时怎么用它

三种遍历**模式**要分清：

- **全遍历**（求总和、全场最值）：两层循环，内层体作用于每个 `D[i][j]`；
- **按行聚合**（求每行最大值/和）：外层循环行、内层循环列，聚合变量在**外层循环体内**声明并清零；
- **按列聚合**：把两层循环的**内外颠倒**（外层列、内层行）即可。

> **这个思想在综合实验中反复出现**：D7 的二维剂量场（行列聚合、找热点）、第 5 章 22 题的温度场节点统计、D8 的能谱"道址—计数率"按道聚合，全部是"二维数组 + 两层循环"。这是从"处理一串数据"到"处理一张表"的跨越。

## 三、解题思路

1. **定义数组**：`double D[10][10];`；
2. **读入 m、n**：`scanf("%d %d", &m, &n);`；
3. **读入网格 + 求总和**：两层循环里读一个、加一个，累计到 `sum`；
4. **输出平均值**：`printf("avg = %.4f\n", sum / (double)(m * n));`——注意 `m*n` 是 int，除之前转 double（其实 `sum` 已是 double，自动提升，写 `sum/(m*n)` 也可以）；
5. **逐行求最大值并输出**：外层遍历行，内层对该行打擂台，得到 `rowmax` 后立即打印。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double D[10][10];           /* 二维剂量场网格 */
    int m, n, i, j;
    double sum = 0.0;           /* 全场剂量率之和，先清零 */
    double rowmax;              /* 当前行的最大值 */

    scanf("%d %d", &m, &n);     /* 读入行数、列数 */

    /* 读入网格，同时累加求和 */
    for (i = 0; i < m; i++) {
        for (j = 0; j < n; j++) {
            scanf("%lf", &D[i][j]);     /* 读入第 i 行第 j 列 */
            sum += D[i][j];             /* 累加进总和 */
        }
    }

    /* 全场平均值 = 总和 / 格点总数 */
    printf("avg = %.4f\n", sum / (m * n));

    /* 逐行找最大值并输出 */
    for (i = 0; i < m; i++) {
        rowmax = D[i][0];               /* 用该行第 0 个元素立擂主 */
        for (j = 1; j < n; j++) {
            if (D[i][j] > rowmax) {
                rowmax = D[i][j];       /* 打擂台更新该行最大值 */
            }
        }
        printf("row %d max = %.4f\n", i, rowmax);
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2×3: 1..6 | 总和 21，平均 21/6 = 3.5；行0 max 3，行1 max 6 | `avg = 3.5000` / `row 0 max = 3.0000` / `row 1 max = 6.0000` ✓ |
| 3×2: 10,20;5,15;30,25 | 总和 105，平均 105/6 = 17.5；各行 max 20、15、30 | `avg = 17.5000` / `row 0 max = 20.0000` / `row 1 max = 15.0000` / `row 2 max = 30.0000` ✓ |
| 1×4: 2.5,9,1,4 | 总和 16.5，平均 16.5/4 = 4.125；行0 max 9 | `avg = 4.1250` / `row 0 max = 9.0000` ✓ |

三例覆盖了 m>1、n>1、单行等情形，平均值与各行最大值均与手算一致；第三例还验证了平均值可能是"非整位小数"（4.1250）。

## 六、常见错误与讲解

**错误 1：平均值分母写成 `m + n`**

```c
printf("avg = %.4f\n", sum / (m + n));     /* 错：这是行列数之和，不是格点数 */
printf("avg = %.4f\n", sum / (m * n));     /* 对：格点总数是 m × n */
```

二维数据的平均值分母是"元素个数"= 行数 × 列数。写成 `m+n` 是极其常见的疏忽，且当 `m·n = m+n` 时（如 2×2）还会碰巧对，更迷惑人。

**错误 2：每行最大值变量没在行内重置**

```c
rowmax = 0;                                /* 错：若剂量率全为正勉强可用，但语义错 */
for (i = 0; i < m; i++) {
    for (j = 0; j < n; j++)
        if (D[i][j] > rowmax) rowmax = D[i][j];   /* 错：rowmax 跨行累积，第 2 行会变成全局最大 */
}
rowmax = D[i][0];                          /* 对：每行开始时用该行首元素重置擂主 */
```

若 `rowmax` 只在循环外初始化一次，它会**跨行累积**，后面的行永远输出的是"到目前为止的全局最大"，无法反映本行情况。**规矩：按行聚合的量必须在行循环体内重置。**

**错误 3：两层循环下标写反**

```c
for (i = 0; i < n; i++)          /* 错：i 对应行，条件却用列数 n */
    for (j = 0; j < m; j++)      /* 错：j 对应列，条件却用行数 m */
```

行列数弄反在方阵（m=n）时不报错且结果对，一旦非方阵就立刻越界或漏读。**规矩：`i` 配 `m`，`j` 配 `n`，始终一致。**

**错误 4：读入顺序与题目不符**

```c
for (i = 0; i < m; i++)
    for (j = 0; j < n; j++)
        scanf("%lf", &D[i][j]);   /* 对：按行读入，每行 n 个数 */
```

`scanf` 会跳过空格和换行，所以输入文件里怎么分行都行，但**数的先后顺序必须与行列遍历顺序一致**。若把内外层颠倒，虽然读进来的是同一批数，但会被"按列"摆放，与题目要求的"按行"不同。
