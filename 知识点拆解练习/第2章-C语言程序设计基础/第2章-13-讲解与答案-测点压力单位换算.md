## 二、预备知识：数据类型与整数除法（零基础阅读）

### 1. 问题是怎么来的

计算机里的数分很多"种类"。整型 `int` 只能表示整数（如 2450、38000），浮点型 `double` 能表示带小数的实数（如 2.45、38.0）。**物理量该用哪种类型，取决于它是否需要小数、范围多大。** 压力可以是 2450 kPa，也可以精细到 2.4500 MPa，带小数、要精度，所以必须用 `double`。

### 2. "整数除法"是怎么来的

C 语言有个非常容易踩的坑：**两个整数相除，结果还是整数，小数部分直接被丢掉**。

```c
2450 / 1000     /* 结果是 2，不是 2.45 */
2450 / 1000.0   /* 结果才是 2.45 */
```

原因是：运算符 `/` 会先看两边操作数的类型，两边都是整数就执行整数除法（截断），只要有一边是浮点数就执行实数除法。所以写换算时，**分子分母至少有一个要带小数点**。

### 3. 用本例走一遍

输入 `p = 2450`（kPa）：

- 整数写法 $2450 / 1000 = 2$，得到 2——错了；
- 实数写法 $2450 / 1000.0 = 2.45$，得到 2.45——对了。

再输入 `p = 38000`：$38000 / 1000.0 = 38.0$，输出 38.0000 MPa。两个单位描述的是同一个物理量，只是量纲不同。

### 4. 编程时怎么用它

程序只读一个 `double` 到 `p`，第一个 `printf` 原样打印 `p`（kPa），第二个 `printf` 打印 `p / 1000.0`（MPa）。为了保证精度，换算系数用 `const double` 定义，既清晰又不会被误改。

> **这个思想在综合实验中反复出现**：C9 压力场、C1 声速剖面、D5 剂量率，都会遇到"同一物理量多种单位"的场合，用统一的换算系数 + 实数除法处理，是最稳妥的做法。

## 三、解题思路

1. **确定类型**：压力值可能达到数万 kPa，且需要保留小数，用 `double` 最合适；
2. **定义常量**：`const double KPA_PER_MPA = 1000.0;`，语义明确，避免在代码里直接散落数字；
3. **读入**：`scanf("%lf", &p);`；
4. **两次输出**：第一次用 `%.2f` 打印 kPa，第二次用 `%.4f` 打印 `p / KPA_PER_MPA`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double KPA_PER_MPA = 1000.0;  /* 1 MPa = 1000 kPa */

    double p;      /* 测点压力，单位 kPa */

    /* 读入测点压力（kPa） */
    scanf("%lf", &p);

    /* 输出 kPa（保留 2 位小数） */
    printf("p = %.2f kPa\n", p);

    /* 换算为 MPa 后输出（保留 4 位小数），除数为实数以保证实数除法 */
    printf("p = %.4f MPa\n", p / KPA_PER_MPA);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2450 | 2450/1000 = 2.45 | `p = 2450.00 kPa`<br>`p = 2.4500 MPa` ✓ |
| 38000 | 38000/1000 = 38.0 | `p = 38000.00 kPa`<br>`p = 38.0000 MPa` ✓ |
| 125 | 125/1000 = 0.125 | `p = 125.00 kPa`<br>`p = 0.1250 MPa` ✓ |
| 5000 | 5000/1000 = 5.0 | `p = 5000.00 kPa`<br>`p = 5.0000 MPa` ✓ |

两个单位的数值互相对应，换算正确。

## 六、常见错误与讲解

**错误 1：整数除法（最典型）**

```c
printf("p = %.4f MPa\n", p / 1000);    /* 错：若 p 是整数会截断；此处 p 为 double 尚可 */
int p = 2450;
printf("%d\n", p / 1000);              /* 错：结果为 2，小数被丢掉 */
```

正确写法是让参与除法的数带小数：`p / 1000.0` 或用 `double` 类型的换算常量。

**错误 2：用 `float` 或 `int` 存压力**

```c
int p;                 /* 错：无法表示 2.45 这类小数 */
float p;               /* 可编译，但本章统一用精度更高的 double */
scanf("%f", &p);       /* 错：double 变量却用 %f 读入，数据错乱 */
```

**错误 3：`%f` 与 `%lf` 混淆**

```c
double p;
scanf("%f", &p);            /* 错：scanf 读 double 必须用 %lf */
printf("p = %f MPa\n", p);  /* 对：printf 里 %f 与 %lf 效果相同 */
```

规律：**scanf 读 `double` 用 `%lf`，printf 打印 `double` 用 `%f` 即可**。

**错误 4：换算方向搞反**

```c
printf("%.4f\n", p * 1000.0);   /* 错：这是 kPa → Pa，方向不对 */
printf("%.4f\n", p / 1000.0);   /* 对：kPa 除以 1000 得 MPa */
```

MPa 是更大的单位，同一压力换成 MPa 数值应**变小**，用它来判断方向是否写反。
