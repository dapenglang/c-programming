## 二、预备知识：矩形法数值积分的基本原理（零基础阅读）

### 1. 问题是怎么来的

剂量率 $D(t)$ 随时间连续变化，累积剂量是它下方、$[0, T]$ 区间上的曲边面积：$\displaystyle\int_0^T D(t)\,dt$。练习 09 处理的是"只有离散采样点"的情形；本题更进一层——被积函数有**解析表达式**，程序可以在任意多的点上计算它。数值积分的通用思路仍然不变：**以直代曲（以平代曲）**，把曲边面积切成小片、每片用简单图形近似、全部相加。

### 2. 方法是怎么想出来的（公式推导）

把区间 $[0, T]$ 等分成 n 格，每格宽度 $\Delta t = T/n$，格点为 $t_i = i \cdot \Delta t$（$i = 0, 1, \ldots, n$）。在每一小格 $[t_i, t_{i+1}]$ 上，用一个**矩形**代替曲边小条：矩形的高取该格**左端点**处的函数值 $D(t_i)$，于是第 i 格面积为

$$
S_i \approx D(t_i) \cdot \Delta t
$$

总累积剂量为 n 个矩形之和：

$$
\int_0^T D(t)\,dt \;\approx\; \sum_{i=0}^{n-1} D(t_i)\,\Delta t \;=\; \Delta t \sum_{i=0}^{n-1} D(t_i)
$$

为什么左端点矩形在本题会**高估**？$D(t)$ 是单调下降的曲线，每一格内左端点处的值是整格里最高的，矩形面积因此略大于真实曲边面积——分割越粗，高估越多。把 n 从 1000 加密到 10000，结果从 13.3723 降到 13.3372，正在向真值 $13.3333\ldots$（可由积分表验证：$\int_0^T \frac{D_0}{(1+kt)^2}dt = \frac{D_0}{k}\left(1 - \frac{1}{1+kT}\right)$）收敛。**"加密分割、误差变小"是所有数值积分方法的共同性质**；相比之下练习 09 的梯形公式在同样分割数下误差更小，因为梯形比矩形更贴近曲线。

### 3. 用本例走一遍（手算）

取 $D_0 = 8.0$，$k = 0.5$，$T = 10$，$n = 1000$，则 $\Delta t = 0.01$：

- 第 0 格：$t_0 = 0$，$D(t_0) = 8.0/(1.0)^2 = 8.0$，贡献 $8.0 \times 0.01 = 0.0800$；
- 第 1 格：$t_1 = 0.01$，$D(t_1) = 8.0/(1.005)^2 = 8.0/1.010025 \approx 7.9206$，贡献约 $0.0792$；
- ……如此累加 1000 格，程序得 `dose = 13.3723`。

而用解析公式核对真值：$\frac{8.0}{0.5}\left(1 - \frac{1}{1+0.5 \times 10}\right) = 16 \times \frac{5}{6} = 13.3333$，矩形结果确实略偏大，符合第 2 步的分析。

### 4. 编程时怎么用它（循环怎么写、什么时候停）

- **格点编号从 0 开始**：左端点用到 $t_0 \sim t_{n-1}$，所以循环写成 `for (i = 0; i <= n - 1; i = i + 1)`（即 `i < n`），共 n 轮。这与练习 05~07"从 1 数到 n"的约定不同——**编号约定由公式决定，数清次数才是本质**；
- **每轮三件事**：算格点 `t = i * dt`、算函数值 `D0 / ((1.0 + k*t) * (1.0 + k*t))`、累加；
- **"宽"提到循环外**：$\Delta t$ 对每格都相同，先在循环里只累加函数值之和，循环结束再统一 `s = s * dt`——少做 n−1 次乘法，也少一处出错机会；
- **何时停**：循环 n 次自然结束，不需要任何额外判断；n 最大 $10^6$，循环毫秒级完成。

## 三、解题思路

1. **确定变量**：`n`、`i` 为 `int`；`D0`、`k`、`T`、`dt`、`t`、`s` 为 `double`；
2. **读入 D0、k、T、n**；
3. **算格宽** `dt = T / n`（注意 T 与 n 相除时 T 是实数，无整数除法问题）；
4. **for 循环 i 从 0 到 n−1**：算 `t = i * dt`，把 $D(t)$ 累加进 `s`；
5. **循环后** `s = s * dt`，输出 `dose = %.4f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i;           /* 分割数、循环变量（格点从 0 开始编号） */
    double D0;          /* 初始剂量率，uGy/h */
    double k;           /* 衰减常数，1/h */
    double T;           /* 积分时段，h */
    double dt;          /* 格宽，h */
    double t;           /* 当前格点时刻，h */
    double s = 0.0;     /* 函数值累加器 */

    scanf("%lf %lf %lf %d", &D0, &k, &T, &n);

    dt = T / n;                       /* 等分区间 */

    for (i = 0; i <= n - 1; i = i + 1) {   /* 左端点 t0 ~ t(n-1) */
        t = i * dt;                        /* 第 i 格左端点 */
        s = s + D0 / ((1.0 + k * t) * (1.0 + k * t));  /* D(t) */
    }

    s = s * dt;                       /* 统一乘上格宽 */

    printf("dose = %.4f\n", s);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算/中间过程 | 程序输出 |
|---|---|---|
| `8.0 0.5 10 1000` | $\Delta t = 0.01$；首格贡献 0.0800、次格约 0.0792；累加 1000 格后乘 $\Delta t$；真值 13.3333，左端点高估 | `dose = 13.3723` ✓ |
| `8.0 0.5 10 10000` | $\Delta t = 0.001$，分割加密 10 倍，误差缩小约 10 倍 | `dose = 13.3372` ✓ |
| `8.0 0.5 10 1` | 单格：$t_0 = 0$，$\Delta t = 10$，$D(0) \times 10 = 80.0$（极端粗糙的高估，用于验证程序骨架） | `dose = 80.0000` ✓ |
| `4.0 1.0 2 100000` | 真值 $\frac{4}{1}(1-\frac{1}{3}) = 2.6667$，程序应逼近它 | `dose = 2.6667` ✓ |

## 六、常见错误与讲解

**错误 1：循环边界数错格数**

```c
for (i = 0; i <= n; i = i + 1)   /* 错：用了 t0 ~ tn 共 n+1 个左端点，n 变 n+1 格 */
for (i = 1; i <= n; i = i + 1)   /* 错：漏掉 t0，且 t_n = T 处 D(t) 最小却把总长算错 */
for (i = 0; i <= n - 1; i = i + 1)   /* 对：恰好 n 格 */
```

用 `n = 1` 的样例自检：单格结果必须是 $D(0) \times T = 80.0$。

**错误 2：整数除法在格宽计算里出现**

```c
dt = T / n;      /* 本题安全：T 是 double，除法按实数进行 */
```

但如果把 T 声明成 `int`（错误做法），`T / n` 就变成整数除法，10/1000 直接得 0，一切归零。**时段、格宽等物理量一律 double。**

**错误 3：用 pow 或连写错误实现平方**

```c
s = s + D0 / (1.0 + k * t) * (1.0 + k * t);   /* 错：除和乘同级从左到右，分母只剩一个因子 */
s = s + D0 / ((1.0 + k * t) * (1.0 + k * t)); /* 对：整个分母括成一个整体 */
```

**错误 4：每格重复乘格宽（不算错但低效易错）**

```c
s = s + D0 / (...) * dt;   /* 每轮乘一次，结果正确但多 n-1 次乘法 */
```

建议"先累加函数值、循环外统一乘 dt"，两行分工清晰。

## 七、与综合实验的衔接

- 实验 **D5（剂量率评估）**中，累积剂量是"掩蔽/撤离决策"的直接输入，程序中的被积函数模型与本题完全一致；把被积函数换成剂量率的实测采样序列，本题骨架又变回练习 09 的数据流积分——**矩形法与梯形法是同一枚硬币的两面**：一个取左端点常数近似，一个取两端线性近似。学到第 4 章（函数）后，被积函数可封装成 `double dose(double t)`、积分器封装成 `double rect_integral(int n)`，实现"函数与积分器分离"（第 4 章练习 18）；学到第 5 章（数组）后还能对误差做收敛性实验（n 翻倍、误差减半的规律）；
- 3.5 节的积分三部曲至此齐备：单段梯形（练习 08）→ 复合梯形（练习 09）→ 矩形法（本练习），后面的二分法（练习 12、13）与迭代法（练习 14）将把"循环逼近"的思想从积分推广到方程求解。
