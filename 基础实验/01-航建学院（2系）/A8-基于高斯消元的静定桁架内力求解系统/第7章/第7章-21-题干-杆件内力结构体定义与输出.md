# 第 7 章 练习 21　杆件内力结构体定义与输出

**所属综合实验**：A8（A8-基于高斯消元的静定桁架内力求解系统）

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型的定义、7.2 结构体变量的定义与初始化、7.3 成员访问）

**场景来源**：综合实验 A8《基于高斯消元的静定桁架内力求解系统》（航建学院）——本练习是该实验中"杆件数据建模"环节的实现。

**建议用时**：20～30 分钟

## 一、应用场景

桁架由若干根杆件组成，每根杆件有好几个属性要一起描述：**杆件编号**（如 `G1`）、**轴力**（kN，拉力为正、压力为负）、**截面面积**（m²）。求解桁架内力时，程序要管理几十根杆件，每根都有自己的三项数据。

如果把它们拆成三个平行数组（`no[]`、`N[]`、`A[]`），写着写着就会对不上号。更自然的做法是把"描述同一根杆件的多个属性"**打包成一个整体**——这就是**结构体**。本练习先定义 `TrussBar`（桁架杆件）结构体，再定义变量、填数据、打印出来。

## 二、任务要求

编写一个完整程序 `bar_struct.c`：

1. 定义结构体类型 `TrussBar`，包含三个成员：`no`（杆件编号，字符数组）、`N`（轴力 kN，double）、`area`（截面面积 m²，double）；
2. 用 `typedef` 给它起别名 `TrussBar`；
3. 在 `main` 中定义**一个** `TrussBar` 变量，用**初始化列表**装入一根杆件的数据（编号 `"G1"`、轴力 `45.6` kN、面积 `0.0012` m²）；
4. 用**点号**访问各成员并输出；同时按公式计算杆件应力

$$
\sigma = \frac{N}{A}
$$

（单位 MPa，注意 $1\ \text{kN/m}^2 = 10^{-3}\ \text{MPa}$，程序中换算为 $\sigma = N / A \times 10^{-3}$），应力保留 **2 位小数**。

## 三、输入输出格式

**输入**：无（数据写在程序里）。

**输出**：四行，`no=编号`、`N=轴力kN`、`area=面积m2`、`sigma=应力MPa`。

## 四、样例

**样例 1**

输出：
```
no=G1
N=45.60
area=0.0012
sigma=38.00
```

## 五、提示

**结构体类型的定义**：

```c
typedef struct {
    char   no[8];      /* 杆件编号 */
    double N;          /* 轴力，kN */
    double area;       /* 截面面积，m^2 */
} TrussBar;
```

这定义了一种**新的数据类型** `TrussBar`，就像 `int`、`double` 一样，只不过它内部装着三个成员。

**定义变量与初始化**：

```c
TrussBar b = {"G1", 45.6, 0.0012};
```

**访问成员**：用点号 `.`：

```c
printf("%s\n", b.no);
printf("%.2f\n", b.N);
```

**应力换算**：$N$（kN）/ $A$（m²）得到 kN/m²，即 kPa；1 kPa $= 10^{-3}$ MPa，故

$$
\sigma(\text{MPa}) = \frac{N}{A} \times 10^{-3}
$$

**完成本练习后你将具备的能力**：定义结构体类型、用 typedef 起别名、定义并初始化结构体变量、用点号访问成员、把物理上相关的多个量打包成一个整体。
