# 第 2 章 练习 21　混凝土强度龄期对数换算

**所属综合实验**：A7（A7-基于拉格朗日插值的混凝土强度发展曲线计算系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——对数换算）

**场景来源**：综合实验 A7《基于拉格朗日插值的混凝土强度发展曲线计算系统》（航建学院）——本练习是该实验中"龄期-强度经验公式换算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

混凝土浇筑后强度随时间增长：3 天时还很软，28 天达到设计强度等级。结构施工中常要知道"某龄期强度达到了 28 天强度的百分之几"，才能决定拆模、张拉预应力或吊装的时机。

规范采用的经验公式把强度比与龄期的**对数**联系起来：

$$
f(n) = A + B \cdot \lg n
$$

其中 $n$ 是龄期（天），$\lg n$ 是以 10 为底的对数，$A$、$B$ 是回归系数，$f(n)$ 是龄期 $n$ 时的强度与 28 天强度的比值（无量纲，0～1 之间）。哈尔滨冬季施工时，工程师会据此判断"7 天龄期的混凝土能否拆模"（一般要求强度比不低于 70%）。

## 二、任务要求

编写一个完整程序 `concrete_age.c`：

1. 程序中用**常量**存放回归系数 $A = 0.256$、$B = 0.516$（哈尔滨地区某水泥品种的规范值）；
2. 从键盘读入一个龄期 `n`（单位：天，double 类型，**题目保证 1 ≤ n ≤ 28**，因此本程序不需要判断分支）；
3. 用对数经验公式计算该龄期对应的强度比 `f`；
4. 在程序内直接计算 $\lg n$（用数学库函数 `log10`，需要 `#include <math.h>`），按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示混凝土龄期 n（天）。

**输出**：一行，按格式 `f = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
28
```
输出：
```
f = 1.0027
```

**样例 2**

输入：
```
7
```
输出：
```
f = 0.6921
```

## 五、提示

对数经验公式：

$$
f(n) = A + B \cdot \lg n
$$

在 C 语言中，$\lg n$ 写作 `log10(n)`，它不是内置运算符，而是数学库 `<math.h>` 提供的函数。使用时：

```c
#include <math.h>
...
f = A + B * log10(n);
```

注意：`log10` 的名称是"log base 10"的缩写，不要和第 4 章才学的自定义函数混淆——它是库函数，直接调用即可。
