# 题目 C6：基于逐点差分与阈值判决的海底回波测深数据处理系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行海底回波测深数据处理工具，围绕"单波束测深仪回波深度时序中混有野值与缺失、需要用逐点差分与阈值判决还原真实海底剖面"这一水声工程常见流程展开。系统从文本文件读入"时间—深度"对，完成有效性检查与缺失插值补齐，计算一阶差分并做三点滑动平滑，用阈值判决识别海底地形阶跃与斜坡段，对深度序列做分段重建与分段统计，最后输出结果文件、屏幕报表与字符深度剖面图。

回波测深是水声工程最基础的应用之一。测深仪向海底发射声脉冲并接收回波，按 $d = \frac{1}{2} \cdot c \cdot \Delta t$ 由往返时间差 $\Delta t$ 与水中声速 $c$ 换算深度。实际测线中，气泡干扰、鱼群回波、浅层混响会让个别深度值明显偏离真实海底，形成"野值"；仪器丢帧则造成缺失点。如果不先做差分判跳变、插值补缺失，直接把原始深度画成地形图，海图上就会出现不存在的"悬崖"与"深坑"。海洋测绘规范中，深度序列的跳变检测与异常剔除是测深数据后处理的必备环节。

本系统支撑的关键场景包括：① 单波束测深仪原始数据的质量控制与清洗；② 海底地形剖面的分段重建（平原、斜坡、阶跃）；③ 港口与航道疏浚监测中的深度对比统计；④ 海底管道与电缆敷设路由的地形预查。学生在大一阶段就能用 C 语言把"差分—平滑—判决—重建"这一经典信号处理链条完整跑通，为后续《水声学原理》《海洋测绘》《信号与系统》等课程建立直观基础。本题目与水声工程专业"水声信号处理"方向直接相关，训练学生把物理流程转化为"数据读入—算法实现—数据输出"完整程序工程的能力。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的海底回波测深数据处理系统：从文本文件读入深度—时间时序，实现数据有效性检查（负值、越界、缺失标记），对缺失点做线性插值补齐，计算一阶差分并做三点滑动平滑差分，用阈值判决识别跳变点并把深度序列划分为若干段（对应海底阶跃/斜坡/平坦地形），对每段做均值、极值与段长统计，最后生成结果文件与字符深度剖面图。

专业关联上，本题目复现了测深数据后处理中"野值检测—插值补齐—地形分段"三类真实业务的核心计算。学生在此过程中将掌握课程中的循环与选择结构、数组、函数、指针与文件读写，并第一次把"差分"这一最简单的数值运算写进完整工程，理解"一个数据流水线如何变成一套程序"。

## 三、数据来源与格式

- **数据文件格式**：深度时序采用纯文本格式，首行为标题说明，其后每行一条记录，字段以空格分隔。字段依次为：时间标记 t（单位：秒，正实数）、回波深度 d（单位：米，非负实数）。当测深仪丢帧时，深度字段填写缺失标记 `NaN`（或 `-1`），由系统识别为缺失点。

```
# time_sec   depth_m
0.0          42.35
0.5          42.41
1.0          NaN
1.5          42.52
2.0          55.18
2.5          55.22
3.0          68.90
```

- **仿真数据生成规则**：
  - 时间标记：从 0.0 起、步长 0.5 秒等间隔递增，总数 80～200 个点。
  - 真实深度：按"平坦段 + 斜坡段 + 阶跃"合成，平坦段深度在 30～120 m 内缓慢起伏（每步变化不超过 0.5 m），斜坡段每步爬升 1～3 m，阶跃处一步突变 5～20 m。
  - 观测噪声：在真实深度上加 ±0.3 m 的小扰动，模拟测深仪量测误差。
  - 缺失标记：随机注入 3%～8% 的 `NaN`（模拟丢帧）；教师提供的生成程序也会在阶跃处人为注入一两个孤立野值（如 150.0 m）供校验模块剔除。
  - **异常值注入方式**：由教师提供的生成程序人为注入三类错误。其一，深度为负数（如 `-3.2`），需在校验模块中识别；其二，深度超出该海区合理范围（如超过 500 m），判为越界；其三，时间字段非数字串导致 `fscanf` 错位。校验模块需输出"行号—异常类型—处理动作"清单。

- **真实数据集（如有）**：真实单波束测深数据可参考国家海洋信息中心发布的海洋测绘成果与 NGDC 全球海底地形数据库（https://www.ngdc.noaa.gov/）。学生**无需下载**真实数据文件，课程提供与上述字段含义对应的简化仿真数据表；表中"深度"对应测深仪换算后的瞬时水深，"时间"对应回波接收时刻。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_POINT      220     /* 最多深度采样点数 */
#define MAX_SEG        40      /* 最多地形分段数 */
#define MISS           -9999.0 /* 缺失点内部标记值 */

/* ===== 深度采样点 ===== */
struct EchoPoint {
    double t;                /* 回波接收时刻，单位：秒 */
    double depth;            /* 回波深度，单位：米；缺失时为 MISS */
    int    valid;            /* 有效标志：1 有效，0 异常/缺失待补 */
};

/* ===== 地形分段信息 ===== */
struct DepthSeg {
    int    begIdx;           /* 段起始下标（含） */
    int    endIdx;           /* 段结束下标（含） */
    double meanD;            /* 段内平均深度，单位：米 */
    double minD;             /* 段内最浅深度 */
    double maxD;             /* 段内最深深度 */
    int    type;             /* 段类型：0 平坦 1 斜坡 2 阶跃边界 */
};

/* ===== 全局数据区 ===== */
struct EchoPoint g_pt[MAX_POINT];      /* 原始/处理后深度序列 */
int              g_n;                  /* 实际采样点数 */
double           g_diff[MAX_POINT];    /* 一阶差分序列 */
double           g_sdiff[MAX_POINT];   /* 三点平滑差分序列 */
double           g_jumpTh;             /* 跳变判决阈值，单位：米 */
struct DepthSeg  g_seg[MAX_SEG];       /* 分段表 */
int              g_segCount;           /* 分段数 */

/* ===== 处理日志（供报表模块使用） ===== */
struct LogItem {
    char  op[24];            /* 操作名，如 "VALIDATE" */
    char  detail[64];        /* 参数与关键结果摘要 */
};
struct LogItem g_log[MAX_POINT / 10 + 8];
int            g_logCount;             /* 已记录日志条数 */
```

辅助说明：深度序列用结构体数组组织（课程 7.1/7.2），差分序列用一维 `double` 数组缓冲（课程 5.1），缺失点统一用 `MISS` 标记后再插值，避免魔法数散落各处。跳变阈值在配置中给定，全表共用。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入与预处理（3 个模块）

**M1 回波深度时序读入模块**（源文件 `EchoIO.c`）

- 功能简介：打开深度时序文本文件，跳过首行标题，用循环 + `fscanf` 逐行读入时间与深度，填充全局序列 `g_pt[]` 并记录点数；遇到 `NaN` 或 `-1` 时把深度置为 `MISS`；文件不存在时给出明确提示。
- 输入：文件路径（菜单输入，默认 `echo_depth.txt`）。
- 输出：填充后的 `g_pt[]` 与 `g_n`；返回成功/失败标志。

**M2 数据有效性检查模块**（源文件 `EchoCheck.c`）

- 功能简介：逐条检查深度是否为负（置 `MISS` 并记日志）、是否超过海区最大合理深度（判越界剔除）、时间是否单调递增；对异常记录生成"行号—异常类型—处理动作"清单并打印。
- 输入：`g_pt[]`、`g_n`、海区最大深度配置值。
- 输出：屏幕校验报告；修正后的 `g_pt[]`。

**M3 缺失点线性插值补齐模块**（源文件 `EchoFix.c`）

- 功能简介：扫描序列找连续 `MISS` 段，对段两端的有效深度做线性插值 $\hat{d} = d_1 + \dfrac{d_2 - d_1}{t_2 - t_1}(t - t_1)$ 逐点补齐；序列首尾缺失用最近有效值外推；统计补齐点数并写入日志。
- 输入：`g_pt[]`、`g_n`。
- 输出：补齐后的 `g_pt[]`；屏幕补齐统计。

### 第二部分：算法实现（4 个模块）

**M4 一阶差分计算模块**（源文件 `EchoDiff.c`）

- 功能简介：对补齐后的深度序列计算一阶差分 $\Delta d_i = d_{i+1} - d_i$（$i = 0, 1, \ldots, n-2$），存入 `g_diff[]`；同时统计差分序列的均值与标准差，作为后续阈值选取的参考量。
- 输入：`g_pt[]`、`g_n`。
- 输出：`g_diff[]` 及其统计量；屏幕摘要。

**M5 三点滑动平滑差分模块**（源文件 `EchoDiff.c`）

- 功能简介：对 `g_diff[]` 做三点滑动平均 $\bar{\Delta}_i = \dfrac{\Delta d_{i-1} + \Delta d_i + \Delta d_{i+1}}{3}$（边界用两端差分补齐），压少量测噪声，得到 `g_sdiff[]`；用函数封装窗口逻辑便于复用。
- 输入：`g_diff[]`、长度。
- 输出：`g_sdiff[]`；屏幕前后对比抽样若干行。

**M6 阈值跳变判决模块**（源文件 `EchoJudge.c`）

- 功能简介：遍历 `g_sdiff[]`，与跳变阈值 `g_jumpTh` 比较：绝对值超过阈值判为阶跃点，连续同号超阈值判为斜坡段，其余为平坦段；输出跳变点下标与方向（变深/变浅）清单。
- 输入：`g_sdiff[]`、`g_jumpTh`。
- 输出：判决结果数组与跳变点清单；屏幕打印。

**M7 深度序列分段重建模块**（源文件 `EchoSeg.c`）

- 功能简介：依据 M6 的判决结果把深度序列切分为若干连续段，填充 `g_seg[]`（起止下标、类型）；对被剔除的孤立野值位置做邻域均值回填，保证段内数据完整。
- 输入：判决结果、`g_pt[]`。
- 输出：`g_seg[]`、`g_segCount`；屏幕分段轮廓表。

### 第三部分：统计与输出（3 个模块）

**M8 分段统计模块**（源文件 `EchoSeg.c`）

- 功能简介：对每段计算平均深度、最浅/最深深度、段内点数与段跨度（秒）；对全序列计算总点数、有效点数、剔除数、补齐数与总段数，形成汇总表。
- 输入：`g_seg[]`、`g_segCount`、`g_pt[]`。
- 输出：填充段统计字段；屏幕汇总表。

**M9 结果文件输出模块**（源文件 `EchoIO.c`）

- 功能简介：把插值后深度序列与平滑差分按"时间—深度—平滑差分—判决标记"列写出到 `echo_result.csv`，首行写列名；把分段统计表写出到 `echo_seg.txt` 便于核对。
- 输入：`g_pt[]`、`g_sdiff[]`、`g_seg[]`。
- 输出：`echo_result.csv`、`echo_seg.txt`；屏幕确认信息。

**M10 屏幕报表与字符深度剖面图模块**（源文件 `Stu_main.c`）

- 功能简介：按深度反向纵轴（海面在上、海底在下）用字符绘制深度剖面图，平坦段用 `-`、斜坡段用 `\`、阶跃处用 `|` 标注；主菜单用 `do-while + switch` 调度 M1～M9，用状态标记约束"必须先读入并校验数据才能计算"。
- 输入：用户菜单选项、`g_pt[]`、`g_seg[]`。
- 输出：屏幕字符剖面图与汇总报表；调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环，先用状态标记 `g_loaded` 约束流程——未读入数据时只允许执行 M1；读入后依次可调用 M2 校验、M3 插值、M4～M7 差分与判决重建、M8 统计、M9～M10 输出。任何计算模块要求序列中至少有 2 个有效点，否则提示先执行 M3。

**数据流**：

```
echo_depth.txt ─► M1 读入 ─► g_pt[] ─► M2 有效性检查 ─► 清洗后序列
                                   │
                M3 线性插值补齐 ◄───┘（缺失点）
                     │
                     ▼
        M4 一阶差分 ─► g_diff[] ─► M5 三点平滑 ─► g_sdiff[]
                     │                              │
                     │                    M6 阈值跳变判决（g_jumpTh）
                     │                              │
                     └──────────► M7 分段重建 ─► g_seg[]
                                        │
                        ┌───────────────┼─────────────────┐
                        ▼               ▼                 ▼
                  M8 分段统计     M9 结果文件输出   M10 屏幕报表与剖面图
```

所有模块之间只通过全局序列数组、分段数组与函数参数交换数据，函数头部（接口）在编码前由全组书面约定。

## 十、选做扩展

1. **阈值敏感性分析**：把跳变阈值取 1.0、2.0、4.0 m/步三档分别重跑 M6～M8，输出"阈值—段数—阶跃点数"对照表，观察阈值过严（地形被切碎）与过松（阶跃漏检）的现象。
2. **五点平滑对比**：在 M5 之外再实现五点滑动平滑，把三点与五点平滑差分同时画在报表中对比，观察平滑窗口对噪声与跳变保留的折中。
3. **双向插值外推实验**：修改 M3，对首尾连续缺失超过 5 点的情形改用段内均值填充而非线性外推，输出两种策略的插值误差对照（以教师提供的真值为基准）。
