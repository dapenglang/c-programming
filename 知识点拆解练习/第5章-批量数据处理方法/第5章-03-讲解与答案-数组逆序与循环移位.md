## 二、预备知识：元素移动算法的基本原理（零基础阅读）

### 1. 问题是怎么来的

数组元素的"搬家"分两类：**互换**（两个位置的内容对调）与**搬移**（一串元素朝同一方向挪一格）。逆序由成对的互换组成，循环移位是一次整体搬移。它们是排序、插入、删除等一切"数组维护算法"的最小构件。

### 2. 交换为什么必须用临时变量

想把 `a[i]` 与 `a[j]` 对调，直觉写法 `a[i] = a[j]; a[j] = a[i];` 是错的：第一句执行后 `a[i]` 的原值已被覆盖，第二句放回去的是 `a[j]` 自己。正确做法是把一个值先寄存到临时变量：

```c
t = a[i];  a[i] = a[j];  a[j] = t;
```

这三行是本章出现频率最高的代码片段，之后每一道排序题都要写它。

### 3. 逆序：对称下标成对互换

逆序的目标是第 1 个与最后 1 个互换、第 2 个与倒数第 2 个互换……设数组长度为 $n$，与下标 $i$ 对称的位置是 $n-1-i$。$i$ 只需走到中间：

$$
i = 0,\, 1,\, \ldots,\, \left\lfloor \frac{n}{2} \right\rfloor - 1
$$

**只走一半**是关键：走满全程等于每个元素换两次手，数组恢复原状。以 $n = 5$、数组 `1 2 3 4 5` 为例：

| i | 交换前 | 执行交换 | 交换后 |
|---|---|---|---|
| 0 | 1 2 3 4 5 | a[0] 与 a[4] 互换 | 5 2 3 4 1 |
| 1 | 5 2 3 4 1 | a[1] 与 a[3] 互换 | 5 4 3 2 1 |

$i$ 走到 2（正中元素 3）停止，它与自己对称，交换与否无影响，循环条件 `i < n/2` 自然把它排除。

### 4. 循环左移一位：先抢救队头，再整体前挪

左移一位的含义：`a[0]` 出队，`a[1]` 顶到 `a[0]`，`a[2]` 顶到 `a[1]`……队尾空出的格子由原 `a[0]` 绕回补上。顺序至关重要：

1. **先**把队头 `a[0]` 存进临时变量（不抢救就会被覆盖）；
2. **从前往后**执行 `a[i] = a[i+1]`（$i$ 从 0 到 $n-2$）——每个格子都是"先读后写"，安全；
3. 把临时值放回 `a[n-1]`。

若把第 2 步写成**从后往前**的 `a[i+1] = a[i]`（模拟右移），必须先抢救 `a[n-1]`，否则同样会连环覆盖。方向与抢救位置是一一对应的，做题时先在纸上画箭头再动键盘。

### 5. 本题的两步是串联的

题目要求"在逆序结果的基础上左移"，即对 `5 4 3 2 1` 左移得 `4 3 2 1 5`——数组只有一份，操作依次累积。写代码时切忌各自从原始数据算起。

## 三、解题思路

1. 读入 $n$ 与数组 `a`；
2. 逆序：`for (i = 0; i < n/2; i++)` 做 `a[i] ↔ a[n-1-i]` 三步交换；
3. 输出逆序结果（一行，空格分隔）；
4. 左移：`t = a[0]`，`for (i = 0; i < n-1; i++) a[i] = a[i+1]`，`a[n-1] = t`；
5. 输出移位结果。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int a[100], t;    /* a 为采样序列，t 为交换/移位临时变量 */
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);

    /* 第一步：逆序——对称位置成对互换，i 只走到一半 */
    for (i = 0; i < n / 2; i++) {
        t = a[i];
        a[i] = a[n - 1 - i];
        a[n - 1 - i] = t;
    }

    /* 输出逆序结果：先输出第一个，避免行末多余空格 */
    printf("%d", a[0]);
    for (i = 1; i < n; i++)
        printf(" %d", a[i]);
    printf("\n");

    /* 第二步：循环左移一位——先抢救队头，再整体前挪，队头绕回队尾 */
    t = a[0];
    for (i = 0; i < n - 1; i++)
        a[i] = a[i + 1];
    a[n - 1] = t;

    printf("%d", a[0]);
    for (i = 1; i < n; i++)
        printf(" %d", a[i]);
    printf("\n");

    return 0;
}
```

## 五、运行验证

以样例 1（n=5，数组 `1 2 3 4 5`）逐步核对：

| 步骤 | 操作 | 数组状态 |
|---|---|---|
| 读入后 | — | 1 2 3 4 5 |
| 逆序 i=0 | a[0]↔a[4] | 5 2 3 4 1 |
| 逆序 i=1 | a[1]↔a[3] | 5 4 3 2 1 |
| 输出第 1 行 | — | `5 4 3 2 1` |
| 左移：抢救 | t = a[0] = 5 | 5 4 3 2 1 |
| 左移 i=0 | a[0] = a[1] | 4 4 3 2 1 |
| 左移 i=1 | a[1] = a[2] | 4 3 3 2 1 |
| 左移 i=2 | a[2] = a[3] | 4 3 2 2 1 |
| 左移 i=3 | a[3] = a[4] | 4 3 2 1 1 |
| 左移：绕回 | a[4] = t = 5 | 4 3 2 1 5 |
| 输出第 2 行 | — | `4 3 2 1 5` |

与样例 1 完全一致。样例 2（8 个数）中逆序执行 4 对交换、左移执行 7 次前挪，结果 `6 12 8 25 0 7 -3 10` 与 `12 8 25 0 7 -3 10 6`，同样吻合。

## 六、常见错误与讲解

**错误 1：逆序循环走满全程**

```c
for (i = 0; i < n; i++) { 交换 a[i] 与 a[n-1-i]; }   /* 错：换两次等于没换，输出原序列 */
for (i = 0; i < n / 2; i++) { ... }                  /* 对：只走一半 */
```

**错误 2：交换漏临时变量**

```c
a[i] = a[n-1-i];  a[n-1-i] = a[i];   /* 错：a[i] 原值已丢，两头变成同一个值 */
t = a[i]; a[i] = a[n-1-i]; a[n-1-i] = t;   /* 对：标准三步 */
```

**错误 3：左移先挪后抢救**

```c
for (i = 0; i < n - 1; i++) a[i] = a[i+1];
t = a[0];   /* 错：此时 a[0] 已被 a[1] 覆盖，队头永久丢失 */
```

**错误 4：边界写错导致越界**

```c
for (i = 0; i < n; i++) a[i] = a[i+1];   /* 错：i = n-1 时读 a[n]，越界 */
for (i = 0; i < n - 1; i++) a[i] = a[i+1];   /* 对：最多写到 a[n-1] */
```
