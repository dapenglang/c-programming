# 题目 B7：基于牛顿迭代法的方程求根计算器系统

**适用学院**：人工智能学院（4 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行方程求根计算器：内置并允许文件扩充若干测试方程（多项式、超越方程），用牛顿迭代法从给定初值出发求方程 f(x)=0 的近似根，完整记录每一轮迭代过程；同时实现二分法作为对照方法，输出两种方法的迭代轮数与误差对比表，并绘制函数曲线字符图标出根的位置。

**解决什么重要问题**：工程与科学问题最终几乎都归结为"解方程"，而绝大多数方程（如 e^x=5x-2、x³-2x-5=0）没有求根公式，只能数值求解。牛顿迭代法"初值→切线→新点"的迭代思想是智能算法（梯度下降、优化器）最原始的雏形：每轮都沿着导数指示的方向前进，直到误差足够小。不掌握数值求根，就无法理解"迭代—收敛—发散"这一贯穿后续所有智能算法的基本范式；二分法作为"笨但稳"的对照，则让学生体会收敛速度与稳健性的权衡。

**支撑哪些关键应用**：① 电路与控制系统设计中的特征方程求根；② 机器人运动学反解（关节角度方程）；③ 机器学习中的参数优化（梯度下降与牛顿法同源）；④ 轨道计算与天体定位；⑤ 任何"求函数极值即求导数零点"的优化场景。

**与专业培养的关联**：人工智能专业的"智能控制与机器人""机器学习"课程都建立在"迭代优化"之上。本系统让学生用 C 语言亲手实现最经典的迭代法，观察收敛过程、经历发散情形，建立"初值、步长、精度门限"的第一手感，为后续优化算法学习铺路，全程只需课程内的循环、函数与数学表达式。

## 二、题目任务与专业关联

本题目要求实现一个含 10 个模块的方程求根计算器：(1) 建立测试函数库并从方程文件读入自定义多项式；(2) 用中心差分近似导数值；(3) 实现牛顿迭代主循环，每轮把近似值、函数值、误差写入迭代记录表；(4) 实现发散保护（导数过小、迭代超限、数值爆炸）；(5) 实现二分法对照求解；(6) 从批量方案文件读入多组初值逐个求解，统计收敛率；(7) 输出两种方法的收敛速度对比表，绘制函数曲线字符图，管理主菜单。

专业关联：牛顿迭代是"沿导数方向迭代"的实例，与机器学习优化器的数学骨架完全一致；批量初值实验揭示"初值决定收敛到哪个根、初值不好会发散"，这正是后续优化课程中"局部最优与初始化"问题的直觉来源。

## 三、数据来源与格式

### 3.1 数据文件格式

（1）方程清单文件 `equations.txt`：每行一个自定义多项式方程，格式为"编号 类型 系数列表"，类型 `P` 表示多项式，系数从最高次到常数项排列，空格分隔；`#` 开头为注释行。

```
# 编号  类型  系数（从高次到低次）
1  P  1.0  0.0  -2.0  -5.0      # f(x)=x^3-2x-5，经典测试方程
2  P  1.0  2.0  0.0  -10.0      # f(x)=x^3+x^2-10
3  P  0.5  -3.0  1.0             # f(x)=0.5x^2-3x+1
```

（2）批量初值方案文件 `scan_plan.txt`：每行一个求解任务，格式为"函数编号 初值 最大迭代次数 精度门限"。

```
# 函数编号  初值x0  最大迭代  精度eps
1  2.0   50  0.000001
1  -2.0  50  0.000001
1  0.1   50  0.000001
2  1.5   50  0.000001
3  0.0   50  0.000001
```

（3）系统另内置 2 个超越方程函数（不需文件）：`f(x)=exp(x)-5x+2` 与 `f(x)=sin(x)-0.5x`，连同文件读入的多项式统一按函数编号 1～N 管理。

### 3.2 仿真数据生成规则

本题目数据为方程参数，由小组按下表规则自拟（也可直接采用 3.1 样例）：

| 字段 | 说明 | 单位/取值规则 |
|---|---|---|
| 多项式系数 | 每行 2～6 个 | 常数项与最高次系数取 [-10,10] 内非零值（保证既有常数项又有最高次项），其余系数取 [-5,5] 随机值 |
| 根的分布 | 设计要求 | 每个方程用绘图或试算法预先确认在 [-5,5] 内至少有 1 个实根，最多 3 个 |
| 初值方案 | 每个方程 5～8 个初值 | 在 [-5,5] 内均匀取点，必须包含"好初值"（离根 0.5 以内）、"边缘初值"（离根 2～4）与"已知会发散的初值"（如导数接近零处）各至少 1 个 |
| 异常注入·坏行 | 考察读入健壮性 | 在 equations.txt 中故意混入 1 行"系数个数与类型不符"的坏行，M1 读入时应跳过并计数提示；在 scan_plan.txt 中混入 1 行精度为 0 或负数的坏行，同样跳过 |
| 精度门限 | 统一量纲 | 取 1e-4 ～ 1e-8，便于两种方法对比 |

### 3.3 真实数据集

无公开数据集。方程参数为课程内自拟数据；选做扩展可引入教材附录或《数值分析》教材中的经典测试方程（如 x·e^x=1）。

## 四、数据结构设计

```c
#define MAX_EQ   8          /* 方程上限 */
#define MAX_COEF 8          /* 多项式最高次数 + 1 */
#define MAX_TASK 40         /* 批量求解任务上限 */
#define MAX_REC  400        /* 迭代过程记录上限 */
#define SAMPLE_N 60         /* 曲线采样点数 */

/* 方程条目：统一管理内置函数与文件读入的多项式 */
struct Equation {
    int  type;               /* 0=多项式  1=exp 型  2=sin 型 */
    double coef[MAX_COEF];   /* 多项式系数（高次到低次）；type 1 存 {a,b} 表 exp(x)-a*x+b */
    int  nCoef;              /* 系数个数，多项式次数 = nCoef-1 */
    char name[48];           /* 数学描述字符串，用于屏幕显示与报告 */
};
struct Equation g_eq[MAX_EQ];  int g_eqCount;

/* 单个求解任务（来自 scan_plan.txt） */
struct SolveTask {
    int    eqNo;             /* 函数编号（1 起） */
    double x0;               /* 初值 */
    int    maxIter;          /* 最大迭代轮数 */
    double eps;              /* 精度门限 */
};
struct SolveTask g_task[MAX_TASK];  int g_taskCount;

/* 迭代过程记录：每轮一条，供过程表与对比分析使用 */
struct IterRec {
    int eqNo;                /* 函数编号 */
    int round;               /* 轮次 k */
    double xk;               /* 本轮近似根 */
    double fx;               /* f(xk) */
    double step;             /* |xk - x(k-1)| */
};
struct IterRec g_rec[MAX_REC];  int g_recCount;

int g_status;                /* 求解状态：0=未求解 1=收敛 2=导数过小 3=超限 4=数值爆炸 */
```

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 测试函数库模块**（源文件 `FuncLib.c`）

- 功能简介：登记 2 个内置超越方程；打开 `equations.txt` 逐行读入自定义多项式（按类型 P 解析系数表），坏行跳过并计数；提供统一求值接口 `double f(int eqNo, double x)`，按编号分发到多项式（秦九韶逐项累乘）或内置公式，另有按编号返回方程描述串的函数。
- 输入：`equations.txt` 路径（菜单选择加载，也可只用内置函数）。
- 输出：`g_eq` 数组与 `g_eqCount`；屏幕函数库清单。

**M7 多初值批量求根模块**（源文件 `BatchRoot.c`）

- 功能简介：打开 `scan_plan.txt` 逐行读入求解任务（坏行跳过），对每个任务调用 M3 牛顿迭代（内部经由 M5 保护），把每个初值的收敛轮数、最终根、结束状态汇总成"初值—结局"总表，并统计每个方程的收敛率。
- 输入：`scan_plan.txt`、已加载的函数库。
- 输出：屏幕批量结果总表；填充实 `g_rec` 过程记录。

### 第二部分：算法实现（5 个模块）

**M2 差分求导模块**（源文件 `DiffDeriv.c`）

- 功能简介：实现中心差分 `f'(x) ≈ (f(x+h)-f(x-h)) / (2h)`，默认 h=1e-4；提供交互试验功能：固定一个方程与点，取 h=1、0.1、0.01、1e-4、1e-6 逐一输出差分值与真值误差，让学生直观看到 h 的取舍。
- 输入：函数编号、自变量 x、步长 h。
- 输出：导数近似值；屏幕步长试验表。

**M3 牛顿迭代主循环模块**（源文件 `Newton.c`）

- 功能简介：实现核心迭代 `x(k+1) = x(k) - f(xk)/f'(xk)`：每轮先由 M2 求导，再更新近似值，`|f(xk)| < eps` 或 `|Δx| < eps` 时判收敛；每轮调用 M4 写入过程记录；每轮调用 M5 检查保护条件。
- 输入：函数编号、初值、最大迭代轮数、精度门限。
- 输出：近似根与 `g_status`；过程记录追加到 `g_rec`。

**M4 迭代过程记录模块**（源文件 `RecTable.c`）

- 功能简介：把每轮迭代的（轮次、xk、f(xk)、|Δx|）追加进 `g_rec` 结构体数组；提供按函数编号打印完整迭代过程表的函数（表头对齐、科学计数法显示误差），记录满时给出提示并停止追加。
- 输入：单轮迭代数据。
- 输出：`g_rec`；屏幕迭代过程表。

**M5 发散保护模块**（源文件 `Guard.c`）

- 功能简介：在每轮迭代前做三项检查并置 `g_status`：① `|f'(xk)| < 1e-9` 判"导数过小"防止除零；② `|xk| > 1e6` 判"数值爆炸"；③ 迭代轮数达到 maxIter 判"不收敛"；对每种失败情形输出一句诊断说明（如"初值落在导数近零点附近，建议更换初值"）。
- 输入：当前 xk、导数值、轮数。
- 输出：状态码 `g_status`；屏幕诊断信息。

**M6 二分法对照求解模块**（源文件 `Bisect.c`）

- 功能简介：对同一方程实现二分法：交互输入区间 [a,b]（或从批量方案读入），校验 `f(a)·f(b) < 0`，否则提示重新输入；每次取中点、保留变号半区间，直到区间宽小于 eps；轮次同样写入 `g_rec` 供 M8 对比。
- 输入：函数编号、区间端点 a、b、精度 eps。
- 输出：近似根与所需轮数；屏幕区间收缩过程（每 5 轮打印一次）。

### 第三部分：数据输出（3 个模块）

**M8 收敛速度对比模块**（源文件 `Compare.c`）

- 功能简介：对已求解过的每个方程，取牛顿法（最优初值）与二分法的记录，输出对比表：方法、初值或区间、迭代轮数、最终 `|f(root)|`；计算"二分轮数 ÷ 牛顿轮数"的倍数指标，并把整表写入 `convergence.csv`。
- 输入：`g_rec`、各次求解的状态。
- 输出：屏幕对比表；`convergence.csv`。

**M9 函数曲线字符画模块**（源文件 `Plot.c`）

- 功能简介：对选定方程在用户给定区间等间隔采样 SAMPLE_N 点，把 f(x) 值映射到 24 行 × 60 列字符网格，用 `*` 绘制曲线、用 `-` 画零轴、在求得的根位置打印 `R` 标记，直观展示根与初值的位置关系。
- 输入：函数编号、绘图区间、已求得的根。
- 输出：屏幕字符曲线图。

**M10 主控菜单模块**（源文件 `main.c`）

- 功能简介：文本主菜单（加载方程库 / 显示函数库 / 步长试验 / 单次牛顿求解 / 批量初值求解 / 二分法求解 / 对比表 / 曲线图 / 退出），`do-while + switch` 调度；用状态标记约束"必须先有函数库才能求解"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → switch 分发 M1～M9 → 直至退出。状态约束：所有求解类功能（M3/M6/M7/M8/M9）运行前必须已加载函数库；M8 依赖 M3 与 M6 的求解记录。

**数据流**：

```
equations.txt ──► M1 解析 ──┐
内置超越方程 ────────────────┴─► g_eq 函数库（编号 1~N）
                                     │
scan_plan.txt ──► M7 读任务 ──► g_task[] ──► 逐任务调用 M3
                                     │              │
                                     │     M2 差分求导（每轮）
                                     │              │
                                     │     M5 保护检查（每轮）
                                     │              │
                                     │              ▼
                                     │      M4 迭代记录 g_rec
                                     │              │
用户输入区间 [a,b] ──► M6 二分法 ─────┴────► 记录也写入 g_rec
                                                    │
                              ┌─────────────────────┼──────────────┐
                              ▼                     ▼              ▼
                        M8 对比表/CSV        M9 曲线字符图      屏幕过程表
```

所有模块之间只通过 `g_eq`、`g_task`、`g_rec`、`g_status` 与参数传递交换数据，接口（函数头部）编码前书面约定。

## 十、选做扩展

1. 割线法：用前两轮点的差商 `(f(xk)-f(xk-1))/(xk-xk-1)` 代替导数，多保留一个历史点即可实现，对比其与牛顿法的轮数；
2. 自动找根扫描：在 [-5,5] 内以步长 0.1 扫描 f(x) 变号区间，自动生成二分法的初始区间，实现"一键求出区间内全部实根"；
3. 重根现象实验：构造 f(x)=(x-1)^2 型方程，观察牛顿法在重根附近的收敛变慢现象，把现象记录写入实验小结（只观察，不引入新理论）。
