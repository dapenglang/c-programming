# 第 2 章 练习 22　传感器采样间隔换算

**所属综合实验**：B2（B2-基于滑动平均滤波的传感器数据去噪系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 B2《基于滑动平均滤波的传感器数据去噪系统》（人工智能学院）——本练习是该实验中"采样参数设置"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

传感器数据去噪系统工作时，会以固定的频率连续采集数据。这个频率叫**采样率**，单位是赫兹（Hz），意思是"每秒钟采多少个点"。例如采样率 1000 Hz，表示每秒钟记录 1000 个数值。

可滑动平均滤波要用到"每个点之间的时间间隔"——只有知道相邻两个采样点相差多少**秒**，才能把数据序列还原成随时间变化的信号。采样率是"每秒多少个点"，采样间隔是"每个点占多少秒"，两者互为倒数。B2 去噪系统在建立采样序列前，必须先把这两个量换算清楚。

## 二、任务要求

编写一个完整程序 `sample_interval.c`：

1. 从键盘读入采样率 `fs`（单位 Hz，double 类型）和采样点数 `n`（整数）；
2. 用公式计算采样间隔 $\Delta t = 1 / f_s$（单位：秒），并换算成毫秒；
3. 用公式计算总采样时长 $T = n \times \Delta t$（单位：秒）；
4. 按规定格式输出结果，采样间隔保留 **3 位小数**（毫秒），总时长保留 **4 位小数**（秒）。

## 三、输入输出格式

**输入**：一行，两个数——先是一个实数（采样率 fs），再是一个整数（采样点数 n），用空格分隔。

**输出**：两行。
第一行按格式 `interval = 结果` 输出采样间隔（毫秒，保留 3 位小数）；
第二行按格式 `total = 结果` 输出总时长（秒，保留 4 位小数）。

## 四、样例

**样例 1**

输入：
```
1000 500
```
输出：
```
interval = 1.000
total = 0.5000
```

**样例 2**

输入：
```
500 250
```
输出：
```
interval = 2.000
total = 0.5000
```

## 五、提示

采样间隔与采样率互为倒数：

$$
\Delta t = \frac{1}{f_s}\ \text{（秒）} = \frac{1000}{f_s}\ \text{（毫秒）}
$$

总采样时长是"点数 × 每点时长"：

$$
T = n \times \Delta t
$$

注意：$f_s$ 必须用 `double` 读入并参与除法；若 $f_s$ 被当成整数，`1 / fs` 会退化成整数除法得到 $0$。**写代码时把分子写成 `1.0` 最保险。**

**完成本练习后你将具备的能力**：理解速率的倒数关系、正确书写含除法的算式、用 scanf/printf 同时输入输出多个不同类型的量——这些是实验 B2 中"采样参数模块"的地基。
