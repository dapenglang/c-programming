## 二、预备知识：函数的嵌套调用与调用栈（零基础阅读）

### 1. 问题来源：大计算要拆成小步骤

"由冰块尺寸算浮力"看上去是一步，其实内含三步：先算体积，再算质量，最后算浮力，后一步依赖前一步的结果。模块化的做法是**一个函数只做一件事**：`ice_volume` 只算体积，`ice_mass` 只算质量（它需要体积时就去调 `ice_volume`），`ice_buoyancy` 只算浮力（它需要质量时就去调 `ice_mass`）。这样每层都很短、很清晰。

### 2. 什么是嵌套调用

函数 A 的函数体里出现了对函数 B 的调用，就叫 A 嵌套调用 B。本例的链条是：

```text
main  ──调用──▶  ice_buoyancy  ──调用──▶  ice_mass  ──调用──▶  ice_volume
```

注意：C 语言**不允许把函数定义写在另一个函数的函数体里面**。所谓"嵌套调用"，指的是**调用关系**（谁调用谁）层层深入，而不是把定义套在一起写。三个函数的定义都是平铺在文件里的。

### 3. 执行过程：调用栈是怎么"压"和"弹"的

以样例 1（$l=1.0,\ w=0.5,\ t=0.3$）为例，程序求浮力 `F = ice_buoyancy(1.0, 0.5, 0.3)` 时的过程如下（可把它想象成一摞盘子，后放的先取）：

```text
① main 调用 ice_buoyancy(1.0, 0.5, 0.3)
        └─ ice_buoyancy 挂起，记住"等我拿到质量后再乘 9.8"
② ice_buoyancy 调用 ice_mass(1.0, 0.5, 0.3)
        └─ ice_mass 挂起，记住"等我拿到体积后再乘 917.0"
③ ice_mass 调用 ice_volume(1.0, 0.5, 0.3)
        └─ ice_volume 没有更深的调用，直接算出 1.0*0.5*0.3 = 0.15
④ ice_volume 返回 0.15  ──▶  ice_mass 醒来：0.15 * 917.0 = 137.55
⑤ ice_mass 返回 137.55  ──▶  ice_buoyancy 醒来：137.55 * 9.8 = 1347.99
⑥ ice_buoyancy 返回 1347.99 ──▶  main 拿到浮力并打印
```

**一定是"先进入的最晚返回"**：`ice_volume` 最先算出结果、最早返回；`ice_buoyancy` 最后返回。这就是"调用栈"的先进后出规律。

### 4. 编程翻译

- `ice_volume`：`return l * w * t;`
- `ice_mass`：`return RHO * ice_volume(l, w, t);`（用调用代替重抄体积公式）
- `ice_buoyancy`：`return G * ice_mass(l, w, t);`（用调用代替重抄质量公式）

要点是：**每层把"需要下层算的量"通过调用取得，绝不自己去重算**。这样如果今后体积公式要改成更精确的模型（比如考虑冰块倒角），只需改 `ice_volume` 一处。

## 三、解题思路

1. **定接口**：三个函数都接收 `l、w、t` 三个 `double`，都返回 `double`；这样每个函数都能独立拿到它需要的输入；
2. **写原型**：三个原型放在 `main` 上方；
3. **写定义**：自底向上写——先 `ice_volume`，再让 `ice_mass` 调用它，最后让 `ice_buoyancy` 调用 `ice_mass`；
4. **主流程**：读入尺寸 → 调 `ice_volume` 得体积 → 调 `ice_mass` 得质量 → 调 `ice_buoyancy` 得浮力 → 三行输出；
5. **校核**：用样例 1 手算 $0.15\to137.55\to1347.99$。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明 */
double ice_volume(double l, double w, double t);
double ice_mass(double l, double w, double t);
double ice_buoyancy(double l, double w, double t);

int main(void)
{
    double l, w, t;            /* 冰块长、宽、厚，m */
    double V, m, F;            /* 体积、质量、浮力 */

    scanf("%lf %lf %lf", &l, &w, &t);

    V = ice_volume(l, w, t);       /* 第 1 层：体积 */
    m = ice_mass(l, w, t);         /* 第 2 层：质量（内部调用体积） */
    F = ice_buoyancy(l, w, t);     /* 第 3 层：浮力（内部调用质量） */

    printf("V = %.4f m^3\n", V);
    printf("m = %.4f kg\n", m);
    printf("F = %.4f N\n", F);

    return 0;
}

/* 第一层：由尺寸求体积 */
double ice_volume(double l, double w, double t)
{
    return l * w * t;
}

/* 第二层：由体积求质量，通过调用取得体积 */
double ice_mass(double l, double w, double t)
{
    const double RHO = 917.0;             /* 冰的密度，kg/m^3 */
    return RHO * ice_volume(l, w, t);
}

/* 第三层：由质量求浮力，通过调用取得质量 */
double ice_buoyancy(double l, double w, double t)
{
    const double G = 9.8;                 /* 重力加速度，m/s^2 */
    return G * ice_mass(l, w, t);
}
```

## 五、运行验证

以样例 1 为例，`F = ice_buoyancy(1.0, 0.5, 0.3)` 的调用过程与中间结果：

| 层 | 调用 | 本层算得 | 返回给谁 |
|---|---|---|---|
| ③ | `ice_volume(1.0, 0.5, 0.3)` | $1.0\times0.5\times0.3=0.15$ | `ice_mass` |
| ② | `ice_mass` 收 0.15 | $917\times0.15=137.55$ | `ice_buoyancy` |
| ① | `ice_buoyancy` 收 137.55 | $9.8\times137.55=1347.99$ | `main` |

三组输入的完整结果：

| 输入 l w t | 体积 V (m³) | 质量 m (kg) | 浮力 F (N) |
|---|---|---|---|
| 1.0 0.5 0.3 | 0.1500 | 137.5500 | 1347.9900 ✓ |
| 2.0 1.0 0.2 | 0.4000 | 366.8000 | 3594.6400 ✓ |
| 1.5 1.0 0.4 | 0.6000 | 550.2000 | 5391.9600 ✓ |

中间结果与最终结果逐一吻合，证明嵌套调用的层次与返回值传递都正确。

## 六、常见错误与讲解

**错误 1：把嵌套方向弄反，形成循环调用**

```c
double ice_volume(double l, double w, double t) { return ice_mass(l, w, t) / 917.0; }  /* 错 */
double ice_mass(double l, double w, double t) { return 917.0 * ice_volume(l, w, t); }
```

两个函数互相调用、谁也无法先算出结果，运行时会陷入无限递归直至栈溢出。**依赖关系必须单向**：体积 → 质量 → 浮力，不能回头。

**错误 2：在函数里重抄下层公式，导致下层函数根本没被调用**

```c
double ice_mass(double l, double w, double t) { return 917.0 * (l * w * t); }  /* 能用，但背离了嵌套调用 */
```

这样写虽然结果正确，却失去了模块化的意义：体积公式被复制了一份，改一处就要改多处。**应当写成 `917.0 * ice_volume(l, w, t)`**。

**错误 3：忘记函数原型**

```c
int main(void) { ... ice_buoyancy(l, w, t); ... }   /* 编译报错：未声明 */
```

三个函数都要有原型，且原型中的参数类型、返回类型必须与实际定义完全一致。

**错误 4：常量写成整数或参数顺序错**

```c
const int RHO = 917;              /* 建议写 917.0，避免整数参与运算的歧义 */
V = ice_volume(t, w, l);          /* 长宽厚顺序乱填 */
```

体积公式对 $l、w、t$ 相乘是对称的，顺序错不影响数值；但一旦换成不对称的公式就会静默出错，**养成按语义顺序传参的习惯**。

## 七、与综合实验的衔接

- 在实验 **C8（碎冰浮力吃水计算系统）**中，这条函数链还要继续往下延伸：浮力求完后，用"浮力 = 排水体积 × 水密度 × g"反解吃水，再配合二分法迭代。本练习写好的 `ice_volume`、`ice_mass`、`ice_buoyancy` 正是这条长链的前三节；
- 嵌套调用是后续所有大型程序的骨架：读入模块调用校验模块，计算模块调用各子公式函数，输出模块调用格式化函数。**"每层只做一件事、下层供上层调用"，是模块化设计最基本的分工方式。**
