## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

前两题已说明：内存里的数据"程序一停就没了"，而文件让数据能长期保存。本题关心的不是保存单个数，而是一张**表**——很多条结构相同的记录。工程数据几乎都以表格形式存在：压力测点表、阻力样本表、冰块清单表；程序常做的工作就是"读进一张表、加工、再写出一张表"。

### 2. 文件操作的标准四步曲

C 语言操作文件，无论读写都遵循同一条流水线：

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题用 `fscanf` 读、`fprintf` 写；
4. **关闭文件**：`fclose(fp);`。

本题要同时管两个文件，就声明两个指针：`FILE *fin, *fout;`，一个读、一个写。

**`fopen` 返回的 `FILE *` 是什么？** 它是这次文件访问的"编号牌"。系统为每个打开的文件建立一套记录（文件在哪、当前进行到哪、是读还是写），指针就指向它；其中有一个**文件位置指针**标明"当前处理到第几个字节"，每读一个字段就自动后推，两个文件各有各的位置指针，互不干扰。

**打开失败会怎样？** 输入文件不存在，或输出文件无法创建（磁盘满、目录只读），`fopen` 都返回 `NULL`。不判空就用，程序会崩溃，所以打开后**必须**紧跟判空：

```c
if (fin == NULL) { printf("打不开 pressure.txt\n"); return 1; }
```

### 3. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fscanf` | 按格式读 | `fscanf(fin, "%d%lf", &id, &p);` | 从文本里按格式读数字 |
| `fprintf` | 按格式写 | `fprintf(fout, "%d %.2f\n", id, p);` | 把数字按人可读格式写进文本 |
| `fgets` | 读一整行 | `fgets(buf, sizeof(buf), fp);` | 一行里有字符串、需要整行处理 |
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理（词频统计） |
| `fread`/`fwrite` | 按字节块读写 | `fread(a, sizeof(double), n, fp);` | 二进制文件、批量存数组 |

本题是"读两列数字、写两列数字"的文本表格，所以读选 `fscanf`、写选 `fprintf`，它们与键盘/屏幕上的 `scanf`/`printf` 用法一模一样，只是多一个文件指针参数。

### 4. 打开模式的区别

| 模式 | 含义 | 文件已存在时 |
|---|---|---|
| `"r"` | 只读文本 | 从文件头开始读，不存在则失败 |
| `"w"` | 只写文本 | **清空原有内容**，从头开始写 |
| `"a"` | 追加文本 | 保留原有内容，从末尾接着写 |
| `"rb"`/`"wb"` | 二进制只读/只写 | 同上，但按二进制方式处理 |

输入用 `"r"`（保护原数据），输出用 `"w"`（生成全新表）。特别提醒：**输出若误用 `"r"` 会打开失败，输入若误用 `"w"` 会把源数据清空**。

### 5. 用本题的数据走一遍文件指针

输入文件内容：

```
1 12.5
2 18.3
3 9.75
```

`fopen` 后 `fin` 的位置指针停在开头。循环判断 `fscanf(fin, "%d%lf", &id, &p) == 2`：第一次成功读到 `1` 和 `12.5`，返回 2，进入循环体算出 `12500.0`，`fprintf` 往 `fout` 写下 `1 12500.00`；第二次读到 `2`、`18.3`，写下 `2 18300.00`；第三次读到 `3`、`9.75`，写下 `3 9750.00`。第四次再调用 `fscanf` 时已无数据，它返回 `EOF`（不是 2），循环结束。`count` 此时为 3，打印提示后两个文件都 `fclose`。**`fscanf` 的返回值告诉我们"到底读到了几个字段"，用它当循环条件就能优雅地读到文件尾。**

## 三、解题思路

1. **开两个文件**：先开输入 `"r"`，再开输出 `"w"`，逐个判空（第二个失败要先关第一个）；
2. **循环读**：条件写成 `fscanf(fin, "%d%lf", &id, &p) == 2`；
3. **每条处理**：`p_pa = p * 1000.0`，`fprintf(fout, ...)` 写一行，`count++`；
4. **关闭两个文件**：先 `fclose(fin)` 再 `fclose(fout)`；
5. **屏幕汇报**：输出转换条数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fin, *fout;             /* 输入文件与输出文件的指针 */
    int    id, count = 0;         /* 测点号 与 已转换条数 */
    double p_kpa, p_pa;           /* 原始压力(kPa) 与 换算后压力(Pa) */

    /* 打开输入文件（只读） */
    fin = fopen("pressure.txt", "r");
    if (fin == NULL) {
        printf("无法打开输入文件 pressure.txt\n");
        return 1;
    }

    /* 打开输出文件（写），失败时先关掉输入文件再返回 */
    fout = fopen("pressure_pa.txt", "w");
    if (fout == NULL) {
        printf("无法创建输出文件 pressure_pa.txt\n");
        fclose(fin);
        return 1;
    }

    /* 逐条读取：只要还能成功读到 2 个字段就继续 */
    while (fscanf(fin, "%d%lf", &id, &p_kpa) == 2) {
        p_pa = p_kpa * 1000.0;                 /* kPa -> Pa */
        fprintf(fout, "%d %.2f\n", id, p_pa);  /* 写入新表 */
        count++;
    }

    /* 先关输入再关输出，确保数据落盘 */
    fclose(fin);
    fclose(fout);

    printf("转换完成，共 %d 条记录，已写入 pressure_pa.txt\n", count);

    return 0;
}
```

## 五、运行验证

**样例 1：运行前** `pressure.txt` 内容：
```
1 12.5
2 18.3
3 9.75
```
屏幕输出：
```
转换完成，共 3 条记录，已写入 pressure_pa.txt
```
**运行后** `pressure_pa.txt` 内容：
```
1 12500.00
2 18300.00
3 9750.00
```
逐行核对：$12.5 \times 1000 = 12500$ → `12500.00`；$18.3 \times 1000 = 18300$ → `18300.00`；$9.75 \times 1000 = 9750$ → `9750.00`。与题面一致，且 `pressure.txt` 内容保持不变。

**样例 2：运行前** `pressure.txt` 内容：
```
101 5.5
102 7.25
```
屏幕输出：
```
转换完成，共 2 条记录，已写入 pressure_pa.txt
```
**运行后** `pressure_pa.txt` 内容：
```
101 5500.00
102 7250.00
```
$5.5 \times 1000 = 5500$，$7.25 \times 1000 = 7250$，换算正确。

## 六、常见错误与讲解

**错误 1：用一个文件指针同时管读和写**

```c
FILE *fp = fopen("pressure.txt", "r");
fprintf(fp, "%d %.2f\n", id, p);      /* 错：只读文件不能写，写不进去 */
```
读和写的目标文件不同，必须用两个指针。混用一个，轻则写不进去，重则误清空源文件。

**错误 2：循环条件写错，导致多读一条或死循环**

```c
while (!feof(fin)) { fscanf(fin, "%d%lf", &id, &p_kpa); ... }   /* 错：最后一次会多处理一条 */
```
`feof` 是在"读失败之后"才为真的，用它做条件会让最后一次读到的空数据也被处理一遍。**改用 `while (fscanf(fin, "%d%lf", &id, &p_kpa) == 2)`，以读取成功为条件最稳妥。**

**错误 3：输出模式用错，或第二个文件打开失败却不收尾**

```c
fout = fopen("pressure_pa.txt", "r");   /* 错：只读模式无法写入新文件 */
fout = fopen("pressure_pa.txt", "w");   /* 对：写模式，文件不存在会新建 */
```
要生成新表就用 `"w"`；若第二个文件打开失败要中途返回，应先把已打开的 `fin` 关掉再退出。

## 七、与综合实验的衔接

实验 C9 的压力场系统在把原始测点表交给强度计算之前，正需要这样一次"单位换算 + 转存"；实验 C7 把辨识结果从一种单位或格式转成另一种，也走同一条"读表—处理—写表"的流水线。本练习的骨架（开两文件、循环 `fscanf` 读、`fprintf` 写、按返回值判断结束）是后面所有文件处理题的通用套路。当数据表多到需要按条件查询、跨表关联、多人共享时，纯文本文件会显得笨重，第 8 章 8.7 节的数据库技术提供了更系统的持久化与管理方案。
