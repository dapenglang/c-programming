## 二、预备知识：采样率与采样间隔的基本原理（零基础阅读）

### 1. 问题是怎么来的

传感器采集数据是"按节拍来的"。这个节拍有两个描述方式：

- **采样率** $f_s$：每秒钟采集多少个数据点，单位赫兹（Hz）。例如 $f_s = 1000$ Hz，就是每秒 1000 个点。
- **采样间隔** $\Delta t$：相邻两个数据点之间相隔多少秒，单位秒（s）。例如 $\Delta t = 0.001$ s，就是每 1 毫秒采一个点。

它们是同一件事的两种说法，只是**以时间为基准还是以个数为基准**的区别。

### 2. 公式是怎么来的

"每秒钟 1000 个点"意味着"1000 个点总共占 1 秒"，那么一个点占的时间就是 1 秒除以 1000：

$$
\Delta t = \frac{1}{f_s}
$$

这就是**互为倒数**的关系：$f_s = 1000$ 时 $\Delta t = 0.001$ s；$f_s = 500$ 时 $\Delta t = 0.002$ s。采样率越高，间隔越短，两个点挨得越近——符合直觉。

总采样时长是"点数 × 每点时长"：

$$
T = n \times \Delta t = \frac{n}{f_s}
$$

### 3. 用本例走一遍

**例 1**：$f_s = 1000$ Hz，$n = 500$。

- 采样间隔：$\Delta t = 1 / 1000 = 0.001$ s，换算成毫秒是 $0.001 \times 1000 = 1.000$ ms；
- 总时长：$T = 500 \times 0.001 = 0.5000$ s。

**例 2**：$f_s = 500$ Hz，$n = 250$。

- 采样间隔：$\Delta t = 1 / 500 = 0.002$ s $= 2.000$ ms；
- 总时长：$T = 250 \times 0.002 = 0.5000$ s。

两例总时长都是 0.5 s，但采样率减半、点数也减半，正好抵消——这个结果可以帮助我们验证换算没有算错。

### 4. 编程时怎么用它

编程只需两步：`dt = 1.0 / fs;` 和 `T = n * dt;`。唯一的陷阱是**除数与被除数都必须是实数**。若写 `1 / fs` 而 `fs` 是 `int`，编译器按整数除法算，$1/1000$ 得 $0$；即使用 `double` 读入 `fs`，也建议把分子写成 `1.0` 提醒自己"这是实数运算"。

单位换算（秒 → 毫秒）就是乘以 1000，写成 `dt * 1000.0`。

> **这个思想在综合实验中反复出现**：B2 传感器采样（采样率→间隔）、B1 图像处理（像素数→采集时间）、D1 核素衰变（半衰期→速率），都是"速率与周期互为倒数"同一个套路。

## 三、解题思路

1. **确定变量**：采样率 `fs` 用 `double`，采样点数 `n` 用 `int`，间隔 `dt`、总时长 `T` 用 `double`；
2. **读入**：一条 `scanf` 同时读入两个不同类型的量，格式串为 `"%lf %d"`；
3. **换算**：先算秒制间隔 `dt = 1.0 / fs`，再算总时长 `T = n * dt`；
4. **输出**：毫秒用 `dt * 1000.0` 且 `%.3f`，秒用 `T` 且 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double fs;    /* 输入：采样率，单位 Hz */
    int n;        /* 输入：采样点数 */

    double dt;    /* 采样间隔，单位 s */
    double T;     /* 总采样时长，单位 s */

    /* 读入采样率（实数）与采样点数（整数） */
    scanf("%lf %d", &fs, &n);

    /* 采样间隔：采样率的倒数。分子写 1.0 保证实数除法 */
    dt = 1.0 / fs;

    /* 总时长 = 点数 × 间隔 */
    T = n * dt;

    /* 输出：间隔换算为毫秒（×1000），保 3 位小数 */
    printf("interval = %.3f\n", dt * 1000.0);
    /* 输出：总时长以秒计，保 4 位小数 */
    printf("total = %.4f\n", T);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 1000 500 | dt = 1/1000 = 0.001 s = 1.000 ms；T = 500×0.001 = 0.5000 s | `interval = 1.000` / `total = 0.5000` ✓ |
| 500 250 | dt = 1/500 = 0.002 s = 2.000 ms；T = 250×0.002 = 0.5000 s | `interval = 2.000` / `total = 0.5000` ✓ |
| 2000 100 | dt = 1/2000 = 0.0005 s = 0.500 ms；T = 100×0.0005 = 0.0500 s | `interval = 0.500` / `total = 0.0500` ✓ |
| 100 1000 | dt = 1/100 = 0.01 s = 10.000 ms；T = 1000×0.01 = 10.0000 s | `interval = 10.000` / `total = 10.0000` ✓ |

采样率与点数同比例变化时总时长不变，说明换算关系正确。

## 六、常见错误与讲解

**错误 1：整数除法（最典型）**

```c
int fs;
scanf("%d", &fs);
dt = 1 / fs;      /* 错：1 与 fs 都是 int，1/1000 = 0 */
dt = 1.0 / fs;    /* 对：分子是 double，按实数除 */
```

**错误 2：忘记换算单位**

```c
printf("interval = %.3f\n", dt);        /* 错：输出的是秒，值是 0.001 */
printf("interval = %.3f\n", dt * 1000.0); /* 对：转成毫秒，值 1.000 */
```

题目要求的是**毫秒**，直接输出秒会差 1000 倍。

**错误 3：scanf 格式串与变量类型不匹配**

```c
scanf("%d %d", &fs, &n);    /* 错：fs 是 double，用 %lf */
scanf("%lf %d", &fs, &n);   /* 对 */
```

`double` 输入用 `%lf`，`int` 输入用 `%d`，顺序要和变量顺序一致。

**错误 4：误用 n / fs 与 n * dt 混算**

```c
T = n * 1 / fs;    /* 危险：若 1/fs 先按整数算则出错 */
T = n * (1.0 / fs);/* 对：先算实数间隔，再乘点数 */
```

建议先求出 `dt` 存成变量，再用 `T = n * dt`，逻辑最清晰。
