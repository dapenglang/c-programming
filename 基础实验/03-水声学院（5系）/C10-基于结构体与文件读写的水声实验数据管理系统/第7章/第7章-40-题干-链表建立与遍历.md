# 第 7 章 练习 40　链表建立与遍历（测点链）

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：7 链表（7.4 链表的定义、7.5 头插法建立链表、7.6 链表遍历）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"链表建立与遍历"环节的最小实现。

**建议用时**：40 分钟

## 一、应用场景

测点记录的条数事先不确定：出海一趟可能测到 5 条，也可能 200 条。数组要预先定长度，不够用会溢出、太大又浪费。**链表**用多少申请多少：每条记录是一个节点，节点之间用指针串起来，像一列车厢。

建立链表最简单的办法是**头插法**：新节点总插在链头。副作用是节点顺序与录入顺序**相反**——本题就让你亲手体验这一点。综合实验 C10 的链表建立模块（M4）用的正是这套代码。

## 二、任务要求

编写一个完整程序 `list_build.c`：

1. 定义节点类型：
   ```c
   struct Node {
       char id[16];       /* 测点编号 */
       double depth;      /* 水深 m */
       struct Node *next; /* 指向下一节点 */
   };
   ```
2. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 50**）与 `n` 条记录（每行 `编号 水深`）；
3. 用**头插法**把 `n` 条记录建成链表（每条记录 `malloc` 一个节点）；
4. 从表头出发遍历链表：逐节点输出编号与水深，同时统计节点个数，最后输出总数。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后 `n` 行，每行 `编号 水深`。

**输出**：每节点一行（格式：编号左对齐占 9 列，水深右对齐占 9 列保留 2 位小数），末行输出 `共 x 个节点`。

## 四、样例

**样例 1**

输入：
```
3
S01 15.5
S02 18.2
S03 22.0
```
输出（注意顺序与录入相反）：
```
S03          22.00
S02          18.20
S01          15.50
共 3 个节点
```

**样例 2**

输入：
```
1
A7 3.0
```
输出：
```
A7           3.00
共 1 个节点
```

## 五、提示

- 节点要**动态申请**：`p = (struct Node *)malloc(sizeof(struct Node));`（头文件 `<stdlib.h>`），用完的程序结束前逐节点 `free`；
- 头插三步曲（`head` 是头指针，初值 `NULL`）：
  ```c
  p->next = head;   /* 1. 新节点牵住旧链头 */
  head = p;         /* 2. 新节点升任链头 */
  ```
  先接后断，顺序不能反；
- 遍历的标准姿势：
  ```c
  for (p = head; p != NULL; p = p->next) { ...p->id, p->depth... }
  ```
  末节点 `next == NULL`，循环自然终止；
- 想一想：头插后为什么顺序反了？第 1 条记录先入链，之后每条新记录都排到它**前面**——所以最后入链的 `S03` 反而在表头。

**完成本练习后你将具备的能力**：`malloc` 申请节点、头插法建链、沿 `next` 指针遍历——这是实验 C10 中"链表建立模块"（M4）的地基，也是练习 41 增删操作的前提。
