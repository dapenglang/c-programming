# 第 4 章 练习 10　递归求组合数

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 B3《基于蒙特卡洛方法的随机模拟实验系统》（人工智能学院）——本练习是该实验中"组合计数"环节的实现（对应 4.3 递归调用）。

**建议用时**：25 分钟

## 一、应用场景

组合数 $C_n^k$（也记作 $\binom{n}{k}$）表示"从 $n$ 个不同元素中任取 $k$ 个"的方案数，是概率计算、随机抽样、二项分布里最常用的量。实验 B3 在估算各类随机事件的概率时，经常需要算出这样一组组合数。组合数有一个来自杨辉三角的漂亮递推：$C_n^k = C_{n-1}^{k-1} + C_{n-1}^{k}$。这又是一个双分支递归，而且比斐波那契更规整。本练习用递归实现它。

## 二、任务要求

编写一个完整程序 `comb.c`：

1. 必须定义**递归函数**，**函数原型为**
   ```c
   long long comb(int n, int k);
   ```
   返回组合数 $C_n^k$；
2. 函数必须同时具备两部分：
   - **基线条件**：当 `k == 0 || k == n` 时返回 `1`；
   - **递推关系**：否则返回 `comb(n - 1, k - 1) + comb(n - 1, k)`；
3. 主函数读入两个整数 `n`、`k`（题目保证 $0 \le k \le n \le 30$），调用 `comb`；
4. 按格式输出结果（用 `long long` 与 `%lld`）。

## 三、输入输出格式

**输入**：一行，两个整数 n、k，用空格分隔（$0 \le k \le n \le 30$）。

**输出**：一行，按格式 `C(n,k) = 结果` 输出，例如输入 `5 2` 时输出 `C(5,2) = 10`。

## 四、样例

**样例 1**

输入：
```
5 2
```
输出：
```
C(5,2) = 10
```

**样例 2**

输入：
```
10 3
```
输出：
```
C(10,3) = 120
```

## 五、提示

杨辉三角（帕斯卡）递推：

$$
C_n^0 = C_n^n = 1,\qquad C_n^k = C_{n-1}^{k-1} + C_{n-1}^{k}\quad(0 < k < n)
$$

**两条基线缺一不可**：只写 `k == 0` 时，遇到"取全部 $k=n$"的情形会继续往 `k>n` 递归下去而永不到达基线；只写 `k == n` 时，遇到"取 0 个"的情形同样停不下来。边界与内部规则要配套使用。

**完成本练习后你将具备的能力**：实现带两个变量的双分支递归、正确设置多个基线条件、理解杨辉三角递推背后的组合意义——这是本章递归训练的收官，也是实验 B3 随机模拟与概率统计的计算基础。
