# 第 5 章 练习 10　有序数组插入与删除

**对应章节**：5 批量数据处理方法（5.1 一维数组——有序表维护；3.3 循环结构）

**场景来源**：综合实验 C6《海冰与结构碰撞模拟系统》（水声学院）——本练习是该实验中"冰块质量有序表维护"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

碰撞模拟系统把场景中的冰块按质量**从小到大**维护在一张有序表里（便于后续按质量段快速筛选与统计）。模拟运行中冰况不断变化：新监测到一块冰，要**插入**表中且不破坏有序；某块冰完全融化离开场景，要把它从表中**删除**且不留空洞。这两种操作都要靠"数组的整体搬移"实现：插入是**腾位置**（后半段整体后移），删除是**补空位**（后半段整体前移）。本练习把练习 03 练过的搬移方向感用到真实的表维护中，是数组算法的综合收尾。

## 二、任务要求

编写一个完整程序 `ordered_table.c`：

1. 读入冰块个数 `n`（`int`，**$3 \le n \le 98$**），再读入 $n$ 个**从小到大已排好**的质量存入长度为 100 的 `double` 数组（单位：t，数据互不相同）；
2. 读入待插入质量 `x`（`double`，保证表中不存在），将其插入数组使序列**仍保持升序**；
3. 读入待删除质量 `y`（`double`，保证在表中存在），在插入后的数组中找到 `y` 并删除它，其后元素整体前移补位；
4. 输出最终数组的 $n$ 个元素，空格分隔（行末不留多余空格），保留 **2 位小数**。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个升序实数；第三行两个实数 `x` 与 `y`（空格分隔）。

**输出**：一行，$n$ 个实数按升序输出，保留 2 位小数，空格分隔。

## 四、样例

**样例 1**

输入：
```
6
2.5 4.0 6.5 8.0 9.5 12.0
7.0 8.0
```
输出：
```
2.50 4.00 6.50 7.00 9.50 12.00
```

**样例 2**

输入：
```
5
1.2 3.4 5.6 7.8 9.9
10.5 1.2
```
输出：
```
3.40 5.60 7.80 9.90 10.50
```

## 五、提示

1. 插入三步：**找位置**（从前往后找第一个大于 `x` 的下标 `p`）→ **后移腾位**（下标 $n-1$ 到 $p$ 的元素逐个 `a[i+1] = a[i]`）→ **落位**（`a[p] = x`），表长变 $n+1$；
2. 后移必须**从后往前**搬：若从 `p` 开始往后 `a[i+1] = a[i]`，会把未搬的元素覆盖丢失；
3. 删除三步：**找位置**（找到值等于 `y` 的下标 `p`）→ **前移补位**（下标 $p+1$ 到 $n$ 的元素逐个 `a[i-1] = a[i]`）→ 表长减 1；
4. 前移必须**从前往后**搬（先读后写，方向与后移相反）；
5. 本题数据保证 x 不在表中、y 必在表中，无需处理重复与缺失；但**插入到末尾**（x 比所有元素都大）与**删除队头**（y 是最小元素）两种边界照样会发生，思路要覆盖它们。

**完成本练习后你将具备的能力**：完成有序表的定位插入与定点删除、根据操作类型正确选择搬移方向、维护数组"实际长度"随增删变化——这是数组数据管理的综合演练，也是实验 C6 冰况动态更新的核心工序。
