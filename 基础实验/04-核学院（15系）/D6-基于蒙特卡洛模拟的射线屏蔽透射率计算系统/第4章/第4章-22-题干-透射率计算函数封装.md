# 第 4 章 练习 22　透射率计算函数封装

**所属综合实验**：D6（D6-基于蒙特卡洛模拟的射线屏蔽透射率计算系统）

**对应章节**：4 函数与模块化程序设计（4.1 函数的定义、声明与调用、4.2 参数传递与返回值、4.3 变量的存储属性与作用域、4.4 模块化设计）

**场景来源**：综合实验 D6《基于蒙特卡洛模拟的射线屏蔽透射率计算系统》（核学院）——本练习是该实验中"透射率计算模块"的接口封装，供整个系统反复调用。

**建议用时**：25 分钟

## 一、应用场景

在综合实验 D6 里，透射率 $T = e^{-\mu x}$ 要算非常多次：不同材料、不同厚度、理论对照、批量扫描……如果每处都手写一遍 `exp(-mu * x)`，代码会重复、容易写错，改进公式时还要逐处修改。

正确的做法是**封装成一个函数**，把"输入 μ 和 x、输出透射率"这件事独立成一个小模块：

$$
\text{trans}(\mu, x) = e^{-\mu x}
$$

全程序需要透射率的地方都调用 `trans`，公式只写一次、只维护一处。本题就来实现这个**函数接口约定**：

```c
double trans(double mu, double x);
```

## 二、任务要求

编写一个完整程序 `trans_func.c`：

1. 定义函数 `double trans(double mu, double x)`，功能是返回透射率 $e^{-\mu x}$（即 `exp(-mu * x)`）；
2. 在 `main` 函数中调用它，完成下面的计算流程：先读入材料线衰减系数 `mu` 和屏蔽厚度 `x`（都是 double，**题目保证 mu > 0、x ≥ 0**），再调用 `trans` 求透射率，最后输出结果（保留 4 位小数）；
3. 函数 `trans` 中不得使用任何输入输出语句——它只负责**计算并返回结果**，输入输出一律留给 `main`（这是模块化设计的基本纪律）；
4. 在 `main` 上方为 `trans` 写函数声明（原型），说明它的接口。

## 三、输入输出格式

**输入**：一行，两个实数，依次为线衰减系数 μ（1/cm）和屏蔽厚度 x（cm），用空格分隔。

**输出**：一行，按格式 `T = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
0.78 2
```
输出：
```
T = 0.2101
```

**样例 2**

输入：
```
0.35 3
```
输出：
```
T = 0.3499
```

## 五、提示

- 函数定义的三要素：**返回类型**（double）、**函数名**（trans）、**参数表**（double mu, double x）；
- 函数体只有一句 `return exp(-mu * x);`，形成"输入参数 → 一步计算 → 返回值"的清晰结构；
- 调用处写成 `T = trans(mu, x);`——实参按**位置**依次传给形参 `mu`、`x`；
- 别忘了 `#include <math.h>`；
- 想一想：把公式封装成函数后，如果将来要改成"含积累因子的宽束衰减"，只需修改 `trans` 一个地方——这正是模块化的价值。

**完成本练习后你将具备的能力**：定义带返回值的函数、声明函数原型、完成参数传递与返回值接收、把一段计算封装成可复用的模块——这些是实验 D6 中"计算模块封装"的地基。
