## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 问题是怎么来的——为什么需要文件

前面所有程序的数据都"活"在内存里：**程序一结束，数据就全丢了**。下次运行又得从头输入。真实系统必须能**保存**数据：规范表要能更新、计算结果要能存档、昨天算的数据今天要能接着用。

解决办法是**文件**——把数据存到硬盘上，程序结束也不丢。C 语言把文件当作一种"流"，用一组专门的函数来读写。

### 2. 文件操作四步曲

**第一步：打开文件**，拿到一个"文件指针"，代表这个文件：

```c
FILE *fin = fopen("wind_in.txt", "r");
```

`"r"` 是**打开模式**，常见的有三种：

| 模式 | 含义 | 文件不存在时 |
|---|---|---|
| `"r"` | 只读 | 返回 NULL（失败） |
| `"w"` | 只写（**清空原内容**） | 新建 |
| `"a"` | 追加（在末尾续写） | 新建 |

**注意 `"w"` 会先把原文件清空**，这是最危险的模式，用之前要确认这就是你想要的。

**第二步：读写**，用 `fscanf`/`fprintf`（文本文件）。它们和 `scanf`/`printf` 几乎一样，只是第一个参数多了一个文件指针：

```c
fscanf(fin, "%lf %lf", &h, &mz);           /* 从 fin 读 */
fprintf(fout, "h=%.0f wk=%.3f\n", h, w);   /* 往 fout 写 */
```

**第三步：关闭文件**，把缓冲区里的内容真正落盘：

```c
fclose(fin);
fclose(fout);
```

**第四步：检查是否成功**。`fopen` 打开失败（文件不存在、没权限、路径写错）会返回 `NULL`。**必须检查**，否则后面用 `NULL` 指针对文件操作会直接崩溃：

```c
if (fin == NULL) { printf("open failed\n"); return 1; }
```

### 3. 怎么知道读到文件尾了——判断 fscanf 的返回值

`fscanf` 的返回值是**成功读到的数据项数**。如果这次要读两个数：

- 读到 2 个，返回 2；
- 遇到文件尾只能读到 0 个或 1 个，返回 0 或 1（或 EOF）。

于是标准的读取循环是：

```c
while (fscanf(fin, "%lf %lf", &h, &mz) == 2) {
    /* 只有成功读到两个数才进循环体 */
}
```

读到最后，`fscanf` 返回小于 2，循环自然结束。这比用别的办法判断"文件有没有结束"更稳妥，也避免了"多读一次"的典型错误。

### 4. 用本例走一遍

假设 `wind_in.txt` 内容为：

```
0.55
10 1.00
20 1.23
30 1.42
```

程序先单独读第一行 $w_0 = 0.55$（用一次 `fscanf(fin, "%lf", &w0)`），然后进入循环：

- 读 `10 1.00` → 返回 2，算 $w_k = 1.00\times0.55 = 0.550$，写入 `h=10 wk=0.550`；
- 读 `20 1.23` → 算 $1.23\times0.55 = 0.6765\approx0.677$，写 `h=20 wk=0.677`；
- 读 `30 1.42` → 算 $1.42\times0.55 = 0.781$，写 `h=30 wk=0.781`；
- 再读，遇到文件尾返回 0，循环结束。

共处理 3 条记录，屏幕输出 `rows=3`。

## 三、解题思路

1. **打开输入文件**，检查 `fin` 是否非空；
2. **打开输出文件** `"w"`；
3. **先读第一行** $w_0$；
4. **循环读记录**：`while (fscanf(...)==2)`，逐条算风压、写输出文件、计数加 1；
5. **关闭两个文件**，屏幕输出记录条数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fin, *fout;
    double w0;            /* 基本风压，kN/m^2 */
    double h, mz, wk;     /* 高度、系数、风压 */
    int rows = 0;         /* 处理记录条数 */

    /* 打开输入文件（只读），必须检查是否成功 */
    fin = fopen("wind_in.txt", "r");
    if (fin == NULL) {
        printf("open input failed\n");
        return 1;
    }

    /* 打开输出文件（只写） */
    fout = fopen("wind_out.txt", "w");
    if (fout == NULL) {
        printf("open output failed\n");
        fclose(fin);      /* 输入文件已开，先关掉 */
        return 1;
    }

    /* 第一行读基本风压 */
    fscanf(fin, "%lf", &w0);

    /* 循环读取后续每条记录，直到读到两个数为止 */
    while (fscanf(fin, "%lf %lf", &h, &mz) == 2) {
        wk = mz * w0;                                   /* 风压 = 系数 × 基本风压 */
        fprintf(fout, "h=%.0f wk=%.3f\n", h, wk);        /* 写入输出文件 */
        rows++;                                          /* 计数 */
    }

    /* 关闭两个文件 */
    fclose(fin);
    fclose(fout);

    printf("rows=%d\n", rows);
    return 0;
}
```

## 五、运行验证

**样例 1**：运行前 `wind_in.txt` 为

```
0.55
10 1.00
20 1.23
30 1.42
```

运行后 `wind_out.txt` 为

```
h=10 wk=0.550
h=20 wk=0.677
h=30 wk=0.781
```

屏幕输出 `rows=3`。手算核对：$1.00\times0.55=0.550$、$1.23\times0.55=0.6765\approx0.677$、$1.42\times0.55=0.781$。

| 记录 | 手算 $w_k=\mu_z w_0$ | 写入文件 |
|---|---|---|
| 10 1.00 | 0.550 | `h=10 wk=0.550` ✓ |
| 20 1.23 | 0.677 | `h=20 wk=0.677` ✓ |
| 30 1.42 | 0.781 | `h=30 wk=0.781` ✓ |

**样例 2**：$w_0=0.60$，`15 1.14` → $0.684$；`40 1.56` → $0.936$；`rows=2`。

## 六、常见错误与讲解

**错误 1：不检查 fopen 返回值**

```c
FILE *fin = fopen("wind_in.txt", "r");
fscanf(fin, "%lf", &w0);        /* 若 fin 为 NULL，这里直接崩溃 */
```

只要 `fopen` 可能失败，就必须判空并给出提示。

**错误 2：用 `fp == NULL` 之外的方式判断文件尾**

```c
while (!feof(fin)) {            /* 常见但易错：会多处理一次 */
    fscanf(fin, "%lf %lf", &h, &mz);
    ...
}
```

`feof` 只在"尝试读并失败后"才为真，容易导致最后一次数据被重复处理。**推荐直接判断 `fscanf` 返回值**。

**错误 3：`"w"` 模式误用导致原文件被清空**

```c
FILE *f = fopen("wind_in.txt", "w");    /* 危险：把要读的输入文件清空了！ */
```

读用 `"r"`、写新文件用 `"w"`、往原文件续写用 `"a"`，不要写反。

**错误 4：忘记 fclose**

```c
fprintf(fout, "...");
return 0;      /* 没关闭，缓冲区数据可能没落盘 */
```

写入文件后要 `fclose`，才能保证内容真正写进磁盘。
