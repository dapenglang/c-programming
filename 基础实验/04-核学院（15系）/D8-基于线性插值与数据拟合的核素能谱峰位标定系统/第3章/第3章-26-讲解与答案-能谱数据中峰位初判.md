## 二、预备知识：局部极大判据

### 1. 问题是怎么来的

一条能谱的数据是一串计数率。射线能量落在某个区间时，计数率会明显抬高，形成一个"小山包"——山的**顶点**对应的道址，就是我们要找的峰位。

怎么用程序"看见"这个小山包？最朴素的想法：**一个点如果比它的左邻和右邻都高，它就在山坡的最高处。** 这就是**局部极大**。

### 2. 判据怎么用

对下标 $i$，检查：

$$
c[i] > c[i-1] \quad\text{且}\quad c[i] > c[i+1]
$$

两个条件**必须同时成立**（用逻辑与 `&&` 连接）。任一个不成立，就不是峰。

要注意**边界**：第 0 个元素没有左邻、最后一个元素没有右邻，无法比较，所以**不参与判断**。循环从 $i=1$ 到 $i=n-2$（含），共检查 $n-2$ 个点。

**为什么用"严格大于"？** 若写成 `>=`，"平台"（几个连续相同的最高值）会被判成多个峰——一个峰被当成好几个，不利于后续编号。用严格 `>` 时，平台不会被判为峰（因为平台上的点与左右相等，不满足"严格大于"），简单干净。

**局限**：局部极大对**噪声**很敏感——一个毛刺也能被当成峰。所以实际能谱寻峰前通常先做**平滑**（第 5 章 28 题的滑动平均），再应用本判据。本题先用干净数据把判据逻辑写对。

### 3. 用本例走一遍

样例 1 的谱：$c = [1, 2, 5, 2, 1, 8, 3, 2, 1]$，$n = 9$，检查 $i = 1 \sim 7$：

| i | c[i-1] | c[i] | c[i+1] | 是否峰 |
|---|---|---|---|---|
| 1 | 1 | 2 | 5 | 否（2 < 5） |
| 2 | 2 | 5 | 2 | **是**（5 > 2 且 5 > 2） |
| 3 | 5 | 2 | 1 | 否 |
| 4 | 2 | 1 | 8 | 否 |
| 5 | 1 | 8 | 3 | **是**（8 > 1 且 8 > 3） |
| 6 | 8 | 3 | 2 | 否 |
| 7 | 3 | 2 | 1 | 否 |

峰位道址是 **2 和 5**。对照上一练习的刻度（$E = 1.5 \times ch$）：道址 2 → 3 keV（太低，一般是低能噪声或逃逸峰，需阈值过滤）；道址 5 → 7.5 keV。在真实能谱里，这两个道址还偏低，但本题只练判据。

样例 3 的谱是单调递增的 $[1,2,3,4]$，每个点都不比右邻高，一个峰也没有，输出 `none`——这正是"标志变量"要处理的边界情况。

### 4. 编程时怎么用它

循环遍历 + 复合条件判断 + 标志变量：

```c
int found = 0;
for (i = 1; i <= n - 2; i++) {
    if (c[i] > c[i-1] && c[i] > c[i+1]) {
        printf("%d ", i);      /* 输出道址 */
        found = 1;
    }
}
if (!found) printf("none\n");
else        printf("\n");
```

> **这个思想在综合实验中反复出现**：D8 的寻峰（局部极大）、D8 指针版找峰（练习 25 第 6 章）、第 3 章 07 的"峰值搜索与位置记录"，全部是"相邻比较 + 条件判断"。这是数组处理里另一种高频模式（前两种是"累加求和"与"打擂台找最值"）。

## 三、解题思路

1. **读入数据**：`scanf("%d", &n);`，循环读入 `c[50]`；
2. **遍历判断**：`for (i = 1; i <= n-2; i++)`，条件 `c[i] > c[i-1] && c[i] > c[i+1]`；
3. **找到就输出道址**：`printf("%d ", i);` 并置 `found = 1`；
4. **收尾**：循环后若 `found` 仍为 0，输出 `none`；否则输出换行。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double c[50];               /* 各道址的计数率 */
    int n, i;
    int found = 0;              /* 标志：是否找到过峰 */

    scanf("%d", &n);            /* 读入谱数据长度 */

    for (i = 0; i < n; i++) {
        scanf("%lf", &c[i]);    /* 读入各道计数率 */
    }

    /* 遍历内部点（下标 1 ~ n-2），判断是否局部极大 */
    for (i = 1; i <= n - 2; i++) {
        if (c[i] > c[i - 1] && c[i] > c[i + 1]) {   /* 同时高于左右 */
            printf("%d ", i);                        /* 输出疑似峰位道址 */
            found = 1;
        }
    }

    if (!found) {
        printf("none\n");       /* 一个峰也没有 */
    } else {
        printf("\n");           /* 有峰，行末换行 */
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 9: 1 2 5 2 1 8 3 2 1 | i=2（5>2,5>2）、i=5（8>1,8>3）满足 | `2 5` ✓ |
| 7: 1 3 2 6 4 1 0.5 | i=1（3>1,3>2）、i=3（6>2,6>4）满足 | `1 3` ✓ |
| 4: 1 2 3 4 | 单调递增，无点高于右邻 | `none` ✓ |
| 3: 5 1 5 | 只检查 i=1：1 > 5？否 | `none` ✓ |
| 5: 3 1 2 1 3 | 只 i=2（2>1,2>1）满足；端点不算 | `2` ✓ |

最后一例特别说明边界处理：下标 0（值 3）虽比右邻大，但它没有左邻，**不参与判断**，所以不被算作峰。

## 六、常见错误与讲解

**错误 1：循环边界包含端点，导致越界**

```c
for (i = 0; i < n; i++)          /* 错：i=0 时 c[i-1]=c[-1] 越界；i=n-1 时 c[n] 越界 */
for (i = 1; i <= n - 2; i++)     /* 对：只检查内部点 */
```

访问 `c[-1]` 或 `c[n]` 是数组越界，读到的是相邻内存的垃圾值——可能悄悄算错，也可能崩溃。

**错误 2：逻辑或写成逻辑与**

```c
if (c[i] > c[i-1] || c[i] > c[i+1])   /* 错：只要高于任一侧就算峰，几乎每个点都命中 */
if (c[i] > c[i-1] && c[i] > c[i+1])   /* 对：必须同时高于左右 */
```

`||` 是"或"，`&&` 是"与"。局部极大要求**两个条件同时成立**，必须是 `&&`。

**错误 3：用 `>=` 导致平台被判成堆峰**

```c
if (c[i] >= c[i-1] && c[i] >= c[i+1])   /* 错：平台/斜坡会假报峰 */
if (c[i] >  c[i-1] && c[i] >  c[i+1])   /* 对：严格大于 */
```

**错误 4：忘记处理"没有峰"的情况**

```c
for (i = 1; i <= n - 2; i++)
    if (...) printf("%d ", i);
printf("\n");                        /* 错：无峰时也打印一行空，题目要求输出 none */
```

题面明确"若无峰输出 `none`"，需要用标志变量判断，不能简单地只输出换行。
