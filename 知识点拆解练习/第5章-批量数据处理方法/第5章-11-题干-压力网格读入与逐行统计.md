# 第 5 章 练习 11　压力网格读入与逐行统计

**对应章节**：5 批量数据处理方法（5.2 二维数组——二维数组定义、行优先存储、双重循环遍历；3.3 循环结构；2.4 标准输入输出）

**场景来源**：综合实验 C9《冰面压力场热点分析系统》（水声学院）——本练习是该实验中"压力测点网格读入与逐行统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

在冰池试验中，冰面被划分为 $m$ 行 $n$ 列的压力测点，一次采集就得到一张冰面压力网格。工程上往往先按"行"做局部统计：每一排（例如沿某一方向的一排测点）的最大值、最小值、平均值，用来快速判断哪一排测点出现异常。一张网格有 $m \times n$ 个数，必须用"一行一行的表格"来存——这正是二维数组。本练习先完成最基础的"读入网格 + 逐行统计"，为后续的行列聚合、转置、报表打好地基。

## 二、任务要求

编写一个完整程序 `grid_stats.c`：

1. 从键盘读入网格行数 `m` 与列数 `n`（`int`，**题目保证 $1 \le m \le 20$、$1 \le n \le 20$**），声明一个二维数组 `double p[20][20]` 存放压力值（单位：kPa）；
2. 用双重循环按"先行后列"的顺序读入 $m \times n$ 个压力值，存入 `p[i][j]`；
3. 对**每一行**统计该行的最大值、最小值与平均值（平均值 = 该行元素之和 ÷ `n`）；
4. 按行输出统计结果，共 $m$ 行。

## 三、输入输出格式

**输入**：第一行两个整数 $m$、$n$；随后 $m$ 行，每行 $n$ 个实数（以空格分隔），表示该行各测点的压力值（kPa）。

**输出**：共 $m$ 行，第 $k$ 行按格式 `行k: max=最大值 min=最小值 avg=平均值` 输出（$k$ 从 1 开始计数），三个数值均保留 **2 位小数**。

## 四、样例

**样例 1**

输入：
```
3 4
101.2 102.5 99.8 103.1
98.6 100.4 101.6 97.2
105.0 104.3 106.1 104.6
```
输出：
```
行1: max=103.10 min=99.80 avg=101.65
行2: max=101.60 min=97.20 avg=99.45
行3: max=106.10 min=104.30 avg=105.00
```

**样例 2**

输入：
```
2 3
50.0 51.5 49.2
52.8 50.0 53.0
```
输出：
```
行1: max=51.50 min=49.20 avg=50.23
行2: max=53.00 min=50.00 avg=51.93
```

## 五、提示

1. 二维数组的声明格式为 `double p[20][20];`——第一个方括号是**行数容量**，第二个是**列数容量**，实际只用前 $m$ 行、每行前 $n$ 列；
2. 元素 `p[i][j]` 表示第 $i$ 行第 $j$ 列（都从 0 开始），双重循环的写法是外层走行、内层走列：`for (i = 0; i < m; i++) for (j = 0; j < n; j++) ...`；
3. 逐行统计时，先假设 `max` 与 `min` 都等于该行的第一个元素 `p[i][0]`，再从 `j = 1` 开始与该行的其余元素比较，这样能避免初值取错；
4. 该行平均值公式为

$$
\text{avg}_i = \frac{1}{n}\sum_{j=0}^{n-1} p[i][j]
$$

即该行 $n$ 个元素之和再除以 $n$。

**完成本练习后你将具备的能力**：定义并访问二维数组、用双重循环按行优先顺序批量读入网格数据、按行做"求和 / 求最值 / 求均值"的局部统计——这些是实验 C9 中"压力场数据管理模块"的地基，也是本章后面所有二维数组题（行列聚合、转置、报表）的公共起点。
