# 第 3 章 练习 21　施工工序时长累加

**所属综合实验**：A6（A6-基于蒙特卡洛模拟的施工工期风险估算系统）

**对应章节**：3 程序控制结构（3.1 顺序结构、3.2 循环结构——`for` 循环、3.3 累加求和）

**场景来源**：综合实验 A6《基于蒙特卡洛模拟的施工工期风险估算系统》（航建学院）——本练习是该实验中"关键路径总工期累加"环节的最小实现。

**建议用时**：20～30 分钟

## 一、应用场景

一栋框架楼的主体施工要拆成若干道前后衔接的工序：支模板、绑钢筋、浇混凝土、养护、拆模……每一道工序都要花若干天。在工期风险分析中，工程师先按**关键路径**把这条链上的各工序时长排在一条线上，总工期就是它们之和：

$$
T = \sum_{i=1}^{n} t_i
$$

在哈尔滨，混凝土养护工序的时长随季节变化很大（冬期养护常达 7～14 天），所以每次估算都要把各工序时长重新累加一遍。这个"循环读入、逐项累加"的操作，是 A6 系统每次模拟都必须执行的一步。

## 二、任务要求

编写一个完整程序 `work_duration.c`：

1. 从键盘先读入工序数量 `n`（整数，**题目保证 1 ≤ n ≤ 20**）；
2. 再用循环读入 `n` 个工序时长 $t_i$（单位：天，均为正整数）；
3. 用**循环累加**求出总工期 `T`；
4. 输出的同时给出平均每道工序的时长（保留 2 位小数）。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个整数，为各工序时长（天），用空格分隔。

**输出**：两行。第一行 `T = 总工期天`（整数）；第二行 `average = 平均时长天`（保留 2 位小数）。

## 四、样例

**样例 1**

输入：
```
5
2 5 3 7 4
```
输出：
```
T = 21
average = 4.20
```

**样例 2**

输入：
```
4
3 3 14 5
```
输出：
```
T = 25
average = 6.25
```

## 五、提示

总工期是各工序时长之和：

$$
T = \sum_{i=1}^{n} t_i
$$

平均时长是

$$
\bar{t} = \frac{T}{n}
$$

累加的标准写法是：**先给累加变量赋初值 0，再在循环里不断往它上面加**：

```c
int sum = 0;
for (i = 0; i < n; i++) {
    scanf("%d", &t);
    sum = sum + t;      /* 每读一个就累加进去 */
}
```

注意 `sum` 和 `n` 相除求平均时要转成实数运算，否则整数除法会丢掉小数部分。可以写 `sum * 1.0 / n`。

**完成本练习后你将具备的能力**：读写 `for` 循环、设计累加结构（初值、循环体、输出在循环外）、区分整数与实数运算、把物理上的"求和"翻译成程序里的"累加"。
