# 第 2 章 练习 29　材料曲率公式计算

**所属综合实验**：D10（D10-基于迭代求解与二分法的反应堆临界尺寸估算系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算）

**场景来源**：综合实验 D10《基于迭代求解与二分法的反应堆临界尺寸估算系统》（核学院）——本练习是该实验中"由材料参数计算材料曲率 $B_m^2$"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

反应堆物理中判断一个系统能否维持链式反应，用的是**单群扩散理论**。它把中子从"产生"到"泄漏"的竞争关系浓缩成一个关系式，核心是**材料曲率**：

$$
B_m^2 = \frac{k - 1}{L^2}
$$

其中 $k$ 是**增殖因子**（表示每一代中子比上一代多出多少倍，$k > 1$ 表示系统能增殖），$L$ 是**中子扩散长度**（单位 cm，反映中子在介质中迁移的平均距离）。

材料曲率 $B_m^2$ 是**材料本身的性质**——它只由 $k$ 和 $L$ 决定，与堆的形状、大小无关。物理含义是：**介质"想要"中子在多小的尺寸内被消耗掉**，数值越大表示介质越"增殖有余"。

综合实验 D10 求解临界尺寸的第一步，就是把给的 $k$ 与 $L$ 代入这个公式算出 $B_m^2$。本题实现这一最小计算流程。

## 二、任务要求

编写一个完整程序 `mat_curv.c`：

1. 程序中用**常量**存放单群理论的物理背景值（本题不需要常数，但需定义变量存放 $k$ 与 $L$）；
2. 从键盘读入两个量：增殖因子 `k`（实数，double，**题目保证 1.05 ≤ k ≤ 1.5**）和扩散长度 `L`（实数，double，单位 cm，**题目保证 2 ≤ L ≤ 10**）；
3. 用材料曲率公式计算 $B_m^2$（单位 $\text{cm}^{-2}$）；
4. 按规定格式输出 $B_m^2$，保留 **6 位小数**。

## 三、输入输出格式

**输入**：一行，两个实数，依次为增殖因子 k 和扩散长度 L（cm），用空格分隔。

**输出**：一行，按格式 `Bm2 = 结果` 输出，结果保留 6 位小数。

## 四、样例

**样例 1**

输入：
```
1.20 5.0
```
输出：
```
Bm2 = 0.008000
```

**样例 2**

输入：
```
1.50 4.0
```
输出：
```
Bm2 = 0.031250
```

## 五、提示

- 公式的 C 语言表达：`Bm2 = (k - 1.0) / (L * L);`——**分子必须先减 1**，所以括号不能省；
- 分母要写成 `L * L` 而不是 `L^2`——**C 语言没有幂运算符**，`^` 是位异或，用错会得到完全错误的结果。需要求幂时用乘法或 `pow(L, 2.0)`（要 `#include <math.h>`）；
- 物理量 $k$、$L$、$B_m^2$ 都是实数，一律用 `double`；
- `scanf` 读两个数用 `"%lf %lf"`，两个参数前都要加 `&`；
- 想一想量级：$L$ 典型 2～10 cm，$L^2$ 是 4～100；$k-1$ 是 0.05～0.5，相除后 $B_m^2$ 大致在 $0.001 \sim 0.06\ \text{cm}^{-2}$，所以用 6 位小数才能看清有效数字；
- 想一想：为什么 $k$ 必须大于 1？因为若 $k \le 1$，则 $B_m^2 \le 0$，材料曲率为非正表示介质本身无法维持链式反应，任何尺寸都达不到临界——**这正是"临界"要求 $k>1$ 的物理原因**。

**完成本练习后你将具备的能力**：为不同物理量选择数据类型、书写含括号的算术表达式、正确表达"平方"、用 printf 控制小数位数——这些是实验 D10 中"材料曲率计算模块"的地基。
