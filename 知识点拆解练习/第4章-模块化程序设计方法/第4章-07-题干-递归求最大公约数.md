# 第 4 章 练习 07　递归求最大公约数

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 B4《基于深度优先搜索的迷宫求解系统》（人工智能学院）——本练习是该实验中"递归算法基础"环节的实现（对应 4.3 递归调用）。

**建议用时**：25 分钟

## 一、应用场景

最大公约数用于把比或尺寸"约到最简"：把长宽比化成最简整数比、把规格尺寸按公因子归并时都要用到它。求最大公约数最经典的算法是两千多年前欧几里得提出的辗转相除：两个数相除取余，再用除数和余数继续相除，直到余数为零。这个"反复用新的一对数做同样的事"的结构，写成函数就是一个优雅的递归。本练习实现欧几里得算法，体会一种比阶乘更一般的递归。

## 二、任务要求

编写一个完整程序 `gcd.c`：

1. 必须定义**递归函数**，**函数原型为**
   ```c
   int gcd(int a, int b);
   ```
   返回 `a` 与 `b` 的最大公约数；
2. 函数必须同时具备两部分：
   - **基线条件**：当 `b == 0` 时返回 `a`（余数为零，此时的除数就是最大公约数）；
   - **递推关系**：否则返回 `gcd(b, a % b)`（用"除数"和"余数"组成新的一对数继续求）；
3. 主函数读入两个**正整数** `a`、`b`，调用 `gcd`；
4. 按格式输出结果（正整数，不带小数）。

## 三、输入输出格式

**输入**：一行，两个正整数 a、b，用空格分隔。

**输出**：一行，按格式 `gcd = 结果` 输出。

## 四、样例

**样例 1**

输入：
```
48 36
```
输出：
```
gcd = 12
```

**样例 2**

输入：
```
1071 462
```
输出：
```
gcd = 21
```

## 五、提示

欧几里得（辗转相除）递归定义：

$$
\gcd(a,\, b) = \gcd(b,\ a \bmod b),\qquad \gcd(a,\, 0) = a
$$

其中 `a % b` 是取余运算（`a` 除以 `b` 的余数）。要注意递归关系里**两个实参被交换了位置**：原来的 `b` 变成第一参数，原来的余数 `a % b` 变成第二参数。基线是"余数为零"。

**完成本练习后你将具备的能力**：实现"参数不断变换、问题形式不变"的递归，理解为什么基站设在"余数为零"处、看懂辗转相除的调用链——这是实验 B4 及后续所有需要整数处理场景的通用工具。
