# 第 4 章 练习 15　牛顿迭代求衰减常数

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.6 非线性方程求解——牛顿迭代法的应用）

**场景来源**：综合实验 D1《放射性核素活度衰减分析系统》（核学院）——本练习是该实验中"由实测计数反解衰减常数"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

放射性核素的活度按 $A(t) = A_0\,e^{-\lambda t}$ 衰减，其中 $\lambda$ 是**衰减常数**。实验中，探测器在时间窗口 $[0,T]$ 内记录到的**总计数**为

$$
C = \int_0^T A_0\,e^{-\lambda t}\,\mathrm{d}t
  = \frac{A_0}{\lambda}\bigl(1 - e^{-\lambda T}\bigr).
$$

已知初始计数率 $A_0$、观测窗口 $T$ 与实测总计数 $C$，要反求 $\lambda$。把上式整理成 $f(\lambda)=0$ 的形式，就得到一个**超越方程**——无法解析求解，只能用牛顿迭代法数值反解。

## 二、任务要求

编写一个完整程序 `decay_lambda.c`：

1. 把方程改写为 $f(\lambda) = A_0\bigl(1 - e^{-\lambda T}\bigr) - C\,\lambda = 0$，并编写两个函数：
   - `double f(double L, double A0, double T, double C)`：返回 $f(\lambda)$ 的值；
   - `double df(double L, double A0, double T, double C)`：返回导数 $f'(\lambda) = A_0 T\,e^{-\lambda T} - C$；
2. 编写函数 `double newton(double A0, double T, double C, double L0, double eps)`：用牛顿迭代公式 $\lambda_{n+1} = \lambda_n - \dfrac{f(\lambda_n)}{f'(\lambda_n)}$ 求解，每完成一次迭代输出一行 `iter k: lambda = 值`；当 $|\lambda_{n+1}-\lambda_n| < \text{eps}$ 时停止并返回 $\lambda$；
3. `main` 读入 $A_0$、$T$、$C$，以初值 `L0 = 0.03`、`eps = 1e-6` 调用 `newton`，最后输出 `lambda = 衰减常数`；
4. **接口约定**：各函数只用参数与返回值通信，不使用全局变量；三个参数按 `A0, T, C` 的顺序传入。

## 三、输入输出格式

**输入**：一行，三个实数 `A0 T C`（初始计数率、观测窗口、累计计数），用空格分隔。

**输出**：每次迭代输出一行 `iter k: lambda = 迭代值`（保留 6 位小数）；最后输出一行 `lambda = 衰减常数`（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
1000 30 20000
```
输出：
```
iter 1: lambda = 0.029158
iter 2: lambda = 0.029141
iter 3: lambda = 0.029141
lambda = 0.029141
```

**样例 2**

输入：
```
1000 60 30000
```
输出：
```
iter 1: lambda = 0.026748
iter 2: lambda = 0.026561
iter 3: lambda = 0.026560
lambda = 0.026560
```

## 五、提示

- 把 $C = \dfrac{A_0}{\lambda}(1-e^{-\lambda T})$ 两边乘以 $\lambda$，得到 $\lambda C = A_0(1-e^{-\lambda T})$，移项即 $f(\lambda) = A_0(1-e^{-\lambda T}) - C\lambda = 0$；
- 求导时注意 $e^{-\lambda T}$ 对 $\lambda$ 的导数是 $-T e^{-\lambda T}$，故 $f'(\lambda) = A_0 T e^{-\lambda T} - C$（$C\lambda$ 的导数是 $C$，前面带负号）；
- 需要用到指数函数 `exp` 与绝对值 `fabs`，请 `#include <math.h>`；
- 初值取 0.03 是量级估计：由 $C/A_0 = (1-e^{-\lambda T})/\lambda \approx T$ 可粗判 $\lambda$ 与 $1/T$ 同数量级，本题 $1/T \approx 0.033$，故 0.03 是个好起点。

**完成本练习后你将具备的能力**：会把一个实际工程方程整理成 $f(x)=0$、会求它的导数、能把牛顿迭代框架套用到含指数函数的超越方程上——这是实验 D1 中"衰减规律参数反演模块"的地基。
