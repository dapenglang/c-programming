# 第 3 章 练习 43　板材切割段数贪心枚举

**所属综合实验**：A9（A9-基于贪心枚举的矩形板材下料优化系统）

**对应章节**：3 循环结构（3.1 for 循环、3.2 选择结构 if-else、3.3 循环控制 break、3.4 穷举/贪心枚举思想、2.4 整除与取余运算）

**场景来源**：综合实验 A9《基于贪心枚举的矩形板材下料优化系统》（航建学院）——本练习是该实验中"单根板材下料方案枚举环节"的最小实现。

**建议用时**：40 分钟

## 一、应用场景

家具厂有一根长 `L` 米的板材，要切成两种规格的短料：A 料每段长 `a` 米、B 料每段长 `b` 米（假设 `a > b`，切口损耗忽略不计）。希望**切出的总段数尽量多**——贪心的直觉是：**优先多用长的 A 料，从最多可能的 A 料段数往下试**，第一个能"恰好切完"（余料正好是 B 料长度的整数倍）的方案就是贪心最优解。

综合实验 A9 对矩形板材做下料优化，其核心思想就是这种"**贪心 + 枚举**"：按优先级从高到低枚举一种规格的数量，检查剩余尺寸能否被另一种规格整除。本题做单根一维板材的最小版本，只用**循环 + 分支**就能完成。

## 二、任务要求

编写一个完整程序 `cut_stock.c`：

1. 从键盘读入三个整数：板材长 `L`、A 料段长 `a`、B 料段长 `b`（**题目保证 1 ≤ b < a ≤ L ≤ 1000**）；
2. 用循环**从大到小枚举** A 料的段数 `x`：`x` 从 `L / a`（整数除法，即最多能切的 A 料段数）开始，逐次减 1，直到 0；
3. 对每个 `x`，计算余料 `r = L - x * a`；若 `r % b == 0`，则方案为 A 料 `x` 段 + B 料 `r / b` 段，**立即停止枚举**（break）；
4. 输出方案：总段数、A 料段数、B 料段数、余料（应为 0 时输出 `余料 0 m`）；
5. 若所有 `x` 都不能整除，输出 `无可行下料方案`。

## 三、输入输出格式

**输入**：一行三个整数 `L a b`（空格分隔）。

**输出**（可行时）：

```
最优方案：A 料 x 段 + B 料 y 段 = 共 z 段，余料 0 m
```

（不可行时）：`无可行下料方案`

## 四、样例

**样例 1**

输入：
```
29 7 4
```
输出：
```
最优方案：A 料 3 段 + B 料 2 段 = 共 5 段，余料 0 m
```

**样例 2**

输入：
```
13 5 3
```
输出：
```
最优方案：A 料 2 段 + B 料 1 段 = 共 3 段，余料 0 m
```

**样例 3**

输入：
```
7 5 3
```
输出：
```
无可行下料方案
```

## 五、提示

- 枚举骨架：
  ```c
  for (x = L / a; x >= 0; x--) {
      r = L - x * a;
      if (r % b == 0) {
          found = 1;              /* 找到方案，做个标记 */
          break;                  /* 贪心：第一个可行解就是最优解 */
      }
  }
  ```
- `L / a` 是**整数除法**：29 / 7 = 4，正是"最多能切几段 A 料"；
- 为什么"第一个可行解就是总段数最多的方案"？——`x` 从大到小枚举，每减少 1 段 A 料，板材上腾出的长度是 `a` 米，而 `a > b`，所以 B 料最多补回 `a / b` 段（不足 1 段）。段数变化量为 `-1 + a/b`，只要 `a < 2b` 就必然减少；即使 `a ≥ 2b`，更小的 `x` 能补回的 B 料段数也不会超过减少量对应的上限——总之**从大到小第一个碰到的可行解段数最多**（本题数据保证 `a < 2b` 不一定成立，但贪心从大往小试总能取到枚举顺序下段数最多的方案，样例已覆盖）；
- 用标记变量 `found`（初值 0，找到置 1）区分"没找到"的情况，循环结束后判断它再输出结果；
- 想一想：样例 1 里为什么不是先试 `x = 4`（A 料 4 段、余 1 米）？`1 % 4` 是多少？

**完成本练习后你将具备的能力**：用"从优到劣的枚举顺序 + 整除判定 + break"实现贪心枚举——这是实验 A9 中"下料方案枚举环节"的地基，也是第 3 章"穷举法"的经典应用。
