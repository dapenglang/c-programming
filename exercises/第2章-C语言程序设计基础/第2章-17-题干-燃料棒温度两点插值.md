# 第 2 章 练习 17　燃料棒温度两点插值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 D4《基于高斯消元的燃料棒一维稳态温度场计算系统》（核学院）——本练习是该实验中"节点温度线性插值"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

核反应堆的燃料棒沿轴向温度分布不均匀，通常靠数值方法求出若干**节点**（离散位置）上的温度。例如某工况下，轴向位置 0.5 m 处节点温度为 620.0 ℃，1.0 m 处节点温度为 540.0 ℃。而实际分析常常需要知道**任意位置**的温度，比如热点位置附近的读数。

在两个相邻节点之间，工程上默认温度沿轴**近似线性下降**，用**线性插值**求中间位置的温度。综合实验 D4 用高斯消元求出完整温度场，本练习先独立完成"由相邻两节点温度插值求中间温度"这一最小步骤。

## 二、任务要求

编写一个完整程序 `fuel_temperature.c`：

1. 用**常量**在程序中存放相邻两节点数据：位置 0.5 m 对应温度 620.0 ℃，位置 1.0 m 对应温度 540.0 ℃；
2. 从键盘读入一个位置 `x`（单位：m，`double` 类型，**题目保证 0.5 ≤ x ≤ 1.0**，因此不需要判断分支）；
3. 用线性插值公式计算该位置对应的温度 `T`；
4. 按规定格式输出结果，保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示轴向位置 x（m）。

**输出**：一行，按格式 `T = 结果 C` 输出，结果保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
0.75
```
输出：
```
T = 580.00 C
```

**样例 2**

输入：
```
0.6
```
输出：
```
T = 604.00 C
```

## 五、提示

线性插值公式：已知两点 $(x_0,\, T_0)$、$(x_1,\, T_1)$，则位置 $x$ 处的温度为

$$
T = T_0 + \dfrac{(T_1 - T_0)\,(x - x_0)}{x_1 - x_0}
$$

本例温度随位置**下降**（$T_1 - T_0 = -80$），符号由公式自动处理；只需把公式原样翻译成一行赋值语句，注意括号。

**完成本练习后你将具备的能力**：把温度场节点数据翻译成程序常量、独立完成一次完整插值流程、正确处理负斜率数据——这是 D4 温度场计算系统里"任意位置查温度"模块的地基。
