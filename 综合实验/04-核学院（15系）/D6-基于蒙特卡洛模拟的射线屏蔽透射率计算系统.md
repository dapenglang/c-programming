# 题目 D6：基于蒙特卡洛模拟的射线屏蔽透射率计算系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行射线屏蔽透射率蒙特卡洛模拟工具，围绕"γ 光子穿过屏蔽板时按概率发生相互作用、未被作用的光子才能穿透"这一辐射防护基本图像展开。系统读入手写线性同余伪随机数发生器的参数与屏蔽参数，为大批光子逐个抽取随机数并判定其是否穿透，用"透射光子数 ÷ 入射光子数"统计出透射率；对一组屏蔽厚度重复实验，得到"厚度—透射率"衰减曲线，并与指数衰减理论值 $I/I_0 = e^{-\mu x}$ 逐点对照，最后做样本数收敛性分析、写出对照表文件。这是蒙特卡洛方法在核领域的入门实现：不求解微分方程，只靠"大量抽样 + 计数统计"逼近真实结果。

屏蔽设计如果失去定量依据，防护厚度就只能凭经验取整，后果是双向的：取薄了，屏蔽体外剂量率超标，人员受照、控制区边界失守；取厚了，屏蔽体重量与造价成倍上升，核电站的楼板荷载、运输容器的自重都承受不起。只有把"某一厚度下还剩多少射线"算准，防护设计才能从"拍脑袋"变成"算出来的"。

本系统支撑的关键场景包括：① 核电站主屏蔽墙与屏蔽门的厚度核算；② 医用加速器机房、CT 室墙体与观察窗铅当量估算；③ 工业辐照装置（钴源室）的迷道与屏蔽层设计；④ 放射性物质运输容器的屏蔽校核；⑤ 电子器件与探测器的辐射加固评估。系统让学生在大一阶段就能亲手实现"取样—判决—计数—对照理论"的完整链路，为后续《辐射防护》《核辐射探测》等课程建立直观基础。本题目与核工程与核技术专业"辐射防护与核安全"方向直接对应。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的射线屏蔽透射率蒙特卡洛模拟系统：从文本文件读入屏蔽材料与板厚配置（含异常值校验）、读入手写线性同余发生器的参数，实现伪随机数发生器与光子穿越深度抽样，封装"单光子透射判定"与"N 光子批量统计"两级函数，对一组厚度值重复模拟得到透射率曲线，用指数衰减公式算理论值对照，做收敛性分析，最后输出对照表文件、在菜单中调度全部功能。

专业关联上，本题目还原了辐射防护屏蔽计算最常用的蒙特卡洛思想：把"光子能否穿过"变成一个可以重复抽取的随机事件，用大样本次序统计逼近真实透射概率。学生在实现中练熟递推循环、取模运算、计数统计、函数的分层封装与文件读写，并第一次体会"随机性如何涌现出稳定规律"，全程不涉及任何机器学习或统计推断理论。

## 三、数据来源与格式

- **数据文件格式**：分两个文本文件。其一是屏蔽配置表 `shield_cfg.txt`，首行为标题说明，其后每行一条记录，字段以空格分隔，依次为：工况标识（无空格字符串）、材料名（无空格字符串）、线衰减系数 μ（单位：1/cm，正实数）、板厚 x（单位：cm，正实数）、光子数 N（整数）。其二是随机数种子配置 `seed_cfg.txt`，给出线性同余发生器的四个参数与最大穿越深度。

```
# case_id  material  mu_per_cm  thickness_cm  photon_num
lead_5      lead       0.780        5.0         50000
lead_10     lead       0.780       10.0         50000
lead_20     lead       0.780       20.0         50000
iron_10     iron       0.240       10.0         50000
concrete_30 concrete   0.092       30.0         50000
```

```
# a  c  m  r0  max_depth_cm
1103515245  12345  2147483648  20261003  60.0
```

- **仿真数据生成规则**：
  - 工况标识：3～12 个字母数字字符（可含下划线），无空格，如 `lead_5`、`concrete_30`。
  - 材料名：`lead`、`iron`、`concrete`、`water` 四类之一。
  - 线衰减系数 μ：单位 1/cm，1 MeV γ 光子下的典型取值——铅 0.70～0.85（典型 0.780）、铁 0.20～0.28（典型 0.240）、混凝土 0.08～0.12（典型 0.092）、水 0.06～0.08（典型 0.070），按均匀分布生成。
  - 板厚 x：单位 cm，取值范围 0.5～50.0，按均匀分布生成并保留一位小数。
  - 光子数 N：整数，取值范围 1000～100000，默认 50000；同一组对照工况应取相同的 N，保证可比。
  - 发生器参数：乘子 a 固定 1103515245，增量 c 固定 12345，模数 m 固定 2147483648（即 $2^{31}$），种子 r0 为 1～2147483647 的正整数；最大穿越深度取 30～100 cm 且不少于最大板厚，保证抽样范围覆盖整块板。
  - **异常值注入方式**：由教师提供的生成程序注入三类错误。其一，μ 字段填 0 或负数（如 `-0.78`），校验模块应剔除该记录；其二，板厚填 0 或远大于最大穿越深度（如 `0.0`、`500.0`），校验时分别判为无效与超范围告警；其三，光子数填 0 或超出 [1000, 100000]（如 `0`、`99999999`），校验时取默认值 50000；另可注入非数字串（如 `NA`），考察 `fscanf` 返回值判断。

- **真实数据集（如有）**：真实的 γ 光子线衰减系数可在美国国家标准与技术研究院 NIST 的 XCOM 光子衰减数据库查询（https://physics.nist.gov/PhysRefData/Xcom/ ）。学生**无需下载**真实数据，课程提供与上述字段含义对应的简化仿真参数表。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_CASE     20        /* 屏蔽工况数量上限 */
#define MAX_THICK    20        /* 厚度扫描点数上限 */
#define MAX_N        100000    /* 单次模拟最大光子数 */
#define LCG_A        1103515245ULL  /* 乘子 a */
#define LCG_C        12345ULL       /* 增量 c */
#define LCG_M        2147483648ULL  /* 模数 m = 2^31 */

/* ===== 屏蔽工况结构体 ===== */
struct ShieldCase {
    char   caseId[16];        /* 工况标识，如 "lead_10" */
    char   material[16];      /* 材料名，如 "lead" */
    double mu;                /* 线衰减系数 μ，单位 1/cm，> 0 */
    double thick;             /* 板厚 x，单位 cm，> 0 */
    long   photonNum;         /* 光子数 N，1000~100000 */
    int    valid;             /* 有效标志：1 有效，0 已判为异常剔除 */
};

/* ===== 线性同余发生器状态 ===== */
struct LcgState {
    unsigned long long a;     /* 乘子 */
    unsigned long long c;     /* 增量 */
    unsigned long long m;     /* 模数 */
    unsigned long long seed;  /* 当前种子 r_n */
    double maxDepth;          /* 最大穿越深度，单位 cm */
    long   callCount;         /* 已产生随机数个数（统计用） */
};

/* ===== 单工况模拟结果 ===== */
struct SimResult {
    char   caseId[16];        /* 工况标识 */
    double thick;             /* 板厚 x，cm */
    long   nIncident;         /* 入射光子数 N */
    long   nTransmit;         /* 透射光子数 */
    double transRate;         /* 模拟透射率 = nTransmit / N */
    double theoryRate;        /* 理论透射率 = exp(-μ·x) */
    double relError;          /* 相对偏差 = |模拟-理论| / 理论 */
};

/* ===== 全局数据区 ===== */
struct ShieldCase g_case[MAX_CASE];       /* 屏蔽工况表 */
int               g_caseCount;            /* 工况条数 */
struct LcgState   g_lcg;                  /* 随机数发生器状态 */
struct SimResult  g_result[MAX_CASE];     /* 各工况模拟结果 */
int               g_resultCount;          /* 已完成模拟的工况数 */
double            g_thickList[MAX_THICK]; /* 厚度扫描列表，cm */
int               g_thickCount;           /* 扫描厚度个数 */
double            g_convRate[32];         /* 收敛分析历史透射率 */
long              g_convN[32];            /* 收敛分析各批光子数 */
int               g_convCount;            /* 收敛分析批次数 */
int               g_seedInit;             /* 发生器是否已初始化的标志 */

/* ===== 处理日志 ===== */
struct LogItem {
    char op[24];              /* 操作名，如 "RUN_THICK_SCAN" */
    char detail[72];          /* 参数与关键结果摘要 */
};
struct LogItem g_log[128];
int            g_logCount;  /* 已记录日志条数 */
```

辅助说明：穿越深度按逆变换抽样生成，取均匀随机数 $u$ 则 $s = -x\cdot\ln(u)$；透射判定条件为 $s \ge x$，等价于直接比较 $u \le e^{-\mu x}$，两种写法都予实现并对照。发生器一律用 `unsigned long long` 承载乘法结果，避免 $a\cdot r$ 溢出。

## 五、功能模块拆解（共 11 个模块）

### 第一部分：数据读入（3 个模块）

**M1 屏蔽参数读入模块**（源文件 `ShieldIO.c`）
- 功能简介：打开屏蔽配置文件，跳过首行标题，用循环 + `fscanf` 逐行读入工况标识、材料名、线衰减系数、板厚与光子数，填充 `g_case[]` 并记录条数；文件不存在时给出明确提示，字段个数不足的行打印行号后跳过。  输入：屏蔽配置文件路径（默认 `shield_cfg.txt`）；输出：`g_case[]`、`g_caseCount` 与成功/失败标志。

**M2 屏蔽参数校验模块**（源文件 `ShieldCheck.c`）
- 功能简介：逐条检查 μ 是否为正且在 [0.01, 5.0] 内、板厚是否为正且不超过最大穿越深度、光子数是否在 [1000, 100000] 内、材料名是否为允许的四类之一；对异常记录置 `valid=0` 并生成"行号—异常类型—处理动作"清单，光子数超限时按默认值 50000 修正而非剔除。  输入：`g_case[]`、`g_lcg.maxDepth`；输出：屏幕校验报告与修正后的有效条数。

**M3 随机数种子配置读入模块**（源文件 `SeedIO.c`）
- 功能简介：读入种子文件的乘子、增量、模数、初始种子与最大穿越深度；做范围检查（模数必须为正、种子必须落在 $[1, m-1]$、最大深度 > 0），越界时取默认值并告警；把参数写入 `g_lcg`，把 `g_seedInit` 置 0 等待 M4 初始化。  输入：种子配置文件路径（默认 `seed_cfg.txt`）；输出：`g_lcg` 全部字段与屏幕参数确认。

### 第二部分：算法实现（4 个模块）

**M4 伪随机数发生器模块**（源文件 `Lcg.c`）
- 功能简介：实现手写线性同余发生器 $r_{n+1} = (a\cdot r_n + c)\bmod m$，提供 `lcgSeed()` 重设种子、`lcgNext()` 返回下一个伪随机整数、`lcgUnit()` 返回 $[0,1)$ 均匀随机小数 $u = r_{n+1}/m$；另提供 `lcgCheck(n)` 分 10 个区间统计 n 个随机数的频数并打印。  输入：`g_lcg` 中的 (a, c, m, r0) 与调用次数 n；输出：伪随机数与屏幕均匀性检验表。

**M5 光子行程数据生成模块**（源文件 `Sample.c`）
- 功能简介：为单个光子抽取一次穿越深度——先取均匀随机数 $u$，按 $s = -x\cdot\ln u$ 算出本次可能穿越的总深度并截断到最大穿越深度；连续抽样 10000 次统计样本均值、最小值和最大值，验证抽样分布正确。  输入：最大穿越深度 `g_lcg.maxDepth`、抽样次数；输出：单个光子穿越深度（cm）与屏幕抽样统计表。

**M6 单光子透射判定模块**（源文件 `Transmit.c`）
- 功能简介：实现单个光子的透射判决函数 `int photonTransmit(double mu, double x)`：按概率 $p = e^{-\mu x}$ 判透射——取随机数 $u$，若 $u \le p$ 返回 1（透射），否则返回 0（被吸收/散射）；同时提供等价写法 `int photonTransmitByDepth(double mu, double x)`，用 M5 抽取深度后比较 $s \ge x$。  输入：线衰减系数 μ（1/cm）、板厚 x（cm）；输出：返回 1 或 0。

**M7 批量透射统计模块**（源文件 `Batch.c`）
- 功能简介：循环调用 M6 共 N 次，统计透射光子数 `nTransmit`，算出透射率 `transRate = nTransmit / N`；按每 10% 打印一次进度并填入 `g_result[]`；N 超过 `MAX_N` 时自动截断并提示。  输入：工况下标或（μ, x, N）参数组；输出：`struct SimResult` 与屏幕透射率。

### 第三部分：数据输出（4 个模块）

**M8 透射率-厚度曲线计算模块**（源文件 `ThickCurve.c`）
- 功能简介：对厚度扫描列表 `g_thickList[]` 中的每个厚度，在固定随机种子下重复调用 M7 得到该厚度的模拟透射率，填入 `g_result[]`；用 `lcgSeed()` 在每个厚度开始前重设种子，保证差异只来自板厚而非随机涨落。  输入：`g_thickList[]`、`g_thickCount`、基础 μ 与 N；输出："厚度—透射率"对照表与 `g_result[]`。

**M9 理论值对照计算模块**（源文件 `Theory.c`）
- 功能简介：对每个厚度用指数衰减公式 $T_{\text{理论}} = e^{-\mu x}$ 计算理论透射率，与 M8 的模拟值逐点比较，计算相对偏差 $|\text{模拟}-\text{理论}|/\text{理论}$，并给出半值层厚度 $\ln 2 / \mu$ 与十分值层厚度 $\ln 10 / \mu$ 的参考值。  输入：`g_result[]`、各工况的 μ；输出：屏幕模拟值与理论值对照表。

**M10 收敛性分析模块**（源文件 `Converge.c`）
- 功能简介：固定 μ 与板厚，按 10 个批次递增光子数（1000, 2000, 5000, 10000, 20000, …, 100000），每批统计透射率并记入 `g_convRate[]` 与 `g_convN[]`，计算相邻两批的差值作为收敛判据，输出"光子数—透射率—相邻波动"表并标注首次进入 ±0.005 带宽的批次。  输入：μ、板厚 x、批次光子数列表；输出：`g_convRate[]`、`g_convN[]`、`g_convCount` 与屏幕收敛过程表。

**M11 结果文件输出与主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：把"厚度—模拟透射率—理论透射率—相对偏差"对照表写出到 `transmit_result.csv`，把收敛分析表写出到 `converge.csv`，并把发生器参数与均匀性检验结果写出到 `lcg_report.txt`；主菜单用 `do-while + switch` 调度 M1～M10，约束"必须先读入屏蔽参数、读入种子配置并执行 M4 初始化才能模拟"。  输入：用户菜单选项、全部全局数据；输出：三个结果文件；调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 进入 `do-while` 菜单循环，用 `switch` 分发 M1～M10。状态约束由两个标记承担：`g_caseCount > 0` 且至少一条 `valid==1` 才允许调用 M5～M10；`g_seedInit == 1`（由 M4 初始化成功后置位）才允许进入任何抽样与判决模块。M1～M3 任意顺序可执行，但 M2 校验必须先于 M8/M9，否则异常工况会把透射率曲线带偏。M8 内部对每个厚度重新调用 `lcgSeed()`，保证各厚度实验的随机序列完全一致。

**数据流**：
```
shield_cfg.txt ─► M1 读入 ─► g_case[] ─► M2 校验 ─► 有效工况表
                                        │
seed_cfg.txt ──► M3 种子配置 ─► g_lcg[]─┘
                                        │
                                 M4 伪随机数发生器 ─► lcgUnit() ∈ [0,1)
                                        │
                     ┌──────────────────┼──────────────────┐
                     ▼                  ▼                  ▼
             M5 光子行程抽样    M6 单光子透射判定    M10 收敛性分析
                     │                  │                  │
                     └──────► M7 批量透射统计 ◄────────────┘
                                        │
                                        ▼
                                 M8 透射率-厚度曲线 ─► M9 理论值对照
                                        │
                     ┌──────────────────┴──────────────────┐
                     ▼                                     ▼
        M11 对照表文件输出                    M11 主控菜单调度
```

所有模块之间只通过全局工况表 `g_case[]`、发生器状态 `g_lcg`、结果数组 `g_result[]` 与函数参数交换数据；随机数只能经 M4 的 `lcgUnit()` 取得，系统内**不得**出现 `rand()`/`srand()`，以保证种子相同则结果完全可复现。函数头部（接口）在编码前由全组书面约定。
