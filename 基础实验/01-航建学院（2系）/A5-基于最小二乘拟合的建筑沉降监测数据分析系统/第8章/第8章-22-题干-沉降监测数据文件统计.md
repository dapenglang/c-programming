# 第 8 章 练习 22　沉降监测数据文件统计

**所属综合实验**：A5（A5-基于最小二乘拟合的建筑沉降监测数据分析系统）

**对应章节**：8 数据持久化存储方法（8.1 文件的打开与关闭、8.2 文本文件读写、8.3 文件的读写循环 + 统计）

**场景来源**：综合实验 A5《基于最小二乘拟合的建筑沉降监测数据分析系统》（航建学院）——本练习是该实验中"监测数据文件统计"环节的实现。

**建议用时**：25～30 分钟

## 一、应用场景

沉降监测的一期数据通常以文件形式存档：每一行是一个观测点，记录着**点号、累计沉降量（mm）**。A5 系统在做最小二乘拟合之前，往往先做一次**快速统计**：一共有多少个点、平均沉降多少、最大和最小沉降是多少、哪几个点沉降速率可能超限。

这些统计全部来自对数据文件的**一次遍历**。本练习就实现这个"读文件 + 统计"的流程。

沉降速率（若文件给出天数）为

$$
v = \frac{s}{\Delta t}
$$

（mm/天），$s$ 是累计沉降量，$\Delta t$ 是观测天数。

## 二、任务要求

编写一个完整程序 `settle_stat.c`：

1. 从文件 `settle_in.txt` 读入：第一行为观测天数 $\Delta t$；之后每行一个观测点，格式为 `点号 累计沉降量`（mm），直到文件结束；
2. 遍历统计：**点数 n**、**平均沉降量**、**最大沉降量及对应点号**、**最小沉降量及对应点号**；
3. 计算平均沉降速率（平均沉降量 / 天数）；
4. **检查 fopen 返回值**；结果输出到屏幕。

## 三、输入输出格式

**输入**：文件 `settle_in.txt`。第一行一个整数（天数）；随后每行 `点号 沉降量`。

**输出**：屏幕输出五行：`n=点数`、`avg=平均沉降量mm`、`max=点名:数值mm`、`min=点名:数值mm`、`rate=平均速率mm/天`（数值保留 3 位小数）。

## 四、样例

**输入文件 settle_in.txt**：
```
145
JC01 12.35
JC02 9.80
JC03 15.20
```
**屏幕输出**：
```
n=3
avg=12.450
max=JC03:15.200
min=JC02:9.800
rate=0.0859
```

**样例 2**

**输入文件 settle_in.txt**：
```
120
JC11 5.00
JC12 7.00
```
**屏幕输出**：
```
n=2
avg=6.000
max=JC12:7.000
min=JC11:5.000
rate=0.0500
```

## 五、提示

**读文件时的字符串成员**：点号是字符串，`fscanf` 用 `%s` 且**不加 `&`**：

```c
char name[16];
double s;
fscanf(fin, "%s %lf", name, &s);
```

**一边读一边统计**（不必先存数组——除非后面还要用）：

- 计数：`n++`；
- 求和：`sum += s`；
- 求最值：读入时直接打擂台，同时记录当前最优点的**点名**（用 `strcpy` 保存）。

```c
if (n == 1 || s > maxv) { maxv = s; strcpy(maxname, name); }
```

**平均速率**：

$$
v = \frac{\bar{s}}{\Delta t}
$$

**完成本练习后你将具备的能力**：从文本文件读入混合类型数据；在读取循环中同时完成计数、求和、求极值；用字符串保存最值对应的点名。
