# 第 2 章 练习 08　冰块体积与质量计算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C8《基于数值积分与二分法的碎冰冰块浮力吃水计算系统》（水声学院）——本练习是该实验中"冰块几何与质量参数计算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

碎冰与船体碰撞的计算里，每一块冰都要先知道它的**体积**和**质量**——体积决定它排开多少水，质量决定它有多大惯性。工程上把碎冰近似成规则的长方体块，测得长、宽、厚三个尺寸后：

- 体积 = 长 × 宽 × 厚；
- 质量 = 体积 × 冰的密度。

海冰的密度约 $917\ \mathrm{kg/m^3}$（比纯水略小，这正是冰能浮在水面的原因）。实验 C8 的"冰块参数计算"模块，就是为后续浮力与吃水计算准备这两个基本量。本题即完成这一步。

## 二、任务要求

编写一个完整程序 `ice_mass.c`：

1. 用**常量**定义冰的密度 `RHO_ICE = 917.0`（kg/m³）；
2. 从键盘读入三个 double 数：冰块长度 `l`、宽度 `w`、厚度 `t`（单位均为**米**），**题目保证三者均为正数**，因此本程序不需要判断分支；
3. 先求体积 $V = l \times w \times t$，再求质量 $m = \rho_{\text{ice}} \times V$；
4. 按规定格式输出体积与质量，均保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，三个实数，依次为冰块长度、宽度、厚度（米），数之间以空格分隔。

**输出**：两行，第一行按 `V = 结果 m^3` 输出体积，第二行按 `m = 结果 kg` 输出质量，结果均保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2 1.5 0.4
```
输出：
```
V = 1.2000 m^3
m = 1100.4000 kg
```

**样例 2**

输入：
```
1 0.8 0.5
```
输出：
```
V = 0.4000 m^3
m = 366.8000 kg
```

## 五、提示

体积与质量公式为

$$
V = l \times w \times t, \qquad m = \rho_{\text{ice}} \times V
$$

三个尺寸都必须用 `double` 存放（尺寸带小数，若用 `int` 会截断）。乘法满足结合律，`l * w * t` 会从左到右依次相乘。

**完成本练习后你将具备的能力**：用一组变量连续完成"几何量 → 物性量"的换算、正确选择浮点数据类型、一次读入并分行输出多组结果——这是实验 C8 浮力计算的地基。
