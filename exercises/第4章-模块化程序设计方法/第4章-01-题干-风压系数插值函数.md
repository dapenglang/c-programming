# 第 4 章 练习 01　风压系数插值函数

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计——分而治之、4.2 函数的声明、调用与参数传递）

**场景来源**：综合实验 A1《基于线性插值的风荷载计算系统》（航建学院）——本练习是该实验中"风压高度变化系数查算"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

结构工程师计算风荷载时，要先按建筑高度查"风压高度变化系数" $\mu_z$。规范表只列出 10 m 对应 1.00、20 m 对应 1.23 两个标准档，中间高度必须用线性插值。实验 A1 把这个"查表 + 插值"的过程做成一个独立函数：只要把高度交给它，它就把系数算好返回。这样主程序以及以后任何需要查系数的地方，都只需要调用一行函数，不必重复抄写插值公式——这正是模块化设计的起点。

## 二、任务要求

编写一个完整程序 `wind_mu.c`：

1. 必须定义一个独立函数，**函数原型为**
   ```c
   double wind_mu(double h);
   ```
   其功能是：给定建筑高度 `h`（m），返回对应的风压高度变化系数；
2. 表中数据（10 m ↔ 1.00、20 m ↔ 1.23）以**常量**形式写在 `wind_mu` 函数体内部，作为该函数自己掌握的知识，主函数不接触它们；
3. 主函数 `main` 只负责三件事：读入高度 `h`、调用 `wind_mu(h)`、按规定格式输出结果；
4. 结果保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示建筑物计算高度 h（米）。题目保证 $10 \le h \le 20$。

**输出**：一行，按格式 `mu_z = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
15
```
输出：
```
mu_z = 1.1150
```

**样例 2**

输入：
```
17.5
```
输出：
```
mu_z = 1.1725
```

## 五、提示

线性插值公式：已知两点 $(x_0,\ y_0)$、$(x_1,\ y_1)$，则 $x$ 处的插值为

$$
y = y_0 + \dfrac{(y_1 - y_0)\,(x - x_0)}{x_1 - x_0}
$$

把这条公式整段搬进 `wind_mu` 的函数体，`main` 里就只剩下"读入—调用—输出"三行骨架。**函数的价值不在于让公式变简单，而在于让公式只写一次、可以被反复调用。**

**完成本练习后你将具备的能力**：书写函数原型、定义函数、调用函数、接收返回值，以及"把一段计算逻辑封装成函数"的模块化思维——这是实验 A1 中所有计算环节的通用写法。
