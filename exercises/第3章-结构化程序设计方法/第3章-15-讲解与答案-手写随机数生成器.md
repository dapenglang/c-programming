## 二、预备知识：线性同余伪随机数的基本原理（零基础阅读）

### 1. 问题是怎么来的

蒙特卡洛模拟要成万上亿个随机数。计算机是确定性的机器，产生不了真随机，于是改用"**看起来随机、算起来确定**"的数列，叫伪随机数。最经典也最简单的做法是线性同余法：只要上一项已知，下一项就能用一条公式唯一确定。它生成的数字在统计上足够"杂乱"，又能通过种子完全复现，非常适合作科学计算。

### 2. 方法是怎么想出来的

我们想要一个 $[0, m-1]$ 之间的整数序列，希望它尽量均匀、周期尽量长。一个朴素想法是：拿上一项乘以一个大数 $a$ 再加一个偏移 $c$，这样数字会"跳"得很远；但它可能超出范围，于是用一个模数 $m$ 把它截回 $[0, m-1]$：

$$
r_{n+1} = (a\,r_n + c) \bmod m
$$

因为结果只有 $m$ 个可能值，序列最终必然重复，所以它其实是"周期为 $m$ 的循环"，但在一个周期内近似均匀。选取适当的 $a, c, m$（本题取经典参数 $a=1103515245,\ c=12345,\ m=2^{31}$）可以让周期足够长。要得到 $[0,1)$ 上的小数，只要做一次归一化：

$$
u_i = \frac{r_i}{m}
$$

由于 $0 \le r_i \le m-1$，必有 $0 \le u_i < 1$。

### 3. 用本例走一遍

取种子 $r_0 = 1$：

- 第 1 项：$r_1 = (1103515245 \times 1 + 12345) \bmod 2^{31} = 1103527590 \bmod 2147483648$。因为 $1103527590 < 2147483648$，模运算不改变它，故 $r_1 = 1103527590$；
- 归一化：$u_1 = 1103527590 / 2147483648 = 0.513870$；
- 第 2 项：$r_2 = (1103515245 \times 1103527590 + 12345) \bmod 2^{31}$，计算得 $377401575$，$u_2 = 0.175741$。

第 2 项的被乘数很大，正是"用大乘子把数字打乱、再用取模截回范围"的体现；程序里交给计算机一步一步算即可。

### 4. 编程时怎么用它

三个要点：**① 溢出防范**：$a \times r$ 最大约 $1.1\times10^9 \times 2.1\times10^9 \approx 2.4\times10^{18}$，`int`（约 $2.1\times10^{9}$）远不够装，必须用 `unsigned long long`（可到约 $1.8\times10^{19}$），并把常量写成 `1103515245ULL` 这样带 `ULL` 后缀的字面量；**② 递推与输出**：`for` 循环里先算 `r = (A*r + C) % M;` 再算 `u`、再输出，循环变量 `i` 正好当序号；**③ 输入输出格式**：`unsigned long long` 用 `%llu`，`double` 用 `%f` 系列，别混淆。

## 三、解题思路

1. **定义常量与变量**：`A`、`C`、`M` 用 `const unsigned long long`；工作变量 `r` 也是 `unsigned long long`；`n`、`i` 是 `int`；`u` 是 `double`；
2. **读入**：`scanf("%llu %d", &r0, &n);` 再把 `r0` 赋给 `r`；
3. **循环递推**：`for (i = 1; i <= n; i++)`，循环体第一句 `r = (A * r + C) % M;`；
4. **归一化**：`u = (double)r / (double)M;`（务必先转成 `double`，否则会做整数除法）；
5. **输出**：`printf("r%d = %llu  u = %.6f\n", i, r, u);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const unsigned long long A = 1103515245ULL;   /* 乘子 */
    const unsigned long long C = 12345ULL;        /* 增量 */
    const unsigned long long M = 2147483648ULL;   /* 模数 = 2^31 */

    unsigned long long r0;      /* 种子 */
    unsigned long long r;       /* 当前伪随机整数 */
    int    n;                   /* 生成个数 */
    int    i;                   /* 序号 */
    double u;                   /* 归一化到 [0,1) 的随机数 */

    scanf("%llu %d", &r0, &n);

    r = r0;                     /* 从种子出发 */

    /* 线性同余递推，生成 n 个伪随机数 */
    for (i = 1; i <= n; i++) {
        r = (A * r + C) % M;            /* 核心递推式 */
        u = (double)r / (double)M;      /* 归一化 */
        printf("r%d = %llu  u = %.6f\n", i, r, u);
    }

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：用 `int` 或 `long` 存储**

```c
int r = 1;
r = (1103515245 * r + 12345) % 2147483648;   /* 错：中间结果远超过 int 范围，结果错乱 */
```

`int` 最大约 $2.1\times10^9$，而中间乘积约 $2.4\times10^{18}$。必须用 `unsigned long long`，并把字面量写成 `...ULL`，必要时加 `(unsigned long long)` 强制转换。

**错误 2：格式符用错**

```c
printf("%d\n", r);     /* 错：r 是 unsigned long long，用 %d 输出得到乱码 */
printf("%llu\n", r);   /* 对：无符号长长整型用 %llu */
```

**错误 3：归一化时发生整数除法**

```c
u = r / M;                    /* 错：r、M 都是整型，结果恒为 0 */
u = (double)r / (double)M;    /* 对：先转 double 再做浮点除法 */
```

**错误 4：偷懒使用 `rand()`**

```c
r = rand();    /* 违反题目要求：本题训练的就是自己实现发生器，禁用现成库函数 */
```

**错误 5：序号与递推顺序颠倒**

循环里应当**先递推、后输出**。若把输出写在递推之前，输出的就是上一项（种子未递推的样子），与样例不符。

## 七、与综合实验的衔接

- 在实验 **C5/C10（冰区蒙特卡洛模拟、碎冰场分布统计）**中，这个 `for` 循环就是"随机数发生器"本身：把生成的 `u_i` 成对组合，就是平面上的随机点，从而可以模拟碎冰的随机位置、随机尺寸；
- 本练习是下一题"投点法估算 $\pi$"的**直接前置**——下一题把这里输出的 $u$ 两两配对当作点的坐标 $(x,y)$，统计落在单位圆内的比例。请务必理解：随机数不是"天上掉下来的"，而是**一条递推公式 + 一个种子 + 一次取模**算出来的确定序列，这正是"程序 = 数据 + 算法"在随机模拟中的体现。
