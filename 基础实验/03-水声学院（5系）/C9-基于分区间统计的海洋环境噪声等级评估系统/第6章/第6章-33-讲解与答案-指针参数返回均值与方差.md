## 二、预备知识：指针参数返回多个结果的基本原理（零基础阅读）

### 1. 问题是怎么来的

统计一个噪声序列，均值、方差、极值……结果往往不止一个。C 的函数 `return` 一次只能带回一个值，把结果打包成全局变量又能不用则不用——那工程上怎么办？

答案是**传地址**。你早就会一个例子：`scanf("%d", &n)`——`scanf` 是函数，你把 `n` 的**地址**给它，它算出的结果就"写回"了你的 `n`。本题的 `noise_stat` 用的是同一招，只不过换成自己写函数。

### 2. 传值 vs 传地址

```c
void f(double m)  { m = 100.0; }        /* 传值：改的是副本，调用者无感 */
void g(double *p) { *p = 100.0; }       /* 传地址：*p 就是调用者那块内存，一改就生效 */
```

调用 `g(&mean);` 后，`mean` 真的变成了 100.0。所以想让函数"带回"多个结果，就给每个结果传一个地址：

```c
void noise_stat(double *a, int n, double *pm, double *pv)
{
    /* 计算好后： */
    *pm = mean;
    *pv = var;
}
```

### 3. 公式推导

均值（样本平均值）：

$$\bar{x}=\frac{1}{n}\sum_{i=0}^{n-1}x_i$$

总体方差：每个样本与均值的离差平方，再取平均：

$$\sigma^2=\frac{1}{n}\sum_{i=0}^{n-1}(x_i-\bar{x})^2$$

为什么必须两趟？因为第二趟要用 $\bar{x}$，而 $\bar{x}$ 要第一趟扫完才知道。

### 4. 用本例走一遍

样例 1：`x = {62, 65, 68, 65, 65}`（dB）。

**第一趟**求均值：$\bar{x} = (62+65+68+65+65)/5 = 325/5 = 65.00$。

**第二趟**累加离差平方：

| $x_i$ | $x_i-\bar{x}$ | $(x_i-\bar{x})^2$ |
|---|---|---|
| 62 | −3 | 9 |
| 65 | 0 | 0 |
| 68 | +3 | 9 |
| 65 | 0 | 0 |
| 65 | 0 | 0 |

$\sigma^2 = (9+0+9+0+0)/5 = 18/5 = 3.60$——与样例一致。

```
主函数内存：              函数内：
+------+------+          a ──→ x[0] x[1] ... x[4]
| mean | var  |          pm ──→ mean（*pm 写入即改这里）
+------+------+          pv ──→ var
  ↑pm    ↑pv
```

> **这个模式在综合实验中反复出现**：C9 的统计汇总（均值+方差+分位数一次带回）、C6 的分段统计、C7 的趋势比较，全部是"数组地址进、多个结果地址出"的函数骨架。

## 三、解题思路

1. 主函数读入 `n` 与序列，存入数组 `x`；
2. 定义 `double mean, var;`，调用 `noise_stat(x, n, &mean, &var);`；
3. `noise_stat` 内两趟循环：先累加求均值写入 `*pm`，再累加离差平方求方差写入 `*pv`；
4. 主函数按格式输出。

## 四、参考代码

```c
#include <stdio.h>

/* 计算均值与总体方差，通过指针带回两个结果 */
void noise_stat(double *a, int n, double *pm, double *pv)
{
    double s = 0.0, q = 0.0;    /* s：和；q：离差平方和 */
    int i;

    for (i = 0; i < n; i++) {   /* 第一趟：求均值 */
        s += a[i];
    }
    *pm = s / n;

    for (i = 0; i < n; i++) {   /* 第二趟：累加离差平方 */
        q += (a[i] - *pm) * (a[i] - *pm);
    }
    *pv = q / n;                /* 总体方差：除以 n */
}

int main(void)
{
    double x[100], mean, var;
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf", &x[i]);
    }

    noise_stat(x, n, &mean, &var);      /* 传数组首地址 + 两个结果地址 */

    printf("均值 = %.2f dB\n", mean);
    printf("方差 = %.2f\n", var);
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：调用时忘加 `&`**

```c
noise_stat(x, n, mean, var);     /* 错：传的是值，函数改不到主函数变量 */
noise_stat(x, n, &mean, &var);   /* 对：传地址 */
```

**错误 2：函数内直接用 `pm = s / n;`**

```c
*pm = s / n;     /* 对：往 pm 指向的内存写 */
pm = s / n;      /* 错：把 double 赋给指针变量，类型不符，结果没带回 */
```

**错误 3：方差除成 n−1**

```c
*pv = q / (n - 1);   /* 错：那是"样本方差"，本题要求总体方差（除 n） */
*pv = q / n;         /* 对 */
```

**错误 4：一趟循环同时算均值和方差**

```c
for (i = 0; i < n; i++) {
    q += (a[i] - *pm) * (a[i] - *pm);   /* 错：此时 *pm 还没算出来 */
}
```

均值必须先于离差算出，**方差注定要两趟扫描**。
