# 第 3 章 练习 28　剂量区间人数统计

**所属综合实验**：D9（D9-基于统计计数的核事故应急人员剂量管理信息系统）

**对应章节**：3 程序控制结构（3.2 选择结构——if/else if、3.3 循环结构——for 循环、3.5 关系与逻辑运算）

**场景来源**：综合实验 D9《基于统计计数的核事故应急人员剂量管理信息系统》（核学院）——本练习是该实验中"按剂量档位统计人数、形成分级名册统计栏"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

应急指挥部最关心的一组数字，不是某个人的剂量，而是**"有多少人在正常档、多少人在关注档、多少人已经超限"**——它决定了要不要启动轮换、要不要安排医学观察。

《电离辐射防护与辐射源安全基本标准》（GB 18871-2002）规定职业照射个人年剂量限值为 **20 mSv/年**。综合实验 D9 按下面的三档对应急人员分类：

| 档位 | 累计剂量 $D$（mSv） | 处置含义 |
|---|---|---|
| 正常 | $D < 20$ | 可继续参与应急 |
| 关注 | $20 \le D < 50$ | 需密切监测，申报剂量 |
| 超限 | $D \ge 50$ | 停止作业，启动干预 |

本题实现"读入若干人员的累计剂量，逐个判定档位并**计数**"这一步，输出三档人数。

## 二、任务要求

编写一个完整程序 `dose_class.c`：

1. 从键盘读入人员数 `n`（**题目保证 1 ≤ n ≤ 100**）；
2. 用**循环**读入 `n` 个累计剂量值（double，单位 mSv，**题目保证 0 ≤ 每值 ≤ 80**）；
3. 在循环中用 **if / else if / else 多分支**结构逐个判定档位，并用三个**计数器**分别累计三档人数；
4. 循环结束后输出三档人数，格式见下。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各人的累计剂量（mSv），用空格分隔。

**输出**：共三行，依次为
```
normal = 正常档人数
attention = 关注档人数
over = 超限档人数
```
三个数都是整数。

## 四、样例

**样例 1**

输入：
```
5
3.2 21.0 8.5 55.0 19.9
```
输出：
```
normal = 3
attention = 1
over = 1
```

**样例 2**

输入：
```
6
20.0 49.9 50.0 5.0 5.0 5.0
```
输出：
```
normal = 3
attention = 2
over = 1
```

**样例 3**

输入：
```
3
0.0 19.9 20.0
```
输出：
```
normal = 2
attention = 1
over = 0
```

## 五、提示

- **计数器**是三个整数变量，循环**前**全部清零：`c1 = c2 = c3 = 0;`（连续赋值从右向左执行，三个变量都被赋 0）；
- 多分支结构要按**顺序**写，把最"严"的条件放前面也行，但更稳妥的写法是按区间从小到大依次排除：
  ```c
  if (d < 20.0)        c1++;
  else if (d < 50.0)   c2++;
  else                 c3++;
  ```
  注意 `else if (d < 50.0)` 隐含了"前面已经排除了 d < 20"，所以不必再写 `d >= 20 && d < 50`——**`else` 天然继承了上一个条件的反面**；
- 每读一个值就当场判定，**不需要保存所有数据**（保存全部是第 5 章数组的事）；
- 想一想：为什么"关注"档上界取 50 mSv？因为 GB 18871-2002 还规定**任一年不得超过 50 mSv**，超过这一"单年限值"就必须停止作业并干预。

**完成本练习后你将具备的能力**：用多分支 if/else if/else 做区间划分、用多个计数器做分组统计、把"逐条判定"扩展为"汇总计数"——这些是实验 D9 中"分级名册统计栏"的地基。
