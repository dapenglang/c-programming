# 第 5 章 练习 20　压力网格统计报表

**对应章节**：5 批量数据处理方法（综合 5.1 一维数组、5.2 二维数组、5.4 数组作函数参数、5.5 排序；第 2～4 章）

**场景来源**：综合实验 C9《冰面压力场热点分析系统》（水声学院）——本练习是该实验中"压力网格统计报表"环节的实现，也是本章的综合题。

**建议用时**：30 分钟

## 一、应用场景

一次冰池试验采集到一张冰面压力网格后，工程上要出一份**统计报表**：总压力、平均压力、峰值、最低值、有多少个测点超限，以及各测线的压力排序。这份报表不是靠一次遍历就能完成的，而是要把"读入 → 统计 → 分行均值 → 排序 → 输出"串成一条流水线，每一步都在同一张网格数据上操作。本练习把本章所学的二维数组、统计、排序、格式化输出综合起来，完成这条流水线。

## 二、任务要求

编写一个完整程序 `grid_report.c`：

1. 从键盘读入行数 `m`、列数 `n`（**题目保证 $1 \le m \le 20$、$1 \le n \le 20$**），声明二维数组 `double p[20][20]` 存放冰面压力值（kPa），并读入 $m \times n$ 个数据；
2. **统计**：全网格所有元素之和、平均值、最大值、最小值，以及**超过阈值**（压力 $\ge 100.00$ kPa）的测点个数；
3. **分行均值**：算出每一行的平均值，存入一维数组，并按**从大到小**排序（用冒泡或选择排序实现）；
4. **报表输出**：按规定格式输出以上全部结果。

## 三、输入输出格式

**输入**：第一行两个整数 $m$、$n$；随后 $m$ 行，每行 $n$ 个实数（空格分隔），表示压力值（kPa）。

**输出**：共 6 行，格式如下（统计数值保留 2 位小数）：

```
sum = 总和
mean = 平均值
max = 最大值
min = 最小值
超阈值(>=100.00) = 超限测点数
行均值降序: 值1 值2 ...
```

其中平均值为"总和 ÷ 测点总数"，行均值降序一行中，各值之间用一个空格分隔，行末不加多余空格。

## 四、样例

**样例 1**

输入：
```
3 3
90 95 100
80 85 90
110 115 120
```
输出：
```
sum = 885.00
mean = 98.33
max = 120.00
min = 80.00
超阈值(>=100.00) = 4
行均值降序: 115.00 95.00 85.00
```

**样例 2**

输入：
```
2 3
100 100 100
99 99 99
```
输出：
```
sum = 597.00
mean = 99.50
max = 100.00
min = 99.00
超阈值(>=100.00) = 3
行均值降序: 100.00 99.00
```

## 五、提示

1. **一趟统计**：用一次双重遍历同时完成求和、求最值、数超限点——每个元素只访问一次、四个量一起更新。最大值、最小值的初值都取第一个元素 `p[0][0]`；
2. **求各行均值**：外层走行、内层走列，第 $i$ 行均值为 $\text{rowMean}_i = \frac{1}{n}\sum_{j=0}^{n-1} p[i][j]$；
3. **降序排序**：对一维数组 `rowMean` 用冒泡排序，规则为"若 $\text{rowMean}[j] < \text{rowMean}[j+1]$ 就交换二者"，一趟下来最小的沉到末尾；
4. **平均值与超限判据**：平均值 = `sum / (m * n)`；超限判据为 `p[i][j] >= 100.0`（达到即算超限）；
5. **报表对齐**：按样例逐行打印，注意 `超阈值(>=100.00)` 中的 `100.00` 也按 2 位小数输出。

**完成本练习后你将具备的能力**：把读入、统计、分行均值、排序、输出串成完整数据流水线、在一次遍历中同时计算多个统计量、用冒泡排序给一维数组降序排列——这是实验 C9 中"压力场统计报表模块"的完整实现，也标志着你已掌握本章的批量数据处理方法。
