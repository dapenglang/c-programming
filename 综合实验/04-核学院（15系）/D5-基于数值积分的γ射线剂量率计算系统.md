# 题目 D5：基于数值积分的 γ 射线剂量率计算系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行 γ 射线剂量率计算工具。放射性核素衰变时放出不同能量的 γ 光子，每个光子在空间中传播时会对人体产生辐射剂量。系统读入核素源项参数（活度与 γ 能量分支）、能量—剂量转换因子表与屏蔽材料衰减参数，把连续 γ 能谱离散成若干能群，逐群计算该能群对空间某点剂量率的贡献（活度 × 分支比 × 转换因子 × 距离衰减 × 屏蔽衰减），再用梯形数值积分累加得到全谱剂量率，最后给出剂量率随距离的变化表、不同屏蔽层厚度的衰减对比与剂量报表。

γ 剂量率计算是辐射防护设计的核心问题。如果不算清剂量率，就无法确定人员可以停留多久、是否需要加装屏蔽、安全距离应当设为多少——辐射防护中最根本的三条原则"时间、距离、屏蔽"全部建立在剂量率量化评估的基础上。核电站检修人员的作业许可、加速器机房的屏蔽墙设计、医用放射源的防护屏障、放射性废物的转运与暂存管理，都必须先回答"在某处、某时、剂量率是多少"。其中距离衰减与屏蔽衰减的联合作用，决定了防护方案的经济性与安全性之间的平衡。

本系统支撑的关键场景包括：① 核设施屏蔽墙与防护门的厚度设计；② 检修作业窗口的时间与距离约束评估；③ 医用与工业放射源的屏蔽计算；④ 放射性物质运输容器的防护校核；⑤ 教学演示——用数值积分把"点核模型"变成可计算的剂量率。系统采用课程内的梯形数值积分、线性插值查表与多源累加，不含任何超纲理论。本题目与核工程与核技术专业"辐射防护"方向直接对应。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的 γ 射线剂量率计算系统：从文本文件读入核素源项参数（活度与各 γ 能量分支）、能量—剂量转换因子表，实现转换因子的线性插值查询，逐能群计算单能群剂量率，用梯形积分对全谱累加得到总剂量率，支持多个源项叠加，输出剂量率随距离变化表、屏蔽层厚度扫描对比表与剂量报表。

专业关联上，本题目还原了辐射防护中最常用的"点核积分"剂量率估算流程。学生在实现中掌握数组、函数、结构体、文件读写、线性插值与梯形积分，理解距离衰减（平方反比）与屏蔽衰减（指数）叠加的物理含义，全程不涉及任何需要先修的专业理论。

## 三、数据来源与格式

- **数据文件格式**：分三个文本文件。其一是核素源项参数文件 `source_terms.txt`，首行为标题，其后每行为一条源项记录，字段依次为：源项标识、核素名、活度 A（单位：Bq）、源点到计算点距离 r（单位：cm）。每个源项对应多条 γ 能量分支记录，位于同一文件中以 `+` 开头的续行给出：γ 能量 E（单位：MeV）、分支比 b（无量纲）。其二是剂量转换因子表 `dose_factor.txt`，每行"能量 E（MeV）—转换因子 CF（单位：pSv·cm²/photon）"。其三是屏蔽材料参数 `shield_param.txt`，每行"材料名—线性衰减系数 μ（单位：1/cm）—屏蔽厚度 d（单位：cm）"。

```
# src_id  nuclide  activity_Bq  distance_cm
S1        Co-60    3.70e12      200.0
+ 1.173   0.9986
+ 1.332   0.9998
S2        Cs-137   1.20e13      300.0
+ 0.662   0.8510
```
```
# energy_MeV  factor_pSv_cm2
0.050        0.0120
0.500        0.4500
1.000        0.9200
3.000        2.1000
```
```
# material  mu_per_cm  thickness_cm
lead        0.580       2.0
iron        0.240       5.0
```

- **仿真数据生成规则**：
  - 源项标识：`S1`、`S2`…，无空格；核素名如 `Co-60`、`Cs-137`，长度 ≤ 15。
  - 活度 A：单位 Bq，取值范围 1.0e8～1.0e13，按对数均匀分布生成。
  - 源点到计算点距离 r：单位 cm，取值范围 50～5000（0.5～50 m），按均匀分布生成。
  - γ 能量分支：每个源项 1～4 条分支，能量 E 取值 0.050～3.000 MeV（按均匀分布），分支比 b 取值 0.05～1.00（保证各分支比之和 ≤ 1）。
  - 转换因子 CF：单位 pSv·cm²/photon，能量 0.05～3.0 MeV，取值随能量单调增大，范围 0.010～2.200，按单调平滑方式生成。
  - 线性衰减系数 μ：单位 1/cm，铅 0.30～0.80、铁 0.10～0.35、混凝土 0.05～0.15，按均匀分布生成。
  - 屏蔽厚度 d：单位 cm，取值 0.0～30.0。
  - **异常值注入方式**：由教师提供的生成程序注入三类错误。其一，活度为负或为 0，校验时剔除；其二，分支比之和 > 1 或单条分支比为负，校验时给出告警并归一化或剔除；其三，转换因子表中能量未按升序排列或出现重复能量，需在插值前排序去重。另可注入非数字串（如 `NA`）考察读入容错。

- **真实数据集（如有）**：真实的 γ 能量分支与发射概率数据来自 IAEA/NDS 的核素衰变数据（如 NUDAT，https://www.nndc.bnl.gov/nudat3/）与评价核结构数据库 ENSDF；剂量转换因子可参考 ICRP 与国际标准化组织发布的注量—剂量转换系数。学生**无需下载**真实数据，课程提供与上述字段含义对应的简化仿真数据表，其中"γ 能量—分支比"对应 NUDAT 的 γ 射线发射概率，"转换因子"对应注量—有效剂量转换系数（单位经统一折算为 pSv·cm²/photon）。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_SRC      20        /* 最多源项个数 */
#define MAX_BRANCH   6         /* 单个源项最多 γ 分支数 */
#define MAX_FACTOR   40        /* 转换因子表最大行数 */
#define MAX_GROUP    40        /* 最大能群数 */
/* ===== γ 能量分支 ===== */
struct GammaBranch {
    double energy;             /* γ 能量 E，单位 MeV */
    double branch;             /* 分支比 b，光子/衰变，0~1 */
};
/* ===== 核素源项 ===== */
struct SourceTerm {
    char   srcId[8];           /* 源项标识，如 "S1" */
    char   nuclide[16];        /* 核素名，如 "Co-60" */
    double activity;           /* 活度 A，单位 Bq，> 0 */
    double distance;           /* 源点到计算点距离 r，单位 cm，> 0 */
    struct GammaBranch br[MAX_BRANCH]; /* γ 能量分支数组 */
    int    nBranch;            /* 分支条数 */
    int    valid;              /* 有效标志 */
};
/* ===== 剂量转换因子表 ===== */
struct DoseFactor {
    double energy;             /* 能量，MeV */
    double factor;             /* 转换因子 CF，pSv·cm²/photon */
};
/* ===== 屏蔽材料参数 ===== */
struct ShieldParam {
    char   material[16];       /* 材料名 */
    double mu;                 /* 线性衰减系数，1/cm */
    double thickness;          /* 屏蔽厚度，cm */
};
/* ===== 全局数据区 ===== */
struct SourceTerm  g_src[MAX_SRC];        /* 源项表 */
int                g_srcCount;            /* 源项条数 */
struct DoseFactor  g_factor[MAX_FACTOR];  /* 转换因子表 */
int                g_factorCount;         /* 转换因子表行数 */
struct ShieldParam g_shield;              /* 当前屏蔽参数 */
double             g_groups[MAX_GROUP];   /* 能群划分能量点，MeV */
double             g_rate[MAX_GROUP];     /* 各能群剂量率贡献，pSv/h */
int                g_groupCount;          /* 能群数 */
double             g_totalRate;           /* 全谱总剂量率，pSv/h */
double             g_distList[16];        /* 距离扫描列表，cm */
int                g_distCount;           /* 距离扫描个数 */
double             g_distRate[16];        /* 各距离总剂量率，pSv/h */
double             g_thickList[16];       /* 屏蔽厚度扫描列表，cm */
int                g_thickCount;          /* 厚度扫描个数 */
double             g_thickRate[16];       /* 各厚度总剂量率，pSv/h */
/* ===== 处理日志 ===== */
struct LogItem { char op[24]; char detail[72]; };
struct LogItem g_log[128];
int            g_logCount;
```

辅助说明：点核模型的剂量率公式为 `Ḋ = A · b · CF(E) / (4π·r²) · exp(−μ·d)`，其中 `CF(E)` 由转换因子表线性插值得到；对连续 γ 谱，把能量范围离散成若干能群，用梯形积分对全谱累加。多源叠加时对各源项结果逐项求和。全部量以 `double` 存储，能量与剂量率用科学计数法输出。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（3 个模块）

**M1 核素源项参数读入模块**（源文件 `SourceIO.c`）

- 功能简介：打开源项参数文件，跳过标题行，循环读入源项主行（标识、核素名、活度、距离），遇到以 `+` 开头的续行则作为 γ 能量分支读入当前源项，填充 `g_src[]`；校验活度是否为正、分支比之和是否超限，异常记录置 `valid=0` 并给出清单。
- 输入：源项参数文件路径（默认 `source_terms.txt`）。
- 输出：`g_src[]`、`g_srcCount`；屏幕源项校验报告。

**M2 能量-剂量转换因子表读入模块**（源文件 `FactorIO.c`）

- 功能简介：读入转换因子表，按能量升序排序并剔除重复能量点；校验能量范围是否覆盖 0.05～3.0 MeV、因子是否为正；读入屏蔽材料参数（材料名、衰减系数、厚度）填充 `g_shield`。
- 输入：转换因子表文件、屏蔽参数文件路径。
- 输出：`g_factor[]`、`g_factorCount`、`g_shield`；屏幕因子表与屏蔽参数摘要。

**M3 转换因子插值模块**（源文件 `Interp.c`）

- 功能简介：实现线性插值函数 `double factorAt(double E)`：在因子表中找到 E 所在区间 [E_i, E_{i+1}]，按 `CF = CF_i + (CF_{i+1}−CF_i)·(E−E_i)/(E_{i+1}−E_i)` 求值；对 E 低于最小能量或高于最大能量时分别取边界值并提示外插。为 M4 提供任意能量下的转换因子查询能力。
- 输入：目标能量 E（MeV）。
- 输出：返回转换因子（pSv·cm²/photon）；屏幕可选打印所用区间。

### 第二部分：算法实现（3 个模块）

**M4 单能群剂量率计算模块**（源文件 `DoseRate.c`）

- 功能简介：对给定源项的一条 γ 分支，计算该能量对应的未屏蔽剂量率 `Ḋ0 = A·b·CF(E)/(4π·r²)`（单位 pSv/h，距离单位 cm 时需做单位换算），再乘屏蔽衰减因子 `exp(−μ·d)` 得到屏蔽后剂量率；同时输出衰减倍数的数量级，直观显示屏蔽效果。
- 输入：源项下标、分支下标、`g_shield`。
- 输出：返回该分支的剂量率贡献（pSv/h）；屏幕打印计算过程。

**M5 分能群梯形积分累加模块**（源文件 `Integrate.c`）

- 功能简介：把源项能量范围划分成 `g_groupCount` 个能群，逐个能群调用 M4 计算能群贡献，用梯形公式对相邻能群做加权累加，得到该源项的全谱剂量率，填入 `g_rate[]`；输出各能群的贡献明细。
- 输入：源项下标、能群划分 `g_groups[]`。
- 输出：`g_rate[]`、该源项总剂量率；屏幕能群贡献表。

**M6 多源叠加计算模块**（源文件/`Sum.c`）

- 功能简介：遍历所有有效源项，对每个源项调用 M5 求其全谱剂量率，逐项累加得到总剂量率 `g_totalRate`；同时输出各源项的分项贡献与占比，标注主导源项。
- 输入：`g_src[]`、`g_shield`、能群划分。
- 输出：`g_totalRate`；屏幕分项贡献与占比表。

### 第三部分：数据输出（4 个模块）

**M7 剂量率-距离表模块**（源文件 `Distance.c`）

- 功能简介：读入一组距离值，对每个距离（其余参数不变）重新执行 M6 求总剂量率，填入 `g_distRate[]`；输出"距离—剂量率—相对首点衰减倍数"对照表，验证平方反比规律。
- 输入：`g_distList[]`、`g_distCount`、源项与屏蔽参数。
- 输出：`g_distRate[]`；屏幕距离扫描对照表。

**M8 屏蔽层厚度实验模块**（源文件 `ShieldExp.c`）

- 功能简介：读入一组屏蔽厚度，对每个厚度（材料与其余参数不变）调用 M6 求总剂量率，填入 `g_thickRate[]`；输出"厚度—剂量率—衰减倍数"对照表，并给出"剂量率降为初始 1/10 所需厚度"的估算（半对数线性插值）。
- 输入：`g_thickList[]`、`g_thickCount`、源项与材料参数。
- 输出：`g_thickRate[]`；屏幕厚度扫描对照表。

**M9 剂量报表输出模块**（源文件 `DoseReport.c`）

- 功能简介：把源项参数、因子表、各能群贡献、总剂量率、距离扫描表与厚度扫描表写出到 `dose_report.txt` 与 `dose_tables.csv`；按预设控制水平（如 2.5 μSv/h 的作业控制区边界）标注各距离是否超限。
- 输入：全部全局数据。
- 输出：`dose_report.txt`、`dose_tables.csv`；屏幕确认信息与控制水平判定。

**M10 主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：文本主菜单（读源项 / 读因子表 / 算单分支 / 算单源项 / 多源叠加 / 距离扫描 / 厚度扫描 / 输出报表 / 退出），用 `do-while + switch` 调度 M1～M9；状态标记约束"必须先读入源项与因子表才能计算剂量率"。
- 输入：用户菜单选项。
- 输出：调度各模块；维护日志表。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → `switch` 分发各模块。状态约束：M4～M9 运行前必须已执行 M1 与 M2；M7/M8 的扫描过程内部对每个距离或厚度重新调用 M6，保证比较条件一致。

**数据流**：

```
source_terms.txt ─────► M1 源项读入 ─► g_src[] (活度 + γ分支)
dose_factor.txt ─┐                                  │
shield_param.txt ┴► M2 因子/屏蔽读入 ─► g_factor[] / g_shield
                                │                   │
                M3 转换因子线性插值 ◄───────────────┘
                                │
        ┌───────────────────────┼────────────────────────┐
        ▼                       ▼                        ▼
  M4 单能群剂量率 ─► M5 分能群梯形积分 ─► M6 多源叠加 ─► g_totalRate
                                                        │
        ┌───────────────────────────────────────────────┼──────────────┐
        ▼                                               ▼              ▼
 M7 剂量率-距离表                                M8 屏蔽厚度实验   M9 剂量报表输出
```

所有模块通过全局源项表、因子表、屏蔽参数与剂量率数组交换数据；转换因子插值（M3）是全系统公用函数，其他模块只能调用，不得另写插值代码。
