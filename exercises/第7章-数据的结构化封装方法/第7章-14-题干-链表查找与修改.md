# 第 7 章 练习 14　链表查找与修改

**对应章节**：7 数据的结构化封装方法（7.5 链表——遍历查找、按条件修改节点数据域、`malloc`/`free`）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"识别异常测点并折减修正载荷"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰载荷测量中，个别测点会因传感器受冲击而出现**偏大的异常读数**。数据辨识模块的标准做法是：设定一个阈值，凡是**载荷超过阈值**的测点判为异常，按经验折减系数 $k$（$0<k<1$）把它的载荷下调，以抑制尖峰对后续统计分析的影响。由于异常测点可能出现在链表的任何位置，程序需要**遍历整条链表**，逐个检查载荷是否超阈，命中就就地修改该节点的数据域，并统计一共修正了多少条。这是链表"只读遍历"到"可写遍历"的第一步。

## 二、任务要求

编写一个完整程序 `list_modify.c`：

1. 定义节点结构体类型 `struct IceLoad`：`int id`、`double load`（载荷，kN）、`struct IceLoad *next`；
2. 读入整数 `n`，再读入 `n` 行记录（`id` 与 `load`），用**尾插法**建立链表；
3. 读入阈值 `limit` 与折减系数 `k`，其中 `0 < k < 1`；
4. **遍历**链表，对每个满足 $load > limit$ 的节点，将它的载荷修改为 $load \times k$，并把修正计数加一；不满足条件的节点保持不变；
5. 遍历结束后，按链表顺序输出每个节点的 `id` 与修改后的载荷（保留 2 位小数），最后输出 `modified = 修正条数`；
6. 每次 `malloc` 检查返回值，程序结束用 `free` 释放全部节点。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`（`0 ≤ n ≤ 100`）；
- 接下来 `n` 行：每行 `id load`；
- 最后一行：两个实数 `limit` 与 `k`（阈值与折减系数）。

**输出**：先按链表顺序输出 `n` 行，每行 `id load`（修改后的载荷，保留 2 位小数）；最后一行输出 `modified = 修正条数`。

## 四、样例

**样例 1**

输入：
```
3
101 30.0
102 10.0
103 50.0
20 0.8
```
输出：
```
101 24.00
102 10.00
103 40.00
modified = 2
```

**样例 2**

输入：
```
4
1 5.0
2 15.0
3 25.0
4 100.0
20 0.5
```
输出：
```
1 5.00
2 15.00
3 12.50
4 50.00
modified = 2
```

## 五、提示

- 遍历骨架与上一题相同：`p = head; while (p != NULL) { …; p = p->next; }`；
- 在循环体内检查并修改：
  ```c
  if (p->load > limit) {       /* 命中异常测点 */
      p->load = p->load * k;   /* 就地修改数据域 */
      modified++;              /* 统计修正条数 */
  }
  ```
- 修改的是**节点里的数据域** `p->load`，不要改动指针 `next`，链表结构不受影响；
- `k` 与 `limit` 用 `double` 读入（`scanf("%lf %lf", &limit, &k);`）；
- 输出必须在**修改之后**进行，才能看到折减结果；若先输出再修改，看到的仍是原值。

**完成本练习后你将具备的能力**：能在遍历链表的途中按条件**定位**并**就地修改**节点数据、能统计修改条数、能区分"改数据"与"改指针"两类操作——这是实验 C7"异常测点修正模块"的地基。
