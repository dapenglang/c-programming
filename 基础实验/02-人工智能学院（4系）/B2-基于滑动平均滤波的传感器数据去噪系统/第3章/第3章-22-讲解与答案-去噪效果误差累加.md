## 二、预备知识：误差平方和的基本原理（零基础阅读）

### 1. 问题是怎么来的

要把"两条数据序列差多少"变成一个数。最朴素的想法是"逐点相减再相加"：

$$
(x_1-y_1) + (x_2-y_2) + \cdots + (x_n-y_n)
$$

但这个办法有个致命缺点：**有正有负会互相抵消**。比如 $x_1$ 比 $y_1$ 大 $5$、$x_2$ 比 $y_2$ 小 $5$，两项一加正好抵消，程序会误以为"完全一致"，其实差得很远。

解决办法：把每个差值**先平方再相加**。平方使所有项都非负，就不会抵消了。

### 2. 公式是怎么来的

$$
S = \sum_{i=1}^{n}{(x_i - y_i)^2}
$$

符号 $\sum$ 读作"西格玛"，意思是"把后面这串东西从 $i=1$ 加到 $i=n$"。展开就是：

$$
S = (x_1-y_1)^2 + (x_2-y_2)^2 + \cdots + (x_n-y_n)^2
$$

这个量叫**误差平方和**（Sum of Squared Errors，SSE），是衡量两组数据差异最常用的指标之一：差得越远，$S$ 越大；完全一致，$S = 0$。它对大误差还有"放大"作用（平方），正合工程上"不能容忍个别点差太多"的要求。

### 3. 用本例走一遍

**例 1**：原始 $x = (10, 12, 14)$，去噪 $y = (10.5, 12.5, 13.5)$。

- 第 1 点：$(10 - 10.5)^2 = (-0.5)^2 = 0.25$；
- 第 2 点：$(12 - 12.5)^2 = (-0.5)^2 = 0.25$；
- 第 3 点：$(14 - 13.5)^2 = (0.5)^2 = 0.25$；
- 合计：$S = 0.25 + 0.25 + 0.25 = 0.75$。

**例 2**：$x = (1,2,3,4)$，$y = (1.5,2.5,3.5,4.5)$，每点差 $0.5$，平方都是 $0.25$，共 4 点：

$$
S = 4 \times 0.25 = 1.00
$$

两例都验证了"逐点平方再累加"。

### 4. 编程时怎么用它

用一个 `double` 累加器，循环里反复"先平方、再相加"：

```c
double sse = 0.0;
for (i = 0; i < n; i++) {
    double d = x[i] - y[i];
    sse += d * d;
}
```

**累加器的初值一定要写成 `0.0`**。若初值给了别的数，结果就整体偏了；若忘了初始化，`sse` 里是随机值，结果无法预料。

> **这个思想在综合实验中反复出现**：B2 去噪误差、B3 蒙特卡洛估计误差、B10 相似度偏差，都是"逐项算差、累加成一个指标"同一个套路。

## 三、解题思路

1. **读入点数**：`scanf("%d", &n);`；
2. **读入两串数据**：用一个 `for` 循环读 $n$ 个原始值到数组 `x[]`，再一个 `for` 循环读 $n$ 个去噪值到数组 `y[]`（数组在下章讲，本题为方便先借用）；
3. **累加平方误差**：`sse = 0.0;` 后循环 `sse += (x[i]-y[i])*(x[i]-y[i]);`；
4. **输出**：`printf("SSE = %.4f\n", sse);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n;                 /* 采样点数 */
    double x[20], y[20];   /* 原始序列 x[]、去噪序列 y[] */
    double sse = 0.0;      /* 误差平方和，累加器初值必须为 0 */
    int i;

    /* 读入点数 */
    scanf("%d", &n);

    /* 读入 n 个原始采样值 */
    for (i = 0; i < n; i++)
        scanf("%lf", &x[i]);

    /* 读入 n 个去噪后的采样值 */
    for (i = 0; i < n; i++)
        scanf("%lf", &y[i]);

    /* 逐点计算差值平方并累加 */
    for (i = 0; i < n; i++) {
        double d = x[i] - y[i];   /* 当前点误差 */
        sse += d * d;             /* 平方后累加 */
    }

    /* 输出误差平方和，保留 4 位小数 */
    printf("SSE = %.4f\n", sse);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3 / 10 12 14 / 10.5 12.5 13.5 | 0.25+0.25+0.25 = 0.75 | `SSE = 0.7500` ✓ |
| 4 / 1 2 3 4 / 1.5 2.5 3.5 4.5 | 4×0.25 = 1.00 | `SSE = 1.0000` ✓ |
| 2 / 5 5 / 5 5 | 0+0 = 0（完全一致） | `SSE = 0.0000` ✓ |
| 2 / 0 0 / 1 1 | 1+1 = 2 | `SSE = 2.0000` ✓ |

完全一致的序列 SSE 为 0，符合"差异为零"的定义。

## 六、常见错误与讲解

**错误 1：累加器忘记初始化或初值写错（最典型）**

```c
double sse;        /* 错：未初始化，起始值是内存里的随机数 */
double sse = 0;    /* 对：初值 0.0 */
```

**错误 2：没有平方就累加，正负抵消**

```c
sse += x[i] - y[i];          /* 错：可能正负抵消，结果为 0 */
sse += (x[i]-y[i])*(x[i]-y[i]);  /* 对：先平方，非负 */
```

**错误 3：用整数存差值或累加和**

```c
int d = x[i] - y[i];   /* 错：若 x、y 是 double，小数部分丢失 */
double d = x[i] - y[i];/* 对 */
```

**错误 4：循环边界写错，漏掉或多算一个点**

```c
for (i = 0; i <= n; i++)   /* 错：i 到 n 时越界，多算一个 */
for (i = 0; i < n; i++)    /* 对：0 ~ n-1 共 n 个 */
```

C 语言数组下标从 0 开始，$n$ 个元素的下标是 $0 \sim n-1$。
