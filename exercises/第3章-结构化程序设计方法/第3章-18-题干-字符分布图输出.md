# 第 3 章 练习 18　字符分布图输出

**对应章节**：3 结构化程序设计方法（3.3 循环结构——嵌套循环、3.1 顺序结构、3.4 关系与逻辑运算）

**场景来源**：综合实验 C9《水下结构表面压力场分析系统》（水声学院）——本练习是该实验中"压力分布条形图显示"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

网格测点的压力数据如果只以数字罗列，很难一眼看出哪里高、哪里低。工程上常把每个数值画成一条横向条形：数值大就画得长，数值小就画得短，整张图就像"热力图"一样直观。在只有文本终端的程序里，条形用一连串星号 `*` 来表示——这就是最简单的字符分布图。本练习用嵌套循环实现"读一个数、画一条星号条"的输出流程。

## 二、任务要求

编写一个完整程序 `barchart.c`：

1. 从键盘先读入一个整数 `n`（测点个数，题目保证 `1 ≤ n ≤ 20`），再依次读入 `n` 个非负整数（每个数代表相应测点的条形长度，即星号个数，保证 `0 ≤ v ≤ 60`）；
2. 用 **外层循环控制"第几条"、内层循环控制"打印多少个星号"** 的嵌套 for 循环完成输出（**不使用数组**）；
3. 每条条形前统一打印序号和分隔符 `| `，随后打印该条形对应数量的星号，最后换行；
4. 条形长度逐个读入并立即输出，不把数据全部存下来。

## 三、输入输出格式

**输入**：第一行为整数 `n`；后续为 `n` 个整数（可与 `n` 在同一行，也可分行），数与数之间用空白分隔。

**输出**：共 n 行，第 i 行格式为 `i | ` 后跟若干个星号（个数等于第 i 个数值），行尾换行。若某数值为 0，则该行 `| ` 之后没有星号。

## 四、样例

**样例 1**

输入：
```
5
3 7 2 9 5
```
输出：
```
1 | ***
2 | *******
3 | **
4 | *********
5 | *****
```

**样例 2**

输入：
```
4
4 1 6 2
```
输出：
```
1 | ****
2 | *
3 | ******
4 | **
```

## 五、提示

本题是"**嵌套循环**"最直观的应用：外层循环管"第几条"，每转一圈处理一条；内层循环管"这条画多长"，转多少圈就打多少个星号：

```c
for (i = 1; i <= n; i++) {      /* 外层：第 i 条 */
    scanf("%d", &v);            /* 读入这条的长度 */
    printf("%d | ", i);         /* 打印序号和分隔符 */
    for (k = 1; k <= v; k++)    /* 内层：打印 v 个星号 */
        printf("*");
    printf("\n");               /* 本条结束，换行 */
}
```

注意换行符 `\n` 一定要放在**内层循环结束之后**，这样一整条星号才会在同一行上。

**完成本练习后你将具备的能力**：用嵌套循环完成"逐条读取 + 逐字符打印"的输出模式、理解"外层管行、内层管列（长度）"的分工——这是实验 C9 中绘制压力分布图以及一切文本图形输出的基础。
