## 二、预备知识：选择排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

与练习 06 同一个任务：把数组排好序。冒泡排序的哲学是"**相邻的比较，大的自然往后冒**"；选择排序换个更"主动"的哲学：**每一轮我直接看清谁该站在最前面，然后请他去**。这个"看清谁最大"的动作，正是练习 02 刚练过的打擂台。

### 2. 一轮选择在做什么

降序排列意味着：最前面应放最大值。于是第 $k$ 轮（$k$ 从 0 起）分两个阶段：

**阶段一（只看不动）**：在下标 $k$ 至 $n-1$ 的未排序部分里打擂台——先假定 `p = k`（擂主下标），`j` 从 `k+1` 扫到 `n-1`，遇 `a[j] > a[p]` 就更新 `p = j`。**整个阶段数组一个元素都不改**，只改一个下标变量。

**阶段二（一次交换）**：擂主下标 `p` 与本轮目标位 `k` 不同则交换 `a[k]` 与 `a[p]`。交换后 `a[k]` 落定，未排序部分左端右移一格。

用本题数据走**第 1 轮**（$n=5$，数组 `6.4 2.1 9.3 4.8 7.6`，目标位 $k=0$）：

| 动作 | 说明 | 擂主下标 p | 数组状态（不变） |
|---|---|---|---|
| 初始假设 | 擂主 = a[0] = 6.4 | 0 | 6.4 2.1 9.3 4.8 7.6 |
| j=1 | 2.1 < 6.4，不换擂主 | 0 | 同上 |
| j=2 | 9.3 > 6.4，换擂主 | 2 | 同上 |
| j=3 | 4.8 < 9.3，不换 | 2 | 同上 |
| j=4 | 7.6 < 9.3，不换 | 2 | 同上 |
| 阶段二 | p=2 ≠ k=0，交换 a[0] 与 a[2] | — | **9.3** 2.1 6.4 4.8 7.6 |

**第 2 轮**（目标位 $k=1$，未排序部分为下标 1~4）：

| 动作 | 说明 | p | 数组状态 |
|---|---|---|---|
| 初始假设 | 擂主 = a[1] = 2.1 | 1 | 9.3 2.1 6.4 4.8 7.6 |
| j=2 | 6.4 > 2.1，换擂主 | 2 | 同上 |
| j=3 | 4.8 > 6.4？否 | 2 | 同上 |
| j=4 | 7.6 > 6.4，换擂主 | 4 | 同上 |
| 阶段二 | 交换 a[1] 与 a[4] | — | 9.3 **7.6** 6.4 4.8 **2.1** |

### 3. 与冒泡排序的对照

| 比较项 | 冒泡排序 | 选择排序 |
|---|---|---|
| 内层做什么 | 相邻比较，逆序就交换 | 打擂台只记下标，不交换 |
| 每轮交换次数 | 最多 $n-1$ 次 | 最多 1 次 |
| 每轮落定 | 最大值沉到**末尾** | 最大值提到**前端** |
| 落定方向 | 从右往左填 | 从左往右填 |

两者外层都是 $n-1$ 轮、每轮落定 1 个、双重循环结构完全平行——学会一个，另一个只是内层换了动作。

### 4. 循环边界的来历

- 外层 $k$ 取 0 到 $n-2$：每轮落定 1 个，$n-1$ 轮后最后一个自动就位；
- 内层 `j` 从 `k+1` 到 `n-1`：擂主已假设在 `k`，只需挑战后面的。

## 三、解题思路

1. 读入 $n$ 与数组；
2. 外层 `for (k = 0; k <= n-2; k++)`；
3. 内层打擂台求未排序部分最大值下标 `p`；
4. `if (p != k)` 三步交换；
5. 打印本轮状态行；全部结束后打印结果行。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double a[100], t;   /* a 为热点强度，t 为交换临时变量 */
    int n, k, j, p, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &a[i]);

    /* 选择排序（降序）：第 k 轮把未排序部分的最大值换到 a[k] */
    for (k = 0; k <= n - 2; k++) {
        p = k;                              /* 阶段一：打擂台，只记下标 */
        for (j = k + 1; j <= n - 1; j++)
            if (a[j] > a[p])
                p = j;
        if (p != k) {                       /* 阶段二：一次交换 */
            t = a[k];
            a[k] = a[p];
            a[p] = t;
        }
        printf("第 %d 轮:", k + 1);
        for (i = 0; i < n; i++)
            printf(" %.2f", a[i]);
        printf("\n");
    }

    printf("排序结果:");
    for (i = 0; i < n; i++)
        printf(" %.2f", a[i]);
    printf("\n");

    return 0;
}
```

## 五、运行验证

样例 1（`6.4 2.1 9.3 4.8 7.6`）各轮状态（前两轮已在预备知识逐步模拟）：

| 轮次 | 目标位 k | 擂主找到 | 是否交换 | 轮末数组 |
|---|---|---|---|---|
| 1 | 0 | 9.3（下标 2） | 是，a[0]↔a[2] | 9.30 2.10 6.40 4.80 7.60 |
| 2 | 1 | 7.6（下标 4） | 是，a[1]↔a[4] | 9.30 7.60 6.40 4.80 2.10 |
| 3 | 2 | 6.4（下标 2） | 否（已在位） | 9.30 7.60 6.40 4.80 2.10 |
| 4 | 3 | 4.8（下标 3） | 否（已在位） | 9.30 7.60 6.40 4.80 2.10 |

与样例 1 输出逐字一致（第 3、4 轮擂主恰在目标位，`p != k` 不成立，数组不变）。样例 2 第 1 轮擂主 5.5 已在位不交换、第 2 轮 3.3 换到中间，输出同样吻合。

## 六、常见错误与讲解

**错误 1：扫描过程中边比边换（混回冒泡）**

```c
for (j = k + 1; j <= n-1; j++)
    if (a[j] > a[k]) { 交换 a[k] 与 a[j]; }   /* 错：这不是选择排序，逻辑也会乱 */
```

选择排序要求**先记下标 `p`，扫描完毕再换**。

**错误 2：擂主比较对象写错**

```c
if (a[j] > a[k]) p = j;    /* 错：应与当前擂主 a[p] 比，不是与目标位 a[k] 比 */
```

与 `a[k]` 比会漏掉"后来居上"的更大值。

**错误 3：内层起点写成 `j = k`**

```c
for (j = k; j <= n-1; j++) ...   /* 多比较一次 a[k] 与它自己，不致错但冗余 */
for (j = k + 1; j <= n-1; j++)   /* 对 */
```

**错误 4：外层轮数差一**

```c
for (k = 0; k <= n - 1; k++)   /* 错：k = n-1 时未排序部分只剩 1 个，j 从 n 到 n-1 空转，且无意义 */
for (k = 0; k <= n - 2; k++)   /* 对：共 n-1 轮 */
```

## 七、与综合实验的衔接

- 实验 **C9（冰面压力场热点分析）**的报告环节要求按强度降序列出热点，本练习的选择排序就是该环节的实现；报告通常只取前十名——降序排好后"前 10 个"就是数组前 10 个下标，取用极其方便；
- 与练习 06 对照总结：冒泡与选择是"每轮落定一个"思想下的两种实现，二者比较次数同为 $O(n^2)$，选择排序交换次数少。往后学到更多排序（如快速排序）时，判断优劣的框架——**比较多少次、交换多少次、是否稳定**——就从这两题的对照中建立起来。实验 C7 的载荷谱整理与 C9 的热点排序共用这套框架。
