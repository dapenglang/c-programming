## 二、预备知识：单位换算与浮点运算的基本原理（零基础阅读）

### 1. 为什么要换算单位

物理公式只在**单位配套**时才成立。风压公式 $w=\frac12\rho v^2$ 中，空气密度 $\rho$ 用的是 $\mathrm{kg/m^3}$，那么速度就必须用 $\mathrm{m/s}$，算出的风压单位才是 Pa（$\mathrm{kg/(m\cdot s^2)}$）。而气象台报的风速是 km/h，两者不能直接代公式，必须先换。

### 2. 换算系数是怎么来的

1 km 等于 1000 m，1 h 等于 3600 s，所以

$$
v = \frac{v_{\mathrm{km/h}}\times 1000}{3600} = \frac{v_{\mathrm{km/h}}}{3.6}
$$

例如 36 km/h：$36 \div 3.6 = 10$ m/s。这个 $1/3.6$ 就是程序里的常量 `KMH_TO_MS`。

### 3. 用本例走一遍

风速 54 km/h：

- 换算：$v = 54 \div 3.6 = 15$ m/s；
- 代公式：$w = \frac12 \times 1.25 \times 15^2 = 0.625 \times 225 = 140.625$ Pa。

### 4. 编程时要注意什么

（1）**整数除法陷阱**。C 语言里若除号两边都是整数，结果自动**舍去小数**：`54 / 3` 得 18 而不是 18.0，`1 / 3.6` 甚至因为写成整数 `1` 而出错。所以常量要写成 `1.0 / 3.6`，除数是 `3.6`（小数）而不是 `3`。

（2）**顺序问题**。公式 $w=\frac12\rho v^2$ 要先算平方、再乘系数。C 里平方写成 `v * v`，不能用 `v^2`（`^` 在 C 语言中不是乘方，而是按位异或，第 2 章先记住不写它）。

（3）**格式符与类型匹配**。`double` 变量读入用 `%lf`，输出用 `%f`（可加精度如 `%.4f`）。用错格式符会输出乱码。

## 三、解题思路

1. **列常量**：空气密度 `RHO = 1.25`、换算系数 `KMH_TO_MS = 1.0 / 3.6`，用 `const double`；
2. **备变量**：读入的 `v_kmh`，换算出的 `v`，算出的 `w`，都用 `double`；
3. **读入**：`scanf("%lf", &v_kmh)`，注意 `&`；
4. **换算**：`v = v_kmh * KMH_TO_MS`；
5. **算风压**：`w = 0.5 * RHO * v * v`；
6. **输出**：两行，各自 `%.4f` 控制 4 位小数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 常量：空气密度与 km/h→m/s 的换算系数 */
    const double RHO = 1.25;            /* 空气密度，kg/m^3 */
    const double KMH_TO_MS = 1.0 / 3.6; /* 1 km/h = 1/3.6 m/s，注意用 1.0 保证浮点除法 */

    double v_kmh;   /* 输入：风速，km/h */
    double v;       /* 中间：风速，m/s */
    double w;       /* 输出：风压，Pa */

    /* 读入风速（km/h） */
    scanf("%lf", &v_kmh);

    /* 第一步：单位换算 km/h -> m/s */
    v = v_kmh * KMH_TO_MS;

    /* 第二步：代入风压公式 w = 0.5 * rho * v^2 */
    w = 0.5 * RHO * v * v;

    /* 输出，均保留 4 位小数 */
    printf("v = %.4f m/s\n", v);
    printf("w = %.4f Pa\n", w);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 36 | $v=36/3.6=10$；$w=0.5\times1.25\times100=62.5$ | `v = 10.0000 m/s` / `w = 62.5000 Pa` ✓ |
| 54 | $v=54/3.6=15$；$w=0.5\times1.25\times225=140.625$ | `v = 15.0000 m/s` / `w = 140.6250 Pa` ✓ |
| 72 | $v=72/3.6=20$；$w=0.5\times1.25\times400=250$ | `v = 20.0000 m/s` / `w = 250.0000 Pa` ✓ |

风速翻倍时风压变成 4 倍（$20^2/10^2=4$），符合"风压与风速平方成正比"的物理规律，说明公式实现正确。

## 六、常见错误与讲解

**错误 1：整数除法——把 3.6 写成 3，或用整数常量**

```c
const double KMH_TO_MS = 1 / 3;     /* 错：1/3 是整数除法，结果为 0 */
const double KMH_TO_MS = 1 / 3.6;   /* 错：1 是整数，1/3.6 会先把 1 当整数参与，新手常在这里翻车 */
const double KMH_TO_MS = 1.0 / 3.6; /* 对：1.0 是浮点，除法按实数进行 */
```

只要除号两边有一个是浮点数，整个除法就按浮点进行。**保险写法：把参与除法的常量至少一个写成小数。**

**错误 2：scanf 漏写取地址符**

```c
scanf("%lf", v_kmh);    /* 错：没有 &，程序崩溃或读不进数据 */
scanf("%lf", &v_kmh);   /* 对 */
```

**错误 3：用 `^` 表示平方**

```c
w = 0.5 * RHO * v ^ 2;  /* 错：^ 是位异或运算符，不是乘方 */
w = 0.5 * RHO * v * v;  /* 对：平方写成自乘 */
```

**错误 4：格式符与类型不匹配**

```c
scanf("%f", &v_kmh);     /* 错：double 读入应用 %lf，用 %f 会读到错误值 */
printf("w = %d\n", w);   /* 错：double 用 %d 输出是乱码 */
printf("w = %.4f\n", w); /* 对 */
```
