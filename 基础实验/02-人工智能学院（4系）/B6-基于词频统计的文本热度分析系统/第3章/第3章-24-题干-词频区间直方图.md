# 第 3 章 练习 24　词频区间直方图

**所属综合实验**：B6（B6-基于词频统计的文本热度分析系统）

**对应章节**：3 程序流程控制（3.1 关系与逻辑运算、3.2 选择结构、3.3 循环结构、3.4 标准输入输出）

**场景来源**：综合实验 B6《基于词频统计的文本热度分析系统》（人工智能学院）——本练习是该实验中"热度分布分析"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

文本热度分析系统统计每个词出现的次数后，还要看"热度是怎么分布的"：有多少词是高频词（出现很多次）、多少是低频词（偶尔出现）、多少只出现一两次。这种分布能反映文本的特点——比如新闻稿里可能高频词很少，而技术文档里高频词较多。

做法是把词频分成几档，统计每档有多少个词，这就得到一张**词频区间直方图**。B6 系统在输出热度排行之外，都会附上这样一张分布图。

## 二、任务要求

编写一个完整程序 `word_hist.c`：

1. 从键盘读入词汇个数 `n`（整数，$1 \le n \le 20$）；
2. 依次读入 $n$ 个整数，表示每个词的词频（$0 \le 词频 \le 100$）；
3. 把词频分成三档并统计每档词数：
   - 低频：词频 $\le 2$；
   - 中频：$3 \le$ 词频 $\le 9$；
   - 高频：词频 $\ge 10$；
4. 输出三档的计数。

## 三、输入输出格式

**输入**：
第一行，一个整数 n；
第二行，n 个整数，为各词词频。

**输出**：三行，按格式输出：
```
low = 结果
mid = 结果
high = 结果
```

## 四、样例

**样例 1**

输入：
```
5
1 2 5 8 12
```
输出：
```
low = 2
mid = 2
high = 1
```

**样例 2**

输入：
```
6
3 10 10 1 7 20
```
输出：
```
low = 1
mid = 2
high = 3
```

## 五、提示

判定规则与分档边界：

$$
\text{词频} \le 2 \to low;\quad 3 \le \text{词频} \le 9 \to mid;\quad \text{词频} \ge 10 \to high
$$

流程是"边读边判"，每读到一个词频就立刻归类：

```
for 每个词:
    读入 f
    if (f <= 2)       low++;
    else if (f <= 9)  mid++;
    else              high++;
```

和上一题一样，用 `else if` 做"筛选式"判断，第二个条件只需写上限 9。三个计数器初值都必须是 0。

**完成本练习后你将具备的能力**：用循环读入一列数据、在循环中用多分支判断归类、维护多个计数器——这些是实验 B6 中"热度分布模块"的地基。
