# 第 6 章 练习 02　指针作参数交换数据

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用）

**场景来源**：综合实验 C6《冰区船舶与冰块碰撞模拟系统》（水声学院）——本练习是该实验中"冰块数据交换与录入纠错"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区碰撞模拟系统 C6 中，每块冰用一组数据（坐标、质量、速度）描述。碰撞发生后，程序要**交换两块冰的数据**；数据录入时也可能出现"两行数据顺序录反"的情况，需要**交换数组中的两个元素**来纠正。这些交换若写成一个函数，就必须把变量的**地址**传进去——只传值的话，函数内部换得再热闹，外面的数据纹丝不动。本练习要求你亲手写出这个"传地址"的交换函数，并把它用于两个真实场景。

## 二、任务要求

编写一个完整程序 `ice_swap.c`：

1. 编写函数 `void swap(double *a, double *b)`：通过指针交换两个 `double` 变量的值；
2. 从键盘读入两块冰的 $x$ 坐标（碰撞后需交换记录），调用 `swap` 交换后按格式输出两个坐标；
3. 从键盘读入 5 块冰的质量存入数组，调用 `swap` 交换数组中下标 1 与下标 3 的两个元素（第 2 块与第 4 块）；
4. 输出交换后的质量序列。

## 三、输入输出格式

**输入**：三行。
第 1 行：两个实数，冰块 A、B 的 $x$ 坐标（米）；
第 2 行：5 个实数，5 块冰的质量（kg），以空格分隔。

**输出**：两行。
第 1 行：`x1 = 交换后坐标 x2 = 交换后坐标`（各保留 1 位小数）；
第 2 行：交换后的 5 个质量，以空格分隔，各保留 1 位小数。

## 四、样例

**样例 1**

输入：
```
12.5 30.2
105.0 88.5 120.3 76.8 95.4
```
输出：
```
x1 = 30.2 x2 = 12.5
105.0 76.8 120.3 88.5 95.4
```

**样例 2**

输入：
```
-8.4 4.6
50.0 62.5 48.2 71.0 66.3
```
输出：
```
x1 = 4.6 x2 = -8.4
50.0 71.0 48.2 62.5 66.3
```

## 五、提示

1. 交换三步曲借助临时变量完成：`t = *a; *a = *b; *b = t;`——注意是 `*a`、`*b`（按地址取东西），而不是 `a`、`b`（柜号本身）；
2. 调用时传**地址**：`swap(&x1, &x2)` 交换两个变量；`swap(&m[1], &m[3])` 交换数组两个元素；
3. 对照实验：如果函数写成 `void swap(double a, double b)`（传值），调用后主函数里的数据不会交换——原因见讲解；
4. 传数组元素地址时，`&m[1]` 与 `m + 1` 等价（练习 03、04 将讲透这一点）。

**完成本练习后你将具备的能力**：编写指针形参函数、理解"传值"与"传地址"的本质区别、用同一个交换函数同时服务于普通变量与数组元素——这是实验 C6 中冰块数据管理模块的核心手法。
