# 第 7 章 练习 38　测点结构体定义与输出

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：7 结构体类型及变量（7.1 结构体类型的定义、7.2 结构体变量的引用与初始化）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"测点记录定义与录入输出"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

管理水声实验数据，一条测点记录包含多个"不同类型"的信息：测点编号是**字符串**，水深是**实数**，观测时刻是**字符串**。用几个零散变量存一条记录太乱——记录一多，变量名满天飞。

**结构体**就是为此而生：把"一个测点的全部字段"打包成一种新类型，一次定义、处处使用。综合实验 C10 的第一步就是定义测点记录结构体并完成录入输出。本题实现这一步。

## 二、任务要求

编写一个完整程序 `rec_out.c`：

1. 定义结构体类型：
   ```c
   struct Rec {
       char id[16];     /* 测点编号 */
       double depth;    /* 水深 m */
       char tm[8];      /* 观测时刻 HH:MM */
   };
   ```
2. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 50**）；
3. 依次读入 `n` 条记录（每条一行三个字段），存入结构体数组；
4. 按下表格式输出全部记录，并统计平均水深（保留 2 位小数）。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后 `n` 行，每行 `编号 水深 时刻`（空格分隔）。

**输出**：先输出表头与分隔线，再逐行输出记录，最后输出平均水深：

```
编号      水深(m)   时刻
------------------------
S01       15.50     08:30
S02       18.20     09:00
------------------------
平均水深：16.85 m
```

编号左对齐占 9 列，水深右对齐占 9 列保留 2 位小数，时刻右对齐占 6 列。

## 四、样例

**样例 1**

输入：
```
3
S01 15.5 08:30
S02 18.2 09:00
S03 22.0 09:30
```
输出：
```
编号      水深(m)   时刻
------------------------
S01          15.50   08:30
S02          18.20   09:00
S03          22.00   09:30
------------------------
平均水深：18.57 m
```

**样例 2**

输入：
```
1
A7 3.0 12:00
```
输出：
```
编号      水深(m)   时刻
------------------------
A7            3.00   12:00
------------------------
平均水深：3.00 m
```

## 五、提示

- 定义结构体类型只是"画图纸"，不占内存；声明变量 `struct Rec r[50];` 才真正分配空间；
- 访问成员用点运算符：`r[i].depth`、`r[i].id`；`r[i].id` 本身是数组首地址，读字符串直接 `scanf("%s", r[i].id)`，**不要加 `&`**；
- 读水深才要取地址：`scanf("%lf", &r[i].depth);`——这是初学者最常混的一处；
- 平均水深 = 所有 `r[i].depth` 之和 / n；
- 想一想：`struct Rec` 与 `int` 的相似之处——都是**类型**，都可以声明变量、数组；区别只是 `struct Rec` 是你自己发明的。

**完成本练习后你将具备的能力**：定义结构体类型、声明结构体数组、点运算符访问成员——这是实验 C10 一切后续操作（排序、链表、文件）的类型地基。
