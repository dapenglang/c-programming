## 二、预备知识：结构体数组统计的基本原理（零基础阅读）

### 1. 报表的本质：对"记录集合"做多种聚合

报表的四行输出对应四种聚合：计数（条数）、均值、最值（连同出处）、条件计数。被聚合的对象是结构体数组——每个元素是一条完整记录：

```
r[0]            r[1]            r[2]
+------+------+ +------+------+ +------+------+ ...
|  no  |force | |  no  |force | |  no  |force |
+------+------+ +------+------+ +------+------+
```

聚合运算只关心 `force` 成员，但输出"最大阻力"时必须**带上出处编号**——光有 15.20 kN 不知道是谁贡献的，报表就没有意义。于是统计时"值与号一起记"，和练习 09 的打擂台完全一致。

### 2. 一遍遍历能同时做几件事

计数、最值、条件计数都只需访问每个元素一次，因此可以放进**同一个循环**：

```
maxF = r[0].force;  maxNo = r[0].no;  count = 0;
for i = 0 .. n-1:
    if r[i].force > maxF: maxF = r[i].force; maxNo = r[i].no;
    if r[i].force > T:    count++;
```

均值涉及"先求和再相除"，也可并入同一循环（循环内累加，循环外除以 n）。对比第 5 章初学时"一个统计量一个循环"的写法，一遍遍历多统计量是效率与条理性的双重进步——但初学时若不放心，拆成多个循环同样正确，先对再优。

### 3. 均值单独成函数：模块化的最后一课

题干要求把平均值交给 `double average(struct Record r[], int n);`。结构体数组作参数与第 5 章的普通数组作参数规则相同：**传的是首地址，函数内读写的就是原数组**；形参写法 `struct Record r[]` 本质上就是 `struct Record *r`（练习 08 已揭示这层关系）。均值函数不需要修改数据，但传参方式决定了它"能改"——本阶段先接受这一点，配套 `const` 保护的进阶写法（`const struct Record r[]`）可作为选做尝试。

### 4. 报表输出：格式即规格

四行报表的每一处空格、括号、小数位数都是"规格"。混合格式行如 `最大阻力 = 15.20 kN（3 号）` 由 `printf("最大阻力 = %.2f kN（%d 号）\n", maxF, maxNo)` 生成。写这类输出前先数清占位符个数与顺序，再用样例逐字比对——工程报表的验收标准就是"逐字符一致"。

## 三、解题思路

1. **定类型定数组**：`struct Record r[20];`，读 n 与阈值 T；
2. **读入**：循环读 n 条记录存入数组（编号、阻力）；
3. **均值函数**：`average` 内累加 force、除以 n 返回；
4. **主统计循环**：一遍遍历同时维护 `maxF、maxNo、count`（超阈值计数）；
5. **输出报表**：按四行格式输出，注意阈值保留 1 位小数（`%.1f`）。

## 四、参考代码

```c
#include <stdio.h>

struct Record {                /* 一条撞击样本记录 */
    int    no;                 /* 样本编号 */
    double force;              /* 撞击阻力 kN */
};

double average(struct Record r[], int n)   /* 均值：数组作参数 */
{
    double sum = 0.0;
    int i;
    for (i = 0; i < n; i++)
        sum += r[i].force;
    return sum / n;
}

int main(void)
{
    struct Record r[20];
    double T;                  /* 警戒阈值 kN */
    double maxF;               /* 最大阻力 */
    int maxNo;                 /* 最大阻力样本编号 */
    int count = 0;             /* 超阈值样本数 */
    int n, i;

    scanf("%d%lf", &n, &T);
    for (i = 0; i < n; i++)
        scanf("%d%lf", &r[i].no, &r[i].force);

    /* 一遍遍历：最大值（连编号）+ 超阈值计数 */
    maxF  = r[0].force;
    maxNo = r[0].no;
    for (i = 0; i < n; i++) {
        if (r[i].force > maxF) {
            maxF  = r[i].force;
            maxNo = r[i].no;
        }
        if (r[i].force > T)
            count++;
    }

    /* 四行报表 */
    printf("样本总数 = %d\n", n);
    printf("平均阻力 = %.2f kN\n", average(r, n));
    printf("最大阻力 = %.2f kN（%d 号）\n", maxF, maxNo);
    printf("超阈值样本数 = %d（阈值 %.1f kN）\n", count, T);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：计数器忘记清零或清零位置错误**

```c
int count;              /* 错：未初始化，初值不确定 */
int count = 0;          /* 对：定义时清零，且必须写在 main 里、循环外 */
```

若把 `count = 0;` 写进循环体，每圈清零，结果恒为 0 或 1。

**错误 2：均值函数的形参把数组写成单个结构体**

```c
double average(struct Record r, int n)   /* 错：只收到第 0 条记录的副本 */
double average(struct Record r[], int n) /* 对：收到整个数组的首地址 */
```

前者连编译都过不了（`r[i]` 不能用在结构体变量上），后者才是"对集合做统计"的正确签名。

**错误 3：最值擂台与编号脱节**

```c
if (r[i].force > maxF)
    maxF = r[i].force;      /* 错：换了擂主却没记编号 */
    maxNo = r[i].no;        /* 必须同分支内一起更新 */
```

输出变成"15.20 kN（1 号）"，值对号错，比直接算错更难被发现。

**错误 4：阈值输出格式没对题**

```c
printf("...（阈值 %.2f kN）\n", T);   /* 错：题目要求阈值保留 1 位小数 */
printf("...（阈值 %.1f kN）\n", T);   /* 对：%.1f */
```

同一行里两个实数位数要求不同时，分别指定格式符，逐字核对样例。
