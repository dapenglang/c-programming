## 二、预备知识：二分法的基本原理（零基础阅读）

### 1. 问题是怎么来的

要求 $x$ 使 $x^2 = a$。对 $a = 2$ 来说，答案是 $1.41421356\dots$，一个无限不循环小数，写不完。计算机没法"直接"给出它，但可以一步一步逼近：先确定答案比 1 大、比 2 小，然后在 $[1, 2]$ 里不断缩小包围圈。**二分法**就是最朴素也最稳健的逼近办法。

### 2. 方法是怎么想出来的

关键前提：函数 $f(x) = x^2 - a$ 在正数范围内是**单调递增**的（$x$ 越大，$x^2$ 越大）。因此只要 $f(lo) < 0$ 且 $f(hi) > 0$，真根就必定夹在 $lo$ 与 $hi$ 之间。取中点

$$
mid = \frac{lo + hi}{2}
$$

有三种可能：若 $f(mid) = 0$ 恰好命中；若 $f(mid) > 0$（说明 mid 偏大），真根在左边，把右端点搬到 mid；若 $f(mid) < 0$（mid 偏小），真根在右边，把左端点搬到 mid。写成一句话：

$$
mid^2 > a \Rightarrow hi \leftarrow mid,\qquad mid^2 < a \Rightarrow lo \leftarrow mid
$$

每做一次，区间长度从 $L$ 变成 $L/2$。做 $n$ 次后长度是 $L/2^{n}$。所以精度几乎以指数速度提升——这叫"**线性收敛但每步减半**"，实际只要几十次就够精确了。

### 3. 用本例走一遍

求 $\sqrt{2}$，初始 $lo = 0,\ hi = 2$（因为 $0^2 < 2 < 2^2$）。

- 第 1 次：$mid = 1.0$，$mid^2 = 1 < 2$，答案在右半边 → $lo = 1.0$，区间 $[1, 2]$；
- 第 2 次：$mid = 1.5$，$mid^2 = 2.25 > 2$，答案在左半边 → $hi = 1.5$，区间 $[1, 1.5]$；
- 第 3 次：$mid = 1.25$，$mid^2 = 1.5625 < 2$ → $lo = 1.25$，区间 $[1.25, 1.5]$。

可以看到真值 $1.4142\dots$ 一直被夹在区间里，区间每次缩短一半。继续做下去，很快就能精确到小数点后 6 位，最终输出 $1.414214$。

### 4. 编程时怎么用它

三个要点：**① 初始区间**要保证"夹住"答案——对平方根，$lo=0$ 一定满足 $0^2 \le a$，右端取 $\max(a,1)$ 保证 $hi^2 \ge a$（因为 $a<1$ 时 $a^2 < a$，若取 $hi=a$ 就夹不住）；**② 循环条件**是 `hi - lo >= 1e-6`（区间还够大就继续对折），循环体内用 `if (mid*mid > a) hi = mid; else lo = mid;` 更新区间；**③ 终止判据**用区间长度而不是迭代次数，这样不管 a 多大，精度都稳定在 $10^{-6}$。循环结束时 `lo` 与 `hi` 已靠得极近，取 `(lo+hi)/2` 输出即可。

## 三、解题思路

1. **读入并设区间**：读 `a`，令 `lo = 0.0`；`hi` 先设为 `a`，若 `a < 1.0` 则改为 `1.0`；
2. **写 while 循环**：条件 `hi - lo >= 1e-6`，循环体内算 `mid`，比较 `mid*mid` 与 `a`，决定搬动 `lo` 还是 `hi`；
3. **循环结束后**输出 `(lo + hi) / 2.0`；
4. **格式**：`printf("sqrt = %.6f\n", ans);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double a;               /* 待求平方根的正实数 */
    double lo, hi;          /* 当前搜索区间 [lo, hi] */
    double mid;             /* 区间中点 */

    scanf("%lf", &a);

    /* 设定初始区间：保证 lo^2 <= a <= hi^2 */
    lo = 0.0;
    hi = a;
    if (a < 1.0) {
        hi = 1.0;           /* a<1 时 a^2<a，必须把右端扩到 1 */
    }

    /* 二分逼近：区间每循环一次缩短一半 */
    while (hi - lo >= 1e-6) {
        mid = (lo + hi) / 2.0;
        if (mid * mid > a) {
            hi = mid;       /* 中点偏大，答案在左半边 */
        } else {
            lo = mid;       /* 中点偏小或命中，答案在右半边 */
        }
    }

    /* 区间已足够小，取中点作为结果 */
    printf("sqrt = %.6f\n", (lo + hi) / 2.0);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：初值区间夹不住答案**

```c
lo = 0.0; hi = a;                 /* 错：a=0.25 时区间 [0,0.25]，根 0.5 落在区间外 */
lo = 0.0; hi = a < 1.0 ? a : a;   /* 同样错，没处理 a<1 */
```

必须先判断：`if (a < 1.0) hi = 1.0;`。区间夹不住根，二分法会收敛到一个错误的值。

**错误 2：循环条件写成"相等判断"**

```c
while (hi - lo == 0)   /* 错：浮点数几乎不可能恰好相等，循环可能永不执行或死循环 */
while (hi - lo >= 1e-6) /* 对：用"是否大于精度"作为条件 */
```

浮点数比较忌用 `==`，应该用"差值与精度比较"。

**错误 3：更新方向搞反**

```c
if (mid * mid > a) lo = mid;   /* 错：中点偏大却把左端右移，区间越走越偏 */
if (mid * mid > a) hi = mid;   /* 对：中点偏大，缩小右端 */
```

记住：$mid$ 平方太大说明 $mid$ 本身太大，要把**右端点**拉回来。

**错误 4：循环里忘了更新 mid 之外的量**

二分法的循环体只需要更新 `lo` 或 `hi` 之一，`mid` 每轮在循环开头重新计算。若把 `mid` 写在循环外，区间更新后中点不再更新，结果会明显偏错。
