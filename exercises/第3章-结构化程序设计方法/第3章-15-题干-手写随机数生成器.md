# 第 3 章 练习 15　手写随机数生成器

**对应章节**：3 结构化程序设计方法（3.3 循环结构、3.4 关系与逻辑运算、3.5 数值求解方法——伪随机序列）

**场景来源**：综合实验 C10《碎冰场分布统计分析系统》、C5《冰区蒙特卡洛模拟》（水声学院）——本练习是该实验中"伪随机数发生器"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

蒙特卡洛方法要用大量随机数来模拟碎冰的随机分布，可计算机本身不会产生"真正的随机数"。工程上常用**线性同余法**：从一个种子出发，用一条固定的递推公式不断算出看似杂乱、实则完全确定的整数序列。只要种子相同，序列就完全可复现——这一点对科学计算非常重要，因为它让实验可以重复验证。本练习亲手实现这个发生器，为下一题的投点估算 $\pi$ 做好准备。

## 二、任务要求

编写一个完整程序 `lcg.c`：

1. 从键盘读入两个整数，用空格分隔：种子 `r0` 和要生成的个数 `n`（题目保证 `r0 > 0`，`1 ≤ n ≤ 100`）；
2. 用常量固定递推参数：乘子 `A = 1103515245`、增量 `C = 12345`、模数 `M = 2147483648`（即 $2^{31}$）；
3. 用 **for 循环**执行 n 次递推 $r = (A \times r + C) \bmod M$，每得到一个新随机数，就输出它的序号、整数值和归一化值；
4. **严禁使用 `rand()` 等现成随机函数**，必须自己用递推式算出序列。为防止 $A \times r + C$ 溢出，请把 `r` 及运算结果声明为 `unsigned long long`。

## 三、输入输出格式

**输入**：一行，两个整数 `r0 n`，中间用空格分隔。

**输出**：共 n 行，第 i 行格式为 `r%d = %llu  u = %.6f`（注意 `r` 与 `u` 之间是两个空格），其中：
- `r%i` 中的数字是序号（从 1 开始）；
- 第一个数值是本次生成的伪随机整数 $r_i$；
- `u` 是归一化值 $u_i = r_i / M$，保留 6 位小数，取值范围 $[0,1)$。

## 四、样例

**样例 1**

输入：
```
1 5
```
输出：
```
r1 = 1103527590  u = 0.513870
r2 = 377401575  u = 0.175741
r3 = 662824084  u = 0.308652
r4 = 1147902781  u = 0.534534
r5 = 2035015474  u = 0.947628
```

**样例 2**

输入：
```
12345 3
```
输出：
```
r1 = 1406932606  u = 0.655154
r2 = 654583775  u = 0.304814
r3 = 1449466924  u = 0.674961
```

## 五、提示

线性同余发生器（LCG）的递推式为

$$
r_{n+1} = (a\,r_n + c) \bmod m
$$

其中 $a$ 是乘子、$c$ 是增量、$m$ 是模数，$r_0$ 是种子。递推得到的 $r_i$ 都是 $0$ 到 $m-1$ 之间的整数；把它除以 $m$ 就得到 $[0,1)$ 区间上的"小数随机数"：

$$
u_i = \frac{r_i}{m}\in[0,\,1)
$$

以种子 $r_0 = 1$ 为例：$r_1 = (1103515245 \times 1 + 12345) \bmod 2^{31} = 1103527590$（比 $2^{31}$ 小，模运算不改变它）。后续每个 $r_i$ 都由上一行同样的公式算出。

**完成本练习后你将具备的能力**：用循环实现递推式、理解"取模 + 除法归一化"产生 $[0,1)$ 随机数的原理、掌握大整数运算的溢出防范——这是实验 C5/C10 中一切蒙特卡洛模拟的起点。
