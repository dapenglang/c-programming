## 二、预备知识：半衰期、幂函数与系统数学函数（零基础阅读）

### 1. 问题是怎么来的

放射性核素衰变有个干净的规律：**每过一个固定的时间，活度就减半**，这个固定时间叫半衰期 $T$。既然每过一个 $T$ 减半一次，那么经过 $t$ 天，就减半了 $k = t/T$ 次，剩余活度就是原来的"二分之一自乘 $k$ 次"。

### 2. 公式是怎么推出来的

"减半 $k$ 次"用数学语言就是**以 2 为底、指数为 $-k$** 的幂：

$$
A/A_0 = \left(\frac{1}{2}\right)^{k} = 2^{-k} = 2^{-t/T}
$$

验证两个特殊值：$t=0$ 时 $k=0$，$2^0=1$，活度没变，正确；$t=T$ 时 $k=1$，$2^{-1}=0.5$，正好减半，符合半衰期的定义。所以这个公式是对的。它其实是更常见的指数衰减式 $A=A_0 e^{-\lambda t}$（其中 $\lambda=\ln 2/T$）的等价写法，两者数值完全相同。

### 3. 用本例走一遍

Co-60，$T=5.27$ 天，$t=10.54$ 天：

- 半衰期个数：$k = 10.54 / 5.27 = 2$；
- 剩余比：$2^{-2} = \dfrac{1}{2^2} = 0.25$；
- 百分数：$0.25\times100 = 25\%$。

正是"两个半衰期后活度剩四分之一"，与常识吻合。

### 4. 编程时怎么用它

C 语言**没有** `^` 这样的乘方运算符（`^` 是按位异或），求幂要调用标准数学库里的 `pow` 函数：

```c
#include <math.h>
...
double k = t / T;                 /* 半衰期个数 */
double ratio = pow(2.0, -k);      /* 2 的 -k 次方 */
```

`pow(a, b)` 返回 $a^b$。这里调用的是**系统已经写好的数学函数**（和 `printf` 一样是库函数），不是我们自己定义函数；本章不允许的是**自定义函数**，调用现成库函数没有问题。注意底数写 `2.0`（小数）而不是 `2`。

## 三、解题思路

1. **确定变量**：读入的 `T`、`t`，中间量 `k = t / T`，结果 `ratio`、`percent`，都用 `double`；
2. **读入**：`scanf("%lf %lf", &T, &t)`；
3. **求半衰期个数**：`k = t / T`；
4. **求活度比**：`ratio = pow(2.0, -k)`；
5. **换算百分数**：`percent = ratio * 100.0`；
6. **输出**：两行，保留 4 位小数；输出百分号本身要写 `%%`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>   /* 使用 pow 函数需要包含数学库头文件 */

int main(void)
{
    double T;         /* 输入：半衰期，天 */
    double t;         /* 输入：经过的天数，天 */
    double k;         /* 中间：经历过的半衰期个数 t/T */
    double ratio;     /* 输出：剩余活度比 A/A0 */
    double percent;   /* 输出：剩余活度百分数 */

    /* 读入半衰期与经过天数 */
    scanf("%lf %lf", &T, &t);

    /* 经历过的半衰期个数 */
    k = t / T;

    /* 幂运算：A/A0 = 2^(-k) */
    ratio = pow(2.0, -k);

    /* 换算成百分数 */
    percent = ratio * 100.0;

    /* 输出，均保留 4 位小数；%% 用于输出一个百分号 */
    printf("ratio = %.4f\n", ratio);
    printf("percent = %.4f %%\n", percent);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 8 24 | $k=24/8=3$；$2^{-3}=0.125$；$0.125\times100=12.5$ | `ratio = 0.1250` / `percent = 12.5000 %` ✓ |
| 5.27 10.54 | $k=10.54/5.27=2$；$2^{-2}=0.25$；$0.25\times100=25$ | `ratio = 0.2500` / `percent = 25.0000 %` ✓ |
| 8 8 | $k=1$；$2^{-1}=0.5$；$0.5\times100=50$ | `ratio = 0.5000` / `percent = 50.0000 %` ✓ |
| 8 0 | $k=0$；$2^{0}=1$；$1\times100=100$ | `ratio = 1.0000` / `percent = 100.0000 %` ✓ |

"经过一个半衰期活度减半、两个半衰期剩四分之一"，与半衰期的定义完全一致，说明公式实现正确。

## 六、常见错误与讲解

**错误 1：用 `^` 求幂**

```c
ratio = 2 ^ (-k);            /* 错：^ 是按位异或，不是乘方 */
ratio = pow(2.0, -k);        /* 对 */
```

**错误 2：忘记包含 math.h，或底数写成整数**

```c
#include <stdio.h>           /* 缺 #include <math.h>，pow 未声明 */
ratio = pow(2, -k);          /* 危险：底数 2 是整数，建议写 2.0 */
```

**错误 3：指数符号漏写负号**

```c
ratio = pow(2.0, k);         /* 错：这会随半衰期个数指数增长，与"衰减"相反 */
ratio = pow(2.0, -k);        /* 对：衰减必须带负号 */
```

**错误 4：整数除法导致 k 被截断**

```c
int k = t / T;                       /* 错：若写成整数，10.54/5.27 会被截成 2 正好，*/
                                     /* 但 24/8=3 尚可，10/8 就会截成 1，结果错 */
double k = t / T;                    /* 对：全程浮点 */
```

另外，输出百分号 `%` 时必须写 `%%`，否则 `printf` 会把它当成格式符的开头。

## 七、与综合实验的衔接

- 在实验 **D1（放射性核素活度计算系统）**中，本练习对应"活度计算函数模块"：正式程序会读入核素参数表（核素名、半衰期、初始活度），对整条时间序列批量算活度，再用二分法反解"衰变到某阈值所需时间"——批量算需要循环（第 3 章），参数表需要数组（第 5 章），反解需要函数与二分法（第 4、7 章）；
- 本练习的 $2^{-t/T}$ 是核工程里最常见的指数模型，后续 D5（γ 射线剂量率）中的衰减因子、核热工中的放射性衰变热都会用到同一套幂运算，本章先把这行公式写对。
