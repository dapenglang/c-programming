## 二、预备知识：型线插值与"为积分做准备"（零基础阅读）

### 1. 问题是怎么来的

冰块的水线宽度随高度变化，测量只能给出离散点：0 m 处 0.90 m，0.20 m 处 1.20 m。**要算入水部分的体积，必须知道每一高度处的宽度**，而表中只有两点。工程上默认这段区间内宽度随高度**均匀变化**（图象为直线），在两点间按比例取值，这就是线性插值。

### 2. 公式是怎么推出来的

设已知点为 $(z_0, B_0)$、$(z_1, B_1)$，要求 $z$ 处（$z_0 \le z \le z_1$）的值。"均匀变化"意味着**宽度增量与高度增量成正比**：

$$
\frac{B - B_0}{B_1 - B_0} = \frac{z - z_0}{z_1 - z_0}
$$

解得

$$
B = B_0 + \dfrac{(B_1 - B_0)(z - z_0)}{z_1 - z_0}
$$

读作"起点宽度 + 全程宽度增量 × 已走高度比例"。

### 3. 用本例走一遍

取 $z = 0.08$，代入 $(z_0, B_0) = (0,\ 0.90)$，$(z_1, B_1) = (0.20,\ 1.20)$：

- 已走比例：$(0.08 - 0)/(0.20 - 0) = 0.08/0.20 = 0.4$；
- 全程增量：$1.20 - 0.90 = 0.30$ m；
- 已增：$0.30 \times 0.4 = 0.12$ m；
- 结果：$B = 0.90 + 0.12 = 1.02$ m。

再取 $z = 0.15$：比例 $= 0.15/0.20 = 0.75$，增量 $0.30 \times 0.75 = 0.225$，得 $B = 1.125$ m。端点 $z=0$ 得 0.90、$z=0.20$ 得 1.20，与测量值一致。

### 4. 编程时怎么用它

四个表格常量 + 一个输入，把公式翻译成一行赋值语句即可。**为什么说这是"为积分做准备"**：第 3 章的数值积分（梯形法）会取很多高度 $z_i$，每次都调用这个插值得到宽度 $B(z_i)$，再把相邻宽度的平均乘高度间隔累加，就得到水线面积/体积。本练习是这一整条计算链条的第一环。

> **这个思想在综合实验中反复出现**：C8 型线插值、C1 声速剖面、D4 温度场，都是"离散表格 + 线性插值"，插值结果常作为下一步积分或求解的输入。

## 三、解题思路

1. **确定常量**：`Z0=0.0, Z1=0.20, B0=0.90, B1=1.20`，用 `const double`；
2. **确定变量**：高度 `z` 与宽度 `B`，用 `double`；
3. **套公式**：`B = B0 + (B1 - B0) * (z - Z0) / (Z1 - Z0);`；
4. **输出**：`printf("B = %.3f m\n", B);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 冰块型线相邻两档：高度(m) 与 水线宽度(m) */
    const double Z0 = 0.0;    /* 下档高度 */
    const double Z1 = 0.20;   /* 上档高度 */
    const double B0 = 0.90;   /* 下档宽度 */
    const double B1 = 1.20;   /* 上档宽度（冰块下部窄、上部宽） */

    double z;    /* 待查高度，m */
    double B;    /* 插值得到的水线宽度，m */

    /* 读入高度（题目保证 0 <= z <= 0.20） */
    scanf("%lf", &z);

    /* 线性插值：B = B0 + (B1 - B0) * (z - Z0) / (Z1 - Z0) */
    B = B0 + (B1 - B0) * (z - Z0) / (Z1 - Z0);

    /* 输出，保留 3 位小数 */
    printf("B = %.3f m\n", B);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 0.08 | 0.90 + 0.30 × 0.08/0.20 = 0.90 + 0.12 = 1.02 | `B = 1.020 m` ✓ |
| 0.15 | 0.90 + 0.30 × 0.15/0.20 = 0.90 + 0.225 = 1.125 | `B = 1.125 m` ✓ |
| 0 | 0.90 + 0.30 × 0/0.20 = 0.90（下端点） | `B = 0.900 m` ✓ |
| 0.20 | 0.90 + 0.30 × 0.20/0.20 = 1.20（上端点） | `B = 1.200 m` ✓ |

端点值与型线测量数据完全一致，中间值线性增大，插值正确。

## 六、常见错误与讲解

**错误 1：常量写成整数**

```c
const double B0 = 0, B1 = 1;      /* 错：宽度 0.90、1.20 被写成整数，精度尽失 */
const double B0 = 0.90, B1 = 1.20;  /* 对：一律带小数点 */
```

**错误 2：忘记取地址符**

```c
scanf("%lf", z);      /* 错：程序崩溃或读不进数据 */
scanf("%lf", &z);     /* 对：scanf 需要变量地址 */
```

**错误 3：输出格式与精度不符**

```c
printf("B = %.3d m\n", B);    /* 错：%d 是整数格式，double 会乱码 */
printf("B = %.3f m\n", B);    /* 对：保留 3 位小数 */
```

**错误 4：公式括号写错**

```c
B = B0 + (B1 - B0) * z - Z0 / (Z1 - Z0);       /* 错：括号缺失，结果全乱 */
B = B0 + (B1 - B0) * (z - Z0) / (Z1 - Z0);     /* 对：先减、再乘、再除 */
```

本题为正斜率，结果应落在 0.90～1.20 之间；若结果超出这一范围，说明公式或括号有误。

## 七、与综合实验的衔接

- 实验 **C8（碎冰冰块浮力吃水）**中，本练习是"型线查宽度"模块的最小实现。第 3 章学到数值积分（梯形法）后，程序会在多个高度上反复调用这一插值，累加各层水线面积，得到排水体积；再由浮力与重力平衡，用二分法求平衡吃水。**插值是积分与求解的输入**，先把它写对，后面才站得稳；
- 同一套"表格 + 线性插值"的做法，也用于 C1 声速剖面、D4 温度场、A1 风荷载。本练习是它在"为积分做准备"这一场景下的又一次巩固。
