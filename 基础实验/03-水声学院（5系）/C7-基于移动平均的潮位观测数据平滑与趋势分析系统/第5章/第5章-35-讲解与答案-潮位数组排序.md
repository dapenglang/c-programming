## 二、预备知识：冒泡排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

拿到 10 个潮位数：

```
3.42  1.85  4.10  2.36  3.75  1.20  4.48  2.05  3.10  0.95
```

要找最高、最低潮位。用练习 34 的"打擂台"扫一遍当然可以，但工程上经常还要"前 3 高的潮位""中间水平"等更多要求——这时**先把整个序列排好序**，所有"第 k 大"的问题都变成"取第 k 个元素"，一劳永逸。综合实验 C7 统计潮差、实验 C8 给多条声线路径"按时间排序找最短"，用的都是排序。

### 2. 公式推导：冒泡排序为什么能排好

冒泡排序（降序）的思想：**每一趟从头到尾依次比较相邻两个数，把小的换到后面**——这样一趟下来，整个序列里最小的数一定被"推"到了最末尾，像水底的气泡升到水面（反过来说：大数在往"前"冒）。

形式化地，设第 $k$ 趟结束后数组为 $d^{(k)}$，则第 $k$ 趟保证：

$$d^{(k)}_{n-k} = \min\{d^{(k-1)}_0, d^{(k-1)}_1, \ldots, d^{(k-1)}_{n-k}\}$$

即"倒数第 $k$ 个位置已放好第 $k$ 小的数，且以后不再动它"。所以：

- 总趟数：$n-1$ 趟就够（剩最后 1 个数时自动就位）；
- 第 $i$ 趟的比较范围：下标 $0$ 到 $n-1-i$（后面 $i$ 个已排好，不用再比），故内层循环上界是 `n - 1 - i`。

比较与交换规则（降序）：若 $d_j < d_{j+1}$，交换二者；否则不动。相等时不交换——这保证相等元素的相对次序不变（稳定性）。

### 3. 代入本例

以样例 1 的前 4 个数 `3.42 1.85 4.10 2.36` 演示第 1 趟（降序）：

| 比较位置 | 比较 | 动作 | 数组状态 |
|---|---|---|---|
| j=0 | 3.42 与 1.85 | 3.42 > 1.85，不换 | `3.42 1.85 4.10 2.36` |
| j=1 | 1.85 与 4.10 | 1.85 < 4.10，换 | `3.42 4.10 1.85 2.36` |
| j=2 | 1.85 与 2.36 | 1.85 < 2.36，换 | `3.42 4.10 2.36 1.85` |

一趟结束，最小值 1.85 已沉到末尾。对完整的 10 个数执行 9 趟后：

```
4.48 4.10 3.75 3.42 3.10 2.36 2.05 1.85 1.20 0.95
```

于是：最高潮位 = `tide[0]` = 4.48，最低潮位 = `tide[9]` = 0.95，潮差 = 4.48 − 0.95 = **3.53** m，与样例一致。

### 4. 编程翻译

| 数学/算法动作 | C 语言翻译 |
|---|---|
| 共 $n-1$ 趟 | 外层 `for (i = 0; i < n-1; i++)` |
| 第 $i$ 趟比较 $0 \sim n-1-i$ | 内层 `for (j = 0; j < n-1-i; j++)` |
| $d_j < d_{j+1}$ 则交换 | `if (tide[j] < tide[j+1]) { tmp 交换三步 }` |
| 取第 $k$ 大 | 排序后直接 `tide[k-1]` |

> **排序 vs 打擂台**：只要一个极值，打擂台一遍循环更快；要"第 k 大""多个极值""整体有序"，排序更划算。C7 的"找最高/最低潮位"两者皆可，C8 的"多条路径按时间排序"则必须排序。

## 三、解题思路

1. **读入**：`n` 与 `n` 个潮位进 `tide[]`；
2. **冒泡排序（降序）**：双重循环，`tide[j] < tide[j+1]` 时借助 `tmp` 交换；
3. **取极值**：`high = tide[0]`，`low = tide[n-1]`；
4. **算潮差**：`range = high - low;`；
5. **输出**：先打印排序后序列（空格分隔），再打印三个统计量。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double tide[50];        /* 一维数组：潮位序列 */
    double tmp, high, low, range;
    int n, i, j;

    scanf("%d", &n);                    /* 读入观测个数 */
    for (i = 0; i < n; i++) {
        scanf("%lf", &tide[i]);         /* 读入潮位 */
    }

    /* 冒泡排序：从大到小（降序） */
    for (i = 0; i < n - 1; i++) {           /* 共 n-1 趟 */
        for (j = 0; j < n - 1 - i; j++) {   /* 每趟比到未排好区末尾 */
            if (tide[j] < tide[j + 1]) {    /* 前小后大 → 交换，让大数前移 */
                tmp = tide[j];
                tide[j] = tide[j + 1];
                tide[j + 1] = tmp;
            }
        }
    }

    high  = tide[0];        /* 降序排好后：第 1 个是最高潮位 */
    low   = tide[n - 1];    /* 最后 1 个是最低潮位 */
    range = high - low;     /* 潮差 */

    printf("排序后：");
    for (i = 0; i < n; i++) {
        printf("%.2f ", tide[i]);
    }
    printf("\n");
    printf("最高潮位 = %.2f m\n", high);
    printf("最低潮位 = %.2f m\n", low);
    printf("潮差 = %.2f m\n", range);
    return 0;
}
```

## 五、运行验证

**第一次运行**（样例 1）：

输入：
```
10
3.42 1.85 4.10 2.36 3.75 1.20 4.48 2.05 3.10 0.95
```
输出：
```
排序后：4.48 4.10 3.75 3.42 3.10 2.36 2.05 1.85 1.20 0.95
最高潮位 = 4.48 m
最低潮位 = 0.95 m
潮差 = 3.53 m
```

数值核对（按 IEEE-754 double 与 `printf("%.2f")` 舍入复算）：排序结果与 Python `sorted(..., reverse=True)` 一致；4.48 − 0.95 = 3.5300000000000002（double 近似），`%.2f` 输出 `3.53`。✓

**第二次运行**（样例 2，含相等元素）：

输入：
```
3
2.00 2.00 1.50
```
输出：
```
排序后：2.00 2.00 1.50
最高潮位 = 2.00 m
最低潮位 = 1.50 m
潮差 = 0.50 m
```
✓ 第 1 趟：j=0 时 2.00 与 2.00 相等不交换；j=1 时 2.00 > 1.50 不交换（降序已满足），数组保持 `2.00 2.00 1.50`。

**反例验证**：若把比较条件误写成 `tide[j] > tide[j+1]`，程序输出升序 `0.95 1.20 ... 4.48`，随后 `tide[0]` 取到的是**最低**潮位、`tide[n-1]` 取到**最高**潮位——最高/最低两行恰好对调，说明比较方向决定升降序。

## 六、常见错误与讲解

**错误 1：不用临时变量直接交换**

```c
tide[j] = tide[j + 1];      /* 错：tide[j] 原值被覆盖 */
tide[j + 1] = tide[j];      /* 结果两个位置都是原来的 tide[j+1] */
```

必须三步：`tmp = tide[j]; tide[j] = tide[j+1]; tide[j+1] = tmp;`

**错误 2：内层循环上界写成 `n - 1`，越界比较**

```c
for (j = 0; j < n - 1; j++) { ... }   /* 第 2 趟起仍比到末尾，浪费但不算大错 */
for (j = 0; j <= n - 1; j++) { ... }  /* 错：j = n-1 时访问 tide[n] → 越界！ */
```

`j <= n-1` 会让内层访问 `tide[j+1] = tide[n]`，越出数组范围，属于**未定义行为**（可能崩溃或悄悄出错）。正确上界是 `j < n - 1 - i`。

**错误 3：升降序方向搞反**

降序要"小的往后换"，条件是 `tide[j] < tide[j+1]` 交换；升序条件是 `tide[j] > tide[j+1]`。写反后取 `tide[0]` 当最高潮位就会出错。

**错误 4：忘记 `n-1` 趟的上限，多循环或循环变量复用混乱**

```c
for (i = 0; i < n; i++)          /* 多跑一趟不致错，但风格差 */
for (i = 0; i < n - 1; i++)      /* 规范：n 个数 n-1 趟足够 */
```

内外层若都用 `i`，内层会把外层的趟数计数打乱——外层用 `i`、内层用 `j`，绝不混用。

## 七、与综合实验的衔接

- 实验 **C7（基于移动平均的潮位观测数据平滑与趋势分析系统）**中，"高低潮极值检测与潮差统计"是本题的直接扩展：实验里先对原始潮位做移动平均平滑（M4），再在平滑序列上检测局部高低潮（M6）并统计相邻高低潮差（M7）；本题的"排序找极值"是其中最朴素的实现路径——不需要找"局部"极值时，排序一次就能拿到全局最高/最低与潮差；
- 与其他实验衔接：实验 **C8** 的"多条声线路径按传播时间排序（M8）"用的是同款双重循环（见练习 36，选择排序版）；实验 **C9** 的"排序求 95% 分位数（M5）"也是"先排序、再按下标取值"的套路。掌握冒泡排序后，"排序 + 定位下标"就能解决一大类"前 k 大 / 分位数 / 中位数"问题。
