# 第 2 章 练习 04　深度-声速两点插值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 C1《基于拉格朗日插值的声速剖面计算系统》（水声学院）——本练习是该实验中"任意深度声速查询"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

海水中的声速随深度缓慢变化，把"深度—声速"画成曲线就是**声速剖面**，它是声呐作用距离、声线弯曲等一切水声计算的输入数据。CTD（温盐深仪）测量时只能在一些离散深度上取点，测出海底某层数据后，往往想知道**任意中间深度**对应的声速。

最简单的做法是：在两个相邻实测深度之间，认为声速随深度**线性变化**，用线性插值求中间点的声速。实验 C1 的"任意深度声速查询"模块，核心就是这一步插值计算。

## 二、任务要求

编写一个完整程序 `sound_speed.c`：

1. 用**常量**存放两个相邻实测档的数据：深度 0 m 处声速 1450 m/s，深度 100 m 处声速 1480 m/s；
2. 从键盘读入一个查询深度 `h`（单位：米，double 类型，**题目保证 0 ≤ h ≤ 100**，因此本程序不需要判断分支）；
3. 用线性插值公式计算该深度的声速 `c`；
4. 按规定格式输出结果，保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示查询深度 h（米）。

**输出**：一行，按格式 `c = 结果 m/s` 输出，结果保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
60
```
输出：
```
c = 1468.00 m/s
```

**样例 2**

输入：
```
25
```
输出：
```
c = 1457.50 m/s
```

## 五、提示

线性插值公式：已知两点 $(h_0,\, c_0)$、$(h_1,\, c_1)$，则 $h$ 处的插值为

$$
c = c_0 + \dfrac{(c_1 - c_0)\,(h - h_0)}{h_1 - h_0}
$$

本题数据都写在代码里（常量），只需读入一个深度、算一步、输出一个数。

**完成本练习后你将具备的能力**：把"表格两点 + 线性插值"这一通用方法，从风荷载场景迁移到声速剖面场景——记住"公式不变，变的是常量表"，这是实验 C1、A1、A7、D3 共用的核心技能。
