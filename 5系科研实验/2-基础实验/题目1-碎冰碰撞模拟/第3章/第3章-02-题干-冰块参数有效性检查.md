# 第 3 章 练习 02　冰块参数有效性检查（选择结构与逻辑运算）

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.2 选择结构——if/else if/else、3.4 关系运算符与逻辑运算符）

**场景来源**：综合实验 C6《冰块与结构碰撞模拟系统》（水声学院船舶冰区工程方向）——本练习是该实验中"冰块模型参数合法性检查"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰区碰撞模拟开始前，程序要先为每块冰建立模型：长 $a$、宽 $b$、厚 $c$（米）、质量 $m$（千克）以及在计算域中的位置坐标 $(x, y)$（米）。如果这些参数本身不合法——边长是零或负数、质量不合理、由尺寸和质量折算出的密度偏离海冰的物理范围、坐标跑出了计算域——后续的碰撞计算就没有任何意义，甚至会让程序除以零而崩溃。真实模拟软件在每块冰入场前都要做一整套"体检"，**按顺序逐项检查、发现第一处不合格立即报告**。本练习实现这套体检的最小版本。

## 二、任务要求

编写一个完整程序 `ice_check.c`：

1. 从键盘按顺序读入 6 个数：冰块的长 $a$、宽 $b$、厚 $c$（米）、质量 $m$（千克）、中心坐标 $x$、$y$（米），均为 `double` 类型；
2. 按以下顺序逐项检查，**一旦某项不合格立即输出对应错误并结束，不再检查后面的项**：
   - 尺寸：$a$、$b$、$c$ 必须满足 $0 < a, b, c \le 20$（米），否则输出 `ERR size`；
   - 质量：$m > 0$（千克），否则输出 `ERR mass`；
   - 密度：由 $\rho = \dfrac{m}{abc}$ 折算，海冰密度合理范围为 $850 \le \rho \le 950$（kg/m³），否则输出 `ERR density`；
   - 位置：计算域为 $0 \le x \le 100$、$0 \le y \le 80$（米），坐标越界输出 `ERR position`；
3. 全部项目合格输出 `OK`；
4. 注意：尺寸不合格时 $abc$ 可能为零或负数，此时**绝不能**去计算密度——这正是"按顺序检查、先到先停"的原因。

## 三、输入输出格式

**输入**：一行，6 个实数，依次为 a、b、c、m、x、y，以空格分隔。

**输出**：一行，为 `OK` 或 `ERR size`、`ERR mass`、`ERR density`、`ERR position` 之一。

## 四、样例

**样例 1**

输入：
```
3 2 1.5 8250 50 40
```
输出：
```
OK
```
（折算密度 $\rho = 8250/9 \approx 916.7$ kg/m³，在 $[850, 950]$ 内）

**样例 2**

输入：
```
3 2 1.5 10000 150 40
```
输出：
```
ERR density
```
（密度 $10000/9 \approx 1111.1$ 超上限；虽然 $x = 150$ 也越界，但按检查顺序密度先不合格）

## 五、提示

"三个边长都要满足 $0 < a, b, c \le 20$"这类"多项同时要求"用逻辑或 `||` 串起来判断**是否违规**更简洁：

```c
a <= 0.0 || a > 20.0 || b <= 0.0 || b > 20.0 || c <= 0.0 || c > 20.0
```

任何一项为真整体就为真。检查顺序不可调换：必须先用尺寸排除 $abc \le 0$ 的情形，才允许做除法求密度。

**完成本练习后你将具备的能力**：用逻辑运算符组合多条件、用 if-else if 链实现"逐项检查、先到先停"、理解检查顺序对安全性的影响（先排除非法再做除法）——这正是实验 C6 中冰块数据入场的把关模块。
