## 二、预备知识：冒泡排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

数组 `8.5 3.2 12.7 5.9 10.4 1.8` 要排成升序。程序一次只能比较两个数，所以排序的本质是**设计一套"两两比较 + 交换"的重复方案**，让乱序在有限轮内自然归位。冒泡排序的方案最简单：**只比较相邻的两个**。

### 2. 一轮冒泡在做什么

从下标 0 出发，依次比较 `a[j]` 与 `a[j+1]`：逆序（前者大）就交换。效果是什么？**大数一路向右"冒泡"**：只要它比右邻大，就被换到右边继续前进，直到撞上一个更大的，或者到达末尾。所以**一轮结束后，参与比较部分的最大值必然落在最右端**——它已到达最终位置，后续轮次不必再碰它。

用本题数据走**第 1 轮**（$n=6$，比较 $j = 0 \sim 4$ 共 5 次）：

| 比较步 | 比较 | 动作 | 数组状态 |
|---|---|---|---|
| j=0 | 8.5 与 3.2 | 逆序，交换 | 3.2 8.5 12.7 5.9 10.4 1.8 |
| j=1 | 8.5 与 12.7 | 有序，不动 | 3.2 8.5 12.7 5.9 10.4 1.8 |
| j=2 | 12.7 与 5.9 | 逆序，交换 | 3.2 8.5 5.9 12.7 10.4 1.8 |
| j=3 | 12.7 与 10.4 | 逆序，交换 | 3.2 8.5 5.9 10.4 12.7 1.8 |
| j=4 | 12.7 与 1.8 | 逆序，交换 | 3.2 8.5 5.9 10.4 1.8 **12.7** |

最大值 12.7 一路冒到末尾，**落定**。

### 3. 下一轮少了谁

第 1 轮落定 1 个，未排序部分只剩前 5 个，第 2 轮只需比较 $j = 0 \sim 3$ 共 4 次：

| 比较步 | 比较 | 动作 | 数组状态 |
|---|---|---|---|
| j=0 | 3.2 与 8.5 | 不动 | 3.2 8.5 5.9 10.4 1.8 12.7 |
| j=1 | 8.5 与 5.9 | 交换 | 3.2 5.9 8.5 10.4 1.8 12.7 |
| j=2 | 8.5 与 10.4 | 不动 | 3.2 5.9 8.5 10.4 1.8 12.7 |
| j=3 | 10.4 与 1.8 | 交换 | 3.2 5.9 8.5 1.8 **10.4** 12.7 |

次大值 10.4 落定。这就是"内层上界逐轮收缩"的由来：**第 $k$ 轮比较 $j = 0 \sim n-k-1$**。

### 4. 一共要几轮

每轮落定 1 个，$n$ 个数需要 $n-1$ 轮（最后 1 个无需再比，剩余的它自动就位）。本题 $n=6$，共 5 轮，正好对应输出的 5 个过程行。

### 5. 交换的翻译

比较后逆序则交换，仍是练习 03 练过的标准三步：

```c
if (a[j] > a[j+1]) { t = a[j]; a[j] = a[j+1]; a[j+1] = t; }
```

> 冒泡排序的**思想**一句话：**反复扫过数组，把未排序部分的最大值逐轮顶到末尾**。下一题的选择排序则相反——每轮主动"挑选"最小值放到前端，两题对照着学效果最好。

## 三、解题思路

1. 读入 $n$ 与数组；
2. 外层 `for (k = 1; k <= n-1; k++)` 控制轮数；
3. 内层 `for (j = 0; j <= n-k-1; j++)`：`a[j] > a[j+1]` 则三步交换；
4. 每轮内层结束后打印 `第 k 轮:` 与当前数组全部元素；
5. 全部轮次结束后打印 `排序结果:` 行。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double a[100], t;   /* a 为载荷序列，t 为交换临时变量 */
    int n, k, j, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &a[i]);

    /* 冒泡排序：共 n-1 轮，第 k 轮把未排序部分的最大值顶到 a[n-k] */
    for (k = 1; k <= n - 1; k++) {
        for (j = 0; j <= n - k - 1; j++)      /* 未排序部分逐轮缩短 */
            if (a[j] > a[j + 1]) {            /* 相邻逆序则交换 */
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        /* 打印本轮结束后的数组状态 */
        printf("第 %d 轮:", k);
        for (i = 0; i < n; i++)
            printf(" %.2f", a[i]);
        printf("\n");
    }

    printf("排序结果:");
    for (i = 0; i < n; i++)
        printf(" %.2f", a[i]);
    printf("\n");

    return 0;
}
```

| 2 | 4 | 10.4 → a[4] | 3.20 5.90 8.50 1.80 10.40 12.70 |

## 六、常见错误与讲解

**错误 1：内层上界写死不收缩**

```c
for (j = 0; j <= n - 2; j++)   /* 错：每轮都比较到已落定区，多比但不致错，浪费且概念不清 */
for (j = 0; j <= n - k - 1; j++)   /* 对：随轮次收缩 */
```

**错误 2：内层上界收缩过度导致越界或漏比**

```c
for (j = 0; j <= n - k + 1; j++)   /* 错：k=1 时 j 到 n，a[j+1] 即 a[n+1]，越界 */
for (j = 0; j < n - k; j++)        /* 对：与 j <= n-k-1 等价，注意 i 与 j 别混写 */
```

**错误 3：交换漏临时变量**

```c
a[j] = a[j+1]; a[j+1] = a[j];   /* 错：两头变成同一个值，数据丢失 */
t = a[j]; a[j] = a[j+1]; a[j+1] = t;   /* 对 */
```

**错误 4：比较方向反了**

```c
if (a[j] < a[j+1]) 交换;   /* 得到降序，与题目"升序"不符 */
```

排完后用眼睛扫一遍结果（首项应最小、末项应最大）是最便宜的验证。

## 七、与综合实验的衔接

- 实验 **C7 模块 M8** 把每个冰情事件的峰值载荷从小到大排好后，才能统计"不超过某载荷的事件占比"，进而绘制载荷谱——冒泡排序就是该模块的实现算法；当事件数增大到成千上万时，冒泡 $O(n^2)$ 的比较次数会成为瓶颈，届时会升级为更快的算法，但"比较 + 交换"的基本语言不变；
- 下一题（练习 07）用同一批数据的"选择排序"版本对照学习：同样的双重循环外壳，内层从"相邻冒泡"换成"先找擂主再一次交换"，两种排序每轮落定一个元素的结构完全平行——**把两个排序放在一起理解，比单独背两个算法有效得多**。
