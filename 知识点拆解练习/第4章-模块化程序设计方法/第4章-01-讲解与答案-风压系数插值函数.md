## 二、预备知识：函数、形参实参与函数原型（零基础阅读）

### 1. 问题来源：为什么要把计算"搬出去"

在没学函数之前，每当程序里要查一次风压系数，就得把那五个常量、那一条插值公式重新抄一遍。抄三遍就出错，抄十遍就无法维护。模块化的做法是：**把这段计算从主程序里"搬出去"，单独定义成一个函数**，并给它起一个能表意的名字 `wind_mu`（wind + mu）。以后任何人想查系数，喊一声这个函数名就行。

### 2. 函数原型：先"打招呼"，后"交底"

C 语言要求"先声明、后使用"。函数原型就是一句**声明**：

```c
double wind_mu(double h);
```

它告诉编译器三件事：函数名叫 `wind_mu`；它需要一个 `double` 类型的参数；它返回一个 `double` 类型的值。原型末尾有分号，表示"我只报名字，不写内容"。真正的实现（函数体）可以写在别的任何地方：

```c
double wind_mu(double h)   /* 这才是定义，末尾没有分号 */
{
    const double H0 = 10.0, H1 = 20.0;
    const double M0 = 1.00, M1 = 1.23;
    return M0 + (M1 - M0) * (h - H0) / (H1 - H0);
}
```

**原型的作用**：让编译器在遇到 `main` 里那行 `wind_mu(h)` 调用时，知道该函数存在且返回 `double`，从而正确编译。如果漏写原型（且定义又放在 `main` 之后），编译器会报"未声明的标识符"或按旧式规则猜测返回类型，容易出隐性错误。

### 3. 形参与实参：两个"传送带"

- **形参**（形式参数）是函数定义括号里的变量，如 `double h`，它是函数内部用来接收数据的"空盒子"；
- **实参**（实际参数）是调用时括号里填的表达式，如 `wind_mu(15.5)` 里的 `15.5`。

调用发生的瞬间，实参的值被**复制**一份放进形参，之后函数内部怎么改形参，都不会影响外面原来的实参——这叫作**值传递**。本例中函数只"读"形参、不"改"形参，所以完全依赖值传递即可。

### 4. 返回值：函数算完把结果"递出来"

`return` 语句有两个作用：把结果交回调用处，并结束函数。`main` 里 `mu = wind_mu(h);` 这一步，就是把 `wind_mu` 交回的结果赋给变量 `mu`。注意：函数的返回值类型 `double` 必须与 `return` 后面的表达式类型匹配。

### 5. 编程时的思路

函数体里写什么，取决于"函数该懂什么"。查系数需要两档数据这个专业知识，就把它作为**局部常量**放进函数；主函数既不必要、也最好不要知道这些常量。**"把知识放在最需要它的地方"，就是模块化的核心。**

## 三、解题思路

1. **定接口**：函数名 `wind_mu`，输入一个 `double` 高度，输出一个 `double` 系数；
2. **定数据**：两档高度与系数共四个常量，写进函数体；
3. **定算法**：在函数体内直接用插值公式计算并 `return`；
4. **定主流程**：`main` 中先 `scanf` 读高度，再 `mu = wind_mu(h);`，最后 `printf` 输出；
5. **定格式**：输出保留 4 位小数，用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：输入高度 h，返回风压高度变化系数 mu_z */
double wind_mu(double h);

int main(void)
{
    double h;                 /* 建筑计算高度，m */
    double mu;                /* 查算得到的风压高度变化系数 */

    scanf("%lf", &h);         /* 读入高度 */
    mu = wind_mu(h);          /* 调用函数，把结果接回来 */
    printf("mu_z = %.4f\n", mu);

    return 0;
}

/* 函数定义：把"查表 + 线性插值"封装在一起 */
double wind_mu(double h)
{
    const double H0 = 10.0;   /* 下档高度，m */
    const double H1 = 20.0;   /* 上档高度，m */
    const double M0 = 1.00;   /* 下档系数，无量纲 */
    const double M1 = 1.23;   /* 上档系数，无量纲 */

    return M0 + (M1 - M0) * (h - H0) / (H1 - H0);
}
```

## 五、运行验证

| 输入 h | 函数内手算过程 | 程序输出 |
|---|---|---|
| 15 | 1.00 + 0.23 × (15−10)/(20−10) = 1.00 + 0.115 = 1.1150 | `mu_z = 1.1150` ✓ |
| 17.5 | 1.00 + 0.23 × 7.5/10 = 1.00 + 0.1725 = 1.1725 | `mu_z = 1.1725` ✓ |
| 10 | 1.00 + 0.23 × 0/10 = 1.0000（下端点） | `mu_z = 1.0000` ✓ |
| 20 | 1.00 + 0.23 × 10/10 = 1.2300（上端点） | `mu_z = 1.2300` ✓ |

端点值恰好退回表格值，说明封装后的函数在边界处仍然正确。

## 六、常见错误与讲解

**错误 1：只写函数定义，忘记函数原型（且定义在 main 之后）**

```c
int main(void) { double mu = wind_mu(15); /* 编译报错：wind_mu 未声明 */ ... }
double wind_mu(double h) { ... }
```

C 编译器自 `main` 往下读，读到 `wind_mu(15)` 时还不认识这个函数。**解决办法**：在 `main` 之前（文件顶部）写上原型 `double wind_mu(double h);`。

**错误 2：函数定义末尾多写分号**

```c
double wind_mu(double h);
{
    ...
}
/* 错：第一行的分号让"定义"变成了"再声明一次"，函数体成了孤立的语句块 */
```

函数**定义**的行末不能有分号，只有**声明（原型）**才有分号。

**错误 3：调用时把返回类型丢掉了**

```c
wind_mu(h);            /* 错：算了，但结果被扔掉，mu 没有被赋值 */
mu = wind_mu(h);       /* 对：用赋值号把返回值接住 */
```

**错误 4：忘了在函数里写 `return`，或返回类型不匹配**

```c
int wind_mu(double h) { ... return M0 + ...; }
/* 错：声明返回 int，却返回 double，小数部分被截断 */
```

接口类型必须严格一致：原型写 `double`，定义也写 `double`，`return` 的表达式也应是 `double`。

## 七、与综合实验的衔接

- 在实验 **A1（风荷载计算系统）**中，本练习就是"系数查算模块"的最小实现：函数名、参数、返回值都与系统中真实模块一致，只是本练习规定 $10\le h\le20$、只查一段，把注意力集中在"函数怎么写"上；
- 学到第 3 章的选择结构后，函数内部就能先判断 h 落在哪一段，再选对应的两档数据；学到第 5 章的数组后，整张规范表可以存进数组，函数就能支持任意档位。**无论细节如何扩展，'主程序只负责调度、计算交给函数'的结构始终不变**——这就是模块化设计在后续所有实验中的通用骨架。
