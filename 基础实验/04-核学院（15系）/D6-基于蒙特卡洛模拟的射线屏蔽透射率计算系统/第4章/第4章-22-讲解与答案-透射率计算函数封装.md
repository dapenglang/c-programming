## 二、预备知识：函数为什么能把复杂程序"变小"

### 1. 问题是怎么来的

假设 D6 综合实验里要 20 次计算透射率。如果不封装函数，代码里就会散落 20 处 `exp(-mu * x)`：

- 一旦公式要改（比如加宽束积累因子），20 处都得改，漏一处就出错；
- 每一处都要保证变量名对、负号对、括号对，容易抄错；
- 读代码的人看到一片 `exp(-mu*x)`，不知道哪句是"算透射率"，哪句是"算别的"。

函数就是解决这个问题的：**把"一件事"打包成一个有名字的模块**，用一次定义、多次调用来替代多次复制。

### 2. 公式与接口是怎么组织的

函数定义的四要素：

```c
double  trans ( double mu , double x )
// ①      ②       ③           ③
// ① 返回类型：这个函数吐出来的是什么类型 —— 透射率是实数，用 double
// ② 函数名：给它起个有意义的名字 —— trans 是 transmittance（透射率）的缩写
// ③ 参数表：需要喂给它什么 —— 材料系数 mu 与 厚度 x，都是 double
{
    return exp(-mu * x);   // 函数体：算出结果并交还（return）
}
```

调用时写成 `T = trans(mu, x);`。C 语言按**位置**配对实参与形参：第 1 个实参 `mu` 传给第 1 个形参 `mu`，第 2 个实参 `x` 传给第 2 个形参 `x`。这就是**值传递**——形参拿到的是实参的**副本**，函数里怎么改都影响不到 `main` 里的变量。

为什么要在 `main` 之前写**函数声明**（原型）？

```c
double trans(double mu, double x);   /* 原型：只写接口，不写函数体 */
```

编译器自上而下扫描代码，遇到 `main` 里调用 `trans` 时，必须先"见过"这个名字才知道怎么检查参数个数与类型。原型就是提前告诉编译器"有这么个函数、接口长这样"。**纪律：函数定义若写在调用之后，前面一定要加原型。**

### 3. 用本例走一遍

取 $\mu = 0.35$、$x = 3$（样例 2，模拟铁的衰减）：

- `main` 读入 `mu = 0.35`、`x = 3`；
- 调用 `trans(0.35, 3)`，实参副本进入形参；
- 函数体算 `exp(-0.35 * 3) = exp(-1.05)`；
- `return` 把结果 $\approx 0.3499$ 交回给调用处，赋给 `T`；
- `main` 打印 `T = 0.3499`。

整个过程函数只做"算"，输入输出都在 `main`——**计算与交互分离**，这是模块化设计的核心习惯。

### 4. 编程时怎么用它

三步：**写原型**（放 `main` 上方）、**写定义**（函数体一句 `return`）、**在 main 里调用**（读入 → 调用 → 输出）。

> **这个思想在综合实验中反复出现**：D6 的 `trans`、D7 的 `doseRate`（点源剂量率）、D8 的 `toEnergy`（道址转能量），都是"把一条物理公式封装成一个函数"。综合实验里还要把关系统的物理量打包成结构体，但**函数这一层永远存在**——它是"物理公式"和"程序流程"之间的翻译层。

## 三、解题思路

1. **接口设计**：返回值是透射率（double），参数是 μ 与 x（都 double），故原型为 `double trans(double mu, double x);`；
2. **函数定义**：函数体只有 `return exp(-mu * x);`，不含任何 `printf`/`scanf`；
3. **main 流程**：定义 `double mu, x, T;` → `scanf("%lf %lf", &mu, &x);` → `T = trans(mu, x);` → `printf("T = %.4f\n", T);`；
4. **头文件**：`exp` 在 `math.h` 中，务必 `#include <math.h>`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>                       /* exp 需要数学库 */

/* 函数声明（原型）：告诉编译器 trans 的接口 */
double trans(double mu, double x);

int main(void)
{
    double mu;      /* 线衰减系数，1/cm */
    double x;       /* 屏蔽厚度，cm */
    double T;       /* 透射率 */

    scanf("%lf %lf", &mu, &x);          /* 读入 mu 与 x */

    T = trans(mu, x);                   /* 调用函数求透射率 */

    printf("T = %.4f\n", T);            /* 输出结果 */
    return 0;
}

/* 函数定义：返回窄束透射率 exp(-mu * x)，只算不打印 */
double trans(double mu, double x)
{
    return exp(-mu * x);
}
```

| 0.78 2 | μx = 1.56，T = e^(−1.56) = 0.2101 | `T = 0.2101` ✓ |
| 0.35 3 | μx = 1.05，T = e^(−1.05) = 0.3499 | `T = 0.3499` ✓ |
| 1.0 0 | μx = 0，T = e^0 = 1.0000 | `T = 1.0000` ✓ |

## 六、常见错误与讲解

**错误 1：忘记写函数声明（或把定义放到 main 之后却不声明）**

```c
int main(void) {
    T = trans(mu, x);        /* 编译告警：隐式声明 trans，返回值默认 int，结果被截断 */
    ...
}
double trans(double mu, double x) { return exp(-mu * x); }   /* 定义在后面 */
```

C 语言规定"先声明后使用"。定义在 `main` 之后时，必须在 `main` 之前补上 `double trans(double mu, double x);`。否则编译器按老规则假定返回 `int`，透射率 $\approx 0.35$ 会被截断成 0。

**错误 2：函数里做了输入输出**

```c
double trans(double mu, double x) {
    double t = exp(-mu * x);
    printf("%f\n", t);       /* 错：函数擅自打印，职责混乱 */
    return t;
}
```

函数应只负责计算。若函数自己打印，一旦需要在别处复用（比如循环里调用一万次），就会打印一万行。**纪律：函数管算，调用者管输入输出。**

**错误 3：调用时参数顺序或类型写错**

```c
T = trans(x, mu);            /* 错：实参顺序反了，把 μ 和 x 弄混 */
T = trans(mu);               /* 错：少传一个参数，编译报错 */
T = trans(0.78, 2);          /* 对：按位置传，也可直接传常量 */
```

实参与形参**按位置一一对应**，顺序错位虽然能编译（都是 double），但物理含义全错。

**错误 4：漏写 `return` 或返回类型写成 int**

```c
int trans(double mu, double x) { return exp(-mu * x); }  /* 错：返回 int，小数被截断 */
double trans(double mu, double x) { exp(-mu * x); }      /* 错：没有 return，返回值是垃圾值 */
```

返回类型必须与"想交还的东西"一致（double），且函数体必须有一条 `return 表达式;`。

## 七、与综合实验的衔接

- 实验 **D6（蒙特卡洛射线屏蔽透射率计算）**中，本练习的 `trans` 是"理论值模块"。综合实验的完整骨架是：用 LCG（练习 24）为每个光子抽样 → 统计透射比例得模拟值 → 用 `trans` 算理论值 → 对照（练习 23 的关系表）。本练习把理论模块"函数化"，正是为了让综合实验的主流程读起来像一段物理描述，而不是一堆散落的公式；
- 与前三个练习衔接：练习 25 学会"算一个点"、练习 23 学会"批量算一串"、练习 24 学会"造随机数"，本练习把公式**封装**起来。到了第 5 章（数组），调用 `trans` 的循环会改成遍历数组；到了第 7 章（结构体），材料参数会打包成一个结构体再传给函数。
