# 第 6 章 练习 19　指针版阈值筛选输出

**对应章节**：6 内存数据深度操控方法（6.3 指针与数组、6.5 指针与函数——指针综合）

**场景来源**：综合实验 C7《基于冲量-动量反演的冰阻力与碰撞事件辨识系统》（水声学院）——本练习是该实验中"超阈值载荷样本筛选"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰载荷辨识中，工程师常要从一整条阻力样本里挑出"超过警戒线"的那些样本，单独拿去分析。筛选这件事有两个特点：一是原始数据只读、不能改动；二是筛选结果要另存一份，而且个数事先不知道。指针正好能同时满足这两点：形参用一个**只读指针**接收原数组（保证不改），再用一个**可写指针**指向结果存放区（把合格样本逐个写进去），函数返回实际筛选出的个数。本练习实现这个"输入只读、输出写指针"的筛选函数。

## 二、任务要求

编写一个完整程序 `filter_threshold.c`：

1. 主函数读入样本数 `n`（题目保证 $1 \le n \le 50$），读入 `n` 个阻力值存入 `double a[50]`，再读入阈值 `thr`；
2. 编写函数，其原型为 `int filter_ge(const double *a, int n, double thr, double *out);`：遍历 `a`，把**大于等于**阈值 `thr` 的元素**按原顺序**写入 `out` 所指的目标数组，并返回写入的个数（`a` 用 `const` 修饰，函数不得修改原数据）；
3. 主函数准备接收数组 `double sel[50]`，调用函数后先输出筛选个数，再按顺序输出筛选出的值（每个保留 2 位小数、空格分隔）。若个数为 0，第二行输出空行。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数；第三行一个实数（阈值 `thr`）。

**输出**：第一行 `count = <个数>`；第二行筛选出的值，各保留 2 位小数、空格分隔（无合格样本时该行为空）。

## 四、样例

**样例 1**

输入：
```
6
12.5 30.0 8.4 45.2 20.0 30.0
20.0
```
输出：
```
count = 4
30.00 45.20 20.00 30.00
```

**样例 2**

输入：
```
5
5 15 25 35 45
25
```
输出：
```
count = 3
25.00 35.00 45.00
```

## 五、提示

- 用一个计数器 `k` 记录已写入几个，每找到一个合格样本就 `out[k] = a[i]; k++;`
- 元素"大于等于"用 `>=`，注意题目要求包含等于阈值的情况；
- 遍历完返回 `k`；主函数用返回值控制第二行输出多少个值；
- `a` 是 `const double *`、`out` 是 `double *`——一个只读、一个可写，分工清晰。

**完成本练习后你将具备的能力**：掌握"只读输入指针 + 可写输出指针"的经典接口模式、学会用返回值报告结果个数、把指针遍历、条件判断与结果回写串成一个完整流程——这是实验 C7 中"样本筛选模块"的地基。
