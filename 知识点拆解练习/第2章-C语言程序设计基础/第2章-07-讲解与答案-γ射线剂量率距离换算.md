## 二、预备知识：平方反比规律与单位换算（零基础阅读）

### 1. 问题是怎么来的

点源向四面八方均匀放出 γ 射线。想象以源为中心、半径 $r$ 的一个球面：所有射线都穿过这个球面，球越大，同样的射线摊得越开，单位面积上的强度就越低。球面积正比于 $r^2$，所以**强度反比于 $r^2$**——这就是"距离加倍、剂量率变四分之一"的来历，称为**平方反比规律**。

### 2. 公式是怎么推出来的

工程手册把常数都打包成一个**转换常数** $\Gamma$（单位 $\mu\mathrm{Sv\cdot cm^2/(h\cdot MBq)}$），于是剂量率写成

$$
D = \frac{\Gamma \cdot A}{r^2}
$$

其中 $A$ 是活度（MBq），$r$ 是距离（**与 $\Gamma$ 的单位配套，即厘米**）。$\Gamma$ 里含 $\mathrm{cm^2}$，是因为它已经"约掉"了球面积里的 $4\pi$，只留下距离平方这一项。

### 3. 用本例走一遍

$\Gamma = 13000$、$A = 100$ MBq、$r = 1$ m：

- 先换算：$r = 1\times100 = 100$ cm；
- 求平方：$r^2 = 100\times100 = 10000\ \mathrm{cm^2}$；
- 代入：$D = \dfrac{13000\times100}{10000} = \dfrac{1300000}{10000} = 130\ \mu\mathrm{Sv/h}$。

把距离换成 2 m（200 cm）：$D = \dfrac{1300000}{200\times200} = \dfrac{1300000}{40000} = 32.5$，正好是 130 的 $1/4$，验证了平方反比。

### 4. 编程时怎么用它

三个输入（$\Gamma, A, r$）+ 一个换算（$\times100$）+ 一个公式（乘法、平方、除法）= 一段顺序代码。要点有三：**平方写成 `rcm * rcm`**；**先换算再平方**（若先平方再乘 100 就错了，因为 $(100r)^2 \neq 100r^2$）；**除数不能为零**（题目已保证 $r>0$）。

## 三、解题思路

1. **备常量与变量**：`const double M_TO_CM = 100.0`；变量 `Gamma, A, r`（输入），`rcm, D`（中间与输出）；
2. **读入**：`scanf("%lf %lf %lf", &Gamma, &A, &r)`；
3. **换算单位**：`rcm = r * M_TO_CM`；
4. **求剂量率**：`D = Gamma * A / (rcm * rcm)`；
5. **输出**：保留 4 位小数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double M_TO_CM = 100.0;   /* 1 m = 100 cm */

    double Gamma;   /* 输入：转换常数，μSv·cm^2/(h·MBq) */
    double A;       /* 输入：活度，MBq */
    double r;       /* 输入：距离，m */
    double rcm;     /* 中间：距离换算为 cm */
    double D;       /* 输出：剂量率，μSv/h */

    /* 读入转换常数、活度与距离 */
    scanf("%lf %lf %lf", &Gamma, &A, &r);

    /* 第一步：距离由米换算为厘米（必须换算后再平方） */
    rcm = r * M_TO_CM;

    /* 第二步：代入平方反比公式 D = Gamma * A / r^2 */
    D = Gamma * A / (rcm * rcm);

    /* 输出，保留 4 位小数 */
    printf("D = %.4f μSv/h\n", D);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 13000 100 1 | $r=100$；$13000\times100/10000=130$ | `D = 130.0000 μSv/h` ✓ |
| 13000 100 2 | $r=200$；$13000\times100/40000=32.5$ | `D = 32.5000 μSv/h` ✓ |
| 13000 100 0.5 | $r=50$；$13000\times100/2500=520$ | `D = 520.0000 μSv/h` ✓ |

第 2 行是第 1 行距离加倍的结果，剂量率恰好降到 $1/4$；第 3 行是距离减半的结果，剂量率升到 $4$ 倍，均与平方反比一致。

## 六、常见错误与讲解

**错误 1：先平方再换算单位**

```c
D = Gamma * A / (r * r * M_TO_CM);       /* 错：等于只除了 100 倍，不是 100^2 倍 */
D = Gamma * A / (r * M_TO_CM * r * M_TO_CM);  /* 对，但冗长 */
rcm = r * M_TO_CM;  D = Gamma * A / (rcm * rcm);  /* 对：先换算成 cm 再平方，最清晰 */
```

**错误 2：用 `^` 表示平方**

```c
D = Gamma * A / (rcm ^ 2);     /* 错：^ 是位异或 */
D = Gamma * A / (rcm * rcm);   /* 对 */
```

**错误 3：括号漏写导致优先级错**

```c
D = Gamma * A / rcm * rcm;     /* 错：等价于 (Gamma*A/rcm)*rcm，平方没生效 */
D = Gamma * A / (rcm * rcm);   /* 对：分母必须整体加括号 */
```

**错误 4：scanf 漏写 `&` 或数不对应**

三个 `%lf` 要对应三个 `&变量`，顺序为 Gamma、A、r，不能颠倒，否则单位换算会用错变量。

## 七、与综合实验的衔接

- 在实验 **D5（γ 射线剂量率计算系统）**中，本练习对应"单能群剂量率计算模块"：正式程序会对**多个能群**分别算剂量率再叠加，还要从文件读入"能量-剂量转换因子表"并插值——叠加需要循环与累加（第 3 章），因子表需要数组与插值（第 5 章）；
- 平方反比对距离的敏感是屏蔽设计的核心：后续"屏蔽层厚度实验"会在此基础上乘上屏蔽衰减因子，用的仍是本练习这套"先换算、再代公式"的顺序写法。
