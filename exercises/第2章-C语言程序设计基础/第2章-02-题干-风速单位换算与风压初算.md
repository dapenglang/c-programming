# 第 2 章 练习 02　风速单位换算与风压初算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 A1《基于线性插值的风荷载计算系统》（航建学院）——本练习是该实验中"基本风压换算模块"的最小实现。

**建议用时**：20 分钟

## 一、应用场景

风荷载计算的起点是**基本风压** $w_0$。气象台给出的风速习惯用"千米每小时"（km/h），而工程师计算风压必须用国际单位制的"米每秒"（m/s），因为风压公式里速度要与空气密度、重力加速度等 SI 单位配套使用。

由伯努利方程，匀速气流对迎风面的动压为：

$$
w = \frac{1}{2}\,\rho\,v^{2}
$$

其中 $\rho$ 是空气密度（常温常压下取 $1.25\ \mathrm{kg/m^3}$），$v$ 是风速（m/s），$w$ 是风压（帕，Pa）。程序要做的第一件事，就是把手里的风速读数换成 m/s，再代入这个公式算出风压。实验 A1 的"基本风压换算模块"正是从这里开始的。

## 二、任务要求

编写一个完整程序 `wind_pressure.c`：

1. 用**常量**定义空气密度 `RHO = 1.25`（kg/m³）和换算系数 `KMH_TO_MS = 1.0 / 3.6`；
2. 从键盘读入一个风速值 `v_kmh`（单位：km/h，double 类型），**题目保证风速为正数**，因此本程序不需要判断分支；
3. 先把 km/h 换算成 m/s，再代入 $w = \dfrac{1}{2}\rho v^{2}$ 计算风压；
4. 按规定格式输出换算后的风速与风压，均保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示风速（km/h）。

**输出**：两行，第一行按 `v = 结果 m/s` 输出风速，第二行按 `w = 结果 Pa` 输出风压，结果均保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
36
```
输出：
```
v = 10.0000 m/s
w = 62.5000 Pa
```

**样例 2**

输入：
```
54
```
输出：
```
v = 15.0000 m/s
w = 140.6250 Pa
```

## 五、提示

km/h 换成 m/s：$1\ \mathrm{km/h} = \dfrac{1000\ \mathrm{m}}{3600\ \mathrm{s}} = \dfrac{1}{3.6}\ \mathrm{m/s}$；风压公式为

$$
v = \frac{v_{\mathrm{km/h}}}{3.6}, \qquad w = \frac{1}{2}\,\rho\,v^{2}
$$

注意：`3.6` 必须写成小数，写成整数会触发整数除法。

**完成本练习后你将具备的能力**：正确选择数据类型、书写带小数常量和算术表达式、识别整数除法陷阱、用 scanf/printf 完成一组单位换算与公式计算——这是实验 A1 中风压计算链的第一环。
