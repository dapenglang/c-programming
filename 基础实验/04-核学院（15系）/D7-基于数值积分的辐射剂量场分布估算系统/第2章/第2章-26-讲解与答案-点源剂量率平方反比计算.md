## 二、预备知识：平方反比律是怎么来的

### 1. 问题是怎么来的

一个点源每秒钟放出固定数量的 γ 光子，光子向四面八方均匀飞散。距离源 $d$ 处的"射线密度"（单位面积上穿过多少光子）决定了那里的剂量率。

关键：源每秒发出的光子总数是固定的，但它们摊开的**球面面积**随距离增大。把光子想象成"往外吹的气球上的点"——气球越大，点越稀疏。

### 2. 公式是怎么推出来的

半径为 $d$ 的球面，表面积是：

$$
A = 4\pi d^{2}
$$

源每秒发出的光子总数记为 $N$，均匀分布在球面上，于是单位面积的光子数（通量）为：

$$
\phi = \frac{N}{4\pi d^{2}}
$$

剂量率与通量成正比（比例系数含 γ 能量、组织吸收等），把所有与 $d$ 无关的常数合并成一个**源强度常数** $S$，就得到：

$$
\dot{D} = \frac{S}{d^{2}}
$$

这就是**平方反比律**：距离变为原来的 2 倍，剂量率降为原来的 $1/4$；距离变为 3 倍，降为 $1/9$。它是辐射防护、光学、声学里共有的规律——**"点源 + 均匀发散"必然导致平方反比**。

### 3. 用本例走一遍

取源强 $S = 120.0$，距离 $d = 5$ m：

- 算平方：$d^{2} = 25$；
- 相除：$\dot{D} = 120/25 = 4.8$。

所以 5 m 处剂量率是 4.8 μSv/h。再验算 $d = 2$：$4\pi$ 无关，直接用公式 $\dot{D} = 120/4 = 30$ μSv/h。可以看到距离从 5 m 缩短到 2 m（变近 2.5 倍），剂量率从 4.8 升到 30（升了 6.25 倍 = $2.5^{2}$ 倍）——正是"平方"反比。

### 4. 编程时怎么用它

公式里只有两个量：常量 $S$ 和输入 $d$。编程就是：**把 $S$ 放进常量、把 $d$ 读进变量、把 $S/d^2$ 翻译成一行赋值语句**。翻译时唯一的注意点是**分母加括号**：写成 `S / (d * d)`。

> **这个思想在综合实验中反复出现**：D7 剂量场（距离 → 平方反比贡献）、声学里的声压衰减、光学里的照度衰减，全部是"平方反比"同一个套路。学会一次，多处可用。而且本题的 `S/(d*d)` 会在 D7 里被调用成千上万次（每个测点都要算一遍），所以第一遍就要写对。

## 三、解题思路

1. **确定数据**：源强是这道题给定的常数，程序运行中不改动，用 `const double S = 120.0;` 表达最贴切；
2. **确定变量**：只有两个变量——读入的距离 `d` 和待求的剂量率 `D`，都是实数，用 `double`；
3. **套用公式**：`D = S / (d * d);`。用 `d * d` 表示平方，比 `pow(d, 2)` 更直接（也省去引入 `math.h` 和一次函数调用）；
4. **输出**：题目要求保留 4 位小数，用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 点源强度常数，单位 μSv·m^2/h（已并入源活度与γ常数） */
    const double S = 120.0;

    double d;                  /* 测点到源的距离，单位 m */
    double D;                  /* 剂量率，单位 μSv/h */

    /* 读入距离 */
    scanf("%lf", &d);

    /* 平方反比律：D = S / d^2，用 d*d 表示平方，分母必须加括号 */
    D = S / (d * d);

    /* 输出，保留 4 位小数 */
    printf("D = %.4f\n", D);

    return 0;
}
```

## 五、运行验证

| 输入 d | 手算过程 | 程序输出 |
|---|---|---|
| 2 | D = 120 / (2×2) = 120/4 = 30.0000 | `D = 30.0000` ✓ |
| 5 | D = 120 / (5×5) = 120/25 = 4.8000 | `D = 4.8000` ✓ |
| 1 | D = 120 / 1 = 120.0000 | `D = 120.0000` ✓ |
| 10 | D = 120 / 100 = 1.2000 | `D = 1.2000` ✓ |

从 d=1 到 d=10 距离增大 10 倍，剂量率从 120 降到 1.2（降 100 倍），恰好是 $10^{2}$ 倍——平方反比律得到验证。

## 六、常见错误与讲解

**错误 1：分母忘记加括号（最典型）**

```c
D = S / d * d;        /* 错：从左到右算成 (S/d)*d = S，结果恒为 120，与距离无关 */
D = S / (d * d);      /* 对：先算 d*d，再相除 */
```

这是本题最隐蔽的错误：程序能编译、能运行、不报错，但输出恒等于 120.0000，与输入的 `d` 毫无关系。**自检办法：换几个不同的 `d` 试试，结果应当随距离变化。**

**错误 2：常量写成整数**

```c
const int S = 120;      /* 能跑，但语义不严谨 */
const double S = 120.0; /* 对：物理常数一律 double */
```

$S = 120$ 本身是整数没问题，但它参与除法后结果应是小数。若搞混类型、写成 `S / (d*d)` 时 `S` 是 `int`，只要分母也是 `int` 就会出现整数除法截断。**纪律：凡是物理上的实数量，一律用 `double`。**

**错误 3：忘记取地址符**

```c
scanf("%lf", d);     /* 错：程序崩溃或读不进数据 */
scanf("%lf", &d);    /* 对：scanf 需要变量的地址 */
```

`&` 的原理在第 6 章（指针）才彻底讲清，当前阶段记住规则：**scanf 的每个参数前面都要加 `&`。**

**错误 4：输出格式与类型不匹配**

```c
printf("D = %d\n", D);     /* 错：double 用 %d 输出得到乱码 */
printf("D = %f\n",  D);    /* 对但没控制位数 */
printf("D = %.4f\n", D);   /* 对：保留 4 位小数 */
```

`double` 读入用 `%lf`、输出用 `%f`（可加精度如 `%.4f`），务必与变量类型严格对应。

## 七、与综合实验的衔接

- 实验 **D7（基于数值积分的辐射剂量场分布估算）**中，"单点源剂量率计算"就是本练习：把剂量源的每一小段当成一个点源，逐点算它到测点的距离，代入 $S/d^{2}$，再全部叠加。本练习故意规定"d > 0"，就是为了让你**先专注于把一个平方反比计算写对**（距离为 0 时公式发散，需要特殊处理，属于后续章节的内容）；
- 同样的公式稍作变化就是"多点源叠加"：练习 25（第 3 章）会用循环把多个点源的贡献累加起来；练习 24（第 4 章）会把它封装成函数 `doseRate(S, d)`；练习 25（第 5 章）会把一整条测线上各点的剂量率存进数组。**公式不变，变的是"算几次、算哪些点"。**
