## 二、预备知识：三道工序如何拼成一个程序（零基础阅读）

本题是本章的综合题，把三种手段按"数据怎么来 → 怎么用 → 怎么反求"的顺序拼在一起。

### 1. 数据怎么来：条数不定的记录用链表

测点记录是动态上报的，条数事先不定，所以用**链表**承载（见练习 11、12）：每读入一条记录，就 `malloc` 一个节点、尾插到链尾。尾插保证链表顺序与上报顺序一致，`head` 指向第一条、`tail` 指向最后一条。节点结构体把"编号 + 载荷 + 下一节点地址"捆在一起。

```
head ──► [101|12.0|●] ──► [102|24.0|●] ──► [103|6.0|●] ──► [104|30.0|NULL]
                                                                 ▲
                                                                tail
```

### 2. 怎么用：沿链遍历，边走边统计

统计四项指标只需**一次遍历**（见练习 13）：

```c
for (p = head; p != NULL; p = p->next) {
    count++;  sum += p->load;
    if (p->load >= limit) over++;
    if (p->load > max)    max = p->load;
}
mean = sum / count;
```

走完一遍得到 `count`、`sum`、`over`、`max`，再算 `mean`。

### 3. 怎么反求：把平均载荷代入模型，用二分法解方程

工程上由平均载荷 $\bar{F}$ 反求一个"等效冰厚" $h$，用的是简化模型 $F(h) = C\,h^2$，其中 $C = 50\ \text{kN/m}^2$。令模型输出等于平均载荷，写成方程：

$$
F(h) = C\,h^2 - \bar{F} = 0 .
$$

这就是一个标准的非线性方程求根问题，用二分法解决（见练习 17、18）。按"问题来源 → 区间收缩 → 代入本例 → 编程实现"四步走：

- **问题来源**：由"模型载荷 = 平均载荷"这一平衡条件整理出残差函数 $F(h)$；
- **区间收缩**：二分法要求两端异号。取区间 $[0,3]$：$F(0) = -\bar{F} < 0$，而 $F(3) = 50\times9 - \bar{F} = 450 - \bar{F} > 0$（平均载荷通常只有几十 kN，远小于 450），两端一负一正，必有根。之后每次取中点，异号留左半、否则留右半；
- **代入本例**：以样例 1 为例，$\bar{F} = 18.00$ kN，方程变成 $50h^2 = 18$，即 $h^2 = 0.36$，根为 $h = 0.6$。二分法从 $[0,3]$ 出发，区间长度每步减半，$22$ 次后 $3/2^{22} \approx 7.2\times10^{-7} < 10^{-6}$，得到 $h \approx 0.600000$；
- **编程实现**：残差与求解器分成两个函数 `F` 和 `bisect`，`F` 用 `double fbar` 接收平均载荷，`bisect` 用 `int *pn` 带回对分次数——这样换个模型只改 `F`，求解器原样复用。

### 4. 收尾：释放链表

程序结束前必须把链表上的每个节点 `free` 归还（见练习 11～16）：`while (head != NULL) { p = head; head = head->next; free(p); }`。借了要还，是链表程序的纪律。

## 三、解题思路

1. **建链**：尾插法把 `n` 条记录建成链表，读入 `limit`；
2. **统计**：一次遍历求 `count`、`sum`、`max`、`over`，再算 `mean`；
3. **写方程**：`F(h, fbar) = 50*h*h - fbar`；
4. **写二分**：在 `[0,3]` 上求 `F(h)=0`，用 `int *pn` 带回次数；
5. **输出报表**：六行格式，冰厚保留 6 位；
6. **释放链表**。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

#define C 50.0                       /* 简化冰载荷模型常数，kN/m^2 */

struct IceLoad {
    int    id;
    double load;
    struct IceLoad *next;
};
/* 模型残差 F(h) = C*h^2 - fbar */
double F(double h, double fbar)
{
    return C * h * h - fbar;
}
/* 二分法：在 [a,b] 内求 F(h)=0 的根，对分次数经 pn 带回 */
double bisect(double fbar, double a, double b, double eps, int *pn)
{
    double m; int n = 0;
    while (b - a > eps) {
        m = (a + b) / 2.0; n++;
        if (F(a, fbar) * F(m, fbar) <= 0.0) b = m;   /* 根在左半 */
        else                                 a = m;   /* 根在右半 */
    }
    *pn = n;
    return (a + b) / 2.0;
}

int main(void)
{
    struct IceLoad *head = NULL, *tail = NULL, *p;
    int n, i, id, count, over, nb = 0;
    double load, limit, sum, mean, max, h;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {            /* 尾插建链 */
        scanf("%d %lf", &id, &load);
        p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
        if (p == NULL) { printf("malloc failed\n"); return 1; }
        p->id = id; p->load = load; p->next = NULL;
        if (head == NULL) head = tail = p;
        else { tail->next = p; tail = p; }
    }
    scanf("%lf", &limit);

    count = 0; sum = 0.0; over = 0; max = head->load;
    for (p = head; p != NULL; p = p->next) {   /* 一次遍历统计 */
        count++; sum += p->load;
        if (p->load >= limit) over++;
        if (p->load > max)    max = p->load;
    }
    mean = sum / count;

    h = bisect(mean, 0.0, 3.0, 1e-6, &nb);     /* 二分求等效冰厚 */

    printf("===== 冰区载荷管理小程序 =====\n");
    printf("样本数 = %d\n", count);
    printf("平均载荷 = %.2f kN\n", mean);
    printf("最大载荷 = %.2f kN\n", max);
    printf("超阈样本数(>= %.2f kN) = %d\n", limit, over);
    printf("等效冰厚 = %.6f m (n = %d)\n", h, nb);

    while (head != NULL) { p = head; head = head->next; free(p); }
    return 0;
}
```

## 五、运行验证

**样例 1**：链表 `12 → 24 → 6 → 30`，`limit = 20`。遍历统计：`count = 4`、`sum = 72.00`、`mean = 18.00`、`max = 30.00`、`over = 2`（24 与 30）。代入 $50h^2 = 18$ 得 $h^2 = 0.36$，二分 22 次收敛到 $\sqrt{0.36} = 0.6$，输出：

```
===== 冰区载荷管理小程序 =====
样本数 = 4
平均载荷 = 18.00 kN
最大载荷 = 30.00 kN
超阈样本数(>= 20.00 kN) = 2
等效冰厚 = 0.600000 m (n = 22)
```

与样例 1 一致。**样例 2**：链表 `20 → 40 → 60`，`mean = 40.00`、`max = 60.00`、`over = 3`。代入 $50h^2 = 40$ 得 $h = \sqrt{0.8} = 0.894427$，二分 22 次，输出与样例 2 一致。两个样例的对分次数都是 22，因为区间长度都是 3，与每行载荷的具体数值无关。

## 六、常见错误与讲解

**错误 1：链表建链时丢失链头或断链**

```c
head = p;  p->next = head;   /* 错：头插顺序反了，只剩自环，整条链丢失 */
```
无论头插还是尾插，都要先接好新节点的 `next` 再改 `head`/`tail`。尾插时别忘了 `p->next = NULL`，否则尾节点没有"链结束"标志，会顺着野指针跑飞。

**错误 2：忘记检查 malloc 返回值就使用节点**

```c
p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
p->id = id;                  /* 错：p 可能是 NULL，解引用崩溃 */
```
每次申请后都要 `if (p == NULL)` 检查。本题数据量小、一般不会失败，但工程代码必须守住这条纪律。

**错误 3：二分法区间更新方向写反**

```c
if (F(a,fbar) * F(m,fbar) <= 0.0) a = m;   /* 错：异号说明根在左半，应令 b=m */
if (F(a,fbar) * F(m,fbar) <= 0.0) b = m;   /* 对 */
```
两端异号表示根在 $[a,m]$ 内，要保留左半、把右端点移到中点。方向写反会收敛到错误的一侧。另外区间必须选成两端异号（本题取 $[0,3]$），否则二分法不保证收敛。

**错误 4：忘记 free，内存泄漏**

```c
/* 报表输出完，链表一个节点都没释放 */
```
链表节点是 `malloc` 借来的，程序结束前要逐个 `free`，顺序是"先存 `head->next`，再 `free(head)`"，避免访问已释放的内存。

## 七、与综合实验的衔接

本题把本章的能力完整地串了一遍：**结构体**把"一条记录 / 一组参数"打包，**链表**承载条数动态变化的数据流，**二分法**完成由统计量到物理参数的反求，最后统一输出成工程报表。这三样正是实验 **C6/C7** 载荷管理系统的骨架——采集模块用链表接数据，统计模块沿链遍历求指标，反演模块用二分法由载荷反推冰厚或吃水。做完这一题，你就具备了一张完整的"数据从进到出"的工程流水线：**读入 → 组织（结构体 + 链表）→ 统计 → 建模 → 求解 → 输出**。这也正是本课程"计算思维与问题求解"希望带给你的核心能力——把一个实际工程问题拆成数据、算法与程序三个层面，再逐层落地。
