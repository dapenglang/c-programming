# 题目 A8：基于高斯消元的静定桁架内力求解系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套静定平面桁架内力求解工具。系统读入桁架的节点坐标与杆件连接表、节点荷载工况文件后，把"每个节点两个方向力平衡"写成线性方程组（未知量为各杆内力与支座反力），用列主元高斯消元法求解全部内力；求解前检查主元大小以发现几何可变体系，求解后统计拉杆、压杆与零杆数量，按容许应力筛查超限杆件，绘制内力分布字符图并把结果写入文件。

**解决什么重要问题**：桁架（屋架、桥梁、塔架、施工脚手架）的内力分析是结构选型与杆件截面设计的前提：每根杆受拉还是受压、拉压力多大，决定采用什么型钢与是否需要验算压杆稳定。节点数多时手算节点法（逐节点解联立方程）既慢又易错，计算机求解的标准做法正是"组装平衡方程组 + 高斯消元"；而主元过小意味着体系几何可变或瞬变——不检查就求解会得到荒谬的巨大内力，这是真实结构事故（脚手架坍塌）的数值表现。本系统让学生完整经历"力学建模 → 方程组装 → 数值求解 → 结果校核"链条。

**支撑哪些关键应用**：① 屋架与桥梁桁架的施工图设计内力计算书；② 结构力学求解器等教学软件的核心内核；③ 临时支撑体系（胎架、卸载用临时塔架）验算；④ 后续"结构力学""有限元法基础"课程中，刚度法组装方程与高斯消元求解正是所有结构分析软件的底层流程，本系统是其静定特例。

**与专业培养的关联**：工程力学与结构力学是航建学院各专业的看家课，高斯消元在课程 5.6 节已学。本题目把"节点平衡方程"的力学知识与"矩阵消元"的算法知识在同一程序中结合，学生输出的每根杆内力可用节点法手算复核，形成理论与程序的互相验证。

## 二、题目任务与专业关联

本题目面向工程力学与土木方向学生，模拟"桁架设计内力计算"场景。系统功能概述：① 读入桁架几何文件（节点坐标、约束类型、杆件连接）与荷载工况文件；② 按"每节点 ΣFx=0、ΣFy=0"组装方程组（未知量含支座反力）；③ 列主元高斯消元求解并做主元检查；④ 统计拉/压/零杆并按容许应力筛查超限杆；⑤ 逐杆条形图输出内力分布；⑥ 结果写文件。先导知识铺垫：教师随题发布示例桁架（5 节点 7 杆 + 3 个反力未知量，方程数 10 = 未知数 10，静定）的手算答案，以及组装规则：杆 j 对节点 i 方程的系数为该杆相对该节点的方向余弦 (±cosθ, ±sinθ)，支座反力只在其约束方向出现。学生不接触刚度矩阵等超纲概念。

## 三、数据来源与格式

**数据文件 1：桁架几何文件**（`truss_geo.txt`）

```
节点数5 杆件数7
节点编号,x_m,y_m,约束代码
1,0.0,0.0,FIX       (固定铰：Fx,Fy两个反力)
2,4.0,0.0,ROLLER_Y  (滚动铰：仅Fy反力)
3,8.0,0.0,NONE
4,2.0,3.0,NONE
5,6.0,3.0,NONE
杆件编号,节点i,节点j
1,1,4
2,1,2
3,2,4
4,2,3
5,2,5
6,4,5
7,3,5
```

字段含义：坐标取值 0~20 m（保留 1 位小数）；约束代码仅 FIX/ROLLER_Y/ROLLER_X/NONE 四种；杆件两端节点号必须存在且不相等。

**数据文件 2：荷载工况文件**（`truss_load.txt`）

```
工况号,节点编号,Fx_kN,Fy_kN
1,3,0.0,-40.0
1,5,0.0,-40.0
2,3,10.0,-40.0
2,5,-10.0,-40.0
```

字段含义：Fx 取值 -60~60 kN、Fy 取值 -80~0 kN（向下为负）；每工况 1~4 行，同工况按节点汇总。

**仿真数据生成规则**：
- 以教师示例桁架为基准另生成 2 个变体：跨长 8 m 改 12 m（节点坐标等比放大）、增加下弦节点形成 7 节点 10 杆桁架（自编连接表并保证 m+r=2n）；
- 荷载：工况 1 对称竖向荷载（跨中两下弦节点各 -40 kN）、工况 2 增加水平风荷载 ±10 kN、工况 3 单侧加载（检验不对称内力）；
- 异常注入：在 `truss_geo.txt` 中故意写 `8,1,5`（杆 8 与杆 1 重复连接，1-4 杆重复）与节点 3 坐标写成 `8.0,0.0o`（非法字符），用于训练读入校验；在荷载文件中写 `1,9,0,-10`（节点 9 不存在）。

**真实数据集**：无必需公开数据集；桁架尺寸与荷载参照《钢结构设计标准》GB 50017 的典型屋架例题，教材《结构力学》桁架章节的算例可直接数字化。

## 四、数据结构设计

```c
#define MAX_NODE 15        /* 最大节点数（方程 ≤ 2*MAX_NODE） */
#define MAX_BAR  25        /* 最大杆件数 */
#define MAX_EQN  30        /* 方程维数上限 = 2*MAX_NODE */

/* 节点 */
struct Node {
    double x, y;           /* 坐标 m，0~20 */
    int    fixX, fixY;     /* 约束标志 1 有反力未知量 / 0 无 */
};

/* 杆件 */
struct Bar {
    int    ni, nj;         /* 两端节点编号 1~MAX_NODE */
    double cos, sin;       /* 由坐标计算的方向余弦 */
    double N;              /* 解得内力 kN，拉为正压为负 */
    int    valid;          /* 几何数据合法性标志 */
};

/* 全局数据 */
struct Node g_node[MAX_NODE];
struct Bar  g_bar[MAX_BAR];
int    g_nodeCnt, g_barCnt;

double g_A[MAX_EQN][MAX_EQN];  /* 增广系数矩阵（含右端项列） */
double g_x[MAX_EQN];           /* 解向量：杆内力在前、反力在后 */
int    g_eqnCnt;               /* 方程数 = 2*节点数 */
```

未知量排列约定：前 g_barCnt 个为杆内力（按杆号），其后依次为各节点 fixX、fixY 对应的支座反力；容许应力常量 `SIGMA_ALLOW=215.0`（MPa）、杆件截面 `BAR_AREA=490.0`（mm²，L50×5 角钢）为全局常量。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 桁架几何数据读入模块**（源文件 `GeoIO.c`）

- 功能简介：读入节点数、杆件数、逐节点坐标与约束代码（字符串比较 FIX/ROLLER_Y 等）、逐杆连接表；校验节点号合法、杆端不相等、杆件不重复（对注入的重复杆与非法字符行打印警告并剔除）；按坐标计算每杆方向余弦存入 cos/sin；打印桁架简表。
- 输入：`truss_geo.txt`。
- 输出：`g_node[]`、`g_bar[]`、计数与方向余弦；屏幕读入与校验摘要。

**M2 荷载工况文件读入模块**（源文件 `LoadIO.c`）

- 功能简介：按工况分组读入节点荷载，校验节点号存在与荷载范围（对注入的节点 9 行告警剔除）；支持选择当前计算工况；回显当前工况荷载清单。
- 输入：`truss_load.txt`、工况号。
- 输出：荷载表（内部数组）；屏幕荷载回显。

### 第二部分：算法实现（5 个模块）

**M3 平衡方程组装模块**（源文件 `Assemble.c`）

- 功能简介：按"节点 k 的 ΣFx=0、ΣFy=0"两行方程填充 g_A：杆 j 连接节点 k 时在对应行列写入 ±cos、±sin（背离节点为正方向），支座反力列在约束方向写 1；右端项写入该节点荷载的负值；组装完成打印系数矩阵供人工检查。
- 输入：`g_node[]`、`g_bar[]`、荷载表。
- 输出：`g_A[][]`、`g_eqnCnt`；屏幕矩阵预览。

**M4 高斯消元求解模块**（源文件 `Gauss.c`）

- 功能简介：实现列主元高斯消元：每列选绝对值最大主元并换行、消元、回代，解存 g_x[]；把杆内力回写 g_bar[].N；消元过程打印每轮主元值供观察。
- 输入：`g_A[][]`、`g_eqnCnt`。
- 输出：`g_x[]`、各杆 `N`；屏幕求解完成提示。

**M5 解的有效性检查模块**（源文件 `GaussCheck.c`）

- 功能简介：检查消元中的主元绝对值是否小于 1e-6：是则判定"体系几何可变或数据有误"终止求解并指出可疑自由度；另做平衡复核——把解代回任选 3 个节点方程计算残差，残差 > 1e-3 时提示检查；输出检查报告。
- 输入：`g_A[][]`、`g_x[]`、主元记录。
- 输出：屏幕有效性结论；复核残差表。

**M6 内力分类统计模块**（源文件 `Classify.c`）

- 功能简介：遍历各杆按符号分类：N>1e-6 为拉杆、N<-1e-6 为压杆、其余为零杆；统计三类数量与最大拉力、最大压力杆号；打印分类清单。
- 输入：`g_bar[]`。
- 输出：屏幕分类统计表。

**M7 超限杆件筛查模块**（源文件 `StressCheck.c`）

- 功能简介：逐杆计算应力 σ=|N|×1000/BAR_AREA，与容许应力 215 MPa 比较生成预警名单（含安全度 σ/容许值排序）；压杆另乘 0.6 的简化稳定折减系数再比较；打印超限与接近限值（>80%）名单。
- 输入：`g_bar[]`。
- 输出：屏幕预警名单。

### 第三部分：数据输出（3 个模块）

**M8 内力分布字符图模块**（源文件 `CharPlot.c`）

- 功能简介：逐杆打印条形图：拉杆用 `+` 向右、压杆用 `-` 向左（按最大内力归一化到 1~30 字符），零杆打 `0`；行尾标注内力值与"拉/压/零"标注。
- 输入：`g_bar[]`。
- 输出：屏幕内力分布图。

**M9 结果文件输出模块**（源文件 `Report.c`）

- 功能简介：把桁架几何表、工况荷载、全部杆件内力表（杆号、两端节点、内力、应力、安全度、是否超限）与分类统计写入 `truss_result.txt`。
- 输入：全部全局数据。
- 输出：`truss_result.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读几何 / 读荷载选工况 / 组装方程 / 求解 / 有效性检查 / 分类统计 / 超限筛查 / 内力图 / 输出结果 / 退出），`do-while + switch` 调度；状态约束：组装前必须读入两个文件，求解后才能统计筛查。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1~M9；状态约束：M3 前必须完成 M1、M2；M4 失败（主元过小）时 M6~M9 禁止执行；工况切换后需重新组装与求解。

**数据流**：

```
truss_geo.txt ─► M1 读入校验 ─► g_node[]/g_bar[]（含方向余弦）─┐
truss_load.txt ─► M2 读入选工况 ─► 荷载表 ────────────────────┤
                                                               ▼
                                    M3 组装 g_A[][]（含右端项）
                                                               ▼
                              M5 主元/残差检查 ◄── M4 高斯消元 ─► g_x[] ─► 杆内力 N
                                                               │
                              M6 分类统计 ◄────────────────────┤
                              M7 超限筛查 ◄────────────────────┤
                                                               ▼
                              M8 内力字符图                M9 truss_result.txt
```

模块间通过全局矩阵 `g_A`、解向量 `g_x` 与杆件结构体数组交换数据，组装与消元两个函数的接口编码前书面约定。

## 十、选做扩展

1. 多工况内力包络：对 3 个工况循环求解，输出每杆在所有工况中的最不利内力（最大拉、最大压）表，模拟设计中的内力包络概念（循环复用已有模块 + 最值比较）；
2. 零杆识别规则验证：先用"两杆不共线节点无荷载"等几何规则程序化预判零杆（只用 if 与连接表判断），再与求解结果比对，输出预判正确率；
3. 杆件截面优选实验：把超限杆的 BAR_AREA 逐档增大重算安全度，输出满足容许应力的最小截面档位表（循环 + 阈值判断的组合运用）。
