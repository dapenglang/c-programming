# 题目 D10：基于迭代求解与二分法的反应堆临界尺寸估算系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行反应堆临界尺寸估算工具，围绕"单群扩散理论下球形反应堆的临界条件"这一反应堆物理核心问题展开。系统读入材料的增殖因子 k、中子扩散长度 L 与二分区间、迭代精度等配置，用函数封装材料曲率 $B_m^2=(k-1)/L^2$ 与几何曲率 $B_g^2=(\pi/R)^2$，构造临界方程残差 $f(R)=B_m^2-B_g^2$，用二分法求出使残差为零的临界半径 R，再由 R 换算临界体积与所需核燃料质量，并能改变 k 值批量扫描得到"k—临界半径"曲线。

临界尺寸计算决定了核装置能不能"点得着、稳得住"。如果不解决它，反应堆设计将失去最基本的几何约束——堆芯做小了，中子泄漏超过产生，链式反应无法自持（次临界）；堆芯做大了，虽然能临界，但材料浪费、屏蔽与冷却负担骤增。历史上，早期实验装置正是靠"逐步加料逼近临界"来确定最小可临界尺寸，而每一次加料前的理论估算都来自这一方程。工程上，它直接支撑小堆模块化设计中的堆芯包络尺寸选定、临界安全分析判断，以及核燃料富集度与慢化条件变化的敏感性评估。

本系统支撑的关键应用场景包括：① 反应堆物理课程实验中的最小临界尺寸理论估算，与临界实验数据对照；② 小型模块化反应堆（SMR）堆芯几何包络的初步选型；③ 核临界安全分析中几何尺寸与材料组成搭配的快速核算；④ 不同富集度/慢化剂条件下的堆芯尺寸敏感性研究。本题目与核工程与核技术专业"反应堆物理与核动力"方向直接相关，训练学生把物理方程转化为"参数读入—迭代求解—结果输出"完整程序工程的能力。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的临界尺寸估算系统：从文本文件读入材料参数表（增殖因子 k、中子扩散长度 L）与求解配置（二分区间上下限、迭代精度），把材料曲率与几何曲率各自封装为独立函数，实现临界方程残差函数 $f(R)=B_m^2-B_g^2$，用二分法在给定区间内求临界半径 R；再用简单迭代法反复修正扩散长度 L 直到相邻两次结果的差小于精度，得到自洽解；随后改变 k 值批量重复求解，输出"k—临界半径—临界体积—燃料质量"表与临界尺寸曲线。

专业关联上，本题目复现了反应堆物理课程实验的最小临界尺寸估算、堆芯初步选型的几何包络核算、临界安全分析中几何与材料的搭配判断三类真实业务的核心计算。学生在此过程中将掌握课程中的函数封装与参数传递、二分法求根、不动点迭代、循环与选择结构、一维数组与文件读写，并第一次把"一个物理判据如何变成一套求解程序"完整地走一遍。

## 三、数据来源与格式

- **数据文件格式**：材料参数表采用纯文本格式，首行为标题说明，其后每行一条材料记录。字段依次为：材料名（无空格字符串）、增殖因子 k（无量纲）、中子扩散长度 L（单位：厘米 cm）。配置文件另给出二分区间上下限（cm）、迭代精度（cm）与扫描点个数。

```
# material      k       L_cm
UO2-H2O         1.32     5.80
UO2-H2O-LEU     1.18     7.40
MOX-H2O         1.09     9.20
UO2-D2O         1.45     3.10
UO2-GRAPHITE    1.06     6.60
```
```
# R_low_cm  R_high_cm  tol_cm  scan_num
10.0        300.0      0.001   9
```

- **仿真数据生成规则**：
  - 材料名：取 3～15 个字母、数字与短横线组成的字符串，无空格，如 `UO2-H2O`、`UO2-D2O`。
  - 增殖因子 k：无量纲，取值范围 1.01～1.50，按 [1.01, 1.50] 上的均匀分布生成（必须严格大于 1，否则系统无可临界解，需在校验中剔除）。
  - 中子扩散长度 L：单位 cm，取值范围 2.0～10.0，按均匀分布生成；轻水慢化堆典型 2～6 cm，重水与石墨慢化堆典型 6～10 cm。
  - 二分区间下界：单位 cm，取值 10.0，必须使残差 $f(R_{low})>0$（下界偏小，几何曲率大）。
  - 二分区间上界：单位 cm，取值 300.0，必须使残差 $f(R_{high})<0$（上界偏大，几何曲率小）；典型临界半径落在 30～150 cm。
  - 迭代精度 tol：单位 cm，取值范围 1.0e-4～1.0e-2，全表共用。
  - 扫描点个数：1～15 个，扫描时 k 在 [1.05, 1.50] 上等间隔取值。
  - **异常值注入方式**：由教师提供的生成程序人为注入四类错误。其一，k 字段填 0.95 或 1.00 等不大于 1 的值，此类材料在本模型下不存在临界解，需判为无效并剔除；其二，L 字段填 0 或负数（如 `-4.5`），会导致材料曲率计算除零或符号错误，需剔除；其三，二分区间上下界的残差同号（如上下界都取 10.0 与 20.0），二分法无解，需在求解前检测并提示"区间未包围根"；其四，配置文件中精度填 0 或负数，会导致死循环，需判为非法并取默认值 1.0e-3。校验模块需输出"行号—异常类型—处理动作"清单。

- **真实数据集（如有）**：单群扩散理论的临界条件与曲率平衡判据可参考反应堆物理教材（如谢仲生《核反应堆物理分析》）中"单群扩散理论与临界方程"章节，材料曲率与几何曲率的定义为标准结论。学生**无需下载**真实数据文件，课程提供与上述字段含义对应的简化仿真数据表；表中"增殖因子 k"对应无限介质增殖因子 $k_\infty$，"中子扩散长度 L"对应单群模型中的扩散长度 $L=\sqrt{D/\Sigma_a}$。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_MAT      20      /* 最多材料条目数 */
#define MAX_MATNAME  20      /* 材料名最大长度（含结束符） */
#define MAX_SCAN     15      /* 参数扫描最大点数 */
#define PI_VALUE     3.14159265358979  /* 圆周率 */

/* ===== 材料参数结构体 ===== */
struct Material {
    char   name[MAX_MATNAME];   /* 材料名，如 "UO2-H2O" */
    double k;                   /* 增殖因子，无量纲，须 > 1.0 才有解 */
    double L;                   /* 中子扩散长度，单位：cm，须 > 0 */
    int    valid;               /* 有效标志：1 有效，0 已判为异常剔除 */
};

/* ===== 求解配置结构体 ===== */
struct SolveCfg {
    double rLow;                /* 二分区间下界，单位：cm，残差应 > 0 */
    double rHigh;               /* 二分区间上界，单位：cm，残差应 < 0 */
    double tol;                 /* 迭代精度，单位：cm，如 1.0e-3 */
    int    scanNum;             /* 参数扫描点数，1~15 */
};

/* ===== 临界求解结果结构体 ===== */
struct CritResult {
    int    matIdx;              /* 对应材料在 g_mat[] 中的下标 */
    double bm2;                 /* 材料曲率 Bm²，单位：1/cm²，=(k-1)/L² */
    double rCrit;               /* 临界半径 R，单位：cm */
    double volCrit;             /* 临界体积，单位：cm³，=(4/3)πR³ */
    double sArea;               /* 临界表面积，单位：cm²，=4πR² */
    int    iterCount;           /* 二分迭代轮数 */
    int    flag;                /* 收敛标志：1 收敛，0 未收敛 */
};

/* ===== 参数扫描点 ===== */
struct ScanPoint {
    double k;                   /* 本次扫描用的 k 值 */
    double rCrit;               /* 对应的临界半径，单位：cm */
    double volCrit;             /* 对应的临界体积，单位：cm³ */
};

/* ===== 全局数据区 ===== */
struct Material   g_mat[MAX_MAT];       /* 材料参数表 */
int               g_matCount;           /* 读入材料条数 */
int               g_validMatCount;      /* 有效材料条数 */
struct SolveCfg   g_cfg;                /* 求解配置 */
struct CritResult g_result[MAX_MAT];    /* 各材料的临界求解结果 */
struct ScanPoint  g_scan[MAX_SCAN];     /* 参数扫描结果 */
int               g_scanCount;          /* 实际扫描点数 */
int               g_loaded, g_solved;   /* 流程状态标记 */
struct LogItem {                        /* 处理日志，供报表模块使用 */
    char op[24];                        /* 操作名，如 "BISECT_RADIUS" */
    char detail[64];                    /* 参数与关键结果摘要 */
};
struct LogItem g_log[MAX_MAT * 4];
int            g_logCount;              /* 已记录日志条数 */
```

辅助说明：材料参数用结构体数组组织（课程 7.1/7.2），求解配置与结果分别用独立结构体封装，便于整体作为函数参数传递（课程 7.3）；临界结果与扫描结果用结构体数组缓冲（课程 5.1）。曲率与残差全部封装为独立函数，通过函数返回值传递（课程 4.1/4.3），主控流程不直接写公式。
## 五、功能模块拆解（共 11 个模块）
### 第一部分：数据读入（2 个模块）

**M1 材料参数读入模块**（源文件 `MatIO.c`）
- 功能简介：打开材料参数文本文件，跳过首行标题，用循环 + `fscanf` 逐行读入材料名、增殖因子 k 与中子扩散长度 L，填充全局材料表，记录读入条数；同时做基础校验——k 必须严格大于 1.0、L 必须为正，不满足者置 `valid=0` 并打印"行号—异常类型—处理动作"清单；文件不存在时给出明确提示。
- 输入：文件路径（菜单输入，默认 `materials.txt`）。
- 输出：填充后的 `g_mat[]`、`g_matCount`、`g_validMatCount`；屏幕校验报告。
**M2 求解配置读入模块**（源文件 `MatIO.c`）
- 功能简介：读入配置文件中的二分区间下界与上界、迭代精度与扫描点数；做范围检查（下界 ≥ 1.0、上界 > 下界、精度在 [1.0e-6, 1.0e-1] 内、扫描点数 1～15），越界时给出提示并取默认值；读入后用残差函数检查区间是否包围根，未包围则提示用户调整区间。
- 输入：配置文件路径（默认 `crit_config.txt`）。
- 输出：`g_cfg`；屏幕确认信息与区间包围性检查结果。
### 第二部分：算法实现（5 个模块）

**M3 材料曲率计算模块**（源文件 `CritEq.c`）
- 功能简介：实现材料曲率函数 `double matCurvature(double k, double L)`，返回 $B_m^2=(k-1)/L^2$，单位 1/cm²；对非法输入（k ≤ 1.0 或 L ≤ 0）返回 -1.0 并打印提示；另提供按材料下标调用的封装 `double matCurvatureByIdx(int idx)`。
- 输入：增殖因子 k、扩散长度 L（cm），或材料下标。
- 输出：返回材料曲率（1/cm²）；非法输入返回 -1.0。
**M4 几何曲率计算模块**（源文件 `CritEq.c`）
- 功能简介：实现几何曲率函数 `double geoCurvature(double R)`，返回球形几何的 $B_g^2=(\pi/R)^2$，单位 1/cm²；对 R ≤ 0 返回 -1.0 并提示；函数内部用 `pow` 求 π/R 的平方，与直接乘法写法做对照。
- 输入：半径 R（cm）。
- 输出：返回几何曲率（1/cm²）；非法输入返回 -1.0。
**M5 临界方程残差计算模块**（源文件 `CritEq.c`）
- 功能简介：实现残差函数 `double critResidual(int matIdx, double R)`，返回 $f(R)=B_m^2-B_g^2$，内部调用 M3 与 M4 得到两个曲率；残差为零即临界。另提供 `int bracketCheck(int matIdx)` 判断给定区间上下界的残差是否异号，为二分法提供前置条件检查。
- 输入：材料下标、半径 R（cm）。
- 输出：返回残差（1/cm²）；`bracketCheck` 返回 1 表示区间包围根，0 表示未包围。
**M6 二分法求临界半径模块**（源文件 `Bisect.c`）
- 功能简介：在 `[rLow, rHigh]` 上用二分法求 $f(R)=0$ 的根得到临界半径 R：每轮取区间中点，按中点残差符号收缩区间，直到区间宽度小于 `tol` 或轮数超过 200 轮；输出每轮的区间上下界、中点与中点残差，便于观察收敛过程；保存迭代轮数与收敛标志到 `g_result[]`。
- 输入：材料下标、`g_cfg`。
- 输出：临界半径 R（cm）、迭代轮数、收敛标志；屏幕每轮迭代明细。
**M7 简单迭代求自洽解模块**（源文件 `Iterate.c`）
- 功能简介：用简单（不动点）迭代修正扩散长度 L 直到自洽：按 $L_{new}=\sqrt{D/\Sigma_a}$ 的单群关系与上一轮临界半径共同更新 L，再调用 M6 重求 R，直到相邻两次临界半径之差小于 `tol` 为止，迭代上限 100 轮；不收敛时输出"已达迭代上限"提示并返回最后一轮结果。
- 输入：材料下标、上一轮临界半径、`g_cfg`。
- 输出：自洽的临界半径 R（cm）与迭代轮数；屏幕迭代收敛曲线摘要。
### 第三部分：数据输出（4 个模块）

**M8 参数扫描计算模块**（源文件 `Scan.c`）
- 功能简介：把 k 在 `[1.05, 1.50]` 上等间隔取 `g_cfg.scanNum` 个值，对每个 k 值（沿用第一条有效材料的 L）重跑 M6 与 M7，把 k、临界半径、临界体积存入 `g_scan[]`；扫描点超过 `MAX_SCAN` 时自动截断并提示。
- 输入：`g_cfg.scanNum`、材料 L、`g_cfg`。
- 输出：`g_scan[]` 与 `g_scanCount`；屏幕扫描进度摘要。
**M9 临界尺寸表输出模块**（源文件 `CritReport.c`）
- 功能简介：遍历全部有效材料，打印"材料名—k—L—Bm²—临界半径—临界体积—表面积—迭代轮数"表，并给出该材料相对第一条材料的临界半径变化率，便于比较不同慢化条件对堆芯尺寸的影响；同时按半径大小分"小型（< 50 cm）/ 中型（50～100 cm）/ 大型（> 100 cm）"三档标注。
- 输入：`g_mat[]`、`g_result[]`、`g_validMatCount`。
- 输出：屏幕临界尺寸对照表与分档标注。
**M10 临界尺寸曲线与结果文件输出模块**（源文件 `CritReport.c`）
- 功能简介：把 `g_scan[]` 中的 k—临界半径数据用 `#` 字符画成横向曲线（横轴为临界半径，纵轴为 k，按比例缩放），并写出 `crit_result.csv`（材料—k—L—临界半径—临界体积）与 `crit_scan.txt`（k 扫描表）；文件首行写列名。
- 输入：`g_scan[]`、`g_scanCount`、`g_mat[]`、`g_result[]`。
- 输出：屏幕字符曲线图；`crit_result.csv`、`crit_scan.txt`。
**M11 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：用 `do-while + switch` 调度 M1～M10，用状态标记 `g_loaded`、`g_solved` 约束"必须先读入材料参数与配置才能求解"；菜单含读入材料、读入配置、单材料求解、自洽迭代求解、参数扫描、尺寸表、曲线与文件输出、退出共 8 项。
- 输入：用户菜单选项。
- 输出：调度各模块；屏幕菜单与状态提示。
## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环，先用状态标记 `g_loaded` 约束流程——未读入材料参数与求解配置时只允许执行 M1/M2；读入后必须先用 M5 的 `bracketCheck` 确认区间包围根，才能调用 M6 二分求解；M6 收敛后开放 M7 自洽迭代与 M8 参数扫描。任何求解模块要求 `g_validMatCount > 0`，否则提示先执行 M1 并重新读入。
**数据流**：

```
materials.txt ─► M1 材料读入 ─► g_mat[]（k, L）
                                      │
crit_config.txt ─► M2 配置读入 ─► g_cfg（区间, 精度） 
                                      │
                    ┌─────────────────┼──────────────────┐
                    ▼                 ▼                  ▼
            M3 材料曲率 Bm²     M4 几何曲率 Bg²    M5 残差 f(R)=Bm²-Bg²
                    └────────┬────────┘                  │
                             ▼                           ▼
                    M6 二分求临界半径 ──► R, 迭代轮数  区间包围性检查
                             │
                             ▼
                    M7 简单迭代求自洽解（修正 L 重求 R）
                             │
              ┌──────────────┼───────────────┐
              ▼              ▼               ▼
      M8 参数扫描 k     M9 临界尺寸表    M10 曲线与结果文件
              │              │               │
              └──────────────┴───────────────┘
                             ▼
                    M11 主控菜单（调度全部模块）
```

所有模块之间只通过全局材料表、全局结果数组、全局扫描数组与函数参数交换数据，函数头部（接口）在编码前由全组书面约定；曲率与残差一律通过函数返回值传递，不在主控中重复写公式。
