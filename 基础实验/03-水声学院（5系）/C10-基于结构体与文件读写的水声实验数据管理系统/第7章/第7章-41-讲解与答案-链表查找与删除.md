## 二、预备知识：链表查找与删除的基本原理（零基础阅读）

### 1. 问题是怎么来的

删除一条测点记录，链表怎么做？节点是散落在内存各处的，靠 `next` 挂钩相连。要摘掉中间某个节点，必须让**它的前驱**绕过它、直接牵住**它的后继**：

```
删除前：  prev ──→ p ──→ 后继
删除后：  prev ──→ 后继        （p 被摘下并 free）
```

而"找到前驱"的办法只有一个：查找时就**带着前驱一起走**——这就是双指针。

### 2. 双指针查找

```c
struct Node *p = head, *prev = NULL;
while (p != NULL && strcmp(p->id, key) != 0) {
    prev = p;         /* 前驱跟上 */
    p = p->next;      /* 当前再走一步 */
}
```

循环结束时：`p == NULL` 表示没找到；否则 `p` 命中、`prev` 是它的前驱（`p` 是头节点时 `prev == NULL`）。

### 3. 删除的两种情况

**情况一：删除的是头节点**（`prev == NULL`）。它没有前驱，让 `head` 直接接管后继：

```c
head = p->next;
free(p);
```

**情况二：删除的是中间/尾节点**。让前驱越过目标：

```c
prev->next = p->next;
free(p);
```

尾节点删除后，`prev->next` 自然成为 `NULL`，链表正确收尾，无需特判。

```
样例 1 删除 S02 的内存图：

删除前：head→S01 ─→ S02 ─→ S03 ─→ S04→NULL
                     ↑命中
删除动作：S01.next = S03（prev->next = p->next），free(S02)
删除后：head→S01 ─→ S03 ─→ S04→NULL
```

### 4. 用本例走一遍

样例 1：链 `S01→S02→S03→S04`，删 `S02`。双指针走到 `p=S02, prev=S01`，命中。`S01->next = S02->next = S03`，`free`。遍历得 S01、S03、S04，剩 3 个——与样例一致。

样例 2：删 `S01`（头节点）。`p=S01, prev=NULL`，走 `head = p->next = S02`，`free`。剩 S02、S03——与样例一致。

样例 3：`p` 一路走到 `NULL` 未命中，输出"未找到"。

> **这套逻辑在综合实验中反复出现**：C10 的"链表删除与有序插入"（M6）由本练习的删除 + 练习 40 的建链合成；"链表查找与修改"（M5）则把本练习的查找命中分支从"删除"换成"改写成员"。查找骨架学会一次，改、删、插全通。

## 三、解题思路

1. 尾插法按录入顺序建链；
2. 双指针查找目标编号；
3. 按"头节点 / 中间尾节点 / 未找到"三种情况分别处理；
4. 遍历输出剩余节点并计数。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Node {
    char id[16];       /* 测点编号 */
    double depth;      /* 水深 m */
    struct Node *next;
};

int main(void)
{
    struct Node *head = NULL, *tail = NULL, *p, *q, *prev;
    char id[16], key[16];
    double depth;
    int n, i, cnt = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {                 /* 尾插法建链（保序） */
        scanf("%s %lf", id, &depth);
        p = (struct Node *)malloc(sizeof(struct Node));
        strcpy(p->id, id);
        p->depth = depth;
        p->next = NULL;
        if (head == NULL) {                   /* 空链：头尾都是它 */
            head = tail = p;
        } else {                              /* 挂到尾后，尾指针后移 */
            tail->next = p;
            tail = p;
        }
    }

    scanf("%s", key);                         /* 待删除编号 */

    p = head;  prev = NULL;                   /* 双指针查找 */
    while (p != NULL && strcmp(p->id, key) != 0) {
        prev = p;
        p = p->next;
    }

    if (p == NULL) {
        printf("未找到该测点\n");
    } else {
        if (prev == NULL) {                   /* 删头节点 */
            head = p->next;
        } else {                              /* 删中间/尾节点 */
            prev->next = p->next;
        }
        free(p);

        for (p = head; p != NULL; p = p->next) {
            printf("%-9s%9.2f\n", p->id, p->depth);
            cnt++;
        }
        printf("剩余 %d 个节点\n", cnt);
    }

    p = head;
    while (p != NULL) {                       /* 释放剩余节点 */
        q = p->next;
        free(p);
        p = q;
    }
    return 0;
}
```

```

S04 9.8
S02
S01          15.50
S03          22.00
S04           9.80

```

**样例 2**（删头节点）：

```
3

S03 22.0
S01
S02          18.20
S03          22.00
剩余 2 个节点
```

**样例 3**（未找到）：

```
2

S09
未找到该测点
```

| 样例 | 验证点 | 程序输出 |
|---|---|---|
| 1 | 中间摘除，链保持 S01→S03→S04 | ✓ |
| 2 | 头节点特判，head 正确后移 | ✓ |
| 3 | 查到 NULL，输出未找到 | ✓ |

**反例验证**：删掉样例 2 的头节点特判（`if (prev == NULL)` 分支），程序会对 `NULL->next` 解引用而**崩溃**——头节点删除必须单独处理。

## 六、常见错误与讲解

**错误 1：漏判头节点**

```c
prev->next = p->next;   /* 错：prev 为 NULL（删头）时直接崩溃 */
```

**错误 2：`free` 后继续用 `p`**

```c
free(p);
p = p->next;        /* 错：已释放的内存不可读 */
/* 对：先记 q = p->next，再 free(p)，p = q */
```

**错误 3：尾插法忘更新 `tail`**

```c
tail->next = p;     /* 错：只挂不后移，下一个新节点会盖在老位置 */
tail->next = p; tail = p;   /* 对：挂完尾指针跟过去 */
```

**错误 4：字符串比较用 `==`**

```c
if (p->id == key)            /* 错：比的是地址，永远不等 */
if (strcmp(p->id, key) == 0) /* 对：逐字符比较内容 */
```
