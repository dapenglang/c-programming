# 第 5 章 练习 04　阻力方差与标准差

**对应章节**：5 批量数据处理方法（5.1 一维数组——多遍遍历；3.3 循环结构；2.3 运算符）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷序列离散程度统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

两段拖曳试验的平均阻力都是 16.0 kN，但第一段数据始终在 15~17 kN 之间平稳波动，第二段却在 5~30 kN 之间剧烈起伏——**平均值相同，安全含义天差地别**。衡量"数据围绕均值波动剧烈程度"的量是**方差**与**标准差**：方差是各数据与均值之差的平方的平均，标准差是方差的算术平方根。它们是冰载荷统计中最基本的离散性指标，直接决定结构安全系数的取值。计算上有个必须注意的细节：均值要先算出来，才能算每个数据对均值的偏差——所以**至少要遍历数组两遍**。

## 二、任务要求

编写一个完整程序 `load_variance.c`：

1. 读入数据个数 `n`（`int`，**$2 \le n \le 100$**），再读入 $n$ 个阻力值存入长度为 100 的 `double` 数组（单位：kN）；
2. 第一遍遍历：累加求和并计算均值 $\bar{x}$；
3. 第二遍遍历：累加各数据与均值之差的平方，计算**总体方差**
$$
\sigma^2 = \frac{1}{n}\sum_{i=0}^{n-1}(x_i - \bar{x})^2
$$
4. 输出均值、方差、标准差（标准差 = 方差的平方根，用 `sqrt` 函数，需包含 `math.h`），三者均保留 **4 位小数**。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个实数，以空格分隔。

**输出**：三行，格式如下：
```
mean = 均值
var  = 方差
std  = 标准差
```

## 四、样例

**样例 1**

输入：
```
5
14.0 16.0 15.0 17.0 18.0
```
输出：
```
mean = 16.0000
var  = 2.0000
std  = 1.4142
```

**样例 2**

输入：
```
4
12.0 14.0 16.0 18.0
```
输出：
```
mean = 15.0000
var  = 5.0000
std  = 2.2361
```

## 五、提示

1. 计算流程是"均值先行"：
$$
\bar{x} = \frac{1}{n}\sum_{i=0}^{n-1} x_i, \qquad
\sigma^2 = \frac{1}{n}\sum_{i=0}^{n-1}(x_i - \bar{x})^2, \qquad
\sigma = \sqrt{\sigma^2}
$$
2. 求平方根用数学库函数 `sqrt(x)`，文件开头写 `#include <math.h>`；
3. 两遍遍历**缺一不可**：偏差 $(x_i - \bar{x})$ 中的 $\bar{x}$ 依赖全部数据，读入的同时就算方差是不可能的；
4. 累加平方时写 `s2 += (r[i] - avg) * (r[i] - avg);`，两个相同因式相乘即可，不必调用 `pow`；
5. 输出用 `%.4f` 保留 4 位小数。

**完成本练习后你将具备的能力**：理解"多遍遍历"的必要性与写法、在数组上实现两阶段统计（先均值后偏差）、使用 `math.h` 中的 `sqrt`——实验 C7 统计模块的离散性指标就由本练习完整实现。
