## 二、预备知识：二维坐标与线性序号互换的基本原理（零基础阅读）

### 1. 问题是怎么来的

计算机内存是"一条线"，本质是一维的。可迷宫、棋盘、图像都是二维的。要在内存里存一张二维网格，就得把二维**拉直**成一维：一行接一行地排下去。

于是同一个格子有了两个"名字"：

- 人看的是**行列坐标** $(r, c)$：第 $r$ 行、第 $c$ 列；
- 机器看的是**线性序号** $idx$：拉直以后它是第几个。

例如一个 4 行 8 列的网格，第 0 行排在前 8 个位置，第 1 行排在第 8～15 个位置……这就是两种表示需要互换的原因。

### 2. 公式是怎么来的

要求 $(r, c)$ 的线性序号，分两部分想：

- **前面整行有多少格**：$r$ 是第 $r$ 行（从 0 数起），在它前面一共有 $r$ 整行，每行 $COLS$ 个格子，共 $r \times COLS$ 个；
- **本行内偏移多少格**：在本行里它是第 $c$ 列，前面还有 $c$ 个格子。

两部分相加：

$$
idx = r \times COLS + c
$$

反过来，已知 $idx$ 想还原坐标，用整数除法与取余：

$$
r = idx \div COLS, \qquad c = idx \bmod COLS
$$

（$idx \div COLS$ 表示整除，$idx \bmod COLS$ 表示取余数。）

### 3. 用本例走一遍

设 $COLS = 8$。

**例 1**：$(r, c) = (1, 3)$。

$$
idx = 1 \times 8 + 3 = 8 + 3 = 11
$$

**例 2**：$(r, c) = (3, 7)$。

$$
idx = 3 \times 8 + 7 = 24 + 7 = 31
$$

验算：4 行 8 列共 32 格，序号 0～31，最后一行最后一列正好是 31，说明换换算正确。

### 4. 编程时怎么用它

编程只需一行：`idx = r * COLS + c;`。三个量都是整数，用 `int` 即可，不涉及除法陷阱。**唯一要记住的是编号从 0 开始**——第 1 行在程序里是第 0 行，这与数学课上"第一行是第 1 行"的习惯不同。

> **这个思想在综合实验中反复出现**：B4 迷宫网格（坐标→序号）、B5 导航邻接矩阵（二维→一维存储）、B1 图像像素（行、列→线性地址），都是"二维拉直"同一个套路。

## 三、解题思路

1. **确定常量**：迷宫每行 8 列，定义 `const int COLS = 8;`；
2. **确定变量**：行号 `r`、列号 `c`、序号 `idx` 都是整数，用 `int`；
3. **读入**：`scanf("%d %d", &r, &c);`；
4. **换算**：`idx = r * COLS + c;`，再用一条 `printf` 把坐标和序号一起输出。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const int COLS = 8;   /* 迷宫每行的格子数（列数） */

    int r, c;   /* 输入：格子的行号、列号，均从 0 开始 */
    int idx;    /* 输出：该格拉直后的线性序号 */

    /* 读入行、列坐标 */
    scanf("%d %d", &r, &c);

    /* 二维坐标换算为一维线性序号：前面整行 + 本行内偏移 */
    idx = r * COLS + c;

    /* 输出：坐标与序号一并显示 */
    printf("(%d,%d) -> idx = %d\n", r, c, idx);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 1 3 | 1×8 + 3 = 11 | `(1,3) -> idx = 11` ✓ |
| 3 7 | 3×8 + 7 = 31 | `(3,7) -> idx = 31` ✓ |
| 0 0 | 0×8 + 0 = 0（起点格） | `(0,0) -> idx = 0` ✓ |
| 2 5 | 2×8 + 5 = 21 | `(2,5) -> idx = 21` ✓ |

起点 $(0,0)$ 序号为 0，末点 $(3,7)$ 序号为 31，符合"从 0 编号"的规则。

## 六、常见错误与讲解

**错误 1：把列数写成行数（最典型）**

```c
idx = r * 4 + c;      /* 错：4 是行数，不是列数 */
idx = r * COLS + c;   /* 对：前面整行每行有 COLS 个格子 */
```

"每行多少格"是**列数**，这个数才是乘的对象，切勿与行数混淆。

**错误 2：算成 c * COLS + r**

```c
idx = c * 4 + r;      /* 错：这是按列拉直，与本题按行拉直不符 */
idx = r * COLS + c;   /* 对 */
```

按行拉直时是"行数乘列数、再加列号"，颠倒过来就是另一种编号规则，结果全错。

**错误 3：从 1 开始编号**

```c
idx = (r + 1) * COLS + (c + 1);  /* 错：C 语言数组下标从 0 开始 */
idx = r * COLS + c;              /* 对 */
```

题目已经说明 $r, c$ 从 0 开始，直接代入公式即可。

**错误 4：scanf 格式串少了分隔或类型不符**

```c
scanf("%d%d", &r, &c);   /* 对：%d%d 之间可省略空格，scanf 自动跳空白 */
scanf("%lf %lf", &r, &c);/* 错：r、c 是 int，应该用 %d */
```
