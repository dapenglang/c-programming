# 第 5 章 练习 02　阻力序列统计量

**对应章节**：5 批量数据处理方法（5.1 一维数组——遍历、打擂台求最值；3.3 循环结构；2.3 运算符）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷序列基本统计量计算"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

船模池试验得到一段阻力序列后，工程师最关心三个数字：**总阻力**（评估平均功耗）、**峰值阻力**（校核结构强度与推进器选型）、**谷值阻力**（判断低载工况）。在数组没有引入之前，第 3 章我们用循环"读一个丢一个"也能求和，但那样**无法再回头找最值**——峰值必须等全部数据都在手边才能确定。把序列存入数组后，一遍循环累加求和，一遍循环"打擂台"找最大值及其位置、最小值及其位置，就构成了实验 C7 统计模块的核心。

## 二、任务要求

编写一个完整程序 `load_stats.c`：

1. 读入数据个数 `n`（`int`，**$1 \le n \le 100$**），再读入 $n$ 个阻力值存入长度为 100 的 `double` 数组（单位：kN）；
2. 用循环累加求出总和 `sum` 与平均值 `avg = sum / n`；
3. 用"打擂台"方法遍历数组，找出最大值、最小值，并**同时记录它们的位置**（位置按数据序号输出，即从 1 开始）；若最大值或最小值出现多次，记录**最先**出现的那个；
4. 按样例格式输出总和（2 位小数）、平均值（2 位小数）、最大值及其位置、最小值及其位置。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个实数，以空格分隔。

**输出**：四行，格式如下（数值均保留 2 位小数，位置为整数）：
```
sum = 总和
avg = 平均值
max = 最大值 (第 p 位)
min = 最小值 (第 q 位)
```

## 四、样例

**样例 1**

输入：
```
6
15.2 18.7 12.4 20.1 16.8 13.5
```
输出：
```
sum = 96.70
avg = 16.12
max = 20.10 (第 4 位)
min = 12.40 (第 3 位)
```

**样例 2**

输入：
```
5
8.5 8.5 8.5 8.5 8.5
```
输出：
```
sum = 42.50
avg = 8.50
max = 8.50 (第 1 位)
min = 8.50 (第 1 位)
```

## 五、提示

1. 总和与平均：
$$
\text{sum} = \sum_{i=0}^{n-1} r_i, \qquad \text{avg} = \frac{\text{sum}}{n}
$$
2. "打擂台"求最值：先假定第 1 个数据（`r[0]`）是最大值，随后每个新数据与当前擂主比较，更大则**取代擂主并记下它的位置**；最小值同理反向比较；
3. 最大值与最小值的擂台可以放在**同一个循环**里同时进行；
4. 位置就用当前下标：擂主存放在 `r[i]` 时，其序号是 `i + 1`；
5. 均值是实数除法，`sum / n` 中 sum 为 `double` 即可，无需担心整数除法。

**完成本练习后你将具备的能力**：在数组上完成"累加"与"打擂台"两类经典遍历、最值与位置的同步记录、理解"先存储后统计"相对"读一个算一个"的本质优势——这四件套是实验 C7 统计模块以及一切数据分析程序的通用骨架。
