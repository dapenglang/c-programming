# 第 5 章 练习 12　网格行列聚合分析

**对应章节**：5 批量数据处理方法（5.2 二维数组——行列两个方向的遍历；3.3 循环结构；2.4 标准输入输出）

**场景来源**：综合实验 C9《冰面压力场热点分析系统》（水声学院）——本练习是该实验中"沿行聚合与沿列聚合"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

压力网格的统计并不总是"只按行"。沿冰面某一方向布置的一排测点构成"行"，把它们相加得到**行和**，反映该方向上一条测线的总压力量级；沿垂直方向布置的一列测点构成"列"，把每一列相加得到**列和**，反映另一方向上一条测线的总压力量级。行和、列和是工程上最常用的两种聚合量，也是画柱状分布图、判断载荷集中区的直接依据。本练习在同一张网格上**同时**做行、列两个方向的聚合。

## 二、任务要求

编写一个完整程序 `grid_aggregate.c`：

1. 从键盘读入行数 `m` 与列数 `n`（**题目保证 $1 \le m \le 20$、$1 \le n \le 20$**），声明二维数组 `double p[20][20]` 存放压力值（kPa）；
2. 双重循环读入 $m \times n$ 个压力值；
3. 用一维数组 `double rowSum[20]` 存放**每行之和**（共 $m$ 个），用一维数组 `double colSum[20]` 存放**每列之和**（共 $n$ 个）；
4. 先输出行和，再输出列和，各占一行。

## 三、输入输出格式

**输入**：第一行两个整数 $m$、$n$；随后 $m$ 行，每行 $n$ 个实数（空格分隔）。

**输出**：共 2 行。第 1 行以 `行和:` 开头，后接 $m$ 个行和；第 2 行以 `列和:` 开头，后接 $n$ 个列和。每个数值保留 **2 位小数**，相邻数值之间用一个空格分隔，行末不加多余空格。

## 四、样例

**样例 1**

输入：
```
3 4
101.0 102.0 103.0 104.0
105.0 106.0 107.0 108.0
109.0 110.0 111.0 112.0
```
输出：
```
行和: 410.00 426.00 442.00
列和: 315.00 318.00 321.00 324.00
```

**样例 2**

输入：
```
2 3
98.5 99.5 100.0
101.0 102.0 103.0
```
输出：
```
行和: 298.00 306.00
列和: 199.50 201.50 203.00
```

## 五、提示

1. **行和**：先遍历行、再遍历列，边遍历边把 `p[i][j]` 累加进 `rowSum[i]`。第 $i$ 行行和公式为

$$
\text{rowSum}_i = \sum_{j=0}^{n-1} p[i][j]
$$

2. **列和**：把所有行的同一列元素加起来。第 $j$ 列列和公式为

$$
\text{colSum}_j = \sum_{i=0}^{m-1} p[i][j]
$$

3. 注意列和的遍历顺序——外层走列 `j`、内层走行 `i`，或先按行优先把每一行累加进"对号入座"的列累加器，两种写法都行，但都要保证 `colSum[j]` 累加的确实是第 $j$ 列；
4. 输出时用循环控制空格：**先输出第 1 个数值，之后每个数值前先打印一个空格**，这样行末不会多出空格。

**完成本练习后你将具备的能力**：在同一张二维表上执行行、列两个方向的聚合遍历、把二维统计结果落到一维数组、组织"带固定标签、空格分隔"的一行输出——这些是实验 C9 中"载荷聚合与分布分析模块"的地基。
