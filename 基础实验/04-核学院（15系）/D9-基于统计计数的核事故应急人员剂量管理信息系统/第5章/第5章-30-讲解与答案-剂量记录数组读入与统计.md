## 二、预备知识：数组与"一遍遍历能得什么"（零基础阅读）

### 1. 问题是怎么来的

前几个练习处理数据都是"读一个、用掉、丢掉"：累加器只需要当前这一笔和总和，所以不必保存。但**求平均值**就不行了——必须知道所有数的和与个数；**求最大值**更麻烦——必须把每个数和"目前为止的最大者"比一遍。

假如数据是"边读边丢"的，读到第 5 个数时，程序早已不记得第 1 个数是多少，**没有任何办法回头再比一次**。所以必须先把数据**整体留下来**。存放一组同类型数据的地方，就是**数组**。

```c
double d[60];      /* 一块能装 60 个 double 的连续空间：d[0], d[1], ..., d[59] */
```

把它想成一排 60 个编了号的小格子，格子编号（下标）从 0 开始。**第 i 个人的剂量放进 `d[i-1]`**——这个"下标从 0 起"是 C 语言最容易踩的坑，务必记牢。

### 2. 最值怎么求：为什么初值取 `d[0]` 而不是 0

求最大值的逻辑是：手里先攥着一个"当前认为的最大值"，然后逐个看新元素，**发现更大的就把它攥住**。

```c
mx = d[0];                          /* 先攥住第 0 个 */
for (i = 1; i < n; i++)
    if (d[i] > mx) mx = d[i];       /* 更大就更新 */
```

为什么初值取 `d[0]`？因为 `d[0]` 是**真实存在的元素**，一定不会错。如果初值写成 0，那么当归数据里所有值都是负数时（本题不会出现，但别的场合会出现），最大值会被错报为 0——**一个根本不在数据里的值**。用 `d[0]` 做初值则天然正确，而且循环可以从 `i = 1` 开始，少比一次。最小值同理，初值也取 `d[0]`，比较方向改成 `<`。

**注意：最值的初值不能取 `d[0]` 之外的自造数**，这是"初值必须来自数据本身"的原则。

### 3. 一遍遍历能得什么，什么必须分两遍

这是数据统计中最值得体会的一点：

- **总和**：可以边读边累加，**第一遍就能得**；
- **最大值、最小值**：只需要"当前元素与当前最值比一次"，**第一遍就能得**；
- **平均值**：$ \bar{d} = \text{sum} / n $——**必须等总和算完**才能算，也就是说它在第一遍遍历结束时才可能得到；
- **超限人数**：条件 `d[i] >= 20.0` 只依赖当前元素，**第一遍就能得**。

所以本题的四个指标中，只有平均值需要"用第一遍的结果再算一步"，其余三个都能在第一遍遍历中同时收集。**一次遍历收集多个统计量**是高效程序的常见写法。

### 4. 用本例走一遍

样例 1 的数据：$[3.50,\ 21.00,\ 8.50,\ 25.00,\ 7.00]$，$n = 5$。

**第一遍遍历**（初值 `sum=0`、`mx=d[0]=3.50`、`mn=d[0]=3.50`、`over=0`）：

| i | d[i] | sum | mx | mn | over |
|---|---|---|---|---|---|
| 0 | 3.50 | 3.50 | 3.50 | 3.50 | 0（3.50<20） |
| 1 | 21.00 | 24.50 | 21.00 | 3.50 | 1（21.00≥20） |
| 2 | 8.50 | 33.00 | 21.00 | 3.50 | 1 |
| 3 | 25.00 | 58.00 | 25.00 | 3.50 | 2（25.00≥20） |
| 4 | 7.00 | 65.00 | 25.00 | 3.50 | 2 |

**算平均**：$65.00 / 5 = 13.00$ mSv。

**结果**：均值 13.00、最大 25.00、最小 3.50、超限 2 人。与样例 1 输出一致。

**物理校验**：均值 13.00 mSv 已接近 20 mSv 限值（65%），且批内最大值 25.00 mSv 已超限——这一批 5 人中有 2 人（21.00 与 25.00）超限，占 40%，属于需要立即干预的状况。这正是 D9 要突出统计指标的原因：**均值掩盖个体风险，必须同时看最大值和超限人数。**

> **这个思想在综合实验中反复出现**：D9 的剂量批次统计、D7 的测线剂量率最值定位、D8 的谱数据平滑前的读入、A1 的逐层风荷载之和，全部是"数组存下来 + 遍历统计"。

## 三、解题思路

1. **定义数组**：`double d[60];`；
2. **读 n 与数据**：`scanf("%d", &n); for (i = 0; i < n; i++) scanf("%lf", &d[i]);`；
3. **初始化统计量**：`sum = 0.0; mx = d[0]; mn = d[0]; over = 0;`（注意 `mx`、`mn` 用 `d[0]`）；
4. **一次遍历同时收集**：循环 `i` 从 0 到 `n-1`，累加 `sum`、更新 `mx`/`mn`、判断并累加 `over`；
5. **算平均值**：`mean = sum / n;`；
6. **输出四项**。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double d[60];               /* 数组：存放 n 个剂量值，mSv */
    int    n, i;
    double sum = 0.0;           /* 总和 */
    double mean;                /* 平均值 */
    double mx, mn;              /* 最大值、最小值 */
    int    over = 0;            /* 超限人数（>= 20 mSv） */

    scanf("%d", &n);            /* 读入记录条数 */

    for (i = 0; i < n; i++) {
        scanf("%lf", &d[i]);    /* 逐个读入数组元素 */
    }

    /* 最值初值取第一个元素：它是真实数据，保证正确；
       n >= 1 由题目保证，因此 d[0] 一定有效 */
    mx = d[0];
    mn = d[0];

    /* 一次遍历同时求总和、最值、超限人数 */
    for (i = 0; i < n; i++) {
        sum += d[i];                        /* 求和 */
        if (d[i] > mx) mx = d[i];           /* 更新最大值 */
        if (d[i] < mn) mn = d[i];           /* 更新最小值 */
        if (d[i] >= 20.0) over++;           /* 达到年剂量限值，计入超限 */
    }

    mean = sum / n;             /* 平均值必须在总和算完后才能求 */

    printf("mean = %.2f\n", mean);      /* 平均值，保留 2 位小数 */
    printf("max = %.2f\n", mx);         /* 最大值 */
    printf("min = %.2f\n", mn);         /* 最小值 */
    printf("over = %d\n", over);        /* 超限人数（整数） */

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 5: 3.50 21.00 8.50 25.00 7.00 | 和 65.00，均值 13.00；max 25.00，min 3.50；≥20 有 2 个 | `mean = 13.00` / `max = 25.00` / `min = 3.50` / `over = 2` ✓ |
| 4: 10.0 10.0 20.0 40.0 | 和 80.0，均值 20.00；max 40.00，min 10.00；≥20 有 2 个 | `mean = 20.00` / `max = 40.00` / `min = 10.00` / `over = 2` ✓ |
| 1: 18.5 | 和 18.5，均值 18.50；max=min=18.50；无超限 | `mean = 18.50` / `max = 18.50` / `min = 18.50` / `over = 0` ✓ |
| 3: 0.0 5.0 10.0 | 和 15.0，均值 5.00；max 10.00，min 0.00 | `mean = 5.00` / `max = 10.00` / `min = 0.00` / `over = 0` ✓ |

第三例是**单元素边界**：$n = 1$ 时，均值、最大、最小三者都是同一个数，`over = 0`——验证了"最值初值取 `d[0]`"在只有一个元素时也成立。

第四例中最小值为 0.00，说明**最小值确实取自数据**（若把初值写成某个大数或误写成 20，就会出现错误结果）。

## 六、常见错误与讲解

**错误 1：最值初值取 0**

```c
mx = 0.0; mn = 0.0;            /* 错：最小值会恒为 0（本题数据全非负） */
for (i = 0; i < n; i++) { ... }

mx = d[0]; mn = d[0];          /* 对：初值必须来自数据本身 */
```

本题数据都 ≥ 0，若把 `mn` 初值写成 0，最小值将永远输出 0.00，与真实最小值不符。

**错误 2：数组下标从 1 开始用**

```c
for (i = 1; i <= n; i++) scanf("%lf", &d[i]);   /* 错：漏用 d[0]，且 d[n] 越界 */
for (i = 0; i < n; i++)  scanf("%lf", &d[i]);   /* 对 */
```

C 数组下标从 0 开始，`d[n]` 是**越界**访问（合法下标是 0 ～ n-1）。越界写会破坏相邻内存，后果难料。

**错误 3：整数除法导致均值被截断**

```c
mean = sum / n;                     /* 对：sum 是 double，自动浮点除 */
mean = (int)sum / n;                /* 错：转成整数后除法截断小数 */
```

本题 `sum` 是 `double`，`sum / n` 中 `n` 会自动提升为 `double`，**不会**截断。危险的是把 sum 声明为 `int`——那样 65/5 得 13，但 66/5 会得 13 而不是 13.2。**求平均数时，被除数必须是实数类型。**

**错误 4：越过数组容量**

```c
double d[60];
scanf("%d", &n);        /* 题目保证 n <= 60，安全 */
/* 若无此保证又读了 n = 100，就会越界写 40 个元素 → 内存破坏 */
```

定义数组时容量要取题目保证的**上界**（本题 60），不可随意取小。
