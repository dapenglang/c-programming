# 第 8 章 练习 12　阈值筛选输出新文件

**对应章节**：8 数据持久化存储方法（8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）

**场景来源**：综合实验 C7《冰区载荷辨识与统计系统》（水声学院）——本练习是该实验中"超阈值载荷样本筛选"环节的实现。

**建议用时**：30～40 分钟

## 一、应用场景

实验 C7 要从连续监测得到的冰阻力序列中找出"危险样本"：阻力超过给定阈值的时刻，意味着冰与结构发生了强烈作用，需要单独建档分析。原始数据文件 `resistance.txt` 里存着几十上百条样本记录，人工翻找既慢又容易漏。本练习编写一个小工具：从键盘读入阈值，扫描整个数据文件，把所有超过阈值的记录**另存**到一个新文件中，并在屏幕上报告筛选结果——筛选前后两个文件都保留，这正是"从数据中提取信息"的最小完整案例。

## 二、任务要求

编写完整程序 `filter.c`：

1. 以只读方式 `"r"` 打开 `resistance.txt`，以写方式 `"w"` 打开 `resistance_high.txt`，**检查两个 fopen 的返回值**，失败时输出提示并结束程序（返回值 1）；
2. 从键盘读入阈值 `F0`（kN，double 类型）；
3. 用 `fscanf` 按 `"%d %lf"` 循环读入每条记录（样本序号、阻力值），**以 fscanf 的返回值等于 2 作为循环继续的条件**（读到文件末尾自动停止）；
4. 若阻力值严格大于 `F0`，把该记录按 `"%d %.1f\n"` 写入 `resistance_high.txt`；
5. 结束后关闭两个文件，屏幕输出总记录数与筛出的记录数，格式为 `共 M 条记录，其中 N 条超过阈值 F0`（F0 保留 1 位小数）。

**数据文件格式约定**：`resistance.txt` 每行两列、空格分隔——第 1 列样本序号（整数），第 2 列阻力值（kN，1 位小数）。样例数据行：`1 23.5`。

## 三、输入输出格式

**键盘输入**：一行，一个实数，表示阈值 F0（kN）。

**输入文件**：`resistance.txt`（空格分隔，若干行）。

**输出文件**：`resistance_high.txt`（空格分隔，只含超过阈值的行）。

**屏幕输出**：一行，`共 M 条记录，其中 N 条超过阈值 F0`，其中 M、N 为整数，F0 保留 1 位小数。

## 四、样例

**输入文件 resistance.txt 的内容**：

```
1 23.5
2 25.1
3 19.8
4 27.6
5 22.4
```

**键盘输入**：

```
25.0
```

**程序运行后 resistance_high.txt 的内容**：

```
2 25.1
4 27.6
```

**屏幕输出**：

```
共 5 条记录，其中 2 条超过阈值 25.0
```

## 五、提示

- `fscanf` 返回"成功读入并赋值的项数"。数据完整时返回 2，读到文件末尾返回 EOF，所以循环写成 `while (fscanf(fin, "%d %lf", &id, &f) == 2)`，不必预先知道行数；
- 筛选就是在"读入"与"写出"之间加一个 `if (f > F0)` 判断——数据流与练习 11 完全同构；
- 阈值比较用严格大于（`>`），恰好等于阈值的记录**不**写入新文件；
- 输出格式串中的中文与数字混排时，注意 `%.1f` 只作用于 F0 一个占位符。

**完成本练习后你将具备的能力**：用 fscanf 返回值控制"不知行数"的文件循环、在文件读写之间插入判断实现筛选、同时输出"文件结果 + 屏幕摘要"——这是实验 C7 载荷事件筛查功能的原型。
