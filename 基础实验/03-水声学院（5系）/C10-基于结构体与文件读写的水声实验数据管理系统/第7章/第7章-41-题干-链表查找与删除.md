# 第 7 章 练习 41　链表查找与删除

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：7 链表（7.6 链表遍历、7.7 链表节点的查找与删除）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"链表查找与删除"环节的最小实现。

**建议用时**：40 分钟

## 一、应用场景

测点数据录入后常要**订正**：某个测点记错了，整条删掉重录。在数组里删除要把它后面的所有元素整体前移；在链表里只需**改两根指针**——把目标节点"摘"下来，前驱直接牵住后继，其余节点原地不动。这正是链表相对数组的看家本领。

综合实验 C10 的链表删除模块（M6）要处理一个细节：如果删的是**头节点**，没有前驱，得直接移动 `head`。本题完整实现"按编号查找并删除"。

## 二、任务要求

编写一个完整程序 `list_del.c`：

1. 定义与练习 40 相同的节点类型 `struct Node`（`id[16]`、`depth`、`next`）；
2. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 50**）与 `n` 条记录（每行 `编号 水深`），按录入顺序用**尾插法**建链（保证链表顺序与录入一致，便于观察删除效果）；
3. 读入待删除的测点编号，在链表中**查找**：找到则**删除该节点**（`free` 释放），若编号出现多次只删**第一个**；找不到输出 `未找到该测点`；
4. 删除后遍历输出剩余节点，最后输出剩余个数。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后 `n` 行，每行 `编号 水深`；最后一行一个字符串，为待删除编号。

**输出**：若找到：逐行输出剩余节点（编号左对齐占 9 列、水深右对齐占 9 列保留 2 位小数），末行 `剩余 x 个节点`；若未找到：仅输出 `未找到该测点`。

## 四、样例

**样例 1**（删除中间节点）

输入：
```
4
S01 15.5
S02 18.2
S03 22.0
S04 9.8
S02
```
输出：
```
S01          15.50
S03          22.00
S04           9.80
剩余 3 个节点
```

**样例 2**（删除头节点）

输入：
```
3
S01 15.5
S02 18.2
S03 22.0
S01
```
输出：
```
S02          18.20
S03          22.00
剩余 2 个节点
```

**样例 3**（未找到）

输入：
```
2
S01 15.5
S02 18.2
S09
```
输出：
```
未找到该测点
```

## 五、提示

- 查找需要**两个指针**：`p` 看当前节点、`prev` 记前驱。`p` 命中后靠 `prev` 才能接线：
  ```c
  prev->next = p->next;   /* 前驱越过 p，牵住 p 的后继 */
  free(p);
  ```
- 头节点没有前驱，要**单独处理**：`head = p->next; free(p);`——这是本题最容易漏的分支；
- 尾插法建链：养一个尾指针 `tail`，新节点挂到 `tail->next`，再 `tail = p`；
- 释放节点**之后**不要再读它的成员；要继续工作就先 `p = p->next;` 再 `free`；
- 想一想：为什么删除时 `free` 前要把 `p->next` 先交给别人？因为 `free` 之后那块内存随时可能被系统收回，里面的 `next` 不再可信。

**完成本练习后你将具备的能力**：双指针查找定位、分情况摘除节点（含头节点特判）——这是实验 C10 中"链表删除模块"（M6）的直接实现，也是"有序插入"（M6 后半）的铺垫。
