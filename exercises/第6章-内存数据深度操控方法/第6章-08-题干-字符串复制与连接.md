# 第 6 章 练习 08　字符串复制与连接

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用、6.4 指针与字符串）

**场景来源**：综合实验 B10《文本相似度分析系统》（人工智能学院）——本练习是该实验中"样本文件名拼接"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本相似度分析系统 B10 批量处理语料样本时，文件名由**前缀 + 编号后缀**动态拼接而成，例如前缀 `sample` 加后缀 `_01.txt` 拼成 `sample_01.txt`。系统规定关键字符串操作自研实现：**复制**（把前缀搬进结果缓冲区）与**连接**（把后缀接到结果末尾）。两个函数都必须用字符指针完成——复制函数要把源串的每个字符连同 `'\0'` 逐一搬过去；连接函数要先走到目标串的 `'\0'` 处，再从那里开始接力复制。这正是实验 B10 预处理模块每天执行的操作。

## 二、任务要求

编写一个完整程序 `name_join.c`：

1. 编写函数 `char *my_strcpy(char *dst, char *src)`：把 `src` 指向的字符串（含 `'\0'`）复制到 `dst`，返回 `dst`；
2. 编写函数 `char *my_strcat(char *dst, char *src)`：把 `src` 接到 `dst` 原有内容之后（覆盖 `dst` 的 `'\0'` 并补回新 `'\0'`），返回 `dst`；
3. 主函数定义 `char result[100]`，读入前缀与后缀两个不含空格的字符串，先用 `my_strcpy` 装入前缀，再用 `my_strcat` 接上后缀；
4. 输出拼接完成的完整文件名与总长度（长度用练习 07 的 `my_strlen` 计算，不得用 `strlen`）。

## 三、输入输出格式

**输入**：一行，两个不含空格的字符串，空格分隔：前缀（不超过 20 字符）与后缀（不超过 20 字符）。

**输出**：两行。
第 1 行：`filename = 拼接结果`；
第 2 行：`length = 总长度`。

## 四、样例

**样例 1**

输入：
```
sample _01.txt
```
输出：
```
filename = sample_01.txt
length = 13
```

**样例 2**

输入：
```
icesample _07.dat
```
输出：
```
filename = icesample_07.dat
length = 16
```

## 五、提示

1. `my_strcpy` 的经典一句版：`while ((*dst++ = *src++) != '\0') ;`——先把 `*src` 赋给 `*dst`，再判断赋值结果是否为 `'\0'`，为真继续；初学建议用清晰的两步写法；
2. `my_strcat` 分两段：先用一个指针把 `dst` 走到其 `'\0'` 处，再从那里执行一段 `my_strcpy`；
3. **缓冲区必须足够大**：`result` 为 100 字节，本题前缀+后缀合计不超过 41 字节，安全；实验中拼接前必须检查长度；
4. 赋值表达式的值就是赋进去的那个值——`while ((*d = *s) != '\0')` 里的 `'\0'` 赋值会发生并随后终止循环，`'\0'` 被如实复制。

**完成本练习后你将具备的能力**：手写复制与连接两大字符串函数、理解"目标缓冲区"与容量意识、掌握"赋值表达式的值"这一惯用法——实验 B10 文件名管理与语料拼接模块的底层实现。
