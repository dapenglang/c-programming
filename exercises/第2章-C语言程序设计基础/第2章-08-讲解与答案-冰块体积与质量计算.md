# 第 2 章 练习 08　讲解与参考答案（冰块体积与质量计算）

## 二、预备知识：数据类型的选择与物理量的单位配套（零基础阅读）

### 1. 问题是怎么来的

一块碎冰，工程上要算它的体积和质量。体积是几何量——长、宽、厚相乘即可；质量还要知道冰有多"实"，这由**密度**决定。海冰密度约 $917\ \mathrm{kg/m^3}$：体积 1 m³ 的冰，质量就是 917 kg。

### 2. 公式是怎么来的

长方体体积等于三个边长之积：

$$
V = l \times w \times t
$$

质量等于体积乘密度（密度的定义就是"单位体积的质量"）：

$$
m = \rho_{\text{ice}} \times V
$$

单位要配套：尺寸用米，体积就是立方米；密度用 kg/m³，乘出来的质量就是 kg。若尺寸用厘米而密度用 SI 单位，就会差 $10^6$ 倍——这是工程计算最常犯的单位错误。

### 3. 用本例走一遍

长 2 m、宽 1.5 m、厚 0.4 m：

- 体积：$V = 2\times1.5\times0.4 = 1.2\ \mathrm{m^3}$；
- 质量：$m = 917\times1.2 = 1100.4\ \mathrm{kg}$。

再算一块 1 m × 0.8 m × 0.5 m 的冰：$V = 0.4\ \mathrm{m^3}$，$m = 917\times0.4 = 366.8$ kg。

### 4. 编程时怎么用它

两个要点。**其一，数据类型**：尺寸带小数（如 1.5、0.4），必须用 `double`；若图省事写成 `int`，输入 `0.4` 会被读成 `0`，体积直接算成 0。**其二，顺序**：先把体积算出来存进变量，再用它乘密度，两步清晰；也可以写成一行的 `m = RHO_ICE * l * w * t`，两者等价，但分步更易读、更易查错。

## 三、解题思路

1. **备常量**：`const double RHO_ICE = 917.0`；
2. **备变量**：`l, w, t`（输入），`V, m`（结果），全用 `double`；
3. **读入**：`scanf("%lf %lf %lf", &l, &w, &t)`；
4. **算体积**：`V = l * w * t`；
5. **算质量**：`m = RHO_ICE * V`；
6. **输出**：两行，保留 4 位小数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double RHO_ICE = 917.0;   /* 海冰密度，kg/m^3 */

    double l, w, t;   /* 输入：冰块的长、宽、厚，m */
    double V;         /* 输出：体积，m^3 */
    double m;         /* 输出：质量，kg */

    /* 读入三个尺寸 */
    scanf("%lf %lf %lf", &l, &w, &t);

    /* 第一步：长方体的体积 = 长 * 宽 * 厚 */
    V = l * w * t;

    /* 第二步：质量 = 密度 * 体积 */
    m = RHO_ICE * V;

    /* 输出，均保留 4 位小数 */
    printf("V = %.4f m^3\n", V);
    printf("m = %.4f kg\n", m);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2 1.5 0.4 | $V=2\times1.5\times0.4=1.2$；$m=917\times1.2=1100.4$ | `V = 1.2000 m^3` / `m = 1100.4000 kg` ✓ |
| 1 0.8 0.5 | $V=1\times0.8\times0.5=0.4$；$m=917\times0.4=366.8$ | `V = 0.4000 m^3` / `m = 366.8000 kg` ✓ |
| 2.5 1.2 0.3 | $V=2.5\times1.2\times0.3=0.9$；$m=917\times0.9=825.3$ | `V = 0.9000 m^3` / `m = 825.3000 kg` ✓ |

质量始终等于体积的 917 倍，与密度定义一致，说明两步计算都正确。

## 六、常见错误与讲解

**错误 1：用 `int` 存放尺寸**

```c
int l, w, t;                 /* 错：输入 0.4 会被截断，体积算成 0 */
double l, w, t;              /* 对 */
```

**错误 2：密度写成整数或漏掉小数**

```c
const int RHO_ICE = 917;     /* 危险：虽能自动提升，但语义上密度是实数量 */
const double RHO_ICE = 917.0;/* 对 */
```

**错误 3：scanf 漏写 `&`、格式符用错**

```c
scanf("%lf %lf %lf", &l, &w, &t);   /* 对：三个 & 一个都不能少 */
scanf("%f %lf %lf", &l, &w, &t);    /* 错：double 读入第一项应用 %lf */
```

**错误 4：输出格式与类型不匹配**

```c
printf("V = %d m^3\n", V);       /* 错：double 用 %d 输出乱码 */
printf("V = %.4f m^3\n", V);     /* 对 */
```

## 七、与综合实验的衔接

- 在实验 **C8（碎冰冰块浮力吃水计算系统）**中，本练习对应"冰块几何与质量参数计算"：正式程序会一次读入成百上千块冰的尺寸，逐块算出体积与质量，再进一步求重力、浮力与吃水——批量处理需要循环（第 3 章）和数组/结构体（第 5、7 章）；
- 本练习算出的体积与质量，正是练习 10"冰块重力与浮力差值"的输入。两题连起来，就构成了 C8 中最基础的"几何 → 质量 → 受力"链条。
