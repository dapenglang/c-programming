## 二、预备知识：从问题分解到递推关系（零基础阅读）

### 1. 问题来源

汉诺塔的规则是：每次只搬一个盘子，大盘不能压在小盘上，要把 $n$ 个盘子从 A 柱全部搬到 C 柱。怎样才能"最少步数"完成？

### 2. 关键一步：把大问题拆成小问题

盯着**最大的那个盘子**想：它最终必须落在 C 柱的底部。在搬到 C 之前，C 柱必须空着，也就是说，压在它上面的 **$n-1$ 个小盘子必须先全部挪到 B 柱**。于是整个过程自然地分成三步：

1. 把上面 $n-1$ 个盘子从 A 搬到 B：需要 $M(n-1)$ 步；
2. 把最大的盘子从 A 搬到 C：需要 $1$ 步；
3. 把 B 柱上的 $n-1$ 个盘子搬到 C：需要 $M(n-1)$ 步。

### 3. 递推关系

把三步加起来：

$$
M(n) = M(n-1) + 1 + M(n-1) = 2M(n-1) + 1
$$

基线是只有一个盘子的情形：$M(1) = 1$。这个递推可以一路解下去：$M(n)=2^n-1$（可用数学归纳法证明）。

### 4. 调用栈展开：用 $M(3)$ 看递归

```text
hanoi_moves(3)  需要 2 * hanoi_moves(2) + 1        ── 挂起
  hanoi_moves(2)  需要 2 * hanoi_moves(1) + 1      ── 挂起
    hanoi_moves(1)  命中基线，返回 1                  （最深处）
  hanoi_moves(2) = 2 * 1 + 1 = 3                   ── 返回 3
hanoi_moves(3) = 2 * 3 + 1 = 7                     ── 返回 7
```

虽然真正的汉诺塔"搬盘子"过程要搬 7 步，但**求"次数"只需要这条单链递归**：函数只关心"要几步"，不用真的去搬。返回阶段每层做一次"乘 2 加 1"，与阶乘的"乘 n"结构类似，只是常数换成了 2、再加 1。

### 5. 编程要点

- 返回类型用 `long long`：$M(31)=2^{31}-1$ 已超过 `int` 上限，$M(60)=2^{60}-1$ 更是天文数字；
- 递推表达式 `2 * hanoi_moves(n - 1) + 1` 里**千万不要漏掉乘 2**（对应"搬过去"和"搬回来"两趟）；
- 打印用 `%lld`。

## 三、解题思路

1. **定接口**：`long long hanoi_moves(int n)`；
2. **写原型**：放在 `main` 上方；
3. **写基线**：`if (n == 1) return 1;`；
4. **写递推**：`return 2 * hanoi_moves(n - 1) + 1;`；
5. **主流程**：读 `n` → 调用 → 打印。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：返回搬 n 个盘子的最少移动次数 */
long long hanoi_moves(int n);

int main(void)
{
    int n;
    scanf("%d", &n);
    printf("moves(%d) = %lld\n", n, hanoi_moves(n));
    return 0;
}

/* 递归函数：汉诺塔移动次数 */
long long hanoi_moves(int n)
{
    if (n == 1)                                  /* 基线条件：一个盘子搬一次 */
        return 1;
    else                                         /* 递推关系：2*M(n-1) + 1 */
        return 2 * hanoi_moves(n - 1) + 1;
}
```

## 五、运行验证

以 `hanoi_moves(3)` 为例的中间结果：

| 调用 | 表达式 | 本层结果 | 返回给谁 |
|---|---|---|---|
| hanoi_moves(1) | 命中基线 | 1 | hanoi_moves(2) |
| hanoi_moves(2) | 2 × 1 + 1 | 3 | hanoi_moves(3) |
| hanoi_moves(3) | 2 × 3 + 1 | 7 | main |

多组输入的程序输出：

| 输入 n | 手算过程 | 程序输出 |
|---|---|---|
| 1 | $2^1-1=1$ | `moves(1) = 1` ✓ |
| 3 | $2^3-1=7$ | `moves(3) = 7` ✓ |
| 10 | $2^{10}-1=1023$ | `moves(10) = 1023` ✓ |
| 20 | $2^{20}-1=1048575$ | `moves(20) = 1048575` ✓ |
| 60 | $2^{60}-1=1152921504606846975$ | `moves(60) = 1152921504606846975` ✓ |

## 六、常见错误与讲解

**错误 1：递推关系漏掉乘 2**

```c
return hanoi_moves(n - 1) + 1;      /* 错：只算了一趟，M(3) 会得 3 而不是 7 */
return 2 * hanoi_moves(n - 1) + 1;  /* 对：搬过去 + 搬最大盘 + 搬回来 */
```

想一想 $M(3)=7$，若漏乘 2 会得到 $M(3)=3$，明显与样例不符——**样例就是检验递推关系的最好工具**。

**错误 2：忘记基线条件**

```c
return 2 * hanoi_moves(n - 1) + 1;  /* 没有 n == 1 的出口，会一路调到 n = 0、-1…… 栈溢出 */
```

**错误 3：用 `int` 承载导致溢出**

```c
int hanoi_moves(int n);              /* n = 31 时 2^31-1 已溢出 */
long long hanoi_moves(int n);        /* 对 */
```

**错误 4：打印格式不匹配**

```c
printf("moves(%d) = %d\n", n, hanoi_moves(n));    /* 错：long long 用 %d */
printf("moves(%d) = %lld\n", n, hanoi_moves(n));  /* 对 */
```

## 七、与综合实验的衔接

- 在实验 **B4（深度优先搜索迷宫求解系统）**中，"把问题分解为同类子问题、先解决小的再合并"的思路与汉诺塔完全一致：迷宫中"从当前格子出发求解到终点的路径"，就是对"从下一个格子出发求解"的递归调用。本练习让你先用最干净的数学问题把这种"分解—递归—合并"的思维练熟；
- 汉诺塔还揭示了递归的**指数级代价**（$M(n)\sim 2^n$）。在后续实验里判断一个算法能不能用递归实现时，除了正确性，还要估计它的调用次数是否可接受——这正是计算思维里"算法效率"意识的起点。
