# 第 3 章 练习 01　多档风压系数区间判断（if-else 链）

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.2 选择结构——if/else if/else 链、3.4 关系运算符与逻辑运算符）

**场景来源**：综合实验 A1《基于线性插值的风荷载计算系统》（航建学院）——本练习是该实验中"风压高度变化系数分档判断"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

计算风荷载时首先要确定建筑物所在高度档的风压高度变化系数 $\mu_z$。规范表格按标准高度档给出系数，工程软件在查表前必须先判断：输入的高度落在哪一个档位区间内？是否超出了表格的适用范围？如果高度不合法却仍然拿去插值，算出的风荷载就是错的，可能直接导致结构设计偏危险。因此"先判断档位、再取系数、超界则报错"是风荷载计算程序（实验 A1）中位于最前面的一道**数据把关工序**——本练习就来实现这道工序的最小版本。

## 二、任务要求

编写一个完整程序 `wind_band.c`：

1. 程序按下列**简化分档表**（地面粗糙度 B 类）判断高度档位：

| 档位 | 高度范围 | 风压高度变化系数 $\mu_z$ |
|---|---|---|
| 1 | $10 \le h < 15$ | 1.00 |
| 2 | $15 \le h < 20$ | 1.13 |
| 3 | $20 \le h < 30$ | 1.23 |
| 4 | $30 \le h < 40$ | 1.39 |

2. 从键盘读入一个建筑物计算高度 `h`（单位：米，`double` 类型）；
3. 用 if-else 链判断 `h` 落在哪一档，按格式输出档位编号与该档系数；注意区间**左闭右开**，例如 $h = 20$ 属于档 3 而不是档 2；
4. 若 $h < 10$ 或 $h \ge 40$，超出了表格适用范围，输出 `out of range`，不允许输出任何档位系数。

## 三、输入输出格式

**输入**：一行，一个实数，表示建筑物计算高度 h（米）。

**输出**：一行。若高度合法，按格式 `band = 档位编号, mu_z = 系数` 输出，系数保留 2 位小数；若超界，输出 `out of range`。

## 四、样例

**样例 1**

输入：
```
16
```
输出：
```
band = 2, mu_z = 1.13
```

**样例 2**

输入：
```
8
```
输出：
```
out of range
```

## 五、提示

判断"落在档 2"需要同时满足两个条件：$h \ge 15$ **并且** $h < 20$。C 语言中"并且"用逻辑与运算符 `&&` 连接，写成

```c
h >= 15.0 && h < 20.0
```

但不能照抄数学写法 `15.0 <= h < 20.0`——这种写法在 C 语言里合法却不是你要的意思（先算 `15.0 <= h` 得 0 或 1，再拿 0 或 1 与 20 比较），是初学者最常见的逻辑陷阱之一。

**完成本练习后你将具备的能力**：书写关系表达式与逻辑表达式、用 if-else 链实现多档分支判断、正确处理区间端点的归属（左闭右开）、为非法输入设置拦截分支——这些是实验 A1 中"输入合法性检查 + 档位判断"模块的核心逻辑。
