## 二、预备知识：线性插值与回声时间公式的串联（零基础阅读）

### 1. 问题是怎么来的

声呐测距的原理很朴素：声音跑过去再跑回来，总路程是 $2h$，用时 $t = 2h/c$。难点在于**声速 $c$ 不是固定的**——它随深度变化。实测只给了两个点：0 m 处 1450 m/s、200 m 处 1500 m/s。要算 100 m 深度的回声时间，必须先知道那个深度的声速，这就得插值。

### 2. 两个公式分别是怎么来的

**插值公式**：假设两档之间声速随深度均匀变化，两点 $(h_0,c_0)$、$(h_1,c_1)$ 之间：

$$
c = c_0 + \dfrac{(c_1 - c_0)\,(h - h_0)}{h_1 - h_0}
$$

含义是"起点声速 + 全程涨幅 × 已走比例"。

**回声时间公式**：声波往返走 $2h$ 的距离，速度是 $c$，时间等于路程除以速度：

$$
t = \frac{2h}{c}
$$

### 3. 用本例走一遍

取 $h=100$：

- 插值求声速：比例 $(100-0)/(200-0)=0.5$；$c = 1450 + (1500-1450)\times0.5 = 1450+25 = 1475$ m/s；
- 求时间：路程 $2h = 200$ m，$t = 200/1475 \approx 0.135593$ s。

再取 $h=50$：$c = 1450 + 50\times0.25 = 1462.5$ m/s；路程 $100$ m，$t = 100/1462.5 \approx 0.068376$ s。可见深度减半，时间也大致减半（声速变化很小），符合直觉。

### 4. 编程时怎么用它

本题体现一个重要的编程模式——**公式串联**：先算出的 $c$ 存进一个变量，立刻作为第二个公式的输入。代码上是两行赋值，但逻辑上前后依赖，顺序不能颠倒（先有 $c$ 才能算 $t$）。另外要注意把 $2h$ 写成 `2.0 * h`，避免整数常量带来的困惑。

## 三、解题思路

1. **确定常量**：两档 (0, 1450)、(200, 1500)，用 `const double`；
2. **确定变量**：深度 `h`（输入），声速 `c`、时间 `t`（结果）；
3. **读入深度**；
4. **第一步插值**：`c = C0 + (C1 - C0) * (h - H0) / (H1 - H0)`；
5. **第二步求时间**：`t = 2.0 * h / c`；
6. **输出**：`c` 保留 2 位小数，`t` 保留 6 位小数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 两档实测数据：深度(m) 与 声速(m/s) */
    const double H0 = 0.0;
    const double H1 = 200.0;
    const double C0 = 1450.0;
    const double C1 = 1500.0;

    double h;   /* 输入：目标深度，m */
    double c;   /* 中间：该深度声速，m/s */
    double t;   /* 输出：回声时间，s */

    /* 读入目标深度 */
    scanf("%lf", &h);

    /* 第一步：线性插值求该深度的声速 */
    c = C0 + (C1 - C0) * (h - H0) / (H1 - H0);

    /* 第二步：回声时间 t = 2h / c */
    t = 2.0 * h / c;

    /* 输出：声速保留 2 位小数，时间保留 6 位小数 */
    printf("c = %.2f m/s\n", c);
    printf("t = %.6f s\n", t);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 100 | $c=1450+50\times0.5=1475$；$t=200/1475\approx0.135593$ | `c = 1475.00 m/s` / `t = 0.135593 s` ✓ |
| 50 | $c=1450+50\times0.25=1462.5$；$t=100/1462.5\approx0.068376$ | `c = 1462.50 m/s` / `t = 0.068376 s` ✓ |
| 200 | $c=1450+50\times1=1500$；$t=400/1500\approx0.266667$ | `c = 1500.00 m/s` / `t = 0.266667 s` ✓ |
| 0 | $c=1450+50\times0=1450$；$t=0/1450=0$ | `c = 1450.00 m/s` / `t = 0.000000 s` ✓ |

$h=0$ 时回声时间自然为 0，$h=200$ 时声速回到表格值 1500，说明插值与时间公式都正确。

## 六、常见错误与讲解

**错误 1：公式顺序颠倒**

```c
t = 2.0 * h / c;   /* 若把这个写在插值之前，c 里还是未初始化的随机值，结果无意义 */
```

必须**先插值算出 `c`，再算 `t`**。代码顺序 = 逻辑顺序。

**错误 2：把 $2h/c$ 写成 $2/(h/c)$ 或漏括号**

```c
t = 2.0 / h / c;     /* 错：分子分母全乱 */
t = 2.0 * h / c;     /* 对：先乘 2h，再除以 c */
```

**错误 3：整数除法**

```c
t = 2 * h / c;       /* 有风险：2 是整数，若 h 恰好也是整数类型会先做整数除法 */
t = 2.0 * h / c;     /* 对：2.0 保证按浮点运算 */
```

**错误 4：输出精度写反**

```c
printf("c = %.6f m/s\n", c);   /* 声速不需要 6 位小数 */
printf("t = %.2f s\n", t);     /* 错：时间很小，2 位小数会显示成 0.14，看不出差异 */
printf("t = %.6f s\n", t);     /* 对 */
```

## 七、与综合实验的衔接

- 在实验 **C1（声速剖面计算系统）**中，本练习对应"回声时间估算"环节：正式程序会用整条声速剖面（几十个深度点）逐层积分声传播时间，而不是只取两点——逐层累加需要循环（第 3 章），剖面表需要数组（第 5 章），多点曲线要用拉格朗日插值（第 8 章）；
- 本练习把"插值 → 物理公式"这一步串起来，正是后续 C3（声传播损失，需插值查吸收系数）和 D5（剂量率，需插值查转换因子）共用的计算骨架：**先插值取参数，再代入公式算结果**。
