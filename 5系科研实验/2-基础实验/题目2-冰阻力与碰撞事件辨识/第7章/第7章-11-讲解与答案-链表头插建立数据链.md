## 二、预备知识：链表与头插法的基本原理（零基础阅读）

### 1. 数组为什么不够用

前几章的数据都存放在**数组**里，数组有两个天然的"硬伤"：

- **长度固定**：定义 `double a[100];` 就写死了一百个位置。记录到底有多少条事先不知道——开小了装不下，开大了浪费；
- **插入、删除要搬移**：在数组中间插入一个元素，得把它后面的元素整体后移一格；删除则整体前移。数据一多，这些"搬家"非常耗时。

测点上报的场景里，记录是**不断到来**、条数不固定的，数组既不省空间也不够灵活。需要的是一种"用一个、申请一个，用完就还"的存储方式——这就是**链表**。

### 2. 链表节点 = 数据 + 下一节点的地址

链表不再要求数据连续存放，而是把每份数据装进一个独立的**节点（node）**。每个节点里除了数据，还要存一句"下一个节点在哪里"，这样即使节点散落在内存各处，也能沿着地址一个个找到。用结构体表示再合适不过：

```c
struct IceLoad {
    int    id;             /* 数据域：测点编号 */
    double load;           /* 数据域：载荷 */
    struct IceLoad *next;  /* 指针域：下一个节点的地址 */
};
```

`next` 是一个"指向 `struct IceLoad` 的指针"，它保存的是**地址**。最后一个节点没有后继，就把它的 `next` 设为 `NULL`，作为"链到头了"的标志；如果一个节点都没有，那么头指针 `head` 本身就是 `NULL`。一串节点靠 `next` 连起来的结构就长这样：

```
head ──► [101|12.5|●] ──► [102|8.3|●] ──► [103|15.7|NULL]
         节点A            节点B            节点C
```

（每个方框里依次是 `id`、`load`、`next`，"●"表示指向右边那个节点的地址。）

### 3. malloc/free：向系统"借"内存，用完"还"回去

数组的空间在编译时就划定好了；链表节点的空间要到**运行时**才知道要多少个，所以必须**临时申请**。

- `malloc(size)`：向系统申请 `size` 个字节的内存，成功时返回这块内存的**首地址**，失败（内存不够）时返回 `NULL`。例如 `malloc(sizeof(struct IceLoad))` 就是"给我一块刚好装下一个节点的内存"；
- `free(p)`：把 `p` 指向的那块内存**归还**给系统。借了就要还，否则程序运行期间这块内存一直被占着，越占越多，称为**内存泄漏**。

因为返回的是"无类型的首地址"，C 语言里要**强制转换**成节点指针类型，并**务必检查是否为 `NULL`**：

```c
p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
if (p == NULL) { printf("malloc failed\n"); return 1; }   /* 申请失败立即处理 */
```

### 4. 头插法：新节点改接到链头

头插就两步，但**顺序绝不能颠倒**。设原来 `head` 指向 A，要在链头插入新节点 N：

```
改接前：  head ──► [A] ──► [B] ──► NULL

第 1 步  p->next = head;    /* N 先指向 A，接上老链 */
第 2 步  head = p;          /* head 改指 N，N 成为新链头 */
改接后：  head ──► [N] ──► [A] ──► [B] ──► NULL
```

若先写 `head = p;` 再写 `p->next = head;`，第一次赋值后 `head` 已指向 N，第二句就变成 `N->next = N`——老链地址被丢掉（叫**丢失原链头**），整条链只剩一个自环。**先接后断、先连后换头**，是链表所有改接操作的总原则。

## 三、解题思路

1. **定义节点类型**：在函数外定义 `struct IceLoad`，让 `main` 能引用；
2. **初始化空链**：`head = NULL`；
3. **循环读入 n 条记录**：每次 `malloc` 一个新节点、检查返回值、填 `id` 与 `load`；
4. **头插**：`p->next = head; head = p;` 完成一次插入；
5. **遍历输出**：`p = head` 起，`while (p != NULL)` 输出后 `p = p->next`，顺带计数；
6. **释放内存**：用 `while (head != NULL)` 逐个 `free`，先存 `head->next` 再释放，避免"释放后又去访问"。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>          /* malloc、free 需要用到的头文件 */

/* 链表节点：数据域 + 指针域 */
struct IceLoad {
    int    id;               /* 测点编号 */
    double load;             /* 载荷，kN */
    struct IceLoad *next;    /* 指向下一个节点的指针 */
};

int main(void)
{
    int n, i, id, count;
    double load;
    struct IceLoad *head = NULL;   /* 空链表的头指针为 NULL */
    struct IceLoad *p;

    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        scanf("%d %lf", &id, &load);

        /* 1. 申请一个节点 */
        p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
        if (p == NULL) {                 /* 2. 检查申请是否成功 */
            printf("malloc failed\n");
            return 1;
        }
        p->id = id;                      /* 3. 填数据域 */
        p->load = load;

        /* 4. 头插：先让新节点接上老链头，再更新 head */
        p->next = head;
        head = p;
    }

    /* 遍历输出，顺便计数 */
    count = 0;
    p = head;
    while (p != NULL) {
        printf("%d %.2f\n", p->id, p->load);
        count++;
        p = p->next;                     /* 沿指针走到下一节点 */
    }
    printf("count = %d\n", count);

    /* 释放整条链：先记住下一个，再释放当前 */
    while (head != NULL) {
        p = head;
        head = head->next;
        free(p);
    }
    return 0;
}
```

## 五、运行验证

以样例 1（依次读入 `101 12.5`、`102 8.3`、`103 15.7`）为例，每次头插后链表状态为：

```
初始:       head ──► NULL
插入 101:   head ──► [101|12.5|NULL]
插入 102:   head ──► [102|8.3|●] ──► [101|12.5|NULL]
插入 103:   head ──► [103|15.7|●] ──► [102|8.3|●] ──► [101|12.5|NULL]
```

从 `head` 遍历输出，得到：

```
103 15.70
102 8.30
101 12.50
count = 3
```

与样例 1 完全一致。**头插法使输出顺序与输入顺序相反**，这是它的固有特点：想要保持输入顺序，请用下一题的**尾插法**。

样例 2 依次读入 `201 4.0`、`202 9.5`，头插后链表为 `head → [202|9.5] → [201|4.0] → NULL`，输出 `202 9.50`、`201 4.00`、`count = 2`，同样相符。当 `n = 0` 时循环体一次也不执行，`head` 保持 `NULL`，遍历直接跳过，只输出 `count = 0`。

## 六、常见错误与讲解

**错误 1：头插两行顺序写反，丢失原来的链头**

```c
head = p;              /* 错：先把 head 指向新节点 */
p->next = head;        /* 结果 p->next = p，老链全部丢失！ */
```
正确写法永远是先 `p->next = head;` 再 `head = p;`。记住口诀"**先接后断**"：新节点先拽住老链，再改头。

**错误 2：忘记检查 malloc 返回值**

```c
p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
p->id = id;            /* 错：p 可能是 NULL，解引用会崩溃 */
```
内存不足或申请失败时 `malloc` 返回 `NULL`，此时写 `p->id` 会访问非法地址。**每次申请后立即判断 `if (p == NULL)`**。

**错误 3：忘记 free，造成内存泄漏**

借了不还，节点所在内存会一直占着。规范做法是遍历链表逐个 `free`，且顺序必须是"先保存 `head->next`，再 `free(head)`"——如果先 `free(head)` 再取 `head->next`，就是在访问已经归还的内存。

**错误 4：遍历时忘记推进指针，死循环**

```c
while (p != NULL) {
    printf("%d %.2f\n", p->id, p->load);
    /* 错：漏了 p = p->next;  p 永远不变，无限输出 */
}
```
遍历三要素：起点 `p = head`、条件 `p != NULL`、推进 `p = p->next`，缺一不可。
