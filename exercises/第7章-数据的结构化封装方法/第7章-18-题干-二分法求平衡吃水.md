# 第 7 章 练习 18　二分法求平衡吃水

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.3 结构体变量作函数参数、7.6 二分法求解——结构体参数传参与方程求根）

**场景来源**：综合实验 C8《冰区船舶浮力与吃水计算系统》（水声学院）——本练习是该实验中"由冰块参数求平衡吃水"环节的实现。

**建议用时**：40 分钟

## 一、应用场景

一个球形碎冰漂浮在海面上，工程上常需要知道它的**吃水深度** $d$（浸入水中的高度）。漂浮的平衡条件是"浮力 = 重力"：对半径 $R$ 的球，浸没部分是一个球缺，其体积为

$$
V(d) = \frac{\pi d^2 (3R - d)}{3}.
$$

平衡方程为

$$
f(d) = \rho_w\,V(d) - \rho_i\,V_{\text{总}} = 0,\qquad V_{\text{总}} = \frac{4}{3}\pi R^3 ,
$$

其中冰密度 $\rho_i = 900\ \text{kg/m}^3$、海水密度 $\rho_w = 1025\ \text{kg/m}^3$。这是一个关于 $d$ 的三次方程，用**二分法**求解最稳妥。本练习的特别之处在于：把"半径、冰密度、海水密度"这组描述冰块的参数**组织成一个结构体**，整体传给求解函数，让"方程函数"和"二分求解器"都能直接用这块冰的参数做计算——这正是结构体作函数参数的典型用法。

## 二、任务要求

编写一个完整程序 `bisect_draft_struct.c`：

1. 定义结构体类型 `struct IceBlock`，包含三个成员：`double R`（半径，m）、`double rho_i`（冰密度）、`double rho_w`（海水密度）；
2. 编写函数 `double f(double d, struct IceBlock blk)`：返回平衡方程的残差

   $$
   f(d) = \rho_w\cdot\frac{\pi d^2(3R-d)}{3} - \rho_i\cdot\frac{4}{3}\pi R^3 ,
   $$

   其中 $R,\rho_i,\rho_w$ 均取自参数结构体 `blk`；
3. 编写函数 `double bisect(struct IceBlock blk, double eps)`：在区间 $[0,\ 2R]$ 上用二分法求 $f(d)=0$ 的根——每次取中点 `m`，若 $f(a)\cdot f(m) \le 0$（说明根在左半区间）则令右端点为 `m`，否则令左端点为 `m`；当 $b-a < eps$ 时停止；用 `int *pn` 带回对分次数，返回近似吃水；
4. `main` 读入半径 `R`，把 `rho_i = 900`、`rho_w = 1025` 填入结构体，以 `eps = 1e-6` 调用 `bisect`；
5. 按格式输出：`draft = 吃水, n = 对分次数`（吃水保留 6 位小数）。

## 三、输入输出格式

**输入**：一行，一个实数 `R`（球半径，单位 m，`R > 0`）。

**输出**：一行，格式为 `draft = 吃水深度, n = 对分次数`（吃水保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
1
```
输出：
```
draft = 1.563805, n = 21
```

**样例 2**

输入：
```
1.5
```
输出：
```
draft = 2.345708, n = 22
```

## 五、提示

- 球缺体积可积分得到：把球沿竖直方向切成薄圆盘，圆盘半径为 $\sqrt{R^2-(R-y)^2}$，从 $y=0$ 积到 $y=d$ 即得 $V(d)=\dfrac{\pi d^2(3R-d)}{3}$；
- 区间端点取值：$d=0$ 时 $f=-\rho_i V_{\text{总}}<0$；$d=2R$ 时 $f=(\rho_w-\rho_i)V_{\text{总}}>0$，两端**异号**，二分法可用；
- 结构体作参数是**按值传递**：函数内得到的是 `blk` 的一份拷贝，使用 `blk.R`、`blk.rho_i`、`blk.rho_w` 访问成员；
- 吃水与半径成正比：$R$ 翻倍，吃水也翻倍（本题 $1.5\times1.5638\approx2.3457$），可用来检查结果是否合理；
- 区间长度每对分一次减半，对分次数约为 $\log_2\dfrac{2R}{\text{eps}}$，本题约 21~22 次。

**完成本练习后你将具备的能力**：会定义结构体来打包"一组相关的物理参数"、能把结构体作参数传给函数、能结合二分法求解带参数的非线性方程——这是实验 C8"冰块参数化平衡吃水求解模块"的地基。
