## 二、预备知识：牛顿迭代法的基本原理（零基础阅读）

### 1. 问题是怎么来的

计算机的 CPU 只会加减乘除，没有"开方"按钮。要算 $\sqrt{a}$，就把它变成一个**解方程**问题：

$$
f(x) = x^2 - a = 0, \qquad x > 0 .
$$

这个方程没有求根公式可用时（或者公式太贵时），数值计算的标准做法是**迭代**：先猜一个值，再用固定的公式把猜测值越改越准。牛顿迭代法就是其中最著名的一个。

### 2. 公式是怎么推出来的

牛顿法的思想是"**用切线代替曲线**"。设当前近似值为 $x_n$，在曲线 $y=f(x)$ 上点 $(x_n, f(x_n))$ 处作切线，切线方程为

$$
y = f(x_n) + f'(x_n)(x - x_n).
$$

令切线与 $x$ 轴相交（即 $y=0$），解出交点：

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}.
$$

这就是**牛顿迭代公式**。对本题 $f(x)=x^2-a$，$f'(x)=2x$，代入得

$$
x_{n+1} = x_n - \frac{x_n^2 - a}{2x_n}
        = x_n - \frac{x_n}{2} + \frac{a}{2x_n}
        = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right).
$$

这个形式也叫"**巴比伦开方法**"：平均一下"猜小了的 $a/x_n$"和"猜大了的 $x_n$"，结果必然更接近真值。

**为什么收敛快？** 可以证明误差大约每迭代一次就**平方**一次：若本次误差为 $\varepsilon$，下次约为 $\varepsilon^2$。比如误差 $10^{-2}$ 一步变 $10^{-4}$，再一步变 $10^{-8}$——所以通常只需寥寥几步。

### 3. 代入本例手算

取 $a=2$，初值 $x_0 = 1.0$（按题设规则 $a<2$ 时取 $1.0$）：

| $n$ | $x_n$ | $\dfrac{2}{x_n}$ | $x_{n+1}=\frac{1}{2}\left(x_n+\frac{2}{x_n}\right)$ |
|---|---|---|---|
| 0 | 1.000000 | 2.000000 | 1.500000 |
| 1 | 1.500000 | 1.333333 | 1.416667 |
| 2 | 1.416667 | 1.411765 | 1.414216 |
| 3 | 1.414216 | 1.414211 | 1.414214 |
| 4 | 1.414214 | 1.414214 | 1.414214 |

第 4 次更新后 $\lvert x_5-x_4\rvert < 10^{-6}$，共迭代 **5 次**，得 $\sqrt{2}\approx 1.414214$，与真值 $\sqrt{2}=1.41421356\ldots$ 一致。

### 4. 编程实现要点

- **循环骨架**：`do-while` 或 `while(1)` + 内部 `break` 都可以；关键是循环里必须**同时**完成"算新值、比较、更新旧值"；
- **保存旧值**：判断 $\lvert x_{\text{新}}-x_{\text{旧}}\rvert$ 需要在覆盖 `x` 之前留一份副本，写成 `double prev = x; x = 0.5*(x + a/x); if (fabs(x-prev) < eps) break;`；
- **绝对值函数**：`fabs` 在 `math.h` 中（本练习允许用它求绝对值，只是不许用 `sqrt`）；
- **计数与输出**：迭代一次计一次数，循环结束后输出结果与次数，再 `return x`。

## 三、解题思路

1. **定初值**：按题设规则 `x = (a >= 2) ? a/2 : 1.0`；
2. **写循环**：保存旧值 → 按公式更新 → 计数 → 判据成立则退出；
3. **输出与返回**：循环外输出 `root` 与 `n`，返回近似值；
4. **`main`**：读入 `a`，调用 `newton_sqrt(a, 1e-6)`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

/* 牛顿迭代法求 sqrt(a)：x_{n+1} = (x_n + a/x_n) / 2 */
double newton_sqrt(double a, double eps)
{
    double x, prev;
    int n = 0;

    x = (a >= 2.0) ? a / 2.0 : 1.0;     /* 初值规则 */
    while (1) {
        prev = x;
        x = 0.5 * (x + a / x);          /* 迭代公式 */
        n++;
        if (fabs(x - prev) < eps)       /* 相邻两次之差足够小 */
            break;
    }
    printf("root = %.6f, n = %d\n", x, n);
    return x;
}

int main(void)
{
    double a;

    scanf("%lf", &a);
    newton_sqrt(a, 1e-6);
    return 0;
}
```

## 五、运行验证

用上表手工迭代核对 $a=2$：5 次迭代后输出 `root = 1.414214, n = 5`，与样例 1 一致。

其他用例（均已按 IEEE-754 double 复算核对）：

| 输入 $a$ | 输出 | 真值 $\sqrt{a}$ |
|---|---|---|
| 2 | `root = 1.414214, n = 5` | 1.414214 |
| 10 | `root = 3.162278, n = 5` | 3.162278 |
| 0.5 | `root = 0.707107, n = 5` | 0.707107 |
| 12345 | `root = 111.108056, n = 11` | 111.108056 |

可见 $a$ 越大、初值越差，迭代次数越多（12345 需 11 次），但都在十几次以内——这就是牛顿法"误差平方收敛"的威力。把 `root` 值自乘，结果与 $a$ 的偏差在 $10^{-6}$ 量级以内，验证正确。

## 六、常见错误与讲解

**错误 1：先更新再比较，旧值已经丢了**

```c
x = 0.5 * (x + a / x);      /* 错：x 被覆盖，无法与旧值比较 */
if (fabs(x - prev) < eps) ...
```

正确做法是先 `prev = x` 再更新。

**错误 2：判据写成"新旧值相等"**

```c
if (x == prev) break;       /* 脆弱：浮点相等几乎不可靠 */
if (fabs(x - prev) < eps)   /* 对：用误差阈值 */
```

**错误 3：除零**

```c
x = 0.5 * (x + a / x);      /* 若 a=0 且初值为 0，a/x 除零 */
```

题设保证 $a>0$ 且初值不为 0；若要更稳，可在 `main` 里先判断 `a <= 0` 时给出提示并退出。

**错误 4：偷偷调用 sqrt**

```c
return sqrt(a);             /* 错：违背练习目的 */
```

## 七、与综合实验的衔接

实验 **B7（方程求根计算器）**中，牛顿迭代是除二分法外的另一大主力算法：二分法**稳但慢**（每次误差减半），牛顿法**快但对初值敏感**（误差每步平方，但选不好初值可能发散或收敛到别的根）。工程上常用"二分法圈区间 + 牛顿法精修"的组合。本练习把迭代公式封装成独立函数、用"相邻两次差"做停止判据，正是实验 B7 中"求根模块"与"精度控制模块"的原型。下一题你将看到同样的思想套用到**弦截/割线**类迭代上时公式如何变化。
