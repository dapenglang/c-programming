## 二、预备知识：函数之间如何"接力"完成统计（零基础阅读）

### 1. 问题是怎么来的

统计一份数据需要总和、均值、最大、最小等多个量。若全写在 `main` 里，代码会又长又乱；若用数组先把数据存起来再统计，又超出了本章的知识边界。因此本题采用两个关键思路：**边读边统计**（不存数据，只维护统计量）与**函数接力**（每个统计量由一个小函数负责更新）。

### 2. 值传递与"传入旧状态、返回新状态"

C 的实参传给形参是**值传递**：函数拿到的是实参的副本，在函数里改动形参**不会**影响外面的变量。所以要让函数把结果"交出来"，必须靠 `return`。于是本题的每个函数都写成同一模式：

$$
\text{新状态} = \texttt{update}(\text{旧状态},\ \text{新增数据}).
$$

例如 `bigger(mx, x)`：把当前最大值 `mx` 和读数 `x` 都传进去，函数返回二者中较大的，`main` 再把它**赋回** `mx = bigger(mx, x);`。反复如此，`mx` 就始终记录着"到目前为止的最大值"。这种方式不依赖全局变量，函数的输入输出一目了然。

### 3. 边读边统计：没有数组怎么办

有了数组，统计顺序是"先全部存下、再遍历"。没有数组时，就要把统计"融进读入过程"：**读一个、算一个**。

- 读到**第一个**数时，它既是当前的总和，也是当前的最大、最小；
- 之后每读到一个新数 `x`：`sum = add(sum, x)` 更新总和；`mx = bigger(mx, x)` 更新最大；`mn = smaller(mn, x)` 更新最小。

读完全部 `n` 个数，`sum`、`mx`、`mn` 就都到位了，均值再用 `mean(sum, n)` 一算即可。这说明：**只要统计量能用"递推"表达，就不必把所有数据都存下来**——这为后面学数组时理解"数组为何有用"提供了对照。

### 4. 函数之间的协作关系

`main` 是调度中心：它维护 `sum`、`mx`、`mn` 三个状态，每读一个数就依次调用 `add`、`bigger`、`smaller` 更新它们；循环结束后调用 `mean` 求均值。四个功能函数彼此独立、各司其职，只通过参数与返回值与 `main` 交换信息——清晰、可测、可复用。

## 三、解题思路

1. **写四个小函数**：`add`、`bigger`、`smaller`、`mean`，接口简单、无副作用；
2. **读 `n` 与首个数**：用首个数把 `sum`、`mx`、`mn` 一起初始化；
3. **循环 `n-1` 次**：每读一个数就更新三个统计量；
4. **打印报表**：`n` 用 `%d`，其余用 `%.3f`，极差用 `mx - mn`。

## 四、参考代码

```c
#include <stdio.h>

/* 累加：返回旧和加新值 */
double add(double s, double x)
{
    return s + x;
}

/* 取较大者 */
double bigger(double a, double b)
{
    return (a > b) ? a : b;
}

/* 取较小者 */
double smaller(double a, double b)
{
    return (a < b) ? a : b;
}

/* 求均值 */
double mean(double s, int n)
{
    return s / n;                  /* s 为 double，自动按浮点除法 */
}

int main(void)
{
    int n, i;
    double x, sum, mx, mn;

    scanf("%d", &n);
    scanf("%lf", &x);              /* 读入第一个测点 */
    sum = x;                       /* 用它初始化三个统计量 */
    mx  = x;
    mn  = x;

    for (i = 1; i < n; i++) {      /* 再读其余 n-1 个测点 */
        scanf("%lf", &x);
        sum = add(sum, x);
        mx  = bigger(mx, x);
        mn  = smaller(mn, x);
    }

    printf("n = %d\n", n);
    printf("sum = %.3f\n", sum);
    printf("mean = %.3f\n", mean(sum, n));
    printf("max = %.3f\n", mx);
    printf("min = %.3f\n", mn);
    printf("range = %.3f\n", mx - mn);
    return 0;
}
```

## 五、运行验证

样例 1（测点 1.20, 3.50, 2.00, 2.80, 2.84）的逐步统计：

| 步骤 | 读入 x | sum | mx | mn |
|---|---|---|---|---|
| 初始化 | 1.20 | 1.200 | 1.200 | 1.200 |
| 第 2 点 | 3.50 | 4.700 | 3.500 | 1.200 |
| 第 3 点 | 2.00 | 6.700 | 3.500 | 1.200 |
| 第 4 点 | 2.80 | 9.500 | 3.500 | 1.200 |
| 第 5 点 | 2.84 | 12.340 | 3.500 | 1.200 |

于是 `sum = 12.340`、`mean = 12.34/5 = 2.468`、`max = 3.500`、`min = 1.200`、`range = 2.300`，与样例 1 输出完全一致。样例 2（0.50, 0.90, 0.70, 1.10）同理得 `sum = 3.200`、`mean = 0.800`、`max = 1.100`、`min = 0.500`、`range = 0.600`。

## 六、常见错误与讲解

**错误 1：忘记用第一个数初始化，把统计量置 0**

```c
sum = 0; mx = 0; mn = 0;       /* 错：若数据全为负，mx 会恒为 0 */
```

最大值/最小值**不能置 0**，必须用第一个真实数据初始化，否则遇到全负或全正数据都会出错。

**错误 2：循环次数多算或漏算**

```c
for (i = 1; i <= n; i++)       /* 错：共读了 n 个数，但已先读 1 个，会多读一次 */
for (i = 1; i < n; i++)        /* 对：再读 n-1 个 */
```

**错误 3：以为函数会"就地"改掉实参**

```c
void bigger(double a, double b) { if (b > a) a = b; }   /* 错：改的是副本，外部 mx 不变 */
mx = bigger(mx, x);            /* 对：靠返回值把新状态交回 */
```

这是 C 值传递最容易踩的坑：**形参的修改不影响实参**，必须用返回值。

**错误 4：均值用了整数除法**

```c
return s / n;                  /* s 若是 int，会截断；本题 s 为 double，正确 */
```

只要 `s` 是 `double`，`s / n` 就按浮点算；若把 `s` 误声明成 `int`，均值会被截断，例如 `12/5` 得 2 而不是 2.4。

## 七、与综合实验的衔接

实验 **C9（板面压力场测点分析）**以及 C7 的载荷报表模块，核心都是"把一串测量值汇总成报表"。本练习用"边读边统计 + 函数接力"完成这件事，既复习了第 2、3 章的数据类型与循环选择，又集中体现了第 4 章模块化的价值：每个统计动作都是一个可读、可测、可复用的函数。更重要的是，它让你**先在不使用数组的条件下**把统计逻辑想清楚——等第 5 章引入数组后，你会发现"先存后算"只是把同一套统计逻辑换一种组织方式，真正的难点（如何定义与维护统计量）已经在这里解决了。
