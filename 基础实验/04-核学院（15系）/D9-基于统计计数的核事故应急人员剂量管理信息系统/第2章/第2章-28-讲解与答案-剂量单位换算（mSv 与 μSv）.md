## 二、预备知识：单位换算为什么就是"乘除一个系数"（零基础阅读）

### 1. 问题是怎么来的

同一条剂量记录，换一种单位来写，数字就变了：0.85 mSv 和 850 μSv 说的是**同一件事**。可是程序若把这两个数字直接相加，就会得到 850.85 这个毫无意义的数。

所以数据处理的第一条纪律是：**先把单位统一，再参与计算**。D9 系统把内部单位统一定为 mSv，于是所有以 μSv 上报的读数，进来第一件事就是换算。

### 2. 公式是怎么来的

"毫"（milli，记作 m）表示 $10^{-3}$，"微"（micro，记作 μ）表示 $10^{-6}$。两者相差 $10^{-3}$，也就是 **1000 倍**：

$$
1\ \text{mSv} = 1000\ \mu\text{Sv}
$$

既然 1000 μSv 才等于 1 mSv，那么把 μSv 化成 mSv 就要**除以 1000**：

$$
d_{\text{mSv}} = \frac{d_{\mu\text{Sv}}}{1000}
$$

反过来，把 mSv 化成 μSv 要**乘以 1000**。口诀：**从小的单位换成大的单位，数值变小，用除**。

### 3. 用本例走一遍

样例 1：读数 850.0 μSv。

- 换算：$850.0 / 1000 = 0.85$ mSv；
- 含义：这一读数约合 0.85 mSv，只有年剂量限值 20 mSv 的 4.25%，属于**正常**档（远小于 20 mSv 的关注阈值）。

样例 2：读数 12500.0 μSv。

- 换算：$12500.0 / 1000 = 12.5$ mSv；
- 含义：12.5 mSv 已达年限值 20 mSv 的 62.5%，属于**关注**档（≥20 mSv 为超限档，这里尚未超限）。这正是 D9 分级要区分的对象。

**可见换算不是为了好看，而是为了让"是否接近 20 mSv"这个判断能在同一个尺度上进行。**

### 4. 编程时怎么用它

整个程序只有四个量：一个常量（1000.0）、一个整数编号、一个输入读数、一个待求结果。程序结构就是"**读两个数 → 除一步 → 输出两个数**"的顺序流程，与练习 01（风压系数）的结构完全一样，只是公式从插值换成了除法。

唯一要留心的两点：

1. **系数写成 1000.0 而不是 1000**。若写成整数 `1000`，在 `d_usv / 1000` 中虽然 `d_usv` 是 double 会触发隐式转换，但这份代码一旦被人搬到纯整数上下文就会出错；更重要的是，**物理常数按实数写是良好习惯**。
2. **格式符与类型对齐**：编号 `%d`，剂量 `%lf`（读）/`%.4f`（写）。这是本章最容易出错的地方。

> **这个思想在综合实验中反复出现**：D9 剂量单位统一、D7 剂量率单位换算（μSv/h 与 mSv/h）、D6 活度单位换算（Bq 与 kBq），全部是"乘除一个 10 的幂次系数"。**统一的量纲是数据可比、可累加、可分级的前提。**

## 三、解题思路

1. **确定常量**：换算系数 1000.0 是规范值，定义为 `const double USV_PER_MSV = 1000.0;`；
2. **确定变量**：编号 `int id`、读数 `double d_usv`、结果 `double d_msv`；
3. **读入**：`scanf("%d %lf", &id, &d_usv);`——注意 `%d` 与 `%lf` 及两个 `&`；
4. **换算**：`d_msv = d_usv / USV_PER_MSV;`；
5. **输出**：`printf("id = %d, dose = %.4f mSv (%.1f uSv)\n", id, d_msv, d_usv);`

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 规范换算系数：1 mSv = 1000 uSv（m 为 10^-3，u 为 10^-6，相差千倍） */
    const double USV_PER_MSV = 1000.0;

    int    id;          /* 人员编号（整数） */
    double d_usv;       /* 录入读数，单位 uSv */
    double d_msv;       /* 换算结果，单位 mSv（系统内部统一单位） */

    /* 读入编号与读数：%d 对应 int，%lf 对应 double，两者都要取地址 */
    scanf("%d %lf", &id, &d_usv);

    /* 单位换算：uSv 化成 mSv，除以 1000 */
    d_msv = d_usv / USV_PER_MSV;

    /* 输出：结果保留 4 位小数，同时回显原始读数（保留 1 位小数） */
    printf("id = %d, dose = %.4f mSv (%.1f uSv)\n", id, d_msv, d_usv);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 1001 850.0 | 850.0 / 1000 = 0.8500 | `id = 1001, dose = 0.8500 mSv (850.0 uSv)` ✓ |
| 1024 12500.0 | 12500.0 / 1000 = 12.5000 | `id = 1024, dose = 12.5000 mSv (12500.0 uSv)` ✓ |
| 2007 20000.0 | 20000.0 / 1000 = 20.0000（恰好落在限值） | `id = 2007, dose = 20.0000 mSv (20000.0 uSv)` ✓ |
| 1001 0.0 | 0.0 / 1000 = 0.0000（本底未受照） | `id = 1001, dose = 0.0000 mSv (0.0 uSv)` ✓ |

第三例说明：**20 mSv 恰好等于 20000 μSv**——这个数值后来会成为 D9 分级判定的关键分界，换算正确与否直接决定等级判定。

## 六、常见错误与讲解

**错误 1：换算方向搞反（最典型）**

```c
d_msv = d_usv * 1000.0;    /* 错：850 uSv 会变成 850000 mSv，荒谬 */
d_msv = d_usv / 1000.0;    /* 对：小单位换大单位，数值应变小，用除 */
```

检查办法：拿 850 μSv 这个数心里过一遍——0.85 mSv 合理，850000 mSv 显然是核爆级别。**换算后用量级直觉验证一遍。**

**错误 2：换算系数写成整数导致类型问题**

```c
const int    COEF = 1000;      /* 不推荐：物理常数应按实数书写 */
const double COEF = 1000.0;    /* 对：明确是实数常量 */
```

**错误 3：scanf 忘记取地址符**

```c
scanf("%d %lf", id, d_usv);      /* 错：程序崩溃或读不进数据 */
scanf("%d %lf", &id, &d_usv);    /* 对：每个参数前都要加 & */
```

**错误 4：格式符与类型不匹配**

```c
printf("dose = %d\n", d_msv);            /* 错：double 用 %d 输出得到乱码 */
printf("dose = %.4f\n", d_msv);          /* 对 */
scanf("%d", &d_usv);                     /* 错：d_usv 是 double，应用 %lf */
```

编号是 `int`（`%d`），剂量是 `double`（`%lf`/`%.4f`）——**同一行里混用不同类型时，逐个对齐格式符**。

## 七、与综合实验的衔接

- 实验 **D9（核事故应急人员剂量管理信息系统）**中，本练习是"数据录入"环节的第一步：真实系统会连续读入多名人员的多次读数，把每条的 μSv 值统一换算成 mSv 后，再按人员编号累加（练习 27 第 3 章）、分档统计（练习 28 第 3 章）、存进数组（练习 30 第 5 章）、打包成结构体（练习 28 第 7 章），最终写成分级名册文件（练习 27 第 8 章）。**没有统一单位，后面所有的累加和比较都是错的**；
- 与前面练习的衔接：本题与练习 01（风压系数插值）结构相同，都是"常量 + 读入 + 一步计算 + 格式化输出"的顺序流程；区别只在公式。练习 13（测点压力单位换算）、练习 24（交通流量单位换算）也是同一套路。**单位换算 = 乘除一个 10 的幂次系数，这是数据治理的第一课。**
