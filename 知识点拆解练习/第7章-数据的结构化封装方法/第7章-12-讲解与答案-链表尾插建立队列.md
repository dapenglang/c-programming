## 二、预备知识：尾插法为什么需要 tail 指针（零基础阅读）

### 1. 数组的局限与链表的两个基本动作

数组长度固定、插入删除要搬移，因此在"记录条数事先不定"的场合要用链表（详见练习 11）。链表上有两个最基本的插入动作：

- **头插**：新节点放链头，简单但要改 `head`，插完顺序与输入**相反**；
- **尾插**：新节点放链尾，能保持输入顺序，但要把链"接"到最后一个节点后面。

尾插得到的链表正好是一个**队列**：先入的节点在前、后入的在后，遵循"先来先服务（First In First Out，FIFO）"。碰撞模拟里冰块的到达顺序正是这个语义，所以必须尾插。

### 2. 尾插的难点：谁是"最后一个节点"

要用尾插，先得找到当前链表的最后一个节点。**从 `head` 一路走到 `next == NULL`** 就是尾巴，但每插一次都要走一趟，节点一多代价就大。更好的办法是**额外记一个 `tail` 指针**，让它始终指着尾节点。这样"挂到尾巴上"就变成两步指针改接，与链长无关（时间 $O(1)$）：

```
初始（空链）： head = NULL , tail = NULL

插入第一个节点 N1：
    head ──► [N1|NULL]
    tail ──► [N1|NULL]          head 与 tail 都指向 N1

再插入 N2（尾插）：
    tail->next = p;  tail = p;
    head ──► [N1] ──► [N2|NULL]
                      ▲
                      tail

再插入 N3：
    head ──► [N1] ──► [N2] ──► [N3|NULL]
                                ▲
                                tail
```

### 3. 尾插的四步与改接图

设链表非空，`tail` 指向当前尾节点 T，新节点记为 N：

```
改接前：  head ──► … ──► [T|NULL]
                          ▲
                          tail

第 1 步：p->next = NULL;      /* N 将成为新尾，先置空 */
第 2 步：tail->next = p;      /* 老尾 T 的 next 指向 N */
          head ──► … ──► [T] ──► [N|NULL]
                          ▲        ▲
                     (旧 tail)     p

第 3 步：tail = p;            /* tail 前移到 N */
          head ──► … ──► [T] ──► [N|NULL]
                                     ▲
                                     tail
```

若链表原来为空，则第 2 步无处可接，要单独处理：直接把 `head` 和 `tail` 同时指向新节点。所以尾插的判断是"**空链和非空链用不同分支**"。

### 4. 关于 malloc/free

每个节点都要用 `malloc(sizeof(struct IceBlock))` 现场申请（向系统借一块刚好放下一个节点的内存，返回首地址），**成功非 `NULL`、失败为 `NULL`**，所以每次申请后都要 `if (p == NULL)` 检查。程序结束前必须逐个 `free` 归还内存，避免内存泄漏。这两点与练习 11 完全相同，不再赘述。

## 三、解题思路

1. **定义节点与指针**：函数外定义 `struct IceBlock`；`main` 中 `head = tail = NULL`；
2. **循环读入 n 条记录**：`malloc` 新节点、检查 `NULL`、填数据、`p->next = NULL`；
3. **尾插**：若 `head == NULL` 则 `head = tail = p`；否则 `tail->next = p; tail = p;`；
4. **遍历输出**：从 `head` 起 `while (p != NULL)` 输出，顺序与输入一致；
5. **释放内存**：`while (head != NULL)` 逐个 `free`。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

/* 冰块节点：数据域 + 指针域 */
struct IceBlock {
    int    id;                  /* 冰块编号 */
    double mass;                /* 质量，kg */
    struct IceBlock *next;      /* 指向下一个节点 */
};

int main(void)
{
    int n, i, id, count;
    double mass;
    struct IceBlock *head = NULL, *tail = NULL, *p;

    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        scanf("%d %lf", &id, &mass);

        p = (struct IceBlock *)malloc(sizeof(struct IceBlock));
        if (p == NULL) {                    /* 申请失败检查 */
            printf("malloc failed\n");
            return 1;
        }
        p->id = id;
        p->mass = mass;
        p->next = NULL;                     /* 新节点先置为尾 */

        if (head == NULL)                   /* 空链：头尾同指新节点 */
            head = tail = p;
        else {                              /* 非空：接到尾部并更新 tail */
            tail->next = p;
            tail = p;
        }
    }

    count = 0;
    p = head;                               /* 从链头开始遍历 */
    while (p != NULL) {
        printf("%d %.2f\n", p->id, p->mass);
        count++;
        p = p->next;
    }
    printf("count = %d\n", count);

    while (head != NULL) {                  /* 逐个释放 */
        p = head;
        head = head->next;
        free(p);
    }
    return 0;
}
```

## 五、运行验证

以样例 1（依次读入 `1 120.5`、`2 88.0`、`3 150.2`）为例，尾插过程为：

```
初始:      head = NULL , tail = NULL
插入 (1,120.5):  head ──► [1|120.5|NULL] ◄── tail
插入 (2,88.0):   head ──► [1|120.5|●] ──► [2|88.0|NULL] ◄── tail
插入 (3,150.2):  head ──► [1|120.5|●] ──► [2|88.0|●] ──► [3|150.2|NULL] ◄── tail
```

从 `head` 遍历输出：

```
1 120.50
2 88.00
3 150.20
count = 3
```

与样例 1 完全一致，**顺序与输入相同**——这正是尾插（队列）区别于头插的地方。样例 2 依次读入 `11`、`12`、`13`、`14`，输出顺序同样是 `11 12 13 14`，末行 `count = 4`，与样例 2 一致。当 `n = 0` 时，`head`、`tail` 保持 `NULL`，输出只有 `count = 0`。

## 六、常见错误与讲解

**错误 1：新节点的 next 没有置 NULL**

```c
p->next = ???;         /* 错：忘记写 p->next = NULL; */
```
新节点将成为尾节点，它的 `next` 必须是 `NULL`，否则遍历到它时会顺着一个**随机地址**继续走（野指针），程序崩溃或输出乱码。

**错误 2：忘记更新 tail，导致重复覆盖**

```c
if (head == NULL) head = tail = p;
else tail->next = p;          /* 错：没有 tail = p; */
```
漏掉 `tail = p;` 后，`tail` 永远指着第一个节点。第二次尾插时又执行 `tail->next = p`，就把上一次挂上去的节点**覆盖**了，链表只剩两个节点。**挂接与移动尾指针必须成对出现。**

**错误 3：空链表分支缺失**

```c
tail->next = p;   /* 错：head 为 NULL 时 tail 也是 NULL，解引用崩溃 */
tail = p;
```
空链时 `tail` 是 `NULL`，直接写 `tail->next` 会访问非法地址。所以尾插必须先判断 `head == NULL`。

**错误 4：忘记 free**

链表节点是用 `malloc` 借来的，程序结束前要 `free` 归还；释放顺序仍是"先存 `head->next`，再 `free(head)`"，避免访问已释放内存。

## 七、与综合实验的衔接

实验 **C6《冰块与结构碰撞模拟系统》**中，计算域里冰块的入场顺序决定了碰撞事件的时间线，必须严格保持"先到先算"。本题的尾插链表就是承载这块队列的数据结构：每来一个冰块对象，就尾插一个节点；碰撞主循环按链表顺序（也就是到达顺序）逐个取出处理。把头插与尾插都做一遍，你就同时掌握了"栈"（头插、后进先出）与"队列"（尾插、先进先出）两种链式结构。下一题将练习在不动结构的前提下**遍历链表做统计**——这是从"建链"走向"用链"的第一步。
