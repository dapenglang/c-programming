# 第 3 章 练习 16　投点法估算 π

**对应章节**：3 结构化程序设计方法（3.5 数值求解方法——蒙特卡洛法、3.3 循环结构、3.2 选择结构、3.4 关系与逻辑运算）

**场景来源**：综合实验 C5《冰区蒙特卡洛模拟》、C10《碎冰场分布统计分析系统》（水声学院）——本练习是该实验中"投点统计"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

蒙特卡洛方法的核心思想是"**用大量随机试验的统计比例去逼近一个几何量**"。经典例子是估算圆周率 $\pi$：往一个正方形里随机撒很多点，数一数有多少点落进了内接的四分之一圆，落在圆内的点数与总点数的比例就等于两块面积的比 $\pi/4$，由此反推出 $\pi$。在碎冰场模拟中，判断"碎冰是否落在某区域内"用的完全是同一套逻辑，只是把圆换成了冰区边界。本练习用估算 $\pi$ 把蒙特卡洛流程完整走一遍。

## 二、任务要求

编写一个完整程序 `montecarlo_pi.c`：

1. 从键盘读入两个整数，用空格分隔：随机数种子 `r0`、投点总数 `n`（题目保证 `r0 > 0`，`1 ≤ n ≤ 100000`）；
2. 复用上一题的线性同余发生器（参数 `A = 1103515245`、`C = 12345`、`M = 2^{31}`），生成 $2n$ 个 $[0,1)$ 上的随机数，每两个配成一个点的坐标 $(x, y)$；
3. 用 **for 循环**处理 n 个点：若 $x^2 + y^2 \le 1$ 则计入圆内点数；
4. 统计完成后，按 $\pi \approx 4 \times \dfrac{内部点数}{n}$ 估算 $\pi$，输出内部点数与估计值。

**严禁使用 `rand()`**，随机数必须由线性同余递推式自己产生。

## 三、输入输出格式

**输入**：一行，两个整数 `r0 n`，中间用空格分隔。

**输出**：

- 第一行：`inside = 内部点数`（整数）；
- 第二行：`pi = 估计值`（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
1 10000
```
输出：
```
inside = 7839
pi = 3.135600
```

**样例 2**

输入：
```
2024 50000
```
输出：
```
inside = 39284
pi = 3.142720
```

## 五、提示

在边长为 1 的单位正方形 $[0,1)\times[0,1)$ 内随机投点，落在四分之一圆 $x^2 + y^2 \le 1$ 内的概率为

$$
P = \frac{\text{四分之一圆面积}}{\text{正方形面积}} = \frac{\pi/4}{1} = \frac{\pi}{4}
$$

当投点数 $n$ 足够大时，实际"落圆比例"接近概率：

$$
\frac{\text{内部点数}}{n} \approx \frac{\pi}{4}
\quad\Longrightarrow\quad
\pi \approx 4 \times \frac{\text{内部点数}}{n}
$$

每个点的两个坐标用连续两次随机数产生：先取 $x = u_{2i-1}$，再取 $y = u_{2i}$。注意判断条件写成 `x*x + y*y <= 1.0`（含等号）。

**完成本练习后你将具备的能力**：把上一题的随机数发生器用于统计模拟、用循环 + 选择完成"逐点判断与计数"、理解"概率比例 ≈ 面积比"这一蒙特卡洛核心思想——可直接迁移到 C5/C10 中判断碎冰分布比例的任务。
