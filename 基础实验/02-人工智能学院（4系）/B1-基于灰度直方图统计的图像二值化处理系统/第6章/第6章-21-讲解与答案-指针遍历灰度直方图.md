## 二、预备知识：指针与数组的基本原理（零基础阅读）

### 1. 问题是怎么来的：内存像一排柜子

计算机内存可以想象成**一排编号的储物柜**，每个柜子有一个唯一的**柜号**（地址），里面放着一个值。变量就好比"给某个柜子起个好记的名字"：

```
柜号:  1000  1004  1008  1012   ...
内容:  [ 1 ] [ 2 ] [ 3 ] [ 4 ]  ...
名字:   hist[0] hist[1] hist[2] hist[3]
```

数组 `int hist[256]` 就是**连续 256 个柜子**（每个 `int` 占 4 个字节，所以柜号每次加 4）。

问题来了：如果只知道"数组从 1000 号柜开始"，怎么找到第 5 个元素？答案是从 1000 号开始，**往后数 5 个柜子**。这个"从某个柜号出发、能往后数"的东西，就是**指针**。

### 2. 指针是什么：存柜号的纸条

**指针本身也是一个变量，只不过它存的不是普通数值，而是一个柜号（地址）。** 可以把它想成一张"写着柜号的纸条"：

```
指针变量 p:  [ 1000 ]     <- 纸条上写着 1000 号柜
                |
                v
             1000 号柜里放着 hist[0] = 1
```

`int *p` 定义的就是"一张指向 int 柜子的纸条"。写 `p = hist;` 就是把"数组开头柜号"抄到纸条上（数组名 `hist` 本身就等于首地址）。

### 3. 两个最基本的操作

- **取值 `*p`**：按纸条上的柜号去**打开柜子**，取出里面的东西。`*p` 就是"p 指向的那个元素"。
- **移动 `p++`**：把纸条上的柜号改成"下一个柜子"的号（因为 int 占 4 字节，1000 会变成 1004）。所以 `p++` 就是"走到下一个元素"。

用一句话记住：**`*p` 是"打开柜子拿东西"，`p++` 是"走到下一个柜子"。**

### 4. 为什么 `hist[i]` 和指针是一回事

C 语言规定：`hist[i]` 完全等价于 `*(hist + i)`——"从头往后走 $i$ 个柜子，再打开拿东西"。所以下面两种写法效果完全一样：

```c
hist[i]        /* 带下标的写法 */
*(p + i)       /* 指针的写法，p = hist */
```

指针遍历只是改用"一边走一边取"的方式：`*p` 取当前元素，`p++` 走到下一个，循环往复，走完 256 个。

### 5. 用本例走一遍

设直方图前 9 个值为 $1,2,3,4,5,6,7,8,0$，其余全 0。

- 峰值：从头走，$1\to2\to\dots\to8$ 不断刷新（严格大于才更新），到 8 后 0 不再大于它，故峰值是灰度 7、像素数 8；
- 谷值：先设第 0 个（值 1）为最小，走到灰度 1 时 $2<1$ 不成立，走到灰度 8 时 $0<1$ 成立，更新为灰度 8、像素数 0；后面都是 0，不**严格小于**就不再更新。

结果 `peak: gray = 7, cnt = 8`、`min : gray = 8, cnt = 0`，与样例一致。

> **这个思想在综合实验中反复出现**：B1 直方图峰值分析、B2 序列最值定位、B10 相似度最值，都是"遍历数组找最值"同一个套路，指针只是换一种走法。

## 三、解题思路

1. **读入数组**：循环 `scanf("%d", &hist[i])` 读 256 个数；
2. **初始化**：设 `p = hist`，先把第 0 个值当成峰值和谷值；
3. **指针遍历**：循环 256 次，每次用 `*p` 与当前最值比较，严格大于/小于就更新，并记录灰度级（可用计数器 `g` 同步递增）；
4. **移动指针**：循环末尾 `p++`；
5. **输出**：两条 `printf`。

## 四、参考代码

```c
#include <stdio.h>

#define LEVELS 256      /* 灰度级数 */

int main(void)
{
    int hist[LEVELS];   /* 灰度直方图：各灰度级的像素数 */
    int *p;             /* 遍历用的指针 */
    int i, g;

    int peak_gray = 0, peak_cnt;   /* 峰值：像素最多的灰度级与其像素数 */
    int min_gray  = 0, min_cnt;    /* 谷值：像素最少的灰度级与其像素数 */

    /* 读入 256 个灰度级的像素数 */
    for (i = 0; i < LEVELS; i++)
        scanf("%d", &hist[i]);

    /* 指针指向数组开头 */
    p = hist;

    /* 以第 0 个元素作为最值的初值 */
    peak_cnt = *p;
    min_cnt  = *p;

    /* 指针遍历：*p 取当前元素，p++ 走到下一个 */
    for (g = 0; g < LEVELS; g++) {
        if (*p > peak_cnt) {        /* 严格大于才更新：并列时保留小灰度 */
            peak_cnt  = *p;
            peak_gray = g;
        }
        if (*p < min_cnt) {         /* 严格小于才更新：并列时保留小灰度 */
            min_cnt  = *p;
            min_gray = g;
        }
        p++;                        /* 指针后移一位 */
    }

    /* 输出峰值与谷值 */
    printf("peak: gray = %d, cnt = %d\n", peak_gray, peak_cnt);
    printf("min : gray = %d, cnt = %d\n", min_gray, min_cnt);

    return 0;
}
```

## 五、运行验证

| 直方图内容（前若干项，其余 0） | 手算过程 | 程序输出 |
|---|---|---|
| 1,2,3,4,5,6,7,8,0,… | 峰=8@灰度7；谷=0@灰度8 | `peak: gray = 7, cnt = 8` / `min : gray = 8, cnt = 0` ✓ |
| 5,5,5,5,…（全为 5） | 全部相等，取灰度 0 | `peak: gray = 0, cnt = 5` / `min : gray = 0, cnt = 5` ✓ |
| 0,0,0,…（全为 0） | 全 0，取灰度 0 | `peak: gray = 0, cnt = 0` / `min : gray = 0, cnt = 0` ✓ |
| 3,1,4,1,5,…（其余 0） | 峰=5@灰度4，谷=0@灰度5 | `peak: gray = 4, cnt = 5` / `min : gray = 5, cnt = 0` ✓ |

全相等与全零的边界情形都给出灰度 0，符合"并列取小灰度"规则。

## 六、常见错误与讲解

**错误 1：忘记让指针前进（最典型）**

```c
for (g = 0; g < LEVELS; g++) {
    if (*p > peak_cnt) { ... }   /* 错：漏了 p++，p 一直指第一个 */
}
```

漏掉 `p++` 会反复比较同一个元素，结果必错，且可能陷入逻辑死循环式的误解。

**错误 2：用 `p` 而不是 `*p` 比较**

```c
if (p > peak_cnt)      /* 错：比较的是"柜号"，不是柜里的值 */
if (*p > peak_cnt)     /* 对：*p 才是元素值 */
```

这是初学指针最容易犯的错——**记住"打开柜子"要带星号**。

**错误 3：指针移动越界**

```c
for (g = 0; g <= LEVELS; g++)   /* 错：多走一步，读到 256 号非法位置 */
for (g = 0; g < LEVELS; g++)    /* 对：正好走 256 个元素 */
```

**错误 4：把「>=」用作峰值判断，破坏并列取小规则**

```c
if (*p >= peak_cnt) { peak_gray = g; }   /* 错：并列时改成更大的灰度 */
if (*p >  peak_cnt) { peak_gray = g; }   /* 对：严格大于，保留小灰度 */
```
