# 第 6 章 练习 04　指针算术与元素访问

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用、6.3 指针与数组）

**场景来源**：综合实验 C1《海洋声速剖面插值系统》（水声学院）——本练习是该实验中"声速表元素定位访问"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

声速剖面插值系统 C1 内部维护一张离散声速表：6 个标准深度档对应的声速（单位 m/s）。插值、绘图、输出报表时，程序需要频繁"跳到表中任意一档"取值，例如直接取第 4 档（下标 3）参与计算。用指针表达这种"跳档"就是**指针算术**：`p + 3` 直接指向下标 3 的元素。本练习要求你用两种等价写法 `*(p + i)` 与 `p[i]` 访问同一张声速表，并观察指针加法前后地址的变化，亲手验证"**指针加 1 跨过一个元素而不是一个字节**"。

## 二、任务要求

编写一个完整程序 `svp_access.c`：

1. 读入 6 个声速值存入 `double` 数组 `c`，定义指针 `p` 指向首元素；
2. 用 `*(p + i)` 形式遍历输出全部 6 个声速（保留 1 位小数）；
3. 用 `p[i]` 形式再次遍历输出，验证两种写法输出完全相同；
4. 输出 `p` 当前指向的元素（下标 0）与 `*(p + 3)`（下标 3）的值，并分别打印两个地址，观察地址差。

## 三、输入输出格式

**输入**：一行，6 个实数（m/s），以空格分隔。

**输出**：四行。
第 1 行：`*(p+i)` 方式输出的 6 个声速，空格分隔，保留 1 位小数；
第 2 行：`p[i]` 方式输出的 6 个声速，格式同上；
第 3 行：`first = 值`（即 `*p`）；
第 4 行：`p[3] = 值 addr0 = 地址 addr3 = 地址`（地址以 `%p` 输出，两次运行不同，以"addr3 比 addr0 大 24"为准）。

## 四、样例

**样例 1**

输入：
```
1448.6 1450.2 1452.1 1451.0 1449.3 1447.8
```
输出：
```
*(p+i): 1448.6 1450.2 1452.1 1451.0 1449.3 1447.8
p[i]  : 1448.6 1450.2 1452.1 1451.0 1449.3 1447.8
first = 1448.6
p[3] = 1451.0 addr0 = 0061FEF0 addr3 = 0061FF08
```

**样例 2**

输入：
```
1500.0 1502.5 1505.0 1507.5 1510.0 1512.5
```
输出：
```
*(p+i): 1500.0 1502.5 1505.0 1507.5 1510.0 1512.5
p[i]  : 1500.0 1502.5 1505.0 1507.5 1510.0 1512.5
first = 1500.0
p[3] = 1507.5 addr0 = 0061FEF0 addr3 = 0061FF08
```

（地址为示意值：`double` 占 8 字节，下标 3 的地址比下标 0 大 $3 \times 8 = 24$ 字节，即十六进制大 `18`。）

## 五、提示

1. 输出格式建议：第 1 行先打印标签 `*(p+i):` 再输出数值，便于与第 2 行对照；
2. `*(p + i)` 中括号必不可少：`*p + i` 的含义是"先取 `*p` 再加 i"，完全不同；
3. `p[i]` 与 `*(p + i)` 等价是 C 语言的规定——下标运算符本来就是按"指针 + 偏移"定义的；
4. 地址差验证：`addr3 - addr0` 应为 24 字节（十六进制 `0x18`），这是"指针加 1 跨过一个元素（8 字节）"的直接证据。

**完成本练习后你将具备的能力**：熟练运用 `*(p+i)` 与 `p[i]` 两种等价访问方式、理解指针算术的"按元素跨度"规则、用地址差定量验证指针运算——实验 C1 中任意跳档取数的基础。
