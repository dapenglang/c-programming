## 二、预备知识：把插值算法接到真实数据上的基本原理（零基础阅读）

### 1. 声速剖面为什么需要多点插值

海洋表层受太阳加热、深层受压力压实，声速随深度的变化是一条**曲线**而不是直线。实验 C1 的声线跟踪程序每前进一小步就要问一次"这个深度声速多少"，而实测只给出每 100 m 一档的离散表。若只用相邻两档做线性插值，在曲线弯曲明显的地方会带来系统误差；取**多个节点**做拉格朗日插值，让一条光滑多项式穿过全部节点，中间深度的声速就还原得更准。第 17 题已经把算法原理（基函数在自身节点为 1、在其他节点为 0，加权平均）推导清楚，本题不再重复推导，重点是**迁移**：把 x 换成深度 $d$、y 换成声速 $c$，公式为

$$
c(d) = \sum_{i=0}^{n-1} c_i L_i(d), \qquad L_i(d) = \prod_{\substack{j=0 \\ j \neq i}}^{n-1} \frac{d - d_j}{d_i - d_j}
$$

### 2. 各环节职责：本题比第 17 题多了什么

- **读入环节**：与第 17 题相同——fopen 检查、读 n、循环读节点、fclose；
- **校验环节（新增）**：物理上的声速剖面只在实测深度范围内有效。待求深度 $d_q$ 若落在 $[d_0, d_{n-1}]$ 之外，用插值多项式"外推"是没有物理依据的（多项式在区间外可能飞出天际）。所以范围检查必须放在插值计算**之前**，这是数值程序的基本自我保护；
- **计算环节**：双重循环与第 17 题逐字相同——外层累加、内层连乘、连乘变量每轮重置 1.0；
- **输出环节**：按物理量习惯格式输出（深度 1 位小数、声速 2 位小数）。

### 3. 样例数据为什么选这四个点

样例的四个节点 $(0, 1449.0)$、$(100, 1453.0)$、$(200, 1455.0)$、$(300, 1455.0)$ 恰好都落在二次曲线

$$
c(d) = 1449 + 0.05d - 0.0001d^2 \quad (\text{m/s})
$$

上（逐点验证：$c(100) = 1449 + 5 - 1 = 1453$，$c(200) = 1449 + 10 - 4 = 1455$，$c(300) = 1449 + 15 - 9 = 1455$）。四个点唯一确定一个次数不超过 3 的多项式，而这条二次曲线本身就是这样的多项式，所以**三次拉格朗日插值会精确还原这条曲线**——任何深度处的插值结果都应等于曲线公式算出的值。这给了我们一把"标准尺"来核对程序。

### 4. 文件指针生命周期

与第 17 题相同：fin 只在"读节点表"这一站活跃，读完立即 fclose；插值与输出只发生在内存与屏幕之间，不再涉及文件。fopen 检查、失败即退两条纪律照旧。

## 三、解题思路

1. **读文件**：打开 svp.txt 检查，读 n，循环读 (d[i], c[i])，fclose；
2. **范围检查**：dq 不在 $[d_0, d_{n-1}]$ 内则输出提示并结束；
3. **双重循环插值**：与第 17 题同构，外层累加 $c_i L_i(d_q)$，内层跳过 $j=i$ 连乘；
4. **输出**：按 `c(%.1f m) = %.2f m/s` 打印。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    int n, i, j;
    double d[20], c[20];   /* 深度 m、声速 m/s */
    double dq;             /* 待求深度 */
    double v, t;           /* v 为插值结果，t 为基函数值 */

    /* 1. 读入声速剖面表 */
    fp = fopen("svp.txt", "r");
    if (fp == NULL) {
        printf("错误：无法打开 svp.txt\n");
        return 1;
    }
    fscanf(fp, "%d", &n);
    for (i = 0; i < n; i++)
        fscanf(fp, "%lf %lf", &d[i], &c[i]);
    fclose(fp);

    /* 2. 读入待求深度并做范围检查 */
    scanf("%lf", &dq);
    if (dq < d[0] || dq > d[n - 1]) {
        printf("深度超出剖面范围\n");
        return 0;
    }

    /* 3. 拉格朗日插值：v = sum c[i] * L[i](dq) */
    v = 0.0;
    for (i = 0; i < n; i++) {
        t = 1.0;                            /* 连乘初值，每轮重置 */
        for (j = 0; j < n; j++) {
            if (j == i)
                continue;
            t = t * (dq - d[j]) / (d[i] - d[j]);
        }
        v = v + c[i] * t;
    }

    /* 4. 输出 */
    printf("c(%.1f m) = %.2f m/s\n", dq, v);

    return 0;
}
```

## 五、运行验证

**样例 1（dq = 150）手算**：四个基函数值——

$$
L_0 = \frac{(150-100)(150-200)(150-300)}{(0-100)(0-200)(0-300)} = \frac{375000}{-6000000} = -0.0625
$$

$$
L_1 = \frac{(150)(150-200)(150-300)}{(100)(100-200)(100-300)} = \frac{1125000}{2000000} = 0.5625
$$

$$
L_2 = \frac{(150)(50)(150-300)}{(200)(100)(200-300)} = \frac{-1125000}{-2000000} = 0.5625
$$

$$
L_3 = \frac{(150)(50)(150-200)}{(300)(200)(100)} = \frac{-375000}{6000000} = -0.0625
$$

检验基函数之和：$-0.0625 + 0.5625 + 0.5625 - 0.0625 = 1$。加权求和：

$$
c(150) = 1449 \times (-0.0625) + 1453 \times 0.5625 + 1455 \times 0.5625 + 1455 \times (-0.0625)
$$

$$
= -90.5625 + 817.3125 + 818.4375 - 90.9375 = 1454.25
$$

**标准尺核对**：曲线公式 $c(150) = 1449 + 0.05 \times 150 - 0.0001 \times 150^2 = 1449 + 7.5 - 2.25 = 1454.25$——与手算、与程序输出三方一致。程序输出：

```
c(150.0 m) = 1454.25 m/s
```

**样例 2（dq = 250）**：程序输出 `c(250.0 m) = 1455.25 m/s`。标准尺核对：$c(250) = 1449 + 12.5 - 6.25 = 1455.25$，一致。

**样例 3（dq = 400）**：超出 $[0, 300]$，程序输出：

```
深度超出剖面范围
```

**文件内容变化**：svp.txt 为只读输入，前后不变。

## 六、常见错误与讲解

**错误 1：范围检查用错边界或漏做**

```c
if (dq < d[0] && dq > d[n - 1])    /* 错：逻辑且，任何 dq 都不成立，检查形同虚设 */
if (dq < d[0] || dq > d[n - 1])    /* 对：越下界或越上界都算越界 */
```

漏做检查时，dq = 400 会被外推成 1478 左右的一个数，屏幕上看起来"一切正常"——错得无声无息，比崩溃更危险。

**错误 2：内层循环不跳过 j == i（除零风险）**

与第 17 题相同：$j = i$ 的因子必须排除。本题若不做范围检查又恰好让 dq 等于某节点深度，分母 $(d_i - d_j)$ 中会出现 0，程序输出 inf 或直接崩溃。

**错误 3：把深度数组与声速数组读反**

```c
fscanf(fp, "%lf %lf", &c[i], &d[i]);   /* 错：文件是 "深度 声速" 的顺序 */
```

读反后范围检查、插值全错。核对方法：用样例 3 输入 400，若读反了，程序会把 400 当声速、拿深度数组当声速表插值，输出荒谬结果。

**错误 4：输出格式串与变量个数不匹配**

```c
printf("c(%.1f m) = %.2f m/s\n", dq);        /* 错：两个占位符只传了一个实参 */
printf("c(%.1f m) = %.2f m/s\n", dq, v);     /* 对 */
```

## 七、与综合实验的衔接

- 实验 **C1（声速剖面与声线跟踪）**中，声线每传播一小步都要用当前深度的声速更新方向角，"逐深度查声速"调用的正是本题的插值函数。实验里通常会再加一层优化：**先二分查找定位 dq 所在的节点区间，只取附近 3~4 个节点做低次拉格朗日插值**（分段插值），既准又稳——第 5 章的二分查找（第 7 章 7.6 也有）在此派上用场，这也是"分段低次优于全局高次"工程经验的具体落地；
- 与第 17 题对照可见：**算法与数据分离**——points.txt 换成 svp.txt，x 换成 d、y 换成 c，程序主体零改动。练习 20 将把"文件读入 + 算法计算 + 文件写出"整条流水线一次贯通，本章的全部技能在那里合体。
