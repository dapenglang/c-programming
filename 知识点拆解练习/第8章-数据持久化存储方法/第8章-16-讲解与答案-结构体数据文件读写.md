## 二、预备知识："结构体 + 文件"数据管理的基本原理（零基础阅读）

### 1. 为什么这样组织数据流

一条冰块记录有三种成分：字符串编号、两个实数。若用三个**平行数组**分别存编号、质量、速度，读写时极易"对不上行"；而结构体把一条记录捆成一个变量 `ice[i]`，数组的每个元素就是一个完整的冰块。与文件打交道时，数据流分两站：

```
ice_in.txt --fscanf逐字段--> ice[i].id/.mass/.speed（内存结构体数组）
            --计算动量--> ice_out.txt --fprintf逐字段--（写出四列）
```

**关键理解：结构体只活在内存里，文件里只有文本。** fscanf/fprintf 每次"借道"一个临时变量或直接访问成员，把文本一行拆给结构体的各个成员（读入），或把各成员拼成文本一行（写出）。

### 2. 各环节的职责

- **读入环节**：`fscanf(fin, "%s %lf %lf", ice[i].id, &ice[i].mass, &ice[i].speed)` 一次读一条。注意 `%s` 的实参是 `ice[i].id`——它是字符数组名，本身就是地址，**不加 &**；两个 double 成员是普通变量，必须加 `&`。返回值 3 表示三个成员都读到了；
- **加工环节**：动量 $p = mv$ 不是文件里现成的，而是在读入与写出之间**算出来**的。这正是流水线中间站的价值：文件只存原始量，派生量随用随算，避免两处数据不一致；
- **写出环节**：`fprintf(fo, "%s %.1f %.1f %.1f\n", ...)` 把四个量（含新算的动量）拼成一行。%s 与 %lf 的顺序、个数必须与格式串一一对应；
- **最值环节**：遍历数组找动量最大者，只需记住下标即可。

### 3. 文件指针的生命周期

fin 覆盖读入站，读完全部记录即可 fclose；fout 覆盖写出站。与练习 15 相同，两个指针活跃期错开。两条纪律照旧：每个 fopen 后检查、每条提前退出的路径上关闭已打开的文件。

### 4. 文本方式与二进制方式不可混用

第 8 章 8.4 节学了两种存法：**文本方式**（fprintf/fscanf，人能看懂）与**二进制方式**（fwrite/fread，把内存字节原样落盘）。本题用文本方式，好处是可以用记事本直接查看、方便手工修改。铁律是：**一个文件用哪种方式写，就必须用同种方式读**——用 fwrite 写的二进制文件拿 fscanf 去读，得到的只能是乱码。

## 三、解题思路

1. **定义与声明**：struct Ice 与 50 元素数组、计数变量、最值变量；
2. **读入**：fin "r" 打开检查，while 循环按字段读入结构体数组，返回值判 3；
3. **加工与写出**：fout "w" 打开检查，循环内对每个冰块算动量并按四列写出，同时更新动量最大者的下标；
4. **收尾**：fclose 两个文件，屏幕输出最大动量及其编号。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>

struct Ice {              /* 冰块记录：编号、质量 t、速度 m/s */
    char id[8];
    double mass;
    double speed;
};

int main(void)
{
    FILE *fin, *fout;
    struct Ice ice[50];       /* 冰块档案，最多 50 条 */
    int n = 0, i, imax = 0;
    double p, pmax = -1.0;    /* p 为动量，kg·m/s */

    /* 1. 读入：文件 -> 结构体数组 */
    fin = fopen("ice_in.txt", "r");
    if (fin == NULL) {
        printf("错误：无法打开 ice_in.txt\n");
        return 1;
    }
    while (n < 50 &&
           fscanf(fin, "%s %lf %lf", ice[n].id, &ice[n].mass, &ice[n].speed) == 3)
        n++;
    fclose(fin);

    if (n == 0) {
        printf("错误：未读到任何有效记录\n");
        return 1;
    }

    /* 2. 加工并写出：结构体数组 -> 文件 */
    fout = fopen("ice_out.txt", "w");
    if (fout == NULL) {
        printf("错误：无法创建 ice_out.txt\n");
        return 1;
    }
    for (i = 0; i < n; i++) {
        p = ice[i].mass * 1000 * ice[i].speed;      /* 吨 -> 千克再乘速度 */
        fprintf(fout, "%s %.1f %.1f %.1f\n",
                ice[i].id, ice[i].mass, ice[i].speed, p);
        if (p > pmax) {
            pmax = p;
            imax = i;
        }
    }
    fclose(fout);

    printf("动量最大：编号 %s，动量 %.1f kg·m/s\n", ice[imax].id, pmax);

    return 0;
}
```

## 五、运行验证

**动量手算核对**：

| 冰块 | 计算过程 | 动量 p（kg·m/s） |
|---|---|---|
| B01 | $12.5 \times 1000 \times 0.8 = 12500 \times 0.8$ | 10000.0 |
| B02 | $18.2 \times 1000 \times 1.1 = 18200 \times 1.1$ | 20020.0 |
| B03 | $9.6 \times 1000 \times 0.5 = 9600 \times 0.5$ | 4800.0 |

最大者为 B02（20020.0），与预期一致。

**文件内容前后变化**：`ice_in.txt` 保持不变；`ice_out.txt` 新建，三行四列，前三列与输入一致，第四列动量如上表。

**屏幕输出**：

```
动量最大：编号 B02，动量 20020.0 kg·m/s
```

## 六、常见错误与讲解

**错误 1：%s 的实参多加了 & 或数值成员漏加 &**

```c
fscanf(fin, "%s %lf %lf", &ice[n].id, ice[n].mass, ice[n].speed);   /* 错：恰好写反 */
fscanf(fin, "%s %lf %lf", ice[n].id, &ice[n].mass, &ice[n].speed);  /* 对：字符数组名是地址，数值要 & */
```

这是"结构体 + 文件"组合里最高频的错误，记住口诀：**字符串免 &, 数值要 &**。

**错误 2：文本与二进制读写混用**

```c
fwrite(&ice[0], sizeof(struct Ice), 1, fo);   /* 用二进制方式写 ice_out.txt */
fscanf(fout, "%s %lf %lf", ...);              /* 错：再用文本方式去读，全是乱码 */
```

同一个文件写读方式必须一致。文本方式人可读、跨平台稳；二进制方式快、整块读写，但文件不可直读。

**错误 3：循环条件只写 n < 50 或只写 == 3**

只判 `n < 50`：文件超过 50 行时 fscanf 读不到内容仍在算"成功"，产生垃圾记录；只判 `== 3`：文件超过 50 条会越界写数组。参考代码把两个条件用 `&&` 连起来，缺一不可。

**错误 4：动量计算忘记吨化千克**

```c
p = ice[i].mass * ice[i].speed;          /* 错：单位是 t·m/s，差 1000 倍 */
p = ice[i].mass * 1000 * ice[i].speed;   /* 对：先化成 kg */
```

单位换算藏在公式 $p = mv$ 里：质量必须先用千克。样例中 B01 若漏乘 1000 会输出 10.0 而非 10000.0，一验便知。
