## 二、预备知识：循环嵌套打字符图的基本原理（零基础阅读）

### 1. 问题是怎么来的

终端只有文字，没有坐标系，怎么"画"潮位曲线？答案是把图**横过来看**：每条观测占一行，用一串 `*` 的长短代替柱状高度。星星个数与潮位成正比，比例尺固定为**每 0.2 m 一颗星**，人眼扫一眼就能看出涨落。这是没条件装绘图软件的嵌入式终端、值班室终端上最朴素的"可视化"。

### 2. 公式推导：潮位怎么变成星数

设潮位为 $h$（m），比例尺 $s = 0.2$ m/星，则理论星数为

$$k = \frac{h}{s}$$

但星数必须是整数，而 $h/s$ 一般带小数，所以要**四舍五入**：

$$\text{stars} = \left[ \frac{h}{s} + 0.5 \right]$$

其中 $[\,\cdot\,]$ 表示截断取整（即 C 的 `(int)`）。为什么"加 0.5 再截断"等于四舍五入？对正数 $x$：若小数部分 $\ge 0.5$，加 0.5 后整数部分进 1，截断后进位；若小数部分 $< 0.5$，加 0.5 后整数部分不变，截断即舍去。以样例 2 的 $h = 0.11$ 为例：

$$\frac{0.11}{0.2} = 0.55,\quad 0.55 + 0.5 = 1.05,\quad [\,1.05\,] = 1 \text{ 颗星}$$

而 $h = 6.0$：$6.0/0.2 = 30$，加 0.5 得 30.5，截断仍是 30——整除情形不受影响。

### 3. 代入本例数值

样例 1 的 6 个潮位逐一换算：

| 潮位 h (m) | h/0.2 | 四舍五入 | 星号数 |
|---|---|---|---|
| 2.4 | 12.0 | 12 | `************` |
| 3.6 | 18.0 | 18 | `******************` |
| 4.8 | 24.0 | 24 | `************************` |
| 3.0 | 15.0 | 15 | `***************` |
| 1.8 | 9.0 | 9 | `*********` |
| 4.2 | 21.0 | 21 | `*********************` |

星号数序列 12, 18, 24, 15, 9, 21 正好复现了"涨—落—再涨"的潮形。

### 4. 通过编程翻译

"每条记录一行、每行若干颗星"是典型的**两层任务**：外层任务重复 n 次（读一条、打一行），内层任务重复 stars 次（打一颗星）。翻译成 C 就是**循环嵌套**——外层 for 里套一个内层 for。内层结束时补 `printf("\n")`，相当于"这一行画完，换纸"。

> **这个思想在综合实验中反复出现**：C7 的"屏幕字符潮位曲线"（M10）、C8 的"字符声线轨迹图"（M10）、C6 的"字符深度剖面图"（M10）全是同一个"外层行、内层符号"的嵌套骨架，只是符号与比例尺不同。字符图是所有实验报表模块的公共地基。

## 三、解题思路

1. **读条数**：`scanf("%d", &n);`；
2. **外层 for**：每圈读入 h，换算 `stars = (int)(h / 0.2 + 0.5);`，打印 `h|` 前缀；
3. **内层 for**：`for (j = 0; j < stars; j++) printf("*");`；
4. **补换行**，外层循环结束后打印比例尺说明。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i, j, stars;
    double h;

    scanf("%d", &n);                    /* 读入观测条数 */

    for (i = 0; i < n; i++) {           /* 外层：每条记录一行 */
        scanf("%lf", &h);
        stars = (int)(h / 0.2 + 0.5);   /* 四舍五入换算星号数 */
        printf("%.2f|", h);             /* 行首：潮位值 + 竖线 */
        for (j = 0; j < stars; j++) {   /* 内层：连续打 stars 颗星 */
            printf("*");
        }
        printf("\n");                   /* 每行结束换行 */
    }

    printf("比例尺: 每0.2米一颗星\n");
    return 0;
}
```

## 五、运行验证

**样例 1 运行结果**：

```
2.40|************
3.60|******************
4.80|************************
3.00|***************
1.80|*********
4.20|*********************
比例尺: 每0.2米一颗星
```

**样例 2 运行结果**：

```
0.11|*
6.00|******************************
比例尺: 每0.2米一颗星
```

**核对**：样例 1 各行星号数 12/18/24/15/9/21 与逐条手算一致；样例 2 中 0.11 → 0.55 + 0.5 = 1.05 → 1 颗星、6.0 → 30 颗星，均已按 IEEE-754 double 运算复算核对（0.11/0.2 的 double 结果约 0.55，加 0.5 取整为 1）。样例 1 中潮位 3.0 恰好落在整比例尺上（15 颗），验证了"整除不受 +0.5 影响"。

**反例验证**：若把星号换算改成直接截断 `(int)(h / 0.2)`，输入 0.11 会打出 0 颗星（该行只剩 `0.11|`）——四舍五入与截断的差异立即显现。

## 六、常见错误与讲解

**错误 1：内层循环后忘换行**

```c
for (j = 0; j < stars; j++) printf("*");
/* 漏了 printf("\n"); → 下一条潮位数紧接在星号后面，图全乱了 */
```

**错误 2：把换行放进内层循环**

```c
for (j = 0; j < stars; j++) { printf("*"); printf("\n"); }
/* 错：每颗星各占一行，变成竖着的一列 */
```

换行属于"行级"操作，应放在外层、内层之后。

**错误 3：四舍五入写成 `(int)(h / 0.2)`（直接截断）**

0.11 这种"差一点"的值会被截成 0 颗星。正数四舍五入要**先加 0.5 再截断**。

**错误 4：外层循环变量误用（打完 stars 颗星后内层 j 没复位）**

内层 `j` 在外层每圈开始时由 `j = 0` 重新赋值——只要内层 for 写完整（含 `j = 0`），就不会有问题；若把内层写成 `for (; j < stars; j++)` 且 j 定义在循环外，第二行起星星就打不全了。**内层循环变量必须每圈重新初始化。**
