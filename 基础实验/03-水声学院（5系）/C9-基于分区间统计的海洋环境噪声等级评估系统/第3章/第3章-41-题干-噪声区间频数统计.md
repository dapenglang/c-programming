# 第 3 章 练习 41　噪声区间频数统计

**所属综合实验**：C9（C9-基于分区间统计的海洋环境噪声等级评估系统）

**对应章节**：3 选择结构（3.2 if-else、3.3 多分支 else-if）与 3 循环结构（for 循环 + 计数器）

**场景来源**：综合实验 C9《基于分区间统计的海洋环境噪声等级评估系统》（水声学院）——本练习是该实验中"区间频数统计（直方图）"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

海洋环境噪声（浪、航船、生物噪声）用**噪声级**（单位 dB）衡量。评估海域噪声状况时，光知道平均值不够，还要知道噪声**落在各个等级区间里的次数**——也就是做一张**频数直方图**。

海洋噪声监测常用的分箱标准（本题简化版）：

| 区间 | 含义 | 判定条件 |
|---|---|---|
| 区间 1 | 安静 | $x < 60$ |
| 区间 2 | 中等 | $60 \le x < 70$ |
| 区间 3 | 较吵 | $70 \le x < 80$ |
| 区间 4 | 吵 | $x \ge 80$ |

综合实验 C9 的 M3 模块（区间频数统计）就是把每一条噪声记录"丢进"对应的箱子并计数。本题就是它的最小实现。

## 二、任务要求

编写一个完整程序 `noise_bin.c`：

1. 从键盘读入样本数 `n`（**题目保证 1 ≤ n ≤ 500**）；
2. 循环读入 `n` 个噪声级（double，dB）；
3. 每读入一个噪声级，用 **if-else if 多分支**判断它落在哪个区间，给对应区间的**计数器加 1**；
4. 全部读完后，按顺序输出 4 个区间的频数。

**知识边界提示**：本题只用选择与循环结构，**不需要函数与数组**——4 个区间用 4 个独立的计数器变量 `cnt1, cnt2, cnt3, cnt4` 即可。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数（空格隔开）。

**输出**：共 4 行：

```
区间1(<60)频数=xx
区间2([60,70))频数=xx
区间3([70,80))频数=xx
区间4(>=80)频数=xx
```

## 四、样例

**样例 1**

输入：
```
12
58.3 61.2 66.8 71.5 74.9 63.4 82.1 77.3 59.9 85.6 70.0 64.5
```
输出：
```
区间1(<60)频数=2
区间2([60,70))频数=4
区间3([70,80))频数=4
区间4(>=80)频数=2
```

**样例 2**

输入：
```
1
70.0
```
输出：
```
区间1(<60)频数=0
区间2([60,70))频数=0
区间3([70,80))频数=1
区间4(>=80)频数=0
```

## 五、提示

- **多分支判定的顺序有讲究**：从小区间往大区间写，条件就可以"只写一侧"——

  ```c
  if (x < 60.0)       cnt1++;
  else if (x < 70.0)  cnt2++;   /* 走到这里说明 x>=60 已成立 */
  else if (x < 80.0)  cnt3++;
  else                cnt4++;
  ```

  这样每个条件只需写上界，`else` 自动补足下界，不易出错；
- **边界值归属要想清楚**：本题 60.0 属于区间 2、70.0 属于区间 3、80.0 属于区间 4（即"左闭右开"）。用 `x < 70.0`（而不是 `x <= 70.0`）配合 `else`，恰好实现这一点；
- 4 个计数器都要**先清零**：`int cnt1 = 0, cnt2 = 0, cnt3 = 0, cnt4 = 0;`；
- 想一想：样例 1 里 59.9 为什么落在区间 1？因为它小于 60，虽然只差 0.1——浮点数比较不能凭感觉"四舍五入"，`<` 就是 `<`。
- 想一想：为什么本题**不需要数组**？区间只有 4 个且固定，用 4 个命名清晰的计数器比数组下标更直白；等学到数组（第 5 章），同样的题目可以改成 `cnt[4]`，用下标 `cnt[x/10-6]` 之类的技巧收拢分支。

**完成本练习后你将具备的能力**：用 else-if 链实现多分支分箱、在循环里维护多个计数器、正确处理区间边界——这些是实验 C9 中"区间频数统计（直方图）"模块的地基。
