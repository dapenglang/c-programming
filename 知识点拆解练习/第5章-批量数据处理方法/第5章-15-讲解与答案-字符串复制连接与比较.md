## 二、预备知识：数组作函数参数与四个字符串工具的写法（零基础阅读）

### 1. 数组怎么"当参数传"

练习 01 说过：数组名代表这条数组的**首地址**。所以当函数形参写成 `char s[]`、调用时写 `mystrlen(s1)`，并不是把整条数组"复制"一份递给函数，而是把**首地址**递过去——函数里的 `s[i]` 与调用者的 `s1[i]` 访问的是**同一块内存**。这一点非常关键：

- 求长度、比较这类**只读**的函数，传地址后读的是原数组，效率高；
- 复制、连接这类**要写入**的函数，形参写成 `char d[]`，函数里 `d[i] = ...` 改的就是调用者的数组，改完调用者能看见——**这正是 `void` 函数也能"带回结果"的原理**（否则 void 没有返回值，结果无处可去）。

形参方括号里**不必写长度**（写成 `char s[]` 即可），因为长度由实参决定、由代码里的 `'\0'` 巡界控制。若要二维数组作参数，才必须写第二维的长度，如 `char a[][30]`。

### 2. 求长度：数到 `'\0'` 为止

下标从 0 走，只要 `s[i] != '\0'` 就 `i++`，循环结束时 `i` 就是长度（`'\0'` 本身不计入），即 `while (s[i] != '\0') i++;`。

### 3. 复制：边赋值边看是否到了结尾

逐字符把 `s[i]` 赋给 `d[i]`：`while ((d[i] = s[i]) != '\0') i++;`。技巧在于**赋值表达式 `d[i] = s[i]` 本身也有值**，值就是刚赋进去的字符——于是"先搬过去、再判断搬的是不是 `'\0'`"一气呵成；搬到 `'\0'` 时条件为假、循环结束，**结尾标志也被一起复制过去**（这点极重要，否则 `d` 不成其为字符串）。若写成 `while (s[i] != '\0') d[i] = s[i];` 就会漏掉 `'\0'`，行不通。

### 4. 连接：从 `d` 的末尾开始接

连接 = "把 `s` 的第一个字符放到 `d` 的 `'\0'` 处"再一路接下去。先用 `mystrlen(d)` 定位 `d` 的末尾，再 `while ((d[i] = s[j]) != '\0') { i++; j++; }`。起点必须是 `d` 的**末尾**而非开头，否则会覆盖原有内容；同时要保证容量够大：`d` 原有长度 + `s` 长度 + 1（给 `'\0'`）不超过数组容量。

### 5. 比较：找第一个不同的字符

字典序规则：从头逐字符比，**第一个不相同的字符谁大，整个字符串就谁大**；比到 `'\0'` 都相同则相等。写作 `while (a[i] != '\0' && a[i] == b[i]) i++;`，退出后按 `a[i]` 与 `b[i]` 的大小返回 1 / -1，双方同时到达 `'\0'` 时返回 0。

退出循环时，要么遇到了不同字符，要么至少有一方到了 `'\0'`。此时 `a[i]` 与 `b[i]` 的大小关系就是两个字符串的大小关系；两者都为 `'\0'` 时相等，返回 0。题目只要符号（正、零、负），这里返回 `1 / 0 / -1` 即可。

## 三、解题思路

1. **写四个函数**（放在主函数之前）：`mystrlen`、`mystrcpy`、`mystrcat`、`mystrcmp`，形参都用 `char x[]` 形式；
2. **准备数组**：`char s1[60], s2[60];` 存两个词条，`char cat[130];` 存连接结果（$50+50+1=101 < 130$，安全）；
3. **读入**：`scanf("%s", s1); scanf("%s", s2);`（词条不含空格，用 `%s` 正好；字符数组不加 `&`）；
4. **先复制再连接**：`mystrcpy(cat, s1); mystrcat(cat, s2);`——不能直接把 `s2` 接到 `s1` 上，否则会破坏 `s1`；
5. **输出三行**：长度用 `mystrlen`，连接串用 `%s` 打印 `cat`，比较结果用 `mystrcmp`。

## 四、参考代码

```c
#include <stdio.h>

/* 求字符串长度：数到 '\0' 为止 */
int mystrlen(char s[])
{
    int i = 0;
    while (s[i] != '\0') i++;
    return i;
}

/* 复制：把 s 连同结尾 '\0' 一起搬到 d */
void mystrcpy(char d[], char s[])
{
    int i = 0;
    while ((d[i] = s[i]) != '\0') i++;
}

/* 连接：先定位 d 的末尾，再把 s 逐字符接上 */
void mystrcat(char d[], char s[])
{
    int i = mystrlen(d);      /* 从 d 原来的 '\0' 处开始写 */
    int j = 0;
    while ((d[i] = s[j]) != '\0') { i++; j++; }
}

/* 字典序比较：返回 1 / 0 / -1 */
int mystrcmp(char a[], char b[])
{
    int i = 0;
    while (a[i] != '\0' && a[i] == b[i]) i++;
    if (a[i] > b[i]) return 1;
    if (a[i] < b[i]) return -1;
    return 0;
}

int main(void)
{
    char s1[60], s2[60];      /* 两个词条 */
    char cat[130];            /* 连接结果，容量足够 */

    scanf("%s", s1);
    scanf("%s", s2);

    printf("长度: %d %d\n", mystrlen(s1), mystrlen(s2));

    mystrcpy(cat, s1);        /* 先把 s1 复制进 cat */
    mystrcat(cat, s2);        /* 再把 s2 接到 cat 末尾 */
    printf("连接: %s\n", cat);

    printf("比较: %d\n", mystrcmp(s1, s2));

    return 0;
}
```

## 五、运行验证

以样例 1 的 `s1 = "ice"`、`s2 = "ship"` 为例：

| 调用 | 过程 | 结果 |
|---|---|---|
| `mystrlen("ice")` | 数到 `'\0'`：i 走过 3 个字符 | 3 |
| `mystrlen("ship")` | 同上 | 4 |
| `mystrcpy(cat, "ice")` | cat 变为 `ice\0` | — |
| `mystrcat(cat, "ship")` | 从 cat 末尾接上，变为 `iceship\0` | 输出 `iceship` |
| `mystrcmp("ice","ship")` | 首字符 `'i'`(105) `<` `'s'`(115) | -1 |

程序输出：

```
长度: 3 4
连接: iceship
比较: -1
```

与题干样例 1 完全一致。样例 2 手工核对：长度 4、3；连接 `loadice`；首字符 `'l'`(108) `>` `'i'`(105)，比较结果 1，与样例输出一致。

再验一个"相等 + 前缀"的情形（自测用）：`mystrcmp("abc","abc")` → 跳过全部相同字符后双方同时到 `'\0'` → 0；`mystrcmp("ab","abc")` → `a[2]='\0'`(0) `<` `b[2]='c'`(99) → -1，符合同样长度下短字符串更小。

## 六、常见错误与讲解

**错误 1：字符串结尾 `'\0'` 遗漏**

```c
int i = 0;
while (s[i] != '\0') { d[i] = s[i]; i++; }   /* 错：没把结尾 '\0' 复制过去 */
d[i] = '\0';                                  /* 对：复制完手动补上结尾 */
```

用 `while ((d[i] = s[i]) != '\0') i++;` 可以自动解决；若用分步写法，收尾时**必须补 `d[i] = '\0'`**，否则 `d` 不是合法字符串，用 `%s` 打印时会一直向后读垃圾数据。

**错误 2：连接时从 `d` 开头而不是末尾开始**

```c
int i = 0;                    /* 错：从开头写，覆盖了 d 原有内容 */
int i = mystrlen(d);          /* 对：从 d 的结尾开始接 */
```

**错误 3：目标数组开得太小**

```c
char cat[60];                 /* 错：s1 与 s2 各 50，拼接后可达 101，越界 */
char cat[130];                /* 对：留足 100+1 以上 */
```

数组越界写入是隐蔽而危险的错误，连接前要先估算长度。

**错误 4：比较函数写反或返回布尔值**

```c
return a[i] - b[i];           /* 可用：符号正确，但值不一定是 1/-1 */
if (a[i] > b[i]) return 1;    /* 对：显式返回 1 / 0 / -1，与题目要求一致 */
```

题目明确要求返回 `1 / 0 / -1`，直接返回字符差值虽然符号对，但数值可能不是 $\pm 1$，判题会不一致。
