# 第 4 章 练习 20　模块化计算报表

**对应章节**：4 模块化程序设计方法（综合运用第 2~4 章：4.1 函数调用与参数传递、4.2 参数传递、4.5 模块划分，以及第 2 章数据类型、第 3 章循环与选择）

**场景来源**：综合实验 C9《板面压力场测点分析系统》（水声学院）——本练习是该实验中"测点压力统计报表"环节的实现，也是本章的综合练习。

**建议用时**：30 分钟

## 一、应用场景

一块试验板面上布置了若干个压力测点，一次测量得到一串压力读数。分析结束时，需要给出一份**统计报表**：测点总数、压力总和、平均压力、最大压力、最小压力以及极差（最大值减最小值）。由于第 4 章不允许使用数组，数据只能**边读边统计**——读到第一个数时把它同时当作当前的和、最大值、最小值，之后每读一个数就用它更新这几个统计量。把"累加""取大""取小""求均值"分别写成小函数，`main` 只负责读数和打印报表，这就是一个典型的多函数协作场景。

## 二、任务要求

编写一个完整程序 `pressure_report.c`：

1. 编写四个统计函数（均接收当前状态与新增数据，返回更新后的状态，不使用全局变量）：
   - `double add(double s, double x)`：返回 `s + x`（累加）；
   - `double bigger(double a, double b)`：返回较大者；
   - `double smaller(double a, double b)`：返回较小者；
   - `double mean(double s, int n)`：返回 `s / n`（均值）；
2. `main` 先读入测点数 `n`，再读入**第一个**读数，用它把 `sum`、`mx`、`mn` 三个统计量都初始化；随后循环 `n-1` 次读入其余读数，每次分别用 `add`、`bigger`、`smaller` 更新三个统计量；
3. 按格式打印报表：测点数、总和、均值、最大值、最小值、极差（`mx - mn`），各数值保留 3 位小数；
4. **接口约定**：`n ≤ 100`，`n ≥ 1`；所有统计量必须通过函数返回值的层层传递得到，不得使用数组、不得使用全局变量。

## 三、输入输出格式

**输入**：第一行一个整数 `n`（测点数）；第二行 `n` 个实数（测点压力，单位 kPa），用空格分隔。

**输出**：六行报表，格式依次为 `n = 测点数`、`sum = 总和`、`mean = 均值`、`max = 最大值`、`min = 最小值`、`range = 极差`，其中数值均保留 3 位小数，整数 `n` 用 `%d` 输出。

## 四、样例

**样例 1**

输入：
```
5
1.20 3.50 2.00 2.80 2.84
```
输出：
```
n = 5
sum = 12.340
mean = 2.468
max = 3.500
min = 1.200
range = 2.300
```

**样例 2**

输入：
```
4
0.50 0.90 0.70 1.10
```
输出：
```
n = 4
sum = 3.200
mean = 0.800
max = 1.100
min = 0.500
range = 0.600
```

## 五、提示

- "边读边统计"的关键是**先用第一个数初始化**：`sum = mx = mn = 第一个读数;`，然后循环读剩下的 `n-1` 个数；
- 每次读入新值 `x` 后：`sum = add(sum, x);`、`mx = bigger(mx, x);`、`mn = smaller(mn, x);`；
- 每个更新函数都遵循"**传入旧状态、返回新状态**"的模式，例如 `bigger(mx, x)` 返回两者中较大的那个，再赋回 `mx`；
- 均值在循环结束后用 `mean(sum, n)` 一次性求出，`range` 直接用 `mx - mn`；
- 输出用 `%.3f` 保证三位小数，例如 `printf("mean = %.3f\n", mean(sum, n));`。

**完成本练习后你将具备的能力**：会把一个统计任务拆成若干单职责函数、能用"值传递 + 返回值"让函数之间协作而不依赖全局变量、能在没有数组的条件下用"边读边统计"完成整份报表——这是实验 C9 中"压力统计报表模块"的地基，也是第 4 章函数与模块化的综合检验。
