## 二、预备知识：for 循环与累加器

### 1. 问题是怎么来的

n 在运行前是未知的（由用户输入决定），程序不可能为"5 个测点"和"80 个测点"各写一个版本。能以**不变的一段代码应对可变的次数**，这正是循环结构存在的理由：把"读一个数、加到总数上"这一动作固定下来，让循环变量 i 替我们数次数。

### 2. for 循环的三要素与执行流程

```c
for (表达式1; 表达式2; 表达式3)
    循环体;
```

- **表达式 1**：初始化，整个循环只做一次（`i = 1`）；
- **表达式 2**：循环条件，每次进入循环体之前检查（`i <= n`），为假则整个循环结束；
- **表达式 3**：步进，每轮循环体执行完之后做（`i = i + 1`）。

执行顺序是：**初始化 → 查条件 → 执行循环体 → 步进 → 再查条件 → …**。以 n = 5 为例，i 依次取 1、2、3、4、5，循环体共执行 5 次；i 变成 6 时条件 `6 <= 5` 为假，循环结束。数清楚"循环体执行几次、i 最终停在几"，是写对循环的基本功。

### 3. 累加器为什么必须清零

`sum = sum + f` 的意思是"取出 sum 现在的值，加上 f，再存回 sum"。第一次执行时 sum 必须已有确定的值——工程上总数从零开始，所以循环前必须 `sum = 0.0`。漏了这句，sum 里的值是内存里的随机数，结果整体偏移且每次运行都不同——这是初学者最常见、也最难排查的错误之一。

### 4. 哪些计算放在循环里、哪些放在循环外

判据：**这个计算是对"单个数据"做的，还是对"全部数据"做的**。读入、累加针对单个数据，放循环体内；平均值是全部数据的性质，必须等循环结束后才能算。若把 `mean = sum / n` 写进循环体，它只是被反复执行了 n 次而已，不改变结果，但属于概念混乱；更糟的是若在累加中途就除，得到的是"前 i 个数的平均值"。

## 三、解题思路

1. **确定变量**：`n`、`i` 为 `int`；`f`（当前读入值）、`sum`（累加器）为 `double`；
2. **读入 n**；
3. **初始化** `sum = 0.0`；
4. **for 循环**：i 从 1 到 n，每次读入一个阻力值并累加；
5. **循环结束后**计算并输出 `sum`（`%.2f`）与 `mean = sum / n`（`%.4f`）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i;            /* 测点个数、循环变量 */
    double f;            /* 当前测点的阻力读数，kN */
    double sum = 0.0;    /* 累加器：循环前必须清零 */

    scanf("%d", &n);

    for (i = 1; i <= n; i = i + 1) {   /* 循环 n 次，i = 1..n */
        scanf("%lf", &f);
        sum = sum + f;                 /* 读一个、加一个 */
    }

    printf("sum = %.2f\n", sum);
    printf("mean = %.4f\n", sum / n);  /* 循环结束后再求均值 */

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `5` + `812.5 790.3 834.7 856.1 788.4` | $812.5+790.3=1602.8$；$+834.7=2437.5$；$+856.1=3293.6$；$+788.4=4082.0$；均值 $4082/5=816.4$ | `sum = 4082.00`、`mean = 816.4000` ✓ |
| `3` + `755.0 760.5 744.5` | $755+760.5=1515.5$；$+744.5=2260.0$；均值 $2260/3=753.3333\ldots$ | `sum = 2260.00`、`mean = 753.3333` ✓ |
| `1` + `832.7` | 只循环一次，sum 即该值；均值相同 | `sum = 832.70`、`mean = 832.7000` ✓ |

第 3 行验证了边界情形 n = 1：循环体执行一次，结果自然正确。

## 六、常见错误与讲解

**错误 1：累加器忘了清零**

```c
double sum;          /* 错：初值是随机数 */
scanf("%d", &n);
for (...) { ... sum = sum + f; ... }
```

必须写 `double sum = 0.0;` 或循环前赋值。症状：结果比手算值多出一大截，且每次运行不同。

**错误 2：循环边界写成 `i < n`**

```c
for (i = 1; i < n; i = i + 1)   /* 错：只执行 n-1 次，漏读/漏加最后一个数 */
for (i = 1; i <= n; i = i + 1)  /* 对：恰好 n 次 */
```

配合样例（n = 5 少加 788.4 会导致 sum = 3293.60）立即可查出。也可以写 `i = 0; i < n`（从 0 数到 n−1），两种约定都能数对次数，但**不能混用**。

**错误 3：把均值计算放进循环体**

```c
for (...) { scanf(...); sum = sum + f; mean = sum / n; }   /* 错：概念混乱 */
```

平均值依赖**完整的** sum，必须在循环结束之后计算。

**错误 4：scanf 漏写取地址符**

```c
scanf("%lf", f);    /* 错：崩溃或读不进 */
scanf("%lf", &f);   /* 对 */
```

循环里的 scanf 和单个 scanf 的规则完全一样，每个参数前都要 `&`。
