# 第 7 章 练习 17　二分法求解非线性方程

**对应章节**：7 数据的结构化封装方法（7.6 二分法求解——方程求根、区间对分、收敛判据、函数封装）

**场景来源**：本节 7.6 二分法求解方法（独立方法训练）——本练习是二分法求解非线性方程的通用范式，其"缩小区间逼近零点"的思想是综合实验 C8《冰区船舶浮力与吃水计算系统》"平衡吃水方程求解"环节的地基。

**建议用时**：40 分钟

## 一、应用场景

工程中大量问题最终归结为"令某个表达式等于零、反求出未知量"，即**解方程**。以结构工程为例，梁的临界屈曲载荷、冰盖在水流作用下的临界流速、稳定分析中的特征参数，往往都满足一个三次或更高次的多项式方程，例如

$$
f(x) = x^3 - x - 1 = 0 .
$$

这类方程有的没有简单的求根公式，有的干脆是超越方程。工程上并不追求"解析解"，而是用**数值方法**求出满足精度要求的**近似根**。其中**二分法**原理最简单、最稳健：只要知道根所在的区间、并且区间两端的函数值一正一负，就能像"猜数字游戏"那样不断折半，稳稳地逼近根。本练习要做的是用函数把"方程"和"求解器"分开，写一个通用的二分求根程序。

## 二、任务要求

编写一个完整程序 `bisect_eq.c`：

1. 编写函数 `double f(double x)`，返回方程左端的函数值

   $$
   f(x) = x^3 - x - 1 ;
   $$

2. 编写函数 `double bisect(double a, double b, double eps)`：在区间 $[a, b]$ 上用二分法求 $f(x)=0$ 的根——每次取中点 $m=\dfrac{a+b}{2}$，若 $f(a)\cdot f(m) \le 0$ 则说明根在左半区间，令 $b=m$，否则令 $a=m$；每次对分令计数器 `n` 加一；当 $b-a < eps$ 时停止，返回中点 $(a+b)/2$ 作为近似根，并把对分次数通过返回值一并报告（可用一个整型指针参数，也可把次数打印在函数内）；
3. `main` 读入两个实数 `a`、`b`（**题目保证** $f(a)$ 与 $f(b)$ 异号，即区间内必有根），以 `eps = 1e-6` 调用 `bisect`；
4. 按格式输出近似根与对分次数：`root = 近似根, n = 对分次数`（根保留 6 位小数）；
5. **接口约定**：`f` 与 `bisect` 只通过参数和返回值通信，不使用全局变量。

## 三、输入输出格式

**输入**：一行，两个实数 `a` 与 `b`（区间端点，保证 $f(a)\cdot f(b) < 0$）。

**输出**：一行，格式为 `root = 近似根, n = 对分次数`（根保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
1 2
```
输出：
```
root = 1.324718, n = 20
```

**样例 2**

输入：
```
1 1.5
```
输出：
```
root = 1.324718, n = 19
```

## 五、提示

- $f(x)=x^3-x-1$ 在 $x=1$ 处 $f(1)=-1<0$，在 $x=2$ 处 $f(2)=5>0$，两端异号，区间 $[1,2]$ 内必有根；
- 二分法的**前提是区间两端异号**。可用零点定理理解：函数图象从负穿到正，中间必然扫过零点；
- 每次对分把区间长度**减半**，$n$ 次后区间长度为原来的 $1/2^n$。要让区间长度小于 `eps = 1e-6`，需要约 $\log_2\dfrac{b-a}{eps}$ 次对分。当 $b-a=1$ 时约 20 次，$b-a=0.5$ 时约 19 次；
- 判据用**区间长度** $b-a$，而不是函数值 $|f(m)|$——这是二分法的正确用法；
- 返回中点 $(a+b)/2$ 作为根的近似值，误差不超过区间长度的一半。

**完成本练习后你将具备的能力**：理解二分法的收敛原理与适用前提、能把"方程函数"与"二分求解器"分开封装、会以区间长度作为收敛判据求一元方程的近似根——这是实验 C8"平衡吃水求解模块"的地基。
