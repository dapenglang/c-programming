# 第 2 章 练习 20　风荷载设计值完整计算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 A1《基于线性插值的风荷载计算系统》（航建学院）——本练习是该实验中"风荷载设计值计算"环节的完整最小实现。

**建议用时**：25 分钟

## 一、应用场景

风是建筑物承受的主要水平荷载之一。计算某高度处风荷载设计值，要连做三步：

1. 根据建筑高度查规范表格，得到**风压高度变化系数** $\mu_z$（高度介于两档之间时用**线性插值**）；
2. 乘以**基本风压** $w_0$，得到风荷载标准值 $w_k$；
3. 再乘以**风荷载分项系数** $\gamma_Q = 1.5$，得到用于承载能力极限状态设计的**风荷载设计值** $w$。

综合实验 A1 把"查表—插值—乘系数"整条链条做成通用计算程序；本练习就是这条链条的最小完整版：读入高度和基本风压，一次算完标准值与设计值。它综合运用了本章全部知识点。

## 二、任务要求

编写一个完整程序 `wind_load_design.c`：

1. 用**常量**存放规范表格相邻两档数据（B 类粗糙度）：高度 10 m 对应 $\mu_z = 1.00$，高度 20 m 对应 $\mu_z = 1.23$；用**常量**存放分项系数 $\gamma_Q = 1.5$；
2. 从键盘读入**建筑高度** $h$（m）和**基本风压** $w_0$（$\mathrm{kN/m^2}$），均为 `double`；题目保证 $10 \le h \le 20$；
3. 先线性插值求 $\mu_z$，再计算标准值 $w_k = \mu_z \times w_0$，最后计算设计值 $w = \gamma_Q \times w_k$；
4. 按三行输出 $\mu_z$、$w_k$、$w$，均保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，两个实数，依次为建筑高度 $h$（m）和基本风压 $w_0$（$\mathrm{kN/m^2}$），用空格分隔。

**输出**：三行，依次为 `mu_z = 结果`、`w_k = 结果`、`w = 结果`，均保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
15 0.40
```
输出：
```
mu_z = 1.1150
w_k = 0.4460
w = 0.6690
```

**样例 2**

输入：
```
18 0.40
```
输出：
```
mu_z = 1.1840
w_k = 0.4736
w = 0.7104
```

## 五、提示

三步公式依次为：

$$
\mu_z = \mu_{z0} + \dfrac{(\mu_{z1} - \mu_{z0})\,(h - h_0)}{h_1 - h_0}
$$

$$
w_k = \mu_z \times w_0, \qquad w = \gamma_Q \times w_k
$$

即"插值求系数 → 乘基本风压 → 乘分项系数"。运算全程使用实数，注意插值公式的括号。
