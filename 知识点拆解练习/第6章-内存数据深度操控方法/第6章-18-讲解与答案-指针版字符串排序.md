## 二、预备知识：排序时"交换指针"还是"交换内容"（零基础阅读）

### 1. 两种做法的对比

要对一批字符串排序，直觉做法是把字符串本身搬来搬去：

```
   交换内容（搬字符串）：
     buf[0]="gamma"  buf[1]="alpha"
     用临时缓冲区：tmp←"gamma"; buf[0]←"alpha"; buf[1]←tmp
     每次搬运 6 个字符，字符串越长越慢，还要保证临时缓冲区够大。
```

更聪明的做法是给每条字符串配一个指针，**只排指针**：

```
   交换指针（换地址）：
     s[0] ──→ buf[0] "gamma"       改动前
     s[1] ──→ buf[1] "alpha"

     交换后： s[0] ──→ buf[1] "alpha"
              s[1] ──→ buf[0] "gamma"
     只动了两格 8 字节的地址，buf 里的字符串一个字都没搬！
```

**地址只有几个字节，字符串可能有几十个字节**——这就是"排指针"高效的原因。

### 2. 内存图（排序前 → 排序后）

```
   排序前                                    排序后
   buf: "gamma\0" "alpha\0" "delta\0"        buf: 内容原封不动
   s[0]──→"gamma"                            s[0]──→"alpha"
   s[1]──→"alpha"                            s[1]──→"delta"
   s[2]──→"delta"                            s[2]──→"gamma"
   遍历 s 打印得到：gamma alpha delta        遍历 s 打印得到：alpha delta gamma
```

排序改变了 `s` 里地址的排列顺序，`buf` 里的字符串内容一个字符都没动。

### 3. `strcmp` 是怎么比较的

`int strcmp(const char *a, const char *b);` 从两个字符串的第一个字符开始，逐个比较它们的 ASCII 码，直到遇到不同字符或到达结尾：

- 返回负数：`a` 在字典序上排在 `b` 前面；
- 返回 0：两串完全相同；
- 返回正数：`a` 排在 `b` 后面。

**注意：字符串不能用 `>`、`<`、`==` 直接比较**——那样比的是两个"地址"的大小，与内容无关。比较内容必须用 `strcmp`。

### 4. 冒泡排序的翻译

两重循环：外层控制"一共比几轮"，内层让相邻两格两两比较；若前一个按字典序"更大"（`strcmp > 0`）就交换。交换的写法与整数排序完全一样，只不过交换的是指针：

```c
char *t = s[j]; s[j] = s[j + 1]; s[j + 1] = t;
```

## 三、解题思路

1. **定数据**：`buf` 存字符串本体，`s[i] = buf[i]` 建立指针数组；
2. **定接口**：`void sort_str(char *s[], int n);`，`s[]` 即 `char **`；
3. **定比较**：`strcmp(s[j], s[j+1]) > 0` 表示相邻逆序；
4. **定交换**：交换 `s[j]`、`s[j+1]` 两个指针；
5. **定输出**：排序后按 `s[0]..s[n-1]` 逐行打印。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>

/* 对指针数组 s 做字典序升序排序：只交换指针，不搬内容 */
void sort_str(char *s[], int n)
{
    int i, j;

    for (i = 0; i < n - 1; i++)                /* 冒泡：n - 1 轮 */
        for (j = 0; j < n - 1 - i; j++)
            if (strcmp(s[j], s[j + 1]) > 0) {  /* 前 > 后，说明逆序 */
                char *t = s[j];                /* 交换两个"地址" */
                s[j] = s[j + 1];
                s[j + 1] = t;
            }
}

int main(void)
{
    char buf[10][50];      /* 字符串本体 */
    char *s[10];           /* 指针数组，指向各条字符串 */
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%s", buf[i]);
        s[i] = buf[i];     /* 让 s[i] 指向第 i 条字符串 */
    }

    sort_str(s, n);        /* s 退化为 char ** */

    for (i = 0; i < n; i++)
        printf("%s\n", s[i]);

    return 0;
}
```

## 五、运行验证

| 输入 | 排序过程 | 程序输出 |
|---|---|---|
| 3 / gamma alpha delta | 比较后 alpha < delta < gamma | `alpha`、`delta`、`gamma` ✓ |
| 3 / ICE-02 ICE-01 ICE-03 | 前缀相同，比数字字符：01 < 02 < 03 | `ICE-01`、`ICE-02`、`ICE-03` ✓ |

> 地址类说明：排序结果只取决于字符串内容，不依赖具体地址数值；`buf` 中字符串的物理位置始终未变，变的是 `s` 数组里地址的次序。

## 六、常见错误与讲解

**错误 1：用 `>`、`<`、`==` 直接比较字符串**

```c
if (s[j] > s[j + 1])   /* 错：比的是两个地址，与字典序无关 */
if (strcmp(s[j], s[j + 1]) > 0)   /* 对 */
```
编译器通常不报错，但排序结果完全乱套——这是最隐蔽的错误之一。

**错误 2：想交换内容却用 `strcpy`，缓冲区不够或漏换**

```c
char t[50];
strcpy(t, buf[i]); ...      /* 若字符串长度 >= 50，越界写，危险 */
```
本题的要求就是"交换指针"，根本不需要 `strcpy`。**除非明确要改内容，否则一律换指针。**

**错误 3：形参类型写错**

```c
void sort_str(char *s, int n)      /* 错：这是单个字符串指针 */
void sort_str(char **s, int n)     /* 对，等价于 char *s[] */
```
`char *s[]` 和 `char **s` 是同一回事，但都不能写成 `char *s`。

**错误 4：`strcmp` 判据方向反了**

```c
if (strcmp(s[j], s[j + 1]) < 0) swap(...);   /* 会变成降序 */
if (strcmp(s[j], s[j + 1]) > 0) swap(...);   /* 升序，正确 */
```
想让"小的排前面"，就得把"前大后小"（`> 0`）的相邻对交换。
