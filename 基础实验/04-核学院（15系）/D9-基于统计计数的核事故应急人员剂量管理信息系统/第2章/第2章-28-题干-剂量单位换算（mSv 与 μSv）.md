# 第 2 章 练习 28　剂量单位换算（mSv 与 μSv）

**所属综合实验**：D9（D9-基于统计计数的核事故应急人员剂量管理信息系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算）

**场景来源**：综合实验 D9《基于统计计数的核事故应急人员剂量管理信息系统》（核学院）——本练习是该实验中"剂量数据录入与单位统一"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

核事故应急响应中，各个监测点和电子个人剂量计（EPD）上报的数据单位并不统一：有的用 **毫希沃特**（mSv），有的用 **微希沃特**（μSv）。而《电离辐射防护与辐射源安全基本标准》（GB 18871-2002）规定，职业照射的个人年剂量限值是 **20 mSv/年**，分级判定也全部以 mSv 为单位。

所以在把所有记录存入系统之前，必须先做一次**单位统一**：

$$
1\ \text{mSv} = 1000\ \mu\text{Sv}, \qquad 1\ \mu\text{Sv} = 0.001\ \text{mSv}
$$

综合实验 D9 的"数据录入模块"第一步就是这个换算——把一条以 μSv 上报的读数，折算成系统内部统一使用的 mSv，再进入后续的累加与分级。本题实现这一最小换算流程。

## 二、任务要求

编写一个完整程序 `dose_convert.c`：

1. 程序中用**常量**存放换算系数（1000.0，即 1 mSv 对应的 μSv 数）；
2. 从键盘读入两个量：人员编号 `id`（整数，int 类型）和该次测量读数 `d_usv`（实数，单位 μSv，double 类型，**题目保证 0 ≤ d_usv ≤ 50000**，因此不需要判断分支）；
3. 用换算关系算出对应的剂量值 `d_msv`（单位 mSv）；
4. 按格式输出人员编号与换算结果，mSv 保留 **4 位小数**，μSv 保留 **1 位小数**。

## 三、输入输出格式

**输入**：一行，一个整数和一个实数，依次为人员编号 id、该次读数 d_usv（μSv），用空格分隔。

**输出**：一行，按格式 `id = 编号, dose = 结果 mSv (原始值 uSv)` 输出；其中 `结果` 保留 4 位小数，`原始值` 保留 1 位小数。

## 四、样例

**样例 1**

输入：
```
1001 850.0
```
输出：
```
id = 1001, dose = 0.8500 mSv (850.0 uSv)
```

**样例 2**

输入：
```
1024 12500.0
```
输出：
```
id = 1024, dose = 12.5000 mSv (12500.0 uSv)
```

## 五、提示

- 换算关系用除法表达：$d_{\text{mSv}} = d_{\mu\text{Sv}} / 1000$；
- 换算系数是固定的规范常数，用 `const double USV_PER_MSV = 1000.0;` 定义，**不要写成整数 1000**，以免在整数运算中丢失精度；
- 两个物理量都是带小数的量，一律用 `double`；编号是整数，用 `int`；
- `scanf` 中读取 `id` 用 `%d`、读取 `d_usv` 用 `%lf`，**两个参数前都要加 `&`**；
- 输出时注意格式符与类型对应：`id` 用 `%d`，两个剂量值用 `%.4f` 和 `%.1f`；
- 想一想：为什么系统内部统一用 mSv 而不是 μSv？因为 mSv 的量级与"20 mSv 年剂量限值"直接对应，判定阈值写起来直观。

**完成本练习后你将具备的能力**：定义常量与变量、为不同物理量选择正确的数据类型、书写算术表达式、用 scanf/printf 完成带格式的输入输出、完成一次单位换算——这些是实验 D9 中"剂量数据录入模块"的地基。
