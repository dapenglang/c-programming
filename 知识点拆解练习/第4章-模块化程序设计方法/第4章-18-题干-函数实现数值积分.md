# 第 4 章 练习 18　函数实现数值积分

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.5 内部函数与模块划分，配合第 3 章数值积分）

**场景来源**：综合实验 D5《γ 射线剂量率与屏蔽计算系统》（核学院）——本练习是该实验中"累积剂量数值积分"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

γ 射线穿过屏蔽层时，剂量率随穿透深度的增加而衰减。若把剂量率随位置的变化记为函数 $f(x)$，那么一定范围内的**累积剂量**就等于定积分

$$
I = \int_a^b f(x)\,\mathrm{d}x .
$$

实际工程中 $f(x)$ 常由查表或经验公式给出，未必有方便的初等原函数，因此普遍采用**数值积分**。本题取归一化的指数衰减律 $f(x)=e^{-x}$ 作为算例，用**复化梯形法**求 $I$。关键在于：把"被积函数"和"积分器"写成两个独立函数——这样将来换一个剂量率模型，只需改被积函数，积分器一行都不用动。

## 二、任务要求

编写一个完整程序 `dose_integral.c`：

1. 编写函数 `double dose(double x)`：返回 $f(x) = e^{-x}$（调用 `exp`）；
2. 编写函数 `double integral(double a, double b, int n)`：把区间 $[a,b]$ 等分为 $n$ 段，用**复化梯形公式**计算 $I$ 并返回：

   $$
   I \approx \frac{h}{2}\Bigl[f(a) + 2\!\!\sum_{i=1}^{n-1}\!f(a+ih) + f(b)\Bigr],\qquad h=\frac{b-a}{n};
   $$

3. `main` 读入积分下限 `a`、上限 `b` 与分段数 `n`，调用 `integral` 并输出结果；
4. **接口约定**：`dose` 只接收一个 `double`；`integral` 接收两个 `double` 与一个 `int`，返回 `double`；被积函数**必须**通过调用 `dose` 获得，不得把表达式写死在积分器里；不使用全局变量。

## 三、输入输出格式

**输入**：一行，`a b n`（两个实数与一个整数，用空格分隔；$n \ge 1$）。

**输出**：一行，`integral = 积分值`（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
0 1 1000
```
输出：
```
integral = 0.632121
```

**样例 2**

输入：
```
0 2 1000
```
输出：
```
integral = 0.864665
```

## 五、提示

- 复化梯形公式的思想：把小段 $[x_{i},x_{i+1}]$ 上的曲边梯形近似为"上底 $f(x_i)$、下底 $f(x_{i+1})$、高 $h$"的直边梯形，面积是 $\dfrac{f(x_i)+f(x_{i+1})}{2}h$，再把 $n$ 个梯形加起来；
- 内部节点 $f(a+ih)$ 会被相邻两个梯形**各用一次**，所以求和系数是 2 而不是 1；
- 编程时用循环 `for (i = 1; i < n; i++)` 累加内部节点，首末点单独取一半；
- 分段数 `n` 越大结果越准：本题 $[0,1]$ 上 $n=1000$ 时误差已小于 $10^{-6}$；参考值 $I=\int_0^1 e^{-x}dx = 1-e^{-1}\approx0.632121$。

**完成本练习后你将具备的能力**：理解复化梯形积分的原理、能把"被积函数"和"积分器"分离成两个函数、会用一个循环完成数值累加——这是实验 D5 中"剂量累积计算模块"的地基。
