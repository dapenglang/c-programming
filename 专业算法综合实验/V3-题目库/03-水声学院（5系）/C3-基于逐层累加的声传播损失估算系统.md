# 题目 C3：基于逐层累加的声传播损失估算系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行声传播损失（Transmission Loss，TL）估算工具。它读入一张"频率—吸收系数"经验表，用线性插值取出工作频率对应的吸收系数，然后对给定声源级和一系列距离，逐距离计算球面扩展损失 20·lg(r) 与吸收损失 α·r 并累加，得到总传播损失与接收级，输出"传播损失—距离"表、损失曲线字符画以及多频率对比结果。

**解决什么重要问题**：声波从声源传到接收点，能量会因波阵面扩展（几何扩展）和海水吸收（介质吸收）而不断衰减。传播损失是声呐方程的核心项：接收级 = 声源级 − 传播损失，若传播损失估计不准，作用距离预报就会差之千里。距离每增加 10 倍，仅球面扩展就要损失 20 dB，而高频还叠加很强的海水吸收——同一频率下 10 km 与 50 km 的损失可能相差数十 dB。不把这些项算清楚，就无法判断某距离上的信号还能不能被接收到。

**支撑哪些关键应用**：① 主动声呐作用距离预报与声呐方程计算；② 水声通信的功率预算与链路设计；③ 被动探测中目标辐射噪声的可听距离估计；④ 频率选择（高频分辨率好但吸收大，需权衡）；⑤ 声呐参数优化与作战辅助决策。

**与专业培养的关联**：水声工程、声学专业的《水声学》《声呐技术》课程都以声呐方程与传播损失为主线。本题让学生用 C 语言实现传播损失的分项计算与逐层累加，建立"几何扩展 + 介质吸收"的定量直觉，并提前熟悉声呐方程的各个量，为后续专业课打基础。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述传播损失估算系统，完成"参数录入→吸收系数查表→损失分项计算→结果输出"的完整流程。具体任务包括：交互录入声源级、工作频率、距离范围、噪声级与指向性指数等参数；读入频率—吸收系数经验表；用线性插值求任意频率的吸收系数；逐距离计算球面扩展损失；逐距离累加吸收损失并合成总传播损失；计算接收级；批量输出"传播损失—距离"表；绘制损失曲线字符画；对多个频率做对比实验；用菜单调度全部功能。

本题对应水声专业"用声呐方程定量估计可探测性"的能力，学生在此过程中练熟循环累加、公式计算、线性插值与多列数据输出。

## 三、数据来源与格式

**数据文件格式**：采用纯文本格式，第 1 行为格式标识，第 2 行为表格行数，其后每行为"频率 吸收系数"。用 `fscanf(fp, "%lf", ...)` 循环读入即可。

```
ABSORB
7
1.0    0.060
2.0    0.100
5.0    0.250
10.0   1.000
20.0   3.000
50.0   13.000
100.0  30.000
```

字段含义：第 1 行 `ABSORB` 为格式标识（Absorption）；第 2 行为表行数 `7`；其后每行为"频率(kHz) 吸收系数(dB/km)"。工作频率落在表内相邻两点之间时由 M3 线性插值求取；超出表范围时按最近端点取值并提示外推。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 频率 | kHz | 1.0～100.0 | 按 1/2/5/10/20/50/100 的近似等比序列取 7～12 个点 |
| 吸收系数 | dB/km | 0.05～35.0 | 随频率近似平方律增长，1 kHz 约 0.06，10 kHz 约 1.0，100 kHz 约 30.0，叠加 ±5% 相对误差 |
| 声源级 SL | dB | 180～230 | 交互录入，典型 200 |
| 噪声级 NL | dB | 50～90 | 交互录入，典型 70 |
| 指向性指数 DI | dB | 0～30 | 交互录入，典型 20 |
| 距离 r | m | 100～50000 | 从起点到终点按整数步长（如 100 m）等间隔取 50～200 个点 |

**异常值与噪声注入方式**：在吸收系数表中等概率选取 1 个点注入 ±(10%～20%) 的相对粗差，用于检验 M2 是否做单调性或量级检查；并在表中插入 1 对频率相同的重复行，用于检验读入模块的去重或告警。距离序列中可插入 1 个 r ≤ 0 的非法值，用于检验 M4 的边界保护。

**真实数据集（如有）**：
- 海水吸收系数的经验模型（Thorp 公式、Francois-Garrison 公式）可参考公开文献，属超纲自学内容；
- 实际授课以教师提供的"频率—吸收系数"标准表为准，无需外部下载。

## 四、数据结构设计

```c
#define MAX_FREQ 64            /* 吸收系数表最大行数 */
#define MAX_DIST 256           /* 最大距离点数 */

/* 吸收系数表项：频率-吸收系数 */
typedef struct {
    double f;                  /* 频率，单位 kHz，取值 1.0~100.0 */
    double alpha;              /* 吸收系数，单位 dB/km，取值 0.05~35.0 */
} AbsPoint;

/* 声呐与工况参数 */
typedef struct {
    double SL;                 /* 声源级，单位 dB re 1uPa@1m，180~230 */
    double f;                  /* 工作频率，单位 kHz，1.0~100.0 */
    double r0, r1;             /* 距离范围起、止，单位 m */
    double dr;                 /* 距离步长，单位 m */
    double NL;                 /* 噪声级，单位 dB，50~90 */
    double DI;                 /* 指向性指数，单位 dB，0~30 */
} SonarParam;

AbsPoint   g_abs[MAX_FREQ];    /* 吸收系数表 */
int        g_nAbs = 0;         /* 表行数 */
SonarParam g_param;            /* 当前工况参数 */

double g_dist[MAX_DIST];       /* 距离序列，单位 m */
double g_tlSph[MAX_DIST];      /* 球面扩展损失，单位 dB */
double g_tlAbs[MAX_DIST];      /* 吸收损失，单位 dB */
double g_tl[MAX_DIST];         /* 总传播损失，单位 dB */
double g_rl[MAX_DIST];         /* 接收级 = SL − TL，单位 dB */
int    g_nDist = 0;            /* 距离点数 */
```

全局数组置于文件作用域以避免栈溢出；各模块只通过 `g_abs`、`g_param`、`g_dist` 及上述结果数组交换数据。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 声源频率与距离参数录入模块**（源文件 `ParamIn.c`）
- 功能简介：交互录入声源级 SL、工作频率 f、距离起点 r0、距离终点 r1、距离步长 dr、噪声级 NL 与指向性指数 DI；对每个量做范围校验并提示重新输入，最后把参数填入 `g_param`。
- 输入：键盘输入的 7 个参数。
- 输出：`g_param`；屏幕参数确认表。

**M2 吸收系数表读入模块**（源文件 `AbsIO.c`）
- 功能简介：打开吸收系数文本文件，读入格式标识与行数，循环读入全部"频率-吸收系数"到 `g_abs[]`；检查频率是否单调递增、是否越界、是否有重复频率，给出告警并返回标志。
- 输入：文件路径（菜单输入，默认 `absorption.txt`）。
- 输出：填充 `g_abs[]`、`g_nAbs`；屏幕校验报告。

### 第二部分：算法实现（4 个模块）

**M3 吸收系数插值模块**（源文件 `AbsInterp.c`）
- 功能简介：实现 `double absorb(double f)`，在 `g_abs[]` 中用线性插值求任意频率的吸收系数：定位 f 所在区间 [f_i, f_{i+1}]，按 α = α_i + (α_{i+1}−α_i)·(f−f_i)/(f_{i+1}−f_i) 计算；超出表范围时取最近端点值。
- 输入：工作频率 f、`g_abs[]`、`g_nAbs`。
- 输出：吸收系数 α(f)，单位 dB/km。

**M4 球面扩展损失计算模块**（源文件 `Spread.c`）
- 功能简介：按步长 dr 生成 `g_dist[]`，对每个距离计算球面扩展损失 TL_sph = 20·lg10(r)；对 r ≤ 0 的非法点给出提示并跳过（或置为极值），避免对数域错误。
- 输入：`g_param`（r0/r1/dr）。
- 输出：`g_dist[]`、`g_tlSph[]`、`g_nDist`。

**M5 吸收损失逐距离累加模块**（源文件 `AbsLoss.c`）
- 功能简介：调用 M3 得到工作频率的吸收系数 α（换算为 dB/m），对每个距离计算吸收损失 TL_abs = α·r/1000，逐点填充 `g_tlAbs[]`，并与同距离的球面扩展损失相加得到总传播损失 `g_tl[]`。
- 输入：`g_dist[]`、`g_tlSph[]`、α(f)。
- 输出：`g_tlAbs[]`、`g_tl[]`。

**M6 接收级计算模块**（源文件 `RecvLvl.c`）
- 功能简介：对每个距离计算接收级 RL = SL − TL，并结合噪声级与指向性指数给出"信号余量" SG = RL − (NL − DI) = SL − TL − (NL − DI)，用于判断该距离处信号是否可被接收。
- 输入：`g_param`、`g_tl[]`、`g_nDist`。
- 输出：`g_rl[]`；（屏幕）信号余量列表。

### 第三部分：数据输出（4 个模块）

**M7 传播损失-距离表模块**（源文件 `TLTable.c`）
- 功能简介：以表格形式输出各距离的球面扩展损失、吸收损失、总传播损失与接收级，列宽对齐、保留 2 位小数；支持按距离抽样输出以免屏刷过快。
- 输入：`g_dist[]`、`g_tlSph[]`、`g_tlAbs[]`、`g_tl[]`、`g_rl[]`、`g_nDist`。
- 输出：屏幕"传播损失—距离"表。

**M8 曲线字符画模块**（源文件 `PlotTL.c`）
- 功能简介：以距离为横轴、传播损失为纵轴，把 `g_tl[]` 序列映射到字符网格，用 `*` 描点绘制损失随距离变化的曲线；纵轴自动缩放到当前损失范围，并标注若干关键点的距离与损失值。
- 输入：`g_dist[]`、`g_tl[]`、`g_nDist`。
- 输出：屏幕传播损失曲线字符画。

**M9 频率对比实验模块**（源文件 `FreqExp.c`）
- 功能简介：对频率列表（如 1/5/10/20/50/100 kHz）逐个调用 M3 求吸收系数并重算指定距离（如 10 km）处的总传播损失，输出"频率-吸收系数-总损失"对比表，展示高频吸收的迅速增长。
- 输入：`g_param`、频率列表。
- 输出：屏幕频率对比表。

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（录参数/读吸收表/算损失/算接收级/看表/画曲线/频率对比/退出），用 `do-while + switch` 调度 M1～M9；用状态标记约束"必须先录入参数并读入吸收表才能计算"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1～M9，循环直至退出；状态标记 `g_ready` 约束"未录入参数或未读入吸收表不得计算"。M1、M2 完成后 M3 可取吸收系数，M4/M5/M6 依次完成损失链路，M7/M8/M9 输出。

**数据流**：

```
吸收系数文件 ─► M2 读入 ─► g_abs[]    M1 参数录入 ─► g_param
                                │                     │
                                ▼                     ▼
                          M3 吸收系数插值 α(f)   M4 球面扩展损失
                                │                 g_dist[] / g_tlSph[]
                                ▼                     │
                          M5 吸收损失逐距离累加 ◄─────┘
                                │  g_tlAbs[] / g_tl[]
                                ▼
                          M6 接收级计算 ─► g_rl[]
                                │
        ┌───────────────────────┼───────────────────────┐
        ▼                       ▼                       ▼
   M7 传播损失表           M8 曲线字符画           M9 频率对比实验
                                │
                                ▼
                          M10 主控菜单调度
```

所有模块仅通过 `g_abs`、`g_param`、`g_dist`、`g_tlSph`、`g_tlAbs`、`g_tl`、`g_rl` 及函数参数交换数据，函数接口在编码前书面约定。

## 十、选做扩展

1. 增加柱面扩展模式（TL = 10·lg r），与球面扩展模式对比同一工况下的损失差，仍是公式计算。
2. 引入目标强度 TS，按主动声呐方程计算回波级（EL = SL − 2·TL + TS）与信噪比，仍在课程公式范围内。
3. 对吸收系数随频率变化的频带做梯形数值积分求平均吸收，复用课程 3.5 的积分方法。
