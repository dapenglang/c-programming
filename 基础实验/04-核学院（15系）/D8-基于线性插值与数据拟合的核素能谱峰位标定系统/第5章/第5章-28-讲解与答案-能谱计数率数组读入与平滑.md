## 二、预备知识：滑动平均为什么能"抹平噪声"

### 1. 问题是怎么来的

γ 计数服从统计规律：**同一个道址重复测量，计数率会在真值附近上下跳动**。这叫统计涨落（噪声）。跳动的幅度可能和真峰一样高，直接寻峰就会把噪声毛刺误判成峰。

要抑制噪声，最自然的想法是：**一个点的随机跳动，被它邻居"中和"掉就好。** 因为噪声是随机上下跳的，而真实的峰是范围内所有点共同抬高——把邻域平均一下，随机部分互相抵消，真实信号保留。

### 2. 三点滑动平均的公式

对内部点 $i$，用左邻、自己、右邻三个值取算术平均：

$$
c'[i] = \frac{c[i-1] + c[i] + c[i+1]}{3}
$$

- 若 $c[i]$ 是**孤立毛刺**（远高于左右），平均后会被明显压低；
- 若 $c[i]$ 位于**真实峰**上（左右也高），平均后仍然高；
- 首尾两点没有完整邻域，**保留原值**。

**为什么能保留峰位？** 因为平均是"局部窗口"操作，最高点不会因平均而移动位置——它还是那附近最高的点。所以**平滑抑制噪声而不改变峰在哪儿**，这正是寻峰预处理想要的。

**窗口大小的权衡**：三点窗口平滑轻、保留细节多；五点、七点窗口平滑强、但会把窄峰也抹平。本题用最简的三点窗口，先把方法学清楚。

### 3. 用"读原写新"走一遍

样例 1：$c = [1, 3, 9, 4, 2, 8, 3]$，$n=7$。

复制一份到 $s$（初值与 $c$ 相同），再逐点算 $i=1 \sim 5$：

| i | c[i-1], c[i], c[i+1] | s[i] = 均值 |
|---|---|---|
| 1 | 1, 3, 9 | (1+3+9)/3 = 4.3333 |
| 2 | 3, 9, 4 | (3+9+4)/3 = 5.3333 |
| 3 | 9, 4, 2 | (9+4+2)/3 = 5.0000 |
| 4 | 4, 2, 8 | (4+2+8)/3 = 4.6667 |
| 5 | 2, 8, 3 | (2+8+3)/3 = 4.3333 |

首尾还原：$s[0]=1$、$s[6]=3$。结果：$1.00,\ 4.33,\ 5.33,\ 5.00,\ 4.67,\ 4.33,\ 3.00$。

注意原来 $c[2]=9$（一个尖毛刺）被压到 $5.33$，两个峰（道址 2 处的 9 和道址 5 处的 8）虽然被削弱但**位置没变**——这就是平滑的作用。

**关键点**：上面所有 $s[i]$ 都是从**原数组 $c$** 读的。若直接改 $c$，算 $s[2]$ 时用的 `c[1]` 已经是平滑后的 4.3333，结果会变成 $(4.3333+9+4)/3 = 5.7778$，全盘皆错。

### 4. 编程时怎么用它

两步：**先复制**（把 $c$ 整体拷进 $s$），**再对内部点计算**（读 $c$、写 $s$）。这是数组变换的通用安全模式。

> **这个思想在综合实验中反复出现**：D8 平滑预处理、第 3 章 10 的滤波、图像处理里的均值滤波，全部是"邻域平均"。**关键的工程纪律是"读原写新"**——但凡变换会改变值域，就用一个独立的结果数组，避免"自己吃自己"。

## 三、解题思路

1. **读入数据**：`scanf("%d",&n);`，循环读入 `c[50]`；
2. **复制**：`for (i=0;i<n;i++) s[i] = c[i];`（首尾自动保留原值）；
3. **平滑内部点**：`for (i=1;i<=n-2;i++) s[i] = (c[i-1] + c[i] + c[i+1]) / 3.0;`——**读 c 写 s**；
4. **输出**：循环输出 `s[i]`，`%.2f`，第一个前不加空格、其余前加空格。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double c[50], s[50];        /* c 为原始谱，s 为平滑结果 */
    int n, i;

    scanf("%d", &n);            /* 读入谱长度 */

    for (i = 0; i < n; i++) {
        scanf("%lf", &c[i]);    /* 读入各道计数率 */
    }

    for (i = 0; i < n; i++) {   /* 先复制原数据；首尾因此自动保留原值 */
        s[i] = c[i];
    }

    /* 三点滑动平均：读原数组 c，写结果数组 s，避免就地修改的污染 */
    for (i = 1; i <= n - 2; i++) {
        s[i] = (c[i - 1] + c[i] + c[i + 1]) / 3.0;
    }

    for (i = 0; i < n; i++) {   /* 输出平滑结果，空格分隔 */
        if (i > 0) printf(" ");
        printf("%.2f", s[i]);
    }
    printf("\n");

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 7: 1 3 9 4 2 8 3 | 内部五点平滑为 4.33/5.33/5.00/4.67/4.33，首尾 1、3 不变 | `1.00 4.33 5.33 5.00 4.67 4.33 3.00` ✓ |
| 5: 全 10 | 任意三点平均都是 10 | `10.00 10.00 10.00 10.00 10.00` ✓ |
| 5: 1 2 3 2 1 | i=1:(1+2+3)/3=2.00；i=2:(2+3+2)/3=2.33；i=3:(3+2+1)/3=2.00 | `1.00 2.00 2.33 2.00 1.00` ✓ |

三例验证：恒定谱平滑后不变（平滑对平坦数据无副作用）；对称谱平滑后仍对称；尖毛刺被压低而非消除。

## 六、常见错误与讲解

**错误 1：就地修改原数组（最典型）**

```c
for (i = 1; i <= n - 2; i++)
    c[i] = (c[i-1] + c[i] + c[i+1]) / 3.0;   /* 错：c[i-1] 已被改过，结果被污染 */
```

算 `c[i]` 时用到的 `c[i-1]` 已经是上一次循环平滑后的值，等于把"上一轮结果"也平均进来了。这会让平滑越来越"糊"，且结果依赖于计算顺序。**纪律：变换数据时用独立的结果数组，读原数组、写新数组。**

**错误 2：把首尾也平滑（越界）**

```c
for (i = 0; i < n; i++)
    s[i] = (c[i-1] + c[i] + c[i+1]) / 3.0;   /* 错：i=0 时 c[-1] 越界，i=n-1 时 c[n] 越界 */
```

平滑只能对"有完整左右邻"的内部点做，循环必须是 `i = 1` 到 `n-2`。

**错误 3：除以 2 或除以 4（窗口数与除数不符）**

```c
s[i] = (c[i-1] + c[i] + c[i+1]) / 2.0;   /* 错：三个数相加却除以 2，结果偏大 */
s[i] = (c[i-1] + c[i] + c[i+1]) / 3.0;   /* 对：三个数除以 3 */
```

平均值的分母必须等于"参与相加的个数"。三点窗口就是除以 3。

**错误 4：忘记复制导致首尾变垃圾值**

```c
double s[50];                    /* 未初始化 */
for (i = 1; i <= n-2; i++) s[i] = ...;
printf("%.2f", s[0]);            /* 错：s[0] 从未赋值，输出垃圾值 */
```

首尾要保留原值，就得先整体复制（或单独给 `s[0]=c[0]; s[n-1]=c[n-1];`）。
