# 第 8 章 练习 22　采样数据文件滤波处理

**所属综合实验**：B2（B2-基于滑动平均滤波的传感器数据去噪系统）

**对应章节**：8 文件（8.1 文件的概念、8.2 打开与关闭、8.3 读写、8.4 文件定位）、4.1 函数定义、5.1 一维数组、3.3 循环结构

**场景来源**：综合实验 B2《基于滑动平均滤波的传感器数据去噪系统》（人工智能学院）——本练习是该实验中"离线滤波处理"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

传感器采集的数据往往先存成文件（比如一次实验记录了几百个采样值），事后用程序做**离线滤波**：读入原始数据，算出去噪结果，再写回新文件。这样原始数据保留不动，随时可以用不同参数重跑。

B2 系统的完整工作流程就是：**读文件 → 滑动平均滤波 → 写文件**。本题把这条链完整实现一遍，滤波窗口固定为 3 点（当前点与左右各一点求平均）。

## 二、任务要求

编写一个完整程序 `filter_file.c`：

1. 从键盘读入两个文件名：输入文件名、输出文件名；
2. 输入文件格式：第一行为整数 $n$（采样点数，$1 \le n \le 50$），随后一行 $n$ 个实数（原始采样值）；
3. 定义函数
   ```c
   double smooth(double *a, int n, int i);
   ```
   功能：返回以 `i` 为中心、窗口半宽 1（即取 $i-1, i, i+1$ 三点）的平均值；若下标越界，则只对有效点求平均。
4. 用该函数对每个点滤波，把 $n$ 个去噪值写入输出文件（每行一个，保留 4 位小数）；
5. **检查 `fopen` 返回值**。

## 三、输入输出格式

**输入**：两行，第一行输入文件名，第二行输出文件名。

**输出**：屏幕输出一行 `done: n points`；去噪结果写入输出文件。

## 四、样例

**输入文件 `data.txt`**：
```
5
10 12 14 16 18
```

**运行**（输入两行文件名）：
```
data.txt
clean.txt
```

**输出文件 `clean.txt`**：
```
11.0000
12.0000
14.0000
16.0000
17.0000
```

**屏幕输出**：
```
done: 5 points
```

## 五、提示

滑动平均（窗口半宽 1）：

$$
\bar{a}_i = \frac{1}{m}\sum_{k=i-1}^{i+1} a_k
$$

其中 $m$ 是实际参与求和的点数（越界的不算）。端点 $i=0$ 只取 $a_0, a_1$ 两点（$m=2$）；$i=n-1$ 只取 $a_{n-2}, a_{n-1}$ 两点；中间点 $m=3$。

流程：

1. `fopen` 打开输入，读出 $n$ 和全部采样值到数组 `a[]`；
2. 对每个 $i$ 调用 `smooth(a, n, i)`；
3. `fprintf(out, "%.4f\n", y)` 逐个写出；
4. `fclose` 两个文件。

**完成本练习后你将具备的能力**：把文件读写与数组、函数结合起来完成完整的数据处理流程——读入、计算、写出——这是实验 B2 中"离线滤波模块"的地基。
