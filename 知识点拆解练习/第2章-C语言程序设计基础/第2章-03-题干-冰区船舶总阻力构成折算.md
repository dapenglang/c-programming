# 第 2 章 练习 03　冰区船舶总阻力构成折算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C6《基于包围盒扫掠检测与冲量计算的碎冰碰撞模拟系统》/ C7《基于冲量-动量反演的冰阻力与碰撞事件辨识系统》（水声学院）——本练习是该实验中"冰阻力分量拆解"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

船舶在冰区航行时，船体受到的**总冰阻力**由几部分叠加而成：破冰时挤压冰层产生的**破冰阻力**，船体与碎冰摩擦产生的**摩擦阻力**，以及把碎冰排开、堆积在船首的**排开阻力**。

在实验 C7 中，程序先用冲量-动量反演算出总阻力，再按经验比例把它拆成各分量，以便分别与强度要求比较。例如某次冰况下测得总阻力 500 kN，各分量占比分别为破冰 40%、摩擦 35%、排开 25%，那么三个分量分别是多少？这就是本题要完成的一次"百分比折算"。

## 二、任务要求

编写一个完整程序 `ice_resistance.c`：

1. 从键盘读入**总阻力** `R`（单位：kN，double 类型）及三个**百分比**：破冰占比 `p1`、摩擦占比 `p2`、排开占比 `p3`（均为百分数，如 40 表示 40%，**题目保证三者之和为 100**，故本程序不需要判断分支）；
2. 用公式 $R_i = R \times \dfrac{p_i}{100}$ 分别反算三个分量值；
3. 按规定格式输出三个分量，均保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，四个实数，依次为总阻力 R（kN）与三个占比 p1、p2、p3（%），数之间以空格分隔。

**输出**：三行，分别按 `R_break = 结果 kN`、`R_friction = 结果 kN`、`R_displace = 结果 kN` 输出，结果均保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
500 40 35 25
```
输出：
```
R_break = 200.0000 kN
R_friction = 175.0000 kN
R_displace = 125.0000 kN
```

**样例 2**

输入：
```
320 50 30 20
```
输出：
```
R_break = 160.0000 kN
R_friction = 96.0000 kN
R_displace = 64.0000 kN
```

## 五、提示

已知总量 $R$ 与某分量占比 $p\%$，则该分量的值为

$$
R_i = R \times \frac{p_i}{100}
$$

注意：百分数在程序里**没有专门的数据类型**，`40` 只是一个普通数字，除以 100 才是它的真实比例；写成 `R * p1 / 100` 时，若 `p1` 与 `100` 都是整数会触发整数除法，必须保证参与运算的数是浮点数。

**完成本练习后你将具备的能力**：把"百分比"这一日常概念准确翻译成程序里的除法与乘法、正确书写多步算术表达式、一次读入多个数并分行输出——这些是实验 C7 中阻力分量报表的基础。
