## 二、预备知识：链表的基本原理（零基础阅读）

### 1. 问题是怎么来的

数组好处是"随叫随到"（下标直达），坏处是**长度定死**、增删要整块搬动。测点数据条数不定、增删频繁，数组两头吃亏。链表把每条记录包进一个**节点**，节点里除了数据成员，还有一根"挂钩"——`next` 指针，指向下一个节点。数据不要求连续存放，挂钩负责把队伍串起来；要加人就**现场造一个节点挂上去**，不用搬动任何人。

### 2. 节点类型与内存图

```c
struct Node {
    char id[16];
    double depth;
    struct Node *next;    /* 挂钩：指向同类型节点 */
};
```

成员类型里出现自身指针，这叫**自引用结构**——注意是 `struct Node *`（指针），不是 `struct Node`（会无限嵌套，非法）。

头插法插入三条记录 `S01, S02, S03` 后的内存图：

```
head
  │
  ▼
+------+------+------+        +------+------+------+        +------+------+------+
| "S03"| 22.0 | next │───┐    | "S02"| 18.2 | next │───┐    | "S01"| 15.5 | NULL │
+------+------+--┬---+   │    +------+------+--┬---+   │    +------+------+------+
                └────────┴───────────────────┘        └──→（队尾，next 为空）
```

`head` 永远指向"最新的节点"；顺着 `next` 走，先遇到后录入的记录——这就是头插法"逆序"的由来。

### 3. 头插三步曲

每读入一条记录：

```c
p = (struct Node *)malloc(sizeof(struct Node));  /* 造节点 */
/* 填数据：strcpy(p->id, ...); p->depth = ...; */
p->next = head;     /* 新节点牵住旧链头 */
head = p;           /* 新节点升任链头 */
```

`head` 初值 `NULL`：第一条记录插入时 `p->next = NULL`，它自动成为队尾。

### 4. 遍历与计数

```c
cnt = 0;
for (p = head; p != NULL; p = p->next) {
    printf("%-9s%9.2f\n", p->id, p->depth);
    cnt++;
}
```

游标 `p` 从 `head` 出发，每步沿 `p = p->next` 前进，踩到 `NULL` 停下——绝不要写 `p != NULL` 之外的"智能"条件（比如数长度再比较），链表长度的唯一真相就是 `next` 链。

### 5. 用本例走一遍

样例 1 依次插入 `S01(15.5)`、`S02(18.2)`、`S03(22.0)`：

| 插入 | 动作 | 链状态（头→尾） |
|---|---|---|
| S01 | head=NULL→p | S01 |
| S02 | 插到 S01 前 | S02 → S01 |
| S03 | 插到 S02 前 | S03 → S02 → S01 |

遍历输出 S03、S02、S01，计数 3——与样例一致。

> **这套代码在综合实验中原样出现**：C10 的链表建立（M4）、文件批量读入建链（M3）都是同一个循环体；练习 41 的查找与删除也只是在遍历骨架上加判断。链表是 C10 的"骨架级"知识点。

## 三、解题思路

1. 定义节点类型，`head = NULL`；
2. 循环 `n` 次：`malloc` 造节点、填数据、头插；
3. 从 `head` 遍历输出并计数；
4. 逐节点 `free`，输出总数。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Node {
    char id[16];       /* 测点编号 */
    double depth;      /* 水深 m */
    struct Node *next; /* 下一节点 */
};

int main(void)
{
    struct Node *head = NULL, *p, *q;
    char id[16];
    double depth;
    int n, i, cnt = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%s %lf", id, &depth);
        p = (struct Node *)malloc(sizeof(struct Node));  /* 造节点 */
        strcpy(p->id, id);
        p->depth = depth;
        p->next = head;     /* 头插第一步：牵住旧链头 */
        head = p;           /* 头插第二步：新节点任链头 */
    }

    for (p = head; p != NULL; p = p->next) {   /* 遍历输出 */
        printf("%-9s%9.2f\n", p->id, p->depth);
        cnt++;
    }
    printf("共 %d 个节点\n", cnt);

    p = head;
    while (p != NULL) {                        /* 逐节点释放 */
        q = p->next;
        free(p);
        p = q;
    }
    return 0;
}
```

## 五、运行验证

**样例 1**（头插逆序）：

```
3
S01 15.5
S02 18.2
S03 22.0
S03          22.00
S02          18.20
S01          15.50
共 3 个节点
```

**样例 2**（单节点）：

```
1
A7 3.0
A7           3.00
共 1 个节点
```

| 样例 | 验证点 | 程序输出 |
|---|---|---|
| 1 | 顺序与录入相反；计数 3 | ✓ |
| 2 | 单节点链；head 与队尾重合 | ✓ |

**反例验证**：把头插两句顺序颠倒（先 `head = p;` 再 `p->next = head;`），`p->next` 会指向自己，遍历**死循环**——"先接后断"的顺序是头插法的生命线。

## 六、常见错误与讲解

**错误 1：头插两句颠倒**

```c
head = p;           /* 错：先上任，再接旧链头，p->next = head 指向自己 */
p->next = head;
```

**错误 2：遍历条件写 `p->next != NULL`**

```c
for (p = head; p->next != NULL; p = p->next)   /* 错：漏掉最后一个节点 */
for (p = head; p != NULL; p = p->next)         /* 对：判 p 自身 */
```

**错误 3：忘 `malloc` 或类型强转漏括号**

```c
struct Node p;                                  /* 错：普通变量没有 next 挂钩语义 */
p = malloc(sizeof(struct Node));                /* 老编译器可过，好习惯是强转 */
p = (struct Node *)malloc(sizeof(struct Node)); /* 对 */
```

**错误 4：释放链表时 `free(p)` 后直接 `p = p->next`**

```c
while (p) { free(p); p = p->next; }   /* 错：free 后再访问已释放内存，危险 */
while (p) { q = p->next; free(p); p = q; }   /* 对：先记住下一站再释放 */
```
