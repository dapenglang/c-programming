## 二、预备知识：结构体的基本原理（零基础阅读）

### 1. 问题是怎么来的

一条测点记录有三个字段：编号（字符串）、水深（double）、时刻（字符串）。若用零散变量，3 条记录就要 9 个变量；50 条就是 150 个。更麻烦的是，这些变量之间**没有任何联系**——排序、查找时无法把它们当成"一条记录"整体搬动。

**结构体 = 把若干不同类型的成员捆成一种新类型。** 一次定义 `struct Rec`，之后它就像 `int`、`double` 一样可以声明变量、数组，而"一条记录"从此是一个整体。

### 2. 定义、声明、访问三步曲

```c
/* 第一步：定义类型（画图纸，不占内存） */
struct Rec {
    char id[16];
    double depth;
    char tm[8];
};

/* 第二步：声明变量/数组（按图纸盖房子，分配内存） */
struct Rec r[50];

/* 第三步：点运算符访问成员 */
r[0].depth = 15.5;
strcpy(r[0].id, "S01");
scanf("%lf", &r[0].depth);    /* 数值成员要取地址 */
scanf("%s", r[0].id);         /* 字符数组成员本身就是地址，不加 & */
```

一条记录在内存里是**连续存放**的三个成员：

```
struct Rec r[3]（示意）：
+----------+--------+--------+----------+--------+--------+----
| r[0].id  |r[0].dep|r[0].tm | r[1].id  |r[1].dep|r[1].tm | ...
| "S01"    | 15.5   |"08:30" | "S02"    | 18.2   |"09:00" | ...
+----------+--------+--------+----------+--------+--------+----
```

### 3. 公式推导

平均水深就是对数组做一遍普通累加：

$$\bar{d}=\frac{1}{n}\sum_{i=0}^{n-1}r[i].\text{depth}$$

### 4. 用本例走一遍

样例 1 的三条记录：15.5 + 18.2 + 22.0 = 55.7，平均 55.7 / 3 = 18.5666…，保留 2 位小数为 18.57——与样例一致。

输出格式：`%-9s` 左对齐占 9 列输出编号，`%9.2f` 右对齐占 9 列输出水深，`%6s` 右对齐输出时刻。

> **这个类型定义在综合实验中反复出现**：C10 的所有模块（录入 M2、链表 M4～M6、排序 M7、文件 M9）都建立在这同一个 `struct Rec` 上；第 8 章练习 38 的文件存取也只是把它整体写入/读出文件。类型定义是"一次投入，处处受益"。

## 三、解题思路

1. 文件顶部定义 `struct Rec`；
2. 读 `n`，循环读入每条记录的三个成员；
3. 循环累加求和，得平均；
4. 先打印表头与分隔线，再逐条打印，最后打印平均。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>

/* 测点记录类型：编号、水深、时刻 */
struct Rec {
    char id[16];      /* 测点编号 */
    double depth;     /* 水深 m */
    char tm[8];       /* 观测时刻 HH:MM */
};

int main(void)
{
    struct Rec r[50];
    double s = 0.0;
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%s", r[i].id);           /* 字符数组：本身就是地址 */
        scanf("%lf", &r[i].depth);      /* 数值成员：取地址 */
        scanf("%s", r[i].tm);
        s += r[i].depth;
    }

    printf("编号      水深(m)   时刻\n");
    printf("------------------------\n");
    for (i = 0; i < n; i++) {
        printf("%-9s%9.2f%6s\n", r[i].id, r[i].depth, r[i].tm);
    }
    printf("------------------------\n");
    printf("平均水深：%.2f m\n", s / n);
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：定义类型忘分号**

```c
struct Rec {
    char id[16];
    double depth;
};                    /* 这个分号极易漏，一漏后面全线报错 */
```

**错误 2：数值成员忘取地址**

```c
scanf("%lf", r[i].depth);     /* 错：double 成员不是数组，必须 & */
scanf("%lf", &r[i].depth);    /* 对 */
```

**错误 3：用类型名当变量**

```c
Rec.depth = 15.5;               /* 错：struct Rec 是类型，不是变量 */
struct Rec a; a.depth = 15.5;   /* 对：先声明变量再访问 */
```

**错误 4：成员访问写错层级**

```c
r.depth        /* 错：r 是数组，不是单条记录 */
r[i].depth     /* 对：先下标取记录，再点运算取成员 */
```
