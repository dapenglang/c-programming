# 第 2 章 练习 01　按高度查算风压系数（单段线性插值）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 A1《基于线性插值的风荷载计算系统》（航建学院）——本练习是该实验中"风压高度变化系数查算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

风是建筑物承受的主要水平荷载之一。结构工程师计算风荷载时，使用的公式是：

$$
w_k = \mu_z \times w_0
$$

其中 $w_0$ 是基本风压，$\mu_z$ 是**风压高度变化系数**——它反映"离地面越高、风速越大、风压越强"的规律。

设计规范不可能列出每一米高度的系数，只给出若干标准高度档的数值。以地面粗糙度 B 类（城市郊区）为例，规范表格如下：

| 高度 h（m） | 风压高度变化系数 μ_z |
|---|---|
| 10 | 1.00 |
| 20 | 1.23 |

当建筑物高度介于两档之间（例如 15.5 m）时，规范允许用**线性插值**求出对应系数。这项查表加插值的工作，就是风荷载计算程序（实验 A1）每天都要成千上万次执行的基本操作。

## 二、任务要求

编写一个完整程序 `wind_pressure.c`：

1. 程序中用**常量**存放上表的数据（相邻两档高度 10 m、20 m 及对应系数 1.00、1.23）；
2. 从键盘读入一个建筑物计算高度 `h`（单位：米，double 类型，**题目保证 10 ≤ h ≤ 20**，因此本程序不需要判断分支）；
3. 用线性插值公式计算该高度对应的风压高度变化系数 `μ_z`；
4. 按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示建筑物计算高度 h（米）。

**输出**：一行，按格式 `mu_z = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
15
```
输出：
```
mu_z = 1.1150
```

**样例 2**

输入：
```
17.5
```
输出：
```
mu_z = 1.1725
```

## 五、提示

线性插值公式：已知两点 $(x_0,\, y_0)$、$(x_1,\, y_1)$，则 $x$ 处的插值为

$$
y = y_0 + \dfrac{(y_1 - y_0)\,(x - x_0)}{x_1 - x_0}
$$

本程序的数据都存放在代码里（常量），只需要读入一个数、算一步、输出一个数——这正是"顺序执行的一个完整计算流程"。

**完成本练习后你将具备的能力**：定义常量与变量、选择正确的数据类型、书写算术表达式、使用 scanf/printf 完成输入输出、手写一个线性插值计算——这些是实验 A1 中"风荷载计算模块"的地基。
