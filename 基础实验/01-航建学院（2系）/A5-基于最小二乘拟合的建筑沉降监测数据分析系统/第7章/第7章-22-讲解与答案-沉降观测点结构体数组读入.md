## 二、预备知识：结构体数组的基本原理（零基础阅读）

### 1. 问题是怎么来的——一个盒子不够用了

上一练习的 `TrussBar b;` 只装得下一根杆件。但一次观测有几十个点，每个点都是"点号 + 沉降量 + 天数"。显然不能定义 `sp1, sp2, ..., sp50` 五十个变量。

回想第 5 章学的数组：**同类型的一排变量，用下标区分**。结构体数组就是"一排结构体变量"——每个元素都是一个完整的结构体盒子，里面装着该对象的所有属性。

### 2. 结构体数组长什么样

```c
SettlePoint sp[50];
```

内存里就是 50 个连着的"观测点盒子"，每个盒子内部有三个格子：

```
sp[0] ┌──────┬─────────┬───────┐
      │ id   │ settle  │ days  │
      │"JC01"│ 12.35   │ 145   │
      └──────┴─────────┴───────┘
sp[1] ┌──────┬─────────┬───────┐
      │ id   │ settle  │ days  │
      │"JC02"│ 9.80    │ 145   │
      └──────┴─────────┴───────┘
      ...
sp[2] ┌──────┬─────────┬───────┐
      │ id   │ settle  │ days  │
      │"JC03"│ 15.20   │ 145   │
      └──────┴─────────┴───────┘
```

### 3. 怎么访问——"先下标，后点号"

要拿到第 `i` 个点的沉降量，分两步：

1. 用下标 `sp[i]` 选出第 `i` 个盒子；
2. 用点号 `.settle` 打开盒子里叫 `settle` 的格子。

连起来就是：

```c
sp[i].settle
```

**优先级提醒**：`[]` 和 `.` 的优先级相同，从左往右结合，所以 `sp[i].settle` 先算 `sp[i]` 再取 `.settle`，含义明确。但如果是"指向结构体的指针"，就要写 `p->settle`（第 7 章后面的链表会用到），不能写成 `*p.settle`。

### 4. 用本例走一遍

读入 3 个点：`JC01 12.35 145`、`JC02 9.80 145`、`JC03 15.20 145`。

- `sp[0].settle = 12.35`；
- `sp[1].settle = 9.80`；
- `sp[2].settle = 15.20`。

平均沉降量：

$$
\bar{s} = \frac{12.35 + 9.80 + 15.20}{3} = \frac{37.35}{3} = 12.45
$$

输出保留 3 位小数即 `12.450`。

### 5. 编程时怎么用它

结构体数组的"读入—遍历—统计"和普通数组几乎一样，唯一的差别是**每个元素要用点号拆开**：

- 读入：`scanf("%s %lf %d", sp[i].id, &sp[i].settle, &sp[i].days);`
- 累加：`sum += sp[i].settle;`
- 输出：`printf("%s ...", sp[i].id);`

注意字符串成员 `id` 本身就是地址（数组名），`scanf` 里**不加 `&`**；而数值成员要加 `&`。

## 三、解题思路

1. **定义结构体类型** `SettlePoint`；
2. **定义结构体数组** `sp[50]`；
3. **读入 n，循环读入 n 个观测点**；
4. **遍历输出**每点信息，同时累加 `settle`；
5. **输出平均沉降量**（`sum / n`，注意转实数）。

## 四、参考代码

```c
#include <stdio.h>

/* 定义"沉降观测点"结构体类型 */
typedef struct {
    char   id[16];     /* 点号，如 "JC01" */
    double settle;     /* 累计沉降量，mm */
    int    days;       /* 距首次观测天数，天 */
} SettlePoint;

int main(void)
{
    SettlePoint sp[50];    /* 最多 50 个观测点 */
    int n, i;
    double sum = 0.0;      /* 累计沉降量之和 */

    scanf("%d", &n);

    /* 循环读入各观测点数据 */
    for (i = 0; i < n; i++) {
        /* id 是字符数组，本身即地址，不加 & */
        scanf("%s %lf %d", sp[i].id, &sp[i].settle, &sp[i].days);
    }

    /* 遍历输出并累加 */
    for (i = 0; i < n; i++) {
        printf("%s: settle=%.2f days=%d\n",
               sp[i].id, sp[i].settle, sp[i].days);
        sum += sp[i].settle;
    }

    /* 平均沉降量：sum 是 double，除法天然为实数运算 */
    printf("avg_settle=%.3f\n", sum / n);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：`scanf` 里给字符串成员加了 `&`**

```c
scanf("%s", &sp[i].id);      /* 不推荐：id 已是地址，加 & 类型不符 */
scanf("%s", sp[i].id);       /* 对：数组名即地址 */
```

字符数组成员作为 `scanf` 的目标时，直接写数组名。

**错误 2：给数值成员忘了 `&`**

```c
scanf("%lf %d", sp[i].settle, sp[i].days);         /* 错：缺 & */
scanf("%lf %d", &sp[i].settle, &sp[i].days);       /* 对 */
```

数值成员和普通变量一样，`scanf` 需要地址。

**错误 3：成员访问顺序写反**

```c
sp.settle[i]        /* 错：sp 不是单个结构体，settle 也不是数组 */
sp[i].settle        /* 对：先选第 i 个盒子，再取 settle 格 */
```

**错误 4：结构体数组未用完就处理了 50 个**

```c
for (i = 0; i < 50; i++) ...    /* 错：实际只有 n 个点，多读的是垃圾数据 */
```

循环上界必须是**实际个数 n**，不是数组的容量 50。
