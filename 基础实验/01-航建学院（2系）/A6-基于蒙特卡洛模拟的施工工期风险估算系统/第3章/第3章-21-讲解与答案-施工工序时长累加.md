## 二、预备知识：累加求和的基本原理（零基础阅读）

### 1. 问题是怎么来的

工程师手里有一条关键路径，上面挂着 $n$ 道工序的时长。要算总工期，就是把它们一个一个加起来。人工做加法，5 个数字还能口算，20 个数字就容易出错，而且每换一次参数就要重算一遍。程序解决这类问题的办法只有一句话：**用一个变量专门做"累加器"，循环着往上面加**。

### 2. 公式是怎么推出来的

总工期就是各工序时长之和：

$$
T = t_1 + t_2 + t_3 + \cdots + t_n = \sum_{i=1}^{n} t_i
$$

写成"逐步累加"的样子，就是把左边这一长串改成一次次赋值：

$$
S_1 = t_1,\quad S_2 = S_1 + t_2,\quad S_3 = S_2 + t_3,\quad \cdots,\quad T = S_{n-1} + t_n
$$

其中 $S_k$ 表示"加完前 $k$ 项的部分和"。这个递推式说明：**每读一个新数，就把它加到累加器上，累加器的值始终等于"目前为止的和"**。循环 $n$ 次之后，累加器里装的就是总和 $T$。

平均时长则是把总和按份数平均：

$$
\bar{t} = \frac{T}{n}
$$

### 3. 用本例走一遍

以样例 1 为例，$n = 5$，时长依次为 2、5、3、7、4：

| 第几次 | 读入 $t_i$ | 累加器 sum（加之前） | 加之后 |
|---|---|---|---|
| 1 | 2 | 0 | 2 |
| 2 | 5 | 2 | 7 |
| 3 | 3 | 7 | 10 |
| 4 | 7 | 10 | 17 |
| 5 | 4 | 17 | 21 |

循环结束时 `sum = 21`，即总工期 21 天。平均时长 $= 21 / 5 = 4.2$，输出 `4.20`。

再看样例 2：3+3+14+5 = 25 天，平均 $25/4 = 6.25$。

### 4. 编程时怎么用它

累加结构有三个必须记住的要点：

1. **初值必须是 0**：`sum = 0;` 放在循环之前。如果忘了赋初值，`sum` 里是内存里的随机垃圾，结果全错；
2. **累加语句在循环体内**：`sum = sum + t;` 每轮执行一次，读一个新数就加一次；
3. **输出在循环之后**：循环结束才得到总和，输出语句不能写在循环里面。

这就是"累加"这类问题的固定模板：**初值 → 循环读入并累加 → 循环外输出**。

## 三、解题思路

1. **读入 n**：`scanf("%d", &n)`；
2. **准备累加器**：`int sum = 0;`；
3. **循环 n 次**：每轮读入一个时长 `t`，执行 `sum = sum + t`；
4. **循环后输出总和**：`printf("T = %d\n", sum)`；
5. **计算并输出平均值**：用 `sum * 1.0 / n` 保证实数除法，`printf("average = %.2f\n", ...)`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n;              /* 工序数量 */
    int i;              /* 循环变量 */
    int t;              /* 当前读入的工序时长，天 */
    int sum = 0;        /* 累加器，初值必须为 0 */

    /* 读入工序数量 */
    scanf("%d", &n);

    /* 循环读入 n 个工序时长并累加 */
    for (i = 0; i < n; i++) {
        scanf("%d", &t);        /* 读入第 i+1 道工序的时长 */
        sum = sum + t;          /* 累加到总工期上 */
    }

    /* 输出总工期（整数） */
    printf("T = %d\n", sum);

    /* 输出平均时长：sum * 1.0 把整数运算提升为实数运算 */
    printf("average = %.2f\n", sum * 1.0 / n);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 5 / 2 5 3 7 4 | 2+5+3+7+4 = 21；21/5 = 4.20 | `T = 21` `average = 4.20` ✓ |
| 4 / 3 3 14 5 | 3+3+14+5 = 25；25/4 = 6.25 | `T = 25` `average = 6.25` ✓ |
| 1 / 8 | 8；8/1 = 8.00 | `T = 8` `average = 8.00` ✓ |
| 3 / 10 20 30 | 10+20+30 = 60；60/3 = 20.00 | `T = 60` `average = 20.00` ✓ |

## 六、常见错误与讲解

**错误 1：累加器忘记赋初值**

```c
int sum;            /* 错：初值随机，结果无法预测 */
int sum = 0;        /* 对：累加器必须从 0 开始 */
```

这是本章最高频的错误。习惯写法：**看到"求和"，第一件事就是给它写上 `= 0`**。

**错误 2：整数除法丢小数**

```c
printf("%.2f\n", sum / n);        /* 错：sum、n 都是 int，21/5 得 4，不是 4.2 */
printf("%.2f\n", sum * 1.0 / n);  /* 对：先乘 1.0 变成 double 再除 */
```

C 语言的整数除法会直接丢弃小数部分（截断）。只要结果可能带小数，就要在其中一步引入实数。

**错误 3：累加语句写在循环外或放错位置**

```c
for (i = 0; i < n; i++) {
    scanf("%d", &t);
}
sum = sum + t;      /* 错：循环只累加了最后一个 t */
```

累加必须写在循环体内，每读一个就加一次。

**错误 4：`n` 与输入行对不上**

如果第二行只给了 4 个数却写了 `n = 5`，第 5 次 `scanf` 会读到下一行的数据或卡住。做题时先核对"第一行的 n"与"后面实际给出的数字个数"是否一致。
