## 二、预备知识：数组遍历求最值与均值的基本原理（零基础阅读）

### 1. 问题是怎么来的

温度场计算把连续分布离散成"节点温度序列"，程序拿到的是**一串数**。要从这串数里得到"最高多少、在哪""平均多少"，就必须**逐个看一遍**。这串数天然适合用**数组**存放，用循环遍历。

### 2. 数组与"遍历"是怎么组织的

数组是"一排编号连续的格子"。存 10 个温度：

```c
double t[50];          /* 最多 50 个节点，实际只用前 n 个 */
```

读入 n 个值：`for (i = 0; i < n; i++) scanf("%lf", &t[i]);`。**遍历**就是"下标 i 从 0 走到 n−1，每次处理 t[i]"。

### 3. 求最值与均值的思路是怎么来的

**（1）求最大值——"擂台法"。**

先假定第一个数（t[0]）就是最大值，把它记在 `Tmax`、下标记在 `imax`。然后从第二个数起逐个挑战：

- 如果 t[i] 比当前 Tmax 大，就"换擂主"：`Tmax = t[i]; imax = i;`；
- 否则擂台不变。

一圈走完，`Tmax`/`imax` 就是全局最大值及其位置。数学上这叫

$$
T_{\max} = \max_{0\le i<n} t[i],\qquad I_{\max} = \arg\max_{0\le i<n} t[i]
$$

用循环翻译：

```c
Tmax = t[0]; imax = 0;
for (i = 1; i < n; i++)
    if (t[i] > Tmax) { Tmax = t[i]; imax = i; }
```

求最小值只需把 `>` 改成 `<`。

**（2）求平均——"先累加、后相除"。**

$$
T_{\text{avg}} = \frac{1}{n}\sum_{i=0}^{n-1} t[i]
$$

累加变量 `sum` 初值必须为 0（累加初值是 0，累乘初值是 1），最后 `Tavg = sum / n`。

### 4. 用本例走一遍

样例 1 的 10 个温度：1750 1620 1490 1360 1230 1100 970 840 710 580。

- 最大值：第一个数 1750 就是最大，后续都更小，故 `Tmax = 1750.0`，下标 0；
- 最小值：最后一个 580 最小，`Tmin = 580.0`，下标 9；
- 平均值：\(\text{sum} = 1750+1620+1490+1360+1230+1100+970+840+710+580 = 11650\)，\(11650/10 = 1165.00\)。

样例 2：800 1200 1000 900 700。

- 最大 1200（下标 1）；最小 700（下标 4）；
- 和 \(= 4600\)，平均 \(= 920.00\)。

均与题意吻合。

> **这个思想在综合实验中反复出现**：D4 温度场统计（最值、均值）、D5 剂量率沿路径的最大值、D2 中子能量序列的最大/最小能量，全部用"擂台法 + 累加"。**"遍历数组求统计量"是核科学数据分析的日常操作。**

## 三、解题思路

1. **定义数组**：`double t[50];`，大小用题目上限 50（不能写变量大小，第 5 章只要求常量上界）；
2. **读入**：先读 `n`，再 `for` 循环读入 `n` 个温度；
3. **求最值**：用擂台法同时更新"值"和"下标"，分别做最大与最小两遍；
4. **求平均**：循环累加后除以 `n`；
5. **输出**：按四行格式，温度用 `%.1f`、平均用 `%.2f`、下标用 `%d`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double t[50];    /* 节点温度数组，最多 50 个节点，K */
    int    n;        /* 实际节点个数 */
    int    i;
    double tmax, tmin, sum, tavg;
    int    imax, imin;

    /* 读入节点个数与各节点温度 */
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf", &t[i]);
    }

    /* 擂台法求最大值及下标 */
    tmax = t[0]; imax = 0;
    for (i = 1; i < n; i++) {
        if (t[i] > tmax) { tmax = t[i]; imax = i; }
    }

    /* 擂台法求最小值及下标 */
    tmin = t[0]; imin = 0;
    for (i = 1; i < n; i++) {
        if (t[i] < tmin) { tmin = t[i]; imin = i; }
    }

    /* 循环累加求平均 */
    sum = 0.0;
    for (i = 0; i < n; i++) {
        sum = sum + t[i];
    }
    tavg = sum / n;

    printf("Tmax = %.1f at node %d\n", tmax, imax);
    printf("Tmin = %.1f at node %d\n", tmin, imin);
    printf("Tavg = %.2f\n", tavg);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：用变量定义数组大小**

```c
int n; scanf("%d", &n);
double t[n];              /* 错（C89/C90 不允许）：数组大小必须是编译期常量 */
double t[50];             /* 对：定义一个足够大的数组，只用前 n 个 */
```

第 5 章要求数组大小写**常量**（如 50），运行时只使用前 `n` 个元素。这是"够用即可"的保守做法。

**错误 2：循环边界写成 `<= n`**

```c
for (i = 0; i <= n; i++)     /* 错：i 会取到 n，t[n] 越界 */
for (i = 0; i < n; i++)      /* 对 */
```

下标范围是 0 ～ n−1，越界会读到垃圾数据，甚至污染其他变量。

**错误 3：求最值只更新值、不更新下标**

```c
if (t[i] > tmax) tmax = t[i];          /* 值对了，但 imax 没跟上 */
if (t[i] > tmax) { tmax = t[i]; imax = i; }   /* 对：值与下标成对更新 */
```

下标是"值的身份证"，两者必须同进同退，否则输出的位置是错的。

**错误 4：平均时整数除法**

```c
int n; ...
tavg = sum / n;        /* sum 是 double，n 是 int：会按 double/int 提升为 double，结果正确 */
```

本题因为 `sum` 是 `double`，混合除法会自动提升，结果无误。但若把 `sum` 也写成 `int`（截断小数），除法就会丢精度。**记住规则：只要有一个操作数是 double，结果就是 double。**
