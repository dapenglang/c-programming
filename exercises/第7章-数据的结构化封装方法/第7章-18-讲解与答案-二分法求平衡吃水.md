## 二、预备知识：结构体打包参数与二分法求解（零基础阅读）

### 1. 为什么要用结构体打包参数

求平衡吃水要用到三个量：半径 $R$、冰密度 $\rho_i$、海水密度 $\rho_w$。如果不用结构体，就得写成 `double bisect(double R, double rho_i, double rho_w, double eps)`，参数一多就"长尾巴"，还容易因为调用时顺序写反而出错。**结构体把"描述同一个物体的一组参数"打包成一个整体**：

```c
struct IceBlock { double R; double rho_i; double rho_w; };
```

之后传参只写一个 `struct IceBlock blk`，函数里用 `blk.R`、`blk.rho_i`、`blk.rho_w` 取用。C 语言中**结构体变量作参数是"按值传递"**：函数收到的是整个结构体的**一份拷贝**，函数内怎么改都不影响主函数里的原变量——正好适合这种"把参数送进去做计算、并不需要改回来"的场合。本题的求解器因此可以写得非常干净：`bisect(struct IceBlock blk, double eps)`。

### 2. 问题来源：平衡条件变成一个方程

漂浮冰块的受力平衡是"浮力 = 重力"。把两边相减，得到**残差函数**：

$$
f(d) = \underbrace{\rho_w\cdot\frac{\pi d^2(3R-d)}{3}}_{\text{浸没体积} \times \rho_w} - \underbrace{\rho_i\cdot\frac{4}{3}\pi R^3}_{\text{整球体积} \times \rho_i}.
$$

$f(d)$ 关于 $d$ **单调递增**：吃水越深，浮力越大、残差越大。所以 $f(d)=0$ 在 $[0,2R]$ 内**只有一个根**，求它就是在找"浮力刚好等于重力"的那个吃水。

### 3. 区间收缩原理与能否用二分法

二分法的依据是**零点定理**：连续函数在区间两端**异号**，区间内必有零点。检查本题的两个端点：

- $d = 0$：$f(0) = 0 - \rho_i V_{\text{总}} = -\rho_i V_{\text{总}} < 0$（浮力为零，重力为正）；
- $d = 2R$：整个球没入水中，$f(2R) = (\rho_w - \rho_i)V_{\text{总}} > 0$（海水比冰重，浮力大于重力）。

两端一负一正，二分法的前提满足。之后每次取中点 $m=\dfrac{a+b}{2}$：若 $f(a)\cdot f(m)\le0$ 就保留左半（令 $b=m$），否则保留右半（令 $a=m$）。区间长度每次减半，$n$ 次后缩到 $\dfrac{2R}{2^n}$，够小即可停。

### 4. 代入本例走一遍（取 $R=1$，区间 $[0,2]$）

| 2 | 1.000000 | 2.000000 | 1.500000 | −147.26 | 右半，$a\leftarrow1.5$ |

| 21 | 1.563805 | 1.563806 | 1.563805 | ≈0.001 | 区间 $<10^{-6}$，停止 |

最终吃水约 $1.563805$ m。回代检验：浮力 $\rho_w V \approx 3769.91$，重力 $\rho_i V_{\text{总}} \approx 3769.91$，两者几乎相等，说明求得的吃水正确。

### 5. 编程实现要点

- **方程与求解器分离**：`f(d, blk)` 只管算残差，`bisect(blk, eps)` 只管折半，换个物体只改传进去的结构体；
- **判据**：`while (b - a > eps)` 看区间长度，不看函数值；
- **端点更新**：异号保留左半（`b = m`），否则保留右半（`a = m`）；
- **返回中点**：停止后返回 `(a+b)/2`；对分次数用 `int *pn` 带回。

## 三、解题思路

1. **定义结构体** `struct IceBlock`；
2. **写 `f`**：按球缺体积公式算浮力项、按整球体积算重力项，返回二者之差；
3. **写 `bisect`**：`a = 0`、`b = 2*blk.R`，循环对分、计数，用 `*pn` 带回次数，返回根；
4. **`main`**：读入 `R`，把 `rho_i=900`、`rho_w=1025` 填入结构体，调用 `bisect`，按格式输出。

## 四、参考代码

```c
#include <stdio.h>

const double PI = 3.14159265358979323846;

/* 冰块参数：半径、冰密度、海水密度 */
struct IceBlock {
    double R;       /* 半径，m */
    double rho_i;   /* 冰密度，kg/m^3 */
    double rho_w;   /* 海水密度，kg/m^3 */
};

/* 残差 f(d) = 浮力 - 重力（结构体按值传入） */
double f(double d, struct IceBlock blk)
{
    double v_sub = PI * d * d * (3.0 * blk.R - d) / 3.0;   /* 球缺体积 */
    double v_tot = 4.0 * PI * blk.R * blk.R * blk.R / 3.0; /* 整球体积 */
    return blk.rho_w * v_sub - blk.rho_i * v_tot;
}

/* 二分法：在 [0, 2R] 内求吃水，对分次数经 pn 带回 */
double bisect(struct IceBlock blk, double eps, int *pn)
{
    double a = 0.0, b = 2.0 * blk.R, m;
    int n = 0;

    while (b - a > eps) {
        m = (a + b) / 2.0;                 /* 取中点 */
        n++;
        if (f(a, blk) * f(m, blk) <= 0.0)  /* 根在左半 */
            b = m;
        else                               /* 根在右半 */
            a = m;
    }
    *pn = n;                               /* 带回对分次数 */
    return (a + b) / 2.0;                  /* 返回中点作为吃水 */
}

int main(void)
{
    struct IceBlock blk;
    double draft;
    int n = 0;

    scanf("%lf", &blk.R);                  /* 只读半径 */
    blk.rho_i = 900.0;                     /* 填入两种密度 */
    blk.rho_w = 1025.0;

    draft = bisect(blk, 1e-6, &n);
    printf("draft = %.6f, n = %d\n", draft, n);

    return 0;
}
```

## 五、运行验证

```

**样例 2**（输入 `1.5`）：区间 $[0,3]$ 长度 3，第 22 次时 $3/2^{22}=7.2\times10^{-7}<10^{-6}$，停止，输出

```

$1.5 \times 1.563805 = 2.345708$，与样例一致——**吃水与半径成正比**，这也是一次合理性检验。

## 六、常见错误与讲解

**错误 1：结构体成员访问写错**

```c
return blk.rho_w * v_sub - blk.rho_i * v_tot;   /* 对：用 . 访问成员 */
return rho_w * v_sub - rho_i * v_tot;           /* 错：成员名脱离结构体，未定义 */
```
结构体成员必须用 `blk.` 前缀访问；`rho_w`、`rho_i` 单独的标识符在函数里并不存在。

**错误 2：区间端点选错，导致两端同号**

```c
double a = 0.0, b = blk.R;    /* 错：b=R 时 f(R) 未必为正，可能同号 */
double a = 0.0, b = 2*blk.R;  /* 对：d=2R 时整球没入，f>0 */
```
二分法要求两端异号。本题必须把右端点取到 $2R$（整球没入），才能保证 $f(2R)>0$。

**错误 3：收敛判据写成函数值足够小**

```c
while (f(m, blk) > eps) { … }   /* 不稳妥：f 的量纲是"力" */
while (b - a > eps) { … }        /* 对：看自变量区间长度 */
```
$f$ 的单位是力的量纲，用它当判据没有统一的尺度。二分法控制的是**吃水的误差**，应判 `b - a`。

**错误 4：忘记用指针带回对分次数**

```c
double bisect(struct IceBlock blk, double eps);   /* 错：n 无法传回主函数 */
```
主函数要知道对分次数，但函数已经用返回值返回了根，只能再用一个**指针参数**把次数写回主函数：`*pn = n;`，调用时传 `&n`。
