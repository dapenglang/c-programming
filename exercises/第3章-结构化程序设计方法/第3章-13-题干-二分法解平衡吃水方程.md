# 第 3 章 练习 13　二分法解平衡吃水方程

**对应章节**：3 结构化程序设计方法（3.5 数值求解方法——二分法解方程、3.3 循环结构、3.2 选择结构、3.4 关系与逻辑运算）

**场景来源**：综合实验 C8《冰块浮力与平衡吃水计算系统》（水声学院）——本练习是该实验中"平衡吃水求解"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰块漂浮在水面上，当它受到的水浮力正好等于自身重力时，就达到平衡；此时冰块浸入水中的深度称为**平衡吃水** $d$。真实冰块的横断面并非矩形，而是底部窄、水面附近宽的梯形（称为"型线"），宽度随离底高度线性增大，这使浸没体积随吃水呈非线性增长——平衡方程是一个二次方程。对这类方程，工程上常用二分法求数值解。本练习就是为 C8 实验求解平衡吃水。

## 二、任务要求

编写一个完整程序 `draft.c`：

1. 从键盘读入两个实数，用空格分隔：冰块总高 `H`（m）、冰块底面宽度 `W0`（m）；
2. 在程序中用常量固定以下参数：断面宽度随离底高度的增长率 `K = 0.10`（m/m，即高度每升高 1 m 宽度增加 0.10 m）、海水密度 `RHO_W = 1025`（kg/m³）、冰密度 `RHO_I = 917`（kg/m³）；
3. 构造平衡函数 `f(d) = 浮力 − 重力`，用 **while 循环 + 二分法**在区间 `[0, H]` 上求 `f(d) = 0` 的根，精度取 `1e-6`；
4. 输出求得的平衡吃水，保留 6 位小数。

## 三、输入输出格式

**输入**：一行，两个实数 `H W0`，中间用空格分隔。

**输出**：一行，格式为 `draft = 结果 m`，结果保留 6 位小数。

## 四、样例

**样例 1**

输入：
```
6.0 4.0
```
输出：
```
draft = 5.405189 m
```

**样例 2**

输入：
```
4.0 3.0
```
输出：
```
draft = 3.600987 m
```

## 五、提示

冰块断面宽度随离底高度 $z$ 线性变化：$w(z) = W0 + K z$。吃水为 $d$ 时，浸没部分体积（`L` 为冰块长度，两侧约去）

$$
V_{sub}(d) = L \int_0^{d}\bigl(W0 + K z\bigr)\,dz = L\left(W0\,d + \frac{K}{2}d^{2}\right)
$$

设冰块总高 $H$，则整体体积 $V_{tot} = L\left(W0\,H + \dfrac{K}{2}H^{2}\right)$。平衡条件为 $\rho_w g V_{sub} = \rho_i g V_{tot}$，约去 $g$、$L$ 后得到

$$
f(d) = \rho_w\left(W0\,d + \frac{K}{2}d^{2}\right) - \rho_i\left(W0\,H + \frac{K}{2}H^{2}\right) = 0
$$

因为 $\rho_w > \rho_i$，必有 $f(0) < 0$ 且 $f(H) > 0$，所以根一定落在 $[0, H]$ 内。用二分法取中点 `mid`，若 `f(mid) < 0` 说明吃水还不够，令 `lo = mid`；否则令 `hi = mid`；循环到 `hi - lo < 1e-6` 为止。

**完成本练习后你将具备的能力**：把一个真实物理平衡条件写成"函数值 = 0"的方程、用二分法求它的根——这正是实验 C8 中"吃水迭代求解模块"以及工程上一切单变量方程求解的通用做法。
