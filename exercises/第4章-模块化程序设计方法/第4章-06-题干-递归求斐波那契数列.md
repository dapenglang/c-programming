# 第 4 章 练习 06　递归求斐波那契数列

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 B4《基于深度优先搜索的迷宫求解系统》（人工智能学院）——本练习是该实验中"递归调用机制基础"环节的实现（对应 4.3 递归调用）。

**建议用时**：25 分钟

## 一、应用场景

斐波那契数列 $1,1,2,3,5,8,13,\dots$ 的规律是"从第三项起，每项等于前两项之和"。它的定义天然是双分支递推：要算第 $n$ 项，得同时知道第 $n-1$ 项和第 $n-2$ 项。这类"一个结果依赖两个更小结果"的递归模式，是与"一条链"式递归（如阶乘）不同的另一种基本形态，也是深度优先搜索等树形递归的入门模型。本练习用斐波那契把"双分支递归"讲清楚。

## 二、任务要求

编写一个完整程序 `fibonacci.c`：

1. 必须定义**递归函数**，**函数原型为**
   ```c
   long long fib(int n);
   ```
   返回斐波那契数列第 $n$ 项；
2. 函数必须同时具备两部分：
   - **基线条件**：当 `n == 1 || n == 2` 时返回 `1`（数列首两项定义为 1）；
   - **递推关系**：否则返回 `fib(n - 1) + fib(n - 2)`（函数中出现**两处**自我调用）；
3. 主函数读入整数 `n`（题目保证 $1 \le n \le 35$），调用 `fib`；
4. 按格式输出结果（整型，不带小数），用 `long long` 与 `%lld`。

## 三、输入输出格式

**输入**：一行，一个整数 n（$1 \le n \le 35$）。

**输出**：一行，按格式 `F(n) = 结果` 输出，例如输入 10 时输出 `F(10) = 55`。

## 四、样例

**样例 1**

输入：
```
10
```
输出：
```
F(10) = 55
```

**样例 2**

输入：
```
20
```
输出：
```
F(20) = 6765
```

## 五、提示

递推定义：

$$
F(1) = F(2) = 1,\qquad F(n) = F(n-1) + F(n-2)\quad(n \ge 3)
$$

与阶乘的"单链递归"相比，本题的递推关系里有**两处**自我调用，函数会像树枝一样分叉。注意：由于同一个下标会被反复计算，当 $n$ 较大时递归调用次数会迅速增多，因此本题把 $n$ 限制在 35 以内。

**完成本练习后你将具备的能力**：识别并实现"一个结果依赖多个更小结果"的双分支递归、理解递归调用树的分叉结构，以及分辨"递归的直观"与"递归的代价"——这是实验 B4 深度优先搜索的直接基础。
