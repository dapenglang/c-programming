# 第 4 章 练习 09　递归求幂与累加

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 C3《基于逐层累加的声传播损失估算系统》（水声学院）——本练习是该实验中"逐层累加与幂运算"环节的实现（对应 4.3 递归调用）。

**建议用时**：25 分钟

## 一、应用场景

在水声传播损失估算里，常常要把某一层的衰减倍率逐层相乘（这就是幂运算），又把各层的损失逐层相加（这就是累加）。幂运算与累加本身用循环实现很方便，但它们的数学定义天然是递推的：$x^n = x\cdot x^{n-1}$、$S_n = n + S_{n-1}$。本练习把这两个运算各写成一个递归函数，体会"同一件事既能用循环、也能用递归"的表达方式，理解递归替代循环的基本套路。

## 二、任务要求

编写一个完整程序 `pow_sum.c`：

1. 必须定义两个**递归函数**，**函数原型分别为**
   ```c
   double my_pow(double x, int n);   /* 返回 x 的 n 次幂 x^n */
   int    sum_to(int n);             /* 返回 1 + 2 + ... + n */
   ```
2. 两个函数都必须同时具备基线与递推两部分：
   - `my_pow`：当 `n == 0` 时返回 `1.0`，否则返回 `x * my_pow(x, n - 1)`；
   - `sum_to`：当 `n == 0` 时返回 `0`，否则返回 `n + sum_to(n - 1)`；
3. 主函数读入一个实数 `x` 和一个非负整数 `n`（题目保证 $0 \le n \le 20$）；
4. 按格式输出幂与累加结果，幂保留 **4 位小数**，累加为整数。

## 三、输入输出格式

**输入**：一行，一个实数 x 和一个非负整数 n，用空格分隔。

**输出**：两行，依次为 `pow = <x 的 n 次幂>`、`sum = <1 到 n 的累加和>`，幂保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2 10
```
输出：
```
pow = 1024.0000
sum = 55
```

**样例 2**

输入：
```
1.5 3
```
输出：
```
pow = 3.3750
sum = 6
```

## 五、提示

两个递推定义：

$$
x^0 = 1,\qquad x^n = x \cdot x^{n-1}\ (n \ge 1)
$$

$$
S(0) = 0,\qquad S(n) = n + S(n-1)\ (n \ge 1)
$$

两者结构完全平行："基线 + 把规模减一的同类问题组合起来"。注意 `my_pow` 的返回类型是 `double`（结果可能是小数），`sum_to` 的返回类型是 `int`（结果是整数），**接口类型必须和实际计算匹配**。

**完成本练习后你将具备的能力**：把循环能做的事改写成递归、识别"递推式的基线 + 组合方式"、在同一程序里组织两个独立递归函数——这是实验 C3 中逐层计算的通用写法，也为后续"递归与迭代的选择"打下判断力。
