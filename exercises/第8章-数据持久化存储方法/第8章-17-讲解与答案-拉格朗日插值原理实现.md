## 二、预备知识：拉格朗日插值的基本原理（零基础阅读）

### 1. 从两点线性插值说起

第 2 章的线性插值只有两个已知点 $(x_0, y_0)$、$(x_1, y_1)$，插值结果是一条直线。换个角度重写这个公式，把"起点 + 涨幅 × 比例"展开整理：

$$
y = y_0 + \frac{(y_1 - y_0)(x - x_0)}{x_1 - x_0}
   = y_0 \cdot \underbrace{\frac{x - x_1}{x_0 - x_1}}_{L_0(x)} + y_1 \cdot \underbrace{\frac{x - x_0}{x_1 - x_0}}_{L_1(x)}
$$

也就是说，线性插值其实可以写成"**加权平均**"的形式：

$$
y = y_0 \, L_0(x) + y_1 \, L_1(x)
$$

其中两个"权重"是

$$
L_0(x) = \frac{x - x_1}{x_0 - x_1}, \qquad L_1(x) = \frac{x - x_0}{x_1 - x_0}
$$

这两个权重函数 $L_0$、$L_1$ 有个奇妙的性质，请动手验证一下：把 $x = x_0$ 代入，得 $L_0(x_0) = 1$、$L_1(x_0) = 0$；把 $x = x_1$ 代入，得 $L_0(x_1) = 0$、$L_1(x_1) = 1$。也就是说——**每个权重只认自己的节点：在自己那儿是 1，在别人那儿是 0**。所以 $y = y_0 L_0 + y_1 L_1$ 在 $x_0$ 处自然等于 $y_0$，在 $x_1$ 处自然等于 $y_1$：加权平均保证插值曲线**精确穿过全部已知点**。

### 2. 推广到多个点：n 个节点构造 n−1 次多项式

两个点能定一条直线（1 次），三个点能定一条抛物线（2 次）——每多一个已知条件，多项式次数就升一次。一般地，$n$ 个节点 $(x_i, y_i)$（$i = 0, 1, \dots, n-1$，横坐标互不相同）唯一确定一个次数不超过 $n-1$ 的多项式 $P(x)$。仿照上面的"加权平均"思想，构造 n 个基函数 $L_0, L_1, \dots, L_{n-1}$，让**每个基函数只在自己的节点取 1、在其他所有节点取 0**：

$$
L_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n-1} \frac{x - x_j}{x_i - x_j}
$$

**为什么它在 $x_i$ 处为 1、在 $x_j$（$j \neq i$）处为 0？** 逐条看：当 $x = x_j$（$j \neq i$）时，连乘的分子中有一项 $(x - x_j) = 0$，整个乘积为 0——"在其他点为 0"由分子保证；当 $x = x_i$ 时，每个因子都变成 $\dfrac{x_i - x_j}{x_i - x_j} = 1$，乘积为 1——"在自己点为 1"由分子分母完全相同保证。由于横坐标互不相同，分母 $x_i - x_j \neq 0$，公式总有意义。

于是插值多项式就是：

$$
P(x) = \sum_{i=0}^{n-1} y_i \, L_i(x)
$$

它精确穿过全部节点：代入任何 $x_k$，只有 $L_k$ 幸存（为 1），其余全为 0，$P(x_k) = y_k$。**两点线性插值正是 $n=2$ 时的特例**——拉格朗日公式把第 2 章的插值统一成了一个一般框架。

### 3. 代入本例手算一遍

本例三个节点：$(1, 1)$、$(2, 4)$、$(3, 9)$（来自 $y = x^2$），求 $x = 2.5$ 处的插值。先算三个基函数值：

**$L_0(2.5)$**：分子 $(2.5-2)(2.5-3) = 0.5 \times (-0.5) = -0.25$；分母 $(1-2)(1-3) = (-1)\times(-2) = 2$；故 $L_0 = -0.25/2 = -0.125$。

**$L_1(2.5)$**：分子 $(2.5-1)(2.5-3) = 1.5 \times (-0.5) = -0.75$；分母 $(2-1)(2-3) = 1 \times (-1) = -1$；故 $L_1 = 0.75$。

**$L_2(2.5)$**：分子 $(2.5-1)(2.5-2) = 1.5 \times 0.5 = 0.75$；分母 $(3-1)(3-2) = 2 \times 1 = 2$；故 $L_2 = 0.375$。

检验：$-0.125 + 0.75 + 0.375 = 1$（基函数之和恒为 1，因为它插值的是常数函数 1）。

加权求和：

$$
P(2.5) = 1 \times (-0.125) + 4 \times 0.75 + 9 \times 0.375 = -0.125 + 3 + 3.375 = 6.25
$$

正好等于 $2.5^2 = 6.25$——插值精确还原了抛物线（三个点唯一确定一条次数不超过 2 的抛物线，而原函数就是它）。样例 2 中 $x=1.5$ 时三个基函数值为 $0.375, 0.75, -0.125$，$P(1.5) = 0.375 + 3 - 1.125 = 2.25 = 1.5^2$，同样精确。

### 4. 编程时怎么写：双重循环的对应关系

公式的两个记号直接对应两层循环：

- $\sum_i$（对 i 求和）→ **外层循环** `for (i = 0; i < n; i++)`：每轮算一个 $y_i L_i(x_q)$ 并累加到结果 `p`；
- $\prod_{j \neq i}$（对 j 连乘）→ **内层循环** `for (j = 0; j < n; j++)`：`j == i` 时跳过，否则把 $\dfrac{x_q - x_j}{x_i - x_j}$ 乘进临时变量 `t`；
- 连乘的临时变量 `t` 初值必须是 1.0（乘法的"零元"），且**每轮外层开始时都要重置**——否则上一轮的乘积会串到下一轮。

## 三、解题思路

1. **读文件**：打开 points.txt 并检查，先读 n，再循环读入 (x[i], y[i])，读完即 fclose；
2. **读待求点**：scanf 读 xq；
3. **双重循环算插值**：外层 i 从 0 到 n−1，内层 j 跳过 i 连乘出 L_i(xq)，累加 y[i] × L_i；
4. **输出**：按 `P(%.2f) = %.4f` 打印。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    int n, i, j;
    double x[10], y[10];   /* 节点表 */
    double xq;             /* 待求点 */
    double p, t;           /* p 为插值结果，t 为基函数值 */

    /* 1. 从文件读入节点表 */
    fp = fopen("points.txt", "r");
    if (fp == NULL) {
        printf("错误：无法打开 points.txt\n");
        return 1;
    }
    fscanf(fp, "%d", &n);
    for (i = 0; i < n; i++)
        fscanf(fp, "%lf %lf", &x[i], &y[i]);
    fclose(fp);

    /* 2. 读入待求点 */
    scanf("%lf", &xq);

    /* 3. 拉格朗日插值：p = sum y[i] * L[i](xq) */
    p = 0.0;
    for (i = 0; i < n; i++) {
        t = 1.0;                            /* 连乘的初值，每轮必须重置 */
        for (j = 0; j < n; j++) {
            if (j == i)                     /* 基函数不含 j = i 的因子 */
                continue;
            t = t * (xq - x[j]) / (x[i] - x[j]);
        }
        p = p + y[i] * t;                   /* 累加 y[i] * L[i](xq) */
    }

    /* 4. 输出 */
    printf("P(%.2f) = %.4f\n", xq, p);

    return 0;
}
```

## 五、运行验证

**样例 1（xq = 2.5）**：基函数值手算见"预备知识"第 3 小节：$L_0 = -0.125$，$L_1 = 0.75$，$L_2 = 0.375$，加权求和 $P(2.5) = -0.125 + 3 + 3.375 = 6.25$。程序输出：

```
P(2.50) = 6.2500
```

与手算一致，且与 $2.5^2$ 精确相等。

**样例 2（xq = 1.5）**：$L_0(1.5) = \dfrac{(1.5-2)(1.5-3)}{(1-2)(1-3)} = \dfrac{0.75}{2} = 0.375$，$L_1(1.5) = \dfrac{(1.5-1)(1.5-3)}{(2-1)(2-3)} = \dfrac{-0.75}{-1} = 0.75$，$L_2(1.5) = \dfrac{(1.5-1)(1.5-2)}{(3-1)(3-2)} = \dfrac{-0.25}{2} = -0.125$；$P(1.5) = 0.375 + 4 \times 0.75 - 9 \times 0.125 = 0.375 + 3 - 1.125 = 2.25$。程序输出：

```
P(1.50) = 2.2500
```

**节点自检（xq = 2）**：代入 $x = 2$（恰为节点 $x_1$），按基函数性质只有 $L_1 = 1$，其余为 0，$P(2) = 4$。程序输出 `P(2.00) = 4.0000`——插值曲线精确穿过节点。

**文件内容变化**：points.txt 为只读输入，前后不变。

## 六、常见错误与讲解

**错误 1：连乘变量 t 忘记每轮重置**

```c
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++)
        if (j != i) t = t * (xq - x[j]) / (x[i] - x[j]);   /* 错：t 在循环外只置了一次 1.0 */
    p += y[i] * t;
}
/* 对：t = 1.0; 必须放在外层循环体的第一行 */
```

漏写重置时，第二个基函数会连着第一个的乘积继续乘，结果大错——且 xq 越靠近节点错得越隐蔽。

**错误 2：内层循环没跳过 j == i**

```c
for (j = 0; j < n; j++)
    t = t * (xq - x[j]) / (x[i] - x[j]);   /* 错：j == i 时分子分母同为 (xq-x[i])，
                                              结果恰为 1，"看起来没错"，但当 xq 恰好
                                              等于某节点时分母为 0，除零崩溃 */
if (j == i) continue;                       /* 对：基函数定义中本就排除 j = i */
```

这个错误最阴险：多数输入下"碰巧"对，唯独 xq 等于节点时程序崩溃——必须从定义上排除。

**错误 3：先乘分子后除分母的写法引起溢出（工程提醒）**

写法 `t *= (xq - x[j]) / (x[i] - x[j]);`（每因子边乘边除）与 `t *= (xq-x[j]); t /= (x[i]-x[j]);`（先全乘后全除）在数学上等价，但后者在节点很多时分子连乘可能溢出 double 上限。养成"每因子即乘即除"的习惯更安全。

**错误 4：文件格式与读入顺序不匹配**

```c
fscanf(fp, "%lf %lf", &x[i], &y[i]);   /* 对：文件每行是 "x y" */
fscanf(fp, "%lf %lf", &y[i], &x[i]);   /* 错：读反了，样例数据下 y 会读到 1、x 读到 1 的错位值 */
```

数据文件是 `x y` 两列，先横后纵；读反后插值结果全错但不报错，只能靠样例核对发现。

## 七、与综合实验的衔接

- 实验 **D3（核数据截面查值）**的表格往往十几档，用本题程序把 n 放大即可直接使用——这正是拉格朗日公式的威力：**算法不随节点数变，变的只是文件里数据的行数**。练习 18 将把它用到声速剖面（实验 C1）上；而第 2 章的两点线性插值，如今可以看成 $n=2$ 的特例——知识到这里完成了闭环；
- 也要建立工程判断力：节点多、数据带噪声时，高次拉格朗日插值会在节点间剧烈震荡（龙格现象），工程上更常用"分段低次插值"。插值不是次数越高越好，**穿过节点**与**逼近规律**是两回事——记住这一点，你在实验 D3 里选择插值方案时就有底气了。
