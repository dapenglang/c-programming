## 二、预备知识：结构体指针作参数的基本原理（零基础阅读）

### 1. 值传递改不动数组？——数组名天生就是地址

第 4 章讲过：普通变量作参数是值传递，函数改的是副本。但数组例外——**数组名本身就是首地址**，把数组名传给函数，传出去的是地址，函数借此直接操作原数组。第 5 章 `double a[]` 形参能"改得动"主调数组的谜底在第 6 章揭开：`double a[]` 形参本质上就是 `double *a`。结构体数组完全同理：`struct Sample *arr` 收到的就是原数组的地址。

### 2. 传指针 = 函数获得"原地改写权"

对比三种形参：

```
void f(struct Sample s)          值传递：整块复制副本，改不动原件
void f(struct Sample *p)         指针传递：拿到原件地址，可原地改写
void f(struct Sample arr[])      写法不同、本质同上：数组名即首地址
```

本任务要"就地改写原数组"，因此必须选后两种之一（题目统一用 `struct Sample *arr`）。函数内 `p->force *= 1000.0;` 修改的就是 main 里那个数组的元素——函数返回后改动保留，这正是"批量修改"需要的效果。

### 3. 移动指针遍历：地址加 1 跨过一个"整块"

第 6 章的指针算术规则对结构体指针同样成立，且更能体现其价值：`p + 1` 前进的字节数 = **一个元素的大小**。对 `struct Sample`（约 16 字节一整块）来说，`p++` 一次跳过整个结构体，自动落到下一个元素开头：

```
arr          arr+1            arr+2
+------+------+------+--------+ +---- ...
|  no  |      force      | | no | ...
+------+------+------+--------+
   p 每次走一步 = 一整块 struct Sample
```

于是循环 `for (p = arr; p < arr + n; p++) p->force *= 1000.0;` 就把 n 个样本逐一改写。`p < arr + n` 中的 `arr + n` 指向末元素之后（不存在的位置），只作边界比较、不解引用，这是第 6 章讲过的标准哨兵用法。

### 4. 为什么不用下标？

`arr[i].force *= 1000.0;` 与移动指针完全等价（第 6 章验证过 `a[i]` 与 `*(a+i)` 的等价性）。用移动指针写一遍，是为了让你在结构体指针上把"地址 + 箭头"的组合练熟——实验 C6/C7 的成熟代码里两种写法都很常见，都要能读懂。

## 三、解题思路

1. **定类型定数组**：`struct Sample a[10];`，读入 n 条记录；
2. **换算函数**：形参 `struct Sample *arr, int n`，移动指针逐元素 `p->force *= 1000.0;`；
3. **调用**：`toNewton(a, n);`——数组名即首地址，直接传；
4. **验证改动**：main 中遍历输出，数值应已扩大 1000 倍，说明函数确实改了原数组；
5. **输出**：按 `编号 号：阻力 N` 格式，保留 2 位小数。

## 四、参考代码

```c
#include <stdio.h>

struct Sample {                /* 一次撞击的阻力样本 */
    int    no;                 /* 样本编号 */
    double force;              /* 阻力（kN 读入，换算后 N） */
};

void toNewton(struct Sample *arr, int n)   /* 收到原数组首地址 */
{
    struct Sample *p;

    /* 移动指针：从首元素走到末元素之后，每步跨一整块 */
    for (p = arr; p < arr + n; p++)
        p->force *= 1000.0;    /* kN -> N，就地改写原数组 */
}

int main(void)
{
    struct Sample a[10];
    int n, i;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d%lf", &a[i].no, &a[i].force);

    toNewton(a, n);            /* 数组名即首地址，函数原地修改 */

    /* 输出换算结果：数组内容已变为 N */
    for (i = 0; i < n; i++)
        printf("%d 号：%.2f N\n", a[i].no, a[i].force);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：调用时给数组名加取地址符**

```c
toNewton(&a, n);    /* 错：&a 是"整个数组的地址"，类型是结构体数组指针 */
toNewton(a, n);     /* 对：数组名本身就是首元素地址 */
```

**错误 2：函数内用点号访问指针**

```c
p.force *= 1000.0;    /* 错：p 是指针，没有 force 成员 */
p->force *= 1000.0;   /* 对：指针用箭头 */
```

**错误 3：移动指针循环条件写错导致越界**

```c
for (p = arr; p <= arr + n; p++)    /* 错：多改一个不存在的元素 */
for (p = arr; p < arr + n; p++)     /* 对：arr+n 是哨兵，只比较不访问 */
```

越界改写可能破坏相邻变量，且不一定立刻报错，务必用样例的输出行数自查。

**错误 4：期待值传递却用了值传递**

```c
void toNewton(struct Sample s, int n)   /* 错：形参是结构体变量，收到的是副本 */
```

若把形参写成 `struct Sample s`，函数内改的是副本，main 里输出仍是 kN 原值——对比输出结果即可发现这个错误。**要改原数据，形参必须是指针。**
