# 题目 A4：基于迭代求解的房间冬季采暖负荷计算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套房间冬季采暖负荷计算工具。系统从文件读入房间各围护面（墙体、外窗、屋面、地面）的面积与传热系数表以及室外气象参数，先按朝向修正传热系数，再逐面计算围护结构传热热损失，按缝隙法估算冷风渗透热损失，汇总得到采暖设计热负荷与单位面积负荷指标；进一步用不动点迭代求解"仅靠散热器供热时房间能达到的热平衡温度"，并做室温敏感性批量实验，全部结果输出报表。

**解决什么重要问题**：采暖负荷是散热器选型、热源容量确定与管网水力计算的基础数据：负荷算小了房间不热、住户投诉；算大了设备投资与运行能耗浪费。负荷由十几项"面积×传热系数×温差×朝向修正"组成，手工逐面累加既繁琐又易错；而"热平衡温度"问题（围护结构传热能力与供热能力相等时室内温度是多少）本质是解一个非线性方程，工程上用迭代法求解——这正是本系统把课程迭代思想落到专业计算的核心训练点。

**支撑哪些关键应用**：① 集中采暖系统施工图设计中的房间负荷计算书；② 建筑节能改造前后的能耗对比评估；③ 供热管网与换热站容量规划；④ 后续"供暖工程""建筑环境学""建筑节能技术"课程的核心计算模型，也是暖通设计软件负荷模块的雏形。

**与专业培养的关联**：建筑环境与能源应用工程专业的核心课"供暖工程""冷热源工程"都以负荷计算开篇。本题目让学生用 C 语言把"修正—逐项累加—迭代求平衡点—敏感性分析"完整流程实现一遍，课程中的循环累加、迭代终止条件、文件与结构体知识全部落地，形成对热工设计流程的整体认识。

## 二、题目任务与专业关联

本题目面向建筑环境与能源应用工程方向学生，模拟"房间采暖设计负荷计算"场景。系统功能概述：① 读入围护结构参数表与室外气象参数文件；② 按朝向与外表面对传热系数做修正；③ 逐面计算传热热损失并累加；④ 按缝隙法简化估算冷风渗透热损失；⑤ 用不动点迭代求热平衡温度；⑥ 汇总总负荷与单位面积指标；⑦ 改变设定室温批量重算做敏感性实验；⑧ 输出分项负荷报表。先导知识铺垫：教师随题发布公式 Q_传=K'·A·(tn-tw)（K'=K·α，α 为朝向修正系数：北 1.10、东西 1.00、南 0.85）、冷风渗透简化式 Q_渗=0.28·c·ρ·L·(tn-tw)（c=1.0 kJ/(kg·℃)，ρ=1.29 kg/m³，L 为每米缝隙渗风量 m³/(m·h) 与缝隙总长的乘积）以及热平衡迭代式 tn_{k+1}=tw+(Q_sup-Q_渗常数项)/Σ(K'A+cL)，其中 Q_sup 为散热器供热能力。

## 三、数据来源与格式

**数据文件 1：围护结构参数表**（`envelope.txt`）

```
名称,朝向代码,面积m2,传热系数W/(m2K)
北外墙,N,12.6,0.45
南外墙,S,12.6,0.45
东外墙,E,9.0,0.45
北外窗,N,4.2,2.30
南外窗,S,4.2,2.30
屋面,R,18.0,0.35
地面,U,18.0,0.30
```

字段含义：朝向代码 N/S/E/W/R/U（R 屋面 U 地面不修正，α=1.00）；面积取值 1～50 m²；传热系数取值 0.2～3.5 W/(m²·K)（节能外墙 0.3～0.6，单框双玻窗 2.0～2.8）。

**数据文件 2：室外气象与缝隙参数**（`weather.txt`）

```
采暖室外计算温度tw_C,-19.0
北向朝向修正,1.10
东西向朝向修正,1.00
南向朝向修正,0.85
每米缝隙渗风量L_m3hm,0.90
北窗缝隙总长m,7.2
南窗缝隙总长m,7.2
散热器供热能力Qsup_W,2600
```

**仿真数据生成规则**：
- 围护表生成 6～10 行：房间取 3.0 m×6.0 m×2.8 m 尺寸，外墙面积按开间与层高算出，窗墙比取 0.3～0.5，各面 K 值按节能设计常用值取一位或两位小数；
- 异常注入：在 `envelope.txt` 中故意把某行面积写成 `126.0`（扩大 10 倍的录入错误）与朝向代码写成 `X`（非法代码），在 `weather.txt` 中把室外温度写成 `19.0`（丢了负号），用于训练读入模块的范围与格式校验。

**真实数据集**：《民用建筑供暖通风与空气调节设计规范》GB 50736 附录（各城市室外计算温度，如哈尔滨 -24.2 ℃）与《严寒和寒冷地区居住建筑节能设计标准》JGJ 26 的围护结构传热系数限值表（纸质规范誊录）。

## 四、数据结构设计

```c
#define MAX_FACE 20      /* 最大围护面数 */

/* 单个围护面 */
struct Envelope {
    char   name[16];     /* 面名称，≤15 字符 */
    char   orient;       /* 朝向代码 N/S/E/W/R/U */
    double area;         /* 面积 m2，取值 1~50 */
    double k;            /* 原始传热系数 W/(m2K)，0.2~3.5 */
    double kAdj;         /* 修正后传热系数 = k*alpha */
    double q;            /* 本面传热热损失 W */
    int    valid;        /* 数据有效性标志 1/0 */
};

/* 气象与系统参数 */
struct Weather {
    double tw;           /* 室外计算温度 C，哈尔滨约 -24.2，须<0 */
    double alphaN;       /* 北向修正 1.10 */
    double alphaEW;      /* 东西向修正 1.00 */
    double alphaS;       /* 南向修正 0.85 */
    double leak;         /* 每米缝隙渗风量 m3/(m*h)，0.5~2.0 */
    double gapN, gapS;   /* 北/南窗缝隙总长 m，0~20 */
    double qsup;         /* 散热器供热能力 W，取值 1000~6000 */
};

/* 全局数据 */
struct Envelope g_face[MAX_FACE];
struct Weather  g_wx;
int    g_faceCnt;        /* 围护面数 */
double g_tn;             /* 设定/平衡室温 C，迭代求出 */
double g_qEnv, g_qLeak, g_qTotal; /* 围护热损失/渗透热损失/总负荷 W */
```

冷风渗透热损失常量：`C_AIR=1.0`（kJ/(kg·℃)）、`RHO_AIR=1.29`（kg/m³），单位换算系数 1000/3.6 由学生在注释中推导说明。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 围护结构参数文件读入模块**（源文件 `EnvelopeIO.c`）

- 功能简介：跳过表头逐行读入围护面记录；校验面积范围、K 值范围与朝向代码合法性（对注入的 X 代码与 126.0 面积打印警告，非法行标记 valid=0 不参与计算）；输出读入摘要。
- 输入：`envelope.txt`。
- 输出：`g_face[]`、`g_faceCnt`；屏幕校验摘要。

**M2 室外气象参数读入模块**（源文件 `WeatherIO.c`）

- 功能简介：按"关键字,数值"格式逐行读入 `weather.txt` 并存入 `g_wx`；校验室外温度必须为负（对丢失负号的注入异常提示"疑似录入错误，已自动取负"）；回显全部气象参数。
- 输入：`weather.txt`。
- 输出：`g_wx`；屏幕参数回显。

### 第二部分：算法实现（5 个模块）

**M3 传热系数修正计算模块**（源文件 `KCorrect.c`）

- 功能简介：遍历 `g_face[]`，按朝向代码从 `g_wx` 取 α（N→1.10，E/W→1.00，S→0.85，R/U→1.00），计算 kAdj=k·α 并回写；打印逐面修正对照表。
- 输入：`g_face[]`、`g_wx`。
- 输出：各面 `kAdj`；屏幕对照表。

**M4 围护热损失逐面累加模块**（源文件 `HeatLoss.c`）

- 功能简介：对每个 valid 围护面按 q=kAdj·area·(tn-tw) 计算热损失，累加得 g_qEnv；打印逐面热损失表与占比（占总热损失百分比）。
- 输入：`g_face[]`、tn、tw。
- 输出：`g_qEnv` 与各面 `q`；屏幕热损失表。

**M5 冷风渗透热损失模块**（源文件 `Infiltration.c`）

- 功能简介：按缝隙法简化式对北、南窗分别计算渗透热损失并求和：Q=0.28·c·ρ·leak·缝隙长·(tn-tw)/3.6；打印计算过程量（渗风量、质量流量、热损失）。
- 输入：`g_wx`、tn。
- 输出：`g_qLeak`；屏幕过程量。

**M6 热平衡温度迭代求解模块**（源文件 `Equilibrium.c`）

- 功能简介：用不动点迭代求散热器单独供热下的平衡室温：tn_new=tw+(qsup-qLeak系数项)/Σ(K'·A+cL换算)，迭代至 |tn_new-tn|<0.01 ℃；每轮打印当前 tn 与增量；迭代超过 100 次判定不收敛并提示检查供热能力。
- 输入：`g_face[]`、`g_wx`。
- 输出：平衡温度 `g_tn`；屏幕迭代过程表。

**M7 采暖负荷汇总模块**（源文件 `SumLoad.c`）

- 功能简介：以设定室温（交互输入，如 18 ℃）重调 M4、M5 求得设计工况总负荷 g_qTotal=qEnv+qLeak；再按房间面积算单位面积负荷指标 W/m²；打印分项汇总与指标评价（与 50～80 W/m² 经验范围对比）。
- 输入：`g_face[]`、`g_wx`、设定室温。
- 输出：`g_qTotal`、负荷指标；屏幕汇总。

**M8 室温敏感性实验模块**（源文件 `Sensitivity.c`）

- 功能简介：把设定室温从 14 ℃ 到 24 ℃ 以 2 ℃ 步长批量重算总负荷，输出"室温-围护热损失-渗透热损失-总负荷"对照表；另对散热器能力从 2000～4000 W 步进调用 M6，输出"供热能力-平衡室温"表，展示迭代模块的复用。
- 输入：实验区间参数。
- 输出：屏幕两张对照表。

### 第三部分：数据输出（2 个模块）

**M9 负荷报表输出模块**（源文件 `Report.c`）

- 功能简介：把参数清单、逐面修正与热损失表、渗透计算过程、设计工况汇总、热平衡迭代结果与敏感性实验表写入 `heat_load_report.txt`，用 fprintf 对齐输出。
- 输入：以上全部全局数据。
- 输出：`heat_load_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读围护表 / 读气象 / 系数修正 / 负荷计算 / 平衡温度迭代 / 汇总 / 敏感性实验 / 输出报表 / 退出），`do-while + switch` 调度；状态约束：未读入两个数据文件不得计算。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1～M9；状态约束：M3 前必须完成 M1、M2；M4、M5 依赖 M3 的修正结果；M6 独立调用 M5；M8 复用 M4、M5、M6 形成批量循环。

**数据流**：

```
envelope.txt ─► M1 读入校验 ─► g_face[] ─► M3 系数修正(kAdj) ─┐
weather.txt ──► M2 读入 ─────► g_wx ──────────────────────────┤
                                                              ▼
       M4 逐面热损失 ─► g_qEnv ─┐      M5 渗透热损失 ─► g_qLeak
                                ├────► M7 汇总 g_qTotal / 指标
       M6 迭代 ◄─ qsup,cL ──► g_tn（平衡室温）
                                │
       M8 敏感性批量 ◄──────────┘
                                ▼
                 M9 报表 heat_load_report.txt
```

模块间通过全局结构体 `g_face[]`、`g_wx` 与结果变量交换数据，`heatLossFace`、`leakLoss`、`iterEquilibrium` 等函数接口编码前书面约定。

## 十、选做扩展

1. 高度附加与风力附加：对层高大于 4 m 的房间按每超高 1 m 附加 2% 的系数放大总负荷，对同一朝向两面以上外墙的面再附加 5%（只用乘法系数与 if 判断）；
2. 夜间值班采暖工况：把 M4、M5 的室温参数换成 12 ℃ 重算一遍夜间负荷，与设计工况对比输出昼夜负荷对照表（函数复用 + 参数化调用）；
3. 多房间汇总：把 envelope 结构体数组扩为"房间号 + 围护面"两层组织（二维结构体数组），对 3 个房间分别算负荷后排序输出排名（结构体数组 + 排序的综合运用）。
