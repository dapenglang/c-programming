## 二、预备知识：线性插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

规范的表格只告诉我们两个"已知点"：

- 高度 10 m 处，系数是 1.00；
- 高度 20 m 处，系数是 1.23。

可实际建筑的高度是任意的，比如 17.5 m——**表格里没有这一档，系数是多少？**

最简单的做法：假设 10 m 到 20 m 之间，系数随高度**均匀变化**（图象是一条直线），那么 17.5 m 处的值就在直线上按比例取一点。这个"在两个已知点之间按直线比例取值"的方法，就叫**线性插值**。

### 2. 公式是怎么推出来的

设两个已知点为 $(x_0,\, y_0)$ 和 $(x_1,\, y_1)$，要求 $x$ 处的 $y$（$x_0 \le x \le x_1$）。

"均匀变化"的数学含义是：**$y$ 的增长量与 $x$ 的增长量成正比**。$x$ 从 $x_0$ 走到 $x_1$，总共走了 $(x_1 - x_0)$，$y$ 相应地总共涨了 $(y_1 - y_0)$；现在 $x$ 只从 $x_0$ 走到 $x$，走了 $(x - x_0)$，那么 $y$ 就应该涨"全程涨幅的同样比例"：

$$
\frac{y - y_0}{y_1 - y_0} = \frac{x - x_0}{x_1 - x_0}
$$

把 $y$ 解出来（两边同乘 $(y_1-y_0)$，再加 $y_0$）：

$$
y = y_0 + \dfrac{(y_1 - y_0)\,(x - x_0)}{x_1 - x_0}
$$

用大白话读这个公式就是：**"起点值 + 全程涨幅 × 已走比例"**。

### 3. 用本例走一遍

取 $h = 17.5$，代入 $(x_0, y_0) = (10,\ 1.00)$，$(x_1, y_1) = (20,\ 1.23)$：

- 已走比例：$(17.5 - 10) / (20 - 10) = 7.5 / 10 = 0.75$，即走完了全程的 75%；
- 全程涨幅：$1.23 - 1.00 = 0.23$；
- 已涨部分：$0.23 \times 0.75 = 0.1725$；
- 结果：$y = 1.00 + 0.1725 = 1.1725$。

再验算两个特殊点：$x = 10$ 时比例为 0，结果正好是 $y_0 = 1.00$；$x = 20$ 时比例为 1，结果正好是 $y_1 = 1.23$——公式在端点处自动退回表格值，说明它是对的。

### 4. 编程时怎么用它

公式里有五个量：四个是表格常量（$x_0, y_0, x_1, y_1$），一个是输入（$x$）。编程就是：**把五个数放进变量里，把公式原样翻译成一行赋值语句**。翻译时唯一的注意点是括号——分子上的 $(x - x_0)$ 必须先算。

> **这个思想在综合实验中反复出现**：A1 风荷载（高度→系数）、A7 混凝土强度（龄期→强度）、C1 声速剖面（深度→声速）、D3 核数据截面（能量→截面），全部是"表格 + 线性插值"同一个套路。学会一次，四处可用。

## 三、解题思路

1. **确定数据**：表格给出两档 (10, 1.00) 和 (20, 1.23)。把它们定义为 `const double` 常量——它们是规范值，程序运行中不允许被改动，用常量表达最贴切；
2. **确定变量**：只有两个变量——读入的高度 `h` 和待求的系数 `mz`，都是实数，用 `double`；
3. **套用插值公式**：`mz = M0 + (M1 - M0) * (h - H0) / (H1 - H0)`；
4. **输出**：题目要求保留 4 位小数，用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 规范表格数据：相邻两档高度与对应的风压高度变化系数（B类粗糙度） */
    const double H0 = 10.0;   /* 下档高度，单位 m */
    const double H1 = 20.0;   /* 上档高度，单位 m */
    const double M0 = 1.00;   /* 下档系数，无量纲 */
    const double M1 = 1.23;   /* 上档系数，无量纲 */

    double h;                 /* 建筑物计算高度，m */
    double mz;                /* 插值得到的风压高度变化系数 */

    /* 读入高度 */
    scanf("%lf", &h);

    /* 线性插值：y = y0 + (y1 - y0) * (x - x0) / (x1 - x0) */
    mz = M0 + (M1 - M0) * (h - H0) / (H1 - H0);

    /* 输出，保留 4 位小数 */
    printf("mu_z = %.4f\n", mz);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 15 | 1.00 + 0.23 × (15−10)/(20−10) = 1.00 + 0.115 = 1.1150 | `mu_z = 1.1150` ✓ |
| 17.5 | 1.00 + 0.23 × 7.5/10 = 1.00 + 0.1725 = 1.1725 | `mu_z = 1.1725` ✓ |
| 10 | 1.00 + 0.23 × 0/10 = 1.0000（下端点，公式同样成立） | `mu_z = 1.0000` ✓ |
| 20 | 1.00 + 0.23 × 10/10 = 1.2300（上端点） | `mu_z = 1.2300` ✓ |

端点值与规范表完全一致，说明插值公式使用正确。

## 六、常见错误与讲解

**错误 1：常量写成整数（最典型）**

```c
const int H0 = 10, H1 = 20;      /* 错：高度虽然写起来像整数 */
const double M0 = 1, M1 = 1.23;  /* 错：1.00 写成 1 */
```

后果之一是 `(M1 - M0)` 中若两端都是 `int`，`1.23 - 1` 若发生在整数运算里会丢失小数；后果之二是语义错误——规范系数本质是实数。**本章纪律：凡是物理上的实数量（高度、系数、重量、声速……），一律用 `double`。**

**错误 2：忘记取地址符**

```c
scanf("%lf", h);    /* 错：程序崩溃或读不进数据 */
scanf("%lf", &h);   /* 对：scanf 需要变量的地址 */
```

`&` 的原理在第 6 章（指针）才会彻底讲清，当前阶段记住规则：**scanf 的每个参数前面都要加 `&`**。

**错误 3：输出格式与类型不匹配**

```c
printf("mu_z = %d\n", mz);    /* 错：double 用 %d 输出得到乱码 */
printf("mu_z = %f\n",  mz);   /* 对但没控制位数 */
printf("mu_z = %.4f\n", mz);  /* 对：%.4f 表示保留 4 位小数 */
```

**错误 4：公式抄错优先级**

```c
mz = M0 + (M1 - M0) * h - H0 / (H1 - H0);          /* 错：少写括号，运算顺序全乱 */
mz = M0 + (M1 - M0) * (h - H0) / (H1 - H0);        /* 对：先减、再乘、再除 */
```

乘除优先于加减，`(h - H0)` 必须加括号。建议先在心里默算一遍样例 1（结果应为 1.1150）再运行验证。

## 七、与综合实验的衔接

- 实验 **A1（风荷载计算）**中，"风压高度变化系数查算"模块就是本练习的直接放大：表格档位更多（0~350 m 共十余档）、输入的不止一个高度。学到第 5 章（数组）后，表格将存入数组；学到第 3 章（选择结构）后，才能自动判断 h 落在哪两档之间——本练习故意规定"10 ≤ h ≤ 20"，就是为了让你**先专注于把一个计算流程写对**；
