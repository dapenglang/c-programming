# 题目 B1：基于灰度直方图统计的图像二值化处理系统

**适用学院**：人工智能学院（4 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**1）系统是做什么的**：本系统是一套命令行灰度图像处理工具，核心能力是把一幅 0~255 的灰度图像按灰度统计规律"二值化"，即把连续灰度图变成只有黑、白两种取值的图像，让目标物体从背景中干净地分离出来；系统同时提供图像统计信息查看、字符画预览、灰度直方图统计与绘制、固定阈值分割、迭代法自动阈值分割、亮度/对比度调整等功能，处理结果可写回文件并生成处理日志。

**2）它解决了什么重要问题**：数字图像在计算机中只是一个二维整数矩阵，程序本身"看不懂"图里有什么。任何图像识别（数零件、提取文字、读车牌）的第一步都必须把目标与背景分开，而二值化是最经典、计算量最小的分离手段。阈值选高了目标被削掉、选低了背景混进来——"阈值怎么选"正是本系统的核心问题：系统同时提供人工指定阈值的固定阈值法与由程序迭代求解的自动阈值法，让学生直观体会两者差别。若不做二值化，后续所有依赖"目标区域"的统计与识别都无从谈起。

**3）它支撑哪些关键应用**：① 工业质检——零件尺寸测量、表面缺陷计数前的图像预处理；② 文档数字化——扫描件文字提取（OCR）的第一步；③ 车牌识别、条码/二维码识别的定位环节；④ 医学影像的目标区域提取；⑤ 交通监控中的车辆与车道线分割。这些系统无一例外都从"灰度化 + 二值化"开始，本系统就是这条技术链的起点。

**4）与专业培养的关联**：对应智能科学与工程学院人工智能专业的"机器视觉与图像处理"方向，也服务于"数据挖掘"方向的数据预处理环节。本系统让学生在大一就用 C 语言亲手实现完整图像处理流程，建立"图像 = 二维数组 + 逐像素运算"的最核心直觉，为后续图像滤波、特征提取、目标检测打下基础，且全程不涉及任何机器学习理论。

## 二、题目任务与专业关联

本题目要求小组用 C 语言多文件工程实现上述命令行灰度图像处理系统，数据一律以文本文件读写。程序需支持：读入文本灰度图、数据校验、统计信息显示、字符画预览、灰度直方图统计与绘制、固定阈值二值化、迭代法自动阈值二值化、亮度/对比度调整、结果图像写出、处理日志报表与主控菜单。全组需完成 12 个模块，总代码 900~1200 行，每人负责 3 个左右模块。题目训练"文件 + 二维数组 + 函数 + 结构体"的综合运用，并把"图像即矩阵、统计决定阈值"的图像处理思维带进人工智能专业学习。

## 三、数据来源与格式

### 3.1 数据文件格式

采用自定义文本灰度格式（与通用 PGM/P2 格式同构），首行为以 `#` 开头的说明行，读入时跳过：

```
# 灰度图像文件 v1：格式标记 P2 / 宽 高 / 最大灰度值 / 像素矩阵
P2
8 6
255
 12  15  15  18  20  20  19  15
 14  16  18  22  25  24  21  16
 13  17  30  60 180 200  45  18
 15  19  35 190 235 220  50  20
 14  18  28  70 195 210  40  17
 13  16  17  20  22  21  19  15
```

有效内容的含义：`P2` 为格式标记；`8 6` 为宽、高；`255` 为最大灰度值；其后为 宽×高 个 0~255 整数，空格分隔、可任意换行。用 `fscanf(fp, "%d", &v)` 逐个读入即可，恰好训练"循环 + 文件读取"。

### 3.2 仿真数据生成规则

| 字段 | 单位 | 取值范围 | 生成规则 |
|---|---|---|---|
| width 宽 | 像素 | 16~256，默认 64 | 任意整数 |
| height 高 | 像素 | 16~256，默认 48 | 任意整数 |
| 背景像素 | 灰度级 | 20~80 | 均匀随机 `20 + rand()%61` |
| 目标像素 | 灰度级 | 150~230 | 均匀随机 `150 + rand()%81` |
| 加性噪声 | 灰度级 | -12~+12 | 每像素叠加均匀噪声后截断到 [0,255] |

目标形状建议：① 矩形块（如第 20~35 行、第 15~40 列为目标）；② 圆盘（距图心半径 ≤ 12 的像素为目标）；③ 文字笔画（用两个矩形拼成字母）。

**异常值注入**（用于检验 M2 校验模块，每张图注入 1~2 类）：

1. 越界值：随机挑 3~5 个像素置为 `300` 或 `-5`；
2. 极值尖峰：随机挑 10 个像素置为 `0` 或 `255`（模拟坏点）；
3. 尺寸越界：故意把某张图标为 `300 × 300`（超过 256 上限）；
4. 格式错误：把格式标记 `P2` 改成 `P3`。

### 3.3 真实数据集

南加州大学信号与图像处理研究所图像库 USC-SIPI：https://sipi.usc.edu/database/ （下载后需自行转成上述文本格式）。

## 四、数据结构设计

```c
#define W_MAX   256
#define H_MAX   256
#define LOG_MAX  64

struct GrayImage {              /* 单幅灰度图像，用全局变量存放避免栈溢出 */
    int width;                  /* 宽度，像素，取值 16~256 */
    int height;                 /* 高度，像素，取值 16~256 */
    int pixel[H_MAX][W_MAX];    /* 灰度值，0~255 */
};

struct LogEntry {               /* 处理日志条目 */
    int    seq;                 /* 操作序号，从 1 递增 */
    char   opName[32];          /* 操作名称，如 "固定阈值二值化" */
    char   param[64];           /* 参数字符串，如 "th=123" */
    double keyStat;             /* 关键统计量，如自动阈值/白像素占比 */
};

struct GrayImage g_img;         /* 当前工作图像 */
struct GrayImage g_bak;         /* 原图备份，供复位使用 */
int  g_hist[256];               /* 灰度直方图计数，下标 = 灰度级 */
struct LogEntry g_log[LOG_MAX];
int  g_logCount;                /* 日志条数，0~LOG_MAX */
int  g_loaded;                  /* 是否已成功读图，0 = 否 1 = 是 */
```

辅助结构：处理日志用结构体数组记录每次操作的名称、参数与统计结果，供报表模块输出——训练结构体数组的使用（课程 7.1/7.2）。

## 五、功能模块拆解（共 12 个模块）

### 第一部分：数据读入（4 个模块）

**M1 图像文件读取模块**（源文件 `ImgIO.c`）
- 功能简介：打开文本灰度图，跳过 `#` 说明行，读入格式标记、宽、高、最大灰度值与像素矩阵；文件不存在或格式标记不为 `P2` 时给出明确提示并返回失败。读入成功后把图像写入全局 `g_img`，同时备份到 `g_bak`。
- 输入：文件路径（菜单输入，默认 `sample1.txt`）。
- 输出：填充 `g_img` 与 `g_bak`；`g_loaded` 置 1；返回 0 成功 / -1 失败。
- 接口示例：`int LoadImage(const char *path, struct GrayImage *img);`

**M2 图像数据校验模块**（源文件 `ImgCheck.c`）
- 功能简介：检查宽、高是否在 16~256 内，逐像素检查灰度值是否落在 0~255；对越界像素打印"行-列-数值"清单并把它截断到 `0` 或 `255`，最后输出校验报告（越界像素个数）。
- 输入：`g_img`。
- 输出：屏幕校验报告；修正后的 `g_img`。
- 接口示例：`int CheckImage(struct GrayImage *img);`

**M3 图像基本信息显示模块**（源文件 `ImgInfo.c`）
- 功能简介：遍历二维数组统计尺寸、像素总数、灰度最小值、最大值、平均值与极差，按固定格式打印——一次典型的"二维数组遍历 + 最值/累加"训练。
- 输入：`g_img`。
- 输出：屏幕统计信息。
- 接口示例：`void ShowInfo(const struct GrayImage *img);`

**M4 图像字符画预览模块**（源文件 `ShowImg.c`）
- 功能简介：把灰度 0~255 映射为 8 档字符 ` .:-=+*#`，逐行打印让用户"看见"图像；`mode=0` 显示原图，`mode=1` 显示二值化结果（白用 `#`、黑用空格），对超过 64 列的大图按步长抽样显示。
- 输入：`g_img` 及显示模式 `mode`。
- 输出：屏幕字符画。
- 接口示例：`void ShowAscii(const struct GrayImage *img, int mode);`

### 第二部分：算法实现（5 个模块）

**M5 灰度直方图统计模块**（源文件 `Hist.c`）
- 功能简介：把 256 格计数数组清零后遍历全部像素按灰度值累加，得到直方图；再统计出现次数最多的前 10 个灰度级，打印其计数与占比。
- 输入：`g_img`。
- 输出：`g_hist[256]`；屏幕 Top-10 灰度级表。
- 接口示例：`void CalcHist(const struct GrayImage *img, int hist[256]);`

**M6 直方图字符画绘制模块**（源文件 `Hist.c`）
- 功能简介：把 256 格直方图按每 16 格合并成 16 根柱，按最大频次归一化后用 `*` 的个数表示频次，打印带区间标注与数值的字符柱状图；支持只绘制非零区间以放大细节。
- 输入：`g_hist[256]`。
- 输出：屏幕字符直方图。
- 接口示例：`void DrawHist(const int hist[256]);`

**M7 固定阈值二值化模块**（源文件 `Binarize.c`）
- 功能简介：交互输入阈值 `th`（并给出"推荐阈值 = 当前全图均值"作参考），遍历像素执行"≥ th 置 255，否则置 0"的变换，统计黑白像素占比。
- 输入：阈值 `th`（0~255）。
- 输出：二值化后的 `g_img`；屏幕占比统计。
- 接口示例：`int BinarizeFixed(struct GrayImage *img, int th);`

**M8 迭代法自动阈值模块**（源文件 `Binarize.c`）
- 功能简介：实现迭代阈值——以全图均值作初始阈值，按阈值把像素分成亮区/暗区，取两区均值的平均作为新阈值，重复至阈值不再变化或达到最大轮数；每轮打印当前阈值与两区均值以展示收敛过程，最后把求得的阈值交给 M7 完成分割。
- 输入：`g_img`、最大迭代轮数（建议 50）。
- 输出：最终阈值（整数）；屏幕迭代过程表。
- 接口示例：`int AutoThreshold(const struct GrayImage *img, int maxIter);`

**M9 亮度/对比度调整模块**（源文件 `Adjust.c`）
- 功能简介：按"新像素 = a × 旧像素 + b"调整图像，`a` 为对比度系数、`b` 为亮度偏移，越界值饱和截断到 [0,255]；打印调整前后的均值、极差对照表。
- 输入：系数 `a`（如 0.8~2.0）、偏移 `b`（如 -50~+50）。
- 输出：调整后的 `g_img`；屏幕前后对照表。
- 接口示例：`void AdjustBC(struct GrayImage *img, double a, double b);`

### 第三部分：数据输出（3 个模块）

**M10 处理结果图像写出模块**（源文件 `ImgIO.c`）
- 功能简介：把当前 `g_img` 按文本格式写出到新文件，文件名自动带序号（如 `out_003.txt`），保证原图不被覆盖；写出后回读校验宽高与像素总数是否一致。
- 输入：`g_img`、输出文件名。
- 输出：结果图像文件；屏幕确认信息。
- 接口示例：`int SaveImage(const struct GrayImage *img, const char *path);`

**M11 处理日志与统计报表模块**（源文件 `Report.c`）
- 功能简介：系统每执行一次处理操作，M1~M9 各模块把"操作名、参数、关键统计量"追加到 `g_log` 结构体数组；本模块把日志写成 `process_log.csv` 并在屏幕汇总显示。
- 输入：`g_log` 与 `g_logCount`。
- 输出：`process_log.csv`；屏幕日志汇总表。
- 接口示例：`void WriteReport(const struct LogEntry log[], int n);`

**M12 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读图 / 校验 / 信息 / 预览 / 直方图 / 固定阈值 / 自动阈值 / 亮度对比度 / 保存 / 查看日志 / 复位原图 / 退出），用 `do-while + switch` 调度各模块，并用 `g_loaded` 约束"必须先读图才能处理"。
- 输入：用户菜单选项。
- 输出：调度各模块。
- 接口示例：`int main(void);`

## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环 → 由 `switch` 分发到 M1~M11 → 处理完回到菜单，直到选择退出。状态约束：M2~M11 执行前必须已成功运行 M1（否则提示"请先读图"）；M10 保存的始终是当前工作图像；M12 的"复位原图"用 `g_bak` 覆盖 `g_img`。

**数据流**：

```
图像文件 ─► M1 读入 ─► g_img (256×256 二维数组)
                          │
        ┌─────────────────┼──────────────────┐
        ▼                 ▼                  ▼
  M2 校验→M3 信息   M5 直方图计数 ─► M6 字符直方图   M4 字符画预览
                          │
                          ▼
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
  M7 固定阈值二值化   M8 迭代自动阈值   M9 亮度对比度调整
        └──────────── 调整后的 g_img ────────┘
                          │
            ┌─────────────┴─────────────┐
            ▼                           ▼
     M10 结果图像写出             M11 处理日志报表
```

所有模块之间只通过全局 `g_img`、`g_hist`、`g_log` 与函数参数交换数据，函数原型（函数头部）编码前书面约定。

## 十、选做扩展

1. 读入 24 位 BMP 真彩图并转灰度（二进制文件读取 + 结构体解析，超纲关键词"BMP 文件格式"）；
2. 实现 3×3 均值滤波去噪后再二值化（9 次累加求均值，含边界处理，无理论门槛）；
3. 对同一幅图比较"固定阈值 / 迭代阈值"两种结果的差异像素个数，并写进实验报告讨论阈值选取的影响。
