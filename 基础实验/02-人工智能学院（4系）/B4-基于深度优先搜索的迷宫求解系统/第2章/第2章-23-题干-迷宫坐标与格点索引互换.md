# 第 2 章 练习 23　迷宫坐标与格点索引互换

**所属综合实验**：B4（B4-基于深度优先搜索的迷宫求解系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 B4《基于深度优先搜索的迷宫求解系统》（人工智能学院）——本练习是该实验中"网格位置表示与换算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

迷宫求解系统把迷宫看成一张二维字符网格：每一格要么是墙，要么是通路。程序描述"某个格子在哪里"时，有两种常见方式：

- **行列坐标** $(r, c)$：第 $r$ 行第 $c$ 列，符合人看地图的直觉；
- **线性序号** $idx$：把二维网格按行"拉直"成一维，第 $idx$ 个格子，符合计算机存一维数组的习惯。

两种表示随时需要互换：从文件读入时用坐标，存到一维数组时用序号。B4 迷宫系统在把网格压平存储时，就要反复做这个换算。

## 二、任务要求

编写一个完整程序 `grid_index.c`：

1. 程序中用**常量**存放迷宫的列数 `COLS`（本题固定为 8）；
2. 从键盘读入行号 `r` 和列号 `c`（均为整数，**题目保证 0 ≤ r ≤ 3、0 ≤ c ≤ 7**，因此不需要判断分支）；
3. 用公式 $idx = r \times COLS + c$ 计算线性序号；
4. 按规定格式输出这个格子的行列坐标和线性序号。

## 三、输入输出格式

**输入**：一行，两个整数，表示格子的行号 r 和列号 c，用空格分隔。

**输出**：一行，按格式 `(r,c) -> idx = 结果` 输出，结果是一个整数。

## 四、样例

**样例 1**

输入：
```
1 3
```
输出：
```
(1,3) -> idx = 11
```

**样例 2**

输入：
```
3 7
```
输出：
```
(3,7) -> idx = 31
```

## 五、提示

二维网格按行拉直时，第 $r$ 行前面有 $r$ 整行，每行 $COLS$ 个格子，所以前面共有 $r \times COLS$ 个格子；在**本行内**再偏移 $c$ 个位置，就是该格的线性序号：

$$
idx = r \times COLS + c
$$

四行八列共 $4 \times 8 = 32$ 个格子，序号从 $0$ 到 $31$，所以本题的 `idx` 一定是这个范围内的整数，用 `int` 存放即可。

**完成本练习后你将具备的能力**：用整数乘加算式做坐标换算、理解"二维拉直成一维"的编号规则、区分坐标的起编号方式（从 0 开始）——这些是实验 B4 中"网格存储模块"的地基。
