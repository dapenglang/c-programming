# 第 2 章 练习 33　潮位昼夜均值差计算

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：2 常量、变量与数据类型；2.x 运算符与表达式；2.x 格式化输入输出（scanf/printf）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"分时段均值比较"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

潮位观测站每天每半小时记录一次水位。水文分析中一个最基础的问题：**白天和夜里的平均潮位差多少？**这个差值反映潮汐的不对称性，也是综合实验 C7 中"前后半段均值趋势比较"模块的核心量——差值持续为正，说明水位在整体上涨；持续为负，说明在回落。

C7 的完整系统要先读入几百个观测值、滤波、再分段求均值。本题只截取**最后一步**：白天时段的均值和夜间时段的均值已经算好（由观测员提供），你的程序只负责读入这两个均值，算出差值和全天总平均，格式化打印。学会它，就等于掌握了 C7 统计模块的"收尾公式"。

## 二、任务要求

编写一个完整程序 `tide_diff.c`：

1. 从键盘读入两个 double：白天时段平均潮位 `h_day`（m）、夜间时段平均潮位 `h_night`（m）；
2. 计算昼夜均值差 $\Delta h = h_{day} - h_{night}$；
3. 计算全天总平均 $h_{all} = \dfrac{h_{day} + h_{night}}{2}$；
4. 按样例格式输出两个结果，均保留 2 位小数。

**注意**：本题只做顺序计算，不允许使用 `if`、循环和函数。

## 三、输入输出格式

**输入**：一行两个实数，用空格分隔：`h_day h_night`（单位：m）。

**输出**：两行：

- 第一行：`day-night = <Δh> m`；
- 第二行：`overall = <h_all> m`。

均保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
2.40 1.86
```
输出：
```
day-night = 0.54 m
overall = 2.13 m
```

**样例 2**

输入：
```
3.75 3.90
```
输出：
```
day-night = -0.15 m
overall = 3.82 m
```

样例 2 中夜间平均反而更高，差值为负——正是"潮汐不对称"的表现。

## 五、提示

- 均值是实数，用 `double`，`scanf` 用 `%lf`；
- 总平均公式 $\dfrac{h_{day}+h_{night}}{2}$ 在 C 中写作 `(h_day + h_night) / 2`，**括号不能省**——除法优先级高，写成 `h_day + h_night / 2` 就错了；
- 输出 `%.2f` 会自动按四舍五入保留两位，负数自动带负号；
- 想一想：本题的"均值比较"其实是减法，为什么不给 `if` 也够用？（因为差值的**符号本身就携带信息**，读结果的人能从负号看出趋势。）

**完成本练习后你将具备的能力**：把两个统计量做差、求总平均并按工程格式输出——这是 C7 实验"前后半段均值趋势比较"模块的最小单元。
