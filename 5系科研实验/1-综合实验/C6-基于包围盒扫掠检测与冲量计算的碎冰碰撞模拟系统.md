# 题目 C6：基于包围盒扫掠检测与冲量计算的碎冰碰撞模拟系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择　**题目来源**：NDEM 论文拓展题

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行碎冰碰撞模拟工具。它以冰场内 N 个碎冰块的初始位置、速度、质量与尺寸为输入，在离散时间步上进阶模拟：每一步先用"扫掠排序 + 轴对齐包围盒（AABB）重叠判定"完成碰撞检测，再用恢复系数冲量公式计算碰撞法向冲量、更新两冰块速度并校验动量守恒，最后把逐步碰撞事件写入日志文件并输出统计报表。本题算法由 Ocean Engineering 2026 论文《Experimental and NDEM investigation of resistance and pressure statistics of an inclined plate interacting with broken ice》中的碰撞检测（SAP 扫掠宽相 + 包围盒窄相）与接触冲量求解环节简化而来：把三维非圆盘冰块一维化、把复杂接触求解简化为恢复系数冲量公式，只保留课程内可实现的核心骨架。

**解决什么重要问题**：碎冰场中冰块数量多、形状不规则，若对全部 N 个冰块两两做精确碰撞检测，判定次数为 N(N−1)/2，当 N 达到几百时计算量急剧膨胀，仿真一晚也跑不完一步。扫掠排序先把冰块按位置排序，只在排序序列的相邻滑动窗口内生成候选对，把候选数从 O(N²) 降到接近 O(N)，这是所有物理引擎与游戏引擎的通用做法。碰撞检测之后若不求解接触冲量、更新速度，冰块会互相穿透，模拟结果完全失真；正确施加冲量才能保证动量守恒，让模拟出的碰撞载荷可信。

**支撑哪些关键应用**：① 冰区船舶与破冰船的碎冰阻力预报，需要先知道板体与碎冰块的碰撞频率与冲击强度；② 冰载荷极值统计与结构安全评估，碰撞冲量日志正是压力统计的原始输入；③ 碎冰场数值仿真（NDEM/DEM）的前置环节，真实商业与科研仿真软件的每一帧都要做"宽相筛选 → 窄相判定 → 冲量求解 → 积分更新"；④ 冰池模型试验的数值对照，例如倾斜板与碎冰作用试验的仿真复现。本题的碰撞日志可直接作为题目 C7"冰阻力与碰撞事件辨识"的输入数据，两题可连做。

**与专业培养的关联**：水声学院学生的后续课程（冰力学、冰区船舶设计、海洋环境载荷）都需要理解"环境离散体 → 接触事件 → 载荷统计"的建模链路。本题让学生用课程内的排序、结构体、数组、文件读写实现论文链条中最前端的"碰撞检测与冲量计算"一环，是 NDEM 数值仿真流水线的第一步。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述碎冰碰撞模拟系统，完成一条完整的"文件读入 → 数据校验 → 扫掠排序 → 候选对生成 → AABB 判定 → 冲量计算 → 速度更新 → 多步仿真 → 日志与报表输出"流水线。具体任务包括：设计冰场初始参数文件格式并完成容错读入；检查冰块初始重叠、越界、质量非正等异常；实现按位置排序的宽相排序模块；在滑动窗口内生成碰撞候选对；对候选对做 x、y 两向包围盒重叠量精确判定；用恢复系数公式计算法向冲量；由冲量更新两冰块速度并校验动量守恒；把检测—碰撞环节封装进多步时间推进循环；输出碰撞日志文件与统计报表；用菜单调度全部功能。

本题直接对应船舶与海洋工程专业"把冰场环境转化为结构载荷"的核心能力：碰撞检测与冲量求解是冰载荷数值仿真的入口，学生在过程中练熟排序查找、结构体数组、函数分解、文件读写等 C 语言要素，同时理解扫掠排序这类"用排序换计算量"的经典工程思想，为后续接触 NDEM/DEM 专业仿真软件打下算法直觉。

## 三、数据来源与格式

**数据文件格式**：采用纯文本格式，第 1 行为格式标识，第 2 行为冰场全局参数，其后每行一个冰块。用 `fscanf(fp, "%s", ...)`、`fscanf(fp, "%d", ...)` 与 `fscanf(fp, "%lf", ...)` 即可逐个读入。

```
ICEF
N=24 DT=0.010 E=0.30 LX=12.00 LY=9.00
1  1.25  2.40  0.35  -0.12  388.80  0.80  0.60
2  3.10  5.75 -0.22   0.40  216.00  0.60  0.40
3  4.05  1.30  0.60  -0.05  972.00  0.90  1.20
```

字段含义：第 1 行 `ICEF` 为格式标识（Ice Field）；第 2 行为冰块数 `N`、时间步长 `DT`（s）、恢复系数 `E`、冰场长度 `LX`（m）、宽度 `LY`（m）；其后为"编号 x y vx vy 质量 半长a 半宽b"，共 `N` 行，其中 x、y 为冰块中心坐标（m），vx、vy 为中心速度（m/s），半长 a、半宽 b 为包围盒半尺寸（m）。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 编号 | — | 1～N | 顺序编号 |
| N | 个 | 20～60 | 由教师按组号指定，如 20+组号×5 |
| DT | s | 0.005～0.02 | 固定 0.010，保证单步位移小于最小冰块半宽 |
| E | — | 0.1～0.5 | 在该区间内取一个定值，钢质板体与冰典型取 0.30 |
| LX, LY | m | 8～20, 6～15 | 固定 12.00×9.00，冰数密度约 0.2 块/m² |
| x, y | m | [a, LX−a]×[b, LY−b] | 在域内近似均匀分布（rand 布置后手工微调），允许人为制造 1～2 对初始重叠块 |
| vx, vy | m/s | −1.0～1.0 | 在该区间近似均匀分布，且保证 |v| ≥ 0.05，使冰块缓慢漂移 |
| 质量 | kg | 80～2000 | 按面积折算：m = ρ_ice·(2a)(2b)·h，冰密度 ρ_ice = 900 kg/m³、冰厚 h 在 0.1～0.3 m 内均匀取值，再叠加 ±5% 随机扰动 |
| 半长 a, 半宽 b | m | 0.3～1.0 | 在该区间内均匀分布，a 与 b 独立取值 |

**异常值与噪声注入方式**：① 人为布置 1～2 对中心距小于 a1+a2 的初始重叠冰块，用于检验 M2 的重叠检查；② 随机令 1 个冰块中心坐标越出冰场边界（如 x = LX + 0.5）；③ 随机令 1 个冰块质量为负（如 −150.0）；④ 在若干速度分量上叠加 ±0.02 m/s 的舍入噪声。以上异常用于检验 M2 校验模块的报错与定位功能。

**真实数据集（如有）**：
- 冰池碎冰尺寸分布实测数据可参考论文原文（Ocean Engineering 357 (2026) 125460）试验部分给出的碎冰粒度统计；
- 波罗的海冰区碎冰航拍影像与粒度分布公开数据（Baltic Sea ice classification）：https://data.fmi.fi/
- 教师亦可提供按上表规则预生成的 2～3 个不同冰块数的 ICEF 文件。

## 四、数据结构设计

```c
#define MAX_ICE   64          /* 最大冰块数，取值 20~60 */
#define MAX_LOG   2000        /* 碰撞日志最大条数 */
#define WIN       4           /* 扫掠滑动窗口宽度（排序序列中前后比较的块数） */

/* 单个冰块：位置、速度、质量与包围盒半尺寸 */
typedef struct {
    int    id;                /* 冰块编号，1~N */
    double x, y;              /* 中心坐标，单位 m，范围 [0,LX]x[0,LY] */
    double vx, vy;            /* 中心速度，单位 m/s，范围 -1.0~1.0 */
    double mass;              /* 质量，单位 kg，范围 80~2000，必须为正 */
    double a, b;              /* 包围盒半长/半宽，单位 m，范围 0.3~1.0 */
} IceBlock;

/* 一条碰撞日志记录 */
typedef struct {
    int    step;              /* 碰撞发生的仿真步号，从 1 起 */
    int    idA, idB;          /* 相撞两冰块的编号 */
    double jn;                /* 法向冲量，单位 N·s，取值 0~500 */
    double rel;               /* 碰撞前法向相对速度，单位 m/s */
} CollideLog;

IceBlock g_ice[MAX_ICE];      /* 冰块数组（物理顺序） */
IceBlock g_sorted[MAX_ICE];   /* 按 x 排序后的工作副本（扫掠用） */
int      g_order[MAX_ICE];    /* 排序后元素对应的原始下标，便于还原 */
int      g_n = 0;             /* 实际冰块数 ≤ MAX_ICE */
double   g_dt = 0.01;         /* 时间步长，s */
double   g_e  = 0.30;         /* 恢复系数，0.1~0.5 */
double   g_lx = 12.0, g_ly = 9.0;  /* 冰场长宽，m */
double   g_xmin[WIN + 1];     /* 滑动窗口左端x坐标缓存（排序判重用） */
int      g_nWin = 0;
CollideLog g_log[MAX_LOG];    /* 碰撞日志数组 */
int      g_nLog = 0;          /* 日志条数 ≤ MAX_LOG */
int      g_step = 0;          /* 当前仿真步号 */
double   g_momErr = 0.0;      /* 动量守恒校验的最大相对误差 */
int      g_loaded = 0;        /* 状态标记：是否已成功读入冰场 */
```

全局数组放在文件作用域以避免栈溢出；排序在副本 `g_sorted[]` 上进行，碰撞结果按 `g_order[]` 映射回 `g_ice[]` 更新；模块之间只通过上述全局结构体与函数参数交换数据。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 冰块参数读入模块**（源文件 `IceIO.c`）
- 功能简介：打开冰场参数文本文件，读入格式标识、全局参数（N/DT/E/LX/LY）与全部冰块记录填入 `g_ice[]`；文件不存在或格式标识错误时给出明确提示并返回失败标志；读入后打印冰场概要（块数、域尺寸、总质量、总动能）。
- 输入：文件路径（菜单输入，默认 `icefield.txt`）。
- 输出：填充 `g_ice[]`、`g_n`、`g_dt`、`g_e`、`g_lx`、`g_ly`、`g_loaded`；屏幕概要信息。

**M2 数据有效性检查模块**（源文件 `IceCheck.c`）
- 功能简介：逐块检查质量是否为正、中心坐标是否越出冰场边界、半尺寸是否在 0.3～1.0 m 内；对全部冰块两两做一次初始 AABB 重叠检查，报告重叠对；对异常冰块打印"编号-字段-数值"定位清单，并按剔除或人工修正处理。
- 输入：已读入的 `g_ice[]`、`g_n`、`g_lx`、`g_ly`。
- 输出：清洗后的 `g_ice[]`（异常块标记剔除并压缩数组）；屏幕校验报告（越界数、负质量数、初始重叠对数）。

### 第二部分：算法实现（6 个模块）

**M3 冰块位置排序模块**（源文件 `SweepSort.c`）
- 功能简介：把 `g_ice[]` 复制到 `g_sorted[]`，按中心 x 坐标升序用冒泡（或选择）排序，同时用 `g_order[]` 记录每个元素对应的原始下标；排序前缓存窗口用左端坐标，排序后打印"序号-编号-x"对照表供调试。
- 输入：`g_ice[]`、`g_n`。
- 输出：排序后的 `g_sorted[]` 与 `g_order[]`。

**M4 相邻候选对生成模块**（源文件 `CandPair.c`）
- 功能简介：在排序序列上开宽度为 WIN 的滑动窗口：对每个 i，仅与 i+1～i+WIN 的元素做"x 向中心距是否小于两块半长之和"的快速预判，通过者登记为候选对 (i, k)；统计候选对数量并与暴力 N(N−1)/2 对比，验证扫掠的筛选效率。
- 输入：`g_sorted[]`、`g_order[]`、`g_n`、窗口宽度 WIN。
- 输出：候选对下标表 `candA[]`、`candB[]` 与候选数 `g_nCand`；屏幕筛选效率报告。

**M5 AABB 重叠判定模块**（源文件 `AABB.c`）
- 功能简介：对每个候选对计算 x、y 两向包围盒重叠量 dx = (a1+a2) − |x1−x2|、dy = (b1+b2) − |y1−y2|；当 dx > 0 且 dy > 0 判定为碰撞接触，并取重叠量较小的方向为碰撞法向（|dx| < |dy| 时法向为 x，否则为 y）；把判定的碰撞对与法向登记待处理。
- 输入：候选对表 `candA[]`、`candB[]` 与 `g_sorted[]`。
- 输出：碰撞对表（对内两块原始编号、法向标志 nx/ny、重叠量）。

**M6 碰撞冲量计算模块**（源文件 `Impulse.c`）
- 功能简介：对每个判定的碰撞对，按所选法向计算碰撞前相对速度 v_rel（如 x 向：vx1 − vx2，必须为相互接近即 v_rel > 0 才处理），用恢复系数冲量公式 j = (1+e)·m1·m2·v_rel/(m1+m2) 计算法向冲量，写入 `g_log[]`。
- 输入：碰撞对表、`g_sorted[]`、恢复系数 `g_e`。
- 输出：每对的法向冲量 j 与 v_rel，追加进 `g_log[]`、`g_nLog`。

**M7 碰撞后速度更新模块**（源文件 `VelUpdate.c`）
- 功能简介：由冲量更新两冰块速度：x 向碰撞时 vx1 -= j/m1、vx2 += j/m2（y 向同理）；更新前缓存系统总动量，更新后重新计算并输出动量相对误差，校验动量守恒；把结果经 `g_order[]` 写回 `g_ice[]`；对同一冰块一步内的多次碰撞按对序依次施加。
- 输入：碰撞对表与冲量表、`g_sorted[]`、`g_order[]`。
- 输出：更新后的 `g_ice[]`；屏幕动量守恒校验值（写入 `g_momErr`）。

**M8 时间步进模拟模块**（源文件 `SimLoop.c`）
- 功能简介：封装多步推进主循环：每步先按 v·dt 更新全部冰块位置并做边界反弹（越界即速度取反、位置拉回），再依次调用 M3→M4→M5→M6→M7 完成一轮"重排序—检测—碰撞"；循环指定步数（默认 200 步），逐步累计步号与日志。
- 输入：`g_ice[]`、仿真步数。
- 输出：多步模拟后的最终 `g_ice[]`、完整 `g_log[]`；每 50 步屏幕进度提示。

### 第三部分：数据输出（2 个模块）

**M9 碰撞日志输出模块**（源文件 `LogOut.c`）
- 功能简介：把 `g_log[]` 写入日志文件 `collide_log.csv`（列为：step, idA, idB, v_rel, jn），并在屏幕分页列出最近 20 条；日志为空时给出"模拟期内无碰撞"提示。
- 输入：`g_log[]`、`g_nLog`。
- 输出：碰撞日志 CSV 文件；屏幕最近碰撞清单。

**M10 统计报表输出模块**（源文件 `Report.c`）
- 功能简介：统计碰撞总次数、涉及碰撞的冰块数、平均/最大冲量及最大冲量发生的步号与冰块对、每步平均碰撞次数；同时输出模拟结束时各冰块的最终位置速度表，屏幕打印报表并把汇总行追加写入 `collide_report.txt`。
- 输入：`g_log[]`、`g_ice[]`、步数。
- 输出：屏幕统计报表；汇总文件 `collide_report.txt`。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1～M10，循环直至选择退出；状态标记 `g_loaded` 约束"未成功读入并校验冰场不得启动模拟"。M8 是唯一的多步循环入口，其内部每步顺序调用 M3～M7；M9、M10 在模拟结束后读取 `g_log[]` 输出。

**数据流**：

```
冰场参数文件 ─► M1 读入 ─► g_ice[] (冰块数组)
                              │
                              ▼
                       M2 有效性检查（越界/负质量/初始重叠）
                              │
                              ▼
   ┌──────────── 每个时间步（M8 时间步进主循环）────────────┐
   │  位置更新 + 边界反弹                                     │
   │        │                                                │
   │        ▼                                                │
   │  M3 位置排序 ─► g_sorted[] / g_order[]                   │
   │        │                                                │
   │        ▼                                                │
   │  M4 滑动窗口候选对生成 ─► candA[] / candB[]               │
   │        │                                                │
   │        ▼                                                │
   │  M5 AABB 重叠判定 ─► 碰撞对表（含法向）                    │
   │        │                                                │
   │        ▼                                                │
   │  M6 冲量计算 ─► j / v_rel ─► g_log[]                     │
   │        │                                                │
   │        ▼                                                │
   │  M7 速度更新 + 动量校验 ─► 写回 g_ice[]                   │
   └──────────────────────────────────────────────────────────┘
                              │
                              ▼
              M9 碰撞日志输出        M10 统计报表输出
         (collide_log.csv)      (屏幕报表 + collide_report.txt)
```

所有模块仅通过 `g_ice`、`g_sorted`、`g_order`、`g_log` 及函数参数交换数据，函数接口在编码前书面约定。
