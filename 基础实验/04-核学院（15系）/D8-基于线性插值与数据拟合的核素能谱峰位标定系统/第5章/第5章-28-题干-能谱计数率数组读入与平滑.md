# 第 5 章 练习 28　能谱计数率数组读入与平滑

**所属综合实验**：D8（D8-基于线性插值与数据拟合的核素能谱峰位标定系统）

**对应章节**：5 数组与批量数据处理（5.1 一维数组、5.2 数组遍历、5.3 数组作函数参数、5.4 遍历中的数据变换）

**场景来源**：综合实验 D8《基于线性插值与数据拟合的核素能谱峰位标定系统》（核学院）——本练习是该实验中"能谱平滑预处理"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

真实的 γ 能谱带有**统计涨落噪声**：同一个道址的计数率时高时低，画出来毛刺很多。如果直接对带噪声的谱找峰，很容易把噪声毛刺误判成峰（假峰）。

处理办法之一是**滑动平均平滑**：用每个点**及其左右邻居**的算术平均，替代该点的原始值。这样随机涨落被"抹平"，真实的峰则保留下来。用三点窗口（左邻、自己、右邻）的平滑公式是：

$$
c'[i] = \frac{c[i-1] + c[i] + c[i+1]}{3}, \qquad i = 1, 2, \dots, n-2
$$

综合实验 D8 的寻峰流程就是：**先平滑、再寻峰**。本题实现"读入能谱 + 三点滑动平均"这一步。

## 二、任务要求

编写一个完整程序 `smooth_spectrum.c`：

1. 从键盘读入谱长度 `n`（**题目保证 3 ≤ n ≤ 50**）；
2. 读入 `n` 个计数率（double，个/秒）存入数组 `c[50]`；
3. 用**三点滑动平均**平滑：对内部点 `i`（1 ≤ i ≤ n-2），把 `c[i]` 更新为 `(c[i-1] + c[i] + c[i+1]) / 3`；**首尾两点（下标 0 和 n-1）保持原值不变**；
4. 输出平滑后的 `n` 个计数率，每个保留 2 位小数，用空格分隔。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各道计数率。

**输出**：一行，为平滑后的 n 个计数率，保留 2 位小数，用空格分隔。

## 四、样例

输入：

输出：
```

```

```

```

## 五、提示

- **关键陷阱**：如果就地修改 `c[i]`，那么计算 `c[i+1]` 时会用到**已经被改过**的 `c[i]`，平滑结果就错了（变成"累积平滑"）。解决办法是用一个**临时数组**存平滑结果：
  ```c
  for (i = 0; i < n; i++) s[i] = c[i];      /* 先复制原数据 */
  for (i = 1; i <= n - 2; i++)
      s[i] = (c[i-1] + c[i] + c[i+1]) / 3;  /* 从原数组 c 读，写进 s */
  ```
- 首尾两点不参与平滑，直接保留；
- 输出时注意格式与空格处理（第一个数前不加空格，其余前面加）；
- 想一想：为什么"用原数据算、写新数组"就安全了？因为 `c` 全程不被改动，每次读到的都是真实原值；若就地改 `c`，后面的计算就被污染了；
- 平滑的效果：噪声被抹平，但**峰位（最高点的位置）基本不变**——这正是平滑的价值：抑制噪声又不移动峰。

**完成本练习后你将具备的能力**：用数组保存批量数据、用"读原数组、写新数组"的方式做数据变换、理解就地修改的陷阱——这些是实验 D8 中"平滑预处理模块"的地基。
