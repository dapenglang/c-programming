## 二、预备知识：二维数组与行优先存储（零基础阅读）

### 1. 为什么需要二维数组

练习 01～10 处理的是"一排数据"，用一维数组就够。但压力测点是**排成表格**的：有行、有列，同一个测点要用"第几行第几列"两个编号才能定位。如果硬用一维数组，就得自己把 $(i, j)$ 折算成 $i \times n + j$ 的下标，既费脑又容易错。二维数组把这个折算交给语言去做，我们直接用两个下标访问。

### 2. 二维数组长什么样

声明

```c
double p[20][20];
```

的含义是：申请 $20 \times 20 = 400$ 个连续的 `double` 单元，用 `p[i][j]` 访问第 $i$ 行第 $j$ 列的元素。**第一个方括号是行的容量，第二个是列的容量**，两个下标都从 0 开始，合法范围是 $i \in [0,19]$、$j \in [0,19]$。

### 3. 关键：内存里其实是"一行接一行"排的

这一点初学者最容易忽略：二维数组在内存中**并不是方方正正的表格**，而是把每一行首尾相接排成一条长长的队伍，这叫**行优先（row-major）存储**。例如 `p[2][3]`：

$$
\underbrace{p[0][0]\ p[0][1]\ p[0][2]}_{\text{第 0 行}}\ \underbrace{p[1][0]\ p[1][1]\ p[1][2]}_{\text{第 1 行}}
$$

第 0 行排完紧接着排第 1 行。元素 `p[i][j]` 在队伍中的位置（从 0 数）是：

$$
\text{位置} = i \times n + j
$$

（$n$ 是**每行的列数**，不是容量 20）。理解了这条公式，就明白了为什么"先走完一行再走下一行"的遍历顺序与内存顺序完全一致——这种顺序访问对缓存最友好，也最符合人的直觉。

### 4. 怎么遍历——双重循环

按行优先顺序遍历整张网格，用**嵌套的两层循环**：

```c
for (i = 0; i < m; i++)        /* 外层：逐行走 */
    for (j = 0; j < n; j++)    /* 内层：走完这一行的每一列 */
        ... 处理 p[i][j] ...
```

外层控制行号 $i$，内层控制列号 $j$。当 $i$ 固定时，内层把这一行的 $n$ 个元素从头到尾访问一遍，然后外层 $i$ 加 1，进入下一行。整个循环体一共执行 $m \times n$ 次，正好把整张表访问一遍。

### 5. 逐行统计怎么写

"逐行统计"意味着：**每一行单独做一次统计**。所以外层循环走行，进入第 $i$ 行后，用内层循环遍历该行的 $n$ 个元素，边遍历边累加求和、边比较更新最值。注意最值的初值要取该行的第一个元素 `p[i][0]`，如果错写成 0 或一个很小的数，当所有压力都是负数或都大于 0 时就会得到错误结果。这一点在练习 02（一维数组找最值）里已经强调过，二维只是把它套进外层循环里重复 $m$ 遍。

## 三、解题思路

1. **定容量与变量**：行列都取上限 20，声明 `double p[20][20];`，用 `int m, n` 接收实际行列数；
2. **读入网格**：双重循环 `for (i=0;i<m;i++) for (j=0;j<n;j++) scanf("%lf", &p[i][j]);`；
3. **逐行统计**：外层 `for (i=0;i<m;i++)`，进入后令 `mx = mn = p[i][0]`、`sum = 0`，内层 `for (j=0;j<n;j++)` 累加 `sum` 并用 `if` 更新 `mx`、`mn`；
4. **输出该行**：`avg = sum / n`，用 `printf("行%d: max=%.2f min=%.2f avg=%.2f\n", i+1, mx, mn, avg)`；
5. **注意序号**：显示"行 $k$"时用 `i + 1`，与数组下标相差 1。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double p[20][20];              /* 压力网格，容量 20x20，够放题目上限 */
    int m, n;                      /* 实际行数、列数 */
    int i, j;

    scanf("%d %d", &m, &n);        /* 读入行数、列数 */

    /* 双重循环：按先行后列的顺序读入 m*n 个压力值 */
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            scanf("%lf", &p[i][j]);

    /* 逐行统计：外层走行，内层遍历这一行的 n 个元素 */
    for (i = 0; i < m; i++) {
        double mx = p[i][0];       /* 最大值初值取本行第一个元素 */
        double mn = p[i][0];       /* 最小值初值同样取本行第一个元素 */
        double sum = 0.0;

        for (j = 0; j < n; j++) {
            if (p[i][j] > mx) mx = p[i][j];   /* 更新最大值 */
            if (p[i][j] < mn) mn = p[i][j];   /* 更新最小值 */
            sum += p[i][j];                   /* 累加求和 */
        }

        printf("行%d: max=%.2f min=%.2f avg=%.2f\n",
               i + 1, mx, mn, sum / n);       /* 显示行号 = 下标 + 1 */
    }

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：行列下标写反（最典型）**

```c
scanf("%lf", &p[j][i]);     /* 错：把行号列号颠倒了 */
printf("%.2f", p[i][j]);    /* 对：第一个下标是行，第二个是列 */
```

写反后数据被转置存放，逐行统计的结果也就跟着错位。记住口诀：**`p[i][j]`——先找第 $i$ 行，再在该行里找第 $j$ 列**。

**错误 2：双重循环写成同一个变量**

```c
for (i = 0; i < m; i++)
    for (i = 0; i < n; i++) ...   /* 错：内层把外层变量覆盖了 */
for (i = 0; i < m; i++)
    for (j = 0; j < n; j++) ...   /* 对：内外各用一个变量 */
```

内层若复用 `i`，外层循环会被打乱，循环次数完全错误，甚至越界。

**错误 3：最值初值取错**

```c
double mx = 0, mn = 0;          /* 错：若本行压力全为负，max 永远是 0 */
double mx = p[i][0], mn = p[i][0];  /* 对：初值取本行第一个真实元素 */
```

这是练习 02 就强调过的坑，二维网格里要为**每一行**重新赋初值。

**错误 4：平均值写成整除**

```c
avg = sum / n;                  /* 对：sum 是 double，除法自动是实数除法 */
int avg = sum / n;              /* 错：int 接收会丢掉小数部分 */
```

`n` 是 `int`，但 `sum` 是 `double`，所以 `sum / n` 先做类型提升，结果是实数；真正的风险在**输出**——用 `%.2f` 打印实数、用 `double` 接收结果，小数才不会丢。
