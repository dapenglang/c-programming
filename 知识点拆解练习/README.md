# 知识点拆解练习 · 索引

**课程**：《计算思维与问题求解》　**对象**：大一非计算机专业学生（航建 2 系、人工智能 4 系、水声 5 系、核 15 系）

本目录收录 **140 道基础知识点练习**。它的作用是把 [`专业算法综合实验/`](../专业算法综合实验/README.md) 中那 30 个综合实验题目**按基础知识点拆解开来**：综合实验里要用到的每一项基础技能，在这里都被还原成一道独立的小练习，随教学进度**逐章、逐步地**渗透给学生，让学生先练熟基础，再自然具备完成综合实验的能力。

> **编排原则**：题目场景全部从综合实验案例中抽取，每题对应某个综合实验系统中真实存在的一个计算环节——做练习时就在接触真实实验的语境。
> 知识边界严格递进——第 N 章只使用第 2 章至第 N 章的知识点。每题代码 10~40 行，建议用时 20~30 分钟。

**使用说明**：每题包含两份文档——**题干**（任务与输入输出要求）与**讲解与答案**（知识点对照、方法原理、完整参考实现）。
凡涉及数值计算方法（线性插值、积分、二分法、牛顿迭代、高斯消元、排序查找、递归、拉格朗日插值等）的题目，讲解文档均含「预备知识」一节，按四步讲透：问题来源、公式推导、代入本例、编程翻译。
