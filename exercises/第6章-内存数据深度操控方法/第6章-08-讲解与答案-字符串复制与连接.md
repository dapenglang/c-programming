## 二、预备知识：复制与连接的基本原理（零基础阅读）

### 1. 复制：把一排柜子的东西连 `'\0'` 一起搬走

`src` 指向 `"sample"` 的内存是：

```
src →   s  a  m  p  l  e  '\0'
```

复制到 `dst` 就是让 `dst` 那块内存变得与 `src` **逐字节相同**，关键有三处：

- 从首字符开始，一格一格搬；
- **`'\0'` 也必须搬**——否则 `dst` 没有终止符，将来 `%s` 输出会一直读到内存垃圾；
- 搬完后 `dst` 是一个独立、完整的字符串。

最经典的紧凑写法把"搬运、前进、判断"压进一行：

```c
while ((*dst++ = *src++) != '\0')
    ;    /* 空循环体：全部工作都在条件里完成 */
```

读懂它需要三个知识叠加：`*dst++` 是"先取 `*dst` 用，再让 `dst` 前进"；赋值表达式 `(*dst++ = *src++)` 的**值**就是刚赋进去的字符；字符 `'\0'` 即 0，条件为假循环结束。初学时建议先用清晰版（循环内 `*dst = *src;` 两指针各自前进，出循环后补 `*dst = '\0';`），写熟后再体会紧凑版。

### 2. 连接：先走到队尾，再从队尾接力

`my_strcat(dst, src)` 的语义是保留 `dst` 原有内容，把 `src` 追加到后面。实现分两段：

```
第一步：p 从 dst 出发走到 '\0'
        d s t →  s a m p l e '\0'
                                  ↑ p 停在这里
第二步：从 p 开始执行一次复制，把 src 连 '\0' 搬进来
        s a m p l e _ 0 1 . t x t '\0'
```

注意第二步**覆盖掉的正是原来的 `'\0'`**，而复制过程末尾会写入新的 `'\0'`——目标串的终止符由"被覆盖"变"被重写"，始终有且只有一个。

### 3. 目标缓冲区：容量意识

`result[100]` 只有 100 格。若前缀+后缀超过 99 个字符，复制会**越过数组边界**写入相邻内存（缓冲区溢出），这是真实世界最危险的一类 bug。本题输入有上限保证安全，但实验 B10 的正式代码中，连接前必须先 `my_strlen` 检查 `len(dst) + len(src) < 容量`。手写函数不像库函数那样替你把关，**安全责任在使用者**。

### 4. 为什么返回 `dst`

函数内部 `dst` 已经走动，无法再代表"目标串起点"，所以要在动身前把起点存起来最后 `return`。返回地址让调用可以串起来写：`my_strlen(my_strcpy(buf, s))`——实验代码中常见的链式风格。## 三、解题思路

1. **`my_strcpy`**：清晰版两步走——循环搬字符、出循环补 `'\0'`；
2. **`my_strcat`**：局部指针 `p = dst`，`while (*p) p++;` 找到尾，然后 `my_strcpy(p, src);` 接力；
3. **主函数**：`char result[100]`；读前缀 `pre`、后缀 `suf`；`my_strcpy(result, pre); my_strcat(result, suf);`；
4. **输出**：`%s` 打印 `result`，长度用 `my_strlen(result)`。

## 四、参考代码

```c
#include <stdio.h>

char *my_strcpy(char *dst, char *src);
char *my_strcat(char *dst, char *src);
int   my_strlen(char *s);

int main(void)
{
    char pre[25], suf[25];   /* 前缀与后缀 */
    char result[100];        /* 拼接结果缓冲区：必须足够大 */

    scanf("%s %s", pre, suf);

    my_strcpy(result, pre);  /* 先装入前缀 */
    my_strcat(result, suf);  /* 再接上后缀 */

    printf("filename = %s\n", result);
    printf("length = %d\n", my_strlen(result));

    return 0;
}

char *my_strcpy(char *dst, char *src)
{
    char *start = dst;       /* 记住起点，供返回 */

    while (*src != '\0')     /* 逐字符搬运 */
    {
        *dst = *src;
        dst++;
        src++;
    }
    *dst = '\0';             /* 终止符必须补上 */

    return start;
}

char *my_strcat(char *dst, char *src)
{
    char *p = dst;

    while (*p != '\0')       /* 第一段：走到 dst 的队尾 */
        p++;

    my_strcpy(p, src);       /* 第二段：从队尾接力复制（含 '\0'） */

    return dst;
}

int my_strlen(char *s)
{
    char *p = s;
    while (*p != '\0')
        p++;
    return (int)(p - s);
}
```

## 五、运行验证

样例 1（前缀 `sample`，后缀 `_01.txt`）：

- 复制后 `result = "sample\0"`；连接时 `p` 停在下标 6 的 `'\0'`，接力写入 `_01.txt\0`；
- 输出 `filename = sample_01.txt`，长度 $6 + 7 = 13$ ✓（`_01.txt` 共 7 字符）。

样例 2：`icesample`（9 字符）+ `_07.dat`（7 字符）= 16，输出 `filename = icesample_07.dat`、`length = 16` ✓。拼接后 `result` 中有且只有一个 `'\0'`，多次调用 `my_strcat` 也始终成立。

## 六、常见错误与讲解

**错误 1：复制函数漏写终止符**

```c
while (*src != '\0') { *dst = *src; dst++; src++; }
/* 漏了 *dst = '\0'; —— result 尾部没有终止符 */
```

后果：`printf("%s", result)` 会把缓冲区后面的垃圾字节一并输出，长度也随机偏大。**复制结束必须补 `'\0'`。**

**错误 2：连接函数从 0 开始覆盖**

```c
void my_strcat(char *dst, char *src)
{
    my_strcpy(dst, src);   /* 错：把 dst 原有内容清掉了，变成复制 */
}
```

连接的精髓是**先走到 `dst` 现有 `'\0'` 处**再复制，起点是队尾不是队首。

**错误 3：缓冲区太小导致越界**

```c
char result[10];   /* 装 "sample_01.txt"（14 字节含 '\0'）必然溢出 */
```

越界写入破坏相邻变量，症状离奇。容量 = 两段长度之和 + 1（给 `'\0'`），再留余量。

**错误 4：紧凑版循环后又补一次 `'\0'`**

```c
while ((*dst++ = *src++) != '\0')
    ;
*dst = '\0';    /* 错：'\0' 已随循环复制，此时 dst 在其后再写一个 0 */
```

紧凑版循环中 `'\0'` 已被复制，循环结束后 `dst` 已越过它；再补一次会在串尾多写一个 0，虽对 `%s` 无害，但说明没读懂循环——清晰版需要补、紧凑版不需要补，选一种，别混用。
