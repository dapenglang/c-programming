## 二、预备知识：行指针的基本原理（零基础阅读）

### 1. 问题是怎么来的

二维数组 `t[m][4]` 在内存里其实是**一长条**：第 0 行 4 个元素排完，紧跟第 1 行……但"逻辑上"它是按行组织的表。逐站处理潮位数据时，最自然的动作是"**把指针对准一整行的开头，处理完这行，一步跳到下一行**"——这正是行指针的本职。

### 2. 两级地址：行地址与元素地址

对 `double t[3][4]`：

- `t`、`t+1`、`t+2` 是**行地址**，类型是 `double (*)[4]`——加 1 跳过 4 个 double；
- `*(t+1)`（即 `t[1]`）是**第 1 行首元素地址**，类型 `double *`——加 1 跳 1 个 double；
- 元素 `t[i][j]` 的等价写法是 `*(*(t+i)+j)`：先"跨 i 行"拿到行首地址，再"偏 j 个"拿到元素。

行指针变量就是专门存放行地址的变量：

```c
double (*p)[4] = t;    /* p 指向第 0 行 */
p++;                    /* p 现在指向第 1 行 */
```

**括号不可省**：`double *p[4]` 是"指针数组"（4 个指针），`double (*p)[4]` 才是"行指针"。优先级记忆：`[]` 比 `*` 亲，所以要加括号把 `*p` 捆住。

```
内存（一长条，共 12 个 double）：
  t[0][0] t[0][1] t[0][2] t[0][3] t[1][0] t[1][1] ...
+-------+-------+-------+-------+-------+-------+--
|  2.0  |  4.0  |  3.0  |  5.0  |  1.0  |  3.0  | ...
+-------+-------+-------+-------+-------+-------+--
  ↑p(行0,步长=4个double)      ↑p+1(行1)
  ↑*(p+1) 即行1首元素地址（元素级指针）
```

### 3. 每行统计的套路

行内统计与练习 32 完全相同：行首元素地址交给一个普通指针 `q`，游走 4 次，同时累加与比极值：

```c
for (p = t; p < t + m; p++) {         /* 行级：p 逐行推进 */
    double *q = *p;                   /* 元素级：q 指向本行首元素 */
    s = *q; mx = *q; mn = *q;
    for (j = 1; j < 4; j++) {
        q++;                          /* 行内走一格 */
        s += *q;
        if (*q > mx) mx = *q;
        if (*q < mn) mn = *q;
    }
    /* 输出 s/4、mx、mn */
}
```

### 4. 用本例走一遍

样例 1 的矩阵与逐站结果：

| 站 | 行数据 | 和 | 平均 | 最高 | 最低 |
|---|---|---|---|---|---|
| 1 | 2.0 4.0 3.0 5.0 | 14.0 | 3.50 | 5.00 | 2.00 |
| 2 | 1.0 3.0 2.0 6.0 | 12.0 | 3.00 | 6.00 | 1.00 |
| 3 | 3.0 5.0 4.0 4.0 | 16.0 | 4.00 | 5.00 | 3.00 |

以站 1 为例走指针：`p` 指向行 0，`q = *p` 指向 `t[0][0]=2.0`（初值 s=2.0, mx=2.0, mn=2.0）；`q++`→4.0（s=6.0, mx=4.0）；`q++`→3.0（s=9.0）；`q++`→5.0（s=14.0, mx=5.0）。得平均 14.0/4=3.50，最高 5.00，最低 2.00——与样例一致。

> **这个结构在综合实验中反复出现**：C7 的多站潮位矩阵逐行平滑与统计、C8 的分层声速表逐层处理、C6 的分段深度表，都是"行指针走行、元素指针走格"的两级遍历。

## 三、解题思路

1. 读入 `m` 与 `m×4` 潮位矩阵；
2. 行指针 `p` 从 `t` 推进到 `t + m`，每行内用元素指针 `q` 游走一遍求和与极值；
3. 平均 = 行和 / 4；
4. 按格式逐站输出。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double t[10][4];            /* 潮位矩阵：m 站 × 4 个时刻 */
    double (*p)[4];             /* 行指针：一步跨一行 */
    double *q;                  /* 元素指针：行内游走 */
    double s, mx, mn;
    int m, j, k = 0;

    scanf("%d", &m);
    for (p = t; p < t + m; p++)         /* 用行指针读入 */
        for (j = 0; j < 4; j++)
            scanf("%lf", &(*p)[j]);     /* (*p)[j] 即 t[k][j] */

    for (p = t; p < t + m; p++) {
        k++;                            /* 站号从 1 开始 */
        q = *p;                         /* q 指向本行首元素 */
        s = mx = mn = *q;
        for (j = 1; j < 4; j++) {
            q++;
            s += *q;
            if (*q > mx) mx = *q;
            if (*q < mn) mn = *q;
        }
        printf("站%d 平均=%.2f 最高=%.2f 最低=%.2f\n",
               k, s / 4, mx, mn);
    }
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：行指针漏括号**

```c
double *p[4];       /* 错：指针数组，不是行指针 */
double (*p)[4];     /* 对：指向"含 4 个 double 的行"的指针 */
```

**错误 2：行内越级用 `p[j]`**

```c
s += p[j];              /* 错：p 是行级指针，p[j] 是"往下跳 j 行"的行地址 */
s += (*p)[j];           /* 对：先解引用到行内元素级，再偏 j */
```

**错误 3：`q++` 与 `p++` 用混**

```c
q = *p;        /* q 是元素指针（double *），加 1 走 1 个元素 */
q++;           /* 对 */
p++;           /* 这是"换下一行"，行内统计时不能用 */
```

**错误 4：读入时忘加解引用**

```c
scanf("%lf", &p[j]);      /* 错：对行地址取元素偏移，类型不符 */
scanf("%lf", &(*p)[j]);   /* 对：元素 t[当前行][j] 的地址 */
```
