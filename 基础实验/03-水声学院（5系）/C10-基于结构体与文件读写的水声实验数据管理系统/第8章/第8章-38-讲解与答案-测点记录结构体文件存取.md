## 二、预备知识：结构体记录如何"落盘"再"取回"

### 1. 问题是怎么来的

一条测点记录有三个字段：测点号、深度、声速。用三个平行数组（`int ids[50]; double depths[50]; ...`）管理，一条记录的字段散落三处，排序、增删时极易错位。**结构体**把三个字段捆成一个整体：

```c
struct Record {
    int    id;       /* 测点号 */
    double depth;    /* 测点深度 (m) */
    double speed;    /* 声速 (m/s) */
};
struct Record rec[50];   /* 结构体数组：最多 50 条记录 */
```

而管理系统要"关机不丢数据"，就必须解决最后一个问题：**结构体在内存里，怎么把它送进文件、再原样取回来？**

### 2. 写文件四步曲（结构体版）

**第一步：打开**

```c
FILE *fp = fopen("station.txt", "w");
```

模式 `"w"`：文件不存在则新建，已存在则清空重写。

**第二步：判断是否成功**

```c
if (fp == NULL) {
    printf("打开文件失败\n");
    return 1;
}
```

**第三步：逐字段写**

结构体**不能**整体 `fprintf(fp, "%???", rec[i])`——`printf` 家族没有"结构体"这种格式符。正确做法是把记录**拆成成员、逐个写**：

```c
fprintf(fp, "%d %.2f %.1f\n", rec[i].id, rec[i].depth, rec[i].speed);
```

这一行同时回答了"结构体怎么写文件"：**结构体 → 成员 → 每个成员一个格式符**。行末 `\n` 保证一条记录一行。

**第四步：关闭**

```c
fclose(fp);
```

### 3. 读回：格式串必须与写入时"镜像一致"

写的时候是 `"%d %.2f %.1f\n"`，读回来就用 `"%d %lf %lf"`：

```c
fscanf(fp, "%d %lf %lf", &back[i].id, &back[i].depth, &back[i].speed);
```

两点注意：

- **`&` 不能少**：`fscanf` 需要每个成员的**地址**。成员是普通变量，所以 `&back[i].id`、`&back[i].depth`、`&back[i].speed` 各自带 `&`（数组名不用加，但这里是结构体成员）；
- `fscanf` 的 `%d`、`%lf` 会自动**跳过空白（空格、换行）**再取值，所以文件里"一条一行、字段空格分隔"的排布正好被它消化——这就是文本存取的好处：**文件人能看懂，程序也能读回**。

题目规定文件第一个数写 `n`，读回时第一个 `fscanf` 先读 `n`，再用 `for (i = 0; i < n; i++)` 逐条读入——这样"读多少条"是文件自己告诉程序的，不依赖屏幕输入（第 4 步与第 2 步是两次独立运行逻辑，文件自描述更稳）。

### 4. 存取闭环与平均声速

整个程序是一个**闭环**：内存（`rec`）→ 文件（`station.txt`）→ 内存（`back`）。闭环的价值在于**验证**：把 `back` 打印出来与 `rec` 对照，若一致，说明存取格式没写错。最后顺手统计平均声速：

$$
\bar{v} = \frac{1}{n}\sum_{i=0}^{n-1} v_i
$$

### 5. 用本例走一遍

样例 1 的三条记录：

| $i$ | id | depth | speed |
|---|---|---|---|
| 0 | 1 | 10.0 | 1500.2 |
| 1 | 2 | 25.5 | 1502.8 |
| 2 | 3 | 40.0 | 1505.1 |

写入时：`fprintf(fp, "%d %.2f %.1f\n", ...)` 把 10.0 变成 `10.00`、1500.2 变成 `1500.2`——格式化写是"存的时候就把样子定好"。

读回时 `fscanf` 从文本 `1 10.00 1500.2` 里取回整数 1、实数 10.00、实数 1500.2，填进 `back[0]` 的三个成员——数值与 `rec[0]` 完全一致，闭环成立。

平均声速：$\bar{v} = \dfrac{1500.2 + 1502.8 + 1505.1}{3} = \dfrac{4508.1}{3} = 1502.70$。

> **这个思想在综合实验中反复出现**：C10 的"文件批量读入（M3）"和"结果文件存取（M9）"是同一个闭环的两个方向；C6、C7 的结果输出也是"内存数据 → 文本文件"。掌握了"结构体逐字段 fprintf / fscanf"，实验的持久化模块就有了万能模板。

## 三、解题思路

1. **定义结构体与数组**：`struct Record rec[50], back[50];`；
2. **键盘录入**：循环 `scanf("%d %lf %lf", &rec[i].id, &rec[i].depth, &rec[i].speed);`；
3. **写文件**：`fopen("station.txt", "w")` 判 `NULL` → 先写 `n` → 循环逐字段 `fprintf` → `fclose`；
4. **读回**：`fopen("station.txt", "r")` 判 `NULL` → 先 `fscanf` 读 `n` → 循环逐字段 `fscanf` 读入 `back` → `fclose`；
5. **报表与统计**：循环打印 `back` 的每条记录，累加声速求平均并输出。

## 四、参考代码

```c
#include <stdio.h>

struct Record {
    int    id;       /* 测点号 */
    double depth;    /* 测点深度 (m) */
    double speed;    /* 声速 (m/s) */
};

int main(void)
{
    struct Record rec[50], back[50];    /* 录入数组、读回数组 */
    FILE *fp;
    double sum = 0.0, mean;
    int n, i;

    scanf("%d", &n);                    /* 键盘录入 n 条记录 */
    for (i = 0; i < n; i++) {
        scanf("%d %lf %lf", &rec[i].id, &rec[i].depth, &rec[i].speed);
    }

    /* ---------- 第一段：写入文件 ---------- */
    fp = fopen("station.txt", "w");
    if (fp == NULL) {
        printf("打开文件 station.txt 失败\n");
        return 1;
    }
    fprintf(fp, "%d\n", n);             /* 先写条数，读回时先读它 */
    for (i = 0; i < n; i++) {           /* 逐条、逐字段写入 */
        fprintf(fp, "%d %.2f %.1f\n", rec[i].id, rec[i].depth, rec[i].speed);
    }
    fclose(fp);                         /* 写完必须关闭，再以 "r" 打开 */

    /* ---------- 第二段：从文件读回 ---------- */
    fp = fopen("station.txt", "r");
    if (fp == NULL) {
        printf("打开文件 station.txt 失败\n");
        return 1;
    }
    fscanf(fp, "%d", &n);               /* 先读回条数 */
    for (i = 0; i < n; i++) {           /* 逐条、逐字段读回 */
        fscanf(fp, "%d %lf %lf", &back[i].id, &back[i].depth, &back[i].speed);
    }
    fclose(fp);

    /* ---------- 第三段：屏幕报表 + 平均声速 ---------- */
    for (i = 0; i < n; i++) {
        printf("%d %.2f %.1f\n", back[i].id, back[i].depth, back[i].speed);
        sum += back[i].speed;
    }
    mean = sum / n;
    printf("平均声速: %.2f\n", mean);
    return 0;
}
```

## 五、运行验证

**第一次运行**（样例 1），**运行后** `station.txt` 内容：

```
3
1 10.00 1500.2
2 25.50 1502.8
3 40.00 1505.1
```

屏幕输出：

```
1 10.00 1500.2
2 25.50 1502.8
3 40.00 1505.1
平均声速: 1502.70
```

**第二次运行**（样例 2：2 条记录），因 `"w"` 清空重写，**运行后** `station.txt` 内容：

```
2
7 100.00 1498.5
8 120.00 1497.9
```

屏幕输出：

```
7 100.00 1498.5
8 120.00 1497.9
平均声速: 1498.20
```

| 样例 | 闭环自检 | 平均声速自检 |
|---|---|---|
| 1 | 屏幕报表与文件内容逐字符一致（id、深度、声速均未变）✓ | $4508.1/3 = 1502.70$ ✓ |
| 2 | 报表与文件一致，`n` 也从文件正确读回 ✓ | $(1498.5+1497.9)/2 = 1498.20$ ✓ |

**反例验证**：把第二步的文件名故意改成 `no_such.txt`，程序会打印 `打开文件 no_such.txt 失败` 并正常退出——说明读失败判断生效。

## 六、常见错误与讲解

**错误 1：试图整体读写结构体**

```c
fprintf(fp, "%d %.2f %.1f", rec[i]);        /* 错：格式符个数与参数不匹配 */
fprintf(fp, "%d %.2f %.1f\n", rec[i].id, rec[i].depth, rec[i].speed);  /* 对 */
```

`printf` 家族没有"结构体格式符"，必须**逐成员**写。想一次传整个结构体，得等学过二进制读写（`fwrite`），本题的文本存取必须拆字段。

**错误 2：`fscanf` 读结构体成员时漏 `&`**

```c
fscanf(fp, "%d %lf %lf", back[i].id, back[i].depth, back[i].speed);        /* 错 */
fscanf(fp, "%d %lf %lf", &back[i].id, &back[i].depth, &back[i].speed);     /* 对 */
```

`fscanf` 要的是**地址**；漏 `&` 编译可能只给警告，运行时把成员的值当地址用，程序崩溃。

**错误 3：写完不关就读（同一个 `FILE *` 混用）**

```c
fp = fopen("station.txt", "w");
/* ...写入... */
fscanf(fp, "%d", &n);          /* 错：还在 "w" 模式上读，且缓冲未冲刷 */
```

必须先 `fclose(fp)` 再用 `"r"` 重新 `fopen`。`"w"` 模式的文件指针只能写；且不关闭时最后一段数据可能还留在缓冲区里没落盘。

**错误 4：读回格式串与写入不一致**

```c
fprintf(fp, "%d %.2f %.1f\n", ...);   /* 写：三个字段 */
fscanf(fp, "%d %lf", &n, &x);         /* 错：只读两个字段，第三个字段残留 */
```

字段对不齐时，`fscanf` 会把"声速"当"下一条记录的测点号"读，报表全乱。**写入与读回的格式串必须镜像一致。**

**错误 5：模式用错**

```c
FILE *fp = fopen("station.txt", "r");   /* 若本意是写入：fprintf 无效 */
FILE *fp = fopen("station.txt", "w");   /* 对：写入用 "w" */
```

再次强调：**读用 `"r"`，写用 `"w"`**；对只读打开的文件执行 `fprintf` 会失败。
