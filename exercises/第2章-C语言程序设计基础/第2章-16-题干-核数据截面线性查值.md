# 第 2 章 练习 16　核数据截面线性查值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 D3《基于拉格朗日插值的核数据截面查值系统》（核学院）——本练习是该实验中"截面线性插值查值"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

在反应堆物理中，中子和原子核发生反应的概率用**截面** $\sigma$ 描述，单位是靶恩（barn，$1\ \mathrm{b} = 10^{-28}\ \mathrm{m^2}$）。截面随入射中子的**能量**变化很大，核数据库不可能对每个能量都给出数值，只给出若干离散能量点的截面，例如 1.0 eV 处 18.0 b、5.0 eV 处 3.0 b。

当计算需要某个中间能量（如 3.0 eV）的截面时，就用**线性插值**在相邻两点间取值。综合实验 D3 要处理完整的截面表格，本练习先独立完成"给定两档能量—截面数据、求中间能量截面"这一最小步骤。

## 二、任务要求

编写一个完整程序 `cross_section.c`：

1. 用**常量**在程序中存放相邻两档数据：能量 1.0 eV 对应截面 18.0 b，能量 5.0 eV 对应截面 3.0 b；
2. 从键盘读入一个中子能量 `E`（单位：eV，`double` 类型，**题目保证 1.0 ≤ E ≤ 5.0**，因此不需要判断分支）；
3. 用线性插值公式计算该能量对应的截面 `sigma`；
4. 按规定格式输出结果，保留 **3 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示中子能量 E（eV）。

**输出**：一行，按格式 `sigma = 结果 b` 输出，结果保留 3 位小数。

## 四、样例

**样例 1**

输入：
```
3.0
```
输出：
```
sigma = 10.500 b
```

**样例 2**

输入：
```
4.2
```
输出：
```
sigma = 6.000 b
```

## 五、提示

线性插值公式：已知两点 $(E_0,\, \sigma_0)$、$(E_1,\, \sigma_1)$，则能量 $E$ 处的截面为

$$
\sigma = \sigma_0 + \dfrac{(\sigma_1 - \sigma_0)\,(E - E_0)}{E_1 - E_0}
$$

本例截面随能量**减小**（$\sigma_1 - \sigma_0 = -15$），符号由公式自动处理；只需把公式原样翻译成一行赋值语句，注意括号。

**完成本练习后你将具备的能力**：把核数据表格翻译成程序常量、独立完成一次完整插值流程、处理递减型数据——这是 D3 截面查值系统里"任意能量查截面"模块的地基。
