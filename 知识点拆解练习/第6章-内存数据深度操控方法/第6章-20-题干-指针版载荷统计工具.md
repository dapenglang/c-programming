# 第 6 章 练习 20　指针版载荷统计工具

**对应章节**：2～6 章综合（以第 6 章指针为核心：6.1 地址与指针、6.2 指针变量、6.3 指针与数组、6.4 指针与字符串、6.5 指针与函数、6.6 指向指针的指针）

**场景来源**：综合实验 C7《基于冲量-动量反演的冰阻力与碰撞事件辨识系统》（水声学院）——本练习是该实验中"载荷序列统计报表"环节的完整实现，也是本章的综合题。

**建议用时**：30 分钟

## 一、应用场景

冰载荷辨识系统每完成一轮测试，都要对采回的阻力样本出具一份"体检报告"：样本总数是多少、平均阻力多大、峰值和谷值各是多少、有多少个样本超过了警戒阈值、超阈占比多少，最后还要把样本按升序排好便于查看。这份报表要用到本章的多项本事：**多结果返回**（均值、最值一次算回）、**只读输入指针**（统计不改原数据）、**输出指针**（另存排序结果）、**指针遍历**（筛选计数）。本练习把它组装成一个完整的指针版统计工具。

## 二、任务要求

编写一个完整程序 `load_report.c`，实现以下功能：

1. 主函数读入样本数 `n`（题目保证 $1 \le n \le 50$），读入 `n` 个阻力值存入 `double a[50]`，再读入阈值 `thr`；
2. 编写函数 `void stat(const double *a, int n, double *mean, double *max, double *min);`，一次算回均值、最大值、最小值（`a` 只读，不改动原数据）；
3. 编写函数 `void sort_asc(const double *a, int n, double *out);`，把 `a` 拷贝到 `out` 后按**升序**排序（用指针方式交换元素，`a` 保持只读）；
4. 主函数用 `const double *a` 只读遍历完成"超阈值样本计数"（大于等于 `thr` 的个数），并按下方格式输出完整报表。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数；第三行一个实数（阈值 `thr`）。

**输出**：共 7 行，依次为：

```
n = <样本数>
mean / max / min = <均值 / 最大值 / 最小值，各保留 4 位小数>
over = <超阈样本个数>
ratio = <超阈占比，保留 2 位小数，带百分号>
sorted = <升序排列的样本，各保留 2 位小数、空格分隔>
```

其中占比 $ratio = \dfrac{over}{n} \times 100\%$。

## 四、样例

**样例 1**

输入：
```
6
12.5 30.0 8.4 45.2 20.0 30.0
20.0
```
输出：
```
n = 6
mean = 24.3500
max = 45.2000
min = 8.4000
over = 4
ratio = 66.67%
sorted = 8.40 12.50 20.00 30.00 30.00 45.20
```

**样例 2**

输入：
```
5
5 15 25 35 45
25
```
输出：
```
n = 5
mean = 25.0000
max = 45.0000
min = 5.0000
over = 3
ratio = 60.00%
sorted = 5.00 15.00 25.00 35.00 45.00
```

## 五、提示

- 多结果返回靠指针参数：`stat(a, n, &mean, &mx, &mn);`；统计与排序的输入都用 `const double *a`（承诺只读），排序结果写进另一个数组 `srt`；
- 排序用冒泡：若相邻两元素逆序（`out[j] > out[j+1]`）就交换，排的是 `out` 里的数值，可以用临时变量 `double t` 完成交换；
- 超阈计数用 `>=`（包含等于阈值的样本）；占比用 `100.0 * over / n`（浮点运算），并用 `%%` 输出百分号。

**完成本练习后你将具备的能力**：综合运用指针参数的"多结果返回"、只读输入指针与可写输出指针的配合、指针遍历与计数、指针版排序，独立完成一份数据统计报表——这正是实验 C7 中"结果汇总模块"的雏形。
