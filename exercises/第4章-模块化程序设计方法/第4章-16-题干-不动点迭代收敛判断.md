# 第 4 章 练习 16　不动点迭代收敛判断

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.6 非线性方程求解——不动点迭代法）

**场景来源**：综合实验 C10《碎冰场覆盖率与浓度分析系统》（水声学院）——本练习是该实验中"覆盖率平衡方程不动点迭代求解"环节的实现。

**建议用时**：28 分钟

## 一、应用场景

碎冰场的覆盖率 $c$（$0<c<1$）在稳态下由一个"关于它自己"的平衡关系决定：一部分来自初生冰（常数 0.6），另一部分来自碎冰的二次堆积（与 $c^2$ 成正比，系数 0.3），即

$$
c = 0.6 + 0.3\,c^2 .
$$

这类可写成 $x = g(x)$ 的方程叫作**不动点方程**。求解它的最简单办法是**不动点迭代**：把当前的 $c$ 代入右边算出新的 $c$，反复进行。但迭代不一定收敛——必须先检查迭代函数在解附近的导数绝对值是否小于 1，这就是本题要重点体会的**收敛条件**。

## 二、任务要求

编写一个完整程序 `fixed_point.c`：

1. 编写函数 `double g(double c)`：返回 $g(c) = 0.6 + 0.3c^2$；
2. 编写函数 `double fixed_point(double c0, double eps)`：从初值 `c0` 出发，反复执行 $c_{n+1} = g(c_n)$；每完成一次迭代令计数 `k` 加一；当 $|c_{n+1}-c_n| < \text{eps}$ 时停止；函数结束前按格式输出最终解与迭代次数，并返回该解；
3. `main` 读入初值 `c0`，以 `eps = 1e-6` 调用 `fixed_point`；
4. **接口约定**：`fixed_point` 的两个形参为 `double`；输出格式为 `c = 解, n = 迭代次数`（解保留 6 位小数）；不使用全局变量。

## 三、输入输出格式

**输入**：一行，一个实数 `c0`（初始猜测，$0 < c0 < 1$）。

**输出**：一行，格式为 `c = 最终解, n = 迭代次数`。

## 四、样例

**样例 1**

输入：
```
0.5
```
输出：
```
c = 0.784749, n = 17
```

**样例 2**

输入：
```
0.7
```
输出：
```
c = 0.784749, n = 16
```

## 五、提示

- 不动点迭代公式：$c_{n+1} = g(c_n)$，本题即 `c1 = 0.6 + 0.3 * c * c;`；
- 终止判据仍是 $|c_{n+1}-c_n| < \text{eps}$，用 `fabs(c1 - c) < eps`；
- **收敛条件**：若在不动点 $c^\*$ 附近 $|g'(c^\*)| < 1$，迭代收敛；本题 $g'(c) = 0.6c$，在 $c^\*\approx0.7847$ 处 $|g'|\approx0.471<1$，所以从 0 到 1 内的任意初值都能收敛；
- 初值越接近真解，需要的迭代次数越少——比较样例 1（`c0=0.5`，17 次）与样例 2（`c0=0.7`，16 次）即可看出。

**完成本练习后你将具备的能力**：理解不动点迭代的构造方式与收敛条件、会比较不同初值对迭代次数的影响、能为迭代法编写带计数的求解函数——这是实验 C10 中"覆盖率平衡求解模块"的地基。
