# 第 4 章 练习 05　递归求阶乘

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 B3《基于蒙特卡洛方法的随机模拟实验系统》（人工智能学院）——本练习是该实验中"概率与组合计数基础"环节的实现（对应 4.3 递归调用）。

**建议用时**：25 分钟

## 一、应用场景

阶乘 $n!$ 是排列组合与概率计算里最常见的量：随机抽样、投点法、各类离散分布中都离不开它。阶乘有一个"自己定义自己"的性质：$n!=n\times(n-1)!$。用函数来实现时，可以让"求 $n$ 的阶乘"这个函数去调用"求 $n-1$ 的阶乘"的它自己——这就是**递归**。本练习用阶乘这个最经典的例子，把递归的"基线条件 + 递推关系"这套机制讲清楚，它是本章后面所有递归题目的模板。

## 二、任务要求

编写一个完整程序 `factorial.c`：

1. 必须定义**递归函数**，**函数原型为**
   ```c
   long long factorial(int n);
   ```
   返回 $n!$；
2. 函数必须同时具备两部分：
   - **基线条件**：当 `n <= 1` 时直接返回 `1`（规定 $0!=1!=1$）；
   - **递推关系**：否则返回 `n * factorial(n - 1)`（函数调用自身）；
3. 主函数读入一个整数 `n`（题目保证 $0 \le n \le 20$），调用 `factorial` 求阶乘；
4. 按格式输出结果（结果用整型输出，不带小数）。因 $20!$ 已超出 `int` 范围，请用 `long long` 及 `%lld`。

## 三、输入输出格式

**输入**：一行，一个整数 n（$0 \le n \le 20$）。

**输出**：一行，按格式 `n! = 结果` 输出，例如输入 5 时输出 `5! = 120`。

## 四、样例

**样例 1**

输入：
```
5
```
输出：
```
5! = 120
```

**样例 2**

输入：
```
10
```
输出：
```
10! = 3628800
```

## 五、提示

阶乘的递推定义：

$$
n! = n \times (n-1)!,\qquad 0! = 1!\ = 1
$$

递归函数必须有两部分：**基线条件**——最小的、能直接给出答案的情形（这里是 $n\le 1$ 返回 1）；**递推关系**——把大问题化成小一号的同类问题（这里是 $n! = n\times(n-1)!$）。**缺了基线条件，函数会永远调用下去，直到程序崩溃。**

**完成本练习后你将具备的能力**：写出带基线条件与递推关系的递归函数、理解递归"层层深入再层层返回"的执行过程、用 `long long` 处理较大整数——这是本章后续所有递归题目的共同模板。
