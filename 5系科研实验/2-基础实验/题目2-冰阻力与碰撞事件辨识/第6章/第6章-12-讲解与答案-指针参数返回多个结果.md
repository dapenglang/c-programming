## 二、预备知识：为什么 `return` 只能带一个值，指针参数怎么把结果写回（零基础阅读）

### 1. 值传递的"死穴"：形参只是副本

C 语言调用函数时，实参的值会被**复制**一份交给形参。也就是说，函数内部的形参和调用处的实参是两个**互不相干的变量**，只是内容一开始相同。看这个失败的交换例子：

```c
void bad_swap(int x, int y) { int t = x; x = y; y = t; }  /* 改的全是副本 */
...
bad_swap(m, n);   /* 调用后 m、n 纹丝不动 */
```

原因很清楚：`bad_swap` 里忙活半天，改的是 `x`、`y` 这两个副本，`m`、`n` 根本没被碰到。**想让函数改动调用者的变量，就必须把那个变量的"门牌号"（地址）交给它。**

### 2. 指针参数如何"隔空写回"

`return` 一次只能吐一个值，而我们想同时带回三个。办法是：把要装结果的三个变量的**地址**传进去。函数拿到的形参虽然不是那三个变量本人，却是它们的地址——顺着地址就能找到本体，把数据直接写进去。

内存示意图（假设地址为示意值）：

```
   main 的局部变量区                     stat 函数的形参区
   ┌──────────────┐                      ┌─────────────────┐
   │  mean        │ 地址 0x2000   <──────│  mean = 0x2000  │  形参名也叫 mean，
   │  mx          │ 地址 0x2008   <──────│  max  = 0x2008  │  但它是"地址的副本"
   │  mn          │ 地址 0x2010   <──────│  min  = 0x2010  │
   └──────────────┘                      └─────────────────┘
          ▲                                      │
          │            函数里写 *mean = 12.5;    │
          └──────────────────────────────────────┘
              *mean 的含义：顺着 0x2000 找到 main 的 mean，
              往里面放 12.5 —— 这就是"隔空写回"
```

关键区分：

- `mean = ...` 改的是**形参本身**（那个存放地址的指针变量），无关痛痒；
- `*mean = ...` 才是**顺着地址写进 main 的变量**，这才是我们要的。

所以三个结果，就传三个地址；`n` 个结果，就传 `n` 个地址——指针参数把"一次只能返回一个值"的限制彻底打破了。

### 3. 编程翻译

- 函数返回类型写 `void`，因为它不通过 `return` 交结果；
- 三个输出形参都是 `double *`，主函数对应传 `&mean`、`&mx`、`&mn`；
- 函数体内用 `*mean`、`*max`、`*min` 赋值，就是往调用者变量里写。

## 三、解题思路

1. **定接口**：`void stat(double *a, int n, double *mean, double *max, double *min);`——输入只有 `a`、`n`，输出走三个指针；
2. **初始化**：先用首元素 `a[0]` 给 `*max`、`*min` 打底，避免"用 0 初始化"在全负数序列上翻车；
3. **一次遍历**：累加求 `sum`，同时更新 `*max` 与 `*min`，一趟扫完；
4. **写回均值**：`*mean = sum / n;`；
5. **主函数**：读数据、传 `&mean/&mx/&mn`、输出。

## 四、参考代码

```c
#include <stdio.h>

/* 一次算回三个统计量：均值、最大值、最小值（结果写进指针所指变量） */
void stat(double *a, int n, double *mean, double *max, double *min)
{
    double sum = 0.0;
    int i;

    *max = a[0];                 /* 用首元素初始化最值，别用 0 */
    *min = a[0];

    for (i = 0; i < n; i++) {
        sum += a[i];             /* 累加求均值 */
        if (a[i] > *max) *max = a[i];
        if (a[i] < *min) *min = a[i];
    }

    *mean = sum / n;             /* 写回调用者的变量 */
}

int main(void)
{
    double a[50];                /* 阻力样本序列，kN */
    int n, i;
    double mean, mx, mn;         /* 三个"空盒子"，等着被填 */

    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%lf", &a[i]);

    stat(a, n, &mean, &mx, &mn); /* 把三个变量的地址传进去 */

    printf("mean = %.4f max = %.4f min = %.4f\n", mean, mx, mn);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 5 / 10 20 30 40 50 | 均值 (10+20+30+40+50)/5 = 30；max 50；min 10 | `mean = 30.0000 max = 50.0000 min = 10.0000` ✓ |
| 3 / 2.5 8.5 6.0 | 均值 17/3 = 5.6667；max 8.5；min 2.5 | `mean = 5.6667 max = 8.5000 min = 2.5000` ✓ |

> 说明：函数返回 `void`，但 `mean`、`mx`、`mn` 里确实被写进了结果，说明指针参数把数据"隔空送回了" `main`。

## 六、常见错误与讲解

**错误 1：调用时忘记取地址 `&`**

```c
stat(a, n, mean, mx, mn);        /* 错：传的是变量的值（未初始化），函数按"地址"去理解它会乱指 */
stat(a, n, &mean, &mx, &mn);     /* 对：传地址，函数才能写回 */
```
`printf` 里直接写 `mean` 是取值，`stat` 里要写 `&mean` 是取地址，两者场合不同，别混。

**错误 2：函数内漏写 `*`**

```c
mean = sum / n;    /* 错：只改了形参（地址副本），main 的 mean 没动，输出仍是随机值 */
*mean = sum / n;   /* 对：顺着地址写回 main 的变量 */
```
这是本题最高频的错误：现象是"函数算对了，主函数输出却是乱码"。

**错误 3：最值用 0 初始化**

```c
*max = 0;   /* 危险：若序列全是负数，最大值会被错误地当成 0 */
*max = a[0];/* 对：用真实存在的数据打底 */
```

**错误 4：把可能是空的指针解引用**

若某个输出指针没指向有效变量（例如调用时误传了 `NULL`），`*mean = ...` 会立刻崩溃。本阶段保证：**每个输出指针在使用前，调用者一定传入了有效变量的地址**。
