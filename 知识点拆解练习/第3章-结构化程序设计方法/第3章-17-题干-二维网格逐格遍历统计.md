# 第 3 章 练习 17　二维网格逐格遍历统计

**对应章节**：3 结构化程序设计方法（3.3 循环结构——嵌套循环、3.1 顺序结构、3.2 选择结构、3.4 关系与逻辑运算）

**场景来源**：综合实验 C9《水下结构表面压力场分析系统》（水声学院）——本练习是该实验中"测点网格统计"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

测量水下结构表面的压力时，实验人员会把测点布置成一个规则的网格：横向若干列、纵向若干行，每个交叉点测量一个压力值。得到整张网格后，最常做的分析就是统计——总和、平均值、最大压力出现在哪个位置、最小压力又在哪里。这些量构成了后续判断结构受力是否安全的基础。本练习用 3 行 4 列共 12 个测点的网格，把"逐格遍历 + 边读边统计"的嵌套循环流程走一遍。

## 二、任务要求

编写一个完整程序 `grid.c`：

1. 程序固定网格为 **3 行 4 列**（共 12 个测点），从键盘依次读入 12 个实数（double，单位 kPa），**按行优先**顺序输入（先第 1 行 4 个，再第 2 行 4 个，最后第 3 行 4 个）；
2. 用 **外层循环控制行、内层循环控制列**的嵌套 for 循环逐个读入数据，每读入一个就参与统计（**不使用数组**）；
3. 统计四个量：总和 `sum`、平均值 `mean`、最大值及其所在行号列号、最小值及其所在行号列号；
4. 按格式输出统计结果，实数保留 3 位小数。

## 三、输入输出格式

**输入**：一行或多行，共 12 个实数，按行优先顺序排列，数与数之间用空白分隔。

**输出**：四行，格式如下（行号、列号从 1 开始）：

```
sum = 总和
mean = 平均值
max = 最大值 (row r, col c)
min = 最小值 (row r, col c)
```

其中总和、平均值、最大值、最小值均保留 3 位小数。

## 四、样例

**样例 1**

输入：
```
12.5 15.3 11.8 14.2
18.6 22.4 19.1 17.5
9.8 13.2 16.7 20.3
```
输出：
```
sum = 191.400
mean = 15.950
max = 22.400 (row 2, col 2)
min = 9.800 (row 3, col 1)
```

**样例 2**

输入：
```
10.0 20.0 30.0 40.0
50.0 60.0 70.0 80.0
90.0 100.0 5.0 25.0
```
输出：
```
sum = 580.000
mean = 48.333
max = 100.000 (row 3, col 2)
min = 5.000 (row 3, col 3)
```

## 五、提示

嵌套循环的结构是"**外层走一行，内层走这一行的每一列**"：

```c
for (i = 1; i <= 3; i++)          /* 第 i 行 */
    for (j = 1; j <= 4; j++)      /* 第 j 列 */
        /* 读入并处理第 (i, j) 个测点 */
```

内层执行 $3\times 4 = 12$ 次，正好读完 12 个数据。每读一个就累加进 `sum`；第一个数同时作为 `max`、`min` 的初值，之后逐个数比较更新并记下其 `i`、`j`。平均值 $\text{mean} = \dfrac{1}{3\times 4}\displaystyle\sum_{i=1}^{3}\sum_{j=1}^{4} v_{ij}$。

**完成本练习后你将具备的能力**：用嵌套循环遍历二维网格、在"边读入边统计"的模式下求总和/最值并记录坐标——这是实验 C9 中一切网格分析（求和、均值、热点定位）的通用骨架。
