# 题目 A2：基于二分法求解的简支梁最大挠度位置计算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套简支梁弯曲变形分析工具。用户给定梁的跨长、截面尺寸、材料弹性模量与荷载工况（均布荷载、跨中集中荷载及其组合）后，系统按叠加公式实现挠度函数 w(x)，用中心差分近似转角 θ(x)，再以二分法在半跨内求 θ(x) = 0 的根——即最大挠度发生位置，并输出该位置的挠度值；同时对 50 个等间隔截面采样绘制挠度曲线字符图，批量工况结果写入报表文件。

**解决什么重要问题**：梁的挠度与转角是刚度设计的基础：楼盖梁挠度过大会引起开裂、抹灰脱落与舒适度问题，桥梁梁挠度超限影响行车。工程上更关心的是"最大挠度发生在哪里、等于多少"——对均布荷载它在中点，但一旦有多种荷载叠加，最大挠度位置会偏离中点，解析求导后解方程十分繁琐。二分法把"求最大挠度位置"化为"求转角函数零点"，只需反复计算 w(x) 十几次就能得到 1 mm 精度的答案，是数值方法替代解析技巧的典型范例。不掌握这类方法，面对组合荷载、变截面等复杂情况时手算将无法进行。

**支撑哪些关键应用**：① 施工模板支撑与脚手架梁的变形验算；② 吊车梁、楼层次梁的挠度限值校核（规范限值 L/250 等）；③ 结构有限元软件中梁单元刚度与位移求解的思想雏形；④ 后续"材料力学""结构力学"课程中变形计算与"计算方法"课程中方程求根的先导训练。

**与专业培养的关联**：工程力学是航建学院各专业的基础课，本题目把"叠加法求挠度"这一材料力学核心内容与课程 7.6 节二分法直接结合，学生写出的每一行代码都对应力学讲义上的公式，实现"力学公式程序化"，并为后续用数值方法处理超静定、变截面问题建立信心。

## 二、题目任务与专业关联

本题目面向工程力学与土木方向学生，模拟"梁刚度验算"场景。系统功能概述：① 交互录入梁与截面参数；② 从 `load_cases.txt` 批量读入多种荷载工况；③ 实现挠度函数与差分转角函数；④ 对每种工况用二分法求最大挠度位置与数值；⑤ 采样 50 点绘制挠度曲线字符画；⑥ 结果写入 `beam_result.txt`。先导知识铺垫：教师随题发布三条挠度公式（均布 q：w(x)=qx(L³-2Lx²+x³)/(24EI)；跨中集中 P：x≤L/2 时 w(x)=Px(3L²-4x²)/(48EI)，x>L/2 由对称取 w(L-x)；两者叠加即组合工况），以及中心差分公式 θ(x)≈[w(x+h)-w(x-h)]/(2h)，h 取 0.001 m。学生不需任何超出材料力学讲义的推导。

## 三、数据来源与格式

**数据文件：荷载工况表**（`load_cases.txt`）

```
工况号,工况名,跨长L_m,荷载类型1均布2集中3组合,数值1,数值2,EI_kNm2
1,均布满载,6.0,1,12.5,0,24500
2,跨中集中,6.0,2,30.0,0,24500
3,组合工况,6.0,3,10.0,20.0,24500
4,小跨集中,4.0,2,18.0,0,14200
```

字段含义：数值 1 为均布荷载 q（kN/m，取值 2~30）或集中荷载 P（kN，取值 5~80，类型 2/3 时作 P）；数值 2 仅类型 3 使用，为跨中集中荷载 P（kN，取值 5~80）；EI 为抗弯刚度（kN·m²，取值 5000~80000，由 E=200 GPa 与矩形截面 b×h 按 I=bh³/12 预先算好填入）。

**仿真数据生成规则**：
- 生成 6~8 个工况：类型在 1/2/3 中轮换；L 取 3.0/4.0/4.5/6.0/7.5 m；q 与 P 按上述范围取整十或一位小数；EI 由截面表（150×250、200×300、200×400、250×450 mm）计算；
- 异常注入：在工况 5 故意写 `5,错误工况,6.0,4,10,0,24500`（荷载类型越界），在工况 6 把跨长写成 `-4.0`（负数），用于训练读入模块的校验与跳过处理。

**真实数据集**：无必需的公开数据集；截面与荷载取值参照《混凝土结构设计规范》GB 50010 与《钢结构设计标准》GB 50017 的常用梁截面，可在实验报告中注明取值出处。

## 四、数据结构设计

```c
#define MAX_CASE 20       /* 最大工况数 */
#define N_SAMPLE 50       /* 挠度曲线采样点数 */

/* 单个荷载工况 */
struct LoadCase {
    int    id;             /* 工况号 1~99 */
    char   name[24];       /* 工况名，≤23 字符 */
    double L;              /* 跨长 m，取值 2~10，>0 */
    int    type;           /* 荷载类型 1/2/3，越界视为非法 */
    double q;              /* 均布荷载 kN/m，取值 0~30 */
    double P;              /* 跨中集中荷载 kN，取值 0~80 */
    double EI;             /* 抗弯刚度 kN*m2，取值 5000~80000 */
    int    valid;          /* 校验标志 1 有效 0 无效 */
};

/* 单工况求解结果 */
struct SolveResult {
    int    caseId;         /* 对应工况号 */
    double xMax;           /* 最大挠度位置 m，0~L */
    double wMax;           /* 最大挠度 mm，向下为正 */
    int    iterCnt;        /* 二分迭代次数 */
};

/* 全局数据 */
struct LoadCase   g_case[MAX_CASE];
struct SolveResult g_res[MAX_CASE];
int    g_caseCnt;          /* 实际读入工况数 */
int    g_resCnt;           /* 已求解工况数 */
```

辅助全局变量：差分步长 `double g_h = 0.001;`（m）、二分精度 `double g_eps = 1e-6;`（m）、采样数组 `double g_sampleX[N_SAMPLE], g_sampleW[N_SAMPLE];`。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 梁与荷载参数录入模块**（源文件 `ParamInput.c`）

- 功能简介：交互输入单个工况的全部字段（或仅输入默认工况用于快速测试），逐项做范围检查（L>0、type∈{1,2,3}、EI>0），不合法重输；录入结果回显确认。
- 输入：键盘输入的工况参数。
- 输出：一个 `struct LoadCase`（可追加进 `g_case[]`）；屏幕回显。

**M2 荷载工况文件读入模块**（源文件 `CaseIO.c`）

- 功能简介：读入 `load_cases.txt` 首行说明后逐行解析工况；对荷载类型越界、跨长为负的行（即注入的异常）标记 `valid=0` 并打印"第 X 工况数据非法，已跳过"；输出合法工况统计。
- 输入：`load_cases.txt`。
- 输出：`g_case[]`、`g_caseCnt`；屏幕读入与校验摘要。

### 第二部分：算法实现（5 个模块）

**M3 挠度函数实现模块**（源文件 `Deflect.c`）

- 功能简介：实现 `double deflection(double x, const struct LoadCase *pc)`：按 pc->type 分别套用均布、跨中集中公式（x>L/2 用对称性），类型 3 将两项相加；x 越界返回 0；另提供单点自测入口（固定工况打印 5 个截面的挠度，与手算对照）。
- 输入：截面位置 x（m）、工况指针。
- 输出：挠度 w（m，正值向下）。

**M4 转角函数（差分）实现模块**（源文件 `Deflect.c`）

- 功能简介：实现 `double slope(double x, const struct LoadCase *pc)`：调用 M3 两次做中心差分近似转角；处理 x-h<0 与 x+h>L 的边界（改用单侧差分）；提供打印转角表的自测功能。
- 输入：x、工况指针。
- 输出：转角近似值（无量纲弧度，符号反映挠度增减趋势）。

**M5 二分法求根模块**（源文件 `Bisect.c`）

- 功能简介：实现 `double bisect(double a, double b, const struct LoadCase *pc)`：在 (a,b) 内对 slope 函数二分求零点，初值取 a=0.1L、b=0.9L（并先检查两端转角符号相反，否则提示该工况最大挠度在支座端），迭代至区间宽小于 g_eps；记录迭代次数；返回根位置。
- 输入：区间端点、工况指针。
- 输出：最大挠度位置 xMax（m）；迭代次数。

**M6 多工况循环求解模块**（源文件 `SolveAll.c`）

- 功能简介：遍历 `g_case[]` 中 valid 的工况，对每个工况调用 M5 求位置，再调 M3 算该处挠度（换算为 mm），填入 `g_res[]`；打印"工况号-位置-挠度-迭代次数"逐行结果；对无效工况输出"跳过"。
- 输入：`g_case[]`。
- 输出：`g_res[]`、`g_resCnt`；屏幕结果表。

**M7 挠度曲线采样模块**（源文件 `Sample.c`）

- 功能简介：对指定工况在 [0,L] 上等间隔采样 N_SAMPLE=50 点，逐点调用 M3 求挠度存入采样数组；统计曲线最值与采样步长；为字符画准备数据。
- 输入：工况在 `g_case[]` 中的下标。
- 输出：`g_sampleX[]`、`g_sampleW[]`；屏幕采样摘要。

### 第三部分：数据输出（3 个模块）

**M8 挠度曲线字符画模块**（源文件 `CharPlot.c`）

- 功能简介：把 50 点挠度按最大值归一化到 1~40 个 `*`，逐行打印"位置-挠度-条形"三列，挠度向下画在左侧形成倒挂梁的视觉效果；在最大挠度行用 `#` 标注；带标题与比例尺。
- 输入：采样数组。
- 输出：屏幕字符曲线图。

**M9 求解结果报表模块**（源文件 `Report.c`）

- 功能简介：把全部工况的求解表（工况号、名称、L、荷载、xMax、wMax、迭代次数、是否收敛）与挠度限值 L/250 的对比列写入 `beam_result.txt`，超限工况加 `*** 超限` 标记。
- 输入：`g_case[]`、`g_res[]`。
- 输出：`beam_result.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（录入参数 / 读工况文件 / 挠度自测 / 转角自测 / 二分求解单工况 / 全部求解 / 曲线图 / 输出报表 / 退出），`do-while + switch` 调度；状态约束：未读入工况不得求解。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1~M9；状态约束：M3 自测、M5、M6 前必须已有工况数据（M1 或 M2 至少执行其一）；M7、M8 需先指定并求解一个有效工况。

**数据流**：

```
load_cases.txt ─► M2 读入校验 ─► g_case[] ─┐
键盘 ─────────► M1 录入 ──────► g_case[] ─┤
                                           ▼
              M3 挠度函数 ◄── x, 工况 ── M5 二分求根 ─► xMax
                    │                                  │
                    ▼                                  ▼
              M4 差分转角 ─► 零点判断          M6 循环求解 ─► g_res[]
                                                       │
                     M7 采样 g_sampleX/W ─► M8 字符图   │
                                                       ▼
                                            M9 报表 beam_result.txt
```

模块间通过全局结构体数组与函数参数传递数据，`deflection` 与 `slope` 两个函数接口在编码前书面约定，全组共用同一实现。
