本题是 6.1～6.4 四小节的收束题：把"数组、指针、字符串"三种概念组装成一个实用的数据结构。注意 `ps` 是**指针数组**（一维、存 `char *`），不是指向指针的指针——后者属于 6.6，练习 15 才使用。

## 二、预备知识：指针数组的基本原理（零基础阅读）

### 1. 为什么需要"存地址的清单"

一批字符串往往长短不一（`svp_10m.dat` 11 字符、`svp_1000m.dat` 13 字符）。若做成规则的表格 `char buf[5][30]`，每行都是 30 字节，整齐但费空间；更灵活的思路是：**字符串本体各放各的，另立一张清单记录每个字符串的起始地址**——这张"地址清单"就是指针数组：

```c
char *ps[5];    /* ps 是数组；5 个元素，每个元素是 char *（一个字符串的地址） */
```

读声明的口诀：**`[]` 优先级高于 `*`，所以先说"是数组"，再说"元素是指针"**。本题先读入文件名到 `buf[i]`，再让 `ps[i] = buf[i];`，清单即告建成。

### 2. 内存示意（样例 1 的前两项，地址为示意值）

```
buf（字符串本体）                    ps（地址清单）
下标  地址      内容                 下标  值
0     0061FD40  svp_10m.dat'\0'      0     0061FD40  ──指向 buf[0]
1     0061FD60  svp_100m.dat'\0'     1     0061FD60  ──指向 buf[1]
2     0061FD80  svp_500m.dat'\0'     2     0061FD80
3     0061FDA0  svp_1000m.dat'\0'    3     0061FDA0
4     0061FDC0  svp_2000m.dat'\0'    4     0061FDC0
```

注意两层结构：`ps` 本体是 5 个连续的地址格（每格 8 字节）；它指到的地方才是字符。`ps[i]` 是一个 `char *`，因此 `%s`、`my_strlen(ps[i])`、`*(ps[i] + j)` 全部照常可用——**"指针数组元素"的用法与普通字符串指针无异**。

### 3. 遍历指针数组

对清单本身用普通下标遍历即可：

```c
for (i = 0; i < n; i++)
    printf("%d %s %d\n", i + 1, ps[i], my_strlen(ps[i]));
```

`ps[i]` 作为整体传给 `%s` 与 `my_strlen`。也可以借用一个临时指针 `char *p = ps[i];` 再去扫字符，但清单层的循环变量 `i` 不必指针化——**数组走下标、字符串走指针**，两层各司其职，这正是本题想建立的分层观念。

### 4. 求最长与"并列取最前"

最值算法照旧：记 `best`（最长长度）与 `bi`（对应下标），遍历中用**严格大于**更新：

```c
if (len > best) { best = len; bi = i; }
```

严格大于保证并列时先出现者胜（后来的相等者不会覆盖），样例 1 中两个 13 字符的文件名，最终留下序号 4 的 `svp_1000m.dat`。

### 5. 与"字符串常量指针数组"的关系

C 语言里更常见的写法是直接用字符串常量初始化：`char *files[] = {"svp_10m.dat", ...};`——常量字符串的地址被填进指针数组。本题为了让你亲手经历"指向自己输入的数据"，选择了 `buf + ps` 两步走；实验 C1 的正式代码中两种写法都会出现，本质是同一张地址清单。

## 三、解题思路

1. **建表**：读 `n` 后循环读入 `buf[i]`（`scanf("%s", buf[i])`，第 `i` 行首地址），随即 `ps[i] = buf[i];`；
2. **长度**：调用练习 07 的 `my_strlen(ps[i])`；
3. **输出报表**：循环输出 `i+1`、`ps[i]`、长度三列；
4. **最值**：同步或单独一遍循环，`len > best` 时更新 `best` 与 `bi`，最后输出 `ps[bi]`。

## 四、参考代码

```c
#include <stdio.h>

int my_strlen(char *s);    /* 练习 07 的函数 */

int main(void)
{
    char buf[5][30];       /* 字符串本体：5 行，每行至多 29 字符 + '\0' */
    char *ps[5];           /* 指针数组：存 5 个字符串的起始地址 */
    int n, i, len, best = 0, bi = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++)
    {
        scanf("%s", buf[i]);   /* buf[i] 是第 i 行的首地址，不加 & */
        ps[i] = buf[i];        /* 清单登记：ps[i] 指向第 i 个文件名 */
    }

    for (i = 0; i < n; i++)    /* 遍历指针数组输出报表 */
    {
        len = my_strlen(ps[i]);
        printf("%d %s %d\n", i + 1, ps[i], len);
        if (len > best)        /* 严格大于：并列时保留最前 */
        {
            best = len;
            bi = i;
        }
    }

    printf("longest = %s\n", ps[bi]);

    return 0;
}

int my_strlen(char *s)
{
    char *p = s;
    while (*p != '\0')
        p++;
    return (int)(p - s);
}
```

## 六、常见错误与讲解

**错误 1：声明写成"指针的指针"**

```c
char **ps;      /* 这是二级指针，属于 6.6，本题不用 */
char *ps[5];    /* 对：指针数组，5 个 char* 元素 */
```

区分口诀：`[]` 先结合，"数组"先定型。本题声明错成二级指针会在 `ps[i] = buf[i]` 处类型不匹配。

**错误 2：忘记登记指针，`ps` 是野指针清单**

```c
for (i = 0; i < n; i++)
    scanf("%s", buf[i]);
/* 漏掉 ps[i] = buf[i]; —— ps 里全是垃圾地址 */
for (i = 0; i < n; i++)
    printf("%s\n", ps[i]);    /* 崩溃或输出乱码 */
```

数组定义不会自动初始化，**每个 `ps[i]` 必须显式指向有效内存**——这就是练习 01 强调的"指针先赋值再使用"在数组层面的重现。

**错误 3：`scanf("%s", &buf[i])` 或 `scanf("%s", ps[i])` 位置颠倒**

```c
scanf("%s", &buf[i]);   /* 类型为 char(*)[30]，不匹配 %s */
scanf("%s", buf[i]);    /* 对：第 i 行首地址，即 char* */
```

**错误 4：求最值用 `>=`，并列时取了最后一个**

```c
if (len >= best) { best = len; bi = i; }   /* 并列时后者覆盖，违背题意 */
if (len > best)  { best = len; bi = i; }   /* 对：并列保留最前 */
```

比较符差一个等号，结果就违反"并列取序号最前"的规定——读题时这类细节要圈出来。

## 七、与综合实验的衔接

实验 **C1（声速剖面插值）**的文件管理模块按本练习的方式维护各深度档数据文件的名称表，报表输出与列宽自适应直接取自这里的遍历与最值逻辑；实验 B10 的语料清单、C6 的冰块标签表也是同一张"指针数组"骨架。下一节 6.6 的二级指针（练习 14、15）会把这张清单本身也变成"可以传地址的对象"，从而实现函数间整表传递与指针排序；练习 18 的指针版字符串排序则演示"只交换 `ps[i]` 与 `ps[j]` 两个地址、不搬运任何字符"的高效技巧——把今天这张清单的概念彻底吃透，那两题不过是给清单加上"重排"操作而已。
