# 第 4 章 练习 19　模块化冰载荷计算器

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.2 参数传递，4.5 内部函数与模块划分，综合运用第 3 章选择与循环）

**场景来源**：综合实验 C7《冰载荷辨识系统》（水声学院）——本练习是该实验中"冰载荷计算器菜单模块"的实现。

**建议用时**：30 分钟

## 一、应用场景

冰载荷辨识的过程中，工程师需要反复做几件互相关联的小计算：把实测力从 kN 换算成 N、由力与接触面积算应力、拿应力与许用值比较判断安全性。与其每次都临时写一段代码，不如做一个**菜单驱动的小计算器**：程序列出可选的运算，用户输入编号选择，程序调用对应的函数完成计算。这正是"多个函数 + 一个主循环 + 一个分支菜单"的经典组织方式，也是绝大多数工程小工具的结构骨架。

## 二、任务要求

编写一个完整程序 `ice_calc.c`：

1. 编写三个内部函数（均用 `static` 修饰）：
   - `static double calc_stress(double f_kn, double area)`：返回应力（MPa）；先换算 $F(\text{N})=f\_kn\times1000$，再除以面积（mm²）；
   - `static double kn_to_n(double kn)`：返回力（N）；
   - `static int check_safe(double sigma, double allow)`：$\sigma \le \sigma_{\text{allow}}$ 返回 1，否则返回 0；
2. `main` 先用 `printf` 打印一行标题与一行菜单，然后用循环实现菜单：
   - 输入 `1`：再读两个实数，调用 `calc_stress`，输出 `stress = 应力 MPa`（保留 3 位小数）；
   - 输入 `2`：再读一个实数，调用 `kn_to_n`，输出 `force = 力 N`（保留 1 位小数）；
   - 输入 `3`：再读两个实数，调用 `check_safe`，输出 `safe` 或 `over`；
   - 输入 `0`：输出 `exit` 并结束程序；
   - 其它输入：输出 `invalid`；
3. 用 `switch` 实现分支、用 `do-while` 实现循环；
4. **接口约定**：各函数只用参数与返回值通信，不使用全局变量；菜单在程序开始时**只打印一次**。

## 三、输入输出格式

**输入**：若干行。程序先按顺序读菜单选项（整数），若选项为 1 则再读 `f_kn area`、选项为 2 则再读 `kn`、选项为 3 则再读 `sigma allow`，读入 `0` 结束。

**输出**：开头两行固定为标题与菜单；此后每处理一个选项输出一行结果（`stress = ...` / `force = ...` / `safe` 或 `over` / `exit` / `invalid`）。

## 五、提示

- 菜单骨架：用 `do { scanf("%d",&opt); switch(opt){...} } while (opt != 0);`，标题与选项行在循环外打印一次；
- 应力公式：$\sigma = \dfrac{F(\text{N})}{A(\text{mm}^2)}$，因为 $1\ \text{N/mm}^2 = 1\ \text{MPa}$；
- 判定用三目表达式 `return (sigma <= allow) ? 1 : 0;`；
- 输出 `safe` / `over` 可以用 `printf("%s\n", check_safe(sigma, allow) ? "safe" : "over");` 一行完成；
- 注意每个菜单选项**先读自己的参数再计算**，不要把参数一次性全部读入。

**完成本练习后你将具备的能力**：能用"主循环 + `switch` 菜单 + 若干功能函数"组织一个交互式程序、会合理安排每个函数与 `main` 的职责、能处理多种输入情形——这是实验 C7 中"交互式计算模块"的地基。
