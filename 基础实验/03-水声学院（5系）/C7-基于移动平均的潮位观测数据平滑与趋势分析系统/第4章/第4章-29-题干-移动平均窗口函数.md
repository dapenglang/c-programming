# 第 4 章 练习 29　移动平均窗口函数

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：4 函数（4.1 函数定义与调用、4.2 参数传递、4.5 函数在循环中的复用）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"移动平均滤波"环节的最小实现。

**建议用时**：40 分钟

## 一、应用场景

潮位观测常带毛刺：浪涌、船只扰动会让单次读数忽高忽低。要看清潮水的**趋势**，标准做法是**移动平均滤波**：取连续 3 个观测值求平均，作为中间时刻的"平滑值"，然后窗口向后滑动一格，再算下一个——像一个小窗口沿着数据流一路滑过去，把毛刺抹平。

对序列 $x_1, x_2, \ldots, x_n$，三点移动平均定义为（从第 3 个点开始有输出）：

$$y_i = \frac{x_{i-2} + x_{i-1} + x_i}{3}, \qquad i = 3, 4, \ldots, n$$

综合实验 C7 的 M4 模块就是移动平均滤波。本题做它的最小实现：把"算一个窗口的均值"封装成函数，主函数循环滑动窗口。

## 二、任务要求

编写一个完整程序 `movavg.c`：

1. 自定义函数 `double movavg3(double a, double b, double c)`：返回三个数的算术平均 $(a+b+c)/3$；
2. 主函数从键盘读入观测条数 `n`（**题目保证 3 ≤ n ≤ 200**），循环读入 `n` 个潮位（double，m）；
3. 从第 3 个潮位开始，每读入一个新值，调用 `movavg3` 计算"它和它前面两个值"的平均，打印平滑结果；
4. 共输出 $n-2$ 个平滑值（保留 3 位小数）。

**知识边界提示**：本题可使用第 2、3 章全部知识与函数；**禁用数组与指针**——窗口内的 3 个值用 3 个变量 + "滚动接力"保存（见提示）。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 个实数（空格或换行隔开）。

**输出**：共 $n-2$ 行，每行格式 `第i个平滑值=x`（i 从 3 开始计数，x 保留 3 位小数）。

## 四、样例

**样例 1**

输入：
```
8
2.10 2.30 2.60 2.45 2.80 3.10 2.95 3.20
```
输出：
```
第3个平滑值=2.333
第4个平滑值=2.450
第5个平滑值=2.617
第6个平滑值=2.783
第7个平滑值=2.950
第8个平滑值=3.083
```

**样例 2**

输入：
```
3
5.0 5.0 5.0
```
输出：
```
第3个平滑值=5.000
```

## 五、提示

- **不用数组也能"记住"前两个值**——用三个变量滚动接力：

  ```c
  double x1 = 0, x2 = 0, x3;   /* x1 最旧，x3 最新 */
  for (i = 1; i <= n; i++) {
      scanf("%lf", &x3);
      if (i >= 3) {
          printf("第%d个平滑值=%.3f\n", i, movavg3(x1, x2, x3));
      }
      x1 = x2;                 /* 接力：全员向后挪一位 */
      x2 = x3;
  }
  ```
  注意接力必须放在**打印之后**：先算"x1、x2、x3"这个窗口，再滑动；
- 窗口内的三个值是 `movavg3` 的三个**参数**，函数内部只管 `(a+b+c)/3`，不知道也不需要知道这些值从哪来——这就是封装带来的"分工"；
- 想一想：窗口为什么从第 3 个点才有输出？因为第 1、2 个点前面凑不够 3 个值——边界情况靠 `if (i >= 3)` 控制；
- 想一想：如果滤波窗口改成 5 点，滚动接力需要几个变量？程序要改哪几处？

**完成本练习后你将具备的能力**：用"滚动变量"在无数组条件下维护滑动窗口、把窗口运算封装成函数、在循环里反复调用——这些是实验 C7 中"移动平均滤波"模块的地基。
