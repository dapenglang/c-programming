# 题目 A10：基于数值积分的太阳能集热器日得热量计算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套太阳能集热器日得热量计算工具。系统读入某地全天逐时（每小时）太阳辐照度数据文件，录入集热器面积、效率与倾角参数后，先把水平面辐照度按朝向与倾角换算为倾斜面辐照度，逐时计算集热器有效得热功率，再用梯形数值积分把全天功率曲线积分得日得热量；支持东、南、西多朝向批量对比计算、多天数据逐日汇总统计，绘制得热功率曲线字符图并输出报表。

**解决什么重要问题**：太阳能热水系统与光伏系统的容量设计必须知道"一套集热器一天到底能收多少热量"，它决定水箱容积、集热面积与辅助热源配置。而太阳辐照度在一天内先升后降呈钟形曲线，气象站只提供逐时离散数据，把功率曲线下的面积加起来必须用数值积分；同时集热面朝向与倾角不同接收的辐照差异巨大（冬季南向倾斜面可比水平面多收 40%），不进行朝向对比就会选错安装方案。若得热量估算失准，系统冬季热水不足、夏季过热，直接造成工程返工。

**支撑哪些关键应用**：① 太阳能热水工程中集热面积与水箱容积的匹配计算；② 光伏电站发电量的初步估算（辐照×面积×效率同构）；③ 《民用建筑太阳能热水系统应用技术标准》中得热量指标的核算；④ 后续"传热学""太阳能利用技术""建筑节能"课程中辐射计算与能量平衡分析的入门训练。

**与专业培养的关联**：建筑环境与能源应用工程专业把太阳能利用作为新能源方向核心内容。本题目把课程 3.5 节梯形数值积分、逐时数据文件处理与多方案对比统计组合成完整的能量计算流程，学生处理的正是气象数据表的真实结构，形成"逐时数据 → 功率曲线 → 积分得能量"的计算范式。

## 二、题目任务与专业关联

本题目面向建筑环境与能源应用工程方向学生，模拟"集热器方案得热量核算"场景。系统功能概述：① 读入逐时辐照度文件（可多天）；② 录入集热器参数；③ 按简化系数把水平面辐照换算为倾斜面辐照；④ 逐时计算有效得热功率；⑤ 梯形积分求日得热量；⑥ 多朝向（东/南/西）批量重算对比；⑦ 多天逐日统计报表；⑧ 功率曲线字符图与结果文件输出。先导知识铺垫：换算式 I_tilt=I_hori·K（K 为朝向-倾角综合修正系数，由文件给出：南向倾角 40° 冬季 1.40、夏季 0.95，东/西向 1.00）；有效得热功率 P=I_tilt·A·η/1000（kW）；日得热量 Q=∫P dt，用逐时梯形积分 Σ(P_i+P_{i+1})·Δt/2 求得。全部算法不超过课程内容。

## 三、数据来源与格式

**数据文件：逐时辐照度数据**（`irradiance.txt`，可含多天）

```
日期序号,时刻h,水平面辐照度W/m2
1,6,10
1,7,80
1,8,210
1,9,380
1,10,540
1,11,650
1,12,700
1,13,660
```

字段含义：日期序号 1～7（一周逐日）；时刻取 6～19 整点（小时）；水平面辐照度取值 0～1000 W/m²，日出日落时刻接近 0，正午最大。

**仿真数据生成规则**：
- 单日辐照用钟形曲线生成：I(h)=I_max·sin(π(h-6)/13)，I_max 在 550～750 W/m² 内按天变化（晴天 700、多云 420、阴天 180，一周内穿插），四舍五入到整数；
- 时刻固定 6～19 共 14 行/天，生成 5～7 天；
- 修正系数文件 `tilt_coef.txt`：`南向,1.40`、`东向,1.00`、`西向,1.00`、`水平,1.00`（固定 4 行）；
- 异常注入：在 `irradiance.txt` 中故意写 `3,12,1500`（超物理上限的坏点）、`4,9,-60`（符号错误的负值），并在第 5 天故意漏掉 `5,14` 行（缺时刻），用于训练读入模块的范围校验、负值修正与缺失时刻补 0 处理。

**真实数据集**：美国 NASA POWER 气象数据（https://power.larc.nasa.gov/ ）与中国气象数据网（http://data.cma.cn/ ）提供逐时辐照数据，可下载哈尔滨站点数据替换仿真数据（选做）；课程实验以仿真数据为准。

## 四、数据结构设计

```c
#define MAX_HOUR  24       /* 每天最多小时记录数 */
#define MAX_DAY   10       /* 最多天数 */
#define MAX_REC   240      /* 逐时记录总数上限 */

/* 逐时辐照记录 */
struct Irradiance {
    int    day;            /* 日期序号 1~7 */
    int    hour;           /* 时刻 6~19 整点 */
    double ih;             /* 水平面辐照度 W/m2，0~1000 */
    int    valid;          /* 校验标志（坏点置 0 后按 0 补记） */
};

/* 集热器参数（M2 录入） */
struct Collector {
    double area;           /* 采光面积 m2，取值 1~100 */
    double eta;            /* 集热效率，取值 0.30~0.70 */
    int    orient;         /* 朝向代码 1 南 2 东 3 西 4 水平 */
    double tilt;           /* 倾角 度，0~90（仅用于显示） */
};

/* 单日计算结果 */
struct DayResult {
    int    day;            /* 日期序号 */
    double qDay;           /* 日得热量 kWh */
    double pMax;           /* 峰值功率 kW */
    int    hPeak;          /* 峰值出现时刻 h */
    int    recCnt;         /* 当日有效记录数 */
};

/* 全局数据 */
struct Irradiance g_irr[MAX_REC];
struct Collector  g_col;
struct DayResult  g_day[MAX_DAY];
int    g_recCnt;           /* 读入记录数 */
int    g_dayCnt;           /* 天数 */
double g_kCoef;            /* 当前朝向修正系数 */
```

各时刻倾斜面辐照与得热功率用全局一维数组 `double g_tiltI[MAX_HOUR], g_power[MAX_HOUR];` 按当日记录顺序存放，供积分与绘图共用。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 逐时辐射数据文件读入模块**（源文件 `IrradIO.c`）

- 功能简介：跳过表头逐行读入"日期,时刻,辐照度"；校验辐照 0～1000 W/m²，对坏点 1500 截断到上限并告警、对负值 -60 取 0 并告警；检测每日期序号内时刻是否完整（缺行按辐照 0 补记，如第 5 天缺 14 时）；统计天数与记录数。
- 输入：`irradiance.txt`。
- 输出：`g_irr[]`、`g_recCnt`、`g_dayCnt`；屏幕读入与校验摘要。

**M2 集热器参数录入模块**（源文件 `ParamInput.c`）

- 功能简介：交互录入采光面积、集热效率、倾角与朝向代码；读入 `tilt_coef.txt` 并按朝向查得修正系数；逐项范围检查；回显参数与 K 值。
- 输入：键盘参数、`tilt_coef.txt`。
- 输出：`g_col`、`g_kCoef`；屏幕回显。

### 第二部分：算法实现（4 个模块）

**M3 倾斜面辐射转换模块**（源文件 `TiltConv.c`）

- 功能简介：对当日逐条记录计算 I_tilt=I_hori·g_kCoef 存入 `g_tiltI[]`；打印逐时"水平面-倾斜面"对照表；统计倾斜面日辐照总量（简单累加，作为换算效果的量化）。
- 输入：当日 `g_irr[]`、`g_kCoef`。
- 输出：`g_tiltI[]`；屏幕对照表。

**M4 有效得热功率计算模块**（源文件 `Power.c`）

- 功能简介：逐时计算 P=I_tilt·A·η/1000（kW）存入 `g_power[]`；查找峰值功率及其时刻；夜间与零辐照时段功率按 0 处理；打印功率表。
- 输入：`g_tiltI[]`、`g_col`。
- 输出：`g_power[]`、峰值与峰值时刻。

**M5 梯形积分累加模块**（源文件 `Trapezoid.c`）

- 功能简介：对当日 `g_power[]` 按相邻时刻梯形面积累加：Q=Σ(P_i+P_{i+1})·(t_{i+1}-t_i)/2，得日得热量（kWh）；处理缺时刻行的时间间隔（按实际小时差）；提供仅 2 个时间点的积分自测（如恒定 5 kW 走 3 小时应得 15 kWh）。
- 输入：`g_power[]`、时刻数组。
- 输出：当日 `qDay`（写入 `g_day[]`）；自测结果。

**M6 多朝向对比计算模块**（源文件 `Compare.c`）

- 功能简介：对当前选定日期，依次把朝向换成南/东/西/水平（每次重读 K 值后顺序调用 M3、M4、M5），输出四朝向"日得热量-峰值功率"对比表与最优朝向结论。
- 输入：`g_col`、选定日期数据。
- 输出：屏幕四朝向对比表。

### 第三部分：数据输出（4 个模块）

**M7 得热功率曲线字符画模块**（源文件 `CharPlot.c`）

- 功能简介：以时刻为横轴、功率归一化为 1～40 字符条形，绘制当日功率曲线，峰值行用 `#` 标注；可选同图叠加水平面功率曲线（用另一种字符）对比换算效果。
- 输入：`g_power[]`。
- 输出：屏幕字符曲线。

**M8 逐日统计报表模块**（源文件 `DailyStat.c`）

- 功能简介：对所有日期循环执行 M3、M4、M5，生成"日期-日得热量-峰值功率-峰值时刻"逐日汇总表；统计一周总得热量、平均日得热量与最好/最差天气日；打印统计结论。
- 输入：`g_irr[]`、`g_col`。
- 输出：`g_day[]`；屏幕逐日统计表。

**M9 结果文件输出模块**（源文件 `Report.c`）

- 功能简介：把集热器参数、逐时换算与功率表（选定日期）、多朝向对比、逐日汇总与周期统计写入 `solar_report.txt`。
- 输入：全部全局数据。
- 输出：`solar_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读辐照数据 / 录入参数 / 换算 / 功率计算 / 日积分 / 多朝向对比 / 功率曲线 / 逐日统计 / 输出报表 / 退出），`do-while + switch` 调度；状态约束：未读数据与参数不得计算。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1～M9；状态约束：M3 前必须完成 M1、M2；M6、M8 内部循环调用 M3～M5；M9 汇总输出。

**数据流**：

```
irradiance.txt ─► M1 读入校验补缺 ─► g_irr[]
tilt_coef.txt ──► M2 查系数 ─► g_col / g_kCoef
                                     │
                M3 倾斜面换算 ─► g_tiltI[] ─► M4 功率计算 ─► g_power[]
                                                                │
                              M5 梯形积分 ─► g_day[].qDay ◄─────┘
                                     │
                M6 多朝向对比（循环 M3~M5）
                M8 逐日统计（循环 M3~M5）
                                     │
                M7 功率曲线字符图        M9 报表 solar_report.txt
```

模块间通过全局逐时数组 `g_tiltI[]/g_power[]` 与日结果结构体数组交换数据，换算、功率、积分三个函数接口编码前书面约定。

## 十、选做扩展

1. 效率随辐照变化实验：把常数效率改为分段效率（辐照 <300 W/m² 取 0.35、≥300 取 0.55），重算日得热量并对比常数效率结果，量化低辐照时段损失（分段函数 + 复用模块）；
2. 多倾角对比：把南向 K 值按倾角 20°/40°/60° 三档（在 tilt_coef.txt 中加行）分别完整计算，输出日得热量随倾角变化表，讨论当地最佳倾角（查表参数化 + 循环）；
3. 集热面积优选：给定日均热水需求（如 500 L，温升 35 ℃ 需热量按定值比热计算），用一周日均得热量反算所需最小集热面积并与现有 20 m² 对比（除法与统计的组合运用）。
