# 第 2 章 练习 35　噪声级单位换算

**所属综合实验**：C9（C9-基于分区间统计的海洋环境噪声等级评估系统）

**对应章节**：2 常量、变量与数据类型；2.x 运算符与表达式；2.x 格式化输入输出

**场景来源**：综合实验 C9《基于分区间统计的海洋环境噪声等级评估系统》（水声学院）——本练习是该实验中"噪声级单位换算与校准"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

水声工程中，海洋环境噪声的强弱用**声压级**表示，单位分贝（dB）。但"0 dB 对应多大声压"有三种常见基准，初学者极易混淆：

- **re 1 μPa**：水声行业标准（1 微帕）；
- **re 1 mPa**：某些文献采用（1 毫帕 = 1000 μPa）；
- **re 1 Pa**：空气声学与部分教材采用（1 帕 = $10^6$ μPa）。

同一个噪声场，换基准后数值差一个**固定常数**：基准每放大 10 倍，声压级减 $20\lg 10 = 20$ dB。因此 re 1 μPa 的声压级换到 re 1 mPa 要**减 60 dB**，换到 re 1 Pa 要**减 120 dB**。

此外，测量仪器出厂时都带一个**校准偏置** $C$（dB），读数需扣除修正。综合实验 C9 在正式分箱统计之前，要先完成这道"换算 + 校准"的预处理。本题就用**纯乘加运算**（只减常数）完成它。

## 二、任务要求

编写一个完整程序 `nl_convert.c`：

1. 定义符号常量：`#define C_UMPAMPA 60.0`、`#define C_UMPAPA 120.0`（两个换算常数）；
2. 从键盘读入两个 double：仪器读得的声压级 `L`（dB re 1 μPa）、校准偏置 `C`（dB，读数偏大则为正）；
3. 计算校准后的声压级 $L_c = L - C$；
4. 计算换算值：$L_{mPa} = L_c - C_{UMPAMPA}$，$L_{Pa} = L_c - C_{UMPAPA}$；
5. 按样例格式输出三行结果，均保留 2 位小数。

**注意**：本题只做顺序计算，不允许使用 `if`、循环和函数，公式里**只允许减法**（换算常数已用 `#define` 给定，不需要对数运算）。

## 三、输入输出格式

**输入**：一行两个实数，用空格分隔：`L C`。

**输出**：三行：

- 第一行：`calibrated = <Lc> dB re 1uPa`；
- 第二行：`re 1mPa = <LmPa> dB re 1mPa`；
- 第三行：`re 1Pa = <LPa> dB re 1Pa`。

均保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
142.5 1.5
```
输出：
```
calibrated = 141.00 dB re 1uPa
re 1mPa = 81.00 dB re 1mPa
re 1Pa = 21.00 dB re 1Pa
```

**样例 2**

输入：
```
128.0 0.0
```
输出：
```
calibrated = 128.00 dB re 1uPa
re 1mPa = 68.00 dB re 1mPa
re 1Pa = 8.00 dB re 1Pa
```

## 五、提示

- 换算关系来源：$20\lg\dfrac{10^6\ \mu Pa}{1\ Pa} = 120$ dB、$20\lg\dfrac{10^3\ \mu Pa}{1\ mPa} = 60$ dB——对数部分课本已算好，本题只需做减法；
- 三行输出的文字部分（含 `re 1uPa` 等）必须与样例**逐字符一致**，包括空格；
- 校准偏置 `C` 可能为 0（样例 2），减去 0 不出错，这正是"统一公式、不特判"的好处；
- 想一想：为什么换算方向是"减"而不是"加"？（基准声压越大，同样的物理声压对应的 dB 数越小。）

**完成本练习后你将具备的能力**：用符号常量封装工程常数、按"校准 → 换算"的顺序组织乘加表达式——这是 C9 实验数据预处理模块的最小单元。
