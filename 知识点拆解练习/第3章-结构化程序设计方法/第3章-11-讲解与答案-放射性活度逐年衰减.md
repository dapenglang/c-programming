## 二、预备知识：循环迭代（累乘）的基本原理（零基础阅读）

### 1. 问题是怎么来的

科学家发现：放射性核素每经过一年，就固定损失掉"当前活度的 $p\%$"。注意这里的关键词是**当前**——第二年衰减的是第一年末剩下的活度，而不是初始活度。所以第 3 年的活度，必须建立在第 2 年结果的基础上，一步一步地算出来。这种"后一步依赖前一步"的计算，无法用一条算术表达式一次写完，只能用**循环**实现。

### 2. 方法是怎么想出来的

把每年发生的事写成一个式子。设第 $k-1$ 年末活度为 $A_{k-1}$，这一年损失了它的 $p\%$，剩下的是原来的 $(1-p/100)$ 倍，于是

$$
A_k = A_{k-1}\left(1 - \frac{p}{100}\right)
$$

把这个式子从 $k=1$ 依次写到 $k=n$，每写一次就用上一次的结果，得到

$$
A_1 = A_0\,r,\quad A_2 = A_1\,r = A_0\,r^{2},\quad \dots,\quad A_n = A_0\,r^{n},
\qquad r = 1 - \frac{p}{100}
$$

可见**逐年递推**与**闭式连乘**结果完全相同。程序里不必真的去写"幂运算"，只要让同一个变量 `A` 在循环里不断"乘 $r$ 再存回自己"，循环 n 次后它自然就是 $A_0 r^n$。

### 3. 用本例走一遍

取样例 1：$A_0 = 1000$，$p = 10$，则 $r = 1 - 0.10 = 0.90$。

- 第 1 年：$A_1 = 1000 \times 0.90 = 900.000$；
- 第 2 年：$A_2 = 900 \times 0.90 = 810.000$；
- 第 3 年：$A_3 = 810 \times 0.90 = 729.000$。

再核验闭式：$1000 \times 0.9^{3} = 1000 \times 0.729 = 729.000$，两种算法一致，说明递推正确。

### 4. 编程时怎么用它

编程三步走：**① 循环前**把 $A_0$ 读进变量 `A`；**② 循环体**只写一条 `A = A * (1.0 - p / 100.0);`，紧接着输出本年末活度；**③ 循环控制**用 `for (k = 1; k <= n; k++)`，循环 n 次后自动结束。要点是：**赋值号右边的 `A` 是"旧值"，左边的 `A` 是"新值"**，这一行语句完成了一次"自我更新"。循环控制变量 `k` 同时用作输出里的年份。

## 三、解题思路

1. **确定变量**：`A0`、`p` 是实数用 `double`，`n` 与循环变量 `k` 是整数用 `int`；工作变量 `A` 用 `double`，初值等于 `A0`；
2. **先读入**：`scanf("%lf %lf %d", &A0, &p, &n);`，注意 3 个格式符与 3 个地址一一对应；
3. **算衰减因子**：`double r = 1.0 - p / 100.0;` 单独算好，循环里只乘 `r`，减少重复运算，也让代码更清晰；
4. **循环累乘**：for 循环从 1 到 n，每次 `A = A * r;` 后立刻 `printf("year %d: %.3f Bq\n", k, A);`；
5. **收尾输出**：循环结束后 `printf("final activity = %.3f Bq\n", A);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double A0;          /* 初始活度，Bq */
    double p;           /* 年衰减率，% */
    int    n;           /* 衰减年限 */
    double A;           /* 当前活度（工作变量，逐年在变） */
    double r;           /* 每年的保留比例 1 - p/100 */
    int    k;           /* 年份计数 */

    /* 读入三个量：初始活度、年衰减率、年限 */
    scanf("%lf %lf %d", &A0, &p, &n);

    r = 1.0 - p / 100.0;   /* 计算每年保留比例 */
    A = A0;                /* 活度从初始值开始 */

    /* 循环 n 次，每轮衰减一年并输出该年末活度 */
    for (k = 1; k <= n; k++) {
        A = A * r;                                /* 累乘：本年末 = 上年末 x r */
        printf("year %d: %.3f Bq\n", k, A);
    }

    /* 输出最终结果 */
    printf("final activity = %.3f Bq\n", A);

    return 0;
}
```

## 五、运行验证

| 输入 | 逐年手算过程 | 程序输出 |
|---|---|---|
| 1000 10 3 | 1000→900→810→729，r = 0.90 | `year 1: 900.000 Bq` / `year 2: 810.000 Bq` / `year 3: 729.000 Bq` / `final activity = 729.000 Bq` ✓ |
| 5000 20 4 | 5000→4000→3200→2560→2048，r = 0.80 | `year 1: 4000.000 Bq` / `year 2: 3200.000 Bq` / `year 3: 2560.000 Bq` / `year 4: 2048.000 Bq` / `final activity = 2048.000 Bq` ✓ |
| 1000 0 2 | r = 1.00，活度保持不变 | `year 1: 1000.000 Bq` / `year 2: 1000.000 Bq` / `final activity = 1000.000 Bq` ✓ |
| 1000 100 1 | r = 0.00，一年后归零 | `year 1: 0.000 Bq` / `final activity = 0.000 Bq` ✓ |

样例 2 恰好是 $5000 \times 0.8^{4}$，结果 2048.000，与闭式完全吻合。

## 六、常见错误与讲解

**错误 1：衰减率当作小数直接相乘**

```c
A = A * (1.0 - p);        /* 错：p = 10 时写成 1-10 = -9，活度变成负数 */
A = A * (1.0 - p / 100.0); /* 对：先把百分数化成小数 */
```

单位是"%"就一定要除以 100，这是物理量换算里最常见的失误。

**错误 2：循环忘写大括号，只重复了半句话**

```c
for (k = 1; k <= n; k++)
    A = A * r;                          /* 只有这一句在循环里 */
    printf("year %d: %.3f Bq\n", k, A); /* 这句只执行一次，k 已越界 */
```

正确做法是用一对 `{}` 把"更新 + 输出"两句都括进循环体。

**错误 3：循环次数写错（差一个）**

```c
for (k = 0; k < n; k++)    /* 从 0 数到 n-1，也是 n 次，但年份会从 0 开始 */
for (k = 1; k <= n; k++)   /* 本题推荐：年份 k 正好是 1..n，与输出一致 */
```

两种都循环 n 次，但本题输出的"年份"要与循环变量对应，用 `k = 1; k <= n` 最直观。

**错误 4：输出格式符与变量类型不匹配**

```c
printf("year %d: %d Bq\n", k, A);     /* 错：A 是 double，用 %d 输出得到乱码 */
printf("year %d: %.3f Bq\n", k, A);   /* 对：%.3f 表示保留 3 位小数 */
```

## 七、与综合实验的衔接

- 在实验 **D1（放射性核素活度衰变计算）**中，"逐年活度表"是本练习的直接放大：衰减率可能由半衰期换算而来，输出还要判断活度是否低于某个控制水平（这就需要第 3.2 节的选择结构）；
- 本练习的真正价值在于建立"**循环迭代**"的思维模型：一个变量在循环里不断用旧值算新值。下一题"二分法求平方根"、再后面的"不动点迭代"以及蒙特卡洛投点，都是这一模型的变体——只不过更新的对象从"活度"换成了"区间中点"或"猜测值"。把这一题的循环骨架吃透，后面几题就只是换公式而已。
