# 第 4 章 练习 31　递归计算等比衰减和

**所属综合实验**：C4（C4-基于短时能量与阈值判决的脉冲信号端点检测系统）

**对应章节**：4 函数（4.6 递归调用、递归出口与递推关系）

**场景来源**：综合实验 C4《基于短时能量与阈值判决的脉冲信号端点检测系统》（水声学院）——本练习是该实验中"脉冲余晖能量估计"环节的简化实现。

**建议用时**：40 分钟

## 一、应用场景

声呐发出一个脉冲后，脉冲能量在介质中逐段衰减：每传过一段路程，剩余能量乘以衰减因子 $r$（$0 < r < 1$）。若初始能量为 $a$，前 $n$ 段的累计能量为**等比衰减和**：

$$S_n = a + ar + ar^2 + \cdots + ar^{n-1} = \sum_{k=0}^{n-1} a\,r^k$$

端点检测系统估计"脉冲余晖还能拖多长"时就要算这个和。这个求和天生是**递归**的形状：$n$ 项的和 = 首项 $a$ 加上"剩下 $n-1$ 项、但每项都多乘了一个 $r$"的和——

$$S_n = a + r \cdot S_{n-1}, \qquad S_0 = 0$$

综合实验 C4 的能量估计环节里就有这种"逐段衰减、逐段累加"的递推结构。本题用**递归函数**实现它。

## 二、任务要求

编写一个完整程序 `geo_sum.c`：

1. 自定义**递归**函数 `double decaySum(double a, double r, int n)`：返回 $S_n = a + r \cdot S_{n-1}$，递归出口为 $S_0 = 0$；
2. 主函数读入三个数：初始能量 `a`（double）、衰减因子 `r`（double，题目保证 $0 < r < 1$）、段数 `n`（**题目保证 1 ≤ n ≤ 30**）；
3. 调用递归函数求和并打印结果（保留 2 位小数）；
4. 程序**不得使用循环**、不得调用 `pow` 等幂函数——累加必须完全由递归完成。

**知识边界提示**：本题可使用第 2、3 章全部知识与函数；**禁用数组与指针**；递归的每一层只做"乘一次、加一次"。

## 三、输入输出格式

**输入**：一行三个数 a、r、n（a、r 为实数，n 为整数）。

**输出**：一行 `前n段累计能量=x`（x 保留 2 位小数）。

## 四、样例

**样例 1**

输入：
```
100 0.8 5
```
输出：
```
前5段累计能量=336.16
```

（手算：$100(1+0.8+0.64+0.512+0.4096) = 100 \times 3.3616 = 336.16$。）

**样例 2**

输入：
```
50 0.5 1
```
输出：
```
前1段累计能量=50.00
```

**样例 3**

输入：
```
100 0.8 30
```
输出：
```
前30段累计能量=499.38
```

（衰减因子小于 1 时，和收敛于几何级数极限 $a/(1-r) = 100/0.2 = 500.00$——n 越大越接近 500，可自检验证。）

## 五、提示

- **递归两要素**：①递归出口（最简单的情况直接给答案）：`if (n == 0) return 0.0;`；②递推关系（把大问题化成小问题）：`return a + r * decaySum(a, r, n - 1);`
- 展开验证递推关系：$S_n = a + r(a + r(\cdots)) = a + ar + ar^2 + \cdots$——每往里一层，多乘一个 $r$、多加一个 $a$；
- **递归是"去程算、回程收"**：调用 `decaySum(100, 0.8, 5)` 会一层层递下去到 `decaySum(..., 0)` 返回 0，然后回程逐层做 `a + r * 子结果`，最外层拿到 336.16；
- 想一想：出口为什么是 `n == 0` 而不是 `n == 1`？两个都行，但 $S_0 = 0$ 是数学上自然的空和，边界更干净；若用 `n == 1` 出口，`decaySum(..., 0)` 会一层层递到负数，**永不停止**（栈溢出）；
- 想一想：把出口改成 `n < 0` 之外的任意条件试试——出口必须保证**有限步内必然到达**。

**完成本练习后你将具备的能力**：识别问题的递归结构、设计递归出口与递推关系、用递归函数实现数学级数——这些是实验 C4 中"逐段衰减能量累加"环节的地基，也是第 4 章函数知识的收官。
