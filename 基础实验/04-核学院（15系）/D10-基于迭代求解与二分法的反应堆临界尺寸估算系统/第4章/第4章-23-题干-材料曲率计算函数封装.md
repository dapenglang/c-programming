# 第 4 章 练习 23　材料曲率计算函数封装

**所属综合实验**：D10（D10-基于迭代求解与二分法的反应堆临界尺寸估算系统）

**对应章节**：4 函数与模块化程序设计（4.1 函数的定义、声明与调用、4.2 参数传递与返回值、4.3 变量的存储属性与作用域、4.4 模块化设计）

**场景来源**：综合实验 D10《基于迭代求解与二分法的反应堆临界尺寸估算系统》（核学院）——本练习是该实验中"材料曲率计算模块"的接口封装，供整条求根链路反复调用。

**建议用时**：25 分钟

## 一、应用场景

在综合实验 D10 里，材料曲率

$$
B_m^2 = \frac{k-1}{L^2}
$$

要被算非常多次：二分法每一次迭代都要用它跟几何曲率比较，参数扫描时对每一组 $(k, L)$ 都要算一遍。如果每处都手写一遍 `(k - 1.0) / (L * L)`，代码会重复、容易写错，将来若要改成"多群修正"还要逐处修改。

正确的做法是**封装成一个函数**，把"输入 $k$ 和 $L$、输出 $B_m^2$"独立成一个小模块：

```c
double matCurv(double k, double L);
```

全程序需要材料曲率的地方都调用 `matCurv`，公式只写一次、只维护一处。本题实现这个**函数接口约定**。

## 二、任务要求

编写一个完整程序 `matcurv_func.c`：

1. 定义函数 `double matCurv(double k, double L)`，功能是返回材料曲率 $(k-1)/L^2$（单位 $\text{cm}^{-2}$）；
2. 在 `main` 函数中调用它，完成下面的计算流程：先读入增殖因子 `k` 和扩散长度 `L`（都是 double，**题目保证 1.05 ≤ k ≤ 1.5、2 ≤ L ≤ 10**），再调用 `matCurv` 求材料曲率，最后输出结果（保留 6 位小数）；
3. 函数 `matCurv` 中不得使用任何输入输出语句——它只负责**计算并返回结果**，输入输出一律留给 `main`（这是模块化设计的基本纪律）；
4. 在 `main` 上方为 `matCurv` 写函数声明（原型），说明它的接口。

## 三、输入输出格式

**输入**：一行，两个实数，依次为增殖因子 k 和扩散长度 L（cm），用空格分隔。

**输出**：一行，按格式 `Bm2 = 结果` 输出，结果保留 6 位小数。

## 四、样例

**样例 1**

输入：
```
1.20 5.0
```
输出：
```
Bm2 = 0.008000
```

**样例 2**

输入：
```
1.50 4.0
```
输出：
```
Bm2 = 0.031250
```

## 五、提示

- 函数定义的三要素：**返回类型**（double）、**函数名**（`matCurv`）、**参数表**（`double k, double L`）；
- 函数体只有一句 `return (k - 1.0) / (L * L);`，形成"输入参数 → 一步计算 → 返回值"的清晰结构；
- 调用处写成 `Bm2 = matCurv(k, L);`——实参按**位置**依次传给形参 `k`、`L`；
- 形参名与 `main` 中的实参变量名相同是允许的（它们彼此独立，详见讲解）；
- 平方用乘法 `L * L`，**不能用 `^`**；求和与减法的括号不能省；
- 为将来升级留空间：如果以后要把单群模型换成含反射层的修正，只需改 `matCurv` 一个地方——**这正是模块化的价值**。

**完成本练习后你将具备的能力**：定义带返回值的函数、声明函数原型、完成参数传递与返回值接收、把一段物理公式封装成可复用的模块——这些是实验 D10 中"计算模块封装"的地基。
