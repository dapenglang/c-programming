# 题目 C5：基于蒙特卡洛模拟的声呐检测概率估算系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行声呐检测概率估算工具。它读入声呐方程参数（声源级、目标强度、噪声级、指向性指数、检测门限）与一张"距离—传播损失"表，逐距离计算回波信噪比；在每一距离上重复进行 N 次"随机判决"——把噪声当作随机量叠加到回波上，按检测门限判定本次是否检测到目标，用检测成功的次数除以总次数得到该距离的检测概率；进而扫描全部距离得到"检测概率—距离"曲线，并做不同门限的对比实验。

**解决什么重要问题**：实际声呐面对的噪声是随机的，同一目标在同一距离上，这一次可能检测到、下一次可能漏检，所以"能不能检测到"本质上是一个概率问题，而不是"是或否"。如果只按信噪比是否大于某个值来下结论，就无法回答"在 20 km 处检测成功的把握有多大""要达到 90% 的检测概率，作用距离是多少"这类真正的工程问题。本系统通过大量随机试验统计频率来估计检测概率，正是最直观、最不需要额外理论的方法。

**支撑哪些关键应用**：① 声呐作用距离预报与检测性能评估；② 检测门限的选取与优化（门限高则虚警少但漏检多，门限低则相反）；③ 不同水文条件下的系统性能比较；④ 作战辅助决策中的可探测性判断；⑤ 水声通信链路可靠性的概率评估。

**与专业培养的关联**：水声工程、声学专业的《声呐技术》《水声信号检测》课程都涉及检测概率与作用距离的关系。本题让学生用 C 语言实现"随机抽样—判决—统计频率"的蒙特卡洛流程，建立"检测是概率事件、概率可用大量试验统计"的直觉，全程只用随机数、计数与比较，不需要任何统计理论先修。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述检测概率估算系统，完成"参数录入→损失表读入→信噪比计算→随机判决→概率统计→曲线输出"的完整流程。具体任务包括：交互录入声呐方程各参数与检测门限；读入"距离—传播损失"表；逐距离计算回波信噪比；实现单次检测的随机判决；对每一距离重复 N 次模拟并统计检测频率；扫描全部距离批量估算检测概率；绘制检测概率—距离曲线字符画；对多个门限做对比实验；输出模拟报告；用菜单调度全部功能。

本题对应水声专业"用蒙特卡洛方法评估系统性能"的能力，学生在此过程中练熟随机数使用、循环累加、计数统计与多列数据输出。

## 三、数据来源与格式

**数据文件格式**：采用纯文本格式，第 1 行为格式标识，第 2 行为表格行数，其后每行为"距离 传播损失"。用 `fscanf(fp, "%lf", ...)` 循环读入即可。

```
TLTABLE
5
1000    60.0
2000    66.0
5000    74.0
10000   80.0
20000   86.0
```

字段含义：第 1 行 `TLTABLE` 为格式标识；第 2 行为表行数 `5`；其后每行为"距离(m) 传播损失(dB)"。距离按升序排列，传播损失可用题目 C3 的估算法产生，也可由教师直接给出。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 距离 r | m | 500~50000 | 按升序取 5~20 个点，可为等间隔或近似等比 |
| 传播损失 TL | dB | 55~110 | 由球面扩展 20·lg r 加吸收项合成后叠加 ±1 dB 随机扰动 |
| 声源级 SL | dB | 180~230 | 交互录入，典型 200 |
| 目标强度 TS | dB | −40~0 | 交互录入，典型 −10 |
| 噪声级 NL | dB | 50~90 | 交互录入，典型 70 |
| 指向性指数 DI | dB | 0~30 | 交互录入，典型 20 |
| 检测门限 DT | — | 0.1~0.9 | 交互录入，归一化幅度门限，典型 0.5 |
| 模拟次数 N | 次 | 1000~100000 | 交互录入，典型 10000 |
| 随机种子 | — | 1~99999 | 交互录入，保证结果可复现 |

**异常值与噪声注入方式**：① 在"距离—传播损失"表中随机插入 1 行传播损失比前一行更小的倒挂行（不符合单调衰减），用于检验 M2 的合理性检查；② 随机令 1 个距离值 ≤ 0，用于检验读入模块的边界保护；③ 单次判决中的噪声由 `rand()` 生成的均匀随机数按"12 个均匀数之和减 6"近似成零均值随机量，属课程内的随机模拟，不使用正态函数库。

**真实数据集（如有）**：
- 声呐方程各参数取自水声教材的典型工况，无需外部下载；
- 距离—传播损失表由题目 C3 的估算法生成，或由教师提供的实测/仿真表为准。

## 四、数据结构设计

```c
#define MAX_DIST 128           /* 最大距离点数 */

/* 声呐方程参数 */
typedef struct {
    double SL;                 /* 声源级，单位 dB re 1uPa@1m，180~230 */
    double TS;                 /* 目标强度，单位 dB，−40~0 */
    double NL;                 /* 噪声级，单位 dB，50~90 */
    double DI;                 /* 指向性指数，单位 dB，0~30 */
    double DT;                 /* 检测门限，归一化幅度，0.1~0.9 */
    int    nSim;               /* 每距离的模拟次数，1000~100000 */
} SonarSetup;

/* 距离-传播损失表项 */
typedef struct {
    double r;                  /* 距离，单位 m，500~50000 */
    double tl;                 /* 传播损失，单位 dB，55~110 */
} TLEntry;

TLEntry    g_tlTable[MAX_DIST];    /* 距离-传播损失表 */
int        g_nTL = 0;              /* 表行数 */
SonarSetup g_sonar;                /* 当前声呐参数 */

double g_sn[MAX_DIST];             /* 各距离回波信噪比，单位 dB */
double g_pd[MAX_DIST];             /* 各距离检测概率，取值 0~1 */
int    g_nDist = 0;                /* 距离点数 */
unsigned int g_seed = 12345;       /* 随机种子 */
```

全局数组置于文件作用域以避免栈溢出；各模块只通过 `g_tlTable`、`g_sonar`、`g_sn`、`g_pd` 及函数参数交换数据。随机数通过统一的封装函数获取，保证全组调用同一序列、结果可复现。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 声呐参数录入模块**（源文件 `SonarIn.c`）
- 功能简介：交互录入声源级 SL、目标强度 TS、噪声级 NL、指向性指数 DI、检测门限 DT、模拟次数 N 与随机种子；对每个量做范围校验并提示重新输入，最后填入 `g_sonar` 与 `g_seed`。
- 输入：键盘输入的 7 个参数。
- 输出：`g_sonar`、`g_seed`；屏幕参数确认表。

**M2 距离-传播损失表读入模块**（源文件 `TLIn.c`）
- 功能简介：打开表格文件，读入格式标识与行数，循环读入全部"距离-传播损失"到 `g_tlTable[]`；检查距离是否递增、传播损失是否随距离单调不减、距离是否为正，给出告警并返回标志。
- 输入：文件路径（菜单输入，默认 `tl_table.txt`）。
- 输出：填充 `g_tlTable[]`、`g_nTL`；屏幕校验报告。

### 第二部分：算法实现（4 个模块）

**M3 回波信噪比计算模块**（源文件 `SNR.c`）
- 功能简介：对表中每个距离按主动声呐方程计算回波级 EL = SL − 2·TL + TS，再减去噪声级与指向性指数之差得到回波信噪比 SN = EL − (NL − DI)，逐点存入 `g_sn[]`；输出各距离信噪比概览。
- 输入：`g_sonar`、`g_tlTable[]`、`g_nTL`。
- 输出：`g_sn[]`、`g_nDist`；屏幕信噪比概览。

**M4 单次检测随机判决模块**（源文件 `Decide.c`）
- 功能简介：实现 `int detect_once(double sn_dB, double dt)`：由信噪比得噪声相对幅度 σ = 10^(−SN/20)，用 `rand()` 生成的均匀随机数按"12 个之和减 6"近似零均值随机量 r，令归一化接收幅度 y = 1.0 + σ·r，若 y > dt 则返回 1（本次检测到），否则返回 0。
- 输入：该距离的信噪比 sn_dB、检测门限 dt。
- 输出：本次判决结果 0 或 1。

**M5 N 次模拟统计模块**（源文件 `SimStat.c`）
- 功能简介：对给定信噪比重复调用 M4 共 N 次，累计检测成功次数，检测概率 = 成功次数 / N；输出成功次数与概率，并打印采用随机种子。
- 输入：sn_dB、dt、N。
- 输出：该距离的检测概率 Pd（0~1）。

**M6 距离扫描批量模拟模块**（源文件 `DistanceScan.c`）
- 功能简介：遍历全部距离点，对每个距离调用 M5 估算检测概率，逐点填入 `g_pd[]`；同时用计数统计找出检测概率首次下降到 0.5 以下的距离区间，供作用距离估计参考。
- 输入：`g_sn[]`、`g_nDist`、`g_sonar`（DT、N）。
- 输出：`g_pd[]`；屏幕"距离-信噪比-检测概率"汇总表。

### 第三部分：数据输出（4 个模块）

**M7 检测概率-距离曲线字符画模块**（源文件 `PlotPd.c`）
- 功能简介：以距离为横轴、检测概率为纵轴（0~1），把 `g_pd[]` 序列映射到字符网格，用 `*` 描点绘制曲线，并在 Pd = 0.5 处画一条水平参考线，直观显示检测概率随距离的下降。
- 输入：`g_tlTable[].r`、`g_pd[]`、`g_nDist`。
- 输出：屏幕检测概率—距离曲线字符画。

**M8 门限参数实验模块**（源文件 `DTExp.c`）
- 功能简介：对检测门限 DT 取 0.3/0.5/0.7（或用户给定的一组值），在固定随机种子下逐个重跑 M6，输出"门限-在指定距离处检测概率-检测概率首次低于 0.5 的距离"对比表，展示门限抬高使作用距离缩短的规律。
- 输入：`g_sn[]`、门限列表、`g_sonar`。
- 输出：屏幕门限对比表。

**M9 模拟报告输出模块**（源文件 `Report.c`）
- 功能简介：把声呐参数、随机种子、各距离的信噪比与检测概率、门限实验对比结果写成 `pd_report.csv`，并在屏幕汇总显示。
- 输入：`g_sonar`、`g_tlTable[]`、`g_sn[]`、`g_pd[]`、门限实验结果。
- 输出：`pd_report.csv`；屏幕汇总表。

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（录参数/读损失表/算信噪比/单次判决演示/逐距离模拟/画曲线/门限实验/写报告/退出），用 `do-while + switch` 调度 M1~M9；用状态标记约束"必须先录入参数并读入损失表才能模拟"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1~M9，循环直至退出；状态标记 `g_ready` 约束"未录入参数或未读入损失表不得模拟"。M1、M2 完成后 M3 可算信噪比，M4~M6 完成随机模拟与统计，M7/M8/M9 输出结果。

**数据流**：

```
损失表文件 ─► M2 读入 ─► g_tlTable[]   M1 参数录入 ─► g_sonar / g_seed
                                │                          │
                                ▼                          ▼
                        M3 回波信噪比计算 ─► g_sn[]
                                │
                                ▼
                        M6 距离扫描批量模拟
                                │
              ┌─────────────────┤（每个距离）
              ▼                 │
        M5 N 次模拟统计         │
              │                 │
              ▼                 │
        M4 单次检测随机判决 ────┘
              │  g_pd[]
              ▼
        ┌─────┼───────────────┐
        ▼     ▼               ▼
   M7 曲线   M8 门限实验   M9 模拟报告输出
                         │
                         ▼
                   M10 主控菜单调度
```

所有模块仅通过 `g_tlTable`、`g_sonar`、`g_sn`、`g_pd` 及函数参数交换数据；随机数统一由封装函数提供，函数接口在编码前书面约定。

## 十、选做扩展

1. 分批模拟观察收敛：把 N 次模拟分成若干批，记录每批累计检测概率，观察其随试验次数增加趋于稳定（复用统计收敛思路）。
2. 引入起伏目标：令回波幅度在 ±3 dB 内按均匀随机数起伏后再判决，比较有无起伏时检测概率的差异，仍属课程内随机模拟。
3. 用线性插值对"检测概率—距离"曲线求 Pd = 0.5 所对应的作用距离，复用课程 2.5 的线性插值。
