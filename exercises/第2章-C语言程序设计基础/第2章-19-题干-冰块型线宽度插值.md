# 第 2 章 练习 19　冰块型线宽度插值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 C8《基于数值积分与二分法的碎冰冰块浮力吃水计算系统》（水声学院）——本练习是该实验中"冰块型线宽度插值"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

一块碎冰的形状可以像船体一样用**型线**描述：沿高度方向，不同高度处的水线**宽度**不同。要计算冰块入水部分的排水体积（进而算浮力和吃水），就需要沿高度把水线宽度"积起来"。

型线测量同样只能给出若干离散高度上的宽度，例如高度 0 m 处宽 0.90 m、高度 0.20 m 处宽 1.20 m。计算体积时，需要**任意高度**处的宽度。综合实验 C8 用数值积分求水线面积、用二分法求平衡吃水，本练习先独立完成"由相邻两档高度—宽度数据插值求中间宽度"这一最小步骤，它正是第 3 章积分计算的前置环节。

## 二、任务要求

编写一个完整程序 `ice_profile.c`：

1. 用**常量**在程序中存放相邻两档数据：高度 0 m 对应宽度 0.90 m，高度 0.20 m 对应宽度 1.20 m；
2. 从键盘读入一个高度 `z`（单位：m，`double` 类型，**题目保证 0 ≤ z ≤ 0.20**，因此不需要判断分支）；
3. 用线性插值公式计算该高度对应的水线宽度 `B`；
4. 按规定格式输出结果，保留 **3 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示高度 z（m）。

**输出**：一行，按格式 `B = 结果 m` 输出，结果保留 3 位小数。

## 四、样例

**样例 1**

输入：
```
0.08
```
输出：
```
B = 1.020 m
```

**样例 2**

输入：
```
0.15
```
输出：
```
B = 1.125 m
```

## 五、提示

线性插值公式：已知两点 $(z_0,\, B_0)$、$(z_1,\, B_1)$，则高度 $z$ 处的宽度为

$$
B = B_0 + \dfrac{(B_1 - B_0)\,(z - z_0)}{z_1 - z_0}
$$

本例宽度随高度**增大**（$B_1 - B_0 = 0.30$，冰块下部窄、上部宽）；只需把公式原样翻译成一行赋值语句，注意括号。

**完成本练习后你将具备的能力**：把型线数据翻译成程序常量、独立完成一次完整插值流程、为正斜率数据求中间值——这是 C8 浮力吃水系统里"型线查宽度"模块的地基，也是后续数值积分的前置准备。
