# 题目 D7：基于数值积分的辐射剂量场分布估算系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行辐射剂量场分布估算工具。系统把一条线状放射源（如一段工艺管道、一根燃料元件棒、一条被污染的管道）沿轴向离散成若干个等距点源，对空间中一条测线上的每个测点，遍历全部点源、按平方反比定律累加各点源的剂量率贡献，得到该测点的总剂量率——这正是"把连续源离散化再求和"的数值积分思想。系统进一步把测线扩展成二维网格，逐格计算剂量率形成剂量场分布矩阵，用选择排序找出最高剂量率的格点作为热点，并按数量级分档打印出 ASCII 字符场分布图，最后把网格矩阵与热点清单写入结果文件。

辐射场分布是辐射防护分区与作业安排的直接依据。工程现场最关心的问题往往是"剂量率在空间上怎么分布、最高的地方在哪里、离源多远才相对安全"：只算一个点的剂量率无法判断人员巡检时会经过多高的剂量率区域，也无法确定控制区边界应设在哪里。如果不做场分布计算，防护最优化（ALARA 原则）就失去了量化前提——不知道该把屏蔽加在哪里、该把哪条通道改道、该把哪个点位设为限制停留点。

本系统支撑的关键场景包括：① 核电站一回路管道、蒸汽发生器周围的剂量场测绘与检修路径规划；② 后处理厂工艺设备间的场分布评估与控制区边界划分；③ 医用近距离治疗源、钴源辐照室的场分布核算；④ 放射性物质暂存库内的货包布置优化（避免热点叠加）；⑤ 退役拆除现场的污染源场分布调查。系统只用课程内的一维/二维数组、嵌套循环、梯形积分思想、选择排序与字符输出，把"线源—点源离散—逐点累加—场分布成像"这条专业路径完整走通。本题目与核工程与核技术专业"辐射防护与核安全"方向直接对应。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的辐射剂量场分布估算系统：从文本文件读入线源参数（长度、源强密度、离散点数）与测点/网格配置（测线位置、二维网格范围与步长，含异常值校验），把线源离散成等距点源数组，实现单点源剂量率计算与测点剂量率累加两级函数，对整条测线逐点计算得到一维分布，对二维网格逐格计算得到场分布矩阵，用选择排序定位热点格点，按数量级分档绘制 ASCII 强度图，最后把矩阵与热点清单写出 CSV，并在菜单中调度全部功能。

专业关联上，本题目还原了辐射防护现场最常用的"离散求和"场计算流程：连续线源不会解析求解，工程上一律先离散再累加。学生在实现中练熟二维数组的双重遍历、函数分层封装、排序定位与格式化输出，理解"距离平方反比"如何决定场分布的空间形态，全程不涉及任何超纲理论。

## 三、数据来源与格式

- **数据文件格式**：分两个文本文件。其一是线源参数文件 `linesource.txt`，首行为标题说明，其后每行一条记录，字段以空格分隔，依次为：源标识（无空格字符串）、线源长度 L（单位：m，正实数）、源强密度 λ（单位：MBq/m，正实数）、离散点数 n（整数，≥ 2）。其二是测点与网格配置 `field_cfg.txt`，给出测线参数与二维网格范围。

```
# src_id   length_m   strength_per_m_MBq   point_num
LS1         4.00        120.0                41
LS2        10.00         50.0               101
```

```
# line_y_m  line_x_from_m  line_x_to_m  point_cnt  grid_x_min grid_x_max grid_x_step grid_y_min grid_y_max grid_y_step
2.0          0.5            7.5          15         0.0         8.0      0.5          0.5         4.0       0.5
```

- **仿真数据生成规则**：
  - 源标识：2～10 个字母数字字符，无空格，如 `LS1`、`pipe_A`。
  - 线源长度 L：单位 m，取值范围 1.00～20.00，按均匀分布生成并保留两位小数。
  - 源强密度 λ：单位 MBq/m，取值范围 10.0～500.0，按均匀分布生成。
  - 离散点数 n：整数，取值范围 11～201（建议奇数，保证中心点落在源中垂线上）；相邻点源间距 $\Delta = L/(n-1)$，单位 m。
  - 测线位置：测点到线源的垂直距离 y（单位 m，取值 0.5～10.0）；测线沿 x 方向的起止坐标（单位 m，起 ≤ 止）与测点数（11～51）。
  - 二维网格：x、y 方向的起止坐标（单位 m，取值 0.0～20.0）与步长（单位 m，取值 0.25～1.00）；行数按 $(y_{\max}-y_{\min})/\text{step}+1$ 计算，须不超过 64，列数不超过 64。
  - **异常值注入方式**：由教师提供的生成程序注入三类错误。其一，线源长度为 0 或负数（如 `-4.0`），校验时应剔除；其二，离散点数填 1 或超大值（如 `1`、`99999`），校验时取默认值 41；其三，测线起止坐标起大于止（如 from=7.5, to=0.5），校验时自动交换并告警；另可注入非数字串（如 `NA`），考察 `fscanf` 返回值判断。

- **真实数据集（如有）**：真实的线源剂量场数据可参考 IAEA 与国际辐射防护委员会（ICRP）发布的点核积分剂量计算手册，以及各核设施公开发布的剂量场测绘报告。学生**无需下载**真实数据，课程提供与上述字段含义对应的简化仿真参数表，其中"源强密度 λ"对应单位长度上的 γ 发射率（光子/秒·米），"离散点数 n"对应工程上梯形积分的分段数。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_SRC      10        /* 最大线源条数 */
#define MAX_POINT   201        /* 单条线源最大离散点数 */
#define MAX_LINE     51        /* 测线最大测点数 */
#define MAX_ROW      64        /* 剂量场网格最大行数 */
#define MAX_COL      64        /* 剂量场网格最大列数 */
#define GAMMA_CONST  1.30e-1   /* 点源剂量率系数 K，单位 μSv·m²/(h·MBq) */

/* ===== 线源结构体 ===== */
struct LineSource {
    char   srcId[12];         /* 源标识，如 "LS1" */
    double length;            /* 线源长度 L，单位 m，> 0 */
    double strength;          /* 源强密度 λ，单位 MBq/m，> 0 */
    int    pointNum;          /* 离散点数 n，11~201 */
    int    valid;             /* 有效标志：1 有效，0 已判为异常剔除 */
};

/* ===== 离散点源结构体 ===== */
struct PointSource {
    double x;                 /* 点源 x 坐标，单位 m */
    double y;                 /* 点源 y 坐标，单位 m */
    double s;                 /* 该点源等效源强，单位 MBq = λ·Δ */
    int    srcIndex;          /* 所属线源下标 */
};

/* ===== 测点结构体 ===== */
struct MeasurePoint {
    double x;                 /* 测点 x 坐标，单位 m */
    double y;                 /* 测点 y 坐标，单位 m */
    double rate;              /* 该测点总剂量率，单位 μSv/h */
};

/* ===== 全局数据区 ===== */
struct LineSource   g_src[MAX_SRC];       /* 线源表 */
int                 g_srcCount;           /* 线源条数 */
struct PointSource  g_ps[MAX_POINT * MAX_SRC]; /* 离散点源数组 */
int                 g_psCount;            /* 离散点源总数 */
double              g_lineY;              /* 测线离源的垂直距离 y，m */
double              g_lineX0, g_lineX1;   /* 测线起止 x 坐标，m */
int                 g_lineN;              /* 测线测点数 */
struct MeasurePoint g_line[MAX_LINE];     /* 测线各测点结果 */
double              g_gridRate[MAX_ROW][MAX_COL]; /* 二维剂量场矩阵，μSv/h */
int                 g_gridRow, g_gridCol; /* 网格实际行数、列数 */
double              g_gx0, g_gstep, g_gy0, g_gystep; /* 网格原点与步长，m */
struct MeasurePoint g_hot[8];             /* 热点格点表，按剂量率降序 */
int                 g_hotCount;           /* 热点个数 */

/* ===== 处理日志 ===== */
struct LogItem {
    char op[24];              /* 操作名，如 "RUN_GRID_FIELD" */
    char detail[72];          /* 参数与关键结果摘要 */
};
struct LogItem g_log[128];
int            g_logCount;    /* 已记录日志条数 */
```

辅助说明：点源剂量率按平方反比公式 $\dot D = K\cdot S/d^2$ 计算，其中 S 为该点源等效源强（MBq）、d 为点源到测点的距离（m）、K 为剂量率系数。线源离散后每个点源的等效源强为 $S_i = \lambda\cdot\Delta$，$\Delta = L/(n-1)$；测点总剂量率为 $\dot D = \sum_i K\cdot S_i/d_i^2$，即离散化后的求和。二维场分布用 `double` 矩阵存储，按行优先的嵌套循环填充。

## 五、功能模块拆解（共 11 个模块）

### 第一部分：数据读入（2 个模块）

**M1 线源参数读入模块**（源文件 `LineIO.c`）
- 功能简介：打开线源参数文件，跳过标题行，循环读入源标识、线源长度、源强密度与离散点数，填充 `g_src[]` 并记录条数；校验长度为正、源强密度为正、点数在 [11, 201] 内，异常记录置 `valid=0` 并打印清单。  输入：线源文件路径（默认 `linesource.txt`）；输出：`g_src[]`、`g_srcCount` 与校验报告。

**M2 测点与网格配置读入模块**（源文件 `FieldIO.c`）
- 功能简介：读入测线的垂直距离、起止坐标与测点数，读入二维网格的 x/y 起止范围与步长；做范围检查（起 ≤ 止，步长 > 0，行数/列数不超过 64），坐标反向时自动交换并告警，越界时取默认值。  输入：配置文件路径（默认 `field_cfg.txt`）；输出：`g_lineY/g_lineX0/g_lineX1/g_lineN`、网格原点与步长、`g_gridRow/g_gridCol`。

### 第二部分：算法实现（5 个模块）

**M3 点源离散化模块**（源文件 `Discretize.c`）
- 功能简介：对每条有效线源按点数 n 等分，算出间距 $\Delta = L/(n-1)$ 与各点源等效源强 $S_i = \lambda\cdot\Delta$，把每个点源的坐标与源强填入 `g_ps[]`，累加 `g_psCount`；点源沿源轴向均匀排布，第一个与最后一个恰好落在源的两端。  输入：`g_src[]`；输出：`g_ps[]`、`g_psCount` 与屏幕离散摘要。

**M4 单点源剂量率计算模块**（源文件 `PointDose.c`）
- 功能简介：实现函数 `double pointDose(const struct PointSource *p, double px, double py)`：先算点源到测点的距离 $d=\sqrt{(p_x-x)^2+(p_y-y)^2}$，再按 $\dot D = K\cdot S/d^2$ 返回剂量率（μSv/h）；距离小于 0.05 m 时判为过近，返回一个上限截断值并置告警标志，避免除零与不合理发散。  输入：点源指针与测点坐标；输出：该点源在测点的剂量率贡献。

**M5 测点剂量率累加模块**（源文件 `SumDose.c`）
- 功能简介：实现函数 `double pointTotal(double px, double py)`：遍历 `g_ps[]` 全部离散点源，逐个调用 M4 并把贡献累加，返回该测点的总剂量率；同时用指针参数 `double *maxContrib` 带回最大单个点源的贡献值，便于判断主导点源。  输入：测点坐标；输出：总剂量率（μSv/h）与最大单项贡献。

**M6 测线剂量率分布计算模块**（源文件 `LineScan.c`）
- 功能简介：沿测线从 `g_lineX0` 到 `g_lineX1` 等距取 `g_lineN` 个测点，对每个测点调用 M5 求总剂量率，填入 `g_line[]`；输出"测点 x 坐标—总剂量率—相对首点倍数"对照表，观察剂量率沿测线的变化。  输入：测线参数、`g_ps[]`；输出：`g_line[]` 与屏幕测线分布表。

**M7 二维剂量场网格计算模块**（源文件 `GridField.c`）
- 功能简介：对网格的每一行每一列算出格点实际坐标 $(x_j, y_i)$，调用 M5 求该格点剂量率并填入 `g_gridRate[i][j]`；按行打印进度，支持中途查看已算行数；计算完成后统计网格的最大值、最小值、平均值与超出给定阈值的格点数。  输入：网格原点、步长、`g_ps[]`；输出：`g_gridRate[][]` 与屏幕网格统计摘要。

### 第三部分：数据输出（4 个模块）

**M8 热点排序定位模块**（源文件 `HotSpot.c`）
- 功能简介：把网格全部格点（含行列坐标与剂量率）拷入一维临时数组，用选择排序按剂量率降序排列，取前 8 个作为热点，把坐标与数值填入 `g_hot[]` 与 `g_hotCount`；同时给出热点在网格中的行列下标以及该点的相对中心点倍数。  输入：`g_gridRate[][]`、网格原点与步长；输出：`g_hot[]`、`g_hotCount` 与屏幕热点排行表。

**M9 场分布字符图绘制模块**（源文件 `FieldPlot.c`）
- 功能简介：把网格剂量率按数量级分档映射为不同字符——空档用 `.`，低档用 `-`，中档用 `*`，较高档用 `#`，最高档用 `@`，逐行逐列打印出二维 ASCII 剂量场；同时在图的左侧标注 y 坐标、下方标注 x 坐标，并在热点位置加标记。  输入：`g_gridRate[][]`、分档阈值；输出：屏幕字符场分布图。

**M10 结果文件输出模块**（源文件 `FieldIO.c`）
- 功能简介：把二维剂量场矩阵按"行号—y 坐标—各列剂量率"格式写出到 `field_grid.csv`（CSV 便于后续用其他工具绘图），把测线分布表写出到 `line_profile.csv`，把热点清单写出到 `hotspot.txt`；输出时统一保留 4 位有效数字。  输入：`g_gridRate[][]`、`g_line[]`、`g_hot[]`；输出：三个结果文件与屏幕确认信息。

**M11 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读线源 / 读网格配置 / 离散化 / 算测线分布 / 算二维场 / 找热点 / 画场分布图 / 输出文件 / 退出），用 `do-while + switch` 调度 M1～M10；用状态标记约束"必须先读入线源与网格配置并完成 M3 离散化才能计算剂量场"。  输入：用户菜单选项；输出：调度各模块并维护日志表。

## 六、数据流与控制流

**控制流**：`main()` 进入 `do-while` 菜单循环，用 `switch` 分发 M1～M10。状态约束由两个标记承担：`g_srcCount > 0` 且至少一条 `valid==1` 才允许调用 M3；`g_psCount > 0`（M3 完成标志）才允许调用 M4～M10。M1/M2 任意顺序可执行，但 M7 与 M6 之间无依赖，可任选先后。M9 与 M10 使用 M7 的结果，M8 的热点排序必须在 M7 之后执行。

**数据流**：
```
linesource.txt ─► M1 线源读入 ─► g_src[]
field_cfg.txt ─► M2 网格配置 ─► g_lineY/g_lineX0/g_lineX1/g_gridRow/g_gridCol
                                      │
                                      ▼
                              M3 点源离散化 ─► g_ps[]
                                      │
                     ┌────────────────┼────────────────┐
                     ▼                ▼                ▼
            M4 单点源剂量率    M5 测点剂量率累加   M8 热点排序定位
                     │                │                ▲
                     └──────► M6 测线分布 / M7 二维场 ┘
                                      │
                     ┌────────────────┼────────────────┐
                     ▼                ▼                ▼
        M9 场分布字符图      M10 结果文件输出     M11 主控菜单调度
```

所有模块之间只通过全局线源表 `g_src[]`、离散点源数组 `g_ps[]`、测线结果 `g_line[]`、剂量场矩阵 `g_gridRate[][]` 与函数参数交换数据；点源剂量率公式只在 M4 中实现一次，M5～M7 一律调用 M4，禁止重复书写公式。函数头部（接口）在编码前由全组书面约定。

## 十、选做扩展

1. **源长对热点的影响**：把线源长度依次取 2、5、10、20 m（保持源强密度不变），重跑 M7 与 M8，输出"源长—最高剂量率—热点距离"对照表，讨论源越长热点越远、峰值越低的现象。
2. **屏蔽隔板在场分布中的作用**：在测点与源之间加入一块屏蔽板，对位于屏蔽板后的格点在 M5 累加时乘上衰减因子 $e^{-\mu d}$（μ 由菜单输入），重跑 M7，对比加屏蔽前后场分布字符图与控制区格点数的变化。
3. **网格步长敏感性**：把网格步长依次取 1.0、0.5、0.25 m，对同一场景计算全场平均剂量率与热点值，观察网格加密后结果趋于稳定的过程，理解数值积分的"步长越细越准"。
