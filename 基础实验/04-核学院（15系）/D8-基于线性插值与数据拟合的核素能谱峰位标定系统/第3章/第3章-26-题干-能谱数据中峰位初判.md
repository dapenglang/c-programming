# 第 3 章 练习 26　能谱数据中峰位初判

**所属综合实验**：D8（D8-基于线性插值与数据拟合的核素能谱峰位标定系统）

**对应章节**：3 程序控制结构（3.2 选择结构——if 判断、3.3 循环结构——for 循环、3.5 关系与逻辑运算）

**场景来源**：综合实验 D8《基于线性插值与数据拟合的核素能谱峰位标定系统》（核学院）——本练习是该实验中"峰位初判（寻峰第一步）"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

一条 γ 能谱就是"道址—计数率"的数列。核素发出的 γ 射线会在特定能量处形成**峰**——在谱图上看，就是某个道址的计数率明显比两边高。找到这些峰（**寻峰**）是核素识别的第一步。

最简单的寻峰判据：**若某个道址的计数率比它左右相邻两个道都高，就把这个道记为"疑似峰位"。** 这叫**局部极大**判据。之后再用能量刻度（上一练习）换算成能量、与核素特征能量比对。

综合实验 D8 的完整寻峰流程（平滑、局部极大、能量换算）就始于这个最简单的判断。本题实现"扫描整条谱、找出所有局部极大道址"这一步。

## 二、任务要求

编写一个完整程序 `find_peaks.c`：

1. 从键盘读入谱数据长度 `n`（**题目保证 3 ≤ n ≤ 50**）；
2. 读入 `n` 个计数率（double，个/秒）存入数组 `c[50]`；
3. **用循环**从第 2 个到第 `n-1` 个元素（下标 1 ～ n-2）逐一检查：若某道计数率**同时高于**左右相邻两道，则判定为疑似峰位；
4. 输出所有疑似峰位的**道址**（下标，整数），每个后跟一个空格；若没有找到任何峰，输出 `none`。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各道址的计数率，用空格分隔。

**输出**：一行，为所有疑似峰位的道址（从 0 开始计数），每个后跟一个空格；若无峰输出 `none`。

## 四、样例

**样例 1**

输入：
```
9
1.0 2.0 5.0 2.0 1.0 8.0 3.0 2.0 1.0
```
输出：
```
2 5
```

**样例 2**

输入：
```
7
1.0 3.0 2.0 6.0 4.0 1.0 0.5
```
输出：
```
1 3
```

**样例 3**

输入：
```
4
1.0 2.0 3.0 4.0
```
输出：
```
none
```

## 五、提示

- 局部极大的判断：对下标 `i`（1 ≤ i ≤ n-2），条件是
  ```c
  if (c[i] > c[i-1] && c[i] > c[i+1]) { /* 是峰，输出道址 i */ }
  ```
  `&&` 是逻辑与，两个条件必须同时成立；
- 边界（第 0 个和最后一个）没有两侧相邻道，**不参与判断**，所以循环从 1 开始、到 `n-2` 结束；
- 用一个标志变量记录"是否找到过峰"：初始 `found = 0`，每输出一个峰就 `found = 1`；循环结束后若 `found == 0` 就输出 `none`；
- 想一想：为什么用"同时高于左右"而不是"高于平均值"？因为局部极大只需比较相邻点，简单可靠，也是能谱寻峰最常用的第一步；
- 严格大于（`>`）意味着"平台状"（左右相等）不算峰——这是常用的处理方式。

**完成本练习后你将具备的能力**：用循环遍历数组、用 if 加逻辑与做复合条件判断、处理"没有命中"的边界情况——这些是实验 D8 中"峰位初判模块"的地基。
