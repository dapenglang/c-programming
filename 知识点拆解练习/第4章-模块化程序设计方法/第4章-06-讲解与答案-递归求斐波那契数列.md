## 二、预备知识：双分支递归与调用树（零基础阅读）

### 1. 问题来源

斐波那契数列的定义是"从第三项起，每项等于前两项之和"。把它写成数学式：

$$
F(1) = 1,\quad F(2) = 1,\quad F(n) = F(n-1) + F(n-2)\quad(n \ge 3)
$$

要算 $F(10)$，需要先有 $F(9)$ 和 $F(8)$；而 $F(9)$ 又需要 $F(8)$ 和 $F(7)$……**一个大问题同时依赖两个小一号的问题**，这就是它与阶乘（只依赖一个更小问题）的最大区别。

### 2. 基线条件：两个最小项

数列的第一项和第二项没法"由前两项相加"得到，必须直接规定：

$$
F(1) = 1,\qquad F(2) = 1
$$

代码写作 `if (n == 1 || n == 2) return 1;`。**基线是递归的出口**，没有它，函数永远停不下来。

### 3. 递推关系：双分支

基线之上写 `return fib(n - 1) + fib(n - 2);`。因为一个函数体里出现了**两处** `fib` 调用，函数的执行会像树枝一样分叉。理解它的诀窍仍然是"信任递归"：**只要假设 `fib(n-1)` 和 `fib(n-2)` 都能算对，你把它们相加就对**。

### 4. 调用树展开：用 fib(5) 看分叉

求 `fib(5)` 时，调用过程展开成一棵"树"（本题数据代入）：

```text
fib(5)
├── fib(4)
│    ├── fib(3)
│    │    ├── fib(2) = 1      命中基线
│    │    └── fib(1) = 1      命中基线
│    │    └─ fib(3) = 1 + 1 = 2
│    └── fib(2) = 1           命中基线
│    └─ fib(4) = 2 + 1 = 3
└── fib(3)
     ├── fib(2) = 1
     └── fib(1) = 1
     └─ fib(3) = 2
→ fib(5) = 3 + 2 = 5
```

可以清楚看到：`fib(3)` 被算了两遍，`fib(2)` 被算了三遍。**"同样的子问题被重复求解"**正是斐波那契递归的固有代价——这也解释了为什么 $n$ 一大，运算量会爆炸式增长（本题因此限制 $n\le 35$）。

### 5. 编程要点

- 基线判断用 `||` 把前两项合并成一句；
- 大数用 `long long`，因为 $F(47)$ 起就超过 `int` 上限；
- 打印格式 `%lld` 对应 `long long`。

## 三、解题思路

1. **定接口**：`long long fib(int n)`；
2. **写原型**：放在 `main` 上方；
3. **写基线**：`if (n == 1 || n == 2) return 1;`；
4. **写递推**：`return fib(n - 1) + fib(n - 2);`；
5. **主流程**：读 `n` → 调用 → 打印。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：返回斐波那契第 n 项 */
long long fib(int n);

int main(void)
{
    int n;
    scanf("%d", &n);                          /* 读入 n */
    printf("F(%d) = %lld\n", n, fib(n));      /* 递归求第 n 项并输出 */
    return 0;
}

/* 递归函数：斐波那契数列 */
long long fib(int n)
{
    if (n == 1 || n == 2)                     /* 基线条件：前两项均为 1 */
        return 1;
    else                                      /* 双分支递推：前两项之和 */
        return fib(n - 1) + fib(n - 2);
}
```

## 五、运行验证

以 `fib(5)` 为例的中间结果：

| 调用 | 展开过程 | 本层结果 |
|---|---|---|
| fib(3)（第一次） | 1 + 1 | 2 |
| fib(4) | fib(3)+fib(2) = 2 + 1 | 3 |
| fib(3)（第二次） | 1 + 1 | 2 |
| fib(5) | fib(4)+fib(3) = 3 + 2 | 5 |

多组输入的程序输出：

| 输入 n | 手算过程 | 程序输出 |
|---|---|---|
| 1 | 基线，直接为 1 | `F(1) = 1` ✓ |
| 2 | 基线，直接为 1 | `F(2) = 1` ✓ |
| 5 | 1,1,2,3,5 | `F(5) = 5` ✓ |
| 10 | 累推至 55 | `F(10) = 55` ✓ |
| 20 | 累推至 6765 | `F(20) = 6765` ✓ |

## 六、常见错误与讲解

**错误 1：基线条件缺失或写错范围**

```c
if (n == 1) return 1;                 /* 错：没有处理 n == 2，fib(2) 会去调 fib(0)、fib(-1)，越陷越深 */
if (n == 1 || n == 2) return 1;       /* 对：两个最小项都作为基线 */
```

**错误 2：双分支写成了同一个分支**

```c
return fib(n - 1) + fib(n - 1);   /* 错：算的是 2*F(n-1)，与 F(n-2) 毫无关系 */
return fib(n - 1) + fib(n - 2);   /* 对 */
```

**错误 3：没意识到重复计算导致效率低下**

`fib(35)` 的调用次数已上百万；如果直接写 `fib(60)` 会长时间算不出来。这说明**递归写法直观，但不总是高效**——要真正解决大 $n$ 问题，需要把已算过的结果存起来，那是第 5 章数组（记忆化）才具备的手段。

**错误 4：用 `int` 承载导致溢出**

```c
int fib(int n);              /* n = 47 起溢出 */
long long fib(int n);        /* 对：用 64 位 */
```
