# 第 5 章 练习 36　声线路径时间排序

**所属综合实验**：C8（C8-基于分层线性插值的声线传播时间计算系统）

**对应章节**：5 一维数组与排序（5.1 数组的定义与引用、5.2 数组的遍历、5.5 排序——选择排序、5.5 数组统计——最小值定位）

**场景来源**：综合实验 C8《基于分层线性插值的声线传播时间计算系统》（水声学院）——本练习是该实验中"路径按传播时间排序（找最短路径）环节"的最小实现。

**建议用时**：40 分钟

## 一、应用场景

声源向海底发射信号时，可以沿**多条不同的声线路径**到达接收点；每条路径对应一个传播时间。哪个接收方案"到得最快"？——把所有路径的传播时间**从小到大排序**，排在最前面的就是最短（最快）路径。

综合实验 C8 批量算出多条路径的传播时间后，要把路径**按传播时间排序**，找出最短路径（M8 模块）。本题的简化版：程序读入各条路径的编号与传播时间，用**选择排序**按时间升序排列，输出排序结果和最短路径的编号。

排序时要注意：**时间数组**和**编号数组**必须"一起换"——如果只交换了时间、没交换编号，编号就和时间对不上号了。

## 二、任务要求

编写一个完整程序 `ray_sort.c`：

1. 从键盘读入路径条数 `m`（**题目保证 1 ≤ m ≤ 20**）；
2. 读入 `m` 对数据：路径编号（int，依次为 1～m 也可任意）与传播时间（double，单位 s），分别存入数组 `id[20]` 与 `t[20]`；
3. 用**选择排序**把路径按传播时间**从小到大（升序）**排列。要求：
   - 每一轮先在"未排序区"里**找最小时间的下标**，再把这个下标对应的元素与未排序区开头**交换一次**；
   - 交换时 `t` 与 `id` **同步交换**，保持配对关系；
4. 输出三部分：
   - 排序后的"编号—时间"对照表（每行一条，时间保留 2 位小数）；
   - 最短传播时间（保留 2 位小数）；
   - 最短路径的编号。

## 三、输入输出格式

**输入**：第一行一个整数 m；随后 m 行，每行"编号 传播时间"。

**输出**：

```
排序后路径表：
编号 1  时间 1.62 s
...
最短传播时间 = 1.62 s（路径 5）
```

（输出表格式：每行 `编号 x  时间 t.xx s`，编号与时间之间两个空格。）

## 四、样例

**样例 1**

输入：
```
6
1 2.71
2 1.93
3 3.05
4 2.14
5 1.62
6 2.48
```
输出：
```
排序后路径表：
编号 5  时间 1.62 s
编号 2  时间 1.93 s
编号 4  时间 2.14 s
编号 6  时间 2.48 s
编号 1  时间 2.71 s
编号 3  时间 3.05 s
最短传播时间 = 1.62 s（路径 5）
```

**样例 2**

输入：
```
1
7 0.88
```
输出：
```
排序后路径表：
编号 7  时间 0.88 s
最短传播时间 = 0.88 s（路径 7）
```

（只有 1 条路径时，它自己就是最短路径——排序循环一次都不用交换。）

## 五、提示

- 选择排序与冒泡排序的区别：冒泡每比较一次就**可能交换一次**；选择排序每一轮只做**一次交换**——先记住最小元素的下标，比完再换：
  ```c
  for (i = 0; i < m - 1; i++) {
      k = i;                          /* k 记录未排序区最小值下标 */
      for (j = i + 1; j < m; j++) {
          if (t[j] < t[k]) k = j;     /* 打擂台：只记下标，不交换 */
      }
      if (k != i) {                   /* 每轮最多交换一次，t 与 id 同步换 */
          tmp = t[i];  t[i] = t[k];  t[k] = tmp;
          it  = id[i]; id[i] = id[k]; id[k] = it;
      }
  }
  ```
- **两个数组必须同步交换**：`t[i]` 换到哪，`id[i]` 就跟到哪，否则"路径 5"的时间会被安到别的编号头上；
- 最短时间就是排序后的 `t[0]`，对应编号是 `id[0]`；
- 想一想：`if (k != i)` 这个判断去掉也能得到正确结果（自己跟自己换一次），那为什么要写它？

**完成本练习后你将具备的能力**：手写选择排序、维护"两个平行数组的配对关系"——这是实验 C8 中"路径按传播时间排序（M8）"的地基，也是以后处理"按某个关键字排序、整行记录跟着移动"问题的第一步。
