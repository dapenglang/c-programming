## 二、预备知识：选择排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

6 条声线路径，各自算出一个传播时间：

| 编号 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 时间(s) | 2.71 | 1.93 | 3.05 | 2.14 | 1.62 | 2.48 |

要"按时间从快到慢"排列，并知道最短的是哪条路径。难点在于：**排序的对象是时间，但"身份"（编号）必须跟着时间走**——时间是 1.62 s 的永远是路径 5，不能排完序后 1.62 s 被标成路径 1。这叫**平行数组**：两个数组按下标一一配对，动一个就必须同时动另一个。综合实验 C8 的 M8 模块、C10 的"按深度排序测点记录"，都是这个模式。

### 2. 公式推导：选择排序为什么对

选择排序每轮只干两件事：**找**未排序区里最小的元素，**换**到未排序区的开头。

形式化地，第 $i$ 轮（$i = 0, 1, \ldots, m-2$）：

$$k = \arg\min_{i \le j < m} t_j$$

即 $k$ 是未排序区 $[i, m)$ 中最小时间的**下标**。然后交换 $(t_i, t_k)$（编号同步交换）。每轮结束后：

$$t_0 \le t_1 \le \cdots \le t_i$$

即前 $i+1$ 个位置已排好且不再变动。$m-1$ 轮后整个数组升序。

**与冒泡排序的区别**：

| | 冒泡排序 | 选择排序 |
|---|---|---|
| 每轮比较次数 | 相邻逐个比，$n-1-i$ 次 | 全区扫一遍找最小，$m-1-i$ 次 |
| 每轮交换次数 | 发现逆序就换，最多 $n-1-i$ 次 | **最多 1 次** |
| 找极值方式 | 边比边换 | 打擂台记**下标**，比完再换 |

### 3. 代入本例

样例 1 逐轮跟踪（只列每轮找到的最小下标与交换结果）：

| 轮 i | 未排序区 | 最小下标 k | 交换后数组（时间） | 交换后编号 |
|---|---|---|---|---|
| 0 | 全部 6 条 | k=4（1.62） | `1.62 1.93 3.05 2.14 2.71 2.48` | `5 2 3 4 1 6` |
| 1 | 后 5 条 | k=2（1.93） | `1.62 1.93 3.05 2.14 2.71 2.48` | `5 2 3 4 1 6` |
| 2 | 后 4 条 | k=3（2.14） | `1.62 1.93 2.14 3.05 2.71 2.48` | `5 2 4 3 1 6` |
| 3 | 后 3 条 | k=5（2.48） | `1.62 1.93 2.14 2.48 2.71 3.05` | `5 2 4 6 1 3` |
| 4 | 后 2 条 | k=4（2.71） | 不变 | 不变 |

最终：`1.62 1.93 2.14 2.48 2.71 3.05`，编号 `5 2 4 6 1 3`。最短传播时间 1.62 s、路径 5，与样例一致。

注意第 1 轮里 3.05（路径 3）被"顶"到了路径 1 原来的位置——因为编号同步交换，3.05 仍带着编号 3，配对关系完好。

### 4. 编程翻译

| 算法动作 | C 语言翻译 |
|---|---|
| 找最小下标 | `k = i; if (t[j] < t[k]) k = j;`（打擂台记下标） |
| 每轮一次交换 | `if (k != i) { ... }` |
| 编号同步 | 交换 `t` 的同时用 `it` 交换 `id` |
| 取最短 | 排序后 `t[0]`、`id[0]` |

> **平行数组思想在综合实验中的地位**：C8 排路径、C7 排潮位找时段、C10 的"按测点深度排序"（第 7 章升级为结构体数组后，`id[]` 和 `t[]` 合并成一个结构体的成员），本质都是"按关键字排序，其余字段跟随移动"。本题是该思想的数组版起点。

## 三、解题思路

1. **读入**：`m`，循环读 `id[i]`、`t[i]`；
2. **选择排序**：外层 `i` 从 0 到 `m-2`；内层 `j` 从 `i+1` 到 `m-1` 打擂台记最小下标 `k`；`k != i` 时同步交换 `t` 与 `id`；
3. **取结果**：`t[0]` 为最短时间，`id[0]` 为最短路径编号；
4. **输出**：对照表逐行 `printf("编号 %d  时间 %.2f s\n", id[i], t[i]);`，最后输出结论行。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int    id[20];          /* 平行数组 1：路径编号 */
    double t[20];           /* 平行数组 2：传播时间(s) */
    double tmp, tmin;
    int    m, i, j, k, it;

    scanf("%d", &m);                        /* 读入路径条数 */
    for (i = 0; i < m; i++) {
        scanf("%d %lf", &id[i], &t[i]);     /* 编号与时间成对读入 */
    }

    /* 选择排序：按传播时间升序，t 与 id 同步交换 */
    for (i = 0; i < m - 1; i++) {
        k = i;                              /* 先假设未排序区开头最小 */
        for (j = i + 1; j < m; j++) {
            if (t[j] < t[k]) {
                k = j;                      /* 打擂台：只记下标 */
            }
        }
        if (k != i) {                       /* 每轮最多交换一次 */
            tmp = t[i];   t[i] = t[k];   t[k] = tmp;
            it  = id[i];  id[i] = id[k]; id[k] = it;
        }
    }

    printf("排序后路径表：\n");
    for (i = 0; i < m; i++) {
        printf("编号 %d  时间 %.2f s\n", id[i], t[i]);
    }
    tmin = t[0];
    printf("最短传播时间 = %.2f s（路径 %d）\n", tmin, id[0]);
    return 0;
}
```

## 五、运行验证

```
6

```
输出：

```
编号 4  时间 2.14 s
编号 6  时间 2.48 s

编号 3  时间 3.05 s
最短传播时间 = 1.62 s（路径 5）
```

数值核对（按 IEEE-754 double 与 `printf("%.2f")` 舍入复算）：排序结果与 Python `sorted` 一致，各时间原样输出两位小数不变。✓

**第二次运行**（样例 2，单路径边界）：

输入：
```
1
7 0.88
```
输出：
```
排序后路径表：
编号 7  时间 0.88 s
最短传播时间 = 0.88 s（路径 7）
```
✓ 外层循环 `i < m-1 = 0` 不执行，数组原样，`t[0]`、`id[0]` 直接就是答案。

**反例验证**：把编号的交换三行删掉再跑样例 1，输出变成：

```
编号 1  时间 1.62 s
编号 2  时间 1.93 s
...
```

编号变成"恰好等于位置 +1"的假象——配对关系被破坏，"最短路径 5"被误报成"路径 1"。这正是"平行数组必须同步交换"的教训。

## 六、常见错误与讲解

**错误 1：只交换时间、不交换编号**

```c
tmp = t[i]; t[i] = t[k]; t[k] = tmp;   /* 换了时间 */
/* 忘了同步换 id → 编号与时间错位 */
```

**错误 2：打擂台时把"下标"当"值"比**

```c
k = i;
if (t[j] < t[k]) k = j;     /* 对：比较的是值 t[j]、t[k]，存的是下标 j */
if (t[j] < k)    k = j;     /* 错：拿时间和下标比，逻辑完全乱了 */
```

**错误 3：交换写在打擂台循环里（退化成冒泡，且编号换乱）**

```c
for (j = i + 1; j < m; j++) {
    if (t[j] < t[i]) {
        tmp = t[i]; t[i] = t[j]; t[j] = tmp;   /* 边比边换，未按选择排序要求 */
        it = id[i]; id[i] = id[j]; id[j] = it;
    }
}
```

这样能得到有序结果，但违背了"每轮只交换一次"的选择排序要求（题目明确禁止）。**先找、后换**才是选择排序。

**错误 4：`if (k != i)` 不写导致"自我交换"**

```c
tmp = t[i]; t[i] = t[k]; t[k] = tmp;   /* k == i 时自己换自己：结果不错，但白做 6 次赋值 */
```

不算 bug，但加上 `if (k != i)` 是好习惯，避免无谓操作；考试评分时也常要求这一判断。

## 七、与综合实验的衔接

- 实验 **C8（基于分层线性插值的声线传播时间计算系统）**中，"多条声线路径批量计算（M7）+ 按传播时间排序（M8）"是本题的完整版：实验先对每条路径逐层累加出传播时间（M4～M6，水平距离用 $\Delta x = \Delta z \cdot \tan\theta$ 等三角关系、层时间用 $\Delta t = \Delta s / c$），再调用本题的选择排序，输出"最快到达"的路径；
- 与其他实验衔接：练习 35 的冒泡排序与本题的选择排序是同一目的的两种实现——数据近乎有序时冒泡可提前结束，交换代价大（如平行数组很长）时选择排序更省；到第 7 章实验 C10 里，"编号 + 时间"这对平行数组会合并成**结构体**，交换一次就带走全部字段，你会发现本题的"同步交换"正是结构体排序的前传。
