## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

内存里的数组"程序一停就没了"。练习 06 已经把这批阻力值以二进制存进 `loads.bin`；本题要做的，正是**把数据取回来**——这也是"持久化"二字真正的价值：数据不仅能存下去，还能原样取回来继续用。读回时用的函数是 `fread`。

### 2. 文本文件与二进制文件的区别

- **文本文件**：存的是"人可读的字符"。数 $12.5$ 写成 4 个字符，占 4 字节，读回来要和字符串互转。
- **二进制文件**：存的是"内存里的原始字节"。一个 `double` 恰好 8 字节，读回来直接就是内存中的那个数，**没有转换、没有精度损失、速度最快**。

正因如此，`fread` 读二进制数据必须与当初 `fwrite` 的布局**逐字节对应**：写的时候先写了 4 字节整数 $n$、再写 $n$ 个 8 字节 `double`；读的时候也必须先读 4 字节整数、再读 $n$ 个 `double`。少读或多读一个字段，后面的数据就全部错位，读出来会是乱七八糟的值。

### 3. 文件操作的标准四步曲

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题用 `fread` 读；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 它是这次文件访问的"编号牌"，指向系统建立的记录（文件在哪、当前进行到哪、是读还是写）；记录里的**文件位置指针**标明"现在读到第几个字节"，每读一段字节就自动后推。本题打开后指针在 0 字节处，正好从文件开头按写入顺序读。

**打开失败会怎样？** 文件不存在时 `fopen` 返回 `NULL`，不判空就用会崩溃，因此打开后**必须**判空：

```c
if (fp == NULL) { printf("无法打开文件 loads.bin\n"); return 1; }
```

### 4. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fread` | 读字节块 | `fread(a, sizeof(double), n, fp);` | 二进制文件、批量读回 |
| `fwrite` | 写字节块 | `fwrite(a, sizeof(double), n, fp);` | 二进制文件、批量存数组 |
| `fscanf` | 按格式读 | `fscanf(fp, "%lf", &v);` | 文本、按格式解析 |
| `fprintf` | 按格式写 | `fprintf(fp, "%.2f\n", v);` | 文本、人可读 |
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理 |

`fread` 的四个参数含义：**① 读到哪去（地址）；② 一个元素多少字节（`sizeof`）；③ 一共几个元素；④ 文件指针。** 读数组 `a` 的 $n$ 个元素，就是 `fread(a, sizeof(double), n, fp)`；它返回**实际读到的元素个数**，可用于判断文件是否读到头或读错。

### 5. 用本题的数据走一遍文件指针

样例 1 的 `loads.bin` 逻辑布局是：第 0～3 字节为整数 `5`，第 4～43 字节依次是 5 个 `double`。`fopen` 后位置指针在 0 字节处。`fread(&n, sizeof(int), 1, fp)` 读走 4 字节，`n` 变成 5，指针移到第 4 字节；`fread(a, sizeof(double), 5, fp)` 从第 4 字节起连续读 40 字节，把 5 个数装进 `a[0..4]`，指针移到第 44 字节（文件末尾）。随后遍历数组算统计量。**读的顺序与写的顺序完全一致，文件位置指针自动后移，每一步都严丝合缝。**

## 三、解题思路

1. **打开**：`fp = fopen("loads.bin", "rb")`，判空；
2. **读个数**：`fread(&n, sizeof(int), 1, fp);`
3. **读数组**：`fread(a, sizeof(double), n, fp);`，随后 `fclose(fp)`；
4. **统计**：先把 `a[0]` 当作当前最大最小，遍历累加求和、逐项比较更新最值；
5. **输出**：`mean = sum / n`，按 2 位小数输出四个结果。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;                 /* 二进制文件指针 */
    int    n, i;              /* n 为读回的个数 */
    double a[100];            /* 阻力数组 */
    double sum = 0.0, mean;   /* 累加和与均值 */
    double maxv, minv;        /* 最大值、最小值 */

    /* 以"二进制读"模式打开文件 */
    fp = fopen("loads.bin", "rb");
    if (fp == NULL) {
        printf("无法打开文件 loads.bin\n");
        return 1;
    }

    fread(&n, sizeof(int), 1, fp);      /* 先读记录个数 n */
    fread(a, sizeof(double), n, fp);    /* 再一次性读回整个数组 */
    fclose(fp);

    /* 遍历统计：求和、最值（与写入顺序一一对应） */
    maxv = minv = a[0];
    for (i = 0; i < n; i++) {
        sum += a[i];
        if (a[i] > maxv) maxv = a[i];
        if (a[i] < minv) minv = a[i];
    }
    mean = sum / n;

    printf("读入 %d 个阻力值\n", n);
    printf("均值 = %.2f\n",   mean);
    printf("最大值 = %.2f\n", maxv);
    printf("最小值 = %.2f\n", minv);

    return 0;
}
```

## 五、运行验证

**样例 1：运行前** `loads.bin` 由练习 06 样例 1 生成，逻辑内容为整数 `5` 加 `12.5 18.3 9.75 21.0 15.5`。

屏幕输出：
```
读入 5 个阻力值
均值 = 15.41
最大值 = 21.00
最小值 = 9.75
```
核对：和 $= 12.5+18.3+9.75+21.0+15.5 = 77.05$，均值 $= 77.05/5 = 15.41$；最大 $21.0$、最小 $9.75$。与输出一致，说明二进制写—读闭环正确。文件内容不被修改（只用 `"rb"` 读）。

**样例 2：运行前** `loads.bin` 逻辑内容为整数 `3` 加 `10.0 20.0 30.0`。

屏幕输出：
```
读入 3 个阻力值
均值 = 20.00
最大值 = 30.00
最小值 = 10.00
```
和 $= 60.0$，均值 $= 20.0$，与输出一致。

## 六、常见错误与讲解

**错误 1：用文本模式 `"r"` 读二进制文件**

```c
fp = fopen("loads.bin", "r");    /* 错：文本模式可能与内存字节布局不符 */
fp = fopen("loads.bin", "rb");   /* 对：模式串带 b */
```
文本模式在部分平台会对换行字节做转换，读出来的数会"面目全非"。**二进制文件一律用带 `b` 的模式。**

**错误 2：读取顺序与写入顺序不一致**

```c
fread(a, sizeof(double), n, fp);   /* 错：没先读 n，后面的读取整体错位 */
fread(&n, sizeof(int), 1, fp);     /* 对：先读个数再读数组 */
```
练习 06 是先写 `n` 再写数组，本题就必须先读 `n` 再读数组。顺序一乱，读到的是把整数 5 当成某 4 个字节、把数据当整数用，结果全是垃圾。

**错误 3：`fread` 参数顺序写反**

```c
fread(a, sizeof(double), n, fp);   /* 对：地址、单元素字节数、元素个数、文件指针 */
fread(a, n, sizeof(double), fp);   /* 错：个数与字节数写反 */
```

**错误 4：`fopen` 不判空、忘记 `fclose`**

```c
fp = fopen("loads.bin", "rb");
fread(&n, sizeof(int), 1, fp);      /* 错：fp 可能为 NULL */
```
文件不存在时程序应给出提示而不是崩溃；读完及时 `fclose` 释放系统资源。

## 七、与综合实验的衔接

实验 C7 每次启动统计模块时，都先用本练习的方式把上次存下的载荷数组二进制读回，再做统计与辨识；C9 的压力网格、B2 的信号序列也走同一条路。**练习 06 与 07 合起来，就是"数组持久化"的完整闭环**：写得出、读得回、数据不失真。这也让"程序运行一次、随时重启继续算"成为可能。若数据量极大、还要多用户按条件检索，第 8 章 8.7 节的数据库技术能在文件之上提供更系统的持久化与查询能力。
