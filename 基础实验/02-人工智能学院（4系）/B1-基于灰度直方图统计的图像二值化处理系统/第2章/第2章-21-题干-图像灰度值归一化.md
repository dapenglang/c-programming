# 第 2 章 练习 21　图像灰度值归一化

**所属综合实验**：B1（B1-基于灰度直方图统计的图像二值化处理系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 B1《基于灰度直方图统计的图像二值化处理系统》（人工智能学院）——本练习是该实验中"灰度数据预处理"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

机器视觉系统处理图像时，最先拿到的是一个一个的像素。灰度图像里，每个像素的亮度用一个 0～255 的整数表示：0 是全黑，255 是全白，中间的数字代表不同的灰。

可很多后续计算（比如求平均亮度、比较两幅图、设置阈值比例）更习惯用 0～1 之间的小数，因为这样数值范围统一、便于比较。于是图像处理的第一个环节，就是把灰度值从 0～255 的整数**归一化**到 0～1 的实数。B1 图像二值化系统在统计直方图之前，就要先做这一步换算。

## 二、任务要求

编写一个完整程序 `gray_normalize.c`：

1. 程序中用**常量**存放灰度满值 255.0；
2. 从键盘读入一个像素的灰度值 `g`（整数，**题目保证 0 ≤ g ≤ 255**，因此不需要判断分支）；
3. 用公式 $g_{norm} = g / 255.0$ 计算归一化灰度；
4. 按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个整数，表示像素灰度值 g（0～255）。

**输出**：一行，按格式 `gray_norm = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
128
```
输出：
```
gray_norm = 0.5020
```

**样例 2**

输入：
```
51
```
输出：
```
gray_norm = 0.2000
```

## 五、提示

归一化公式：

$$
g_{norm} = \frac{g}{255}
$$

这里唯一的陷阱是 C 语言的整数除法：若 $g$ 是 `int`，$255$ 也写成整数，那么 $\frac{128}{255}$ 会被算成 $0$。**分母一定要写成 `255.0`**，或者先把 $g$ 转成 `double`，除法就会自动按实数进行。

**完成本练习后你将具备的能力**：区分整数类型与实数类型、理解整数除法与实数除法的差别、书写算术表达式、用 scanf/printf 完成输入输出——这些是实验 B1 中"灰度预处理模块"的地基。
