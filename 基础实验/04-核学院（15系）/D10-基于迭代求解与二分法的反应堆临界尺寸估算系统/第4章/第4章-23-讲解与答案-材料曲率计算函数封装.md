## 二、预备知识：函数、形参实参、值传递（零基础阅读）

### 1. 问题是怎么来的

在 `main` 里直接写 `Bm2 = (k - 1.0) / (L * L);` 完全能跑。那为什么还要"封装成函数"？想象 D10 的完整程序：二分法要迭代几十次，每次都要算一次材料曲率；参数扫描要对十几组 $(k, L)$ 各算一遍。于是同一行公式会出现在三四个地方。

坏处有两个：一是**改公式要改多处**，漏改一处就前后不一致；二是**读代码的人无法一眼看出"这一行在干什么"**——`(k-1.0)/(L*L)` 到底是什么物理量？函数名 `matCurv` 就替我们回答了这个问题。

**封装 = 给一段计算起个有意义的名字，并规定它的输入输出。**

### 2. 函数的四个部分

```c
double matCurv(double k, double L)   /* ①返回类型 ②函数名 ③参数表 */
{
    return (k - 1.0) / (L * L);      /* ④函数体：算出结果并通过 return 交出去 */
}
```

逐项读：

- **返回类型 `double`**：说明这个函数会"交回"一个实数。`void` 表示不交回任何东西；本题要交回 $B_m^2$，所以是 `double`；
- **函数名 `matCurv`**：调用时的"暗号"，要含义明确（material curvature 的缩写）；
- **参数表 `(double k, double L)`**：说明调用时要"递进来"两个实数；括号里的 `k`、`L` 叫**形参**（形式参数），是函数内部使用的名字；
- **`return`**：把算好的值交给调用者。**函数遇到 `return` 就立即结束并返回**。

### 3. 形参、实参与"值传递"

调用时写：

```c
Bm2 = matCurv(k, L);
```

这里的 `k`、`L` 是 `main` 里的变量，叫**实参**（实际参数）。C 语言按**位置**对应：第一个实参给第一个形参，第二个给第二个。

**值传递**的含义是：调用时，系统把实参的**值**复制一份给形参。此后函数内部对形参的任何修改，都只改那份复制品，**不会影响 `main` 里的原变量**。

```c
double matCurv(double k, double L)
{
    k = 999.0;              /* 改的是复制品，main 里的 k 一点没变 */
    return (k - 1.0) / (L * L);
}
```

这一点很重要：**函数是"只读输入、返回输出"的，天然不会破坏调用者的数据**（除数组等特殊情况外）。这也是它比"到处改写全局变量"安全得多的原因。

顺带说明：**形参名与实参名相同完全没问题**。`main` 里的 `k` 与 `matCurv` 的形参 `k` 是两个互不相干的变量，只是恰好同名。函数内部的 `k` 属于函数的**局部作用域**，出了函数就消失。

### 4. 为什么要写函数声明

```c
double matCurv(double k, double L);      /* 声明（原型）：放在 main 之前 */
```

声明的作用是"**提前告诉编译器这个函数长什么样**"：返回什么类型、要几个什么类型的参数。这样 `main` 里用到 `matCurv` 时，编译器才知道该检查实参类型对不对、返回值该按什么类型用。

若把函数定义写在 `main` **之前**，定义本身就起了声明的作用，可以不再单独写声明；若写在 `main` **之后**，则必须在 `main` 之前补一行声明。本题要求写声明，就是为了让你熟悉这个约定。

> **这个思想在综合实验中反复出现**：D10 的 `matCurv`、`geomCurv`（几何曲率）与 `residual`（残差）三个函数、D6 的 `trans`（透射率）、D7 的剂量率函数，全部是"一个物理量一个小函数"。**先有清晰的函数接口，才有可靠的数值程序。**

## 三、解题思路

1. **定义函数**：`double matCurv(double k, double L) { return (k - 1.0) / (L * L); }`；
2. **写函数声明**：在 `main` 之前写 `double matCurv(double k, double L);`；
3. **在 main 中读入**：`scanf("%lf %lf", &k, &L);`；
4. **调用并接收返回值**：`Bm2 = matCurv(k, L);`；
5. **输出**：`printf("Bm2 = %.6f\n", Bm2);`。

## 四、参考代码

```c
#include <stdio.h>

/* 函数声明（原型）：说明 matCurv 接收两个 double，返回一个 double */
double matCurv(double k, double L);

int main(void)
{
    double k, L;        /* 增殖因子、扩散长度（cm） */
    double Bm2;         /* 材料曲率，cm^-2 */

    /* 读入两个材料参数 */
    scanf("%lf %lf", &k, &L);

    /* 调用函数求材料曲率：实参按位置传给形参 k、L，返回值赋给 Bm2 */
    Bm2 = matCurv(k, L);

    /* 输出，保留 6 位小数 */
    printf("Bm2 = %.6f\n", Bm2);

    return 0;
}

/* 函数定义：只做计算，不做任何输入输出（模块化设计纪律） */
double matCurv(double k, double L)
{
    /* 材料曲率 Bm2 = (k - 1) / L^2，平方用乘法，分子加括号 */
    return (k - 1.0) / (L * L);
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 1.20 5.0 | 形参 k=1.20、L=5.0 → (0.20)/25 = 0.008000 | `Bm2 = 0.008000` ✓ |
| 1.50 4.0 | 形参 k=1.50、L=4.0 → (0.50)/16 = 0.031250 | `Bm2 = 0.031250` ✓ |
| 1.05 5.0 | 形参 k=1.05、L=5.0 → (0.05)/25 = 0.002000 | `Bm2 = 0.002000` ✓ |
| 1.20 2.0 | 形参 k=1.20、L=2.0 → (0.20)/4 = 0.050000 | `Bm2 = 0.050000` ✓ |

四例结果与练习 29（第 2 章）直接写公式的结果**完全一致**——说明函数封装的只是"组织形式"，计算内容一字未变。**封装不改变结果，只改变代码的结构。**

**验证值传递**：把函数体临时改成 `k = 999.0; return (k - 1.0) / (L * L);` 再跑样例 1，函数返回 998.0/25 = 39.92，但 `main` 中输出的 `k`（若打印）仍是 1.20——**证实形参是复制品。**

## 六、常见错误与讲解

**错误 1：漏写函数声明或返回类型**

```c
matCurv(double k, double L);                 /* 错：漏了返回类型 double */
double matCurv(double k, double L);          /* 对 */
```

漏掉返回类型时，老式编译器会默认返回 `int`，导致返回值被截断为整数（0.008 变成 0），**结果全错但不报错**。

**错误 2：函数定义漏写 `return` 或返回类型与 return 表达式不符**

```c
double matCurv(double k, double L)
{
    double r = (k - 1.0) / (L * L);      /* 算了但没返回 */
}                                        /* 错：返回类型是 double 却没有 return，结果未定义 */

double matCurv(double k, double L)
{
    return (k - 1.0) / (L * L);          /* 对 */
}
```

**错误 3：在函数里做输入输出**

```c
double matCurv(double k, double L)
{
    double r = (k - 1.0) / (L * L);
    printf("Bm2 = %f\n", r);             /* 不推荐：函数职责不单一，复用困难 */
    return r;
}
```

一旦函数里带 `printf`，二分法迭代 50 次就会打印 50 行无用信息。**函数只算、不打印；打印留给调用者决定。**

**错误 4：调用时把实参类型传错或漏传**

```c
Bm2 = matCurv(k);                        /* 错：少传一个参数，编译报错 */
Bm2 = matCurv(k, L);                     /* 对 */
printf("Bm2 = %f\n", matCurv);           /* 错：漏了括号，输出的是函数地址而非返回值 */
```

**错误 5：公式里用 `^` 表示平方**

```c
return (k - 1.0) / (L ^ 2);              /* 错：^ 是位异或 */
return (k - 1.0) / (L * L);              /* 对 */
```

## 七、与综合实验的衔接

- 实验 **D10（反应堆临界尺寸估算系统）**中，本练习是"计算模块化"的第一步：真实系统会把三个物理量各封装成一个函数——`matCurv(k, L)` 算材料曲率、`geomCurv(R)` 算几何曲率（练习 24 第 4 章）、`residual(k, L, R)` 算残差。**有了这三个函数，二分法的主循环才能写得干净利落**（每轮只需调两次函数、比一次符号）；
- 与前面练习的衔接：练习 29（第 2 章）先在 `main` 里把公式写通，本练习把它搬进函数——**同一条公式，两种组织方式**，这正是本章要体会的"模块化"。练习 22（第 4 章，D6 的透射率封装）用的是完全相同的套路，只是物理量不同。练习 24（第 4 章）将把几何曲率也封装好，并用这两个函数搭出完整的二分法求根程序。**从"能算"到"好维护"，就是函数封装的收获。**
