# 第 8 章 练习 03　数据表格格式化读写

**对应章节**：8 数据持久化存储方法（8.3 文件的打开与关闭、8.4 文件的读写——`fprintf`/`fscanf`）

**场景来源**：综合实验 C9《冰面压力场热点分析系统》（水声学院）——本练习是该实验中"压力测点表格单位换算与转存"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰面压力场系统采集到的测点压力，原始记录常以 kPa 为单位保存在表格文件里；而结构强度计算模块要求统一用 Pa。于是程序要做一件很典型的事：**读一张表、逐条处理后、把结果写成另一张表**。这就是"数据表格格式化读写"。本练习读入 `pressure.txt`（单位 kPa），把每条压力值乘 1000 换算成 Pa，写出新表 `pressure_pa.txt`，两个文件都保留"测点号 压力值"的两列结构。

## 二、任务要求

编写一个完整程序 `convert_table.c`：

1. 以只读模式打开输入文件 `pressure.txt`，以写模式新建输出文件 `pressure_pa.txt`，两个文件都要检查是否打开成功；
2. 循环从输入文件读入记录，直到文件结束，记录只有两列：测点号（整数）、压力值（实数，单位 kPa）；
3. 对每条记录，把压力值乘以 1000 换算为 Pa，再用 `fprintf` 把"测点号 压力值(Pa)"写入输出文件，保留 2 位小数；
4. 两个文件都关闭后，在屏幕上报告一共转换了多少条记录。

**数据文件格式约定**

- 输入文件名：`pressure.txt`；输出文件名：`pressure_pa.txt`
- 均为纯文本文件，每行一条记录
- 每行两个字段：第 1 个是整数测点号，第 2 个是实数压力值
- 两个字段之间用**一个空格**分隔，行末换行
- 样例数据行：`1 12.50`

## 三、输入输出格式

**输入**：程序不从键盘读数据，输入全部来自文件 `pressure.txt`。

**输出**：屏幕只输出一行汇总 `转换完成，共 X 条记录，已写入 pressure_pa.txt`；转换后的数据表写入文件 `pressure_pa.txt`。

## 四、样例

**样例 1**

`pressure.txt` 的内容：
```
1 12.5
2 18.3
3 9.75
```
程序运行后，`pressure_pa.txt` 的内容为：
```
1 12500.00
2 18300.00
3 9750.00
```
屏幕输出：
```
转换完成，共 3 条记录，已写入 pressure_pa.txt
```

**样例 2**

`pressure.txt` 的内容：
```
101 5.5
102 7.25
```
程序运行后，`pressure_pa.txt` 的内容为：
```
101 5500.00
102 7250.00
```
屏幕输出：
```
转换完成，共 2 条记录，已写入 pressure_pa.txt
```

## 五、提示

- 同时操作两个文件就要两个指针：`FILE *fin, *fout;`，分别对应输入与输出；
- 打开输入用 `fopen("pressure.txt", "r")`，打开输出用 `fopen("pressure_pa.txt", "w")`；
- 判断"读到文件末尾"的常用写法是 `while (fscanf(fin, "%d%lf", &id, &p) == 2)`：只要还成功读到 2 个字段就继续循环，读到末尾时 `fscanf` 返回值不再是 2，循环自然结束；
- 每读一条就换算、写一条，不需要把整张表存进数组；
- 两个文件都要 `fclose`；若第二个文件打开失败，记得先关掉已经打开的输入文件再返回。

**完成本练习后你将具备的能力**：同时管理输入与输出两个文件、用 `fscanf` 的返回值控制"读到文件尾就停"的循环、用 `fprintf` 把处理结果写成新表——这是实验 C9 中"数据格式转换、结果转存"这类模块的通用骨架。
