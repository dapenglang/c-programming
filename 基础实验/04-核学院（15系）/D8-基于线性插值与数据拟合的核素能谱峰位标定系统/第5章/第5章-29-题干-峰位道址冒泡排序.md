# 第 5 章 练习 29　峰位道址冒泡排序

**所属综合实验**：D8（D8-基于线性插值与数据拟合的核素能谱峰位标定系统）

**对应章节**：5 数组与批量数据处理（5.2 数组遍历、5.4 排序——冒泡排序）

**场景来源**：综合实验 D8《基于线性插值与数据拟合的核素能谱峰位标定系统》（核学院）——本练习是该实验中"峰位按道址排序输出"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

一次测量可能找到好几个峰，它们的道址是**乱序**的（寻峰是逐道扫过去的，谁先被找到说不准）。但输出峰位表时，习惯上要**按道址从小到大排列**——这样能量也从小到大，读起来一目了然，也便于与核素特征能量逐一对齐。

综合实验 D8 里，找到峰位后会把它们的道址排好序再输出。本题要求用**冒泡排序**把一组峰位道址按**从小到大**排列——这是 D8 中"峰位排序"模块的最小实现。

## 二、任务要求

编写一个完整程序 `peak_sort.c`：

1. 从键盘读入峰个数 `n`（**题目保证 2 ≤ n ≤ 20**），再读入 `n` 个道址（整数）存入数组 `ch[20]`；
2. 用**冒泡排序**把道址按**从小到大**排列；
3. 输出排序后的道址，每个后跟一个空格。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个整数，为各峰的道址，用空格分隔。

**输出**：一行，为从小到大排序后的道址，每个后跟一个空格。

## 四、样例

**样例 1**

输入：
```
5
888 441 782 100 1332
```
输出：
```
100 441 782 888 1332 
```

**样例 2**

输入：
```
4
50 10 40 20
```
输出：
```
10 20 40 50 
```

## 五、提示

**冒泡排序**（从小到大）的思路：每一趟把"未排好部分里最大的元素"一路**冒泡**到末尾，像水里的气泡浮上来：

```c
for (i = 0; i < n - 1; i++) {              /* 共 n-1 趟 */
    for (j = 0; j < n - 1 - i; j++) {      /* 每趟比较相邻两元素 */
        if (ch[j] > ch[j + 1]) {           /* 前大后小 → 交换 */
            tmp = ch[j];
            ch[j] = ch[j + 1];
            ch[j + 1] = tmp;
        }
    }
}
```

- 内层比较的是**相邻**两元素 `ch[j]` 与 `ch[j+1]`，逆序（前 > 后）就交换；
- 内层上界是 `n - 1 - i`：每趟结束，末尾 `i+1` 个元素已经排好，不用再比；
- 交换需要临时变量 `tmp`；
- 想一想：一趟扫过之后，最大的元素一定"冒"到了最右边（因为它每遇到比它小的就换到右边）。所以一趟排好一个元素，最多 `n-1` 趟就全部有序。

**与选择排序的对照**（练习 27 第 5 章用的是选择排序）：选择排序每趟只交换一次（先找最大下标再换）；冒泡排序每趟可能交换多次（边比边换）。两者都能排好序，冒泡更简单直观、代码更短，但交换次数通常更多。

**完成本练习后你将具备的能力**：用冒泡法对数组排序、理解"相邻比较 + 交换"的排序结构、对照两种排序算法的差异——这些是实验 D8 中"峰位排序模块"的地基。
