## 二、预备知识：`static` 局部变量的生命周期与可见性（零基础阅读）

### 1. 一个函数里的变量，默认"活"多久

在函数里写的普通变量，例如 `int hit;`，叫作**自动变量**（auto）。它的生命很短：**函数一开始执行就诞生，函数一返回就消失**。下一次再调用这个函数，它会被重新造一个、重新初始化。所以如果写成 `int cnt = 0;`，无论调用多少次，`cnt` 每次都从 0 开始，永远记不住历史。

### 2. static 局部变量：值"搬不走"

如果在变量前加关键字 `static`，例如 `static int cnt = 0;`，它的性质就变了：

- **初始化只做一次**。程序运行到这里时创建并为它赋初值 0，之后再调用函数，这一行不再执行（初值不会重设）；
- **生命周期贯穿整个程序**。函数返回时它不会被销毁，而是"留在原地"保留着上次的值，等下次函数再进来时继续用；
- **可见性仍然只在本函数内**。别的函数（包括 `main`）都看不见、也不能直接读写它。它就像一个"只属于这个函数、但能记住历史"的抽屉。

一句话概括：**`static` 局部变量 = 被限制在本函数内使用的"长寿变量"**。它既不像自动变量那样"每次归零"，也不像全局变量那样"人人可见"。

### 3. 为什么本题非它不可

题目要求"每次调用检测函数时输出这是第几次"。若把计数器放在 `main` 的循环里（例如用 `i`），当别的模块也调用 `detect` 时序号就会乱；而全局变量又会污染命名空间、让别人误改。`static` 局部变量恰好两头都占：计数逻辑封装在函数内部，调用者无须操心，同时又能跨调用累加。这正是工程上"把一个统计量封在它所属的模块里"的常见写法。

### 4. 在本题里走一遍

第一次调用 `detect`：`cnt` 从初始值 0 加 1 变成 1，输出 `call 1: ...`；函数返回，`cnt=1` 被保留。第二次调用：`cnt` 加 1 变成 2，输出 `call 2: ...`。可见尽管每一次函数体都"重新开始"，`cnt` 却一直记得上次的数——这就是"静态存储"与"自动存储"最直观的差别。

## 三、解题思路

1. **定接口**：`int detect(double d, double r1, double r2)`，返回 0/1，计数用内部 `static int cnt`；
2. **先计数后判断**：进入函数先 `cnt++`，这样第一次就是 1；再用条件表达式算出 `hit`；
3. **一处输出**：在函数内部直接 `printf`，把序号和结果一起打印，`main` 不必再处理；
4. **主控在 main**：读 `n`，循环 `n` 次读三个数并调用 `detect`，验证"序号跨调用累加"这一现象。

## 四、参考代码

```c
#include <stdio.h>

/* 碰撞检测：每次调用累计次数（static 局部变量），并返回是否碰撞 */
int detect(double d, double r1, double r2)
{
    static int cnt = 0;            /* 只初始化一次，函数返回后仍保留 */
    int hit;                       /* 普通自动变量，每次调用重新生成 */

    cnt = cnt + 1;                 /* 累计第几次调用 */
    hit = (d < r1 + r2) ? 1 : 0;   /* 中心距小于半径和即判定碰撞 */
    printf("call %d: hit = %d\n", cnt, hit);
    return hit;
}

int main(void)
{
    int n, i;
    double d, r1, r2;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf %lf %lf", &d, &r1, &r2);   /* 读入一组船-冰参数 */
        detect(d, r1, r2);                    /* 注意：不接收返回值也可以调用 */
    }
    return 0;
}
```

## 五、运行验证

以样例 1（`n = 3`）和样例 2（`n = 2`）输入为例，逐次调用的情况如下：

| 本次输入 `d r1 r2` | $r_1+r_2$ | 判定 $d<r_1+r_2$ | 程序输出 |
|---|---|---|---|
| 5.0 2.0 1.5 | 3.5 | 假 | `call 1: hit = 0` |
| 3.0 2.0 1.5 | 3.5 | 真 | `call 2: hit = 1` |
| 8.5 2.0 1.5 | 3.5 | 假 | `call 3: hit = 0` |
| 3.0 2.0 2.0 | 4.0 | 真 | `call 1: hit = 1` |
| 4.5 2.0 2.0 | 4.0 | 假 | `call 2: hit = 0` |

注意第 4、5 行是新一次运行（重新开始计数），所以序号又回到 1——`static` 变量只在**同一次程序运行**内累加。若把 `static` 去掉，则每次进入函数 `cnt` 都从 0 开始，输出会变成连续多个 `call 1`，与上表不符，可用这一现象自检。

## 六、常见错误与讲解

**错误 1：把计数器写成普通自动变量**

```c
int cnt = 0;            /* 错：每次调用都重新置 0，输出永远是 call 1 */
static int cnt = 0;     /* 对：只初始化一次，能跨调用累加 */
```

这是最典型的错误。判断标准很简单：**需要跨调用记住的东西，才加 `static`**。

**错误 2：误以为 `static` 会让 `main` 也能看见 `cnt`**

```c
printf("%d", cnt);      /* 在 main 里写：编译报错，cnt 未定义 */
```

`static` 只改变"活多久"，不改变"谁能看见"。`cnt` 仍然只能在 `detect` 内部使用。想让 `main` 拿到调用次数，应让函数通过 `return` 把值交出去（本题返回的是 0/1，如需次数可另设返回）。

**错误 3：`scanf` 漏写取地址符或格式符不匹配**

```c
scanf("%lf %lf %lf", d, r1, r2);       /* 错：少了 & */
scanf("%d %d %d", &d, &r1, &r2);       /* 错：double 必须用 %lf */
```

**错误 4：把 `n` 的读入写成每次循环都读**

```c
for (i = 0; i < n; i++) {
    scanf("%d", &n);            /* 错：n 只需在循环外读一次 */
    ...
}
```
