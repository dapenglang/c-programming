## 二、预备知识：关系运算、绝对值与多条件判定

### 1. 问题是怎么来的

数据筛查的本质是给每个样本组回答一个是非题："这组数据可信吗？"回答依据是若干条**可量化的判据**：数值是否越上限、变化是否过于剧烈。每条判据都能写成一个取值为真/假的 C 表达式，最后把各判据用"或"合并——任一为真即异常。这是工程中最常见的"多判据一票否决"结构。

### 2. 绝对值为什么需要、怎么手写

突跳规则要求比较的是相邻样本**变化的幅度**，与升降方向无关：从 700 涨到 790 和从 790 跌到 700 同样异常。幅度就是差的绝对值 $|f_1 - f_2|$。第 3 章还没有介绍数学库，绝对值用选择结构三行就能实现：

```c
d = f1 - f2;      /* 先算出带符号的差 */
if (d < 0.0)
    d = -d;       /* 差为负说明是下降，取反后即幅度 */
```

原理：$|x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}$。其中一元负号 `-d` 是第 2 章学过的单目运算符，把正数变负、负数变正。

### 3. 关系运算符的返回值

C 语言中关系表达式本身就是值：条件成立得 1，不成立得 0。`f1 > 850.0` 这个式子求值后就是 0 或 1，可以直接参与逻辑运算，因此

```c
if (f1 > F_MAX || f2 > F_MAX || f3 > F_MAX || d1 > JUMP || d2 > JUMP)
```

一条 if 就容纳了全部五项检查，逻辑上等价于"五项检查逐个做，任何一项命中即异常"。

### 4. "严格大于"与阈值的关系

题面说"超过 850 判异常"，物理含义是 850.0 本身仍属正常（正好满量程不算超），所以必须写 `>` 而不是 `>=`。同理突跳阈值 60.0 也用 `>`。**读题时把每个比较的边界归属看清楚**，是筛查类程序的死规矩。

## 三、解题思路

1. **定义常量**：上限阈值 850 与突跳阈值 60 用 `const double`，它们是规程值；
2. **读入三个样本**；
3. **手算两个幅度**：`d1 = |f1 - f2|`、`d2 = |f2 - f3|`，各用"相减 + 负则取反"实现；
4. **合并判定**：五项越界/突跳条件用 `||` 串成一个 if 条件；
5. **输出**：条件成立输出 `abnormal`，else 输出 `normal`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double F_MAX = 850.0;   /* 样本上限阈值，kN */
    const double JUMP  = 60.0;    /* 相邻样本突跳限值，kN */

    double f1, f2, f3;            /* 连续三个阻力样本，kN */
    double d1, d2;                /* 相邻差值的绝对值，kN */

    scanf("%lf %lf %lf", &f1, &f2, &f3);

    d1 = f1 - f2;                 /* 手写绝对值：先相减 */
    if (d1 < 0.0)
        d1 = -d1;                 /* 负差取反 */
    d2 = f2 - f3;
    if (d2 < 0.0)
        d2 = -d2;

    if (f1 > F_MAX || f2 > F_MAX || f3 > F_MAX || d1 > JUMP || d2 > JUMP)
        printf("abnormal\n");
    else
        printf("normal\n");

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `800 810 790` | 最大 810 ≤ 850；$d_1 = 10$、$d_2 = 20$ 均 ≤ 60 | `normal` ✓ |
| `700 790 700` | 三个值均 ≤ 850；$d_1 = \lvert 700-790\rvert = 90 > 60$ → 突跳触发 | `abnormal` ✓ |
| `860 800 790` | $f_1 = 860 > 850$ → 上限触发 | `abnormal` ✓ |
| `850 850 850` | $850 > 850$ 不成立（严格大于）；$d_1 = d_2 = 0$ | `normal` ✓ |
| `790 700 760` | $d_1 = \lvert 790-700\rvert = 90 > 60$（下降同样算突跳） | `abnormal` ✓ |

第 4、5 行分别验证了"严格大于的边界归属"与"绝对值与方向无关"。

## 六、常见错误与讲解

**错误 1：绝对值漏了取反分支**

```c
d1 = f1 - f2;               /* 错：若 f1 < f2，d1 为负，任何比较都判不出突跳 */
if (d1 > JUMP) ...
```

下降型突跳（`790 700 760`）会漏检。没有 if 取反，`d1` 不是绝对值。

**错误 2：把"或"写成逐条 if 各自输出**

```c
if (f1 > F_MAX) printf("abnormal\n");
if (f2 > F_MAX) printf("abnormal\n");   /* 错：多条规则同时触发会输出多次 */
```

多条规则应合并进**同一个** if 条件，保证结果只输出一次。

**错误 3：阈值写成 `>=`**

`f1 >= 850.0` 会把恰好 850 的正常样本误判异常。边界归属（本题：恰好等于阈值算正常）要以题面为准，逐条核对。

**错误 4：绝对值手写成"永远取正的加减游戏"**

```c
d1 = f2 - f1;               /* 错：只解决了一个方向 */
d1 = f1 > f2 ? ...          /* 错：条件运算符尚未学到，不必提前 */
```

就用"相减 + if 取反"的标准两步，简洁且不易错。
