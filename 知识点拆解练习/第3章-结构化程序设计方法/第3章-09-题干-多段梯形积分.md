# 第 3 章 练习 09　多段梯形积分（循环 + 积分）

**对应章节**：3 结构化程序设计方法（3.3 循环结构——for 循环、3.5 数值积分——复合梯形公式）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"由速度采样求船模位移"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰池拖曳试验要测量船模破冰过程中的**位移**。测量系统不能直接测位移，只能以固定时间间隔 $\Delta t$ 采样船模的瞬时速度 $v$——比如每 0.5 秒记录一次。位移是速度对时间的积分 $s = \int v\,dt$，而离散的速度采样点之间的真实速度曲线是未知的。工程上的标准做法：把相邻两个采样点之间的速度看成线性变化（梯形近似），每段算一个小梯形面积，全部相加就是位移——这就是**复合梯形公式**，也是实验 C7 由试验数据反推位移、冲量的核心算法。

## 二、任务要求

编写一个完整程序 `disp_trap.c`：

1. 第一行读入两个数：采样段数 `n`（整数，**题目保证 $1 \le n \le 100$**）与采样间隔 `dt`（实数，秒）；
2. 随后读入 $n + 1$ 个实数：各时刻的瞬时速度 $v_0, v_1, \ldots, v_n$（单位 m/s，按时间顺序）；
3. 用复合梯形公式计算总位移：第 $i$ 段（$i = 1 \sim n$）的位移为 $\dfrac{(v_{i-1} + v_i)\,\Delta t}{2}$，n 段累加；
4. 按格式输出总位移，保留 3 位小数。

## 三、输入输出格式

**输入**：第一行两个数 n 与 dt，以空格分隔；第二行 $n+1$ 个实数，以空格分隔。

**输出**：一行，格式为 `s = 位移`，保留 3 位小数。

## 四、样例

**样例 1**

输入：
```
4 0.5
0 2.0 3.5 4.5 5.0
```
输出：
```
s = 6.250
```

**样例 2**

输入：
```
3 1.0
0.0 1.2 2.4 3.0
```
输出：
```
s = 5.100
```

## 五、提示

循环里只需要**当前点与前一个点**两个速度值，不需要把全部采样点都记住：

```c
prev = 第 1 个速度;
for (i = 1; i <= n; i = i + 1) {
    scanf("%lf", &v);            /* 读入下一个时刻的速度 */
    s = s + (prev + v) / 2.0 * dt;   /* 本段梯形面积累加 */
    prev = v;                    /* 当前点变成下一段的前一点 */
}
```

"读新点 → 算本段 → 旧点让位"的三步节奏是数据流积分的标准写法。

**完成本练习后你将具备的能力**：用循环实现复合梯形公式、只维护"前一点/当前点"两个状态处理数据流、把积分从单段公式推广到任意段数——这是实验 C7 位移计算模块的完整实现。
