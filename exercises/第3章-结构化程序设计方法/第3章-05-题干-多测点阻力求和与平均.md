# 第 3 章 练习 05　多测点阻力求和与平均（循环累加）

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.3 循环结构——for 循环、3.4 关系运算符）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》/ C9《冰压力场可视化系统》（水声学院）——本练习是该实验中"多测点载荷汇总"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰池模型试验在船模表面沿水线布置了多个测力传感器，每个传感器输出一个冰阻力样本（kN）。试验结束后，数据系统要做的第一件事就是**汇总**：把 n 个测点的读数加起来得到总阻力，再除以测点数得到平均阻力——总阻力用于与拖曳力对比校核，平均阻力用于绘制沿程载荷分布。测点数随模型方案变化（少则三个、多则上百个），汇总程序必须能处理**任意个数**的输入，这靠顺序书写 n 条加法显然行不通，必须引入循环。

## 二、任务要求

编写一个完整程序 `sum_mean.c`：

1. 从键盘先读入一个整数 `n`（测点个数，**题目保证 $1 \le n \le 100$**）；
2. 随后读入 n 个实数（每个测点的阻力值，单位 kN，`double` 类型）；
3. 用循环把 n 个值逐个累加到求和变量中，不允许写 n 条加法语句；
4. 输出总和 `sum`（保留 2 位小数）与平均值 `mean`（保留 4 位小数）。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，以空格分隔（也可以每行一个）。

**输出**：两行，格式分别为 `sum = 总和`（2 位小数）与 `mean = 平均值`（4 位小数）。

## 四、样例

**样例 1**

输入：
```
5
812.5 790.3 834.7 856.1 788.4
```
输出：
```
sum = 4082.00
mean = 816.4000
```

**样例 2**

输入：
```
3
755.0 760.5 744.5
```
输出：
```
sum = 2260.00
mean = 753.3333
```

## 五、提示

循环累加的骨架是"**累加器清零 → 循环 n 次：读一个加一个**"：

```c
sum = 0.0;
for (i = 1; i <= n; i = i + 1) {
    scanf("%lf", &f);
    sum = sum + f;
}
```

平均值在循环**结束后**再算，不要写进循环体里。

**完成本练习后你将具备的能力**：写 for 循环处理任意个数的输入、正确初始化与使用累加器、区分"循环内做"与"循环后做"的计算——这是实验 C7/C9 所有统计功能的最基础单元。
