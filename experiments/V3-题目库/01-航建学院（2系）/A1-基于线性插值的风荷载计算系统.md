# 题目 A1：基于线性插值的风荷载计算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套面向建筑结构设计的命令行风荷载计算工具。用户输入建筑的高度、层数、迎风面宽度、体型类别、地面粗糙度类别与重现期后，系统从"高度-风压高度变化系数"标准表中查值并线性插值，把建筑沿高度分成若干层，逐层计算风荷载标准值，最后汇总总风荷载、合力作用位置，并绘制风荷载沿高度分布图。

**解决什么重要问题**：风荷载是高层建筑与大跨结构设计的控制性水平荷载之一。荷载规范给出的是离散高度点上的风压高度变化系数（如 10 m 处 1.23、15 m 处 1.35），而实际建筑高度、各层标高几乎不会恰好落在表格节点上——不解决"任意高度取值"问题，设计就无法进行；同时风荷载沿高度逐层分布，抗侧力构件（剪力墙、框架柱）的配筋必须知道每一层承担多大水平力，只算总量是不够的。若风荷载算小了，结构在台风中有倾覆与变形超限风险；算大了则材料浪费、造价上升。

**支撑哪些关键应用**：① 框架、剪力墙结构施工图设计中风荷载工况的计算；② 塔架、烟囱、广告牌等高耸结构的基础设计；③ 结构有限元软件（如 PKPM、SAP2000）中风荷载自动加载模块的底层逻辑与本系统完全同构；④ 后续"结构力学""建筑结构设计""工程荷载与可靠度"等课程都要反复使用"查表 + 插值 + 分层累加"这套基本功。

**与专业培养的关联**：土木、建环、力学、航天专业均开设"工程荷载"或"结构设计基础"类课程。本系统让学生用 C 语言亲手实现规范查表法的完整流程，把课程中学到的线性插值（2.5 节）、数组查表、循环累加直接落到一个真实工程计算上，理解"设计软件 = 数据表 + 数值方法 + 程序组织"。

## 二、题目任务与专业关联

本题目面向土木工程与工程力学方向的学生，模拟结构设计前期的"风荷载标准值计算"场景。系统要实现的功能概述：① 交互录入建筑与场地参数；② 从文本文件读入四类地面粗糙度（A/B/C/D）的"高度-系数"表与体型系数表；③ 对任意层高标高做线性插值求 μz；④ 按重现期换算基本风压；⑤ 逐层计算风荷载标准值并汇总；⑥ 绘制分布字符图并输出结果报表。先导知识铺垫：教师提供《建筑结构荷载规范》GB 50009 中表 8.2.1（风压高度变化系数）的节选文本与风荷载标准值公式 wk = μz·μs·w0（本系统忽略风振系数或取常数），学生只需实现"查表—插值—乘系数—累加"。

## 三、数据来源与格式

**数据文件 1：风压高度变化系数表**（每个粗糙度类别一个文件：`windcoef_A.txt` ~ `windcoef_D.txt`）

```
地面粗糙度类别B 高度m 风压高度变化系数muz
0,1.00
5,1.09
10,1.23
15,1.35
20,1.46
30,1.65
```

**数据文件 2：体型系数表**（`shape_coef.txt`，体型代码 1~5 对应封闭式双坡屋面矩形平面建筑的五种典型体型）

```
体型代码,名称,体型系数us
1,矩形高层塔楼,1.30
2,矩形多层房屋,1.20
3,圆形塔楼,0.80
4,L形平面建筑,1.40
5,大跨屋盖(简化),0.60
```

**仿真数据生成规则**：
- 高度表：高度 z 取 0,5,10,15,20,30,40,50,60,80,100,120,150 m 共 13 行；类别 A 的 μz 从 1.17（10 m）按每 10 m 约 +0.13 递增到 2.20（150 m），类别 B 从 1.00 递增到 2.05，类别 C 从 0.74 递增到 1.70，类别 D 从 0.62 递增到 1.45（参照规范表 8.2.1 手工誊录即可）；数值保留两位小数；
- 异常注入：在 `windcoef_C.txt` 中故意把 40 m 行写成 `40,1.65`（照抄了 B 类值），并把 60 m 行的高度写成 `060`，用于训练"数据校验 + 错误提示"；
- 体型系数表如上 5 行固定，无需生成。

**真实数据集**：《建筑结构荷载规范》GB 50009-2012 表 8.2.1 与表 8.3.1（纸质规范或学校图书馆电子版，学生手工录入成上述文本格式）。

## 四、数据结构设计

```c
#define MAX_LAYER 60        /* 最大层数，建筑不高于 150 m */
#define MAX_ROW   20        /* 系数表最大行数 */

/* 建筑与场地参数（M1 交互录入） */
struct Building {
    char  name[32];         /* 工程名称，≤31 字符 */
    double height;          /* 总高 m，取值 10~150 */
    double width;           /* 迎风面宽度 m，取值 10~80 */
    double floorH;          /* 层高 m，取值 2.8~4.5 */
    int    nFloor;          /* 层数 = height/floorH 向上取整，≤MAX_LAYER */
    int    roughClass;      /* 粗糙度类别 1~4 对应 A~D */
    double w0;              /* 基本风压 kN/m2，取值 0.30~0.90 */
    int    returnPeriod;    /* 重现期 10/50/100 年 */
    int    shapeCode;       /* 体型代码 1~5 */
};

/* 高度-系数表的一行（M2 读入） */
struct WindRow {
    double z;               /* 高度 m，0~150 */
    double muz;             /* 风压高度变化系数，0.5~2.5 */
};

/* 每层计算结果（M6 填写） */
struct LayerResult {
    int    no;              /* 层号 1~nFloor，1 为底层 */
    double zMid;            /* 本层形心标高 m，取值 1~150 */
    double muz;             /* 插值得到的系数 */
    double wi;              /* 本层风荷载标准值 kN */
};
```

全局数组：`struct WindRow g_table[MAX_ROW]; int g_rowCnt;`、`struct LayerResult g_layer[MAX_LAYER];`、体型系数表用二维字符数组与 double 数组各一存放。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（3 个模块）

**M1 场地与建筑参数录入模块**（源文件 `ParamInput.c`）

- 功能简介：交互式逐项输入工程名称、总高、迎风面宽度、层高、粗糙度类别、基本风压、重现期与体型代码；对每个输入做范围检查（如总高必须在 10~150 m），不合法则要求重输；自动由总高与层高推算层数。
- 输入：键盘输入的 8 项参数。
- 输出：填充全局结构体 `g_bld`；屏幕回显参数清单。

**M2 风压高度变化系数表读入模块**（源文件 `WindTableIO.c`）

- 功能简介：根据 M1 选定的粗糙度类别拼出文件名（如 `windcoef_C.txt`），逐行读入"高度,系数"对并存入结构体数组；检查行数是否超界、高度是否递增，发现 M3 数据文件中的异常行时打印警告与行号。
- 输入：系数表文本文件。
- 输出：`g_table[]` 与行数 `g_rowCnt`；屏幕读入摘要（行数、高度范围）。

**M3 体型系数查表模块**（源文件 `ShapeTable.c`）

- 功能简介：读入 `shape_coef.txt`，按 M1 输入的体型代码查表返回体型系数 μs；代码越界（不在 1~5）时提示错误并允许重选；同时提供"打印全部体型供参考"的功能。
- 输入：`shape_coef.txt`、体型代码。
- 输出：全局变量 `g_shapeCoef`；屏幕查表结果。

### 第二部分：算法实现（4 个模块）

**M4 线性插值计算模块**（源文件 `Interp.c`）

- 功能简介：实现通用线性插值函数 `double interpMu(double z)`：在 `g_table[]` 中定位 z 所在区间 [z_k, z_{k+1}]，按公式 μz = μz_k + (μz_{k+1}-μz_k)·(z-z_k)/(z_{k+1}-z_k) 求值；z 低于首点或高于末点时分别返回端点值并打印"外推提示"；另提供单点交互测试入口（输入任意高度立即返回系数），便于单独调试。
- 输入：高度 z（m）。
- 输出：插值系数 μz；调试模式下的屏幕结果。

**M5 基本风压换算模块**（源文件 `WindPressure.c`）

- 功能简介：按重现期换算基本风压：R10 取 0.80 倍、R50 取 1.10 倍、R100 取 1.20 倍的 w0（其他重现期提示不支持）；换算前后风压与取值依据一并回显。
- 输入：`g_bld.w0`、`g_bld.returnPeriod`。
- 输出：换算后风压 `g_w0Adj`（kN/m²）。

**M6 分层风荷载计算模块**（源文件 `LayerCalc.c`）

- 功能简介：把建筑自底向上分成 nFloor 层，对每层形心标高 zMid = (i-0.5)·floorH 调用 M4 求μz，按 wi = μz·μs·w0_adj·(width·floorH) 逐层算风荷载标准值并填入 `g_layer[]`；打印各层中间量便于核对。
- 输入：`g_bld`、`g_w0Adj`、`g_shapeCoef`、插值函数。
- 输出：`g_layer[MAX_LAYER]`；屏幕逐层计算表。

**M7 层间汇总与总风荷载模块**（源文件 `SumLoad.c`）

- 功能简介：累加各层风荷载得总风荷载 F；按合力作用位置 zc = Σ(wi·zMid)/F 求荷载合力等效高度；另统计最大层荷载及其层号；结果存入全局汇总结构体。
- 输入：`g_layer[]`。
- 输出：总风荷载、合力高度、最大层荷载；屏幕汇总行。

### 第三部分：数据输出（3 个模块）

**M8 风荷载沿高度分布字符图模块**（源文件 `CharPlot.c`）

- 功能简介：以楼层为纵轴（自上而下打印），用 `*` 个数表示每层荷载大小（按最大层归一化到 1~50 个字符），右侧标注数值；带标题与比例尺说明。
- 输入：`g_layer[]`。
- 输出：屏幕字符分布图。

**M9 结果报表输出模块**（源文件 `Report.c`）

- 功能简介：把参数清单、逐层计算表（层号、标高、μz、面积、荷载）与汇总结果写入 `wind_result.txt`，采用对齐的 fprintf 表格；文件尾追加生成时间与参与者姓名占位行。
- 输入：`g_bld`、`g_layer[]`、汇总结构体。
- 输出：`wind_result.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（录入参数 / 读系数表 / 查体型 / 换算风压 / 分层计算 / 汇总 / 分布图 / 输出报表 / 退出），`do-while + switch` 调度；用状态标记约束模块执行顺序（未录入参数不得计算）。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 中菜单循环 `do-while + switch` 分发 M1~M9；状态变量约束：M4~M9 运行前必须已成功执行 M1 与 M2，M6 前必须完成 M5 与 M3。

**数据流**：

```
windcoef_X.txt ─► M2 读入 ─► g_table[] ─► M4 线性插值函数 ◄── zMid
shape_coef.txt ─► M3 读入 ─► g_shapeCoef        │
键盘参数 ───────► M1 录入 ─► g_bld ─► M5 换算 ─► g_w0Adj
                                                 ▼
                              M6 分层计算 ─► g_layer[]
                                                 │
                              M7 汇总 ◄──────────┤
                                                 ▼
                              M8 字符图      M9 报表文件 wind_result.txt
```

所有模块之间只通过全局结构体、数组和少量参数交换数据，函数头部在编码前书面约定。
