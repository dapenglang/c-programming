## 二、预备知识：冒泡排序是怎么"冒"的

### 1. 问题是怎么来的

上一练习（练习 27 第 5 章）学过**选择排序**：每趟找最小值放好。这里学另一种更直观的排序——**冒泡排序**。

"冒泡"的名字来自一个形象：一串数字里，最大的数就像水里的气泡，**每和旁边比一次就往右挪一格**，一路冒到最右端。

### 2. 冒泡排序的机制

核心动作只有一条：**比较相邻的两个元素，如果前面的大于后面的（逆序），就交换它们**。

从数组开头开始，一路比下去：

- 比较 `ch[0]` 和 `ch[1]`：若 `ch[0] > ch[1]`，交换；
- 比较 `ch[1]` 和 `ch[2]`：若 `ch[1] > ch[2]`，交换；
- ……
- 比较 `ch[n-2]` 和 `ch[n-1]`。

**一趟结束时会发生什么？** 最大的元素一定被"推"到了最右边 `ch[n-1]`。原因：每次遇到比它小的就换到右边，所以它一路向右，直到末尾。于是**最右端的位置排好了**。

第二趟：对前 `n-1` 个元素重复上述过程，第二大的元素冒到 `ch[n-2]`。依此类推。

**需要几趟？** 每趟排好一个元素，排好 `n-1` 个之后，剩下那个自然就位，所以共 `n-1` 趟。第 `i` 趟（`i` 从 0 计）只需比较前 `n-i` 个元素，即内层 `j` 从 0 到 `n-2-i`。

### 3. 用本例走一遍

样例 2：$[50, 10, 40, 20]$，$n = 4$。

**第 0 趟**（比较 j=0,1,2）：

- j=0：50 > 10，交换 → $[10, 50, 40, 20]$；
- j=1：50 > 40，交换 → $[10, 40, 50, 20]$；
- j=2：50 > 20，交换 → $[10, 40, 20, 50]$。

最大值 50 冒到了末尾，位置 3 归位。

**第 1 趟**（比较 j=0,1）：

- j=0：10 > 40？否，不动；
- j=1：40 > 20，交换 → $[10, 20, 40, 50]$。

40 冒到位置 2，归位。

**第 2 趟**（比较 j=0）：

- j=0：10 > 20？否，不动。

结果 $[10, 20, 40, 50]$。已经是排好序的了。

**观察**：每一趟结束后，数组末尾就多一个"已排好的大元素"，而且有序部分只增不减。这就是冒泡排序的正确性保证。

### 4. 编程时怎么用它

两层循环 + 相邻交换：

```c
for (i = 0; i < n - 1; i++) {           /* n-1 趟 */
    for (j = 0; j < n - 1 - i; j++) {   /* 比较相邻两元素 */
        if (ch[j] > ch[j + 1]) {        /* 逆序则交换 */
            tmp = ch[j]; ch[j] = ch[j+1]; ch[j+1] = tmp;
        }
    }
}
```

> **这个思想在综合实验中反复出现**：D8 峰位排序、D7 热点排序（练习 27 第 5 章的选择排序）、D3 指标排序。**同一个排序任务，可以用选择排序、冒泡排序等多种算法完成，结果相同、过程不同。** 理解两种算法，能帮助你体会"同一问题多种解法"的思维。

## 三、解题思路

1. **读入数据**：`scanf("%d",&n);`，循环读入 `ch[20]`（`int` 型，道址是整数）；
2. **冒泡排序**：外层 `i` 从 0 到 `n-2`；内层 `j` 从 0 到 `n-2-i`；条件 `ch[j] > ch[j+1]` 时交换；
3. **输出**：循环 `printf("%d ", ch[i]);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int ch[20];                 /* 各峰的道址（整数） */
    int n, i, j;
    int tmp;                    /* 交换用临时变量 */

    scanf("%d", &n);            /* 读入峰个数 */

    for (i = 0; i < n; i++) {
        scanf("%d", &ch[i]);    /* 读入各峰道址 */
    }

    /* 冒泡排序：从小到大 */
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - 1 - i; j++) {
            if (ch[j] > ch[j + 1]) {        /* 前大后小 → 交换 */
                tmp = ch[j];
                ch[j] = ch[j + 1];
                ch[j + 1] = tmp;
            }
        }
    }

    for (i = 0; i < n; i++) {
        printf("%d ", ch[i]);   /* 输出排序后的道址 */
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 排序过程要点 | 程序输出 |
|---|---|---|
| 5: 888 441 782 100 1332 | 1332 依次冒到末尾，再排其余 | `100 441 782 888 1332 ` ✓ |
| 4: 50 10 40 20 | 50 冒到末尾 → 40 冒到倒数第二 → 完成 | `10 20 40 50 ` ✓ |
| 3: 5 4 3 | 完全逆序，每趟多次交换 | `3 4 5 ` ✓ |
| 4: 1 2 3 4 | 已有序，内层判断从不交换 | `1 2 3 4 ` ✓ |

第四例说明：即便数据已经有序，冒泡排序仍会完成全部比较（只是不发生交换），结果不变。

## 六、常见错误与讲解

**错误 1：交换时丢值**

```c
ch[j] = ch[j+1];
ch[j+1] = ch[j];            /* 错：ch[j] 已被覆盖，两位置变成同一个值 */
/* 正确： */
tmp = ch[j]; ch[j] = ch[j+1]; ch[j+1] = tmp;
```

**错误 2：内层上界写成 `n-1`**

```c
for (j = 0; j < n - 1; j++)       /* 可行但多做无用功：末尾已排好的元素还被反复比较 */
for (j = 0; j < n - 1 - i; j++)   /* 对：已排好 i 个，只需比较前 n-1-i 对 */
```

虽然写 `n-1` 不影响**结果**（已排好的部分不会被破坏），但多做了比较，且不体现"每趟少比一个"的规律。

**错误 3：比较方向或交换条件写反**

```c
if (ch[j] < ch[j + 1])      /* 错：会把大的往左推，最后变成从大到小 */
if (ch[j] > ch[j + 1])      /* 对：从小到大排序 */
```

从小到大排序时，条件是"**前 > 后**（逆序）就交换"。方向反了就排成降序。

**错误 4：漏写 `tmp` 声明或与选择排序混淆**

```c
tmp = ch[j]; ch[j] = ch[j+1]; ch[j+1] = tmp;   /* 冒泡：相邻两个交换，用 tmp */
```

别把冒泡写成选择排序的"找下标"结构（那是 `imax`）。冒泡的核心是**相邻比较**，不是**找最值下标**。
