## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

程序内存里的数据"一停就没了"，要长期保存就必须写入文件。本题的场景更进一步：文件里存着成千上万条**固定长度的记录**，我们希望"想看哪条就直接跳到哪条"，而不是从头一条条读。要做到"直接跳"，前提是**每条记录长度一致**——只要知道记录长度和下标，就能算出它的起始位置。

### 2. 文本文件与二进制文件的区别

- **文本文件**：存的是人可读字符，每行长度往往不一样，无法用简单的乘法算出第 $k$ 行的偏移。
- **二进制文件**：存的是内存原始字节。如果每条记录都是同一个结构体，那么每条在文件里占的字节数**完全相同**（都是 `sizeof(struct Rec)`），于是第 $k$ 条记录的起始偏移就是 $(k-1) \times$ 记录长度。

这就是"固定长度记录 + 文件定位"能成立的原因，也是数据库"定长页"思想的源头。本题的规则用结构体定义：

```c
struct Rec { int id; double p; };   /* 测点号 + 压力值 */
```

在常见平台上 `sizeof(struct Rec)` 为 16（`int` 4 字节，随后 4 字节对齐填充，`double` 8 字节）。**编程时一律写 `sizeof(struct Rec)`，不要手写 16**，这样换了平台或改了成员也不用改代码。

### 3. 文件操作的标准四步曲

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题先用 `fseek`/`ftell` 定位、再用 `fread` 读；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 它是这次文件访问的"编号牌"，指向系统为该文件建立的记录；记录里的**文件位置指针**标明"现在到第几个字节"。本题的整套操作，都是围绕这个位置指针展开的。

**打开失败会怎样？** 文件不存在时 `fopen` 返回 `NULL`，不判空就用会崩溃，因此打开后**必须**判空：

```c
if (fp == NULL) { printf("无法打开文件 pressure.bin\n"); return 1; }
```

### 4. 常用读写与定位函数怎么选

| 函数 | 作用 | 典型写法 |
|---|---|---|
| `fseek` | 移动文件位置指针 | `fseek(fp, offset, SEEK_SET);` |
| `ftell` | 返回当前位置字节偏移 | `size = ftell(fp);` |
| `rewind` | 回到文件开头 | `rewind(fp);`（等价于 `fseek(fp,0,SEEK_SET)`） |
| `fread` | 读字节块 | `fread(&r, sizeof(struct Rec), 1, fp);` |
| `fwrite` | 写字节块 | `fwrite(&r, sizeof(struct Rec), 1, fp);` |

**`fseek(fp, offset, whence)` 三个参数**：`fp` 是文件指针；`offset` 是相对偏移（可为负）；`whence` 是基准位置，取 `SEEK_SET`（文件开头）、`SEEK_CUR`（当前位置）、`SEEK_END`（文件末尾）。本题两种用法：求大小用 `fseek(fp, 0, SEEK_END)` 到末尾，定位用 `fseek(fp, (k-1)*len, SEEK_SET)` 从开头跳。

### 5. 用本题的数据走一遍文件指针

文件里有 4 条记录，每条 16 字节，总大小 $64$ 字节。打开后指针在 0。

- `fseek(fp, 0, SEEK_END)`：指针移到第 64 字节（末尾）；`ftell(fp)` 返回 64，`count = 64 / 16 = 4`。
- 输入 $k=2$：`fseek(fp, (2-1)*16, SEEK_SET)` 把指针移到第 16 字节，正好是第 2 条记录的起始处（第 1 条占 0~15 字节）。
- `fread(&r, sizeof(struct Rec), 1, fp)`：从第 16 字节读 16 字节装进 `r`，指针移到第 32 字节。读出 `id = 1002`、`p = 18.30`。

要点：**定位是"算出来"的**——偏移量 $= (k-1) \times$ 记录长度，这是定长记录随机访问的核心公式。

## 三、解题思路

1. **打开**：`fp = fopen("pressure.bin", "rb")`，判空；
2. **求长度**：`fseek(fp, 0, SEEK_END); size = ftell(fp); count = size / sizeof(struct Rec);`
3. **读 k 并校验**：`scanf("%d", &k)`，若 $k<1$ 或 $k>count$ 则报错退出；
4. **定位并读**：`fseek(fp, (long)(k-1) * sizeof(struct Rec), SEEK_SET);` 再 `fread(&r, sizeof(struct Rec), 1, fp);`
5. **输出并关闭**：打印 count、`sizeof`、size 与记录内容，`fclose(fp)`。

## 四、参考代码

```c
#include <stdio.h>

struct Rec {              /* 一条压力记录：测点号 + 压力值 */
    int    id;
    double p;
};

int main(void)
{
    FILE *fp;
    struct Rec r;                 /* 读回的一条记录 */
    int  k;
    long size, count, offset;     /* 文件总字节、记录数、定位偏移 */

    fp = fopen("pressure.bin", "rb");
    if (fp == NULL) {
        printf("无法打开文件 pressure.bin\n");
        return 1;
    }

    /* 求文件大小与记录数：每条记录占 sizeof(struct Rec) 字节 */
    fseek(fp, 0, SEEK_END);
    size  = ftell(fp);
    count = size / sizeof(struct Rec);

    scanf("%d", &k);              /* 读入要查看的记录号 */
    if (k < 1 || k > count) {     /* 越界检查 */
        printf("记录号 %d 超出范围 1~%ld\n", k, count);
        fclose(fp);
        return 1;
    }

    /* 定位到第 k 条记录（下标 k-1）并读取 */
    offset = (long)(k - 1) * sizeof(struct Rec);
    fseek(fp, offset, SEEK_SET);
    fread(&r, sizeof(struct Rec), 1, fp);
    fclose(fp);

    printf("文件共 %ld 条记录，每块 %d 字节，总大小 %ld 字节\n",
           count, (int)sizeof(struct Rec), size);
    printf("第 %d 条记录：编号 = %d, 压力 = %.2f kPa\n", k, r.id, r.p);

    return 0;
}
```

## 五、运行验证

`pressure.bin` 是二进制文件，无法手工敲入。可用下面这段小程序先生成它（逻辑上等价于练习 06 的写法）：

```c
#include <stdio.h>
struct Rec { int id; double p; };
int main(void) {
    struct Rec d[4] = { {1001,12.5}, {1002,18.3}, {1003,9.75}, {1004,21.0} };
    FILE *f = fopen("pressure.bin", "wb");
    fwrite(d, sizeof(struct Rec), 4, f);
    fclose(f);
    return 0;
}
```
运行后 `pressure.bin` 共 64 字节，逻辑内容即题面表格。

**样例 1：运行前** 文件逻辑内容为 4 条记录（见上表）。输入 `2`，屏幕输出：
```
文件共 4 条记录，每块 16 字节，总大小 64 字节
第 2 条记录：编号 = 1002, 压力 = 18.30 kPa
```
核对：偏移 $=(2-1)\times16=16$ 字节，正好跳过第 1 条记录，读到第 2 条的 `id=1002`、`p=18.30`，与题面一致。文件只读，内容不变。

**样例 2：运行前** 同一文件。输入 `4`，屏幕输出：
```
文件共 4 条记录，每块 16 字节，总大小 64 字节
第 4 条记录：编号 = 1004, 压力 = 21.00 kPa
```
偏移 $=(4-1)\times16=48$ 字节，读到第 4 条记录，正确。

## 六、常见错误与讲解

**错误 1：偏移量算错，漏乘或写成 $k$ 倍**

```c
fseek(fp, k * sizeof(struct Rec), SEEK_SET);        /* 错：多跳了一条 */
fseek(fp, (k - 1) * sizeof(struct Rec), SEEK_SET);  /* 对：下标从 0 起 */
```
第 $k$ 条记录的起始字节是 $(k-1)\times$ 记录长度，因为第一条从偏移 0 开始。这是最典型的"差一"错误。

**错误 2：手写记录长度，与 `sizeof` 不一致**

```c
fseek(fp, (k - 1) * 16, SEEK_SET);        /* 错：写死 16，换平台或改结构体就错 */
fseek(fp, (k - 1) * sizeof(struct Rec), SEEK_SET);   /* 对：用 sizeof */
```
结构体可能存在对齐填充，长度由编译器决定，必须用 `sizeof(struct Rec)`。

**错误 3：定位前不检查 k 的范围**

```c
scanf("%d", &k);
fseek(fp, (k - 1) * sizeof(struct Rec), SEEK_SET);   /* 错：k 越界时读到文件外 */
```
`fseek` 定位到文件外不会报错，但 `fread` 读不到数据，`r` 里就是垃圾值。**定位前先做 $1 \le k \le count$ 的检查。**另外，定位基准要用 `SEEK_SET`（从文件开头算），别误用 `SEEK_END`；`fopen` 后判空、操作完 `fclose` 也别忘了。

## 七、与综合实验的衔接

实验 C9 把压力测点记录按定长二进制存放，正是为了支持本练习这样的"按记录号随机访问"：查看第几个测点、抽取若干条做热点分析，都能一步定位，无需顺序扫描。C7 的载荷样本、C6 的冰块清单若改用定长记录存储，也同样能实现随机访问。**"记录长度 × 下标 = 偏移量"** 这一公式，几乎是所有数据库按主键定位记录的底层原理。当记录变长、关系变复杂时，就需要第 8 章 8.7 节介绍的数据库技术来做更系统的管理。
