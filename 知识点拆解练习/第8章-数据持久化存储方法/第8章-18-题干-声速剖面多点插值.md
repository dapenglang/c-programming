# 第 8 章 练习 18　声速剖面多点插值

**对应章节**：8 数据持久化存储方法（8.6 拉格朗日插值、8.4 文件的读写）；另用到第 5 章 5.1 一维数组

**场景来源**：综合实验 C1《声速剖面与声线跟踪计算系统》（水声学院）——本练习是该实验中"由离散声速表插值任意深度声速"环节的实现。

**建议用时**：30~40 分钟

## 一、应用场景

海洋中声速随深度变化，声呐测距、声线跟踪都要用到"任意深度处的声速"。实验 C1 的实测声速剖面是一张**离散表**：每隔 100 m 水深给出一个声速值，存放在数据文件 `svp.txt` 中。计算声线时需要的却是任意深度（如 150 m、250 m）的声速——这就要求程序能从离散表出发，用**拉格朗日多点插值**算出表内任意深度的声速。本练习把第 17 题的插值算法接到真实的声速剖面数据上：节点表来自文件，插值结果与理论曲线核对。

## 二、任务要求

编写完整程序 `svpitch.c`：

1. 以 `"r"` 方式打开 `svp.txt`，**检查返回值**，失败时输出提示并结束（返回值 1）；
2. **数据文件格式约定**：第一行是节点个数 n（整数，$2 \le n \le 20$），其后 n 行每行两列、空格分隔——深度 $d_i$（m）与声速 $c_i$（m/s，1 位小数），深度按从小到大排列；
3. 读入 n 个节点到两个一维 double 数组，关闭文件；
4. 从键盘读入待求深度 `dq`（m）；
5. 用拉格朗日插值计算该深度处的声速，按 `c(%.1f m) = %.2f m/s` 的格式输出；
6. 若 dq 超出节点深度范围 $[d_0, d_{n-1}]$，输出 `深度超出剖面范围` 并结束——本练习只做内插，不做外推。

**数据文件样例数据行**：第一行 `4`，其后 `0 1449.0`、`100 1453.0`、`200 1455.0`、`300 1455.0`。

## 三、输入输出格式

**输入文件**：`svp.txt`（第一行 n，其后 n 行两列）。

**键盘输入**：一行，一个实数，表示待求深度 dq（m）。

**屏幕输出**：一行，`c(dq) = 声速`（dq 保留 1 位小数，声速保留 2 位小数）；越界时输出 `深度超出剖面范围`。

## 四、样例

**输入文件 svp.txt 的内容**：

```
4
0 1449.0
100 1453.0
200 1455.0
300 1455.0
```

**样例 1**

键盘输入：
```
150
```
屏幕输出：
```
c(150.0 m) = 1454.25 m/s
```

**样例 2**

键盘输入：
```
250
```
屏幕输出：
```
c(250.0 m) = 1455.25 m/s
```

**样例 3**

键盘输入：
```
400
```
屏幕输出：
```
深度超出剖面范围
```

## 五、提示

- 插值算法与第 17 题完全相同：$c(d) = \sum_{i=0}^{n-1} c_i L_i(d)$，基函数 $L_i(d) = \prod_{j \neq i} \dfrac{d - d_j}{d_i - d_j}$，双重循环实现，连乘变量每轮重置为 1.0；
- 把第 17 题代码中的 x 换成深度 d、y 换成声速 c，算法主体一行不用改——变的只是变量含义与数据文件；
- 范围检查要在**插值之前**做：`if (dq < d[0] || dq > d[n-1])`，防止外推；
- 样例数据取自一条光滑的声速曲线（近似 $c(d) = 1449 + 0.05d - 0.0001d^2$，单位 m/s），四个节点恰好都在这条二次曲线上，因此三次拉格朗日插值会**精确还原**该曲线——样例 1、2 的结果可按曲线公式直接核对。

**完成本练习后你将具备的能力**：把拉格朗日插值算法迁移到真实物理数据（深度—声速剖面）上、增加"内插不外推"的工程保护——这正是实验 C1 声线跟踪模块中"逐层查声速"的核心代码。
