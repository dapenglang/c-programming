## 二、预备知识：一阶差分的基本原理（零基础阅读）

### 1. 问题是怎么来的

看一串深度读数 `12.5, 12.8, 13.4, 13.1, 15.0`——不明显；看它们的相邻变化量 `+0.30, +0.60, -0.30, +1.90`——海底"缓坡、缓坡、小上坡、**陡坎**"的形状立刻跳出来。**一阶差分**就是把序列"求变化率"的运算：相邻两点之差。它把缓变的背景压成小量、把突变放大成大数，是检测阶跃、边缘的第一件工具。

### 2. 公式推导

对深度序列 $\{x_i\}$，一阶差分定义为：

$$\Delta x_i = x_i - x_{i-1}, \qquad i = 2, 3, \ldots, n$$

几点说明：

- **有符号**：$\Delta x_i > 0$ 表示深度增大（声呐往下打得更深，地形下坡），$\Delta x_i < 0$ 表示深度减小；
- **少一个点**：n 个点只能产生 $n-1$ 个差分——第 1 个点没有"前值"；
- **与导数的关系**：差分是导数的离散近似，$\Delta x_i / \Delta t \approx \dfrac{dx}{dt}$。等时间间隔采样时，差分大小正比于变化速率。

对差分再做一次阈值判决（$\Delta x_i > \tau$ 判为跳变），就是综合实验 C6 的 M6 模块；本题先负责把 $\Delta x_i$ 算出来。

### 3. 代入本例数值

样例 1 逐点计算：

| 点 i | 深度 $x_i$ | 前值 $x_{i-1}$ | $\Delta x_i = x_i - x_{i-1}$ |
|---|---|---|---|
| 2 | 12.8 | 12.5 | +0.30 |
| 3 | 13.4 | 12.8 | +0.60 |
| 4 | 13.1 | 13.4 | −0.30 |
| 5 | 15.0 | 13.1 | +1.90 |

第 5 点差分 +1.90 远大于其余各点，正是"阶跃候选"——C6 的阈值判决会在这一处报警。

### 4. 通过编程翻译

相邻点运算的通用套路（与练习 29 一脉相承）：**两个变量滚动**。`curr` 接新值，与 `prev` 一起交给函数 `firstDiff(prev, curr)`；用完 `prev = curr` 滚动。函数本身只有一行 `return curr - prev;`——有人会问"一行也要封装？"要：C6 里差分要被 M4（逐点差分）、M5（平滑差分）多处复用，封装后改一处公式、处处生效，这正是函数化的意义。

> **这个思想在综合实验中反复出现**：C6 的 M4 一阶差分（本题）、M5 三点滑动平滑差分（先平滑再差分）、M6 阈值跳变判决（在差分结果上做 if 判决），构成同一条"差分管线"。练习 29 的移动平均与本题互为对偶：一个求和（压噪声）、一个求差（显变化）。

## 三、解题思路

1. **写函数**：`double firstDiff(double prev, double curr) { return curr - prev; }`，原型放 main 前；
2. **主循环**：读 n；两变量滚动，`if (i >= 2)` 时调用函数并按 `%+.2f` 打印；
3. **滚动**：`prev = curr;` 放在输出之后。

## 四、参考代码

```c
#include <stdio.h>

double firstDiff(double prev, double curr);   /* 原型声明 */

int main(void)
{
    int n, i;
    double prev = 0.0, curr;

    scanf("%d", &n);                /* 读入深度点数 */

    for (i = 1; i <= n; i++) {
        scanf("%lf", &curr);        /* 读入当前深度 */
        if (i >= 2) {               /* 第 2 点起才有差分 */
            printf("第%d点差分=%+.2f\n", i, firstDiff(prev, curr));
        }
        prev = curr;                /* 当前值滚动为前值 */
    }
    return 0;
}

/* 一阶差分：当前值减前值 */
double firstDiff(double prev, double curr)
{
    return curr - prev;
}
```

## 五、运行验证

**样例 1 运行结果**：

```
第2点差分=+0.30
第3点差分=+0.60
第4点差分=-0.30
第5点差分=+1.90
```

**样例 2 运行结果**（相等值自检）：

```
第2点差分=+0.00
```

**核对**：样例 1 四个差分值 $12.8-12.5=0.30$、$13.4-12.8=0.60$、$13.1-13.4=-0.30$、$15.0-13.1=1.90$，均已按 IEEE-754 double 与 `%.2f` 舍入规则复算核对；输出条数恰为 $n-1=4$。样例 2 相等值之差为 0，`%+.2f` 打出 `+0.00`。

**反例验证**：若把函数写成 `return prev - curr;`，样例 1 第 2 点会打出 `-0.30`——符号方向反了，"下坡变上坡"，这正是差分题最隐蔽的错误（数值对、方向错），带符号输出让这类错误无处藏身。

## 六、常见错误与讲解

**错误 1：差分方向写反**

```c
return prev - curr;      /* 错：差分定义是后减前 */
```

约定俗成 $\Delta x_i = x_i - x_{i-1}$（后减前），写反了整个 C6 管线的符号语义全错。

**错误 2：滚动次序颠倒或漏滚动**

```c
prev = curr;      /* 错：先滚动，prev 已变成当前值 */
printf(... firstDiff(prev, curr) ...);
```

必须**先用后滚**：先算差分，再 `prev = curr`。

**错误 3：输出格式忘了 `+`**

```c
printf("第%d点差分=%.2f\n", ...);   /* 正数没有 + 号，方向不醒目 */
```

用 `%+.2f` 让正负号都显式出现。

**错误 4：从第 1 点就开始输出**

```c
printf(... firstDiff(prev, curr) ...);   /* i=1 时 prev 还是 0.0，打出假差分 */
```

第 1 个点没有前值，必须用 `if (i >= 2)` 挡住。

## 七、与综合实验的衔接

- 实验 **C6（基于逐点差分与阈值判决的海底回波测深数据处理系统）**中，M4"一阶差分计算"就是本题的直接放大：真实 C6 的深度序列从文件读入并存进数组（第 5 章知识），差分结果同样存数组，供 M5 平滑差分与 M6 阈值判决连用；M5 的"三点平滑差分"只是把 `firstDiff(prev, curr)` 换成对平滑后相邻点再调用同一个函数——**函数复用**的价值在此显现；
- 与前后练习衔接：第 3 章练习 37（深度跳变阈值判定）在单点差分上做 if 判决，第 3 章练习 38（跳变段计数）在循环里数跳变——本题把"算差分"封装成函数后，那两题的骨架立刻可以函数化重构；练习 29 的滚动窗口技巧在本题原样复用（窗口从 3 点缩到 2 点）。掌握了本题，C6 差分管线的第一环就打通了。
