# 第 3 章 练习 21　灰度阈值分段判定

**所属综合实验**：B1（B1-基于灰度直方图统计的图像二值化处理系统）

**对应章节**：3 程序流程控制（3.1 关系与逻辑运算、3.2 选择结构 if-else、3.4 标准输入输出）

**场景来源**：综合实验 B1《基于灰度直方图统计的图像二值化处理系统》（人工智能学院）——本练习是该实验中"灰度分档判定"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

图像二值化系统要把灰度图像变成黑白两色图：亮度超过某个阈值的像素判为白，低于阈值的判为黑。但在确定阈值之前，系统常先对像素做一次"亮度分档"，统计各档像素的多少，以便选择合适的阈值。

按经验，灰度值可以分成三档：

- $0 \sim 84$：偏暗（多为背景或阴影）；
- $85 \sim 169$：中等（多为过渡区域）；
- $170 \sim 255$：偏亮（多为目标的明亮部分）。

分档统计的结果直接影响阈值选取，是 B1 系统图像分析的第一步。

## 二、任务要求

编写一个完整程序 `gray_class.c`：

1. 从键盘读入一个像素灰度值 `g`（整数，**题目保证 0 ≤ g ≤ 255**）；
2. 按下列规则判定它属于哪一档：
   - 若 `g <= 84`，输出 `Dark`；
   - 否则若 `g <= 169`，输出 `Medium`；
   - 否则输出 `Bright`；
3. 按规定格式输出判定结果。

## 三、输入输出格式

**输入**：一行，一个整数，表示像素灰度值 g（0～255）。

**输出**：一行，输出该像素所属的档位名称：`Dark`、`Medium` 或 `Bright`。

## 四、样例

**样例 1**

输入：
```
50
```
输出：
```
Dark
```

**样例 2**

输入：
```
200
```
输出：
```
Bright
```

## 五、提示

三个档位对应三段数值区间：

$$
[0, 84] \to \text{Dark},\quad [85, 169] \to \text{Medium},\quad [170, 255] \to \text{Bright}
$$

用 `if ... else if ... else` 结构时，**判断顺序很关键**：先判是否 $\le 84$，再判是否 $\le 169$。因为到了第二个判断时，$g$ 已经不满足第一个条件（即 $g > 84$），所以"$\le 169$"实际表达的是 $85 \le g \le 169$，不必再写下限。这种"层层筛掉"的写法既简洁又不容易错。

**完成本练习后你将具备的能力**：书写关系表达式、使用 if-else if-else 实现多分支判断、理解"按顺序筛选"的判断逻辑——这些是实验 B1 中"灰度分档模块"的地基。
