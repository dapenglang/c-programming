## 二、预备知识：累加器——为什么一个变量就能算总和（零基础阅读）

### 1. 问题是怎么来的

假设一名应急人员有 3 笔读数：5.5、7.0、4.0 mSv。人脑会这样算：先记 5.5，加 7.0 得 12.5，再加 4.0 得 16.5。这个"记在脑子里、每读一个新数就更新一次"的记账本，就是**累加器**。

程序里没有"脑子"，就用一个变量来充当这个记账本。关键在于：**这个变量必须在一开始被清空**——否则它里面是上一次运行遗留的垃圾值，从垃圾值往上加，结果自然全错。

### 2. 累加器的机制

分三步：

1. **初始化**：`total = 0.0;`——把记账本清零。这一步必须在循环**外面、之前**；
2. **循环累加**：每读入一笔 `x`，执行 `total = total + x;`。读这个式子的顺序是"先算右边、再存回左边"：右边是"原累计 + 新读数"，算完的结果存回 `total`，于是 `total` 里装的是**到目前为止的总和**；
3. **循环结束后**，`total` 就是全部 n 笔的和。

写成表格更直观。以样例 1 的 $[5.5, 7.0, 4.0]$ 为例：

| 第几笔 | 读入 x | 执行前 total | 执行后 total |
|---|---|---|---|
| 1 | 5.5 | 0.0 | 5.5 |
| 2 | 7.0 | 5.5 | 12.5 |
| 3 | 4.0 | 12.5 | 16.5 |

循环结束，`total = 16.5`。**注意变量 `x` 只活了"一轮"**——每一轮被重新读入、覆盖，所以整个程序只需要 2 个变量（`x` 和 `total`）就能处理 100 笔甚至 100 万笔记录。

### 3. 从"求总和"到"分级判定"

拿到 `total` 之后，判定就是一个选择结构：

```c
if (total >= 20.0)
    printf("level = over\n");
else
    printf("level = normal\n");
```

`>=` 表示"大于或等于"。为什么用 `>=` 而不是 `>`？因为限值 20 mSv 是**不得超过**的界线，恰好等于 20 也算达到限值，必须判为超限。

关注提示是**独立的第二个判断**，条件区间是 $15 \le \text{total} < 20$，翻译成 C 语言就是 `total >= 15.0 && total < 20.0`。C 语言**不允许**写成 `15.0 <= total < 20.0`——那会被理解为 `(15.0 <= total) < 20.0`，即"先算出一个 0 或 1，再拿它和 20 比"，永远为真。**区间判断必须用 `&&` 把两个不等式连起来。**

### 4. 用本例走一遍

样例 2 的 $[8.0, 9.5, 6.0, 5.0]$：

| 第几笔 | x | 执行后 total |
|---|---|---|
| 1 | 8.0 | 8.0 |
| 2 | 9.5 | 17.5 |
| 3 | 6.0 | 23.5 |
| 4 | 5.0 | 28.5 |

`total = 28.5 ≥ 20`，判 `over`；同时 `28.5 < 20` 不成立，所以**不**打印关注提示——这与样例 2 的输出（只有两行）完全吻合。

> **这个思想在综合实验中反复出现**：D9 的人员累计剂量、D7 的多点源剂量率求和、D3 的通行量累计、A1 的风荷载逐层累加，全部是"累加器 + 循环"的同一个套路。**累加器是统计类程序的第一块积木。**

## 三、解题思路

1. **读 n**：`scanf("%d", &n);`；
2. **初始化累加器**：`total = 0.0;`（关键，务必在循环前）；
3. **循环累加**：`for (i = 0; i < n; i++) { scanf("%lf", &x); total += x; }`；
4. **输出累计值**：`printf("total = %.2f mSv\n", total);`；
5. **判等级**：`if (total >= 20.0) ... else ...`；
6. **关注提示**：`if (total >= 15.0 && total < 20.0) printf("warning: approaching limit\n");`

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int    n, i;        /* 记录条数、循环变量 */
    double x;           /* 当笔剂量读数，mSv */
    double total = 0.0; /* 累计剂量，必须在循环前清零 */

    scanf("%d", &n);    /* 读入记录条数 */

    for (i = 0; i < n; i++) {
        scanf("%lf", &x);       /* 读入第 i 笔读数 */
        total += x;             /* 累加进累计剂量 */
    }

    printf("total = %.2f mSv\n", total);    /* 输出累计剂量 */

    if (total >= 20.0) {                    /* 与年限值 20 mSv 比较 */
        printf("level = over\n");           /* 达到或超过限值：超限 */
    } else {
        printf("level = normal\n");         /* 未超限：正常 */
    }

    /* 15 ~ 20 mSv 为关注区：未超限但已接近限值，需提示 */
    if (total >= 15.0 && total < 20.0) {
        printf("warning: approaching limit\n");
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 累加过程 | 程序输出 |
|---|---|---|
| 3: 5.5 7.0 4.0 | 5.5 → 12.5 → 16.5 | `total = 16.50 mSv` / `level = normal` / `warning: approaching limit` ✓ |
| 4: 8.0 9.5 6.0 5.0 | 8.0 → 17.5 → 23.5 → 28.5 | `total = 28.50 mSv` / `level = over` ✓ |
| 2: 1.2 0.8 | 1.2 → 2.0 | `total = 2.00 mSv` / `level = normal` ✓ |
| 1: 20.0 | 20.0 | `total = 20.00 mSv` / `level = over` ✓ |

第四例是**边界验证**：累计恰好 20 mSv，程序判 `over`——说明用的是 `>=` 而不是 `>`，与"限值即界线"的规定一致。

## 六、常见错误与讲解

**错误 1：累加器忘记初始化**

```c
double total;                  /* 错：未初始化，里面是垃圾值 */
for (...) total += x;

double total = 0.0;            /* 对：先清零 */
for (...) total += x;
```

这是本章最隐蔽的错误之一：程序能编译、能运行，结果却完全不对，而且**每次运行的错值可能不同**。

**错误 2：累加器初始化写在循环里**

```c
for (i = 0; i < n; i++) {
    total = 0.0;               /* 错：每轮清零，最后 total 只等于最后一笔 */
    total += x;
}
```

结果是 `total` 等于最后一笔读数（本例 4.0），而不是总和。**初始化放在循环外。**

**错误 3：区间判断写成数学式**

```c
if (15.0 <= total < 20.0)      /* 错：恒为真 */
if (total >= 15.0 && total < 20.0)   /* 对：两个不等式用 && 连接 */
```

**错误 4：用了 `>` 而不是 `>=`**

```c
if (total > 20.0)              /* 不严谨：恰好 20 mSv 会被判为正常 */
if (total >= 20.0)             /* 对：20 mSv 是限值，达到即超限 */
```
