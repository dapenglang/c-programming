# 题目 C7：基于冲量-动量反演的冰阻力与碰撞事件辨识系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择　**题目来源**：NDEM 论文拓展题

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行冰阻力辨识与碰撞事件统计工具。它以等采样间隔记录的"板体速度时间序列"与"外力（拖曳装置记录力）时间序列"为输入，用动量定理的差分形式反演冰致阻力分量 R = m·Δv/Δt − F_ext；先对开水（无冰）段数据求平均得到基线阻力并扣除，再对冰致阻力序列计算均值 μ 与标准差 σ，以 μ+3σ 为阈值把显著超出正常水平的片段分离为碰撞事件，统计事件次数、持续步数与峰值，对峰值做排序与上尾分位数分析，并绘制阻力分布直方图，最后输出结果文件与屏幕报表。本题算法由 Ocean Engineering 2026 论文《Experimental and NDEM investigation of resistance and pressure statistics of an inclined plate interacting with broken ice》中的"冲量-动量反演辨识阻力 + 基线扣除与 3σ 阈值碰撞事件统计"环节简化而来：把二维板面压力重建一维化，只保留课程内可实现的差分反演与统计骨架。

**解决什么重要问题**：冰池或实海域试验中，冰与结构的总作用力可以直接测量，但"冰致阻力"无法用传感器直接分离——测得的总是冰阻力与拖曳、惯性等外力的合力。动量定理提供了一条反演路径：板体速度的逐点差分给出动量变化率，从总外力中扣除已知外力项与惯性项，剩下的就是冰的作用。若不做基线扣除，开水段的系统性偏置会混入冰致阻力；若不用 μ+3σ 这类阈值筛选，真实碰撞事件会淹没在噪声里，冰载荷极值就无从谈起。

**支撑哪些关键应用**：① 冰区船舶阻力预报：碎冰场航行阻力中"连续破冰分量"与"碰撞冲击分量"的分离正是本流程的直接应用；② 冰池模型试验数据分析：对倾斜板-碎冰作用试验的测力与测速记录做事件辨识与峰值统计；③ 冰载荷极值与超越概率评估：上尾分位数与直方图为结构强度校核提供载荷输入；④ 后续 NDEM/DEM 数值仿真的验证环节：模拟结果与实测辨识结果对比。本题输入数据可由题目 C6 的碰撞模拟结果加工而来，两题可连做。

**与专业培养的关联**：水声学院学生的后续课程（冰力学、冰区船舶设计、海洋环境载荷、试验设计与数据处理）都依赖"从测量序列中辨识物理量、从噪声中提取事件"的基本功。本题让学生用课程内的差分、均值方差、排序查找、阈值判断、直方图统计与文件读写，实现论文链条中"载荷辨识与统计"这一环，是连接测量数据与工程结论的关键一步。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述冰阻力辨识与碰撞事件统计系统，完成一条完整的"文件读入 → 基线计算 → 差分反演 → 统计分析 → 事件检测 → 极值分析 → 报表输出"流水线。具体任务包括：设计板体速度与外力两个时序数据文件格式并完成容错读入；对开水段数据求平均得到基线阻力；用动量差分公式逐步计算冰致阻力分量；计算冰致阻力序列的均值与标准差；以 μ+3σ 为阈值检测碰撞事件；统计事件次数、持续步数与峰值；对碰撞峰值排序并提取上尾分位数；分区间统计阻力分布直方图；把统计结果写入文件并输出屏幕报表；用菜单调度全部功能。

本题直接对应船舶与海洋工程专业"从试验数据中辨识冰载荷"的核心能力：冲量-动量反演是冰池试验数据分析的标准手段之一，学生在过程中练熟数组、函数、结构体、文件等 C 语言要素，同时掌握差分、基线扣除、3σ 阈值、直方图这套试验数据处理通用流程，为后续专业试验课与毕业论文数据分析建立方法直觉。

## 三、数据来源与格式

**数据文件格式**：采用两个纯文本时序文件，格式一致：第 1 行为格式标识与总步数 N，其后每行一个采样点。用 `fscanf(fp, "%s", ...)`、`fscanf(fp, "%d", ...)` 与 `fscanf(fp, "%lf", ...)` 即可逐个读入。

速度文件 `vel_series.txt`：
```
VELF N=2000
0.00  1.502
0.01  1.498
0.02  1.455
0.03  1.401
```
字段含义：第 1 行 `VELF` 为格式标识，`N` 为采样点数；其后为"时间 t(s) 板体速度 v(m/s)"，共 N 行，采样间隔固定 0.01 s，速度为板体沿拖曳方向的速度。

外力文件 `ext_series.txt`：
```
EXTF N=2000
0.00  118.6
0.01  119.1
0.02  121.3
0.03  122.0
```
字段含义：第 1 行 `EXTF` 为格式标识，`N` 为采样点数；其后为"时间 t(s) 外力合力 F_ext(N)"，为拖曳装置测得的除冰作用外的已知外力（拖曳力 + 惯性修正项已并入），共 N 行，与速度文件时间轴严格对齐。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 采样点数 N | 个 | 1500～3000 | 固定 2000，采样间隔 dt = 0.01 s，总时长 20 s |
| 时间 t | s | 0～20 | 等间隔递增 |
| 板体速度 v | m/s | 0.5～2.0 | 三段构造：0～5 s 开水段恒速 1.5 匀速；5～15 s 冰区段叠加周期性减速（基线 1.5，叠加幅值 0.1～0.4 m/s 的随机碰撞减速脉冲，单脉冲持续 3～10 步）；15～20 s 开水段恢复 1.5；全程叠加 σ=0.008 m/s 高斯噪声 |
| 外力 F_ext | N | 80～200 | 开水段约 120 N 恒定（拖曳力，叠加 σ=2 N 噪声）；冰区段按"附加拖曳阻力 = 30·(1.5−v)"构造并叠加 σ=3 N 噪声 |
| 板体质量 m | kg | 300～800 | 固定 500.0，作为全局参数写入速度文件第 2 行亦可，本题取常量 |
| 碰撞脉冲 | — | 20～40 个 | 冰区段内 rand 均匀撒布，每个脉冲使速度单步下降 0.05～0.25 m/s 后按指数缓升恢复 |

**异常值与噪声注入方式**：① 随机选 0.5% 的速度点叠加 ±0.05 m/s 的粗差；② 随机令 2～3 个外力点出现缺失标记 −9999.0，读入时按相邻点线性补齐；③ 令开水段前 10 点人为偏置 +5 N，检验基线平均对少量坏点的抗性。以上异常用于检验 M1/M2 读入与预处理功能。

**真实数据集（如有）**：
- 论文原文（Ocean Engineering 357 (2026) 125460）试验部分给出的倾斜板-碎冰作用测力曲线可作为数据形态参照；
- HSVA、MARIN 等冰池公开试验报告中的阻力时程曲线（示例链接）：https://www.hsva.de/
- 教师亦可提供按上表规则预生成的 2～3 组不同冰况（轻冰/中冰/密集冰）的速度与外力时序文件。

## 四、数据结构设计

```c
#define MAX_N     4000        /* 最大采样点数，取值 1500~3000 */
#define MAX_EVT   256         /* 最大碰撞事件数，取值 20~40 */
#define MAX_BIN   20          /* 直方图区间数 */
#define MISSING   -9999.0     /* 缺测标记 */
#define MASS      500.0       /* 板体质量，单位 kg，固定值 */

/* 单个时序采样点 */
typedef struct {
    double t;                 /* 时间，单位 s，0~20，等间隔 0.01 */
    double v;                 /* 板体速度，单位 m/s，取值 0.5~2.0 */
    double fext;              /* 外力合力，单位 N，取值 80~200 */
} TimePoint;

/* 单个碰撞事件 */
typedef struct {
    int    start;             /* 事件起始采样点下标，0~N-1 */
    int    len;               /* 持续步数，取值 1~20 */
    double peak;              /* 事件内冰致阻力峰值，单位 N，取值 0~800 */
    int    peakIdx;           /* 峰值所在采样点下标 */
} Event;

TimePoint g_ts[MAX_N];        /* 时序数据数组 */
int       g_n = 0;            /* 实际采样点数 ≤ MAX_N */
double    g_rIce[MAX_N];      /* 反演得到的冰致阻力序列，单位 N */
double    g_base = 0.0;       /* 开水基线阻力，单位 N，约 120 */
double    g_mu = 0.0;         /* 冰致阻力（扣基线后）均值，单位 N */
double    g_sigma = 0.0;      /* 冰致阻力（扣基线后）标准差，单位 N */
double    g_th = 0.0;         /* 事件检测阈值 μ+3σ，单位 N */
double    g_dev[MAX_N];       /* 冰致阻力相对基线的偏差序列，单位 N */
Event     g_evt[MAX_EVT];     /* 碰撞事件数组 */
int       g_nEvt = 0;         /* 实际事件数 ≤ MAX_EVT */
double    g_sortedPeak[MAX_EVT]; /* 排序后的峰值数组，升序 */
int       g_hist[MAX_BIN];    /* 直方图各区间频数 */
double    g_binLo[MAX_BIN];   /* 各区间下界，单位 N */
int       g_nVel = 0, g_nExt = 0;  /* 两个文件分别读入的点数 */
int       g_loaded = 0;       /* 状态标记：两文件均已成功读入 */
```

全局数组放在文件作用域以避免栈溢出；`g_ts[]` 由速度与外力两个文件按时间轴对齐合并填入，时间不齐时报错；模块之间只通过上述全局数组与函数参数交换数据。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 板体速度时序读入模块**（源文件 `VelIO.c`）
- 功能简介：打开速度时序文件，校验格式标识后循环读入"时间-速度"各点填入临时数组并记录点数；检查等间隔性（相邻间隔与 0.01 s 偏差超过 1e-6 报警）；屏幕打印点数、时长、速度范围概要。
- 输入：文件路径（菜单输入，默认 `vel_series.txt`）。
- 输出：填充速度序列与 `g_nVel`；屏幕概要信息。

**M2 外力时序读入模块**（源文件 `ExtIO.c`）
- 功能简介：读入外力时序文件填入外力数组；把缺测标记 −9999.0 按相邻两点线性插值补齐并计数；校验两文件点数与时间轴严格一致后，合并填入 `g_ts[]`，置 `g_loaded` 为真。
- 输入：外力文件路径、M1 已读入的速度序列。
- 输出：填充 `g_ts[]`、`g_n`、`g_loaded`；屏幕补齐与对齐报告。

### 第二部分：算法实现（7 个模块）

**M3 开水基线计算模块**（源文件 `Baseline.c`）
- 功能简介：提示用户输入开水段的起止采样点下标（默认第 1～500 点），对该段逐点用差分式 R = m·Δv/Δt − F_ext 计算总反演阻力并求算术平均得到基线 `g_base`；同时输出该段标准差，供判断基线稳定性。
- 输入：`g_ts[]`、开水段起止下标、板体质量 MASS。
- 输出：`g_base`；屏幕基线值与开水段统计。

**M4 冰致阻力反演模块**（源文件 `Invert.c`）
- 功能简介：对全程逐步计算反演阻力 R_i = m·(v_{i+1} − v_i)/dt − F_ext_i，再减去基线 `g_base` 得到冰致偏差序列存入 `g_dev[]`（单位 N）；对第 1 点用前向差分特殊处理；屏幕输出反演序列的最小、最大值与曲线抽查点。
- 输入：`g_ts[]`、`g_base`。
- 输出：`g_dev[]`；屏幕反演概要（最大冰致偏差、出现时刻）。

**M5 均值方差统计模块**（源文件 `Stat.c`）
- 功能简介：对 `g_dev[]` 全序列计算均值 μ 与标准差 σ（先累加求和再求平方和，按 σ = sqrt(Σx²/n − μ²) 计算），得到阈值 `g_th = μ + 3σ`；屏幕输出 μ、σ、阈值及三者对应的冰阻力量纲。
- 输入：`g_dev[]`、`g_n`。
- 输出：`g_mu`、`g_sigma`、`g_th`；屏幕统计值。

**M6 3σ 阈值事件检测模块**（源文件 `Event.c`）
- 功能简介：扫描 `g_dev[]`，以偏差连续超过阈值 `g_th` 的一段为一个碰撞事件：记录起始下标、持续步数与段内峰值及其下标，存入 `g_evt[]`；孤立单点超限但与前后段间隔小于 2 步的合并处理；屏幕输出事件个数与检测阈值。
- 输入：`g_dev[]`、阈值 `g_th`。
- 输出：`g_evt[]`、`g_nEvt`；屏幕事件检测报告。

**M7 事件特征统计模块**（源文件 `EvtStat.c`）
- 功能简介：对事件数组统计：总次数、平均持续步数、最长持续步数、平均峰值、总冲量近似（各事件 峰值×持续步数×dt 之和）；找出峰值最大的事件并报告其发生时刻；屏幕打印事件特征汇总表。
- 输入：`g_evt[]`、`g_nEvt`、采样间隔。
- 输出：屏幕事件特征汇总；总冲量等汇总变量供 M10 使用。

**M8 峰值排序与上尾分析模块**（源文件 `Tail.c`）
- 功能简介：把全部事件峰值复制到 `g_sortedPeak[]` 用冒泡排序升序排列；提取上尾分位数：输出 P50、P75、P90、P95、P99 对应的峰值（按下标 ⌈p·n⌉−1 取值）；屏幕打印排序后的最大 10 个峰值排行表。
- 输入：`g_evt[]`、`g_nEvt`。
- 输出：升序 `g_sortedPeak[]`；屏幕分位数表与 Top-10 排行。

**M9 直方图统计模块**（源文件 `Hist.c`）
- 功能简介：以 `g_dev[]` 的最小、最大值为端点均分 MAX_BIN 个区间，分区间统计频数存入 `g_hist[]`；屏幕按"区间 [下界, 上界) | 频数 | 字符块"格式逐行打印直方图，并标出阈值 `g_th` 所在区间。
- 输入：`g_dev[]`、`g_n`。
- 输出：`g_hist[]`、`g_binLo[]`；屏幕字符直方图。

### 第三部分：数据输出（1 个模块）

**M10 结果报表输出模块**（源文件 `Report.c`）
- 功能简介：把基线、μ、σ、阈值、事件个数、峰值分位数与直方图表写入结果文件 `ice_report.txt`；屏幕打印完整统计报表（参数区、统计区、事件排行区）；同时输出逐时刻的"时间-冰致偏差-是否事件"清单文件 `ice_event_detail.csv`。
- 输入：全部全局统计量、`g_evt[]`、`g_hist[]`。
- 输出：`ice_report.txt`、`ice_event_detail.csv`；屏幕统计报表。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1～M10，循环直至选择退出；状态标记 `g_loaded` 约束"速度与外力两文件均读入且对齐后方可分析"。M3 必须先于 M4 执行（反演需要基线），M4 先于 M5～M9 执行（统计均基于偏差序列），M10 最后汇总输出。

**数据流**：

```
速度文件 ─► M1 读入 ─┐
                     ├─► M2 对齐合并 ─► g_ts[] (时序数组)
外力文件 ─► M2 读入 ─┘        │
                              ▼
                     M3 开水基线计算 ─► g_base
                              │
                              ▼
                     M4 差分反演 − 基线 ─► g_dev[] (冰致偏差序列)
                              │
        ┌─────────────────────┼──────────────────────┐
        ▼                     ▼                      ▼
   M5 均值方差           M9 直方图统计           M6 3σ事件检测
   μ/σ/阈值 g_th         g_hist[]               g_evt[] / g_nEvt
        │                     │                      │
        │                     │              ┌───────┴───────┐
        └──────► g_th ────────┘              ▼               ▼
                                       M7 事件特征统计  M8 峰值排序上尾
                                        (次数/步数/冲量)  (排序分位数)
                                              │               │
                                              └───────┬───────┘
                                                      ▼
                                            M10 结果报表输出
                                  (ice_report.txt / ice_event_detail.csv)
```

所有模块仅通过 `g_ts`、`g_dev`、`g_evt`、`g_hist` 及函数参数交换数据，函数接口在编码前书面约定。

## 十、选做扩展

1. 用二分法在峰值序列上查找给定载荷水平（如 200 N）的超越次数所对应的设计峰值，与直接排序取分位数结果对比，仍属查找范畴。
