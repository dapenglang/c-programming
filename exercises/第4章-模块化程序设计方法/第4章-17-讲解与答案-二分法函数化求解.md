## 二、预备知识：二分法的基本原理（零基础阅读）

### 1. 问题是怎么来的

要求球形冰块的吃水 $d$，即解方程 $\rho_w V(d) = \rho_i V_{\text{总}}$，其中 $V(d)$ 是 $d$ 的三次表达式。三次方程理论上能求根，但去掉一个不合理的负根后剩下的根也需数值计算；工程上更常用**二分法**：它思想极简单，只要函数在两端异号就**一定收敛**，非常稳健。

### 2. 公式是怎么推出来的

先把平衡方程写成残差形式。球缺体积可这样推：球心在原点，沿竖直方向取高度 $y$ 处的薄圆盘，其半径平方为 $R^2-(R-y)^2$，于是

$$
V(d) = \int_0^d \pi\bigl[R^2-(R-y)^2\bigr]\,\mathrm{d}y
     = \pi\int_0^d (2Ry-y^2)\,\mathrm{d}y
     = \pi\left(R d^2 - \frac{d^3}{3}\right)
     = \frac{\pi d^2(3R-d)}{3}.
$$

再令

$$
f(d) = \rho_w\,\frac{\pi d^2(3R-d)}{3} - \rho_i\,\frac{4}{3}\pi R^3 = 0 .
$$

二分法的依据是**零点定理**：若 $f(a)$ 与 $f(b)$ 异号，则 $[a,b]$ 内必有零点。取中点 $m=\dfrac{a+b}{2}$，看 $f(a)$ 与 $f(m)$ 的符号：异号说明根在左半边，否则在右半边。如此每次把区间**减半**，$k$ 次后区间长度缩为原来的一半的 $k$ 次方，必然收敛到根：

$$
b-a \to \frac{b_0-a_0}{2^k} < \text{eps},\qquad
k \approx \log_2\frac{b_0-a_0}{\text{eps}} .
$$

### 3. 代入本例手算

取 $R=1$，则区间 $[0,2]$。方程约去常数后等价于 $d^2(3-d) = \dfrac{\rho_i}{\rho_w}\cdot 4 = \dfrac{900}{1025}\times4 \approx 3.5122$。

- $d=1.5$：$1.5^2\times1.5 = 3.375 < 3.5122$，根在右侧；
- $d=1.625$：$1.625^2\times1.375 = 3.631 > 3.5122$，根在左侧；
- 继续对分：$1.5625$（偏低）、$1.56445$（偏高）……逐步锁定到 $d\approx1.5638$。

### 4. 编程实现要点

- **必先保证异号**：先算 $f(0)$、$f(2R)$ 确认一负一正，再进入循环；
- **中点与符号**：`m=(a+b)/2`；用 `f(a)*f(m) <= 0` 判断根在左半，令 `b=m`，否则 `a=m`；
- **终止判据**：以**区间长度** $b-a<\text{eps}$ 为准（二分法看区间宽度，而非函数值）；
- **返回中点**：停止后用 `(a+b)/2` 作为近似根，误差不超过区间的一半。

## 三、解题思路

1. **定常量**：`RHO_I=900`、`RHO_W=1025`、`PI` 用常量表示，避免魔法数字；
2. **写 `f`**：把球缺体积与重力项都算出来，返回浮力减重力；
3. **写 `bisect`**：初始化 `a=0`、`b=2R`，循环对分并计数，结束打印 `draft`、`n`；
4. **`main`**：读入 `R`，调用 `bisect(R, 1e-6)`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

const double RHO_I = 900.0;      /* 冰密度 kg/m^3 */
const double RHO_W = 1025.0;     /* 海水密度 kg/m^3 */
const double PI    = 3.14159265358979323846;

/* 平衡方程残差 f(d) = 浮力 - 重力（用 密度×体积 表示） */
double f(double d, double R)
{
    double v_sub = PI * d * d * (3.0 * R - d) / 3.0;   /* 球缺体积 */
    double v_tot = 4.0 * PI * R * R * R / 3.0;         /* 整球体积 */
    return RHO_W * v_sub - RHO_I * v_tot;
}

/* 二分法：在 [0, 2R] 内求 f(d)=0 的根，|b-a|<eps 时停止 */
double bisect(double R, double eps)
{
    double a = 0.0, b = 2.0 * R, m;
    int k = 0;

    while (b - a > eps) {
        m = (a + b) / 2.0;                 /* 取中点 */
        k++;
        if (f(a, R) * f(m, R) <= 0.0)      /* 根在左半区间 */
            b = m;
        else                               /* 根在右半区间 */
            a = m;
    }
    printf("draft = %.6f, n = %d\n", (a + b) / 2.0, k);
    return (a + b) / 2.0;
}

int main(void)
{
    double R;

    scanf("%lf", &R);
    bisect(R, 1e-6);
    return 0;
}
```

## 六、常见错误与讲解

**错误 1：区间两端同号就贸然二分**

```c
/* 若 f(a) 与 f(b) 同号，二分法不保证收敛 */
```

二分法的**前提是两端异号**。本题 $f(0)<0$、$f(2R)>0$ 恰好异号；换方程时务必先检查，必要时手工调整区间。

**错误 2：判据写成函数值足够小**

```c
while (fabs(f(m, R)) > eps)   /* 不稳妥：函数值大小与 x 误差不成正比 */
while (b - a > eps)           /* 对：以区间长度为准 */
```

**错误 3：忘记在循环里更新端点**

```c
while (b - a > eps) {
    m = (a + b) / 2.0;
    k++;                       /* 错：没有 b=m 或 a=m，死循环 */
}
```

**错误 4：端点更新方向写反**

```c
if (f(a,R)*f(m,R) <= 0) a = m;   /* 错：异号说明根在左半，应令 b=m */
if (f(a,R)*f(m,R) <= 0) b = m;   /* 对 */
```

## 七、与综合实验的衔接

实验 **C8（冰区船舶浮力与吃水）**中，吃水、排水体积、稳性等计算都归结为"解一个非线性平衡方程"。二分法最大的优点是**稳健**——只要区间包住根就一定收敛，不会像牛顿法那样因初值不当而失效；缺点是收敛较慢（线性收敛，每次只把误差减半）。工程上常先用二分法把根"圈"到一个小区间，再用牛顿法快速精修。把"方程函数 `f`"与"求解器 `bisect`"分离，正是让这段代码可复用的关键。下一题（18）将用同样的"函数分离"思想来做**数值积分**。
