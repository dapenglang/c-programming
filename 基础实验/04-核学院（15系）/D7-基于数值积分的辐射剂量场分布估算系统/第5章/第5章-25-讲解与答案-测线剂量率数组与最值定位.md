## 二、预备知识：为什么需要数组，以及"打擂台找最值"

### 1. 问题是怎么来的

上一练习算出了总剂量率——那是**一个数**。但测线上有 $n$ 个测点，会算出 $n$ 个数。用 `n` 个独立变量名显然不行（`D1, D2, ..., D50` 没法写）。

而且我们要做的是**在整个序列上比较**：这一点比那一点高多少？最高的是第几个？这些问题都要求数据**同时存在、可以来回比较**，不能算一个丢一个。

数组就是为此而生的：**一串同类型的数，共用一个名字，靠下标区分**。

```c
double d[50];   /* 50 个距离，d[0]、d[1]、…、d[49] */
double D[50];   /* 50 个剂量率，与距离一一对应 */
```

`d[i]` 与 `D[i]` 描述的是"同一个测点"的两个属性——距离与剂量率；下标 `i` 就是测点编号。

### 2. "打擂台找最值"的算法是怎么想出来的

要找一组数里的最大值，最朴素的想法是：**设一个擂台，让第一个数先当擂主，然后每个数都上台挑战，谁大谁当擂主，全部比完，最后的擂主就是最大值。**

具体三步：

1. **立擂主**：假设第 0 个最大，记 `Dmax = D[0]`、`imax = 0`；
2. **逐个挑战**：从下标 1 到 `n-1`，若 `D[i] > Dmax`，则换擂主（`Dmax = D[i]; imax = i;`）；
3. **宣布结果**：`Dmax` 是最大值，`imax` 是它的位置。

正确性说明：擂台上的数**始终是"已经检查过的那部分"里的最大值**。初始时"检查过的部分"只有 0 号，擂主是 0 号，显然成立。每次新来一个数，若它更大就换擂主，否则擂主不变——无论哪种情况，比完后擂主仍是"检查过的部分"的最大值。全部比完，"检查过的部分"就是全部，擂台上的就是全局最大值。

**为什么用严格大于 `>` 而不带等号？** 若有两个数并列最大，用 `>` 会保留**先出现的**那个；若用 `>=`，后来者会顶替，保留**后出现的**。本题要求"取先出现的"，所以用 `>`。

### 3. 用本例走一遍

样例 1：距离 $2.0, 3.0, 1.5, 4.0, 5.0$，$S = 120$，逐点算 $\dot{D}_i = 120/d_i^2$：

| i | d | D = 120/d² |
|---|---|---|
| 0 | 2.0 | 30.0000 |
| 1 | 3.0 | 13.3333 |
| 2 | 1.5 | **53.3333** ← 最大 |
| 3 | 4.0 | 7.5000 |
| 4 | 5.0 | 4.8000 |

打擂台过程：擂主先是 0 号（30.00）；1 号 13.33 不更大，不换；2 号 53.33 更大，换擂主（`imax = 2`）；3 号、4 号更小，不换。结果 `Dmax = 53.3333, index = 2`。

可以顺便验证物理直觉：**距离最小的测点（1.5 m，下标 2）剂量率最大**——与平方反比律完全一致。这条直觉可以用来快速检查程序结果是否合理。

### 4. 编程时怎么用它

两个循环：**第一个循环**边读距离边算剂量率、存进两个数组；**第二个循环**在数组上打擂台。也可以用"边读边打擂台"一次完成，但分成两步更清晰、更便于后面对数组做别的处理（如求平均、排序）。

> **这个思想在综合实验中反复出现**：D7 找剂量场热点、D8 找能谱峰值道址、D3 找最接近的截面点，全部是"数组 + 打擂台找最值/定位"。学会一次，多处可用。

## 三、解题思路

1. **定义数组**：`double d[50], D[50];`，大小取题目上限 50；
2. **读入并计算**：`for (i=0;i<n;i++) { scanf("%lf",&d[i]); D[i] = S/(d[i]*d[i]); }`；
3. **打擂台**：`Dmax = D[0]; imax = 0; for (i=1;i<n;i++) if (D[i] > Dmax) { Dmax = D[i]; imax = i; }`；
4. **输出**：`printf("Dmax = %.4f, index = %d\n", Dmax, imax);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double S = 120.0;      /* 点源强度，μSv·m^2/h */
    double d[50], D[50];         /* 各测点距离与对应剂量率 */
    int n, i;
    double Dmax;                 /* 最大剂量率 */
    int imax;                    /* 最大剂量率所在下标 */

    scanf("%d", &n);             /* 读入测点个数 */

    for (i = 0; i < n; i++) {
        scanf("%lf", &d[i]);           /* 读入第 i 个测点距离 */
        D[i] = S / (d[i] * d[i]);      /* 算该点剂量率存入数组 */
    }

    /* 打擂台：找最大剂量率及其下标 */
    Dmax = D[0];
    imax = 0;
    for (i = 1; i < n; i++) {
        if (D[i] > Dmax) {             /* 严格大于：并列时保留先出现的 */
            Dmax = D[i];
            imax = i;
        }
    }

    printf("Dmax = %.4f, index = %d\n", Dmax, imax);
    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 5: 2.0 3.0 1.5 4.0 5.0 | D = 30.00, 13.33, 53.33, 7.50, 4.80；最大 53.33 在下标 2 | `Dmax = 53.3333, index = 2` ✓ |
| 4: 6.0 4.0 8.0 10.0 | D = 3.33, 7.50, 1.875, 1.20；最大 7.50 在下标 1 | `Dmax = 7.5000, index = 1` ✓ |
| 3: 1.0 2.0 4.0 | D = 120.00, 30.00, 7.50；最大 120.00 在下标 0 | `Dmax = 120.0000, index = 0` ✓ |

三例中最大剂量率都出现在**距离最小的测点**上（下标 2、1、0 分别对应 1.5 m、4.0 m、1.0 m，均为该组的最小距离），与平方反比律一致。

## 六、常见错误与讲解

**错误 1：打擂台初始值取 0**

```c
Dmax = 0; imax = 0;              /* 错：若所有剂量率都小于 0 才安全，但本题都 > 0，会漏掉真正最大 */
for (i = 0; i < n; i++)
    if (D[i] > Dmax) { Dmax = D[i]; imax = i; }
Dmax = D[0]; imax = 0;           /* 对：用第 0 个元素初始化 */
for (i = 1; i < n; i++) ...
```

用 `0` 初始化看似方便，但语义上"假设 0 是最大"是错的——若数组元素全为正（本题剂量率必然为正），虽然结果碰巧对，但一旦数据换成可正可负（如温差），就会出错。**规矩：用第 0 个元素初始化，循环从 1 开始。**

**错误 2：只记录最大值，忘记记录下标**

```c
if (D[i] > Dmax) {
    Dmax = D[i];              /* 忘了 imax = i */
}
```

**错误 3：下标与编号混淆**

```c
printf("... index = %d\n", imax + 1);   /* 若题目期望 0 基下标，+1 就错了一位 */
```

数组下标从 0 开始。题目要求"下标从 0 开始"，直接输出 `imax`。若题目说"第几个测点"，才需要 `imax + 1`。**看清题目对编号的约定。**

**错误 4：数组越界**

```c
double d[50];
for (i = 0; i <= n; i++)      /* 错：i 可以取到 n，d[n] 越界 */ 
```

`n` 个元素的有效下标是 `0 ～ n-1`，循环条件必须是 `i < n`。越界会破坏相邻内存或直接崩溃。
