# 第 6 章 练习 21　指针遍历灰度直方图

**所属综合实验**：B1（B1-基于灰度直方图统计的图像二值化处理系统）

**对应章节**：6 指针（6.1 指针与地址、6.2 指针与数组、6.3 指针运算、3.2 选择结构、3.3 循环结构）

**场景来源**：综合实验 B1《基于灰度直方图统计的图像二值化处理系统》（人工智能学院）——本练习是该实验中"直方图峰值分析"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

图像二值化系统统计出灰度直方图后，得到的是一个长度为 256 的数组：`hist[0]` 存灰度 0 的像素个数，`hist[1]` 存灰度 1 的个数……`hist[255]` 存灰度 255 的个数。这个数组描述了整幅图的亮度分布。

选阈值时，程序常常要找**峰值**：哪个灰度级上像素最多？哪个灰度级像素最少？用**指针**遍历这个数组，可以更直接地"在内存里走一趟"，这也是 C 语言处理数组的经典方式。B1 系统分析直方图时就用指针来做。

## 二、任务要求

编写一个完整程序 `hist_pointer.c`：

1. 定义数组 `int hist[256];`，读入 256 个整数（题目保证每个 $0 \le hist[i] \le 1000$）；
2. 定义指针 `int *p`，用**指针遍历**的方式完成统计（即用 `*p` 取值、`p++` 移动，而不是 `hist[i]`）：
   - 找出像素最多的灰度级 `peak_gray` 及其像素数 `peak_cnt`；
   - 找出像素最少的灰度级 `min_gray` 及其像素数 `min_cnt`；
3. 输出这两个结果。

## 三、输入输出格式

**输入**：一行，256 个整数，为各灰度级的像素数，用空格分隔。

**输出**：两行，按格式输出：
```
peak: gray = 峰值灰度, cnt = 像素数
min : gray = 谷值灰度, cnt = 像素数
```

若出现并列，取**灰度值较小**的那一个。

## 四、样例

输入（为便于展示，此处只列出前若干个，实际输入为 256 个数）：

```
1 2 3 4 5 6 7 8 ... 0 ... 0
```
（第 0 个为 1，第 1 个为 2，……第 7 个为 8，其余为 0。）

输出：
```
peak: gray = 7, cnt = 8
min : gray = 8, cnt = 0
```

> 说明：样例中灰度 7 的像素数 8 最大，故峰值在灰度 7；灰度 8 的像素数 0 最小，故谷值在灰度 8。并列时取小灰度的规则，用于保证结果唯一。

## 五、提示

指针遍历的核心是"不写下标，用指针走"：

```c
int *p = hist;        /* p 指向数组第一个元素 */
for (i = 0; i < 256; i++) {
    /* 此时 *p 就是 hist[i] */
    ...
    p++;              /* 指针后移一位，指向下一个元素 */
}
```

数组名 `hist` 本身就代表"第一个元素的地址"，所以 `int *p = hist;` 就是让 `p` 指向开头。`p++` 让指针前进一步（前进一个 `int` 的距离），正好走到下一个元素。

找最值时，先假设第 0 个元素是峰值和谷值，然后一边走一边比较更新；因为是从小灰度往大灰度走，只有在**严格大于**（峰值）或**严格小于**（谷值）时才更新，就自然实现了"并列取小灰度"的规则。

**完成本练习后你将具备的能力**：理解指针与数组的关系、用指针遍历数组、用指针取值与移动——这些是实验 B1 中"直方图分析模块"的地基。
