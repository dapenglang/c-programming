# 第 7 章 练习 16　链表有序插入

**对应章节**：7 数据的结构化封装方法（7.5 链表——有序链表的建立、边查找边插入、头插与中间插入的统一处理、`malloc`/`free`）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"把新测点按载荷大小插入有序数据链"环节的实现。

## 一、应用场景

有些分析要求数据链**始终按载荷从小到大排列**（例如取分位数、做单调性检查）。这样每来一条新记录，就不能简单地头插或尾插，而要**先找到它应该待的位置，再插进去**，使插入后链表仍然有序。做法是从链头出发一直走，直到遇到第一个"载荷不小于新记录"的节点，把新记录插到它前面。它可能插在链头（比所有节点都小），也可能插在中间或链尾（比所有节点都大）——本练习要把这三种情况用同一段代码统一处理。

## 二、任务要求

编写一个完整程序 `list_insert_sorted.c`：

1. 定义节点结构体类型 `struct IceLoad`：`int id`、`double load`（载荷，kN）、`struct IceLoad *next`；
2. 读入整数 `m`（初始记录数），再读入 `m` 行记录（`id` 与 `load`）——**这些输入不保证有序**；程序对每条记录都调用"有序插入"，从而把整条链表建成**按载荷升序**排列；
3. 再读入一行新记录（`id` 与 `load`），对它同样执行一次**有序插入**；
4. 按链表顺序（升序）输出全部节点（每行 `id load`，保留 2 位小数），最后输出 `count = 节点总数`；
5. 每次 `malloc` 检查返回值；程序结束用 `free` 释放全部节点。

> 说明：当载荷相等时，新记录插在已有等值节点**之前**（只要查找条件写成 `cur->load < p->load` 即可自然满足），本题样例中不出现相等情形。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `m`（`0 ≤ m ≤ 100`）；
- 接下来 `m` 行：每行 `id load`；
- 接下来一行：新记录的 `id load`。

**输出**：按载荷升序输出 `m + 1` 行，每行 `id load`（保留 2 位小数）；最后一行输出 `count = 节点总数`。

## 四、样例

**样例 1**

输入：
```
3
101 30.0
102 10.0
103 50.0
104 25.0
```
输出：
```
102 10.00
104 25.00
101 30.00
103 50.00
count = 4
```

**样例 2**

输入：
```
2
201 8.0
202 20.0
203 12.0
```
输出：
```
201 8.00
203 12.00
202 20.00
count = 3
```

## 五、提示

- 有序插入 = **顺序查找插入位置 + 改接指针**，同样用 `prev`/`cur` 双指针定位：
  ```c
  prev = NULL; cur = head;
  while (cur != NULL && cur->load < p->load) {  /* 跳过所有比新值小的 */
      prev = cur;
      cur = cur->next;
  }
  /* 停下时：cur 是第一个不小于新值的节点（或 NULL） */
  if (prev == NULL) { p->next = head; head = p; }  /* 插在链头 */
  else              { p->next = cur; prev->next = p; } /* 插在 prev 之后 */
  ```
- **关键点**：`if (prev == NULL)` 这一支同时覆盖了"空链表"（`head == NULL`）和"新值最小"两种情况，无需额外特判；
- 插入前先把新节点的数据填好，`next` 由插入代码负责改接；
- 对每条输入记录都执行上面这段插入代码，就能把整条链建成升序；
- 遍历输出（按链序）即为升序；输出前记得先完成所有插入。

**完成本练习后你将具备的能力**：把"查找"和"插入"合二为一、用统一代码处理头插与中间插入、建立并维护一条有序链表——这是实验 C7"有序数据链维护模块"的地基。
