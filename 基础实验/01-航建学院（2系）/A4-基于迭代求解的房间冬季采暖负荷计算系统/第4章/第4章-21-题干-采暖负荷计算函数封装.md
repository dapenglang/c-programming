# 第 4 章 练习 21　采暖负荷计算函数封装

**所属综合实验**：A4（A4-基于迭代求解的房间冬季采暖负荷计算系统）

**对应章节**：4 模块化程序设计（4.1 函数的定义与调用、4.2 参数传递、4.3 返回值、4.4 函数声明）

**场景来源**：综合实验 A4《基于迭代求解的房间冬季采暖负荷计算系统》（航建学院）——本练习是该实验中"围护结构传热负荷计算"环节的模块化实现。

**建议用时**：20～30 分钟

## 一、应用场景

哈尔滨冬季室外温度可低至 $-29\ ^\circ\text{C}$，房间要保持 $20\ ^\circ\text{C}$，就必须由采暖系统不断补上围护结构向外散失的热量。冬季采暖负荷的基本计算式是

$$
Q = K \cdot A \cdot \Delta T
$$

其中 $K$ 是围护结构传热系数（W/(m²·K)），$A$ 是围护结构面积（m²），$\Delta T$ 是室内外温差（K），$Q$ 是采暖负荷（W）。

**围护结构**（外墙、屋面、外窗、外门……）不止一种，每种都有自己的 $K$ 和 $A$，室内外温差却都是同一个。于是程序需要把"算一种围护结构的负荷"这件事封装成一个**函数**，反复调用不同参数来累加总负荷。本练习就实现这个函数。

## 二、任务要求

编写一个完整程序 `heating_load.c`：

1. 定义一个函数 `double calc_Q(double K, double A, double dT)`，按公式 $Q = K \cdot A \cdot \Delta T$ 计算并**返回**负荷；
2. 主函数中依次读入"外墙、外窗、屋面"三种围护结构的 $K$、$A$（共 6 个实数）以及一个室内外温差 `dT`；
3. 三次调用 `calc_Q`，把结果累加得到总负荷；
4. 输出每种围护结构的负荷和总负荷，均保留 **1 位小数**。

## 三、输入输出格式

**输入**：7 行实数，依次为外墙 K、外墙 A、外窗 K、外窗 A、屋面 K、屋面 A、室内外温差 dT。

**输出**：4 行，前三行分别为 `Q_wall`、`Q_window`、`Q_roof` 的负荷（W），第四行为 `Q_total` 总负荷（W），均保留 1 位小数。

## 四、样例

**样例 1**

输入：
```
0.45 120.0
2.80 30.0
0.35 150.0
49.0
```
输出：
```
Q_wall = 2646.0
Q_window = 4116.0
Q_roof = 2572.5
Q_total = 9334.5
```

**样例 2**

输入：
```
0.50 100.0
3.00 20.0
0.40 120.0
30.0
```
输出：
```
Q_wall = 1500.0
Q_window = 1800.0
Q_roof = 1440.0
Q_total = 4740.0
```

## 五、提示

函数原型固定为：

```c
double calc_Q(double K, double A, double dT);
```

返回值类型是 `double`（负荷是实数），三个参数也都是 `double`。公式为

$$
Q = K \cdot A \cdot \Delta T
$$

函数体内只需要一行计算加一行 `return`：

```c
double calc_Q(double K, double A, double dT)
{
    return K * A * dT;
}
```

**完成本练习后你将具备的能力**：定义带参数、带返回值的函数；理解形参与实参的对应关系；用函数的返回值参与主函数的计算；把"重复使用的计算"从主函数里抽出来单独封装。
