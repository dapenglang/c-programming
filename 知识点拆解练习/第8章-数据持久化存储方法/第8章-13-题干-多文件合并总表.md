# 第 8 章 练习 13　多文件合并总表

**对应章节**：8 数据持久化存储方法（8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）

**场景来源**：综合实验 C9《冰区结构压力场监测与热点分析系统》（水声学院）——本练习是该实验中"多时刻压力数据合并总表"环节的实现。

**建议用时**：30~40 分钟

## 一、应用场景

实验 C9 的压力监测系统每隔一小时输出一个数据文件（`p_t1.txt`、`p_t2.txt`、`p_t3.txt`），分别记录三个时刻各测点的压力值。做热点分析之前，需要把三个"分时刻"文件合并成一张**总表**：一行对应一个测点，后面依次跟三个时刻的压力值，这样各测点的压力变化一目了然。本练习编写合并程序：同时打开三个源文件和一个目标文件，以第一个文件为"节拍"，逐行从三个文件各取一条记录，拼成一行写进总表。

## 二、任务要求

编写完整程序 `merge.c`：

1. 以 `"r"` 方式打开 `p_t1.txt`、`p_t2.txt`、`p_t3.txt`，以 `"w"` 方式打开 `p_all.txt`，**四个 fopen 的返回值都要检查**；任一打开失败时输出提示，关闭所有已打开的文件后结束程序（返回值 1）；
2. 三个源文件格式完全相同：每行两列、空格分隔——测点编号（整数）、该时刻压力值（kPa，1 位小数）；三个文件的测点编号与排列顺序**保证一致**、行数相同；
3. 以第一个文件的读入成功为节拍循环：每轮用 `fscanf` 分别从三个文件各读一条记录（三者的测点编号应相同），把"编号 + 三个时刻压力"按 `"%d %.1f %.1f %.1f\n"` 写入 `p_all.txt`；
4. 循环结束后关闭全部四个文件，屏幕输出 `合并完成：共 N 个测点`；
5. 在总表第一行写入表头 `Point t1 t2 t3`（便于人工查看）。

**数据文件格式约定**：源文件每行形如 `1 21.5`；总表每行形如 `1 21.5 22.1 22.9`。

## 三、输入输出格式

**输入文件**：`p_t1.txt`、`p_t2.txt`、`p_t3.txt`（格式相同的三个空格分隔文本）。

**输出文件**：`p_all.txt`（第一行为表头 `Point t1 t2 t3`，其后每行四列）。

**屏幕输出**：一行，`合并完成：共 N 个测点`。

## 四、样例

**输入文件 p_t1.txt**：

```
1 21.5
2 22.0
3 21.8
4 22.4
```

**输入文件 p_t2.txt**：

```
1 22.1
2 22.8
3 22.5
4 23.0
```

**输入文件 p_t3.txt**：

```
1 22.9
2 23.5
3 23.2
4 23.8
```

**程序运行后 p_all.txt 的内容**：

```
Point t1 t2 t3
1 21.5 22.1 22.9
2 22.0 22.8 23.5
3 21.8 22.5 23.2
4 22.4 23.0 23.8
```

**屏幕输出**：

```
合并完成：共 4 个测点
```

## 五、提示

- 本题同时活跃着**四个**文件指针：三个读、一个写。每个 fopen 之后立即检查 NULL 是本题主打纪律；
- 循环节拍：`while (fscanf(f1, "%d %lf", &id, &p1) == 2)`，循环体内再从 f2、f3 各 fscanf 一次。由于三个文件行数相同、编号一致，一个节拍器就够了；
- 表头用 `fprintf(fo, "Point t1 t2 t3\n");` 在循环之前写一次即可；
- 若想更严格，可以在循环内检查三个文件读到的编号是否相同，不同则报错退出——工程上这叫"对齐校验"。

**完成本练习后你将具备的能力**：同时管理多个文件指针、以单一节拍器对齐多个同构数据源、把分散的"分表"拼成"总表"——这是实验 C9 热点分析前数据处理的第一步，也是练习 20 完整流水线中"多源汇聚"思想的雏形。
