## 二、预备知识：线性插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

核数据库只给出两个离散能量点的截面：1.0 eV 处 18.0 b，5.0 eV 处 3.0 b。**中间能量（如 3.0 eV）的截面是多少？** 工程上默认在相邻两档之间截面随能量**均匀变化**（图象近似为直线），于是在两点之间按比例取值，这就是线性插值。

### 2. 公式是怎么推出来的

设已知点为 $(E_0, \sigma_0)$、$(E_1, \sigma_1)$，要求 $E$ 处（$E_0 \le E \le E_1$）的值。"均匀变化"意味着**截面变化量与能量变化量成正比**：

$$
\frac{\sigma - \sigma_0}{\sigma_1 - \sigma_0} = \frac{E - E_0}{E_1 - E_0}
$$

解得

$$
\sigma = \sigma_0 + \dfrac{(\sigma_1 - \sigma_0)(E - E_0)}{E_1 - E_0}
$$

读作"起点截面 + 全程截面变化 × 已走能量比例"。$(\sigma_1 - \sigma_0)$ 为负表示截面在下降，公式自动带符号。

### 3. 用本例走一遍

取 $E = 3.0$，代入 $(E_0, \sigma_0) = (1.0,\ 18.0)$，$(E_1, \sigma_1) = (5.0,\ 3.0)$：

- 已走比例：$(3.0 - 1.0)/(5.0 - 1.0) = 2/4 = 0.5$；
- 全程变化：$3.0 - 18.0 = -15.0$ b；
- 已变化：$-15.0 \times 0.5 = -7.5$ b；
- 结果：$\sigma = 18.0 - 7.5 = 10.5$ b。

再取 $E = 4.2$：比例 $= (4.2-1.0)/4 = 3.2/4 = 0.8$，变化量 $-15 \times 0.8 = -12$，得 $\sigma = 6.0$ b。端点处 $E=1.0$ 得 18.0、$E=5.0$ 得 3.0，与数据一致。

### 4. 编程时怎么用它

四个表格常量 + 一个输入，把公式翻译成一行赋值语句即可。注意分子分母都要先各自算好，尤其分母 $(E_1 - E_0)$ 必须单独成组。

> **这个思想在综合实验中反复出现**：D3 核截面、C1 声速剖面、A1 风荷载、D4 温度场，都是"表格 + 线性插值"。本题与练习 01、15 同一方法，请独立完成、独立验算。

## 三、解题思路

1. **确定常量**：`E0=1.0, E1=5.0, S0=18.0, S1=3.0`，用 `const double`；
2. **确定变量**：能量 `E` 与截面 `sigma`，用 `double`；
3. **套公式**：`sigma = S0 + (S1 - S0) * (E - E0) / (E1 - E0);`；
4. **输出**：`printf("sigma = %.3f b\n", sigma);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 截面表相邻两档：中子能量(eV) 与 截面(barn) */
    const double E0 = 1.0;    /* 下档能量 */
    const double E1 = 5.0;    /* 上档能量 */
    const double S0 = 18.0;   /* 下档截面 */
    const double S1 = 3.0;    /* 上档截面（截面随能量递减） */

    double E;        /* 待查中子能量，eV */
    double sigma;    /* 插值得到的截面，barn */

    /* 读入能量（题目保证 1.0 <= E <= 5.0） */
    scanf("%lf", &E);

    /* 线性插值：sigma = s0 + (s1 - s0) * (E - E0) / (E1 - E0) */
    sigma = S0 + (S1 - S0) * (E - E0) / (E1 - E0);

    /* 输出，保留 3 位小数 */
    printf("sigma = %.3f b\n", sigma);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3.0 | 18 + (−15) × 2/4 = 18 − 7.5 = 10.5 | `sigma = 10.500 b` ✓ |
| 4.2 | 18 + (−15) × 3.2/4 = 18 − 12 = 6.0 | `sigma = 6.000 b` ✓ |
| 1.0 | 18 + (−15) × 0/4 = 18.0（下端点） | `sigma = 18.000 b` ✓ |
| 5.0 | 18 + (−15) × 4/4 = 3.0（上端点） | `sigma = 3.000 b` ✓ |

端点值与数据库给值完全一致，中间值线性下降，插值正确。

## 六、常见错误与讲解

**错误 1：常量写成整数**

```c
const double S0 = 18, S1 = 3;    /* 错：整数字面量，语义与精度都不对 */
const double S0 = 18.0, S1 = 3.0;  /* 对：一律带小数点 */
```

**错误 2：忘记取地址符**

```c
scanf("%lf", E);      /* 错：程序崩溃或读不进数据 */
scanf("%lf", &E);     /* 对：scanf 需要变量地址 */
```

**错误 3：输出格式与精度不符**

```c
printf("sigma = %.3d b\n", sigma);   /* 错：%d 是整数格式，double 会乱码 */
printf("sigma = %.3f b\n", sigma);   /* 对：%.3f 保留 3 位小数 */
```

**错误 4：公式括号写错**

```c
sigma = S0 + (S1 - S0) * E - E0 / (E1 - E0);      /* 错：括号缺失 */
sigma = S0 + (S1 - S0) * (E - E0) / (E1 - E0);    /* 对：先减、再乘、再除 */
```

本题斜率本来就为负，若结果大于 18.0 或小于 3.0，一定超出了合理范围，可据此自查。
