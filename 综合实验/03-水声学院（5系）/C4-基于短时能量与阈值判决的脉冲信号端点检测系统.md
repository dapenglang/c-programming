# 题目 C4：基于短时能量与阈值判决的脉冲信号端点检测系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行脉冲信号端点检测工具。它读入一段连续采样的水声信号，按固定帧长与帧移把长序列切分成一帧一帧（用二维数组组织），逐帧计算短时能量与短时过零率，再由背景静音段的统计量自动设定高、低门限，用双门限判决找出每一段脉冲信号的起点与终点，统计脉冲个数与各段时长，输出检测结果、门限敏感性对比表以及波形与能量曲线字符画。

**解决什么重要问题**：声呐、水声通信接收到的是一长段连续数据，其中真正感兴趣的脉冲（回波、通信帧、目标瞬态）只占一小部分，其余是静音与噪声。如果不知道信号在什么时刻开始、什么时刻结束，就无法对单次脉冲做长度、能量、到达时刻等的分析，也无法把它们一段段切出来单独处理。端点检测就是给数据"分段"的第一步：做不好会出现漏判（脉冲被整段漏掉）或误判（把噪声当成脉冲）。用短时能量判断"这一段是否有信号"，再用短时过零率区分"低能量的噪声"和"低能量的信号"，是本系统要解决的核心问题。

**支撑哪些关键应用**：① 声呐回波的分段与计数；② 水声通信数据帧的同步与定位；③ 目标瞬态（螺旋桨噪声突变、敲击声）事件的自动截取；④ 语音/声学信号的静音切除（同一套方法）；⑤ 长时监测数据的有效事件提取与存储压缩。

**与专业培养的关联**：水声信号处理课程中的"分帧、短时分析"是信号处理的第一课。本题让学生用 C 语言实现分帧、短时能量、短时过零率与双门限判决，建立"把连续信号切成帧、逐帧统计、再按门限判决"的核心直觉，为后续学习更复杂的检测方法打基础，全程只用到计数、求和与比较。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述脉冲信号端点检测系统，完成"文件读入→分帧→特征计算→门限设定→端点判决→结果输出"的完整流程。具体任务包括：设计信号文件格式并容错读入采样序列；按帧长与帧移把序列切分成帧并组织为二维数组；逐帧计算短时能量；逐帧计算短时过零率；由背景段统计自动设定高、低门限；用能量与过零率联合的双门限法判决脉冲起点、终点；统计脉冲个数与各段时长；做门限敏感性对比实验；绘制波形与能量曲线字符画；用菜单调度全部功能。

本题对应水声专业"从连续数据中自动截取有用事件"的基础能力，学生在此过程中练熟二维数组、嵌套循环、计数统计与文件读写。

## 三、数据来源与格式

**数据文件格式**：采用纯文本格式，第 1 行为格式标识，第 2 行为信号信息，其后每行一个采样值。用 `fscanf(fp, "%lf", ...)` 循环读入即可。

```
DET
P1 10000 16
0.0012
-0.0034
0.0048
0.5100
...
0.0007
```

字段含义：第 1 行 `DET` 为格式标识（Detection）；第 2 行为信号名 `P1`、采样率 `10000`（Hz）、样本数 `16`；其后每行为一个采样值，归一化幅度（相对满量程），典型范围 [−1.0, 1.0]，脉冲段幅值可达 ±1.0，静音段幅值约 ±0.02。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 信号名 | — | P1～P4 | 顺序编号 |
| 采样率 fs | Hz | 10000（或 48000） | 固定值，写入文件头 |
| 样本数 n | 个 | 3000～6000 | 覆盖 0.3～0.6 s 时长 |
| 脉冲个数 | 个 | 3～5 | 在时间轴上随机分布，彼此间隔 ≥ 0.05 s |
| 脉冲段 | — | 幅值 0.3～1.0 | 载频 1～3 kHz 正弦加高斯包络，脉宽 5～20 ms，起止各带 1 ms 升余弦过渡 |
| 静音段 | — | 幅值 ±0.02 | 高斯白噪声 σ=0.01，叠加缓慢基线漂移 |
| 干扰 | — | 幅值 ±0.08 | 在静音段随机叠加 2～4 个短促的弱噪声尖峰（防止检测过于理想） |

**异常值与噪声注入方式**：① 在静音段随机叠加 2～4 个幅值约 ±0.08 的弱尖峰，用于检验双门限法对噪声的抑制（避免过零率高但能量低的噪声被误判）；② 在某个脉冲附近插入 1 段幅值 0.05 的准正弦干扰，用于检验过零率判据的辅助作用。以上注入使检测不再是"看一眼就能分出来"，必须靠门限统计。

**真实数据集（如有）**：
- 公开水下听音器数据可参考 Ocean Networks Canada 水声观测：https://oceannetworks.ca/
- 实际授课以教师提供的脉冲串仿真文件与实测转存文件为主。

## 四、数据结构设计

```c
#define N_MAX   16384          /* 最大样本数 */
#define L_MAX   512            /* 最大帧长（样点） */
#define FR_MAX  512            /* 最大帧数 */

/* 一段待检测信号 */
typedef struct {
    char   name[16];           /* 信号名，如 "P1" */
    int    fs;                 /* 采样率，单位 Hz，取值 10000~48000 */
    int    n;                  /* 实际样本数 ≤ N_MAX */
    double x[N_MAX];           /* 采样序列，归一化幅度，[−1.0, 1.0] */
    int    frameLen;           /* 帧长 L，单位样点，默认 256 */
    int    shift;              /* 帧移 S，单位样点，默认 128 */
    int    nFrame;             /* 总帧数 = (n − L)/S + 1 */
} DetectSig;

DetectSig g_sig;                   /* 当前工作信号 */

double g_frame[FR_MAX][L_MAX];     /* 分帧后二维数组，帧号 × 帧内样点 */
double g_energy[FR_MAX];           /* 短时能量，逐帧 */
double g_zcr[FR_MAX];              /* 短时过零率，逐帧，取值 0~1 */
int    g_state[FR_MAX];            /* 帧状态：1 = 信号帧，0 = 静音帧 */

/* 检测出的脉冲段 */
typedef struct {
    int    startFrame;         /* 起点帧号 */
    int    endFrame;           /* 终点帧号 */
    int    startSample;        /* 起点样点号 = startFrame × shift */
    int    endSample;          /* 终点样点号 = endFrame × shift + L − 1 */
    double peak;               /* 该段峰值幅度 */
} Pulse;

Pulse  g_pulse[32];                /* 检测到的脉冲段，最多 32 段 */
int    g_nPulse = 0;               /* 脉冲个数 */
double g_thHigh = 0.0;             /* 高门限（能量域），由背景段统计得到 */
double g_thLow  = 0.0;             /* 低门限（能量域） */
double g_zcrTh  = 0.0;             /* 过零率辅助门限 */
```

全局数组置于文件作用域以避免栈溢出；各模块只通过 `g_sig`、`g_frame`、`g_energy`、`g_zcr` 及函数参数交换数据。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 信号文件读入模块**（源文件 `DetIO.c`）
- 功能简介：打开信号文本文件，读入格式标识、信号名、采样率与样本数，再循环读入全部采样值填入 `g_sig.x[]`；文件不存在、标识错误或样本数越界时给出明确提示并返回失败标志。
- 输入：文件路径（菜单输入，默认 `pulse_P1.txt`）。
- 输出：填充 `g_sig`（name/fs/n/x）；返回成功/失败标志。

**M2 分帧模块**（源文件 `Framing.c`）
- 功能简介：按帧长 L=256、帧移 S=128 把 `g_sig.x[]` 切分成帧，第 k 帧的第 m 个样本为 `g_frame[k][m] = x[k·S + m]`；计算总帧数 `g_sig.nFrame`，并检查帧长是否超过上限；用二维数组组织，重叠部分按帧移自然重复。
- 输入：`g_sig`（n、frameLen、shift）。
- 输出：`g_frame[FR_MAX][L_MAX]`、`g_sig.nFrame`。

### 第二部分：算法实现（4 个模块）

**M3 短时能量逐帧计算模块**（源文件 `FrameEnergy.c`）
- 功能简介：对每一帧计算短时能量 E_k = Σ_{m=0}^{L−1} (x[k·S+m])²，存入 `g_energy[k]`；输出能量的最大值、最小值与前若干帧的能量值供观察。
- 输入：`g_frame[][]`、帧数。
- 输出：`g_energy[]`；屏幕能量概览。

**M4 短时过零率计算模块**（源文件 `FrameZCR.c`）
- 功能简介：对每一帧统计相邻样点符号变化的次数并除以帧长，得到过零率 ZCR_k = (Σ 符号变化次数)/(L−1)，存入 `g_zcr[k]`；用于区分"低能量但高频的噪声"与"低能量但低频的信号"。
- 输入：`g_frame[][]`、帧数。
- 输出：`g_zcr[]`；屏幕过零率概览。

**M5 能量门限设定模块**（源文件 `Threshold.c`）
- 功能简介：取信号起始若干帧（如最少能量的 20% 帧）作为背景静音段，统计其能量均值 μ_b 与标准差 σ_b，设定高门限 `g_thHigh = μ_b + 5σ_b`、低门限 `g_thLow = μ_b + 2σ_b`，过零率门限 `g_zcrTh` 取背景段过零率均值的一定倍数；输出门限值与依据。
- 输入：`g_energy[]`、`g_zcr[]`、帧数。
- 输出：`g_thHigh`、`g_thLow`、`g_zcrTh`；屏幕门限设定说明。

**M6 双门限端点判决模块**（源文件 `Decide.c`）
- 功能简介：逐帧做双门限判决：能量超过高门限的帧直接判为信号帧；能量介于低、高门限之间且过零率低于辅助门限的帧也判为信号帧；据此给 `g_state[]` 赋值，并把连续信号帧合并为脉冲段，记录每段的起止帧号与峰值，滤除长度小于最小脉宽（如 3 帧）的伪段。
- 输入：`g_energy[]`、`g_zcr[]`、`g_thHigh`、`g_thLow`、`g_zcrTh`。
- 输出：`g_state[]`、`g_pulse[]`、`g_nPulse`。

### 第三部分：数据输出（4 个模块）

**M7 检测结果统计模块**（源文件 `PulseStat.c`）
- 功能简介：汇总检测到的脉冲个数、每段的起止样点号、起止时间（样点号/fs）、时长（ms）与峰值幅度，输出检测结果明细表；对过短或过长的可疑段加标注。
- 输入：`g_pulse[]`、`g_nPulse`、`g_sig.fs`。
- 输出：屏幕检测结果明细表。

**M8 门限敏感性实验模块**（源文件 `ThExp.c`）
- 功能简介：对门限系数（高门限用 3σ/5σ/8σ、低门限用 1σ/2σ/3σ）组合分别重跑 M6，输出"门限系数-检测脉冲数-总信号帧数"对比表，观察门限收紧或放松对漏检与误检的影响。
- 输入：`g_energy[]`、`g_zcr[]`、门限系数列表。
- 输出：屏幕门限敏感性对比表。

**M9 波形与能量曲线字符画模块**（源文件 `PlotDet.c`）
- 功能简介：在同一屏分三栏显示：原始波形（按帧峰值抽样）、短时能量曲线（标注高/低门限水平线）、帧状态条（信号帧用 `#`、静音帧用 `.`），让端点检测结果一目了然。
- 输入：`g_sig.x[]`、`g_energy[]`、`g_state[]`、`g_nFrame`。
- 输出：屏幕波形、能量与状态字符画。

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读信号/分帧/算能量/算过零率/定门限/判决/看结果/门限实验/画图/退出），用 `do-while + switch` 调度 M1～M9；用状态标记约束"必须依次完成分帧、特征计算、门限设定后才能判决"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1～M9，循环直至退出；状态标记约束处理顺序（读入→分帧→能量/过零率→门限→判决→输出）。M6 判决依赖 M3/M4/M5 的结果，M7/M8/M9 依赖判决结果。

**数据流**：

```
信号文件 ─► M1 读入 ─► g_sig.x[]
                            │
                            ▼
                     M2 分帧 ─► g_frame[][]
                            │
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   │
   M3 短时能量        M4 短时过零率             │
        │ g_energy[]       │ g_zcr[]            │
        └─────────┬─────────┘                   │
                  ▼                             │
        M5 能量门限设定 ─► 高/低门限、过零率门限 │
                  │                             │
                  ▼                             │
        M6 双门限端点判决 ◄────────────────────┘
                  │  g_state[] / g_pulse[] / g_nPulse
                  ▼
        ┌─────────┼─────────────┐
        ▼         ▼             ▼
   M7 结果统计  M8 敏感性实验  M9 波形/能量/状态字符画
                  │
                  ▼
            M10 主控菜单调度
```

所有模块仅通过 `g_sig`、`g_frame`、`g_energy`、`g_zcr`、`g_state`、`g_pulse` 及函数参数交换数据，函数接口在编码前书面约定。

## 十、选做扩展

1. 先用滑动平均对信号做平滑，再做短时能量与判决，比较平滑前后检测结果（复用 C2 思路）。
2. 实现端点去抖动：要求连续 3 帧满足条件才确认起点/终点，避免单帧噪声引起的误判，属纯逻辑拼接。
3. 把背景门限的均值改用背景段能量的中位数（排序取中位）来计算，比较对弱尖峰干扰的鲁棒性。
