# 第 7 章 练习 15　链表节点删除

**对应章节**：7 数据的结构化封装方法（7.5 链表——按值查找、删除节点、头节点删除的特殊处理、`free` 释放被删节点）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"剔除作废或无效测点记录"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

在载荷数据链中，某个测点可能因为传感器故障或重复上报而需要**作废剔除**。剔除一条链表记录，不能像删除数组元素那样"整体前移"，而是要让它的**前一个节点直接指向它的后一个节点**，把它从链上"摘"下来，再释放它占用的内存。这里有一个绕不开的坑：要删除的节点可能是**链头**，而链头没有"前一个节点"。因此删除操作必须区分"删头节点"和"删中间（尾）节点"两种情况。本练习把删除的完整流程做一遍。

## 二、任务要求

编写一个完整程序 `list_delete.c`：

1. 定义节点结构体类型 `struct IceLoad`：`int id`、`double load`（载荷，kN）、`struct IceLoad *next`；
2. 读入整数 `n`，再读入 `n` 行记录（`id` 与 `load`），用**尾插法**建立链表；
3. 读入一个待删除的测点编号 `target`；
4. 在链表中**查找编号等于 `target` 的节点**：若找到则将其从链表中删除并 `free` 释放；**若目标恰为链头，需更新 `head`**；
5. 删除后按链表顺序输出剩余节点（每行 `id load`，保留 2 位小数），最后输出 `count = 剩余节点数`；**若未找到目标编号，只输出一行 `not found`**（链表保持不变）；
6. 每次 `malloc` 检查返回值；程序结束用 `free` 释放剩余全部节点。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`（`0 ≤ n ≤ 100`）；
- 接下来 `n` 行：每行 `id load`；
- 最后一行：一个整数 `target`（待删除的编号）。

**输出**：

- 若找到并删除：剩余节点每行 `id load`（保留 2 位小数），末行 `count = 剩余节点数`；
- 若未找到：只输出 `not found`。

## 四、样例

**样例 1**（删除中间节点）

输入：
```
4
101 10.0
102 20.0
103 30.0
104 40.0
102
```
输出：
```
101 10.00
103 30.00
104 40.00
count = 3
```

**样例 2**（删除链头节点）

输入：
```
3
201 5.0
202 6.0
203 7.0
201
```
输出：
```
202 6.00
203 7.00
count = 2
```

## 五、提示

- 删除要同时用到两个指针：`cur`（当前节点）和 `prev`（它的前一个节点）。初始 `prev = NULL; cur = head;`；
- 查找循环：只要 `cur != NULL` 且 `cur->id != target`，就让 `prev = cur; cur = cur->next;` 一起向后挪；
- 找到后分两种情况改接（这是本题的核心）：
  ```c
  if (prev == NULL)          /* 删的是头节点 */
      head = cur->next;         /* 让 head 直接跳过它 */
  else                       /* 删的是中间或尾节点 */
      prev->next = cur->next;   /* 让前驱越过它指向它的后继 */
  free(cur);                 /* 摘下来后释放内存 */
  ```
- **必须 `free(cur)`**：仅改指针只是把它"摘"出了链，它占的内存还在，不还就泄漏；
- 若循环结束时 `cur == NULL`，说明没找到，输出 `not found`，**不要**动链表；
- 输出剩余节点、统计剩余个数可与删除共用一次遍历。

**完成本练习后你将具备的能力**：掌握链表删除的"双指针 + 分类改接 + 释放"三步法、会单独处理删除头节点的特殊情况——这是实验 C7"无效测点剔除模块"的地基。
