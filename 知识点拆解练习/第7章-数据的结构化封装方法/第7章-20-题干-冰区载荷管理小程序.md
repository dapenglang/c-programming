# 第 7 章 练习 20　冰区载荷管理小程序（本章综合题）

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型、7.5 链表、7.6 二分法求解——本章综合）

**场景来源**：综合实验 C6《冰块与结构碰撞模拟系统》/ C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"动态载荷台账管理 + 统计 + 反求等效冰厚"环节的综合实现。

**建议用时**：40 分钟

## 一、应用场景

冰区监测系统运行时，测点记录是**一条条动态上报**的，条数事先不定——适合用**链表**承载；数据到齐后要给出样本数、平均载荷、最大载荷、超阈个数等**统计量**；而工程上还常由平均载荷**反求一个等效冰厚**：在简化模型下，冰载荷与冰厚满足 $F(h) = C\,h^2$，其中 $C = 50\ \text{kN/m}^2$ 是模型常数，$h$ 是等效冰厚（m）。已知平均载荷 $\bar{F}$，求出使 $F(h)=\bar{F}$ 的 $h$，这又是一个非线性方程求根，正好用**二分法**。本题把**结构体（链表节点）、链表、二分法**三种封装手段串起来，做成一个完整的小程序。

## 二、任务要求

编写一个完整程序 `ice_manager.c`：

1. 定义链表节点结构体 `struct IceLoad`：`int id`（测点编号）、`double load`（载荷，kN）、`struct IceLoad *next`；
2. 读入整数 `n`，再读入 `n` 行记录（`id` 与 `load`），用**尾插法**建立链表；读入阈值 `limit`；常量 $C=50$ 定义在程序里；
3. **遍历链表**统计四项：样本数 `count`、载荷总和 `sum` 与平均 `mean`、最大载荷 `max`、载荷不小于 `limit` 的个数 `over`；
4. 编写方程函数 `double F(double h, double fbar)`，返回模型残差 $F(h) = C\,h^2 - \bar{F}$（平均载荷经参数 `fbar` 传入）；再编写二分函数 `double bisect(double fbar, double a, double b, double eps, int *pn)`，在区间 $[0,3]$ 上求 $F(h)=0$ 的根（即等效冰厚），`eps = 1e-6`，对分次数经 `pn` 带回；
5. 按规定的报表格式输出统计量与等效冰厚（冰厚保留 6 位小数，其余载荷保留 2 位小数）；
6. 每次 `malloc` 检查返回值，程序结束用 `free` 释放整条链表。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`（`1 ≤ n ≤ 100`）；
- 接下来 `n` 行：每行 `id load`；
- 最后一行：一个实数 `limit`（阈值，kN）。

**输出**：按下述六行格式输出（载荷、阈值保留 2 位小数，冰厚保留 6 位小数）：
```
===== 冰区载荷管理小程序 =====
样本数 = <n>
平均载荷 = <mean> kN
最大载荷 = <max> kN
超阈样本数(>= <limit> kN) = <over>
等效冰厚 = <h> m (n = <对分次数>)
```

## 五、提示

- **三段式结构**：建链（尾插）→ 遍历统计 → 二分求根，三个环节依次进行，互不干扰；
- 建链时用 `head`、`tail` 两个指针，第一个节点让 `head = tail = p`，之后 `tail->next = p; tail = p;`；
- 统计时 `max` 可先取 `head->load` 作初始值，再沿链更新；`mean = sum / count;`（`count ≥ 1`）；
- 二分前要先确认区间两端异号：$F(0) = -\bar{F} < 0$，$F(3) = 50\times9 - \bar{F} > 0$（因为 $\bar{F}$ 是几十 kN 量级，远小于 450），两端异号，区间 $[0,3]$ 内必有根；
- 本题方程 $50h^2 = \bar{F}$ 的解正好是 $h = \sqrt{\bar{F}/50}$，可用它校对二分结果是否合理；
- 区间长度 3，对分次数约 22 次（$3/2^{22} < 10^{-6}$）。
