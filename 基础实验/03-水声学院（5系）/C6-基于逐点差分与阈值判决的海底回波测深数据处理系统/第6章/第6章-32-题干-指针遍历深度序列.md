# 第 6 章 练习 32　指针遍历深度序列

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：6 地址与指针（6.1 地址与指针变量、6.3 指针与数组——指针算术遍历）

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"深度时序统计"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

测深仪按固定时间间隔记录一次海底回波深度，得到一个深度序列。处理前要先做基础统计：**总深度、平均深度、最大与最小深度**——平均深度反映海底整体走势，最大/最小深度给出地形起伏范围。

在前面的练习里，我们用"数组 + 下标"循环统计。综合实验 C6 的正式代码改用**指针遍历**：指针一步步在数组上"走"，效率高、写法也更能体现"数组名就是地址"的本质。本题就用指针把这段统计写出来。

## 二、任务要求

编写一个完整程序 `depth_ptr.c`：

1. 从键盘读入测点个数 `n`（**题目保证 1 ≤ n ≤ 100**）；
2. 读入 `n` 个海底深度值（double，单位 m），存入数组 `d[100]`；
3. **只允许用指针遍历数组**（循环体内用 `*p` 访问元素，不得用 `d[i]` 下标形式参与计算）；
4. 求出并输出：深度总和、平均深度、最大深度、最小深度，各保留 2 位小数。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后一行 `n` 个实数。

**输出**：四行，依次为：

```
总和 = xx.xx m
平均 = xx.xx m
最大 = xx.xx m
最小 = xx.xx m
```

## 四、样例

**样例 1**

输入：
```
5
12.0 13.5 11.0 14.0 12.5
```
输出：
```
总和 = 63.00 m
平均 = 12.60 m
最大 = 14.00 m
最小 = 11.00 m
```

**样例 2**

输入：
```
1
9.8
```
输出：
```
总和 = 9.80 m
平均 = 9.80 m
最大 = 9.80 m
最小 = 9.80 m
```

## 五、提示

- 数组名 `d` 本身就是首元素地址，所以 `p = d;` 就让指针指向了第一个元素；
- 指针加 1 不是"地址加 1 个字节"，而是**跳到下一个元素**：`p + 1` 指向 `d[1]`，`p + 2` 指向 `d[2]`……这正是指针能逐个遍历元素的原因；
- 两种常见遍历写法（任选其一即可）：
  ```c
  /* 写法 A：指针当游标，每轮前移 */
  for (p = d; p < d + n; p++) {
      s += *p;
      if (*p > mx) mx = *p;
  }

  /* 写法 B：p 固定指向首元素，用 p+i 偏移 */
  for (i = 0; i < n; i++) {
      s += *(p + i);
  }
  ```
- 最大/最小值初始化：先令 `mx = mn = *d;`（即第一个元素），再从第二个元素开始比较；
- 想一想：`d + n` 是什么？它是"最后一个元素再往后一个位置"的地址，循环条件 `p < d + n` 正好保证不越界。

**完成本练习后你将具备的能力**：用指针算术遍历一维数组、区分"指针的值"与"指针指向的值"（`p` 与 `*p`）——这些是实验 C6 中"深度时序读入与统计模块"的地基。
