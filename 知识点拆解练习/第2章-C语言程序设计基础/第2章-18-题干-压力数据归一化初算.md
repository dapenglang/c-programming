# 第 2 章 练习 18　压力数据归一化初算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C9《基于二维网格统计的冰压力场分析与可视化系统》（水声学院）——本练习是该实验中"压力数据归一化预处理"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

冰压力场实验采集到的压力值范围可能相差很大：有的工况最大值只有几 kPa，有的工况能到几百 kPa。若直接把原始压力画成灰度图，不同工况之间就没法比较。为此，数据分析第一步往往是把压力**归一化**——把所有数值等比压缩到统一的 $[0, 1]$ 区间，使最小值变成 0、最大值变成 1，中间的值按位置分配。

综合实验 C9 在把压力场转成可视化图之前，就要对每个测点做这一步归一化；综合实验 B1 的图像二值化也依赖同样的 min-max 归一化。本练习把"由最小值、最大值和当前测点值算归一化结果"这一最小步骤抽出来实现。

## 二、任务要求

编写一个完整程序 `pressure_normalize.c`：

1. 从键盘读入三个实数，依次为压力**最小值** $x_{min}$、**最大值** $x_{max}$ 和**当前测点值** $x$（单位 kPa，均用 `double`）；
2. 题目保证 $x_{max} > x_{min}$ 且 $x_{min} \le x \le x_{max}$，因此不需要判断分支；
3. 用 min-max 归一化公式计算归一化值 $x'$；
4. 按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，三个实数，依次为 $x_{min}$、$x_{max}$、$x$（kPa），用空格分隔。

**输出**：一行，按格式 `x_norm = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
0 200 150
```
输出：
```
x_norm = 0.7500
```

**样例 2**

输入：
```
50 250 175
```
输出：
```
x_norm = 0.6250
```

## 五、提示

min-max 归一化公式为：

$$
x' = \dfrac{x - x_{min}}{x_{max} - x_{min}}
$$

它的含义是"当前值在整个数据范围内的相对位置"：最小值处得 0，最大值处得 1，中点处得 0.5。运算时分子分母务必都是实数，避免整数除法把结果算成 0。

**完成本练习后你将具备的能力**：理解并实现 min-max 归一化、用实数除法处理数据缩放、把三个输入组合成一个比值型结果输出——这是压力场可视化与图像处理实验中"数据预处理"的基本功。
