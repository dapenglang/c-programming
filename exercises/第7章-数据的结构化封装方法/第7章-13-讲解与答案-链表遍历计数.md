## 二、预备知识：链表遍历与"边走边统计"（零基础阅读）

### 1. 为什么不能像数组那样用下标

用数组时，`a[i]` 能靠"首地址 + 偏移量"直接跳到第 `i` 个元素。可链表的节点是**分散在内存各处**的，彼此之间只有一根 `next` 指针相连，没有"第几个"的编号。想知道第 5 个节点在哪，只能从 `head` 出发，一个接一个地顺着 `next` 走过去。**这种"顺着链子一步步走、每步处理当前节点"的动作，就叫遍历。** 它必须从链头开始、不能跳、也不回头。

### 2. 遍历的骨架：一个会移动的游标

遍历只用**一个指针变量 `p`** 当"游标"，让它先站在 `head`，每走一步就 `p = p->next` 挪到下一个节点。走的过程画出来是这样：

```
head ──► [101|10.0|●] ──► [102|25.0|●] ──► [103|8.0|●] ──► [104|40.0|NULL]
            ▲  第1步处理它，然后 p=p->next
                        ▲  第2步
                                    ▲  第3步
                                                ▲  第4步
  下一步 p 变成 NULL，循环结束
```

写成代码就是固定三要素：

```c
p = head;                    /* 起点：站在链头 */
while (p != NULL) {          /* 条件：只要 p 不是空，就说明还有节点 */
    /* 在这里处理 p 指向的节点 */
    p = p->next;             /* 推进：挪到下一个 */
}
```

**"起点、条件、推进"缺一不可**。少了推进 `p = p->next`，`p` 永远不动，程序会无限循环；条件写成 `p->next != NULL`，则会漏掉最后一个节点。

### 3. "边走边统计"：累加器 + 计数器

统计问题的通用套路是准备几个**就地累加的变量**，在遍历中对每个节点更新它们：

- **累加器** `sum`：初始 `0.0`，每遇到一个节点就 `sum += p->load;`，走完一遍 `sum` 就是总和；
- **计数器** `count`：初始 `0`，每遇到一个节点就 `count++;`，走完就是节点总数；
- **条件计数器** `over`：初始 `0`，只有满足条件时才加一：

  ```c
  if (p->load >= limit) over++;
  ```

平均值不是"每步都算"，而是**遍历完再算一次**：`mean = sum / count;`。因为除法要用到最终的总和与个数，只有走完整条链它们才准确。

### 4. 一个必须守住的边界：空链不能求平均

如果链表是空的（`n = 0`），`count` 就是 `0`，此时 `sum / count` 就是"除以零"，结果无意义甚至导致程序异常。所以求平均前必须先判断：

```c
if (count > 0) mean = sum / count;
else           mean = 0.0;      /* 或直接跳过除法 */
```

**"先判空、再做除法"**是所有平均值计算的纪律。链表题里的 `malloc` 检查、程序结束时的 `free` 与前面练习一致：申请后 `if (p == NULL)`，结束前逐个归还。

## 三、解题思路

1. **建链**：用练习 12 的尾插法，把 `n` 条记录建成一条链表；
2. **初始化统计量**：`count = 0; sum = 0.0; over = 0;`；
3. **一次遍历完成三件事**：计数、累加、超阈判断，每步都要 `p = p->next`；
4. **算平均并处理空链**：`count > 0` 才做除法；
5. **输出**：`sum`、`mean` 用 `%.2f`；
6. **释放链表**。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

struct IceLoad {
    int    id;
    double load;
    struct IceLoad *next;
};

int main(void)
{
    int n, i, id, count, over;
    double load, limit, sum, mean;
    struct IceLoad *head = NULL, *tail = NULL, *p;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {           /* 尾插建链 */
        scanf("%d %lf", &id, &load);
        p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
        if (p == NULL) { printf("malloc failed\n"); return 1; }
        p->id = id; p->load = load; p->next = NULL;
        if (head == NULL) head = tail = p;
        else { tail->next = p; tail = p; }
    }
    scanf("%lf", &limit);               /* 读入阈值 */

    count = 0; sum = 0.0; over = 0;     /* 初始化累加器与计数器 */
    p = head;
    while (p != NULL) {                 /* 一次遍历完成全部统计 */
        count++;
        sum += p->load;
        if (p->load >= limit) over++;
        p = p->next;                    /* 推进游标 */
    }

    if (count > 0) mean = sum / count;  /* 空链不求平均 */
    else           mean = 0.0;

    printf("count = %d\n", count);
    printf("sum = %.2f\n", sum);
    printf("mean = %.2f\n", mean);
    printf("over = %d\n", over);

    while (head != NULL) { p = head; head = head->next; free(p); }
    return 0;
}
```

## 五、运行验证

对样例 1 的链表 `10 → 25 → 8 → 40`，阈值 `limit = 20`，遍历过程逐步累加：

| 节点 | 处理前 sum | 处理后 sum | 是否 ≥ 20 |
|---|---|---|---|
| 101 / 10.0 | 0.00 | 10.00 | 否 |
| 102 / 25.0 | 10.00 | 35.00 | 是（over=1） |
| 103 / 8.0 | 35.00 | 43.00 | 否 |
| 104 / 40.0 | 43.00 | 83.00 | 是（over=2） |

遍历结束：`count = 4`、`sum = 83.00`、`mean = 83.00 / 4 = 20.75`、`over = 2`，输出

```
count = 4
sum = 83.00
mean = 20.75
over = 2
```

与样例 1 一致。样例 2 的链表为 `5 → 5 → 6`，阈值 `6`：总和 `16.00`、`mean = 16/3 = 5.33`（保留 2 位）、只有 `6` 满足 $\ge 6$ 故 `over = 1`，输出与样例 2 一致。当 `n = 0` 时，遍历一次也不执行，输出 `count = 0`、`sum = 0.00`、`mean = 0.00`、`over = 0`。

## 六、常见错误与讲解

**错误 1：遍历时漏写 `p = p->next`，死循环**

```c
while (p != NULL) {
    count++;
    sum += p->load;      /* 错：p 永不改变，无限循环 */
}
```
"起点、条件、推进"三要素里，最容易漏的就是推进。写遍历时先把 `p = p->next;` 敲上去，再往循环体里填统计语句。

**错误 2：空链表时除以零**

```c
mean = sum / count;      /* 错：count 可能为 0 */
```
`n = 0` 时 `count = 0`，整数除零会出错。应先判断 `if (count > 0)`。

**错误 3：阈值条件写成 `>`**

```c
if (p->load > limit) over++;    /* 错：漏掉"等于" */
```
题目要求"不小于"，即 $load \ge limit$，等于阈值的节点也算超阈，应写 `>=`。

**错误 4：求和变量用了整数类型**

```c
int sum = 0;             /* 错：载荷是小数，累加会截断 */
sum += p->load;          /* 25.0 + 8.0 被截成整数 */
```
载荷、总和、平均都必须是 `double`，否则小数部分被丢弃，样例 1 会算出 `sum = 83 → 但更严重的例子会明显出错`。**凡是物理上的连续量，一律 `double`。**
