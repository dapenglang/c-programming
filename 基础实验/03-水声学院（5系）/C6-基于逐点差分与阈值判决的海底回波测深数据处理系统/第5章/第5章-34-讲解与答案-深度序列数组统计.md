## 二、预备知识：数组统计的基本原理（零基础阅读）

### 1. 问题是怎么来的

测深仪每隔一段时间记下一个海底深度，得到一串数：

```
12.4  15.8  13.2  18.6  14.9  11.7  16.3  13.9
```

它们个数不定（今天测 8 个点、明天可能测 100 个点），所以不能定义 8 个零散变量，而要用**一维数组**——"一排编了号的格子"，`depth[0]` 放第 1 个、`depth[1]` 放第 2 个……用循环配合下标就能批量处理。

拿到这串数要回答三个问题：平均多深？最深多少？最浅多少？这就是**数组统计**。

### 2. 公式推导

平均深度的数学定义：

$$\bar{d} = \frac{1}{n}\sum_{i=0}^{n-1} d_i$$

最大值、最小值的定义：

$$d_{\max} = \max_{0 \le i < n} d_i, \qquad d_{\min} = \min_{0 \le i < n} d_i$$

三个量都不需要"先排序"——平均值只要**累加**，极值只要**逐个比较**。

**打擂台法**找极值：先让第 1 个数"站上擂台"（作为当前最大值），然后第 2 个数上来比，谁能打谁上；直到最后一个数比完，擂台上站的就是真正的最大值。数学上等价于：

$$m_0 = d_0,\qquad m_{k+1} = \max(m_k,\ d_{k+1})$$

### 3. 代入本例

样例 1 的 8 个深度：

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| depth[i] | 12.4 | 15.8 | 13.2 | 18.6 | 14.9 | 11.7 | 16.3 | 13.9 |

- **求和**：12.4 + 15.8 + 13.2 + 18.6 + 14.9 + 11.7 + 16.3 + 13.9 = 116.8，均值 = 116.8 ÷ 8 = **14.60**；
- **打擂台找最大**：初始 maxd = 12.4；i=1 时 15.8 > 12.4 → maxd = 15.8；i=3 时 18.6 > 15.8 → maxd = **18.60**，之后无变化；
- **打擂台找最小**：初始 mind = 12.4；i=5 时 11.7 < 12.4 → mind = **11.70**，之后无变化。

三个输出：14.60 / 18.60 / 11.70，与样例一致。

### 4. 编程翻译

| 数学动作 | C 语言翻译 |
|---|---|
| 存 n 个数 | `double depth[100];`，循环 `scanf("%lf", &depth[i]);` |
| $\sum d_i$ | `sum += depth[i];`（累加器） |
| $\max$ | `if (depth[i] > maxd) maxd = depth[i];` |
| $\bar d$ | `avg = sum / n;` |

关键初始化：`sum = 0`（累加器清零），`maxd = mind = depth[0]`（擂台上先站第 1 个数）。

> **这个套路在综合实验中反复出现**：C6 的"分段统计（均值、极值、段数）"模块、C7 的"前后半段均值比较"、C9 的"超阈值样本占比"，全都是"遍历数组 + 累加器/打擂台"。掌握本题，等于拿到了所有统计模块的公共骨架。

## 三、解题思路

1. **读入**：`scanf` 读 `n`，循环读 `n` 个深度进 `depth[]`；
2. **一遍循环统计**：`sum` 累加、`maxd`/`mind` 打擂台；
3. **计算均值**：`avg = sum / n`；
4. **输出**：三个 `printf`，均用 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double depth[100];      /* 一维数组：存放深度序列 */
    double sum, avg, maxd, mind;
    int n, i;

    scanf("%d", &n);                    /* 读入样本个数 */
    for (i = 0; i < n; i++) {
        scanf("%lf", &depth[i]);        /* 逐个读入深度 */
    }

    sum  = 0.0;             /* ① 累加器清零 */
    maxd = depth[0];        /* ② 极值初值 = 第一个元素 */
    mind = depth[0];

    for (i = 0; i < n; i++) {               /* 一遍循环完成三项统计 */
        sum += depth[i];                    /* 累加求和 */
        if (depth[i] > maxd) maxd = depth[i];   /* 打擂台：最大 */
        if (depth[i] < mind) mind = depth[i];   /* 打擂台：最小 */
    }

    avg = sum / n;          /* ③ 平均深度 */

    printf("平均深度 = %.2f m\n", avg);
    printf("最大深度 = %.2f m\n", maxd);
    printf("最小深度 = %.2f m\n", mind);
    return 0;
}
```

## 五、运行验证

**第一次运行**（样例 1）：

输入：
```
8
12.4 15.8 13.2 18.6 14.9 11.7 16.3 13.9
```
输出：
```
平均深度 = 14.60 m
最大深度 = 18.60 m
最小深度 = 11.70 m
```

数值核对（按 IEEE-754 double 与 `printf("%.2f")` 舍入复算）：Σd = 116.8，116.8/8 = 14.6 → `14.60`；max = 18.6 → `18.60`；min = 11.7 → `11.70`。✓

**第二次运行**（样例 2，单样本边界）：

输入：
```
1
7.25
```
输出：
```
平均深度 = 7.25 m
最大深度 = 7.25 m
最小深度 = 7.25 m
```
✓ 循环只跑一遍，`maxd = mind = depth[0]`，均值 = 7.25/1。

**反例验证**：若把 `maxd` 初值改成 `0`，输入全为正深度时结果碰巧对——但把输入换成水下高程（全负值，如 `-3.2 -5.1`）就会输出 `最大深度 = 0.00 m`，说明初值设 0 是隐患；设为 `depth[0]` 则任何输入都正确。

## 六、常见错误与讲解

**错误 1：极值初值设为 0 或 1e9 一类的"想当然"值**

```c
maxd = 0;                        /* 错：输入全负时永远打不赢擂台 */
maxd = depth[0];                 /* 对：任何输入都正确 */
```

**错误 2：循环里先 `scanf` 又重复统计，漏掉第一个元素**

```c
maxd = mind = depth[0];
for (i = 1; i < n; i++) { ... }  /* 这也对：从第 2 个开始比 */
for (i = 0; i < n; i++) { ... }  /* 这也对：自己跟自己比一次不改变结果 */
```

两种写法都对，但**不能**从 `i = 1` 开始却把初值设成 0。

**错误 3：整数除法截断均值**

```c
int sum_i = 0;                   /* 若把 sum 定义成 int，深度又是整数…… */
avg = sum_i / n;                 /* 错：整数除法，7/2 = 3，丢掉小数 */
```

本题 `sum` 是 double，`sum / n` 中 `n` 会被自动转换，结果正确；但如果统计的是整数序列（如样本计数），就要写成 `sum * 1.0 / n` 强制实数除法。

**错误 4：数组越界**

```c
scanf("%d", &n);                 /* 题目保证 n ≤ 100，若不保证则必须先检查 */
scanf("%lf", &depth[i]);         /* n > 100 时写 depth[100] 及以后 → 未定义行为 */
```

工程习惯：读入 `n` 后立即 `if (n < 1 || n > 100) return 1;` 挡住非法输入。

## 七、与综合实验的衔接

- 实验 **C6（基于逐点差分与阈值判决的海底回波测深数据处理系统）**中，"分段统计模块（M8）"就是本题的扩展：先按阈值把深度序列切成若干段，再对**每一段**调用本题的"求和 + 打擂台"骨架，得到各段均值、极值与段数；
