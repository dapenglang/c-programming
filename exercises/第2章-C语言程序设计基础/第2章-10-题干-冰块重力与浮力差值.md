# 第 2 章 练习 10　冰块重力与浮力差值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C8《基于数值积分与二分法的碎冰冰块浮力吃水计算系统》（水声学院）——本练习是该实验中"冰块受力平衡分析"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

一块冰漂在海面上，受两个主要的竖直力：向下的**重力**（由冰自身的质量产生）和向上的**浮力**（由它排开的海水产生）。按阿基米德原理：

$$
F_{\text{浮}} = \rho_{\text{水}} \, V_{\text{排}} \, g
$$

其中 $V_{\text{排}}$ 是被冰压入水下的那一部分体积。若重力大于浮力，冰会下沉；若浮力更大，冰会浮起——两者之差反映了冰块的"净受力"。

实验 C8 的"受力平衡分析"模块，就是分别算出重力和浮力，再求两者的差值，为后续用二分法求解"平衡吃水"提供判断依据。本题只完成这一步差值计算。

## 二、任务要求

编写一个完整程序 `ice_force.c`：

1. 用**常量**定义海冰密度 `RHO_ICE = 917.0`（kg/m³）、海水密度 `RHO_WATER = 1025.0`（kg/m³）、重力加速度 `GRAV = 9.8`（m/s²）；
2. 从键盘读入四个 double 数：冰块长度 `l`、宽度 `w`、厚度 `t`、**水下部分深度** `d`（单位均为**米**）。**题目保证各尺寸为正且 $d \le t$**，因此本程序不需要判断分支；
3. 分别计算重力 $G = \rho_{\text{ice}}\,l\,w\,t\,g$ 与浮力 $F = \rho_{\text{水}}\,l\,w\,d\,g$，再求差值 $G - F$；
4. 按规定格式输出重力、浮力与差值，均保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，四个实数，依次为冰块长度、宽度、厚度、水下深度（米），数之间以空格分隔。

**输出**：三行，分别按 `G = 结果 N`、`F = 结果 N`、`diff = 结果 N` 输出重力、浮力与差值（差值 = 重力 − 浮力），均保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2 1.5 0.4 0.34
```
输出：
```
G = 10783.9200 N
F = 10245.9000 N
diff = 538.0200 N
```

**样例 2**

输入：
```
1 0.8 0.5 0.45
```
输出：
```
G = 3594.6400 N
F = 3616.2000 N
diff = -21.5600 N
```

## 五、提示

重力用冰的全部质量，浮力只与**排开体积**有关：

$$
G = \rho_{\text{ice}} \, l \, w \, t \, g, \qquad F = \rho_{\text{水}} \, l \, w \, d \, g
$$

注意两者用的"高度"不同：重力用**整个厚度 $t$**，浮力用**水下深度 $d$**；差值为正说明冰受净向下的力（会沉），为负说明浮力占优（会浮）。

**完成本练习后你将具备的能力**：在同一程序里区分"总尺寸"与"部分尺寸"两种体积、按物理意义分步计算多个量、正确输出带符号的差值——这是实验 C8 浮力分析的基础。
