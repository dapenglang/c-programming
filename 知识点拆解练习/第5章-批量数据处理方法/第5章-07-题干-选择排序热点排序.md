# 第 5 章 练习 07　选择排序热点排序

**对应章节**：5 批量数据处理方法（5.5 排序与查找——选择排序；5.1 一维数组；3.3 循环结构）

**场景来源**：综合实验 C9《冰面压力场热点分析系统》（水声学院）——本练习是该实验中"热点强度降序排序"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰面压力场的数值模拟输出若干"热点"（局部压力显著高于周围的位置），每个热点有一个强度值。生成热点报告时，必须把热点**从强到弱**排列——工程师只关注最危险的几个位置。这道题用**选择排序**完成降序排列：每一轮从未排序部分**选出最大值**，把它**一次性换到**未排序部分的开头。与冒泡排序"相邻交换多次"不同，选择排序每轮最多只交换一次，思路是把"打擂台"（练习 02 刚练过）嵌进排序循环里。

## 二、任务要求

编写一个完整程序 `select_sort.c`：

1. 读入热点个数 `n`（`int`，**$2 \le n \le 100$**），再读入 $n$ 个热点强度值存入长度为 100 的 `double` 数组（单位：MPa）；
2. 用**选择排序**将数组按**降序**排列：外层共 $n-1$ 轮；第 $k$ 轮在下标 $k-1$ 至 $n-1$ 的未排序部分中**找出最大值的下标**，将其与位置 $k-1$ 的元素交换（若最大值已在位则不交换）；
3. 输出排好序的 $n$ 个数，空格分隔（行末不留多余空格），保留 **2 位小数**；
4. 每完成一轮，打印当前数组状态一行（格式见样例），观察选择排序与冒泡排序过程差异。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个实数，以空格分隔。

**输出**：先输出 $n-1$ 行过程行，每行格式为 `第 k 轮: 数值 数值 …`（数值保留 2 位小数）；最后输出一行 `排序结果: 数值 数值 …`。

## 四、样例

**样例 1**

输入：
```
5
6.4 2.1 9.3 4.8 7.6
```
输出：
```
第 1 轮: 9.30 2.10 6.40 4.80 7.60
第 2 轮: 9.30 7.60 6.40 4.80 2.10
第 3 轮: 9.30 7.60 6.40 4.80 2.10
第 4 轮: 9.30 7.60 6.40 4.80 2.10
排序结果: 9.30 7.60 6.40 4.80 2.10
```

**样例 2**

输入：
```
3
5.5 1.1 3.3
```
输出：
```
第 1 轮: 5.50 1.10 3.30
第 2 轮: 5.50 3.30 1.10
排序结果: 5.50 3.30 1.10
```

## 五、提示

1. 选择排序骨架：
$$
\text{外层：} k = 0, 1, \ldots, n-2; \qquad
\text{内层找擂主：} j = k+1, \ldots, n-1
$$
第 $k$ 轮先假设 `p = k` 是未排序部分最大值的下标，再用 `j` 扫描 `k+1` 至 `n-1`，遇更大者更新 `p`；扫描结束后若 `p != k` 则交换 `a[k]` 与 `a[p]`；
2. **先记下标、后交换**是选择排序的精髓：扫描过程中只更新记录用的下标 `p`，不动数组；
3. 降序排列找的是**最大值**；若改为升序，只需把"找最大"改成"找最小"；
4. 交换仍是标准三步，且要加 `if (p != k)` 判断——自己和自己换虽无害，但省去更清晰；
5. 每轮打印放在交换之后。

**完成本练习后你将具备的能力**：实现选择排序、理解"记录下标"与"执行交换"两个动作的分离、对比冒泡与选择两种每轮落定机制——实验 C9 热点报告的排序环节即由此实现。
