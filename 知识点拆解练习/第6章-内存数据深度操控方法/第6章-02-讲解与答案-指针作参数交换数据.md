## 二、预备知识：为什么交换必须传地址（零基础阅读）

### 1. 回忆"传值"：形参是复印件

第 4 章讲过：C 语言函数的普通参数是**传值**的——调用 `f(x)` 时，系统把 `x` 的**值**复印一份给形参，函数里操作的是复印件，改复印件绝不会影响原件。

用柜子语言说：主调函数把柜子里放的东西**抄了一份**递给函数，函数在自己屋里的新柜子中折腾，主调函数的柜子纹丝不动。所以下面这个函数永远无效：

```c
void swap_bad(double a, double b)   /* 交换的是复印件 */
{
    double t = a; a = b; b = t;     /* 白忙一场 */
}
```

### 2. 传地址：把柜号告诉函数

要真正改到主调函数的柜子，就得把**柜号**递过去。指针形参就是干这个的：

```c
void swap(double *a, double *b)     /* a、b 存放的是地址 */
{
    double t = *a;   /* 按柜号 a 取出原件，暂存 */
    *a = *b;         /* 把 b 柜里的原件搬进 a 柜 */
    *b = t;          /* 把暂存的值放进 b 柜 */
}
```

调用 `swap(&x1, &x2)` 时，形参 `a` 收到的是 `x1` 的地址、`b` 收到的是 `x2` 的地址。函数内每写一次 `*a`，都是在**按地址操作主调函数的原始柜子**。三步交换的过程（设 `x1=12.5, x2=30.2`）：

```
步骤        x1 的柜子      x2 的柜子      临时变量 t
开始        12.5           30.2           —
t = *a      12.5           30.2           12.5
*a = *b     30.2           30.2           12.5
*b = t      30.2           12.5           12.5
```

### 3. 同一个函数能交换数组元素吗

能，而且一模一样。`m[1]`、`m[3]` 也是普通的 `double` 变量，取地址 `&m[1]`、`&m[3]` 传进去即可。这正是"函数复用"的价值：**一份交换代码，变量与数组元素通吃**。实验 C6 里交换冰块坐标用 `swap(&x1, &x2)`，纠正录入顺序用 `swap(&m[i], &m[j])`，函数体一行不改。

### 4. 一个重要观察

数组名 `m` 在传参时会自动退化为首元素地址（练习 03 详讲），所以"把整个数组交给函数"本身就是靠地址实现的。指针作参数不是 C 语言的花哨技巧，而是它传递"可修改数据"的**唯一通道**。

## 三、解题思路

1. **先写对 `swap`**：形参写成 `double *a, double *b`，函数体内所有操作都带 `*`；临时变量 `t` 是普通 `double`；
2. **场景一**：读入两块冰的坐标 `x1`、`x2`，调用 `swap(&x1, &x2)` 后输出——验证指针交换对普通变量生效；
3. **场景二**：读入 5 个质量存入数组 `m`，调用 `swap(&m[1], &m[3])` 后遍历输出；
4. **输出格式**：坐标保留 1 位小数用 `%.1f`，质量序列用空格分隔、末尾换行；
5. 主函数开头按第 4 章规范给出函数声明 `void swap(double *a, double *b);`。

## 四、参考代码

```c
#include <stdio.h>

void swap(double *a, double *b);   /* 函数声明：参数是指针 */

int main(void)
{
    double x1, x2;        /* 两块冰的 x 坐标 */
    double m[5];          /* 5 块冰的质量 */
    int i;

    scanf("%lf %lf", &x1, &x2);
    for (i = 0; i < 5; i++)
        scanf("%lf", &m[i]);

    swap(&x1, &x2);       /* 场景一：交换两个普通变量 */

    printf("x1 = %.1f x2 = %.1f\n", x1, x2);

    swap(&m[1], &m[3]);   /* 场景二：交换数组下标 1、3 的元素 */

    for (i = 0; i < 5; i++)
        printf("%.1f ", m[i]);
    printf("\n");

    return 0;
}

void swap(double *a, double *b)   /* 通过地址交换原件 */
{
    double t = *a;    /* 取出 a 所指的值暂存 */
    *a = *b;          /* b 所指的值写入 a 所指的变量 */
    *b = t;           /* 暂存值写回 b 所指的变量 */
}
```

## 五、运行验证

以样例 1（坐标 `12.5 30.2`，质量 `105.0 88.5 120.3 76.8 95.4`）为例：

- 坐标交换后：`x1 = 30.2 x2 = 12.5` ✓
- 数组下标 1 的 88.5 与下标 3 的 76.8 交换，输出 `105.0 76.8 120.3 88.5 95.4` ✓

样例 2：坐标 `-8.4 4.6` 交换后输出 `x1 = 4.6 x2 = -8.4`；质量中 62.5 与 71.0 互换，输出 `50.0 71.0 48.2 62.5 66.3` ✓。数组其余元素（下标 0、2、4）不受影响，说明交换是"点对点"的。

## 六、常见错误与讲解

**错误 1：把指针形参当普通变量直接交换**

```c
void swap(double *a, double *b)
{
    double *t = a; a = b; b = t;   /* 错：只交换了两个"柜号纸条"，原件没动 */
}
```

交换 `a`、`b`（地址）只是让两条纸条换了内容，主调函数的柜子毫无变化。必须交换 `*a`、`*b`（柜子里的东西）。

**错误 2：调用时忘记取地址**

```c
swap(x1, x2);       /* 错：把值当地址传，编译报警告，运行崩溃 */
swap(&x1, &x2);     /* 对 */
```

编译器通常给出"pointer type mismatch"类警告，**看到警告必须处理**，不能带伤运行。

**错误 3：函数内漏写解引用**

```c
void swap(double *a, double *b)
{
    double t = a;      /* 错：t 存的是地址不是数值 */
    *a = *b;
    *b = t;            /* 错：把地址赋给了 double 变量 */
}
```

`double t` 应配合 `*a` 取值：`double t = *a;`。

**错误 4：交换数组元素时下标越界**

```c
swap(&m[1], &m[5]);   /* 错：m 只有 5 个元素，合法下标 0~4，&m[5] 越界 */
```

指针越界写入会破坏相邻内存，程序可能"看起来还能跑"却埋下隐患。传元素地址前先确认下标合法。

## 七、与综合实验的衔接

实验 **C6（冰区碰撞模拟）**中，冰块数据（坐标、质量、速度）需要在碰撞事件中成对交换、在录入纠错时按序号交换，全部通过本练习这样的指针版 `swap` 完成；第 5 章（练习 06、07）的排序算法内部每一步"交换相邻元素"，用的也是同一个函数。学到 6.5"指针与函数"更深入的内容后（练习 11～20 展开：函数返回地址、通过指针让函数一次带回多个结果），你会看到指针参数还承担着"函数的第二条返回通道"——本练习已经把这条通道的门打开了。
