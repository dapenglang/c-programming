# 第 6 章 练习 34　行指针遍历潮位矩阵

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：6 指针与数组（6.5 行指针与二维数组——`double (*p)[4]`）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"多测站潮位矩阵统计"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

潮位观测常按"**测站 × 时刻**"组织：3 个验潮站，每天 4 个整点各记一次潮位，就构成一张 `3×4` 的潮位矩阵。分析时通常**逐行处理**——每个测站一行，先算该站平均潮位，再挑出该站最高潮与最低潮。

二维数组的行首地址有一个专用工具：**行指针** `double (*p)[4]`。它"一步跨过一整行"，`*(p + i)` 就是第 `i` 行的首地址，`*(p + i) + j` 再定位到该行第 `j` 个元素。综合实验 C7 的逐站统计就用它遍历矩阵。本题实现这段代码。

## 二、任务要求

编写一个完整程序 `tide_mat.c`：

1. 从键盘读入站数 `m`（**题目保证 1 ≤ m ≤ 10**；列数固定为 4，代表 4 个观测时刻）；
2. 读入 `m×4` 个潮位值（double，单位 m），存入二维数组 `t[10][4]`；
3. **必须用行指针遍历**：定义 `double (*p)[4] = t;`，用 `p + i`（或 `p++`）逐行访问，行内再用普通指针或 `*(*(p+i)+j)` 访问元素；
4. 对每个测站输出一行：站号（从 1 开始）、该站平均潮位、最高潮位、最低潮位，均保留 2 位小数。

## 三、输入输出格式

**输入**：第一行一个整数 `m`；随后 `m` 行，每行 4 个实数（一个测站一行）。

**输出**：共 `m` 行，格式：

```
站1 平均=x.xx 最高=x.xx 最低=x.xx
```

## 四、样例

**样例 1**

输入：
```
3
2.0 4.0 3.0 5.0
1.0 3.0 2.0 6.0
3.0 5.0 4.0 4.0
```
输出：
```
站1 平均=3.50 最高=5.00 最低=2.00
站2 平均=3.00 最高=6.00 最低=1.00
站3 平均=4.00 最高=5.00 最低=3.00
```

**样例 2**

输入：
```
1
7.5 7.5 7.5 7.5
```
输出：
```
站1 平均=7.50 最高=7.50 最低=7.50
```

## 五、提示

- 行指针的声明**别忘括号**：`double (*p)[4];` 是"指向含 4 个 double 的整行的指针"；写漏括号变成 `double *p[4];`，那是"4 个 double 指针组成的数组"，完全两回事；
- `p + 1` 跳过**一整行**（4 个 double，共 32 字节）；`*(p + i)` 退化成第 `i` 行首元素地址（`double *`），所以 `*(*(p+i)+j)` 就是 `t[i][j]`；
- 每站统计套路与练习 32 相同：行内普通指针游走一遍，同时累加、比最大、比最小；
- 想一想：为什么行指针必须写死列数 4？因为"跳一行"要知道一行多长，编译器才能算出 `p + 1` 到底加多少字节。

**完成本练习后你将具备的能力**：用行指针访问二维数组、分清"行指针"与"元素指针"两级地址——这是实验 C7 中"多站潮位矩阵逐行处理"的地基。
