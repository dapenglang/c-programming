## 二、预备知识：不动点迭代的基本原理（零基础阅读）

### 1. 问题是怎么来的

方程 $\eta = 1 - c\,e^{-\eta}$ 里，$\eta$ 同时出现在等号两边，而且还被套在指数里，写不出 $\eta = \dots$ 的显式解。但换个角度看，它天然就是"**某个数等于对某个数做一次运算的结果**"：给一个 $\eta$，代入右端能算出一个新数；若新数恰好等于原数，这个 $\eta$ 就是解。于是我们把求解变成了"**反复代入、自我校正**"的过程。

### 2. 方法是怎么想出来的

把方程写成 $x = f(x)$ 的形式（本题 $f(x) = 1 - c\,e^{-x}$），然后任取一个初值 $x_0$，构造序列

$$
x_1 = f(x_0),\quad x_2 = f(x_1),\quad x_3 = f(x_2),\quad \dots,\quad x_{k+1} = f(x_k)
$$

这里 $x_k$ 就是解 $x^{*}$ 的第 $k$ 次近似。它收不收敛，取决于 $f$ 在根附近的"放大能力" $|f'(x^{*})|$：若 $|f'(x^{*})| < 1$，每迭代一次误差大约缩小 $|f'|$ 倍，序列收敛；若 $|f'(x^{*})| > 1$，误差被放大，序列发散。本题 $f'(x) = c\,e^{-x}$，在根附近 $c\,e^{-x^{*}} \approx c\,(1-x^{*}) < c < 1$，所以只要 $0 < c < 1$ 就能收敛。

### 3. 用本例走一遍

取样例 1：$c = 0.5$，初值 $x_0 = 1.0$。

- 第 1 次：$x_1 = 1 - 0.5\,e^{-1} = 1 - 0.5 \times 0.367879 = 0.816060$；
- 第 2 次：$x_2 = 1 - 0.5\,e^{-0.816060} = 1 - 0.5 \times 0.442163 = 0.778918$；
- 第 3 次：$x_3 = 1 - 0.5\,e^{-0.778918} = 1 - 0.229451 = 0.770549$。

可以看到相邻两次的差在迅速缩小（$0.184 \to 0.037 \to 0.008 \to \dots$），继续迭代下去，序列收敛到 $\eta = 0.768039$。

### 4. 编程时怎么用它

三个要点：**① 初值**：随便取一个不太离谱的数即可（本题取读入的 `x0`），收敛结果与初值无关；**② 循环结构**：用 `while` 而不是 `for`，因为预先不知道要迭代几次，循环条件是"还没收敛就继续"，即 `fabs(xn - x) >= 1e-6`；**③ 变量更新**：把上一轮的 `xn` 交给 `x` 后进入下一轮，注意在更新之前先判断收敛。终止判据用绝对值 `fabs()`（`<math.h>`）。

## 三、解题思路

1. **读入** `x0`、`c`；
2. **设初值** `x = x0`，进入循环；
3. **算新值**：`xn = 1.0 - c * exp(-x);`；
4. **判收敛**：若 `fabs(xn - x) < 1e-6` 则跳出循环；否则 `x = xn;` 继续；
5. **输出** `eta = %.6f`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>          /* 用到 exp() 与 fabs() */

int main(void)
{
    double x0;             /* 初始猜测值 */
    double c;              /* 吸收系数 0<c<1 */
    double x, xn;          /* 当前近似值与下一次近似值 */

    scanf("%lf %lf", &x0, &c);

    x = x0;                /* 从初值出发 */

    /* 不动点迭代：xn = 1 - c * exp(-x)，直到相邻两次足够接近 */
    while (1) {
        xn = 1.0 - c * exp(-x);     /* 代入公式得到新近似值 */
        if (fabs(xn - x) < 1e-6) {
            x = xn;                 /* 把最后结果收进 x，准备输出 */
            break;                  /* 已收敛，跳出循环 */
        }
        x = xn;                     /* 未收敛，用新值继续迭代 */
    }

    printf("eta = %.6f\n", x);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算/验证过程 | 程序输出 |
|---|---|---|
| 1.0 0.5 | $x_0=1\to0.816060\to0.778918\to\dots\to0.768039$，相邻差迅速缩小 | `eta = 0.768039` ✓ |
| 0.5 0.8 | 换一个系数，收敛到 0.528327（$0.8\times e^{-0.528327}\approx0.471673$，$1-0.471673=0.528327$） | `eta = 0.528327` ✓ |
| 1.0 0.3 | 收敛到 0.874933，$c$ 越小收敛越快（约 7 步） | `eta = 0.874933` ✓ |
| 2.0 0.5 | 初值不同但收敛到同一个根，验证"结果与初值无关" | `eta = 0.768039` ✓ |

把最后结果代回方程验证：$1 - 0.5\,e^{-0.768039} = 1 - 0.5 \times 0.463923 = 0.768038\approx 0.768039$，两端一致。

## 六、常见错误与讲解

**错误 1：用新值覆盖旧值后再比较**

```c
x = 1.0 - c * exp(-x);      /* 错：直接把 x 覆盖了，再也拿不到旧值做差 */
if ... 
```
正确做法是用**两个变量**：先用 `xn` 存新值，比较 `fabs(xn-x)`，确认未收敛后再 `x = xn`。

**错误 2：收敛判据用"函数值"而不是"两次结果的差"**

```c
while (fabs(1.0 - c*exp(-x) - x) < 1e-6)   /* 也能用，但概念上是残差，写起来易错 */
while (fabs(xn - x) < 1e-6)                 /* 本题推荐：直观反映"结果是否稳定" */
```

两者都能反映收敛，但"相邻两次结果的差"最直观，也便于和第 4.6 节牛顿法统一。

**错误 3：忘记 `#include <math.h>`**

```c
#include <stdio.h>
double y = exp(-x);    /* 错：未声明 exp，编译器报警，链接可能失败 */
```

使用 `exp()`、`fabs()` 等数学库函数，必须包含 `<math.h>`。

**错误 4：循环可能永不收敛（死循环）**

如果系数取到 $c \ge 1$，或公式抄错（如漏掉负号写成 `exp(x)`），序列会发散，`while(1)` 就成了死循环。写迭代程序时给循环加一个最大次数保护是好习惯，例如 `for (k = 1; k <= 1000; k++)`，本题因 $0<c<1$ 保证收敛，可不必加。

## 七、与综合实验的衔接

- 在实验 **D1（放射性核素活度衰变计算）**中，"由测量计数率反解修正因子"就是本练习的应用：物理模型一般都能整理成 $x = f(x)$ 的隐式形式，迭代是标准解法；
- 本题是第 4.6 节**牛顿迭代法**的直接前身：牛顿法 $x_{k+1} = x_k - \dfrac{f(x_k)}{f'(x_k)}$ 也是一种不动点迭代，只不过它的 $f$ 经过精心构造，收敛更快（二阶收敛）。先把"旧值→新值→比差值"的循环骨架写熟，第 4 章学牛顿法就只是换一条迭代公式；第 7 章的二分法求解同样沿用它。
