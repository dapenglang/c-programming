## 二、预备知识：字典序比较与字符定位的基本原理（零基础阅读）

### 1. 字典序：逐字符比 ASCII 码

两个单词比大小，规则与英语词典相同：**从第一个字符开始逐对比较**，第一对不同的字符决定胜负；若所有字符都相同且同时走到结尾，则两串相等。而"字符比大小"比的是它们的 ASCII 编码值，例如 `'e'` 是 101、`'i'` 是 105，故 `"shell"` 与 `"ship"` 的第 3 对字符（下标 2）分出胜负：`'e' < 'i'`，于是 `shell < ship`。

### 2. 双指针同步前进的循环写法

比较函数让两个指针**步调一致**地走，循环条件是"当前字符相等且还没到结尾"：

```c
while (*s1 == *s2 && *s1 != '\0')
{
    s1++;
    s2++;
}
return *s1 - *s2;
```

循环为何终止？只有两种可能：某对字符不同（已分胜负），或两串同时到达 `'\0'`（相等）。此时 `*s1 - *s2` 恰好给出三种结果：**负数**表示 `s1` 在前，**0** 表示相等，**正数**表示 `s2` 在前——一个减法同时回答三个问题，这是标准库 `strcmp` 的约定，实验中所有"按返回值符号判断"的代码都依赖它。

### 3. 字符定位：单指针扫描 + 返回地址

`my_strchr` 是练习 06 查找函数的字符版：`p` 从 `s` 出发逐格走，`*p == ch` 时把地址交出去；走到 `'\0'` 还没见着，交出 `NULL`。调用方拿到地址后：

- 想知道"第几个"：`p - s`；
- 想从那里继续操作：直接用 `p`（例如截取后缀、统计后续字符）。

返回地址比返回下标通用，这正是练习 06 讲过的道理。

### 4. 读入一个字符：`%c` 与空格的陷阱

`scanf(" %c", &ch)`（`%c` 前加一个空格）能跳过前面的空白读入单个字符；不加空格则会把上一项后面的空格读进来。这是字符输入最常踩的坑，本题输入格式"单词 单词 字符"正好训练这一点。

## 三、解题思路

1. **`my_strcmp`**：双指针同步循环 + `return *s1 - *s2;`，一个函数覆盖三种结局；
2. **`my_strchr`**：单指针扫描，命中 `return p`，走完 `return NULL`；
3. **主函数**：读 `w1`、`w2`、`ch`；按 `my_strcmp` 返回值符号输出比较结论；调 `my_strchr`，判空后输出 `p - w1` 或 `-1`；
4. **细节**：`scanf("%s %s %c", w1, w2, &ch)` 中 `%c` 前加空格。

## 四、参考代码

```c
#include <stdio.h>

int   my_strcmp(char *s1, char *s2);   /* <0: s1在前  0:相等  >0: s2在前 */
char *my_strchr(char *s, char ch);     /* 首次出现地址，无则 NULL */

int main(void)
{
    char w1[50], w2[50], ch;
    char *p;
    int r;

    scanf("%s %s %c", w1, w2, &ch);    /* %c 前的空格用于跳过空白 */

    r = my_strcmp(w1, w2);
    if (r < 0)      printf("w1 < w2\n");
    else if (r == 0) printf("w1 = w2\n");
    else            printf("w1 > w2\n");

    p = my_strchr(w1, ch);
    if (p != NULL)                     /* 铁律：先判空 */
        printf("pos = %d\n", (int)(p - w1));   /* 指针相减得下标 */
    else
        printf("pos = -1\n");

    return 0;
}

int my_strcmp(char *s1, char *s2)
{
    while (*s1 == *s2 && *s1 != '\0')  /* 相同且未到尾，同步前进 */
    {
        s1++;
        s2++;
    }
    return *s1 - *s2;    /* 负/零/正 三种结果一次给出 */
}

char *my_strchr(char *s, char ch)
{
    char *p;

    for (p = s; *p != '\0'; p++)
        if (*p == ch)    /* 首次命中即返回地址 */
            return p;

    return NULL;         /* 走到终止符仍未见 */
}
```

## 五、运行验证

样例 1（`shell` `ship` `l`）：比较至下标 2，`'e'(101) - 'i'(105) = -4 < 0`，输出 `w1 < w2`；`'l'` 在 `shell` 中首次出现于下标 2，输出 `pos = 2` ✓。

样例 2（`ice` `ice` `z`）：两串逐字符相同且同到 `'\0'`，返回 0，输出 `w1 = w2`；`z` 不在 `ice` 中，返回 `NULL`，输出 `pos = -1` ✓。

补充自测：`ship shell i` 应输出 `w1 > w2` 与 `pos = 1`（`'i'` 在下标 1）。

## 六、常见错误与讲解

**错误 1：比较循环漏掉 `*s1 != '\0'`**

```c
while (*s1 == *s2)   /* 错：'\0' == '\0' 恒成立，双指针越过字符串尾部狂奔 */
```

两串相等时 `'\0'` 与 `'\0'` 相等，条件永真，指针扫进未知内存。**必须限定"未到终止符"。**

**错误 2：只返回 0 和 1，丢失大小信息**

```c
if (*s1 > *s2) return 1; else return 0;   /* 错：分不清 s1 在前还是 s2 在前 */
return *s1 - *s2;                          /* 对：负零正三种结果 */
```

返回值符号是字典序比较的标准约定，第 5 章排序中"字符串比大小"全靠它。

**错误 3：`%c` 读到空格**

```c
scanf("%s %s%c", w1, w2, &ch);   /* 错：ch 读到的是 ' '（空格） */
scanf("%s %s %c", w1, w2, &ch);  /* 对：%c 前的空格跳过空白 */
```

症状是查找结果"永远找不到"。字符输入前先想想缓冲区里还残留着什么。

**错误 4：把 `NULL` 当下标输出**

```c
printf("pos = %d\n", (int)p);   /* 错：把地址当整数打印 */
if (p != NULL) printf("pos = %d\n", (int)(p - w1));
else printf("pos = -1\n");      /* 对：判空后用指针相减 */
```

地址与下标是两个层次的概念，相减才能完成翻译。
