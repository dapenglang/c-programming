## 二、预备知识：结构体的基本原理（零基础阅读）

### 1. 为什么需要把不同类型的数据"打包"

描写一块冰需要：编号（整数）、长、宽、厚（实数）、质量（实数）。不用结构体时的写法是平行变量：

```c
int    id1, id2, id3;                    /* 三块冰的编号 */
double len1, len2, len3;                 /* 三块冰的长 */
double wid1, wid2, wid3;                 /* 三块冰的宽 */
double thick1, thick2, thick3;           /* 三块冰的厚 */
```

三块冰就要 12 个变量，十块冰 40 个，变量与变量之间的"亲缘关系"全靠名字末尾的编号来维系。输出第 2 块冰时要同时想起 `id2、len2、wid2、thick2` 四个名字，一旦手滑写成 `len3`，**把 3 号冰的长配给了 2 号冰**，编译器毫无察觉——因为它看来只是几个毫不相干的变量。结构体的做法是：**把属于同一事物的、类型可以不同的数据，封装成一个新的整体类型**。于是"一块冰"在程序里就是一个变量 `b`，`b.length` 与 `b.thickness` 被语法绑定为同一块冰的属性，错配在结构上就不可能发生。

### 2. 结构体是"类型"，不是"变量"

`struct IceBlock { ... };` 定义的是一个**类型**，好比一张图纸：它规定了"一块冰由哪些成员组成"，但图纸本身不占存储空间、没有值。必须再写 `struct IceBlock b;` 用类型去**定义变量**，变量 `b` 才是真正占内存、可赋值可读取的实体。类比第 2 章：`double` 是类型，`double x;` 中的 `x` 才是变量。最常见的初学错误就是把类型名当变量名使用（如写 `IceBlock.mass`）。

### 3. 成员访问用点号

结构体变量像一个带隔间的箱子，每个隔间（成员）有自己的名字。访问的语法是"**变量名.成员名**"：

```c
b.id = 3;
scanf("%lf", &b.length);   /* 读成员同样要取地址 & */
b.mass = ...;
```

### 4. 结构体变量在内存里长什么样

成员按定义顺序**连续存放**在一段内存中（编译器可能为对齐插入少量空隙，不影响理解）：

```
b（struct IceBlock 类型，一整块连续内存，约 40 字节）
+------+------+-------+-----------+-------+
|  id  |length| width | thickness |  mass |
| 4字节| 8字节 | 8字节  |   8字节    | 8字节  |
+------+------+-------+-----------+-------+
  b.id  b.length ...                b.mass
```

"一块冰 = 一整块内存"，取一块冰的全部信息不需要再东拼西凑。这正是本章标题"数据的结构化封装"的含义：程序从"管理一堆散装数字"升级为"管理若干个完整对象"。

## 三、解题思路

1. **先定类型**：按题干框架定义 `struct IceBlock`，注意 `};` 末尾分号；
2. **再定变量**：`struct IceBlock b;`——先有类型、后有变量，顺序不能反；
3. **读入成员**：编号用 `%d`，三个尺寸用 `%lf`，每个成员前加 `&`；
4. **算质量**：`b.mass = b.length * b.width * b.thickness * RHO_ICE;`，密度用 `const double` 常量；
5. **输出**：printf 的参数列表就是结构体成员清单，按题目格式逐项输出，体积在输出时现算即可。

## 四、参考代码

```c
#include <stdio.h>

struct IceBlock {              /* 结构体类型定义：一块冰的完整信息 */
    int    id;                 /* 冰块编号 */
    double length;             /* 长 m */
    double width;              /* 宽 m */
    double thickness;          /* 厚 m */
    double mass;               /* 质量 kg，程序内计算 */
};                             /* 这里的分号不能漏 */

int main(void)
{
    const double RHO_ICE = 917.0;   /* 海冰密度 kg/m^3 */
    struct IceBlock b;              /* 用类型定义变量 b */

    /* 读入编号与三个尺寸，成员前都要取地址 */
    scanf("%d%lf%lf%lf", &b.id, &b.length, &b.width, &b.thickness);

    /* 质量 = 体积 x 密度 */
    b.mass = b.length * b.width * b.thickness * RHO_ICE;

    /* 输出结构体的全部字段 */
    printf("冰块 %d 号：%.2f x %.2f x %.2f m，体积 %.2f m^3，质量 %.2f kg\n",
           b.id, b.length, b.width, b.thickness,
           b.length * b.width * b.thickness, b.mass);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `3 2.0 1.5 0.6` | $V = 2.0 \times 1.5 \times 0.6 = 1.80$，$m = 1.80 \times 917 = 1650.60$ | `冰块 3 号：2.00 x 1.50 x 0.60 m，体积 1.80 m^3，质量 1650.60 kg` ✓ |
| `7 1.2 0.8 0.5` | $V = 1.2 \times 0.8 \times 0.5 = 0.48$，$m = 0.48 \times 917 = 440.16$ | `冰块 7 号：1.20 x 0.80 x 0.50 m，体积 0.48 m^3，质量 440.16 kg` ✓ |
| `9 1.0 1.0 1.0` | $V = 1.00$，$m = 917.00$（立方米冰恰为一吨冰的一半多点，密度合理） | `冰块 9 号：1.00 x 1.00 x 1.00 m，体积 1.00 m^3，质量 917.00 kg` ✓ |

三组数据与物理常识一致（海冰密度 917 kg/m³ 介于 900~920 之间），输出格式与样例完全一致。

## 六、常见错误与讲解

**错误 1：结构体定义末尾忘写分号**

```c
struct IceBlock {
    int    id;
    double length;
};              /* ← 这个分号是类型定义的一部分，漏掉会连累下一行报错 */
```

漏写分号时，报错位置往往在**下一行**（如 `int main(void)` 处），让初学者摸不着头脑。请养成习惯：写完 `}` 立刻补分号。

**错误 2：把类型名当变量名用**

```c
IceBlock.mass = 100.0;      /* 错：IceBlock 是类型，不是变量 */
struct IceBlock b;          /* 对：先定义变量 b */
b.mass = 100.0;             /* 对：通过变量访问成员 */
```

**错误 3：scanf 读成员忘取地址**

```c
scanf("%lf", b.length);     /* 错：程序运行时崩溃或读不进数据 */
scanf("%lf", &b.length);    /* 对：scanf 需要成员的地址 */
```

成员也是普通变量，scanf 的老规矩（第 2 章）在这里同样适用。

**错误 4：成员访问符号用错（提前用了箭头）**

```c
b->length = 2.0;    /* 错：-> 是"结构体指针"用的符号，b 是普通变量 */
b.length = 2.0;     /* 对：普通结构体变量用点号 */
```

记住本章 7.1~7.3 阶段的规则：**变量用点号，指针才用箭头**（箭头在第 07 题才会登场）。

## 七、与综合实验的衔接

实验 C6（冰块碰撞仿真）中，每块冰的真实数据结构远不止 5 个成员：还要有位置 $(x, y)$、速度 $(v_x, v_y)$、材质编号等十余项，但"先定义类型、再定义变量、点号访问成员"的套路与本练习完全一致。本练习完成的是仿真系统中"冰块参数建模与信息输出"环节。下一题（练习 02）把单个结构体扩展为**结构体数组**，一次管理一片冰场的所有冰块——这正是仿真主程序维护"冰块清单"的方式。
