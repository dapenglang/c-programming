## 二、预备知识：牛顿迭代法的基本原理（零基础阅读）

### 1. 问题是怎么来的

要解方程 $f(x)=0$，例如 $x^3-2x-5=0$。三次方程虽然理论上能求根，但工程里的方程往往更复杂（含指数、三角、超越函数），根本套不出公式。怎么办？——**用近似**：先猜一个差不多的数，再一步步把它"修"到足够准。

### 2. 公式是怎么推出来的

在猜测点 $x_n$ 处，用曲线 $y=f(x)$ 的**切线**近似曲线本身。切线过点 $\bigl(x_n, f(x_n)\bigr)$，斜率为 $f'(x_n)$，其方程是

$$
y - f(x_n) = f'(x_n)\,(x - x_n).
$$

让这条切线与 $x$ 轴相交（令 $y=0$），得到的横坐标记作 $x_{n+1}$：

$$
0 - f(x_n) = f'(x_n)\,(x_{n+1} - x_n)
\quad\Longrightarrow\quad
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} .
$$

这就是**牛顿迭代公式**。直观地说：切线是曲线的局部近似，切线的零点就比原来更接近真正的零点；反复作切线，交点会飞快地逼近根。

### 3. 代入本例手算

取 $f(x)=x^3-2x-5$，则 $f'(x)=3x^2-2$。从 $x_0 = 2$ 出发：

- 第 1 次：$f(2)=-1$，$f'(2)=10$，$x_1 = 2 - \dfrac{-1}{10} = 2.1$；
- 第 2 次：$f(2.1)=0.061$，$f'(2.1)=11.23$，$x_2 = 2.1 - \dfrac{0.061}{11.23} \approx 2.094568$；
- 第 3 次：$f(2.094568)\approx 1.85\times10^{-4}$，$f'(2.094568)\approx 11.1616$，$x_3 \approx 2.094568 - 0.0000165 = 2.094551$；
- 第 4 次：$f(2.094551)\approx 0$，故 $x_4 \approx x_3 = 2.094551$。

可以看到误差从 $10^{-1}$ 级迅速掉到 $10^{-6}$ 以下——牛顿法在根附近是**二次收敛**的，通常几次就够。手算得到的根 $x^\* \approx 2.094551$。

### 4. 编程实现要点

- **初值**：$x_0$ 要选在根附近，否则可能不收敛甚至发散；本题取 2 或 3 都能稳定收敛到同一个正根。
- **迭代公式**：直接翻译为 `x1 = x - f(x) / df(x);`，其中 `x` 是上一次的值、`x1` 是本次的新值。
- **终止判据**：以相邻两次之差 $|x_{n+1}-x_n|<\text{eps}$ 为准；`eps` 太小会多算、太大又不够准，本题取 $10^{-6}$。
- **顺序**：务必"先算、先打印、再判断"，这样程序至少输出一次迭代结果，也便于观察收敛过程。

## 三、解题思路

1. **写 `f` 与 `df`**：把函数值与导数值分别实现，避免在迭代里重复书写长表达式；
2. **写 `newton`**：用循环反复套用迭代公式，每轮打印 `iter k: x = ...`；
3. **设终止条件**：`if (fabs(x1 - x) < eps) break;`，否则把 `x1` 赋给 `x` 继续；
4. **`main` 调用**：读初值 `x0`，以 `1e-6` 调用 `newton`，打印最终 `root`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>   /* 提供 fabs 求绝对值 */

/* 原函数 f(x) = x^3 - 2x - 5 */
double f(double x)
{
    return x * x * x - 2.0 * x - 5.0;
}

/* 导函数 f'(x) = 3x^2 - 2 */
double df(double x)
{
    return 3.0 * x * x - 2.0;
}

/* 牛顿迭代求根：从 x0 出发，|x1-x|<eps 时停止 */
double newton(double x0, double eps)
{
    double x = x0, x1;
    int k = 0;

    do {
        x1 = x - f(x) / df(x);      /* 牛顿迭代公式 */
        k++;
        printf("iter %d: x = %.6f\n", k, x1);   /* 先输出本次结果 */
        if (fabs(x1 - x) < eps)     /* 再判断是否收敛 */
            break;
        x = x1;                     /* 未收敛则继续 */
    } while (k < 1000);             /* 安全上限，防止意外死循环 */

    return x1;
}

int main(void)
{
    double x0, root;

    scanf("%lf", &x0);
    root = newton(x0, 1e-6);
    printf("root = %.6f\n", root);
    return 0;
}
```

## 五、运行验证

以 $x_0 = 2$ 为初值，逐次迭代的手算结果与程序输出对照如下：

| 迭代 | $x_n$ | $f(x_n)$ | $f'(x_n)$ | $x_{n+1}=x_n-\frac{f}{f'}$ | 程序输出 |
|---|---|---|---|---|---|
| 1 | 2.000000 | −1.000000 | 10.000000 | 2.100000 | `iter 1: x = 2.100000` |
| 2 | 2.100000 | 0.061000 | 11.230000 | 2.094568 | `iter 2: x = 2.094568` |
| 3 | 2.094568 | 0.000185 | 11.161648 | 2.094551 | `iter 3: x = 2.094551` |
| 4 | 2.094551 | ≈0 | ≈11.161 | 2.094551 | `iter 4: x = 2.094551` |

第 4 次时 $|x_4-x_3| < 10^{-6}$，迭代停止，`root = 2.094551`。若改取 $x_0 = 3$，第一次迭代跳到 2.360000，随后 2.127197、2.095136、2.094552、2.094551，共 5 次收敛到同一根——说明只要初值在根附近，收敛结果不受初值影响。

## 六、常见错误与讲解

**错误 1：终止判据写成判断 $f(x)$ 是否等于 0**

```c
while (f(x) != 0)              /* 错：浮点数几乎不可能精确等于 0，会死循环 */
if (fabs(x1 - x) < eps) break; /* 对：用相邻两点的接近程度作为判据 */
```

浮点数比较必须用"差小于某个小量"，不能直接用 `==`。

**错误 2：先判断后迭代，导致一次都不输出**

```c
while (fabs(x1 - x) >= eps) { ... }   /* 若初值恰好收敛，可能一次都不进循环 */
```

本题要求"每完成一次迭代就输出一行"，因此采用 `do-while` 结构更贴合：**先做一次，再判断**。

**错误 3：忘记更新 `x`**

```c
do {
    x1 = x - f(x) / df(x);
    if (fabs(x1 - x) < eps) break;
} while (1);                   /* 错：没有 x = x1，x 永远不变，死循环 */
```

**错误 4：把导数写错**

```c
return 3.0 * x - 2.0;          /* 错：这是 3x-2，正确是 3x^2-2 */
return 3.0 * x * x - 2.0;      /* 对 */
```

导数一旦写错，迭代就收敛到别的值甚至发散，务必核对。

## 七、与综合实验的衔接

实验 **A8（桁架结构内力分析）**里，节点位移、几何非线性引起的平衡方程往往无法解析求解，必须以数值方法迭代求根，牛顿法因为收敛快而成为首选。本练习把"函数值—导数值—迭代器"三件套拆成独立函数，既练了模块化，又为后续更复杂的求解（例如方程里出现指数、对数）预留了复用空间：只要替换 `f` 与 `df`，`newton` 本身一行都不用改。下一题（15）将把同一套牛顿框架用到核工程的实际问题上。
