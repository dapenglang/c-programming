# 第 2 章 练习 07　γ 射线剂量率距离换算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 D5《基于数值积分的 γ 射线剂量率计算系统》（核学院）——本练习是该实验中"单能群剂量率计算模块"的最小实现。

**建议用时**：20 分钟

## 一、应用场景

辐射防护中最关心的问题是：**站在离放射源多远的地方，剂量率是多少？** 对一个点源，γ 射线向四周呈球面扩散，距离越远越稀疏，剂量率与距离的**平方成反比**——距离加倍，剂量率降到四分之一。

工程手册给出的是**比释动能/剂量率常数** $\Gamma$（常以 $\mu\mathrm{Sv\cdot cm^2/(h\cdot MBq)}$ 为单位），剂量率公式为：

$$
D = \frac{\Gamma \cdot A}{r^2}
$$

注意手册里的 $r$ 单位是**厘米**，而现场人员报的距离往往是**米**，程序必须先把米换算成厘米再代入。实验 D5 的"单能群剂量率计算模块"就是完成这一步。

## 二、任务要求

编写一个完整程序 `dose_rate.c`：

1. 用**常量**定义长度换算系数 `M_TO_CM = 100.0`（1 m = 100 cm）；
2. 从键盘读入三个 double 数：转换常数 `Gamma`（μSv·cm²/(h·MBq)）、活度 `A`（MBq）、距离 `r`（**米**），**题目保证 Gamma > 0、A > 0、r > 0**，因此本程序不需要判断分支；
3. 先把距离从米换算成厘米，再代入 $D = \dfrac{\Gamma A}{r^2}$ 计算剂量率；
4. 按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，三个实数，依次为转换常数 Gamma、活度 A（MBq）、距离 r（米），数之间以空格分隔。

**输出**：一行，按格式 `D = 结果 μSv/h` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
13000 100 1
```
输出：
```
D = 130.0000 μSv/h
```

**样例 2**

输入：
```
13000 100 2
```
输出：
```
D = 32.5000 μSv/h
```

## 五、提示

平方反比公式为

$$
D = \frac{\Gamma \cdot A}{r^2}
$$

单位换算：$r(\mathrm{cm}) = r(\mathrm{m}) \times 100$。算 $r^2$ 时写成 `rcm * rcm`，不要用 `^`（C 语言里 `^` 不是乘方）。距离加倍时剂量率应降到 $1/4$，可用它自检。

**完成本练习后你将具备的能力**：理解平方反比规律的物理含义、正确进行长度单位换算、书写含平方的公式并对结果做量纲自检——这是实验 D5 剂量率计算链的基础。
