## 二、预备知识：文件复制与"读一行、解析一行"数据流的基本原理（零基础阅读）

### 1. 为什么不能"一个字符一个字符地抄"

如果只是原样复制文件，逐字符 `fgetc`/`fputc` 就够了。但本题不是原样复制，而是**格式转换**：逗号要变成空格，数值还要按新的精度重新排版。所以正确的做法不是"抄字符"，而是"抄数据"——把每一行先**解析**成结构化的数据（一个序号 + 一个实数），再用新格式**重组**写出去。

### 2. 数据流是怎样组织的

整个程序的数据流只有一条主线，三个角色各司其职：

```
resistance_raw.txt --fgets--> line缓冲区 --sscanf--> id, f --fprintf--> resistance.txt
     （源文件）                （一行文本）          （结构化数据）        （目标文件）
```

- **fgets** 负责"搬一行"：把源文件中的一行原文（含 `'\n'`）搬进内存里的字符数组 `line`，搬完一个游标自动移到下一行；
- **sscanf** 负责"拆一行"：从 `line` 这个字符串里按格式 `"%d,%lf"` 取出整数和实数。它与 `scanf` 的唯一区别是数据来源——`scanf` 从键盘读，`sscanf` 从你指定的字符串读；
- **fprintf** 负责"写一行"：把拆出来的数据按 `"%d %.1f\n"` 重新排版写进目标文件。

"读一行 → 拆一行 → 写一行"三步放进一个 while 循环，循环结束转换就完成了。**每次只在内存里保留一行**，无论文件有 5 行还是 500 万行，内存占用都一样小——这就是逐行处理的价值。

### 3. 两个文件指针的生命周期

程序里有 `fin` 和 `fout` 两个 `FILE*`，它们可以**同时处于打开状态**：`fin` 的生命周期从 `fopen("resistance_raw.txt","r")` 开始，到所有行读完 `fclose(fin)` 结束；`fout` 的生命周期从 `fopen("resistance.txt","w")` 开始，到最后一行写完 `fclose(fout)` 结束。两者读写互不干扰。

必须强调两点纪律：第一，**每个 fopen 之后立刻检查返回值**——文件名写错、文件不在当前目录、磁盘写保护，fopen 都会返回 NULL，拿着 NULL 指针继续读写程序就会崩溃；第二，**用完必须 fclose**—— fclose 会把缓冲区里还没落盘的数据真正写入文件，忘记 fclose 可能导致输出文件内容不完整。

## 三、解题思路

1. **开两个文件**：先开源文件（"r"），检查；再开目标文件（"w"），检查。若目标文件打开失败，别忘了先把已打开的 fin 关掉再退出；
2. **循环读行**：`while (fgets(...) != NULL)` 逐行处理，循环体内先跳过空行；
3. **解析与重组**：`sscanf(line, "%d,%lf", &id, &f)` 拆出两个字段，`fprintf(fout, "%d %.1f\n", id, f)` 按新格式写出，计数器加一；
4. **收尾**：关闭两个文件，屏幕输出转换行数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fin, *fout;        /* 源文件指针、目标文件指针 */
    char line[100];          /* 存放读入的一行原文 */
    int id;                  /* 样本序号 */
    double f;                /* 阻力值，kN */
    int count = 0;           /* 成功转换的行数 */

    /* 1. 打开源文件（只读） */
    fin = fopen("resistance_raw.txt", "r");
    if (fin == NULL) {
        printf("错误：无法打开 resistance_raw.txt\n");
        return 1;
    }

    /* 2. 打开目标文件（写，若已存在则清空） */
    fout = fopen("resistance.txt", "w");
    if (fout == NULL) {
        printf("错误：无法创建 resistance.txt\n");
        fclose(fin);         /* 别忘了关掉已打开的源文件 */
        return 1;
    }

    /* 3. 逐行"读入-解析-写出" */
    while (fgets(line, sizeof(line), fin) != NULL) {
        if (line[0] == '\n')          /* 跳过空行 */
            continue;
        sscanf(line, "%d,%lf", &id, &f);        /* 逗号分隔拆字段 */
        fprintf(fout, "%d %.1f\n", id, f);      /* 空格分隔写出去 */
        count++;
    }

    /* 4. 收尾 */
    fclose(fin);
    fclose(fout);
    printf("转换完成：共 %d 行\n", count);

    return 0;
}
```

## 五、运行验证

| resistance_raw.txt（转换前） | resistance.txt（转换后） |
|---|---|
| `1,23.5` | `1 23.5` |
| `2,25.1` | `2 25.1` |
| `3,19.8` | `3 19.8` |
| `4,27.6` | `4 27.6` |
| `5,22.4` | `5 22.4` |

若在原始文件末尾补一个空行再运行，`resistance.txt` 内容不变，屏幕输出仍为 5 行——空行被正确跳过。

**屏幕输出**：

```
转换完成：共 5 行
```

验证要点：逗号全部变成了空格；数值部分 `23.5` 等以 `%.1f` 重新写出，与原文一致；源文件内容保持不变。

## 六、常见错误与讲解

**错误 1：sscanf 格式串与数据行不匹配**

```c
sscanf(line, "%d %lf", &id, &f);   /* 错：数据是逗号分隔的，%d 后遇到 ',' 就停了，f 读不到 */
sscanf(line, "%d,%lf", &id, &f);   /* 对：格式串里的逗号与数据中的逗号对应 */
```

**错误 2：目标文件打开失败时忘记关闭源文件**

```c
fout = fopen("resistance.txt", "w");
if (fout == NULL) {
    return 1;              /* 错：fin 还开着，造成资源泄漏 */
    /* 正确做法：先 fclose(fin); 再 return 1; */
}
```

**错误 3：把 "w" 用在了源文件上**

```c
fin = fopen("resistance_raw.txt", "w");   /* 错：w 模式会立刻清空原始数据！ */
```

`"w"` 一旦打开成功，文件内容**立即被清空**。若不小心对原始数据文件用了 "w"，数据就没了。动手前先确认：读旧文件用 `"r"`，写新文件用 `"w"`，往末尾续写用 `"a"`。

**错误 4：没有跳过空行**

若末尾有空行而程序不跳过，`sscanf` 解析失败，`id` 和 `f` 保持原值，可能把一行垃圾数据写进新文件，计数也会多一。跳过空行的两个常用办法：`if (line[0] == '\n') continue;` 或检查 `sscanf` 返回值是否为 2。

## 七、与综合实验的衔接

- 实验 **C7（冰区载荷辨识与统计）**的完整流程是"原始数据导入 → 预处理 → 统计辨识 → 报表输出"，本练习实现的就是第一、二步之间的"格式转换"环节。以后你拿到任何仪器导出的 CSV 文件，都可以用本题的 `fgets + sscanf + fprintf` 三步法把它变成自己程序需要的格式；
