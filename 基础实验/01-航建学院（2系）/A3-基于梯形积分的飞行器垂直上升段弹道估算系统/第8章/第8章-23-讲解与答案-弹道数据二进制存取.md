## 二、预备知识：二进制文件的基本原理（零基础阅读）

### 1. 问题是怎么来的——文本存储的两个痛点

文本文件把数据存成**字符**。数字 39.2 在文本里是 `'3'`、`'9'`、`'.'`、`'2'` 四个字符，占 4 个字节；而在内存里它是一个 `double`，占 8 个字节。文本方式每读写一个数都要做"字符 → 数值"或"数值 → 字符"的**转换**，数据量大时很慢。

二进制文件直接**把内存里的字节原样搬进文件**，不做任何转换：

- **快**：不需要字符转换；
- **省**：结构固定、无多余字符；
- **精确**：浮点数按位保存，不存在文本转换的舍入。

代价是**人看不懂**（记事本打开是乱码），且**平台相关**（不同机器字节序可能不同）。它适合"程序写、程序读"的大批量数值数据——正是弹道序列这种场景。

### 2. 二进制文件四步曲

**打开**：模式加 `b`：

```c
FILE *fp = fopen("speed.dat", "wb");   /* 二进制只写 */
FILE *fp = fopen("speed.dat", "rb");   /* 二进制只读 */
```

**写**：`fwrite` 把内存里的一片字节搬到文件：

```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);
```

- `ptr`：要写的数据的起始地址（数组名即可）；
- `size`：单个元素占几个字节（用 `sizeof(double)` 自动取）；
- `count`：一共写几个元素；
- 返回值：实际写成功的元素个数。

**读**：`fread` 把文件里的一片字节搬回内存：

```c
size_t fread(void *ptr, size_t size, size_t count, FILE *stream);
```

参数含义与 `fwrite` 对称，返回值是**实际读到的元素个数**。

**关闭**：`fclose`。

### 3. sizeof 为什么要用

`sizeof(double)` 由编译器自动算出 `double` 的字节数（一般为 8），比手写 8 更安全、更通用。写和读时**必须用同一个 `sizeof`**，否则字节数对不上，读出来就是垃圾。

### 4. 用本例走一遍

以样例 1 为例：$v_0 = 0$、$a = 9.8$、$n = 5$。生成的速度序列为

| i | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| $v_i$ | 0.0 | 9.8 | 19.6 | 29.4 | 39.2 |

`fwrite(arr, 8, 5, fp)` 把这 5 个 `double`（共 40 字节）写进 `speed.dat`。文件大小正好 40 字节（可用 `ls -l` 查看）。

读回后统计：

- 元素个数 5；
- 最大 39.200；
- 平均 $= (0+9.8+19.6+29.4+39.2)/5 = 98/5 = 19.6$ → 19.600。

### 5. 编程时怎么用它

要点：

1. **写和读用同一类型、同一 `sizeof`**；
2. **`fread` 后检查返回值**：若小于请求数，说明文件里数据没那么多；
3. **写完后先 `fclose` 再以 `"rb"` 打开**，或写完用 `rewind`/`fseek` 回到文件头（本题用"关掉再开"最直观）。

## 三、解题思路

1. **读入 v0、a、n**；
2. **生成数组**：`arr[i] = v0 + a*i`；
3. **以 `"wb"` 打开 `speed.dat`**，`fwrite` 写入整个数组，关闭；
4. **以 `"rb"` 重新打开**，`fread` 读回 `arr2`，关闭；
5. **统计** `arr2` 的最大值与平均值，输出（含读回个数）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double v0, a;             /* 初速度 m/s、净加速度 m/s^2 */
    int n, i;
    double arr[1000];         /* 原始速度序列 */
    double arr2[1000];        /* 读回的速度序列 */
    int got;                  /* fread 实际读到的个数 */
    double vmax, sum = 0.0;

    FILE *fp;

    scanf("%lf %lf %d", &v0, &a, &n);

    /* 生成速度序列 v_i = v0 + a*i */
    for (i = 0; i < n; i++) {
        arr[i] = v0 + a * i;
    }

    /* 写入二进制文件 */
    fp = fopen("speed.dat", "wb");
    if (fp == NULL) {
        printf("open write failed\n");
        return 1;
    }
    fwrite(arr, sizeof(double), n, fp);   /* 整块写出 n 个 double */
    fclose(fp);

    /* 以二进制方式读回 */
    fp = fopen("speed.dat", "rb");
    if (fp == NULL) {
        printf("open read failed\n");
        return 1;
    }
    got = fread(arr2, sizeof(double), n, fp);   /* got 为实际读到的个数 */
    fclose(fp);

    /* 统计 */
    vmax = arr2[0];
    for (i = 0; i < got; i++) {
        if (arr2[i] > vmax) vmax = arr2[i];
        sum += arr2[i];
    }

    printf("count=%d\n", got);
    printf("vmax=%.3f\n", vmax);
    printf("vavg=%.3f\n", sum / got);

    return 0;
}
```

## 五、运行验证

**样例 1**：输入 `0.0 9.8 5`。

| 项目 | 手算 | 程序输出 |
|---|---|---|
| 序列 | 0, 9.8, 19.6, 29.4, 39.2 | —— |
| 写文件 | 40 字节（5×8） | —— |
| 读回个数 | 5 | `count=5` ✓ |
| 最大 | 39.2 | `vmax=39.200` ✓ |
| 平均 | 98/5 = 19.6 | `vavg=19.600` ✓ |

**样例 2**：输入 `100.0 20.0 4`。序列 100、120、140、160，$n=4$，最大 160、平均 130 → `count=4`、`vmax=160.000`、`vavg=130.000`。

文件变化：运行前无 `speed.dat`；运行后生成 `speed.dat`（本样例为 32 字节）。用文本编辑器打开会显示乱码，这正是二进制文件的特点。

## 六、常见错误与讲解

**错误 1：打开模式忘了加 `b`**

```c
fp = fopen("speed.dat", "w");     /* 在某些平台上写二进制会出问题 */
fp = fopen("speed.dat", "wb");    /* 对：二进制写 */
```

跨平台时，文本模式可能对换行符做转换，破坏二进制数据。二进制读写一律用 `"wb"`/`"rb"`。

**错误 2：写读的 `sizeof` 不一致**

```c
fwrite(arr, sizeof(double), n, fp);
fread(arr2, sizeof(float), n, fp);    /* 错：类型/大小不一致，读出来是垃圾 */
```

写读必须用**同一类型、同一 `sizeof`**。

**错误 3：写完立刻用同一文件指针读**

```c
fwrite(arr, sizeof(double), n, fp);
fread(arr2, sizeof(double), n, fp);   /* 错：文件位置在末尾，读不到数据 */
```

要么 `fclose` 后重新 `fopen`（本题做法），要么用 `rewind(fp)` 把位置移回开头。

**错误 4：不检查 `fopen`/`fread` 返回值**

```c
if (fp == NULL) { ... }               /* 判断打开成功 */
if (got < n) printf("read short\n");  /* 判断读够了 */
```

工程代码必须检查，避免对空指针操作或读取不完整数据。
