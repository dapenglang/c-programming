## 二、预备知识：把大问题拆成"多趟遍历"的数据流水线（零基础阅读）

### 1. 为什么不能一趟把所有事做完

面对"读入一张网格，出一份报表"这样的大任务，初学者常想"能不能边读边把所有结果都算出来"。答案是：**有些能、有些不能**。例如"总和、最大值、超限个数"确实能在读入的同时算出来（每个元素一读到就更新这几个量）；但"**各行均值的降序排名**"做不到——因为要比较第 3 行的均值和第 1 行的均值，必须**等两行都读完、都算出均值**才知道谁大谁小。

因此正确的思路是：**先按依赖关系把大任务拆成若干阶段，每个阶段做一件事、走一趟数据**。这就是"数据流水线"的思想，也是工程程序的基本组织方式。

### 2. 本报表的五个阶段

- **阶段 1 读入**：把整张网格装进二维数组 `p`；
- **阶段 2 全局统计**：走一趟网格，算出和、最大、最小、超限个数（这四个互相独立，可以合并在同一趟里）；
- **阶段 3 分行均值**：走一趟网格，按行聚合，得到一维数组 `rowMean`；
- **阶段 4 排序**：对 `rowMean` 做降序冒泡排序；
- **阶段 5 输出**：把所有结果按报表格式打印。

每个阶段只依赖前一阶段的产物，边界清晰、互不干扰——**这正是模块化思想（第 4 章）在数据处理上的体现**。

### 3. 为什么阶段 2 能"一趟多算"

阶段 2 里的四个量（和、最大、最小、超限数）都满足"每读一个元素就能立刻更新"的性质，于是可以写在同一个双重循环体内：累加 `sum += p[i][j];`、更新 `if (p[i][j] > mx) mx = p[i][j];`、`if (p[i][j] < mn) mn = p[i][j];`、超限计数 `if (p[i][j] >= THRESH) over++;`。一次访问、四个结果，是所有"可增量计算"的统计量的通用写法。

### 4. 分行均值：外层行、内层列

求第 $i$ 行均值，需要固定行号、走遍该行所有列：外层 `for (i...)`，进入后令 `s = 0.0`，内层 `for (j...) s += p[i][j];`，最后 `rowMean[i] = s / n;`。注意每行的累加器 `s` 要在进入内层循环前**重新置 0**，否则会把上一行的和带进来。

### 5. 降序排序：冒泡法的"小数下沉"

冒泡排序的思想是"相邻两个比大小，不合顺序就交换"。要得到**降序**，规则是"**前一个比后一个小，就交换**"：`for (i...) for (j...) if (rowMean[j] < rowMean[j+1]) { 交换 }`。交换借助临时变量 `t` 三步走完（练习 06 已练过）；若把比较符号改成 `>`，就得到升序。

## 三、解题思路

1. **读入**：`double p[20][20]`，双重循环读入 $m \times n$ 个值；
2. **全局统计**：最值初值取 `p[0][0]`，一趟双重遍历同时累加和、更新最值、数超限点（阈值用 `#define THRESH 100.0`）；
3. **分行均值**：外层 `i`、内层 `j`，每行和除以 `n` 存入 `double rowMean[20]`；
4. **降序排序**：对 `rowMean`（长度 `m`）做冒泡排序，前小后大则交换；
5. **报表输出**：依次打印 `sum`、`mean`（= `sum/(m*n)`）、`max`、`min`、超限计数，最后一行打印排序后的行均值。

## 四、参考代码

```c
#include <stdio.h>
#define ROWS 20
#define COLS 20
#define THRESH 100.0            /* 超限阈值（kPa） */

int main(void)
{
    double p[ROWS][COLS];       /* 压力网格 */
    double rm[ROWS];            /* 每行均值 */
    int m, n, i, j;
    double sum = 0.0, mx, mn;
    int over = 0;               /* 超限测点个数 */

    scanf("%d %d", &m, &n);
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            scanf("%lf", &p[i][j]);

    /* 阶段 2：一趟统计和、最值、超限数 */
    mx = mn = p[0][0];
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++) {
            sum += p[i][j];
            if (p[i][j] > mx) mx = p[i][j];
            if (p[i][j] < mn) mn = p[i][j];
            if (p[i][j] >= THRESH) over++;
        }

    /* 阶段 3：求每行均值 */
    for (i = 0; i < m; i++) {
        double s = 0.0;
        for (j = 0; j < n; j++)
            s += p[i][j];
        rm[i] = s / n;
    }

    /* 阶段 4：冒泡排序，行均值降序 */
    for (i = 0; i < m - 1; i++)
        for (j = 0; j < m - 1 - i; j++)
            if (rm[j] < rm[j + 1]) {          /* 小的往后沉 */
                double t = rm[j];
                rm[j] = rm[j + 1];
                rm[j + 1] = t;
            }

    /* 阶段 5：报表输出 */
    printf("sum = %.2f\n", sum);
    printf("mean = %.2f\n", sum / (m * n));
    printf("max = %.2f\n", mx);
    printf("min = %.2f\n", mn);
    printf("超阈值(>=%.2f) = %d\n", THRESH, over);
    printf("行均值降序:");
    for (i = 0; i < m; i++)
        printf(" %.2f", rm[i]);
    printf("\n");

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：每行累加器忘记清零**

```c
double s;                       /* 错：初值随机 */
for (i = 0; i < m; i++) {
    double s = 0.0;             /* 对：每行都从 0 开始 */
    for (j = 0; j < n; j++) s += p[i][j];
    rm[i] = s / n;
}
```

若把 `s` 声明在循环外且不重置，第 2 行的均值会把第 1 行的和也算进来，越往后的行错得越离谱。

**错误 2：排序的内层上界写错**

```c
for (j = 0; j < m; j++)          /* 错：j+1 会取到 rm[m]，越界 */
for (j = 0; j < m - 1 - i; j++)  /* 对：每趟可少比一个 */
```

比较 `rm[j]` 与 `rm[j+1]` 时，`j` 最大只能到 `m-2`，越界会读写到非法内存。

**错误 3：交换时漏掉临时变量的某一"步"**

```c
rm[j] = rm[j + 1];
rm[j + 1] = rm[j];      /* 错：第一步已把 rm[j] 覆盖，结果两个值相同 */
double t = rm[j]; rm[j] = rm[j+1]; rm[j+1] = t;  /* 对：三步交换 */
```

**错误 4：平均值写成整除 / 用 int 接收**

```c
printf("mean = %d\n", sum / (m * n));   /* 错：%d 打印 double，且丢小数 */
printf("mean = %.2f\n", sum / (m * n)); /* 对：实数输出、保留 2 位 */
```

`m * n` 是整数，但 `sum` 是 `double`，除法结果是实数，关键在输出格式用 `%.2f`。
