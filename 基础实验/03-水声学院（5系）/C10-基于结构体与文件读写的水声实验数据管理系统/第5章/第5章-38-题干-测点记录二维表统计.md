# 第 5 章 练习 38　测点记录二维表统计

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：5 二维数组（5.3 二维数组的定义与引用、5.3 二维数组的遍历——按行/按列、5.5 数组统计——行均值/列均值）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"统计汇总（各测站均值、极值）环节"的最小实现。

**建议用时**：45 分钟

## 一、应用场景

一次水声实验在 **3 个测站**上各连续观测 **4 个时刻**的声速，把数据整理成一张**二维表**：每行是一个测站、每列是一个时刻。要回答"**哪个测站平均声速最高？哪个时刻整体声速最高？**"就需要对这张表做**按行统计**（各测站均值）和**按列统计**（各时刻均值）。

综合实验 C10 用结构体数组管理测点记录，其"统计汇总模块（M8）"的本质就是对"测站 × 时刻"二维数据做行列统计。本题用**二维数组**实现它的最小版本：读入一张声速表，输出每个测站的行均值与每个时刻的列均值。

## 二、任务要求

编写一个完整程序 `grid_stat.c`：

1. 从键盘读入测站数 `m` 与时刻数 `n`（**题目保证 1 ≤ m ≤ 10、1 ≤ n ≤ 10**）；
2. 读入 `m×n` 个声速值（double，单位 m/s），按行存入二维数组 `v[10][10]`（`v[i][j]` 表示第 `i` 个测站第 `j` 个时刻的声速）；
3. **按行统计**：对每个测站计算 4 个时刻的均值，输出 `测站 i 平均声速 = xx.xx m/s`；
4. **按列统计**：对每个时刻计算 m 个测站的均值，输出 `时刻 j 平均声速 = xx.xx m/s`；
5. 找出**行均值最大的测站**（若并列取编号最小的），输出 `声速最高测站：第 i 号`；
6. 所有数值保留 2 位小数；测站、时刻编号从 1 开始。

## 三、输入输出格式

**输入**：第一行两个整数 m、n；随后 m 行，每行 n 个实数。

**输出**：

```
各测站平均声速：
测站 1 平均声速 = xx.xx m/s
...
各时刻平均声速：
时刻 1 平均声速 = xx.xx m/s
...
声速最高测站：第 i 号
```

## 五、提示

- 二维数组两层循环的**行列顺序**决定统计方向：
  ```c
  for (i = 0; i < m; i++) {           /* 按行：外层是行（测站） */
      rowsum = 0;
      for (j = 0; j < n; j++) {
          rowsum += v[i][j];          /* 行不变、列变 → 累加一行 */
      }
      printf("测站 %d 平均声速 = %.2f m/s\n", i + 1, rowsum / n);
  }
  ```
  按列统计时**把两层循环对调**：外层 `j`（时刻）、内层 `i`（测站），累加 `v[i][j]`；
- 找"行均值最大的测站"不必另存均值数组：在按行统计的循环里顺手打擂台——比较 `rowsum / n` 与当前最大值即可；也可以先把均值存进一维数组 `avg[10]` 再统一找，两种写法都对；
- 打擂台初值用**第 1 行的均值**（或第一个循环里算出的值），不要想当然设 0——本题声速虽都是正数，但养成"初值取真实数据"的习惯；
- 想一想：按列统计时内层循环变量是谁、累加表达式里行标和列标各是谁？如果把 `v[i][j]` 误写成 `v[j][i]`，行列数不等时会发生什么？

**完成本练习后你将具备的能力**：用二维数组按行/按列两个方向统计、"循环方向对调"技巧——这是实验 C10 中"统计汇总（M8）"的地基，也是处理一切"表格型数据"的基本功。
