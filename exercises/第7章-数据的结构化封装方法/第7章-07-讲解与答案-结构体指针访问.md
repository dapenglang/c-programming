## 二、预备知识：结构体指针的基本原理（零基础阅读）

### 1. 从"副本"到"本体"

练习 05 讲过：结构体作函数参数是值传递，函数拿到的是**副本**，改副本动不了原件。可仿真程序偏偏要改原件——每个时间步都必须把冰块的真实位置推进到新值，改副本等于白算。第 6 章的指针给了出路：**传地址**。地址标识变量在内存中的位置，拿着地址就能找到变量本体、原地读写。

### 2. 结构体指针长什么样

```c
struct IceBlock b;              /* 一块冰，一整块内存 */
struct IceBlock *p = &b;        /* p 存放 b 的首地址 */
```

指针 `p` 的值是变量 `b` 的**首地址**——因为结构体成员连续存放，知道首地址加上成员偏移就能定位每个成员。`p` 的类型是 `struct IceBlock *`，含义是"指向 struct IceBlock 类型变量的指针"。

### 3. 箭头运算符 `->`：指针访问成员的专用符号

通过指针访问成员有两种等价写法：

```c
(*p).x      /* 先解引用拿到整个结构体，再用点号取成员 */
p->x        /* 箭头写法：先取指向的结构体，再进成员——两者完全等价 */
```

`(*p).x` 的括号不可省（点号优先级高于 `*`），写起来别扭，于是 C 语言提供箭头 `->` 作为专用简写。**规则一句话：变量用点号，指针用箭头。** `p->x = p->x + p->vx * dt;` 读作"把 p 所指冰块的位置 x 按其速度推进一个时间步"。

### 4. 通过指针修改的就是本体

执行 `p->x += 3.0;` 后，main 里打印 `b.x` 会发现它真的变了——因为 `p->x` 与 `b.x` 是**同一块内存**的两个名字。对比值传递：副本改一万次，原件岿然不动；指针传递：改一次，原地生效。实验 C6 的时间步更新、C7 的批量单位换算（练习 08），凡要"改数据"的场合都走指针这条路。

## 三、解题思路

1. **定类型定变量**：五个成员的状态结构体，main 中定义 `b`；
2. **建指针**：`struct IceBlock *p = &b;`，此后按题目要求一切访问走 `p->`；
3. **输出更新前**：`printf` 用 `p->id、p->x、p->y`；
4. **推进一个时间步**：`p->x += p->vx * dt; p->y += p->vy * dt;`；
5. **输出更新后**：同一组成员，值已更新。

## 四、参考代码

```c
#include <stdio.h>

struct IceBlock {              /* 冰块运动状态 */
    int    id;                 /* 编号 */
    double x;                  /* 位置 x m */
    double y;                  /* 位置 y m */
    double vx;                 /* 速度 vx m/s */
    double vy;                 /* 速度 vy m/s */
};

int main(void)
{
    struct IceBlock b;         /* 冰块本体 */
    struct IceBlock *p = &b;   /* p 指向 b：存的是 b 的首地址 */
    double dt;                 /* 时间步长 s */

    scanf("%d%lf%lf%lf%lf%lf",
          &b.id, &b.x, &b.y, &b.vx, &b.vy, &dt);

    /* 更新前：全部通过指针 -> 访问 */
    printf("更新前：%d 号冰块位置 (%.2f, %.2f) m\n", p->id, p->x, p->y);

    /* 原地推进一个时间步：改的是 b 本体 */
    p->x += p->vx * dt;
    p->y += p->vy * dt;

    printf("更新后：%d 号冰块位置 (%.2f, %.2f) m\n", p->id, p->x, p->y);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `3 12.0 5.0 1.5 -0.8 2.0` | $x = 12.0 + 1.5 \times 2.0 = 15.00$，$y = 5.0 + (-0.8) \times 2.0 = 3.40$ | `更新前：3 号冰块位置 (12.00, 5.00) m`、`更新后：3 号冰块位置 (15.00, 3.40) m` ✓ |
| `7 20.0 10.0 -2.0 4.0 0.5` | $x = 20.0 + (-2.0) \times 0.5 = 19.00$，$y = 10.0 + 4.0 \times 0.5 = 12.00$ | `更新前：7 号冰块位置 (20.00, 10.00) m`、`更新后：7 号冰块位置 (19.00, 12.00) m` ✓ |

样例 1 中 vy 为负表示冰块向 y 负方向漂移，y 由 5.00 减小到 3.40，方向处理正确。

## 六、常见错误与讲解

**错误 1：点号与箭头用混**

```c
p.x = 1.0;        /* 错：p 是指针，没有 x 成员 */
p->x = 1.0;       /* 对：指针用箭头 */
b->x = 1.0;       /* 错：b 是变量，用点号 b.x */
```

**错误 2：解引用写法漏括号**

```c
*p.x = 1.0;       /* 错：等价于 *(p.x)，先取 p.x 就出错了 */
(*p).x = 1.0;     /* 对：括号保证先解引用 */
p->x = 1.0;       /* 推荐：没有括号烦恼 */
```

**错误 3：指针未初始化就使用**

```c
struct IceBlock *p;    /* 野指针：不知道指向哪里 */
p->x = 1.0;            /* 危险：写到未知内存，程序可能崩溃 */
struct IceBlock *p = &b;   /* 对：定义的同时指向确定变量 */
```

第 6 章的规矩在结构体指针上原样生效：指针必须先有确定的指向，才能解引用。

**错误 4：把更新公式写成覆盖**

```c
p->x = p->vx * dt;     /* 错：位置被覆盖成"这一步的位移"，丢了原位置 */
p->x += p->vx * dt;    /* 对：在原位置上累加位移 */
```

用样例 1 自查：更新后 x 必须是 15.00；若输出 3.00，就是犯了覆盖错误。

## 七、与综合实验的衔接

实验 C6 的仿真主循环形如"对清单中每块冰：`p = &b[i]; 推进位置; 检测碰撞; 更新速度`"，通过指针原地修改每块冰的状态，本练习是它的单步最小实现。到这里，7.1~7.4 的两套访问方式已经配齐：**只读计算用值传递（练习 05、06），原地修改用指针（练习 07）**。练习 08 把结构体指针传进函数，完成"批量修改"——你会看到函数形参从 `struct Sample b` 变成 `struct Sample *p` 后，函数终于获得了改写主调函数数据的能力。
