## 二、预备知识：数组与表格插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

规范/数据库给出的是一张**表**：若干"能量-截面"数据点。可中子的能量是任意的，表里不可能列全所有值。于是面临两个问题：**怎么把整张表装进程序？** 以及 **怎么由任意能量求截面？**

- 第一个问题靠**数组**：把一列数放进一个带下标的"格子序列"里；
- 第二个问题靠**线性插值**：在两个相邻数据点之间按直线比例取值。

### 2. 数组是怎么组织的

数组就是"一排编号连续的格子"：

```c
double en[6]  = {0.025, 1.0, 100.0, 1.0e4, 1.0e5, 1.0e6};  /* 能量 */
double sig[6] = {587.0, 250.0, 60.0, 20.0, 12.0, 8.0};     /* 截面 */
```

可以把它们画成两行下标对齐的格子：

```
下标 i :   0      1      2      3       4       5
en[i]  : 0.025   1.0   100.0  1e4     1e5     1e6
sig[i] : 587.0  250.0   60.0   20.0    12.0    8.0
```

**关键性质：下标从 0 开始，到"个数−1"结束（这里 0～5）**。访问第 i 个数据点就是同时读 `en[i]` 和 `sig[i]`。

### 3. 公式与"找区间"是怎么来的

线性插值公式（与第 2 章相同）：

$$
\sigma = \sigma_i + \dfrac{(\sigma_{i+1}-\sigma_i)\,(E - E_i)}{E_{i+1} - E_i}
$$

难点不在公式，而在**如何确定 `i`**——即 `E` 落在哪两个数据点之间。用循环从头扫描：只要满足 \(E_i \le E \le E_{i+1}\)，这个 `i` 就是答案：

```c
for (i = 0; i < N - 1; i++) {
    if (en[i] <= E && E <= en[i + 1]) {
        /* 找到区间，用 i 和 i+1 插值 */
        break;
    }
}
```

因为数据是**按能量递增排列**的，所以"第一次满足条件的区间"就是唯一正确的区间。

### 4. 用本例走一遍

**样例 1**：\(E = 0.5\) eV。它在 `en[0]=0.025` 与 `en[1]=1.0` 之间（\(i=0\)）。

- 比例：\((0.5-0.025)/(1.0-0.025) = 0.475/0.975 = 0.487179\)；
- 结果：\(\sigma = 587 + (250-587)\times 0.487179 = 587 - 337\times 0.487179 = 422.82\) barn。

**样例 2**：\(E = 10\) eV。它在 `en[1]=1.0` 与 `en[2]=100.0` 之间（\(i=1\)）。

- 比例：\((10-1)/(100-1) = 9/99 = 0.0909091\)；
- 结果：\(\sigma = 250 + (60-250)\times 0.0909091 = 250 - 190\times 0.0909091 = 232.73\) barn。

两个样例与程序输出一致。

> **这个思想在综合实验中反复出现**：D3 截面查值（能量-截面表）、D1 可以查"核素-半衰期表"、D4 查"材料-导热系数表"。**"数组存表 + 循环找区间 + 插值"是核数据处理的通用套路。**

## 三、解题思路

1. **定义数组**：`en[6]`、`sig[6]` 用初始化列表赋入 6 组数据，`N` 用常量 6；
2. **读入能量**：`scanf("%lf", &E);`；
3. **循环找区间**：`for (i = 0; i < N - 1; i++)`，条件 `en[i] <= E && E <= en[i+1]`，找到就记下 `i` 并 `break`；
4. **插值计算**：把 `i`、`i+1` 代入公式求 `sigma`；
5. **输出**：`printf("sigma = %.2f\n", sigma);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const int N = 6;   /* 数据点个数 */

    /* 能量-截面数据表（简化仿真数据，单位：eV、barn） */
    double en[N]  = {0.025, 1.0, 100.0, 1.0e4, 1.0e5, 1.0e6};
    double sig[N] = {587.0, 250.0, 60.0, 20.0, 12.0, 8.0};

    double e;       /* 输入能量，eV */
    double sigma;   /* 查得的截面，barn */
    int    i;

    /* 读入待查能量 */
    scanf("%lf", &e);

    /* 循环扫描，寻找 e 所在的区间 */
    sigma = sig[N - 1];          /* 默认取下端点（应对 e 恰为最大值） */
    for (i = 0; i < N - 1; i++) {
        if (en[i] <= e && e <= en[i + 1]) {
            /* 在 en[i] 与 en[i+1] 之间做线性插值 */
            sigma = sig[i] + (sig[i + 1] - sig[i]) * (e - en[i])
                             / (en[i + 1] - en[i]);
            break;               /* 找到区间就退出循环 */
        }
    }

    printf("sigma = %.2f\n", sigma);
    return 0;
}
```

## 五、运行验证

| 输入（eV） | 手算过程 | 程序输出 |
|---|---|---|
| 0.5 | 区间 [0.025,1.0]，\(587-337\times0.48718=422.82\) | `sigma = 422.82` ✓ |
| 10 | 区间 [1.0,100.0]，\(250-190\times0.09091=232.73\) | `sigma = 232.73` ✓ |
| 1000 | 区间 [100,1e4]，\(60-40\times0.090909=56.36\) | `sigma = 56.36` ✓ |
| 0.025 | 恰为下端点，取表值 587.0 | `sigma = 587.00` ✓ |
| 1000000 | 恰为上端点，取表值 8.0 | `sigma = 8.00` ✓ |

端点输入直接退回表格值，说明"找区间 + 插值"在边界处同样成立。

## 六、常见错误与讲解

**错误 1：数组下标越界**

```c
for (i = 0; i <= N; i++)        /* 错：i 会取到 N，en[N] 越界 */
for (i = 0; i < N; i++)         /* 对：i 取 0~N-1 */
for (i = 0; i < N - 1; i++)     /* 本题找区间用：要访问 en[i+1]，故上界是 N-1 */
```

**数组下标绝不能等于或超过元素个数**，否则读到的是内存里的垃圾值，程序可能崩溃或给出荒谬结果。找区间时用了 `en[i+1]`，所以循环上界必须是 `N-1`。

**错误 2：循环里忘记 `break`**

```c
for (i = 0; i < N - 1; i++) {
    if (en[i] <= e && e <= en[i + 1]) {
        sigma = ...;   /* 算完没 break，后面的区间会重复查找，最后一次会覆盖结果 */
    }
}
```

数据递增排列时，若不 `break`，循环会一直找下去，虽然条件通常不再满足，但一旦有重复边界就可能给出错误结果。**找到即停，是清晰与高效的双重要求。**

**错误 3：整数与实数混合的除法**

```c
sigma = sig[i] + (sig[i+1] - sig[i]) * (e - en[i]) / (en[i+1] - en[i]);
```

本题所有量都是 `double`，不会触发整数除法。但若把数组定义成 `int`（如误以为截面是整数），`(sig[i+1]-sig[i]) / ...` 可能退化成整数除法而丢失小数。**凡是物理量，数组元素类型也一律用 `double`。**

**错误 4：忘记处理端点**

```c
/* 若 e 恰等于表最大值，循环里找不到满足 en[i]<=e<=en[i+1] 的 i（因为 e 在最后一点） */
```

参考代码里把 `sigma` 预置为 `sig[N-1]`（最大值点），保证 `E` 落在表上界时也有正确输出。**预置一个安全的默认值，是防止"漏网情形"导致输出垃圾的常用手法。**

## 七、与综合实验的衔接

- 实验 **D3（截面查值系统）** 的真实版本有几百个数据点、覆盖 eV～MeV 全能量段，并采用**对数能量坐标**（因为截面在对数坐标下更平滑）和**拉格朗日插值**（用多个邻近点提高精度，第 8 章学习）。本练习用 6 个点、线性插值，把"数组存表 + 找区间 + 插值"的骨架先搭好；
- 学到第 6 章，你会用**指针**遍历这张表；学到第 7 章，会用**结构体**把 `(能量, 截面)` 打包成一个数据点；学到第 8 章，会从**文件**读入这张表。**同一张截面表，贯穿第 5～8 章，是核学院编程能力递进的载体。**
