# 第 6 章 练习 01　变量地址与指针初识

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用）

**场景来源**：综合实验 D1《放射性核素活度计算系统》（核学院）——本练习是该实验中"活度参数的存取与更新"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

核电站运行过程中，监测系统需要持续跟踪放射性核素的活度：初始活度 $A_0$ 存放在程序的某个变量里，每次采样后按衰减因子 $k$ 折算更新。在实验 D1 的完整系统中，这些参数并不是"直接按名字使用"的，而是由一个**参数管理模块**统一通过**内存地址**来读写——因为函数之间传递参数时，传的正是地址。本练习就是这个模块的最小雏形：定义活度变量，取出它的地址存入指针，再通过指针读取和更新活度。

## 二、任务要求

编写一个完整程序 `activity_ptr.c`：

1. 定义 `double` 型变量 `A0`（初始活度，单位 Bq）与 `k`（单次采样衰减因子），从键盘读入这两个值；
2. 定义一个指向 `double` 的指针 `p`，令其指向 `A0`；用 `%p` 分别输出 `&A0` 和 `p` 的值，验证两者相同；
3. 通过 `*p` 读出活度并按格式输出；
4. 通过 `*p` 把活度更新为原来的 $k$ 倍（即执行 `*p = *p * k`），再输出更新后的 `A0` 值。

## 三、输入输出格式

**输入**：一行，两个实数，依次为初始活度 `A0`（Bq）与衰减因子 `k`（$0 < k < 1$），以空格分隔。

**输出**：共 5 行，格式如下（地址行每次运行结果不同，以两者相等为准）：

```
A0  = 值
&A0 = 地址
p   = 地址
*p  = 值
after update: A = 值
```

## 四、样例

**样例 1**

输入：
```
200.0 0.8
```
输出：
```
A0  = 200.000000
&A0 = 0061FF1C
p   = 0061FF1C
*p  = 200.000000
after update: A = 160.000000
```

**样例 2**

输入：
```
500.0 0.5
```
输出：
```
A0  = 500.000000
&A0 = 0061FF1C
p   = 0061FF1C
*p  = 500.000000
after update: A = 250.000000
```

（说明：样例中的地址是示意值，实际地址每次运行、每台机器都可能不同，判题时以"两行地址相同"以及数值行为准。）

## 五、提示

1. 取地址运算符 `&`：`&A0` 得到变量 `A0` 在内存中的地址；解引用运算符 `*`：`*p` 表示"按指针 `p` 中存放的地址去找对应的变量"；
2. 输出地址用 `printf("%p", ...)`，不同编译器显示形式可能带 `0x` 前缀或十六进制数字，本题只要求比较两行地址是否一致；
3. `*p = *p * k` 与 `A0 = A0 * k` 效果完全相同——因为 `p` 指向的正是 `A0`；
4. 内存示意（一排带编号的柜子，`p` 是写着柜号 `&A0` 的纸条）：

```
变量名    地址        值
A0      0061FF1C    200.0
k       0061FF24    0.8
p       0061FF2C    0061FF1C   ── 指向 A0
```

**完成本练习后你将具备的能力**：理解"变量—地址—指针"三层关系、定义指针变量并让它指向已有变量、用 `*` 读写被指变量、用 `%p` 观察地址——这是实验 D1 参数管理模块以及第 6 章全部后续题目的地基。
