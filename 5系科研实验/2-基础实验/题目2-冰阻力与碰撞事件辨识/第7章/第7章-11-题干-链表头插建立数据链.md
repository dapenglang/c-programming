# 第 7 章 练习 11　链表头插建立数据链

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.5 链表——节点结构体定义、动态内存申请 `malloc`/`free`、头插法建立链表、链表遍历）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"逐条采集冰载荷测点记录、建立动态数据链"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

在冰区结构模型试验中，船体或平台表面布置了若干压力与载荷测点，试验系统会**一条接一条**地上报测点记录（测点编号 `id`、载荷值 `load`）。这些记录在程序运行之前并不知道有多少条：用固定长度的数组既要猜一个够大的上限，又会浪费空间，删改时还要整段搬移。工程上更常用的做法是**链表**——每来一条记录，就临时向系统申请一个小节点把它装进去，再用指针把节点一个个"串"起来。本练习采用最简单的**头插法**：新节点永远插在链头，因此链表顺序与输入顺序恰好相反，正适合"后到的最新记录最需要优先处理"的在线监测场景。

## 二、任务要求

编写一个完整程序 `list_headinsert.c`：

1. 定义节点结构体类型 `struct IceLoad`，成员为：`int id`（测点编号）、`double load`（载荷，kN）、`struct IceLoad *next`（指向下一个节点的指针）；
2. 读入整数 `n`（记录条数），再循环读入 `n` 行，每行两个数：编号 `id` 与载荷 `load`；
3. 对每一条记录，用 `malloc` 申请一个新节点，填入数据后**插入到链表头部**（头插），使头指针 `head` 始终指向最新的节点；
4. 建链完成后，从 `head` 出发遍历整条链表，按 `%d %.2f` 输出每个节点；遍历结束输出 `count = 节点数`；
5. 程序结束前必须用 `free` 释放所有节点；每次 `malloc` 都要检查返回值是否为 `NULL`。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`（`0 ≤ n ≤ 100`）；
- 接下来 `n` 行：每行两个数 `id` 与 `load`（`id` 为整数，`load` 为实数）。

**输出**：先按**链表顺序**（头插后即为输入的逆序）输出 `n` 行，每行格式为 `id load`（载荷保留 2 位小数）；最后一行输出 `count = 节点数`。当 `n = 0` 时，只输出 `count = 0`。

## 四、样例

**样例 1**

输入：
```
3
101 12.5
102 8.3
103 15.7
```
输出：
```
103 15.70
102 8.30
101 12.50
count = 3
```

**样例 2**

输入：
```
2
201 4.0
202 9.5
```
输出：
```
202 9.50
201 4.00
count = 2
```

## 五、提示

- 一个链表节点由两部分组成：**数据域**（`id`、`load`）和**指针域**（`next`）。`next` 保存"下一个节点在内存中的地址"，最后一个节点的 `next` 为 `NULL`（空指针），表示链到此结束；
- 空链表的表示：`struct IceLoad *head = NULL;`；
- 头插只需两行，顺序不能颠倒：
  ```c
  p->next = head;   /* 新节点先接上原来的链头 */
  head = p;         /* 再让 head 指向新节点 */
  ```
- 申请节点：`p = (struct IceLoad *)malloc(sizeof(struct IceLoad));`，其中 `sizeof(struct IceLoad)` 是"一个节点占多少字节"，`malloc` 返回这块内存的首地址；
- 遍历的固定写法：`p = head; while (p != NULL) { …; p = p->next; }`；
- 释放整条链的固定写法：先记住下一个节点，再释放当前节点：
  ```c
  while (head != NULL) { p = head; head = head->next; free(p); }
  ```

**完成本练习后你将具备的能力**：定义"数据 + 指针"的节点结构体、用 `malloc` 动态申请节点、用头插法建立一条链表、用 `while` 沿指针遍历链表、用 `free` 回收内存——这是本章 7.5 链表的入门，也是实验 C7"动态载荷数据链"模块的地基。
