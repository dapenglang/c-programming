## 二、预备知识：转置与"最值 + 坐标"定位（零基础阅读）

### 1. 什么是转置

把一个矩阵**沿主对角线翻一下**，原来的行变成列、原来的列变成行，这叫**转置（transpose）**。用公式表达就是：

$$
b[j][i] = a[i][j]
$$

读法是："原矩阵第 $i$ 行第 $j$ 列的值，写到转置矩阵的第 $j$ 行第 $i$ 列去。"例如一个 $3 \times 4$ 的矩阵（3 行 4 列），转置后变成 $4 \times 3$（4 行 3 列）。

### 2. 为什么不能"原地交换"

若有元素 `a[0][1]` 和 `a[1][0]`，看起来直接交换二者就能转置。但这样做有两个问题：

- 当 $m \ne n$ 时矩阵不是正方形，转置后形状都变了，原地根本放不下（$3 \times 4$ 的表从逻辑上要变成 $4 \times 3$）；
- 即使在方阵里交换，也要小心只交换"一半"（避免换回来），写法复杂、易错。

最稳妥、最符合初学者的做法是：**另开一张表 `b`，老老实实把 `a[i][j]` 抄到 `b[j][i]`**。代价是多用一点内存，换来的是逻辑清晰、不会错。本题就采用这种做法。

### 3. 转置后遍历的上界也变了

原矩阵遍历时外层上界是 $m$、内层是 $n$；转置矩阵的行数是 $n$、列数是 $m$，所以**输出转置矩阵时外层上界是 $n$、内层是 $m$**。这是本练习最容易混淆的地方——把 `m` 和 `n` 的位置记反，就会越界或漏输出。记忆口诀：**转置就是"行列互换"，凡是原来用 $m$ 的地方（行数）改看 $n$，凡是原来用 $n$ 的地方（列数）改看 $m$。**

### 4. 怎样同时记住"最大值"和"它在哪"

练习 02、11 找最大值时只存了数值本身。要报坐标，就必须**再多养两个变量**分别记住行号和列号。写法是"发现更大的值，就连值带坐标一起更新"：

```c
mx = a[0][0];  mi = 0;  mj = 0;          /* 初值：第一个元素及其坐标 */
for (i = 0; i < m; i++)
    for (j = 0; j < n; j++)
        if (a[i][j] > mx) {              /* 严格大于，保证取最先遇到的最大值 */
            mx = a[i][j];  mi = i;  mj = j;
        }
```

这里有三点讲究：

- **初值取第一个真实元素**再加其坐标，而不是取 0，否则网格全为负时会出错；
- 用**严格大于号 `>`**，遇到相等值不更新，自然保留"最先出现的那个"；若题意要求"最后一个"，改成 `>=` 即可；
- 遍及整张表后，`(mi, mj)` 就是最大值的位置（0 计数），显示时 `+1` 变成人习惯的 1 计数。

### 5. 输出矩阵时怎么控制行末空格

沿用练习 12 的技巧：内层循环里用"除最后一个元素外都补空格"的判断，或者干脆让每个值后跟空格但用条件控制。本题采用更清晰的写法——**不是最后一个就打印空格，是最后一个就打印换行**：

```c
printf("%.2f%c", b[i][j], j == m - 1 ? '\n' : ' ');
```

这样每一行恰好以换行结束，行末不会残留空格。

## 三、解题思路

1. **定两张表**：`double a[20][20]`（原网格）、`double b[20][20]`（转置网格）；
2. **读入原网格**：双重循环读入 `a[i][j]`；
3. **执行转置**：双重循环（行 $i$、列 $j$）执行 `b[j][i] = a[i][j]`；
4. **输出转置矩阵**：外层 `i` 走 $0 \sim n-1$、内层 `j` 走 $0 \sim m-1$，按"末列换行、其余空格"输出；
5. **定位峰值**：遍历原网格 `a`，用 `mx / mi / mj` 三变量更新，最后输出 `max = ... at (行, 列)`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double a[20][20], b[20][20];   /* a 原网格，b 转置网格 */
    int m, n, i, j;
    double mx;
    int mi = 0, mj = 0;            /* 最大值所在的行、列（0 计数） */

    scanf("%d %d", &m, &n);
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            scanf("%lf", &a[i][j]);

    /* 转置：b 的 j 行 i 列 = a 的 i 行 j 列 */
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            b[j][i] = a[i][j];

    /* 输出转置矩阵：共 n 行、每行 m 个；末列换行，其余空格 */
    for (i = 0; i < n; i++) {
        for (j = 0; j < m; j++)
            printf("%.2f%c", b[i][j], (j == m - 1) ? '\n' : ' ');
    }

    /* 在原网格中定位最大值及其坐标（取最先遇到的） */
    mx = a[0][0];
    mi = 0;
    mj = 0;
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            if (a[i][j] > mx) {
                mx = a[i][j];
                mi = i;
                mj = j;
            }

    printf("max = %.2f at (%d, %d)\n", mx, mi + 1, mj + 1);

    return 0;
}
```

## 五、运行验证

以样例 1 的 $3 \times 4$ 网格为例，转置过程如下：

| 原矩阵 (3×4) | 转置矩阵 (4×3) |
|---|---|
| 1 2 3 4 | 1 5 9 |
| 5 6 7 8 | 2 6 10 |
| 9 10 11 12 | 3 7 11 |
| | 4 8 12 |

最大值 12 位于原矩阵第 3 行第 4 列，程序输出：

```
1.00 5.00 9.00
2.00 6.00 10.00
3.00 7.00 11.00
4.00 8.00 12.00
max = 12.00 at (3, 4)
```

与题干样例 1 完全一致。样例 2 手工核对：原 $2 \times 3$ 网格转置为 $3 \times 2$，最大值 9.9 位于第 2 行第 2 列，输出 `max = 9.90 at (2, 2)`，同样吻合。

## 六、常见错误与讲解

**错误 1：转置时下标没对调**

```c
b[i][j] = a[i][j];    /* 错：只是照抄了一张表，没有转置 */
b[j][i] = a[i][j];    /* 对：行列互换 */
```

这是本练习最核心的一行，写错就前功尽弃。可记住"**原表是 `[i][j]`，目标表是 `[j][i]`**"。

**错误 2：转置矩阵输出时行列表的上界用反**

```c
for (i = 0; i < m; i++)          /* 错：转置矩阵行数是 n，不是 m */
for (i = 0; i < n; i++)          /* 对：转置矩阵有 n 行 */
```

$m$ 和 $n$ 在转置后互换角色。当 $m \ne n$ 时用反了会越界或漏打印。

**错误 3：只记值不记坐标**

```c
if (a[i][j] > mx) mx = a[i][j];              /* 错：只知道最大值，不知道在哪 */
if (a[i][j] > mx) { mx=a[i][j]; mi=i; mj=j; } /* 对：值、行、列一起更新 */
```

坐标变量要和最大值变量在同一个 `if` 里同步更新，否则会出现"值对了、坐标是旧值"的错位。

**错误 4：坐标忘记 +1**

```c
printf("at (%d, %d)\n", mi, mj);       /* 错：输出的是 0 计数，样例要求 1 计数 */
printf("at (%d, %d)\n", mi + 1, mj + 1); /* 对：显示时加 1 */
```

内部用 0 计数符合 C 语言习惯，显示给人看时一律加 1，这是贯穿本章的约定。

## 七、与综合实验的衔接

- 实验 **C9（冰面压力场热点分析系统）**中，热点图渲染前必须把逻辑行列转成绘图行列，本练习的转置算法正是这一步；而"峰值 + 坐标"定位则是系统报警功能的依据——只有知道峰值在第几行第几列，才能驱动执行机构去处理对应测点；
- "最值 + 坐标双变量同步更新"的模式会在练习 20（统计报表）中作为"求全网格极值"的基础复用；转置的思想也会在练习 19（高斯消元）里以"按列消元、按行回代"的形式再次出现——**二维数组的两种遍历方向，是贯穿本章的一条暗线**。
