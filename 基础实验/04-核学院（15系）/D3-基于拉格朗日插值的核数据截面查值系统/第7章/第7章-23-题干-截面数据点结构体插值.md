# 第 7 章 练习 23　截面数据点结构体插值

**所属综合实验**：D3（D3-基于拉格朗日插值的核数据截面查值系统）

**对应章节**：7 结构体与链表（7.1 结构体类型定义、7.2 结构体数组、7.3 结构体数组成员的访问）

**场景来源**：综合实验 D3《基于拉格朗日插值的核数据截面查值系统》（核学院）——本练习是该实验中"用结构体数组存储截面表并插值查值"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

核数据截面表（实验 D3）里每一个数据点都由"**能量 + 截面**"成对构成，天然适合用**结构体**表示。把整张表存成**结构体数组**后，每个数组元素就是一个完整的数据点，遍历、查找、插值都只需针对一个数组操作，不会像"两个平行数组"那样担心错位。

本练习把第 5 章的"数组插值"升级为"结构体数组插值"：定义 `struct SigmaPt`，用结构体数组存能量-截面表，输入任意能量，找到所在区间并做线性插值。

## 二、任务要求

编写一个完整程序 `sigma_struct.c`：

1. 定义结构体类型 `struct SigmaPt { double e; double sigma; };`（能量 eV、截面 barn）；
2. 用**结构体数组**（初始化列表）存放下表 6 组数据；
3. 从键盘读入中子能量 `E`（eV，\(0.025 \le E \le 10^6\)）；
4. 用**循环遍历结构体数组**找到 `E` 所在区间，用线性插值计算截面，输出结果保留 2 位小数。

下表为简化的仿真数据（单位：eV、barn）：

| 能量 E（eV） | 截面 σ（barn） |
|---|---|
| 0.025 | 587.0 |
| 1.0 | 250.0 |
| 100.0 | 60.0 |
| 1.0×10⁴ | 20.0 |
| 1.0×10⁵ | 12.0 |
| 1.0×10⁶ | 8.0 |

## 三、输入输出格式

**输入**：一行，一个实数，表示中子能量 `E`（eV）。

**输出**：一行，按格式 `sigma = 结果` 输出截面，保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
0.5
```
输出：
```
sigma = 422.82
```

**样例 2**

输入：
```
10
```
输出：
```
sigma = 232.73
```

## 五、提示

结构体数组的初始化列表把每个元素写成 `{能量, 截面}`：

```c
struct SigmaPt tab[6] = {
    {0.025, 587.0},
    {1.0,   250.0},
    {100.0, 60.0},
    {1.0e4, 20.0},
    {1.0e5, 12.0},
    {1.0e6, 8.0}
};
```

访问第 `i` 个数据点的成员用 `tab[i].e` 与 `tab[i].sigma`。线性插值公式与第 5 章相同：

$$
\sigma = \sigma_i + \dfrac{(\sigma_{i+1}-\sigma_i)\,(E - E_i)}{E_{i+1} - E_i}
$$

只是这里的 \(E_i\)、\(\sigma_i\) 要从结构体成员的 `tab[i].e`、`tab[i].sigma` 取出。

**完成本练习后你将具备的能力**：定义并初始化结构体数组、用"下标 + 点号"读取成员、在结构体数组上做区间查找与插值、把一个数据点当作整体管理——这些是实验 D3 中"截面数据表结构"的地基。
