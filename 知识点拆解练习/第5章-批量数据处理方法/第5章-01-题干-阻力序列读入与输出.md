# 第 5 章 练习 01　阻力序列读入与输出

**对应章节**：5 批量数据处理方法（5.1 一维数组——数组定义、下标引用；2.4 标准输入输出；3.3 循环结构）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷时间序列读入与显示"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

船模池中拖曳冰区船模时，阻力仪每隔相等的时间间隔记录一次总阻力，一次试验往往得到几十个数据。后续所有的统计与辨识工作（求均值、找峰值、算方差、画直方图）都必须**先把整批数据放进内存**，而不能读一个算一个丢一个。一维数组正是"一批同类型数据在内存中的连续存放方式"。本练习完成最基础也是最关键的第一步：把 $n$ 个阻力值读入数组，再按顺序完整输出，并统计有效数据个数。

## 二、任务要求

编写一个完整程序 `load_series.c`：

1. 从键盘读入数据个数 `n`（`int`，**题目保证 $1 \le n \le 100$**），声明一个长度为 100 的 `double` 数组 `r` 存放阻力值（单位：kN）；
2. 用循环依次读入 $n$ 个阻力值，逐个存入 `r[0]` 至 `r[n-1]`；
3. 用另一个循环按下标 $1$ 至 $n$ 的顺序输出每个阻力值，格式为 `r[序号] = 数值`，数值保留 **2 位小数**；
4. 最后一行输出 `共 n 个数据`（n 为实际个数）。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个实数，以空格分隔，表示各时刻的阻力值（kN）。

**输出**：共 $n+1$ 行，前 $n$ 行每行一个 `r[序号] = 数值`（序号从 1 开始，数值保留 2 位小数），最后一行为数据个数统计。

## 四、样例

**样例 1**

输入：
```
5
12.5 13.2 11.8 14.6 13.9
```
输出：
```
r[1] = 12.50
r[2] = 13.20
r[3] = 11.80
r[4] = 14.60
r[5] = 13.90
共 5 个数据
```

**样例 2**

输入：
```
3
20.15 9.8 16.733
```
输出：
```
r[1] = 20.15
r[2] = 9.80
r[3] = 16.73
共 3 个数据
```

## 五、提示

1. 数组的声明格式为 `double r[100];`——方括号中的 100 是**容量**，实际只用前 $n$ 个单元；
2. 第 $i$ 个读入的数据存放在 `r[i-1]` 中：数组下标从 **0** 开始，而数据的自然序号从 1 开始，两者相差 1，这是本章第一个要养成的习惯；
3. `scanf("%lf", &r[i])` 一次只读一个元素，必须放在循环体内逐个读入；
4. 读入与输出是**两次独立的遍历**，各自写一个 `for` 循环，不要在一个循环里边读边输出（虽然本题结果相同，但养成"先存储、后处理"的习惯，后面的统计题才能做对）。

**完成本练习后你将具备的能力**：定义一维数组并用下标访问元素、用循环完成数组的批量读入与遍历输出、理解"容量"与"实际个数"的区别——这些是实验 C7 中"载荷时间序列管理模块"的地基，也是本章后面所有数组题的公共起点。
