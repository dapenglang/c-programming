# 第 7 章 练习 24　链表管理施工工序

**所属综合实验**：A6（A6-基于蒙特卡洛模拟的施工工期风险估算系统）

**对应章节**：7 数据的结构化封装方法（7.7 链表的概念、7.8 链表的建立与遍历、7.9 动态内存分配）

**场景来源**：综合实验 A6《基于蒙特卡洛模拟的施工工期风险估算系统》（航建学院）——本练习是该实验中"工序清单动态管理"环节的实现。

**建议用时**：25～30 分钟

## 一、应用场景

施工进度计划里的工序数量**事先不确定**：有的工程 5 道工序，有的 20 道。用数组管理就得先定一个最大长度（万一不够用呢？）。链表正好解决这个问题——**要多少节点就动态申请多少**，插到链上即可。

A6 系统读入各工序的名称和时长，把它们串成一条链，再遍历求总工期。本练习就实现这个"链表存工序 + 遍历求和 + 释放内存"的完整流程。

## 二、任务要求

编写一个完整程序 `work_list.c`：

1. 定义链表节点结构体

```c
typedef struct Node {
    char  name[16];         /* 工序名称 */
    int   dur;              /* 工序时长，天 */
    struct Node *next;      /* 指向下一个节点的指针 */
} Node;
```

2. 读入工序个数 `n`（整数，**题目保证 1 ≤ n ≤ 100**），再读入 n 行工序（每行 `名称 时长`）；
3. 用**头插法或尾插法**把 n 个工序建成一条链表（本练习采用**尾插**，保持读入顺序）；
4. **遍历链表**输出每道工序，并累加求总工期；
5. 输出总工期后，**释放所有节点的内存**（`free`）。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 行，每行形如 `工序名 时长`。

**输出**：先输出 n 行，每行 `名称 dur=时长天`；最后一行 `T=总工期天`。

## 四、样例

**样例 1**

输入：
```
3
mould 2
tie 5
pour 3
```
输出：
```
mould dur=2
tie dur=5
pour dur=3
T=10
```

**样例 2**

输入：
```
4
cure 7
strip 2
hoist 1
grout 2
```
输出：
```
cure dur=7
strip dur=2
hoist dur=1
grout dur=2
T=12
```

## 五、提示

**为什么用链表**：数组长度固定，链表长度可变。链表的每个节点"存着数据 + 下一个节点的地址"，**靠地址串起来**，像一列首尾用绳子拴住的火车。

```
head → [mould|2|*] → [tie|5|*] → [pour|3|NULL]
```

**动态申请节点**：

```c
Node *p = (Node *)malloc(sizeof(Node));   /* 申请一个节点 */
```

需要 `#include <stdlib.h>`。

**尾插法建立链表**的要点：维护一个 `tail` 指针始终指向当前链尾，新节点接到 `tail->next` 后，再让 `tail` 后移。

**遍历**：

```c
for (p = head; p != NULL; p = p->next) {
    printf("%s\n", p->name);       /* 指针访问成员用 -> */
}
```

**释放内存**：遍历时先记住下一个节点，再 `free` 当前节点。

**完成本练习后你将具备的能力**：理解链表的节点结构（数据 + 下个地址）；用 `malloc` 动态申请节点；用 `tail` 尾插建链；用 `->` 访问节点成员；遍历链表并释放内存。
