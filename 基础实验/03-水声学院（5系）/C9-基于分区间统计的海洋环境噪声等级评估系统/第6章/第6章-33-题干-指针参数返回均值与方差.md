# 第 6 章 练习 33　指针参数返回均值与方差

**所属综合实验**：C9（C9-基于分区间统计的海洋环境噪声等级评估系统）

**对应章节**：6 指针与函数（6.4 指针作函数参数——通过指针带回多个结果）

**场景来源**：综合实验 C9《基于分区间统计的海洋环境噪声等级评估系统》（水声学院）——本练习是该实验中"噪声级均值与方差统计"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

评估海洋环境噪声，最基础的两个统计量是噪声级序列的**均值**（背景噪声水平）与**方差**（噪声起伏大小）。均值大说明海域嘈杂，方差大说明噪声忽高忽低、可能有间歇性干扰源。

一个 C 函数只能 `return` 一个值，可均值和方差是两个结果，怎么办？工程上的标准做法：**把结果的地址作为参数传进函数，函数通过 `*p` 直接往调用者的变量里写**。综合实验 C9 的统计模块就是这样封装的。本题实现这个函数并调用它。

## 二、任务要求

编写一个完整程序 `noise_stat.c`：

1. 定义函数：
   ```c
   void noise_stat(double *a, int n, double *pm, double *pv);
   ```
   功能：计算长度为 `n` 的序列 `a` 的均值与**总体方差**，分别通过指针 `pm`、`pv` 带回。方差公式为
   $$\sigma^2=\frac{1}{n}\sum_{i=0}^{n-1}(x_i-\bar{x})^2,\qquad \bar{x}=\frac{1}{n}\sum_{i=0}^{n-1}x_i$$
2. 主函数读入样本个数 `n`（**题目保证 2 ≤ n ≤ 100**）与 `n` 个噪声级（double，单位 dB）；
3. 调用 `noise_stat`，输出均值与方差，各保留 2 位小数。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后一行 `n` 个实数。

**输出**：

```
均值 = xx.xx dB
方差 = xx.xx
```

## 四、样例

**样例 1**

输入：
```
5
62.0 65.0 68.0 65.0 65.0
```
输出：
```
均值 = 65.00 dB
方差 = 3.60
```

**样例 2**

输入：
```
5
60.0 64.0 68.0 72.0 76.0
```
输出：
```
均值 = 68.00 dB
方差 = 32.00
```

## 五、提示

- 想让函数"返回"两个值，就传两个**地址**进去：调用写 `noise_stat(x, n, &mean, &var);`，函数内写 `*pm = ...; *pv = ...;`；
- 方差要两趟扫描：第一趟求均值，第二趟累加离差平方——均值没算出来之前没法算离差，一趟完不成；
- 数组参数 `double *a` 收到的就是首元素地址，函数内 `a[i]` 与 `*(a + i)` 完全等价，两种写法都可；
- 想一想：为什么不直接 `return` 两个值？因为 C 的 `return` 只能带回一个值；指针参数让函数**直接改写调用者的内存**，这正是 6.4 节"传地址"与"传值"的区别。

**完成本练习后你将具备的能力**：用指针参数让函数带回多个结果、理解传值与传地址的区别——这是实验 C9 中"统计汇总模块"的地基，也是第 7 章结构体指针传参的前置。
