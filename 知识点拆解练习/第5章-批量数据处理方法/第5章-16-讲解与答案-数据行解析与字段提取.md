## 二、预备知识：逐字符扫描中的"状态判断"（零基础阅读）

### 1. 解析的本质：走过去，边看边决定

"解析（parse）"听起来高深，做起来很朴素：**从头到尾把每个字符看一遍，根据它是"普通字符"还是"分隔符"决定下一步做什么**。本题分隔符是逗号，于是每个字符只有两种情况：是逗号，就"结束当前字段、开始下一个"；不是逗号，就把该字符存入当前字段。程序无需一次看完整行，只需在每个位置回答一个问题——"我现在读到的是分隔符吗？"，这就是"**状态判断**"。

### 2. 三个游标各管一件事

为了把这件事写清楚，需要三个互相配合的游标：

- `i`：走在**输入** `line` 上，指向当前正在看的字符 `line[i]`；
- `k`：指向**当前是第几个字段**（配合二维数组的第一维，如 `field[k]`）；
- `c`：指向**当前字段内已经写了几个字符**（配合二维数组的第二维，如 `field[k][c]`）。

把它们想成"三条尺子同时移动"：`i` 在外层从左向右匀速前进；`c` 在字段内部一格一格填字，遇到逗号就"清零重来"；`k` 每遇到一个逗号就加 1，切换到下一个字段。

### 3. 二维字符数组就是"字符串清单"

`char field[8][30];` 可以读作"**8 个字符串，每个最多 29 个字符**"。原因是：

- 第一维 `field[0]`、`field[1]`……每个都是一整条字符数组（一行文本）；
- 第二维是这条字符串内部的字符位置，`field[0][0]` 是第 1 个字段的第 1 个字符。

于是"第 $k$ 个字段的第 $c$ 个字符"写作 `field[k][c]`，正好对应我们两个游标 `k`、`c`。

### 4. 为什么要补 `'\0'`

练习 14 讲过：字符串必须有 `'\0'` 收尾，否则 `%s` 会一直往后读。本题里，字段内容是从 `line` 一格一格**抄**过来的，抄的时候并没有把 `'\0'` 一起抄（`line` 里字段之间是逗号，不是 `'\0'`）。所以每结束一个字段，都要**在它末尾手动补一个 `'\0'`**：

- 遇到逗号时：`field[k][c] = '\0';` —— 给刚读完的字段封口；
- 整行扫描完后：`field[k][c] = '\0';` —— 给**最后一个**字段封口。

最后这一次特别容易漏！因为最后一段后面没有逗号，循环遇不到"收尾信号"，只能靠循环结束后补一次。字段总数 = 逗号个数 + 1 = `k + 1`。

### 5. 边界与容量

解析前要保证容量足够：原文不超过 `line` 容量（本题 ≤ 99）；字段个数不超过 `field` 第一维（≤ 8）；每个字段长度不超过第二维减 1（≤ 29）。题目已保证"格式规范、无空字段"，故代码不必处理连续逗号、首尾逗号；真实数据里的稳健解析属于第 8 章内容。

## 三、解题思路

1. **定数组**：`char line[100];` 存原文，`char field[8][30];` 存字段；
2. **读一整行**：`scanf("%[^\n]", line);`；
3. **初始化游标**：`k = 0`（从第 1 个字段开始）、`c = 0`（字段内从第 1 格开始）；
4. **逐字符扫描**：`for (i = 0; line[i] != '\0'; i++)`，是逗号就 `field[k][c]='\0'; k++; c=0;`，否则 `field[k][c]=line[i]; c++;`；
5. **封口 + 输出**：循环后 `field[k][c]='\0';`，字段数 = `k+1`，循环打印每个字段。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    char line[100];                 /* 原始记录行 */
    char field[8][30];              /* 字段清单：最多 8 个，每个最多 29 字符 */
    int k = 0;                      /* 当前字段序号 */
    int c = 0;                      /* 当前字段内已写入的字符数 */
    int i;

    scanf("%[^\n]", line);          /* 读入含逗号的一整行（不加 &） */

    /* 逐字符扫描：逗号断开，普通字符抄入当前字段 */
    for (i = 0; line[i] != '\0'; i++) {
        if (line[i] == ',') {
            field[k][c] = '\0';     /* 给当前字段封口 */
            k++;                    /* 切换到下一个字段 */
            c = 0;                  /* 新字段从第 1 格开始 */
        } else {
            field[k][c] = line[i];  /* 字符写入当前字段 */
            c++;
        }
    }
    field[k][c] = '\0';             /* 别忘了给最后一个字段封口 */

    printf("字段数 = %d\n", k + 1);
    for (i = 0; i <= k; i++)
        printf("字段%d = %s\n", i + 1, field[i]);

    return 0;
}
```

## 五、运行验证

以样例 1 的 `S07,13.25,2.5` 为例，逐字符演示：

| i | line[i] | 判断 | 动作 | k | c |
|---|---|---|---|---|---|
| 0 | 'S' | 非逗号 | field[0][0]='S' | 0 | 1 |
| 1 | '0' | 非逗号 | field[0][1]='0' | 0 | 2 |
| 2 | '7' | 非逗号 | field[0][2]='7' | 0 | 3 |
| 3 | ',' | 逗号 | field[0][3]='\0'，k++，c=0 | 1 | 0 |
| 4 | '1' | 非逗号 | field[1][0]='1' | 1 | 1 |
| … | … | … | … | … | … |
| 11 | end | 循环结束 | field[2][3]='\0' | 2 | 3 |

字段数 = `k+1` = 3，程序输出：

```
字段数 = 3
字段1 = S07
字段2 = 13.25
字段3 = 2.5
```

与题干样例 1 完全一致。样例 2 的 `ICE-9,0.8,15.6,ok` 有 3 个逗号，字段数 4，各字段依次为 `ICE-9`、`0.8`、`15.6`、`ok`，同样吻合。

## 六、常见错误与讲解

**错误 1：最后一个字段忘记补 `'\0'`（最高发）**

```c
field[k][c] = '\0';   /* 少了这一行，最后一段没有结尾，%s 会打印乱码 */
```

循环里只在遇到逗号时封口，最后一段不是以逗号结尾，必须在循环外补封口。漏掉它时，`字段3 = 2.5` 后面会跟一串垃圾字符。

**错误 2：封口后忘记把 `c` 归零**

```c
if (line[i] == ',') { field[k][c] = '\0'; k++; }   /* 错：c 没清零，下一字段接在旧位置后面 */
if (line[i] == ',') { field[k][c] = '\0'; k++; c = 0; }  /* 对 */
```

`c` 是"当前字段内写到第几格"，换字段就要从头开始，否则第 2 个字段会从第 1 个字段的末尾继续写。

**错误 3：把二维字符数组与二维数值数组混淆**

```c
field[k][c] = line[i];      /* 对：字符数组元素是 char */
scanf("%lf", &field[k]);    /* 错：field[k] 是字符串，不是数值 */
```

若要**把字段转成数值**参与计算（如把 `13.25` 读成 `double`），应使用 `sscanf` 或逐个字符自行转换——这属于后续内容，本题只做字段提取。

**错误 4：扫描时直接改 `line` 或越界**

```c
for (i = 0; i <= 100; i++) ...    /* 错：应扫到 '\0' 为止，不要扫满容量 */
```

终止条件一律用 `line[i] != '\0'`，既正确又能适配任意长度。

## 七、与综合实验的衔接

- 实验 **C7（冰区船舶载荷辨识与统计系统）**的试验记录以"逗号分隔的文本行"形式保存，系统读入后第一步就是按本练习的方式把每行拆成编号、阻力、时间等字段，再转成数值做统计。本练习处理的虽只有一行，但把它放进一个循环里，就能逐行解析整份数据；
- "逐字符扫描 + 遇分隔符断开 + 补 `'\0'` 封口"是**文本解析的通用骨架**：第 8 章读文件时，`fgets` 读回一行后仍要用它来切字段。本练习是把这套骨架在本章先练熟。此外，`char field[8][30]` 这种"二维字符数组管理一批字符串"的用法，也是第 6 章"字符串指针数组"要解决的问题的原型。
