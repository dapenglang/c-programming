# 第 7 章 练习 22　沉降观测点结构体数组读入

**所属综合实验**：A5（A5-基于最小二乘拟合的建筑沉降监测数据分析系统）

**对应章节**：7 数据的结构化封装方法（7.2 结构体变量的定义、7.4 结构体数组的定义与遍历）

**场景来源**：综合实验 A5《基于最小二乘拟合的建筑沉降监测数据分析系统》（航建学院）——本练习是该实验中"多观测点数据批量录入"环节的实现。

**建议用时**：20～30 分钟

## 一、应用场景

一栋高层建筑通常布置多个沉降观测点，每期观测后要记录每个点的数据：**点号**、**累计沉降量**（mm）、**距首次观测的天数**（天）。A5 系统要一次性录入全部观测点，逐点分析沉降规律。

上一练习用结构体描述"一根杆件"，本练习把结构体扩成**结构体数组**——一排结构体盒子，每个装一个观测点的数据。这是管理"一批同类对象"的标准做法。

## 二、任务要求

编写一个完整程序 `settle_struct.c`：

1. 定义结构体类型 `SettlePoint`，成员为：`id`（点号，字符数组）、`settle`（累计沉降量 mm，double）、`days`（天数，int）；
2. 在 `main` 中定义**结构体数组** `sp[50]`；
3. 读入观测点个数 `n`（整数，**题目保证 1 ≤ n ≤ 50**），再循环读入 n 个观测点的三项数据；
4. **遍历数组**，逐点输出，并计算平均累计沉降量（保留 3 位小数）。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 行，每行形如 `点号 沉降量 天数`（用空格分隔）。

**输出**：先输出 n 行，每行 `点号: settle=沉降量mm days=天数`（沉降量保留 2 位小数）；最后一行输出 `avg_settle=平均沉降量mm`（保留 3 位小数）。

## 四、样例

**样例 1**

输入：
```
3
JC01 12.35 145
JC02 9.80 145
JC03 15.20 145
```
输出：
```
JC01: settle=12.35 days=145
JC02: settle=9.80 days=145
JC03: settle=15.20 days=145
avg_settle=12.450
```

**样例 2**

输入：
```
2
JC11 5.00 100
JC12 7.00 100
```
输出：
```
JC11: settle=5.00 days=100
JC12: settle=7.00 days=100
avg_settle=6.000
```

## 五、提示

**结构体数组的定义**：

```c
SettlePoint sp[50];         /* 50 个观测点盒子 */
```

**访问数组里第 i 个结构体的成员**：先用下标拿到那个结构体，再用点号访问成员：

```c
sp[i].id          /* 第 i 个点的点号 */
sp[i].settle      /* 第 i 个点的沉降量 */
sp[i].days        /* 第 i 个点的天数 */
```

**读入模板**（注意字符串成员用 `%s` 且不加 `&`）：

```c
for (i = 0; i < n; i++) {
    scanf("%s %lf %d", sp[i].id, &sp[i].settle, &sp[i].days);
}
```

**累加求平均**的套路与第 3 章一致，只是累加的是 `sp[i].settle`。

**平均沉降量**：

$$
\bar{s} = \frac{1}{n}\sum_{i=0}^{n-1} s_i
$$

**完成本练习后你将具备的能力**：定义结构体数组；用循环批量读入结构体数据；用"下标 + 点号"访问结构体数组成员；遍历结构体数组做统计。
