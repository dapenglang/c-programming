# 第 5 章 练习 21　迷宫网格读入与遍历

**所属综合实验**：B4（B4-基于深度优先搜索的迷宫求解系统）

**对应章节**：5 数组与批量数据处理（5.1 一维数组、5.2 二维数组、5.3 字符数组与字符串、3.2 选择结构、3.3 循环结构）

**场景来源**：综合实验 B4《基于深度优先搜索的迷宫求解系统》（人工智能学院）——本练习是该实验中"网格初始化"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

迷宫求解系统的输入是一张二维字符网格：`S` 表示起点，`G` 表示终点，`.` 表示通路，`#` 表示墙。程序拿到这张图后，必须**先把它完整存进一个二维字符数组**，才能在上面搜索路径。

把地图读进来这个动作看似简单，却决定了后面所有算法的输入是否正确。B4 系统在搜索之前，先读入网格、打印出来核对、统计各类格子的数量、定位起点终点，这就是本题要做的事。

## 二、任务要求

编写一个完整程序 `maze_read.c`：

1. 定义二维字符数组 `char grid[10][10];` 用于存放迷宫；
2. 从键盘读入行数 `r`（$1 \le r \le 10$）和列数 `c`（$1 \le c \le 10$）；
3. 用双重循环读入 $r$ 行字符串，逐字符存入 `grid`；
4. 遍历整个网格，统计并输出：
   - 起点 `S` 的位置（行、列，从 0 开始）与终点 `G` 的位置；
   - 通路 `.` 的个数 `road`、墙 `#` 的个数 `wall`。

## 三、输入输出格式

**输入**：
第一行，两个整数 r 和 c；
接下来 r 行，每行一个长度为 c 的字符串（只含 `S`、`G`、`.`、`#`）。

**输出**：三行，按格式输出：
```
S at (sr,sc)
G at (gr,gc)
road = 通路数, wall = 墙数
```

## 四、样例

**样例 1**

输入：
```
3 3
S..
.#.
..G
```
输出：
```
S at (0,0)
G at (2,2)
road = 6, wall = 1
```

**样例 2**

输入：
```
2 4
S..G
####
```
输出：
```
S at (0,0)
G at (0,3)
road = 2, wall = 4
```

## 五、提示

本题要用到三类数组知识：

1. **二维数组**：`char grid[10][10]`，两个下标分别表示行和列；
2. **字符数组**：每一行可以用 `scanf("%s", line)` 读入一个临时字符数组，再逐字符赋给 `grid[i][j]`；
3. **遍历**：双重循环 $\text{for } i \text{ in } 0..r-1,\ \text{for } j \text{ in } 0..c-1$。

统计时判断 `grid[i][j]` 的字符值：是 `'S'` 就记下 $(i,j)$，是 `'G'` 就记下 $(i,j)$，是 `'.'` 就 `road++`，是 `'#'` 就 `wall++`。字符常量用单引号，如 `if (grid[i][j] == 'S')`。

**完成本练习后你将具备的能力**：定义与访问二维数组、读入字符网格、用双重循环遍历全部格子、在遍历中记录多个统计量——这些是实验 B4 中"网格初始化模块"的地基。
