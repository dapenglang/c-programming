# 第 8 章 练习 23　弹道数据二进制存取

**所属综合实验**：A3（A3-基于梯形积分的飞行器垂直上升段弹道估算系统）

**对应章节**：8 数据持久化存储方法（8.1 文件的打开与关闭、8.4 二进制文件读写 `fwrite`/`fread`、8.5 数据块存取）

**场景来源**：综合实验 A3《基于梯形积分的飞行器垂直上升段弹道估算系统》（航建学院）——本练习是该实验中"速度序列二进制存档"环节的实现。

**建议用时**：25～30 分钟

## 一、应用场景

飞行器垂直上升段的弹道估算（A3）会算出一长串"时刻-速度"数据：每秒一个采样点，一次仿真可能几千个点。若用文本文件存，速度和体积都不理想；用**二进制文件**存，数据按内存中的原样写出，**读写快、体积小**，适合这种大批量数值序列的存档与后续读取。

本练习先按梯形积分的思想生成一段速度序列，用 `fwrite` 存成二进制文件，再用 `fread` 读回来验证，并统计最大速度与平均速度。

速度与加速度关系为

$$
v(t) = v_0 + \int_0^t a(\tau)\,d\tau
$$

本练习简化为匀加速上升段：$v(t) = v_0 + a t$，$a$ 为净加速度（kN 推力换算得到的加速度，m/s²）。

## 二、任务要求

编写一个完整程序 `ballistic_bin.c`：

1. 读入初速度 `v0`（m/s）、净加速度 `a`（m/s²）、采样点数 `n`（整数，**保证 1 ≤ n ≤ 1000**）；
2. 用循环生成速度序列 $v_i = v_0 + a \cdot i$（$i = 0,1,\dots,n-1$），存入 `double` 数组；
3. 用 `fwrite` 把整个数组**以二进制方式**写入文件 `speed.dat`；
4. 关闭后重新以二进制方式打开，用 `fread` 把数据读回另一个数组；
5. 遍历读回的数组，输出**最大速度**、**平均速度**（保留 3 位小数）和**读回的元素个数**；
6. **必须检查 fopen 返回值**。

## 三、输入输出格式

**输入**：一行三个数：v0、a、n。

**输出**：三行，`count=元素个数`、`vmax=最大速度`、`vavg=平均速度`（速度保留 3 位小数）。

## 四、样例

**样例 1**

输入：
```
0.0 9.8 5
```
输出：
```
count=5
vmax=39.200
vavg=19.600
```

**样例 2**

输入：
```
100.0 20.0 4
```
输出：
```
count=4
vmax=160.000
vavg=130.000
```

## 五、提示

**二进制文件 vs 文本文件**：文本文件存的是"人能读的字符"（如数字 39.2 存成字符 `'3' '9' '.' '2'`），二进制文件存的是**数据在内存里的原始字节**。同样一个 `double`，二进制方式固定占 8 字节，读写不用做"字符↔数值"转换，因此**更快、更省空间**，但用记事本打开是乱码。

**写二进制**：

```c
fwrite(arr, sizeof(double), n, fp);
/* 参数：数据起始地址、单个元素大小、元素个数、文件指针 */
```

**读二进制**：

```c
int got = fread(arr2, sizeof(double), n, fp);
/* fread 返回实际读到的元素个数 */
```

打开模式用 `"wb"`（二进制写）和 `"rb"`（二进制读）。

**完成本练习后你将具备的能力**：理解文本与二进制文件的区别；用 `fwrite`/`fread` 整块读写数组；用 `"wb"`/`"rb"` 模式打开文件；通过 `fread` 返回值确认读取数量。
