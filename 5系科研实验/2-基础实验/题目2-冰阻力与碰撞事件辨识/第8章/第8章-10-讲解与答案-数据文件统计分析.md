## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

内存里的数据"程序一停就没了"。试验数据往往由测量设备或前一段程序先存成文件，之后**任何时候**都能读回来分析——文件让数据跨越了时间与程序的边界。本题的数据是一列采样值，我们要做的是"读进来、算指标"。这是文件读操作最常见的用途之一：**把外部数据变成程序能加工的信息**。

### 2. 文件操作的标准四步曲

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题用 `fscanf` 逐个读；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 它是这次文件访问的"编号牌"，指向系统为该文件建立的记录（文件在哪、当前进行到哪、是读还是写）；记录里的**文件位置指针**标明"现在读到第几个字节"，每读一个数就自动后推，直到读完全部内容。

**打开失败会怎样？** 文件不存在或无读权限时 `fopen` 返回 `NULL`，不判空就用会崩溃，因此打开后**必须**判空：

```c
if (fp == NULL) { printf("无法打开文件 loads.txt\n"); return 1; }
```

### 3. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fscanf` | 按格式读 | `while (fscanf(fp, "%lf", &v) == 1) {...}` | 读一列数、格式规整的文本 |
| `fprintf` | 按格式写 | `fprintf(fp, "%.2f\n", v);` | 把数字按人可读格式写进文本 |
| `fgets` | 读一整行 | `fgets(buf, sizeof(buf), fp);` | 整行处理（含字符串字段） |
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理 |
| `fread`/`fwrite` | 按字节块读写 | `fread(a, sizeof(double), n, fp);` | 二进制、批量存数组 |

本题文件是"每行一个实数"，用 `fscanf` 逐个数读最省事。关键在于**怎么知道读完了**：`fscanf` 返回"成功读到的字段个数"，读到文件末尾时返回 `EOF`（不是 1），于是用 `while (fscanf(fp, "%lf", &v) == 1)` 就能优雅地读到文件尾。这比用 `feof` 更稳妥——`feof` 是"读失败之后"才为真的。

### 4. 打开模式的区别

| 模式 | 含义 | 文件已存在时 |
|---|---|---|
| `"r"` | 只读文本 | 从文件头开始读，不存在则失败 |
| `"w"` | 只写文本 | 清空原有内容，从头开始写 |
| `"a"` | 追加文本 | 保留原有内容，从末尾接着写 |
| `"rb"`/`"wb"` | 二进制只读/只写 | 同上，但按二进制方式处理 |

本题只读原始数据、只打印统计量，用 `"r"`；**绝不能用 `"w"`，否则原始数据会被清空**。

### 5. 用本题的数据走一遍文件指针

样例文件为 `12.5 / 18.3 / 9.75 / 21.0 / 15.5` 五行。打开后位置指针在开头。循环开始：第一次 `fscanf` 读到 `12.5` 返回 1，`count=1`、`sum=12.5`，因是第一个数，`max=min=12.5`；第二次读 `18.3`，`sum=30.8`，`max` 更新为 `18.3`；第三次读 `9.75`，`sum=40.55`，`min` 更新为 `9.75`；第四次读 `21.0`，`sum=61.55`，`max=21.0`；第五次读 `15.5`，`count=5`、`sum=77.05`。第六次再调用 `fscanf` 时已无数据，返回 `EOF`，循环结束，`mean = 77.05/5 = 15.41`。**位置指针每读一个数前进一步，读到文件末尾后 `fscanf` 用返回值通知我们"没有更多数据了"。**

## 三、解题思路

1. **打开**：`fp = fopen("loads.txt", "r")`，判空；
2. **循环读**：`while (fscanf(fp, "%lf", &v) == 1)`；
3. **循环体内统计**：`count++`、`sum += v`；用 `first` 标志处理最值初值（第一个数同时作初值，之后逐个比较更新）；
4. **关闭并计算**：`fclose(fp)`，`mean = sum / count;`
5. **输出**：行数（整数）与三个统计量（均 2 位小数）。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    double v;                       /* 每次读入的一个数 */
    double sum = 0.0, mean;         /* 累加和、均值 */
    double maxv = 0.0, minv = 0.0;  /* 最大值、最小值 */
    int    count = 0;               /* 数据个数 */
    int    first = 1;               /* 是否读到第一个数 */

    /* 以只读方式打开数据文件 */
    fp = fopen("loads.txt", "r");
    if (fp == NULL) {
        printf("无法打开文件 loads.txt\n");
        return 1;
    }

    /* 逐个读入，读到文件尾自动结束 */
    while (fscanf(fp, "%lf", &v) == 1) {
        sum += v;
        count++;
        if (first) {                /* 第一个数同时作为最值初值 */
            maxv = minv = v;
            first = 0;
        } else {
            if (v > maxv) maxv = v; /* 更新最大值 */
            if (v < minv) minv = v; /* 更新最小值 */
        }
    }
    fclose(fp);

    mean = sum / count;             /* 均值 = 总和 / 个数 */

    printf("共 %d 行数据\n", count);
    printf("均值 = %.2f\n",   mean);
    printf("最大值 = %.2f\n", maxv);
    printf("最小值 = %.2f\n", minv);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：用 `feof` 控制循环，导致最后一次多算**

```c
while (!feof(fp)) {
    fscanf(fp, "%lf", &v);   /* 错：读失败后 v 保留旧值，会被重复统计一次 */
    sum += v; count++;
}
while (fscanf(fp, "%lf", &v) == 1) {   /* 对：以读取成功为条件 */
    sum += v; count++;
}
```
`feof` 要等到"读失败之后"才为真，会多走一圈。**直接用 `fscanf` 的返回值当条件最稳妥。**

**错误 2：最值初值设为 0，遇到负值或全正值时出错**

```c
double maxv = 0.0, minv = 0.0;   /* 若数据全为正，minv 会一直是 0，错误 */
```
若采样值都可能为正，把 `minv` 初值设为 0 会得到错误的最小值。正确做法是**用第一个数据初始化两个最值**（本练习用 `first` 标志实现），或把 `max` 初值设为很小的数、`min` 初值设为很大的数。

**错误 3：`fopen` 不判空、忘记 `fclose`，或误用 `"w"`**

`fopen` 后不判空、循环里直接用 `fp`，文件不存在时程序会崩溃；同理，若把打开模式误写成 `"w"`，会在打开瞬间清空原始数据文件，不可挽回。**读文件一律用 `"r"`，用完 `fclose`。**

**错误 4：均值用整数除法**

```c
int count; double sum; mean = sum / count;   /* 只要有一方是浮点，就是浮点除法 */
```
若把累加和也写成 `int`，除法就会丢掉小数。本章纪律：**统计量一律用 `double` 累加。**
