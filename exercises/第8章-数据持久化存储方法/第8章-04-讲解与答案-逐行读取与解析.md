## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

程序里的变量、数组，"程序一停就没了"；要长期保存的试验记录必须落到文件里。本题要读的是一份**试验记录表**：每行一次试验、每行三个字段。这类文件的特点是"行是天然的分隔单位"——所以我们希望以**一行**为单位来读，而不是像 `fscanf` 那样一个个字段地读。C 语言里负责"读一整行"的函数就是 `fgets`。

### 2. 文件操作的标准四步曲

无论读写，文件操作都是同一条流水线：

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题用 `fgets` 读行、`sscanf` 解析；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 它是这次文件访问的"编号牌"，指向系统为这个文件建立的一套记录（文件在哪、当前进行到哪、是读还是写）；记录里有一个**文件位置指针**标明"现在读到第几个字节"，每读一行就自动后推。

**打开失败会怎样？** 文件不存在或没有读权限时，`fopen` 返回 `NULL`。不判空就用会崩溃，所以打开后**必须**紧跟：

```c
if (fp == NULL) { printf("打不开 loads.csv\n"); return 1; }
```

### 3. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fgets` | 读一整行 | `fgets(buf, sizeof(buf), fp);` | 一行里有字符串、需要整行处理 |
| `fscanf` | 按格式读 | `fscanf(fp, "%d%lf", &id, &v);` | 纯数字、格式规整的文本 |
| `fprintf` | 按格式写 | `fprintf(fp, "%d %.2f\n", id, v);` | 把数字按人可读格式写进文本 |
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理（词频统计） |
| `fread`/`fwrite` | 按字节块读写 | `fread(a, sizeof(double), n, fp);` | 二进制文件、批量存数组 |

本题一行里既有字符串编号 `s01` 又有两个数字，用 `fscanf` 也能读，但一旦某行格式有点出入，读指针就会错位；用 **`fgets` 先把整行拿到手，再用 `sscanf` 在内存里慢慢拆**，出错只影响当前这一行，健壮得多。`sscanf` 的用法与 `scanf` 完全相同，只是数据来源从键盘换成了字符数组 `line`。

### 4. 打开模式的区别

| 模式 | 含义 | 文件已存在时 |
|---|---|---|
| `"r"` | 只读文本 | 从文件头开始读，不存在则失败 |
| `"w"` | 只写文本 | 清空原有内容，从头开始写 |
| `"a"` | 追加文本 | 保留原有内容，从末尾接着写 |
| `"rb"`/`"wb"` | 二进制只读/只写 | 同上，但按二进制方式处理 |

只读原始记录，用 `"r"`；**绝不能用 `"w"`**，那会把原始记录清空。

### 5. 用本题的数据走一遍文件指针

文件前两行：

```
s01,12.5,1.2
s02,18.3,1.5
```

打开后位置指针在开头。第一次 `fgets(line, sizeof(line), fp)` 把 `s01,12.5,1.2\n` 整行（含换行）读进 `line`，指针推到第二行开头；`sscanf` 把 `line` 拆成 `id="s01"`、`r=12.5`、`v=1.2`，输出一行并把 `r` 累加。第二次读 `s02,18.3,1.5\n`，同理。第三次调用 `fgets` 时已无内容，返回 `NULL`，循环结束，输出行数与总阻力。

要点：`fgets` 读进来的行**末尾带着 `'\n'`**，本不必手动删除，因为 `sscanf` 的 `%lf` 和 `%[^,]` 都会自动跳过空白和换行。若将来要把整行当字符串比较，才需要动手去掉换行。

## 三、解题思路

1. **打开**：`fopen("loads.csv", "r")`，判空；
2. **循环按行读**：`while (fgets(line, sizeof(line), fp) != NULL)`；
3. **每行解析**：`sscanf(line, "%15[^,],%lf,%lf", id, &r, &v) == 3` 时才处理，输出并累加 `sum`、`count++`；
4. **收尾**：`fclose(fp)`；
5. **报表**：输出 `共读取 X 行` 与 `总阻力 = X kN`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;                    /* 数据文件指针 */
    char  line[128];             /* 存放读入的一整行 */
    char  id[16];                /* 解析出的样本编号 */
    double r, v;                 /* 阻力(kN)、航速(m/s) */
    int    count = 0;            /* 记录条数 */
    double sum = 0.0;            /* 总阻力 */

    /* 以只读方式打开数据文件 */
    fp = fopen("loads.csv", "r");
    if (fp == NULL) {
        printf("无法打开文件 loads.csv\n");
        return 1;
    }

    /* 按行读取，直到文件结尾 */
    while (fgets(line, sizeof(line), fp) != NULL) {
        /* 用 sscanf 从这一行里按逗号拆出三个字段 */
        if (sscanf(line, "%15[^,],%lf,%lf", id, &r, &v) == 3) {
            printf("记录 %s 阻力 = %.2f kN 航速 = %.2f m/s\n", id, r, v);
            sum += r;
            count++;
        }
    }

    fclose(fp);

    printf("共读取 %d 行\n", count);
    printf("总阻力 = %.2f kN\n", sum);

    return 0;
}
```

## 五、运行验证

**样例 1：运行前** `loads.csv` 内容：

屏幕输出：
```

```
核对：三条记录逐行解析正确；总阻力 $= 12.5 + 18.3 + 9.75 = 40.55$，与输出一致。

## 六、常见错误与讲解

**错误 1：`fopen` 不判空**

```c
fp = fopen("loads.csv", "r");
fgets(line, sizeof(line), fp);   /* 错：文件不存在时 fp 为 NULL，崩溃 */
```
判空是读文件的第一步，任何情况下都不能省。

**错误 2：用 `scanf` 去解析字符串**

```c
sscanf(line, "%15[^,],%lf,%lf", id, &r, &v);   /* 对：从字符数组里读 */
scanf(line, "%15[^,],%lf,%lf", id, &r, &v);    /* 错：scanf 第一个参数是格式串 */
```
`scanf` 的数据源是键盘，第一个参数必须是格式串；要从 `line` 里读，必须用 `sscanf`。

**错误 3：字符串编号用 `%d` 去读**

```c
sscanf(line, "%d,%lf,%lf", &id, &r, &v);      /* 错：s01 不是整数，读失败 */
sscanf(line, "%15[^,],%lf,%lf", id, &r, &v);  /* 对：编号是字符串，用 %[^,] */
```
`%15[^,]` 表示"最多读 15 个非逗号字符"，正好取到编号并停在逗号处；`id` 是数组名，本身就代表地址，前面**不加 `&`**。另外，`fgets` 的第二个参数是**缓冲区总容量**，它最多读"容量减 1"个字符，要留出结束符 `'\0'` 的位置。

## 七、与综合实验的衔接

实验 C7 读取原始试验记录、C9 读取测点日志、B6 读取待统计的文本，第一步都是"按行读进来、再拆字段"。练好 `fgets + sscanf` 这个组合，就能应付绝大多数"一行一条记录、字段用固定分隔符"的数据文件。当记录字段更多、还夹杂表头与空行时，可以在此基础上加判断，跳过不需要的行——这正是真实数据清洗的开端。若数据的规模和结构复杂到需要按条件检索、跨文件关联，第 8 章 8.7 节的数据库技术是更系统的持久化与管理方案。
