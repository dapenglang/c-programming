# 第 7 章 练习 19　冰场载荷数据管理

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型、7.2 结构体数组——批量存放与遍历统计）

**场景来源**：综合实验 C6《冰块与结构碰撞模拟系统》/ C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"测点载荷台账的批量管理与统计报表"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

一次冰区模型试验会布设固定数量的测点，每个测点有**编号**和**载荷**两项数据，天然是一张"记录"表。当测点数量已知、且不需要中途增删时，最合适的容器是**结构体数组**：数组下标代表"第几个测点"，每个元素是一个结构体，把编号和载荷绑在一起。试验结束后，管理模块要一次性算出这批记录的**最大载荷、最小载荷、平均载荷**，并统计**超过报警阈值**的测点个数，最后打印成一张规整的统计报表。本练习用结构体数组完成这套"读入—统计—出报表"的完整流程。

## 二、任务要求

编写一个完整程序 `ice_report.c`：

1. 定义结构体类型 `struct IceLoad`：`int id`（测点编号）、`double load`（载荷，kN）；
2. 读入整数 `n`（`1 ≤ n ≤ 100`），再读入 `n` 行记录（`id` 与 `load`），存入结构体数组；
3. 读入统计阈值 `limit`；遍历数组求：最大载荷及其编号、最小载荷及其编号、载荷总和与平均值、载荷不小于 `limit` 的测点个数；
4. 按规定的**多行报表格式**输出上述结果，`load`、`mean` 及报表中的阈值均保留 2 位小数；
5. 求平均值时使用 `double` 累加；编号与载荷的对应关系不能在统计中错位（最大值取到哪个编号，就输出哪个编号）。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`；
- 接下来 `n` 行：每行 `id load`；
- 最后一行：一个实数 `limit`（阈值，kN）。

**输出**：按下述六行格式输出（数值保留 2 位小数）：
```
===== 冰场载荷统计报表 =====
样本数 = <n>
最大载荷 = <max> kN (编号 <maxId>)
最小载荷 = <min> kN (编号 <minId>)
平均载荷 = <mean> kN
超阈样本数(>= <limit> kN) = <over>
```

## 四、样例

**样例 1**

输入：
```
5
101 12.0
102 25.0
103 8.0
104 40.0
105 15.0
20
```
输出：
```
===== 冰场载荷统计报表 =====
样本数 = 5
最大载荷 = 40.00 kN (编号 104)
最小载荷 = 8.00 kN (编号 103)
平均载荷 = 20.00 kN
超阈样本数(>= 20.00 kN) = 2
```

**样例 2**

输入：
```
3
1 30.0
2 12.0
3 18.0
20
```
输出：
```
===== 冰场载荷统计报表 =====
样本数 = 3
最大载荷 = 30.00 kN (编号 1)
最小载荷 = 12.00 kN (编号 2)
平均载荷 = 20.00 kN
超阈样本数(>= 20.00 kN) = 1
```

## 五、提示

- 结构体数组定义：`struct IceLoad a[100];`；读入用 `scanf("%d %lf", &a[i].id, &a[i].load);`；
- 求最值的标准做法：先把 `max`、`min` 初始化为 `a[0].load`，其编号也初始化为 `a[0].id`，再从下标 1 开始循环比较，**每个最值都要连带记住它的编号**；
- 求和用 `double`：`sum += a[i].load;`，平均为 `mean = sum / n;`（`n ≥ 1`，不必担心除零）；
- 超阈计数条件为 $load \ge limit$（"不小于"含等于）；
- 报表的表头、单位、括号等符号要与样例**逐字符一致**，可用多个 `printf` 分行输出。

**完成本练习后你将具备的能力**：会用结构体数组批量存放"多条记录"、能在一次遍历中同步求出多个统计量（最值、均值、条件计数）、能按格式输出完整报表——这是实验 C6/C7"载荷台账统计报表模块"的地基。
