## 二、预备知识：组合数与帕斯卡递推（零基础阅读）

### 1. 问题来源

$C_n^k$ 表示"从 $n$ 个不同元素中取 $k$ 个（不计次序）"的方案数，例如 $C_5^2 = 10$ 表示从 5 个里选 2 个有 10 种选法。直接按公式 $C_n^k = \dfrac{n!}{k!(n-k)!}$ 需要先算阶乘，容易溢出；更好的办法是利用杨辉三角的递推结构。

### 2. 递推关系怎么推出来

在 $n$ 个元素里**盯住某一个特定的元素**（比如"1 号元素"），那么任取 $k$ 个的方案分成两类：

- **不选 1 号**：剩下的 $k$ 个只能从其余 $n-1$ 个里取，方案数 $C_{n-1}^{k}$；
- **选了 1 号**：还要从其余 $n-1$ 个里再取 $k-1$ 个，方案数 $C_{n-1}^{k-1}$。

两类互不重叠、又覆盖全部，相加即得帕斯卡递推：

$$
C_n^k = C_{n-1}^{k-1} + C_{n-1}^{k}
$$

### 3. 基线条件

- 从 $n$ 个里取 0 个：只有"什么都不取"一种方案，$C_n^0 = 1$；
- 从 $n$ 个里取全部 $n$ 个：只有"全选"一种方案，$C_n^n = 1$。

代码写作 `if (k == 0 || k == n) return 1;`。**两条基线都要有**：如果只留 `k == 0`，当 $k=n$ 时会算出 $C_{n-1}^{n}$（即"从 $n-1$ 个里取 $n$ 个"），这已经超出定义范围，会继续递归下去而永不终止。

### 4. 调用树展开：用 $C_4^2$ 看递归

```text
comb(4, 2)
├── comb(3, 1)
│    ├── comb(2, 0) = 1     命中基线（取 0 个）
│    └── comb(2, 1)
│         ├── comb(1, 0) = 1
│         └── comb(1, 1) = 1   命中基线（取全部）
│         └─ comb(2, 1) = 1 + 1 = 2
│    └─ comb(3, 1) = 1 + 2 = 3
└── comb(3, 2)
     ├── comb(2, 1) = 2      （与上面重复计算）
     └── comb(2, 2) = 1     命中基线（取全部）
     └─ comb(3, 2) = 2 + 1 = 3
→ comb(4, 2) = 3 + 3 = 6
```

可以看到两个特点：**每个节点都向下分出两支**（因为递推里有两个 `comb` 调用）；**同一个子问题会被重复计算**（如 `comb(2,1)` 出现两次）。这和斐波那契是同一类"双分支递归"。

### 5. 编程要点

- 两个形参 `n`、`k` 都要朝基线方向缩小：`n-1`、`k-1`；
- 结果可能较大，用 `long long` 返回、用 `%lld` 打印；
- 题目限定 $k \le n$，无须处理 $k>n$ 的非法输入。

## 三、解题思路

1. **定接口**：`long long comb(int n, int k)`；
2. **写原型**：放在 `main` 上方；
3. **写基线**：`if (k == 0 || k == n) return 1;`——两条都要；
4. **写递推**：`return comb(n - 1, k - 1) + comb(n - 1, k);`；
5. **主流程**：读 `n`、`k` → 调用 → 打印。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：返回组合数 C(n, k) */
long long comb(int n, int k);

int main(void)
{
    int n, k;
    scanf("%d %d", &n, &k);                          /* 读入 n、k，保证 0<=k<=n */
    printf("C(%d,%d) = %lld\n", n, k, comb(n, k));   /* 递归求组合数 */
    return 0;
}

/* 递归函数：杨辉三角（帕斯卡）递推 */
long long comb(int n, int k)
{
    if (k == 0 || k == n)                             /* 基线：取 0 个或取全部 */
        return 1;
    else                                              /* 递推：不选 + 选，两类相加 */
        return comb(n - 1, k - 1) + comb(n - 1, k);
}
```

## 五、运行验证

以 `comb(4,2)` 为例的中间结果：

| 调用 | 表达式 | 本层结果 |
|---|---|---|
| comb(2, 0) | 命中基线 | 1 |
| comb(2, 1) | comb(1,0)+comb(1,1) = 1 + 1 | 2 |
| comb(3, 1) | comb(2,0)+comb(2,1) = 1 + 2 | 3 |
| comb(3, 2) | comb(2,1)+comb(2,2) = 2 + 1 | 3 |
| comb(4, 2) | comb(3,1)+comb(3,2) = 3 + 3 | 6 |

多组输入的程序输出：

| 输入 n k | 手算过程 | 程序输出 |
|---|---|---|
| 6 0 | 取 0 个，基线 | `C(6,0) = 1` ✓ |
| 6 3 | 杨辉三角第 6 行第 3 个数 = 20 | `C(6,3) = 20` ✓ |
| 5 2 | 10 | `C(5,2) = 10` ✓ |
| 10 3 | 120 | `C(10,3) = 120` ✓ |

## 六、常见错误与讲解

**错误 1：只写一条基线**

```c
if (k == 0) return 1;    /* 错：k == n 的情形没有出口，会递归到 k > n 而永不终止 */
if (k == 0 || k == n) return 1;   /* 对：两条边界都处理 */
```

**错误 2：递推关系参数写错**

```c
return comb(n - 1, k) + comb(n - 1, k);       /* 错：两项一样，算成了 2*C(n-1,k) */
return comb(n - 1, k - 1) + comb(n - 1, k);   /* 对：一个 k-1，一个 k */
```

**错误 3：用 `int` 承载导致溢出**

```c
int comb(int n, int k);          /* n 较大时组合数很快超过 int */
long long comb(int n, int k);    /* 对 */
```

**错误 4：忽略了重复计算带来的开销**

`comb(30,15)` 会重复计算大量子问题，调用次数很大。与斐波那契一样，**递归写法直观清晰，但效率并非最优**；要真正快速求解，需要把已算结果缓存（第 5 章数组），或用数学公式直接计算。
