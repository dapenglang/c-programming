# 题目 A7：基于拉格朗日插值的混凝土强度发展曲线计算系统

**适用学院**：航建学院（2 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套混凝土强度发展曲线计算工具。系统读入某配合比混凝土"龄期-抗压强度"试验点数据，经排序与校验后实现 n 点拉格朗日插值函数，支持任意龄期的强度交互查询、等间隔龄期的批量插值成表、强度发展曲线字符图绘制；同时用"留一点作检验点"的方式评估插值误差，并按二分查找反查"强度达到设计值所需的最短龄期"（拆模与张拉预应力的关键依据），查询结果写入报表。

**解决什么重要问题**：混凝土强度随龄期增长，但试验只可能在有限龄期（3、7、14、28、60、90 天）制作试块，施工中却常常需要知道任意时刻的强度：模板几岁可以拆除？预应力梁何时可以张拉？冬期施工掺防冻剂后 14 天能达多少强度？这些"表格中间的点"必须由插值求得。线性插值在曲线弯曲段（早期强度快速增长段）误差明显，拉格朗日多项式插值能利用全部试验点得到更光滑、更准确的估计；反过来"已知目标强度反求所需龄期与养护天数"则是排进度计划（确定拆模时间、张拉窗口）的直接输入，估算不准要么延误工期、要么过早受力引发质量事故。

**支撑哪些关键应用**：① 施工技术方案中拆模时间与预应力张拉时间的确定；② 冬期施工养护措施的效果评估；③ 混凝土配合比试验室的数据整理与回归报告；④ 后续"土木工程材料""混凝土结构设计""数值分析"课程中，材料时变性能建模与多项式插值都是标准内容。

**与专业培养的关联**：土木、建材方向的学生在材料试验课上亲手压过试块，本题目把试验数据变成可查询、可预测的计算模型，课程 8.6 节拉格朗日插值与 5.5 节二分查找在真实材料数据上完成闭环，训练"试验数据 → 数学模型 → 工程决策"的专业思维方式。

## 二、题目任务与专业关联

本题目面向土木工程（建筑材料方向）学生，模拟"试验室强度曲线建库与查询"场景。系统功能概述：① 读入试验点文件并按龄期排序、剔除重复与越界数据；② 实现 n 点拉格朗日插值；③ 单点交互查询与等间隔批量查询成表；④ 绘制强度发展曲线字符图；⑤ 留检验点比较插值误差；⑥ 用二分查找反查达标龄期；⑦ 输出查询报表。先导知识铺垫：拉格朗日插值公式 L(x)=Σ y_i·Π (x-x_j)/(x_i-x_j)（j≠i，课程 8.6 已给出）与双精度累乘的实现要点；二分查找前提为函数单调（本系统限定查询区间在强度单调增长段 1~90 天）。学生不需要任何超出课程的知识即可完成。

## 三、数据来源与格式

**数据文件：试验点数据**（`strength.txt`）

```
龄期d,抗压强度MPa
3,12.5
7,21.8
14,29.6
28,36.4
60,41.2
90,42.8
```

字段含义：龄期取值 1~180 天（整数）；抗压强度取值 5.0~60.0 MPa（C30~C50 混凝土的实测范围，保留 1 位小数）；至少 5 个、至多 8 个试验点，龄期不得重复。

**仿真数据生成规则**：
- 主数据集 6 个点：按 f(t)=42·(1-e^(-t/14)) 的饱和增长规律在 3/7/14/28/60/90 天取值，四舍五入到 0.1 MPa（模拟试验离散性可加固定偏差 ±0.3）；
- 另生成 2 个对比数据集：`strength_c40.txt`（同规律、终值 47 MPa，加 2 个早期加密点 2 天、5 天）与 `strength_winter.txt`（冬期施工，增长减半：f(t)=42·(1-e^(-t/28))）；
- 异常注入：在 `strength.txt` 中故意加入 `28,36.4`（与已有 28 天重复）和 `200,45.0`（龄期越界）、`14,296.0`（强度超物理范围），用于训练排序前校验与剔除逻辑；
- 数据生成时统一保留原始无重复版本 `strength_clean.txt` 供误差评估模块使用。

**真实数据集**：无必需公开数据集；配合比强度发展数据可参照《普通混凝土配合比设计规程》JGJ 55 附录与教材《土木工程材料》试验章节的典型曲线，报告中注明。

## 四、数据结构设计

```c
#define MAX_POINT 10      /* 最大试验点数 */

/* 单个试验点 */
struct TestPoint {
    int    age;            /* 龄期 天，1~180 */
    double fc;             /* 抗压强度 MPa，5.0~60.0 */
    int    valid;          /* 校验标志 1 有效 / 0 重复或越界 */
};

/* 全局数据 */
struct TestPoint g_pt[MAX_POINT];
int    g_ptCnt;            /* 读入点数（含无效） */
int    g_validCnt;         /* 有效点数 */
double g_target;           /* 设计强度目标值 MPa，交互输入，20~50 */
```

插值计算使用的有效数据通过下标遍历有效点获得；批量查询表用局部一维数组 `double xs[N], ys[N];`（N≤40）存放等间隔龄期与插值结果；检验点评估用结构体 `struct ErrItem { int age; double real, est, err; } g_errTab[MAX_POINT];` 存放逐点误差。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 试验数据文件读入模块**（源文件 `DataIO.c`）

- 功能简介：跳过表头逐行读入"龄期,强度"试验点；支持交互指定文件名（默认 strength.txt）；输出读入点数与龄期范围摘要。
- 输入：试验点文本文件。
- 输出：`g_pt[]`、`g_ptCnt`；屏幕读入摘要。

**M2 数据排序与校验模块**（源文件 `DataCheck.c`）

- 功能简介：按龄期用冒泡排序升序排列；逐点校验龄期 1~180、强度 5~60，龄期重复与越界点置 valid=0 并打印剔除清单（含注入的重复点、200 天与 296 MPa 异常）；统计有效点数并回显有序数据表。
- 输入：`g_pt[]`。
- 输出：排序且标记后的 `g_pt[]`、`g_validCnt`；屏幕校验报告。

### 第二部分：算法实现（5 个模块）

**M3 拉格朗日插值函数模块**（源文件 `Lagrange.c`）

- 功能简介：实现 `double lagrange(double x)`：对全部有效点按公式累乘累加求插值；x 在数据范围外时返回端点值并打印外推警告；另设"低阶对照"开关，仅用相邻 3 点做 3 点插值比较结果。
- 输入：龄期 x（天）。
- 输出：强度估计值（MPa）。

**M4 单点交互查询模块**（源文件 `QueryOne.c`）

- 功能简介：循环交互输入龄期（0 退出），调用 M3 返回强度并打印"龄期-强度-所在区间-是否外推"明细；龄期越界时提示重输；查询历史保留在屏幕滚动区便于核对。
- 输入：键盘龄期。
- 输出：屏幕查询结果。

**M5 批量查询模块**（源文件 `QueryBatch.c`）

- 功能简介：对 1~90 天按 3 天间隔生成 30 个查询点，逐点调用 M3 形成等间隔强度发展表打印；表尾标注每 10 天节点的数值供人工核对。
- 输入：M3 插值函数。
- 输出：屏幕批量查询表。

**M6 强度曲线字符画模块**（源文件 `CharPlot.c`）

- 功能简介：以龄期为横轴 40 列、强度为纵轴 18 行，用 `o` 画试验点、`*` 按 M3 插值画连续曲线；纵轴自动按数据范围缩放并标注刻度。
- 输入：`g_pt[]`、M3 函数。
- 输出：屏幕字符曲线。

**M7 插值误差讨论模块**（源文件 `ErrorEval.c`）

- 功能简介：逐一隐藏一个试验点，用其余点对该点插值并与实测值比较，统计平均绝对误差与最大误差；再对同一检验点比较"全点插值 / 3 点局部插值 / 线性插值"三种方式的误差，形成误差对照表（线性插值函数在模块内用相邻两点自行实现）。
- 输入：`g_pt[]`。
- 输出：`g_errTab[]`；屏幕误差对照表。

**M8 设计强度达标龄期反查模块**（源文件 `Inverse.c`）

- 功能简介：交互输入设计强度目标值（如 C30 取 30 MPa），在强度单调增长段 [首点龄期, 90 天] 内用二分查找对 M3 插值函数求 f(x)=目标 的龄期，输出达标龄期与按 7 天养护周期折算的拆模建议天数；目标超过曲线终值时提示"该配合比无法达标"。
- 输入：目标强度 MPa。
- 输出：达标龄期（天）；屏幕建议。

### 第三部分：数据输出（3 个模块）

**M9 查询报表输出模块**（源文件 `Report.c`）

- 功能简介：把数据表、校验剔除记录、批量查询表、误差对照表与达标龄期结论写入 `strength_report.txt`，采用对齐表格输出。
- 输入：全部全局数据与结果。
- 输出：`strength_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Main.c`）

- 功能简介：文本菜单（读数据 / 排序校验 / 单点查询 / 批量查询 / 曲线图 / 误差评估 / 反查龄期 / 输出报表 / 退出），`do-while + switch` 调度；状态约束：未完成排序校验不得查询。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环分发 M1~M9；状态约束：M3~M9 前必须完成 M2；M7、M8 复用 M3 的插值函数；菜单可随时切换数据文件重跑。

**数据流**：

```
strength.txt ─► M1 读入 ─► g_pt[] ─► M2 排序校验(有效点) ─► M3 拉格朗日插值函数
                                                                │
              M4 单点查询 ◄── 交互龄期 ─────────────────────────┤
              M5 批量查询表 ◄──────────────────────────────────┤
              M6 曲线字符图 ◄──────────────────────────────────┤
              M7 隐藏点误差对照 ◄──────────────────────────────┤
              M8 二分反查 ◄── 目标强度 ────────────────────────┤
                                                                ▼
                                              M9 报表 strength_report.txt
```

模块间通过全局试验点数组与插值函数交换数据，`lagrange(x)` 的函数签名在编码前书面约定，全组共用。
