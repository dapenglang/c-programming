# 题目 C9：基于分区间统计的海洋环境噪声等级评估系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行海洋环境噪声等级评估工具，围绕"水声实验前需要掌握海区背景噪声水平，把连续采样的噪声级时间序列做分区间频数统计、累积分布与分位数分析，最终按阈值表给出噪声等级判定"这一水声工程常规流程展开。系统从文本文件读入噪声级时间序列，完成有效性检查，按噪声级区间做频数统计形成直方图，计算累积分布，用排序求 95% 分位数，统计超过给定阈值的样本占比，比较昼夜两个时段的均值差异，按阈值表判定噪声等级，最后输出结果文件、屏幕直方图与报表。

海洋环境噪声是水声信号的"背景底色"。海面风浪、航船辐射噪声、生物噪声与降雨共同构成了从几赫兹到几十千赫兹的背景声场，声呐检测、水声通信与水声实验方案设计都必须先回答"这个海区有多吵、吵到什么概率水平"。工程上常用噪声级（单位 dB re 1 μPa）时间序列的统计特征刻画它：直方图看分布形态，累积分布与分位数（如 95% 位）看"多大声级算少见的高噪声"，超阈占比看"有多少时间噪声会淹没信号"。这些全部可以用计数、累加与排序这三类大一课程内最基础的算法完成。

本系统支撑的关键场景包括：① 水声实验前的海区背景噪声摸底与实验窗口选择；② 声呐检测性能预报中的噪声级输入估计；③ 港口与航道的船舶噪声长期监测；④ 海洋保护区噪声影响评估。学生在大一阶段就能用 C 语言把"分箱统计—累积分布—排序分位—阈值判定"这一统计处理链条完整跑通，为后续《水声学原理》《声呐技术》《随机信号分析》等课程建立直观基础。本题目与水声工程专业"海洋环境参数获取与处理"方向直接相关，训练学生把统计分析流程转化为"数据读入—算法实现—数据输出"完整程序工程的能力。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的海洋环境噪声等级评估系统：从文本文件读入噪声级时序（含采样时刻），实现数据有效性检查，按噪声级区间做频数统计形成直方图，计算累积分布，把样本排序后求 95% 分位数，统计超过给定阈值的样本占比，把序列按时段（昼 06:00～18:00 / 夜 18:00～06:00）分组比较均值，按教师给定的阈值表判定噪声等级（如安静/一般/嘈杂/强干扰四档），最后生成结果文件与屏幕直方图报表。

专业关联上，本题目复现了噪声监测业务中"分布统计—分位分析—等级判定"三类真实环节的核心计算。学生在此过程中将掌握课程中的循环与选择结构、数组统计、排序、指针传参与文件读写，并第一次体会"同一批数据从不同统计口径看会得到不同结论"，理解"一个统计分析流程如何变成一套程序"。

## 三、数据来源与格式

- **数据文件格式**：噪声级时序采用纯文本格式，首行为标题说明，其后每行一条记录，字段以空格分隔。字段依次为：采样时刻 t（单位：小时，自 0.0 起累计，24.0 表示第二天 0 点）、噪声级 L（单位：dB re 1 μPa）。仪器故障时段的噪声级字段填写缺失标记 `NaN`（或 `-1`）。

```
# time_hr   noise_dB
0.5         72.4
1.0         73.1
1.5         NaN
2.0         71.8
2.5         88.6
3.0         74.2
```

- **仿真数据生成规则**：
  - 时刻：从 0.0 起、步长 0.5 小时递增，总长 48～168 小时。
  - 真实噪声级：以约 70 dB 为底，叠加昼夜起伏（白天 +3～5 dB）、若干航船过境事件（每次持续 1～3 小时、抬升 10～20 dB）与随机小扰动（±1.5 dB）。
  - 缺失标记：随机注入 2%～5% 的 `NaN`（模拟仪器故障）。
  - **异常值注入方式**：由教师提供的生成程序人为注入三类错误。其一，噪声级为负数（如 `-5.0`）；其二，噪声级超出水听器量程（如超过 160 dB，判越界）；其三，时刻字段重复或非数字串导致 `fscanf` 错位。校验模块需输出"行号—异常类型—处理动作"清单。

- **真实数据集（如有）**：真实环境噪声资料可参考美国国家海洋大气署 NOAA 的海洋噪声监测项目与 NCEI 水声存档（https://www.ncei.noaa.gov/products/ocean-acoustic-data）。学生**无需下载**真实数据文件，课程提供与上述字段含义对应的简化仿真数据表；表中"噪声级"对应水听器在规定频段内测得的宽带噪声级。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_SAMPLE  400      /* 最多噪声采样点数 */
#define MAX_BIN     20       /* 最多直方图区间数 */
#define MISS        -9999.0  /* 缺失点内部标记值 */
#define MAX_GRADE   4        /* 噪声等级档数 */

/* ===== 噪声采样点 ===== */
struct NoisePoint {
    double t;                /* 采样时刻，单位：小时 */
    double level;            /* 噪声级，单位：dB；缺失时为 MISS */
    int    valid;            /* 有效标志：1 有效，0 异常/缺失 */
};

/* ===== 噪声等级阈值表项 ===== */
struct GradeRule {
    double upLimit;          /* 该档上界，单位：dB */
    char   name[12];         /* 档名，如 "安静" */
};

/* ===== 全局数据区 ===== */
struct NoisePoint g_np[MAX_SAMPLE];   /* 原始噪声序列 */
int               g_n;                /* 实际采样点数 */
double            g_binLo;            /* 直方图首区间下界，单位：dB */
double            g_binW;             /* 区间宽度，单位：dB */
int               g_binCount;         /* 区间个数 */
int               g_freq[MAX_BIN];    /* 各区间频数 */
double            g_cum[MAX_BIN];     /* 累积分布（累计占比） */
double            g_sorted[MAX_SAMPLE];/* 排序后的噪声级副本 */
double            g_th95;             /* 95% 分位数 */
double            g_overTh;           /* 超阈判定门限，单位：dB */
struct GradeRule  g_rule[MAX_GRADE];  /* 等级阈值表 */

/* ===== 处理日志（供报表模块使用） ===== */
struct LogItem {
    char  op[24];            /* 操作名，如 "HISTOGRAM" */
    char  detail[64];        /* 参数与关键结果摘要 */
};
struct LogItem g_log[MAX_BIN + 8];
int            g_logCount;         /* 已记录日志条数 */
```

辅助说明：噪声序列用结构体数组组织（课程 7.1/7.2），频数表与累积分布用一维 `int`/`double` 数组（课程 5.1），排序副本用指针参数传入排序函数（课程 6.2），等级阈值表用结构体数组由配置读入（课程 7.2），避免把档名硬编码进判断逻辑。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入与预处理（2 个模块）

**M1 噪声级时序读入模块**（源文件 `NoiseIO.c`）

- 功能简介：打开噪声级时序文本文件，跳过首行标题，用循环 + `fscanf` 逐行读入时刻与噪声级，填充 `g_np[]` 并记录点数；遇到 `NaN` 或 `-1` 时把噪声级置为 `MISS`；同时读入配置文件中的直方图区间参数与超阈门限；文件不存在时给出明确提示。
- 输入：文件路径（默认 `noise_obs.txt` 与 `noise_config.txt`）。
- 输出：`g_np[]`、`g_n`、直方图参数、`g_overTh`；返回成功/失败标志。

**M2 数据有效性检查模块**（源文件 `NoiseCheck.c`）

- 功能简介：逐条检查噪声级是否为负、是否超过水听器量程上限、时刻是否单调递增；对异常记录置 `MISS` 并生成"行号—异常类型—处理动作"清单打印；统计有效样本数。
- 输入：`g_np[]`、`g_n`、量程上限配置。
- 输出：屏幕校验报告；修正后的 `g_np[]`。

### 第二部分：统计与判定（5 个模块）

**M3 区间频数统计模块**（源文件 `NoiseStat.c`）

- 功能简介：对全部有效样本，按下标换算 $\text{bin} = \left\lfloor \dfrac{L - \text{binLo}}{\text{binW}} \right\rfloor$ 把每个噪声级归入对应区间并给 `g_freq[bin]` 加一（越出两端的样本归入最低/最高区间并计数）；统计区间设置是否合理（避免所有样本挤进一两个区间）。
- 输入：`g_np[]`、`g_binLo`、`g_binW`、`g_binCount`。
- 输出：`g_freq[]`；屏幕各区间频数表。

**M4 累积分布计算模块**（源文件 `NoiseStat.c`）

- 功能简介：按区间序号由低到高累加频数并除以有效样本总数，得到累积占比 `g_cum[]`；打印"区间上界—频数—累积占比"表，标注累积占比首次达到 50% 与 95% 的区间。
- 输入：`g_freq[]`、有效样本数。
- 输出：`g_cum[]`；屏幕累积分布表。

**M5 排序求分位数模块**（源文件 `NoiseSort.c`）

- 功能简介：把有效样本的噪声级复制到 `g_sorted[]`，用选择排序升序排列；第 $p$ 百分位数取第 $\lceil p \cdot N \rceil$ 个有序样本，求出 50% 位（中位数）与 95% 位 `g_th95`；用指针参数把两个分位数同时带回主流程。
- 输入：`g_np[]`、`g_sorted[]`。
- 输出：排序副本、`g_th95` 与中位数；屏幕分位数结论。

**M6 超阈值样本占比统计模块**（源文件 `NoiseStat.c`）

- 功能简介：遍历有效样本统计 $L > \text{overTh}$ 的样本数并计算占比，同时统计超过 95% 分位数的样本数做交叉核对；列出超阈样本的时刻清单（供对照航船过境事件）。
- 输入：`g_np[]`、`g_overTh`、`g_th95`。
- 输出：超阈占比与时刻清单；屏幕打印。

**M7 分时段均值比较模块**（源文件 `NoiseStat.c`）

- 功能简介：按时刻把样本分为昼（06:00～18:00）夜（18:00～06:00）两组，分别求均值与最大值，输出昼夜均值差；两组样本均同时计算极值，判断昼夜差异是否明显（差值超过 3 dB 记"明显"）。
- 输入：`g_np[]`。
- 输出：昼夜统计表与结论；屏幕打印。

### 第三部分：判定与输出（3 个模块）

**M8 噪声等级判定模块**（源文件 `NoiseGrade.c`）

- 功能简介：从配置读入等级阈值表（各档上界与档名），用序列均值与 95% 分位数分别查表判定等级，输出"均值判级"与"分位判级"两个结论；判级结果写入日志。
- 输入：`g_rule[]`、均值、`g_th95`。
- 输出：等级判定结论；屏幕打印。

**M9 结果文件输出模块**（源文件 `NoiseIO.c`）

- 功能简介：把频数表与累积分布按"区间—频数—累积占比"列写出到 `noise_hist.csv`；把分位数、超阈占比、昼夜比较与等级判定的完整报表写出到 `noise_report.txt` 便于核对。
- 输入：`g_freq[]`、`g_cum[]`、各统计结论。
- 输出：`noise_hist.csv`、`noise_report.txt`；屏幕确认信息。

**M10 屏幕直方图、报表与主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：用 `#` 字符按频数比例绘制噪声级直方图（横轴为噪声级区间、每格若干样本），在直方图上标注超阈门限位置；主菜单用 `do-while + switch` 调度 M1～M9，用状态标记约束"必须先读入并校验数据才能统计"。
- 输入：用户菜单选项、`g_freq[]`、`g_cum[]`。
- 输出：屏幕直方图与汇总报表；调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 进入菜单循环，先用状态标记 `g_loaded` 约束流程——未读入数据时只允许执行 M1；读入后依次可调用 M2 校验、M3～M7 统计分析、M8 判级、M9～M10 输出。任何统计模块要求至少有 10 个有效样本，否则提示补充数据。

**数据流**：

```
noise_obs.txt ─► M1 读入 ─► g_np[] ─► M2 有效性检查 ─► 有效样本
noise_config.txt ─► M1 读入 ─► g_binLo/g_binW/g_binCount/g_overTh
                                        │
        ┌───────────────┬───────────────┼────────────────┐
        ▼               ▼               ▼                ▼
  M3 区间频数统计  M5 排序求分位数  M6 超阈占比     M7 昼夜均值比较
        │ g_freq[]      │ g_th95        │               │
        ▼               │               │               │
  M4 累积分布计算        │               │               │
        │               └───────┬───────┴───────────────┘
        │                       ▼
        │                M8 噪声等级判定（g_rule[] 查表）
        │                       │
        └──────────┬────────────┘
                   ▼
        M9 结果文件输出          M10 屏幕直方图/报表 + 主控菜单
```

所有模块之间只通过全局采样数组、频数数组、分位数与函数参数交换数据，函数头部（接口）在编码前由全组书面约定。

## 十、选做扩展

1. **分箱宽度敏感性分析**：把区间宽度取 1、2、4 dB 三档分别重跑 M3～M4，输出"区间宽—直方图形态—峰值区间"对照，观察分箱过细（锯齿状）与过粗（细节丢失）的现象。
2. **滑动超阈时长统计**：按连续超阈段统计每次超阈事件的持续时间，输出"事件序号—起始时刻—持续时长"表，对照航船过境事件的典型时长。
3. **双时段判级对比**：把 M8 的判级分别对昼、夜两个子序列独立执行，输出昼夜各自的等级报表，观察同一阈值表下昼夜判级结果的差异。
