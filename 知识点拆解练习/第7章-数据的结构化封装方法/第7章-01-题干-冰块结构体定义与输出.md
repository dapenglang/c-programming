# 第 7 章 练习 01　冰块结构体定义与输出

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量）

**场景来源**：综合实验 C6《冰区航行冰块碰撞仿真系统》（水声学院）——本练习是该实验中"冰块参数建模与基本信息输出"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区航行的船舶随时可能与漂浮海冰发生碰撞。碰撞仿真程序（实验 C6）的第一步，是把每一块冰的完整信息"装"进计算机：编号是整数，长、宽、厚是实数，质量是计算得到的实数——不同类型的数据描述的是同一块冰。如果用十几个散装的平行变量来保存，三块冰就会有十几个变量名满天飞，极易把甲的长度配上乙的厚度。结构体正是解决这个问题的工具：把一块冰的全部属性封装成一个整体，仿真系统里"每块冰"就是这样一个结构体变量。

## 二、任务要求

编写一个完整程序 `ice_block.c`：

1. 按下面的框架定义结构体类型 `struct IceBlock`（成员名不得改动，可补充注释）：

```c
struct IceBlock {
    int    id;         /* 冰块编号 */
    double length;     /* 长（m） */
    double width;      /* 宽（m） */
    double thickness;  /* 厚（m） */
    double mass;       /* 质量（kg），由程序计算得到 */
};
```

2. 在 `main` 中用该类型定义**一个**结构体变量，从键盘读入编号与三个尺寸；
3. 按 $m = \rho_{ice}\,V$ 计算质量，其中海冰密度取 $\rho_{ice} = 917\ \mathrm{kg/m^3}$，体积 $V = 长 \times 宽 \times 厚$；
4. 按规定格式输出这块冰的完整信息（含所有结构体成员的值）。

## 三、输入输出格式

**输入**：一行，4 个数据，依次为编号（整数）、长、宽、厚（实数，单位米），以空格分隔。

**输出**：一行，按格式 `冰块 编号 号：长 x 宽 x 厚 m，体积 V m^3，质量 m kg` 输出，其中尺寸、体积、质量均保留 **2 位小数**。

## 四、样例

**样例 1**

输入：
```
3 2.0 1.5 0.6
```
输出：
```
冰块 3 号：2.00 x 1.50 x 0.60 m，体积 1.80 m^3，质量 1650.60 kg
```

**样例 2**

输入：
```
7 1.2 0.8 0.5
```
输出：
```
冰块 7 号：1.20 x 0.80 x 0.50 m，体积 0.48 m^3，质量 440.16 kg
```

## 五、提示

- 质量计算式：`b.mass = b.length * b.width * b.thickness * 917.0;`；
- 结构体类型定义**末尾的分号不能少**；
- 访问成员用点号：`b.id`、`b.length`；scanf 读成员时别忘了取地址：`&b.length`；
- 密度 917.0 建议定义为 `const double` 常量。

**完成本练习后你将具备的能力**：定义结构体类型、定义结构体变量、用点号访问成员、把"描述同一事物的不同类型数据"封装成一个整体并组织输出——这是实验 C6 中冰块对象建模的第一步。
