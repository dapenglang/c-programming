## 二、预备知识：二分法的基本原理（零基础阅读）

### 1. 问题是怎么来的

要求解 $x^3-x-1=0$。三次方程虽有公式解，但表达式冗长、还要处理复数根；像 $\cos x = x$ 这类**超越方程**更是根本没有初等求根公式。工程上的做法是求**近似根**：把方程写成

$$
f(x) = x^3 - x - 1 = 0 ,
$$

"求方程的根"就等价于"求函数 $f(x)$ 的零点"——即函数图象与 $x$ 轴的交点。二分法就是用来找这个零点的一种最简单可靠的办法。

### 2. 区间收缩原理：零点定理 + 反复折半

二分法的理论依据是**零点定理**：若函数 $f$ 在闭区间 $[a,b]$ 上连续，且两端**异号**，即 $f(a)\cdot f(b) < 0$，那么在 $(a,b)$ 内**至少存在一个**零点。道理很直观：函数图象从 $x$ 轴下方（负）画到上方（正），途中必然要穿过 $x$ 轴一次。

有了"区间必含零点"这个保证，就可以执行下面的循环：

1. 取区间的**中点** $m = \dfrac{a+b}{2}$；
2. 看 $f(m)$ 的符号：
   - 若 $f(a)\cdot f(m) \le 0$，说明零点在**左半区间** $[a,m]$，令 $b = m$；
   - 否则零点在**右半区间** $[m,b]$，令 $a = m$；
3. 每做一次，区间长度就**减半**。$n$ 次之后区间长度从 $(b_0-a_0)$ 缩到

$$
\frac{b_0-a_0}{2^n}.
$$

只要反复折半，区间迟早会短到可以忽略，其中的每一点都可以当作根的近似值。要让区间长度小于给定精度 `eps`，需要的对分次数约为

$$
n \approx \log_2 \frac{b_0-a_0}{\text{eps}} .
$$

例如 $b_0-a_0=1$、$\text{eps}=10^{-6}$ 时，$n \approx \log_2 10^6 \approx 20$ 次。

### 3. 代入本例走一遍

取区间 $[1,2]$，先验证异号：$f(1) = 1-1-1 = -1 < 0$，$f(2) = 8-2-1 = 5 > 0$，符合前提。前几轮对分如下：

| 第几次 | $a$ | $b$ | 中点 $m$ | $f(m)$ | 零点位置 |
|---|---|---|---|---|---|
| 1 | 1.000000 | 2.000000 | 1.500000 | +0.875000 | 左半，$b \leftarrow 1.5$ |
| 2 | 1.000000 | 1.500000 | 1.250000 | -0.296875 | 右半，$a \leftarrow 1.25$ |
| 3 | 1.250000 | 1.500000 | 1.375000 | +0.224609 | 左半，$b \leftarrow 1.375$ |
| 4 | 1.250000 | 1.375000 | 1.312500 | -0.051514 | 右半，$a \leftarrow 1.3125$ |
| … | … | … | … | … | … |
| 20 | — | — | — | — | 区间长度 $<10^{-6}$，停止 |

最终根约为 $1.324718$（它正是著名的"塑料数"）。可以回代检验：$1.324718^3 - 1.324718 - 1 \approx 0$，说明求得的近似根正确。

### 4. 编程时怎么翻译

把上面三步"翻译"成代码有三个要点：

- **函数分离**：把方程写成 `double f(double x)`，把"折半循环"写进 `double bisect(double a, double b, double eps)`。这样换个方程只改 `f`，求解器原样复用；
- **判据用区间长度**：循环条件是 `while (b - a > eps)`，因为二分法控制的是**自变量的误差**。写成"函数值足够小"并不稳妥（函数值大小与 $x$ 的误差不成正比）；
- **返回中点**：停止后返回 `(a + b) / 2`，它的误差不超过区间长度的一半，正好满足精度要求。

对分次数可以用一个"输出型"整型指针参数 `int *pn` 带回主函数，这种"一个函数返回一个值、再通过指针带回另一个值"的手法，正是第 6 章指针作参数的典型应用。

## 三、解题思路

1. **写 `f`**：直接返回 `x*x*x - x - 1`；
2. **写 `bisect`**：初始化 `n = 0`，`while (b-a > eps)` 中对分、判符号、收窄区间，并累计次数；
3. **带回次数**：用 `*pn = n;` 把次数写到主函数传进来的地址里；
4. **返回根**：`return (a+b)/2.0;`；
5. **`main`**：读入 `a`、`b`，调用 `bisect(a, b, 1e-6, &n)`，按格式输出。

## 四、参考代码

```c
#include <stdio.h>

/* 方程左端：f(x) = x^3 - x - 1 */
double f(double x)
{
    return x * x * x - x - 1.0;
}

/* 二分法：在 [a,b] 内求 f(x)=0 的根，|b-a|<eps 时停止；
   对分次数通过指针 pn 带回 */
double bisect(double a, double b, double eps, int *pn)
{
    double m;
    int n = 0;

    while (b - a > eps) {
        m = (a + b) / 2.0;              /* 取中点 */
        n++;
        if (f(a) * f(m) <= 0.0)         /* 零点在左半区间 */
            b = m;
        else                            /* 零点在右半区间 */
            a = m;
    }
    *pn = n;                            /* 通过指针返回对分次数 */
    return (a + b) / 2.0;               /* 返回区间中点作为近似根 */
}

int main(void)
{
    double a, b, root;
    int n = 0;

    scanf("%lf %lf", &a, &b);           /* 读入区间端点 */
    root = bisect(a, b, 1e-6, &n);
    printf("root = %.6f, n = %d\n", root, n);

    return 0;
}
```

## 五、运行验证

**样例 1**（输入 `1 2`，区间长度 1）：程序按上表对分，第 20 次时 $b-a < 10^{-6}$，停止，输出

```
root = 1.324718, n = 20
```

**样例 2**（输入 `1 1.5`，区间长度 0.5）：起始区间更短，$0.5/2^{19} = 9.5\times10^{-7} < 10^{-6}$，只需 19 次，输出

```
root = 1.324718, n = 19
```

两个样例的根完全相同（因为根只有一个），次数相差一次（因为初始区间长短差一倍），与样例输出一致。

## 六、常见错误与讲解

**错误 1：区间两端同号就贸然二分**

二分法的**前提是两端异号**。本题 $f(1)<0$、$f(2)>0$ 恰好满足；若换方程时没先检查符号，区间内可能根本没有根，程序会收敛到一个无意义的点。

**错误 2：收敛判据写成函数值足够小**

```c
while (fabs(f(m)) > eps) { … }   /* 不稳妥 */
while (b - a > eps) { … }         /* 对：以区间长度为准 */
```
函数值小不等于自变量离根近（例如曲线很平的地方，$f$ 很小但 $x$ 误差可能很大）。二分法控制的是**自变量区间宽度**，应判 `b - a`。

**错误 3：循环里忘记更新端点**

```c
while (b - a > eps) {
    m = (a + b) / 2.0;
    n++;                          /* 错：没有 b=m 或 a=m，区间不变，死循环 */
}
```
每次对分必须真正收窄区间，否则 `b - a` 恒大于 `eps`，程序卡死。

**错误 4：端点更新方向写反**

```c
if (f(a) * f(m) <= 0.0) a = m;   /* 错：异号说明零点在左半，应令 b=m */
if (f(a) * f(m) <= 0.0) b = m;   /* 对 */
```
异号意味着零点落在 $[a,m]$ 内，所以要保留左半、把右端点 `b` 移到 `m`。方向写反会收敛到区间的错误一侧。

## 七、与综合实验的衔接

实验 **C8《冰区船舶浮力与吃水计算系统》**的核心环节，就是把"浮力 = 重力"这一平衡条件整理成一个关于吃水 $d$ 的非线性方程，再用二分法反求 $d$。二分法最大的优点是**稳健**：只要区间包住根就必定收敛，不像牛顿法那样怕初值不当；缺点是收敛慢（每次只把误差减半）。工程上常先用二分法把根"圈"进一个小区间，再用牛顿法快速精修。本题把"方程 `f`"与"求解器 `bisect`"彻底分开，还练了用指针带回对分次数，为下一题（练习 18）做铺垫——下一题将把冰块参数组织成**结构体**传进二分求解器，让求解过程更贴近真实的工程数据。
