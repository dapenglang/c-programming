# 第 8 章 练习 17　拉格朗日插值原理实现

**对应章节**：8 数据持久化存储方法（8.6 拉格朗日插值）；另用到第 5 章 5.1 一维数组、8.4 文件的读写

**场景来源**：教材 8.6 节"拉格朗日插值"核心例题（多点插值原理），呼应综合实验 D3《核数据截面查值系统》（核学院）——本练习是 D3 插值模块从"两点线性插值"推广到"多点插值"的原理实现。

**建议用时**：30～40 分钟

## 一、应用场景

第 2 章学过**两点线性插值**：已知两个点，中间取直线比例。但工程表格往往不止两档——核数据手册中的反应截面随能量变化是一条曲线，只取两个点插值误差太大，规范做法是取**多个节点**构造一条光滑多项式穿过全部节点。这条多项式怎么构造？答案就是**拉格朗日插值**。本练习用一组可以精确验证的数据（抛物线 $y = x^2$ 上的三个点）实现三点拉格朗日插值：既然三个点来自抛物线，插值结果应当**精确还原**原函数——这是检验插值程序写没写对的最好试金石。

## 二、任务要求

编写完整程序 `lagrange.c`：

1. 以 `"r"` 方式打开数据文件 `points.txt`，**检查返回值**，失败时输出提示并结束（返回值 1）；
2. **数据文件格式约定**：第一行是节点个数 n（整数，$2 \le n \le 10$），其后 n 行每行两列、空格分隔——节点横坐标 $x_i$ 与纵坐标 $y_i$（均为实数）；
3. 把 n 个节点读入两个一维 double 数组 `x[10]`、`y[10]`，关闭文件；
4. 从键盘读入待求点 `xq`（double 类型）；
5. 用拉格朗日插值公式（外层循环对每个节点 $i$ 构造基函数值，内层循环连乘）计算 $P(x_q)$，按 `P(%.2f) = %.4f` 的格式输出到屏幕。

**数据文件样例数据行**：第一行 `3`，其后 `1 1`、`2 4`、`3 9`（即抛物线 $y=x^2$ 上的三个点）。

## 三、输入输出格式

**输入文件**：`points.txt`（第一行 n，其后 n 行两列）。

**键盘输入**：一行，一个实数，表示待求点 xq。

**屏幕输出**：一行，`P(xq) = 结果`，xq 保留 2 位小数、结果保留 4 位小数。

## 四、样例

**输入文件 points.txt 的内容**：

```
3
1 1
2 4
3 9
```

**样例 1**

键盘输入：
```
2.5
```
屏幕输出：
```
P(2.50) = 6.2500
```
（$2.5^2 = 6.25$，插值精确还原了抛物线。）

**样例 2**

键盘输入：
```
1.5
```
屏幕输出：
```
P(1.50) = 2.2500
```
（$1.5^2 = 2.25$，同样精确还原。）

## 五、提示

- 拉格朗日插值公式：$P(x) = \sum_{i=0}^{n-1} y_i \, L_i(x)$，其中基函数

$$
L_i(x) = \prod_{j=0,\, j \neq i}^{n-1} \frac{x - x_j}{x_i - x_j}
$$

- 编程翻译成**双重循环**：外层 `for (i = 0; i < n; i++)` 算每一项 $y_i L_i(x)$，循环外把各项累加；内层 `for (j = 0; j < n; j++)` 当 `j != i` 时把 $\dfrac{x_q - x_j}{x_i - x_j}$ 连乘到一个临时变量 `t`（初值必须为 1.0）；
- 每算完一个 $L_i$，`t` 必须**重新置 1.0**——这是本程序最常见的错误来源；
- 本例三个节点恰好来自 $y = x^2$，任意三次以下多项式被三个点唯一确定，所以插值结果应与 $x^2$ 完全一致，可用来逐项手算核对（见配套讲解）。

**完成本练习后你将具备的能力**：把一个带连乘、连加记号的数学公式逐层翻译成双重循环、理解拉格朗日基函数"在自己节点为 1、在别的节点为 0"的构造思想——这是实验 D3 截面查值模块（以及第 18 题声速剖面插值）的算法内核。
