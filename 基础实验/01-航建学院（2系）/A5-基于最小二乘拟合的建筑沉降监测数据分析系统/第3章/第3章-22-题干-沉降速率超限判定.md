# 第 3 章 练习 22　沉降速率超限判定

**所属综合实验**：A5（A5-基于最小二乘拟合的建筑沉降监测数据分析系统）

**对应章节**：3 程序控制结构（3.1 顺序结构、3.2 循环结构、3.3 选择结构——`if`/`else`、多分支）

**场景来源**：综合实验 A5《基于最小二乘拟合的建筑沉降监测数据分析系统》（航建学院）——本练习是该实验中"沉降速率超限报警"环节的最小实现。

**建议用时**：20～30 分钟

## 一、应用场景

高层建筑和桥梁在施工期必须做沉降监测：每隔一段时间用水准仪测一次各观测点的高程，算出相邻两期之间的**沉降速率**（单位：mm/天）。规范对沉降速率有控制值：超过控制值就说明地基可能失稳，需要停工或采取加固措施。

设某观测点第 $i$ 期与第 $i+1$ 期的沉降量之差为 $\Delta s_i$（mm，取正值表示下沉），两期间隔 $\Delta t$ 天，则第 $i$ 段沉降速率为

$$
v_i = \frac{\Delta s_i}{\Delta t}\ \ (\text{mm/天})
$$

监测员每天拿到一批新数据，都要逐点判断：这段沉降速率是否超限？超限的点要不要标记出来？这就是 A5 系统里"逐点超限判定"要做的事。

## 二、任务要求

编写一个完整程序 `settle_rate.c`：

1. 程序内用**常量**存放沉降速率控制值 `LIMIT = 0.15`（mm/天，规范控制值）；
2. 从键盘读入时段数量 `n`（整数，**题目保证 1 ≤ n ≤ 20**）；
3. 循环读入 `n` 个沉降速率值 $v_i$（mm/天，实数），**逐点判断**：
   - 若 $v_i > \text{LIMIT}$，输出 `warning: 超限`；
   - 否则输出 `normal: 正常`；
4. 统计并输出超限点的个数。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，为各时段沉降速率（mm/天），用空格分隔。

**输出**：先输出 n 行判定结果，每行形如 `第i段 v=数值 结论`（速率保留 3 位小数）；最后一行输出超限段数 `exceed = 个数`。

## 四、样例

**样例 1**

输入：
```
5
0.12 0.16 0.09 0.20 0.15
```
输出：
```
第1段 v=0.120 normal: 正常
第2段 v=0.160 warning: 超限
第3段 v=0.090 normal: 正常
第4段 v=0.200 warning: 超限
第5段 v=0.150 normal: 正常
exceed = 2
```

**样例 2**

输入：
```
4
0.05 0.30 0.18 0.10
```
输出：
```
第1段 v=0.050 normal: 正常
第2段 v=0.300 warning: 超限
第3段 v=0.180 warning: 超限
第4段 v=0.100 normal: 正常
exceed = 2
```

## 五、提示

判定条件是"严格大于"控制值：

$$
v_i > \text{LIMIT} \Rightarrow \text{超限}
$$

用 `if`/`else` 实现：

```c
if (v > LIMIT) {
    printf("warning: 超限\n");
    cnt++;              /* 只有超限时才计数 */
} else {
    printf("normal: 正常\n");
}
```

注意 $v_i = 0.15$ 时**不算**超限（等于控制值不触发报警）。计数变量 `cnt` 同样要先赋初值 0，且只能在超限分支里自增。

**完成本练习后你将具备的能力**：用 `if`/`else` 表达二选一判断、在分支内做累加计数、把物理规范里的"超过控制值报警"翻译成程序里的条件语句。
