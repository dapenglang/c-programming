## 二、预备知识：递归是什么、基线条件与调用栈（零基础阅读）

### 1. 递归是什么

**递归（recursion）就是函数在它的函数体里调用它自己。** 听起来像"自己要吃自己"，但数学上很多量天生是"自己定义自己"的。阶乘就是典型：

$$
n! = n \times (n-1)!
$$

要算 $5!$，就要先算 $4!$；要算 $4!$，又要先算 $3!$……这样一路把问题变小。

### 2. 基线条件：递归的"刹车"

如果一直"变小"下去：$5!\to4!\to3!\to2!\to1!\to0!\to(-1)!\to\cdots$，永远停不下来。所以必须规定一个**不再递归、直接给出答案的最小情形**，这就是**基线条件**：

$$
0! = 1 \quad(\text{约定}),\qquad 1! = 1
$$

在代码里写成 `if (n <= 1) return 1;`。基线条件是递归的"刹车"，**没有它，函数会无限自我调用，直到把调用栈撑爆而崩溃**。

### 3. 递推关系：把大问题拆成一模一样的小问题

基线之上，用 `return n * factorial(n - 1);` 表达递推。注意关键点：**`factorial(n-1)` 的形式与 `factorial(n)` 完全一样**，只是规模小了一号。递归的美妙之处就在于——你不用关心 $4!$ 具体怎么算，只要假设"它会算对"，把它当成一个普通函数来用就行。

### 4. 调用栈展开：用本题数据看 4! 怎么算

求 `factorial(4)` 时，计算机会把每次调用"压栈"，先一路深入，再一路返回（把本题数据代入）：

```text
factorial(4)  需要 4 * factorial(3)   ── 挂起，等 3! 
  factorial(3)  需要 3 * factorial(2)   ── 挂起，等 2!
    factorial(2)  需要 2 * factorial(1)   ── 挂起，等 1!
      factorial(1)  命中基线，直接返回 1        （最深处）
    factorial(2) = 2 * 1 = 2      ── 返回 2
  factorial(3) = 3 * 2 = 6        ── 返回 6
factorial(4) = 4 * 6 = 24         ── 返回 24
```

**深入**时每层都记住"我拿到下一层结果后还要乘什么"；**返回**时逐层把这个乘法补上。规律是"先进后出"：`factorial(1)` 最先返回，`factorial(4)` 最后返回。整个过程像把一摞盘子叠起来再逐个取下。

### 5. 编程要点

- 返回类型用 `long long`，因为 $13!$ 就超过了 `int` 的表示上限（约 $2.1\times10^9$）；打印用 `%lld`；
- 乘法里写 `(long long)n * factorial(n-1)`，确保按 64 位整数运算。

## 三、解题思路

1. **定接口**：`long long factorial(int n)`，输入整数、返回长整型；
2. **写原型**：放在 `main` 上方；
3. **写基线**：`if (n <= 1) return 1;`——先想清楚"到哪停"；
4. **写递推**：`return (long long)n * factorial(n - 1);`；
5. **主流程**：读 `n` → 调用 → 打印。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：返回 n 的阶乘 */
long long factorial(int n);

int main(void)
{
    int n;
    scanf("%d", &n);                              /* 读入 n */
    printf("%d! = %lld\n", n, factorial(n));      /* 递归求阶乘并输出 */
    return 0;
}

/* 递归函数：计算 n! */
long long factorial(int n)
{
    if (n <= 1)                                   /* 基线条件：0! = 1! = 1 */
        return 1;
    else                                          /* 递推关系：n! = n * (n-1)! */
        return (long long)n * factorial(n - 1);
}
```

## 六、常见错误与讲解

**错误 1：忘记写基线条件（死递归）**

```c
long long factorial(int n)
{
    return (long long)n * factorial(n - 1);   /* 错：n 一直减小，永不停，栈溢出崩溃 */
}
```

**基线条件是递归函数的第一要务**。写递归时先问自己："最小的情形是什么？答案是多少？"

**错误 2：递推方向写反**

```c
return (long long)n * factorial(n + 1);   /* 错：n 越来越大，永远到不了基线 */
```

参数必须**朝基线方向**递减（本题是 `n-1`）。

**错误 3：用 `int` 承载大数导致溢出**

```c
int factorial(int n);              /* 当 n = 13 时 13! = 6227020800 已溢出 */
long long factorial(int n);        /* 对：用 64 位整数 */
```

**错误 4：打印格式与类型不匹配**

```c
printf("%d! = %d\n", n, factorial(n));    /* 错：long long 用 %d 打印会得到乱码 */
printf("%d! = %lld\n", n, factorial(n));  /* 对：%lld 对应 long long */
```

## 七、与综合实验的衔接

- 在实验 **B3（蒙特卡洛随机模拟系统）**中，阶乘是排列数 $A_n^k=\dfrac{n!}{(n-k)!}$ 与组合数的零件，概率计算、随机抽样都要用到它。本练习把阶乘封装成递归函数，正是为这些公式提供现成的计算单元；
- 递归不只用于数学：实验 B4 的**深度优先搜索（DFS）迷宫求解**、实验 A2/C8 中树形结构的遍历，本质都是递归。**把阶乘这一步走扎实——想清基线、写对递推、看懂调用栈——后面所有递归问题都会变得有迹可循。**
