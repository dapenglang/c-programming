## 二、预备知识：结构体的基本原理（零基础阅读）

### 1. 问题是怎么来的：为什么要打包

假设一个采样点有 3 条信息：序号、时刻、数值。不用结构体时，只能开三个数组：

```c
int    ids[100];
double times[100];
double values[100];
```

这样做有两个麻烦：

1. **容易对不上号**：第 5 个采样点的信息分散在三个数组的第 5 格，一旦某个数组同步出错，数据就张冠李戴；
2. **不便于传递**：想把"一个采样点"传给函数，得同时传三个参数。

**结构体的作用就是"打包"**：把这几条信息捆在一起，让它们永远待在一起、一起移动、一起传递。

### 2. 结构体是一种"类型"，不是变量

这一点最容易混淆。看两行代码：

```c
struct Sample { int id; double time; double value; };  /* 定义类型 */
struct Sample s;                                        /* 定义变量 */
```

- 第一行 `struct Sample { ... }` 是**造模具**：它规定"采样点"这种类型由哪些成员组成，但**不占内存**（只是告诉编译器以后怎么摆数据）；
- 第二行 `struct Sample s;` 是**用模具压出一个实物**：这个变量才真正占内存。

打个比方：`struct Sample` 是"一张图纸"，`s` 是按图纸造出来的"一个零件"。图纸可以有无数张用途，但零件才是实际存在的东西。

### 3. 结构体在内存里是怎么摆的

结构体的内存是**把成员依次摆好**。`struct Sample` 的内存布局大致如下（`int` 占 4 字节、`double` 占 8 字节）：

```
偏移:   0        4        8           16
        [ id ]   (填充)   [ time      ][ value     ]
        int              double        double
```

一共约 16～24 个字节（具体对齐方式由编译器决定），三块内容紧挨在一起，这就是"打包成整体"的含义。

### 4. 点号：打开包装取出某一件

要拿结构体里的某一块，用**点号** `.`：

```
s . id          s . time          s . value
```

读法就是"s 的 id 成员"。它和"柜子里的柜子"是一个道理：`s` 是一个大柜子，`.id` 是打开大柜子后取里面的"id 小抽屉"。点号左边是结构体变量，右边是成员名。

**注意**：点号只能用于**变量**。若拿到的是指针，要用箭头 `->`（这属于更深的内容，本题用不到）。

### 5. 用本例走一遍

输入 `1 0.001 3.30`：

- `s.id = 1`；
- `s.time = 0.001`；
- `s.value = 3.30`。

输出时按格式拼接：

```
Sample #1 @0.001s value = 3.30V
```

时刻用 `%.3f` 得到 `0.001`，数值用 `%.2f` 得到 `3.30`，与样例一致。

> **这个思想在综合实验中反复出现**：B2 采样点、B5 导航节点（名称、坐标、距离）、B9 任务（编号、截止时间、耗时）、B6 词条（单词、词频），都是"把相关数据打包成一个整体"同一个套路。

## 三、解题思路

1. **定义类型**：写 `struct Sample { int id; double time; double value; };`（注意结尾有分号）；
2. **定义变量**：`struct Sample s;`；
3. **读入**：`scanf("%d %lf %lf", &s.id, &s.time, &s.value);`（每个成员都要取地址）；
4. **输出**：`printf` 里用 `s.id`、`s.time`、`s.value`，配合 `%d`、`%.3f`、`%.2f`。

## 四、参考代码

```c
#include <stdio.h>

/* 定义结构体类型：一个采样点包含序号、时刻、数值 */
struct Sample {
    int    id;      /* 采样序号 */
    double time;    /* 采样时刻，单位：秒 */
    double value;   /* 采样数值，单位：伏 */
};

int main(void)
{
    struct Sample s;    /* 定义该类型的结构体变量 */

    /* 读入三个成员：注意每个成员前面都要取地址 & */
    scanf("%d %lf %lf", &s.id, &s.time, &s.value);

    /* 输出：用点号访问各成员，控制小数位数 */
    printf("Sample #%d @%.3fs value = %.2fV\n",
           s.id, s.time, s.value);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `1 0.001 3.30` | id=1, time=0.001, value=3.30 | `Sample #1 @0.001s value = 3.30V` ✓ |
| `5 0.005 2.75` | id=5, time=0.005, value=2.75 | `Sample #5 @0.005s value = 2.75V` ✓ |
| `100 1.500 5.00` | id=100, time=1.500, value=5.00 | `Sample #100 @1.500s value = 5.00V` ✓ |

各成员按格式正确落位，说明点号访问和格式串都写对了。

## 六、常见错误与讲解

**错误 1：结构体类型定义末尾漏分号（最典型）**

```c
struct Sample { int id; double time; double value; }   /* 错：漏了分号 */
struct Sample { int id; double time; double value; };  /* 对 */
```

这个分号错误会引发一串莫名其妙的报错，务必检查。

**错误 2：把类型名当变量名用**

```c
scanf("%d", &Sample.id);    /* 错：Sample 是类型，不是变量 */
scanf("%d", &s.id);         /* 对：s 才是变量 */
```

**错误 3：读入时漏了取地址符**

```c
scanf("%d %lf %lf", s.id, s.time, s.value);     /* 错：缺少 & */
scanf("%d %lf %lf", &s.id, &s.time, &s.value);  /* 对 */
```

**错误 4：输入格式符与成员类型不符**

```c
scanf("%d %d %d", &s.id, &s.time, &s.value);    /* 错：time、value 是 double */
scanf("%d %lf %lf", &s.id, &s.time, &s.value);  /* 对 */
```

`int` 成员用 `%d`，`double` 成员用 `%lf`。
