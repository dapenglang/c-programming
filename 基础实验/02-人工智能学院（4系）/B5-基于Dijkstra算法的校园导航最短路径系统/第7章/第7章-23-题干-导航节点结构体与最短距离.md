# 第 7 章 练习 23　导航节点结构体与最短距离

**所属综合实验**：B5（B5-基于Dijkstra算法的校园导航最短路径系统）

**对应章节**：7 构造数据类型（7.1 结构体类型定义、7.4 结构体数组、7.3 成员访问、5.1 一维数组、3.3 循环结构）

**场景来源**：综合实验 B5《基于 Dijkstra 算法的校园导航最短路径系统》（人工智能学院）——本练习是该实验中"节点距离管理"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

校园导航系统把校园里每个地点（教学楼、食堂、图书馆……）当作一个**节点**，节点之间由道路连接，道路的长度就是**边权**。计算从起点到各点的最短路径之前，系统要维护一张表：每个节点叫什么名字、当前从起点到它已知的最短距离是多少、这个距离是不是已经确定了。

这张表天然就是一个**结构体数组**：每一项把"节点名"和"距离"打包在一起。B5 系统的距离表就长这样。

## 二、任务要求

编写一个完整程序 `nav_node.c`：

1. 定义结构体类型
   ```c
   struct Node {
       char   name[16];   /* 节点名称 */
       int    dist;       /* 当前已知的最短距离（从起点算起） */
       int    fixed;      /* 是否已确定：1 已定，0 未定 */
   };
   ```
2. 从键盘读入节点个数 `n`（$1 \le n \le 8$）；
3. 读入 $n$ 个节点：每个节点的名称和从起点算起的最短距离（本题假设距离都已算好、全部已确定）；
4. 遍历结构体数组，找出**距离起点最远**（`dist` 最大）的节点，输出它的名称和距离；
5. 再输出全部节点的名称与距离。

## 三、输入输出格式

**输入**：
第一行，一个整数 n；
接下来 n 行，每行一个字符串（节点名）和一个整数（距离），用空格分隔。

**输出**：
第一行，按格式 `farthest: 名称 距离` 输出最远节点；
接下来 n 行，每行按格式 `名称: 距离` 输出全部节点（按读入顺序）。

## 四、样例

**样例 1**

输入：
```
3
lib 250
canteen 120
gym 480
```
输出：
```
farthest: gym 480
lib: 250
canteen: 120
gym: 480
```

**样例 2**

输入：
```
2
gate 0
dorm 90
```
输出：
```
farthest: dorm 90
gate: 0
dorm: 90
```

## 五、提示

结构体里的**字符数组成员** `name[16]` 可以直接用 `scanf("%s", ...)` 读入，不需要取地址符——因为数组名本身就是地址：

```c
scanf("%s %d", nd[i].name, &nd[i].dist);
```

找最远节点就是"遍历数组找最大值"，和第 6 章练习 21 的直方图峰值分析一模一样，只是这次比较的成员是 `nd[i].dist`：

$$
\text{若 } nd[i].dist > maxdist,\ \text{则更新 } maxdist \text{ 与最远节点名}
$$

**完成本练习后你将具备的能力**：在结构体中用字符数组成员存字符串、通过下标访问结构体数组成员、遍历结构体数组求极值——这些是实验 B5 中"距离表管理模块"的地基。
