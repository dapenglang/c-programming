# 第 8 章 练习 06　阻力数组二进制写入

**对应章节**：8 数据持久化存储方法（8.3 文件的打开与关闭、8.4 文件的读写——`fwrite`）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷数组的二进制保存"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区船舶载荷辨识系统一次试验会产生成千上万个阻力采样值，如果按文本逐行保存，每个数占十几个字节，文件又大、读起来又慢。工程上常把整个数组以**二进制**方式一次性存盘：一个 `double` 固定占 8 字节，原样写入，文件紧凑、读写极快，下次直接读回内存即可继续计算。本练习把一个阻力数组以二进制写入文件 `loads.bin`，并报告写入了多少个数据、文件共多少字节。

## 二、任务要求

编写一个完整程序 `save_binary.c`：

1. 从键盘读入一个整数 $n$，表示阻力值的个数（题目保证 $1 \le n \le 100$）；
2. 随后读入 $n$ 个实数，存入 `double` 数组；
3. 以二进制写模式打开文件 `loads.bin`，并检查是否成功；先把 $n$（一个整数）写进文件开头，再把整个数组一次性写入；
4. 用 `ftell` 得到文件当前总字节数，输出"写入了几个值、文件共多少字节"；关闭文件。

**数据文件格式约定**

- 文件名：`loads.bin`
- 文件为**二进制文件**，不能用普通文本编辑器阅读
- 文件开头是 1 个整数 $n$（记录个数），紧接着是 $n$ 个 `double` 型的阻力值，连续存放，**没有分隔符、没有换行**
- 逻辑内容示例（并非文本，仅示意字节含义）：先 4 字节存整数 3，再依次存 3 个 8 字节的实数

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个实数，以空格分隔（本题不要求分行，空格分隔即可）。

**输出**：屏幕输出一行 `已写入 X 个阻力值，文件共 Y 字节`，其中 `X` 是 $n$，`Y` 是文件总字节数；数据写入文件 `loads.bin`。

## 四、样例

**样例 1**

输入：
```
5
12.5 18.3 9.75 21.0 15.5
```
屏幕输出：
```
已写入 5 个阻力值，文件共 44 字节
```
（说明：$4$ 字节存整数 $n=5$，$5 \times 8 = 40$ 字节存 5 个 `double`，合计 $44$ 字节。）

**样例 2**

输入：
```
3
10.0 20.0 30.0
```
屏幕输出：
```
已写入 3 个阻力值，文件共 28 字节
```
（说明：$4 + 3 \times 8 = 28$ 字节。）

## 五、提示

- 二进制写用 `fp = fopen("loads.bin", "wb")`，模式串里的 `b` 表示 binary（二进制）；
- `fwrite` 的四个参数依次是：数据起始地址、单个元素的字节数、元素个数、文件指针。写整数用 `fwrite(&n, sizeof(int), 1, fp);`，写数组用 `fwrite(a, sizeof(double), n, fp);`；
- 写数组时第一个参数直接写数组名 `a` 即可，它代表数组首元素的地址；
- `ftell(fp)` 返回文件位置指针当前所在字节偏移，刚写完时它就等于文件总字节数；
- 二进制文件请务必用 `"wb"` 打开（而不是 `"w"`），读写才能与后续练习 07 的回读严格对应。

**完成本练习后你将具备的能力**：理解文本文件与二进制文件的区别、用 `wb` 模式打开二进制文件、用 `fwrite` 把变量与整个数组一次性写入文件、用 `ftell` 检查文件大小——这是实验 C7 中"批量数据高速存盘"的基础。
