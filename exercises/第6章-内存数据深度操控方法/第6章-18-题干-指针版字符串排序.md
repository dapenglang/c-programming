# 第 6 章 练习 18　指针版字符串排序

**对应章节**：6 内存数据深度操控方法（6.4 指针与字符串、6.6 指向指针的指针——排序时交换指针而非内容）

**场景来源**：综合实验 B10《基于编辑距离的文本相似度计算系统》（人工智能学院）——本练习是该实验中"词条字典序排序"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本相似度系统常把一批词条按字典序排好，方便展示与查找。排序时有两种做法：一是把字符串**内容**整体搬来搬去，长字符串一来一回开销很大；二是给每条字符串配一个指针，排的是**指针**——比较用 `strcmp`，交换时只交换两个地址（各 4 或 8 字节），字符串本体原地不动。显然后者又快又稳。要对调指针数组里的两个元素，函数接收指针数组的地址（二级指针），在内部用 `s[i]`、`s[j]` 完成交换。本练习实现这个"交换指针"的字符串排序函数。

## 二、任务要求

编写一个完整程序 `sort_str_ptr.c`：

1. 主函数读入词条数 `n`（题目保证 $1 \le n \le 10$），再读入 `n` 个不含空格的字符串（长度 < 50）存入 `char buf[10][50]`，并建立**指针数组** `char *s[10]`，令 `s[i]` 指向 `buf[i]`；
2. 编写函数，其原型为 `void sort_str(char *s[], int n);`，用 `strcmp` 按字典序升序排序；排序过程中**只交换指针数组里的元素（即交换指针），绝不搬动字符串内容**；
3. 主函数调用后，按排序结果逐行输出字符串。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；接下来 `n` 行，每行一个不含空格的字符串。

**输出**：`n` 行，按字典序升序排列的字符串，每行一个。

## 四、样例

**样例 1**

输入：
```
3
gamma
alpha
delta
```
输出：
```
alpha
delta
gamma
```

**样例 2**

输入：
```
3
ICE-02
ICE-01
ICE-03
```
输出：
```
ICE-01
ICE-02
ICE-03
```

## 五、提示

- 字典序比较用标准库函数 `int strcmp(const char *a, const char *b);`（需 `#include <string.h>`）：返回值 $<0$ 表示 `a` 在 `b` 前，$=0$ 表示相等，$>0$ 表示在后；
- 交换两个字符串指针与交换两个整数完全同构：`char *t = s[i]; s[i] = s[j]; s[j] = t;`
- 用冒泡排序结构即可：两重循环，若 `strcmp(s[j], s[j+1]) > 0` 就交换 `s[j]` 与 `s[j+1]`。

**完成本练习后你将具备的能力**：能对字符串数组排序、理解"交换指针"与"交换内容"的本质区别、熟练运用指针数组与二级指针——这是本章 6.4、6.6 节的综合运用。
