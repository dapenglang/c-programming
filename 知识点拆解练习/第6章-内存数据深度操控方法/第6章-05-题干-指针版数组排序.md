# 第 6 章 练习 05　指针版数组排序

**对应章节**：6 内存数据深度操控方法（6.2 指针变量的定义与使用、6.3 指针与数组；为 6.5 指针与函数中"指针作参数"打基础）

**场景来源**：综合实验 C7《冰区船舶载荷统计与辨识系统》（水声学院）——本练习是该实验中"冰载荷序列排序（模块 M8）"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

载荷统计系统 C7 在输出统计报表前，需要把一段冰载荷序列**从小到大排序**，以便绘制分布图、计算分位数（如前 10% 大载荷）。第 5 章你已用下标写过冒泡排序；本练习要求把排序函数升级为**指针版**：函数形参只收一个指针 `double *a` 与长度 `n`，函数内部比较、交换、遍历**全部用指针写法**完成。排序结束后，主函数输出有序序列。这一版排序函数将原样进入实验 C7 的 M8 模块。

## 二、任务要求

编写一个完整程序 `load_sort.c`：

1. 编写函数 `void bubble_sort(double *a, int n)`：对 `a` 指向的 `n` 个元素做冒泡排序（升序），内部只用指针写法（`*(a + j)`、`a + j` 等），不得出现 `[ ]` 下标；
2. 编写或复用练习 02 的 `void swap(double *x, double *y)` 完成相邻元素交换；
3. 主函数读入 5 个冰载荷值（kN），调用 `bubble_sort` 后按升序输出（保留 2 位小数）；
4. 排序必须**就地完成**（直接改原数组），不得另开第二个数组。

## 三、输入输出格式

**输入**：一行，5 个实数（kN），以空格分隔。

**输出**：一行，升序排列的 5 个值，空格分隔，保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
320.5 180.2 455.8 267.4 390.1
```
输出：
```
180.20 267.40 320.50 390.10 455.80
```

**样例 2**

输入：
```
100.0 99.5 100.5 99.0 101.0
```
输出：
```
99.00 99.50 100.00 100.50 101.00
```

## 五、提示

1. 冒泡排序框架（指针版）：外层 $n-1$ 趟，内层第 $i$ 趟比较到"末尾倒数第 $i$ 个"为止；
2. 相邻元素用指针表达：`*(a + j)` 是左邻，`*(a + j + 1)` 是右邻；若 `*(a + j) > *(a + j + 1)` 则调用 `swap(a + j, a + j + 1)`；
3. 传相邻元素地址：`a + j` 本身就是地址，**前面不要再加 `&`**；
4. 内层终止位置的指针写法：让 `q` 从 `a` 走到 `a + n - i - 1` 为止，保证最大值每趟"冒泡"到未排序区间的末端。

**完成本练习后你将具备的能力**：写出"只凭指针与长度就能工作"的通用排序函数、把指针算术用于两两比较与就地交换——实验 C7 报表模块 M8 的完整核心，也是练习 06 查找函数的前置训练。
