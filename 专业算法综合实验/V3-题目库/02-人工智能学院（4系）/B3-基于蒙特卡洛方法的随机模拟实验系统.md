# 题目 B3：基于蒙特卡洛方法的随机模拟实验系统

**适用学院**：人工智能学院（4 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**1）系统是做什么的**：本系统用随机数模拟两类经典实验——"向单位正方形内随机撒点，统计落在四分之一圆内的比例来估算圆周率 π"，以及"布丰投针：把针随机投向等距平行线，由相交频率估算 π"；系统自动进行多轮实验（模拟次数从 100 逐级放大到 1000000），记录每轮估计值与真值的误差，最后画出误差随模拟次数变化的收敛曲线。

**2）它解决了什么重要问题**：很多问题难以用解析公式直接求解，但可以通过"大量随机试验 + 频率统计"得到近似答案。蒙特卡洛方法把"计算难题"转化为"重复试验"，本系统用最直观的几何例子说明：随机模拟的结果为什么可靠、误差为什么随试验次数增大而减小（与 1/√N 成正比）。不掌握这种思想，学生面对高维积分、复杂概率问题时就会缺少最基本的求解工具。

**3）它支撑哪些关键应用**：① 数值积分与高维体积计算；② 工程可靠性/风险评估（如工期、结构失效概率）；③ 粒子输运与辐射屏蔽模拟；④ 排队与调度系统的随机仿真；⑤ 计算机图形学中的光线追踪与随机采样。这些应用的共同内核就是"随机采样 + 频率统计"，本系统是它的最小可运行入门模型。

**4）与专业培养的关联**：对应人工智能学院"数据挖掘/计算智能"方向，随机模拟与概率统计是理解抽样、估计、收敛等概念的基础。本系统让学生在大一用 C 语言实现随机数封装、频率统计与误差分析，建立"随机实验 = 循环 + 判断 + 计数"的直觉，为后续概率统计与优化算法课程打基础，全程不涉及任何机器学习理论。

## 二、题目任务与专业关联

本题目要求小组用 C 语言多文件工程实现上述随机模拟系统。程序需支持：实验参数（模拟次数、随机种子、布丰参数）读入、随机数封装与均匀性检验、撒点法估算 π、布丰投针模拟、多轮实验主循环、误差收敛记录、收敛曲线字符画、实验报告输出、结果解读提示与主控菜单。全组需完成 10 个模块，总代码 900~1200 行，每人 2~3 个模块。题目训练"函数封装 + 循环 + 随机数 + 文件"，并把"用频率近似概率"的计算思维带进人工智能专业学习。

## 三、数据来源与格式

### 3.1 数据文件格式

系统运行前需准备实验参数文件 `mc_config.txt`，首行为 `#` 开头的说明行：

```

# 第1行：随机种子 seed（整数）
# 第2行：实验轮数 roundCount（1~12）
# 第3行起：每行一个模拟次数 N（严格递增，建议每轮×10）
# 末行：布丰参数 L D M（针长 线距 每轮投掷次数，实数）
20261003
6
100
1000
10000
100000
1000000
10000000
0.8 1.0 1000000
```

说明：`L` 为针长，`D` 为平行线间距，要求 `L < D`；`M` 为布丰实验每轮投掷次数。用 `fscanf(fp, "%u", &seed)` 等逐个读入。

### 3.2 仿真数据生成规则

本系统数据由程序内部生成，规则如下：

| 字段 | 单位 | 取值范围 | 生成规则 |
|---|---|---|---|
| seed 随机种子 | — | 1~2^31-1 | 任意整数，`srand(seed)` |
| N 模拟次数 | 次 | 100~10000000 | 严格递增，每轮 ×10 |
| 撒点坐标 x, y | — | [0,1) | `rand()/(double)RAND_MAX` |
| 针中点 y0 | — | [0, D) | 均匀随机 |
| 针倾角 θ | rad | [0, π/2) | 均匀随机 |
| 命中判据 | — | — | 撒点法：x²+y² ≤ 1；投针法：y0 ≤ (L/2)·sinθ 或 y0 ≥ D-(L/2)·sinθ |

**异常值注入与边界测试**（用于检验参数录入模块）：

1. 把某轮 N 写成比上一轮小（非递增）；
2. 把 `L` 写成 `1.5`、`D` 写成 `1.0`（违反 L<D）；
3. 把 `roundCount` 写成 `0` 或 `20`（超出 1~12）；
4. 把 `seed` 写成 `0`（提示建议用非零种子）。

### 3.3 真实数据集

本题不依赖外部数据集；如需了解随机数质量检验，可参考 NIST 随机数测试套件（仅作了解）：https://csrc.nist.gov/projects/random-bit-generation 。

## 四、数据结构设计

```c
#define ROUND_MAX  12      /* 最大实验轮数 */
#define BUCKET     10      /* 均匀性检验分桶数 */

struct RoundResult {       /* 每轮实验记录 */
    long   n;              /* 本轮模拟次数 N，100~10000000 */
    double piPoint;        /* 撒点法 π 估计值 */
    double piBuffon;       /* 布丰投针 π 估计值 */
    double errPoint;       /* 撒点法绝对误差 |估计-π| */
    double errBuffon;      /* 布丰绝对误差 */
};

struct RoundResult g_round[ROUND_MAX];
int    g_roundCnt;         /* 实验轮数，1~ROUND_MAX */
unsigned int g_seed;       /* 随机种子 */
double g_L, g_D;           /* 布丰针长 L、线距 D，L<D */
long   g_M;                /* 布丰每轮投掷次数 */
int    g_bucket[BUCKET];   /* 均匀性检验计数桶 */
```

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入与基础计算（4 个模块）

**M1 实验参数录入模块**（源文件 `McConfig.c`）
- 功能简介：从 `mc_config.txt` 读入随机种子、实验轮数、各轮模拟次数与布丰参数，逐项检查合法性（N 递增、轮数 1~12、L<D、seed≠0），不合法时给出提示并要求修正或退出。
- 输入：参数文件路径。
- 输出：`g_seed`、`g_roundCnt`、`g_round[].n`、`g_L`、`g_D`、`g_M`。
- 接口示例：`int LoadConfig(const char *path);`

**M2 随机数封装与均匀性检验模块**（源文件 `RandomUtil.c`）
- 功能简介：封装 `MyRand01()`（返回 [0,1) 均匀实数）与 `MyRandInt(a,b)`；并做均匀性检验——生成 1000000 个随机数投入 10 个区间统计频次，打印各桶计数与偏离均匀值的百分比。
- 输入：`g_seed`、检验次数。
- 输出：`g_bucket[BUCKET]`；屏幕均匀性检验表。
- 接口示例：`double MyRand01(void);` / `void UniformTest(int bucket[], int n);`

**M3 撒点法估算圆周率模块**（源文件 `PiPoint.c`）
- 功能简介：在单位正方形内随机撒 N 个点，统计落在四分之一圆（x²+y²≤1）内的点数，用 4×命中数/N 估算 π 并返回估计值。
- 输入：模拟次数 N。
- 输出：π 估计值（double）。
- 接口示例：`double PiByPoint(long n);`

**M4 布丰投针模拟模块**（源文件 `PiBuffon.c`）
- 功能简介：针长为 L、平行线间距为 D，随机生成针中点位置与倾角，按判据统计相交次数，用 2·L·M/(D·相交数) 估算 π（相交数为 0 时返回 -1 标记无效）。
- 输入：投掷次数 M、`g_L`、`g_D`。
- 输出：π 估计值（double，-1 表示失败）。
- 接口示例：`double PiByBuffon(long m, double L, double D);`

### 第二部分：算法实现（2 个模块）

**M5 多轮实验主循环模块**（源文件 `Experiment.c`）
- 功能简介：按配置的轮数与各轮 N，逐轮调用 M3、M4 得到两种 π 估计值并填入手写 `g_round[]`；每轮完成后打印当前进度与估计值。
- 输入：`g_roundCnt`、`g_round[].n`、`g_L`、`g_D`、`g_M`。
- 输出：更新 `g_round[]` 的估计值字段。
- 接口示例：`void RunExperiment(void);`

**M6 误差收敛记录模块**（源文件 `Experiment.c`）
- 功能简介：以 π 真值（3.141592653589793）为基准，计算每轮两种方法的绝对误差与相对误差填入 `g_round[]`，并计算"误差×√N"看其是否近似稳定，从而验证误差与 1/√N 成正比。
- 输入：`g_round[]`、`g_roundCnt`。
- 输出：更新误差字段；屏幕误差表。
- 接口示例：`void CalcError(void);`

### 第三部分：数据输出（4 个模块）

**M7 收敛曲线字符画模块**（源文件 `PlotConv.c`）
- 功能简介：横轴为模拟次数（取对数刻度），纵轴为绝对误差，用 `*` 画撒点法误差、用 `+` 画布丰法误差，另用 `-` 画出理论参考线 1/√N 的趋势，让收敛过程可视化。
- 输入：`g_round[]`、`g_roundCnt`。
- 输出：屏幕字符收敛曲线。
- 接口示例：`void PlotConvergence(void);`

**M8 实验报告输出模块**（源文件 `Report.c`）
- 功能简介：把每轮的 N、两种估计值、绝对误差、相对误差、误差×√N 写成表格 `mc_report.csv`（首行列名），供实验报告引用。
- 输入：`g_round[]`、`g_roundCnt`。
- 输出：`mc_report.csv`。
- 接口示例：`int SaveReport(const char *path);`

**M9 结果解读提示模块**（源文件 `Report.c`）
- 功能简介：根据误差表自动生成文字结论，如"模拟次数每增大 10 倍，误差约减小到原来的 1/√10≈0.32"，并比较两种方法在同一 N 下的精度差异，提示布丰法的随机误差来源更多。
- 输入：`g_round[]`、`g_roundCnt`。
- 输出：屏幕结论文字。
- 接口示例：`void InterpretResult(void);`

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读参数 / 均匀性检验 / 撒点法 / 投针法 / 多轮实验 / 误差记录 / 收敛曲线 / 写报告 / 结果解读 / 退出），`do-while + switch` 调度，未读参数前禁止运行实验。
- 输入：用户菜单选项。
- 输出：调度各模块。
- 接口示例：`int main(void);`

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → switch 分发到 M1~M9 → 回菜单直到退出。状态约束：必须先执行 M1 才能做实验；M5 内部依赖 M3、M4；M6 必须在 M5 之后、M7~M9 之前。

**数据流**：

```
mc_config.txt ─► M1 参数录入 ─► g_seed / g_round[].n / g_L / g_D / g_M
                                    │
              ┌─────────────────────┼──────────────────────┐
              ▼                     ▼                      ▼
     M2 随机数封装与均匀性检验   M3 撒点法估算 π   M4 布丰投针模拟
              │                     └────────┬─────────────┘
              ▼                              ▼
         g_bucket[BUCKET]            M5 多轮实验主循环 ─► g_round[]
                                             │
                                             ▼
                                    M6 误差收敛记录 ─► g_round[].err*
                                             │
                     ┌───────────────┬───────┴────────┐
                     ▼               ▼                ▼
              M7 收敛曲线字符画  M8 实验报告输出  M9 结果解读提示
```
