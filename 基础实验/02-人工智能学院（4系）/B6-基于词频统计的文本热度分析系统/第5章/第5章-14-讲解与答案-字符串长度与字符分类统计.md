## 二、预备知识：字符数组、`'\0'` 结尾与逐字符扫描（零基础阅读）

### 1. 字符串在内存里到底是什么

C 语言没有专门的"字符串类型"，一段文本就是一条**字符数组**：

```c
char s[100];
```

这申请了 100 个字节，每个字节存一个字符。如果你输入 `abc`，内存看起来是：

$$
s[0]='a',\quad s[1]='b',\quad s[2]='c',\quad s[3]='\textbackslash 0',\quad s[4]\sim s[99]\ \text{闲置}
$$

注意 `s[3]` 存的不是空格，而是**结束标志 `'\0'`**（反斜杠加 0，读作"空字符"，编码值为 0）。

### 2. `'\0'` 为什么必不可少

数组 `s[100]` 有 100 个格子，可你输入的可能只有 3 个字符。程序怎么知道"字符串到哪儿为止"？——靠 `'\0'` 这个**哨兵**。凡是字符串相关操作，都必须**从头扫到 `'\0'` 就停**，绝不能扫满 100 格。这也解释了为什么容量 100 的数组最多只能存 **99 个字符**：必须留一格给 `'\0'`。

用 `scanf("%s", s)` 输入时，系统会自动在末尾补上 `'\0'`；这就是为什么读字符数组**不加 `&`**（数组名 `s` 已经是首地址），也是为什么它一遇到空格就停（空格被视为分隔符）。

### 3. 读入"含空格的一整行"

本题的文本里有空格，用 `%s` 会一遇空格就断。这时用 scanf 的**扫描集（scanset）**：

```c
scanf("%[^\n]", s);   /* 读入从当前位置到换行符之前的所有字符 */
```

`%[^\n]` 的意思是"接收任何不是换行符的字符，直到遇见换行符停止"，系统同样会自动补 `'\0'`。这样 `Ice-2024 Model #7` 才能整行读进来。

### 4. 逐字符扫描是本章的通用范式

对一条字符串做任何统计，模板都是"**设一个下标 i 从 0 开始，while 循环的条件是 `s[i] != '\0'`，循环体里处理 `s[i]`，最后 `i++`**"：

```c
int i = 0;
while (s[i] != '\0') {
    ... 处理字符 s[i] ...
    i++;
}
```

循环自然终止于 `'\0'`，根本不需要事先知道字符串有多长。本题的"长度"就是循环体执行的次数，用一个计数器边扫边加即可，不必单独再数一遍。

### 5. 字符其实就是小整数——所以能用范围比较

在第 2 章我们提过：`char` 本质上是整数，存的是字符的 ASCII 编码。`'A'` 是 65、`'Z'` 是 90、`'a'` 是 97、`'z'` 是 122、`'0'` 是 48、`'9'` 是 57，且大小写字母、数字在编码表里都是**连续排列**的。因此判断类别可以直接比较范围：

- 大写字母：`c >= 'A' && c <= 'Z'`
- 小写字母：`c >= 'a' && c <= 'z'`
- 数字：`c >= '0' && c <= '9'`
- 空格：`c == ' '`
- 以上都不是 → 归入"其他"（标点、符号等）

判断的顺序用 if-else 链：前面都不满足时，落到最后的 `else` 归为"其他"。四类计数用四个 `int` 计数器，再加一个 `len` 记总长度，五次判断各加各的，互不干扰。

## 三、解题思路

1. **定数组**：`char s[100];`（容量 100，最多 99 个字符 + `'\0'`）；
2. **读一整行**：`scanf("%[^\n]", s);`；
3. **准备五个计数器**：`len, letter, digit, space, other`，全部初始化为 0；
4. **逐字符扫描**：`while (s[i] != '\0')`，用 if-else 链判断 `s[i]` 属于哪一类并对应计数器加 1，随后 `len++`、`i++`；
5. **输出**：按固定五行格式打印各计数器的值。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    char s[100];                    /* 存放一行文本，容量 100 */
    int len = 0;                    /* 字符总数 */
    int letter = 0, digit = 0;      /* 字母、数字个数 */
    int space = 0, other = 0;       /* 空格、其他字符个数 */
    int i = 0;

    scanf("%[^\n]", s);             /* 读入含空格的一整行（不加 &） */

    /* 从下标 0 扫到 '\0' 为止 */
    while (s[i] != '\0') {
        char c = s[i];
        if ((c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z'))
            letter++;               /* 字母 */
        else if (c >= '0' && c <= '9')
            digit++;                /* 数字 */
        else if (c == ' ')
            space++;                /* 空格 */
        else
            other++;                /* 其他可见字符 */

        len++;                      /* 长度 = 扫描过的字符个数 */
        i++;
    }

    printf("长度 = %d\n", len);
    printf("字母 = %d\n", letter);
    printf("数字 = %d\n", digit);
    printf("空格 = %d\n", space);
    printf("其他 = %d\n", other);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：漏掉 `'\0'`，循环条件写错**

```c
while (s[i] != 0) ...      /* 对：'\0' 的编码就是 0，两种写法等价 */
while (i < 100) ...        /* 错：会扫进 '\0' 之后的垃圾字节，统计错误 */
for (i = 0; i <= strlen(s); i++) ...  /* 错：把 '\0' 也当成一个字符统计 */
```

以 `'\0'` 为终止条件是唯一正确的做法；用 `i < 容量` 或 `<= 长度` 都会把结束标志或垃圾数据误当成字符。

**错误 2：读入一整行却用了 `%s`**

```c
scanf("%s", s);          /* 错：遇到空格就停，只读到 "Ice-2024" */
scanf("%[^\n]", s);      /* 对：读到换行为止，整行都进来 */
```

**错误 3：判断类别时范围写反或漏掉小写**

```c
if (c >= 'A' || c <= 'Z') ...              /* 错：条件几乎恒为真，逻辑完全错 */
if (c >= 'a' && c <= 'z') ...              /* 对：小写字母单独判断 */
```

判断字母要**同时**满足"大于等于下界"且"小于等于上界"，两个条件用 `&&` 连接，大写、小写各判一次、用 `||` 合并。

**错误 4：`scanf` 读字符数组时多写了 `&`**

```c
scanf("%[^\n]", &s);     /* 错：s 已经是地址，再加 & 语义出问题 */
scanf("%[^\n]", s);      /* 对：数组名本身就代表首地址 */
```
