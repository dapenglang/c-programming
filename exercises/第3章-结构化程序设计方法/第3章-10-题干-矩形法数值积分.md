# 第 3 章 练习 10　矩形法数值积分（循环 + 积分）

**对应章节**：3 结构化程序设计方法（3.3 循环结构——for 循环、3.5 数值积分——矩形法）

**场景来源**：综合实验 D5《γ 射线剂量率评估系统》（核学院）——本练习是该实验中"累积剂量估算"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

核设施发生一次性泄漏后，监测点记录到的 γ 射线剂量率随时间不断下降（源衰减、大气扩散共同作用）。工程上常用经验模型描述这一衰减：

$$
D(t) = \frac{D_0}{(1 + k t)^2}
$$

其中 $D_0$ 是初始剂量率（μGy/h），$k$ 是衰减常数（1/h）。决策人员真正关心的是**累积剂量**——剂量率在 $0 \sim T$ 时段内的积分，它决定人员是否需要在掩蔽所停留。与练习 09 不同，这里的被积函数有解析表达式，程序可以**按任意细的分割直接对函数求积**，这正是矩形法数值积分：把区间等分成 n 小格，每格用一个小矩形近似，累加所有矩形面积。

## 二、任务要求

编写一个完整程序 `rect_integral.c`：

1. 从键盘按顺序读入 4 个数：初始剂量率 `D0`（μGy/h）、衰减常数 `k`（1/h）、积分时段 `T`（h）、分割数 `n`（整数，**题目保证 $1 \le n \le 10^6$**）；
2. 用**左端点矩形法**计算 $0 \sim T$ 内的累积剂量：把区间 $[0, T]$ 等分为 n 格，每格宽 $\Delta t = T/n$，第 $i$ 格（$i = 0 \sim n-1$）取左端点 $t_i = i \cdot \Delta t$ 处的函数值 $D(t_i)$ 作矩形高，面积为 $D(t_i) \cdot \Delta t$，累加全部 n 格；
3. 注意：不允许调用数学库函数（`pow` 等），$D(t)$ 的分母 $(1+kt)^2$ 直接用两次乘法实现；
4. 按格式输出累积剂量，保留 4 位小数。

## 三、输入输出格式

**输入**：一行，4 个数 D0、k、T、n，以空格分隔（n 为整数）。

**输出**：一行，格式为 `dose = 累积剂量`，保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
8.0 0.5 10 1000
```
输出：
```
dose = 13.3723
```

**样例 2**

输入：
```
8.0 0.5 10 10000
```
输出：
```
dose = 13.3372
```
（同样的被积函数，分割加密到 10000 格，结果更接近真值 13.3333）

## 五、提示

左端点矩形法的骨架：

```c
dt = T / n;
s = 0.0;
for (i = 0; i <= n - 1; i = i + 1) {
    t = i * dt;                       /* 第 i 格的左端点 */
    s = s + D0 / ((1.0 + k * t) * (1.0 + k * t));   /* 高：D(t) */
}
s = s * dt;                           /* 最后统一乘上宽 */
```

循环变量从 0 数到 n−1，恰好 n 格；矩形的"宽"在循环外乘一次即可，不必每格乘一遍。

**完成本练习后你将具备的能力**：对解析函数实现矩形法数值积分、理解分割数 n 对精度的影响、掌握"循环变量从 0 开始"的格点编号约定——这是实验 D5 累积剂量模块的完整实现。
