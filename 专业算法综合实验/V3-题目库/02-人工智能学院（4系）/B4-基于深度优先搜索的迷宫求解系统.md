# 题目 B4：基于深度优先搜索的迷宫求解系统

**适用学院**：人工智能学院（4 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**1）系统是做什么的**：本系统读入一个用字符表示的二维迷宫地图（`#` 表示墙、`.` 表示通路、`S` 起点、`G` 终点），先把它显示出来，然后分别用深度优先搜索（DFS，走不通就回退）和广度优先搜索（BFS，一层一层向外扩展）从起点搜索到终点，回溯出完整路径并比较两种方法找到的路径长度；系统还能逐帧播放搜索过程，并对多张迷宫批量统计步数。

**2）它解决了什么重要问题**：在机器人路径探索、游戏寻路、地图导航中，如何在"已知环境地图"里找到一条从起点到终点的可行路径，是最基本的搜索问题。DFS 会尽量往深处走、走不通就回退，能找到路径但不保证最短；BFS 会均匀地向外扩散，能找到最短路径。理解这两种搜索的差异，是理解更复杂路径规划算法的前提。若不会搜索，"让智能体自己找路"就无从谈起。

**3）它支撑哪些关键应用**：① 机器人与无人车的栅格地图寻路；② 电子游戏中的 NPC 寻路与关卡连通性判断；③ 网络爬虫与连通分量分析；④ 迷宫/数独类问题的求解；⑤ 更复杂路径规划算法（如 A*、Dijkstra）的基础。DFS/BFS 是这些技术的共同起点。

**4）与专业培养的关联**：对应人工智能学院"智能控制与机器人"方向，路径探索与规划是机器人自主移动的核心能力之一。本系统让学生在大一用 C 语言亲手实现栈、队列与两种图搜索，建立"搜索 = 状态扩展 + 访问标记 + 回溯"的直觉，为后续人工智能导论、机器人规划课程打基础，全程只用到数组、循环/递归与字符处理。

## 二、题目任务与专业关联

本题目要求小组用 C 语言多文件工程实现上述迷宫求解系统。程序需支持：迷宫地图文件读入、迷宫字符画显示、数组栈实现、数组队列实现、DFS 探索主循环、路径回溯与记录、BFS 最短路径对照、探索过程逐帧动画、多迷宫批量测试报表与主控菜单。全组需完成 10 个模块，总代码 900～1200 行，每人 2～3 个模块。题目综合训练"文件 + 二维字符数组 + 结构体 + 函数"，并把"搜索与回溯"的计算思维带进人工智能专业学习。

## 三、数据来源与格式

### 3.1 数据文件格式

采用纯文本字符网格格式，首行以 `#` 开头的说明行在读入时跳过：

```
# 迷宫文件 v1：第一行为 行数 列数，其后为字符网格
5 9
#########
#S..#...#
#.#.#.#.#
#...#.#G#
#########
```

字符含义：`#` 墙（不可通行）、`.` 通路、`S` 起点（有且仅有一个）、`G` 终点（有且仅有一个）。用 `fscanf(fp, "%s", line)` 逐行读入字符数组即可。

### 3.2 仿真数据生成规则

| 字段 | 单位 | 取值范围 | 生成规则 |
|---|---|---|---|
| rows 行数 | 格 | 5～51 | 奇数优先，便于生成规则迷宫 |
| cols 列数 | 格 | 5～51 | 奇数优先 |
| 墙 `#` | — | — | 用"递归回溯挖路法"生成连通迷宫 |
| 通路 `.` | — | — | 与墙互补 |
| 起点 `S` / 终点 `G` | — | — | 分别放在两个随机通路格 |

**迷宫生成建议（连通迷宫）**：先把所有格子置为墙，从 (1,1) 出发随机选一个方向前进两格挖成通路，走不动就回退（可用递归或栈），直到所有可达格都挖通。此过程只用到数组与随机数。

**异常值注入**（用于检验读入与校验，每张迷宫注入 1～2 类）：

1. 缺少 `S` 或缺少 `G`（提示"地图非法"）；
2. `G` 被墙完全包围、不可达（DFS/BFS 应报告"无解"）；
3. 出现非法字符（如 `X`、`0`），读入时提示并当墙处理；
4. 网格行长度不一致（某行少一个字符），提示"行宽不符"；
5. 尺寸越界（如 60×60，超过 51 上限）。

### 3.3 真实数据集

迷宫生成与求解是经典问题，可参考公开迷宫基准（仅作了解）：https://movingai.com/benchmarks/maze/ 。

## 四、数据结构设计

```c
#define ROW_MAX  51
#define COL_MAX  51
#define STK_MAX 4096        /* 栈/队列容量，4×51×51 足够 */

struct Point {              /* 网格坐标 */
    int r;                  /* 行号，0~rows-1 */
    int c;                  /* 列号，0~cols-1 */
};

struct Maze {
    int  rows;                        /* 行数 5~51 */
    int  cols;                        /* 列数 5~51 */
    char cell[ROW_MAX][COL_MAX];      /* '#'墙 '.'通路 'S'起点 'G'终点 */
    int  sx, sy;                      /* 起点坐标 (行,列) */
    int  gx, gy;                      /* 终点坐标 (行,列) */
};

struct Maze  g_maze;                  /* 当前迷宫 */
struct Point g_stack[STK_MAX];        /* 数组栈，用于 DFS */
int          g_top;                   /* 栈顶指针，-1 表示空 */
struct Point g_queue[STK_MAX];        /* 数组队列，用于 BFS */
int          g_head, g_tail;          /* 队头、队尾指针 */

int  g_visited[ROW_MAX][COL_MAX];     /* 访问标记 0=未访 1=已访 */
int  g_prevR[ROW_MAX][COL_MAX];       /* 前驱行，-1 表示无 */
int  g_prevC[ROW_MAX][COL_MAX];       /* 前驱列，-1 表示无 */
struct Point g_path[STK_MAX];         /* 回溯出的路径序列 */
int  g_pathLen;                       /* 路径长度（含起点终点） */
```

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（4 个模块）

**M1 迷宫地图文件读入模块**（源文件 `MazeIO.c`）
- 功能简介：跳过说明行，读入行数与列数，再逐行读入字符网格；扫描出 `S`、`G` 的坐标，检查是否各存在一个、行列是否越界、尺寸是否超过 51，非法时给出提示。
- 输入：迷宫文件路径（默认 `maze1.txt`）。
- 输出：填充 `g_maze`；返回 0 成功 / -1 失败。
- 接口示例：`int LoadMaze(const char *path, struct Maze *m);`

**M2 迷宫字符画显示模块**（源文件 `MazeIO.c`）
- 功能简介：把迷宫网格按行打印，墙用 `#`、通路用空格、起终点用 `S`/`G`；若传入路径数组，则用 `*` 覆盖路径经过的格子，直观显示求解结果。
- 输入：`g_maze`、可选路径数组与长度。
- 输出：屏幕字符画。
- 接口示例：`void ShowMaze(const struct Maze *m, const struct Point path[], int len);`

**M3 数组栈实现模块**（源文件 `StackArr.c`）
- 功能简介：用一维数组实现后进先出的栈，提供压入、弹出、判空、取栈顶四个操作，并做溢出保护；供 DFS 使用。
- 输入：`struct Point` 元素。
- 输出：修改 `g_stack` 与 `g_top`。
- 接口示例：`void StackInit(void);` / `int StackPush(struct Point p);` / `int StackPop(struct Point *p);` / `int StackEmpty(void);`

**M4 数组队列实现模块**（源文件 `QueueArr.c`）
- 功能简介：用一维数组实现先进先出的循环队列，提供入队、出队、判空三个操作，并做队满保护；供 BFS 使用。
- 输入：`struct Point` 元素。
- 输出：修改 `g_queue`、`g_head`、`g_tail`。
- 接口示例：`void QueueInit(void);` / `int QueuePush(struct Point p);` / `int QueuePop(struct Point *p);` / `int QueueEmpty(void);`

### 第二部分：算法实现（3 个模块）

**M5 DFS 探索主循环模块**（源文件 `Search.c`）
- 功能简介：把起点压栈并标记已访问，循环取栈顶、按"上右下左"顺序尝试四个方向的未访问通路邻居，能走则压栈并记录前驱，走不动则弹栈回退，直到到达终点或栈空（无解）。
- 输入：`g_maze`。
- 输出：`g_visited`、`g_prevR`、`g_prevC`；返回是否找到终点。
- 接口示例：`int DfsSearch(void);`

**M6 路径回溯与记录模块**（源文件 `Search.c`）
- 功能简介：从终点沿 `g_prevR`/`g_prevC` 前驱数组一步步回退到起点，把坐标按"起点→终点"顺序存入 `g_path`，并统计路径长度；无解时输出提示。
- 输入：`g_prevR`、`g_prevC`、终点坐标。
- 输出：`g_path`、`g_pathLen`。
- 接口示例：`int BuildPath(struct Point path[], int *len);`

**M7 BFS 最短路径对照模块**（源文件 `Search.c`）
- 功能简介：把起点入队并标记，循环出队、扩展未访问邻居并记录前驱，逐层向外扩散直至到达终点；随后同样用前驱数组回溯路径，输出 BFS 路径长度并与 DFS 结果对照。
- 输入：`g_maze`。
- 输出：BFS 的 `g_visited`、前驱与路径；屏幕路径长度对照。
- 接口示例：`int BfsSearch(void);`

### 第三部分：数据输出（3 个模块）

**M8 探索过程逐帧动画模块**（源文件 `Animate.c`）
- 功能简介：每扩展若干格（如每 20 格）刷新一次屏幕，用不同字符表示"已访问""当前路径""尚未访问"，把 DFS 或 BFS 的扩散过程逐帧播出；支持按键暂停或直接连续播放。
- 输入：`g_maze`、搜索过程记录。
- 输出：屏幕逐帧字符画。
- 接口示例：`void AnimateSearch(int mode);`

**M9 多迷宫批量测试报表模块**（源文件 `Report.c`）
- 功能简介：从文件读入迷宫文件名清单，逐个调用 M1、M5、M7 求解，记录每张迷宫的尺寸、DFS 路径长度、BFS 路径长度、是否可达与访问格数，写入 `maze_report.csv` 并在屏幕汇总。
- 输入：迷宫清单文件。
- 输出：`maze_report.csv`；屏幕批量报表。
- 接口示例：`int BatchTest(const char *listPath, const char *outPath);`

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读迷宫 / 显示 / DFS / BFS / 回溯路径 / 动画 / 批量测试 / 写报表 / 退出），`do-while + switch` 调度，未读迷宫前禁止搜索。
- 输入：用户菜单选项。
- 输出：调度各模块。
- 接口示例：`int main(void);`

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → switch 分发到 M1～M9 → 回菜单直至退出。状态约束：M2～M9 前必须先执行 M1；M5 与 M7 都会重置 `g_visited`；M6 必须在 M5 或 M7 之后执行。

**数据流**：

```
迷宫文件 ─► M1 读入 ─► g_maze (字符二维数组 + 起终点坐标)
                          │
                          ▼
                    M2 字符画显示
                          │
          ┌───────────────┼────────────────┐
          ▼               ▼                ▼
   M3 数组栈        M4 数组队列        g_visited / g_prev
          │               │                │
          ▼               ▼                │
   M5 DFS 主循环    M7 BFS 对照模块         │
          └───────┬───────┘                │
                  ▼                        │
          M6 路径回溯 ─► g_path / g_pathLen
                  │
       ┌──────────┼───────────┐
       ▼          ▼           ▼
  M8 逐帧动画  M9 批量报表   M2 显示带路径迷宫
```
