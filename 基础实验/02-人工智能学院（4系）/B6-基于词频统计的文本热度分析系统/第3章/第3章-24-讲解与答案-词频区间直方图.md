## 二、预备知识：直方图与分档统计的基本原理（零基础阅读）

### 1. 问题是怎么来的

一列原始数据（比如 20 个词的词频）看起来是一堆零散的数字，很难一眼看出规律。**直方图**就是把这些数字按大小分成若干"档"，统计每档里有多少个数——用几个计数结果，概括整列数据的分布形状。

本题只分三档，是最简单的直方图，只有三个区间、三个计数。

### 2. 分档边界是怎么定的

分档的边界靠经验确定，本题用：

- 低频：$f \le 2$，意思是"只出现一两次的词"，多为偶然出现的词；
- 中频：$3 \le f \le 9$，正常出现的词；
- 高频：$f \ge 10$，反复出现的关键词。

三档互不重叠、也无遗漏，任意词频必落在其中一档。因此必有：

$$
low + mid + high = n
$$

这个等式是验算的利器。

### 3. 判定顺序为什么重要

用 `if-else if-else` 时，第二个条件只需写 `f <= 9`。原因和上一题一样：程序走到第二个判断时，已经知道第一个条件 `f <= 2` 不成立，也就是 $f \ge 3$ 了。所以 `f <= 9` 实际表达的是 $3 \le f \le 9$。这种**层层筛选**的写法简洁又不漏。

### 4. 用本例走一遍

**例 1**：词频序列 $1, 2, 5, 8, 12$。

- $1 \le 2$ → low（$low=1$）；
- $2 \le 2$ → low（$low=2$）；
- $5$：不 $\le 2$，但 $\le 9$ → mid（$mid=1$）；
- $8$：$\le 9$ → mid（$mid=2$）；
- $12$：不 $\le 9$ → high（$high=1$）。

结果 $low=2,\ mid=2,\ high=1$，校验 $2+2+1=5=n$ ✓。

**例 2**：词频序列 $3, 10, 10, 1, 7, 20$。

- $3 \to mid$（$mid=1$）；
- $10 \to high$（$high=1$）；
- $10 \to high$（$high=2$）；
- $1 \to low$（$low=1$）；
- $7 \to mid$（$mid=2$）；
- $20 \to high$（$high=3$）。

结果 $low=1,\ mid=2,\ high=3$，校验 $1+2+3=6=n$ ✓。

### 5. 编程时怎么用它

三个计数器先归零，循环里每读一个词频就判断归类：

```c
int low = 0, mid = 0, high = 0, f;
for (i = 0; i < n; i++) {
    scanf("%d", &f);
    if (f <= 2)       low++;
    else if (f <= 9)  mid++;
    else              high++;
}
```

**注意**：如果先把所有词频读进数组再统计，会占更多内存；本题只需"边读边统计"，用不着保存原始数据，这也是直方图统计常用的省内存做法。

> **这个思想在综合实验中反复出现**：B6 词频分档、B1 灰度分级统计、B9 任务优先级分布，都是"分区间计数"同一个套路。

## 三、解题思路

1. **读入 n**：`scanf("%d", &n);`；
2. **初始化三个计数器**：`low = mid = high = 0;`；
3. **循环读取并归类**：每次都读一个词频 `f`，用 `if-else if-else` 判定；
4. **输出**：三条 `printf` 分别输出三档计数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n;                          /* 词汇个数 */
    int low = 0, mid = 0, high = 0; /* 三档计数器，初值均为 0 */
    int f;                          /* 当前读入的词频 */
    int i;

    /* 读入词汇个数 */
    scanf("%d", &n);

    /* 边读边统计：每个词频立即归入对应档位 */
    for (i = 0; i < n; i++) {
        scanf("%d", &f);
        if (f <= 2)              /* 低频：只出现一两次 */
            low++;
        else if (f <= 9)         /* 中频：3~9（此处 f 已 > 2） */
            mid++;
        else                     /* 高频：10 及以上 */
            high++;
    }

    /* 输出三档计数 */
    printf("low = %d\n", low);
    printf("mid = %d\n", mid);
    printf("high = %d\n", high);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 5 / 1 2 5 8 12 | 1,2→low；5,8→mid；12→high | `low = 2` / `mid = 2` / `high = 1` ✓ |
| 6 / 3 10 10 1 7 20 | 3,7→mid；10,10,20→high；1→low | `low = 1` / `mid = 2` / `high = 3` ✓ |
| 3 / 1 1 1 | 全为低频 | `low = 3` / `mid = 0` / `high = 0` ✓ |
| 2 / 10 10 | 全为高频 | `low = 0` / `mid = 0` / `high = 2` ✓ |

每组都满足三档之和等于 n，说明分类没有遗漏。

## 六、常见错误与讲解

**错误 1：边界写错，出现"夹缝"（最典型）**

```c
if (f < 2)       low++;      /* 错：f = 2 无人接收 */
else if (f < 9)  mid++;
else             high++;
```

用 `<` 而不是 `<=` 会让边界值落空，导致三档之和不等于 n。本题明确"$\le 2$ 归低频"，必须用 `<=`。

**错误 2：用三个独立 if，导致重复计数**

```c
if (f <= 2)  low++;
if (f <= 9)  mid++;   /* 错：f=1 时 low 和 mid 同时加 */
if (f >= 10) high++;
```

必须用 `else if` 保证只进一支。

**错误 3：计数器忘记初始化或初值非 0**

```c
int low, mid, high;
low = mid = high = 0;   /* 对：全部归零 */
```

**错误 4：把统计写在循环外，只算了最后一个词**

```c
for (i = 0; i < n; i++)
    scanf("%d", &f);      /* 错：只读了数据，没统计 */
if (f <= 2) low++;        /* 只处理了最后一个 f */
```

判断必须写在循环体内，每读一个就归类一次。
