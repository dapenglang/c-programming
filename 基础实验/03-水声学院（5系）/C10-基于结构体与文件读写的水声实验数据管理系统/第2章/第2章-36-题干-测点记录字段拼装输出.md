# 第 2 章 练习 36　测点记录字段拼装输出

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：2 常量、变量与数据类型；2.x 格式化输入输出（scanf/printf 的域宽控制）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"屏幕报表输出"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

水声实验数据管理系统中，每个**测点**有一条记录：测站编号、观测时刻、测点深度、水温、回波强度。数据在程序内部是零散的几个变量，但交付给实验员看的必须是**对齐的报表**——列与列对得整齐，一眼能扫出异常值。

综合实验 C10 的第 10 模块"屏幕报表"就是把存储的记录按表头 + 数据行的形式打印。本题截取其最小单元：读入**一个测点**的五个字段，按固定列宽打印一行表头和一行记录。核心训练点是 `printf` 的**域宽控制**（`%5d`、`%8.1f` 等）——不用它，报表就是歪的。

## 二、任务要求

编写一个完整程序 `record_print.c`：

1. 从键盘按顺序读入一个测点的五个字段：
   - 测站编号 `id`（int，1～999）；
   - 观测时刻 `t`（double，单位 h，如 14.5 表示 14:30）；
   - 测点深度 `depth`（double，单位 m）；
   - 水温 `temp`（double，单位 ℃）；
   - 回波强度 `echo`（double，单位 dB）；
2. 先打印一行表头（内容与列宽见样例）；
3. 再按同样列宽打印这行记录：`id` 占 6 列宽（`%6d`），三个实数各占 10 列宽、保留 1 位小数（`%10.1f`）；
4. 表头与数据行必须**列对齐**。

**注意**：本题只做顺序计算，不允许使用 `if`、循环和函数，不允许使用数组。

## 三、输入输出格式

**输入**：一行五个值，用空格分隔：`id t depth temp echo`。

**输出**：两行——第一行表头，第二行数据。格式如下（列宽以样例为准）：

- 表头行直接按下述**固定字符串**输出（含竖线分隔符，每段宽度与数据行的 `%6d`、`%10.1f` 严格对齐）：

```
    id|      t/h|  depth/m|   temp/C|  echo/dB
```

（提示中给出精确的表头 `printf` 语句，直接照抄即可。）

## 四、样例

**样例 1**

输入：
```
207 14.5 38.2 12.6 -42.8
```
输出：
```
    id|      t/h|  depth/m|   temp/C|  echo/dB
   207|      14.5|      38.2|      12.6|     -42.8
```

**样例 2**

输入：
```
31 6.0 105.0 8.4 -55.1
```
输出：
```
    id|      t/h|  depth/m|   temp/C|  echo/dB
    31|       6.0|     105.0|       8.4|     -55.1
```

## 五、提示

- 表头行请直接使用这条语句（照抄）：
  ```c
  printf("    id|      t/h|  depth/m|   temp/C|  echo/dB\n");
  ```
- 数据行的格式串为 `"%6d|%10.1f|%10.1f|%10.1f|%10.1f\n"`——请先在纸上数一数表头每个字段的宽度，验证它们与 `%6d`、`%10.1f` 的关系（表头每段与数据行对应列**总宽相等**，右对齐）；
- `%10.1f` 的含义：总宽 10 列（含小数点与负号），小数 1 位，不足左补空格，右对齐；`-42.8` 占 5 列，前面自动补 5 个空格；
- 先用样例 2 的短数据调试（补空格多、错位明显），再用样例 1 验证。

**完成本练习后你将具备的能力**：用域宽控制打印对齐报表——这是 C10 实验"屏幕报表"模块乃至所有数据系统"人机界面"的基本功。
