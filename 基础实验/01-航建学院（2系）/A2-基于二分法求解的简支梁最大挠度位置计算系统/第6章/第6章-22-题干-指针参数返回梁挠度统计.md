# 第 6 章 练习 22　指针参数返回梁挠度统计

**所属综合实验**：A2（A2-基于二分法求解的简支梁最大挠度位置计算系统）

**对应章节**：6 内存数据深度操控方法（6.1 地址与指针变量、6.4 指针作为函数参数、6.5 经指针参数返回多个结果）

**场景来源**：综合实验 A2《基于二分法求解的简支梁最大挠度位置计算系统》（航建学院）——本练习是该实验中"挠度统计函数"环节的实现，用指针参数回传最大值与位置。

**建议用时**：25～30 分钟

## 一、应用场景

简支梁挠度分析中，程序要在一排离散计算点里找出**最大挠度**和**它所在的位置**——两个结果要一起交回给主函数。可是 C 语言的函数 `return` 每次只能带回**一个**值。怎么办？

办法是：把一个结果的**地址**交给函数，函数通过这个地址直接写回结果。A2 系统的"挠度统计"函数正是这么写的：返回值传回最大挠度，指针参数带回它所在的位置下标。掌握这个技巧，函数就能"一次交出多个答案"。

## 二、任务要求

编写一个完整程序 `beam_stat.c`：

1. 定义函数

```c
double beam_stat(double *y, int n, int *pos);
```

它在长度为 `n` 的挠度数组 `y` 中找出最大值，**返回最大值本身**，并通过指针参数 `pos` 把最大值的**下标**带回给调用者；

2. 主函数读入分段数 `n`（整数，**题目保证 3 ≤ n ≤ 50**）和梁参数 `L`、`q`、`E`、`I`，按上一练习的挠度公式算出 n+1 个点的挠度存入数组；
3. 调用 `beam_stat`，得到最大挠度与位置；
4. 输出最大挠度（保留 3 位小数）与对应坐标 x（保留 2 位小数）。

## 三、输入输出格式

**输入**：第一行 4 个实数 L、q、E、I；第二行 1 个整数 n。

**输出**：两行，`max_y = 最大挠度m` 与 `x_at_max = 位置m`。

## 四、样例

**样例 1**

输入：
```
6.0 10.0 30000.0 0.0008
6
```
输出：
```
max_y = 7.031
x_at_max = 3.00
```

**样例 2**

输入：
```
4.0 10.0 30000.0 0.0008
4
```
输出：
```
max_y = 1.389
x_at_max = 2.00
```

## 五、提示

挠度公式与上一练习相同：

$$
y(x) = \frac{q\,x\,(L^3 - 2Lx^2 + x^3)}{24 E I}
$$

**指针参数回传结果的用法**：在函数里对 `*pos` 赋值，就等于修改了主函数里那个变量：

```c
double beam_stat(double *y, int n, int *pos)
{
    int imax = 0;
    for (int i = 1; i <= n; i++)
        if (y[i] > y[imax]) imax = i;
    *pos = imax;          /* 通过地址把下标写回主函数 */
    return y[imax];       /* 通过返回值把最大值交回 */
}
```

主函数调用时，要传**变量的地址**：

```c
int pos;
double mx = beam_stat(y, n, &pos);   /* &pos 把 pos 的地址交给函数 */
```

**完成本练习后你将具备的能力**：理解"值传递只能带回一个结果"的局限；用指针参数实现"一次带回多个结果"；在函数内通过 `*指针` 修改调用者的变量。
