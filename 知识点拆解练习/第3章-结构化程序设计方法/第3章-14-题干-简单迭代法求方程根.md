# 第 3 章 练习 14　简单迭代法求方程根

**对应章节**：3 结构化程序设计方法（3.5 数值求解方法——不动点迭代法、3.3 循环结构、3.4 关系与逻辑运算）

**场景来源**：综合实验 D1《放射性核素活度衰变计算系统》（核学院）——本练习是该实验中"自吸收修正因子求解"环节的实现，同时为第 4.6 节"非线性方程求解（牛顿迭代法）"作前置铺垫。

**建议用时**：25 分钟

## 一、应用场景

测量放射性核素的活度时，样品自身会吸收一部分射线，使仪器读到的计数率偏低，需要用"自吸收修正因子" $\eta$ 把结果修正回去。根据探测器的几何布置和样品厚度，可以推导出 $\eta$ 满足一个含指数函数的超越方程 $\eta = 1 - c\,e^{-\eta}$，其中 $c$ 是吸收系数。这种方程无法手工解出，但可以把它看作 $x = f(x)$ 的形式，用一个值反复代入右端，逐步逼近真正的解——这就是**不动点迭代法**。

## 二、任务要求

编写一个完整程序 `fixed_point.c`：

1. 从键盘读入两个实数，用空格分隔：初始猜测值 `x0`（double）、吸收系数 `c`（double，题目保证 `0 < c < 1`）；
2. 用 **while 循环**反复执行迭代公式 $x_{k+1} = 1 - c\,e^{-x_k}$，每轮用上一次的结果算出新的结果；
3. 当相邻两次结果的差 $|x_{k+1} - x_k| < 10^{-6}$ 时停止循环（迭代收敛）；
4. 输出最终的 $\eta$，保留 6 位小数。可调用标准库函数 `exp()` 计算指数（它在 `<math.h>` 中，是现成的库函数，不属于"自定义函数"）。

## 三、输入输出格式

**输入**：一行，两个实数 `x0 c`，中间用空格分隔。

**输出**：一行，格式为 `eta = 结果`，结果保留 6 位小数。

## 四、样例

**样例 1**

输入：
```
1.0 0.5
```
输出：
```
eta = 0.768039
```

**样例 2**

输入：
```
0.5 0.8
```
输出：
```
eta = 0.528327
```

## 五、提示

把方程写成"左端单变量 = 右端含该变量的表达式"的形式：

$$
\eta = f(\eta) = 1 - c\,e^{-\eta}
$$

于是可以构造迭代序列

$$
x_{k+1} = 1 - c\,e^{-x_k},\qquad k = 0,1,2,\dots
$$

只要初值选得不太离谱，序列 $x_0, x_1, x_2, \dots$ 就会逐步靠近真根。终止判据是相邻两次的差：

$$
\left|\,x_{k+1} - x_k\,\right| < 10^{-6}
$$

注意：**判断收敛用的是"两次结果的差"，而不是"与前一次比大小"**——差小于给定精度就认为已经找到满意的解。

**完成本练习后你将具备的能力**：用 while 循环实现"旧值代入公式算出新值"的不动点迭代、用相邻两次结果的差作为收敛判据——这是第 4.6 节牛顿迭代法以及大量工程反问题求解的共同基础。
