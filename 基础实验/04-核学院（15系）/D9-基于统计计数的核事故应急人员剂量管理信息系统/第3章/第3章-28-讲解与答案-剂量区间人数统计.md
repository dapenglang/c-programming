## 二、预备知识：计数器与多分支——怎么把一堆数分成几堆（零基础阅读）

### 1. 问题是怎么来的

上一练习（练习 27 第 3 章）只关心**一个人**：把他的读数加起来、判一个等级。现在的问题要复杂一步：面对**一群人**，要数出每一档各有多少人。

人脑的算法是：准备三个空盒子（画正字），每看到一个数，判断它属于哪一档，就在对应盒子里添一笔。程序里这三个"盒子"就是三个**计数器**变量。

### 2. 计数器为什么必须先清零

计数器的规矩和累加器一样：**循环之前必须清零**。因为 C 语言的局部变量在没有初始化时，里面是上一次用这块内存时留下的**垃圾值**——可能是任何整数。从垃圾值往上数，结果自然全错。

```c
int c1 = 0, c2 = 0, c3 = 0;    /* 三个盒子，都清空 */
...
c1++;                          /* 属于正常档，第一个盒子添一笔 */
```

`c1++` 等价于 `c1 = c1 + 1`，就是把盒子里的小石子数加一。

### 3. 多分支结构：为什么 `else if` 能自动排除前面的区间

本题要把整个数轴切成三段，分界线在两个点上：20 和 50。

```c
if (d < 20.0)
    c1++;
else if (d < 50.0)
    c2++;
else
    c3++;
```

读这段代码的逻辑链条：**先问第一个问题**"d 小于 20 吗？"——是，就落到第一档，后面的问题根本不再问；**不是**，才进入 `else if` 问第二个问题"d 小于 50 吗？"。**关键就在这里**：走到第二个问题时，程序已经知道 `d < 20` 是**假**的，所以此刻 `d >= 20` 是确定的事实。于是 `else if (d < 50.0)` 实际上表达的是"$20 \le d < 50$"。

**这就是 `else` 的"继承反面"特性**：它天然带着前面所有条件之否定的信息，所以不需要重复书写下界。反过来说，如果写成三个平行的 `if`：

```c
if (d < 20.0)   c1++;
if (d >= 20.0 && d < 50.0)  c2++;
if (d >= 50.0)  c3++;
```

结果也正确，但每个条件都要自己写完整，既啰嗦又容易漏掉下界（写成 `if (d < 50.0) c2++;` 就会把正常档的人也数第二遍）。**多分支结构是为"互斥区间划分"量身定做的。**

### 4. 用本例走一遍

样例 1 的 $[3.2,\ 21.0,\ 8.5,\ 55.0,\ 19.9]$，三个计数器初始全为 0：

| 第几个 | d | 判定 | c1（正常） | c2（关注） | c3（超限） |
|---|---|---|---|---|---|
| 1 | 3.2 | d<20 → 正常 | 1 | 0 | 0 |
| 2 | 21.0 | d≥20 且 d<50 → 关注 | 1 | 1 | 0 |
| 3 | 8.5 | d<20 → 正常 | 2 | 1 | 0 |
| 4 | 55.0 | 既不<20 也不<50 → 超限 | 2 | 1 | 1 |
| 5 | 19.9 | d<20 → 正常 | 3 | 1 | 1 |

输出 `normal = 3`、`attention = 1`、`over = 1`。注意第 5 个人的 19.9：**它离 20 只差 0.1，但仍然算正常档**——判定用的是严格小于，界值处不含入。而样例 2 中的 20.0 则判入关注档，50.0 判入超限档，**说明界值点一律归入更高一档**，这与"限值即界线"的规定一致。

> **这个思想在综合实验中反复出现**：D9 的三档剂量统计、D8 的峰/非峰判定、D7 的剂量场高/中/低区统计、D6 的屏蔽合格/不合格计数，全部是"多分支 + 计数器"。**分组统计是任何管理系统的报表核心。**

## 三、解题思路

1. **读 n**：`scanf("%d", &n);`；
2. **三个计数器清零**：`int c1 = 0, c2 = 0, c3 = 0;`；
3. **循环读入并判定**：`for (i = 0; i < n; i++) { scanf("%lf", &d); if (d < 20.0) c1++; else if (d < 50.0) c2++; else c3++; }`；
4. **输出三行**：`%d` 对应整数计数器。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int    n, i;
    int    c1 = 0, c2 = 0, c3 = 0;  /* 正常 / 关注 / 超限 三个计数器，必须清零 */
    double d;                       /* 当人的累计剂量，mSv */

    scanf("%d", &n);                /* 读入人员数 */

    for (i = 0; i < n; i++) {
        scanf("%lf", &d);           /* 读入第 i 个人的累计剂量 */

        /* 多分支：else if 自动继承“d >= 20”；最后的 else 即“d >= 50” */
        if (d < 20.0) {
            c1++;                   /* 正常档 */
        } else if (d < 50.0) {
            c2++;                   /* 关注档：20 ~ 50 mSv */
        } else {
            c3++;                   /* 超限档：>= 50 mSv */
        }
    }

    printf("normal = %d\n", c1);        /* 正常档人数 */
    printf("attention = %d\n", c2);     /* 关注档人数 */
    printf("over = %d\n", c3);          /* 超限档人数 */

    return 0;
}
```

## 五、运行验证

| 输入 | 逐项判定 | 程序输出 |
|---|---|---|
| 5: 3.2 21.0 8.5 55.0 19.9 | 正常,关注,正常,超限,正常 | `normal = 3` / `attention = 1` / `over = 1` ✓ |
| 6: 20.0 49.9 50.0 5.0 5.0 5.0 | 关注,关注,超限,正常,正常,正常 | `normal = 3` / `attention = 2` / `over = 1` ✓ |
| 3: 0.0 19.9 20.0 | 正常,正常,关注 | `normal = 2` / `attention = 1` / `over = 0` ✓ |
| 4: 50.0 50.0 20.0 20.0 | 超限,超限,关注,关注 | `normal = 0` / `attention = 2` / `over = 2` ✓ |

第二、三、四例都是**界值验证**：20.0 落入关注档、50.0 落入超限档、19.9 仍属正常档，说明分界处"含下界、不含上界"的规则被严格执行。

**验算总量**：每一例的三档人数之和都等于 n（如样例 2：3+2+1=6），这是分组统计的一个自检方法——**若三数之和 ≠ n，必有某档判漏或重复计数。**

## 六、常见错误与讲解

**错误 1：计数器未初始化**

```c
int c1, c2, c3;                 /* 错：垃圾值，结果荒谬 */
for (...) if (...) c1++;

int c1 = 0, c2 = 0, c3 = 0;     /* 对 */
```

**错误 2：用三个平行 `if` 但条件写不全**

```c
if (d < 20.0)              c1++;
if (d < 50.0)              c2++;   /* 错：正常档的人也被数成关注档 */
if (d >= 50.0)             c3++;

/* 正确：要么用 else if 链，要么把条件写全 */
if (d < 20.0)                    c1++;
else if (d < 50.0)               c2++;
else                             c3++;
```

**错误 3：`else if` 顺序颠倒**

```c
if (d < 50.0)  c2++;       /* 错：先判大区间，正常档全被吞进关注档 */
else if (d < 20.0) c1++;
```

一旦把宽区间放在窄区间前面，`else if` 后面那个条件就永远轮不到。**规则：按区间从小到大（或从大到小）单调排列，绝不能交叉。**

**错误 4：格式符错用**

```c
printf("normal = %f\n", c1);       /* 错：c1 是 int，%f 会输出乱码 */
printf("normal = %d\n", c1);       /* 对 */
```

计数结果是整数，用 `%d`；只有剂量值本身才是 `double`。
