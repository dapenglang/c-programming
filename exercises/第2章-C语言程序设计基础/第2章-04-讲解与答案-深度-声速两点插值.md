## 二、预备知识：线性插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

实测只给了两个点：

- 深度 0 m 处，声速 1450 m/s；
- 深度 100 m 处，声速 1480 m/s。

如果声呐工作在 60 m 深度，需要知道那里的声速。可表里没有 60 m 这一档——**怎么求？**

最朴素的想法：假设 0 m 到 100 m 之间，声速随深度**均匀变化**（图象是一条直线），那么 60 m 处的声速就在这条直线上按比例取一点。这个"在两个已知点之间按直线比例取值"的方法就是**线性插值**。

### 2. 公式是怎么推出来的

设两已知点为 $(h_0,\, c_0)$、$(h_1,\, c_1)$，要求 $h_0 \le h \le h_1$ 处的 $c$。

"均匀变化"意味着**声速的增长量与深度的增长量成正比**。深度从 $h_0$ 走到 $h_1$，总共走了 $(h_1 - h_0)$，声速相应涨了 $(c_1 - c_0)$；现在深度只走到 $h$，走了 $(h - h_0)$，那声速就应涨"全程涨幅的同样比例"：

$$
\frac{c - c_0}{c_1 - c_0} = \frac{h - h_0}{h_1 - h_0}
$$

两边同乘 $(c_1-c_0)$ 再加 $c_0$，解出：

$$
c = c_0 + \dfrac{(c_1 - c_0)\,(h - h_0)}{h_1 - h_0}
$$

用大白话读就是：**起点值 + 全程涨幅 × 已走比例**。

### 3. 用本例走一遍

取 $h=60$，代入 $(h_0,c_0)=(0,1450)$、$(h_1,c_1)=(100,1480)$：

- 已走比例：$(60-0)/(100-0)=0.6$，即走完 60%；
- 全程涨幅：$1480-1450=30$ m/s；
- 已涨部分：$30\times0.6=18$ m/s；
- 结果：$c = 1450+18=1468$ m/s。

再验端点：$h=0$ 时比例为 0，结果正好 1450；$h=100$ 时比例为 1，结果正好 1480——公式在端点自动退回表格值，说明它是对的。

### 4. 编程时怎么用它

公式里有五个量：四个是实测常量（$h_0,c_0,h_1,c_1$），一个是输入 $h$。编程就是**把五个数放进变量、把公式原样翻译成一行赋值语句**。唯一要注意的是括号——分子 $(h-h_0)$、分母 $(h_1-h_0)$ 都必须先算。

> **这个套路在综合实验中反复出现**：C1 声速剖面（深度→声速）、A1 风荷载（高度→系数）、A7 混凝土强度（龄期→强度）、D3 核数据截面（能量→截面），全是"表格 + 线性插值"。学会一次，四处通用。

## 三、解题思路

1. **确定常量**：两档实测数据 (0, 1450) 与 (100, 1480)，用 `const double`；
2. **确定变量**：读入的深度 `h` 和待求声速 `c`，都是 `double`；
3. **套公式**：`c = C0 + (C1 - C0) * (h - H0) / (H1 - H0)`；
4. **输出**：题目要求保留 2 位小数，用 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 相邻两档实测数据：深度(m) 与 该深度声速(m/s) */
    const double H0 = 0.0;      /* 下档深度 */
    const double H1 = 100.0;    /* 上档深度 */
    const double C0 = 1450.0;   /* 下档声速 */
    const double C1 = 1480.0;   /* 上档声速 */

    double h;      /* 输入：查询深度，m */
    double c;      /* 输出：插值得到的声速，m/s */

    /* 读入查询深度 */
    scanf("%lf", &h);

    /* 线性插值：c = c0 + (c1 - c0) * (h - h0) / (h1 - h0) */
    c = C0 + (C1 - C0) * (h - H0) / (H1 - H0);

    /* 输出，保留 2 位小数 */
    printf("c = %.2f m/s\n", c);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 60 | $1450 + 30\times(60-0)/(100-0) = 1450+18 = 1468.00$ | `c = 1468.00 m/s` ✓ |
| 25 | $1450 + 30\times25/100 = 1450+7.5 = 1457.50$ | `c = 1457.50 m/s` ✓ |
| 0 | $1450 + 30\times0/100 = 1450.00$（下端点） | `c = 1450.00 m/s` ✓ |
| 100 | $1450 + 30\times100/100 = 1480.00$（上端点） | `c = 1480.00 m/s` ✓ |

两个端点的结果与实测表完全一致，说明插值公式实现正确。

## 六、常见错误与讲解

**错误 1：常量写成整数**

```c
const int C0 = 1450, C1 = 1480;   /* 错：声速是实数量，应使用 double */
```

声速虽然看起来像整数，但它属于物理实数，后续也要参与比例运算，一律用 `double`。

**错误 2：括号漏写、优先级错**

```c
c = C0 + (C1 - C0) * h - H0 / (H1 - H0);      /* 错：运算顺序全乱 */
c = C0 + (C1 - C0) * (h - H0) / (H1 - H0);    /* 对：先减、再乘、再除 */
```

乘除优先于加减，`(h - H0)` 必须整体加括号，否则 `* h - H0` 会被拆成"先乘 h 再减 H0"。

**错误 3：scanf 漏写 `&`**

```c
scanf("%lf", h);    /* 错：应为 &h */
scanf("%lf", &h);   /* 对 */
```

**错误 4：格式符或精度不符**

```c
printf("c = %f m/s\n", c);      /* 能输出但位数太多，不符合题目要求 */
printf("c = %.2f m/s\n", c);    /* 对：保留 2 位小数 */
printf("c = %d m/s\n", c);      /* 错：double 用 %d 输出乱码 */
```
