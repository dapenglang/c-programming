## 二、预备知识：材料曲率为什么是 $(k-1)/L^2$（零基础阅读）

### 1. 问题是怎么来的

反应堆能不能"自持"地维持链式反应，取决于两件事的赛跑：

- 中子**产生**的速度——由增殖因子 $k$ 描述。$k$ 是"下一代中子数 / 上一代中子数"，$k = 1.2$ 表示每代多出 20% 的中子；
- 中子**泄漏**的速度——由扩散长度 $L$ 描述。$L$ 越大，中子在介质里跑得越远，越容易跑到边界外泄漏掉。

**产生多于泄漏，堆才能持续运行。** 材料曲率 $B_m^2$ 就是把这个"产生与泄漏之争"用材料参数表达出来的量。

### 2. 公式怎么理解

$$
B_m^2 = \frac{k - 1}{L^2}
$$

逐项读：

- **分子 $(k-1)$**：净增殖多少。$k = 1.0$ 时分子为 0——刚好不赚不赔；$k = 1.2$ 时分子 0.2——每代净赚 20%。分子越大，介质越"有富余"；
- **分母 $L^2$**：$L$ 越大，$L^2$ 越大，$B_m^2$ 越小。物理上，$L$ 大意味着中子跑得远、泄漏风险高，所以介质"要求"的曲率就小——也就是需要更大的堆尺寸才能达到临界；
- **整体量纲**：$k$ 无量纲，$L^2$ 是 $\text{cm}^2$，所以 $B_m^2$ 的单位是 $\text{cm}^{-2}$（"曲率"本质上是 $1/\text{长度}^2$，与几何上的曲率定义一致）。

**核心结论**：$B_m^2$ 只与材料有关，是**材料的固有属性**。D10 接下来要算的"几何曲率" $B_g^2 = (\pi/R)^2$ 则只与**堆的尺寸**有关。**临界条件就是这两者相等**：

$$
B_m^2 = B_g^2
$$

### 3. 用本例走一遍

样例 1：$k = 1.20$，$L = 5.0$ cm。

- 分子：$1.20 - 1.0 = 0.20$；
- 分母：$5.0 \times 5.0 = 25.0$；
- 结果：$B_m^2 = 0.20 / 25.0 = 0.008$，保留 6 位小数得 `0.008000`。

样例 2：$k = 1.50$，$L = 4.0$ cm。

- 分子：$1.50 - 1.0 = 0.50$；
- 分母：$4.0 \times 4.0 = 16.0$；
- 结果：$B_m^2 = 0.50 / 16.0 = 0.03125$，保留 6 位小数得 `0.031250`。

**量级校验**：样例 2 的 $B_m^2 = 0.03125$ 比样例 1 的 0.008 大得多（大了近 4 倍），说明 $k$ 大、$L$ 小的材料"增殖能力"强得多。后面求临界半径时，$B_m^2$ 大意味着 $B_g^2 = (\pi/R)^2$ 也要大，即 $R$ 要小——**这把"材料好"翻译成了"堆可以做小"，正是临界计算的直觉。**

### 4. 编程时怎么用它

公式里有三个量，两个输入、一个输出。翻译成 C 语言唯一的难点是**分母的"平方"怎么写**：

```c
Bm2 = (k - 1.0) / (L * L);      /* 对：用乘法表示平方 */
```

C 语言**没有**幂运算符。写成 `L^2` 会被编译器理解为"L 与 2 做按位异或"（`^` 在位运算里是异或），得到的是一个毫无意义的整数结果，而且**语法完全合法、不会报错**——这是最典型的"静默错误"。

另外要注意**括号**：`(k - 1.0) / (L * L)` 里两组括号都不能省。若写成 `k - 1.0 / L * L`，乘除优先于加减，程序会先算 `1.0 / L * L`（结果恰好是 1.0），再算 `k - 1.0`，得到 0.2——本例碰巧数值相近，但在别的数据上会完全错误。**规则：凡是心里的运算顺序与默认优先级不一致，一律加括号。**

> **这个思想在综合实验中反复出现**：材料曲率 $B_m^2=(k-1)/L^2$、几何曲率 $B_g^2=(\pi/R)^2$、点源剂量率平方反比、屏蔽透射率指数衰减，全部是"把物理公式原样翻译成一行赋值语句"。**公式翻译是数值程序的第一步：先算对一个点，再谈批量与迭代。**

## 三、解题思路

1. **确定变量**：输入 `k`、`L`，结果 `Bm2`，都是 `double`；
2. **读入**：`scanf("%lf %lf", &k, &L);`；
3. **套公式**：`Bm2 = (k - 1.0) / (L * L);`——分子减 1 要括号，分母平方用乘法；
4. **输出**：题目要求保留 6 位小数，用 `%.6f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double k;       /* 增殖因子（无量纲），本题保证 1.05 ~ 1.5 */
    double L;       /* 中子扩散长度，单位 cm，本题保证 2 ~ 10 */
    double Bm2;     /* 材料曲率，单位 cm^-2 */

    /* 读入两个材料参数 */
    scanf("%lf %lf", &k, &L);

    /* 材料曲率公式：Bm2 = (k - 1) / L^2
       注意：C 语言没有幂运算符，L^2 必须写成 L * L；
       分子要加括号，否则减法会被除法抢先执行 */
    Bm2 = (k - 1.0) / (L * L);

    /* 输出，保留 6 位小数（Bm2 量级约 0.001 ~ 0.06，需要足够位数） */
    printf("Bm2 = %.6f\n", Bm2);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 1.20 5.0 | (1.20−1)/25 = 0.20/25 = 0.008000 | `Bm2 = 0.008000` ✓ |
| 1.50 4.0 | (1.50−1)/16 = 0.50/16 = 0.031250 | `Bm2 = 0.031250` ✓ |
| 1.05 5.0 | (1.05−1)/25 = 0.05/25 = 0.002000 | `Bm2 = 0.002000` ✓ |
| 1.20 2.0 | (1.20−1)/4 = 0.20/4 = 0.050000 | `Bm2 = 0.050000` ✓ |

第三例取最小 $k$，得到最小曲率 0.002；第四例取最小 $L$，得到较大曲率 0.05。**两例分别验证了分子、分母的影响方向**：$k$ 小则 $B_m^2$ 小，$L$ 小则 $B_m^2$ 大，与公式的分析一致。

## 六、常见错误与讲解

**错误 1：用 `^` 表示平方（最典型）**

```c
Bm2 = (k - 1.0) / (L ^ 2);      /* 错：^ 是位异或，不是幂 */
Bm2 = (k - 1.0) / (L * L);      /* 对 */
Bm2 = (k - 1.0) / pow(L, 2.0);  /* 也对，但需 #include <math.h> */
```

`^` 在 C 中是**按位异或**运算符。若 $L$ 是 `double`，`L ^ 2` 甚至无法通过编译（`^` 只作用于整数）；若 $L$ 是 `int`，则会算出一个完全无关的整数，编译器**不报错**——这类错误极难发现。

**错误 2：忘记括号导致运算顺序错误**

```c
Bm2 = k - 1.0 / L * L;             /* 错：先算 1.0/L*L = 1.0，结果 = k - 1.0 */
Bm2 = (k - 1.0) / (L * L);         /* 对：分子分母都加括号 */
```

**错误 3：除号两边都是整数**

```c
int k = 1, L = 5;
Bm2 = (k - 1) / (L * L);           /* 错：0/25 = 0，整数除法 */
```

本题变量都是 `double`，不会出现这个问题；但若误把 `k` 声明为 `int`（因为它常写成 1.2 这样的小数，容易忽略），就会丢精度。**物理量一律 `double`。**

**错误 4：输出位数不够**

```c
printf("Bm2 = %.2f\n", Bm2);       /* 不推荐：0.008000 会显示成 0.01，丢有效数字 */
printf("Bm2 = %.6f\n", Bm2);       /* 对：本题要求 6 位 */
```

材料曲率量级小（0.001～0.06），用 2 位小数会把不同材料的差异抹平。**小数位数的选择要与物理量的量级匹配。**
