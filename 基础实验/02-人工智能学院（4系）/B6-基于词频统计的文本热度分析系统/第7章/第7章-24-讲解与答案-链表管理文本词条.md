## 二、预备知识：链表的基本原理（零基础阅读）

### 1. 问题是怎么来的：数组的"长度必须事先定好"

第 7 章前面几题都用结构体数组存数据，数组有个硬性限制：**长度在写代码时就要写死**（比如 `struct Node nd[8]`）。可词条个数在运行前根本不知道，写小了不够用，写大了浪费。

**链表**换了一种组织方式：不预先分配一整排柜子，而是**用一个就申请一个**，各节点散落在内存各处，靠指针互相牵引。

### 2. 链表长什么样

每个节点是一个结构体，里面除了数据，还有一个**指向下一个节点的指针**。画成图就是这样：

```
head
  |
  v
+-------+------+     +--------+------+     +--------+------+
| apple |  5   | --> | banana |  3   | --> | cherry |  7   | --> NULL
| next ------+      | next ------+       | next = NULL |
+-------+------+     +--------+------+     +--------+------+
```

每个方框是一个节点，包含三部分：`text`、`count`、`next`。`next` 里存的是"下一个节点的地址"，也就是第 6 章说过的"写着柜号的纸条"。最后一个节点的 `next` 是 `NULL`（空指针），表示链子到头了。

### 3. 三个关键操作

**（1）申请节点**

```c
struct Word *p = malloc(sizeof(struct Word));
```

`malloc` 向系统要一块能装下一个 `struct Word` 的内存，返回这块内存的地址（纸条），存进 `p`。

**（2）尾插：把新节点接到末尾**

```
插入前:   head -> [A] -> [B] -> NULL        tail 指向 B
插入后:   head -> [A] -> [B] -> [P] -> NULL
                              ^
                         让 B.next 指向 P，再让 tail = P
```

代码是两步改接：

```c
tail->next = p;    /* 原来的尾节点 next 指向新节点 */
tail = p;          /* 尾指针移到新节点 */
p->next = NULL;    /* 新节点成为新的末尾 */
```

**（3）遍历：沿链子一个个走**

```c
struct Word *cur = head;
while (cur != NULL) {
    /* 处理 cur->count、cur->text */
    cur = cur->next;      /* 走到下一个节点 */
}
```

`cur = cur->next` 就是"顺着纸条找到下一个节点"。

### 4. 为什么要用箭头 `->` 而不是点号

第 7 章练习 21 讲点号时说过：点号用于**变量**本身。而遍历时拿到的 `cur` 是一个**指针**（指向节点的纸条），要用箭头：

```c
cur->count     /* 等价于 (*cur).count：先打开柜子，再取成员 */
cur->next      /* 下一个节点的地址 */
```

一句话记法：**变量用点号，指针用箭头**。

### 5. 为什么必须 free

链表节点是运行中用 `malloc` 申请的，这些内存**不会被自动回收**。程序结束前要逐个 `free`：

```c
while (cur != NULL) {
    struct Word *tmp = cur->next;   /* 先记住下一个 */
    free(cur);                      /* 释放当前 */
    cur = tmp;                      /* 再走到下一个 */
}
```

**顺序不能反**：如果先 `free(cur)` 再去读 `cur->next`，就是访问已经释放的内存，属于严重错误。

### 6. 用本例走一遍

**样例 1**：依次读 apple(5)、banana(3)、cherry(7)。

- 空链表时插入 apple，`head = tail = apple 节点`；
- 插入 banana：`tail->next = banana`，`tail = banana`；
- 插入 cherry：`tail->next = cherry`，`tail = cherry`。

链表为 apple → banana → cherry。遍历输出三行，词频总和 $5+3+7 = 15$，与样例一致。

> **这个思想在综合实验中反复出现**：B6 词条链表、B4 搜索路径栈（先进后出）、B5 待访问节点表、B9 任务队列，都是"用链表处理数量不定、需要动态增删的数据"同一个套路。

## 三、解题思路

1. **定义类型**：`struct Word { char text[16]; int count; struct Word *next; };`（注意里面用到了自己的指针）；
2. **建表**：初始化 `head = tail = NULL;`，循环 $n$ 次，每次 `malloc` 一个新节点、填数据、按尾插法接到末尾；
3. **遍历求和输出**：`cur = head;` 沿链走，逐个 `printf`，同时累加 `count`；
4. **释放**：再次遍历，先存 `next` 再 `free`；
5. **输出总和**。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>     /* malloc、free */
#include <string.h>     /* strcpy */

/* 词条节点：文本、词频、指向下一个节点的指针 */
struct Word {
    char        text[16];
    int         count;
    struct Word *next;
};

int main(void)
{
    int n, i;
    struct Word *head = NULL;   /* 头指针 */
    struct Word *tail = NULL;   /* 尾指针，便于尾插 */
    struct Word *cur;
    int total = 0;

    scanf("%d", &n);

    /* 逐个读入并用尾插法建立链表 */
    for (i = 0; i < n; i++) {
        struct Word *p = (struct Word *)malloc(sizeof(struct Word));
        scanf("%s %d", p->text, &p->count);
        p->next = NULL;

        if (head == NULL) {     /* 第一个节点 */
            head = tail = p;
        } else {                /* 接到末尾 */
            tail->next = p;
            tail = p;
        }
    }

    /* 遍历链表，输出并累加词频 */
    for (cur = head; cur != NULL; cur = cur->next) {
        printf("%s: %d\n", cur->text, cur->count);
        total += cur->count;
    }
    printf("total = %d\n", total);

    /* 释放所有节点：先记下一个，再释放当前 */
    cur = head;
    while (cur != NULL) {
        struct Word *tmp = cur->next;
        free(cur);
        cur = tmp;
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3 / apple 5 / banana 3 / cherry 7 | 链表顺次三段；总和 5+3+7=15 | 三行词条 + `total = 15` ✓ |
| 2 / go 8 / run 2 | 总和 8+2=10 | `go: 8` / `run: 2` / `total = 10` ✓ |
| 1 / solo 4 | 单节点链表；总和 4 | `solo: 4` / `total = 4` ✓ |
| 3 / a 1 / b 1 / c 1 | 总和 1+1+1=3 | 三行词条 + `total = 3` ✓ |

单节点与多节点都能正确建链、遍历与释放，说明尾插逻辑无误。

## 六、常见错误与讲解

**错误 1：忘记把新节点的 next 置 NULL（最典型）**

```c
struct Word *p = malloc(sizeof(struct Word));
scanf("%s %d", p->text, &p->count);
/* 漏写 p->next = NULL; —— 遍历时会读到垃圾地址，程序崩溃 */
```

**错误 2：遍历时用箭头写成点号**

```c
printf("%d", cur.count);    /* 错：cur 是指针，应用箭头 */
printf("%d", cur->count);   /* 对 */
```

**错误 3：释放时顺序颠倒**

```c
free(cur);
cur = cur->next;      /* 错：cur 已释放，再读它的 next 属于非法访问 */
```

必须先 `tmp = cur->next;` 存下下一个，再 `free(cur)`，最后 `cur = tmp;`。

**错误 4：没有检查 malloc 是否成功**

```c
struct Word *p = malloc(sizeof(struct Word));
if (p == NULL) return 1;    /* 对：内存不足时及时退出 */
```

小规模练习中很少失败，但工程上必须检查。

## 七、与综合实验的衔接

- 实验 **B6（文本热度分析）**中，"词条表组织"模块就是本练习的直接放大：实际程序每读到一个新词，先遍历链表查是否已存在，存在就把 `count` 加一，不存在才新建节点——这正是"链表查找 + 插入"。学到第 7 章后面的内容后，还可以对链表做排序、删除低频词——本练习先把"建链、遍历、释放"三部曲写对；
