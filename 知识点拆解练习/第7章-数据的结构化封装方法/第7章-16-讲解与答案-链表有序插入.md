## 二、预备知识：有序插入是怎么"边找边插"的（零基础阅读）

### 1. 什么是"有序链表"

一条链表的节点如果从头到尾**按某个关键字单调排列**（本题按载荷 `load` 升序），它就是**有序链表**。有序链表的好处是：遍历出来天然有序，取最小值就是链头，取分位数、判断单调性都非常方便。维护有序性的代价是——**每次插入都要先找位置，不能再随便头插或尾插**。

### 2. 找位置：停在"第一个不小于新值的节点"前面

设想要把新记录 N 插进升序链。它应该插在"所有比它小的节点"之后、"第一个不小于它的节点"之前。于是从链头开始走，一边走一边比较：

```
升序链：  head ──► [10] ──► [30] ──► [50] ──► NULL
要插入：  N = 25

第 1 步：cur=[10]，10 < 25 → 跳过，prev=[10]，cur=[30]
第 2 步：cur=[30]，30 < 25 不成立 → 停下
结论：N 插在 prev=[10] 之后、cur=[30] 之前
```

循环条件写成 `while (cur != NULL && cur->load < p->load)`：只要当前节点的载荷**小于**新值就继续走；一旦遇到"不小于"的节点，或者走到链尾（`cur == NULL`），就停下来。停下来的位置就是新节点的归宿。

### 3. 改接：头插与中间插入其实是一回事

停下来后有两种可能，画出来一看就清楚。

**情形一：新值最小（或空链），`prev == NULL`** —— 新节点应成为新链头：

```
改接前：  head ──► [30] ──► [50] ──► NULL   ,  N=[5]
执行：    p->next = head;   head = p;
改接后：  head ──► [5] ──► [30] ──► [50] ──► NULL
```

**情形二：插在中间或尾部，`prev != NULL`** —— 把它夹在 `prev` 和 `cur` 之间：

```
改接前：  head ──► [10] ──► [30] ──► [50] ──► NULL   ,  N=[25]
                    ▲prev   ▲cur
执行：    p->next = cur;      /* N 先指向 cur */
          prev->next = p;     /* 再让 prev 指向 N */
改接后：  head ──► [10] ──► [25] ──► [30] ──► [50] ──► NULL
```

（注意情形二里两句**顺序不能反**：先把 `p->next` 接好，再改 `prev->next`，否则会丢失 `cur` 往后的链。）当新值最大时，`cur` 走到 `NULL`，`prev` 指向尾节点，`p->next = NULL; prev->next = p;` 正好把新节点接成新的尾节点——中间插入的代码自动覆盖了尾插。

统一起来就是：

```c
if (prev == NULL) { p->next = head; head = p; }   /* 情形一 */
else              { p->next = cur;  prev->next = p; } /* 情形二（含尾插） */
```

**空链表**（`head == NULL`）时循环不执行、`prev` 就是 `NULL`，天然落进情形一，无需单独判断。这就是有序插入代码优雅的地方。

### 4. malloc/free

每条新记录都要 `malloc` 一个新节点并检查返回值是否为 `NULL`；所有插入完成后，程序结束前逐个 `free` 归还内存。

## 三、解题思路

1. **定义节点与指针**：`head = NULL`，另备 `prev`、`cur`、`p`；
2. **循环读入 m 条初始记录**：每条都 `malloc` 一个节点，执行一次有序插入；
3. **读入新记录**：同样 `malloc` + 一次有序插入；
4. **输出**：从 `head` 遍历，按链序即为升序，同时计数；
5. **释放内存**。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

struct IceLoad {
    int    id;
    double load;
    struct IceLoad *next;
};

/* 有序插入：把新节点 p 插入升序链表，返回新的链头 */
struct IceLoad *insert_sorted(struct IceLoad *head, struct IceLoad *p)
{
    struct IceLoad *prev = NULL, *cur = head;

    while (cur != NULL && cur->load < p->load) {  /* 跳过比新值小的 */
        prev = cur;
        cur = cur->next;
    }
    if (prev == NULL) { p->next = head; head = p; }  /* 插链头 */
    else              { p->next = cur;  prev->next = p; } /* 插中间/尾 */
    return head;
}

int main(void)
{
    int m, i, id, count;
    double load;
    struct IceLoad *head = NULL, *p;

    scanf("%d", &m);
    for (i = 0; i < m; i++) {                 /* m 条初始记录 */
        scanf("%d %lf", &id, &load);
        p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
        if (p == NULL) { printf("malloc failed\n"); return 1; }
        p->id = id; p->load = load; p->next = NULL;
        head = insert_sorted(head, p);
    }
    scanf("%d %lf", &id, &load);              /* 1 条新记录 */
    p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
    if (p == NULL) { printf("malloc failed\n"); return 1; }
    p->id = id; p->load = load; p->next = NULL;
    head = insert_sorted(head, p);

    count = 0;                                /* 输出升序链表 */
    p = head;
    while (p != NULL) {
        printf("%d %.2f\n", p->id, p->load);
        count++;
        p = p->next;
    }
    printf("count = %d\n", count);

    while (head != NULL) { p = head; head = head->next; free(p); }
    return 0;
}
```

## 五、运行验证

样例 1 输入的初始记录为 `30`、`10`、`50`（**未排序**），逐条有序插入的过程：

```
插入 30:  head ──► [101|30] ──► NULL
插入 10:  10 < 30，落情形一
          head ──► [102|10] ──► [101|30] ──► NULL
插入 50:  50 比所有都大，落情形二（尾插）
          head ──► [102|10] ──► [101|30] ──► [103|50] ──► NULL
插入 25:  25 介于 10 与 30 之间，落情形二（中间）
          head ──► [102|10] ──► [104|25] ──► [101|30] ──► [103|50] ──► NULL
```

遍历输出：

```
102 10.00
104 25.00
101 30.00
103 50.00
count = 4
```

与样例 1 一致。样例 2 中初始记录 `8`、`20` 建成升序链，新记录 `12` 有序插入到 `8` 与 `20` 之间，输出 `8`、`12`、`20`、`count = 3`，与样例 2 一致。若新记录比所有节点都小（如 `5`），走到链头落情形一，成为新链头；若比所有节点都大，则尾插，代码都能正确应对。

## 六、常见错误与讲解

**错误 1：情形二的改接顺序写反，丢失后半条链**

```c
prev->next = p;      /* 错：先让 prev 指向 p，cur 往后的链全丢了 */
p->next = cur;
```
正确顺序是 **先 `p->next = cur;`，再 `prev->next = p;`**。这与头插"先接后断"的道理完全一致：新节点先接住后面的链，前任再改指向它。

**错误 2：忘记处理"插在链头"的情形**

```c
prev->next = p;      /* 错：新值最小时 prev 为 NULL，崩溃 */
```
新值最小或链表为空时 `prev == NULL`，必须走 `head = p;` 这一支。用 `if (prev == NULL)` 判断即可，切勿遗漏。

**错误 3：查找条件写反或漏了 `cur != NULL`**

```c
while (cur->load < p->load) { … }              /* 错：cur 变 NULL 后解引用崩溃 */
while (cur != NULL && cur->load < p->load) { … } /* 对 */
```
条件里必须先判 `cur != NULL` 再访问 `cur->load`，否则走到链尾会访问空指针。另外若把 `<` 写成 `>`，插入位置就完全错了。

**错误 4：忘记 free**

插入型程序同样要回收内存。释放用 `while (head != NULL) { p = head; head = head->next; free(p); }`，先存后继再释放。
