## 二、预备知识：线性插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

试验只给了两个点：7 天强度 20.0 MPa，28 天强度 38.0 MPa。工程上要问"14 天时强度多少"，可表里没有 14 天这一档。假设两个龄期之间强度**均匀增长**（图象是一条直线），那么 14 天处的强度就在直线上按比例取一点——这就是**线性插值**。

### 2. 公式是怎么推出来的

设两已知点为 $(t_0,\, f_0)$、$(t_1,\, f_1)$，要求 $t_0 \le t \le t_1$ 处的 $f$。

"均匀增长"意味着**强度的增量与龄期的增量成正比**。龄期从 $t_0$ 走到 $t_1$，总共走了 $(t_1-t_0)$，强度相应涨了 $(f_1-f_0)$；现在龄期只走到 $t$，走了 $(t-t_0)$，强度就应涨"全程涨幅的同样比例"：

$$
\frac{f - f_0}{f_1 - f_0} = \frac{t - t_0}{t_1 - t_0}
$$

解出 $f$：

$$
f = f_0 + \dfrac{(f_1 - f_0)\,(t - t_0)}{t_1 - t_0}
$$

一句话：**起点值 + 全程涨幅 × 已走比例**。

### 3. 用本例走一遍

取 $t=14$，代入 $(t_0,f_0)=(7,20.0)$、$(t_1,f_1)=(28,38.0)$：

- 已走比例：$(14-7)/(28-7)=7/21\approx0.3333$，即走完约 1/3；
- 全程涨幅：$38.0-20.0=18.0$ MPa；
- 已涨部分：$18.0\times7/21=6.0$ MPa；
- 结果：$f = 20.0+6.0=26.0$ MPa。

验端点：$t=7$ 时结果是 20.0，$t=28$ 时结果是 38.0，与试验表一致。

### 4. 编程时怎么用它

公式里五个量：两个龄期、两个强度是常量，$t$ 是输入。翻译成一行赋值语句即可，唯一注意括号。**重点体会：这道题和练习 04 的声速插值，代码结构一模一样，只是常量表换了。** 这就是"程序 = 数据 + 算法"——算法（插值公式）不动，只换数据。

> 换一组常量，就能用于：A1 风荷载（高度→系数）、C1 声速剖面（深度→声速）、A7 混凝土强度（龄期→强度）、D3 核数据截面（能量→截面）。

## 三、解题思路

1. **确定常量**：两个试验点 (7, 20.0) 与 (28, 38.0)，用 `const double`；
2. **确定变量**：读入的龄期 `t` 和待求强度 `f`，都是 `double`；
3. **套公式**：`f = F0 + (F1 - F0) * (t - T0) / (T1 - T0)`；
4. **输出**：保留 2 位小数，用 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 两个试验点：龄期(d) 与 抗压强度(MPa) */
    const double T0 = 7.0;    /* 下档龄期 */
    const double T1 = 28.0;   /* 上档龄期 */
    const double F0 = 20.0;   /* 下档强度 */
    const double F1 = 38.0;   /* 上档强度 */

    double t;   /* 输入：养护龄期，d */
    double f;   /* 输出：插值得到的抗压强度，MPa */

    /* 读入龄期 */
    scanf("%lf", &t);

    /* 线性插值：f = f0 + (f1 - f0) * (t - t0) / (t1 - t0) */
    f = F0 + (F1 - F0) * (t - T0) / (T1 - T0);

    /* 输出，保留 2 位小数 */
    printf("f = %.2f MPa\n", f);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 14 | $20.0 + 18.0\times7/21 = 20.0+6.0 = 26.00$ | `f = 26.00 MPa` ✓ |
| 21 | $20.0 + 18.0\times14/21 = 20.0+12.0 = 32.00$ | `f = 32.00 MPa` ✓ |
| 7 | $20.0 + 18.0\times0/21 = 20.00$（下端点） | `f = 20.00 MPa` ✓ |
| 28 | $20.0 + 18.0\times21/21 = 38.00$（上端点） | `f = 38.00 MPa` ✓ |

端点值与试验表一致，说明插值公式实现正确。

## 六、常见错误与讲解

**错误 1：把 20.0 写成 20，导致类型混淆**

```c
const int F0 = 20;          /* 错：强度是实数量，且后续要参与比例运算 */
const double F0 = 20.0;     /* 对 */
```

**错误 2：公式漏括号**

```c
f = F0 + (F1 - F0) * t - T0 / (T1 - T0);     /* 错：优先级全乱 */
f = F0 + (F1 - F0) * (t - T0) / (T1 - T0);   /* 对 */
```

**错误 3：scanf 漏写 `&`、格式符用错**

```c
scanf("%lf", t);       /* 错：应写 &t */
scanf("%f", &t);       /* 错：double 读入用 %lf，%f 对应 float */
scanf("%lf", &t);      /* 对 */
```

**错误 4：照抄练习 04 却忘了改常量**

把 `H0/H1/C0/C1` 那套式子直接抄来、只改数值不改物理含义，容易把龄期放进声速的位置。写代码前先问自己："这两点横坐标是龄期还是深度？纵坐标是强度还是声速？"确保常量名与含义对应。
