## 二、预备知识：嵌套循环的打印模式（零基础阅读）

### 1. 问题是怎么来的

要画一张"条形图"，每一行由若干个星号组成，行与行之间的星号个数不同。也就是说，输出里有**两个层次**：一层是"总共几行"，另一层是"每行几个字符"。单层循环只能描述一个层次，所以必须用嵌套循环——这是所有"文本图形"程序共同的结构。

### 2. 方法是怎么想出来的

把任务拆成两步，各用一个循环：

- 外层循环 $i$ 从 1 到 $n$，表示"正在画第 $i$ 条"；
- 对每一条，先把这条的数值 $v_i$ 读进来，再让内层循环 $k$ 从 1 到 $v_i$，每转一圈打一个星号。

因为内层的循环次数 $v_i$ 每次都可能不同（由输入决定），所以**内层的上界是变量**，这正是嵌套循环最灵活的地方。用伪代码表达：

```c
for (i = 1; i <= n; i++) {         /* 有几条 */
    读入 v;
    打印 "i | ";
    for (k = 1; k <= v; k++)       /* 这条多长 */
        打印 "*";
    打印换行;
}
```

总共打印的星号数等于所有 $v_i$ 之和 $\sum_{i=1}^{n} v_i$。

### 3. 用本例走一遍

以样例 1（$n=5$，数值 3 7 2 9 5）为例：

- $i=1$：读入 $v=3$，先打印 `1 | `，内层 $k=1,2,3$ 各打一个 `*`，得到 `1 | ***`，换行；
- $i=2$：读入 $v=7$，打印 `2 | `，内层打 7 个 `*`，得到 `2 | *******`，换行；
- $i=3,4,5$：分别打 2、9、5 个星号。

注意**换行发生在内层循环之外**：先打完整条星号，再换行，这样星号才会排在同一行上。

### 4. 编程时怎么用它

三个要点：**① 行内不换行**：内层循环里只 `printf("*")`，绝不能带 `\n`；`\n` 必须放在内层循环结束后；**② 循环次数用数据**：内层上界写 `k <= v`，边读边用；**③ 变量分工**：外层用 `i`、内层用 `k`，序号 `i` 直接用于打印。这种"外层管行、内层管列（或长度）"的分工，和第 17 题遍历网格是同一种思路。

## 三、解题思路

1. **读入条数** `n`；
2. **外层循环** `i` 从 1 到 `n`，每轮先 `scanf` 读入本条长度 `v`；
3. **打印序号**：`printf("%d | ", i);`；
4. **内层循环** `k` 从 1 到 `v`，循环体只做 `printf("*");`；
5. **本条结束**：在内层循环之后 `printf("\n");`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n;                    /* 条形条数 */
    int v;                    /* 当前条形的长度（星号个数） */
    int i, k;                 /* i: 第几条；k: 星号计数 */

    scanf("%d", &n);          /* 读入条数 */

    /* 外层：逐条处理 */
    for (i = 1; i <= n; i++) {
        scanf("%d", &v);      /* 读入本条长度 */
        printf("%d | ", i);   /* 打印序号与分隔符 */

        /* 内层：打印 v 个星号（注意这里不换行） */
        for (k = 1; k <= v; k++) {
            printf("*");
        }

        printf("\n");         /* 本条结束，换行 */
    }

    return 0;
}
```

## 五、运行验证

| 输入 | 验证过程 | 程序输出 |
|---|---|---|
| 5 / 3 7 2 9 5 | 逐条打印 3、7、2、9、5 个星号 | `1 \| ***` / `2 \| *******` / `3 \| **` / `4 \| *********` / `5 \| *****` ✓ |
| 4 / 4 1 6 2 | 逐条打印 4、1、6、2 个星号 | `1 \| ****` / `2 \| *` / `3 \| ******` / `4 \| **` ✓ |
| 3 / 0 5 2 | 长度为 0 时该行 `\| ` 后无星号，内层循环一次也不执行 | `1 \| ` / `2 \| *****` / `3 \| **` ✓ |

第三组说明：当 `v = 0` 时，内层循环条件 `1 <= 0` 一开始就不成立，一次也不执行，正好输出空条。

## 六、常见错误与讲解

**错误 1：把换行写进了内层循环**

```c
for (k = 1; k <= v; k++)
    printf("*\n");        /* 错：每个星号独占一行，条形变成竖线 */
printf("*");              /* 对：内层只打星号 */
/* 内层结束后再 */ printf("\n");
```

**错误 2：内层循环次数差一个**

```c
for (k = 1; k < v; k++)    /* 错：只打 v-1 个星号 */
for (k = 1; k <= v; k++)   /* 对：打 v 个星号 */
```

用"从 1 数到 v"（`<=`）最不容易错。

**错误 3：内外层循环变量混用**

```c
for (i = 1; i <= n; i++)
    for (i = 1; i <= v; i++)   /* 错：外层变量被内层覆盖 */
```

内外层必须用不同的变量（`i` 与 `k`）。

**错误 4：读数据的位置不对**

数据个数由 `n` 决定，应当**在外层循环里逐条读入**（本题不用数组）。若在循环外一次性读 n 个又没有数组，就无处存放，会把数据丢掉。
