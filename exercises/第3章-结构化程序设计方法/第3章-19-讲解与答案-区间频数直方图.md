## 二、预备知识：多区间归属判断与分类计数的基本原理（零基础阅读）

### 1. 问题是怎么来的

要把一批数据分到几个筐里，就得对每个数据回答一个问题："**你属于哪一格？**"数据本身是连续的实数，区间却是分段的。判断一个实数落在哪一段，本质上是一串"比大小"，正好用**多分支 if-else 链**来表达。

### 2. 方法是怎么想出来的

设区间按从小到大排好序，用一串比较即可。关键技巧是**只在每个分支判断上界**：

$$
v < 20 \Rightarrow \text{区间 1};\quad
\text{否则 } v < 40 \Rightarrow \text{区间 2};\quad \dots
$$

为什么不必再判断下界？因为能走到第 2 个分支的样本，已经**隐含**满足 $v \ge 20$（第一个条件不成立意味着 $v \ge 20$）。这样写既简洁又不易出错。落到哪个区间，就把对应计数器加 1；最后用

$$
\text{占比}_i = \frac{c_i}{n}\times 100\%
$$

算出各区间比例。五个计数满足 $c_1 + c_2 + c_3 + c_4 + c_5 = n$，可用来检验统计有没有漏算或重算。

### 3. 用本例走一遍

以样例 1（$n=8$）为例，逐个判断：

- $12 < 20$ → 落在区间 1，$c_1$ 加 1；$35$：$35 \ge 20$ 但 $35 < 40$ → 区间 2，$c_2$ 加 1；
- $67$：$\ge 60$ 但 $< 80$ → 区间 4；$88$：$\ge 80$ → 区间 5；
- …… 全部走完后得 $c_1=1, c_2=2, c_3=1, c_4=2, c_5=2$，合计 8，与 $n$ 相符。

占比：$c_1/n = 1/8 = 12.5\%$，$c_2/n = 2/8 = 25.0\%$，依此类推。

### 4. 编程时怎么用它

三个要点：**① 用 `else if` 而不是并列的 `if`**：并列的独立 `if` 在区间重叠时会让一个样本被多次计数；`else if` 保证只命中一个分支；**② 计数器先清零**：`int c1=0, c2=0, ...;`，未初始化会得到乱数；**③ 百分号要转义**：`printf` 里要打印一个字面的 `%`，必须写成 `%%`（例如 `%.1f%%`）。

## 三、解题思路

1. **读入** `n`，定义 5 个计数器并全部初始化为 0；
2. **循环统计**：`for (i=1; i<=n; i++)`，每轮读入 `v`，用 if-else 链判断区间并自增相应计数器；
3. **计算并输出**：先输出区间标记，再输出计数，最后输出 `100.0 * c / n` 保留 1 位小数的百分比；
4. **自查**：五个计数之和应等于 `n`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n;                                   /* 样本个数 */
    double v;                                /* 当前样本值 */
    int c1 = 0, c2 = 0, c3 = 0, c4 = 0, c5 = 0;   /* 五个区间的计数 */
    int i;

    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        scanf("%lf", &v);
        /* 只在每个分支判断上界：能进入下一分支说明已大于等于其下界 */
        if (v < 20.0)       c1 = c1 + 1;
        else if (v < 40.0)  c2 = c2 + 1;
        else if (v < 60.0)  c3 = c3 + 1;
        else if (v < 80.0)  c4 = c4 + 1;
        else                c5 = c5 + 1;      /* 80 <= v <= 100 */
    }

    /* 输出每个区间的计数与占比（%% 打印一个百分号） */
    printf("[  0, 20) : %d (%.1f%%)\n", c1, 100.0 * c1 / n);
    printf("[ 20, 40) : %d (%.1f%%)\n", c2, 100.0 * c2 / n);
    printf("[ 40, 60) : %d (%.1f%%)\n", c3, 100.0 * c3 / n);
    printf("[ 60, 80) : %d (%.1f%%)\n", c4, 100.0 * c4 / n);
    printf("[ 80,100] : %d (%.1f%%)\n", c5, 100.0 * c5 / n);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：用并列的独立 `if` 而不是 `else if`**

```c
if (v < 40) c2++;      /* 若 v=10，会同时满足 v<40 和下面的 v<60 …… */
if (v < 60) c3++;      /* 错：一个样本被重复计入多个区间 */
```

必须用 `else if` 串成一条链，保证只命中一个分支。

**错误 2：计数器没有初始化**

```c
int c1, c2, c3, c4, c5;         /* 错：初值是内存中的随机数 */
int c1 = 0, c2 = 0, ...;        /* 对：计数器一律清零 */
```

**错误 3：打印百分号时忘记转义**

```c
printf("... (%.1f%)\n", p);     /* 错：单个 % 会被当作格式符，输出错乱 */
printf("... (%.1f%%)\n", p);    /* 对：%% 才输出一个百分号 */
```

**错误 4：百分比算成整数或忘乘 100**

```c
100 * c1 / n        /* 若全为 int，先整除再赋给 double，小数丢失；应写成 100.0 * c1 / n */
```

`100.0` 是实数，整个表达式按浮点运算，结果带小数，配合 `%.1f` 输出。

## 七、与综合实验的衔接

- 在实验 **C7（冰区结构载荷辨识与统计）**中，"载荷分布直方图"就是本练习的应用：真实程序的区间数目和边界可能由参数给定，还可能把计数再画成星号条形（结合第 18 题），但"逐样本判断归属 + 计数 + 算比例"的内核完全一致；
- 本练习是 if-else 多分支与循环配合的典型：如果区间很多（成百上千个），用 5 个变量手写计数就不现实了，第 5 章会引入**计数数组**把 $c_1,c_2,\dots$ 组织起来；再做直方图时还能与排序、查找结合。但无论区间多少，判断归属和累加计数的思路仍是这一题。
