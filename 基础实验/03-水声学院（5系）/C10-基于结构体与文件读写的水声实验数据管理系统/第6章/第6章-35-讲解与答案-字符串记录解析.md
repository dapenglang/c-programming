## 二、预备知识：字符串切分的基本原理（零基础阅读）

### 1. 问题是怎么来的

一条记录 `"S01,15.5,08:30"` 在内存里就是 14 个字符排成一排，最后跟 `'\0'`。程序并不"认识"字段——所谓解析，就是**找到两个逗号的位置，把中间的字符分别搬走**。这项工作在 C10 里是结构体录入（M2）与文件读入（M3/M9）的前置步骤：文本进来的都是一整行，字段是切出来的。

### 2. 核心武器：`strchr` + 结束符改写

```c
char *q = strchr(line, ',');   /* q = 第一个逗号的地址；没有则 q == NULL */
```

拿到地址后做两件事：

**第一件：截断。** 把逗号改成 `'\0'`，字符串就"到此为止"：

```
改前： S 0 1 , 1 5 . 5 , 0 8 : 3 0 \0
              ↑q
改后： S 0 1 \0 1 5 . 5 , 0 8 : 3 0 \0
              ↑q（q+1 指向 '1'）
```

`line` 现在（从 `strchr` 视角）就是 `"S01"`——第一个字段到手。

**第二件：推进。** 第二个字段从 `q + 1` 开始，对它再 `strchr` 找下一个逗号，同样截断；剩下的 `q + 1` 就是第三个字段。

这套"**找分隔符 → 改结束符 → 指针推进**"是 C 语言字符串解析的标准套路。

### 3. 字段的两条去向

- **当字符串用**（编号、时刻）：`strcpy(id, line);` 整段复制走；
- **当数用**（水深）：`atof(q + 1)` 把 `"15.5"` 转成 `15.5`。

### 4. 用本例走一遍

对 `"S01,15.5,08:30"`：

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | `q = strchr(line, ',')` | q 指向第一个 `,` |
| 2 | `*q = '\0'; strcpy(id, line);` | `id = "S01"` |
| 3 | `q++`，`r = strchr(q, ',')` | r 指向第二个 `,` |
| 4 | `*r = '\0'; depth = atof(q);` | `depth = 15.5` |
| 5 | `r++`，`strcpy(tm, r);` | `tm = "08:30"` |

三字段齐全。样例 1 三行记录水深 15.5、18.2、22.0，最大者 22.0，对应编号 S03——与样例一致。

> **这个套路在综合实验中反复出现**：C10 的键盘录入校验与文件批量读入（M2/M3/M9）都靠它把 CSV 行拆成字段；C6/C7/C9 的数据文件读入同理。学会一次，处处可用。

## 三、解题思路

1. `fgets` 读一行，去掉行末 `'\n'`；
2. 两次"找逗号 → 截断 → 推进"，得到编号、水深字符串、时刻；
3. `atof` 转水深，`strcpy` 搬编号与时刻，输出；
4. 顺手比较记录最大水深，最后输出最大者。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int main(void)
{
    char line[64], id[32], tm[32];
    char *q, *r;
    double depth, mx = -1.0;    /* 水深非负，-1 作"暂无"初值 */
    char mxid[32];
    int n, i;

    scanf("%d", &n);
    getchar();                          /* 吃掉数字后的换行 */
    for (i = 0; i < n; i++) {
        fgets(line, sizeof(line), stdin);
        line[strcspn(line, "\n")] = '\0';       /* 去行末换行 */

        q = strchr(line, ',');                  /* 找第 1 个逗号 */
        if (q == NULL) continue;
        *q = '\0';                              /* 截断 → 编号字段 */
        strcpy(id, line);

        q++;                                    /* 越过逗号 */
        r = strchr(q, ',');                     /* 找第 2 个逗号 */
        if (r == NULL) continue;
        *r = '\0';                              /* 截断 → 水深字段 */
        depth = atof(q);

        r++;                                    /* 越过逗号 */
        strcpy(tm, r);                          /* 剩余即时刻字段 */

        printf("编号=%s 水深=%.1fm 时刻=%s\n", id, depth, tm);

        if (depth > mx) {                       /* 记录最大水深 */
            mx = depth;
            strcpy(mxid, id);
        }
    }
    printf("最大水深：%s %.1fm\n", mxid, mx);
    return 0;
}
```

## 五、运行验证

**样例 1**：

```
3
S01,15.5,08:30
S02,18.2,09:00
S03,22.0,09:30
编号=S01 水深=15.5m 时刻=08:30
编号=S02 水深=18.2m 时刻=09:00
编号=S03 水深=22.0m 时刻=09:30
最大水深：S03 22.0m
```

**样例 2**（单条记录，检验边界）：

```
1
A7,3.0,12:00
编号=A7 水深=3.0m 时刻=12:00
最大水深：A7 3.0m
```

| 样例 | 手算验证 | 程序输出 |
|---|---|---|
| 1 | 15.5/18.2/22.0，最大 22.0（S03） | ✓ |
| 2 | 3.0，最大即自身 | ✓ |

**反例验证**：把某行故意写成少一个逗号（如 `S01,15.5`），第二个 `strchr` 返回 `NULL`，程序跳过该行不崩溃——说明 `NULL` 判断生效。

## 六、常见错误与讲解

**错误 1：对字符串常量做截断**

```c
char *line = "S01,15.5,08:30";
*q = '\0';       /* 错：常量区不可写，运行时崩溃 */
char line[64] = "S01,15.5,08:30";
*q = '\0';       /* 对：数组可写 */
```

**错误 2：截断后忘推进，重复解析同一段**

```c
r = strchr(q, ',');
*r = '\0';
depth = atof(q);     /* 错：q 还停在第一个逗号后，atof 的其实是编号？不——此处 q 已是第二字段起点， */
                     /* 真正的错是：没有 q++/r++，下一字段起点错位 */
r++;                 /* 对：越过截断点 */
```

**错误 3：`fgets` 忘去 `'\n'`**

时刻字段会变成 `"08:30\n"`，输出后光标错位、比较也出错。一行 `line[strcspn(line, "\n")] = '\0';` 解决。

**错误 4：`scanf("%d")` 与 `fgets` 混用忘吃换行**

```c
scanf("%d", &n);
fgets(...);          /* 错：读到的是数字后残留的空行 */
scanf("%d", &n); getchar(); fgets(...);   /* 对：getchar 吃掉残留换行 */
```

**错误 5：水深字段用 `strcpy` 后再 `atof` 拼错地址**

字段起点是"逗号地址 + 1"，不是逗号地址本身：`atof(q)` 前 `q` 必须已指向数字首字符。
