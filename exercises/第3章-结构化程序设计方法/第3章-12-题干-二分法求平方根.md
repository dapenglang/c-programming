# 第 3 章 练习 12　二分法求平方根

**对应章节**：3 结构化程序设计方法（3.5 数值求解方法——二分法、3.3 循环结构、3.4 关系与逻辑运算）

**场景来源**：3.5 数值求解方法（二分法入门）。本练习以最简单的"求平方根"作为载体，练熟二分法的通用循环骨架；该骨架正是综合实验 C8《冰块浮力与平衡吃水计算系统》、D1《放射性核素活度衰变计算系统》中"方程求根"环节的地基。

**建议用时**：25 分钟

## 一、应用场景

很多工程问题最后都可归结为"求一个数 $x$，使得某个方程成立"。例如"求 $x$ 使 $x^2 = a$"，本质就是求 $a$ 的平方根。当方程复杂到写不出解析解时，工程上最可靠的通用办法之一就是**二分法**：把答案锁在一个区间里，每次把区间对折，看答案落在左半还是右半，如此反复，区间越缩越小，最终得到一个满足精度要求的结果。本练习用"求平方根"这个人人都会验算的问题，把二分法的完整流程走一遍。

## 二、任务要求

编写一个完整程序 `bisect_sqrt.c`：

1. 从键盘读入一个正实数 `a`（double，题目保证 `a > 0`）；
2. 用变量 `lo`、`hi` 表示当前搜索区间，初始取 `lo = 0`，`hi = a`（若 `a < 1` 则取 `hi = 1`，以保证区间一定包含答案）；
3. 用 **while 循环**反复执行：取中点 `mid = (lo + hi) / 2`；若 `mid * mid > a` 说明答案在左半边，令 `hi = mid`；否则令 `lo = mid`；
4. 当区间长度 `hi - lo < 1e-6` 时停止循环，输出 `(lo + hi) / 2` 作为结果，保留 6 位小数。

## 三、输入输出格式

**输入**：一行，一个正实数 `a`。

**输出**：一行，格式为 `sqrt = 结果`，结果保留 6 位小数。

## 四、样例

**样例 1**

输入：
```
2
```
输出：
```
sqrt = 1.414214
```

**样例 2**

输入：
```
0.25
```
输出：
```
sqrt = 0.500000
```

## 五、提示

二分法的核心是"**区间对折**"。始终保持一个性质：待求答案一定在 $[lo,\,hi]$ 之内。取中点

$$
mid = \frac{lo + hi}{2}
$$

判断 $mid^2$ 与 $a$ 的大小：

$$
mid^2 > a \Rightarrow \text{答案在左半边，令 } hi = mid;\qquad
mid^2 < a \Rightarrow \text{答案在右半边，令 } lo = mid
$$

每次循环区间长度减半，循环到 $hi - lo < 10^{-6}$ 即可认为精度足够。注意：本题**不要调用 `sqrt()` 函数**，必须自己用循环算出来（这正是 3.5 节"数值求解"要训练的能力）。

**完成本练习后你将具备的能力**：用 while 循环表达"逐步逼近"的过程、用关系表达式作为循环终止条件、区间的动态更新——这是实验 C8、D1 中一切方程求根问题的通用骨架。
