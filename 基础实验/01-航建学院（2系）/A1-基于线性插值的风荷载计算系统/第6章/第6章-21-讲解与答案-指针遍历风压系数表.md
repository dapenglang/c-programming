## 二、预备知识：指针的基本原理（零基础阅读）

### 1. 问题是怎么来的——内存像一排带编号的柜子

计算机的内存可以想象成**一排带编号的柜子**，每个柜子有一个"门牌号"（地址），里面可以放东西（数据）。你在程序里写 `double mu[5];`，就是向系统申请了 5 个连在一起的柜子，每个柜子放一个 `double`（占 8 个字节，即 8 个连续的小格）。

关键在于：**这 5 个柜子是有门牌号的**。假设第一个柜子的门牌号是 1000，由于每个 `double` 占 8 字节，那么 5 个柜子的门牌号分别是 1000、1008、1016、1024、1032。

```
地址:   1000      1008      1016      1024      1032
        +---------+---------+---------+---------+---------+
mu[]:   |  1.00   |  1.14   |  1.25   |  1.42   |  1.56   |
        +---------+---------+---------+---------+---------+
下标:      mu[0]     mu[1]     mu[2]     mu[3]     mu[4]
```

### 2. 指针是"存柜号的纸条"，* 是按柜号找东西，& 是查柜号

**指针变量**就是一张**专门用来记柜号的纸条**。定义 `double *p;` 表示"p 是一张能记 `double` 柜号的纸条"。

两个最基础的运算符：

- `&`（取地址）：给出某个变量的柜号。`&mu[0]` 就是 1000；
- `*`（解引用）：给出纸条上柜号里的东西。若 `p` 记的是 1000，则 `*p` 就是 `mu[0]` 的值 1.00。

**数组名其实就是首柜的柜号**。所以 `mu` 和 `&mu[0]` 完全等价，都等于 1000。

### 3. 指针遍历是怎么走的

```c
p = mu;          /* p 记下 1000，即指向第 0 个柜子 */
*p              /* 取出 1.00 */
p++;            /* p 变成 1008，指向下一个柜子（注意：跨过 8 字节，不是一个字节）*/
*p              /* 取出 1.14 */
```

每执行一次 `p++`，指针就向后跳一个元素。当 `p` 越过最后一个柜子的地址（`mu + 5` 对应 1040）时，循环结束。这就是 `for (p = mu; p < mu + 5; p++)` 的含义。

用本题数据画一张遍历中的快照：

```
初始:  p -> [1.00] 1.14  1.25  1.42  1.56      *p = 1.00
一轮后:p ->  1.00 [1.14] 1.25  1.42  1.56      *p = 1.14
二轮后:p ->  1.00  1.14 [1.25] 1.42  1.56      *p = 1.25
...                                            ...
末轮后:p ->  1.00  1.14  1.25  1.42 [1.56]      *p = 1.56
                 （此处 p 再 ++ 就越过末尾，循环结束）
```

### 4. 编程时怎么用它

遍历数组求最大值时，可以把"用下标"的思路直接翻译成"用指针"：

- 用一个指针 `pmax` 记住当前最大元素**所在的地址**（相当于下标版的 `imax`）；
- 每走一步，比较 `*p` 和 `*pmax`，大就更新 `pmax`；
- 循环结束时 `*pmax` 是最大值，它对应的下标可以用**指针相减**求出：`pmax - mu`（两个地址之差除以元素大小，得到相差几个元素）。

**注意**：本题同时要输出高度，可以维护两个同步移动的指针 `ph`（指高度数组）和 `p`（指系数数组），它们一起 `++`。

## 三、解题思路

1. **定义数组**：`double h[5] = {10,15,20,30,40};` 和 `double mu[5] = {1.00,1.14,1.25,1.42,1.56};`；
2. **定义指针**：`double *ph, *p, *pmax;`；
3. **双指针遍历**：`ph` 指高度、`p` 指系数，同时前进；每步输出 `*ph` 与 `*p`；
4. **同步打擂台**：若 `*p > *pmax` 则 `pmax = p`；同时用一个指针 `phmax` 记住对应高度；
5. **输出**最大值与高度。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* B 类粗糙度风压高度变化系数表（部分档位） */
    double h[5]  = {10.0, 15.0, 20.0, 30.0, 40.0};     /* 高度，m */
    double mu[5] = {1.00, 1.14, 1.25, 1.42, 1.56};     /* 系数，无量纲 */

    double *ph;         /* 指向高度数组当前位置 */
    double *p;          /* 指向系数数组当前位置 */
    double *pmax;       /* 指向当前最大系数所在位置 */

    pmax = mu;          /* 先假定第 0 个系数最大 */

    /* 用指针遍历整张表：ph 与 p 同步后移 */
    for (ph = h, p = mu; p < mu + 5; ph++, p++) {
        printf("h=%.0f mu_z=%.2f\n", *ph, *p);   /* *ph、*p 取出当前值 */

        if (*p > *pmax) {    /* 打擂台：遇到更大的就更新 */
            pmax = p;        /* 记住它所在的地址 */
        }
    }

    /* 输出最大值：pmax - mu 得到它相对首元素的偏移（即下标） */
    printf("max: mu_z=%.2f at h=%.0f\n", *pmax, h[pmax - mu]);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算/中间过程 | 程序输出 |
|---|---|---|
| 无（数据在程序中） | 遍历 5 个系数，逐个与当前最大比较，最后最大为 1.56，位于下标 4，对应高度 40 | 前 5 行如样例逐行输出，末行 `max: mu_z=1.56 at h=40` ✓ |

逐行核对：`*p` 依次为 1.00、1.14、1.25、1.42、1.56；`*ph` 依次为 10、15、20、30、40。打擂台过程：初始 pmax→1.00；1.14>1.00 更新；1.25>1.14 更新；1.42>1.25 更新；1.56>1.42 更新。最终 `*pmax = 1.56`，`pmax - mu = 4`，`h[4] = 40`。

## 六、常见错误与讲解

**错误 1：把指针当普通变量，忘记 `*`**

```c
p = mu;
printf("%.2f", p);     /* 错：打印的是地址（柜号），不是值 */
printf("%.2f", *p);    /* 对：*p 才是柜子里的数据 */
```

`p` 是纸条（地址），`*p` 是纸条指向的东西（数据）。输出数值必须写 `*p`。

**错误 2：指针没有初始化就解引用**

```c
double *p;
printf("%.2f", *p);    /* 错：p 是野指针，柜号未定，访问非法内存会崩溃 */
```

指针使用前必须让它指向一个合法地址。遍历前先写 `p = mu;`。

**错误 3：写成 `*p++` 以为和 `(*p)++` 一样**

```c
(*p)++;    /* 把 p 指向的值加 1 */
*p++;      /* 先取 *p，再把指针 p 后移（因优先级，等价于 *(p++)） */
```

两者含义完全不同。本题只需 `p++`（移动指针），不要动数据。

**错误 4：用 `p < mu + 5` 写成 `p <= mu + 5`**

```c
for (p = mu; p <= mu + 5; p++)   /* 错：多走一步，访问了尾后地址，越界 */
```

数组有 5 个元素，合法地址是到 `mu + 4`。结束条件是 `p < mu + 5`。
