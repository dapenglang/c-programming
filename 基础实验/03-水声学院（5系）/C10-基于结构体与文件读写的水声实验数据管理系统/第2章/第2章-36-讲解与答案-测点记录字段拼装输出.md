## 二、预备知识：格式化报表的基本原理（零基础阅读）

### 1. 问题是怎么来的

实验数据系统里，一条测点记录有多个字段：编号、时刻、深度、水温、回波强度。如果用最朴素的 `printf("%d %f %f ...")` 打印，每次字段宽度随数值变化，多行记录上下错位，看起来像一串歪歪扭扭的数字——看不出哪列是深度、哪列是温度。

交付给人看的输出必须像表格：**每一列占固定宽度，右对齐，列间有分隔符**。这是所有数据系统（C10 的报表模块、数据库终端、Excel）共同的排版思路。

### 2. 公式推导（printf 域宽的"算术"）

`printf` 域宽格式：`%[总宽][.小数位]类型`。以 `%10.1f` 为例：

- 小数位 `1`：小数点后保留 1 位（四舍五入）；
- 总宽 `10`：整个数字（**含小数点、负号**）至少占 10 个字符位；
- 不足 10 位时**左侧补空格**（右对齐）；超出 10 位时按实际宽度输出（不截断）。

数值占用的列数可以"推导"出来。设数值绝对值的整数部分有 $k$ 位，则一个 `%10.1f` 数值实际占

$$k + 1(\text{小数点}) + 1(\text{小数位}) + [\text{负号，若为负}]$$

个字符。例如 `38.2` 占 4 列 → 补 6 个空格；`-42.8` 占 5 列 → 补 5 个空格；`105.0` 占 5 列 → 补 5 个空格。

整行格式串 `"%6d|%10.1f|%10.1f|%10.1f|%10.1f\n"` 打印的总宽度为

$$6+1+10+1+10+1+10+1+10 = 50\ \text{列}$$

表头字符串也必须是 50 列、且每段宽度逐一对应，两行才能对齐。

### 3. 代入本例数值

样例 1：`id=207, t=14.5, depth=38.2, temp=12.6, echo=-42.8`。

- `%6d` 打印 `207`：占 3 列，补 3 空格 → `␣␣␣207`；
- `%10.1f` 打印 `14.5`：占 4 列，补 6 空格 → `␣␣␣␣␣␣14.5`；
- `-42.8`：占 5 列（含负号），补 5 空格 → `␣␣␣␣␣-42.8`。

拼接（`|` 分隔）后：

```
   207|      14.5|      38.2|      12.6|     -42.8
```

与表头 `    id|      t/h|  depth/m|   temp/C|  echo/dB`（各段分别为 6、10、10、10、10 列）逐列对齐。

### 4. 通过编程翻译

| 数学/排版意图 | C 语言 |
|---|---|
| 编号占 6 列 | `printf("%6d", id);` |
| 实数占 10 列、1 位小数 | `printf("%10.1f", t);` |
| 列间竖线 | 格式串里直接写 `|` |
| 换行 | `\n` |
| 五字段一行读入 | `scanf("%d %lf %lf %lf %lf", ...)` |

## 三、解题思路

1. 声明 `int id; double t, depth, temp, echo;`；
2. 一条 `scanf` 读五个字段；
3. 一条固定字符串 `printf` 打表头（题干已给出，照抄）；
4. 一条带域宽的 `printf` 打数据行。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int id;                     /* 测站编号 */
    double t, depth, temp, echo;/* 时刻、深度、水温、回波强度 */

    scanf("%d %lf %lf %lf %lf", &id, &t, &depth, &temp, &echo);

    /* 表头：各段宽度 6/10/10/10/10，与数据行严格对齐 */
    printf("    id|      t/h|  depth/m|   temp/C|  echo/dB\n");

    /* 数据行：%6d 与 %10.1f 域宽输出 */
    printf("%6d|%10.1f|%10.1f|%10.1f|%10.1f\n", id, t, depth, temp, echo);
    return 0;
}
```

## 五、运行验证

**样例 1**（输入 `207 14.5 38.2 12.6 -42.8`）：

```
    id|      t/h|  depth/m|   temp/C|  echo/dB
   207|      14.5|      38.2|      12.6|     -42.8
```

**样例 2**（输入 `31 6.0 105.0 8.4 -55.1`）：

```
    id|      t/h|  depth/m|   temp/C|  echo/dB
    31|       6.0|     105.0|       8.4|     -55.1
```

| 字段 | 格式 | 实际占列 | 补空格数 |
|---|---|---|---|
| 207 | `%6d` | 3 | 3 ✓ |
| -42.8 | `%10.1f` | 5（含负号） | 5 ✓ |
| 105.0 | `%10.1f` | 5 | 5 ✓ |

（表头与数据行均为 50 列，逐列对齐；所有数值均为 1 位小数精确值，输出无舍入歧义。）

## 六、常见错误与讲解

**错误 1：表头与数据行宽度不配**

```c
printf("  id | t/h | depth | temp | echo\n");        /* 错：每段宽度与 %6d/%10.1f 不等 */
printf("%6d|%10.1f|...\n", ...);
```

对齐的关键是**逐段宽度相等**。数格子的耐心比对任何"玄学调空格"都可靠。

**错误 2：以为域宽会截断超宽数据**

```c
printf("%10.1f", 123456789.12);   /* 实际输出 123456789.1，占 12 列，不截断 */
```

域宽是"至少"，不是"恰好"。C10 实验中若深度可能超过 8 位整数，应加宽域宽而不是指望截断。

**错误 3：忘记负号占宽度**——`-42.8` 占 5 列而非 4 列。若报表右边界差 1 格，通常是没算负号。

**错误 4：`scanf` 里 `double` 用 `%f`、`int` 用 `%lf`**——类型与占位符必须一一对应：`int→%d`，`double→%lf`（输入）/`%f`（输出）。
