# 第 5 章 练习 34　深度序列数组统计

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：5 一维数组（5.1 数组的定义与引用、5.2 数组的初始化与遍历、5.5 数组统计——求和/极值/均值）

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"分段统计（均值、极值）环节"的最小实现。

**建议用时**：30 分钟

## 一、应用场景

测深仪沿测线工作一段时间后，会得到一串**海底深度值**——比如每 10 秒记录一次的回波深度。拿到一串数，最先要回答的问题是：这段测线上**平均水深多少？最深、最浅各是多少？**

综合实验 C6 把回波深度时序存进**一维数组**，再对整个数组（或每个分段）做"求和取均值、打擂台找极值"的统计。本题就是这个统计环节的最小实现：把 n 个深度值读进数组，输出均值与极值。

## 二、任务要求

编写一个完整程序 `depth_stat.c`：

1. 从键盘读入样本个数 `n`（**题目保证 1 ≤ n ≤ 100**）；
2. 读入 `n` 个海底深度值（double，单位 m），存入一维数组 `depth[100]`；
3. 计算并输出三个统计量：
   - 平均深度（保留 2 位小数）；
   - 最大深度（最深处，保留 2 位小数）；
   - 最小深度（最浅处，保留 2 位小数）；
4. **禁止**先排序再取头尾——本题练的是"边遍历边统计"的数组基本功。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数（空格分隔）。

**输出**：三行，依次为：

```
平均深度 = xx.xx m
最大深度 = xx.xx m
最小深度 = xx.xx m
```

## 四、样例

**样例 1**

输入：
```
8
12.4 15.8 13.2 18.6 14.9 11.7 16.3 13.9
```
输出：
```
平均深度 = 14.60 m
最大深度 = 18.60 m
最小深度 = 11.70 m
```

**样例 2**

输入：
```
1
7.25
```
输出：
```
平均深度 = 7.25 m
最大深度 = 7.25 m
最小深度 = 7.25 m
```

（只有 1 个样本时，均值、极值都是它自己——注意均值分母是 `n` 而不是 1 之外的任何数。）

## 五、提示

- 统计三板斧，全在一个循环里完成：
  ```c
  sum  = 0;                       /* 累加器清零 */
  maxd = depth[0];                /* 极值初值 = 第一个元素，不能是 0！ */
  mind = depth[0];
  for (i = 0; i < n; i++) {
      sum += depth[i];            /* ① 求和 */
      if (depth[i] > maxd) maxd = depth[i];   /* ② 打擂台找最大 */
      if (depth[i] < mind) mind = depth[i];   /* ③ 打擂台找最小 */
  }
  ```
- **极值初值陷阱**：`maxd` 初值若设为 `0`，当所有深度都是负数时结果错误；设为第一个元素 `depth[0]` 则任何情况都对。
- 均值 = `sum / n`，注意 `sum` 是 double、`n` 是 int，C 会自动把 `n` 转成 double 再除，结果不会被"整除截断"。
- 想一想：为什么样例 2 里均值也等于 7.25？如果程序里把均值写成 `sum / 100`，样例 1 会输出多少？

**完成本练习后你将具备的能力**：把一批数据存入一维数组并用**一遍循环**同时完成求和与极值统计——这是实验 C6 中"分段统计模块（M8）"的地基，也是所有"数组统计"类实验的公共套路。
