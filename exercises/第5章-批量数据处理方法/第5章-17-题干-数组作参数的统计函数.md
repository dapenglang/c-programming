# 第 5 章 练习 17　数组作参数的统计函数

**对应章节**：5 批量数据处理方法（5.4 数组作函数参数；5.1 一维数组；4.1 函数定义与调用）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"载荷序列统计量计算函数库"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

载荷辨识系统里有大量地方需要对一条数据序列求"和、均值、最大值、最小值"。如果每处都重写一遍循环，代码会又长又容易出错。正确的做法是把这些计算**封装成函数**：调用者只递进去"一条数组 + 数据个数"，函数返回统计结果。本练习要求你把四个统计量各写成一个函数，首次体会"数组作函数参数"的用法，也为后续模块化协作打好基础。

## 二、任务要求

编写一个完整程序 `array_stats.c`，实现以下四个函数（形参一律使用 `double a[]` 与 `int n` 形式）：

1. `double sum(double a[], int n)`——返回 `n` 个元素之和；
2. `double mean(double a[], int n)`——返回平均值（即 `sum` 除以 `n`）；
3. `double maxv(double a[], int n)`——返回最大值；
4. `double minv(double a[], int n)`——返回最小值。

主函数中：

5. 读入数据个数 `n`（**题目保证 $1 \le n \le 100$**）与随后的 `n` 个实数，存入数组；
6. 依次调用四个函数并输出结果。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（空格分隔），表示载荷序列（单位：kN）。

**输出**：共 4 行：

```
sum = 和
mean = 平均值
max = 最大值
min = 最小值
```

每个数值保留 **2 位小数**。

## 四、样例

**样例 1**

输入：
```
5
12.5 13.2 11.8 14.6 13.9
```
输出：
```
sum = 66.00
mean = 13.20
max = 14.60
min = 11.80
```

**样例 2**

输入：
```
4
20.0 9.5 15.5 10.0
```
输出：
```
sum = 55.00
mean = 13.75
max = 20.00
min = 9.50
```

## 五、提示

1. **数组作参数的写法**：形参写成 `double a[]`（方括号里**不必**写长度），调用时直接把数组名 `r` 递进去，如 `sum(r, n)`；
2. **为什么必须同时传 `n`**：函数里只拿到数组的首地址，**它无法自己知道数组里有多少个有效元素**。字符数组还能靠 `'\0'` 判断结尾，数值数组没有这种"哨兵"，所以长度必须由调用者另外用一个参数 `n` 传进来。这是数组作参数最重要的一条纪律；
3. **求和的循环**：

$$
\text{sum} = \sum_{i=0}^{n-1} a[i]
$$

4. **求均值**直接复用 `mean` 里调用 `sum`：`return sum(a, n) / n;`，体会"函数调用函数"；
5. **求最值**先把答案设为 `a[0]`，再从 `i = 1` 开始逐个比较更新。

**完成本练习后你将具备的能力**：把对数组的遍历封装成函数、理解"数组名作参数传的是首地址、长度必须另传"、在函数内部调用函数——这是实验 C7 中"统计函数库"的地基，也是练习 20 综合报表的基础。
