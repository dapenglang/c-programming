## 二、预备知识：单位换算与自然对数的基本原理（零基础阅读）

### 1. 问题是怎么来的

中子能量是一个跨越近 8 个数量级的物理量：快中子约 \(10^{6}\ \text{eV}\)，热中子只有 \(0.025\ \text{eV}\)。核数据库（ENDF、IAEA 公开库）字段统一用 eV，而很多实验报告写 MeV。计算机在读入数据后，第一步就是把单位对齐，否则后续的慢化计算会整体错 \(10^{6}\) 倍。

### 2. 公式是怎么来的

**（1）单位换算**

"兆"（M）是国际单位词头，表示 \(10^{6}\)。所以：

$$
1\ \text{MeV} = 10^{6}\ \text{eV}
$$

一个数值从 MeV 换到 eV，就是把"每 1 MeV 含 \(10^{6}\) 个 eV"这个事实乘上去：

$$
E_{\text{eV}} = E_{\text{MeV}} \times 10^{6}
$$

**（2）自然对数**

自然对数 \(\ln x\) 的定义是：**以 \(e \approx 2.71828\) 为底、使得 \(e^{\ln x}=x\) 的那个指数**。它把"乘法"变成"加法"，正是处理跨数量级物理量的利器。由对数的乘法性质 \(\ln(ab)=\ln a + \ln b\)，有

$$
\ln\!\left(E_{\text{eV}}\right) = \ln\!\left(E_{\text{MeV}} \times 10^{6}\right) = \ln\!\left(E_{\text{MeV}}\right) + 6\ln 10
$$

用这条式子可以在心里快速估算：只要知道 \(\ln 10 \approx 2.302585\)，就能估算任意 MeV 能量的对数量级。

### 3. 用本例走一遍

**样例 1**：\(E_{\text{MeV}} = 1\)。

- 换算：\(E_{\text{eV}} = 1 \times 10^{6} = 1.0\times10^{6}\ \text{eV}\)；
- 对数：\(\ln(10^{6}) = 6 \times 2.302585 = 13.815511 \approx 13.8155\)。

**样例 2**：\(E_{\text{MeV}} = 2\)。

- 换算：\(E_{\text{eV}} = 2 \times 10^{6} = 2.0\times10^{6}\ \text{eV}\)；
- 对数：\(\ln(2\times10^{6}) = \ln 2 + \ln 10^{6} = 0.693147 + 13.815511 = 14.508658 \approx 14.5087\)。

两个样例与程序输出完全一致。

### 4. 编程时怎么用它

`math.h` 提供了 `log()`（自然对数）、`exp()`（自然指数）、`pow()`（幂）等函数。**三个纪律**：一是 `#include <math.h>`；二是函数自变量要写进括号里，如 `log(e_ev)`；三是部分编译器（GCC/Clang）在链接时需要加 `-lm`。所谓"把公式翻译成代码"，在这一步就是把 \(\ln(E_{\text{eV}})\) 写成 `log(e_ev)`。

> **这个思想在综合实验中反复出现**：D1 活度衰减里 \(\ln 2 / T_{1/2}\) 求衰变常数、D2 慢化里对数能量减缩、D3 截面查值里的对数能量轴、D5 剂量率里的指数衰减项，全部要用 `log()`/`exp()`。**同一套数学库，五处复用。**

## 三、解题思路

1. **确定数据**：单位换算因子 \(10^{6}\) 是物理常数，定义为 `const double MEV_TO_EV = 1.0e6;`；
2. **确定变量**：读入的 MeV 能量 `e_mev`、换算后的 eV 能量 `e_ev`、对数值 `ln_e`，都是实数，用 `double`；
3. **作换算与对数**：`e_ev = e_mev * MEV_TO_EV;`，再 `ln_e = log(e_ev);`；
4. **输出**：eV 结果用 `%.4e`（科学计数法保留 4 位小数），对数值用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
    /* 物理单位换算常数：1 MeV = 1e6 eV */
    const double MEV_TO_EV = 1.0e6;

    double e_mev;   /* 输入：中子能量，MeV */
    double e_ev;    /* 换算后：中子能量，eV */
    double ln_e;    /* eV 能量的自然对数，无量纲 */

    /* 读入 MeV 能量 */
    scanf("%lf", &e_mev);

    /* 单位换算：MeV -> eV */
    e_ev = e_mev * MEV_TO_EV;

    /* 求自然对数（math.h 的 log 函数） */
    ln_e = log(e_ev);

    /* 输出：eV 用科学计数法，对数用定点 4 位小数 */
    printf("E_eV = %.4e\n", e_ev);
    printf("lnE = %.4f\n", ln_e);

    return 0;
}
```

## 五、运行验证

| 输入（MeV） | 手算过程 | 程序输出 |
|---|---|---|
| 1 | \(10^{6}\)，\(\ln 10^{6}=6\ln10=13.8155\) | `E_eV = 1.0000e+06` / `lnE = 13.8155` ✓ |
| 2 | \(2\times10^{6}\)，\(\ln2+\ln10^{6}=0.6931+13.8155=14.5087\) | `E_eV = 2.0000e+06` / `lnE = 14.5087` ✓ |
| 14.1 | \(1.41\times10^{7}\)，\(\ln1.41+\ln10^{6}=0.3436+13.8155=14.1591\) | `E_eV = 1.4100e+07` / `lnE = 14.1591` ✓ |

样例 2 的对数由 \(\ln 2 \approx 0.693147\) 手算得 14.508658，四舍五入为 14.5087，与程序一致。

## 六、常见错误与讲解

**错误 1：漏写 `#include <math.h>`**

```c
#include <stdio.h>
/* 缺少 #include <math.h> */
...
ln_e = log(e_ev);   /* 错：编译器警告隐式声明，结果不可靠 */
```

不带 `<math.h>` 时，编译器会把 `log` 当成"未知函数"，按默认规则猜参数类型，浮点结果可能出错。**凡是调用数学函数的程序，第一行必须包含 `#include <math.h>`。**

**错误 2：忘记 `-lm` 链接选项**

```bash
gcc neutron_energy.c -o neutron_energy        # 可能报 undefined reference to `log'
gcc neutron_energy.c -o neutron_energy -lm    # 对：链接数学库
```

在 Linux/GCC 下数学函数位于单独的 `libm`，必须显式链接。这是核科学计算中最常见的编译错误之一。

**错误 3：把换算常数写成整数**

```c
const int MEV_TO_EV = 1000000;   /* 可运行，但语义上仍是实数因子 */
const double MEV_TO_EV = 1.0e6;  /* 对：物理常数用 double，且 1e6 写法不易数错零 */
```

写成 `int` 在本题不会立即出错，但当输入变成 \(3.5\) MeV 时，`3.5 * 1000000` 中若发生整数截断就会丢精度。**本章纪律：物理量一律用 `double`。**

**错误 4：输出格式与控制不符**

```c
printf("E_eV = %.4f\n", e_ev);   /* 错：1e6 会打印成 1000000.0000，不是科学计数法 */
printf("E_eV = %.4e\n", e_ev);   /* 对：得到 1.0000e+06 */
```

题干明确要求科学计数法，必须用 `%e`/`%.4e`。`%f` 与 `%e` 只是显示形式不同，数值本身不变。

## 七、与综合实验的衔接

- 实验 **D2（中子慢化模拟）**的第一步就是"能量初始化"：把源中子能量从 MeV 统一到 eV，并取对数进入对数能量坐标。本练习把这一步独立出来，让你**先专注于"读一个数、算两步、输出两个数"**而不被循环和随机数分心；
