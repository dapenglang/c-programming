## 二、预备知识：均值比较的基本原理（零基础阅读）

### 1. 问题是怎么来的

潮位观测每半小时记录一次水位，一天 48 个点。把白天时段的点求平均、夜间时段的点求平均，得到两个数：$h_{day}$ 与 $h_{night}$。

有了这两个数，水文分析员最关心的问题是：**这两个时段的水位差多少？总体水位又是多少？**前者叫昼夜均值差，用于刻画潮汐的不对称性；后者是全天总平均。综合实验 C7 的"前后半段均值趋势比较"模块，把"白天/夜间"推广成"序列前半段/后半段"，用的正是同样的减法与平均公式。

### 2. 公式推导

设白天时段（$n_1$ 个观测点）的潮位为 $x_1,\dots,x_{n_1}$，夜间时段（$n_2$ 个点）为 $y_1,\dots,y_{n_2}$，则

$$h_{day} = \frac{1}{n_1}\sum_{i=1}^{n_1} x_i,\qquad h_{night} = \frac{1}{n_2}\sum_{j=1}^{n_2} y_j$$

本题中这两个均值**已经算好**（作为输入给出），所以只需做两个后续量：

$$\Delta h = h_{day} - h_{night}$$

$$h_{all} = \frac{h_{day} + h_{night}}{2}$$

（严格说，只有当 $n_1 = n_2$ 时 $h_{all}$ 才等于两天段的算术平均；本题按两时段点数相同处理。）

- $\Delta h > 0$：白天水位整体更高；
- $\Delta h < 0$：夜间水位整体更高。

**差值的符号本身就是信息**——这就是"均值比较"不需要 `if` 的原因。

### 3. 代入本例数值

样例 1：$h_{day}=2.40$，$h_{night}=1.86$。

$$\Delta h = 2.40 - 1.86 = 0.54\ \text{m}$$

$$h_{all} = \frac{2.40 + 1.86}{2} = \frac{4.26}{2} = 2.13\ \text{m}$$

样例 2：$h_{day}=3.75$，$h_{night}=3.90$。

$$\Delta h = 3.75 - 3.90 = -0.15\ \text{m},\qquad h_{all} = \frac{7.65}{2} = 3.825 \approx 3.82\ \text{m}\ (\%.2f\ \text{舍入})$$

（3.825 在 IEEE-754 double 下表示为略小于 3.825 的数，`%.2f` 输出为 `3.82`，已用 Python 复核。）

### 4. 通过编程翻译

| 数学 | C 语言 |
|---|---|
| $h_{day},\ h_{night}$ | `double h_day, h_night;` |
| 读入 | `scanf("%lf %lf", &h_day, &h_night);` |
| $\Delta h = h_{day}-h_{night}$ | `dh = h_day - h_night;` |
| $h_{all}=\frac{h_{day}+h_{night}}{2}$ | `hall = (h_day + h_night) / 2;` |
| 输出 | `printf("day-night = %.2f m\n", dh);` 等 |

关键点：**先加括号再除**。C 的运算符优先级中 `/` 高于 `+`，`h_day + h_night / 2` 会被解释为 $h_{day} + \frac{h_{night}}{2}$，结果完全错误。

## 三、解题思路

1. 声明 `double h_day, h_night, dh, hall;`；
2. `scanf` 读入两个均值；
3. 计算 `dh` 与 `hall`（注意括号）；
4. 两次 `printf`，都用 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double h_day, h_night;      /* 白天、夜间平均潮位 */
    double dh, hall;            /* 昼夜均值差、全天总平均 */

    scanf("%lf %lf", &h_day, &h_night);

    dh = h_day - h_night;               /* 差值：白天减夜间 */
    hall = (h_day + h_night) / 2;       /* 总平均：先加后除，括号必须 */

    printf("day-night = %.2f m\n", dh);
    printf("overall = %.2f m\n", hall);
    return 0;
}
```

## 五、运行验证

**样例 1**（输入 `2.40 1.86`）：

```
day-night = 0.54 m
overall = 2.13 m
```

**样例 2**（输入 `3.75 3.90`）：

```
day-night = -0.15 m
overall = 3.82 m
```

| 输入 | $\Delta h$ | $h_{all}$ | 核对 |
|---|---|---|---|
| 2.40 1.86 | 0.54 | 2.13 | $4.26/2=2.13$ ✓ |
| 3.75 3.90 | −0.15 | 3.82 | $7.65/2=3.825$，`%.2f` 舍入为 3.82 ✓ |

**边界验证**：输入 `2.00 2.00`，输出 `day-night = 0.00 m`、`overall = 2.00 m`——两时段持平。

## 六、常见错误与讲解

**错误 1：总平均漏括号**

```c
hall = h_day + h_night / 2;      /* 错：等于 h_day + h_night/2 */
hall = (h_day + h_night) / 2;    /* 对 */
```

用样例 1 自测：错版算出 $2.40 + 0.93 = 3.33$，一对照样例就露馅。

**错误 2：整数除法**

```c
hall = (h_day + h_night) / 2;        /* 对：h_day 等是 double，除法是实数除法 */
int n = 2; hall = (h_day + h_night) / n;   /* 也对：分母是 int 但分子是 double，会被提升 */
double bad = 5 / 2;                  /* 错例：整数 5/2 = 2（若两侧都是 int） */
```

只要 `+`、`/` 两侧有一个 `double`，运算就按实数进行；**两侧都是 `int` 才会截断**。

**错误 3：`scanf` 漏写 `&`**

```c
scanf("%lf %lf", h_day, h_night);      /* 错：缺 &，程序崩溃或读不进去 */
scanf("%lf %lf", &h_day, &h_night);    /* 对 */
```

**错误 4：输出格式写成 `%d`**——`printf("%d", dh)` 对 `double` 是未定义行为，务必用 `%f` 系。
