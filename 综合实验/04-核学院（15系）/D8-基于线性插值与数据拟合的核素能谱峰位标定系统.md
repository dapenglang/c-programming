# 题目 D8：基于线性插值与数据拟合的核素能谱峰位标定系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行核素 γ 能谱峰位标定工具。γ 能谱仪的多道分析器输出的是一组"道址—计数率"数据（第 ch 道记录了计数率），而核素识别的关键是"某个峰对应多少 keV 的 γ 能量"。系统读入整段谱数据，先用滑动平均对计数率做平滑以压低统计涨落，再用局部极大判据找出所有峰的道址；随后用两个已知能量的标准源峰作为标定点，解出线性刻度关系 $E = k\cdot ch + b$，把每个峰的道址换算成能量；最后用峰两侧基线扣减算出峰净面积，按能量升序输出峰位表与能量刻度曲线，并写出标定报告文件。

能谱峰位标定是核测量中最基础也最不可省略的一步。谱仪的道址与能量之间没有固定的换算关系，会随高压漂移、温度变化和增益设置而改变；如果不做标定，测出来的峰永远只是"第 350 道"，无法判断它是 Cs-137 的 662 keV 还是别的什么。核素识别、活度定量、剂量率评估全部建立在"能量准确"这一前提上，可以说标定是把谱仪从"计数机器"变成"测量仪器"的关键环节。

本系统支撑的关键场景包括：① 环境样品 γ 能谱分析中的核素识别与能量刻度；② 核设施排出流监测中在线谱仪的日常能量校核；③ 放射性废物桶 γ 扫描测量（SGS）的峰位标定与活度计算；④ 应急监测中便携谱仪用标准源现场标定；⑤ 教学实验——用 Cs-137、Co-60 标准源亲手完成一次完整的能量刻度。系统只用课程内的线性插值、两点线性关系求解、滑动平均、排序查找与文件读写，把"谱数据—平滑—寻峰—刻度—换算—报表"这条专业数据链完整走通。本题目与核工程与核技术专业"核辐射探测与核电子学"方向直接对应。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的核素能谱峰位标定系统：从文本文件读入道址—计数率谱数据（含异常点）与两个标准源能量标定点，实现对计数率的滑动平均平滑、局部极大的峰位检测、由两点解线性刻度系数、峰位道址到能量的换算、峰净面积的基线扣减计算，按能量升序排列峰位表，输出能量刻度曲线与标定报告，并在菜单中调度全部功能。

专业关联上，本题目还原了能谱分析的标准工作流：平滑、寻峰、标定、换算、定面积。学生在实现中练熟一维数组遍历、窗口滑动、局部比较、两点线性关系求解、结构体数组排序与文件读写，理解"道址"与"能量"之间的线性映射以及"净面积"与"峰计数"的差别，全程不涉及任何机器学习或谱解析高级理论。

## 三、数据来源与格式

- **数据文件格式**：分两个文本文件。其一是谱数据文件 `spectrum.txt`，首行为标题说明，其后每行一条记录，字段以空格分隔，依次为：道址（整数，从 0 开始递增）、计数率（单位：计数/秒，正实数）。其二是标准源标定文件 `calib.txt`，给出两个已知峰的道址与能量。

```
# channel  count_rate_per_s
0          12.4
1          13.1
2          12.8
...
350       1842.6
...
351       1795.2
...
1023       9.7
```

```
# calib_id  channel  energy_keV
Cs-137       350      661.7
Co-60        637     1332.5
```

- **仿真数据生成规则**：
  - 道址 ch：整数，从 0 开始逐道递增至 1023（共 1024 道），不允许跳号；若出现跳号，读入模块应告警并按实际行序填充。
  - 计数率：单位计数/秒，取值范围 0.0～20000.0；本底水平 10～20 计数/秒，按均匀分布生成并叠加小幅统计涨落。
  - 谱峰：在指定道址处叠加高斯形峰（中心道址 ±15 道、峰高 1800～4000 计数/秒、半高宽 6～10 道），至少 2 个峰、至多 6 个峰；标定用峰应包含其中两个。
  - 标定点：道址取整数（落在峰中心附近），能量取标准核素的特征能量——Cs-137 的 661.7 keV、Co-60 的 1173.2 与 1332.5 keV、Na-22 的 511.0 keV、Mn-54 的 834.8 keV。
  - 平滑窗口：奇数，取值范围 3～15，由菜单输入，默认 5。
  - 寻峰判据参数：峰高下限（计数/秒，默认 100.0）与最小峰间距（道，默认 5）。
  - **异常值注入方式**：由教师提供的生成程序注入三类错误。其一，某几道计数率填负数（如 `-5.0`），校验时置 0 并告警；其二，个别道计数率填极端野值（如正常值的 50 倍），需靠滑动平均平滑抑制；其三，标定文件中道址超出谱范围（如 `2000`）或能量为 0，校验时剔除并提示重新指定标定点；另可注入非数字串（如 `NaN`），考察 `fscanf` 返回值判断。

- **真实数据集（如有）**：真实的 γ 能谱与核素特征能量可参考 NNDC 的 NuDat 数据库（https://www.nndc.bnl.gov/nudat3/ ）与 IAEA 核数据中心。学生**无需下载**真实数据，课程提供与上述字段含义对应的简化仿真谱，其中"道址—计数率"对应多道分析器的原始输出，"标定能量"对应 NuDat 中该核素 γ 射线的能量字段。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_CH      1024       /* 最大道数 */
#define MAX_PEAK     16        /* 最大峰数 */
#define MAX_WIN      15        /* 最大平滑窗口长度（奇数） */
#define MIN_PEAK_H  100.0      /* 默认峰高下限，计数/秒 */
#define MIN_PEAK_D    5        /* 默认最小峰间距，道 */

/* ===== 谱峰结构体 ===== */
struct Peak {
    int    ch;                 /* 峰位道址 */
    double energy;             /* 换算后的能量，keV */
    double rate;               /* 峰顶计数率，计数/秒 */
    double netArea;            /* 峰净面积（计数），基线扣减后 */
    int    srcIndex;           /* 对应的标准源下标，-1 表示非标定峰 */
};

/* ===== 标准源标定点 ===== */
struct CalibPoint {
    char   calibId[12];        /* 标准源标识，如 "Cs-137" */
    int    ch;                 /* 已知峰的道址 */
    double energy;             /* 已知峰的能量，keV */
};

/* ===== 能量刻度系数 ===== */
struct LinearCalib {
    double k;                  /* 斜率，keV/道 */
    double b;                  /* 截距，keV */
    int    solved;             /* 是否已求解：1 已解，0 未解 */
};

/* ===== 全局数据区 ===== */
double               g_rate[MAX_CH];    /* 原始计数率，计数/秒 */
double               g_smooth[MAX_CH];  /* 滑动平均后的计数率，计数/秒 */
int                  g_chCount;         /* 谱实际道数 */
struct Peak          g_peak[MAX_PEAK];  /* 峰位表 */
int                  g_peakCount;       /* 峰个数 */
struct CalibPoint    g_calib[2];        /* 两个标定点 */
struct LinearCalib   g_lin;             /* 能量刻度系数 k、b */
double               g_win[MAX_WIN];    /* 平滑窗口缓存 */
int                  g_winLen;          /* 平滑窗口长度，默认 5 */
double               g_peakTh;          /* 峰高下限，计数/秒 */
int                  g_peakDist;        /* 最小峰间距，道 */

/* ===== 处理日志 ===== */
struct LogItem {
    char op[24];              /* 操作名，如 "SOLVE_CALIB" */
    char detail[72];          /* 参数与关键结果摘要 */
};
struct LogItem g_log[128];
int            g_logCount;    /* 已记录日志条数 */
```

辅助说明：能量刻度为线性关系 $E = k\cdot ch + b$，由两个标定点联立求解——$k = (E_2-E_1)/(ch_2-ch_1)$，$b = E_1 - k\cdot ch_1$。峰净面积用峰两侧基线扣减：取峰左、右各若干道作为本底基线，用梯形思想对其上方的计数求和得到净计数。滑动平均结果写入 `g_smooth[]`，寻峰一律在 `g_smooth[]` 上进行，避免涨落造成假峰。

## 五、功能模块拆解（共 11 个模块）

### 第一部分：数据读入（2 个模块）

**M1 能谱数据读入模块**（源文件 `SpectrumIO.c`）
- 功能简介：打开谱数据文件，跳过标题行，循环读入道址与计数率，按行序填入 `g_rate[]` 并记录实际道数；计数率为负时置 0 并打印行号，道址跳号时告警并按行序填充，文件末尾道数超过 `MAX_CH` 时截断提示。  输入：谱文件路径（默认 `spectrum.txt`）；输出：`g_rate[]`、`g_chCount` 与读入报告。

**M2 标准源能量对读入模块**（源文件 `CalibIO.c`）
- 功能简介：读入两行标定记录（标识、道址、能量），检查道址落在 [0, `g_chCount`-1] 内、能量为正且两道址不相等（否则斜率无意义）；把有效标定点填入 `g_calib[]` 并把 `g_lin.solved` 置 0；越界或重复记录给出提示并拒绝。  输入：标定文件路径（默认 `calib.txt`）；输出：`g_calib[]`、`g_lin.solved = 0` 与屏幕确认信息。

### 第二部分：算法实现（5 个模块）

**M3 谱数据平滑模块**（源文件 `Smooth.c`）
- 功能简介：实现函数 `void smoothSpectrum(const double in[], double out[], int n, int w)`：对每一道取以它为中心的 w 个道（w 为奇数）求算术平均写入 `g_smooth[]`；在谱两端自动缩小窗口宽度；平滑前后各统计峰值与均方根，展示涨落被压低的程度。  输入：`g_rate[]`、道数、窗口长度 w；输出：`g_smooth[]` 与平滑前后统计对照。

**M4 寻峰检测模块**（源文件 `FindPeak.c`）
- 功能简介：在 `g_smooth[]` 上逐道判断是否满足局部极大——当前道大于左右各 `MIN_PEAK_D` 道的值、且峰高不低于 `g_peakTh`；对满足条件的候选点再检查与上一个峰的间距是否小于 `g_peakDist`，过近时只保留更高者；把峰位道址、峰顶计数率填入 `g_peak[]` 并累计峰数。  输入：`g_smooth[]`、`g_peakTh`、`g_peakDist`；输出：`g_peak[]`、`g_peakCount` 与屏幕寻峰结果。

**M5 能量刻度系数求解模块**（源文件 `Calib.c`）
- 功能简介：由两个标定点解线性关系 $E = k\cdot ch + b$，算出斜率 $k = (E_2-E_1)/(ch_2-ch_1)$ 与截距 $b = E_1-k\cdot ch_1$，写入 `g_lin` 并把 `solved` 置 1；打印 k、b 数值以及"每道对应多少 keV"的解释，便于判断刻度是否合理（典型谱仪约 1 keV/道量级）。  输入：`g_calib[]`；输出：`g_lin`、`g_lin.solved = 1` 与屏幕刻度系数。

**M6 峰位能量换算模块**（源文件 `PeakEnergy.c`）
- 功能简介：遍历全部峰，用 `E = k·ch + b` 把峰位道址换算成能量（keV），写回 `g_peak[].energy`；对与标定点道址相差不超过 3 道的峰标注 `srcIndex` 为对应标准源，其余置 -1；打印"道址—能量—峰顶计数率"对照，便于核对标定是否正确。  输入：`g_peak[]`、`g_lin`；输出：带能量的峰位表。

**M7 峰净面积计算模块**（源文件 `PeakArea.c`）
- 功能简介：对每个峰取峰左、右各 5 道作为本底基线，用基线两端点做线性插值得到每道的本底值，把峰区各道计数减去本底后按梯形思想累加，得到峰净面积（计数）；同时给出峰区道数与基线水平，用于判断面积是否可靠。  输入：`g_peak[]`、`g_rate[]`；输出：`g_peak[].netArea` 与屏幕净面积表。

### 第三部分：数据输出（4 个模块）

**M8 能量刻度曲线输出模块**（源文件 `CalibPlot.c`）
- 功能简介：在屏幕打印"道址—能量"刻度曲线，沿道址方向抽样取点，用 `*` 标出刻度直线、用 `o` 标出落在曲线上的峰位，并在两侧标注能量范围；同时用字符柱状图展示各峰净面积的相对高度，让峰位与强度一目了然。  输入：`g_lin`、`g_peak[]`；输出：屏幕能量刻度曲线与峰强柱状图。

**M9 峰位表排序模块**（源文件 `PeakSort.c`）
- 功能简介：用选择排序把 `g_peak[]` 按能量升序排列，便于按能量顺序核对核素；排序同时搬移整套字段（道址、能量、计数率、净面积、来源标记），并统计相邻峰的能量间隔。  输入：`g_peak[]`、`g_peakCount`；输出：排序后的 `g_peak[]` 与屏幕升序峰位表。

**M10 标定报告文件输出模块**（源文件 `CalibIO.c`）
- 功能简介：把能量刻度系数、两个标定点、峰位表（道址—能量—峰顶计数率—净面积—是否标准源峰）写出到 `calib_report.txt`，并把峰位表按 CSV 格式写出到 `peaks.csv`，把平滑后的谱数据写出到 `spectrum_smooth.csv`；文件首行均写列名说明。  输入：`g_lin`、`g_calib[]`、`g_peak[]`、`g_smooth[]`；输出：三个结果文件与屏幕确认信息。

**M11 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读谱数据 / 读标定点 / 平滑 / 寻峰 / 解刻度 / 换算能量 / 算净面积 / 画刻度曲线 / 排序峰位 / 输出报告 / 退出），用 `do-while + switch` 调度 M1～M10；用状态标记约束"必须先读谱并完成平滑才能寻峰，必须解出刻度才能换算能量"。  输入：用户菜单选项；输出：调度各模块并维护日志表。

## 六、数据流与控制流

**控制流**：`main()` 进入 `do-while` 菜单循环，用 `switch` 分发 M1～M10。状态约束由三个标记承担：`g_chCount > 0` 才允许调用 M3；`g_smooth` 有效（M3 完成标志）才允许调用 M4；`g_lin.solved == 1` 才允许调用 M6～M10。M1/M2 顺序无关，但 M5 必须在 M6 之前执行，否则能量全为 0。

**数据流**：
```
spectrum.txt ─► M1 谱读入 ─► g_rate[]
calib.txt ────► M2 标定点读入 ─► g_calib[] ─► M5 解刻度 ─► g_lin(k,b)
                                  │
                                  ▼
                          M3 滑动平均平滑 ─► g_smooth[]
                                  │
                                  ▼
                          M4 寻峰检测 ─► g_peak[] (道址,峰顶计数率)
                                  │
                     ┌────────────┼────────────┐
                     ▼            ▼            ▼
          M6 峰位能量换算   M7 峰净面积   M9 峰位表排序
                     │            │            │
                     └────────────┼────────────┘
                                  ▼
                     ┌────────────┴────────────┐
                     ▼                         ▼
        M8 能量刻度曲线输出        M10 标定报告文件输出
                                  │
                                  ▼
                          M11 主控菜单调度
```

所有模块之间只通过全局谱数组 `g_rate[]`/`g_smooth[]`、峰位表 `g_peak[]`、标定点 `g_calib[]`、刻度系数 `g_lin` 与函数参数交换数据；能量换算公式只在 M6 中实现一次，其他模块一律调用 M6 的结果，禁止重复书写。

## 九、预期成果示例

```
====== 能谱数据读入（1024 道，有效 1024 道） ======
道 0~1023 计数率范围 3.7~3982.4 计数/秒；第 217 道计数率为负 -> 置 0
```
