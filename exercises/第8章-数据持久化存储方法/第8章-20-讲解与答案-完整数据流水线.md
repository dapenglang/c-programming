## 二、预备知识：完整流水线的基本原理（零基础阅读）

### 1. 为什么这样组织数据流

实验 C7 的主流程是一条**四站流水线**，站与站之间只传递"干净的数据"：

```
load_in.txt --【读入站】--> 数组 a[0..n-1] --【统计站】--> avg/max/min/count
                  |                            |
                  |                            v
                  +--------【排序站】--> 降序数组 --【报表站】--> load_report.txt + 屏幕
```

- **读入站**只负责"外存 → 内存"搬运加合法性校验，不做任何计算；
- **统计站**只负责"从乱序数组提取统计量"，不改动数组——统计与顺序无关，乱序照样算得准；
- **排序站**只负责"把数组变成降序"，不做统计；
- **报表站**只负责"把结果写成报表"，不做任何计算。

**为什么要分成四站？** 因为每站职责单一，出问题时能立刻定位是哪一站的错；要改统计口径只动统计站，要改报表样式只动报表站。这就是第 4 章"模块化"思想与第 8 章"文件流水线"骨架的合流：**函数是站的代码形态，文件是流水线的出入口**。

### 2. 各环节职责

**读入站**：fopen 检查（第 8 章 8.3 的铁律）、读 n 并校验 $(1 \le n \le 100)$（防止数组越界，练习 15 已练过）、循环 fscanf 读入、读完即 fclose。

**统计站**：要一次返回平均、最大、最小三个结果。函数的 return 只能带一个值，第 6 章的答案是**指针形参**：

```c
void stats(double a[], int n, double *pavg, double *pmax, double *pmin)
```

主调函数传三个变量的地址，被调函数通过 `*pavg = ...` 间接写入。超阈值计数因为依赖 `#define` 的阈值常量，可以放在统计函数里一并算，也可以单独算。

**排序站**：第 5 章冒泡排序的降序版——只把比较条件从 `a[j] > a[j+1]` 反成 `a[j] < a[j+1]`，每轮把最小值"沉"到末尾。

**报表站**：本题的点睛之笔。函数原型 `void report(FILE *out, ...)`，函数体内**只用 fprintf(out, ...)**。第 8 章 8.2 节讲过，`stdout` 是系统预先打开的"标准输出"文件指针——所以同一个函数传 `fo` 写进 load_report.txt、传 `stdout` 打印到屏幕，报表代码写一遍、两个出口复用。这就是"设备即文件"思想的第一次实际受益。

### 3. 文件指针生命周期

本题主函数里的生命周期清单：fin 覆盖读入站（读完即关）；fout 覆盖报表站（写完即关）。统计与排序发生在两个文件的活跃期**之间**，不占任何文件资源。每条退出路径（读入失败、n 非法、报表文件创建失败）都要清点"谁还开着"。流水线越长，这条纪律越重要。

## 三、解题思路

1. **读入**：封装 `read_data`（或直接写在 main 中）——fopen 检查、读 n 校验、循环读数组、fclose；
2. **统计**：调用 `stats(a, n, &avg, &max, &min)`，指针带回三个量；循环统计超阈值个数；
3. **排序**：调用 `sort_desc(a, n)` 冒泡降序；
4. **报表**：打开 load_report.txt（检查），`report(fo, ...)` 写文件、`report(stdout, ...)` 上屏幕，fclose；
5. **自查**：报表五行摘要与手算一致、降序序列与排序站输出一致。

## 四、参考代码

```c
#include <stdio.h>
#define N   100        /* 数组容量上限 */
#define TH  25.0       /* 超阈值判定阈值，kN */

/* 统计站：均值、最大、最小通过指针形参一次带回 */
void stats(double a[], int n, double *pavg, double *pmax, double *pmin)
{
    int i;
    double s = 0.0, mx = a[0], mn = a[0];
    for (i = 0; i < n; i++) {
        s += a[i];
        if (a[i] > mx) mx = a[i];
        if (a[i] < mn) mn = a[i];
    }
    *pavg = s / n;
    *pmax = mx;
    *pmin = mn;
}

/* 排序站：冒泡，从大到小 */
void sort_desc(double a[], int n)
{
    int i, j;
    double t;
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - 1 - i; j++)
            if (a[j] < a[j + 1]) {      /* 与升序只差比较方向 */
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
}

/* 报表站：一份代码两个去处（out 传文件指针或 stdout） */
void report(FILE *out, double a[], int n, double avg, double mx, double mn, int over)
{
    int i;
    fprintf(out, "====== 冰区载荷统计报表 ======\n");
    fprintf(out, "样本总数：%d\n", n);
    fprintf(out, "平均阻力：%.2f kN\n", avg);
    fprintf(out, "最大阻力：%.2f kN\n", mx);
    fprintf(out, "最小阻力：%.2f kN\n", mn);
    fprintf(out, "超阈值(>%.1f)样本数：%d\n", TH, over);
    fprintf(out, "------ 降序排序结果 ------\n");
    for (i = 0; i < n; i++)
        fprintf(out, "%.1f\n", a[i]);
}

int main(void)
{
    FILE *fin, *fo;
    double a[N], avg, mx, mn;
    int n, i, over = 0;

    /* 读入站：文件 -> 数组（含两道校验） */
    fin = fopen("load_in.txt", "r");
    if (fin == NULL) {
        printf("错误：无法打开 load_in.txt\n");
        return 1;
    }
    fscanf(fin, "%d", &n);
    if (n < 1 || n > N) {
        printf("数据个数无效\n");
        fclose(fin);
        return 1;
    }
    for (i = 0; i < n; i++)
        fscanf(fin, "%lf", &a[i]);
    fclose(fin);

    /* 统计站 + 排序站 */
    stats(a, n, &avg, &mx, &mn);
    for (i = 0; i < n; i++)
        if (a[i] > TH)
            over++;
    sort_desc(a, n);

    /* 报表站：先写文件，再上屏幕 */
    fo = fopen("load_report.txt", "w");
    if (fo == NULL) {
        printf("错误：无法创建 load_report.txt\n");
        return 1;
    }
    report(fo, a, n, avg, mx, mn, over);
    report(stdout, a, n, avg, mx, mn, over);
    fclose(fo);

    return 0;
}
```

## 五、运行验证

**统计量手算核对**（数据 8 个）：

- 总和：$23.5+25.1+19.8+27.6+22.4+24.9+31.2+18.7 = 193.2$，平均 $193.2/8 = 24.15$；
- 最大 31.2、最小 18.7（乱序数组中逐个比较得出，与顺序无关）；
- 超阈值（> 25.0）：25.1、27.6、31.2 共 **3** 个（24.9 不算，差 0.1 是特意设置的边界检验）。

**降序排序核对**：8 个数从大到小依次为 31.2、27.6、25.1、24.9、23.5、22.4、19.8、18.7（第 15 题的升序版反过来即此序列）。

**文件内容前后变化**：`load_in.txt` 保持不变；`load_report.txt` 新建，内容与题干样例逐字符一致（含表头、五个摘要行、分隔线与 8 行降序数值）。

**屏幕输出**：与 load_report.txt 内容完全相同——这正是 report 被调用两次的验证点。

**附加测试**：把第一行 8 改成 0，程序输出 `数据个数无效` 且不生成报表文件；把 load_in.txt 移走再运行，输出 `错误：无法打开 load_in.txt`——两道防线均生效（测完还原）。

## 六、常见错误与讲解

**错误 1：统计函数用 return 返回三个值**

```c
double stats(double a[], int n, double avg, double mx, double mn)   /* 错：形参是值拷贝，
    函数内对 avg/mx/mn 的修改回不到主函数，主函数读到的是未初始化的变量 */
void stats(double a[], int n, double *pavg, double *pmax, double *pmin)   /* 对：传地址，
    *pavg = ... 才能写回主函数的变量 */
```

第 6 章 6.2 节的核心结论在综合题里的第一次大考：**要改谁的值，就传谁的地址**。

**错误 2：报表函数里混用 printf 与 fprintf**

```c
void report(FILE *out, ...) {
    fprintf(out, "====== 冰区载荷统计报表 ======\n");
    printf("样本总数：%d\n", n);        /* 错：这一行永远上屏幕，写文件时丢失 */
}
```

报表函数体内**所有**输出都必须走 `fprintf(out, ...)`，一处 printf 就会造成文件与屏幕内容不一致。

**错误 3：先排序后统计超阈值也没错，但顺序混乱易出 bug**

本题统计与排序互不依赖，但若先排序再统计"第一个超阈值样本的位置"之类的量，就会依赖顺序。纪律是：**每站只依赖明说过的输入**，站与站之间除约定好的数组与统计量外互不伸手。

**错误 4：报表文件打开失败时屏幕报表也跟着没了**

```c
fo = fopen("load_report.txt", "w");
if (fo == NULL) return 1;      /* 可以接受，但更好的做法是提示后仍把报表输出到屏幕 */
report(fo, ...);
```

工程取舍：文件写不进去时，至少让用户在屏幕上看到结果。参考代码选择了简单退出，你能说出改进方案吗？（提示：`if (fo != NULL) report(fo, ...); report(stdout, ...);`）

**错误 5：stdout 用完去 fclose**

```c
fclose(stdout);    /* 错：stdout 由系统管理，程序不得关闭 */
```

stdout/stdin/stderr 是系统预打开的，只可使用、不可关闭——这也是 8.2 节"文件指针"概念的自然推论。
