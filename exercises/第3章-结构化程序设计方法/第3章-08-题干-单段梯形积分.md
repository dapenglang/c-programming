# 第 3 章 练习 08　单段梯形积分（积分方法入门）

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.5 数值积分——梯形公式）

**场景来源**：综合实验 C8《冰块浮力与淹没面积计算系统》（水声学院）——本练习是该实验中"淹没面积分段求积"环节的最小单元。

**建议用时**：25 分钟

## 一、应用场景

计算冰块的浮力时，需要先算出冰块**淹没在水下部分的截面积**。冰块经过风化与融蚀，侧壁并不垂直，其淹没部分在竖直平面内的轮廓近似为梯形：水线处的截面宽度较大，底部的截面宽度较小。工程上把这个不规则轮廓沿吃水方向分成许多窄条，每一窄条按梯形求积——**梯形公式就是数值积分最小的"积木块"**，第 3 章后面与第 4 章的所有数值积分程序都是用它一块块搭起来的。本练习先把这一块积木单独写对。

## 二、任务要求

编写一个完整程序 `trap_area.c`：

1. 从键盘读入 3 个实数：淹没轮廓在水线处的宽度 `b1`（上底，米）、底部宽度 `b2`（下底，米）、吃水深度 `h`（米）；
2. 用梯形面积公式计算淹没部分在该竖直面内的截面积 `area`（平方米）；
3. 按格式输出面积，保留 2 位小数。

## 三、输入输出格式

**输入**：一行，3 个实数 b1、b2、h，以空格分隔。

**输出**：一行，按格式 `area = 面积` 输出，保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
4.8 3.5 1.2
```
输出：
```
area = 4.98
```

**样例 2**

输入：
```
6.0 6.0 0.8
```
输出：
```
area = 4.80
```
（上底等于下底，梯形退化为矩形）

## 五、提示

梯形面积公式：

$$
S = \frac{(b_1 + b_2)\,h}{2}
$$

在数值积分的语言里，这个公式读作"**两端函数值的平均 × 区间长度**"——记住这个读法，它是后面所有积分程序的基础。

**完成本练习后你将具备的能力**：理解梯形公式作为数值积分基本单元的含义、把几何公式翻译成一行赋值语句——为多段梯形积分（练习 09）和矩形法积分（练习 10）做好准备。
