## 二、预备知识：多文件处理的基本原理（零基础阅读）

### 1. 问题是怎么来的

前几题的输入都来自**一个**文件。但真实数据常分散在多个文件里：每一期观测一个文件、每一类记录一个文件。程序必须能**打开一个、处理一个、关掉、再打开下一个**——这就是多文件处理。

难点在于：文件个数可能是可变的（比如本月有 5 期，下月有 6 期）。用**文件名字符串数组 + 循环**就能统一处理，不必为每个文件写一遍代码。

### 2. 文件名也是字符串

文件名在程序里就是字符串，可以放进数组：

```c
char *files[3] = {"s1.txt", "s2.txt", "s3.txt"};
```

`files[0]` 是 `"s1.txt"`，`files[1]` 是 `"s2.txt"`。循环变量 `k` 走 0～2，`files[k]` 就依次是三个文件名。`fopen(files[k], "r")` 打开第 k 个文件。

### 3. 输入文件"用完就关"，输出文件"只开一次"

这是本题最容易出错的地方：

- **输入文件**：每个只在处理它时用一会儿，处理完立刻 `fclose`。所以 `fopen`/`fclose` 都在循环**里面**；
- **输出文件**：所有输入文件的数据都要写进**同一个** `all.txt`，所以它必须在循环**外面**只打开一次，循环结束后再关闭。

如果输出文件在循环里反复以 `"w"` 打开，每次都会把之前写的内容**清空**，最后文件里只剩最后一期的数据——这是最典型的错误。

画一张结构图：

```
fout = fopen("all.txt","w")   <-- 循环外，只开一次
  │
  for k = 0..2:
  │    fin = fopen(files[k], "r")    <-- 循环内，每期开一次
  │      循环读 records:
  │         fprintf(fout, ...)        <-- 都写进同一个 fout
  │    fclose(fin)                    <-- 每期用完就关
  │
fclose(fout)                  <-- 循环外，收尾
```

### 4. 打开失败怎么办

某个文件可能不存在（比如某期还没观测）。此时 `fopen` 返回 `NULL`，若继续用会崩溃。合理做法是**提示并跳过**（`continue`），继续处理其余文件：

```c
if (fin == NULL) {
    printf("skip %s\n", files[k]);
    continue;                /* 跳过这一期，继续下一期 */
}
```

这样某一个文件缺失不会导致整个程序失败——这在工程上很重要。

### 5. 用本例走一遍

三个文件各 2 条记录。循环处理：

- k=0（期号 1）：读 `JC01 3.20`、`JC02 2.10`，写 `1 JC01 3.20`、`1 JC02 2.10`；
- k=1（期号 2）：写 `2 JC01 4.10`、`2 JC02 3.30`；
- k=2（期号 3）：写 `3 JC01 5.00`、`3 JC02 4.40`。

统计：记录数 6；沉降量和 $= 3.20+2.10+4.10+3.30+5.00+4.40 = 22.10$。

## 三、解题思路

1. **准备文件名数组** `files[3]`；
2. **循环外打开输出文件** `all.txt`（`"w"`）；
3. **循环 k = 0..2**：
   - 打开 `files[k]`，判空则 `continue`；
   - 循环 `fscanf` 读每条记录，写入 `fout`（带期号 `k+1`），累加 `total`、`sum`；
   - 关闭 `fin`；
4. **循环外关闭 `fout`**，输出统计。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    char *files[3] = {"s1.txt", "s2.txt", "s3.txt"};   /* 三期观测文件 */
    FILE *fout, *fin;
    char name[16];
    double s, sum = 0.0;
    int total = 0, k;

    /* 输出文件在循环外只打开一次 */
    fout = fopen("all.txt", "w");
    if (fout == NULL) {
        printf("open output failed\n");
        return 1;
    }

    /* 逐期处理 */
    for (k = 0; k < 3; k++) {
        fin = fopen(files[k], "r");
        if (fin == NULL) {                    /* 该期文件不存在：提示并跳过 */
            printf("skip %s\n", files[k]);
            continue;
        }

        /* 读取该期所有记录，写入合并文件 */
        while (fscanf(fin, "%s %lf", name, &s) == 2) {
            fprintf(fout, "%d %s %.2f\n", k + 1, name, s);   /* 期号 = k+1 */
            total++;
            sum += s;
        }

        fclose(fin);                          /* 该期用完就关 */
    }

    fclose(fout);                             /* 收尾关闭输出文件 */

    printf("total=%d\n", total);
    printf("sum=%.3f\n", sum);

    return 0;
}
```

## 五、运行验证

**输入**：`s1.txt`（JC01 3.20 / JC02 2.10）、`s2.txt`（JC01 4.10 / JC02 3.30）、`s3.txt`（JC01 5.00 / JC02 4.40）。

**运行后 `all.txt`**：

```
1 JC01 3.20
1 JC02 2.10
2 JC01 4.10
2 JC02 3.30
3 JC01 5.00
3 JC02 4.40
```

| 统计量 | 手算 | 程序输出 |
|---|---|---|
| 总记录数 | 2+2+2 = 6 | `total=6` ✓ |
| 沉降量之和 | 3.20+2.10+4.10+3.30+5.00+4.40 = 22.10 | `sum=22.100` ✓ |

变异验证：若把 `s2.txt` 删除（模拟缺一期），程序输出 `skip s2.txt`，`total=4`、`sum=14.70`，其余期正常合并——体现"跳过失败文件"的健壮性。

## 六、常见错误与讲解

**错误 1：输出文件开在循环里**

```c
for (k = 0; k < 3; k++) {
    FILE *fout = fopen("all.txt", "w");   /* 错：每期清空重写，只剩最后一期 */
    ...
}
```

输出文件必须在循环**外面**只打开一次。

**错误 2：输入文件忘记关闭**

```c
for (k = 0; k < 3; k++) {
    fin = fopen(files[k], "r");
    while (...) { ... }
    /* 漏了 fclose(fin); */
}
```

每处理完一个输入文件要关闭，否则文件句柄泄漏，文件数多时可能打不开后续文件。

**错误 3：`fopen` 失败不处理**

```c
fin = fopen(files[k], "r");
fscanf(fin, "%s %lf", name, &s);     /* 若 fin 为 NULL，直接崩溃 */
```

必须判空并 `continue` 或退出。

**错误 4：期号计算错误**

```c
fprintf(fout, "%d ...\n", k);        /* 若 k 从 0 开始，期号会从 0 开始 */
fprintf(fout, "%d ...\n", k + 1);    /* 对：期号 = 下标 + 1 */
```

留意"下标从 0 开始"与"期号从 1 开始"的差异。
