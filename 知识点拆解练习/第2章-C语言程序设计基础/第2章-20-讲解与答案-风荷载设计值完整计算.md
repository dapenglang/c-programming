## 二、预备知识：从"查系数"到"设计值"的三步原理（零基础阅读）

### 1. 问题是怎么来的

结构设计中的风荷载不能直接用一个数给出，它由"规范表格 + 多个修正系数"层层确定。给定建筑高度和所在地区的基本风压，规范要求：先按高度查出**风压高度变化系数**（高度越高、风压越大），再乘基本风压得到**标准值**，最后乘**分项系数**得到考虑安全裕度的**设计值**。本练习把这三步完整实现。

### 2. 三步的公式是怎么来的

**第一步，线性插值求 $\mu_z$。** 表格只给 10 m（1.00）和 20 m（1.23）两档，中间高度按均匀变化取值：

$$
\mu_z = \mu_{z0} + \dfrac{(\mu_{z1} - \mu_{z0})(h - h_0)}{h_1 - h_0}
$$

**第二步，乘基本风压得标准值。** 风压与系数成正比，标准值就是系数乘以该地区的基本风压：

$$
w_k = \mu_z \times w_0
$$

**第三步，乘分项系数得设计值。** 极限状态设计要在标准值上考虑荷载安全裕度，乘以风荷载分项系数：

$$
w = \gamma_Q \times w_k, \qquad \gamma_Q = 1.5
$$

### 3. 用本例走一遍

样例 1：$h = 15$，$w_0 = 0.40$。

- 插值：$\mu_z = 1.00 + 0.23 \times (15-10)/(20-10) = 1.00 + 0.23 \times 0.5 = 1.115$；
- 标准值：$w_k = 1.115 \times 0.40 = 0.446$；
- 设计值：$w = 1.5 \times 0.446 = 0.669$。

样例 2：$h = 18$，$w_0 = 0.40$。

- 插值：$\mu_z = 1.00 + 0.23 \times (18-10)/10 = 1.00 + 0.184 = 1.184$；
- 标准值：$w_k = 1.184 \times 0.40 = 0.4736$；
- 设计值：$w = 1.5 \times 0.4736 = 0.7104$。

结果随高度上升而增大，符合"越高风压越大"的规律。

### 4. 编程时怎么用它

程序就是三步顺序翻译：**插值一行、乘一行、再乘一行**，最后分别打印。要点是：表格值、分项系数都用 `const`，输入用 `double`，插值注意括号，输出统一 `%.4f`。

> **这个思想在综合实验中反复出现**：第 2 章各题练的"常量表、实数运算、插值、格式化输出"，在本题被串成一条完整流水线。实验 A1 只是在这条链上增加了更多档位和更多高度，其内核与本练习完全一致。

## 三、解题思路

1. **定义常量**：表格 `H0=10.0, H1=20.0, M0=1.00, M1=1.23`，分项系数 `GAMMA=1.5`，全用 `const double`；
2. **读入**：`h` 与 `w0` 两个 `double`，`scanf("%lf %lf", &h, &w0);`；
3. **第一步插值**：`mz = M0 + (M1 - M0) * (h - H0) / (H1 - H0);`；
4. **第二、三步连乘**：`wk = mz * w0;`、`w = GAMMA * wk;`；
5. **输出**：三行 `printf`，均用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 规范表格数据（B 类粗糙度）：相邻两档高度与风压高度变化系数 */
    const double H0 = 10.0;    /* 下档高度，m */
    const double H1 = 20.0;    /* 上档高度，m */
    const double M0 = 1.00;    /* 下档系数 */
    const double M1 = 1.23;    /* 上档系数 */
    const double GAMMA = 1.5;  /* 风荷载分项系数 */

    double h;      /* 建筑高度，m */
    double w0;     /* 基本风压，kN/m^2 */
    double mz;     /* 风压高度变化系数（插值结果） */
    double wk;     /* 风荷载标准值，kN/m^2 */
    double w;      /* 风荷载设计值，kN/m^2 */

    /* 读入高度与基本风压（题目保证 10 <= h <= 20） */
    scanf("%lf %lf", &h, &w0);

    /* 第一步：线性插值求风压高度变化系数 */
    mz = M0 + (M1 - M0) * (h - H0) / (H1 - H0);

    /* 第二步：标准值 = 系数 × 基本风压 */
    wk = mz * w0;

    /* 第三步：设计值 = 分项系数 × 标准值 */
    w = GAMMA * wk;

    /* 输出三个结果，均保留 4 位小数 */
    printf("mu_z = %.4f\n", mz);
    printf("w_k = %.4f\n", wk);
    printf("w = %.4f\n", w);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：常量写成整数**

```c
const int H0 = 10, H1 = 20;      /* 错：破坏了实数语义 */
const double M0 = 1, M1 = 1.23;  /* 错：1.00 写成 1 */
```

全用带小数点的 `double` 常量，才能保证后续运算都是实数运算。

**错误 2：忘记取地址符**

```c
scanf("%lf %lf", h, w0);        /* 错：程序崩溃或读不进数据 */
scanf("%lf %lf", &h, &w0);      /* 对：每个变量都要取地址 */
```

**错误 3：插值公式括号写错（最典型）**

```c
mz = M0 + (M1 - M0) * h - H0 / (H1 - H0);      /* 错：括号缺失，顺序全乱 */
mz = M0 + (M1 - M0) * (h - H0) / (H1 - H0);    /* 对：先减、再乘、再除 */
```

乘除优先于加减，$(h-H_0)$ 必须加括号。可先手算样例 1（$\mu_z$ 应为 1.1150）再上机核对。

**错误 4：连乘顺序或系数用错**

```c
w = GAMMA * w0;          /* 错：漏乘了系数 mz，设计值偏小 */
w = mz * w0;             /* 错：这是标准值 w_k，不是设计值 */
w = GAMMA * mz * w0;     /* 对：设计值 = 1.5 × μ_z × w0 */
```

注意区分**标准值** $w_k$ 与**设计值** $w$，两者只差一个分项系数，别混淆。
