## 二、预备知识：链表的基本原理（零基础阅读）

### 1. 问题是怎么来的——数组为什么不够用

数组很方便，但有两个限制：**长度必须事先定死**（`Node a[100]` 就最多存 100 个），而且**在中间插入/删除很麻烦**（要把后面所有元素整体搬移）。

施工工序的数量事先不知道：有的工程 5 道、有的 30 道。定大了浪费，定小了不够。链表正好解决这个矛盾——**它根据需要一个个地申请节点，并在链上接起来**，长度随时可变。

### 2. 节点 = 数据 + 下个节点地址

链表由一个个**节点**组成，每个节点是一个结构体：

```c
typedef struct Node {
    char  name[16];         /* 数据部分：工序名 */
    int   dur;              /* 数据部分：时长 */
    struct Node *next;      /* 链接部分：下一个节点的地址 */
} Node;
```

关键在 `next`：它是"**指向同一种节点的指针**"，存着下一个节点的柜号（地址）。有了它，节点之间就能串起来。注意 `struct Node *next` 这一句——结构体还在定义中就要引用自己，所以必须写 `struct Node *`（不能写 `Node *`）。

### 3. head 串起整条链

我们只需记住**第一个节点的地址**，叫它 `head`（头指针）。顺着 `head->next`、`->next->next` ……就能走遍整条链。最后一个节点的 `next` 设为 `NULL`，表示"到头了"。

用本题样例 1 画一张链表图：

```
 head
   │
   ▼
 ┌─────────┬─────┬──────┐   ┌───────┬─────┬──────┐   ┌──────┬─────┬──────┐
 │ "mould" │  2  │  ●───┼──▶│ "tie" │  5  │  ●───┼──▶│"pour"│  3  │ NULL │
 └─────────┴─────┴──────┘   └───────┴─────┴──────┘   └──────┴─────┴──────┘
```

每个 ● 就是一个 next 指针，指向下一个节点的地址。最后一个是 NULL，链条到头。

### 4. 尾插建链——指针怎么改接

从头开始，我们要一个个把新节点接到链尾。维护一个 `tail` 指针，始终指着当前链尾：

- **第一个节点**：`head = tail = 新节点`（头和尾都指向它，它的 next 先设为 NULL）；
- **后面的节点**：让当前尾巴的 next 指向新节点（`tail->next = 新节点`），再把 tail 挪到新节点（`tail = 新节点`）。

以插入 `tie` 为例：

```
插入前:  head         tail
           │            │
           ▼            ▼
        [mould|2|NULL]

步骤1: tail->next = newNode（把新节点挂到尾巴后面）
        [mould|2|●] → [tie|5|NULL]

步骤2: tail = newNode（把尾巴指针挪到新节点）
        [mould|2|●] → [tie|5|NULL]
                       ▲
                      tail
```

**插入的关键**：新节点的 next 先置 NULL，再让旧的 tail 指向它。顺序不能反。

### 5. 遍历与释放

**遍历**用一个游标 `p`：从 `head` 开始，每步 `p = p->next`，直到 `p == NULL`。

**释放**要小心：`free(p)` 之后，`p->next` 就读不到了，所以必须先**保存下一个节点**再释放当前：

```c
while (p != NULL) {
    Node *q = p->next;     /* 先记住下一个 */
    free(p);               /* 再释放当前 */
    p = q;                 /* 移到下一个 */
}
```

### 6. 用本例走一遍

读入 3 道工序：`mould 2`、`tie 5`、`pour 3`。建链后遍历：

- p = head（mould），输出 `mould dur=2`，累加 2；
- p = p->next（tie），输出 `tie dur=5`，累加得 7；
- p = p->next（pour），输出 `pour dur=3`，累加得 10；
- p = p->next（NULL），循环结束。

总工期 `T = 10`。

## 三、解题思路

1. **定义节点结构体** `Node`；
2. **读入 n**，循环 n 次：`malloc` 一个新节点、读入 name 与 dur、`next = NULL`、尾插到链上；
3. **遍历**：从 head 出发输出并累加 `dur`；
4. **输出总工期**；
5. **释放**：遍历时保存 next 再 free。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>          /* malloc、free */

/* 链表节点：工序名 + 时长 + 下一个节点地址 */
typedef struct Node {
    char  name[16];
    int   dur;
    struct Node *next;
} Node;

int main(void)
{
    int n, i;
    Node *head = NULL;       /* 头指针，初始为空链 */
    Node *tail = NULL;       /* 尾指针，用于尾插 */
    Node *p;
    int total = 0;

    scanf("%d", &n);

    /* 尾插法建立链表 */
    for (i = 0; i < n; i++) {
        Node *np = (Node *)malloc(sizeof(Node));   /* 申请一个新节点 */
        scanf("%s %d", np->name, &np->dur);
        np->next = NULL;                            /* 新节点先断尾 */

        if (head == NULL) {         /* 第一个节点 */
            head = tail = np;
        } else {                    /* 接到当前链尾之后 */
            tail->next = np;
            tail = np;
        }
    }

    /* 遍历链表：输出各工序并累加时长 */
    for (p = head; p != NULL; p = p->next) {
        printf("%s dur=%d\n", p->name, p->dur);
        total += p->dur;
    }
    printf("T=%d\n", total);

    /* 释放全部节点内存 */
    p = head;
    while (p != NULL) {
        Node *q = p->next;      /* 先保存下一个 */
        free(p);                /* 再释放当前 */
        p = q;
    }

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：忘记给新节点 next 置 NULL**

```c
Node *np = malloc(sizeof(Node));
scanf("%s %d", np->name, &np->dur);
/* 漏了 np->next = NULL; */
```

若新节点 next 是随机值，遍历时会跟着乱指针跑飞。**每个新节点的 next 都要先置 NULL**（对尾插而言）。

**错误 2：用 `malloc` 后不检查、不释放**

```c
Node *np = malloc(sizeof(Node));   /* 若内存不足返回 NULL */
```

工程代码应判空；本题数据量小可省，但**释放**不能省：用到 `malloc` 就必须有对应的 `free`，否则内存泄漏。

**错误 3：`free` 后还想用 `p->next`**

```c
free(p);
p = p->next;          /* 错：p 已释放，p->next 是非法访问 */
```

必须先 `q = p->next; free(p); p = q;`。

**错误 4：成员访问用点号**

```c
p.name                /* 错：p 是指针，要用 -> */
p->name               /* 对：p 指向的节点的成员 */
np->name              /* 对 */
```

只有**结构体变量**才用 `.`；**指向结构体的指针**用 `->`。等价写法是 `(*p).name`。
