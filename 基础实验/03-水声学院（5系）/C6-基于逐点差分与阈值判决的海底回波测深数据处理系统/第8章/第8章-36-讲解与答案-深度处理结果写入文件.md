## 二、预备知识：一阶差分与结果文件的写出

### 1. 问题是怎么来的

综合实验 C6 的主线是"逐点差分 → 阈值判决 → 分段统计"，其中差分是最底层的加工：相邻两次测得的回波深度相减，得到深度变化量。差分值大，说明海底在这一点发生了阶跃（可能是坡或沟）；差分值接近 0，说明海底平坦。而整条流水线的最后一步（M9），是把加工结果**落到磁盘**——变成一个能用 Excel 打开、能交给画图软件的文件。

一阶差分的定义（用 LaTeX 写出）：

$$
\mathrm{diff}[i] = d[i] - d[i-1], \quad i = 1, 2, \dots, n-1
$$

首点没有"前一点"，约定 $\mathrm{diff}[0] = 0.00$。

平均深度：

$$
\bar{d} = \frac{1}{n}\sum_{i=0}^{n-1} d[i]
$$

### 2. 写文件四步曲

**第一步：打开**

```c
FILE *fp = fopen("depth_result.csv", "w");
```

模式 `"w"`（write）：文件不存在则**新建**，已存在则**清空重写**。

**第二步：判断是否成功**

```c
if (fp == NULL) {
    printf("打开文件失败\n");
    return 1;
}
```

磁盘写保护、路径不存在、无权限……都可能导致打开失败。**每次 `fopen` 后必须判 `NULL`。**

**第三步：写数据**

```c
fprintf(fp, "%d,%.2f,%.2f\n", i + 1, d[i], diff[i]);
```

`fprintf` 的第一个参数是文件指针，其余用法与 `printf` **完全一样**——所以你会 `printf` 就会 `fprintf`。行末的 `\n` 是 CSV 的"换行"，一条记录一行。

**第四步：关闭**

```c
fclose(fp);
```

关闭时把缓冲区数据**冲刷到磁盘并释放资源**。忘关可能导致最后一部分数据没写进去。

### 3. 数据行和汇总行可以混在同一个文件里

本题文件里既有"逐点数据行"，又有"汇总行"。CSV 并不要求每行字段含义完全相同——只要**人能看懂、程序能解析**就行。写法上就是两个连续的循环/段落：

```c
for (i = 0; i < n; i++) {                       /* 数据行 */
    fprintf(fp, "%d,%.2f,%.2f\n", i + 1, d[i], diff[i]);
}
fprintf(fp, "max,%.2f\n", dmax);                /* 汇总行 */
fprintf(fp, "min,%.2f\n", dmin);
fprintf(fp, "mean,%.2f\n", dmean);
```

汇总行本身也是一种"一条记录"，字段是 `标签,数值`。这种"明细 + 汇总"的文件结构，在实验报告数据导出里非常常见。

### 4. 用本例走一遍

样例 1 的深度序列：

| 序号 $i$ | 深度 $d[i]$ | 差分 $\mathrm{diff}[i]=d[i]-d[i-1]$ |
|---|---|---|
| 1 | 12.50 | 0.00（首点约定） |
| 2 | 13.20 | $13.20-12.50=0.70$ |
| 3 | 12.80 | $12.80-13.20=-0.40$ |
| 4 | 15.60 | $15.60-12.80=2.80$ |
| 5 | 15.40 | $15.40-15.60=-0.20$ |

统计：$\bar{d} = \dfrac{12.50+13.20+12.80+15.60+15.40}{5} = \dfrac{69.50}{5} = 13.90$；最大 15.60，最小 12.50。

注意第 4 点差分 $+2.80$ 是全序列最大跳变——在 C6 的后续模块（阈值判决）里，这一步就是识别"海底阶跃"的依据。

> **这个思想在综合实验中反复出现**：C6 的结果文件输出、C7 的平滑结果输出、C10 的测点记录存档，全部是"把内部数据写成人类可读的文件"。掌握"明细 + 汇总"的 CSV 输出，实验的收尾模块就有了模板。

## 三、解题思路

1. **读入序列**：`scanf("%d", &n);`，循环读入 `d[i]`；
2. **算差分**：`diff[0] = 0;`，`for (i = 1; i < n; i++) diff[i] = d[i] - d[i-1];`；
3. **算统计**：一趟循环同时维护 `dmax`、`dmin`、`sum`，最后 `mean = sum / n`；
4. **打开文件**：`fopen("depth_result.csv", "w")`，判 `NULL`；
5. **写数据行**：循环写 `序号,深度,差分`；**写汇总行**：三行 `max/min/mean`；
6. **关闭文件**：`fclose(fp);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double d[100], diff[100];   /* 深度序列、一阶差分 */
    double dmax, dmin, sum, mean;
    FILE *fp;                   /* 输出文件指针 */
    int n, i;

    scanf("%d", &n);            /* 读入测点数 */
    for (i = 0; i < n; i++) {
        scanf("%lf", &d[i]);    /* 读入深度序列 */
    }

    diff[0] = 0.0;              /* 首点差分约定为 0 */
    for (i = 1; i < n; i++) {
        diff[i] = d[i] - d[i - 1];      /* 一阶差分 */
    }

    dmax = d[0];                /* 统计最大、最小、平均 */
    dmin = d[0];
    sum = 0.0;
    for (i = 0; i < n; i++) {
        if (d[i] > dmax) dmax = d[i];
        if (d[i] < dmin) dmin = d[i];
        sum += d[i];
    }
    mean = sum / n;

    fp = fopen("depth_result.csv", "w");    /* 第一步：以写入方式打开文件 */
    if (fp == NULL) {                       /* 第二步：判断是否成功 */
        printf("打开文件 depth_result.csv 失败\n");
        return 1;
    }

    for (i = 0; i < n; i++) {               /* 第三步：写数据行 */
        fprintf(fp, "%d,%.2f,%.2f\n", i + 1, d[i], diff[i]);
    }
    fprintf(fp, "max,%.2f\n", dmax);        /* 写汇总行 */
    fprintf(fp, "min,%.2f\n", dmin);
    fprintf(fp, "mean,%.2f\n", mean);

    fclose(fp);                             /* 第四步：关闭文件 */
    return 0;
}
```

## 五、运行验证

**运行前**，`depth_result.csv` 不存在（或存在旧内容）。

**第一次运行**（样例 1：5 点序列），**运行后** `depth_result.csv` 内容：

```
1,12.50,0.00
2,13.20,0.70
3,12.80,-0.40
4,15.60,2.80
5,15.40,-0.20
max,15.60
min,12.50

```

**第二次运行**（样例 2：3 点等深序列），因 `"w"` 会清空重写，**运行后** `depth_result.csv` 内容：

```
1,100.00,0.00
2,100.00,0.00
3,100.00,0.00
max,100.00
min,100.00
mean,100.00
```

| 样例 | 数据行数 | 差分自检 | 汇总自检 |
|---|---|---|---|
| 1 | 5 | $0.70-0.40=0.30$，$15.60-13.20=2.40=0.70+(-0.40)+2.80$ ✓ | $69.50/5=13.90$ ✓ |
| 2 | 3 | 全零差分对应等深序列 ✓ | 三个统计量都等于 100.00 ✓ |

**反例验证**：把文件名改成无权写入的路径（如只读目录），程序会打印 `打开文件 depth_result.csv 失败` 并正常退出——说明失败判断生效。

## 六、常见错误与讲解

**错误 1：不检查 `fopen` 返回值**

```c
FILE *fp = fopen("depth_result.csv", "w");
fprintf(fp, "%d\n", n);        /* 错：若 fp 为 NULL，程序崩溃 */
```

**错误 2：差分下标越界**

```c
for (i = 0; i < n; i++) diff[i] = d[i] - d[i - 1];   /* 错：i=0 时访问 d[-1] */
for (i = 1; i < n; i++) diff[i] = d[i] - d[i - 1];   /* 对：从第 2 点开始 */
```

首点差分要**单独赋 0**，循环从 `i = 1` 开始，否则读 `d[-1]` 是未定义行为。

**错误 3：忘写行末换行（所有行挤成一行）**

```c
for (i = 0; i < n; i++) {
    fprintf(fp, "%d,%.2f,%.2f", i + 1, d[i], diff[i]);   /* 错：漏 \n */
}
```

CSV 靠换行分记录，漏了 `\n` 整个文件会挤成一行，无法按行解析。

**错误 4：模式用错（写结果却用 `"r"`）**

```c
FILE *fp = fopen("depth_result.csv", "r");   /* 错：只读模式，fprintf 失败 */
FILE *fp = fopen("depth_result.csv", "w");   /* 对：写文件用 "w" */
```

`"r"` 只能读、不能写；把结果往只读打开的文件里写会失败。**记牢：读用 `"r"`，写用 `"w"`。**
