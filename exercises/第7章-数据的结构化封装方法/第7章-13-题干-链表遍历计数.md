# 第 7 章 练习 13　链表遍历计数

**对应章节**：7 数据的结构化封装方法（7.5 链表——链表遍历、遍历中累加与计数、`malloc`/`free`）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"对动态数据链做汇总统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

试验或监测结束后，需要给出这批冰载荷记录的**汇总指标**：一共多少条记录、载荷总和与平均值是多少、有多少条超过了报警阈值。数据存在链表里，既不能用数组的中央下标，也不能一开始就知道条数——唯一可行的办法是**从头到尾走一遍**：每走一步，把当前节点的载荷累加到总和里、把计数加一；遇到超过阈值的节点，再把超阈计数加一。这种"沿链遍历、边走边统计"的写法，是链表使用频率最高的操作。

## 二、任务要求

编写一个完整程序 `list_count.c`：

1. 定义节点结构体类型 `struct IceLoad`：`int id`（测点编号）、`double load`（载荷，kN）、`struct IceLoad *next`；
2. 读入整数 `n`，再读入 `n` 行记录（每行 `id` 与 `load`）以及一个实数阈值 `limit`，用**尾插法**建立链表；
3. 用**一次遍历**完成四项统计：节点总数 `count`、载荷总和 `sum`、平均载荷 `mean = sum / count`、载荷不小于 `limit` 的节点数 `over`；
4. 按规定格式输出四项结果，`sum`、`mean` 保留 2 位小数；
5. 遍历过程中不得修改任何节点；每次 `malloc` 检查返回值，程序结束用 `free` 释放全部节点。特别地，**当 `count = 0` 时不能做除法**，此时 `mean` 直接输出 `0.00`。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`（`0 ≤ n ≤ 100`）；
- 接下来 `n` 行：每行 `id load`；
- 最后一行：一个实数 `limit`（阈值，kN）。

**输出**：四行，依次为
```
count = 节点数
sum = 载荷总和
mean = 平均载荷
over = 不小于阈值的节点数
```
其中 `sum`、`mean` 保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
4
101 10.0
102 25.0
103 8.0
104 40.0
20
```
输出：
```
count = 4
sum = 83.00
mean = 20.75
over = 2
```

**样例 2**

输入：
```
3
1 5.0
2 5.0
3 6.0
6
```
输出：
```
count = 3
sum = 16.00
mean = 5.33
over = 1
```

## 五、提示

- 统计四件套的初始值：`count = 0; sum = 0.0; over = 0;`；
- 遍历骨架（务必背熟）：
  ```c
  p = head;
  while (p != NULL) {
      count++;                        /* 计数 */
      sum += p->load;                 /* 累加 */
      if (p->load >= limit) over++;   /* 条件计数 */
      p = p->next;                    /* 移动到下一节点 */
  }
  ```
- 平均值：`mean = sum / count;`。**除法前要保证 `count != 0`**；
- 阈值判定是 $load \ge limit$（"不小于"含等于），不要写成 `>`；`limit` 在全部记录读完后读入（`scanf("%lf", &limit);`）。

**完成本练习后你将具备的能力**：掌握链表遍历的通用骨架、在遍历中同步完成累加与条件计数、处理"空链表不能求平均"的边界——这是实验 C7"动态数据链统计模块"的地基。
