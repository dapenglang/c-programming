# 第 8 章 练习 21　灰度图像文件读写

**所属综合实验**：B1（B1-基于灰度直方图统计的图像二值化处理系统）

**对应章节**：8 文件（8.1 文件的概念与类型、8.2 文件的打开与关闭、8.3 文件的读写、3.2 选择结构、5.2 二维数组）

**场景来源**：综合实验 B1《基于灰度直方图统计的图像二值化处理系统》（人工智能学院）——本练习是该实验中"图像数据存取"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

图像二值化系统的输入常常是磁盘上的一个文件：文件里按行存放着每个像素的灰度值。系统读入这张"灰度表"，设定一个阈值（本题固定 128），把每个像素变成 0（黑）或 255（白），再把结果写回另一个文件。这样原始图像不受影响，处理结果单独保存。

读写文件是程序与磁盘打交道的基本功。B1 系统从"打开输入文件、逐行读入、处理、写出"这一整套流程开始。

## 二、任务要求

编写一个完整程序 `gray_file.c`：

1. 从键盘读入两个文件名：输入文件名和输出文件名；
2. 打开输入文件（文本方式读取），文件格式为：
   - 第一行两个整数：行数 $r$、列数 $c$（$1 \le r, c \le 20$）；
   - 接着 $r$ 行，每行 $c$ 个整数，为各像素的灰度值（$0 \le$ 灰度 $\le 255$）；
3. 逐个像素处理：灰度 $\ge 128$ 输出 `255`，否则输出 `0`；
4. 把处理后的 $r$ 行结果写入输出文件；
5. **必须检查 `fopen` 是否成功**，失败时给出提示并退出。

## 三、输入输出格式

**输入**：两行，第一行为输入文件名，第二行为输出文件名。

**输出**：程序不向屏幕输出图像数据；处理结果写入输出文件（每行 $c$ 个整数，空格分隔）。屏幕只输出一行提示，格式为：
```
done: r rows written
```

## 四、样例

**输入文件 `in.txt`**：
```
2 3
10 200 130
50 255 100
```

**运行**（输入两行文件名）：
```
in.txt
out.txt
```

**输出文件 `out.txt`**：
```
0 255 255
0 255 0
```

**屏幕输出**：
```
done: 2 rows written
```

## 五、提示

文件操作的**四步曲**：

1. **打开**：`fopen("in.txt", "r")`，返回文件指针 `FILE *fp`；若返回 `NULL` 说明打开失败（文件不存在等）；
2. **读写**：用 `fscanf(fp, ...)` 读、`fprintf(out, ...)` 写；
3. **关闭**：`fclose(fp)`；
4. **（对读文件）判空**：打开后立刻检查是否为 `NULL`。

二值化规则：

$$
g_{out} = \begin{cases} 255, & g \ge 128 \\ 0, & g < 128 \end{cases}
$$

注意本题**只需输出结果文件**，不必用数组存整幅图——每读一个就立刻判断、立刻写出去，这叫"流式处理"。

**完成本练习后你将具备的能力**：用 fopen 打开文件、检查打开是否成功、用 fscanf/fprintf 读写文本文件、用 fclose 关闭文件——这些是实验 B1 中"图像存取模块"的地基。
