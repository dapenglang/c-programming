# 题目 C2：基于滑动平均与中值滤波的水声信号去噪系统

**适用学院**：水声学院（5 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行水声信号去噪工具。它读入一段含噪水声信号（文件中同时给出用于对照的干净参考信号），提供波形统计概览、滑动平均滤波、中值滤波、去噪误差统计、窗口长度对比实验、波形字符画对比等功能，并把滤波结果写成数据文件、生成实验小结报告。

**解决什么重要问题**：水声信道中接收信号总是淹没在海洋环境噪声、本舰自噪声和脉冲干扰（敲击、流噪声野值）里。噪声不抑制，后续的检测、参数估计与识别都会失效：弱回波会被噪声淹没而漏检，脉冲野值又会被误判成目标而虚警。滑动平均利用"噪声随机、信号连续"的特点做低通平滑，中值滤波对脉冲野值有很好的抑制能力。两种方法若都不做，信号处理的后续环节就无从谈起。

**支撑哪些关键应用**：① 声呐回波预处理与波束形成前的阵元平滑；② 水声通信接收机前端抗噪；③ 被动声呐线谱增强与目标辐射噪声分析；④ 海洋环境噪声测量数据的清洗；⑤ 拖曳阵列姿态传感器数据的平滑。

**与专业培养的关联**：水声信号处理、数字信号处理课程的第一课就是时域去噪。本题让学生用 C 语言亲手实现两种最经典的时域滤波，建立"窗口滑动 + 逐点统计"的最核心直觉，为后续学习滤波器与谱分析打下基础，全程不涉及任何变换理论。

## 二、题目任务与专业关联

本题目要求小组用 C 语言实现上述水声信号去噪系统，完成"文件读入→统计概览→两种滤波→误差评估→对比实验→结果输出"的完整流程。具体任务包括：设计双列信号文件格式并容错读入含噪与干净信号；统计均值、峰值、有效值（RMS）；实现可变窗口的滑动平均滤波；实现窗口内排序取中位数的中值滤波；与干净参考信号比较计算平均绝对误差与均方根误差；对窗口长度 3/5/9/15 做对比实验；同屏绘制原始与滤波波形字符画；把滤波结果写出文件；生成实验小结报告；用菜单调度全部功能。

本题对应水声专业"从被污染的数据中恢复可用信号"的基础能力，学生在此过程中练熟一维数组遍历、窗口滑动、排序与文件读写。

## 三、数据来源与格式

**数据文件格式**：采用纯文本格式，第 1 行为格式标识，第 2 行为信号信息，其后每行两个浮点数（含噪值、干净参考值）。用 `fscanf(fp, "%lf", ...)` 循环读入即可。

```
SIG
S2 10000 8
0.2341  0.2100
-0.0456 -0.0300
0.5123  0.5000
...
1.9870  0.6400
```

字段含义：第 1 行 `SIG` 为格式标识（Signal）；第 2 行为信号名 `S2`、采样率 `10000`（Hz）、样本数 `8`；其后每行为"含噪样本值 干净参考值"，均为归一化幅度（相对满量程），典型范围 [−1.0, 1.0]，被脉冲噪声污染的样点可达 ±3.0。

**仿真数据生成规则**（逐字段给出）：

| 字段 | 单位 | 取值范围 | 分布规律与生成方式 |
|---|---|---|---|
| 信号名 | — | S1～S4 | 顺序编号 |
| 采样率 | Hz | 10000（或 48000） | 固定值，写入文件头 |
| 样本数 | 个 | 2000～4000 | 覆盖 0.2～0.4 s 时长 |
| 干净信号 s[n] | — | −1.0～1.0 | 基础 800 Hz 正弦（幅值 0.5）+ 3 段高斯包络脉冲（中心位于 0.05/0.10/0.15 s，幅值 0.8，宽度约 1 ms） |
| 环境噪声 | — | — | 高斯白噪声 σ=0.15，叠加缓慢基线漂移 0.05·sin(2π·2t) |
| 含噪信号 x[n] | — | −3.0～3.0 | x[n] = s[n] + 白噪声 |

**异常值与噪声注入方式**：在全部样点中随机选取 3～5 个位置注入脉冲野值，采用"随机位置 + 相邻两样点极性反转、幅值 ±(1.5～3.0)"的方式；白噪声用于检验滑动平均的平滑能力，脉冲野值用于检验中值滤波的抑制能力。文件中第 2 列始终是未被污染的干净信号，供误差统计模块作对照。

**真实数据集（如有）**：
- 公开水下听音器数据可参考 Ocean Networks Canada 水声观测：https://oceannetworks.ca/
- 其余以教师提供的实测转存文件（已同时给出含噪与降噪参考列）为主。

## 四、数据结构设计

```c
#define N_MAX 8192            /* 最大样本数 */
#define W_MAX 31              /* 最大窗口长度（奇数） */

/* 一段水声信号：含噪、干净参考与滤波结果 */
typedef struct {
    char   name[16];          /* 信号名，如 "S2" */
    int    fs;                /* 采样率，单位 Hz，取值 10000~48000 */
    int    n;                 /* 实际样本数 ≤ N_MAX */
    double x[N_MAX];          /* 含噪信号，归一化幅度，约 [−3.0, 3.0] */
    double s[N_MAX];          /* 干净参考信号，归一化幅度，[−1.0, 1.0] */
    double y[N_MAX];          /* 当前滤波输出，归一化幅度 */
} Signal;

Signal g_sig;                  /* 当前工作信号 */
double g_ma[N_MAX];            /* 滑动平均滤波结果 */
double g_med[N_MAX];           /* 中值滤波结果 */
double g_win[W_MAX];           /* 窗口内样本缓存，供排序取中值 */

/* 误差统计结果 */
typedef struct {
    char   method[24];         /* 方法名，如 "MA(W=5)" */
    double mae;                /* 平均绝对误差 */
    double rmse;               /* 均方根误差 */
} ErrStat;

ErrStat g_err[8];              /* 各方法的误差统计，供对比与报告 */
int     g_errCount = 0;        /* 已记录的方法数 */
```

全局数组置于文件作用域以避免栈溢出；各模块只通过 `g_sig`、`g_ma`、`g_med` 与函数参数交换数据。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 信号文件读入模块**（源文件 `SigIO.c`）
- 功能简介：打开信号文本文件，读入格式标识、信号名、采样率与样本数，再循环读入含噪值与干净参考值分别填入 `g_sig.x[]` 与 `g_sig.s[]`；文件不存在、标识错误或样本数越界时给出明确提示并返回失败标志。
- 输入：文件路径（菜单输入，默认 `sig_S2.txt`）。
- 输出：填充 `g_sig`（name/fs/n/x/s）；返回成功/失败标志。

**M2 波形统计概览模块**（源文件 `SigStat.c`）
- 功能简介：遍历样本分别统计含噪信号与干净信号的均值、峰值（绝对值最大）、有效值（RMS = √(Σx²/n)）、极差；输出对照表，便于判断污染程度。
- 输入：`g_sig`。
- 输出：屏幕统计信息。

### 第二部分：算法实现（4 个模块）

**M3 滑动平均滤波模块**（源文件 `MovingAvg.c`）
- 功能简介：实现变窗口滑动平均 `void moving_average(double in[], double out[], int n, int w)`，对每个样点取以其为中心的 w 点（w 为奇数）求算术平均；边界处自动缩小窗口；结果写入 `g_ma[]`，并统计滤波后的峰值与有效值。
- 输入：`g_sig.x[]`、样本数 n、窗口长度 w（3/5/9/15）。
- 输出：`g_ma[]`；屏幕统计信息。

**M4 中值滤波模块**（源文件 `MedianFlt.c`）
- 功能简介：实现中值滤波，对每个样点把窗口内 w 个样本拷入 `g_win[]`，用冒泡排序取中位数作为输出；边界处自动缩小窗口；结果写入 `g_med[]`，并统计滤波后的峰值与有效值。
- 输入：`g_sig.x[]`、样本数 n、窗口长度 w。
- 输出：`g_med[]`；屏幕统计信息。

**M5 去噪误差统计模块**（源文件 `ErrStat.c`）
- 功能简介：以干净参考信号 `g_sig.s[]` 为基准，对原始含噪信号、滑动平均结果、中值滤波结果分别计算平均绝对误差 MAE = (Σ|x−s|)/n 与均方根误差 RMSE = √(Σ(x−s)²/n)；把结果追加写入 `g_err[]`。
- 输入：`g_sig.s[]` 与待评估序列（`x`、`g_ma`、`g_med`）。
- 输出：`g_err[]`；屏幕误差对照表。

**M6 窗口长度实验模块**（源文件 `WinExp.c`）
- 功能简介：对窗口长度 3/5/9/15 依次调用 M3 与 M4 并计算 MAE，输出"窗口长度-滑动平均 MAE-中值 MAE"对比表，直观展示窗口变长的平滑效果与过度平滑风险。
- 输入：`g_sig`、窗口长度列表。
- 输出：屏幕窗口对比表；若干 `g_err[]` 记录。

### 第三部分：数据输出（4 个模块）

**M7 波形字符画对比模块**（源文件 `PlotSig.c`）
- 功能简介：把时间轴映射为横轴、幅度映射为纵向的字符区间，在同一屏幕上下两栏分别绘制原始含噪波形与滤波后波形（用 `.` 与 `*` 描点），并支持按步长抽样显示长序列。
- 输入：原始序列与滤波序列、样本数。
- 输出：屏幕波形字符画。

**M8 滤波信号写出模块**（源文件 `SigIO.c`）
- 功能简介：把当前选定的滤波结果与干净参考信号按两列格式写出到新文件 `sig_<信号名>_denoised.txt`，保证原始文件不被覆盖，并在文件头写入所用方法与窗口长度。
- 输入：`g_sig.name`、滤波序列、`g_sig.s[]`。
- 输出：滤波结果文件；屏幕确认信息。

**M9 实验小结报告模块**（源文件 `Report.c`）
- 功能简介：把信号基本信息、原始/滤波统计概览、各方法误差统计与窗口长度对比表写成 `denoise_report.csv`，并在屏幕汇总显示，供撰写实验报告引用。
- 输入：`g_sig`、`g_err[]`、`g_errCount`。
- 输出：`denoise_report.csv`；屏幕汇总表。

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读信号/统计/滑动平均/中值滤波/误差统计/窗口实验/画波形/写结果/看报告/退出），用 `do-while + switch` 调度 M1～M9；用状态标记约束"必须先成功读入信号才能处理"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 用 `do-while + switch` 显示菜单并分发 M1～M9，循环直至退出；状态标记 `g_loaded` 约束"未成功读入信号不得进行后续处理"。M1 完成后 `g_sig` 即可用，M3/M4 产生滤波结果，M5/M6 依赖滤波结果，M7/M8/M9 输出。

**数据流**：

```
信号文件 ─► M1 读入 ─► g_sig.x[] / g_sig.s[]
                          │
                          ▼
                   M2 波形统计概览
                          │
        ┌─────────────────┼──────────────────┐
        ▼                 ▼                  ▼
   M3 滑动平均       M4 中值滤波        M6 窗口长度实验
        │                 │            （循环调用 M3/M4）
        ▼                 ▼                  │
      g_ma[]          g_med[]                │
        └─────────────────┼──────────────────┘
                          ▼
                   M5 去噪误差统计 ─► g_err[]
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   M7 波形字符画    M8 滤波信号写出    M9 实验小结报告
                          │
                          ▼
                    M10 主控菜单调度
```

所有模块仅通过 `g_sig`、`g_ma`、`g_med`、`g_err` 及函数参数交换数据，函数接口在编码前书面约定。

## 十、选做扩展

1. 按 3σ 准则先标记并剔除脉冲野值，再做滑动平均，比较剔除前后的 MAE 变化。
2. 实现加权滑动平均（三角形权重 w_i 单调递增到峰再递减），仍是加权求和，比较与等权平均的差异。
3. 实现分段自适应窗口：按局部方差大小自动切换窗口长度（方差大时用小窗），统计量驱动，无新理论。
