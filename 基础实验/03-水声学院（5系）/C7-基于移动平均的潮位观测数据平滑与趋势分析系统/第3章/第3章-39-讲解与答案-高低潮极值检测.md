## 二、预备知识：局部极值检测的基本原理（零基础阅读）

### 1. 问题是怎么来的

潮位随时间起伏，一条观测序列 $x_1,\dots,x_N$ 画出来就是一条波浪线。水文分析要回答：波峰在哪（**高潮**）、波谷在哪（**低潮**）？有了峰谷才能算潮差、预报潮时。综合实验 C7 在移动平均平滑（去掉毛刺）之后，紧接着就做这道检测。

与练习 38 的思路一脉相承：判定一个点是否为极值，只需要它**自己和左右两个邻居**，共三个数——更早的数据不必保留。于是用三个变量组成一个**滑动窗口**沿序列滚动。

### 2. 公式推导

对内部点 $x_i$（$2 \le i \le N-1$）：

$$x_i \text{ 是高潮} \iff x_i > x_{i-1} \ \text{且}\ x_i > x_{i+1}$$

$$x_i \text{ 是低潮} \iff x_i < x_{i-1} \ \text{且}\ x_i < x_{i+1}$$

三个要点：

- **严格**不等号：若 $x_i = x_{i-1}$（平台段），两个条件都不成立，平台不判——平台的"真峰位"在数据里本就无法分辨；
- **互斥性**：$x_i$ 不可能同时比两个邻居都大且都小，所以高潮、低潮判据天然互斥；
- **首尾不判**：$x_1$ 缺左邻、$x_N$ 缺右邻，窗口无法覆盖，本题一概不算。

### 3. 代入本例数值

样例 1 序列：`2.1 2.8 3.6 3.1 2.4 2.9 3.8 3.3 2.6 3.0`（$N=10$，内部点 $i=2..9$）。

| $i$ | 窗口 $(a,b,c)$ | $b>a$ 且 $b>c$? | $b<a$ 且 $b<c$? | 结论 |
|---|---|---|---|---|
| 3 | 2.8, 3.6, 3.1 | 是 | 否 | **high 3.60** |
| 4 | 3.6, 3.1, 2.4 | 否 | 否 | — |
| 5 | 3.1, 2.4, 2.9 | 否 | 是 | **low 2.40** |
| 7 | 2.9, 3.8, 3.3 | 是 | 否 | **high 3.80** |
| 9 | 3.3, 2.6, 3.0 | 否 | 是 | **low 2.60** |

（其余内部点既非峰也非谷，表中略。）高潮 2 个、低潮 2 个，与样例输出一致。所有数值均为一位小数，`%.2f` 输出无舍入歧义。

样例 2 序列 `1.5 2.2 2.2 2.2 1.8 1.9`：内部点逐一检查——第 2 点 $b=2.2$，左邻 1.5、右邻 2.2，$b>c$ 不成立；第 3、4 点同理（都有相等邻居）；第 5 点 $b=1.8$，左邻 2.2、右邻 1.9，$b<c$ 不成立。所以极值 0 个——**平台段吞掉了整个峰**，这正是"严格不等号"规则的表现。

### 4. 通过编程翻译

| 数学 | C 语言 |
|---|---|
| 窗口 $x_{i-1}, x_i, x_{i+1}$ | `double a, b, c;` |
| $x_i > x_{i-1}$ 且 $x_i > x_{i+1}$ | `b > a && b > c` |
| $x_i < x_{i-1}$ 且 $x_i < x_{i+1}$ | `b < a && b < c` |
| 窗口右滚：$x_{i-1}\!\leftarrow\!x_i,\ x_i\!\leftarrow\!x_{i+1}$ | `a = b; b = c;` |
| 计数 $H, L$ | `int H = 0, L = 0;` |

## 三、解题思路

1. 读 `n`；
2. 读前两点到 `a、b`；
3. `for i = 3..n`：读 `c` → 判高潮（输出+`H++`）→ 判低潮（输出+`L++`）→ 滚动 `a=b; b=c;`；
4. 输出 `highs = H`、`lows = L`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i, H = 0, L = 0;     /* 点数、循环变量、高潮/低潮计数 */
    double a, b, c;             /* 滑动窗口：左邻、中心、右邻 */

    scanf("%d", &n);
    scanf("%lf %lf", &a, &b);   /* 先读前两点，窗口差一个右邻 */

    for (i = 3; i <= n; i++) {
        scanf("%lf", &c);       /* 读右邻，窗口凑齐 */
        if (b > a && b > c) {   /* 中心比两边都大 → 高潮 */
            printf("high %.2f\n", b);
            H++;
        }
        if (b < a && b < c) {   /* 中心比两边都小 → 低潮 */
            printf("low %.2f\n", b);
            L++;
        }
        a = b;                  /* 窗口右滚一格 */
        b = c;
    }

    printf("highs = %d\n", H);
    printf("lows = %d\n", L);
    return 0;
}
```

## 五、运行验证

**样例 1**（`10` + 序列）：输出

```
high 3.60
low 2.40
high 3.80
low 2.60
highs = 2
lows = 2
```

✓（逐点核对见第二节表格。）

**样例 2**（`6` + 平台序列）：极值记录无，输出 `lows = 0` 与 `highs = 0` 两行 ✓

**边界验证**：输入 `3 5.0 1.0 5.0`——窗口恰为整体序列，输出 `low 1.00`、`highs = 0`、`lows = 1`：单谷序列正确检出。

## 六、常见错误与讲解

**错误 1：滚动时机或顺序错**

```c
a = c; b = c;        /* 错：左邻信息丢失，窗口错乱 */
a = b; b = c;        /* 对：先挪左邻，再挪中心，最后 c 位置留给下一轮读入 */
```

滚动前必须**先用 b、c 判完**再滚——若先 `a = b; b = c;` 后判，判的就不是刚才那个中心了。

**错误 2：条件写成"或"**

```c
if (b > a || b > c)   /* 错：比其中一个大就算高潮，起伏段大量误报 */
if (b > a && b > c)   /* 对：必须比两边都大 */
```

**错误 3：非严格比较把平台当峰**

```c
if (b >= a && b >= c)   /* 错：样例 2 的 2.2 平台会被误判 */
if (b > a && b > c)     /* 对：严格不等号排除平台 */
```

**错误 4：循环从第 2 点读起、窗口没读满就判**——窗口三值必须先就位（循环外读 `a、b`，循环内第一轮读 `c` 后才有完整的窗口）。若循环写成从 `i = 2` 读 `c` 并判 `b`，首轮 `c` 还是垃圾值。

## 七、与综合实验的衔接

- 实验 **C7《基于移动平均的潮位观测数据平滑与趋势分析系统》**的第 6 模块就是本题：对平滑后的序列滑窗检测高、低潮；第 7 模块"潮差统计"紧接着把**相邻的高潮与低潮相减**得到每个潮周期内的潮差。本题的极值输出行（`high x.xx`/`low x.xx`）正是第 7 模块的输入；
- 与练习 38 相比，窗口从 2 个变量升级到 3 个、判据从单比较升级到复合条件 `&&`——但骨架完全相同：**读新值 → 判中心 → 滚动**。将来学到第 5 章数组后，同样的检测可写成 `x[i-1]、x[i]、x[i+1]` 的下标版；学到第 4 章函数后，可把"判一点"封装成函数。手段在升级，窗口思想不变。
