## 二、预备知识：复合梯形公式的基本原理（零基础阅读）

### 1. 问题是怎么来的

船模在加速破冰，速度时刻在变。物理上，位移是速度曲线下方与时间轴之间的面积：$s = \int_{t_0}^{t_n} v(t)\,dt$。但试验只给了 $n+1$ 个等间隔时刻的离散采样值 $v_0, v_1, \ldots, v_n$，两个采样点**之间**速度究竟怎么变并不知道。这是一个典型的"只有离散数据、没有解析公式"的积分问题——实验数据永远长这样，必须学会处理。

### 2. 方法是怎么想出来的（公式推导）

补上未知曲线的最朴素假设：**相邻两采样点之间速度按直线变化**（练习 08 说过，这正是线性插值）。于是整个区间被 $n$ 个采样点切成 $n$ 小段，第 $i$ 段 $[t_{i-1}, t_i]$ 上曲边面积用梯形近似：

$$
s_i \approx \frac{(v_{i-1} + v_i)\,\Delta t}{2}
$$

总位移是各段之和：

$$
s = \sum_{i=1}^{n} s_i = \sum_{i=1}^{n} \frac{(v_{i-1} + v_i)\,\Delta t}{2}
$$

这就是**复合梯形公式**（"复合" = 多段拼接）。段数 n 越大、每段越窄，"以直代曲"的失真越小，结果越接近真值——与练习 08 单段情形的关系是"细胞 → 组织"。

### 3. 用本例走一遍（手算）

样例 1：$n = 4$，$\Delta t = 0.5$，速度 $0,\ 2.0,\ 3.5,\ 4.5,\ 5.0$：

- 第 1 段：$(0 + 2.0)/2 \times 0.5 = 0.5$；
- 第 2 段：$(2.0 + 3.5)/2 \times 0.5 = 1.375$；
- 第 3 段：$(3.5 + 4.5)/2 \times 0.5 = 2.0$；
- 第 4 段：$(4.5 + 5.0)/2 \times 0.5 = 2.375$；
- 总位移：$0.5 + 1.375 + 2.0 + 2.375 = 6.25$ m。

直观核对：平均速度约 3 m/s、历时 2 s，位移约 6 m，量级相符。

### 4. 编程时怎么用它（循环怎么写、什么时候停）

把"第 i 段梯形"翻译进循环体。关键洞察：算第 i 段只需要 $v_{i-1}$ 和 $v_i$ 两个数，**不需要记住全部采样值**（那是第 5 章数组干的事）。于是用两个变量维护"滑动窗口"：

- 循环前读入 $v_0$ 存入 `prev`；
- 每轮读入下一个速度 `v`，累加 `(prev + v) / 2.0 * dt`，然后 `prev = v` 让位；
- 循环执行 n 轮（`for (i = 1; i <= n; ...)`），恰好消耗掉剩余的 n 个采样值，不多不少——**"读新点、算本段、旧点让位"三步一个都不能少**，漏了 `prev = v` 会导致每段都拿 $v_0$ 当起点。

## 三、解题思路

1. **确定变量**：`n`、`i` 为 `int`；`dt`、`prev`、`v`、`s` 为 `double`；
2. **读入 n 与 dt**；
3. **清零累加器** `s = 0.0`，**读入 $v_0$** 存入 `prev`；
4. **for 循环 i 从 1 到 n**：读入 `v`，累加本段梯形，更新 `prev`；
5. **输出** `s = %.3f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i;          /* 采样段数、循环变量 */
    double dt;         /* 采样间隔，s */
    double v;          /* 当前时刻速度，m/s */
    double prev;       /* 前一时刻速度，m/s */
    double s = 0.0;    /* 位移累加器，m */

    scanf("%d %lf", &n, &dt);
    scanf("%lf", &prev);          /* 先读 v0 作为第 1 段的起点 */

    for (i = 1; i <= n; i = i + 1) {
        scanf("%lf", &v);                     /* 读新点 */
        s = s + (prev + v) / 2.0 * dt;        /* 本段梯形面积 */
        prev = v;                             /* 旧点让位 */
    }

    printf("s = %.3f\n", s);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `4 0.5` + `0 2.0 3.5 4.5 5.0` | 四段梯形 $0.5 + 1.375 + 2.0 + 2.375$（手算见预备知识） | `s = 6.250` ✓ |
| `3 1.0` + `0.0 1.2 2.4 3.0` | 三段 $(0+1.2)/2 + (1.2+2.4)/2 + (2.4+3.0)/2 = 0.6+1.8+2.7 = 5.1$ | `s = 5.100` ✓ |
| `1 2.0` + `1.5 2.5` | 单段 $(1.5+2.5)/2 \times 2.0 = 4.0$（退化为练习 08 的单段情形） | `s = 4.000` ✓ |

第 3 行验证了 n = 1 的边界：复合梯形公式退回单段梯形公式，与练习 08 的结果衔接。

## 六、常见错误与讲解

**错误 1：漏了 `prev = v`（旧点不让位）**

```c
for (i = 1; i <= n; i = i + 1) {
    scanf("%lf", &v);
    s = s + (prev + v) / 2.0 * dt;
    /* 错：缺 prev = v; 每段都从 v0 出发，结果偏大 */
}
```

用样例 1 自查：漏写后输出 9.000 而非 6.250。

**错误 2：循环次数写错导致采样点数不匹配**

```c
for (i = 0; i < n; i = i + 1)   /* 少读一个数，最后一个速度悬空 */
```

n 段需要 n+1 个点：1 个在循环前 + n 个在循环内。循环体内 scanf 执行次数必须是 n。

**错误 3：梯形公式括号或除号写错**

```c
s = s + prev + v / 2.0 * dt;       /* 错：只有 v 被除了 2 */
s = s + (prev + v) / 2.0 * dt;     /* 对 */
```

**错误 4：累加器 s 不清零**

```c
double s;          /* 错：随机初值 */
double s = 0.0;    /* 对 */
```

## 七、与综合实验的衔接

- 实验 **C7（载荷辨识）**中，"由速度求位移"是拖曳系统标定的标准环节；同一程序把速度换成加速度还能求速度、把速度换成力再乘力臂还能求功——**数据流积分的骨架完全通用**。实验 C8 的淹没体积（沿长度方向逐段累乘截面宽）、D5 的累积剂量（练习 10 的矩形法版本）都是这个骨架的近亲；
- 学到第 5 章（数组）后，n+1 个采样值会先存入数组，允许"先存后算、来回多遍"，还能用中点加密（复合梯形的改进）减小误差；学到第 4 章（函数）后可封装 `double trap_sum(int n, double dt)`。**"以直代曲、逐段累加"这八个字，是 3.5 节数值积分全部内容的总纲。**
