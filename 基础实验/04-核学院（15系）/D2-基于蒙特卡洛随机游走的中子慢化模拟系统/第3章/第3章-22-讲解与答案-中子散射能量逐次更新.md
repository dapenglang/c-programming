## 二、预备知识：迭代终止条件与循环控制（零基础阅读）

### 1. 问题是怎么来的

慢化过程的物理图景是"一步接一步"的：中子撞一个氢核，能量降一点；再撞一个，再降一点……**我们不知道要撞多少次才够**，因为次数取决于初始能量和每次的损失比例。这种"次数事先不确定、由某个条件决定何时停止"的过程，正是 `while` 循环的用武之地。

### 2. 公式与条件是怎么来的

**（1）能量递推公式**

设每次碰撞后能量变为碰撞前的 \(\alpha\) 倍（\(0<\alpha<1\)）：

$$
E_1 = \alpha E_0,\quad E_2 = \alpha E_1 = \alpha^2 E_0,\quad \dots,\quad E_k = \alpha^{k} E_0
$$

这是一条**几何递减序列**，也可以直接求闭式解；但本题要的是"逐步模拟"，所以用递推。

**（2）终止条件**

热中子能量约 \(E_{\text{th}} = 0.025\) eV。当某次散射后能量 \(E < E_{\text{th}}\)，就认为中子已热化，结束模拟。用数学写就是：

$$
\alpha^{k} E_0 < 0.025
$$

两边取对数可估算所需次数 \(k > \dfrac{\ln(0.025/E_0)}{\ln \alpha}\)，但程序不需要这个闭式解，只要一步步乘、一步步判断。

**（3）两个必须同步更新的量**

循环体里每次要做两件事：`E = E * alpha;` 和 `k = k + 1;`（本题写作 `collisions++`）。**它们必须成对出现**，否则"次数"和"能量"就会脱节——这是初学者最容易出的错。

### 3. 用本例走一遍

取 \(E_0 = 2\times10^{6}\) eV，\(\alpha = 0.6\)。

- 递推：\(E_k = 2\times10^{6} \times 0.6^{k}\)；
- 求 \(0.6^k < 0.025/(2\times10^{6}) = 1.25\times10^{-8}\)：两边取自然对数，\(k \ln 0.6 < \ln(1.25\times10^{-8})\)，即 \(k \times (-0.5108) < -18.199\)，得 \(k > 35.63\)，故 \(k = 36\)；
- 验证：\(E_{36} = 2\times10^{6} \times 0.6^{36} = 0.02063\) eV \(< 0.025\) eV，而 \(E_{35} = 0.03438\) eV \(> 0.025\) eV，恰好在第 36 次后跨过阈值。

再取 \(\alpha = 0.5\)：\(k \times (-0.6931) < -18.199\)，得 \(k>26.25\)，故 \(k=27\)，此时 \(E_{27} = 0.01490\) eV。两个样例都与程序一致。

### 4. 编程时怎么用它

用 `while` 写"能量还没降到阈值、且没超过最大次数"的循环：

```c
while (e >= E_TH && collisions < MAXC) {
    e = e * alpha;       /* 散射一次，能量更新 */
    collisions++;        /* 计数同步 +1 */
}
```

也可以先散射再判断、满足即 `break`。**关键是"判断条件用的是散射后的能量"，这样碰撞次数才与能量一一对应。**

> **这个思想在综合实验中反复出现**：D2 中子慢化（能量→阈值）、D5 剂量率积分（步数→路径终点）、蒙卡类（粒子数→抽样次数上限），全部是"未知次数 + 条件终止"的 `while` 循环。**学会一次，处处可用。**

## 三、解题思路

1. **定义常量**：阈值 `const double E_TH = 0.025;`，上限 `const int MAXC = 1000;`；
2. **读入**：`scanf("%lf %lf", &e0, &alpha);`，用 `e0` 初始化当前能量 `e`；
3. **循环**：`while (e >= E_TH && collisions < MAXC)`，循环体内能量乘 `alpha`、计数加一；
4. **输出**：`printf("collisions = %d\n", collisions);` 与 `printf("E = %.4e\n", e);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 常量：热中子阈值与最大碰撞次数上限 */
    const double E_TH = 0.025;   /* 热中子能量阈值，eV */
    const int    MAXC = 1000;    /* 防止死循环的上限 */

    double e0;         /* 初始能量，eV */
    double alpha;      /* 平均能量保留因子 */
    double e;          /* 当前能量，eV */
    int    collisions; /* 已发生的碰撞次数 */

    /* 读入初始能量与保留因子 */
    scanf("%lf %lf", &e0, &alpha);

    /* 循环散射：能量未降至阈值以下且有次数余量时继续 */
    e = e0;
    collisions = 0;
    while (e >= E_TH && collisions < MAXC) {
        e = e * alpha;      /* 散射一次：能量降低 */
        collisions++;       /* 计数与能量同步更新 */
    }

    /* 输出碰撞次数与最终能量 */
    printf("collisions = %d\n", collisions);
    printf("E = %.4e\n", e);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2000000 0.6 | \(0.6^{36} \times 2\text{e}6 = 0.02063 < 0.025\)，第 36 次跨阈值 | `collisions = 36` / `E = 2.0629e-02` ✓ |
| 2000000 0.5 | \(0.5^{27} \times 2\text{e}6 = 0.01490 < 0.025\)，第 27 次跨阈值 | `collisions = 27` / `E = 1.4901e-02` ✓ |
| 2000000 0.9 | \(0.9^{k} \times 2\text{e}6 < 0.025 \Rightarrow k=173\) | `collisions = 173` / `E = 2.4265e-02` ✓ |

保留因子越接近 1（每次损失越少），需要的碰撞次数越多——例如 \(\alpha=0.9\) 时需 173 次，而 \(\alpha=0.5\) 时只需 27 次，符合"损失越慢、慢化越慢"的物理直觉。

## 六、常见错误与讲解

**错误 1：循环体里漏掉计数**

```c
while (e >= E_TH) {
    e = e * alpha;
    /* 忘写 collisions++：计数永远是 0 */
}
```

能量与计数是"同一枚硬币的两面"，更新能量就必须更新计数，否则输出的次数毫无意义。

**错误 2：判断条件放在散射前，导致多计/少计一次**

```c
e = e * alpha;                 /* 先散射 */
if (e < E_TH) break;           /* 再判断并退出 —— 计数与能量已同步，正确 */
```
```c
if (e < E_TH) break;           /* 若在散射前判断，最后一次散射会多算了 */
```

务必让"判断依据的能量"与"已记录的次数"对应同一次散射之后的时刻。

**错误 3：忘记防止死循环**

```c
while (e >= E_TH) { e = e * alpha; collisions++; }   /* 若 alpha >= 1 或 alpha <= 0 会死循环 */
```

题干要求设 `MAXC` 上限并用 `&&` 联入循环条件。**这是数值模拟的自我保护纪律**：输入可能是非法的（\(\alpha \ge 1\) 时能量不降反升），程序必须能停下来。

**错误 4：`%e` 与 `%f` 混用**

```c
printf("E = %.4f\n", e);    /* 会打印成 0.0206 甚至 0.0000，看不到量级 */
printf("E = %.4e\n", e);    /* 对：2.0629e-02，量级一目了然 */
```

核物理量跨 8 个数量级，**务必用科学计数法 `%e` 输出**，否则小能量会被"看成 0"。

## 七、与综合实验的衔接

- 实验 **D2（中子慢化模拟）** 的真实版本把固定的 \(\alpha\) 换成"由随机数抽样的散射角，再按碰撞运动学算新能量"——那时才会引入第 3 章要求的**手写线性同余随机数** $\;r_{n+1}=(a r_n + c)\bmod m$。本练习先让你掌握"循环推进 + 条件终止"的骨架，把随机性留到后面加；
- 同一套骨架稍作修改即可用于：D1 活度衰减到阈值以下（"何时可排放"）、D2 中子逃逸判断（"何时穿出反应堆"）、D5 剂量率沿路径积分（"何时到达计算终点"）。**"能量/时间/路径推进 + 阈值终止"是核科学模拟的通用循环结构。**
