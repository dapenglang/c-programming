## 二、预备知识：矩形法数值积分的基本原理（零基础阅读）

### 1. 问题是怎么来的

载荷随时间连续变化，冲量是载荷曲线下的面积 $I = \int F(t)\,\mathrm{d}t$。但实际测量得到的只是一串**离散的样本点** $F_1, F_2, \dots, F_n$，并没有连续的 $F(t)$——面积无法用积分公式精确算。工程上退而求其次：**用一串小矩形去近似这块面积**。

### 2. 方法是怎么想出来的

把时间轴按采样间隔 $\Delta t$ 切成 $n$ 小段，每段长 $\Delta t$。设想在第 $i$ 段内，载荷近似等于该段起点处的样本值 $F_i$，那么这一小段的面积约为"宽 × 高"：

$$
\Delta I_i \approx F_i \cdot \Delta t
$$

把 $n$ 个小矩形的面积全部加起来，就得到总面积的近似：

$$
I = \int_0^{T_{end}} F(t)\,\mathrm{d}t \;\approx\; \sum_{i=1}^{n} F_i\,\Delta t \;=\; \Delta t\sum_{i=1}^{n}F_i
$$

这正是**矩形法（左端点法）**。它的好处是只需一次累加（把已算好的总和乘以 $\Delta t$ 即可），代价是忽略了每段内载荷的变化——$\Delta t$ 越小、采样越密，误差越小。更精细的还有把每段换成梯形（第 8、9 题已练过），本题用矩形法。

### 3. 用本例走一遍

取样例 1：$\Delta t = 0.5$ s，六个样本 $42.5, 68.3, 55.1, 30.2, 71.8, 49.6$。

- 先求总和：$42.5 + 68.3 + 55.1 + 30.2 + 71.8 + 49.6 = 317.5$；
- 矩形法：$I \approx 0.5 \times 317.5 = 158.75$ kN·s。

直观理解：把每个样本看成持续 0.5 s 的恒定载荷，六个矩形拼起来的总面积就是 158.75。

### 4. 编程时怎么用它

三个要点：**① 求和复用**：矩形法不需要另写循环，直接拿统计阶段已经累加好的 `sum` 乘 $\Delta t$ 即可——这是"结构化"的体现，一段数据只读一遍、算一遍；**② 单位与量纲**：$\Delta t$ 的单位是秒，冲量单位是 kN·s，输出时标注清楚；**③ 顺序**：先完成统计（循环），再在循环外计算均值、极差、冲量并统一输出，避免在循环里反复计算。

## 三、解题思路

1. **读入** `n`、`T`、`dt`；定义 `sum = 0`、`above = 0`、标志 `first = 1` 及最值、位置变量；
2. **循环统计**：`for (i=1; i<=n; i++)`，每轮读入 `v`：累加 `sum`；用 `first` 决定初始化最值还是比较更新（同时记位置）；若 `v >= T` 则 `above++`；
3. **算派生量**：循环结束后算 `mean = sum/n`、`range = vmax - vmin`、`impulse = dt * sum`；
4. **输出报表**：按固定九行格式输出，`%%` 打印百分号；
5. **自查**：`above` 不超过 `n`，`vmin ≤ mean ≤ vmax`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int    n, i;                          /* 样本个数与循环变量 */
    double T;                             /* 阈值 kN */
    double dt;                            /* 采样间隔 s */
    double v;                             /* 当前载荷样本 */
    double sum = 0.0;                     /* 总和 */
    double vmax = 0.0, vmin = 0.0;        /* 最大值、最小值 */
    int    imax = 0, imin = 0;            /* 最值出现位置 */
    int    above = 0;                     /* 不小于阈值的个数 */
    int    first = 1;                     /* 是否为首个样本 */

    scanf("%d %lf %lf", &n, &T, &dt);

    for (i = 1; i <= n; i++) {
        scanf("%lf", &v);
        sum = sum + v;                    /* 累加求和 */

        if (first) {                      /* 首个样本初始化最值 */
            vmax = vmin = v;
            imax = imin = i;
            first = 0;
        } else {
            if (v > vmax) { vmax = v; imax = i; }   /* 更新最大值及位置 */
            if (v < vmin) { vmin = v; imin = i; }   /* 更新最小值及位置 */
        }

        if (v >= T) {                     /* 不小于阈值则计数 */
            above = above + 1;
        }
    }

    /* 输出规范报表：实数 4 位小数，百分比 1 位小数 */
    printf("==== 载荷统计报表 ====\n");
    printf("样本数 = %d\n", n);
    printf("总和 = %.4f\n", sum);
    printf("均值 = %.4f\n", sum / n);
    printf("最大值 = %.4f (位置 %d)\n", vmax, imax);
    printf("最小值 = %.4f (位置 %d)\n", vmin, imin);
    printf("极差 = %.4f\n", vmax - vmin);
    printf("超阈值数 = %d (占比 %.1f%%)\n", above, 100.0 * above / n);
    printf("载荷冲量 = %.4f kN·s\n", dt * sum);   /* 矩形法积分 */

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：最值初值取 0，遇到全正或全负数据出错**

```c
double vmax = 0.0;                  /* 若样本全为负，max 会错误保留 0 */
```

正确做法是用**首个样本**初始化最值（本题用 `first` 标志）。

**错误 2：均值或冲量发生整数除法**

```c
mean = sum / n;         /* sum 是 double，尚可；但若写成 (int)sum / n 就丢小数 */
impulse = dt * sum;     /* 对：dt、sum 都是 double，结果带小数 */
```

建议分母、系数都保持浮点，例如 `sum / (double)n`，避免隐式类型问题。

**错误 3：阈值比较符号写反**

```c
if (v > T) above++;     /* 题目是"不小于阈值"，应包含等于 T 的情形 */
if (v >= T) above++;    /* 对 */
```

"不小于"就是 $\ge$，边界值 $v = T$ 要计入。

**错误 4：忘记记录最值位置**

```c
if (v > vmax) vmax = v;                 /* 只记值不记位置，报表"位置"会错 */
if (v > vmax) { vmax = v; imax = i; }   /* 对：值 + 位置一起更新 */
```

**错误 5：打印百分号未转义**

```c
printf("... (占比 %.1f%)\n", p);    /* 错：单个 % 被当成格式符 */
printf("... (占比 %.1f%%)\n", p);   /* 对：%% 输出一个百分号 */
```
