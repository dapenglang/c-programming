# 第 2 章 练习 27　道址-能量线性换算

**所属综合实验**：D8（D8-基于线性插值与数据拟合的核素能谱峰位标定系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性关系）

**场景来源**：综合实验 D8《基于线性插值与数据拟合的核素能谱峰位标定系统》（核学院）——本练习是该实验中"能量刻度"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

γ 能谱仪测量时，探测器把不同能量的 γ 光子记录在不同的**道址**（channel，整数，类似"第几号格子"）上。要判断测到的是什么核素，必须把道址换算成**能量**（keV）。

在有限的能量范围内，道址与能量近似成**线性关系**，用两个标准源刻度出斜率 $k$ 与截距 $b$ 后：

$$
E = k \cdot \text{ch} + b
$$

其中 $\text{ch}$ 是道址，$E$ 是能量（keV）。综合实验 D8 里，一旦找到峰所在的道址，就用这个式子换算出峰能量，再对照核素特征能量（如 Cs-137 的 661.7 keV、Co-60 的 1173.2 与 1332.5 keV）判断核素身份。本题就是这个"能量刻度"公式的最小实现。

## 二、任务要求

编写一个完整程序 `ch2energy.c`：

1. 程序中用**常量**存放刻度系数 $k$（取 1.5，keV/道）与截距 $b$（取 0.0，keV）；
2. 从键盘读入一个道址 `ch`（整数，**题目保证 0 ≤ ch ≤ 4095**）；
3. 用线性刻度公式计算能量 `E`（keV）；
4. 按规定格式输出结果，保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个整数，表示道址 ch。

**输出**：一行，按格式 `E = 结果` 输出，结果保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
441
```
输出：
```
E = 661.50
```

**样例 2**

输入：
```
888
```
输出：
```
E = 1332.00
```

## 五、提示

线性刻度公式：能量等于"斜率乘道址再加上截距"。

$$
E = k \cdot \text{ch} + b
$$

在 C 语言里写成一行：

```c
E = K * ch + B;
```

注意：道址 `ch` 是整数，但 $k$、$b$、$E$ 都是实数（double）。`K * ch` 中 `ch` 会自动提升为 double，**不会**发生整数截断；但为保险起见，也可以显式写成 `K * (double)ch + B`。

**验证公式是否写对的小技巧**：$k = 1.5$ 时，道址 441 应对应 $1.5 \times 441 = 661.5$ keV——正好是 Cs-137 的特征峰能量 661.7 keV 附近；道址 888 对应 $1.5 \times 888 = 1332.0$ keV，正是 Co-60 的一个特征峰 1332.5 keV 附近。这说明刻度系数选得合理。

**完成本练习后你将具备的能力**：定义常量与变量、选择正确的数据类型、书写"整数与实数混合"的算术表达式、使用 scanf/printf 完成输入输出、把线性公式翻译成一行 C 代码——这些是实验 D8 中"能量刻度模块"的地基。
