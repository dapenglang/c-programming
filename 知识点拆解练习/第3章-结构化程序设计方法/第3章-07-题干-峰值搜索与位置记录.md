# 第 3 章 练习 07　峰值搜索与位置记录（循环 + 最值）

**对应章节**：3 结构化程序设计方法（3.2 选择结构、3.3 循环结构——for 循环、3.4 关系运算符）

**场景来源**：综合实验 C9《冰压力场可视化系统》（水声学院）——本练习是该实验中"压力峰值定位"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰与结构相互作用时，接触压力在结构表面上分布极不均匀，总有一个局部区域承受最大压力——这个**压力峰值**及其**出现的位置**是抗冰结构设计的两个关键参数：峰值决定局部构件的强度校核载荷，位置决定加强筋该布在哪里。实验 C9 对每个时刻的测点压力序列做峰值搜索：依次读入各测点的压力值，随时记住"到目前为止见过的最大值"和"它在第几个测点"，全部读完即得结论。这种"打擂台"式算法是求最值的标准方法。

## 二、任务要求

编写一个完整程序 `peak_search.c`：

1. 第一行读入测点个数 `n`（整数，**题目保证 $1 \le n \le 100$**）；
2. 随后读入 n 个实数（各测点压力，单位 MPa，按测点顺序编号 $1 \sim n$）；
3. 找出其中的最大值 `peak` 及其**首次出现**的测点序号 `index`；若最大值并列出现多次，记录最先出现的那个；
4. 按格式输出峰值与序号。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，以空格分隔。

**输出**：一行，格式为 `peak = 峰值, index = 序号`，峰值保留 3 位小数，序号为整数。

## 四、样例

**样例 1**

输入：
```
6
2.415 2.508 2.470 2.508 2.332 2.194
```
输出：
```
peak = 2.508, index = 2
```
（最大值 2.508 出现两次：第 2 与第 4 号测点，记录先出现的第 2 号）

**样例 2**

输入：
```
4
1.1 2.2 3.3 4.4
```
输出：
```
peak = 4.400, index = 4
```
（序列单调递增，峰值在最后一个测点）

## 五、提示

"打擂台"算法：擂主（当前最大值）先由第 1 个数担任，此后每读一个数就挑战一次——**严格大于**擂主才换人、换序号：

```c
if (p > peak) {
    peak = p;
    index = i;
}
```

第 1 个数要在循环开始前单独读入作为初值，不能拿未赋值的 `peak` 去比较。

**完成本练习后你将具备的能力**：打擂台求最值、同步记录最值位置、正确处理并列情形与单元素序列——这是实验 C9 中峰值定位模块的完整实现。
