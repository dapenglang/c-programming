## 二、预备知识：地址与指针的基本原理（零基础阅读）

### 1. 内存像一排带编号的柜子

程序运行时，每个变量都要占据内存中的一小块空间。把内存想象成**一排带编号的柜子**：柜子的编号就是**地址**，柜子里放的东西就是**变量的值**，柜子上贴的标签就是**变量名**。

本题程序启动后，内存里大致是这样的（地址为示意值，每次运行可能不同）：

```
变量名     地址        值
--------  ----------  ----------
A0        0061FF1C    200.0
k         0061FF24    0.8
p         0061FF2C    0061FF1C   （p 里放的是另一个柜子的编号）
```

注意三层对应关系：**变量名是给人看的，地址是编号，值才是数据**。`double` 占 8 个字节，所以 `A0` 的地址是 `...1C`，下一个变量 `k` 的地址是 `...24`（十六进制中 1C + 8 = 24）。

### 2. 指针是"存柜号的纸条"

普通变量存放数据，指针变量存放的却是**另一个变量的地址**。声明

```c
double *p;
```

的意思是：`p` 是一个"专门用来放 `double` 变量地址"的变量。执行 `p = &A0;` 后，纸条 `p` 上写着柜号 `0061FF1C`——我们就说"**p 指向 A0**"。

### 3. `&` 是查柜号，`*` 是按柜号找东西

- `&A0`：问"A0 存在几号柜？"——得到地址 `0061FF1C`；
- `*p`：拿着纸条 `p` 上的柜号去开柜子——取出（或放入）`A0` 的值。

两者是互逆运算：`*(&A0)` 就是 `A0` 本身。所以下面两种写法效果完全一样：

```c
*p = *p * k;    /* 通过指针更新 */
A0 = A0 * k;    /* 按名字直接更新 */
```

既然效果一样，为什么还要绕道指针？因为**在很多场合你拿不到变量名**：例如把地址传给函数（本章练习 02）、让一个指针依次扫过数组（练习 03、04）时，只有地址可用，没有名字可叫。指针就是让程序"凭地址办事"的通用手段。

### 4. `scanf` 与 `%p` 的呼应

现在可以回头解释第 2 章的一句"咒语"了：`scanf("%lf", &A0)` 为什么要加 `&`？因为 scanf 需要知道"把读到的数放进哪个柜子"——它要的是**柜号**（地址），不是柜子里的旧值。本章之后，这条规则的原理你就完全掌握了。输出地址则用 `%p`，它会按编译器约定的十六进制格式打印一个地址。

## 三、解题思路

1. **数据**：两个输入 `A0`、`k`，都是实数，用 `double`；
2. **定义指针**：`double *p;` 然后立刻 `p = &A0;`——**先赋值再使用**，绝不让指针处于"不知道指向哪里"的状态；
3. **验证指向关系**：分别打印 `&A0` 与 `p`，两者应完全相同——这是检查"指针是否指向了预期变量"最直观的方法；
4. **通过指针读写**：`*p` 出现在赋值号右边是"读"，出现在左边是"写"；
5. **更新**：`*p = *p * k;` 后再打印 `A0`，验证通过指针的修改真实生效。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double A0;        /* 初始活度，单位 Bq */
    double k;         /* 单次采样衰减因子 */
    double *p;        /* 指针变量：存放 A0 的地址 */

    scanf("%lf %lf", &A0, &k);

    p = &A0;                          /* 让 p 指向 A0 */

    printf("A0  = %.6f\n", A0);       /* 按名字访问 */
    printf("&A0 = %p\n", (void *)&A0);/* A0 的地址 */
    printf("p   = %p\n", (void *)p);  /* p 里存的值——应与上一行相同 */
    printf("*p  = %.6f\n", *p);       /* 按地址访问，读 */

    *p = *p * k;                      /* 按地址访问，写：等价于 A0 = A0 * k */

    printf("after update: A = %.6f\n", A0);

    return 0;
}
```

## 五、运行验证

以样例 1（输入 `200.0 0.8`）为例：

| 输出行 | 验证要点 |
|---|---|
| `A0  = 200.000000` | 按名字读出的初始值，正确 |
| `&A0 = 0061FF1C` | 地址值每次运行不同，以相对关系为准 |
| `p   = 0061FF1C` | 与上一行**完全相同**，说明 p 确实指向 A0 |
| `*p  = 200.000000` | 按地址读出的值与 `A0` 相同 |
| `after update: A = 160.000000` | $200 \times 0.8 = 160$，通过指针的修改生效 |

样例 2（输入 `500.0 0.5`）：$500 \times 0.5 = 250$，程序输出 `after update: A = 250.000000`，正确。

## 六、常见错误与讲解

**错误 1：使用未初始化的指针（野指针）**

```c
double *p;
printf("%p\n", *p);   /* 错：p 还没指向任何变量，*p 是"按随机柜号开柜" */
```

未赋值的指针里是垃圾值，`*p` 读它可能崩溃，写它更会破坏别的数据。**纪律：定义指针后立刻让它指向确定的变量。**

**错误 2：`*` 与 `&` 混淆**

```c
p = *A0;    /* 错：A0 不是地址，*A0 无意义（A0 不是指针） */
p = &A0;    /* 对：把 A0 的地址放进 p */
```

记忆口诀：**`&` 是"查柜号"，`*` 是"按柜号取东西"**。`&` 后面必须跟变量，`*` 后面必须跟指针。

**错误 3：声明与赋值混写的歧义**

```c
double *p = &A0, k;   /* 对：* 只修饰 p，k 是普通 double */
double *p = A0;       /* 错：把数据 200.0 当成地址放进 p */
```

注意 `double *p = &A0;` 中的 `*` 属于**声明**部分，与 `*p = 5;` 中的解引用 `*` 含义不同——前者是"p 是指针"的记号，后者是"按地址访问"的动作。

**错误 4：类型不匹配**

```c
int *p = &A0;   /* 错：int* 指针指向 double 变量，类型不符 */
```

指针类型决定了"开柜子时按多大尺寸取数"：`double *` 按 8 字节取，`int *` 按 4 字节取。指错类型读出的就是乱码。

## 七、与综合实验的衔接

实验 **D1（放射性核素活度计算）**中，活度参数由独立的参数管理模块统一维护，模块内部正是通过地址（指针）来读写这些参数的；后续学到 6.5"指针与函数"时（本章练习 11~20 将展开），你会发现函数之间传递可修改的数据也只有"传地址"这一条路——本练习的 `p = &A0; *p = ...` 就是那条路的第一步。此外，`scanf(..., &x)` 加 `&` 的原因至此彻底明朗：它就是把你定义的变量的地址交给库函数，让它按地址写入。
