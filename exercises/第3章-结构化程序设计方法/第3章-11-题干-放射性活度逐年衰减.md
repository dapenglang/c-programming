# 第 3 章 练习 11　放射性活度逐年衰减

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.3 循环结构——for 循环与累乘迭代、3.4 关系与逻辑运算）

**场景来源**：综合实验 D1《放射性核素活度衰变计算系统》（核学院）——本练习是该实验中"逐年活度衰减表生成"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

放射性核素在存放和使用过程中，活度会随时间的推移不断降低。工程上常常不用一个连续公式一次算出结果，而是按"每年衰减一次"的方式逐年递推：本年末的活度 = 上年末的活度 × (1 − 年衰减率)。这样生成的逐年活度表，既便于安排辐射防护巡检的周期，也便于判断哪一年活度降到了安全水平。本练习实现的就是这个"逐年累乘"的循环过程。

## 二、任务要求

编写一个完整程序 `decay.c`：

1. 从键盘读入三个量，用空格分隔：初始活度 `A0`（单位 Bq，double）、年衰减率 `p`（单位 %，double）、衰减年限 `n`（正整数，int）；
2. 用 **for 循环**执行 n 次，每循环一次，把当前活度乘以 $(1 - p/100)$，实现"衰减一年"；
3. 每衰减一年，就输出一行该年末的活度，保留 3 位小数；
4. 全部循环结束后，再输出一行最终活度。

提示：本题只用一个变量 `A` 反复更新自己即可，**不需要数组**。

## 三、输入输出格式

**输入**：一行，三个数 `A0 p n`，中间用空格分隔。

**输出**：

- 前 n 行，格式为 `year k: 活度 Bq`（k 从 1 到 n，活度保留 3 位小数）；
- 最后一行，格式为 `final activity = 活度 Bq`（活度保留 3 位小数）。

## 四、样例

**样例 1**

输入：
```
1000 10 3
```
输出：
```
year 1: 900.000 Bq
year 2: 810.000 Bq
year 3: 729.000 Bq
final activity = 729.000 Bq
```

**样例 2**

输入：
```
5000 20 4
```
输出：
```
year 1: 4000.000 Bq
year 2: 3200.000 Bq
year 3: 2560.000 Bq
year 4: 2048.000 Bq
final activity = 2048.000 Bq
```

## 五、提示

设第 $k$ 年末活度为 $A_k$，则递推关系为

$$
A_k = A_{k-1} \times \left(1 - \frac{p}{100}\right),\qquad k = 1,2,\dots,n
$$

连乘展开后也可写成闭式 $A_n = A_0\left(1-\dfrac{p}{100}\right)^{n}$。程序里用循环实现，只需一行 `A = A * (1.0 - p / 100.0);` 反复执行 n 次即可——这就是**循环迭代**：把上一次的计算结果作为这一次的输入。

**完成本练习后你将具备的能力**：用 for 循环控制重复次数、书写循环内的累乘更新语句、按固定格式逐年输出中间结果——这是实验 D1 中"衰变表生成模块"的地基，也是后续所有迭代算法（二分法、不动点迭代）的第一步。
