# 第 2 章 练习 34　层内水平跨距计算

**所属综合实验**：C8（C8-基于分层线性插值的声线传播时间计算系统）

**对应章节**：2 常量、变量与数据类型；2.x 运算符与表达式；2.x 标准数学函数（sin/cos）；2.x 格式化输入输出

**场景来源**：综合实验 C8《基于分层线性插值的声线传播时间计算系统》（水声学院）——本练习是该实验中"层内水平距离计算"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

海洋声速随深度变化，声线（声波传播路径）在水中是弯的。工程上常用"分层常梯度"模型：把海水按深度切成若干层，认为每层内声线沿**直线**传播，只是方向逐层折转。

在每层内，已知该层厚度 $H$ 和声线的**掠射角** $\theta$（声线与水平面的夹角），就能算出声线在这层里"横着走了多远"——即**层内水平跨距** $x$。把每层的水平跨距累加起来，就得到声线落地时的水平偏移；这正是综合实验 C8 第 4 模块"层内水平距离计算"的工作。

本题只算**一层**的水平跨距，用到三角函数 $\sin$、$\cos$ 与弧度换算。

## 二、任务要求

编写一个完整程序 `span_calc.c`：

1. 定义符号常量 `#define PI 3.14159265358979`；
2. 从键盘读入两个 double：层厚度 `H`（m）、该层内声线的掠射角 `theta_deg`（**角度制**，度）；
3. 将角度换算为弧度：$\theta_{rad} = \theta_{deg} \times \dfrac{\pi}{180}$；
4. 计算层内水平跨距 $x = \dfrac{H}{\tan\theta} = \dfrac{H\cos\theta_{rad}}{\sin\theta_{rad}}$（用 `cos` 与 `sin` 实现，**不允许直接调用 `tan`**，以练习三角函数库的使用）；
5. 按样例格式输出跨距，保留 2 位小数。

**注意**：本题只做顺序计算，不允许使用 `if`、循环和函数定义（调用标准库函数 `sin`/`cos` 不受限）。程序开头需 `#include <math.h>`。

## 三、输入输出格式

**输入**：一行两个实数，用空格分隔：`H theta_deg`。

**输出**：一行：`span = <x> m`（保留 2 位小数）。

## 四、样例

**样例 1**

输入：
```
120.0 32.5
```
输出：
```
span = 188.36 m
```

**样例 2**

输入：
```
80.0 45.0
```
输出：
```
span = 80.00 m
```

样例 2 是检验程序的好标尺：$45°$ 时 $\tan 45° = 1$，跨距恰好等于层厚。

## 五、提示

- 三角函数库使用**弧度**，不是角度——这是 C 语言三角计算第一大坑：`sin(30.0)` 不是 $\sin 30°$！必须先乘 $\pi/180$；
- `#define PI 3.14159265358979` 提供足够精度；`PI/180` 可以先算成一个中间变量 `rad_per_deg`，表达式更清晰；
- `x = H * cos(th) / sin(th)` 中，`cos(th)` 与 `sin(th)` 都是 `double`，先乘后除与数学式一致；
- 掠射角越小，声线越"躺平"，跨距越大——可拿 $\theta = 10°$、$H = 100$ 自测（跨距应约 567.13 m）验证程序的物理合理性。

**完成本练习后你将具备的能力**：角度—弧度换算、调用 `math.h` 三角函数、按物理公式组织表达式——这是 C8 实验声线追踪逐层计算的地基。
