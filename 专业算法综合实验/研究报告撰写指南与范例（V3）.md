# 第一部分　研究报告结构说明

研究报告是一份**学术论文风格**的独立文档，与按固定模板撰写的《综合实践报告》（docx）互为补充：docx 报告面向"工程验收"，逐模块记录代码与截图；研究报告面向"学术表达"，讲清楚为什么做、怎么做、结果说明了什么。

# 第二部分　研究报告范例

# 基于灰度直方图统计的图像二值化处理系统研究报告

**摘要**：针对数字图像处理中"目标与背景分离"这一基础问题，本文设计并实现了一个基于灰度直方图统计的图像二值化处理系统。系统采用 C 语言（C99）开发，以文本灰度图像为数据载体，围绕"数据读入—算法实现—数据输出"三大环节划分为 12 个功能模块，提供图像读入与校验、字符画预览、灰度直方图统计与绘制、固定阈值二值化、迭代法自动阈值二值化、亮度对比度调整、结果写出与处理日志等功能。在 6 幅 64×48 至 256×256 的灰度图像上的实验表明：固定阈值法在直方图呈单峰分布的图像上效果较差，而迭代法仅需 3~6 轮即可收敛，得到的阈值与人工优选阈值的偏差不超过 8 个灰度级，二值化结果保留目标轮廓完整。本系统验证了仅使用课程内 C 语言知识（二维数组、循环、文件读写、结构体）实现实用图像处理工具的可行性，为后续学习图像滤波与目标检测建立了"图像即二维数组、处理即逐像素运算"的直观认识。

**关键词**：图像二值化；灰度直方图；迭代阈值；C 语言；结构体数组

## 1 引言

### 1.1 问题背景

数字图像在计算机中是一个二维像素矩阵，每个像素用 0~255 的整数表示亮度。计算机"看不懂"图像内容，一切图像识别任务（车牌识别、文档文字提取、工业缺陷检测）的第一步，都是把感兴趣的目标从背景中分离出来。二值化是其中最经典、计算量最小的手段：通过设定一个灰度阈值，把图像压缩为纯黑白两色。然而阈值的选择直接决定成败——阈值过高会把目标削掉，过低会把背景混入。

### 1.2 研究动机

在真实图像中，光照不均、目标与背景灰度接近等都会让"拍脑袋"选阈值失效。我们希望实现一个系统：既能人工调节阈值并即时看到效果，又能按图像自身的灰度分布**自动**计算合理阈值（迭代法），并通过直方图统计帮助使用者理解图像的灰度构成。同时，借助这个系统完整实践一次"需求分析 → 数据结构设计 → 模块划分 → 编码调试 → 实验分析"的软件开发流程，综合运用课程所学的文件、二维数组、函数与结构体知识。

### 1.3 本文工作

本文的主要工作包括：（1）设计了基于文本灰度格式的图像读入、校验与字符画预览方案；（2）实现了 256 级灰度直方图统计与字符柱状图绘制；（3）实现了固定阈值与迭代法自动阈值两种二值化算法，并提供了亮度/对比度调整等辅助工具；（4）在多幅图像上开展了两种阈值方法的对比实验，分析了迭代法的收敛性与适用条件。

## 2 相关知识

### 2.1 灰度直方图

灰度直方图统计图像中每个灰度级出现的次数。设图像有 N 个像素，开一个 256 格的计数数组 hist，遍历像素执行 hist[p]++ 即得。直方图反映灰度构成：若直方图呈"双峰"形态（暗背景一峰、亮目标一峰），两峰之间的谷底就是理想阈值；若单峰，固定阈值难以兼顾。

### 2.2 固定阈值二值化

对每个像素 p：p ≥ t 则置 255（白），否则置 0（黑）。实现简单，但阈值 t 需人工指定，对不同图像不具有通用性。

### 2.3 迭代法自动阈值

迭代法的思想是"用分割结果反过来修正阈值"：

1. 取全图均值作初始阈值 t₀；
2. 按 t 分割为亮区（≥t）与暗区（<t），分别计算两区均值 μ₁、μ₂；
3. 新阈值 t' = (μ₁+μ₂)/2；
4. 若 |t'-t| ≤ 1 则收敛，否则以 t' 为新阈值回到第 2 步。

整个过程只有求和、求均值、比较三种运算，通常 3~6 轮收敛。

## 3 系统设计

### 3.1 总体架构

系统由三大功能部分、12 个模块组成：数据读入（M1 文件读取、M2 数据校验、M3 信息显示、M4 字符画预览）、算法实现（M5 直方图统计、M6 直方图绘制、M7 固定阈值二值化、M8 迭代自动阈值、M9 亮度对比度调整）、数据输出（M10 结果写出、M11 处理日志报表、M12 主控菜单）。

### 3.2 数据结构设计及选型理由

```c
#define W_MAX 256
#define H_MAX 256

struct GrayImage {
    int width;                /* 实际宽度，≤ W_MAX */
    int height;               /* 实际高度，≤ H_MAX */
    int pixel[H_MAX][W_MAX];  /* 灰度值 0~255 */
};
```

选择**定长二维数组**而非动态内存或链表的理由：图像尺寸上限固定（256×256），定长数组可直接作为全局变量避免栈溢出；二维数组支持按行列随机访问，逐像素算法实现和调试都最简单；课程尚未讲授动态内存。处理日志采用结构体数组记录每次操作的名称、参数与统计量，训练结构体数组的组织能力。

### 3.3 数据流与控制流设计

控制流上，主控函数采用与范例一致的 `do-while + switch` 菜单循环，并用"已读图"状态标记约束各处理模块的调用次序。数据流上，数据沿"图像文件 → 全局图像结构 → 直方图数组/二值化结果 → 结果文件与日志"单向流动，各模块只通过全局 g_img、g_hist 和参数传递交换数据。

## 4 关键实现

### 4.1 迭代法自动阈值

```c
/* autoThreshold: 迭代法自动求阈值，返回最终阈值 */
int autoThreshold(void) {
    int t = meanGray();              /* 初始阈值 = 全图均值 */
    int tNew = t, round = 0;
    do {
        t = tNew;
        tNew = (regionMean(t, 1) + regionMean(t, 0)) / 2;  /* 亮暗两区均值平均 */
        round++;
    } while (tNew != t && round < MAX_ROUND);
    return tNew;
}
```

实现要点：regionMean 内部一次遍历同时累加两区的和与计数，避免两次扫描；MAX_ROUND 限制防止极端图像死循环。

## 5 实验与结果分析

### 5.1 实验数据

使用 6 幅灰度图像：3 幅教师提供的真实场景图（零件照片、文字页、指纹），3 幅程序生成的仿真图（渐变图、双峰合成图、含噪声图），尺寸 64×48 至 256×256。

### 5.2 实验设置

对比固定阈值（取全图均值）与迭代法两种方案；记录迭代轮数、最终阈值、黑白占比；以人工在直方图谷底优选的阈值为参照，统计偏差。

### 5.3 实验结果

### 5.4 结果讨论

迭代法在全部双峰图像上与人工优选阈值偏差 ≤5 个灰度级，且 3~6 轮收敛，说明"两区均值迭代"是有效的自动阈值策略。单峰渐变图像上两种方法都缺乏明确依据，说明**任何阈值方法都有适用条件**，直方图形态判断应当前置。系统不足：迭代法对噪声敏感（含噪图迭代轮数增加）；未处理光照不均场景（需自适应局部阈值，超出课程范围，列为展望）。

## 6 计算机伦理考量

图像处理涉及个人影像信息。本系统实验全部使用教师提供的脱敏样例图与程序生成图像，不采集、不处理任何真实人脸等个人信息。若在真实场景部署（如课堂考勤、监控分析），应遵循知情同意原则，二值化等预处理只服务于既定功能，不得用于超出告知范围的身份追踪；处理结果应限定访问权限，防止影像泄露。作为开发者，还应意识到自动阈值在低对比度图像上可能产生误导性结果，关键决策场景必须保留人工复核。

## 7 结论与展望

本文基于课程内 C 语言知识完成了图像二值化处理系统的设计与实现，验证了二维数组 + 循环即可完成实用图像处理任务。实验表明迭代法自动阈值在双峰直方图图像上效果稳定。后续可从三方面改进：增加 3×3 均值滤波降噪后再二值化；实现分块自适应阈值应对光照不均；支持 24 位 BMP 真彩图读入（涉及二进制文件解析，作为自学方向）。
