## 二、预备知识：排序输出与文件写入的基本原理（零基础阅读）

### 1. 问题是怎么来的：结果要"写下来、看得懂"

程序算出的词频结果如果只显示在屏幕上，一关窗口就没了，也没法交给别人看。**写进文件**就能长期保存、随时查看。而"热度榜"必须排好序才有意义——排在前面的才是热词。

### 2. 排序规则：两个关键字

本题排序有**主关键字**和**次关键字**：

- 主关键字：**词频**，越大越靠前（降序）；
- 次关键字：**单词**，词频相同时按字母顺序从小到大（升序）。

比较"单词字典序"要用 `strcmp`。它的返回值含义是：

$$
\text{strcmp}(a,b) \begin{cases} <0, & a \text{ 在 } b \text{ 前面} \\ =0, & a \text{ 与 } b \text{ 相同} \\ >0, & a \text{ 在 } b \text{ 后面} \end{cases}
$$

所以"$a$ 排在 $b$ 后面"就写成 `strcmp(a, b) > 0`。**注意**：字符串不能用 `==` 或 `<` 直接比较（那比较的是地址），必须用 `strcmp`。

### 3. 冒泡排序的两个条件

```c
int swap_needed = 0;
if (t[j].count < t[j+1].count)          /* 词频小的往后 */
    swap_needed = 1;
else if (t[j].count == t[j+1].count &&
         strcmp(t[j].word, t[j+1].word) > 0)   /* 词频相同按词序 */
    swap_needed = 1;
if (swap_needed) { /* 整体交换 t[j] 与 t[j+1] */ }
```

交换时记得**整条记录交换**（第 7 章练习 22 强调过），用结构体整体赋值即可。

### 4. 写文件：格式串怎么拼

报告每行形如 `1. banana 12`，对应的 `fprintf` 是：

```c
fprintf(out, "%d. %s %d\n", rank, t[i].word, t[i].count);
```

`rank` 从 1 开始，每写一行加一。最后再写一行汇总：

```c
fprintf(out, "total words = %d, total count = %d\n", n, total);
```

### 5. 用本例走一遍

词条：apple(5)、banana(12)、cherry(5)。

- 排序：banana(12) 词频最大排第一；apple 与 cherry 词频都是 5，按字典序 `apple < cherry`，故 apple 第二、cherry 第三；
- 排名：1. banana 12、2. apple 5、3. cherry 5；
- 汇总：$total\ words = 3$，$total\ count = 5 + 12 + 5 = 22$。

写出的文件与样例完全一致。

> **这个思想在综合实验中反复出现**：B6 热度榜报告、B9 调度方案输出、B5 路径报告、B1 处理日志，都是"排序 + 写文件"同一个套路。

## 三、解题思路

1. **读文件名**并打开输入文件，判 `NULL`；
2. **读入 $n$ 与词条**到结构体数组 `t[]`，同时累加 `count` 得到总和；
3. **冒泡排序**：词频降序、并列按字典序升序，整条交换；
4. **打开输出文件**，判 `NULL`；
5. **写出报告**：循环 `fprintf` 每行，再写汇总行，`fclose`；
6. **屏幕提示**。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>     /* strcmp */

/* 词条结构体：单词与词频 */
struct Word {
    char word[16];
    int  count;
};

int main(void)
{
    char inName[64], outName[64];
    FILE *in, *out;
    struct Word t[10];
    int n, i, j;
    int total = 0;

    scanf("%s", inName);
    scanf("%s", outName);

    in = fopen(inName, "r");
    if (in == NULL) {
        printf("cannot open %s\n", inName);
        return 1;
    }

    /* 读入词条并累加总词频 */
    fscanf(in, "%d", &n);
    for (i = 0; i < n; i++) {
        fscanf(in, "%s %d", t[i].word, &t[i].count);
        total += t[i].count;
    }
    fclose(in);

    /* 冒泡排序：词频降序，并列按单词字典序升序 */
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - 1 - i; j++) {
            int sw = 0;
            if (t[j].count < t[j+1].count)
                sw = 1;
            else if (t[j].count == t[j+1].count &&
                     strcmp(t[j].word, t[j+1].word) > 0)
                sw = 1;
            if (sw) {
                struct Word tmp = t[j];
                t[j] = t[j+1];
                t[j+1] = tmp;
            }
        }
    }

    /* 写入报告文件 */
    out = fopen(outName, "w");
    if (out == NULL) {
        printf("cannot open %s\n", outName);
        return 1;
    }
    for (i = 0; i < n; i++)
        fprintf(out, "%d. %s %d\n", i + 1, t[i].word, t[i].count);
    fprintf(out, "total words = %d, total count = %d\n", n, total);
    fclose(out);

    printf("report written to %s\n", outName);

    return 0;
}
```

## 五、运行验证

**输入文件 `words.txt`**：
```
3
apple 5
banana 12
cherry 5
```

**运行前**：`report.txt` 不存在。

**运行后 `report.txt`**：
```
1. banana 12
2. apple 5
3. cherry 5
total words = 3, total count = 22
```

| 词条 | 词频 | 排名依据 | 输出行 |
|---|---|---|---|
| banana | 12 | 词频最大 | `1. banana 12` |
| apple | 5 | 并列，字典序在前 | `2. apple 5` |
| cherry | 5 | 并列，字典序在后 | `3. cherry 5` |

屏幕输出 `report written to report.txt`。输入文件不存在时输出 `cannot open xxx` 并正常退出。

## 六、常见错误与讲解

**错误 1：用 `==` 比较字符串（最典型）**

```c
if (t[j].word == t[j+1].word)              /* 错：比较地址 */
if (strcmp(t[j].word, t[j+1].word) == 0)   /* 对 */
```

**错误 2：并列时漏写次关键字，排序结果不稳定**

```c
if (t[j].count <= t[j+1].count) sw = 1;   /* 错：会把相同词频的也换来换去 */
```

必须区分"严格小于"与"相等且词序在后"两种情况。

**错误 3：只交换部分成员**

```c
int tmp = t[j].count; t[j].count = t[j+1].count; t[j+1].count = tmp;  /* 错：单词没跟着换 */
struct Word tmp = t[j]; t[j] = t[j+1]; t[j+1] = tmp;                  /* 对 */
```

**错误 4：忘记 fclose 或忘记判 NULL**

```c
out = fopen(outName, "w");
if (out == NULL) { ... }     /* 必须检查 */
...
fclose(out);                 /* 必须关闭，保证数据落盘 */
```
