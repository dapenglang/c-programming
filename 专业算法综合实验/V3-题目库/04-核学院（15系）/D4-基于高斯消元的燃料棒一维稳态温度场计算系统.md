# 题目 D4：基于高斯消元的燃料棒一维稳态温度场计算系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行燃料棒温度场计算工具。核燃料棒在运行时会持续产生裂变热，热量从燃料芯部向表面传导，形成由中心到表面的温度分布（温度场）。系统把燃料棒沿半径方向离散成有限个网格点，根据稳态导热方程与边界条件组装出一组线性方程，用高斯消元法求解，得到每个网格点上的温度，并进一步给出最高温度（中心温度）及其位置、温度沿半径的分布曲线，还支持通过加密网格考察计算精度。

燃料棒中心温度是反应堆安全分析中最关键的参数之一。如果不做这项计算，就无法判断燃料是否会熔化——铀燃料的熔点约 2865 ℃，一旦中心温度逼近熔点就会出现芯块熔化、包壳破损、放射性物质释放等严重事故。反应堆热工设计中的功率限值、燃耗极限、安全裕度评估，全部依赖准确的燃料温度计算。此外，温度的径向分布还直接影响燃料的多普勒效应、热应力与芯块—包壳间隙的传热，是反应堆物理与热工耦合分析的基础输入。看似简单的一维导热问题，正是这些复杂计算的起点。

本系统支撑的关键场景包括：① 核电站燃料棒的热工安全裕度评估；② 燃料棒功率限值与最大线功率密度设计；③ 反应堆稳态与瞬态热工分析的基础模块；④ 新型燃料（如事故容错燃料）导热性能对比；⑤ 教学实验——用数值方法复现导热方程，理解"离散 + 线性方程组求解"这一工程计算的基本范式。本系统采用有限差分把导热方程离散成三对角线性方程组，再用高斯消元求解；离散化本身只是"数组 + 循环"的组合运用，不涉及任何超出课程范围的数值方法。本题目与核工程与核技术专业"反应堆热工水力"方向直接对应。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的燃料棒一维稳态温度场计算系统：从文本文件读入棒半径、网格数、表面温度、导热系数与功率分布参数，逐网格计算体积发热率，按导热方程组装三对角系数矩阵与右端项，用带列主元的高斯消元求解温度场，输出温度分布结果表、查找最高温度及其径向位置，做不同网格数的加密对比实验，绘制温度分布字符画并写出结果文件。

专业关联上，本题目还原了核热工分析中"把偏微分导热方程离散为线性方程组再求解"的核心流程。学生在实现中掌握二维数组、循环嵌套、函数调用、高斯消元与排序查找，理解网格数与计算精度的关系，全程不涉及矩阵求逆等超纲内容。

## 三、数据来源与格式

- **数据文件格式**：燃料棒参数采用纯文本格式，首行为标题说明，其后每行一条工况记录，字段以空格分隔。文件 `rod_config.txt` 字段依次为：工况标识（无空格字符串）、棒半径 R（单位：cm）、径向网格数 N（整数）、表面温度 Ts（单位：℃）、导热系数 k（单位：W/(cm·℃)）、平均体积发热率 qv（单位：W/cm³）、功率分布类型（`uniform` 或 `cosine`，字符串）。

```
# case_id  radius_cm  n_grid  surf_temp_C  k_W_cmC  qv_W_cm3  profile
base      0.41       40      320.0        0.0300   350.0     cosine
uniform   0.41       40      320.0        0.0300   350.0     uniform
highpower 0.41       60      300.0        0.0300   520.0     cosine
```
```
# refine_case  radius_cm  k_W_cmC  qv_W_cm3  surf_temp_C  n_grid_list
base           0.41       0.0300   350.0     320.0        10 20 40 80 160
```
- **仿真数据生成规则**：
  - 工况标识：3～12 个字母数字字符，无空格。
  - 棒半径 R：单位 cm，取值范围 0.30～0.60，按均匀分布生成，保留两位小数。
  - 网格数 N：整数，取值范围 10～200（且为偶数，便于取中心节点），默认 40。
  - 表面温度 Ts：单位 ℃，取值范围 280.0～360.0，按均匀分布生成。
  - 导热系数 k：单位 W/(cm·℃)，取值范围 0.0200～0.0500，模拟 UO₂ 芯块导热系数的量级。
  - 平均体积发热率 qv：单位 W/cm³，取值范围 50.0～600.0，按均匀分布生成。
  - 功率分布类型：`uniform`（均匀）或 `cosine`（中心高、边缘低，q(r)=qv·(1+0.5·cos(π·r/R))/1.5），由生成程序随机选取。
  - **异常值注入方式**：由教师提供的生成程序注入三类错误。其一，半径或导热系数填 0 或负数，校验时应剔除；其二，网格数超出 10～200 或不是正整数（如 `0`、`5`、`500`），校验时取默认 40 并告警；其三，表面温度越界（如 `1000.0`），校验时给出提示；另可注入非数字串（如 `N/A`）考察读入容错。

- **真实数据集（如有）**：真实燃料棒热工参数可参考 IAEA 与国际经合组织核能署（NEA）发布的燃料性能分析基准题与国际燃料性能数据库（如 OECD/NEA IFPE，https://www.oecd-nea.org/）；UO₂ 导热系数与裂变气体行为可参考 IAEA-TECDOC 系列报告。学生**无需下载**真实数据，课程提供与上述字段含义对应的简化仿真参数表。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_GRID    201        /* 最大网格点数（含中心与表面） */
#define MAX_CASE    20         /* 最多工况数 */
#define MAX_REFINE  10         /* 加密实验网格数个数 */

/* ===== 工况参数结构体 ===== */
struct RodCase {
    char   caseId[12];         /* 工况标识 */
    double radius;             /* 棒半径 R，单位：cm，> 0 */
    int    nGrid;              /* 径向网格数 N，含中心点 r=0 */
    double surfTemp;           /* 表面温度 Ts，单位：℃ */
    double kCond;              /* 导热系数 k，单位：W/(cm·℃)，> 0 */
    double qvAvg;              /* 平均体积发热率，单位：W/cm³ */
    char   profile[10];        /* 功率分布："uniform" / "cosine" */
    int    valid;              /* 有效标志 */
};

/* ===== 三对角线性方程组系数 ===== */
struct TriDiag {
    double a[MAX_GRID];        /* 下对角线系数 a[i]，用于 T[i-1] */
    double b[MAX_GRID];        /* 主对角线系数 b[i]，用于 T[i] */
    double c[MAX_GRID];        /* 上对角线系数 c[i]，用于 T[i+1] */
    double d[MAX_GRID];        /* 右端项 d[i] */
    double x[MAX_GRID];        /* 解向量：各网格点温度，℃ */
    int    n;                  /* 方程个数（= 未知温度节点数） */
};

/* ===== 温度场结果 ===== */
struct TempField {
    double r[MAX_GRID];        /* 各网格点半径坐标，cm */
    double T[MAX_GRID];        /* 各网格点温度，℃ */
    double qv[MAX_GRID];       /* 各网格点体积发热率，W/cm³ */
    int    n;                  /* 节点数 */
    double tCenter;            /* 中心温度，℃ */
    int    iCenter;            /* 中心温度所在下标 */
    double tAve;               /* 截面平均温度，℃ */
};

/* ===== 全局数据区 ===== */
struct RodCase   g_case[MAX_CASE];        /* 工况表 */
int              g_caseCount;             /* 工况条数 */
int              g_current;               /* 当前工况下标 */
struct TriDiag   g_mat;                   /* 当前线性方程组 */
struct TempField g_field;                 /* 当前温度场结果 */
int              g_refineN[MAX_REFINE];   /* 加密实验网格数列表 */
int              g_refineCount;           /* 加密实验网格数个数 */
double           g_refineTc[MAX_REFINE];  /* 各网格数对应的中心温度 */

/* ===== 处理日志 ===== */
struct LogItem { char op[24]; char detail[72]; };
struct LogItem g_log[128];
int            g_logCount;
```

辅助说明：导热方程在柱坐标下为 `(1/r)·d/dr(k·r·dT/dr) + qv = 0`，采用有限体积（差分）离散后每个内部节点得到"下对角线—主对角线—上对角线"形式的三对角方程，中心节点用对称条件 `dT/dr|(r=0) = 0` 处理，表面节点用第一类边界条件 `T(R) = Ts` 消元并入右端项。全部系数存入 `TriDiag` 结构体，用一维数组承载（课程 5.1），避免使用超纲的矩阵求逆。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（3 个模块）

**M1 网格与边界条件读入模块**（源文件 `RodIO.c`）

- 功能简介：打开参数文件，跳过首行标题，循环读入各工况的半径、网格数、表面温度、导热系数、发热率与分布类型，填充 `g_case[]`；对网格数越界、半径或导热系数非正的记录置 `valid=0` 并给出校验清单；生成各网格点的半径坐标 `r[i] = i·R/N`。
- 输入：参数文件路径（默认 `rod_config.txt`）。
- 输出：`g_case[]`、`g_caseCount`、当前工况的 `r[]`；屏幕校验报告。

**M2 热源项计算模块**（源文件 `HeatSrc.c`）

- 功能简介：按工况的功率分布类型逐网格计算体积发热率 `qv[i]`：均匀分布时各点等于平均值；余弦分布时按 `qv(r) = qvAvg·(1+0.5·cos(π·r/R))/1.5` 计算并归一化，保证体积平均值等于 `qvAvg`。
- 输入：当前工况参数、`r[]`。
- 输出：`g_field.qv[]`；屏幕打印热源分布的若干抽样点。

**M3 差分方程组装模块**（源文件 `Assemble.c`）

- 功能简介：按径向有限体积离散公式，对每个内部节点计算三对角系数 `a[i]`、`b[i]`、`c[i]` 与右端项 `d[i]`；中心节点用对称边界条件，表面节点用 `T=Ts` 把已知温度移入右端项；输出矩阵的非零元个数与首行系数作检查。
- 输入：`g_case[g_current]`、`g_field.qv[]`、`r[]`。
- 输出：`g_mat` 中的 `a/b/c/d` 与方程个数 `n`；屏幕矩阵摘要。

### 第二部分：算法实现（3 个模块）

**M4 高斯消元求解模块**（源文件 `Gauss.c`）

- 功能简介：对三对角方程组用带列主元的高斯消元（消元 + 回代）求解温度向量 `x[]`，写入 `g_mat.x[]`；每步选主元时若主元绝对值小于 1e-12 给出"矩阵奇异或几何异常"提示并中止；提供直接针对三对角的简化消元作为对照实现。
- 输入：`g_mat` 的 `a/b/c/d`、方程个数 `n`。
- 输出：解向量 `g_mat.x[]`；返回成功标志；屏幕消元轮数信息。

**M5 温度场结果表模块**（源文件 `TempField.c`）

- 功能简介：把高斯消元的解与网格半径对应起来，填充 `g_field` 的 `r[]`、`T[]`，计算截面平均温度 `tAve`（按面积加权，梯形法），并按解析近似 `T_center ≈ Ts + qvAvg·R²/(4k)` 给出理论中心温度作对照。
- 输入：`g_mat.x[]`、`g_case[g_current]`、`r[]`。
- 输出：`g_field`（含 `tCenter`、`tAve`）；屏幕温度场结果表。

**M6 最高温度与位置查找模块**（源文件 `FindMax.c`）

- 功能简介：遍历温度场数组找出最高温度节点（迭代求最大值并记录下标），输出最高温度、对应半径位置及其相对位置百分比；同时输出最低温度与径向温度差（ΔT = 中心 − 表面）。
- 输入：`g_field`。
- 输出：屏幕最高温度与位置信息；写入日志。

### 第三部分：数据输出（4 个模块）

**M7 网格加密实验模块**（源文件 `Refine.c`）

- 功能简介：读入加密实验的网格数列表，对每个网格数重新执行 M1～M4（保持半径、导热系数、发热率、表面温度不变），记录对应的中心温度 `g_refineTc[]`，输出"网格数—中心温度—与前一次之差"对照表，考察数值解随网格加密的收敛过程，并与理论值比较。
- 输入：`g_refineN[]`、`g_refineCount`、基础参数。
- 输出：`g_refineTc[]`；屏幕收敛对照表。

**M8 温度分布字符画模块**（源文件 `TempPlot.c`）

- 功能简介：以半径为横轴、温度为纵轴（或把半径作为纵轴、用竖条长度表示温度），绘制温度沿半径的分布字符图；标出中心温度点与表面温度点的位置，让"中心最高、边缘最低"的分布形态直观可见。
- 输入：`g_field`。
- 输出：屏幕字符温度分布图。

**M9 结果文件输出模块**（源文件 `RodReport.c`）

- 功能简介：把当前工况的温度场结果（半径—发热率—温度三列）写出到 `tempfield_<工况>.csv`，把网格加密实验对照表写出到 `refine_check.csv`，并把最高温度、中心温度、ΔT 等摘要写入 `rod_report.txt`。
- 输入：`g_field`、`g_refineN[]`、`g_refineTc[]`。
- 输出：`tempfield_base.csv`、`refine_check.csv`、`rod_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：文本主菜单（读参数 / 选工况 / 算热源 / 组装方程 / 高斯求解 / 温度场表 / 找最高温度 / 网格加密 / 画温度分布 / 输出结果 / 退出），用 `do-while + switch` 调度 M1～M9；状态标记约束"必须先完成组装与求解才能查看温度场"。
- 输入：用户菜单选项。
- 输出：调度各模块；维护日志表。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → `switch` 分发各模块。状态约束：M4 求解前必须已执行 M3 组装；M5/M6/M8/M9 展示或输出前必须已求解；M7 网格加密实验内部会对每个网格数重新走 M2→M3→M4 流程。

**数据流**：

```
rod_config.txt ─► M1 网格与边界读入 ─► g_case[] / r[]
                        │
                        ▼
                 M2 热源项计算 ─► g_field.qv[]
                        │
                        ▼
                 M3 差分方程组装 ─► g_mat.a/b/c/d (三对角)
                        │
                        ▼
                 M4 高斯消元求解 ─► g_mat.x[] (温度解)
                        │
        ┌───────────────┼────────────────┬──────────────────┐
        ▼               ▼                ▼                  ▼
  M5 温度场结果表  M6 最高温度查找  M7 网格加密实验  M8 温度分布字符画
        └───────────────┴───────┬────────┴──────────────────┘
                                ▼
                        M9 结果文件输出
```

所有模块通过全局工况表、全局矩阵结构与全局温度场结构体交换数据；高斯消元（M4）、热源计算（M2）、方程组装（M3）均封装为独立函数，接口在编码前书面约定。

## 十、选做扩展

1. **分区导热系数**：允许芯块与包壳采用不同的导热系数（在参数文件中增加一段包壳区），组装方程时按节点所在区域选取 k，比较有无包壳时的中心温度差别。
2. **线功率密度换算**：由体积发热率换算线性功率密度 `q' = qv·π·R²`（W/cm），输出一组不同 q' 下的中心温度对照表，理解工程上常用的"线功率密度"限值。
3. **温度—功率敏感性分析**：固定几何参数，把体积发热率取 5 个递增的值逐一求解，输出"qv—中心温度"对照表与曲线字符画，观察中心温度随发热率的近似线性增长。
