## 二、预备知识：比值、浓度与百分比（零基础阅读）

### 1. 问题是怎么来的

"冰有多密"不能只看冰块个数，也不能只看总面积——同样 3600 m² 的冰块，铺在 10000 m² 的海域和铺在 100000 m² 的海域里，稀稠程度完全不同。因此需要一个**和面积无关的相对量**：把冰块总面积除以域面积，得到 0 到 1 之间的一个数。这就是**面积浓度**。

### 2. 公式是怎么来的

设冰块总面积为 $A_{ice}$、计算域面积为 $A_{domain}$，定义

$$
C = \frac{A_{ice}}{A_{domain}}
$$

- 当域内全是冰时 $A_{ice} = A_{domain}$，$C = 1$；
- 当域内没有冰时 $A_{ice} = 0$，$C = 0$。

所以 $C$ 天然落在 $[0, 1]$ 内，含义是"冰覆盖了域面积的几成"。工程上还常用百分比表示，只需再乘 100：

$$
\text{百分比} = C \times 100\%
$$

### 3. 用本例走一遍

输入 $A_{ice} = 7250$，$A_{domain} = 10000$：

- 浓度 $C = 7250 / 10000 = 0.725$；
- 检查量纲：分子分母都是 m²，相除后无量纲，符合"浓度"的物理含义；
- 百分比 $= 0.725 \times 100 = 72.5\%$，即"冰覆盖了七成多的面积"。

再取 $A_{ice} = 3600$：$C = 0.36$，百分比 $36\%$，与现象一致：冰块变少了，浓度下降。

### 4. 编程时怎么用它

两个面积用 `double` 读入，浓度用一行除法算出，百分比在 `printf` 里用 `C * 100` 现算。关键有两点：**分子分母必须都是实数**（否则 3600/10000 会被整数除法截断成 0），以及 `printf` 中要显示百分号必须写 `%%`。

> **这个思想在综合实验中反复出现**：C10 碎冰场浓度、C7 事件占比、B1 直方图频率，本质都是"部分 / 全体"的比值，写法完全一致。

## 三、解题思路

1. **确定变量**：`A_ice`、`A_domain` 用 `double`，浓度 `C` 也用 `double`；
2. **读入**：`scanf("%lf %lf", &A_ice, &A_domain);`；
3. **算浓度**：`C = A_ice / A_domain;`；
4. **输出**：一条 `printf`，小数值用 `%.4f`、百分比用 `%.2f`，百分号写成 `%%`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double A_ice;      /* 冰块总面积，单位 m^2 */
    double A_domain;   /* 计算域总面积，单位 m^2 */
    double C;          /* 面积浓度，无量纲，0~1 */

    /* 读入两个面积 */
    scanf("%lf %lf", &A_ice, &A_domain);

    /* 面积浓度 = 冰块总面积 / 域总面积（实数除法） */
    C = A_ice / A_domain;

    /* 同时输出小数值与百分比，%% 用于显示一个百分号 */
    printf("C = %.4f (%.2f%%)\n", C, C * 100.0);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3600 10000 | 3600/10000 = 0.36，×100 = 36% | `C = 0.3600 (36.00%)` ✓ |
| 7250 10000 | 7250/10000 = 0.725，×100 = 72.5% | `C = 0.7250 (72.50%)` ✓ |
| 8000 10000 | 0.8，×100 = 80% | `C = 0.8000 (80.00%)` ✓ |
| 2500 10000 | 0.25，×100 = 25% | `C = 0.2500 (25.00%)` ✓ |

浓度均落在 0～1 之间，且小数与百分比一一对应，换算正确。

## 六、常见错误与讲解

**错误 1：整数除法把浓度算成 0（最典型）**

```c
int A_ice = 3600, A_domain = 10000;
double C = A_ice / A_domain;   /* 错：3600/10000 整数除法得 0，C = 0 */
```

即使 `C` 声明为 `double`，右边先按整数除法算完再赋值，结果仍是 0。正确做法：让面积本身是 `double`，或用 `3600.0 / 10000`。

**错误 2：百分号忘了转义**

```c
printf("C = %.4f (%.2f%)\n", C, C * 100);    /* 错：单个 % 会被当成格式符 */
printf("C = %.4f (%.2f%%)\n", C, C * 100);   /* 对：%% 才显示一个 % */
```

**错误 3：读入漏掉 `&`**

```c
scanf("%lf %lf", A_ice, A_domain);      /* 错 */
scanf("%lf %lf", &A_ice, &A_domain);    /* 对：每个变量都要取地址 */
```

**错误 4：百分比多乘或少乘 100**

```c
printf("%.2f%%\n", C);          /* 错：0.36 会显示成 0.36% */
printf("%.2f%%\n", C * 100.0);  /* 对：0.36 显示成 36.00% */
```

先想清楚"要小数形式还是百分比形式"，再决定是否乘 100。

## 七、与综合实验的衔接

- 实验 **C10（碎冰场生成与碰撞频率估算）**中，面积浓度既是生成碎冰场时要控制的输入参数，也是统计输出的核心指标，本练习就是这一环节的最小实现；学到第 3 章（循环）后可以逐个累计每块冰的面积，学到第 5 章（数组）后可以按网格分区计算局部浓度；
- 同类"部分 / 全体"的比值计算还出现在 C7 事件占比、B1 直方图频率统计里。掌握"实数除法 + 百分比输出"这一套，就能在多个实验中复用。
