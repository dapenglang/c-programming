## 二、预备知识：计数数组——让下标代表"类别"（零基础阅读）

### 1. 直方图要回答的问题

给一批载荷值，我们想知道"**落在每个区间的数有多少个**"。把 $[0,100)$ 等分成 5 个区间，答案就是 5 个整数：第 1 个区间几个、第 2 个区间几个……直到第 5 个。要把这 5 个整数记下来，最自然的容器就是一条长度为 5 的数组：

```c
int cnt[5];    /* cnt[0] 记第 1 个区间，cnt[1] 记第 2 个区间，…… */
```

这种"**用下标代表一个类别、用单元值代表该类别的计数**"的数组，叫**计数数组**。它的妙处在于：把"统计类别 $k$ 有几个"这件事，变成了"给 `cnt[k]` 加 1"这么简单——不需要写一长串 `if-else` 去逐个判断。

### 2. 怎么把"一个值"变成"区间编号"

关键是找到从数值到区间下标的换算。本题每个区间宽度是 20，区间编号就是"这个值里包含几个 20"：

$$
\text{bin} = \left\lfloor \dfrac{v}{20} \right\rfloor
$$

例如 $v = 27$，$27 / 20 = 1.35$，取整得 1，落在第 2 个区间 $[20,40)$；$v = 91$，$91/20 = 4.55$，取整得 4，落在第 5 个区间 $[80,100)$。在 C 语言里用强制类型转换实现"向下取整"：

```c
b = (int)(v / 20.0);   /* v 一定要用 20.0（实数）除，再用 (int) 截断小数 */
```

注意这里的两个细节：用 `20.0` 而不是 `20`，保证先做实数除法再截断；`(int)` 截断是**向零取整**，在 $v \ge 0$ 时与向下取整一致（本题 $v$ 均非负，安全）。

### 3. 为什么是"左闭右开"

用 $\lfloor v/20 \rfloor$ 分桶时，边界值天然满足**左闭右开**：$v = 20$ 得到 $20/20 = 1$，计入 $[20,40)$；$v = 19.9$ 得到 0，计入 $[0,20)$。这样每个值都有**唯一**归属，区间之间既不重叠也不遗漏——这正是直方图分桶的正确做法。若规则设计成"左开右闭"，就会导致区间接缝处的归属混乱。

### 4. 计数数组必须先清零

`int cnt[5]` 若在函数内定义，初值是内存残留的随机数。直接 `cnt[b]++` 就是在上一次运行留下的垃圾值上累加，结果完全错误。所以第一步必须清零：

```c
int cnt[5] = {0};      /* 花括号里的 0 表示"其余全部置 0"，5 个单元都清零 */
```

这条"**累加前先清零**"的纪律，练习 12（列和）也强调过，是所有计数、累加问题的共同前提。

### 5. 怎样把频数画成"条形"

打印条形就是"频数是几，就连续打几个星号"。用一个内层循环：

```c
for (j = 0; j < cnt[k]; j++)
    printf("*");
```

外层循环走 5 个区间，内层循环按该区间频数打印星号，密度大的区间自然"条"更长，一眼就能看出载荷集中在哪一档。

## 三、解题思路

1. **定计数数组**：`int cnt[5] = {0};`，对应 5 个区间；
2. **读入并计数**：循环 `n` 次，每读一个 `v`，算 `b = (int)(v / 20.0)`，执行 `cnt[b]++`；
3. **（可选）先把数据存入数组再统计**：本题边读边计即可，但若后续还要用原始数据，建议先存数组（呼应练习 01 的"先存储后处理"）；
4. **输出 5 行**：外层 `k` 从 0 到 4，用 `%3d` 输出区间两端 `k*20` 与 `k*20+20`，输出频数，再内层循环打印 `cnt[k]` 个星号。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int cnt[5] = {0};          /* 5 个区间的计数数组，全部清零 */
    int n, i, j, k;
    int b;                     /* 区间编号 */
    double v;                  /* 当前载荷值 */

    scanf("%d", &n);

    /* 边读入边统计：每个值归入区间 b，对应计数加 1 */
    for (i = 0; i < n; i++) {
        scanf("%lf", &v);
        b = (int)(v / 20.0);   /* 落在第几个区间，0 ~ 4 */
        cnt[b]++;
    }

    /* 逐区间输出标签、频数与星号条形 */
    for (k = 0; k < 5; k++) {
        printf("[%3d,%3d): %d ", k * 20, k * 20 + 20, cnt[k]);
        for (j = 0; j < cnt[k]; j++)
            printf("*");
        printf("\n");
    }

    return 0;
}
```

## 五、运行验证

以样例 1 的 10 个数为例，逐个归桶：

| 值 | 区间编号 `(int)(v/20)` | 落入区间 |
|---|---|---|
| 3, 8, 12 | 0 | $[0,20)$ |
| 27, 39 | 1 | $[20,40)$ |
| 41, 58 | 2 | $[40,60)$ |
| 62, 79 | 3 | $[60,80)$ |
| 91 | 4 | $[80,100)$ |

得到 `cnt = {3, 2, 2, 2, 1}`。程序输出：

```
[  0, 20): 3 ***
[ 20, 40): 2 **
[ 40, 60): 2 **
[ 60, 80): 2 **
[ 80,100): 1 *
```

与题干样例 1 完全一致。样例 2 的 `0 19 20 40 79 99`：`0`、`19` 归第 1 桶，`20` 归第 2 桶，`40` 归第 3 桶，`79` 归第 4 桶，`99` 归第 5 桶，得 `cnt = {2,1,1,1,1}`，输出与样例 2 吻合（注意 `20` 计入 $[20,40)$，体现了左闭右开规则）。

## 六、常见错误与讲解

**错误 1：计数数组忘记清零**

```c
int cnt[5];          /* 错：初值随机，累加结果不可预测 */
int cnt[5] = {0};    /* 对：先全部置 0 */
```

**错误 2：整除用整数导致边界错**

```c
b = v / 20;          /* 错：v 是 double，若写成 v/20 仍可（会提升），但若 v 是 int 则需注意 */
b = (int)(v / 20.0); /* 对：明确用实数除、再截断，规则清晰 */
```

更稳妥的写法是常量除。若区间宽度或个数改变，把 `20.0` 换成新的宽度、把 5 换成新的桶数即可，逻辑不变。

**错误 3：循环边界与桶数不一致**

```c
int cnt[5];
for (k = 0; k < 10; k++) ...   /* 错：桶只有 5 个，k=5 起越界 */
for (k = 0; k < 5; k++) ...    /* 对：与桶数一致 */
```

**错误 4：星号个数写成了固定值**

```c
printf("***");                       /* 错：所有区间都打三个星 */
for (j = 0; j < cnt[k]; j++) printf("*");  /* 对：按频数打 */
```

- 实验 **C7（冰区船舶载荷辨识与统计系统）**模块 M9 用直方图呈现载荷幅值分布，判断载荷是否集中在某档，为结构设计提供依据。本练习的计数数组就是该模块的核心：真实系统桶数更多（如 10 个区间），但"值 → 桶号 → 计数"三段式完全一样；
