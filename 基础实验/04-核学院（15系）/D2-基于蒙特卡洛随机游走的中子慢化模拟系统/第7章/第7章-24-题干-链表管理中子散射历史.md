# 第 7 章 练习 24　链表管理中子散射历史

**所属综合实验**：D2（D2-基于蒙特卡洛随机游走的中子慢化模拟系统）

**对应章节**：7 结构体与链表（7.1 结构体类型、7.4 链表的建立与遍历、7.5 动态内存分配与释放）

**场景来源**：综合实验 D2《基于蒙特卡洛随机游走的中子慢化模拟系统》（核学院）——本练习是该实验中"用链表记录中子散射事件序列"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

慢化模拟（实验 D2）要跟踪一个中子从快中子减速到热中子的全过程。它**每散射一次就产生一条记录**（第几次散射、散射后能量），次数事先并不知道——取决于初始能量与每次的损失比例。

这种"数量不定、逐个追加"的记录，用**数组**预设大小很浪费（可能不够，也可能空很多），最自然的容器是**链表**：每发生一次散射，就动态申请一个结点接在链尾。模拟结束后从头遍历，就能读到完整的**散射历史**。本练习实现这个链表。

## 二、任务要求

编写一个完整程序 `list_scatter.c`：

1. 定义链表结点结构体 `struct Scatter`，成员包括：
   - `int order;`（第几次散射，从 1 开始）；
   - `double energy;`（该次散射后的能量，eV）；
   - `struct Scatter *next;`（指向下一个结点）；
2. 从键盘读入初始能量 `E0`（eV）、平均能量保留因子 `alpha`（\(0<\alpha<1\)）、散射次数 `n`（\(1 \le n \le 100\)）；
3. 用 `malloc` **逐次申请结点并接到链表尾部**，每次能量乘 `alpha` 并记入结点；
4. **遍历链表**输出散射历史（每次一行），再输出总散射次数；
5. 程序结束前**释放所有结点**（`free`），避免内存泄漏。

## 三、输入输出格式

**输入**：一行，三个数，依次为初始能量 `E0`（eV）、保留因子 `alpha`、散射次数 `n`，用空格分隔（`n` 为整数）。

**输出**：`n` 行散射记录，每行格式 `step i: E = x.xxxxe±xx`（能量科学计数法保留 4 位小数）；最后一行输出 `collisions = n`。

## 四、样例

**样例 1**

输入：
```
1000000 0.5 4
```
输出：
```
step 1: E = 5.0000e+05
step 2: E = 2.5000e+05
step 3: E = 1.2500e+05
step 4: E = 6.2500e+04
collisions = 4
```

**样例 2**

输入：
```
2000000 0.9 3
```
输出：
```
step 1: E = 1.8000e+06
step 2: E = 1.6200e+06
step 3: E = 1.4580e+06
collisions = 3
```

## 五、提示

链表结点结构体的定义：

```c
struct Scatter {
    int    order;    /* 第几次散射 */
    double energy;   /* 散射后能量，eV */
    struct Scatter *next;   /* 指向下一个结点 */
};
```

**建链（尾插法）**：维护一个 `tail` 指针始终指向当前链尾，每次新结点接到 `tail->next`，再把 `tail` 移到新结点。**动态申请**用 `malloc(sizeof(struct Scatter))`，用完用 `free` 释放。

能量递推：第 \(k\) 次散射后能量为

$$
E_k = \alpha^{\,k} E_0
$$

**完成本练习后你将具备的能力**：定义自引用结构体（含 `next` 指针）、用 `malloc` 动态申请结点、用尾插法建立链表、遍历链表、用 `free` 释放内存——这些是实验 D2 中"散射历史记录"的地基。
