# 第 5 章 练习 05　插值表数组化查算

**对应章节**：5 批量数据处理方法（5.1 一维数组——表格数据存储与区间定位；3.2 选择结构、3.3 循环结构；2.5 线性插值方法）

**场景来源**：综合实验 C1《声速剖面查算与声线跟踪系统》（水声学院）——本练习是该实验中"深度-声速表数组化查算"环节的实现（同一结构也用于实验 A1 风荷载的多档查表）。

**建议用时**：30 分钟

## 一、应用场景

声呐的作用距离取决于海水中的声速分布。海洋调查给出的是**离散档位**的声速表：只在若干个标准深度上实测了声速，而声线跟踪程序需要**任意深度**的声速。第 2 章的插值题只处理"两档表格"，档位写死在常量里；真实的声速表有五档、十档甚至更多，必须用**两个平行数组**存放——一个存深度、一个存声速，同一下标对应表格同一行。查算时先用循环找出输入深度落在哪两档之间，再对那一档做线性插值。这就是实验 C1 与 A1 中"查表插值模块"的标准形态。

## 二、任务要求

编写一个完整程序 `sound_profile.c`：

1. 程序中用两个长度为 5 的 `const double` 数组存放声速表：
   - 深度表 `dep[5] = {0, 20, 50, 100, 200}`（单位：m）；
   - 声速表 `spd[5] = {1450.0, 1447.0, 1445.0, 1452.0, 1465.0}`（单位：m/s）；
2. 从键盘读入一个查询深度 `d`（`double`，**题目保证 $0 \le d \le 200$**）；
3. 用循环扫描深度表，确定 $d$ 落在哪两档 `dep[i]` 与 `dep[i+1]` 之间（$d$ 恰好等于某档值时直接取该档声速）；
4. 用线性插值公式计算该深度的声速并输出，保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示查询深度 d（米）。

**输出**：一行，格式为 `c = 声速`，声速保留 2 位小数（单位 m/s）。

## 四、样例

**样例 1**

输入：
```
35
```
输出：
```
c = 1446.00
```

**样例 2**

输入：
```
150
```
输出：
```
c = 1458.50
```

## 五、提示

1. 线性插值公式：已知 $(x_0, y_0)$、$(x_1, y_1)$，则
$$
y = y_0 + \dfrac{(y_1 - y_0)\,(x - x_0)}{x_1 - x_0}
$$
2. "找区间"的循环写法：让 $i$ 从 0 扫到 3，只要 `d >= dep[i] && d <= dep[i+1]` 成立，区间就找到了，用 `break` 跳出；
3. 区间找到后，插值的四个量就是 `dep[i]`、`spd[i]`、`dep[i+1]`、`spd[i+1]`——**下标相同**的两个数组是同一行的两列；
4. 查询深度恰好等于档位值时，落在两个区间判断的边界上，此时 `dep[i] <= d <= dep[i+1]` 的闭区间写法能自然命中其中一个区间，插值公式在端点处自动退回表格值，无需特判；
5. 本题深度表只有 5 档，若扩展到 10 档、20 档，循环与插值代码**一个字都不用改**——这正是数组化相对第 2 章"常量写死"的进步。

**完成本练习后你将具备的能力**：用平行数组存放二维含义的表格数据、循环定位输入所在的表格区间、把第 2 章的两点插值升级为"任意档数表格的通用查算"——实验 C1 的声速查算模块与 A1 的风压系数查表模块都建立在这个结构上。
