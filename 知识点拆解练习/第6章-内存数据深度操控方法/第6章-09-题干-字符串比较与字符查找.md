# 第 6 章 练习 09　字符串比较与字符查找

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用、6.4 指针与字符串）

**场景来源**：综合实验 B10《文本相似度分析系统》（人工智能学院）——本练习是该实验中"词条比对与关键字符定位"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本相似度分析系统 B10 在比对两条语料时，需要判断两个单词**是否相同、谁排在词典更前面**——这就是字符串比较（按字典序逐字符比 ASCII 码）；在词形分析时，还需要**定位某个字符在单词中首次出现的位置**。本练习要求手写两个函数：`my_strcmp` 逐字符比较两个字符串，返回"负、零、正"三种结果；`my_strchr` 返回目标字符首次出现处的**地址**（找不到返回 `NULL`）。这两个函数与练习 08 的复制、连接共同构成 B10 的自研字符串工具包。

## 二、任务要求

编写一个完整程序 `word_cmp.c`：

1. 编写函数 `int my_strcmp(char *s1, char *s2)`：从首字符开始逐对比较，字符不同立即返回 $s1$ 当前字符 $-\ s2$ 当前字符；一路相同走到末尾则返回 0；
2. 编写函数 `char *my_strchr(char *s, char ch)`：用指针扫描 `s`，返回 `ch` 首次出现处的地址；若直到 `'\0'` 都未出现，返回 `NULL`；
3. 主函数读入两个单词与一个待查字符：调用 `my_strcmp`，按返回值符号输出 `w1 < w2`、`w1 = w2` 或 `w1 > w2`；
4. 调用 `my_strchr` 在第一个单词中查找该字符：找到输出 `pos = 首次出现的下标`（用指针相减求），否则输出 `pos = -1`。

## 三、输入输出格式

**输入**：一行，两个不含空格的单词与一个字符，空格分隔（单词长度不超过 49）。

**输出**：两行。
第 1 行：`w1 < w2`、`w1 = w2` 或 `w1 > w2`；
第 2 行：`pos = 下标` 或 `pos = -1`。

## 四、样例

**样例 1**

输入：
```
shell ship l
```
输出：
```
w1 < w2
pos = 2
```

**样例 2**

输入：
```
ice ice z
```
输出：
```
w1 = w2
pos = -1
```

## 五、提示

1. 比较的是**字符的 ASCII 码**：小写字母中 `'a' < 'b' < ... < 'z'`，逐位比出高低即得字典序；
2. `my_strcmp` 骨架：`while (*s1 == *s2 && *s1 != '\0') { s1++; s2++; }`，循环后 `return *s1 - *s2;`——同时处理"中途分出胜负"与"完全相等"两种结局；
3. `my_strchr` 骨架：`for (p = s; *p != '\0'; p++) if (*p == ch) return p;`，循环后 `return NULL;`；
4. 下标 = `p - w1`（同数组内指针相减为元素个数）；主函数输出 `-1` 时**不要**返回 `NULL` 的地址值，而是根据判空结果打印 -1。

**完成本练习后你将具备的能力**：手写字典序比较与字符定位函数、理解"返回值符号表三种结果"的函数设计、熟练运用指针相减与判空——实验 B10 词条比对模块的完整实现。
