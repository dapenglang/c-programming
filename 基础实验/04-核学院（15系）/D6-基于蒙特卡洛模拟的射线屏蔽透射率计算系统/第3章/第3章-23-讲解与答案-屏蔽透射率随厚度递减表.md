## 二、预备知识：为什么"按比例削减"会得到指数

### 1. 问题是怎么来的

上一练习算出"2 cm 铅板透射率 0.21"，但那只是一个点。实际工程需要一整张表：**每增加一点厚度，透射率掉多少？** 手工算 11 个点要按 11 次计算器的 `exp`，又慢又容易错——这正是计算机循环最擅长的活。

### 2. 公式是怎么推出来的

回顾指数衰减律的推导逻辑：设厚度增加一小段 $dx$，透射的强度损失与当前强度成正比，比例系数是 $\mu$：

$$
dI = -\mu I \, dx
$$

把 $I$ 归到一边积分并代入边界条件 $I(0)=I_0$，得到

$$
\frac{I}{I_0} = e^{-\mu x}
$$

关键结论：**透射率是厚度的负指数函数**。它不是直线下降，而是先快后慢——厚度 0 到 0.5 cm 掉得快，4.5 到 5.0 cm 掉得慢。这可以换个角度理解：透射率每经过一个半值层厚度 $x_{1/2}=\ln 2/\mu$ 就减半，所以永远减不到 0，但会越来越接近 0。

### 3. 用本例走一遍

取 $\mu = 0.78$，逐个厚度代入 $T = e^{-0.78x}$：

- $x = 0.5$：$\mu x = 0.39$，$T = e^{-0.39} \approx 0.6769$；
- $x = 1.0$：$\mu x = 0.78$，$T = e^{-0.78} \approx 0.4584$；
- $x = 2.0$：$\mu x = 1.56$，$T = e^{-1.56} \approx 0.2101$（与练习 25 的样例 1 一致）；
- $x = 5.0$：$\mu x = 3.90$，$T = e^{-3.90} \approx 0.0202$。

可以看出相邻两点之间透射率的比值近似恒定（约 0.677）——这正是"每段按固定比例削减"的直接体现。

### 4. 编程时怎么用它

循环三要素：**起点**（$x=0$）、**终点**（$x \le 5$）、**步长**（$x = x + 0.5$）。循环体里就是上一练习那句 `T = exp(-MU * x);` 加上打印。循环变量必须用 `double`，因为厚度是小数——若用 `int`，`x += 0.5` 会永远加 0 造成死循环（整数 0 + 0.5 截断回 0）。

> **这个思想在综合实验中反复出现**：D6 厚度扫描、D7 测线位置扫描、D8 道址扫描，全部是"对一个物理量按固定步长遍历、逐个计算并输出表格"。学会一次，多处可用。

## 三、解题思路

1. **确定数据**：$\mu$ 是材料属性，用 `const double MU = 0.78;`；
2. **确定变量**：循环变量 `x`（double，从 0 到 5，步长 0.5）、透射率 `T`（double）；
3. **确定循环**：`for (x = 0.0; x <= 5.0; x += 0.5)`。担心浮点累加误差漏掉终点，可把条件写成 `x <= 5.0 + 1e-9`，但本题步长 0.5 是二进制可精确表示的数，直接 `<= 5.0` 即可；
4. **循环体**：先 `T = exp(-MU * x);`，再 `printf("x = %.1f, T = %.4f\n", x, T);`；
5. **输出格式**：厚度 `%.1f`（保留 1 位），透射率 `%.4f`（保留 4 位）。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>              /* exp 需要数学库 */

int main(void)
{
    const double MU = 0.78;    /* 铅的线衰减系数，单位 1/cm */
    double x;                  /* 屏蔽厚度，单位 cm */
    double T;                  /* 透射率 I/I0 */

    /* 厚度从 0 扫到 5 cm，步长 0.5 cm */
    for (x = 0.0; x <= 5.0; x += 0.5) {
        T = exp(-MU * x);                       /* 指数衰减律 */
        printf("x = %.1f, T = %.4f\n", x, T);   /* 逐行打印表格 */
    }

    return 0;
}
```

## 五、运行验证

| 循环轮次 | 手算过程 | 程序输出 |
|---|---|---|
| 第 1 行 | x = 0，T = e^0 = 1.0000 | `x = 0.0, T = 1.0000` ✓ |
| 第 2 行 | x = 0.5，μx = 0.39，T = e^(−0.39) = 0.6769 | `x = 0.5, T = 0.6769` ✓ |
| 第 3 行 | x = 1.0，μx = 0.78，T = e^(−0.78) = 0.4584 | `x = 1.0, T = 0.4584` ✓ |
| 第 5 行 | x = 2.0，μx = 1.56，T = e^(−1.56) = 0.2101 | `x = 2.0, T = 0.2101` ✓ |
| 第 11 行 | x = 5.0，μx = 3.90，T = e^(−3.90) = 0.0202 | `x = 5.0, T = 0.0202` ✓ |

共 11 行，透射率从 1.0000 单调递减到 0.0202；相邻两行比值近似 0.677，符合"每段按固定比例削减"的规律。

## 六、常见错误与讲解

**错误 1：循环变量用 int**

```c
int x;
for (x = 0; x <= 5; x += 0.5)   /* 错：x += 0.5 对 int 等于 x += 0，死循环 */
```

`x += 0.5` 会先把 `0.5` 转成整型参与运算，结果是 0，`x` 永远是 0，程序打印无数行不停止。**规则：被遍历的量是小数，循环变量就必须是 `double`。**

**错误 2：步长写成整数乘法（漏掉小数）**

```c
for (x = 0; x <= 5; x = x + 1)   /* 错：步长 1，只得到 6 个点，不是 11 个 */
```

要求每隔 0.5 取一点，写成 `+1` 会让点数、样例都对不上。**照抄题干步长，别凭感觉改。**

**错误 3：循环条件写成 `< 5.0`（丢终点）**

```c
for (x = 0.0; x < 5.0; x += 0.5)   /* 少一行：x = 5.0 被排除 */
```

题干要求"含 5"，用 `<` 会少输出最后一行，得 10 行而样例要求 11 行。

**错误 4：公式里的负号丢失或 `exp` 忘声明**

```c
T = exp(MU * x);                 /* 错：算成 e^(+μx)，透射率随厚度递增，物理荒谬 */
/* 且若漏写 #include <math.h>，exp 会被隐式声明，结果不可靠 */
```

对照检查：透射率必须落在 0～1 之间、随厚度**递减**。若出现大于 1 或递增，就是符号或库头文件的问题。
