# 第 5 章 练习 16　数据行解析与字段提取

**对应章节**：5 批量数据处理方法（5.3 字符数组——二维字符数组、逐字符扫描；3.2 选择结构；3.3 循环结构）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"试验记录行解析与字段提取"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区船舶载荷试验保存下来的数据是一行一行的**记录文本**，每一行由逗号分成若干字段，例如"编号,阻力值,时间"。程序要把这类文本变成可计算的数据，第一步就是**拆行**：把一行字符串按逗号切成一个个字段。这项"逐字符扫描、遇分隔符就断开"的工作，是所有数据文件处理（第 8 章）的公共前置步骤。本练习先在标准输入上练习：读入一行记录，把它拆成若干字段并逐个输出。

## 二、任务要求

编写一个完整程序 `parse_line.c`：

1. 从键盘读入**一行**记录文本（长度不超过 99 个字符），存入字符数组 `char line[100]`；
2. 用**逐字符扫描**的方式，把这行按逗号 `,` 切分成若干字段，每个字段作为一个字符串存入二维字符数组 `char field[8][30]`（**字段数最多 8 个，每个字段长度最多 29**）；
3. 题目保证输入**格式规范**：字段之间用单个逗号分隔，行首、行尾没有多余逗号，也没有空字段；
4. 先输出字段总数，再按顺序逐行输出每个字段的内容。

## 三、输入输出格式

**输入**：一行记录文本（长度 1 ~ 99，含若干逗号，字段之间无空格）。

**输出**：共 $k+1$ 行（$k$ 为字段数）。第 1 行为 `字段数 = k`；随后 $k$ 行，第 $i$ 行为 `字段i = 字段内容`（$i$ 从 1 开始）。

## 四、样例

**样例 1**

输入：
```
S07,13.25,2.5
```
输出：
```
字段数 = 3
字段1 = S07
字段2 = 13.25
字段3 = 2.5
```

**样例 2**

输入：
```
ICE-9,0.8,15.6,ok
```
输出：
```
字段数 = 4
字段1 = ICE-9
字段2 = 0.8
字段3 = 15.6
字段4 = ok
```

## 五、提示

1. 读入含逗号的一整行仍用扫描集：`scanf("%[^\n]", line);`（字符数组不加 `&`）；
2. `char field[8][30]` 是**二维字符数组**，可以理解为"8 个字符串的清单"：`field[0]` 是第 1 个字段（一条字符串），`field[0][0]` 是它里面的第 1 个字符；
3. 用两个游标配合扫描：`k` 记录当前是第几个字段，`c` 记录当前字段已经写了几个字符。遇到普通字符就"抄进当前字段"，遇到逗号就"给当前字段补上 `'\0'`、把 `k` 加 1、把 `c` 归零"，逻辑为

$$
\begin{cases}
\text{line}[i] = \text{','} & \Rightarrow \text{结束当前字段，开始下一个}\\
\text{line}[i] \ne \text{','} & \Rightarrow \text{line}[i] \text{ 写入当前字段}
\end{cases}
$$

4. 扫描到字符串末尾（`line[i] == '\0'`）时，**最后一个字段还没有补 `'\0'`**，循环结束后必须单独补一次，字段总数 = `k + 1`。

**完成本练习后你将具备的能力**：用二维字符数组管理多个字符串、用"逐字符扫描 + 遇分隔符断开"的范式解析文本行、正确维护字段下标与写入位置——这是实验 C7 中"试验记录解析模块"的地基，也是第 8 章文件逐行处理的前置技能。
