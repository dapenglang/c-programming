# 第 6 章 练习 14　二级指针交换字符串

**对应章节**：6 内存数据深度操控方法（6.6 指向指针的指针——用二级指针修改"指针本身"）

**场景来源**：综合实验 B10《基于编辑距离的文本相似度计算系统》（人工智能学院）——本练习是该实验中"待比对文本对调"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本相似度系统在比较两份文本前，常按约定把二者"摆正"：让内容较前的一份排在前面，或者按要求把两个待比对对象对调次序。在 C 语言里，一份文本通常用"字符指针"来代表（指针指向字符串的首字符）。要对调两份文本的顺序，有两种做法：把两个字符串的**内容**整体搬来搬去（费时），或者只把两个**指针**互换（飞快）。换指针意味着要修改调用者手里的指针变量本身，而"要修改指针变量"，就得把指针变量的**地址**传给函数——于是形参成了"指向指针的指针"。本练习实现这个二级指针版的交换函数。

## 二、任务要求

编写一个完整程序 `swap_ptr.c`：

1. 主函数读入两个不含空格的字符串（长度 < 50），分别存入两个字符数组；
2. 定义两个字符指针 `char *s1`、`char *s2`，分别指向这两个字符数组；
3. 编写函数，其原型为 `void swap_str(char **pa, char **pb);`，它**交换两个指针所占保存的地址**（即让 `s1` 指向原来的第二份、`s2` 指向原来的第一份），**不交换字符串内容**；
4. 主函数调用 `swap_str(&s1, &s2)` 后，输出 `s1`、`s2` 各自指向的字符串。

## 三、输入输出格式

**输入**：两行，每行一个不含空格的字符串。

**输出**：两行，格式分别为 `s1 = <s1 指向的字符串>` 与 `s2 = <s2 指向的字符串>`。

## 四、样例

**样例 1**

输入：
```
alpha
beta
```
输出：
```
s1 = beta
s2 = alpha
```

**样例 2**

输入：
```
ICE-01
ICE-02
```
输出：
```
s1 = ICE-02
s2 = ICE-01
```

## 五、提示

- `s1` 是"一级指针"，它里面存着一个地址；`&s1` 就是这个指针变量自己的地址，类型是 `char **`；
- 函数里要交换的是指针变量里的地址，写法为 `char *t = *pa; *pa = *pb; *pb = t;`——**两边都要带一个 `*`**；
- 想验证"只换了指向、没换内容"这一点，可再单独打印两个字符数组：它们的内容顺序仍与输入一致，变的只是 `s1`、`s2` 指向谁。

**完成本练习后你将具备的能力**：理解"指针本身也是变量、也有自己的地址"，掌握二级指针"解引用一次得到一级指针、再解引用一次才得到数据"的两层访问——这是本章 6.6 节的核心。
