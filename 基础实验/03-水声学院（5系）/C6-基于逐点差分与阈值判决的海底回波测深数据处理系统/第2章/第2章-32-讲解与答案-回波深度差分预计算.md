## 二、预备知识：逐点差分的基本原理（零基础阅读）

### 1. 问题是怎么来的

声呐测深时，每发一个 ping 得到一个海底深度。把深度按时间排开，就得到一条"深度—时间"序列。海底平坦处，相邻深度几乎不变；海底出现断层、斜坡处，相邻深度会发生明显变化。

怎么从数值上刻画"变化"？最简单的办法是**一阶差分**——相邻两点的差：

$$\Delta d_i = d_i - d_{i-1}$$

差分把"水平"变成"零"，把"阶跃"变成"大数"，后面的阈值判决模块才能一眼认出跳变。所以差分是 C6 整个系统的"地基工序"。

### 2. 公式推导

本题对**一对**相邻深度做差分。设上一 ping 深度为 $d_1$，当前 ping 深度为 $d_2$：

$$\Delta d = d_2 - d_1$$

- $\Delta d > 0$：海底变深（当前 ping 更深）；
- $\Delta d < 0$：海底变浅；
- $\Delta d = 0$：海底平坦。

再引入一个折算口径：工程上常关心"按固定 ping 间隔折算的变化量"。本题定义为每 100 ping 的变化：

$$\Delta d_{100} = \Delta d \times 100$$

这只是与一个常量相乘，仍属于第 2 章的算术表达式。

### 3. 代入本例数值

样例 1：$d_1 = 149.85$，$d_2 = 152.30$。

$$\Delta d = 152.30 - 149.85 = 2.45\ \text{m}$$

$$\Delta d_{100} = 2.45 \times 100 = 245.0\ \text{m}$$

样例 2：$d_1 = 150.00$，$d_2 = 149.55$。

$$\Delta d = 149.55 - 150.00 = -0.45\ \text{m},\qquad \Delta d_{100} = -45.0\ \text{m}$$

负号说明第二 ping 的深度更小——回波提前了，海底变浅。

### 4. 通过编程翻译

把公式翻成 C 语言，只需要**三个变量、一次减法、一次乘法**：

| 数学 | C 语言 |
|---|---|
| $d_1,\ d_2$（实数） | `double d1, d2;` |
| 读入 | `scanf("%lf %lf", &d1, &d2);` |
| $\Delta d = d_2 - d_1$ | `dd = d2 - d1;` |
| $\Delta d_{100} = \Delta d \times GAIN$ | `dd100 = dd * GAIN;` |
| 输出保留 2 位/1 位小数 | `printf("diff = %.2f m\n", dd);` 等 |

注意：深度是测量值，必须用 `double`；`scanf` 读 `double` 要用 `%lf`，而 `printf` 用 `%f` 系即可。

## 三、解题思路

1. `#define GAIN 100.0` 定义换算常量；
2. 声明 `double d1, d2, dd, dd100;`；
3. `scanf` 读入两个深度；
4. 顺序计算 `dd`、`dd100`；
5. 两次 `printf` 按格式输出。

全程无分支、无循环——一条直线走到底。

## 四、参考代码

```c
#include <stdio.h>

#define GAIN 100.0              /* 折算口径：每 100 ping */

int main(void)
{
    double d1, d2;              /* 上一 ping、当前 ping 的深度 */
    double dd, dd100;           /* 一阶差分、折算变化量 */

    scanf("%lf %lf", &d1, &d2); /* 读入两个深度 */

    dd = d2 - d1;               /* 一阶差分：当前减上一 */
    dd100 = dd * GAIN;          /* 折算成每 100 ping 的变化量 */

    printf("diff = %.2f m\n", dd);
    printf("per 100 pings = %.1f m\n", dd100);
    return 0;
}
```

## 五、运行验证

**样例 1**（输入 `149.85 152.30`）：

```
diff = 2.45 m
per 100 pings = 245.0 m
```

**样例 2**（输入 `150.00 149.55`）：

```
diff = -0.45 m
per 100 pings = -45.0 m
```

| 输入 | $\Delta d$ | $\Delta d_{100}$ | 核对 |
|---|---|---|---|
| 149.85 152.30 | 2.45 | 245.0 | $152.30-149.85=2.45$ ✓ |
| 150.00 149.55 | −0.45 | −45.0 | $149.55-150.00=-0.45$ ✓ |

（以上均按 IEEE-754 double 与 printf 四舍五入规则复核：`2.45`、`-0.45` 经 `%.2f` 输出稳定无歧义。）

**边界验证**：输入 `150.00 150.00`，输出 `diff = 0.00 m` 与 `per 100 pings = 0.0 m`——平坦海底差分为零。

## 六、常见错误与讲解

**错误 1：用 `int` 存深度**

```c
int d1, d2;
scanf("%d %d", &d1, &d2);    /* 错：149.85 会被读成 149，精度全丢 */
```

**错误 2：`scanf` 的 double 用了 `%f`**

```c
scanf("%f %f", &d1, &d2);    /* 错：%f 对应 float*，double 变量得到垃圾值 */
scanf("%lf %lf", &d1, &d2);  /* 对：double 用 %lf */
```

**错误 3：差分方向搞反**

```c
dd = d1 - d2;    /* 错：题目约定"当前减上一"，反了符号全反 */
dd = d2 - d1;    /* 对 */
```

方向错不会报编译错误，但会让后续"正号=变深"的约定失效——这类"符号约定"错误在实际工程中最难排查。

**错误 4：`printf` 中写了多余的取地址或漏写 `\n`**——`printf` 参数不需要 `&`；两行输出各以 `\n` 结尾。

## 七、与综合实验的衔接

- 实验 **C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》**的第 4 模块（一阶差分）对本题做了推广：把本题的"一对深度"放进循环，对整条深度序列 $d_1,\dots,d_N$ 逐对计算 $\Delta d_i$，就得到差分序列；再在第 5 模块做三点滑动平滑、第 6 模块做阈值判决。本题正是这个循环体的"单次展开"；
- 学完第 3 章循环后（练习 38），你就能把本题的两变量减法改写成对整条序列的差分统计——从"算一次"升级为"算一路"。
