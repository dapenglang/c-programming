## 二、预备知识：指针与数组的基本原理（零基础阅读）

### 1. 数组在内存里是"编号连续的一排柜子"

`double a[8]` 申请了 8 个连续的 8 字节空间：

```
下标        0        1        2        3    ...    7
地址   0061FEF0 0061FEF8 0061FF00 0061FF08  ... 0061FF28
值        12.4     15.8     13.2     18.6   ...    17.3
```

关键事实一：**连续**——相邻元素地址恰好相差一个元素的大小（8 字节）。
关键事实二：**数组名 `a` 本身就是首元素的地址**，即 `a` 等价于 `&a[0]`。所以 `double *p = a;` 一句就让 `p` 指向了下标 0 的柜子。

### 2. 指针 + 1 跨过一个元素，而不是一个字节

`p + 1` 不是"地址数值加 1"，而是"**跨过 p 所指类型的一个元素**"。`p` 是 `double *`，一个元素 8 字节，所以：

```
p     = 0061FEF0  （指向 a[0]）
p + 1 = 0061FEF8  （指向 a[1]，数值上加了 8）
p + 2 = 0061FF00  （指向 a[2]，数值上加了 16）
```

这就是 `p++` 的含义：从当前柜子走到下一格。编译器全权负责"走多远"，你只需表达"走一格"。

### 3. `*(p + i)` 与 `a[i]` 是同一件事

`a[i]` 的本质就是"从 `a` 指的地址出发，跨过 $i$ 个元素，取出那里的值"，即 `*(a + i)`。因此下面四种写法**完全等价**：

```c
a[3]        *(a + 3)        p[3]        *(p + 3)    /* 此时 p == a */
```

第 5 章用 `a[i]` 写的每一个循环，都能原样改写成 `*(a + i)` 或"让 `p` 自己走"的形式。扫尾条件也顺理成章：8 个元素的合法地址范围是 `a` 到 `a + 7`，循环写 `p < a + 8`（或 `p <= a + 7`），`p` 到达 `a + 8` 时停止——`a + 8` 这个地址**只用于比较，不用于访问**。

### 4. 为什么实验代码偏爱指针写法

实验 C7 处理的序列动辄几千个采样点，指针遍历让"当前位置"成为一个可以传递、可以比较、可以回退的**地址变量**：找到峰值时记下的就是地址本身（练习 06 直接用它），把区间 `[p1, p2)` 交给函数时传的也是地址。下标写法易读，指针写法通用，两者你都必须熟练。

## 三、解题思路

1. **读入**：用普通下标循环读入 8 个数（读入阶段允许用 `scanf("%lf", &a[i])`，它本质上也是在传地址）；
2. **求和遍历**：`for (p = a; p < a + 8; p++) sum += *p;`；
3. **最值与计数遍历**：可以与求和合并在同一个循环里——先假设 `max = *a`（首元素），之后每走一步比较 `*p > max` 与 `*p > 15.0`；
4. **输出**：均值 `mean = sum / 8`，按 `%.2f` 输出三个量与计数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double a[8];          /* 8 个时刻的冰阻力采样值，kN */
    double *p;            /* 遍历用指针 */
    double sum = 0.0, max;
    int cnt = 0;          /* 超阈值计数 */
    int i;

    for (i = 0; i < 8; i++)
        scanf("%lf", &a[i]);

    max = *a;                       /* 峰值先设为首元素 */
    for (p = a; p < a + 8; p++)     /* p 从首元素走到 a+8 为止 */
    {
        sum += *p;                  /* 按地址取值累加 */
        if (*p > max)
            max = *p;               /* 更新峰值 */
        if (*p > 15.0)
            cnt++;                  /* 超阈值计数 */
    }

    printf("total = %.2f kN mean = %.2f kN\n", sum, sum / 8);
    printf("max = %.2f kN above = %d\n", max, cnt);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：扫尾条件写成 `p <= a + 8`**

```c
for (p = a; p <= a + 8; p++)   /* 错：多走一步，访问了 a[8] */
```

`a + 8` 是"末元素的下一位置"，只许比较不许解引用。`*p` 一旦作用在它上面就是越界访问，可能读到垃圾值甚至崩溃。

**错误 2：混淆"指针加 1"与"地址加 1"**

```c
p = p + 1;   /* 对：跨过一个 double（8 字节） */
p = (double *)((char *)p + 1);   /* 这才是地址数值加 1 字节，几乎从不用 */
```

本题只需记住：**对 `double *` 做 `+1`，移动 8 个字节**；移动多少由编译器按元素大小自动处理。

**错误 3：循环中修改数组名**

```c
a++;   /* 错：数组名是地址常量，不能自增 */
p++;   /* 对：p 是指针变量，可以走动 */
```

这正是要引入指针 `p` 的原因——数组名只能"站着"，让指针替它"走"。

**错误 4：峰值初始化为 0 或某个固定小数**

```c
max = 0.0;    /* 潜伏错误：本题数据全为正侥幸正确，若全为负则错 */
max = *a;     /* 对：用首元素初始化最稳妥 */
```

## 七、与综合实验的衔接

实验 **C7（冰载荷统计与辨识）**的数据处理模块对每个采样序列都要做"求和—均值—峰值—超阈值计数"这套标准统计，其底层就是本练习的指针遍历；系统中"记录峰值发生时刻"的需求，只需在 `*p > max` 时顺带记下当前指针 `p`（或 `p - a` 即下标），这自然过渡到练习 06"返回元素地址"。指针遍历的扫尾范式 `for (p = a; p < a + n; p++)` 会在本章后续每一题中反复出现，务必写熟。
