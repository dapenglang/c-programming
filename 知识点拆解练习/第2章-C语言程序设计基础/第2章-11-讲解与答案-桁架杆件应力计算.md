## 二、预备知识：应力概念与工程单位换算（零基础阅读）

### 1. 问题是怎么来的

一根杆被多大的力"绷"得紧，不能只看力的大小，还要看它有多粗。同样的 100 kN，加在细杆上会绷断，加在粗杆上却轻松承受。衡量这种"单位面积上承受多大的力"的量就叫**应力**：

$$
\sigma = \frac{N}{A}
$$

其中 $N$ 是杆件轴力，$A$ 是横截面积。应力越大越危险。

### 2. 单位是怎么配套的

- 轴力 $N$ 常用千牛（kN），$1\ \mathrm{kN} = 1000\ \mathrm{N}$；
- 截面积 $A$ 常用平方毫米（mm²），$1\ \mathrm{mm^2} = 10^{-6}\ \mathrm{m^2}$；
- 应力基本单位是帕（Pa = N/m²），工程常用兆帕（MPa），$1\ \mathrm{MPa} = 10^6\ \mathrm{Pa}$。

要把应力算成 MPa，先把 $N$ 换成 N、把 $A$ 换成 m²：

$$
\sigma = \frac{N \times 1000}{A \times 10^{-6}}\ \mathrm{Pa}
$$

再把 Pa 换成 MPa（除以 $10^6$）：

$$
\sigma = \frac{N \times 1000}{A \times 10^{-6}} \times 10^{-6} = \frac{N \times 1000}{A}\ \mathrm{MPa}
$$

$10^{-6}$ 与 $10^{6}$ 相抵，得到工程口诀：**轴力用 kN、面积用 mm²，相除就是 MPa**。又因为 $1\ \mathrm{N/mm^2} = 1\ \mathrm{MPa}$，也可理解为"直接把 kN 化成 1000 N 再除以 mm²"。

### 3. 用本例走一遍

轴力 120 kN、面积 2000 mm²：

- 化轴力：$120 \times 1000 = 120000$ N；
- 相除：$\sigma = 120000 / 2000 = 60\ \mathrm{MPa}$。

再看受压杆 -90 kN、1500 mm²：$\sigma = -90000/1500 = -60$ MPa。负号表示受压。

### 4. 编程时怎么用它

两个要点：**其一，科学计数法**。$10^{-6}$ 在 C 里写成 `1.0e-6`（字母 e 表示"乘 10 的几次方"），不能写成 `10^-6`。**其二，除法顺序**。$\dfrac{N \times 1000}{A}$ 里，分子要先乘 1000，否则若 `N` 与 `A` 都是整数，`N / A` 会先做整数除法丢掉小数。写成 `N * KN_TO_N / A` 最稳妥。

## 三、解题思路

1. **备常量**：`const double KN_TO_N = 1000.0`（`MM2_TO_M2 = 1.0e-6` 可用来说明换算，但计算时因相抵可省）；
2. **备变量**：`N`（轴力）、`A`（面积）、`sigma`（应力），全用 `double`；
3. **读入两个数**；
4. **算应力**：`sigma = N * KN_TO_N / A`；
5. **输出**：保留 4 位小数，负号会自动显示。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double KN_TO_N  = 1000.0;   /* 1 kN = 1000 N */
    const double MM2_TO_M2 = 1.0e-6;  /* 1 mm^2 = 1e-6 m^2（此处因量纲相抵可省略） */

    double N;       /* 输入：杆件轴力，kN（拉正压负） */
    double A;       /* 输入：横截面积，mm^2 */
    double sigma;   /* 输出：应力，MPa */

    /* 读入轴力与面积 */
    scanf("%lf %lf", &N, &A);

    /* 应力 = 力(换算为N) / 面积(mm^2)，结果即为 MPa */
    sigma = N * KN_TO_N / A;

    /* 输出，保留 4 位小数 */
    printf("sigma = %.4f MPa\n", sigma);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 120 2000 | $120\times1000/2000 = 120000/2000 = 60$ | `sigma = 60.0000 MPa` ✓ |
| -90 1500 | $-90\times1000/1500 = -90000/1500 = -60$ | `sigma = -60.0000 MPa` ✓ |
| 75 2500 | $75\times1000/2500 = 75000/2500 = 30$ | `sigma = 30.0000 MPa` ✓ |

符号规律正确：轴力为正（拉）应力为正，为负（压）应力为负。

## 六、常见错误与讲解

**错误 1：单位换算漏乘 1000**

```c
sigma = N / A;              /* 错：numerator 没换成 N，结果小了 1000 倍 */
sigma = N * KN_TO_N / A;    /* 对 */
```

**错误 2：用 `10^-6` 表示科学计数法**

```c
const double M = 10^-6;     /* 错：^ 不是乘方，且 10^-6 会被语法误解 */
const double M = 1.0e-6;    /* 对：字母 e 表示 10 的幂 */
```

**错误 3：整数除法**

```c
int N = 120, A = 2000;
sigma = N * 1000 / A;       /* 恰好整除尚可，但 90*1000/1500 也可能因类型不统一而截断 */
double sigma = N * 1000.0 / A;   /* 对：全程浮点 */
```

**错误 4：scanf 漏写 `&` 或格式符不匹配**

```c
scanf("%lf %lf", N, A);     /* 错：两个都漏了 & */
scanf("%lf %lf", &N, &A);   /* 对 */
```

## 七、与综合实验的衔接

- 在实验 **A8（静定桁架内力求解系统）**中，本练习对应"超限杆件筛查"环节：正式程序先用高斯消元解出每根杆的轴力，再逐根算应力、与容许应力比较，输出预警名单——逐根处理需要循环（第 3 章），杆件数据需要数组/结构体（第 5、7 章），比较判断需要选择结构（第 3 章）；
- 本练习还预告了"单位统一"这一工程编程的通用纪律：A8 里轴力来自方程组（kN）、面积来自几何表（mm²），若单位不统一，再好的算法也会算出错误结论。养成"算之前先统一单位"的习惯，是走向综合实验的最后一块基石。
