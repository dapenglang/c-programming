# 第 3 章 练习 25　多点源剂量率累加

**所属综合实验**：D7（D7-基于数值积分的辐射剂量场分布估算系统）

**对应章节**：3 程序控制结构（3.1 顺序结构、3.3 循环结构——for 循环、3.5 关系与逻辑运算、3.6 数值方法初步——叠加求和）

**场景来源**：综合实验 D7《基于数值积分的辐射剂量场分布估算系统》（核学院）——本练习是该实验中"多源叠加贡献"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

实际场合往往不止一个辐射源：核设施里有若干条管道、若干块工件，每个都在往测点方向发射射线。测点处的总剂量率，是**所有源贡献之和**。

每个点源按上一练习的平方反比律贡献 $\dot{D}_j = S_j / d_j^{2}$，若共有 $k$ 个源，则测点总剂量率为：

$$
\dot{D}_{\text{总}} = \sum_{j=1}^{k} \frac{S_j}{d_j^{2}}
$$

综合实验 D7 的剂量场本质就是这样：把一条线状源离散成 $k$ 个点源，再对每个测点累加这 $k$ 份贡献。本题模拟这一"离散—叠加"过程：读入若干点源的强度与到测点的距离，累加出总剂量率。

## 二、任务要求

编写一个完整程序 `multi_dose.c`：

1. 从键盘读入点源个数 `k`（**题目保证 1 ≤ k ≤ 100**）；
2. 用**循环**依次读入每个点源的强度 `S`（μSv·m²/h）和它到测点的距离 `d`（m），**题目保证每个 d > 0**；
3. 对每个源计算其贡献 $\dot{D}_j = S_j / d_j^{2}$，并累加到总和 `Dtotal`；
4. 循环结束后按格式输出总剂量率（保留 4 位小数）。

## 三、输入输出格式

**输入**：第一行一个整数 k；接下来 k 行，每行两个实数，依次为该源强度 S 与距离 d，用空格分隔。

**输出**：一行，按格式 `Dtotal = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2
120 2
60 5
```
输出：
```
Dtotal = 32.4000
```

**样例 2**

输入：
```
3
120 2
60 5
40 10
```
输出：
```
Dtotal = 32.8000
```

## 五、提示

- 累加变量要先**清零**：`double Dtotal = 0.0;`——这是累加类程序的铁律，忘了清零会得到一个莫名其妙的初始值；
- 循环体三件事：读一个源、算一份贡献、累加到总和：
  ```c
  for (i = 0; i < k; i++) {
      scanf("%lf %lf", &S, &d);
      Dtotal += S / (d * d);      /* 分母加括号，与练习 26 一致 */
  }
  ```
- `Dtotal += x` 是 `Dtotal = Dtotal + x` 的简写；
- 想一想：多个源叠加意味着剂量率**单调不减**。若某次输出反而比少一个源时更小，说明累加写错了；
- 物理常识：靠近的强源主导总量（距离进了平方），远处弱源只是"添一点"。

**完成本练习后你将具备的能力**：用 `for` 循环做定次数累加、理解"清零—累加"的固定套路、把多个同类贡献求和成一个总量——这些是实验 D7 中"多源叠加模块"的地基。
