# 第 6 章 练习 21　指针遍历截面表

**所属综合实验**：D3（D3-基于拉格朗日插值的核数据截面查值系统）

**对应章节**：6 指针（6.1 指针变量的定义、6.2 指针与数组的关系、6.3 用指针遍历数组）

**场景来源**：综合实验 D3《基于拉格朗日插值的核数据截面查值系统》（核学院）——本练习是该实验中"用指针高效遍历核数据表"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

截面查值系统（实验 D3）的核数据表可能有几千个数据点。上一章我们用"数组下标 + 循环"遍历表格，`en[i]`、`sig[i]` 是大家熟悉的写法。但 C 语言的底层提供了更直接的遍历方式——**指针**：它直接"指向"数组元素的内存位置，用 `*(p + i)` 或 `*p++` 访问，效率更高，也是阅读专业核数据处理代码（如 CERN ROOT、开源蒙卡程序）的必备能力。

本练习用指针遍历能量-截面表，统计"能量不超过给定值的数据点个数"及其中的最大截面，体会**指针与数组的等价性**。

## 二、任务要求

编写一个完整程序 `ptr_sigma.c`：

1. 程序中用**数组**存放下表 6 组能量-截面数据，并用**指针**（`double *pe`、`double *ps`）指向这两个数组的首元素；
2. 从键盘读入一个能量阈值 `E`（eV，double）；
3. 用**指针遍历**整张表（不得使用 `en[i]` 形式的下标访问，必须用 `*(pe + i)` 或 `*pe++` 等指针写法），统计能量不超过 `E` 的数据点个数 `count`，并求这些点中截面最大值 `sigmax`；
4. 输出 `count`（整数）与 `sigmax`（保留 2 位小数）。

下表为简化的仿真数据（单位：eV、barn）：

| 能量 E（eV） | 截面 σ（barn） |
|---|---|
| 0.025 | 587.0 |
| 1.0 | 250.0 |
| 100.0 | 60.0 |
| 1.0×10⁴ | 20.0 |
| 1.0×10⁵ | 12.0 |
| 1.0×10⁶ | 8.0 |

## 三、输入输出格式

**输入**：一行，一个实数，表示能量阈值 `E`（eV）。

**输出**：两行。
第一行按格式 `count = 结果` 输出数据点个数。
第二行按格式 `sigmax = 结果` 输出这些点中的最大截面，保留 2 位小数。

若没有任何数据点的能量不超过 `E`，则 `count = 0`、`sigmax = 0.00`。

## 五、提示

指针与数组的关系：数组名 `en` 可以看作"指向首元素的指针"，因此

$$
pe = en \quad\Longleftrightarrow\quad pe \text{ 指向 } en[0]
$$

访问第 i 个元素有三种等价写法：`en[i]`、`*(en + i)`、`*(pe + i)`。指针遍历的标准形式：

```c
pe = en; ps = sig;
for (i = 0; i < N; i++) {
    if (*(pe + i) <= E) { ... *(ps + i) ... }
}
```

本题要求用指针写法，因此数组元素必须以 `*(pe + i)` 或 `*pe` 的形式读取。

**完成本练习后你将具备的能力**：定义指针变量、理解"数组名是指向首元素的指针"、用指针访问与遍历数组、在遍历中做判断与统计——这些是实验 D3 中"用指针处理核数据表"的地基。
