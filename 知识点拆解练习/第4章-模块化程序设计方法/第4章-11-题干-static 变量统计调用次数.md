# 第 4 章 练习 11　static 变量统计调用次数

**对应章节**：4 模块化程序设计方法（4.1 函数的声明、调用与参数传递，4.4 变量的存储属性——static 局部变量）

**场景来源**：综合实验 C6《冰区船舶碰撞模拟系统》（水声学院）——本练习是该实验中"碰撞检测函数调用次数统计"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

在冰区航行的仿真中，程序要一遍遍判断"船体与某块浮冰是否相撞"：已知船-冰中心距 $d$ 与两者的等效半径 $r_1$、$r_2$，只要 $d < r_1 + r_2$ 就判定为碰撞。为了评估仿真的工作量与检测频率，工程师希望在每次调用检测函数时自动记下"这是第几次检测"。这个序号不能靠 `main` 里的循环变量——真实系统里检测函数会被许多不同地方调用；最自然的做法，是让检测函数自己用一个 `static` 局部变量把调用次数**记住**。

## 二、任务要求

编写一个完整程序 `collision_count.c`：

1. 编写函数 `int detect(double d, double r1, double r2)`：内部用一个 `static` 局部变量 `cnt` 统计本函数**累计被调用**的次数（从 1 开始计），每被调用一次先把 `cnt` 加一，再按格式输出本次调用序号与判定结果；当 $d < r_1 + r_2$ 时返回 1（判定为碰撞），否则返回 0；
2. `main` 中先读入整数 `n`（检测次数，$0 < n \le 100$），再在循环中读入每组 `d`、`r1`、`r2` 三个实数，逐个调用 `detect`；
3. **接口约定**：`detect` 的三个形参均为 `double`，返回值为 `int`；本题**不允许使用全局变量**，计数必须放在函数内部的 `static` 局部变量里；
4. 输出格式严格按下节要求，每调用一次输出一行。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；接下来 `n` 行，每行三个实数 `d r1 r2`（单位：米），用空格分隔。

**输出**：共 `n` 行，第 $k$ 次调用输出一行，格式为

```
call k: hit = 结果
```

其中 `结果` 为 0 或 1，`k` 为累计调用序号（从 1 开始）。

## 四、样例

**样例 1**

输入：
```
3
5.0 2.0 1.5
3.0 2.0 1.5
8.5 2.0 1.5
```
输出：
```
call 1: hit = 0
call 2: hit = 1
call 3: hit = 0
```

**样例 2**

输入：
```
2
3.0 2.0 2.0
4.5 2.0 2.0
```
输出：
```
call 1: hit = 1
call 2: hit = 0
```

## 五、提示

- `static` 局部变量的关键特性：**只初始化一次，函数返回后它的值仍然保留**。所以 `static int cnt = 0;` 只在第一次调用时执行，之后每次进入函数 `cnt` 都还是上次退出时的值。
- 判断是否碰撞用关系表达式 `d < r1 + r2`；可直接写成 `(d < r1 + r2) ? 1 : 0`。
- 输出序号用 `printf("call %d: hit = %d\n", cnt, hit);`，其中 `hit` 是先算好的 0/1。
- 对比一下：如果把 `cnt` 写成普通的自动变量（`int cnt = 0;`），那么每次进入函数它都会重新变成 0，永远输出 `call 1`——这正是本题要你去体会的差别。

**完成本练习后你将具备的能力**：会用 `static` 局部变量在函数内部保存跨调用状态、理解自动变量与静态变量在生命周期上的区别、能按照约定设计带返回值的函数并用循环驱动它——这是实验 C6 中"碰撞检测与统计模块"的地基。
