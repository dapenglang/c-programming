# 第 6 章 练习 13　函数接收数组指针与长度

**对应章节**：6 内存数据深度操控方法（6.3 指针与数组、6.5 指针与函数——指针形参遍历数组）

**场景来源**：综合实验 C9《基于二维网格统计的冰压力场分析与可视化系统》（水声学院）——本练习是该实验中"测点压力零点修正"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

压力传感器长期服役后会出现零点漂移，同一批测点在正式分析前必须做一次统一修正：给每个读数加上同一个偏置量 $b$。这个修正要对整条序列逐个元素执行，如果每次都把序列在函数内外来回拷贝，既费内存又容易出错。工程师的做法是把数组的首地址和长度交给函数，函数**直接在原数组上**逐个修改——因为函数拿到的是数组的地址，改的就是调用者数组本身。本练习实现这个"指针形参遍历数组并原地修改"的函数。

## 二、任务要求

编写一个完整程序 `offset_array.c`：

1. 主函数读入测点数 `n`（题目保证 $1 \le n \le 50$），读入 `n` 个压力值存入 `double a[50]`，再读入一个实数偏置量 `bias`；
2. 编写函数，其原型为 `void offset_all(double *a, int n, double bias);`，用**指针**遍历数组，对每个元素执行 $a_i \leftarrow a_i + b$，**直接在传入的数组上修改**，不产生新数组；
3. 主函数调用后，按顺序输出修正后的 `n` 个压力值，每个保留 2 位小数、以空格分隔，末尾换行。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数；第三行一个实数（偏置量 `bias`）。

**输出**：一行，`n` 个修正后的压力值，每个保留 2 位小数、用空格分隔。

## 四、样例

**样例 1**

输入：
```
4
100 105 110 115
-2
```
输出：
```
98.00 103.00 108.00 113.00
```

**样例 2**

输入：
```
3
20 40 60
1.5
```
输出：
```
21.50 41.50 61.50
```

## 五、提示

- 形参 `double *a` 与数组名在函数内的用法基本等价：`a[i]` 和 `*(a + i)` 是同一个元素；
- 修改用 `*(a + i) += bias;` 或 `a[i] += bias;`，两行写法结果相同，均直接作用在调用者的数组上；
- 注意：函数里的 `sizeof(a)` 得到的是**指针的大小**（如 8 字节），不是数组总字节数，所以你**必须**另外把长度 `n` 作为参数传进来——这正是本练习接口里带 `int n` 的原因。

**完成本练习后你将具备的能力**：掌握"数组首地址 + 长度"这一 C 语言处理数组的标准接口、理解指针形参能修改调用者数组、记住函数内无法用 `sizeof` 得到数组长度——这是实验 C9 中"数据预处理模块"的地基。
