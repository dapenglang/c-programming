# 第 2 章 练习 21　中子能量对数换算

**所属综合实验**：D2（D2-基于蒙特卡洛随机游走的中子慢化模拟系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——常用数学函数）

**场景来源**：综合实验 D2《基于蒙特卡洛随机游走的中子慢化模拟系统》（核学院）——本练习是该实验中"中子能量输入与单位归一"环节的实现。

**建议用时**：20 分钟

## 一、应用场景

在反应堆物理和中子输运计算中，中子能量是一个核心物理量。它的跨度极大：从快中子的 MeV（10⁶ eV）量级，一直到热中子的 0.025 eV 量级，相差近 8 个数量级。国际上（IAEA、ENDF 核数据库）惯用 **eV** 作为能量的基本单位，而实验测量报告里常写成 **MeV**。

中子慢化模拟（实验 D2）在开始随机游走之前，必须把用户输入的能量**统一到同一种单位**，并且常常需要对能量取对数——因为慢化过程在**对数能量坐标**下近似均匀分布，反应堆物理中把它称为"**对数能量减缩**"（lethargy）。

本练习先完成最小的一步：把以 MeV 给出的中子能量换算成 eV，并计算它的自然对数值，为后续慢化步长计算做准备。

## 二、任务要求

编写一个完整程序 `neutron_energy.c`：

1. 程序中用**常量**存放单位换算关系：\(1\ \text{MeV} = 10^6\ \text{eV}\)（用 `const double` 定义）；
2. 从键盘读入一个中子能量值 `E_MeV`（单位：MeV，double 类型，题目保证 \(0.001 \le E \le 20\)）；
3. 用换算关系计算其对应的 eV 数值 `E_eV`，再用标准库函数计算 `E_eV` 的**自然对数** `lnE`（提示：需要 `#include <math.h>`，链接时用 `-lm`）；
4. 按规定格式输出两个结果，`E_eV` 用科学计数法保留 **4 位小数**，`lnE` 保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示中子能量（单位 MeV）。

**输出**：两行。
第一行按格式 `E_eV = 结果` 输出，科学计数法保留 4 位小数（形如 `1.0000e+06`）。
第二行按格式 `lnE = 结果` 输出，保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
1
```
输出：
```
E_eV = 1.0000e+06
lnE = 13.8155
```

**样例 2**

输入：
```
2
```
输出：
```
E_eV = 2.0000e+06
lnE = 14.5087
```

## 五、提示

单位换算用一次乘法：

$$
E_{\text{eV}} = E_{\text{MeV}} \times 10^{6}
$$

自然对数用数学库函数 `log()`，它的自变量是 eV 数值：

$$
\mathrm{lnE} = \ln\!\left(E_{\text{eV}}\right) = \ln\!\left(E_{\text{MeV}}\right) + \ln\!\left(10^{6}\right)
$$

其中 \(\ln(10^6) = 6\ln 10 \approx 13.815511\)。可以把这两条物理公式逐字翻译成赋值语句。

**完成本练习后你将具备的能力**：定义并使用 `const` 常量、选择 `double` 数据类型、书写含数学函数的算术表达式、调用 `math.h` 中的 `log()`、使用科学计数法输出——这些是实验 D2 中"中子能量初始化模块"的地基。
