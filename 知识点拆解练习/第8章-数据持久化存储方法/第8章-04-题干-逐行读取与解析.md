# 第 8 章 练习 04　逐行读取与解析

**对应章节**：8 数据持久化存储方法（8.4 文件的读写——`fgets` 与 `sscanf`）

**场景来源**：综合实验 C7《冰区船舶载荷辨识与统计系统》（水声学院）——本练习是该实验中"试验记录文件逐行解析"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区船舶载荷试验的原始记录文件里，一行就是一次试验：样本编号、测得的冰阻力、当时航速，三个字段用逗号隔开。要把这些记录交给统计模块，程序得先"一行一行地读、把每行的字段拆出来"。这类文件每行格式相同但内容各异，用 `fgets` 按行读入再 `sscanf` 解析字段，是最直观也最稳的做法。本练习读入 `loads.csv`，逐行解析并输出每条记录，同时累加总阻力。

## 二、任务要求

编写一个完整程序 `parse_lines.c`：

1. 以只读模式打开数据文件 `loads.csv`，并检查是否成功；
2. 用 `fgets` 逐行读取文件，每行是一条记录；再用 `sscanf` 按逗号把字段解析出来：样本编号（字符串）、冰阻力（实数，kN）、航速（实数，m/s）；
3. 对每条记录在屏幕输出一行解析结果，并累加冰阻力；
4. 读完全部行后，输出总行数（记录条数）与总阻力；关闭文件。

**数据文件格式约定**

- 文件名：`loads.csv`（程序运行目录下）
- 文件为纯文本文件，每行一条记录，**行末有换行符**
- 每行三个字段：样本编号（字符串，如 `s01`）、冰阻力（实数）、航速（实数）
- 三个字段之间用**逗号**分隔
- 样例数据行：`s01,12.5,1.2`

## 三、输入输出格式

**输入**：程序不从键盘读数据，输入全部来自文件 `loads.csv`。

**输出**：对每条记录输出一行 `记录 <编号> 阻力 = X kN 航速 = Y m/s`（阻力、航速均保留 2 位小数）；全部读完后输出一行 `共读取 X 行` 和一行 `总阻力 = X kN`（保留 2 位小数）。

## 四、样例

**样例 1**

`loads.csv` 的内容：
```
s01,12.5,1.2
s02,18.3,1.5
s03,9.75,0.9
```
屏幕输出：
```
记录 s01 阻力 = 12.50 kN 航速 = 1.20 m/s
记录 s02 阻力 = 18.30 kN 航速 = 1.50 m/s
记录 s03 阻力 = 9.75 kN 航速 = 0.90 m/s
共读取 3 行
总阻力 = 40.55 kN
```

**样例 2**

`loads.csv` 的内容：
```
s10,20.0,2.0
s11,5.5,0.8
```
屏幕输出：
```
记录 s10 阻力 = 20.00 kN 航速 = 2.00 m/s
记录 s11 阻力 = 5.50 kN 航速 = 0.80 m/s
共读取 2 行
总阻力 = 25.50 kN
```

## 五、提示

- 逐行读用 `while (fgets(line, sizeof(line), fp) != NULL)`：`line` 是字符数组，`sizeof(line)` 是它的容量，读到文件尾时 `fgets` 返回 `NULL`，循环结束；
- `fgets` 会把行末的换行符 `'\n'` 也读进来，一般不用管，因为 `sscanf` 会自动跳过空白；
- 解析用 `sscanf(line, "%15[^,],%lf,%lf", id, &r, &v)`：`%15[^,]` 表示"最多读 15 个非逗号字符"，正好把 `s01` 这类编号取出来；
- `sscanf` 从**字符串**里读，用法和 `scanf` 一样，只是第一个参数变成了字符数组 `line`；
- 判断解析成功用返回值的办法：`sscanf(...) == 3` 表示三个字段都取到了。

**完成本练习后你将具备的能力**：用 `fgets` 按行读取文本、用 `sscanf` 从一行中拆分字段、把"编号 + 数值"混合的记录解析成可以计算的量——这是实验 C7 读取原始试验记录时最常用的一步，也为解析任意格式的文本文件打下基础。
