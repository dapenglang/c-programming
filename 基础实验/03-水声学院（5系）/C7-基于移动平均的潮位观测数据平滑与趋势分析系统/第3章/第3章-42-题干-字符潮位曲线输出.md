# 第 3 章 练习 42　字符潮位曲线输出

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：3 循环结构（3.4 循环嵌套、for 循环、循环控制输出）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"屏幕字符潮位曲线"环节的最小实现。

**建议用时**：35 分钟

## 一、应用场景

潮位站每半小时记录一次潮位（相对基准面的高度，单位 m）。值班员在**没有绘图软件**的终端上，也要一眼看出潮水涨落——办法是用**字符图**：每条观测记录画一行，行内打若干个 `*`，星星的个数与潮位高度成正比。星多表示潮高，星少表示潮低，整屏看起来就是一条"潮位曲线"。

综合实验 C7 的 M10 模块（屏幕字符潮位曲线）就是这样一幅图。本题做它的最小实现：固定比例尺（每 0.2 m 一颗星），读入一串潮位，逐行打印星星。

## 二、任务要求

编写一个完整程序 `tide_curve.c`：

1. 从键盘读入观测条数 `n`（**题目保证 1 ≤ n ≤ 60**）；
2. 循环读入 `n` 个潮位值 `h`（double，m，题目保证 $0 \le h \le 6.0$）；
3. 每读入一个潮位，按比例尺换算星号数：`stars = (int)(h / 0.2 + 0.5);`（即四舍五入，每 0.2 m 一颗星）；
4. 打印一行：先输出潮位值（保留 2 位小数），接着输出竖线 `|`，再**连续输出 `stars` 个星号 `*`**；
5. 全部行打印完毕后，输出比例尺说明一行 `比例尺: 每0.2米一颗星`。

**知识边界提示**：本题只用循环与顺序结构，**不需要函数与数组**——潮位值读完一行打印一行，不需要回头再访问。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 行（或一行空格隔开），每行一个潮位值。

**输出**：共 n+1 行，前 n 行格式为 `h|*****`（h 保留 2 位小数，后跟竖线与若干星号）；最后一行为比例尺说明。

## 四、样例

**样例 1**

输入：
```
6
2.4 3.6 4.8 3.0 1.8 4.2
```
输出：
```
2.40|************
3.60|******************
4.80|************************
3.00|***************
1.80|*********
4.20|*********************
比例尺: 每0.2米一颗星
```

**样例 2**

输入：
```
2
0.11 6.0
```
输出：
```
0.11|*
6.00|******************************
比例尺: 每0.2米一颗星
```

（样例 2 中 0.11 换算为 0.55 颗星，四舍五入得 1 颗；6.0 m 换算为 30 颗星。）

## 五、提示

- 本题的核心是**循环嵌套**：外层循环负责"每条记录一行"，内层循环负责"这一行打 stars 颗星"——

  ```c
  for (i = 0; i < n; i++) {
      scanf("%lf", &h);
      stars = (int)(h / 0.2 + 0.5);       /* 四舍五入换算星数 */
      printf("%.2f|", h);
      for (j = 0; j < stars; j++) {       /* 内层：打星 */
          printf("*");
      }
      printf("\n");                       /* 每行结束必须换行 */
  }
  ```
- **星号换算**：`(int)(x + 0.5)` 是正数四舍五入的经典技巧——先加 0.5 再截断取整。请代入样例 2 的 0.11 自己算一遍：0.11/0.2 = 0.55，加 0.5 得 1.05，取整为 1——体会"加 0.5 再截断"为什么对正数等于四舍五入；
- 内层循环结束时**必须补换行**，否则下一行的潮位数会接在同一行后面；
- 想一想：潮位 0.0 时 stars 为 0，内层循环一次都不执行，这一行只有 `0.00|`——这就是循环次数可能为 0 的正常情况，不需要特判。

**完成本练习后你将具备的能力**：用循环嵌套打印字符图形、用"加 0.5 取整"做四舍五入、控制行内换行——这些是实验 C7 中"屏幕字符潮位曲线"模块的地基。
