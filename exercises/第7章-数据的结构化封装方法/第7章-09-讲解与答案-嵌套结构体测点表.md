## 二、预备知识：嵌套结构体的基本原理（零基础阅读）

### 1. 现实数据本来就是分层的

"板面—测点"是典型的两级数据：板面有编号；板面上的每个测点又有编号和压力。如果强行压平成一个结构体：

```c
struct Flat {                 /* 反例：压平写法 */
    int id;
    int no1;  double p1;      /* 测点 1 */
    int no2;  double p2;      /* 测点 2 */
    ...
};
```

四个测点就要手写八对成员，想扩到 8 个测点、想写循环遍历，都无从下手。分层封装则顺其自然：先定义"测点"这个内层类型，再把"测点数组"当作板面的一个成员——**成员本身又是一个结构体（数组）**，这就是嵌套结构体：

```c
struct Panel {
    int id;
    struct MeasPoint pts[4];   /* 成员是另一个结构体类型的数组 */
};
```

### 2. 内存布局：大箱子里排着小盒子

嵌套结构体的成员仍然**连续存放**，只是"格子里又分小格"：

```
panel（struct Panel，一整块）
+------+---------------------------------------------+
|  id  |                pts[4]（测点数组）             |
| 4字节 |  pts[0]        pts[1]        pts[2]  pts[3] |
|      | +----+------+ +----+------+ +----+---- ...   |
|      | | no | press| | no | press| | no | ...      |
|      | +----+------+ +----+------+ +----+---- ...   |
+------+---------------------------------------------+
```

### 3. 逐层访问：点号连用，从外到内

访问"板面的第 i 个测点的压力"，从最外层往里走，每一层用一层点号，数组层用下标：

```c
panel.id                  /* 板面编号（第一层成员） */
panel.pts[i]              /* 第 i 个测点（一个 struct MeasPoint） */
panel.pts[i].pressure     /* 该测点的压力（第二层成员） */
panel.pts[i].no = i + 1;  /* 该测点的编号 */
```

理解关键：`panel.pts[i]` 整体是一个结构体变量，因此它后面可以继续接点号。点号与下标"从左到右逐层剥开"，与变量定义的嵌套层次一一对应。

### 4. 打擂台要"连人带名"一起记

找压力最大的测点时，光记住压力值还不够——报告要的是"几号测点"。所以擂台上放两个变量：`maxP` 记压力、`maxNo` 记编号，每次换擂主时**两个一起换**。这与练习 03"交换整个结构体"是同一个思想：属性之间的一致性要靠"整体操作"来维护。

## 三、解题思路

1. **先内后外定类型**：先定义 `struct MeasPoint`，再定义 `struct Panel`（内层类型必须先于外层定义，编译器要认识它才能用）；
2. **读入**：板面编号直接进 `panel.id`；循环读 4 个压力，同时自动填 `pts[i].no = i + 1`；
3. **打擂台**：初值取 0 号测点，循环比较 `pts[i].pressure`，更大则同时更新 `maxP` 与 `maxNo`；
4. **输出**：按格式输出板面编号、最大测点编号与压力。

## 四、参考代码

```c
#include <stdio.h>

struct MeasPoint {             /* 内层类型：一个测点 */
    int    no;                 /* 测点编号 1~4 */
    double pressure;           /* 冰压力 MPa */
};

struct Panel {                 /* 外层类型：一块板面 */
    int    id;                 /* 板面编号 */
    struct MeasPoint pts[4];   /* 成员是测点数组：嵌套封装 */
};

int main(void)
{
    struct Panel panel;        /* 一块板面 */
    double maxP;               /* 最大压力擂台 */
    int maxNo;                 /* 最大压力测点的编号 */
    int i;

    scanf("%d", &panel.id);
    for (i = 0; i < 4; i++) {
        panel.pts[i].no = i + 1;              /* 编号自动置 1~4 */
        scanf("%lf", &panel.pts[i].pressure); /* 逐层访问读入 */
    }

    /* 打擂台：初值取 1 号测点，连值带号一起记 */
    maxP  = panel.pts[0].pressure;
    maxNo = panel.pts[0].no;
    for (i = 1; i < 4; i++) {
        if (panel.pts[i].pressure > maxP) {
            maxP  = panel.pts[i].pressure;
            maxNo = panel.pts[i].no;
        }
    }

    printf("板面 %d 压力最大测点：%d 号，压力 %.2f MPa\n",
           panel.id, maxNo, maxP);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `2 1.20 0.85 1.56 1.02` | 四个压力中 1.56 最大，位于 3 号测点 | `板面 2 压力最大测点：3 号，压力 1.56 MPa` ✓ |
| `5 0.90 1.31 1.05 0.77` | 四个压力中 1.31 最大，位于 2 号测点 | `板面 5 压力最大测点：2 号，压力 1.31 MPa` ✓ |
| 并列检查：`8 1.10 1.10 0.50 0.60` | 1 号与 2 号同为 1.10，严格大于比较下先到先得 | `板面 8 压力最大测点：1 号，压力 1.10 MPa` ✓ |

压力值 1~2 MPa 量级与船体冰压力实测范围相符，数据合理。

## 六、常见错误与讲解

**错误 1：内外层类型定义顺序颠倒**

```c
struct Panel {                 /* 错：编译器还不认识 struct MeasPoint */
    int id;
    struct MeasPoint pts[4];
};
struct MeasPoint { int no; double pressure; };
```

必须**先定义内层类型，再定义外层类型**——外层定义里要用到内层类型的名字。

**错误 2：访问路径缺层或跳层**

```c
panel.pressure          /* 错：pressure 在测点里，不在板面里 */
panel.pts.pressure      /* 错：pts 是数组，必须先给下标 */
panel.pts[i].pressure   /* 对：下标 + 点号逐层剥开 */
```

**错误 3：只记最大值、不记编号**

```c
maxP = panel.pts[0].pressure;
for (i = 1; i < 4; i++)
    if (panel.pts[i].pressure > maxP)
        maxP = panel.pts[i].pressure;    /* 错：忘了同步更新 maxNo */
```

输出时编号还停在初值，"值对了号错了"。属性要一起更新——和排序时交换整个结构体同一个道理。

**错误 4：测点编号手忙脚乱地读入**

```c
scanf("%d%lf%lf%lf%lf%lf%lf%lf%lf%lf", ...)   /* 错：编号 1~4 是规律值，不该让用户敲 */
panel.pts[i].no = i + 1;                      /* 对：程序自动生成 */
```

能由规律推出的数据不要读入，这是输入设计的基本素养。

## 七、与综合实验的衔接

实验 C9 的真实测点表是"船体—板面—测点"三级结构，本练习完成了其中两级；把 `struct Panel` 再作为数组元素（`struct Panel panels[8];`），就得到完整的多板面监测网，遍历时点号层数相应加深。嵌套结构体与结构体数组（练习 02）、结构体指针（练习 07）组合起来，几乎能组织工程中的任何层级数据。练习 10 是 7.1~7.3 部分的收官题：在结构体数组上完成一份带最值、均值、计数的**统计报表**，把本章学过的批量数据技法串成一条完整流水线。
