# 第 6 章 练习 07　手写字符串长度统计

**对应章节**：6 内存数据深度操控方法（6.1 地址和指针、6.2 指针变量的定义与使用、6.4 指针与字符串）

**场景来源**：综合实验 B6《英文文本词频统计系统》（人工智能学院）——本练习是该实验中"单词长度测量"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本词频统计系统 B6 处理语料的第一步，是弄清每个单词的基本属性，其中最基础的就是**单词长度**。系统读入一个不含空格的英文单词，需要统计它的字符个数、取首字符做词根聚类、取末字符做词形分析。标准库虽有 `strlen`，但实验要求关键处理逻辑自研以便插桩统计——本练习要求用**字符指针**从字符串第一个字符出发，逐个字符向后走，直到遇上字符串结束符 `'\0'` 为止，全程手写，不用库函数。

## 二、任务要求

编写一个完整程序 `word_len.c`：

1. 定义字符数组 `char w[50]`，用 `scanf("%s", w)` 读入一个不含空格的英文单词；
2. 编写函数 `int my_strlen(char *s)`：用字符指针遍历字符串，统计到 `'\0'` 为止的字符个数并返回，**不得调用** `strlen`；
3. 在主函数中调用 `my_strlen` 输出单词长度；
4. 利用指针输出该单词的首字符与末字符（末字符即"长度减 1 处"的字符）。

## 三、输入输出格式

**输入**：一行，一个不含空格的英文单词（长度不超过 49）。

**输出**：三行。
第 1 行：`length = 字符个数`；
第 2 行：`first = 首字符`；
第 3 行：`last = 末字符`。

## 四、样例

**样例 1**

输入：
```
acoustic
```
输出：
```
length = 8
first = a
last = c
```

**样例 2**

输入：
```
underwater
```
输出：
```
length = 10
first = u
last = r
```

## 五、提示

1. 字符串在内存里是"字符数组 + 结束符"：`"acoustic"` 存为 `a c o u s t i c \0` 共 9 个字节，**最后必有 `'\0'`**（值为 0 的字符）；
2. `my_strlen` 的骨架：让指针 `p = s`，只要 `*p != '\0'` 就计数并 `p++`；或走完后用 `return p - s;` 一步算出长度；
3. `scanf("%s", w)` 中 `w` 前面**不加 `&`**——数组名本身就是地址（6.3 的结论在字符串上的应用）；
4. 末字符的地址是 `s + len - 1`，用 `*(s + len - 1)` 或 `p[-1]`（走完后回退一步）取出均可。

**完成本练习后你将具备的能力**：理解 `'\0'` 终止符在字符串存储中的地位、掌握"指针扫到 `'\0'` 为止"的字符串遍历范式、手写第一个字符串处理函数——实验 B6 全部文本处理函数的起点。
