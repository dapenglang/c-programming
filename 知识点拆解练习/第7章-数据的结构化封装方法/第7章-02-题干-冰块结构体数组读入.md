# 第 7 章 练习 02　冰块结构体数组读入

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.2 结构体数组）

**场景来源**：综合实验 C6《冰区航行冰块碰撞仿真系统》（水声学院）——本练习是该实验中"冰场冰块清单批量建立"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

真实的冰场里不会只有一块冰。仿真程序启动时，要先从观测数据中读入冰场内全部 $n$ 块冰的编号与尺寸，建立一份"冰块清单"，后续的碰撞检测、运动模拟都在这份清单上进行。单个结构体变量只能装一块冰，要装 $n$ 块就需要**结构体数组**——每个数组元素都是一整个 `struct IceBlock`，第 $i$ 块冰的全部信息集中在 `b[i]` 里，配合循环即可批量读入、批量计算、批量输出，这正是实验 C6 建立仿真对象清单的标准做法。

## 二、任务要求

编写一个完整程序 `ice_list.c`：

1. 定义与练习 01 相同的结构体类型 `struct IceBlock`（含 `id、length、width、thickness、mass` 五个成员）；
2. 定义长度为 10 的**结构体数组**存放冰块清单（题目保证 $1 \le n \le 10$）；
3. 先读入冰块数 $n$，再循环读入每块冰的编号与三个尺寸，并计算每块冰的质量（$\rho_{ice} = 917\ \mathrm{kg/m^3}$）；
4. 遍历数组输出全部冰块信息表格，最后一行输出总质量。

## 三、输入输出格式

**输入**：第一行一个整数 $n$（$1 \le n \le 10$）；随后 $n$ 行，每行 4 个数据：编号（整数）、长、宽、厚（实数），以空格分隔。

**输出**：第一行为表头 `编号 长(m) 宽(m) 厚(m) 质量(kg)`；随后 $n$ 行，每行按 `编号 长 宽 厚 质量` 输出，实数保留 **2 位小数**，数据之间以一个空格分隔；最后一行输出 `总质量 = X kg`，保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
3
3 2.0 1.5 0.6
7 1.2 0.8 0.5
5 2.5 2.0 0.4
```
输出：
```
编号 长(m) 宽(m) 厚(m) 质量(kg)
3 2.00 1.50 0.60 1650.60
7 1.20 0.80 0.50 440.16
5 2.50 2.00 0.40 1834.00
总质量 = 3924.76 kg
```

**样例 2**

输入：
```
2
1 3.0 2.0 0.8
4 1.0 1.0 0.4
```
输出：
```
编号 长(m) 宽(m) 厚(m) 质量(kg)
1 3.00 2.00 0.80 4401.60
4 1.00 1.00 0.40 366.80
总质量 = 4768.40 kg
```

## 五、提示

- 结构体数组的定义：`struct IceBlock b[10];`，第 $i$ 块冰的编号是 `b[i].id`；
- 循环变量 `i` 从 0 到 `n-1`，先读入、算质量，再第二次循环输出（两次遍历）；
- 总质量用一个 `double` 变量在输出循环中累加；
- 对结构体数组元素读入时，`&b[i].length` 表示"第 i 个元素中 length 成员的地址"。

**完成本练习后你将具备的能力**：定义结构体数组、用下标加点号访问"第 i 个对象的某个成员"、配合循环批量读入与遍历输出——实验 C6 与 C7 中所有"数据清单"类模块都建立在这个模式上。
