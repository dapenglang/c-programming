# 第 7 章 练习 24　链表管理文本词条

**所属综合实验**：B6（B6-基于词频统计的文本热度分析系统）

**对应章节**：7 构造数据类型（7.5 链表、7.1 结构体类型定义、7.3 成员访问、6 指针、3.3 循环结构）

**场景来源**：综合实验 B6《基于词频统计的文本热度分析系统》（人工智能学院）——本练习是该实验中"词条表组织"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

词频统计系统在读入文本时，事先并不知道会出现多少个不同的词——可能是几十个，也可能是几千个。用固定大小的数组存词条，要么浪费空间，要么不够用。

**链表**正是为解决这种"数量不定"的问题而生的：每读到一个新词就"挂"一个新节点上去，用多少申请多少。节点之间靠指针串起来，像一条可以不断接长的链子。B6 系统的词条表就用链表组织。

## 二、任务要求

编写一个完整程序 `word_list.c`：

1. 定义节点结构体类型
   ```c
   struct Word {
       char        text[16];   /* 词条文本 */
       int         count;      /* 词频 */
       struct Word *next;      /* 指向下一个词条 */
   };
   ```
2. 从键盘读入词条个数 `n`（$1 \le n \le 10$）；
3. 依次读入 $n$ 个词条（每行一个单词和它的词频），用**尾插法**依次挂成链表；
4. 遍历链表，输出每个词条，并统计词频总和；
5. 最后释放所有节点。

## 三、输入输出格式

**输入**：
第一行，一个整数 n；
接下来 n 行，每行一个字符串（单词）和一个整数（词频），空格分隔。

**输出**：
先按链表顺序输出 n 行，每行按格式 `词条: 词频` 输出；
最后输出一行 `total = 词频总和`。

## 四、样例

**样例 1**

输入：
```
3
apple 5
banana 3
cherry 7
```
输出：
```
apple: 5
banana: 3
cherry: 7
total = 15
```

**样例 2**

输入：
```
2
go 8
run 2
```
输出：
```
go: 8
run: 2
total = 10
```

## 五、提示

链表由一串**节点**组成，每个节点包含数据（词条 + 词频）和一个 `next` 指针，指向下一个节点。最后一个节点的 `next` 是空指针 `NULL`，表示"链子到头了"。

**尾插法**要做的事：每次申请一个新节点，把它接到链表的末尾。

- 申请节点：`struct Word *p = malloc(sizeof(struct Word));`
- 填数据：`strcpy(p->text, ...)`、`p->count = ...`；
- 接到末尾：让"尾节点"的 `next` 指向 `p`，再让尾指针移到 `p`；空链表时新节点直接成为头节点。

**遍历**：从 `head` 开始，只要当前节点不是 `NULL` 就处理，然后 `cur = cur->next`。

**释放**：链表节点是用 `malloc` 申请的，程序结束前必须逐个 `free`，否则内存泄漏。释放时先保存下一个节点的地址，再 `free` 当前节点。

**完成本练习后你将具备的能力**：定义含指针成员的结构体、用 malloc 动态申请节点、用尾插法建立链表、遍历链表并在结束时释放内存——这些是实验 B6 中"词条表模块"的地基。
