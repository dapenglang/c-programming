## 二、预备知识：指针的基本原理（零基础阅读）

### 1. 用"内存柜子—柜号纸条"理解指针

把计算机内存想象成一排**带编号的柜子**，每个柜子存一个数，柜子的编号叫**地址**。**普通变量** `double x = 3.0;` 就像"打开某个柜子，往里放 3.0"（柜子里装的是**数据**）；**指针变量** `double *p;` 就像"一张纸条，上面写着某个柜子的编号"（纸条上装的是**地址**）。`&` 是"取柜号"（取地址），`*` 是"按柜号去开柜子取数据"（解引用）：

```c
double x = 3.0;
double *p = &x;      /* p 这张纸条写上 x 的柜号 */
printf("%.1f", *p);  /* 按柜号开柜，取出 3.0 */
```

画成图：

```
   柜子地址      柜子内容          纸条 p
  +---------+   +---------+      +-----------+
  |  1000   |   |   3.0   |      |   1000    |   ← p 存的是地址
  +---------+   +---------+      +-----------+
        ↑                              │
        └──────── *p ────────────────┘
```

### 2. 数组名其实是指针

定义一个数组 `double en[6];`，编译器会**连续分配** 6 个柜子。数组名 `en` 的值，就是第一个柜子的地址——它"天然是指向首元素的指针"。于是：

$$
en \;\Longleftrightarrow\; \&en[0]
$$

数组元素访问的三种等价写法：

| 写法 | 含义 |
|---|---|
| `en[i]` | 下标法：第 i 个元素 |
| `*(en + i)` | 指针法：从首地址往后走 i 个柜子 |
| `*(pe + i)`（`pe = en`） | 同上，用指针变量表达 |

它们的**含义完全等价**——`en[i]` 只是 `*(en + i)` 的语法糖。第 5 章的 `en[i]` 和第 6 章的 `*(pe + i)` 访问的是同一个柜子。

### 3. 指针遍历的写法

**下标偏移法**——指针不动，靠 `+i` 定位：

```c
pe = en;
for (i = 0; i < N; i++)
    if (*(pe + i) <= e) { ... }
```

也可让指针自己往后挪（`for (i = 0; i < N; i++, pe++)` 后用 `*pe`）。注意 `*pe++` 的优先级是 `*(pe++)`，即"先取 `*pe`，再把 `pe` 后移一格"；本题为清晰起见推荐用 `*(pe + i)`。

### 4. 用本例走一遍

表：能量 0.025、1、100、1e4、1e5、1e6，截面 587、250、60、20、12、8。

**样例 1**：\(E = 100\)。用指针从 `pe=en[0]` 起逐个比较：

- `*(pe+0)=0.025 ≤ 100` → count=1，sigmax=587；
- `*(pe+1)=1 ≤ 100` → count=2，sigmax=max(587,250)=587；
- `*(pe+2)=100 ≤ 100` → count=3，sigmax=max(587,60)=587；
- `*(pe+3)=1e4 > 100` → 不计；后面 1e5、1e6 也都不计。

结果 `count=3`、`sigmax=587.00`。

**样例 2**：\(E = 1000\)。与上面相同的三个点满足 ≤ 1000（第四点 1e4 已超），所以仍是 `count=3`、`sigmax=587.00`。

> **这个思想在综合实验中反复出现**：D3 遍历截面表、D4 遍历节点温度数组、D1 遍历核素活度序列。**"指针遍历 + 条件统计"是 C 语言处理大批量核数据的标准写法**，也是读懂专业核计算程序的基本功。

## 三、解题思路

1. **定义数组与指针**：`double en[6]`、`sig[6]` 存表；`double *pe = en, *ps = sig;`；
2. **初始化统计量**：`count = 0; sigmax = 0.0;`；
3. **指针遍历**：`for (i = 0; i < N; i++)`，用 `*(pe + i)` 与 `*(ps + i)` 读取；
4. **判断统计**：若 `*(pe + i) <= E`，则 `count++`，并与 `sigmax` 比较更新；
5. **输出**：`%d` 与 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const int N = 6;

    /* 能量-截面数据表（简化仿真数据，单位：eV、barn） */
    double en[N]  = {0.025, 1.0, 100.0, 1.0e4, 1.0e5, 1.0e6};
    double sig[N] = {587.0, 250.0, 60.0, 20.0, 12.0, 8.0};

    double *pe = en;      /* 指向能量表首元素的指针 */
    double *ps = sig;     /* 指向截面表首元素的指针 */
    double e;             /* 输入能量阈值，eV */
    int    count = 0;     /* 满足条件的数据点个数 */
    double sigmax = 0.0;  /* 满足条件点中的最大截面 */
    int    i;

    scanf("%lf", &e);

    /* 用指针遍历整张表 */
    for (i = 0; i < N; i++) {
        if (*(pe + i) <= e) {           /* 指针法读取能量 */
            count++;
            if (*(ps + i) > sigmax) {   /* 指针法读取截面并更新最大值 */
                sigmax = *(ps + i);
            }
        }
    }

    printf("count = %d\n", count);
    printf("sigmax = %.2f\n", sigmax);

    return 0;
}
```

## 五、运行验证

| 输入（eV） | 手算过程 | 程序输出 |
|---|---|---|
| 100 | 0.025、1、100 三点满足，最大截面 587 | `count = 3` / `sigmax = 587.00` ✓ |
| 1000 | 同上三点满足（1e4 已超），最大截面 587 | `count = 3` / `sigmax = 587.00` ✓ |
| 0.01 | 无点满足（最小能量 0.025 > 0.01） | `count = 0` / `sigmax = 0.00` ✓ |
| 1e6 | 全部 6 点满足，最大截面 587 | `count = 6` / `sigmax = 587.00` ✓ |

指针遍历结果与第 5 章的下标遍历完全一致，说明"数组名即首元素指针"这一等价关系成立。

## 六、常见错误与讲解

**错误 1：指针未初始化就解引用**

```c
double *pe;           /* pe 里是随机地址（野指针） */
printf("%f", *pe);    /* 错：访问非法内存，可能崩溃 */
double *pe = en;      /* 对：指向数组首元素 */
```

指针必须先"指向某个有效柜子"才能打开它。**定义指针后立刻赋初值。**

**错误 2：混淆 `*p++`、`(*p)++`、`*(p++)`**

```c
*pe++;      /* 等价 *(pe++)：先取 *pe，再把 pe 后移一格 */
(*pe)++;    /* 把 pe 指向的那个数加 1，pe 本身不动 */
```

两者的作用对象不同：前者动"指针"，后者动"数据"。若只想读数据不想移动指针，用 `*(pe + i)` 最安全。

**错误 3：把数组名当普通变量赋值**

```c
en = pe;      /* 错：数组名是常量地址，不能被赋值 */
pe = en;      /* 对：让指针指向数组首元素 */
```

数组名不能被修改（它本身不是变量），指针变量才可以。

**错误 4：遍历时指针越界**

```c
for (i = 0; i <= N; i++)            /* 错：i 取到 N，*(pe+N) 越界 */
for (i = 0; i < N; i++)             /* 对 */
```

指针偏移同样遵守"0 ～ N-1"的边界。越界读取会得到垃圾值甚至崩溃。
