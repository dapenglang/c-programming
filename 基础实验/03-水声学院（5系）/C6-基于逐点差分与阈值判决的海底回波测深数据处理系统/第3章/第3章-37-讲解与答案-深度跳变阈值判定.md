## 二、预备知识：阈值判决的基本原理（零基础阅读）

### 1. 问题是怎么来的

测深序列里，海底平坦处的相邻深度差只有零点几米，而海底断层处一下跳几米。想让机器"看懂"这个区别，就要给差分值 $\Delta d$ 分级。分级靠**阈值 $T$**：它是观测员根据海区经验给定的"正常起伏上限"。

但一个问题：深度差有正负——往下跳 $+3.2$ m 是断层，往上跳 $-3.2$ m 也是断层。**判决只关心变化的"幅度"，不关心方向**，所以先取绝对值 $A = |\Delta d|$，把正负问题消掉。

### 2. 公式推导（判决规则的形式化）

给定阈值 $T > 0$，把幅度 $A = |\Delta d|$ 划分为三段：

$$
\begin{cases}
A > 2T & \Rightarrow \text{阶跃跳变（step jump）}\\[2pt]
T < A \le 2T & \Rightarrow \text{斜坡缓变（gentle slope）}\\[2pt]
A \le T & \Rightarrow \text{平稳（steady）}
\end{cases}
$$

三个区间在数轴上首尾相接、互不重叠：

```
 0 ——— T ——— 2T ———→ ∞
 └─steady─┘┘─slope─┘└─step───
```

这正是 C 语言 `if / else if / else` 的天然形状：**自上而下排除，命中即出**。写成"上档严格大于、下档顺延覆盖"的形式后，第二档条件只需写 `A > T`——`A <= 2T` 已由"第一档没中"隐含保证。

**边界归属**：$A = 2T$ 归第二档（判据是严格 $>$）；$A = T$ 归第三档。边界给谁，是工程规则的一部分，必须与样例严格一致。

### 3. 代入本例数值

取 $T = 0.5$（即判决线 $T = 0.5$、$2T = 1.0$）：

- 样例 1：$\Delta d = 153.2 - 150.0 = 3.2$，$A = 3.2$。$3.2 > 1.0$ → **step jump**；
- 样例 2：$\Delta d = 151.0 - 150.0 = 1.0$，$A = 1.0$。$1.0 > 1.0$ 不成立（严格大于），$1.0 > 0.5$ 成立 → **gentle slope**；
- 样例 3：$\Delta d = 150.4 - 150.0 = 0.4$，$A = 0.4$。$0.4 > 0.5$ 不成立 → **steady**。

### 4. 通过编程翻译

| 数学规则 | C 语言 |
|---|---|
| $\Delta d = d_1 - d_0$ | `dd = d1 - d0;` |
| $A = \|\Delta d\|$ | `A = fabs(dd);`（需 `math.h`） |
| $A > 2T$ | `A > 2 * T` |
| 三档互斥顺序判决 | `if ... else if ... else ...` |

若不想用 `fabs`，也可自行翻译绝对值定义：

$$A = \begin{cases} \Delta d, & \Delta d \ge 0 \\ -\Delta d, & \Delta d < 0 \end{cases}
\quad\Longleftrightarrow\quad
\texttt{if (dd >= 0) A = dd; else A = -dd;}$$

两种写法都是第 3 章知识的正当应用。

## 三、解题思路

1. 读入 `T, d0, d1`；
2. 计算 `dd = d1 - d0`、`A = fabs(dd)`；
3. `if (A > 2*T)` → step jump；`else if (A > T)` → gentle slope；`else` → steady；
4. 每个分支只输出一行，三支互斥。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
    double T, d0, d1;           /* 阈值、上一 ping 深度、当前 ping 深度 */
    double dd, A;               /* 差分、差分幅度 */

    scanf("%lf %lf %lf", &T, &d0, &d1);

    dd = d1 - d0;               /* 一阶差分（带方向） */
    A = fabs(dd);               /* 取幅度：判决只看大小 */

    if (A > 2 * T) {                    /* 第一档：A > 2T */
        printf("step jump\n");
    } else if (A > T) {                 /* 第二档：T < A <= 2T（上档已排除） */
        printf("gentle slope\n");
    } else {                            /* 第三档：A <= T */
        printf("steady\n");
    }
    return 0;
}
```

## 五、运行验证

**样例 1**（`0.5 150.0 153.2`）：输出 `step jump`（$3.2 > 1.0$ ✓）

**样例 2**（`0.5 150.0 151.0`）：输出 `gentle slope`（$A=2T$ 不算阶跃 ✓）

**样例 3**（`0.5 150.0 150.4`）：输出 `steady`（$0.4 \le 0.5$ ✓）

| 输入 | $A$ | 与 $2T$、$T$ 比较 | 输出 |
|---|---|---|---|
| 0.5 150.0 153.2 | 3.2 | $>1.0$ | step jump ✓ |
| 0.5 150.0 151.0 | 1.0 | $=2T$，不 $>$ | gentle slope ✓ |
| 0.5 150.0 150.4 | 0.4 | $\le 0.5$ | steady ✓ |

**方向对称性验证**（`0.5 150.0 146.8`）：$\Delta d = -3.2$，$A = 3.2$，输出 `step jump`——变浅的断层同样被识别。

## 六、常见错误与讲解

**错误 1：不取绝对值**

```c
if (dd > 2 * T) printf("step jump\n");   /* 错：dd = -3.2 的断层被漏判为 steady */
```

用负方向样例（`0.5 150.0 146.8`）自测即可暴露。

**错误 2：三个并列 if 造成多判**

```c
if (A > 2 * T)      printf("step jump\n");
if (A > T)          printf("gentle slope\n");   /* 错：A=3.2 时两行都输出 */
else                printf("steady\n");
```

三档区间互斥，必须用 `else if` 串联，保证**至多命中一支**。

**错误 3：边界方向写反**——把第二档写成 `A >= 2 * T`（或第一档写成 `A >= 2*T`）都会把样例 2 的 $A = 2T$ 错判为阶跃。边界给谁必须与规则一致：**上档严格 $>$，边界顺延给下档**。

**错误 4：条件写法冗余且易错**

```c
if (A > 2*T) ... else if (A > T && A <= 2*T) ... else if (A <= T) ...
```

逻辑上没错，但中间条件里 `A <= 2*T` 是多余的，且三段若有一处笔误（如写成 `A < T`）就出现"三档都不命中"的空洞。**自上而下排除法**让每个条件只写半句，天然无缝。
