## 二、预备知识：结构体的基本原理（零基础阅读）

### 1. 问题是怎么来的——为什么要"打包"

一根桁架杆件同时有编号（字符串）、轴力（实数）、面积（实数）三种**不同类型**的数据。如果分开存：

```c
char   no1[8] = "G1";  double N1 = 45.6;  double A1 = 0.0012;
char   no2[8] = "G2";  double N2 = -30.2; double A2 = 0.0009;
...
```

几十根杆件就要写几十组变量，而且"哪个编号配哪个轴力"全靠人工记忆和对应，非常容易错位。就像寄快递时把收件人、地址、电话分别写在三张纸条上，路上很容易弄混。

**结构体的思想**：把这些"属于同一个对象的属性"装进一个大盒子，给盒子起名，盒子里再分成几个格子放各属性。这个盒子就是结构体。上面两行 `no1/N1/A1` 就是"一根杆件"的盒子，`no2/N2/A2` 是"另一根杆件"的盒子，从此不再错位。

### 2. 结构体是"类型"，不是"变量"

这一点是初学者最大的困惑，必须分清两层：

**第一层：定义类型**（画图纸）

```c
typedef struct {
    char   no[8];
    double N;
    double area;
} TrussBar;
```

这段代码**没有创建任何变量**，它只是定义了一种新的数据类型 `TrussBar`，相当于画了一张"杆件盒子的图纸"——规定了这个盒子有 `no`、`N`、`area` 三个格子，各是什么类型。`typedef` 的作用是给这个类型起个简短的别名 `TrussBar`，省得每次写 `struct {...}`。

**第二层：定义变量**（照图纸造盒子）

```c
TrussBar b;                 /* 照图纸造出一个盒子，名字叫 b */
TrussBar b2, b3;            /* 再造两个 */
```

只有这一句才真正在内存里开辟了空间。所以"结构体是类型不是变量"——`TrussBar` 是名词，`b` 才是实实在在的东西。这和 `int`、`double` 完全一致：`double` 是类型，`double x;` 才产生变量。

### 3. 成员用点号访问

盒子里各格子的访问方式是"盒子名 + 点 + 格子名"：

```c
b.N = 45.6;              /* 把 45.6 放进 b 的 N 格 */
printf("%s", b.no);      /* 取出 b 的 no 格 */
```

点号 `.` 叫**成员访问运算符**。初始化时也可以一次性装好：

```c
TrussBar b = {"G1", 45.6, 0.0012};   /* 按定义顺序依次装入三个格子 */
```

### 4. 用本例算一遍应力

轴力 $N = 45.6$ kN，面积 $A = 0.0012$ m²。

先算 $N/A = 45.6/0.0012 = 38000$ kN/m²。因为 $1$ kN/m² $= 1$ kPa $= 10^{-3}$ MPa，所以

$$
\sigma = 38000 \times 10^{-3} = 38.00\ \text{MPa}
$$

这是拉应力（$N>0$），数值与常见钢材、混凝土的容许应力同量级，合理。程序里写成 `sigma = b.N / b.area * 1e-3;`。

## 三、解题思路

1. **定义结构体类型** `TrussBar`（三成员）；
2. **在 main 中定义变量并初始化**；
3. **分别输出**三个成员，点号访问；
4. **计算并输出应力**：`b.N / b.area * 1e-3`。

## 四、参考代码

```c
#include <stdio.h>

/* 定义"桁架杆件"结构体类型（图纸，此时并未分配内存） */
typedef struct {
    char   no[8];      /* 杆件编号，如 "G1" */
    double N;          /* 轴力，kN（拉为正、压为负） */
    double area;       /* 截面面积，m^2 */
} TrussBar;

int main(void)
{
    /* 按图纸造出一个杆件变量并初始化 */
    TrussBar b = {"G1", 45.6, 0.0012};

    double sigma;      /* 应力，MPa */

    /* 用点号访问成员并输出 */
    printf("no=%s\n", b.no);
    printf("N=%.2f\n", b.N);
    printf("area=%.4f\n", b.area);

    /* 应力 sigma = N / A，单位由 kN/m^2 换算为 MPa（乘 1e-3） */
    sigma = b.N / b.area * 1e-3;
    printf("sigma=%.2f\n", sigma);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算/中间过程 | 程序输出 |
|---|---|---|
| 无（数据在程序中） | $N/A = 45.6/0.0012 = 38000\ \text{kN/m}^2$；$\times 10^{-3} = 38.00\ \text{MPa}$ | `no=G1` `N=45.60` `area=0.0012` `sigma=38.00` ✓ |

可再自行改动初始化数据验证：若把轴力改成 `-30.0`、面积 `0.0010`，则 $\sigma = -30/0.001 \times 10^{-3} = -30.00$ MPa（压应力，负号表示受压）。

## 六、常见错误与讲解

**错误 1：把类型定义和变量定义搞混**

```c
TrussBar;                 /* 错：这只是引用了类型，没造出变量 */
TrussBar b;               /* 对：造出变量 b */
```

结构体类型是图纸，必须照图纸"造"变量才能用。

**错误 2：定义类型时忘记分号**

```c
typedef struct {
    char no[8];
    double N;
} TrussBar          /* 错：漏了结尾的分号，后续全部报错 */
```

`}` 后面必须有分号，这是结构体定义最经典的坑。

**错误 3：成员访问写成数组下标**

```c
b[0]          /* 错：结构体不是数组，不能用下标 */
b.no          /* 对：点号访问成员 */
```

结构体用点号，数组才用下标。

**错误 4：字符数组成员不能用 `=` 整体赋值**

```c
TrussBar b;
b.no = "G1";              /* 错：数组名不可赋值 */
b.N = 45.6; b.area = 1;   /* 对：数值成员可直接赋值 */
```

若不在初始化列表里赋初值，字符串成员要用 `strcpy(b.no, "G1")`（第 6 章字符串知识）。
