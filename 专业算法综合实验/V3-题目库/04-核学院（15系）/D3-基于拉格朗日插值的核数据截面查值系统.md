# 题目 D3：基于拉格朗日插值的核数据截面查值系统

**适用学院**：核学院（15 系）　**组容量**：本题目最多 2 组选择

## 一、系统/算法说明

本系统是一套命令行核数据截面查值工具。核数据中最重要的一类数据是"截面"——它描述中子和原子核发生反应的概率大小，单位是靶恩（barn）。真实的截面数据以"能量—截面"离散数据点的形式给出，工程计算中经常需要查询不在数据点上的任意能量对应的截面值。本系统读入若干核素的能量—截面数据表，用拉格朗日插值算法计算任意给定能量处的截面，支持多核素数据切换、生成等间隔能量截面表、按能量分群求平均截面，并把数据点与插值曲线以字符画方式显示、把查询结果写成报表。

截面数据是反应堆中子学计算的第一手输入。如果没有可靠的截面查值与插值，就无法计算反应率、无法求解中子输运方程、无法评估反应堆的临界安全——反应堆的功率分布、燃耗计算、屏蔽设计全部建立在截面数据之上。更直接地说，"某个能量下这个核素的截面是多少"这个看似简单的问题，是反应堆物理计算中调用频率最高、最基础的一步。插值方法选择不当（如跨越大共振峰使用高阶插值）会带来显著误差，因此如何用离散数据点尽可能准确、稳定地估计中间值，是核数据应用的核心技能之一。

本系统支撑的关键场景包括：① 反应堆中子学计算中的截面查询与处理；② 屏蔽计算中材料宏观截面的能量分群平均；③ 中子注量率谱加权下的反应率计算；④ 核数据评价与检验的辅助工具；⑤ 探测器响应计算的输入数据准备。系统把国际评价核数据库（如 ENDF、IAEA 数据库）中数据点的使用方式，简化为可编程的文本表与插值函数，让学生无需下载大数据文件即可体验核数据处理的完整流程。本题目与核工程与核技术专业"核数据应用与反应堆计算基础"方向直接对应。

## 二、题目任务与专业关联

本题目要求学生实现一个完整的核数据截面查值系统：从文本文件读入某核素的能量—截面数据表，做排序与合法性校验，实现 n 点拉格朗日插值函数，提供任意能量的交互查询，管理多核素数据集并支持切换，生成等间隔能量下的截面表，按能量分群计算平均截面，最后绘制数据点与插值曲线的字符画并输出查值报表。

专业关联上，本题目还原了核数据处理中最基础的"查表 + 插值"环节。学生在实现中掌握数组、函数、结构体、文件读写与排序查找，并理解拉格朗日插值的原理与局限（如数据点选择、共振峰附近的插值误差），全程不涉及任何机器学习理论。

## 三、数据来源与格式

- **数据文件格式**：每个核素一个文本文件，首行为标题说明（含核素名与反应道），其后每行一个数据点，字段以空格分隔。字段依次为：能量 E（单位：电子伏特 eV，正实数）、截面 σ（单位：靶恩 barn，正实数）。文件 `xs_U235.txt`、`xs_Pu239.txt` 等采用同一格式。

```
# nuclide=U-235  reaction=total  energy_eV  xs_barn
1.0000e-03   3.950e+01
1.0000e-01   2.680e+01
1.0000e+00   1.520e+01
1.0000e+01   9.400e+00
1.0000e+02   7.100e+00
1.0000e+03   6.050e+00
1.0000e+04   5.900e+00
1.0000e+05   5.880e+00
1.0000e+06   5.870e+00
```

```
# nuclide_list       file_name
U-235                xs_U235.txt
Pu-239               xs_Pu239.txt
Fe-56                xs_Fe56.txt
H-1                  xs_H1.txt
```

- **仿真数据生成规则**：
  - 核素名：元素符号加质量数，如 `U-235`、`Fe-56`，长度 ≤ 15。
  - 反应道：字符串，取 `total`、`capture`、`fission`、`scatter` 之一。
  - 能量 E：单位 eV，取值范围 1.0e-3～2.0e7，按对数均匀分布生成（`lgE` 均匀），每条数据表 20～60 个点，保证覆盖热区（～0.025 eV）、共振区与快区。
  - 截面 σ：单位 barn，取值范围 1.0e-2～1.0e4。基础曲线随能量缓慢下降，并在共振能量处叠加 1～3 个共振峰（峰高为基础值的 5～50 倍），模拟真实截面形状。生成时保证 σ > 0。
  - **异常值注入方式**：由教师提供的生成程序注入三类错误。其一，能量非正或重复（如两行同为 `1.0000e+03`），需在校验中剔除重复点；其二，截面为 0 或负数（如 `-2.0`），需剔除；其三，能量序列未按从小到大排列（乱序），需在排序模块中重排；另可注入非数字串（如 `ND`）考察读入容错。

- **真实数据集（如有）**：真实截面数据来自评价核数据库，如 IAEA/NDS 的 ENDF 格式库（https://www-nds.iaea.org/）、美国 BNL 的国家核数据中心（https://www.nndc.bnl.gov/）以及 NEA 的 JANIS 检索平台（https://www.oecd-nea.org/janis/）。数据点对应 ENDF 文件中的 `MF=3`（截面随能量变化）记录，字段含义为"能量（eV）—截面（barn）"。学生**无需下载**真实数据文件，课程提供与之同构的简化仿真数据表。

## 四、数据结构设计

```c
/* ===== 常量定义 ===== */
#define MAX_POINTS   80        /* 单条数据表最大点数 */
#define MAX_NUCLIDE  10        /* 最多核素个数 */
#define MAX_NAME_LEN 16        /* 核素名长度 */
#define MAX_REACT    12        /* 反应道名长度 */

/* ===== 单个数据点 ===== */
struct XsPoint {
    double energy;             /* 能量 E，单位 eV，> 0 */
    double sigma;              /* 截面 σ，单位 barn，> 0 */
};

/* ===== 一条核数据的完整数据集 ===== */
struct XsTable {
    char   nuclide[MAX_NAME_LEN];   /* 核素名，如 "U-235" */
    char   reaction[MAX_REACT];     /* 反应道，如 "total" */
    struct XsPoint pt[MAX_POINTS];  /* 数据点数组，按能量升序 */
    int    n;                       /* 有效点数 */
    int    valid;                   /* 数据集有效标志 */
};

/* ===== 分群平均结果 ===== */
struct GroupAvg {
    double eLow;                /* 分群下边界，eV */
    double eHigh;               /* 分群上边界，eV */
    double sigmaAvg;            /* 该群平均截面，barn */
    int    nPoint;              /* 落在该群内的数据点数 */
};

/* ===== 全局数据区 ===== */
struct XsTable  g_table[MAX_NUCLIDE];   /* 多核素数据集 */
char            g_fileList[MAX_NUCLIDE][32]; /* 数据集文件名列表 */
int             g_tableCount;           /* 已载入数据集个数 */
int             g_current;              /* 当前工作数据集下标 */
struct GroupAvg g_group[32];            /* 分群平均结果数组 */
int             g_groupCount;           /* 分群个数 */
double          g_uniformE[64];         /* 等间隔能量采样点，eV */
double          g_uniformS[64];         /* 对应的插值截面值，barn */
int             g_uniformCount;         /* 等间隔表点数 */

/* ===== 处理日志 ===== */
struct LogItem { char op[24]; char detail[72]; };
struct LogItem g_log[128];
int            g_logCount;
```

辅助说明：数据点用结构体数组存储（课程 7.2），排序采用冒泡或选择排序（课程 5.5），插值用函数实现（课程 4.2）。能量跨度跨越多个数量级，插值时可用能量的对数值参与插值或直接插值，两种做法都要在报告中讨论其差别；本系统默认直接在 E–σ 坐标上插值，超纲的对数插值作为选做。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（3 个模块）

**M1 能量-截面数据文件读入模块**（源文件 `XsIO.c`）

- 功能简介：打开某核素的数据文件，跳过首行标题，用循环 + `fscanf` 读入能量与截面两个字段填充 `XsPoint` 数组；对字段数量不足或转换失败的行给出提示并跳过，记录实际读入点数。
- 输入：数据文件路径（如 `xs_U235.txt`）。
- 输出：`g_table[g_current]` 数据点数组与点数；返回成功/失败标志。

**M2 数据排序与校验模块**（源文件 `XsCheck.c`）

- 功能简介：对数据点按能量升序排序（冒泡/选择排序）；剔除能量重复（相邻点能量差小于 1e-9 认为是重复）、能量非正、截面非正的异常点；生成"原始点数—剔除点数—有效点数"校验报告与异常清单。
- 输入：`g_table[g_current]`。
- 输出：排序并清洗后的数据集；屏幕校验报告。

**M5 多核素数据管理模块**（源文件 `XsTable.c`）

- 功能简介：读入核素列表文件（核素名与文件名对照表），逐个调用 M1/M2 载入多个核素的数据集存于 `g_table[]`；提供"列出全部已载入数据集""按编号切换当前数据集"功能，并显示当前数据集摘要（核素名、反应道、点数、能量范围）。
- 输入：核素列表文件路径（默认 `nuclide_list.txt`）。
- 输出：`g_table[]` 与 `g_tableCount`、`g_current`；屏幕数据集列表。

### 第二部分：算法实现（4 个模块）

**M3 拉格朗日插值函数模块**（源文件 `Lagrange.c`）

- 功能简介：实现 n 点拉格朗日插值函数 `double lagrange(int idx, double x)`：在指定数据集上选取全部数据点（或距 x 最近的 m 个点），按 L_i(x) = ∏(x−x_j)/(x_i−x_j) 计算基函数并加权求和；处理 x 恰为数据点、m 过小等边界情况。
- 输入：数据集下标、目标能量 x（eV）、可选邻近点个数 m。
- 输出：返回插值截面值（barn）；屏幕可选打印所用数据点与基函数值。

**M4 任意能量截面交互查询模块**（源文件 `Query.c`）

- 功能简介：循环读入用户输入的能量值（eV），对当前数据集调用 M3 求截面并打印结果；同时给出"该能量落在哪两个相邻数据点之间""若用线性插值结果是多少"作对照，便于学生比较两种方法。
- 输入：用户输入的能量序列。
- 输出：屏幕查询结果表（能量—拉格朗日插值—线性插值—所用点数）。

**M6 等间隔截面表生成模块**（源文件 `Uniform.c`）

- 功能简介：在当前数据集的能量范围内，按用户给定的点数等间距（或按对数等间距）生成采样能量，逐点调用 M3 求插值截面，填入 `g_uniformE[]`/`g_uniformS[]`；生成结果供曲线与报表模块使用。
- 输入：采样点数、间距类型（线性/对数）。
- 输出：`g_uniformE[]`、`g_uniformS[]`、`g_uniformCount`；屏幕前若干行预览。

**M7 平均截面简化计算模块**（源文件 `GroupAvg.c`）

- 功能简介：把能量范围划分成用户指定的若干群，对每群内相邻数据点按能量宽度做加权平均（梯形法思想，课程 3.5），得到群平均截面 `σ_avg`，填入 `g_group[]`；输出各群的能量范围与平均截面。
- 输入：分群个数（如 8 群）、当前数据集。
- 输出：`g_group[]`、`g_groupCount`；屏幕分群平均截面表。

### 第三部分：数据输出（3 个模块）

**M8 数据点与插值曲线字符画模块**（源文件 `XsPlot.c`）

- 功能简介：把原始数据点（用 `*`）与 M6 生成的插值曲线（用 `.`）绘制在同一张字符图上，横轴为能量（对数刻度），纵轴为截面；当某位置两者重合时显示 `*`，便于观察插值曲线是否穿过数据点。
- 输入：当前数据集、`g_uniformE[]`/`g_uniformS[]`。
- 输出：屏幕字符曲线图。

**M9 查值报表输出模块**（源文件 `XsReport.c`）

- 功能简介：把当前数据集的原始数据点、等间隔插值表、分群平均截面表写出到 `xs_report_<核素名>.txt`，把分群结果单独写出到 `xs_group.csv`，并记录本次操作日志。
- 输入：`g_table[]`、`g_uniformE[]`/`g_uniformS[]`、`g_group[]`。
- 输出：`xs_report_U235.txt`、`xs_group.csv`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `Stu_main.c`）

- 功能简介：文本主菜单（载入核素列表 / 切换数据集 / 查看摘要 / 插值查询 / 生成等间隔表 / 分群平均 / 绘制曲线 / 输出报表 / 退出），用 `do-while + switch` 调度 M1～M9；状态标记约束"必须先载入并校验数据集才能查询"。
- 输入：用户菜单选项。
- 输出：调度各模块；维护日志表。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → `switch` 分发各模块。状态约束：M3～M9 运行前必须先执行 M5 成功载入至少一个数据集；M3/M4/M6/M7 只作用于 `g_current` 指向的当前数据集，切换数据集后需重新生成等间隔表。

**数据流**：

```
xs_U235.txt ─┐
xs_Pu239.txt ─┼─► M1 读入 ─► M2 排序校验 ─► 清洗后数据集
xs_Fe56.txt  ─┘                                    │
nuclide_list.txt ─► M5 多核素管理 ─► g_table[] / g_current
                                                   │
        ┌──────────────────────────┬───────────────┼────────────────┐
        ▼                          ▼               ▼                ▼
  M3 拉格朗日插值 ◄────── M4 交互查询    M6 等间隔表生成    M7 分群平均截面
        │                          │               │                │
        └──────────────────────────┴───────┬───────┴────────────────┘
                                           ▼
                                   M8 数据点+曲线字符画
                                           │
                                           ▼
                                   M9 查值报表输出
```

所有模块通过全局数据集数组、当前数据集下标与插值函数交换数据；插值函数（M3）是全系统的公共内核，其他模块只能调用，不得各自另写插值代码。

## 十、选做扩展

1. **插值方法对比**：对同一数据集分别用拉格朗日插值、线性插值与（超纲可选的）对数能量插值计算同一批查询点，输出"能量—三种方法结果—两两差值"对照表，讨论共振峰附近误差最大的原因。
2. **邻近点个数实验**：把拉格朗日插值所用邻近点数 m 取 2/4/6/8，对同一组查询点比较结果，观察"跨共振峰选点"导致的振荡，理解高阶插值的局限。
3. **多核素对比曲线**：把 U-235、Pu-239、Fe-56 的插值曲线用不同字符（`*`、`+`、`o`）画在同一张字符图上，直观比较不同核素截面随能量的变化趋势。
