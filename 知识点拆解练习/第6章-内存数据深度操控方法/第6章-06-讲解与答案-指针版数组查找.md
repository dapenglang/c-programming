本题第一次让**函数的返回值是一个地址**，是从"用指针"迈向"造指针工具"的转折点。

## 二、预备知识：返回地址与空指针的基本原理（零基础阅读）

### 1. 函数可以返回"柜号"

函数的返回值是一个表达式：可以返回数值（`return sum;`），当然也可以返回**地址**（`return p;`）。返回类型相应写成 `double *`：

```c
double *find(double *a, int n, double key);
/*    ↑ 返回的不是 double 数，而是"存放 double 的柜子的编号" */
```

为什么返回地址比返回"第几个"更有用？因为**地址自带读写能力**：主函数拿到地址后，`*pos` 可以读，`*pos = fix` 可以写，甚至还能把 `pos` 继续传给别的函数。返回下标则只能"知道在哪"，不能"直接操作"。实验 C6 的修正模块选的正是地址方案。

### 2. `NULL`：一张"没写柜号"的纸条

查找可能失败。失败时返回什么呢？绝不能返回一个随意的地址——主函数一旦对它解引用就是灾难。C 语言约定了一个特殊常量 `NULL`（空指针）：它**保证不指向任何有效数据**。习惯上：

```c
return NULL;              /* 函数内：查找失败 */
pos = find(m, 6, key);
if (pos != NULL)          /* 主函数：先判空，再解引用 */
    *pos = fix;
```

"**先判空，后解引用**"是使用返回指针函数的铁律，实验代码中的每一处都应如此。

### 3. 指针相减：同一条街上的门牌差

同一数组内的两个指针可以相减：`pos - m` 的结果**不是字节数，而是两者之间的元素个数**。若 `pos` 指向下标 1，则 `pos - m` 就是 1——这恰好把"地址"翻译回了"下标"，方便打印人看得懂的序号。注意：只有指向**同一数组**（更准确地说是同一连续区域）的指针相减才有意义，两个毫不相干的地址相减是非法行为。指针相加没有对应的合法运算（`pos + m` 无意义），这一点与算术直觉不同，需要专门记住。

### 4. 顺序查找的指针化

第 5 章的顺序查找是"逐个比下标"；指针版只是换了访问方式：让 `p` 从 `a` 走到 `a + n`，一旦 `*p == key` 立即 `return p;`——提前返回，后面的元素不必再看。循环自然走完仍未命中，就返回 `NULL`。**"找到即返回，走完给 NULL"** 是一切查找函数的通用骨架。

## 三、解题思路

1. **函数设计**：签名 `double *find(double *a, int n, double key)`；局部指针 `p` 从 `a` 走到 `a + n`，命中即 `return p`；
2. **失败出口**：循环后统一 `return NULL;`；
3. **主函数判空分支**：非 `NULL` 时输出下标（`pos - m`）、执行 `*pos = fix;`、遍历输出数组；`NULL` 时输出 `NOT FOUND`；
4. **输出细节**：质量保留 2 位小数、空格分隔；下标用 `(long)(pos - m)` 配 `%ld`，或赋给 `int` 变量后用 `%d`。

## 四、参考代码

```c
#include <stdio.h>

double *find(double *a, int n, double key);   /* 返回元素地址 */

int main(void)
{
    double m[6];        /* 6 块冰的质量记录，kg */
    double key, fix;    /* 待查原质量、修正值 */
    double *pos;        /* 接收查找结果地址 */
    int i;

    for (i = 0; i < 6; i++)
        scanf("%lf", &m[i]);
    scanf("%lf %lf", &key, &fix);

    pos = find(m, 6, key);

    if (pos != NULL)                     /* 铁律：先判空 */
    {
        printf("found at index %d\n", (int)(pos - m));  /* 指针相减得下标 */
        *pos = fix;                      /* 通过返回的地址就地修正 */
        for (i = 0; i < 6; i++)
            printf("%.2f ", m[i]);
        printf("\n");
    }
    else
        printf("NOT FOUND\n");

    return 0;
}

double *find(double *a, int n, double key)
{
    double *p;

    for (p = a; p < a + n; p++)
        if (*p == key)      /* 命中：立即返回当前地址 */
            return p;

    return NULL;            /* 走完全表仍未命中 */
}
```

## 五、运行验证

样例 1（质量 `105.0 88.5 120.3 76.8 95.4 110.2`，`key=88.5, fix=92.0`）：

- 88.5 位于下标 1，输出 `found at index 1`（`pos - m = 1`）✓；
- `*pos = 92.0` 后数组变为 `105.00 92.00 120.30 76.80 95.40 110.20` ✓，其余元素原样保留。

样例 2（`key=60.0`）：60.0 不在表中，`find` 返回 `NULL`，输出 `NOT FOUND`，数组未被改动 ✓。

## 六、常见错误与讲解

**错误 1：不判空直接解引用**

```c
pos = find(m, 6, key);
*pos = fix;              /* 错：find 可能返回 NULL，此处崩溃 */
if (pos != NULL) *pos = fix;   /* 对：先判空 */
```

对 `NULL` 解引用是 C 程序最经典的崩溃原因，实验判卷时此错误一票否决。

**错误 2：返回局部变量的地址**

```c
double *bad(void)
{
    double t = key;
    return &t;           /* 错：t 是局部变量，函数返回后其内存即失效 */
}
```

本题返回的是**主函数数组**中元素的地址，数组在主函数里活得好好的，所以安全。返回"函数自己局部变量"的地址则是悬空指针——两者的区别务必分清。

**错误 3：把指针相减的结果想当然**

```c
printf("%d\n", pos - m);        /* 对但建议强转：结果是字节差/8 之后的元素个数 */
printf("%d\n", (int)(pos - m)); /* 稳妥写法 */
```

误以为 `pos - m` 是字节数（如 8）的人，会在下标输出上翻车；同数组内相减结果自动除以元素大小。

**错误 4：找到后继续扫描**

```c
for (p = a; p < a + n; p++)
    if (*p == key)
        result = p;      /* 不够好：找到后仍扫完全表 */
        return p;        /* 更好：命中即返回，效率高且逻辑清晰 */
```

顺序查找命中即止；若业务确需"所有匹配项"，那是另一个函数（返回多个结果属于练习 12 的主题）。
