# 第 7 章 练习 23　桁架节点平衡结构体求解

**所属综合实验**：A8（A8-基于高斯消元的静定桁架内力求解系统）

**对应章节**：7 数据的结构化封装方法（7.4 结构体数组、7.5 结构体数组作函数参数、7.6 结构体与数组综合应用——高斯消元）

**场景来源**：综合实验 A8《基于高斯消元的静定桁架内力求解系统》（航建学院）——本练习是该实验中"节点平衡方程组求解"环节的实现。

**建议用时**：25～30 分钟

## 一、应用场景

静定桁架的杆件轴力，由**节点平衡条件**决定：取某个节点为研究对象，作用在该节点上的所有力（各相连杆件的轴力在坐标轴上的投影）必须平衡，即水平方向与竖直方向的合力都为零。若把每根杆件的轴力作为未知量，每个节点就给出一个线性方程，全部方程联立成一个线性方程组。

A8 系统用**高斯消元法**解这个方程组得到各杆轴力。本练习简化为一个 **2 杆 2 未知量**的小型桁架节点：两根斜杆汇交于一点。用结构体数组存放杆件信息，再用高斯消元求两杆轴力。

**力学方程**（对节点列平衡）：设两根杆的轴力分别为 $N_1$、$N_2$，它们与水平方向的夹角分别为 $\theta_1 = 60^\circ$、$\theta_2 = 30^\circ$，节点受竖直向下的荷载 $P = 10$ kN。平衡方程为

$$
\begin{cases}
N_1\cos\theta_1 + N_2\cos\theta_2 = 0 \\
N_1\sin\theta_1 + N_2\sin\theta_2 = P
\end{cases}
$$

## 二、任务要求

编写一个完整程序 `truss_node.c`：

1. 定义结构体类型 `Bar`，成员为 `name`（杆件名，字符数组）和 `N`（轴力 kN，double）；
2. 在 `main` 中定义 2×2 系数矩阵 `a` 和一个 **`Bar` 结构体数组 `bar[2]`**；
3. 读入 $P$ 与两个角度 $\theta_1$、$\theta_2$（度数），把 $\cos$、$\sin$ 填入系数矩阵（用 `cos`/`sin`，角度需转弧度）；
4. 定义函数 `void gauss(double a[][3], int n, double x[])` 求解 $n$ 元线性方程组（采用**列主元 + 回代**的简化高斯消元），把解写回 `x`；
5. 把解得的两杆轴力存入结构体数组 `bar` 并输出，轴力保留 **3 位小数**。

## 三、输入输出格式

**输入**：三个实数：荷载 P（kN）、角度 θ1（度）、角度 θ2（度）。

**输出**：两行，`杆名 N=轴力kN`，顺序为 `bar1`、`bar2`。

## 四、样例

**样例 1**

输入：
```
10.0 60.0 30.0
```
输出：
```
bar1 N=17.321
bar2 N=-10.000
```

**样例 2**

输入：
```
20.0 60.0 45.0
```
输出：
```
bar1 N=54.641
bar2 N=-38.637
```

## 五、提示

**把角度转弧度**：C 的 `sin`/`cos` 接受弧度。$\text{rad} = \theta \times \pi / 180$，$\pi$ 取 `3.141592653589793`。

**增广矩阵**：把 2×2 系数矩阵与常数项拼成 2×3 的增广矩阵 `a[2][3]`，高斯消元直接在上面做。

**高斯消元（列主元 + 回代）要点**：

1. **选主元**：在第 $k$ 列从第 $k$ 行往下找绝对值最大的行，与第 $k$ 行交换（避免除以很小的数）；
2. **消元**：用第 $k$ 行把下面各行的第 $k$ 列消成 0；
3. **回代**：从最后一行往上依次求出 $x_i$。

**完成本练习后你将具备的能力**：把结构体数组作为函数参数；实现高斯消元求解线性方程组；理解"节点平衡方程 → 矩阵 → 求解"的工程建模流程。
