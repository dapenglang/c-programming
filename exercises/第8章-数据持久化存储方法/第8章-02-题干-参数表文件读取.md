# 第 8 章 练习 02　参数表文件读取

**对应章节**：8 数据持久化存储方法（8.1 文件概述、8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）

**场景来源**：综合实验 C6《冰区航行冰块碰撞仿真系统》（水声学院）——本练习是该实验中"仿真模型参数从文件载入"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰区冰块碰撞仿真系统运行时需要一组模型参数：海冰密度、海冰弹性模量、碰撞恢复系数等。这些参数经常需要调整，如果把它们硬写在程序代码里，每改一次就要重新编译；工程上的做法是把参数单独放在一个**参数文件**里，程序启动时先把它读进来。这样修改参数只需编辑文本文件，程序本身不用动。本练习就实现这个"参数表文件读取"环节，读完之后再用读到的密度算一次冰块质量，验证参数确实被读进来了。

## 二、任务要求

编写一个完整程序 `read_params.c`：

1. 打开参数文件 `model_params.txt`（只读模式），并检查是否成功；
2. 依次读入 3 个参数，每个参数占一行，格式为 `参数名 参数值`：`rho`（海冰密度，kg/m³）、`E`（弹性模量，Pa）、`e`（碰撞恢复系数，无量纲）；
3. 用读到的密度 `rho` 计算体积 $V = 2.5\ \mathrm{m^3}$ 的冰块质量 $m = \rho V$；
4. 把 3 个参数与算出的质量按格式输出到屏幕，最后关闭文件。

**数据文件格式约定**

- 文件名：`model_params.txt`（程序运行目录下）
- 文件为纯文本文件，共 3 行
- 每行两个字段：第 1 个是参数名（字符），第 2 个是参数值（实数），之间用**一个空格**分隔
- 样例数据行：`rho 917.0`

## 三、输入输出格式

**输入**：程序不从键盘读任何数据，全部输入来自文件 `model_params.txt`。

**输出**：屏幕输出 4 行，格式如下（`rho` 与 `e` 保留 3 位小数，`E` 用科学计数法保留 2 位小数，质量保留 2 位小数）：
```
rho = 参数值
E   = 参数值
e   = 参数值
冰块质量（V = 2.5 m^3）= 质量值 kg
```

## 四、样例

**样例 1**

`model_params.txt` 的内容：
```
rho 917.0
E 8.5e9
e 0.35
```
屏幕输出：
```
rho = 917.000
E   = 8.50e+09
e   = 0.350
冰块质量（V = 2.5 m^3）= 2292.50 kg
```

**样例 2**

`model_params.txt` 的内容：
```
rho 930.0
E 9.0e9
e 0.40
```
屏幕输出：
```
rho = 930.000
E   = 9.00e+09
e   = 0.400
冰块质量（V = 2.5 m^3）= 2325.00 kg
```

## 五、提示

- 读文件用 `fp = fopen("model_params.txt", "r")`，`"r"` 表示只读；文件不存在时 `fopen` 返回 `NULL`，务必判断；
- 逐行读参数用 `fscanf(fp, "%s%lf", name, &value)`：`%s` 把参数名读进字符数组 `name`，`%lf` 把数值读进 `double` 变量；
- 参数名读进 `name` 只是为了"跳过它"，本题并不使用这个字符串，所以三行可以共用同一个 `name` 数组；
- 三个参数用三条 `fscanf` 依次读入，顺序必须和文件里的行顺序一致；
- 科学计数法输出用 `%.2e`，`8.5e9` 会输出成 `8.50e+09`。

**完成本练习后你将具备的能力**：用只读模式打开文件、用 `fscanf` 按格式从文件中读入数据、把外部参数与程序逻辑分离——这是实验 C6 中"模型参数可配置"的地基，也是程序"数据与代码分离"思想的第一次实践。
