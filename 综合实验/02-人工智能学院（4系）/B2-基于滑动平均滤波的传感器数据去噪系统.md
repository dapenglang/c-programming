# 题目 B2：基于滑动平均滤波的传感器数据去噪系统

**适用学院**：人工智能学院（4 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**1）系统是做什么的**：本系统读入一段带有噪声的传感器"时间戳-测量值"序列，先用 3σ 准则标记出可疑野值，再用滑动平均和中值两种滤波方法对数据去噪，并把原始曲线与滤波曲线同屏对照；系统还提供不同窗口长度（3/5/9/15）的对比实验与误差统计，最后把滤波结果写回文件。

**2）它解决了什么重要问题**：任何传感器（温度、压力、位移、惯性测量单元）经模数转换后得到的原始数据都混有噪声——白噪声让曲线出现"毛刺"，野值（坏点）让曲线出现虚假尖峰，漂移让基线缓慢抬升。若不处理，后续无论是画趋势、算极值还是做闭环控制，都会被这些虚假数据带偏。滤波就是要在"保留真实变化"和"压掉随机扰动"之间取得平衡，本系统让学生亲手比较两种经典滤波器的效果。

**3）它支撑哪些关键应用**：① 无人系统/机器人的姿态与位置感知——IMU、编码器数据实时滤波；② 工业过程监测——温度、压力、流量趋势的平滑显示与报警去误报；③ 物联网与智能家居——传感器上报数据的清洗；④ 医学监护——心电/呼吸信号基线稳定；⑤ 实验数据处理——任何物理实验采集曲线的噪声抑制。以上场景共享同一套"读数据—判野值—滤波—评估"流程。

**4）与专业培养的关联**：对应人工智能学院"智能控制与机器人"方向，感知层的数据质量直接决定决策层与执行层的可靠性。本系统让学生在大一用 C 语言实现完整的数据清洗流程，建立"采样序列 = 一维数组 + 窗口运算"的直觉，为后续信号处理、传感器融合、嵌入式采集课程做准备，全程只用到循环、数组与排序。

## 二、题目任务与专业关联

本题目要求小组用 C 语言多文件工程实现上述传感器去噪系统，数据一律以文本文件读写。程序需支持：读入三列数据文件、数据统计概览、3σ 异常标记、可变窗口滑动平均、中值滤波（窗口内排序取中位）、与干净参考值的误差评估、多窗口对比实验、原始与滤波曲线的字符画对照、滤波结果写出与主控菜单。全组需完成 10 个模块，总代码 900～1200 行，每人负责 2～3 个模块。题目综合训练"文件 + 一维数组 + 排序 + 函数"，并把"数据质量"这一工程意识带进人工智能专业学习。

## 三、数据来源与格式

### 3.1 数据文件格式

采用纯文本三列格式，首行以 `#` 开头的说明行在读入时跳过：

```
# 传感器数据文件 v1：time(s) raw(℃) clean(℃)
# 说明：raw 为含噪测量值，clean 为同期干净参考值（真值），用于误差评估
0.000 20.13 20.00
0.100 20.87 20.31
0.200 19.42 20.62
0.300 25.90 20.94
0.400 20.55 21.25
```

三列含义：采样时刻（秒）、原始测量值（摄氏度）、干净参考值（摄氏度）。用 `fscanf(fp, "%lf %lf %lf", &t, &raw, &clean)` 逐行读入，恰好训练"循环 + 文件读取 + 浮点数组"。

### 3.2 仿真数据生成规则

| 字段 | 单位 | 取值范围 | 生成规则 |
|---|---|---|---|
| time 采样时刻 | s | 0.000～409.500 | 从 0 开始，步长 0.100 |
| clean 真值 | ℃ | 5～85 | `clean = 45 + 20*sin(2π*time/60)`（周期 60 s 的温度波动） |
| noise 噪声 | ℃ | ±1.5 | 均匀随机 `(rand()/(double)RAND_MAX-0.5)*3.0` |
| raw 测量值 | ℃ | -40～125 | `raw = clean + noise` |

**异常值注入**（每段数据注入 1～3 类）：

1. 尖峰野值：以 1% 概率把某个 raw 加上 `±(20 + rand()%60)`，模拟电磁干扰导致的坏点；
2. 连续失效：随机挑 1 段连续 3～5 个样本，raw 置为 `-999`（模拟传感器掉线）；
3. 基线漂移：从第 60% 个样本起给 raw 逐步加 `0.05 × 序号偏移`，模拟零漂；
4. 采样缺失：把某行的 time 写成与上一行相同（时间戳重复，供读入模块检测）。

### 3.3 真实数据集

UCR 时间序列归档（可下载单变量时间序列作为真实信号源）：https://www.cs.ucr.edu/～eamonn/time_series_data_2018/ 。使用时取其中一列转成上述三列格式（clean 列用原文，raw 列叠加自生成噪声）。

## 四、数据结构设计

```c
#define N_MAX    4096
#define WIN_MAX    31      /* 窗口长度上限，取奇数便于确定中心 */

struct Sample {
    double t;              /* 采样时刻，s，0.000~409.500，步长 0.1 */
    double raw;            /* 原始测量值，℃，量程 -40~125，可含野值 */
    double clean;          /* 干净参考值，℃，用于误差评估 */
};

struct Sample g_data[N_MAX];   /* 全部样本 */
int    g_n;                    /* 有效样本数，1~N_MAX */
double g_ma[N_MAX];            /* 滑动平均滤波结果，℃ */
double g_med[N_MAX];           /* 中值滤波结果，℃ */
int    g_flag[N_MAX];          /* 异常标记：0 = 正常 1 = 可疑，默认 0 */
double g_mean;                 /* raw 均值，℃ */
double g_sigma;                /* raw 标准差，℃ */
int    g_winLen;               /* 当前窗口长度，奇数 3~31，默认 5 */
```

辅助：排序用局部临时数组 `double buf[WIN_MAX]`，训练冒泡/选择排序（课程 5.5）。

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（3 个模块）

**M1 传感器数据文件读入模块**（源文件 `SensorIO.c`）
- 功能简介：打开数据文件，跳过 `#` 说明行，按"时刻—原始值—参考值"三列逐行读入并累计有效行数；遇到时间戳重复或行数超过 `N_MAX` 时给出提示并截断。
- 输入：文件路径（菜单输入，默认 `sensor1.txt`）。
- 输出：填充 `g_data` 与 `g_n`；返回 0 成功 / -1 失败。
- 接口示例：`int LoadSensor(const char *path, struct Sample d[], int *n);`

**M2 数据统计概览模块**（源文件 `SensorStat.c`）
- 功能简介：遍历所有样本，统计 raw 的最小值、最大值、均值、极差与标准差并打印统计表——"循环累加 + 最值查找 + 方差公式"训练。
- 输入：`g_data`、`g_n`。
- 输出：屏幕统计概览；写入全局 `g_mean`、`g_sigma`。
- 接口示例：`void StatOverview(const struct Sample d[], int n);`

**M3 异常值标记模块**（源文件 `SensorStat.c`）
- 功能简介：按 3σ 准则把满足 `|raw - mean| > 3σ` 的样本标记为可疑（`g_flag=1`），打印可疑点的序号、时刻与数值清单，并统计可疑点个数与占比。
- 输入：`g_data`、`g_n`、`g_mean`、`g_sigma`。
- 输出：更新 `g_flag[]`；屏幕可疑点清单。
- 接口示例：`int MarkOutlier(struct Sample d[], int n, int flag[]);`

### 第二部分：算法实现（4 个模块）

**M4 滑动平均滤波模块**（源文件 `Filter.c`）
- 功能简介：对每个样本取其邻域 `g_winLen` 个原始值求算术平均作为输出，边界处自动缩短窗口；对已标记为可疑的点采用"跳过野值"策略，仅对正常点求平均。
- 输入：`g_data`、`g_n`、`g_flag`、`g_winLen`。
- 输出：`g_ma[N_MAX]`；屏幕首尾若干点对照。
- 接口示例：`void MovingAverage(const struct Sample d[], int n, const int flag[], int win, double out[]);`

**M5 中值滤波模块**（源文件 `Filter.c`）
- 功能简介：对每个样本取窗口内原始值复制到临时数组，用冒泡排序排好后取中位数作为输出；中值对尖峰野值天然不敏感，可与滑动平均形成对照。
- 输入：`g_data`、`g_n`、`g_winLen`。
- 输出：`g_med[N_MAX]`。
- 接口示例：`double Median(const double buf[], int m);` / `void MedianFilter(const struct Sample d[], int n, int win, double out[]);`

**M6 滤波误差统计模块**（源文件 `EvalError.c`）
- 功能简介：以 `clean` 列作真值，分别计算原始数据、滑动平均结果、中值滤波结果的平均绝对误差（MAE）与均方根误差（RMSE），打印三种数据的误差对照表。
- 输入：`g_data`、`g_ma`、`g_med`、`g_n`。
- 输出：屏幕误差对照表。
- 接口示例：`void EvalError(const struct Sample d[], const double ma[], const double med[], int n);`

**M7 窗口长度实验模块**（源文件 `EvalError.c`）
- 功能简介：对窗口长度 3、5、9、15 依次调用 M4 与 M5，记录每种窗口下两种滤波的 RMSE 并输出对比表，让学生观察"窗口越大越平滑但越容易抹掉真实变化"的规律。
- 输入：`g_data`、`g_n`。
- 输出：屏幕窗口—误差对比表。
- 接口示例：`void WindowExperiment(const struct Sample d[], int n);`

### 第三部分：数据输出（3 个模块）

**M8 曲线字符画对比模块**（源文件 `PlotLine.c`）
- 功能简介：把时间轴等分为若干列、数值范围映射到若干行，在同一坐标系用 `*` 画原始曲线、用 `+` 画滤波曲线，两图上下对照或叠加显示，让去噪效果"看得见"。
- 输入：`g_data`（raw 或 clean）、`g_ma` 或 `g_med`。
- 输出：屏幕字符曲线。
- 接口示例：`void PlotCompare(const double y1[], const double y2[], int n, int cols, int rows);`

**M9 滤波数据写出模块**（源文件 `SensorIO.c`）
- 功能简介：把"时刻、原始值、滑动平均、中值滤波、异常标记"写入 `filtered_out.csv`，首行写列名，便于用表格软件打开查看。
- 输入：`g_data`、`g_ma`、`g_med`、`g_flag`、`g_n`。
- 输出：`filtered_out.csv` 文件。
- 接口示例：`int SaveFiltered(const char *path, const struct Sample d[], const double ma[], const double med[], const int flag[], int n);`

**M10 主控菜单模块**（源文件 `Stu_main.c`）
- 功能简介：文本主菜单（读数据 / 统计概览 / 标异常 / 滑动平均 / 中值滤波 / 误差统计 / 窗口实验 / 看曲线 / 写结果 / 退出），`do-while + switch` 调度，用状态标记约束"必须先读数据"。
- 输入：用户菜单选项。
- 输出：调度各模块。
- 接口示例：`int main(void);`

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → switch 分发到 M1～M9 → 每步打印结果后回到菜单，直至退出。状态约束：M2～M9 前必须先执行 M1；M3 依赖 M2 得到的均值与标准差；M6 依赖 M4 或 M5 已产出滤波数组。

**数据流**：

```
传感器文件 ─► M1 读入 ─► g_data / g_n (一维结构体数组)
                            │
              ┌─────────────┼───────────────┐
              ▼             ▼               ▼
       M2 统计概览 ─► M3 异常标记    (g_mean / g_sigma)
              │             │
              ▼             ▼
        M4 滑动平均 ─► g_ma        M5 中值滤波 ─► g_med
              └──────┬──────┘
                     ▼
             M6 误差统计 / M7 窗口实验
                     │
          ┌──────────┴──────────┐
          ▼                     ▼
   M8 曲线字符画对比      M9 滤波数据写出
```

## 十、选做扩展

1. 增加"加权滑动平均"（距离中心越近权重越大，如 1-2-3-2-1 权重），与等权平均比较误差；
2. 增加"阈值限幅"预处理：把超过 3σ 的点直接线性插值补齐后再滤波，观察对尖峰野值的抑制效果；
3. 把窗口实验的 RMSE 结果用字符柱状图输出，直观对比不同窗口的优劣。
