## 二、预备知识：结构体数组排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

一个任务有三条信息（编号、截止时间、机器数），第 7 章练习 21 已经把"三条信息打包成结构体"讲清了。现在有 $n$ 个任务，就要存 $n$ 个结构体——这就是**结构体数组**：

```c
struct Task t[10];   /* 最多 10 个任务，每个任务含 3 个成员 */
```

`t[0]` 是第一个任务，`t[1]` 是第二个……要访问第 $i$ 个任务的截止时间，写 `t[i].deadline`——**先下标取记录，再用点号取成员**。

### 2. 冒泡排序在做什么

冒泡排序的思路像"水里的气泡往上冒"：每一轮从头到尾比较相邻两个元素，谁大谁往后走，一轮结束最大的就"沉"到了末尾；下一轮再排剩下的。重复 $n-1$ 轮，全部有序。

以数组 $5, 3, 4$ 为例（按升序）：

```
第1轮: (5,3) 换 -> 3,5,4 ; (5,4) 换 -> 3,4,5   （5 到位）
第2轮: (3,4) 不换 -> 3,4,5                       （4 到位）
```

### 3. 为什么结构体排序要"整体交换"

排序本质是"调整顺序"。若数组里存的是**结构体**，交换时必须把**整条记录**一起换：

```c
struct Task tmp = t[j];   /* 整条备份 */
t[j] = t[j+1];            /* 整条搬过去 */
t[j+1] = tmp;             /* 整条搬回来 */
```

**不能只换 deadline 成员**：

```c
int tmp = t[j].deadline;          /* 错：只换了截止时间 */
t[j].deadline = t[j+1].deadline;
t[j+1].deadline = tmp;
```

这样一换，"编号"和"机器数"就留在原地了，和新的截止时间**对不上号**——这是结构体排序最典型的错误。

### 4. 结构体可以整体赋值

好消息是：C 语言允许**结构体变量直接赋值**。`t[j] = t[j+1];` 会自动把对方**所有成员**逐一复制过来，不需要我们逐个成员搬。所以交换只用三行，和交换两个 `int` 完全一样，只是类型从 `int` 换成了 `struct Task`。

### 5. 比较规则与并列处理

本题按"截止时间升序"排，规则是"前面的比后面的大就换"：

$$
t[j].deadline > t[j+1].deadline \Rightarrow \text{交换}
$$

为了结果唯一，题目规定**截止时间相同时按编号升序**，于是"要不要换"的条件写成：

$$
t[j].deadline > t[j+1].deadline \quad \textbf{或} \quad (t[j].deadline = t[j+1].deadline\ \wedge\ t[j].id > t[j+1].id)
$$

### 6. 用本例走一遍

**样例 1**：任务 1(deadline 5)、2(deadline 3)、3(deadline 4)。

- 第 1 轮：(1,2) 比，$5>3$ 换 → 2,1,3；(1,3) 比，$5>4$ 换 → 2,3,1。最大者（任务 1）到位；
- 第 2 轮：(2,3) 比，$3<4$ 不换。结束。

结果：任务 2(3)、任务 3(4)、任务 1(5)，与样例一致。

**样例 2**：任务 1(4)、2(4)、3(2)。

- 第 1 轮：(1,2) 比，两截止时间都是 4，编号 $1<2$ 不换；(2,3) 比，$4>2$ 换 → 1,3,2；
- 第 2 轮：(1,3) 比，$4>2$ 换 → 3,1,2。结束。

结果：任务 3(2)、任务 1(4)、任务 2(4)，编号也保持升序，与样例一致。

> **这个思想在综合实验中反复出现**：B9 任务排序、B6 词频排序（按词频降序）、B5 按距离升序、B10 按相似度排序，都是"结构体数组 + 冒泡排序"同一个套路。

## 三、解题思路

1. **定义类型**：`struct Task { int id; int deadline; int machines; };`；
2. **读入**：循环读 `t[i].id`、`t[i].deadline`、`t[i].machines`；
3. **冒泡排序**：外层轮次 $1 \sim n-1$，内层比较相邻两个，按规则决定是否整体交换；
4. **输出**：循环打印每条记录。

## 四、参考代码

```c
#include <stdio.h>

/* 任务结构体：编号、截止时间、所需机器数 */
struct Task {
    int id;         /* 任务编号 */
    int deadline;   /* 截止时间 */
    int machines;   /* 所需机器数 */
};

int main(void)
{
    struct Task t[10];   /* 结构体数组，最多 10 个任务 */
    int n, i, j;

    scanf("%d", &n);     /* 读入任务个数 */

    /* 读入 n 条任务记录 */
    for (i = 0; i < n; i++)
        scanf("%d %d %d", &t[i].id, &t[i].deadline, &t[i].machines);

    /* 冒泡排序：按截止时间升序；相同时按编号升序 */
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - 1 - i; j++) {
            int need_swap = (t[j].deadline > t[j+1].deadline) ||
                            (t[j].deadline == t[j+1].deadline &&
                             t[j].id > t[j+1].id);
            if (need_swap) {
                struct Task tmp = t[j];   /* 整条记录交换 */
                t[j] = t[j+1];
                t[j+1] = tmp;
            }
        }
    }

    /* 输出排序后的任务表 */
    for (i = 0; i < n; i++)
        printf("id=%d deadline=%d machines=%d\n",
               t[i].id, t[i].deadline, t[i].machines);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 3 / (1,5,2)(2,3,1)(3,4,3) | 按 deadline 升序：3,4,5 | `id=2 deadline=3 machines=1` / `id=3 deadline=4 machines=3` / `id=1 deadline=5 machines=2` ✓ |
| 3 / (1,4,2)(2,4,1)(3,2,5) | 2 最先；两条 deadline=4 按 id 升序 | `id=3 deadline=2 machines=5` / `id=1 deadline=4 machines=2` / `id=2 deadline=4 machines=1` ✓ |
| 2 / (1,3,1)(2,1,1) | 2 的截止时间早 | `id=2 deadline=1 machines=1` / `id=1 deadline=3 machines=1` ✓ |
| 1 / (7,2,9) | 单条无需排序 | `id=7 deadline=2 machines=9` ✓ |

并列截止时间的两条（$deadline=4$）按编号 1、2 输出，符合规则。

## 六、常见错误与讲解

**错误 1：只交换某个成员（最典型）**

```c
int tmp = t[j].deadline;              /* 错：编号、机器数没跟着走 */
t[j].deadline = t[j+1].deadline;
t[j+1].deadline = tmp;
```

必须用 `struct Task tmp = t[j];` 做**整条交换**。

**错误 2：内层循环边界写成 n-1，多比一轮**

```c
for (j = 0; j < n - 1; j++)        /* 能排序，但多做了无用比较 */
for (j = 0; j < n - 1 - i; j++)    /* 对：每轮末尾已排好 i 个 */
```

**错误 3：比较用错成员或方向反了**

```c
if (t[j].id > t[j+1].id)      /* 错：题目要求按 deadline 排 */
if (t[j].machines > ...)      /* 错：不是按机器数 */
```

**错误 4：把结构体数组的成员写成 t.id[i]**

```c
t.id[i]          /* 错：t 是数组，不是结构体 */
t[i].id          /* 对：先下标取记录，再点号取成员 */
```
