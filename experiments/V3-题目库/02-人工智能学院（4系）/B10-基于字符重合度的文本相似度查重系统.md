# 题目 B10：基于字符重合度的文本相似度查重系统

**适用学院**：人工智能学院（4 系）　**组容量**：本题目最多 3 组选择

## 一、系统/算法说明

**系统做什么**：本系统是一套命令行文本相似度查重工具：读入若干篇英文文档，把每篇文档转换成"相邻两字符组成二元组"的集合，用集合重合度（Jaccard 相似度 = 交集大小 ÷ 并集大小）量化两篇文档的相似程度；再以滑动窗口定位两篇文档中连续相似的片段并给出行号，按阈值把文档对判定为"高度相似 / 疑似相似 / 正常"，输出两两比对矩阵与查重报告。

**解决什么重要问题**：论文抄袭、作业代写、内容搬运是学术与内容平台的顽疾。逐字比对无法应对"改几个词、调一下语序"的抄袭，而字符二元组统计天然对局部改写不敏感——只要大段文字雷同，二元组集合就会大面积重合。这个简单方法正是真实查重系统（如知网、Turnitin 底层思想之一）的原型：把文本变成可比较的"特征指纹"。不做查重，学术诚信就没有自动化防线；方法选得太粗糙（如只比词数），又会冤枉原创作者，所以阈值设计与片段定位同样重要。

**支撑哪些关键应用**：① 高校论文与作业查重；② 新闻与自媒体平台的重复内容识别；③ 搜索引擎网页去重（避免结果重复）；④ 代码托管平台的重复代码检测；⑤ 版权监测与转载溯源。

**与专业培养的关联**：文本表示与相似度度量是"数据挖掘""自然语言处理"课程的基石概念，本系统用纯 C 语言的字符数组与标记数组实现一次完整的"文本 → 特征 → 度量 → 判级 → 报告"流程，让学生亲手体验文本挖掘的第一课，全程不涉及任何机器学习理论。

## 二、题目任务与专业关联

本题目要求实现一个含 10 个模块的文本查重系统：(1) 从文档清单文件成对读入多篇文档；(2) 清洗文本（去标点、统一小写）；(3) 提取每篇文档的字符二元组特征，用 676 格标记数组记录"哪些二元组出现过"；(4) 计算 Jaccard 相似度，实现滑动窗口相似片段定位（行号 + 片段文本）；(5) 按阈值分级判定，输出多文档两两比对矩阵，并把完整查重报告写入文件。

专业关联：字符二元组是最朴素的 n-gram 特征，Jaccard 系数是数据挖掘标准的集合相似度度量，滑动窗口定位则与真实查重系统的"片段级比对"一致。学生完成本题后，对"特征提取—相似度度量—阈值决策"三件套形成完整的第一手经验。

## 三、数据来源与格式

### 3.1 数据文件格式

（1）文档清单文件 `doclist.txt`：每行一个待查重文档的文件名。

```
# 待查重文档列表（每行一个文件名，最多 6 篇）
doc1.txt
doc2.txt
doc3.txt
doc4.txt
doc5.txt
```

（2）每篇文档为纯英文文本：首行为 `#` 说明行，其后每行一句英文，示例（doc1 为原文，doc2 为其改写抄袭版）：

```
# doc1.txt 智能建筑课程报告 原文
The quick brown fox jumps over the lazy dog near the river bank
A study on campus energy use shows lighting costs drop at night
Students collected sensor data from three buildings every hour

# doc2.txt doc1 的改写版（同义替换 + 语序微调）
The fast brown fox leaps over the lazy dog beside the river bank
A research on campus energy usage shows lighting expense falls at night
Sensor data from three buildings was collected by students every hour
```

### 3.2 仿真数据生成规则

学生按下述规则构造 5 篇仿真文档（每篇 30~60 行，行文风格统一）：

| 字段 | 说明 | 取值规则 |
|---|---|---|
| doc1 原文 | 基准文档 | 围绕 1 个主题自写 30~60 句，句长 8~15 词 |
| doc2 全篇改写版 | 模拟整篇抄袭 | 复制 doc1 后对每句做 15%~30% 的同义词替换并微调 20% 句子的语序；预期与 doc1 判为"高度相似" |
| doc3 拼接版 | 模拟片段抄袭 | 独立主题的文档中嵌入 doc1 的 2~3 个原句段落；预期与 doc1 判为"疑似相似"，且片段定位模块应恰好找出嵌入段落 |
| doc4 / doc5 独立文档 | 对照组 | 各自独立主题书写；预期与 doc1~doc3 判为"正常" |
| 异常注入·字符噪声 | 考察清洗模块 | 全部文档中约 15% 的句子混入大写开头、逗号句号粘连、连续空格等脏字符，清洗模块须统一处理 |
| 异常注入·重复行 | 考察标记逻辑 | 在 doc3 中复制 2 行自身已有句子，检验标记数组对重复特征的正确处理 |

### 3.3 真实数据集（选做）

PAN@Webis 文本查重评测语料（PAN Plagiarism Detection Corpus）提供带标注的英文学术文本抄袭语料，可作为选做扩展的数据来源：https://pan.webis.de

## 四、数据结构设计

```c
#define MAX_DOC   6          /* 文档上限 */
#define MAX_LINES 300        /* 单篇文档最大行数 */
#define MAX_LINE  160        /* 单行最大字符数 */
#define BIGN      676        /* 二元组总数：26 × 26 个字母对 */
#define WIN_LEN   40         /* 相似片段定位窗口长度（字符） */

char g_doc[MAX_DOC][MAX_LINES][MAX_LINE];  /* 原始文本，按文档按行存储 */
int  g_len[MAX_DOC];                       /* 各文档实际行数 */
char g_name[MAX_DOC][32];                  /* 各文档文件名 */
int  g_docCount;                           /* 文档篇数 */

int  g_flagA[BIGN];        /* 文档 A 的二元组标记：1=出现过 */
int  g_flagB[BIGN];        /* 文档 B 的二元组标记 */
int  g_bigramA[BIGN];      /* 文档 A 各二元组出现次数（片段定位用） */

double g_sim[MAX_DOC][MAX_DOC];   /* 两两相似度矩阵（对角线为 1） */
int    g_grade[MAX_DOC][MAX_DOC]; /* 判级：0=正常 1=疑似 2=高度相似 */

/* 相似片段定位结果 */
struct Frag {
    int docA, lineA;         /* 文档 A 的行号（1 起） */
    int docB, lineB;         /* 文档 B 的行号 */
    char text[WIN_LEN + 8];  /* 相似片段文本 */
    double rate;             /* 该窗口的二元组重合比例 */
};
struct Frag g_frag[50];  int g_fragCount;
```

## 五、功能模块拆解（共 10 个模块）

### 第一部分：数据读入（2 个模块）

**M1 文本文件成对读入模块**（源文件 `DocIO.c`）

- 功能简介：打开 `doclist.txt` 逐一读入文档文件名，再逐篇按行读入 `g_doc`；跳过 `#` 说明行；处理文件缺失（跳过该篇并警告）、超长行截断；读入后报告各篇行数与总字符数。
- 输入：清单文件路径（默认 `doclist.txt`）。
- 输出：`g_doc`、`g_len`、`g_name`、`g_docCount`；屏幕读入报告。

**M2 文本清洗模块**（源文件 `Clean.c`）

- 功能简介：对每篇每行执行统一清洗：大写转小写、标点替换为空格、连续空格压缩为单个空格、去掉行首尾空格；统计各篇被替换的字符数供报告使用。
- 输入：`g_doc`。
- 输出：就地清洗后的 `g_doc`；屏幕清洗摘要。

### 第二部分：算法实现（4 个模块）

**M3 字符二元组提取模块**（源文件 `Bigram.c`）

- 功能简介：对清洗后的一篇文档，逐行扫描字符串：跳过空格后，把相邻两个字母 `c1 c2` 组成二元组，按下标公式 `(c1-'a')*26 + (c2-'a')` 映射到 0~675，对应计数加一；同时提供"把计数数组转为 0/1 标记数组"的函数。
- 输入：某篇清洗后的文档。
- 输出：`g_bigramA`（或 B）计数数组与标记数组。

**M4 特征标记数组模块**（源文件 `Flag.c`）

- 功能简介：封装两个文档特征的装载与比对原语：`装载特征`（调用 M3 填充 g_flagA/g_flagB）、`交集大小`（两标记数组按位与计数）、`并集大小`（按位或计数）；提供打印 Top-K 高频二元组（可读形式 `th`、`he`）的调试函数。
- 输入：两篇文档的文档编号。
- 输出：交集数、并集数；调试时屏幕输出。

**M5 Jaccard 相似度计算模块**（源文件 `Jaccard.c`）

- 功能简介：对用户指定的文档对调用 M4 得到交集与并集，相似度 = 交集 ÷ 并集（并集为 0 时记 0）；对全部文档两两循环计算，填充 `g_sim` 矩阵；屏幕输出保留 3 位小数的对称矩阵。
- 输入：`g_doc`、文档篇数。
- 输出：`g_sim`；屏幕相似度矩阵。

**M6 相似片段定位模块**（源文件 `SlidingWin.c`）

- 功能简介：对指定的文档对，以 WIN_LEN 个字符为窗口在 A 文档每行内滑动：统计窗口内非空格二元组出现在 B 文档特征中的比例，比例超过 0.8 记为一个相似片段；对相邻重叠窗口合并，记录 A、B 两侧大致行号与片段文本，结果存入 `g_frag`。
- 输入：文档对编号、两篇文档的标记数组。
- 输出：`g_frag` 与 `g_fragCount`；屏幕片段清单。

### 第三部分：数据输出（4 个模块）

**M7 相似度分级报告模块**（源文件 `Grade.c`）

- 功能简介：按阈值把每对文档判级：相似度 ≥ 0.5 为"高度相似 [!!]"、0.2~0.5 为"疑似相似 [?]"、其余为"正常"；阈值允许用户交互修改后重判；屏幕输出判级清单及每对的一句话说明（引用其片段定位结果条数）。
- 输入：`g_sim`、阈值参数。
- 输出：`g_grade`；屏幕分级清单。

**M8 多文档两两比对矩阵模块**（源文件 `Matrix.c`）

- 功能简介：输出带行列标题的 n×n 比对矩阵，格内为相似度（3 位小数）并叠加判级符号（`!!`/`?`）；矩阵下方列出按相似度降序排序的文档对 Top-5 名单，方便快速锁定重点对。
- 输入：`g_sim`、`g_grade`。
- 输出：屏幕比对矩阵与 Top-5 名单。

**M9 查重报告文件输出模块**（源文件 `Report.c`）

- 功能简介：把完整结果写入 `check_report.txt`：文档清单与行数、清洗统计、判级阈值、两两相似度与判级表、每个"高度相似/疑似"文档对的相似片段明细（行号 + 片段文本）；报告文件名带生成序号不覆盖旧报告。
- 输入：各全局结果。
- 输出：`check_report.txt`；屏幕确认信息。

**M10 主控菜单模块**（源文件 `main.c`）

- 功能简介：文本主菜单（读入文档 / 清洗 / 单对相似度 / 全部两两比对 / 片段定位 / 修改阈值与分级 / 比对矩阵 / 生成报告 / 退出），`do-while + switch` 调度；状态约束"必须先读入并清洗文档才能计算特征与相似度"。
- 输入：用户菜单选项。
- 输出：调度各模块。

## 六、数据流与控制流

**控制流**：`main()` 菜单循环 → switch 分发 M1~M9 → 直至退出。状态约束：M3~M9 均要求已执行 M1 与 M2；M5/M6/M7/M8/M9 可对任意已装载的文档对反复执行。

**数据流**：

```
doclist.txt ──► M1 逐篇读入 ──► g_doc（6×300×160 三维字符数组）
                                      │
                                      ▼
                                 M2 统一清洗
                                      │
              ┌───────────────────────┴───────────────────────┐
              ▼                                               ▼
     M3 提取二元组特征 ──► g_flagA / g_flagB / g_bigramA   （对每对文档重复装载）
              │                                               │
              ▼                                               ▼
     M4 交集 / 并集原语 ──► M5 Jaccard ──► g_sim 相似度矩阵
                                      │
                              M6 滑动窗口片段定位 ──► g_frag
                                      │
              ┌───────────────────────┼──────────────────────┐
              ▼                       ▼                      ▼
       M7 阈值分级 g_grade      M8 比对矩阵+Top5       M9 check_report.txt
```

所有模块之间只通过 `g_doc`、`g_flagA/g_flagB`、`g_sim`、`g_grade`、`g_frag` 与参数传递交换数据，接口（函数头部）编码前书面约定。

## 十、选做扩展

1. 词级二元组：把特征从"字符对"升级为"相邻单词对"，对比两种特征对 doc2 这类同义替换抄袭的区分能力（仍是字符串处理 + 计数）；
2. 阈值敏感性实验：阈值从 0.1 到 0.9 以 0.05 步长扫描，统计每个阈值下的判级数量表，讨论阈值选择的权衡（纯循环重判）；
3. 接入 PAN 真实语料：下载 2~3 对带标注的英文文档对，验证系统判级与人工标注是否一致，把结论写入实验小结。
