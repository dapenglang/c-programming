## 二、预备知识：复化梯形积分的基本原理（零基础阅读）

### 1. 问题是怎么来的

定积分 $\int_a^b f(x)\,dx$ 的几何意义是曲线 $y=f(x)$ 下方、$x$ 轴上方在 $[a,b]$ 内的**面积**。当 $f$ 的原函数不好求时，就把这块面积切成很多细长条，用容易算的形状（梯形）去近似，再把它们加起来——这就是**数值积分**。切得越细，越接近真值。

### 2. 公式是怎么推出来的

先把 $[a,b]$ 等分成 $n$ 段，每段宽度 $h=\dfrac{b-a}{n}$，分点 $x_i=a+ih$（$i=0,1,\dots,n$）。在第 $i$ 小段 $[x_i,x_{i+1}]$ 上，用连接两端点 $\bigl(x_i,f(x_i)\bigr)$、$\bigl(x_{i+1},f(x_{i+1})\bigr)$ 的直线代替曲线，这块曲边梯形就近似成一个**直边梯形**，面积为

$$
S_i = \frac{f(x_i)+f(x_{i+1})}{2}\,h .
$$

把所有小梯形相加：

$$
I \approx \sum_{i=0}^{n-1} S_i
= \frac{h}{2}\Bigl[f(x_0) + 2f(x_1) + 2f(x_2) + \cdots + 2f(x_{n-1}) + f(x_n)\Bigr].
$$

写成紧凑形式就是**复化梯形公式**：

$$
I \approx \frac{h}{2}\Bigl[f(a) + 2\!\!\sum_{i=1}^{n-1}f(a+ih) + f(b)\Bigr].
$$

注意中间的 $x_1,\dots,x_{n-1}$ 每个点被左右两个梯形共用，故系数是 2。

### 3. 代入本例手算

取 $f(x)=e^{-x}$、$[a,b]=[0,1]$，先用较粗的 $n=4$（$h=0.25$）体会一下。各分点函数值：

| $x_i$ | 0 | 0.25 | 0.50 | 0.75 | 1.00 |
|---|---|---|---|---|---|
| $f(x_i)=e^{-x_i}$ | 1.000000 | 0.778801 | 0.606531 | 0.472367 | 0.367879 |

代入公式：

$$
I \approx \frac{0.25}{2}\bigl[1.000000 + 2(0.778801+0.606531+0.472367) + 0.367879\bigr]
= 0.125\times\bigl[1.367879 + 3.715398\bigr] = 0.635410 .
$$

真值为 $1-e^{-1}=0.632121$，粗分 $n=4$ 时误差约 $3\times10^{-3}$。把 $n$ 增大到 1000，误差降到 $10^{-6}$ 以下，得到 $0.632121$。

### 4. 编程实现要点

- **分离**：`dose(x)` 只负责"给定 $x$ 返回 $f(x)$"；`integral(a,b,n)` 只负责"怎么切、怎么加"。二者由函数调用连接，互不干扰——这就是模块化在数值计算里的典型用法；
- **首末各半**：`s` 的初值取 $\dfrac{f(a)+f(b)}{2}$，循环只加内部节点，最后乘 `h`；
- **分段数**：`n` 为 `int`，$h$ 为 `double`，注意 `(b-a)/n` 中 `n` 会自动转成浮点参与除法；
- **精度**：梯形法误差与 $h^2$ 成正比，$n$ 翻倍误差约降为四分之一。

## 三、解题思路

1. **写 `dose`**：一行 `return exp(-x);`；
2. **写 `integral`**：先算 `h`，用 `(dose(a)+dose(b))/2` 作为累加初值，再循环累加内部节点，返回 `s*h`；
3. **`main`**：读 `a`、`b`、`n`，打印 `integral` 的结果；
4. **验证**：用已知真值 $1-e^{-1}$ 核对。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

/* 被积函数：归一化剂量率 f(x) = exp(-x) */
double dose(double x)
{
    return exp(-x);
}

/* 复化梯形积分：把 [a,b] 等分为 n 段 */
double integral(double a, double b, int n)
{
    double h = (b - a) / n;
    double s = (dose(a) + dose(b)) / 2.0;   /* 首末两点各计一半 */
    int i;

    for (i = 1; i < n; i++)                 /* 内部节点全权累加 */
        s += dose(a + i * h);

    return s * h;                           /* 统一乘步长 */
}

int main(void)
{
    double a, b;
    int n;

    scanf("%lf %lf %d", &a, &b, &n);
    printf("integral = %.6f\n", integral(a, b, n));
    return 0;
}
```

## 五、运行验证

以 $[0,1]$、$f(x)=e^{-x}$ 为例，不同分段数的结果如下（真值 $0.632121$）：

| 输入 `a b n` | 手算/公式说明 | 程序输出 |
|---|---|---|
| 0 1 10 | $h=0.1$，粗分，误差约 $5\times10^{-4}$ | `integral = 0.632647` |
| 0 1 100 | $h=0.01$，误差约 $5\times10^{-6}$ | `integral = 0.632126` |
| 0 1 1000 | $h=0.001$，误差约 $5\times10^{-8}$ | `integral = 0.632121` |
| 0 2 1000 | 真值 $1-e^{-2}=0.864665$ | `integral = 0.864665` |

可以看到分段数越大越接近真值，第 3、4 行已精确到小数点后 6 位。

## 六、常见错误与讲解

**错误 1：内部节点系数漏乘 2**

```c
s = (dose(a) + dose(b)) / 2.0;
for (i = 0; i <= n; i++) s += dose(a + i*h);   /* 错：首末点被重复计入，内部点也没按梯形合并 */
```

标准写法是"首末各半 + 内部全加"，二者等价于"每个小梯形用两底各半"。若把每个分点都直接相加，结果会偏大。

**错误 2：循环边界越界**

```c
for (i = 1; i <= n; i++)     /* 错：i=n 时加上 f(b)，而 f(b) 已计入初值 */
for (i = 1; i < n; i++)      /* 对：只加内部点 x_1..x_{n-1} */
```

**错误 3：整数除法丢精度**

```c
double h = (b - a) / n;      /* b-a 是 double，会自动按浮点除法，正确 */
double h = 1 / n;            /* 错：1 和 n 都是 int，结果恒为 0 */
```

只要除号左边是 `double` 就没问题；若分子写成整数字面量，要写成 `1.0` 才安全。

**错误 4：把被积函数写死在积分器里**

```c
double integral(double a, double b, int n)
{
    s += exp(-(a + i*h));    /* 错：换模型就得改积分器，失去模块化意义 */
}
```

应始终调用 `dose(...)`，把"变的部分"留在被积函数里。

## 七、与综合实验的衔接

实验 **D5（γ 射线剂量率与屏蔽计算）**里，累积剂量、屏蔽层衰减、能谱加权等都要做数值积分，而被积函数往往随模型（单能、多能、含屏蔽因子）而变。把"被积函数 `dose`"和"积分器 `integral`"分离后，换模型只需要改一个函数，积分器完全复用——这正是模块化程序设计在数值计算中的价值。到这里，第 4 章的非线性方程求解与数值积分工具箱已经齐备；下一题（19）将把多个计算函数组织进一个带菜单的**计算器**里，进入真正的"多函数协作"。
