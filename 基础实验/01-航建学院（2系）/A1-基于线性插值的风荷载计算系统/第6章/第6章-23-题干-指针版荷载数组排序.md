# 第 6 章 练习 23　指针版荷载数组排序

**所属综合实验**：A1（A1-基于线性插值的风荷载计算系统）

**对应章节**：6 内存数据深度操控方法（6.1 地址与指针变量、6.2 指针与数组、6.4 指针作为函数参数）

**场景来源**：综合实验 A1/A4《风荷载计算系统》与《冬季采暖负荷计算系统》（航建学院）——本练习是该实验中"各层/各构件荷载排序与筛选"环节的指针实现。

**建议用时**：25～30 分钟

## 一、应用场景

风荷载系统 A1 要统计各楼层迎风面的风压强度，采暖系统 A4 要统计各房间的采暖负荷。系统常需要把这些数**从大到小排好序**：找出最不利荷载、筛选出负荷最大的几个房间优先处理。排序的输入是一排数，程序把它交给一个**以指针为参数**的排序函数来完成。

用指针写排序函数的好处是：`void sort(double *a, int n)` 只要拿到数组首地址和长度，就能操作整个数组，调用时不必复制数据，函数签名也更简洁。本练习实现按**从大到小（降序）**排序。

## 二、任务要求

编写一个完整程序 `sort_ptr.c`：

1. 定义函数

```c
void sort(double *a, int n);
```

用冒泡排序把数组 `a` 的 `n` 个元素按**从大到小**排列（函数无返回值，直接修改原数组）；

2. 主函数读入元素个数 `n`（整数，**题目保证 1 ≤ n ≤ 30**），再读入 `n` 个实数（各楼层风压强度，kN/m²）；
3. 调用 `sort` 排序；
4. 输出排序后的序列，每个数保留 **2 位小数**，用空格分隔。

## 三、输入输出格式

**输入**：第一行一个整数 n；第二行 n 个实数，用空格分隔。

**输出**：一行，排序后的 n 个数（降序），保留 2 位小数，数与数之间一个空格。

## 四、样例

**样例 1**

输入：
```
6

```
输出：
```
1.55 1.20 1.10 0.95 0.85 0.60
```

**样例 2**

输入：
```
5

```
输出：

```
2.10 1.80 1.20 0.75 0.30
```

## 五、提示

**冒泡排序**（降序）的思路：每一轮从头到尾比较相邻两个数，如果前一个比后一个**小**（不符合"大的在前"），就交换它们。一轮下来，最小的数会被"冒"到末尾；重复多轮，整个数组就排好了。

```c
void sort(double *a, int n)
{
    int i, j;
    double t;
    for (i = 0; i < n - 1; i++) {          /* 共 n-1 轮 */
        for (j = 0; j < n - 1 - i; j++) {
            if (a[j] < a[j + 1]) {         /* 前小后大 --> 需交换（降序）*/
                t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
        }
    }
}
```

用指针写也可以：`if (*(a+j) < *(a+j+1))` 与 `a[j] < a[j+1]` 完全等价。本题两种写法均接受，重点是理解**函数参数 `double *a` 就是数组首地址**。

**完成本练习后你将具备的能力**：实现冒泡排序；理解 `void` 函数；掌握"指针参数直接修改原数组"的机制；理解 `a[j]` 与 `*(a+j)` 的等价关系。
