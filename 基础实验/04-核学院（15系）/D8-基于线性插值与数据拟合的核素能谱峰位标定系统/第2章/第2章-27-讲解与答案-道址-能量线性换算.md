## 二、预备知识：能谱刻度为什么是线性的

### 1. 问题是怎么来的

γ 能谱仪工作时，探测器把接收到的光子按能量大小"分拣"进很多个道（格子），每个道有一个道址（0、1、2、…）。测完之后，我们看到的是一条"道址—计数"曲线，峰出现在某些道址上。

可是我们要知道的是"**能量**是多少 keV"，才能判断核素。道址是仪器内部的编号，能量才是物理量。怎么把道址翻译成能量？——这就要靠**刻度**。

### 2. 公式是怎么推出来的

用两个已知能量的标准源测一次：比如 Cs-137 的特征峰 661.7 keV 落在道址 $ch_1$ 上，Co-60 的 1332.5 keV 峰落在道址 $ch_2$ 上。把这看成两个点 $(ch_1, E_1)$、$(ch_2, E_2)$，在仪器工作范围内，道址与能量近似成**直线关系**（探测器的"道宽"在能量上大致均匀），于是：

$$
E = k\,\text{ch} + b
$$

其中斜率 $k$ 是"**每个道对应多少 keV**"（也叫增益），截距 $b$ 是"零道对应的能量偏移"。

由两点定直线：

$$
k = \frac{E_2 - E_1}{ch_2 - ch_1}, \qquad b = E_1 - k\,ch_1
$$

本题把刻度系数直接给定为 $k = 1.5$、$b = 0$，你只需做**正算**（道址 → 能量）。

### 3. 用本例走一遍

取 $k = 1.5$、$b = 0$：

- 道址 441：$E = 1.5 \times 441 + 0 = 661.5$ keV——正好落在 Cs-137 的特征峰 661.7 keV 附近，说明这个道址上的峰很可能就是 Cs-137；
- 道址 888：$E = 1.5 \times 888 + 0 = 1332.0$ keV——落在 Co-60 的 1332.5 keV 峰附近；
- 道址 0：$E = 0$ keV，这是刻度的原点。

再反推验证一下刻度是否合理：Co-60 的另一个特征峰 1173.2 keV 应对应道址 $1173.2 / 1.5 \approx 782.1$。也就是说，若在 782 道附近看到峰、在 888 道附近也看到峰，就能判定样品里有 Co-60——这正是综合实验 D8 要做的核素识别。

### 4. 编程时怎么用它

公式里三个量：常数 $k$、$b$ 和输入 `ch`，求 `E`。注意**类型混合**：`ch` 是 `int`，$k$ 是 `double`，相乘时 C 自动把 `ch` 提升为 `double`，结果正确保留小数。编程就是"把 $k$、$b$ 放进常量、把 ch 读进变量、把公式翻译成一行赋值"。

> **这个思想在综合实验中反复出现**：D8 的能量刻度（道址 → 能量）、D1 的半衰期换算（时间 → 活度）、第 2 章的线性插值（高度 → 系数），全部是"两个物理量之间的线性/指数换算"。学会一次，多处可用。

## 三、解题思路

1. **确定数据**：刻度系数是仪器标定的结果，程序运行中不改动，用 `const double K = 1.5, B = 0.0;`；
2. **确定变量**：读入的道址 `ch` 是整数，用 `int`；待求的能量 `E` 是实数，用 `double`；
3. **套用公式**：`E = K * ch + B;`——`ch` 自动提升为 double；
4. **输出**：题目要求保留 2 位小数，用 `%.2f`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 能量刻度系数：斜率 k 与截距 b，由标准源标定得到 */
    const double K = 1.5;      /* 每道对应 1.5 keV */
    const double B = 0.0;      /* 零道对应 0 keV */

    int ch;                    /* 道址，整数编号 */
    double E;                  /* 能量，keV */

    scanf("%d", &ch);          /* 读入道址 */

    /* 线性刻度：E = k * ch + b，ch 会自动提升为 double */
    E = K * ch + B;

    printf("E = %.2f\n", E);   /* 输出能量，保留 2 位小数 */

    return 0;
}
```

## 五、运行验证

| 输入 ch | 手算过程 | 程序输出 |
|---|---|---|
| 441 | E = 1.5×441 + 0 = 661.50 | `E = 661.50` ✓ |
| 888 | E = 1.5×888 + 0 = 1332.00 | `E = 1332.00` ✓ |
| 0 | E = 1.5×0 + 0 = 0.00 | `E = 0.00` ✓ |
| 782 | E = 1.5×782 = 1173.00（接近 Co-60 的 1173.2 keV） | `E = 1173.00` ✓ |

第四例换算出 1173 keV，与 Co-60 的 1173.2 keV 特征峰吻合，说明刻度系数合理、公式应用正确。

## 六、常见错误与讲解

**错误 1：把 ch 定义成 int 就担心"整数除法"**

```c
E = K * ch + B;            /* 对：只乘除，无整数除法，自动提升 */
E = (double)ch * K + B;    /* 也可以：显式转换，语义更清楚 */
```

本题只涉及乘法加法，不会发生整数除法截断（那是 `ch / 2` 之类才有风险）。但如果公式里含除法，如 `E = ch / 2 * K`，就要小心 `ch/2` 先按整数算——此时应写成 `ch / 2.0 * K`。

**错误 2：常量写成整数**

```c
const int K = 1.5;          /* 错：1.5 存进 int 变成 1 */
const double K = 1.5;       /* 对：刻度系数一律 double */
```

**错误 3：scanf 格式符与变量类型不匹配**

```c
scanf("%lf", &ch);          /* 错：ch 是 int，要用 %d */
scanf("%d", &ch);           /* 对：整数用 %d */
```

读 `int` 用 `%d`、读 `double` 用 `%lf`；若混用，读入的值是错误的（甚至破坏内存）。

**错误 4：忘记取地址符 / 输出格式不匹配**

```c
scanf("%d", ch);            /* 错：漏了 & */
printf("E = %d\n", E);      /* 错：E 是 double，用 %d 得到乱码 */
printf("E = %.2f\n", E);    /* 对：保留 2 位小数 */
```

## 七、与综合实验的衔接

- 实验 **D8（基于线性插值与数据拟合的核素能谱峰位标定）**中，"能量刻度"就是本练习：先确定 $k$、$b$（可由两个标准源峰位拟合，或由已知刻度曲线给出），再用它把每个峰的道址换算成能量，与核素库比对；
- 同样的公式稍作变化就是"两点定刻度"：练习 26（第 3 章）会对谱数据做峰位初判；练习 28（第 5 章）会读入整条能谱并平滑；练习 27（第 7 章）会把峰打包成结构体（含道址、能量、净面积）再逐峰换算能量。**公式不变，变的是"对哪个道址算、算什么量"**。本练习是 D8 全部内容的第一块地基——把道址翻译成能量。
