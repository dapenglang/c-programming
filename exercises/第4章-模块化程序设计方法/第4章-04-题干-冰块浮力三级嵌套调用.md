# 第 4 章 练习 04　冰块浮力三级嵌套调用

**对应章节**：4 模块化程序设计方法（4.1 模块化程序设计、4.2 函数的声明调用与参数传递、4.3 函数嵌套调用与递归调用）

**场景来源**：综合实验 C8《基于数值积分与二分法的碎冰冰块浮力吃水计算系统》（水声学院）——本练习是该实验中"冰块体积—质量—浮力换算"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

计算碎冰的浮力与吃水时，第一步是由冰块的三个尺寸算出它的体积，第二步体积乘冰密度得质量，第三步质量乘重力加速度得它受到的浮力（漂浮冰块的重力与浮力平衡，二者大小相等）。这三次计算首尾相接、层层依赖。实验 C8 把这三个环节各写成一个函数，让"浮力函数"去调用"质量函数"，"质量函数"再去调用"体积函数"。本练习就来实现这条嵌套调用链。

## 二、任务要求

编写一个完整程序 `ice_buoyancy.c`：

1. 必须定义三个函数，**函数原型分别为**
   ```c
   double ice_volume(double l, double w, double t);    /* 体积 V = l*w*t */
   double ice_mass(double l, double w, double t);      /* 质量 m = rho*V  */
   double ice_buoyancy(double l, double w, double t);  /* 浮力 F = m*g    */
   ```
   其中 `l`、`w`、`t` 分别为冰块的长、宽、厚（单位：m）；
2. **必须体现三级嵌套调用**：`ice_buoyancy` 内部调用 `ice_mass`，`ice_mass` 内部调用 `ice_volume`；后两个函数中**不得直接重抄**体积公式，只能通过调用获取中间量；
3. 常量写在函数内部：冰的密度 $\rho_{ice}=917\ \text{kg/m}^3$，重力加速度 $g=9.8\ \text{m/s}^2$；
4. 主函数读入长、宽、厚，依次调用三个函数，按格式输出体积、质量和浮力，各保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，三个实数 l、w、t，用空格分隔（单位：米），均非负。

**输出**：三行，依次为

```
V = <体积> m^3
m = <质量> kg
F = <浮力> N
```

每个结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
1.0 0.5 0.3
```
输出：
```
V = 0.1500 m^3
m = 137.5500 kg
F = 1347.9900 N
```

**样例 2**

输入：
```
2.0 1.0 0.2
```
输出：
```
V = 0.4000 m^3
m = 366.8000 kg
F = 3594.6400 N
```

## 五、提示

三个物理量的计算关系：

$$
V = l \times w \times t,\qquad m = \rho_{ice} \times V,\qquad F = m \times g
$$

**嵌套调用的含义**：`ice_buoyancy` 不自己算质量，而是"喊" `ice_mass` 来算；`ice_mass` 也不自己算体积，而是"喊" `ice_volume` 来算。这样每一层只关心自己那一步，把不属于自己的细节交给下层——这正是"分而治之"。

**完成本练习后你将具备的能力**：理解函数嵌套调用的执行顺序与调用链、掌握"每一层只做一件事"的分解方法，以及把物理公式按依赖顺序组织成函数链的能力——这是实验 C8 中"体积→质量→浮力→吃水"整条计算链的通用构造方式。
