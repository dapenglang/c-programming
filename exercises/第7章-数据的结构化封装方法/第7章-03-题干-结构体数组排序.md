# 第 7 章 练习 03　结构体数组排序

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.2 结构体数组）

**场景来源**：综合实验 C7《冰载荷样本统计与载荷辨识系统》（水声学院）——本练习是该实验中"撞击载荷样本按阻力降序排序"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

冰载荷辨识系统（实验 C7）从测量数据中整理出若干次"冰块撞击船体"事件，每次事件记录：冰块编号、该冰块质量、撞击阻力峰值（kN）。为了快速找出最危险的几次撞击，需要把样本按**阻力从大到小**排序输出。与第 5 章的普通数组排序不同：这里的每个样本是"编号 + 质量 + 阻力"三件套，交换两个样本时必须**把整个结构体整个换过去**——只换阻力值而把编号、质量留在原位，报表就会张冠李戴。这是结构体数组最典型、也最容易出错的用法。

## 二、任务要求

编写一个完整程序 `load_sort.c`：

1. 按下面的框架定义结构体类型（成员名不得改动）：

```c
struct Sample {
    int    no;      /* 冰块编号 */
    double mass;    /* 冰块质量（kg） */
    double force;   /* 撞击阻力峰值（kN） */
};
```

2. 定义长度为 10 的结构体数组（题目保证 $1 \le n \le 10$），读入 $n$ 个样本；
3. 用**冒泡排序**按 `force` 降序排列，交换时必须交换**整个结构体**；
4. 输出排序后的样本表（编号、质量、阻力），实数保留 2 位小数。

## 三、输入输出格式

**输入**：第一行一个整数 $n$（$1 \le n \le 10$）；随后 $n$ 行，每行 3 个数据：编号（整数）、质量（实数，kg）、阻力（实数，kN），以空格分隔。

**输出**：$n$ 行，每行按 `编号 质量 阻力` 输出，实数保留 2 位小数，数据以一个空格分隔，按阻力**降序**排列。

## 四、样例

**样例 1**

输入：
```
5
1 1650.60 12.5
2 440.16 8.3
3 1834.00 15.2
4 890.50 8.3
5 1210.00 10.6
```
输出：
```
3 1834.00 15.20
1 1650.60 12.50
5 1210.00 10.60
2 440.16 8.30
4 890.50 8.30
```

**样例 2**

输入：
```
3
6 500.00 9.9
7 720.50 11.2
8 300.00 9.9
```
输出：
```
7 720.50 11.20
6 500.00 9.90
8 300.00 9.90
```

## 五、提示

- 冒泡排序降序的比较条件是：若前一个的 `force` **小于**后一个的 `force`，则交换；
- 交换整个结构体：`temp = a[j]; a[j] = a[j+1]; a[j+1] = temp;`，其中 `temp` 也是 `struct Sample` 类型；
- 阻力相等的样本（如样例 1 的 2 号与 4 号）保持输入时的先后次序即可；
- 判断"交换条件"时只看 `force`，编号与质量跟着结构体一起走。

**完成本练习后你将具备的能力**：在结构体数组上做排序、理解"交换整个结构体"与"只交换排序关键字"的区别——实验 C7 的载荷排行榜、C9 的热点排序用的都是这个模式。
