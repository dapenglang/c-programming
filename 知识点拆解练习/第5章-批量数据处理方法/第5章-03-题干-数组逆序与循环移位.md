# 第 5 章 练习 03　数组逆序与循环移位

**对应章节**：5 批量数据处理方法（5.1 一维数组——下标运算与元素交换；3.3 循环结构）

**场景来源**：综合实验 B2《海洋监测信号序列预处理系统》（人工智能学院）——本练习是该实验中"信号序列反转与移位"环节的实现（同一算法也用于实验 C7 的载荷序列对齐）。

**建议用时**：30 分钟

## 一、应用场景

海洋监测仪器按时间先后记录一串信号采样值，存成数组后，下标 0 是最早的时刻。某些处理算法（如卷积、相关分析）要求序列**先反转**（新序列第 1 个是原序列最后 1 个）；另一些滑窗算法则要求序列**循环移位**（队头出队又从队尾进来）。这两种操作都不增加、不减少数据，只是**元素在数组内搬家**，是数组下标运算最经典的练习。本练习用一组整数采样值，完成逆序输出与循环左移一位两种变换。

## 二、任务要求

编写一个完整程序 `seq_transform.c`：

1. 读入数据个数 `n`（`int`，**$2 \le n \le 100$**），再读入 $n$ 个整数存入长度为 100 的 `int` 数组 `a`；
2. **不借助第二个数组**，仅用临时变量完成原数组的逆序（首尾对应元素两两交换），然后按顺序输出逆序后的 $n$ 个数；
3. 在逆序结果的基础上再做**循环左移一位**（每个元素向前挪一格，原来的第 1 个元素绕回末尾），输出移位后的 $n$ 个数；
4. 数值之间以一个空格分隔，行末不留多余空格。

## 三、输入输出格式

**输入**：第一行一个整数 $n$；第二行 $n$ 个整数，以空格分隔。

**输出**：两行，第一行为逆序后的序列，第二行为再循环左移一位后的序列；同一行内以空格分隔。

## 四、样例

**样例 1**

输入：
```
5
1 2 3 4 5
```
输出：
```
5 4 3 2 1
4 3 2 1 5
```

**样例 2**

输入：
```
8
10 -3 7 0 25 8 12 6
```
输出：
```
6 12 8 25 0 7 -3 10
12 8 25 0 7 -3 10 6
```

## 五、提示

1. 交换两个变量的标准三步：`t = a; a = b; b = t;`——直接 `a = b` 会把 `a` 的原值覆盖丢失；
2. 逆序只需交换 $\lfloor n/2 \rfloor$ 对：下标 $i$ 与下标 $n-1-i$ 的元素互换，$i$ 从 0 取到 $n/2 - 1$；
3. 循环左移一位：先把 `a[0]` 临时存起来，再用一个循环把 `a[1]` 移到 `a[0]`、`a[2]` 移到 `a[1]`、……、`a[n-1]` 移到 `a[n-2]`，最后把临时值放回 `a[n-1]`；
4. 移位循环的方向不能反：若从前往后 `a[i] = a[i+1]` 逐个执行是安全的（先读后写），反过来从后往前会把数据冲掉；
5. 输出空格处理：每个数后面都跟一个空格的写法行末会多一个空格，可用"先输出第一个，再循环输出 `空格+数`"的方式。

**完成本练习后你将具备的能力**：借临时变量交换数组元素、用对称下标 $i$ 与 $n-1-i$ 设计循环、按正确方向搬移数组元素——这三项是排序算法（练习 06、07）与有序表维护（练习 10）的直接基础。
