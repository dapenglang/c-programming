# 第 8 章 练习 38　测点记录结构体文件存取

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：8 文件（8.1 文件的打开与关闭、8.2 文件的读写——fprintf/fscanf、8.3 格式化读写、8.4 错误处理）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"结果文件存取（文本读写）"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

水声实验数据管理系统的核心数据是**测点记录**：一次观测由"测点号、测点深度、声速"三个字段共同描述，拆成三个零散变量管理会很乱，工程上用**结构体**把它们捆在一起。而管理系统要"关机不丢数据"，就必须把结构体记录**写进文件**；下次开机，再从文件**读回**内存继续处理。

综合实验 C10 的 M1（测点记录结构体定义）+ M9（结果文件存取）合起来就是这件事：**键盘录入 → 写文件 → 从文件读回 → 屏幕报表**。本题模拟这个"存了再取"的完整闭环。

## 二、任务要求

编写一个完整程序 `station_io.c`：

1. 定义结构体：
   ```c
   struct Record {
       int    id;       /* 测点号 */
       double depth;    /* 测点深度 (m) */
       double speed;    /* 声速 (m/s) */
   };
   ```
2. 从键盘读入测点数 `n`（**题目保证 1 ≤ n ≤ 50**），随后读入 `n` 条记录存入结构体数组 `rec[50]`；
3. 以**写入**方式打开文件 `station.txt`；若打开失败，打印提示并返回；把 `n` 条记录按"每行一条"写入文件，字段顺序为 `id depth speed`，以空格分隔，深度保留 2 位小数、声速保留 1 位小数；关闭文件；
4. 再以**只读**方式重新打开 `station.txt`，把记录**逐条读回**另一个结构体数组 `back[50]`；若打开失败，打印提示并返回；关闭文件；
5. 在屏幕上输出读回的记录报表与全部测点的**平均声速**（保留 2 位小数），验证"写出去又读回来，数据没有变"。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 行，每行依次为 `测点号 深度 声速`（空格分隔）。

**输出文件 `station.txt`**：共 n 行，每行 `id depth speed`（空格分隔，深度 2 位小数、声速 1 位小数）。

**屏幕输出**：n 行报表，每行格式 `测点号 深度 声速`（格式同文件），最后输出一行 `平均声速: xx.xx`。

## 四、样例

**样例 1**

输入：
```
3
1 10.0 1500.2
2 25.5 1502.8
3 40.0 1505.1
```
运行后 `station.txt` 内容：
```
1 10.00 1500.2
2 25.50 1502.8
3 40.00 1505.1
```
屏幕输出：
```
1 10.00 1500.2
2 25.50 1502.8
3 40.00 1505.1
平均声速: 1502.70
```

**样例 2**

输入：
```
2
7 100.0 1498.5
8 120.0 1497.9
```
运行后 `station.txt` 内容：
```
7 100.00 1498.5
8 120.00 1497.9
```
屏幕输出：
```
7 100.00 1498.5
8 120.00 1497.9
平均声速: 1498.20
```

## 五、提示

- 结构体成员的访问用点运算符：`rec[i].id`、`rec[i].depth`、`rec[i].speed`；
- 写结构体数组到文件，就是**循环里对每个成员逐个 `fprintf`**——结构体不能整体 `fprintf`，要一个字段一个字段写：
  ```c
  fprintf(fp, "%d %.2f %.1f\n", rec[i].id, rec[i].depth, rec[i].speed);
  ```
- 读回用 `fscanf`，**格式串要与写入时一致**（`"%d %lf %lf"`），按成员逐个读：
  ```c
  fscanf(fp, "%d %lf %lf", &back[i].id, &back[i].depth, &back[i].speed);
  ```
  注意 `&` 不能少——`fscanf` 需要的是成员的**地址**；
- "读回 n 条"有两种写法：先把 `n` 也写进文件再第一个读回；或利用 `fscanf` 的返回值读到末尾。本题选前者更直观，**文件第一个数写 n**；
- 两次打开同一个文件，**第一次 `fclose` 之后才能再用 `"r"` 打开**——同一个文件同时只持有一个 `FILE *`，写完不关就读，会读到旧缓冲甚至失败；
- **务必检查两次 `fopen` 的返回值**——写失败和读失败都要兜住；
- 平均声速 = 各测点声速之和 ÷ 测点数（用 LaTeX 表示即 $\bar{v} = \frac{1}{n}\sum v_i$）。

**完成本练习后你将具备的能力**：定义并用结构体数组组织记录、把结构体成员逐字段写成文本文件、把文件逐字段读回结构体、验证"存取闭环"数据一致——这些是实验 C10 中"结果文件存取模块"的地基。
