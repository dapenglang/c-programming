# 第 2 章 练习 25　屏蔽透射率与厚度指数关系计算

**所属综合实验**：D6（D6-基于蒙特卡洛模拟的射线屏蔽透射率计算系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——指数与幂运算）

**场景来源**：综合实验 D6《基于蒙特卡洛模拟的射线屏蔽透射率计算系统》（核学院）——本练习是该实验中"窄束条件下透射率理论值计算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

在辐射防护设计中，判断一块屏蔽板能不能把 γ 射线削弱到安全水平，靠的是**窄束指数衰减律**：

$$
\frac{I}{I_0} = e^{-\mu x}
$$

其中 $\mu$ 是材料的**线衰减系数**（单位 1/cm，与射线能量和材料有关），$x$ 是屏蔽板厚度（单位 cm），比值 $I/I_0$ 称为**透射率**（无量纲，取值 0～1）。透射率越小，说明屏蔽效果越好。

例如铅对某能量的 γ 射线，$\mu = 0.78\ \text{cm}^{-1}$。一块 2 cm 厚的铅板能把射线削弱多少？这个问题在屏蔽设计里每天都要算无数次。综合实验 D6 用蒙特卡洛方法模拟光子穿透，算出的透射率要拿本练习的理论公式对照验证——所以这是整个 D6 的第一块地基。

## 二、任务要求

编写一个完整程序 `shielding_trans.c`：

1. 程序中用**常量**存放线衰减系数 $\mu$（取铅的 0.78，单位 1/cm）；
2. 从键盘读入铅板厚度 `x`（单位 cm，double 类型，**题目保证 0 ≤ x ≤ 10**，本程序不需要判断分支）；
3. 用指数衰减公式计算透射率 `T`；
4. 按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示铅板厚度 x（厘米）。

**输出**：一行，按格式 `T = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2
```
输出：
```
T = 0.2101
```

**样例 2**

输入：
```
0.9
```
输出：
```
T = 0.4956
```

## 五、提示

指数衰减律：透射率等于"$e$ 的 $-\mu x$ 次方"。

$$
T = e^{-\mu x}
$$

在 C 语言里 $e^{y}$ 由数学库函数 `exp(y)` 计算，因此本式写成一个调用：

```c
T = exp(-mu * x);
```

注意：`exp` 属于数学库，程序开头要 `#include <math.h>`。想验证公式是否写对，可以算两个特殊点：厚度 $x = 0$ 时应有 $T = e^0 = 1$（不挡不透射全部通过）；厚度很大时 $T$ 应趋近于 0。

此外，把 $T = 0.5$ 反解出的厚度叫**半值层厚度** $x_{1/2} = \ln 2 / \mu$，本题不要求计算，但它是 D6 综合实验的重要指标。
