# 第 5 章 练习 15　字符串复制连接与比较

**对应章节**：5 批量数据处理方法（5.3 字符数组、5.4 数组作函数参数；3.2 选择结构；3.3 循环结构）

**场景来源**：综合实验 B10《文本相似度分析系统》（人工智能学院）——本练习是该实验中"词条长度测量、样本名拼接与字典序比较"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

文本相似度系统在正式比对之前，要做一连串**字符串基础操作**：量出每个词条有多长、把"样本前缀 + 序号后缀"拼成一个完整的样本名、按字典序判断两个词条谁在前谁在后。这些操作标准库里有现成函数，但为了真正理解"字符串是以 `'\0'` 结尾的字符数组"，本练习要求你**亲手实现**这四件工具：求长度、复制、连接、比较。它们全部把字符数组作为函数参数——这正是"数组作函数参数"的第一次实战。

## 二、任务要求

编写一个完整程序 `string_ops.c`，**不使用** `<string.h>` 中的 `strlen` / `strcpy` / `strcat` / `strcmp`，改为自己实现以下四个函数：

1. `int mystrlen(char s[])`——返回字符串长度（不含 `'\0'`）；
2. `void mystrcpy(char d[], char s[])`——把 `s` 复制到 `d`（连同结尾的 `'\0'`）；
3. `void mystrcat(char d[], char s[])`——把 `s` 接到 `d` 的末尾（覆盖 `d` 原来的 `'\0'`）；
4. `int mystrcmp(char a[], char b[])`——按字典序比较：若 `a > b` 返回 `1`，`a < b` 返回 `-1`，完全相等返回 `0`。

在主函数中：

5. 读入两个不含空格的词条 `s1`、`s2`（每个长度不超过 50），先输出它们的长度，再把 `s1` 与 `s2` **连接**后输出，最后输出 `s1` 与 `s2` 的比较结果。

## 三、输入输出格式

**输入**：两行，每行一个不含空格的字符串（长度 1 ～ 50）。

**输出**：共 3 行：

```
长度: 长度1 长度2
连接: s1与s2连接后的字符串
比较: 比较结果（1 / 0 / -1）
```

各数值为整数或字符串，按上面的字面格式输出。

## 四、样例

**样例 1**

输入：
```
ice
ship
```
输出：
```
长度: 3 4
连接: iceship
比较: -1
```

**样例 2**

输入：
```
load
ice
```
输出：
```
长度: 4 3
连接: loadice
比较: 1
```

## 五、提示

1. **求长度**：设下标 `i` 从 0 开始，只要 `s[i] != '\0'` 就 `i++`，循环结束时 `i` 就是长度；
2. **复制**：把 `s[i]` 逐个赋给 `d[i]`，赋值表达式本身有值，可边赋值边判断是否已到 `'\0'`：`while ((d[i] = s[i]) != '\0') i++;`；
3. **连接**：连接点不是 `d` 的开头，而是 `d` 的**末尾**（`d` 的 `'\0'` 处）。先求出这个位置，再从那里把 `s` 的字符接上去；连接后仍以 `'\0'` 结尾，并满足 $\text{len}(d) + \text{len}(s) \le \text{容量} - 1$；
4. **比较**：从前往后逐个比，**遇到第一个不同字符就分出胜负**；比到 `'\0'` 仍相同则相等。返回 $a>b$ 时 `1`、$a=b$ 时 `0`、$a<b$ 时 `-1`。

**完成本练习后你将具备的能力**：把数组作为函数参数进行"读"与"写"两种操作、手写四大字符串工具、用赋值表达式的返回值简化循环——这是实验 B10 中"词条预处理模块"的完整实现。
