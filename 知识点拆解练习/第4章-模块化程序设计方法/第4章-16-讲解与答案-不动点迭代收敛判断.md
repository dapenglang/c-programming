## 二、预备知识：不动点迭代的基本原理（零基础阅读）

### 1. 问题是怎么来的

有些方程天然能写成"$x$ 等于一个含 $x$ 的表达式"的形式，例如本题 $c = 0.6+0.3c^2$。这种形式的好处是：**右边给了左边一个新值**。于是可以这样想——先随便猜一个 $c$，代入右边算出一个"更好的" $c$，再代回去……如果这一串数越来越稳定，最后就停在真正的解上。这个"代来代去"的过程就是**不动点迭代**。所谓"不动点"，就是指满足 $x = g(x)$ 的那个值（代入后不再变化）。

### 2. 公式与收敛条件

迭代公式非常朴素：

$$
c_{n+1} = g(c_n), \qquad g(c) = 0.6 + 0.3c^2 .
$$

但它**不是总收敛**。判断标准来自微分中值定理：把误差 $e_n = c_n - c^\*$ 代入，利用 $g(c^\*)=c^\*$ 可得

$$
e_{n+1} = g(c_n) - g(c^\*) \approx g'(c^\*)\,e_n .
$$

也就是说，每一步误差会被乘以约 $\lvert g'(c^\*)\rvert$。于是结论很直观：

$$
\lvert g'(c^\*)\rvert < 1 \;\Rightarrow\; \text{误差不断缩小，迭代收敛};\qquad
\lvert g'(c^\*)\rvert > 1 \;\Rightarrow\; \text{误差被放大，迭代发散}.
$$

本题 $g'(c) = 0.6c$，解附近 $c^\*\approx0.7847$，故 $\lvert g'(c^\*)\rvert\approx0.471<1$，**收敛**。

### 3. 代入本例手算

从 $c_0 = 0.5$ 出发，反复代入 $c_1 = 0.6+0.3c_0^2$：

- $c_1 = 0.6+0.3\times0.25 = 0.675000$；
- $c_2 = 0.6+0.3\times0.675^2 = 0.736687$；
- $c_3 = 0.6+0.3\times0.736687^2 = 0.762813$；
- … 逐次逼近，$c_{10}=0.784640$、$c_{17}=0.784749$。

第 17 次时 $\lvert c_{17}-c_{16}\rvert\approx6.3\times10^{-7}<10^{-6}$，停止。真解也可由一元二次方程求得：$0.3c^2-c+0.6=0$，取 $0<c<1$ 的根 $c^\* = \dfrac{1-\sqrt{0.28}}{0.6}\approx0.784750$——与迭代结果一致，说明方法正确。

### 4. 编程实现要点

- **初值**：只要求在收敛域内；本题从 $(0,1)$ 内任意值出发都能收敛，初值越靠近解，迭代次数越少；
- **迭代公式**：`c1 = g(c);`，再用 `fabs(c1 - c) < eps` 判断；
- **不要忘了更新**：未收敛时必须 `c = c1;`，否则每轮都用同一个旧值，陷入死循环；
- **收敛速度**：不动点迭代是**线性收敛**（每步误差按固定倍数缩小），比牛顿法慢，所以本题要迭代十几次；这是它和牛顿法最重要的区别。

## 三、解题思路

1. **写 `g`**：把迭代函数单独封装，便于修改与阅读；
2. **写 `fixed_point`**：用循环反复赋值 `c1 = g(c)`，用 `fabs(c1-c) < eps` 判断收敛，同时用 `k` 计数；
3. **输出与返回**：循环结束后打印 `c = ..., n = ...` 并返回解；
4. **`main`**：只读一个初值并调用一次。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>

/* 迭代函数 g(c) = 0.6 + 0.3*c^2 */
double g(double c)
{
    return 0.6 + 0.3 * c * c;
}

/* 不动点迭代求 g(c)=c 的解，并输出迭代次数 */
double fixed_point(double c0, double eps)
{
    double c = c0, c1;
    int k = 0;

    do {
        c1 = g(c);                   /* 一次迭代 */
        k++;
        if (fabs(c1 - c) < eps)      /* 收敛判据 */
            break;
        c = c1;                      /* 未收敛则继续 */
    } while (k < 1000);              /* 安全上限 */

    printf("c = %.6f, n = %d\n", c1, k);
    return c1;
}

int main(void)
{
    double c0;

    scanf("%lf", &c0);
    fixed_point(c0, 1e-6);
    return 0;
}
```

## 五、运行验证

以 $c_0 = 0.5$ 为例，迭代中间值（保留 6 位小数）如下：

| 迭代 $n$ | $c_n$ | $\lvert c_n-c_{n-1}\rvert$ | 状态 |
|---|---|---|---|
| 1 | 0.675000 | 0.175000 | 继续 |
| 2 | 0.736687 | 0.061687 | 继续 |
| 3 | 0.762813 | 0.026126 | 继续 |
| 5 | 0.779985 | 0.005420 | 继续 |
| 10 | 0.784640 | 0.000123 | 继续 |
| 17 | 0.784749 | 0.00000063 | 收敛，停止 |

程序输出 `c = 0.784749, n = 17`。改取 $c_0 = 0.7$，起点更靠近真解，只需 16 次即收敛，输出 `c = 0.784749, n = 16`。两者结果相同、次数不同，体现了"初值只影响速度、不影响收敛结果"。

## 六、常见错误与讲解

**错误 1：忘记更新迭代变量**

```c
do {
    c1 = g(c);
    if (fabs(c1 - c) < eps) break;
} while (1);                 /* 错：没有 c = c1，永远算同一个值 */
```

**错误 2：收敛判据写成 $g(c)=c$ 的精确比较**

```c
if (g(c) == c) break;        /* 错：浮点数几乎不可能精确相等 */
if (fabs(c1 - c) < eps) break;  /* 对：用相邻两次之差 */
```

**错误 3：忽略收敛条件，强行迭代发散函数**

如果改为 $c = 2.0 + 0.9c^2$ 这类 $\lvert g'(c^\*)\rvert>1$ 的方程，迭代会越跑越远。**动手前先估一下 $\lvert g'(c^\*)\rvert$**，是使用迭代法的好习惯。

**错误 4：把 `%lf`、`%d`、`%f` 用错**

```c
printf("c = %d, n = %f\n", c1, k);   /* 错：类型全反了 */
printf("c = %.6f, n = %d\n", c1, k); /* 对 */
```

## 七、与综合实验的衔接

实验 **C10（碎冰场覆盖率与浓度分析）**中，覆盖率、浓度等状态量常用"自洽平衡关系"描述，天然是不动点方程。相比牛顿法，不动点迭代的好处是**只需写出 $x=g(x)$、无需求导**，实现门槛低；代价是收敛慢，且必须先确认 $\lvert g'(x^\*)\rvert<1$。工程上两种方法常配合使用：先不动点迭代粗算，再用牛顿法精修。下一题（17）将学习第三种求解思路——**二分法**，它虽慢但极其稳健，只要区间两端函数值异号就一定收敛。
