# 第 3 章 练习 03　冰区航行状态判定（多条件逻辑）

**对应章节**：3 结构化程序设计方法（3.2 选择结构——if/else if/else 链、3.4 关系运算符与逻辑运算符）

**场景来源**：综合实验 C6《冰块与结构碰撞模拟系统》/ C10《碎冰场分布统计系统》（水声学院）——本练习是该实验中"海冰工况等级划分"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

船舶在冬季高纬海域航行，能否安全通过一片海区，主要取决于两个因素：**海冰厚度**（决定船体能否直接压过）和**冰浓度**（海面上冰的覆盖比例，%）。船级社的冰区航行规程据此划分航行状态等级：0 级可自由航行，1 级需保持瞭望，2 级需降速航行，3 级必须请求破冰船引航。值班驾驶员输入航海雷达测得的冰厚与冰浓度后，系统必须立刻给出等级结论——判错等级可能导致船体受损。这个"双因素、分等级"的判定逻辑，就是实验 C6/C10 中海冰工况模块的核心。

## 二、任务要求

编写一个完整程序 `ice_level.c`：

1. 从键盘读入两个数：冰厚 `t`（米）与冰浓度 `c`（%，0～100 的实数），均为 `double` 类型；
2. 按**下表**判定航行状态等级（判定时冰厚条件与冰浓度条件是"或"的关系，任一达标即取该等级）：

| 等级 | 判定条件（满足其一） | 含义 |
|---|---|---|
| 3 | $t \ge 0.5$ 或 $c \ge 80$ | 破冰船引航 |
| 2 | $t \ge 0.3$ 或 $c \ge 60$ | 降速航行 |
| 1 | $t \ge 0.15$ 或 $c \ge 30$ | 保持瞭望 |
| 0 | 以上条件均不满足 | 自由航行 |

3. 等级判定从 3 级往下依次进行：只要 3 级条件满足就直接定 3 级，**不再考虑更低等级**；
4. 按格式输出等级编号。

## 三、输入输出格式

**输入**：一行，两个实数 t、c，以空格分隔（单位：米、%）。

**输出**：一行，按格式 `level = 等级编号` 输出，编号为 0～3 的整数。

## 四、样例

**样例 1**

输入：
```
0.4 50
```
输出：
```
level = 2
```
（冰厚 0.4 ≥ 0.3 达到 2 级线，但不满足 3 级的 0.5；浓度 50 介于 30 与 60 之间）

**样例 2**

输入：
```
0.1 85
```
输出：
```
level = 3
```
（冰厚虽只有 0.1 米，但浓度 85 ≥ 80，两个条件满足其一即定 3 级）

## 五、提示

判定 3 级的条件是"冰厚达标**或**浓度达标"，用逻辑或写成

```c
t >= 0.5 || c >= 80.0
```

if-else 链从最严格的等级开始往下写，命中即输出——链条的顺序就是等级的高低次序，写反了低等级会抢在高等级之前命中。

**完成本练习后你将具备的能力**：用 `||` 组合双因素判据、按从高到低的次序组织 if-else 链、把工程规程表格逐行翻译成分支条件——这是实验 C6/C10 中海冰工况分级模块的完整逻辑。
