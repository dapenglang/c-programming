## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

练习 01 讲过一个事实：**程序运行时存放在内存里的变量，程序一结束就全部消失**。反过来，有些数据我们希望它在**程序还没运行时就存在**，运行开始后直接取用——模型参数正是如此。海冰密度 917 kg/m³ 这样的值来自实验测定，是"已知输入"，不是程序算出来的。把它放进磁盘文件，程序每次启动读一遍，就能做到"参数改了、程序不改"。这就是文件持久化在"输入方向"上的价值：**文件让数据先于程序存在、长于程序存在。**

### 2. 文件操作的标准四步曲

C 语言操作文件，无论读写都遵循同一条流水线：

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：本题用 `fscanf` 读；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 你把它理解为"这次文件访问的编号牌"即可。把文件名交给操作系统后，系统建立一套记录——文件放在哪、当前读到哪、是读还是写——`fopen` 返回的指针就指向这套记录。之后每一个读写函数都靠这个牌子找到文件。那块记录里有一个**文件位置指针**，记录"现在读到第几个字节"，每读一点它自动往后推。

**打开失败会怎样？** 如果文件不存在、路径不对、没有读权限，`fopen` 返回 `NULL`。不对它判断就用，程序会崩溃。所以打开后**必须**紧跟判空：

```c
fp = fopen("model_params.txt", "r");
if (fp == NULL) { printf("打不开参数文件\n"); return 1; }
```

### 3. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fscanf` | 按格式读 | `fscanf(fp, "%s%lf", name, &v);` | 从文本里按格式读数字/单词 |
| `fprintf` | 按格式写 | `fprintf(fp, "%d %.2f\n", id, v);` | 把数字按人可读格式写进文本 |
| `fgets` | 读一整行 | `fgets(buf, sizeof(buf), fp);` | 一行里有字符串、需要整行处理 |
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理（词频统计） |
| `fread`/`fwrite` | 按字节块读写 | `fread(a, sizeof(double), n, fp);` | 二进制文件、批量存数组 |

本题的文件是"参数名 + 数值"的文本，按格式读最方便，故选 **`fscanf`**。它和键盘上的 `scanf` 用法完全一样，只是第一个参数多了文件指针：`scanf("%s%lf", name, &v)` 对应 `fscanf(fp, "%s%lf", name, &v)`。

### 4. 打开模式的区别

| 模式 | 含义 | 文件已存在时 |
|---|---|---|
| `"r"` | 只读文本 | 从文件头开始读，不存在则失败 |
| `"w"` | 只写文本 | **清空原有内容**，从头开始写 |
| `"a"` | 追加文本 | 保留原有内容，从末尾接着写 |
| `"rb"`/`"wb"` | 二进制只读/只写 | 同上，但按二进制方式处理 |

本题只是"读参数"，绝不能改坏参数文件，所以用 `"r"`。特别提醒：**读文件用 `"w"` 会把参数文件清空**，这是很危险的错误。

### 5. 用本题的数据走一遍文件指针

参数文件前两行是：

```
rho 917.0
E 8.5e9
```

打开后文件位置指针在开头。第一条 `fscanf(fp, "%s%lf", name, &rho)`：先读 `rho` 四个字符进 `name`（顺带跳过它们后面的空格），再把 `917.0` 读进 `rho` 变量，此时位置指针已推到第一行末尾之前。第二条 `fscanf(fp, "%s%lf", name, &E)`：`%s` 会**自动跳过前面的空白（空格和换行）**，读入 `E`，再把 `8.5e9` 按科学计数法读进 `E`，指针推到第二行末尾。第三条同理读入 `e` 与 `0.35`。三行读完后指针停在文件末尾——正好可以 `fclose`。

要点：`%s` 和 `%lf` 都会**自动跳过前导空白**，所以文件里用空格还是换行分隔都不影响读取，这也是 `fscanf` 比 `fgets` 省心的原因之一。

## 三、解题思路

1. **打开**：`fp = fopen("model_params.txt", "r")`，判空；
2. **读三个参数**：三次 `fscanf(fp, "%s%lf", name, &值)`，依次读 `rho`、`E`、`e`；
3. **立即关闭**：参数已全部读进变量，`fclose(fp)`；
4. **计算质量**：`mass = rho * 2.5;`；
5. **输出**：按 `%.3f`、`%.2e`、`%.3f`、`%.2f` 打印四行。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;                     /* 参数文件指针 */
    char  name[20];               /* 用来接收参数名（本题只借它跳过名字） */
    double rho, E, e;             /* 三个模型参数 */
    double mass;                  /* 待求的冰块质量 */

    /* 以只读方式打开参数文件 */
    fp = fopen("model_params.txt", "r");
    if (fp == NULL) {             /* 打开失败必须处理 */
        printf("无法打开参数文件 model_params.txt\n");
        return 1;
    }

    /* 依次读入三行参数：每一行是 "参数名 参数值" */
    fscanf(fp, "%s%lf", name, &rho);   /* 读 rho */
    fscanf(fp, "%s%lf", name, &E);     /* 读 E   */
    fscanf(fp, "%s%lf", name, &e);     /* 读 e   */

    fclose(fp);                   /* 参数已读入，及时关闭 */

    /* 用读到的密度计算体积 2.5 m^3 冰块的质量 m = rho * V */
    mass = rho * 2.5;

    /* 输出参数与计算结果 */
    printf("rho = %.3f\n", rho);
    printf("E   = %.2e\n", E);
    printf("e   = %.3f\n", e);
    printf("冰块质量（V = 2.5 m^3）= %.2f kg\n", mass);

    return 0;
}
```

## 五、运行验证

**样例 1：运行前** `model_params.txt` 内容：
```
rho 917.0
E 8.5e9
e 0.35
```
程序读取文件后屏幕输出：
```
rho = 917.000
E   = 8.50e+09
e   = 0.350
冰块质量（V = 2.5 m^3）= 2292.50 kg
```
逐项核对：`rho` 读入 917.0，`%.3f` 输出 `917.000`；`E` 读入 8.5e9，`%.2e` 输出 `8.50e+09`；`e` 读入 0.35，`%.3f` 输出 `0.350`；质量 $= 917.0 \times 2.5 = 2292.5$，输出 `2292.50 kg`。文件内容不变（用的是 `"r"`，不写回）。

**样例 2：运行前** `model_params.txt` 内容：
```
rho 930.0
E 9.0e9
e 0.40
```
屏幕输出：
```
rho = 930.000
E   = 9.00e+09
e   = 0.400
冰块质量（V = 2.5 m^3）= 2325.00 kg
```
质量 $= 930.0 \times 2.5 = 2325.0$，与输出一致。两次结果只随文件内容变化、程序代码不变，正说明参数已成功"数据与代码分离"。

## 六、常见错误与讲解

**错误 1：`fopen` 之后不判 `NULL`**

```c
fp = fopen("model_params.txt", "r");
fscanf(fp, "%s%lf", name, &rho);   /* 错：文件不存在时 fp 为 NULL，直接崩溃 */
```
文件名哪怕只差一个字母都会打不开。判空是读文件前**雷打不动的第一步**。

**错误 2：读文件误用了 `"w"` 模式**

```c
fp = fopen("model_params.txt", "w");   /* 致命错误：参数文件被瞬间清空 */
```
`"w"` 会先清空文件。本题是"只读"，必须用 `"r"`。一旦误用，参数文件会变成空文件，后续读到的都是垃圾值。

**错误 3：`fscanf` 的 `%lf` 写成了 `%f`**

```c
float rho; fscanf(fp, "%s%lf", name, &rho);   /* 类型混用，可能读到错值 */
double rho; fscanf(fp, "%s%lf", name, &rho);  /* 对：double 配 %lf */
```
`scanf` 系列里 `double` 要用 `%lf`，`float` 才用 `%f`。本题统一用 `double`，格式串统一用 `%lf`。另外，三个参数要逐行读全再打印，漏读一行不仅少数据，还会让后面的读取整体错位。

## 七、与综合实验的衔接

实验 C6 的仿真内核启动时，第一件事就是从参数文件载入密度、弹性模量、恢复系数等设定；改变工况时只需换一个参数文件，程序无需重新编译，这正是工程软件"可配置"的基本要求。实验 A1 的风荷载计算、C1 的声速剖面查算，也都可以把规范表或系数表放进数据文件，实现算法与数据分离。本练习只做了"读参数"这一半；练习 03 会把"读数据—处理—写数据"完整地串成一条流水线。当参数与数据量大到需要结构化查询、多用户并发时，文件就不够了，第 8 章 8.7 节的数据库技术提供了更系统的持久化方案。
