# 第 2 章 练习 13　测点压力单位换算

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 C9《基于二维网格统计的冰压力场分析与可视化系统》（水声学院）——本练习是该实验中"测点压力双单位输出"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

在冰压力场实验中，压力传感器把采集到的压力值统一以 **kPa（千帕）** 上传；但工程报告和规范里，高压段常用 **MPa（兆帕）** 表示。同一个冰压力，例如某测点 2450 kPa，写成 MPa 就是 2.450 MPa。为了让不同单位和习惯的使用者都能读懂数据，程序需要**同时输出两种单位**的数值。

综合实验 C9 处理的是成百上千个测点，每个测点都要做这个换算；本练习把"读入一个 kPa 值、输出 kPa 与 MPa 两种单位"这一最小步骤抽出来单独实现，同时借它体会一句重要纪律：**物理量必须选对数据类型**，否则形如 38000 这样的值一旦用错类型就会出问题。

## 二、任务要求

编写一个完整程序 `pressure_convert.c`：

1. 从键盘读入一个测点压力 `p`（单位：kPa，`double` 类型）；
2. 依据换算关系 $1\ \mathrm{MPa} = 1000\ \mathrm{kPa}$，把该压力换算为 MPa；
3. 按两行输出，第一行给 kPa 值（保留 2 位小数），第二行给 MPa 值（保留 4 位小数）。

## 三、输入输出格式

**输入**：一行，一个实数，表示测点压力 p（kPa）。

**输出**：两行，第一行按 `p = 结果 kPa` 格式（保留 2 位小数），第二行按 `p = 结果 MPa` 格式（保留 4 位小数）。

## 四、样例

**样例 1**

输入：
```
2450
```
输出：
```
p = 2450.00 kPa
p = 2.4500 MPa
```

**样例 2**

输入：
```
38000
```
输出：
```
p = 38000.00 kPa
p = 38.0000 MPa
```

## 五、提示

换算关系为：

$$
p_{\mathrm{MPa}} = \dfrac{p_{\mathrm{kPa}}}{1000}
$$

注意除数一定要写成 `1000.0` 而不能写成 `1000`，同时被除数是 `double`——这样才能保证做的是**实数除法**而不是整数除法。

**完成本练习后你将具备的能力**：根据数值范围与精度需求选择合适的数据类型、用 `const` 表达固定换算系数、区分整数除法与实数除法、把同一数据用多种单位格式化输出——这些是压力场实验"数据规范化输出"的基础操作。
