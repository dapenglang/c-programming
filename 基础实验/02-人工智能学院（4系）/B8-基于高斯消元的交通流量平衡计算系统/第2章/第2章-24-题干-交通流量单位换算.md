# 第 2 章 练习 24　交通流量单位换算

**所属综合实验**：B8（B8-基于高斯消元的交通流量平衡计算系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出）

**场景来源**：综合实验 B8《基于高斯消元的交通流量平衡计算系统》（人工智能学院）——本练习是该实验中"流量数据单位统一"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

交通流量平衡系统要在每个路口列出"流入 = 流出"的方程，方程里的系数就是各条道路的流量。可不同来源的流量数据单位常常不一致：

- 交通调查报告里写的是**辆/小时**（车流量，数值大，如 1800）；
- 单次通行、单车道控制时用的是**辆/分钟**（数值小，如 30）。

要把它们放进同一个方程组，必须先**统一单位**。B8 系统在建立系数矩阵之前，就要把所有流量都换算成同一种单位（本题统一成辆/分钟）。

## 二、任务要求

编写一个完整程序 `flow_unit.c`：

1. 程序中用**常量**存放每小时的分钟数 60.0；
2. 从键盘读入一个以"辆/小时"为单位的流量 `qph`（double 类型）；
3. 用公式 $q_{pm} = q_{ph} / 60$ 换算成"辆/分钟"；
4. 按规定格式输出换算前后两个流量，均保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示流量（辆/小时）。

**输出**：一行，按格式 `qph = 结果辆/h, qpm = 结果辆/min` 输出，两个结果均保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
1800
```
输出：
```
qph = 1800.00辆/h, qpm = 30.00辆/min
```

**样例 2**

输入：
```
900
```
输出：
```
qph = 900.00辆/h, qpm = 15.00辆/min
```

## 五、提示

小时与分钟之间的换算是 $1$ 小时 $= 60$ 分钟，所以"每小时多少辆"除以 60 就是"每分钟多少辆"：

$$
q_{pm} = \frac{q_{ph}}{60}
$$

写成代码时把分母写作 `60.0`，保证按实数除法计算；若写成整数 `60`，结果会被截断。本题流量以实数读入，用 `double` 存放。

**完成本练习后你将具备的能力**：理解时间单位的换算关系、正确书写带除法的算式、用 scanf/printf 完成实数输入输出并控制小数位数——这些是实验 B8 中"流量数据模块"的地基。
