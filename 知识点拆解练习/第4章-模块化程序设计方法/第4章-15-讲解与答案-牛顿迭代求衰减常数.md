## 二、预备知识：用牛顿法反解衰减常数的原理（零基础阅读）

### 1. 问题是怎么来的

核素活度按指数规律衰减，探测器在一段时间里录到的**总计数**等于活度对时间的积分。已知 $A_0$、$T$、$C$ 要反求 $\lambda$，就得解一个含 $e^{-\lambda T}$ 的方程。这类"指数套在外面"的方程叫**超越方程**，没有代数求根公式，只能数值逼近——这正是牛顿法的用武之地。

### 2. 公式是怎么推出来的

从计数公式出发：

$$
C = \frac{A_0}{\lambda}\bigl(1-e^{-\lambda T}\bigr)
\;\Longrightarrow\;
\lambda C = A_0\bigl(1-e^{-\lambda T}\bigr)
\;\Longrightarrow\;
f(\lambda) = A_0\bigl(1-e^{-\lambda T}\bigr) - C\lambda = 0 .
$$

求导（把 $A_0,T,C$ 当常数，$\lambda$ 当自变量）：

$$
f'(\lambda) = A_0\cdot\bigl(-e^{-\lambda T}\bigr)\cdot(-T) - C
            = A_0 T\,e^{-\lambda T} - C .
$$

注意 $e^{-\lambda T}$ 对 $\lambda$ 求导用链式法则，得到 $-T e^{-\lambda T}$，负号与括号前的负号相乘变正。于是牛顿迭代式为

$$
\lambda_{n+1} = \lambda_n - \frac{A_0(1-e^{-\lambda_n T}) - C\lambda_n}{A_0 T\,e^{-\lambda_n T} - C}.
$$

### 3. 代入本例手算

取 $A_0=1000$、$T=30$、$C=20000$，初值 $\lambda_0 = 0.03$：

- 第 1 次：$e^{-30\times0.03}=e^{-0.9}=0.406570$，$f = 1000\times0.593430 - 20000\times0.03 = 593.430-600 = -6.570$；$f' = 1000\times30\times0.406570-20000 = -7802.9$；$\lambda_1 = 0.03 - \dfrac{-6.570}{-7802.9} = 0.029158$；
- 第 2 次：$e^{-0.874740}\approx0.416970$，$f \approx 583.030-583.160 = -0.130$，$f' \approx -7490.9$，$\lambda_2 = 0.029158 - 0.0000174 = 0.029141$；
- 第 3 次：$\lambda_3 \approx 0.029141$，与上次之差已小于 $10^{-6}$，停止。

反解得 $\lambda \approx 0.029141\ \text{天}^{-1}$。若换算成半衰期：$T_{1/2} = \dfrac{\ln 2}{\lambda} \approx \dfrac{0.6931}{0.029141}\approx 23.79$ 天。

### 4. 编程实现要点

- **参数传递**：$A_0,T,C$ 三个物理量贯穿整个求解，最清楚的做法是把它们作为形参逐层传下去，而不是用全局变量；
- **初值**：由 $C/A_0 \approx T$（当 $\lambda T$ 不大时）可粗估 $\lambda \sim 1/T$，本题 $1/T\approx0.033$，取 0.03 很快收敛；
- **终止判据**：仍用 $|\lambda_{n+1}-\lambda_n|<\text{eps}$，取 $\text{eps}=10^{-6}$；
- **导数除零风险**：本题 $f'(\lambda)$ 恒为负且远离 0，不必担心除零。

## 三、解题思路

1. **建模**：把积分形式的计数公式化为 $f(\lambda)=A_0(1-e^{-\lambda T})-C\lambda$，并求出导函数；
2. **封装**：`f` 与 `df` 都接收 `(L, A0, T, C)` 四个参数，保持"纯函数"风格；
3. **迭代器**：`newton` 循环套用迭代公式并打印中间值，收敛后返回；
4. **主控**：`main` 读三个数、调用一次、打印结果。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>   /* exp, fabs */

/* 目标方程 f(L) = A0*(1 - exp(-L*T)) - C*L = 0 */
double f(double L, double A0, double T, double C)
{
    return A0 * (1.0 - exp(-L * T)) - C * L;
}

/* 导函数 f'(L) = A0*T*exp(-L*T) - C */
double df(double L, double A0, double T, double C)
{
    return A0 * T * exp(-L * T) - C;
}

/* 牛顿迭代反解衰减常数 L */
double newton(double A0, double T, double C, double L0, double eps)
{
    double L = L0, L1;
    int k = 0;

    do {
        L1 = L - f(L, A0, T, C) / df(L, A0, T, C);   /* 迭代公式 */
        k++;
        printf("iter %d: lambda = %.6f\n", k, L1);
        if (fabs(L1 - L) < eps)      /* 收敛判据 */
            break;
        L = L1;
    } while (k < 1000);

    return L1;
}

int main(void)
{
    double A0, T, C, lam;

    scanf("%lf %lf %lf", &A0, &T, &C);
    lam = newton(A0, T, C, 0.03, 1e-6);   /* 初值 0.03，容差 1e-6 */
    printf("lambda = %.6f\n", lam);
    return 0;
}
```

## 五、运行验证

样例 1（$A_0=1000,\ T=30,\ C=20000$）的迭代过程：

| 迭代 | $\lambda_n$ | $f(\lambda_n)$ | $f'(\lambda_n)$ | $\lambda_{n+1}$ | 程序输出 |
|---|---|---|---|---|---|
| 1 | 0.030000 | −6.570 | −7802.9 | 0.029158 | `iter 1: lambda = 0.029158` |
| 2 | 0.029158 | −0.130 | −7490.9 | 0.029141 | `iter 2: lambda = 0.029141` |
| 3 | 0.029141 | ≈0 | ≈−7485 | 0.029141 | `iter 3: lambda = 0.029141` |

第 3 次时 $|\lambda_3-\lambda_2|\approx7.6\times10^{-9}<10^{-6}$，停止，输出 `lambda = 0.029141`。样例 2（$T=60,\ C=30000$）同理收敛到 `lambda = 0.026560`。用反解出的 $\lambda$ 回代计数公式，可得 $C' \approx 20000$ 与实测值吻合，说明结果可信。

## 六、常见错误与讲解

**错误 1：把方程两边直接除以 $\lambda$ 后忘了 $C\lambda$ 这一项**

```c
return A0 * (1.0 - exp(-L * T)) - C;      /* 错：漏乘 L，方程完全不同 */
return A0 * (1.0 - exp(-L * T)) - C * L;  /* 对 */
```

建模时移项要仔细：$C = \dfrac{A_0}{\lambda}(1-e^{-\lambda T})$ 两边同乘 $\lambda$ 才得到 $\lambda C$。

**错误 2：导函数漏掉因子或符号**

```c
return A0 * exp(-L * T) - C;         /* 错：漏了 T，且符号错 */
return A0 * T * exp(-L * T) - C;     /* 对 */
```

**错误 3：忘记 `#include <math.h>`**

调用 `exp`、`fabs` 之前必须包含头文件，否则编译器会警告"隐式声明"，运行结果异常。

**错误 4：初值离根太远导致不收敛**

若把初值取成 1.0，$\lambda T = 30$ 巨大，$e^{-30}\approx0$，迭代可能越过根甚至发散。**先用 $1/T$ 估个量级**，是牛顿法工程应用的常规动作。

## 七、与综合实验的衔接

实验 **D1（放射性核素活度衰减分析）**的核心任务之一就是"参数反演"：由可测量的计数反推物理参数（衰减常数、半衰期、活度）。这类问题几乎都以"解一个非线性方程"收尾，而牛顿法提供了统一、快速的解法。本练习的 `f`、`df`、`newton` 三件套可原样移植到实验里；只要把模型换成另一个核素或另一种测量方式，仅需修改 `f` 与 `df`。下一题（16）将介绍另一种更简单、但收敛速度较慢的迭代思想——不动点迭代，并重点讨论它的**收敛条件**。
