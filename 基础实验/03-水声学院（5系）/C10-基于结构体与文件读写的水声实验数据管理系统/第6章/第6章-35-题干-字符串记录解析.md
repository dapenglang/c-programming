# 第 6 章 练习 35　字符串记录解析

**所属综合实验**：C10（C10-基于结构体与文件读写的水声实验数据管理系统）

**对应章节**：6 指针与字符串（6.6 字符指针、6.7 字符串处理函数 `strchr`/`strcpy`）

**场景来源**：综合实验 C10《基于结构体与文件读写的水声实验数据管理系统》（水声学院）——本练习是该实验中"文本记录解析"环节的最小实现。

**建议用时**：40 分钟

## 一、应用场景

测点数据常以**一行一条记录**的文本形式存放，字段用逗号分隔（CSV）：

```
S01,15.5,08:30
```

三个字段依次是：测点编号、水深（m）、观测时刻。程序要把它"拆开"——编号存进一个字符数组、水深转成 double、时刻存进另一个字符数组，才能参与后续计算。综合实验 C10 在把记录装进结构体之前，**先要完成这个字段切分**。本题就用字符指针把这个切分器写出来。

## 二、任务要求

编写一个完整程序 `parse_rec.c`：

1. 从键盘读入记录条数 `n`（**题目保证 1 ≤ n ≤ 20**），随后读入 `n` 行记录，每行格式 `编号,水深,时刻`（编号与时刻均不含逗号，行长不超过 63 字符）；
2. 对每行记录，**用字符指针切分**：以 `','` 为界，把三段分别取出——编号存入 `char id[32]`，时刻存入 `char tm[32]`，水深用 `atof` 转成 double；
3. 每解析完一行，立即输出该记录的三个字段，水深保留 1 位小数；
4. 最后输出全部记录中的最大水深及其对应编号。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；随后 `n` 行，每行一条记录。

**输出**：每条记录一行：

```
编号=S01 水深=15.5m 时刻=08:30
```

末行输出最大水深：

```
最大水深：S03 22.0m
```

## 四、样例

**样例 1**

输入：
```
3
S01,15.5,08:30
S02,18.2,09:00
S03,22.0,09:30
```
输出：
```
编号=S01 水深=15.5m 时刻=08:30
编号=S02 水深=18.2m 时刻=09:00
编号=S03 水深=22.0m 时刻=09:30
最大水深：S03 22.0m
```

**样例 2**

输入：
```
1
A7,3.0,12:00
```
输出：
```
编号=A7 水深=3.0m 时刻=12:00
最大水深：A7 3.0m
```

## 五、提示

- `strchr(line, ',')` 返回**第一个逗号的地址**（字符指针），找不到返回 `NULL`；
- 切分三板斧：拿到逗号地址 `q` 后，`*q = '\0'` 把逗号改成字符串结束符，逗号**之前**就是第一个字段；再把 `q + 1` 当作"剩余字符串的开头"继续找下一个逗号；
- "把一段字符拿走"用 `strcpy(dst, src)`（头文件 `<string.h>`）；"把一段字符转成 double"用 `atof`（头文件 `<stdlib.h>`）；
- 深度转数也可以不用 `atof`，用 `sscanf(q, "%lf", &depth);`——`sscanf` 会自动停在逗号处；
- 注意 `fgets` 读入的行末带 `'\n'`，切分前先把 `line[strcspn(line, "\n")] = '\0';` 去掉；
- 想一想：为什么改 `*q = '\0'` 是安全的？因为 `line` 是你自己的字符数组，可写；这也正是**必须用字符数组而不能用字符串常量**做切分的原因。

**完成本练习后你将具备的能力**：用字符指针切分 CSV 记录、配合 `strchr`/`strcpy`/`atof` 完成字段提取——这是实验 C10 中"文本记录解析"的地基，练完它，下一章就能把字段直接装进结构体。
