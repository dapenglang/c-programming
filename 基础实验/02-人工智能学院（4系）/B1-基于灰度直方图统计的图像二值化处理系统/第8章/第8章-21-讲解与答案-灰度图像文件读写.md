## 二、预备知识：文件读写与打开模式的基本原理（零基础阅读）

### 1. 问题是怎么来的：数据要"存下来"

前面所有练习的数据都靠键盘输入、屏幕输出，程序一关，数据就没了。实际系统需要把数据**保存到磁盘上的文件里**，下次再打开。B1 系统的图像就是磁盘上的一个文件。

### 2. 文件是什么：磁盘上的一串字节

文件可以理解成"磁盘上的一串字节"，平时看不见、摸不着。程序要读写它，必须通过一个"中介"——**文件指针** `FILE *`：

```c
FILE *fp = fopen("in.txt", "r");
```

`fopen` 做两件事：把文件和程序"接上线"，并返回一根"管子"（文件指针）。以后所有的读、写、关，都通过这根管子进行。

### 3. 打开模式：想干什么就开什么模式

`fopen` 的第二个参数是**打开模式**，它决定了这次"开管子"是来干什么的：

| 模式 | 含义 | 若文件不存在 |
|---|---|---|
| `"r"` | 只读（read） | 打开失败，返回 `NULL` |
| `"w"` | 只写（write） | **创建新文件**；若已存在则**清空** |
| `"a"` | 追加（append） | 创建新文件；在末尾接着写 |
| `"rb"`/`"wb"` | 二进制读/写 | 同上，但不做文本转换 |

**本题读用 `"r"`、写用 `"w"`**。要特别警惕：`"w"` 会把已存在的文件**清空重写**，如果误把输入文件用 `"w"` 打开，数据就没了——这是新手常见的"惨案"。

### 4. 为什么必须检查 fopen 的返回值

用 `"r"` 打开一个不存在的文件，`fopen` 会返回 `NULL`。若不加检查就用这根"空管子"去读，程序立刻崩溃。所以**打开后必须马上判断**：

```c
FILE *fp = fopen(inName, "r");
if (fp == NULL) {
    printf("cannot open %s\n", inName);
    return 1;              /* 直接退出，不再往下走 */
}
```

这一句检查，是文件程序与内存程序最重要的区别。

### 5. 文件读写的四步曲

```
① 打开 fopen        ② 读写 fscanf/fprintf        ③ 关闭 fclose
（记得判 NULL）
```

`fscanf` / `fprintf` 的用法和 `scanf` / `printf` 几乎一样，只是**多了第一个参数——文件指针**：

```c
fscanf(fp, "%d", &g);            /* 从文件读一个整数 */
fprintf(out, "%d ", g);          /* 往文件写一个整数 */
```

### 6. 用本例走一遍

输入文件前两行：

```
2 3
10 200 130
50 255 100
```

程序先 `fscanf` 读出行数 2、列数 3；再逐个读灰度并判断：$10<128 \to 0$、$200\ge128 \to 255$、$130\ge128 \to 255$、$50<128 \to 0$、$255\ge128 \to 255$、$100<128 \to 0$。写出的文件正是：

```
0 255 255
0 255 0
```

处理完两行，屏幕提示 `done: 2 rows written`。

> **这个思想在综合实验中反复出现**：B1 图像文件存取、B2 采样数据文件、B6 词频结果文件，全都是"打开—读写—关闭"同一个套路。

## 三、解题思路

1. **读文件名**：两条 `scanf("%s", ...)` 读入两个文件名；
2. **打开输入**：`fopen(inName, "r")`，判 `NULL`；
3. **打开输出**：`fopen(outName, "w")`，同样判 `NULL`；
4. **读尺寸**：`fscanf(in, "%d %d", &r, &c);`；
5. **流式处理**：双重循环读一个灰度、判断、写一个结果；每行末尾写换行；
6. **收尾**：`fclose` 两个文件，输出提示。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    char inName[64], outName[64];
    FILE *in, *out;
    int r, c, i, j, g;

    /* 读入两个文件名 */
    scanf("%s", inName);
    scanf("%s", outName);

    /* 打开输入文件（只读），必须检查是否成功 */
    in = fopen(inName, "r");
    if (in == NULL) {
        printf("cannot open %s\n", inName);
        return 1;
    }

    /* 打开输出文件（只写），同样检查 */
    out = fopen(outName, "w");
    if (out == NULL) {
        printf("cannot open %s\n", outName);
        fclose(in);                 /* 先关掉已开的输入文件 */
        return 1;
    }

    /* 读入图像尺寸 */
    fscanf(in, "%d %d", &r, &c);

    /* 逐行逐列读入灰度，按阈值 128 二值化后写出 */
    for (i = 0; i < r; i++) {
        for (j = 0; j < c; j++) {
            fscanf(in, "%d", &g);
            int b = (g >= 128) ? 255 : 0;    /* 二值化 */
            fprintf(out, "%d", b);
            if (j < c - 1) fprintf(out, " ");    /* 列间空格 */
        }
        fprintf(out, "\n");              /* 每行末尾换行 */
    }

    /* 关闭两个文件 */
    fclose(in);
    fclose(out);

    printf("done: %d rows written\n", r);

    return 0;
}
```

## 五、运行验证

**输入文件 `in.txt` 内容**：
```
2 3
10 200 130
50 255 100
```

**运行前**：`out.txt` 不存在（或内容被清空）。

**运行后**：`out.txt` 内容为
```
0 255 255
0 255 0
```

| 场景 | 处理过程 | 结果 |
|---|---|---|
| 灰度 10 | 10 < 128 | 输出 `0` |
| 灰度 200 | 200 ≥ 128 | 输出 `255` |
| 灰度 130 | 130 ≥ 128 | 输出 `255` |
| 灰度 100 | 100 < 128 | 输出 `0` |

屏幕输出：`done: 2 rows written`。若输入文件名不存在，屏幕输出 `cannot open xxx` 并正常退出，不崩溃。

## 六、常见错误与讲解

**错误 1：不检查 fopen 返回值（最典型）**

```c
in = fopen(name, "r");
fscanf(in, "%d", &r);      /* 错：若 in 为 NULL，程序崩溃 */
```

**错误 2：输入文件误用 "w" 模式**

```c
in = fopen(inName, "w");   /* 灾难：把输入文件清空了 */
in = fopen(inName, "r");   /* 对：读用 r */
```

**错误 3：忘记 fclose**

```c
fprintf(out, "%d", b);
/* 程序结束前必须 fclose(out)，否则数据可能没真正写入磁盘 */
```

缓冲区里的内容要靠 `fclose`（或程序正常结束）才会落盘。

**错误 4：fprintf 少写了文件指针**

```c
fprintf("%d\n", b);         /* 错：缺少文件指针，编译器会警告 */
fprintf(out, "%d\n", b);    /* 对 */
```
