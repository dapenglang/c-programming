# 第 2 章 练习 05　混凝土龄期-强度插值

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——线性插值）

**场景来源**：综合实验 A7《基于拉格朗日插值的混凝土强度发展曲线计算系统》（航建学院）——本练习是该实验中"任意龄期强度查询"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

混凝土浇筑后，强度随养护龄期逐渐增长：刚拆模时强度很低，到 28 天左右达到设计强度，之后增长变缓。施工中常需要"某个龄期时强度够不够"，因此要把"龄期—强度"的试验点整理成一条可查询的曲线。

实验 A7 采集了一批标准养护试块的实测点。假设试验数据表里只有两个关键点：**7 天**强度 **20.0 MPa**、**28 天**强度 **38.0 MPa**。当工程需要知道 14 天、21 天等中间龄期的强度时，就按"两龄期之间强度线性变化"做插值。本题与练习 04 用的是**同一个插值公式，只是换了一组常量表**。

## 二、任务要求

编写一个完整程序 `concrete_strength.c`：

1. 用**常量**存放两个试验点：龄期 7 天强度 20.0 MPa，龄期 28 天强度 38.0 MPa；
2. 从键盘读入一个查询龄期 `t`（单位：天，double 类型，**题目保证 7 ≤ t ≤ 28**，因此本程序不需要判断分支）；
3. 用线性插值公式计算该龄期的抗压强度 `f`；
4. 按规定格式输出结果，保留 **2 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示养护龄期 t（天）。

**输出**：一行，按格式 `f = 结果 MPa` 输出，结果保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
14
```
输出：
```
f = 26.00 MPa
```

**样例 2**

输入：
```
21
```
输出：
```
f = 32.00 MPa
```

## 五、提示

线性插值公式：已知两点 $(t_0,\, f_0)$、$(t_1,\, f_1)$，则 $t$ 处的插值为

$$
f = f_0 + \dfrac{(f_1 - f_0)\,(t - t_0)}{t_1 - t_0}
$$

请对照练习 04 的声速插值，体会"公式结构完全相同，只是物理量名称和常量数值换了"。

**完成本练习后你将具备的能力**：识别不同专业场景背后**同一个数学模型**，把一组新常量填入同一个插值模板——这正是综合实验 A7、C1、D3 共用的核心能力。
