## 二、预备知识：递归求和的基本原理（零基础阅读）

### 1. 问题是怎么来的

声呐脉冲发出后能量逐段衰减：走过一段，剩余能量乘衰减因子 $r$（$0 < r < 1$）。初始能量 $a$，前 $n$ 段累计能量是**等比衰减和**：

$$S_n = a + ar + ar^2 + \cdots + ar^{n-1} = \sum_{k=0}^{n-1} a\,r^k$$

实验 C4 的端点检测要估计"脉冲余晖能量"，就这类逐段衰减、逐段累加的计算。用循环能算（第 3 章练习 40 的累加器），但这个和有一个更漂亮的**自相似**结构——自己缩小的自己。

### 2. 公式推导：找出"自己缩小的自己"

把 $S_n$ 的首项摘出来，剩下的项每项都多带一个因子 $r$：

$$S_n = a + \underbrace{ar + ar^2 + \cdots + ar^{n-1}}_{r\,(a + ar + \cdots + ar^{n-2})} = a + r\,S_{n-1}$$

于是得到**递推关系**与**递归出口**：

$$\boxed{\,S_0 = 0, \qquad S_n = a + r\,S_{n-1} \;(n \ge 1)\,}$$

直观读法："n 段的能量 = 首段的 a，加上余下 n−1 段的能量整体再衰减一个 r"。这就是递归的本质——**大问题 = 一小步 + 缩小一号的同款问题**。

（顺带一提：对这个递推反复代入，可得闭式 $S_n = a\,\dfrac{1-r^n}{1-r}$。本题为了练递归，**不许**直接用闭式或 `pow`。）

### 3. 代入本例数值

以样例 1（a=100, r=0.8, n=5）跟踪递归的"去程"与"回程"：

```
去程（展开）：          回程（收敛，逐层计算）：
decaySum(100,0.8,5)     = 100 + 0.8 × 295.20 = 336.16
 └ decaySum(...,4)      = 100 + 0.8 × 244.00 = 295.20
    └ decaySum(...,3)   = 100 + 0.8 × 180.00 = 244.00
       └ decaySum(...,2)= 100 + 0.8 × 100.00 = 180.00
          └ decaySum(,1)= 100 + 0.8 × 0.00   = 100.00
             └ decaySum(,0) = 0.00   ← 递归出口
```

回程结束时最外层得到 $S_5 = 336.16$，与手算 $100 \times (1+0.8+0.64+0.512+0.4096) = 336.16$ 一致。

再看收敛性（样例 3，n=30）：由于 $r = 0.8 < 1$，和收敛于极限 $a/(1-r) = 500$；递归 30 层算得 499.38，已经非常接近 500——递归深度 30 完全在栈的安全范围内。

### 4. 通过编程翻译

递归函数的翻译模板就是"出口 + 递推"两行：

```c
double decaySum(double a, double r, int n)
{
    if (n == 0) return 0.0;               /* 出口：空和 */
    return a + r * decaySum(a, r, n - 1); /* 递推：一小步 + 缩小一号 */
}
```

每次调用 `decaySum(a, r, n-1)` 时，`a`、`r` 又被**抄一份**压进新的一层（传值调用），每层都有自己的副本、自己的 `n`——层层独立，互不干扰。到 `n == 0` 触底返回，回程逐层做乘加。

> **这个思想在综合实验中反复出现**：C4 的逐段衰减能量累加是本题的直接对应；C8 的逐层传播时间累加（第 3 章练习 40）也可以写成 $T_n = t_n + T_{n-1}$ 的递归形式——累加类问题几乎都有递归写法。递归未必更快，但它教会你"把问题看成自己缩小的自己"，这种思维方式在第 6 章的**链表**里是必需品（链表天然是递归结构）。

## 三、解题思路

1. **写递归函数**：出口 `n == 0` 返回 0.0；否则返回 `a + r * decaySum(a, r, n - 1)`；
2. **原型声明**放 main 前；
3. **主函数**：读 a、r、n；调用 `decaySum`；按 `%.2f` 打印。

## 四、参考代码

```c
#include <stdio.h>

double decaySum(double a, double r, int n);   /* 原型声明 */

int main(void)
{
    double a, r, s;
    int n;

    scanf("%lf %lf %d", &a, &r, &n);   /* 初始能量、衰减因子、段数 */

    s = decaySum(a, r, n);             /* 递归求和 */
    printf("前%d段累计能量=%.2f\n", n, s);
    return 0;
}

/* 等比衰减和：S_0 = 0，S_n = a + r * S_{n-1}（纯递归，无循环无 pow） */
double decaySum(double a, double r, int n)
{
    if (n == 0) {
        return 0.0;                    /* 递归出口：空和 */
    }
    return a + r * decaySum(a, r, n - 1);   /* 递推关系 */
}
```

## 五、运行验证

**样例 1 运行结果**（100, 0.8, 5）：

```
前5段累计能量=336.16
```

**样例 2 运行结果**（50, 0.5, 1）：

```
前1段累计能量=50.00
```

**样例 3 运行结果**（100, 0.8, 30）：

```
前30段累计能量=499.38
```

**核对**：样例 1 与逐项手算 $100 \times 3.3616 = 336.16$ 一致；样例 3 已按 IEEE-754 double 与递归的实际求和次序（先里后外）复算核对：递归回程相当于从 $k = n-1$ 项往回累加，结果 499.3810299…，`%.2f` 舍入为 499.38；闭式 $100(1-0.8^{30})/0.2 = 499.381$ 相符。样例 3 的 499.38 与极限 500.00 相差 0.62，验证了"r < 1 时和收敛于 a/(1−r)"。样例 2 中 n=1 时递归只下探一层（`decaySum(...,0)` 返回 0，回程 `50 + 0.5×0 = 50`），边界正确。

**反例验证**：若把出口写成 `if (n == 1) return a;` 而主程序传入 n = 0，递归会一路调用 `decaySum(..., -1), (-2), ...` **永不触底**，最终栈溢出崩溃——出口必须覆盖"可能被传入的最小 n"。

## 六、常见错误与讲解

**错误 1：没有递归出口（或出口漏掉 n=0）**

```c
double decaySum(double a, double r, int n)
{
    return a + r * decaySum(a, r, n - 1);   /* 错：无出口，栈溢出崩溃 */
}
```

**错误 2：递推系数放错位置**

```c
return a * r + decaySum(a, r, n - 1);   /* 错：算成 a·r + a·r + ... = n·a·r */
```

衰减的是"余下各段的整体"，所以是 `a + r * 递归结果`，而不是首项先乘 r。

**错误 3：用循环偷偷实现（违背题意）**

```c
double decaySum(double a, double r, int n)
{
    double s = 0.0, term = 1.0;
    while (n--) { s += a * term; term *= r; }   /* 错：这是循环解法 */
    return s;
}
```

本题考核递归，累加必须由函数自调用完成。

**错误 4：把 a、r 定义在函数外用全局变量"省参数"**

```c
double a, r;                       /* 不推荐：本阶段应通过参数传递 */
double decaySum(int n) { ... }
```

传参是第 4 章的核心训练点：数据通过参数进入函数，函数才是可复用的"黑盒"。
