# 第 5 章 练习 14　字符串长度与字符分类统计

**对应章节**：5 批量数据处理方法（5.3 字符数组——字符串的存储与 `'\0'` 结尾、逐字符遍历；3.2 选择结构；3.3 循环结构）

**场景来源**：综合实验 B6《英文文本词频统计系统》（人工智能学院）——本练习是该实验中"文本预处理与字符分类统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

词频统计的第一步不是数单词，而是**把一段文本"拆开看"**：有多少个字母、多少个数字、多少个空格、多少个标点符号。这些统计量决定了后续分词策略——例如标点要作为词与词的分隔符处理，纯数字不计入词频。文本在内存里就是一条**字符数组**，最末尾由一个不可见的结束标志 `'\0'` 收尾。本练习练习最基础也最重要的字符数组操作：**从数组头开始逐个字符扫描，扫到 `'\0'` 为止**，边扫边给每个字符归类计数。

## 二、任务要求

编写一个完整程序 `char_classify.c`：

1. 从键盘读入**一行**文本（可能含空格，总长度不超过 99 个字符），存入字符数组 `char s[100]`；
2. 用循环从下标 0 开始逐个扫描字符，直到遇到字符串结束标志 `'\0'` 才停止；
3. 对每个字符分类计数，共分四类：**字母**（`A`～`Z`、`a`～`z`）、**数字**（`0`～`9`）、**空格**（字符 `' '`）、**其他**（除以上三类外的任何可见字符，如 `-`、`#`、`.`）；
4. 顺序输出文本长度（字符总数）以及四类字符的个数。

## 三、输入输出格式

**输入**：一行文本（长度 1 ～ 99，可能包含空格）。

**输出**：共 5 行，依次为：

```
长度 = 字符总数
字母 = 字母个数
数字 = 数字个数
空格 = 空格个数
其他 = 其他字符个数
```

均为整数，按上面的字面格式输出（含中文标签、空格、等号）。

## 四、样例

**样例 1**

输入：
```
Ice-2024 Model #7
```
输出：
```
长度 = 17
字母 = 8
数字 = 5
空格 = 2
其他 = 2
```

**样例 2**

输入：
```
C5-a9b
```
输出：
```
长度 = 6
字母 = 3
数字 = 2
空格 = 0
其他 = 1
```

## 五、提示

1. 字符数组声明为 `char s[100];`，读入**含空格的一整行**时不能再用 `scanf("%s", s)`（它一遇空格就停），改用

```c
scanf("%[^\n]", s);
```

其中 `%[^\n]` 表示"连续读取直到遇到换行符为止"；字符数组名 `s` 本身就代表首地址，**不加 `&`**；

2. 判断一个字符属于哪一类，用它的**编码范围**比较：

- 字母：`(c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z')`
- 数字：`c >= '0' && c <= '9'`
- 空格：`c == ' '`

3. 字符串结束标志是 `'\0'`（数值为 0），它不是可见字符，**不参与计数**，循环的终止条件写作 `s[i] != '\0'`；
4. 文本长度 = 扫描过的字符个数，在同一个循环里边扫描边让计数器 `+1` 即可，不必另写一遍。

**完成本练习后你将具备的能力**：理解字符串以 `'\0'` 结尾的存储方式、掌握"从数组头扫到 `'\0'`"的字符数组遍历范式、用编码范围判断字符类别——这是实验 B6 中"文本预处理与分词准备模块"的地基。
