## 二、预备知识：链表的基本原理（零基础阅读）

### 1. 问题是怎么来的

散射事件的**数量事先不确定**：中子可能散射几次就热化，也可能几十次。用数组就得猜一个上限：猜小了溢出，猜大了浪费内存。链表的思想是"**需要一条记录就现申请一个结点，用一根链子接到已有记录的尾巴上**"，结点数量随实际需要增长，不多不少。

### 2. 结点与"链子"是怎么组织的

每个结点是一个结构体，除数据外还带一个**指针成员 `next`**——它就是"链子"，指向下一个结点：

```c
struct Scatter {
    int    order;
    double energy;
    struct Scatter *next;   /* 链子：指向下一个结点 */
};
```

`next` 指向"同类型的另一个结点"，这叫**自引用结构体**。画成图（3 个散射事件）：

```
  head                                              tail
   │                                                 │
   ▼                                                 ▼
+------+------+------+   +------+------+------+   +------+------+------+
|order |energy| next |──▶|order |energy| next |──▶|order |energy| next |──▶ NULL
|  1   |5.0e5 |  ●───┘   |  2   |2.5e5 |  ●───┘   |  3   |1.25e5| NULL |
+------+------+------+   +------+------+------+   +------+------+------+
```

- 头指针 `head` 指向第一个结点，是"整条链的入口"；
- 尾结点的 `next` 是 `NULL`，表示"链子到头了"；
- 遍历就是"从 `head` 出发，顺着 `next` 一格一格走，直到 `NULL`"。

### 3. 尾插法怎么"接链子"

要保持一个 `tail` 指针**始终停在链尾**：① 申请新结点 `node`，填好数据并把 `node->next` 置 `NULL`（它将成新链尾）；② 把旧链尾的 `next` 指向它（`tail->next = node;`）；③ 把 `tail` 移到它（`tail = node;`）。

```
  接之前： ... 3号[●─▶NULL]   4号[●─▶NULL]   (tail 停在 3 号)
  ② 之后： ... 3号[●──▶4号]   4号[●─▶NULL]
  ③ 之后： ... 3号[●──▶4号]   4号[●─▶NULL]   (tail 移到 4 号)
```

**关键**：接新结点前必须先把它的 `next` 设成 `NULL`，否则链尾判断会出错。

### 4. 动态内存：malloc 与 free

`malloc(sizeof(struct Scatter))` 向系统"租借"一块刚好装下一个结点的内存，返回其首地址。**租来的内存必须还**——用 `free(p)` 归还，否则程序长时间运行会"内存泄漏"。链表释放的标准写法（用临时指针暂存下一个结点，再释放当前）：

```c
p = head;
while (p != NULL) {
    q = p->next;   /* 先记住下一个 */
    free(p);       /* 再释放当前 */
    p = q;         /* 走到下一个 */
}
```

若先 `free(p)` 再访问 `p->next`，就访问了已释放的内存（悬空指针），非常危险。

### 5. 用本例走一遍

**样例 1**：\(E_0 = 10^{6}\) eV，\(\alpha = 0.5\)，\(n = 4\)，能量依次 \(5\text{e}5, 2.5\text{e}5, 1.25\text{e}5, 6.25\text{e}4\)。

**样例 2**：\(E_0 = 2\times10^{6}\)，\(\alpha = 0.9\)，\(n=3\)，能量依次 \(1.8\text{e}6, 1.62\text{e}6, 1.458\text{e}6\)。

> **这个思想在综合实验中反复出现**：D2 散射事件链表、D3 可动态增长的数据表、D1 待处理核素队列。**凡是"数量事先不定"的数据序列，链表都是首选；而"申请—使用—释放"是动态内存的三步纪律。**

## 三、解题思路

1. **定义结点类型** `struct Scatter`，含 `next` 自引用指针；
2. **读入** `E0`、`alpha`、`n`；
3. **建链**：循环 `n` 次，每次 `malloc` 一个结点，填数据、接链尾、移动 `tail`；第一次建链时同时设定 `head`；
4. **遍历输出**：从 `head` 顺着 `next` 走，打印 `order` 与 `energy`；
5. **释放**：用临时指针逐个 `free`，并输出 `collisions = n`。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

/* 散射事件结点：次数、能量、指向下一结点的指针 */
struct Scatter {
    int    order;             /* 第几次散射 */
    double energy;            /* 散射后能量，eV */
    struct Scatter *next;     /* 链子 */
};

int main(void)
{
    double e0, alpha, e;
    int    n, k;

    struct Scatter *head = NULL, *tail = NULL, *node, *p, *q;

    scanf("%lf %lf %d", &e0, &alpha, &n);

    /* 逐次散射，尾插法建立链表 */
    e = e0;
    for (k = 1; k <= n; k++) {
        e = e * alpha;                              /* 散射一次，能量降低 */

        node = (struct Scatter *)malloc(sizeof(struct Scatter));
        node->order  = k;
        node->energy = e;
        node->next   = NULL;                        /* 新结点暂时是链尾 */

        if (head == NULL) {
            head = node;                            /* 第一个结点 */
            tail = node;
        } else {
            tail->next = node;                      /* 旧链尾接到新结点 */
            tail = node;                            /* tail 移到新结点 */
        }
    }

    /* 遍历链表输出散射历史 */
    for (p = head; p != NULL; p = p->next) {
        printf("step %d: E = %.4e\n", p->order, p->energy);
    }
    printf("collisions = %d\n", n);

    /* 释放所有结点，防止内存泄漏 */
    p = head;
    while (p != NULL) {
        q = p->next;    /* 先记住下一个 */
        free(p);        /* 再释放当前 */
        p = q;
    }

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：新结点的 `next` 没置空、头指针没初始化**

```c
struct Scatter *head;              /* 错：野指针，head==NULL 判断不可靠 */
struct Scatter *head = NULL;       /* 对：一开始链表为空 */
node->next = NULL;                 /* 错法：漏写此行 → 链尾判断失效，遍历越界 */
```

**错误 2：释放顺序错误，访问已释放内存**

```c
free(p);
p = p->next;    /* 错：p 已被释放，再访问 p->next 是悬空指针操作 */
q = p->next; free(p); p = q;   /* 对：先存下一个再释放当前 */
```

**错误 3：只 `malloc` 不 `free`**：建链用了 `malloc`、程序结束前从不 `free`，就会内存泄漏。短程序看不出问题，但长时运行的模拟程序会耗尽内存。**养成"申请了就要释放"的习惯。**
