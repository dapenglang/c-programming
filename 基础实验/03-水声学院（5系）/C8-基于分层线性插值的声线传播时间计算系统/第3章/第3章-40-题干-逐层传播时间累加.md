# 第 3 章 练习 40　逐层传播时间累加

**所属综合实验**：C8（C8-基于分层线性插值的声线传播时间计算系统）

**对应章节**：3 循环结构（3.1 while、3.2 do-while、3.3 for、3.4 循环嵌套与累加器）

**场景来源**：综合实验 C8《基于分层线性插值的声线传播时间计算系统》（水声学院）——本练习是该实验中"逐层累加总传播时间"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

声波在海水中传播，不同深度的水温、盐度、压力不同，**声速**也不同。工程上把海洋按深度分成若干层，认为每一层内声速近似不变。声波从海面传到海底，**总传播时间**就是逐层时间之和：

$$T = t_1 + t_2 + \cdots + t_n = \sum_{i=1}^{n} \frac{h_i}{c_i}$$

其中 $h_i$ 是第 $i$ 层的厚度（m），$c_i$ 是第 $i$ 层的声速（m/s）。这一"**循环读入一层、算一层、累加一层**"的过程，正是综合实验 C8 中 M6 模块（逐层累加总传播时间）的雏形。

## 二、任务要求

编写一个完整程序 `layer_time.c`：

1. 从键盘读入层数 `n`（**题目保证 1 ≤ n ≤ 100**）；
2. 循环读入 `n` 对数据：每层的厚度 `h`（double，m）与声速 `c`（double，m/s）；
3. 每读入一层，立即算出该层传播时间 `t = h / c`，并打印（保留 6 位小数）；
4. 用累加器变量把各层时间**累加**起来；
5. 循环结束后打印总传播时间 `T`（保留 6 位小数）。

**知识边界提示**：本题只使用顺序、选择、循环结构——**不需要函数，也不需要数组**：每层数据读完即用即弃，只保留累加和。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 行，每行两个实数 h、c。

**输出**：共 n+1 行：前 n 行每行为 `第i层时间=xxx`（i 从 1 开始，保留 6 位小数）；最后一行为 `总传播时间=xxx`（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
4
50 1500
80 1520
30 1480
100 1540
```
输出：
```
第1层时间=0.033333
第2层时间=0.052632
第3层时间=0.020270
第4层时间=0.064935
总传播时间=0.171170
```

**样例 2**

输入：
```
1
100 1500
```
输出：
```
第1层时间=0.066667
总传播时间=0.066667
```

## 五、提示

- 累加器必须**先清零**：`double total = 0.0;`——忘记清零是循环累加最常见的错误；
- 累加的经典写法是"读入 → 计算本层 → 打印本层 → 累加"，全部放在同一个 for 循环里：

  ```c
  for (i = 1; i <= n; i++) {
      scanf("%lf %lf", &h, &c);
      t = h / c;
      printf("第%d层时间=%.6f\n", i, t);
      total = total + t;          /* 累加器自增 */
  }
  ```
- 层号 `i` 从 1 开始更符合"第几层"的说法，所以循环写成 `i = 1; i <= n`；
- 想一想：本题为什么**不需要数组**？因为第 `i` 层的结果用完就不需要再访问了——凡是"流式处理、只需保留累计结果"的问题，都可以不用数组。
- 时间单位是**秒**，数量级在零点零几秒，所以保留 6 位小数才够精度。

**完成本练习后你将具备的能力**：用 for 循环逐条处理数据流、维护累加器、边读边算边输出——这些是实验 C8 中"逐层累加总传播时间"模块的地基。
