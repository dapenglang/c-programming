# 第 4 章 练习 14　牛顿迭代法求方程根

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.6 非线性方程求解——牛顿迭代法）

**场景来源**：综合实验 A8《桁架结构内力分析系统》（航建学院）——本练习是该实验中"杆件几何非线性平衡方程求解"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

桁架结构在荷载下的变形协调关系，经过几何化简后常常归结为一个**非线性方程**。以某个简化模型为例，杆件的无量纲变形参数 $x$ 满足

$$
f(x) = x^3 - 2x - 5 = 0 .
$$

这类方程没有求根公式可以套，工程上普遍采用**牛顿迭代法**：从一个初始猜测出发，用切线与 $x$ 轴的交点不断逼近真正的根。本练习要把"求函数值""求导数值""迭代逼近"三件事分别写成函数，再组合出一个通用的小型求根器。

## 二、任务要求

编写一个完整程序 `newton_root.c`：

1. 编写函数 `double f(double x)`：返回 $f(x) = x^3 - 2x - 5$ 的值；
2. 编写函数 `double df(double x)`：返回导函数 $f'(x) = 3x^2 - 2$ 的值；
3. 编写函数 `double newton(double x0, double eps)`：用牛顿迭代公式

   $$
   x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
   $$

   从初值 $x_0$ 出发迭代；每完成一次迭代就输出一行中间结果；当相邻两次结果之差满足 $|x_{n+1} - x_n| < \text{eps}$ 时停止，返回最后的近似根；
4. `main` 读入初值 `x0`，以 `eps = 1e-6` 调用 `newton`，最后输出根；
5. **接口约定**：三个函数均只用参数与返回值通信，不使用全局变量；`newton` 必须**先打印本次迭代结果、再判断是否收敛**。

## 三、输入输出格式

**输入**：一行，一个实数 `x0`（初始猜测值）。

**输出**：每次迭代输出一行 `iter k: x = 迭代值`（`k` 为迭代次数，`x` 保留 6 位小数）；全部结束后输出一行 `root = 近似根`（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
2
```
输出：
```
iter 1: x = 2.100000
iter 2: x = 2.094568
iter 3: x = 2.094551
iter 4: x = 2.094551
root = 2.094551
```

**样例 2**

输入：
```
3
```
输出：
```
iter 1: x = 2.360000
iter 2: x = 2.127197
iter 3: x = 2.095136
iter 4: x = 2.094552
iter 5: x = 2.094551
root = 2.094551
```

## 五、提示

- 牛顿迭代公式的几何含义：在点 $\bigl(x_n, f(x_n)\bigr)$ 处作切线，切线与 $x$ 轴的交点横坐标就是 $x_{n+1}$；切线斜率正是 $f'(x_n)$，故有上式；
- 终止判据用 $|x_{n+1} - x_n| < \text{eps}$，实现时用 `fabs(x1 - x) < eps`（需 `#include <math.h>`）；
- 循环结构建议用 `do { ... } while (...)` 或 `for (;;) { ...; if (...) break; }`，**先算一次再判断**，保证至少输出一次迭代结果；
- 注意 $f'(x)$ 不能为 0：本题在正根附近 $f'(x) \approx 11.16$，不会出现除零。

**完成本练习后你将具备的能力**：理解牛顿迭代法的原理与迭代公式、能把"函数值与导数值"和"迭代过程"分开封装、会为迭代设置合理的初值与终止判据——这是实验 A8 中"非线性平衡方程求解模块"的地基。
