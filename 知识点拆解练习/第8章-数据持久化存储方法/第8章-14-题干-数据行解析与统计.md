# 第 8 章 练习 14　数据行解析与统计

**对应章节**：8 数据持久化存储方法（8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）；另用到第 5 章 5.3 字符数组

**场景来源**：综合实验 C7《冰区载荷辨识与统计系统》（水声学院）——本练习是该实验中"混合类型记录的解析与统计"环节的实现。

**建议用时**：30～40 分钟

## 一、应用场景

实验 C7 的事件记录文件 `samples.txt` 中，每行是一条"混合类型"记录：样本编号是**字符串**（如 A01），阻力与航速是**实数**，三者用逗号分隔。统计模块需要从中提取出全部记录条数、阻力总和与平均阻力。第 5 章曾用 `sscanf` 解析过这类行；但真实仪器的导出格式五花八门，有时分隔符不统一，`sscanf` 反而不好使——这时就需要**手写字符扫描**来拆字段。本练习要求不使用 sscanf，逐字符扫描把一行拆成三个字段，再完成统计。

## 二、任务要求

编写完整程序 `parse.c`：

1. 以 `"r"` 方式打开 `samples.txt`，检查 fopen 返回值，失败时输出提示并结束（返回值 1）；
2. 用 `fgets` 逐行读入（每行不超过 100 字符），**不使用 sscanf**，自己写代码扫描字符数组：遇到逗号 `,` 就把当前字段截断——第 1 个字段（编号）存入字符数组，第 2、3 个字段（阻力 kN、航速 m/s）用 `atof`（在 `<stdlib.h>` 中）转换成 double；
3. 每成功解析一条记录：记录条数加一，阻力累加求和，同时记录最大阻力及其样本编号；
4. 跳过空行；解析完关闭文件；
5. 屏幕输出三行：`共 N 条记录`、`阻力总和 = S kN`、`平均阻力 = A kN`、`最大阻力 = M kN（编号 X）`（S、A、M 保留 2 位小数）。

**数据文件格式约定**：`samples.txt` 每行三列、逗号分隔——样本编号（3 个字符，如 A01）、阻力值（kN）、航速（m/s）。样例数据行：`A01,23.5,0.82`。

## 三、输入输出格式

**输入文件**：`samples.txt`（逗号分隔文本，若干行）。

**屏幕输出**：四行，格式如上（条数、总和、平均、最大及编号）。

## 四、样例

**输入文件 samples.txt 的内容**：

```
A01,23.5,0.82
A02,25.1,0.85
A03,19.8,0.78
A04,27.6,0.90
```

**屏幕输出**：

```
共 4 条记录
阻力总和 = 96.00 kN
平均阻力 = 24.00 kN
最大阻力 = 27.60 kN（编号 A04）
```

## 五、提示

- 手工截断字段的核心动作是"找到逗号，把逗号改成 `'\0'`"：例如对字符数组 `line` 中的编号字段，可以让一个指针从头扫到第一个逗号，把逗号位置写 `'\0'`，编号就"自动"成了以 `'\0'` 结尾的字符串；
- 截断后把"逗号之后的位置"交给下一段处理：数值字段可以直接把起始地址交给 `atof`——`atof` 会从该位置开始读数字，遇到非数字字符（包括逗号、换行符）自动停止，所以不必真的把后两个字段的逗号也改成 `'\0'`；
- `atof` 的原型是 `double atof(const char *s);`，在 `<stdlib.h>` 中声明；
- 最大阻力的编号要跟着最大值一起更新：`if (f > fmax) { fmax = f; strcpy(maxid, id); }`（`strcpy` 在 `<string.h>` 中）。

**完成本练习后你将具备的能力**：不依赖现成函数、按字符扫描拆分混合类型数据行，"字符串字段 + 数值字段"的完整解析能力——面对实验 C7 中格式不规则的真实数据文件时，这是比 sscanf 更可靠的通用武器。
