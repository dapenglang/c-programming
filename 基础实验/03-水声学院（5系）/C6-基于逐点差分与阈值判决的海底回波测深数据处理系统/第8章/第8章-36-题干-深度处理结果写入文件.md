# 第 8 章 练习 36　深度处理结果写入文件

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：8 文件（8.1 文件的打开与关闭、8.2 文件的读写——fprintf、8.3 格式化读写、8.4 错误处理）

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"结果文件输出"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

测深系统在内存里算完深度序列的一阶差分、均值、极值之后，结果只打印在屏幕上是"留不住"的——程序一关，数据就没了。工程的收尾一步是把处理结果**写成文件**存档，最通用的格式是 **CSV**（逗号分隔值）：每行一条记录，字段之间用逗号隔开，Excel、Python、绘图软件都能直接打开。

综合实验 C6 的 M9 模块就是：把逐点深度、与前一点的一阶差分，以及全序列的统计汇总，按 CSV 格式写进结果文件。本题模拟这个过程。

## 二、任务要求

编写一个完整程序 `depth_out.c`：

1. 从键盘读入测点数 `n`（**题目保证 2 ≤ n ≤ 100**），随后读入 `n` 个海底深度值（double，单位 m）；
2. 计算一阶差分：约定**首点差分为 0.00**，其余 `diff[i] = d[i] − d[i−1]`；
3. 统计全序列的**最大深度、最小深度、平均深度**（平均保留 2 位小数）；
4. 以**写入**方式打开文件 `depth_result.csv`；若打开失败，打印提示并返回；
5. 按 CSV 格式写入：前 `n` 行为数据行，每行三个字段 `序号,深度,差分`（逗号分隔、行末换行）；随后写 3 行汇总行，格式为 `max,值`、`min,值`、`mean,值`；
6. 关闭文件。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后一行 n 个实数，为各测点深度。

**输出文件 `depth_result.csv`**：前 n 行每行 `序号,深度,差分`（深度、差分各保留 2 位小数）；最后 3 行汇总 `max,值`、`min,值`、`mean,值`（保留 2 位小数）。

## 四、样例

**样例 1**

输入：
```
5
12.50 13.20 12.80 15.60 15.40
```
运行后 `depth_result.csv` 内容：
```
1,12.50,0.00
2,13.20,0.70
3,12.80,-0.40
4,15.60,2.80
5,15.40,-0.20
max,15.60
min,12.50
mean,13.90
```

**样例 2**

输入：
```
3

```
运行后 `depth_result.csv` 内容：
```
1,100.00,0.00

3,100.00,0.00
max,100.00
min,100.00
mean,100.00
```

## 五、提示

- 文件操作四步曲：**打开 → 判断成功 → 读写 → 关闭**；
- 打开输出文件用 `"w"` 模式：`FILE *fp = fopen("depth_result.csv", "w");`；
- 写入用 `fprintf`，格式与 `printf` 相同，只是多一个文件指针参数：`fprintf(fp, "%d,%.2f,%.2f\n", i + 1, d[i], diff[i]);`；
- 汇总行只是"字段内容换了"，写法完全一样：`fprintf(fp, "max,%.2f\n", dmax);`；
- 想一想：为什么 CSV 里"最后一个字段后不能有逗号"？因为 Excel 等软件会把末尾的逗号当成"多出来一个空字段"，导致列数不符；
- **务必检查 `fopen` 返回值**——磁盘只读或无权限时打开会失败；
- 差分 `diff[i] = d[i] − d[i−1]` 从第 2 个点开始算，注意循环下标别越界。

**完成本练习后你将具备的能力**：用 `fprintf` 把"逐点数据 + 汇总统计"写出文件、按 CSV 规范组织输出格式、处理文件打开失败——这些是实验 C6 中"结果文件输出模块"的地基。
