# 第 4 章 练习 32　牛顿迭代法求平方根

**所属综合实验**：B7（B7-基于牛顿迭代法的方程求根计算器系统）

**对应章节**：4 模块化程序设计方法（4.1 函数调用与参数传递，4.6 非线性方程求解——迭代法思想）

**场景来源**：综合实验 B7《基于牛顿迭代法的方程求根计算器系统》（人工智能学院）——本练习是该实验中"牛顿迭代核心模块"的实现。

**建议用时**：30 分钟

## 一、应用场景

科学计算器里的 $\sqrt{\ }$ 键背后并没有"开方"指令——计算机内部只有加减乘除。求 $\sqrt{a}$ 等价于解方程

$$
f(x) = x^2 - a = 0 .
$$

对这类方程，**牛顿迭代法**是最经典的数值方法：从猜测值 $x_0$ 出发，每次用"切线代替曲线"的思想得到更好的近似

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right),
$$

反复迭代直到相邻两次结果之差小于精度要求。本练习要把"迭代公式"封装成函数，并统计迭代次数。

## 二、任务要求

编写一个完整程序 `newton_sqrt.c`：

1. 编写函数 `double newton_sqrt(double a, double eps)`：用牛顿迭代法求 $\sqrt{a}$——
   - 初值取 $x = a/2$（当 $a \ge 2$），否则取 $x = 1.0$；
   - 每次按 $x \leftarrow \dfrac{1}{2}\left(x + \dfrac{a}{x}\right)$ 更新，迭代计数 `n` 加一；
   - 当相邻两次近似值之差 $\lvert x_{\text{新}} - x_{\text{旧}}\rvert < \text{eps}$ 时停止；
   - 按格式输出结果与迭代次数，并返回近似值；
2. `main` 读入 `a`，以 `eps = 1e-6` 调用 `newton_sqrt`；
3. **接口约定**：`newton_sqrt` 只用参数与返回值通信，不使用全局变量、不调用 `sqrt` 库函数；输出格式为 `root = 近似值, n = 迭代次数`（近似值保留 6 位小数）。

## 三、输入输出格式

**输入**：一行，一个正实数 `a`。

**输出**：一行，格式为 `root = 近似值, n = 迭代次数`（保留 6 位小数）。

## 四、样例

**样例 1**

输入：
```
2
```
输出：
```
root = 1.414214, n = 5
```

**样例 2**

输入：
```
12345
```
输出：
```
root = 111.108056, n = 11
```

## 五、提示

- 牛顿迭代的几何意义：在点 $(x_n, f(x_n))$ 处作切线，切线与 $x$ 轴的交点就是 $x_{n+1}$。对 $f(x)=x^2-a$，切线斜率 $f'(x)=2x$，代入牛顿公式即得 $x_{n+1}=\dfrac{1}{2}\left(x_n+\dfrac{a}{x_n}\right)$；
- 判据用**相邻两次近似值之差** $\lvert x_{\text{新}}-x_{\text{旧}}\rvert<\text{eps}$，与二分法"看区间长度"不同；
- 牛顿法收敛极快（误差大约每步**平方**），本题一般 5～11 次就达标；但若初值取得太差可能多迭代几次，本题给定的初值规则已保证收敛；
- 严禁直接调用 `math.h` 的 `sqrt`——那正是本练习要"手搓"的东西。
