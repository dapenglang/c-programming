# 第 8 章 练习 16　结构体数据文件读写

**对应章节**：8 数据持久化存储方法（8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）；另用到第 7 章 7.1~7.2 结构体类型与结构体数组

**场景来源**：综合实验 C6《冰区船舶与冰块碰撞模拟系统》（水声学院）——本练习是该实验中"冰块档案的存盘与回读"环节的实现。

**建议用时**：30~40 分钟

## 一、应用场景

实验 C6 的碰撞模拟中，每个冰块用一条完整记录描述：编号、质量（吨）、速度（m/s）。模拟结束后要把冰块档案**存入文件**；下次继续分析时再从文件**读回**结构体数组。存档时还要求顺手算出每个冰块的动量 $p = mv$（质量先化成 kg），供碰撞计算直接使用。本练习完成"文件 → 结构体数组 → 加工 → 文件"的完整往返——结构体让你把"一条记录"当一个变量操作，文件让记录在程序关闭后依然存在，两者结合才是真正的数据管理。

## 二、任务要求

编写完整程序 `icefile.c`：

1. 定义结构体类型 `struct Ice { char id[8]; double mass; double speed; };`（编号、质量 t、速度 m/s），并声明一个最多 50 个元素的数组；
2. 以 `"r"` 方式打开 `ice_in.txt`，**检查返回值**；用循环 `fscanf(fin, "%s %lf %lf", ...)` 把记录逐条读入结构体数组（以 fscanf 返回值等于 3 为循环条件），统计实际条数 n；
3. 以 `"w"` 方式打开 `ice_out.txt`，检查返回值；对每个冰块计算动量 $p = m \times 1000 \times v$（kg·m/s，质量由吨化成千克）；
4. 把每个冰块按 `"%s %.1f %.1f %.1f\n"`（编号、质量、速度、动量）写入 `ice_out.txt`；
5. 关闭两个文件，并在屏幕上输出动量最大的冰块的编号与动量（动量保留 1 位小数）。

**数据文件格式约定**：`ice_in.txt` 每行三列、空格分隔——编号（3 字符）、质量（t，1 位小数）、速度（m/s，1 位小数）。样例数据行：`B01 12.5 0.8`。

## 三、输入输出格式

**输入文件**：`ice_in.txt`（空格分隔，若干行）。

**输出文件**：`ice_out.txt`（每行四列：编号、质量、速度、动量）。

**屏幕输出**：一行，`动量最大：编号 X，动量 Y kg·m/s`（Y 保留 1 位小数）。

## 四、样例

**输入文件 ice_in.txt 的内容**：

```
B01 12.5 0.8
B02 18.2 1.1
B03 9.6 0.5
```

**程序运行后 ice_out.txt 的内容**：

```
B01 12.5 0.8 10000.0
B02 18.2 1.1 20020.0
B03 9.6 0.5 4800.0
```

**屏幕输出**：

```
动量最大：编号 B02，动量 20020.0 kg·m/s
```

## 五、提示

- `fscanf(fin, "%s %lf %lf", ice[i].id, &ice[i].mass, &ice[i].speed)`：`%s` 对应字符数组**名**（本身就是地址，不加 `&`），数值成员仍要 `&`；
- 循环条件用 `fscanf(...) == 3`，读到文件末尾自动停止，不必预先知道行数；
- 动量最大的判定：遍历数组，用 `if (p > pmax)` 更新最大动量与对应下标；
- 结构体数组的每个成员都要逐个读写——本题用**文本方式**按字段读写，与 8.4 节的 fwrite/fread **二进制方式**是两条不同的路线，同一个文件绝不能混用两种方式读写。

**完成本练习后你将具备的能力**：结构体数组与文件之间的双向搬运（按字段文本读写）、在搬运过程中插入派生量计算（动量）与最值查找——这是实验 C6 冰块档案管理模块的核心，也是"结构体 + 文件"这一数据管理标准组合的入门。
