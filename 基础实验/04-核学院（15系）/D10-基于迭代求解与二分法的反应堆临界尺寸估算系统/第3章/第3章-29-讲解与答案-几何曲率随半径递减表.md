## 二、预备知识：等间距扫描——怎么用循环"走遍"一个区间（零基础阅读）

### 1. 问题是怎么来的

上一练习（练习 29 第 2 章）算了**一个点**的材料曲率。现在要算**一串点**的几何曲率：从半径 30 cm 一路到 150 cm，每隔一段取一个，看看曲率怎么变。

人脑的做法是列一张表：第一行 30 cm，第二行 60 cm……每行算一个值。程序里"每行"就是循环的**一轮迭代**。关键是：给定起点、终点、要分几段，怎么算出每一个半径？

### 2. 步长与第 i 个点

设起点 $R_0$、终点 $R_1$、分 $m$ 段。**步长**（每一段的长度）是总长除以段数：

$$
h = \frac{R_1 - R_0}{m}
$$

第 $i$ 个半径（$i$ 从 0 数起）就是从起点往右走 $i$ 段：

$$
R_i = R_0 + i \cdot h
$$

**这里最容易出错的是"点数"**：分 $m$ 段就有 $m+1$ 个点。比如 30 到 150 分 4 段，步长 30，点分别是 30、60、90、120、150——**5 个点**。所以循环上界写 `i <= m`，而不是 `i < m`。

为什么用 `R0 + i*h` 而不是"每轮把 R 累加一个 h"？两种写法在数学上等价，但 **`R0 + i*h` 更稳**：累加会在浮点运算中一点点积累舍入误差，扫 1000 个点时误差可能显现；而 `R0 + i*h` 每次都从起点重新算，误差不会累积。**这是数值编程的一个好习惯。**

### 3. 几何曲率为什么随半径递减，且是"平方"关系

$$
B_g^2 = \left(\frac{\pi}{R}\right)^2 = \frac{\pi^2}{R^2}
$$

半径 $R$ 在**分母上**，所以 $R$ 越大，$B_g^2$ 越小——**单调递减**。更进一步：$R$ 变成 2 倍，分母 $R^2$ 变成 4 倍，$B_g^2$ 就变成 **1/4**。这叫**平方反比**。

用样例 1 验证：$R = 30$ 时 $B_g^2 = 0.010966$，$R = 60$ 时是 0.002742。

$$
0.010966 / 4 = 0.0027415 \approx 0.002742 \quad \checkmark
$$

**这个观察非常重要**：说明几何曲率随尺寸下降得很快（二次方），因此"找临界点"时，半径范围很宽（30～150 cm）而曲率范围很窄且集中在低值区。

### 4. 用本例走一遍

样例 2：$R_0 = 50$、$R_1 = 70$、$m = 2$。

**步长**：$h = (70-50)/2 = 10$。

**循环** `i = 0, 1, 2`（共 3 个点）：

| i | R = 50 + 10i | β = π/R | Bg2 = β² |
|---|---|---|---|
| 0 | 50.0 | 0.0628319 | 0.0039478 |
| 1 | 60.0 | 0.0523599 | 0.0027416 |
| 2 | 70.0 | 0.0448799 | 0.0020142 |

输出即样例 2 的三行。

**物理意义**：如果这批材料的 $B_m^2$ 恰好等于 0.002742（相当于样例 4 的组合 $k=1.20, L=2.0$），那么临界半径正好在 **60 cm** 附近——**这张递减表就是"用查表找临界点"的工具，而二分法（练习 24 第 4 章）是它的自动化升级版。**

> **这个思想在综合实验中反复出现**：D10 的半径扫描、D6 的厚度-透射率扫描、D8 的滑动平均窗口扫描、A1 的多高度风压表，全部是"循环 + 等间距取值 + 打印表格"。**扫描表是数值方法的"体检报告"：先看清函数长什么样，再动手求根。**

## 三、解题思路

1. **定义常量**：`const double PI = 3.14159265358979;`；
2. **读参数**：`scanf("%lf %lf %d", &R0, &R1, &m);`——注意 `m` 是 `int`，用 `%d`；
3. **算步长**：`h = (R1 - R0) / m;`；
4. **循环 m+1 个点**：`for (i = 0; i <= m; i++) { R = R0 + i * h; Bg2 = (PI/R)*(PI/R); printf(...); }`；
5. **格式化输出**：`printf("R = %.1f, Bg2 = %.6f\n", R, Bg2);`

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double PI = 3.14159265358979;     /* 圆周率，常量 */

    double R0, R1;          /* 扫描起止半径，cm */
    int    m;               /* 分段数（点数为 m+1） */
    int    i;
    double h;               /* 步长，cm */
    double R;               /* 当前半径，cm */
    double Bg2;             /* 几何曲率，cm^-2 */

    /* 读入起始半径、终止半径、分段数（m 是整数，用 %d） */
    scanf("%lf %lf %d", &R0, &R1, &m);

    h = (R1 - R0) / m;      /* 步长 = 总跨度 / 段数 */

    /* 分 m 段，共 m+1 个点，故循环上界为 m */
    for (i = 0; i <= m; i++) {
        R = R0 + i * h;                     /* 第 i 个半径，从起点重算不累积误差 */
        Bg2 = (PI / R) * (PI / R);          /* 几何曲率 Bg2 = (PI/R)^2，平方用乘法 */

        printf("R = %.1f, Bg2 = %.6f\n", R, Bg2);   /* 打印一行 */
    }

    return 0;
}
```

## 五、运行验证

**样例 1**（30 到 150，分 4 段，步长 30）：

| i | R | β = π/R | Bg2 = β² | 输出 |
|---|---|---|---|---|
| 0 | 30.0 | 0.1047198 | 0.0109662 | `R = 30.0, Bg2 = 0.010966` ✓ |
| 1 | 60.0 | 0.0523599 | 0.0027416 | `R = 60.0, Bg2 = 0.002742` ✓ |
| 2 | 90.0 | 0.0349066 | 0.0012185 | `R = 90.0, Bg2 = 0.001218` ✓ |
| 3 | 120.0 | 0.0261799 | 0.0006854 | `R = 120.0, Bg2 = 0.000685` ✓ |
| 4 | 150.0 | 0.0209439 | 0.0004386 | `R = 150.0, Bg2 = 0.000439` ✓ |

**样例 2**（50 到 70，分 2 段，步长 10）：50.0 → 0.003948；60.0 → 0.002742；70.0 → 0.002014，与样例输出一致 ✓。

**规律校验**：样例 1 中 $R = 30$ 与 $R = 60$ 的曲率之比为 $0.010966 / 0.002742 = 4.00$；$R = 60$ 与 $R = 120$ 之比也是 $0.002742 / 0.000685 = 4.00$——**半径翻倍、曲率变 1/4，平方反比规律被两处独立验证。**

**点数校验**：样例 1 输出 5 行（$m+1 = 5$），样例 2 输出 3 行（$m+1=3$），与"分 m 段有 m+1 个点"一致。

## 六、常见错误与讲解

**错误 1：循环上界写成 `m-1`（漏掉端点）**

```c
for (i = 0; i < m; i++)        /* 错：只输出 m 个点，丢了终点 R1 */
for (i = 0; i <= m; i++)       /* 对：m 段有 m+1 个点，输出到终点 */
```

**错误 2：步长公式写反**

```c
h = (R1 - R0) / m;             /* 对 */
h = (R0 - R1) / m;             /* 错：步长为负，半径一路递减 */
```

**错误 3：用 `^` 表示平方**

```c
Bg2 = (PI / R) ^ 2;            /* 错：^ 是位异或；PI/R 是 double，甚至无法编译 */
Bg2 = (PI / R) * (PI / R);     /* 对 */
```

**错误 4：格式符与类型不匹配**

```c
scanf("%lf %lf %lf", &R0, &R1, &m);    /* 错：m 是 int，%lf 会破坏内存 */
scanf("%lf %lf %d", &R0, &R1, &m);     /* 对 */
printf("R = %d, Bg2 = %f\n", R, Bg2);  /* 错：R 是 double，必须用 %f/%.1f */
```

**错误 5：用累加代替 `R0 + i*h`**

```c
R = R0;
for (i = 0; i <= m; i++) { ...; R += h; }    /* 可行，但误差会累积 */
```

对本题小规模扫描两种写法结果相同；但当扫描点数很大时，累加写法会因浮点舍入而逐渐偏离，**推荐 `R0 + i*h`**。

## 七、与综合实验的衔接

- 实验 **D10（反应堆临界尺寸估算系统）**中，本练习是"扫描观察"环节：先把半径-几何曲率表算出来，与材料的 $B_m^2$ 一比，就能看出临界半径**落在哪两个相邻半径之间**。真实系统的扫描区间通常取 30 ～ 150 cm（与题目给定的典型范围一致）。这张表还是**二分法的合法性检查**：只有确认 $B_m^2 - B_g^2$ 在区间两端异号，二分法才保证能收敛到根；
- 与前面练习的衔接：练习 29（第 2 章）算了材料曲率（一个点），本练习算几何曲率（一串点）——两者合起来就构成临界方程 $B_m^2 - B_g^2 = 0$ 的两边。练习 30（第 3 章）接着利用这张表的递减规律，由残差正负判断半径偏大还是偏小；练习 24（第 4 章）把"查表找点"升级为"自动折半求根"。**从"看得见"到"算得准"，是数值方法的标准进阶路线。**
