# 第 5 章 练习 23　中子能量序列排序

**所属综合实验**：D2（D2-基于蒙特卡洛随机游走的中子慢化模拟系统）

**对应章节**：5 数组与批量数据处理（5.1 一维数组、5.2 数组元素访问、5.3 数组与循环配合——排序算法）

**场景来源**：综合实验 D2《基于蒙特卡洛随机游走的中子慢化模拟系统》（核学院）——本练习是该实验中"对落点中子能量样本序列排序统计"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

中子慢化模拟（实验 D2）会记录一批中子在到达热化前的能量样本。为了让结果可读、便于统计"有多少中子处于哪个能量段"，需要把这些**能量样本按从小到大排序**。排序后的能量序列可用于：确定能量分布的中位数、划分能群、观察慢化程度。

核能物理中能量跨 8 个数量级（0.025 eV ～ 10⁶ eV），排序时数据大小差异极大，正好用来练习**基础的交换排序（冒泡排序）**。本练习实现这个排序内核。

## 二、任务要求

编写一个完整程序 `energy_sort.c`：

1. 从键盘读入样本个数 `n`（整数，题目保证 \(1 \le n \le 50\)），再读入 `n` 个中子能量（eV，double），存入**一维数组**；
2. 用**冒泡排序**把数组按**从小到大**（升序）排列；
3. 把排序后的序列**每个元素一行**输出，用科学计数法保留 4 位小数（`%.4e`）；
4. 输出格式：第一个数前面不加多余文字，每行一个数即可。

## 三、输入输出格式

**输入**：第一行一个整数 `n`；第二行 `n` 个实数（能量，eV），用空格分隔。

**输出**：`n` 行，每行一个能量值，科学计数法保留 4 位小数，按升序排列。

## 四、样例

**样例 1**

输入：
```
7
2.0e6 5.0e5 5.0e4 1.0e3 100 1.0 0.025
```
输出：
```
2.5000e-02
1.0000e+00
1.0000e+02
1.0000e+03
5.0000e+04
5.0000e+05
2.0000e+06
```

**样例 2**

输入：
```
3
100 0.5 50
```
输出：
```
5.0000e-01
5.0000e+01
1.0000e+02
```

## 五、提示

冒泡排序的核心思想是"**相邻两个数比较，逆序就交换**"，一轮扫描把当前最大的数"冒泡"到末尾。对 n 个数需要 `n-1` 轮：

$$
\text{第 } k \text{ 轮：比较 } (a_0,a_1), (a_1,a_2), \dots, (a_{n-2},a_{n-1})
$$

外层循环 `for (i = 0; i < n - 1; i++)`，内层循环 `for (j = 0; j < n - 1 - i; j++)`，内层比较 `if (a[j] > a[j+1])` 时交换两数。交换需要**第三个临时变量**：

```c
tmp = a[j]; a[j] = a[j + 1]; a[j + 1] = tmp;
```

**完成本练习后你将具备的能力**：书写嵌套循环、用临时变量交换两个变量的值、理解冒泡排序的轮数与比较次数、把待排序的物理量数组整理成有序序列——这些是实验 D2 中"能量样本统计模块"的地基。
