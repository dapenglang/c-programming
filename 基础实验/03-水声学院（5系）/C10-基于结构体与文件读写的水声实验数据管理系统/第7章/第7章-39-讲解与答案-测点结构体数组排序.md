## 二、预备知识：结构体数组排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

第 5 章已经用冒泡排序排过 double 数组。现在要排的是"记录"：排序依据只是一个成员（水深），但**跟着动的必须是整条记录**——只把 `depth` 互换了、`id` 没换，编号就张冠李戴。

好消息是 C 的结构体赋值 `a = b;` 会**逐成员整体复制**，交换一个结构体变量的代码与交换一个 int 完全同构。

### 2. 冒泡骨架 + 新的比较键

```c
for (i = 0; i < n - 1; i++) {           /* 共 n-1 轮 */
    for (j = 0; j < n - 1 - i; j++) {   /* 每轮两两相邻比较 */
        if (r[j].depth > r[j + 1].depth) {   /* 键值：depth 升序 */
            struct Rec t = r[j];        /* 整条交换，三行 */
            r[j] = r[j + 1];
            r[j + 1] = t;
        }
    }
}
```

与第 5 章的唯一区别：比较对象从 `a[j] > a[j+1]` 变成 `r[j].depth > r[j+1].depth`，交换从单值换成整条。

### 3. 用本例走一遍

样例 1：录入顺序 `S01(22.0), S02(12.5), S03(15.5)`。

**第 1 轮**（j 走 0、1）：

| j | 比较 | 动作 | 数组状态 |
|---|---|---|---|
| 0 | 22.0 > 12.5 | 交换 S01↔S02 | S02(12.5), S01(22.0), S03(15.5) |
| 1 | 22.0 > 15.5 | 交换 S01↔S03 | S02(12.5), S03(15.5), S01(22.0) |

**第 2 轮**（j 走 0）：12.5 > 15.5？否，不动。

结果：`S02, S03, S01`——注意 `S01` 连同它的时刻 `08:30` 一起被搬到了最后，编号、水深、时刻始终配套。

**相等情形**（样例 2）：`B3(8.0)` 与 `A1(8.0)` 比较时条件 `>` 不成立，不交换，保持录入顺序 `B3` 在前——冒泡排序是**稳定排序**。

> **这个模式在综合实验中反复出现**：C10 的按深度排序（M7）、按时间排序、以及 C8 的声线路径按传播时间排序（M8），全是"同一条冒泡骨架，换一个比较成员"。用结构体指针做函数参数封装的版本（`void sort(struct Rec *a, int n)`）在综合实验里更常用，原理相同。

## 三、解题思路

1. 定义 `struct Rec`，读入 `n` 条记录；
2. 冒泡排序：按 `.depth` 升序比较，结构体赋值整条交换；
3. 逐条输出排序后的记录。

## 四、参考代码

```c
#include <stdio.h>
#include <string.h>

struct Rec {
    char id[16];      /* 测点编号 */
    double depth;     /* 水深 m */
    char tm[8];       /* 观测时刻 */
};

int main(void)
{
    struct Rec r[50], t;
    int n, i, j;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%s", r[i].id);
        scanf("%lf", &r[i].depth);
        scanf("%s", r[i].tm);
    }

    for (i = 0; i < n - 1; i++) {               /* 冒泡：n-1 轮 */
        for (j = 0; j < n - 1 - i; j++) {
            if (r[j].depth > r[j + 1].depth) {  /* 按水深升序 */
                t = r[j];                       /* 整条交换 */
                r[j] = r[j + 1];
                r[j + 1] = t;
            }
        }
    }

    for (i = 0; i < n; i++) {
        printf("%-9s%9.2f%6s\n", r[i].id, r[i].depth, r[i].tm);
    }
    return 0;
}
```

## 五、运行验证

**样例 1**：

```
3
S01 22.0 08:30
S02 12.5 10:00
S03 15.5 09:15
S02          12.50   10:00
S03          15.50   09:15
S01          22.00   08:30
```

**样例 2**（含相等键值，检验稳定性）：

```
4
B3 8.0 11:00
A1 8.0 09:00
C2 5.5 10:30
D4 9.9 08:45
C2           5.50   10:30
B3           8.00   11:00
A1           8.00   09:00
D4           9.90   08:45
```

| 样例 | 验证点 | 程序输出 |
|---|---|---|
| 1 | 12.5 < 15.5 < 22.0，记录整体搬动 | ✓ |
| 2 | 相等键 8.0 保持录入序（B3 在 A1 前） | ✓ |

**反例验证**：若交换时只换 `depth` 不换 `id`（把 `t = r[j];` 换成 `t.depth = r[j].depth; ...`），样例 1 会输出 `S01 12.50` 之类的错位结果——证明"必须整条交换"。

## 六、常见错误与讲解

**错误 1：只交换键值成员**

```c
t = r[j].depth;  r[j].depth = r[j+1].depth;  r[j+1].depth = t;  /* 错：id、tm 没跟着走 */
```

**错误 2：比较条件用 `>=`**

```c
if (r[j].depth >= r[j + 1].depth)   /* 错：相等也交换，排序慢且不稳定 */
```

**错误 3：交换临时变量类型用错**

```c
double t = r[j];        /* 错：t 是 double，装不下整条记录 */
struct Rec t = r[j];    /* 对 */
```

**错误 4：冒泡轮数/内层边界写错**

```c
for (j = 0; j < n - i; j++)          /* 错：j+1 会越界访问 r[n] */
for (j = 0; j < n - 1 - i; j++)      /* 对：j+1 最大为 n-1-i，不越界 */
```
