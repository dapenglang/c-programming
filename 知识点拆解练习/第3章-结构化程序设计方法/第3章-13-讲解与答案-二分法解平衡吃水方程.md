## 二、预备知识：二分法解方程的基本原理（零基础阅读）

### 1. 问题是怎么来的

冰块浮在水上，什么时候平衡？物理定律告诉我们：**浮力等于重力**时平衡。浮力随浸没深度 $d$ 增大而增大，重力是固定的。把"浮力 − 重力"看成一个关于 $d$ 的量 $f(d)$：$d$ 太小时 $f(d) < 0$（浮力不够），$d$ 太大时 $f(d) > 0$（浮力过头）。平衡吃水正是让 $f(d)$ 从负变正的那个临界点，也就是方程 $f(d) = 0$ 的根。

### 2. 方法是怎么想出来的

先把这个方程具体写出来。断面宽度 $w(z) = W0 + K z$，则浸没体积是宽度沿高度累积出来的：

$$
V_{sub}(d) = L\int_0^{d}(W0 + K z)\,dz = L\left(W0\,d + \frac{K}{2}d^{2}\right)
$$

整体体积 $V_{tot} = L\left(W0 H + \dfrac{K}{2}H^{2}\right)$ 是定值。由 $\rho_w g V_{sub} = \rho_i g V_{tot}$，两边同除以公共量 $g\cdot L$，得到

$$
f(d) = \rho_w\left(W0\,d + \frac{K}{2}d^{2}\right) - \rho_i\left(W0\,H + \frac{K}{2}H^{2}\right)
$$

注意右端第二项是**常数**（只含 $H$），可以事先算好；第一项含 $d^2$，随 $d$ 增大而增大，所以 $f(d)$ 在 $[0,H]$ 上单调递增，二分法一定收敛。取中点 $mid$：若 $f(mid) < 0$，说明吃水还偏小，把左端抬到 $mid$；若 $f(mid) > 0$，说明吃水偏大，把右端压到 $mid$。区间每轮减半，直到 $hi - lo < 10^{-6}$。

### 3. 用本例走一遍

取样例 1：$H = 6.0$、$W0 = 4.0$、$K = 0.10$。

先算常数项：$W0 H + \dfrac{K}{2}H^{2} = 24 + 0.05 \times 36 = 24 + 1.8 = 25.8$，故重力项 $= 917 \times 25.8 = 23658.6$。

- 验端点：$f(0) = -23658.6 < 0$；$f(6) = 1025 \times 25.8 - 23658.6 = 26445 - 23658.6 = 2786.4 > 0$，根确实在 $[0,6]$；
- 第 1 次：$mid = 3$，$f(3) = 1025 \times (12 + 0.45) - 23658.6 = 12761.3 - 23658.6 < 0$ → $lo = 3$；
- 第 2 次：$mid = 4.5$，$f(4.5) = 1025 \times (18 + 1.0125) - 23658.6 = 19487.8 - 23658.6 < 0$ → $lo = 4.5$。

区间从 $[0,6]$ 缩到 $[4.5,6]$，继续对折，最终收敛到 $d = 5.405189$ m。

### 4. 编程时怎么用它

三个要点：**① 函数值**：把 $f(d)$ 写成一行表达式，把与 $d$ 无关的部分（$\rho_i \times 25.8$）先算成常数 `area_tot`，提高可读性；**② 初始区间**：直接取 $[0, H]$，由 $\rho_w > \rho_i$ 可保证两端异号；**③ 方向判断**：本题 $f$ 单调递增，所以 `f(mid) < 0` 就抬左端、否则压右端。循环条件仍用 `hi - lo >= 1e-6`。

## 三、解题思路

1. **读入** `H`、`W0`，把 $\rho_w,\rho_i,K$ 定义为常量；
2. **算常数项**：`area_tot = W0 * H + 0.5 * K * H * H;`（整体断面面积）；
3. **二分主体**：区间 `[0, H]`，循环里算 `mid` 和 `fmid = RHO_W*(W0*mid + 0.5*K*mid*mid) - RHO_I*area_tot;`；
4. **定方向**：`if (fmid < 0) lo = mid; else hi = mid;`；
5. **输出**：`printf("draft = %.6f m\n", (lo + hi) / 2.0);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double RHO_W = 1025.0;   /* 海水密度 kg/m^3 */
    const double RHO_I = 917.0;    /* 冰密度 kg/m^3 */
    const double K     = 0.10;     /* 断面宽度增长率 m/m */

    double H, W0;                  /* 冰块总高、底面宽度 */
    double lo, hi, mid;            /* 二分区间与中点 */
    double fmid;                   /* 中点处的平衡函数值 */
    double area_tot;               /* 整体断面面积(长度已约去) */

    scanf("%lf %lf", &H, &W0);

    /* 整体断面面积: ∫_0^H (W0 + K z) dz = W0*H + K*H^2/2 */
    area_tot = W0 * H + 0.5 * K * H * H;

    lo = 0.0;                      /* f(0) < 0 */
    hi = H;                        /* f(H) > 0 */

    /* 二分法求 f(d)=0 的根 */
    while (hi - lo >= 1e-6) {
        mid  = (lo + hi) / 2.0;
        fmid = RHO_W * (W0 * mid + 0.5 * K * mid * mid) - RHO_I * area_tot;
        if (fmid < 0.0) {
            lo = mid;              /* 浮力还不够，吃水偏小 */
        } else {
            hi = mid;              /* 浮力已足够，吃水偏大 */
        }
    }

    printf("draft = %.6f m\n", (lo + hi) / 2.0);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：把常数项写成含 mid 的形式**

```c
fmid = RHO_W*(W0*mid + 0.5*K*mid*mid) - RHO_I*(W0*mid + 0.5*K*mid*mid); /* 错：两端同形，恒为 0 */
```

重力项只与**总高 H** 有关，不能跟着 mid 变。正确的重力项是 $\rho_i\,area\_tot$，其中 `area_tot` 用 `H` 算。

**错误 2：判断方向反了**

```c
if (fmid < 0.0) hi = mid;   /* 错：吃水偏小却压右端，区间会跑向错误一侧 */
if (fmid < 0.0) lo = mid;   /* 对：f<0 说明还差，抬高下限 */
```

记忆口诀：**"负数往上抬，正数往下压"**。

**错误 3：整数除法截断**

```c
area_tot = W0 * H + (1 / 2) * K * H * H;   /* 错：1/2 = 0，二次项整项消失 */
area_tot = W0 * H + 0.5 * K * H * H;       /* 对：写 0.5 或 1.0/2 */
```

C 语言中两个 `int` 相除结果仍为 `int`，`1/2` 等于 `0`。凡是可能出现小数的除法，至少一个操作数要写成实数。

**错误 4：循环体里忘记更新区间**

```c
while (hi - lo >= 1e-6) {
    mid = (lo + hi) / 2.0;
    fmid = ...;              /* 算了 fmid 却没更新 lo/hi —— 死循环 */
}
```

二分法的循环体必须**恰好**更新 `lo` 或 `hi` 中的一个，否则区间不变、永远达不到精度。

- 在实验 **C8（冰块浮力与平衡吃水）**中，"求平衡吃水"就是本练习的直接应用：实际程序里断面型线可能由插值表给出（第 5 章会存入数组），但"构造 f(d)、二分求根"的框架完全一致；
