## 二、预备知识：梯形公式的基本原理（零基础阅读）

### 1. 问题是怎么来的

冰块淹没部分的侧壁是**曲边**的，要算的截面积就是曲边梯形的面积 $\int_a^b f(x)\,dx$——可"积分"这个数学符号程序不会执行，程序只会做加减乘除。数值积分的全部思路就一句话：**用直线代替曲线，把曲边问题变成直边问题**。最简单的替身：把曲边梯形的两个上角用一条直线连起来，曲边梯形就变成了一个真正的直边梯形，面积用中学公式就能算。

### 2. 公式是怎么推导出来的（并且和线性插值接上了）

设区间两端 $x_0$、$x_1$ 处曲线的纵坐标分别是 $y_0 = f(x_0)$、$y_1 = f(x_1)$（本例中就是水线宽 $b_1$ 与底宽 $b_2$）。连接 $(x_0, y_0)$ 与 $(x_1, y_1)$ 的直线，正是第 2 章学过的**线性插值**：两端值已知、中间按直线比例取值。于是曲边梯形被替换成上底为 $y_0$、下底为 $y_1$、高为 $x_1 - x_0$ 的直边梯形：

$$
\int_{x_0}^{x_1} f(x)\,dx \;\approx\; \frac{(y_0 + y_1)\,(x_1 - x_0)}{2}
$$

用大白话读：**"两端值的平均 × 区间长度"**。当 $y_0 = y_1$（本例样例 2）它退化成矩形面积 $y_0 \, h$；当曲线本身是直线时，这个公式**分毫不差**——误差只在曲线弯曲时产生，弯得越厉害、区间越宽，误差越大。这解释了后面练习 09、10 为什么要"分成许多小段"：把大区间切成窄条，每条里曲线都近似直线，梯形公式逐条计算再相加，误差就小了。

### 3. 用本例走一遍（手算）

样例 1：上底（水线宽）$b_1 = 4.8$，下底（底宽）$b_2 = 3.5$，高（吃水）$h = 1.2$：

- 两端值的平均：$(4.8 + 3.5)/2 = 8.3/2 = 4.15$；
- 乘区间长度：$4.15 \times 1.2 = 4.98$（m²）。

几何直观核对：4.98 介于"窄矩形" $3.5 \times 1.2 = 4.2$ 与"宽矩形" $4.8 \times 1.2 = 5.76$ 之间，合理。

### 4. 编程时怎么用它

公式里只有三个输入量与一个输出量，编程就是把公式原样翻译成一行赋值语句，唯一要注意括号：$(b_1 + b_2)$ 必须先加、除以 2 再乘 $h$（或先乘后除，结果相同）。单独一行也许显得"太简单"，但请把这一行记牢——练习 09 里它会被装进循环体，练习 10 里它会变成矩形版本，第 4 章、第 8 章里它还会被封装成函数。

## 三、解题思路

1. **确定变量**：`b1`、`b2`、`h` 与 `area` 全是 `double`；
2. **读入三个数**；
3. **套梯形公式**：`area = (b1 + b2) / 2.0 * h`；
4. **输出**：`%.2f` 保留 2 位小数；
5. **自查**：结果应落在"窄矩形面积 $b_2 h$"与"宽矩形面积 $b_1 h$"之间，越界即公式写错。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double b1;      /* 水线处宽度（上底），m */
    double b2;      /* 底部宽度（下底），m */
    double h;       /* 吃水深度，m */
    double area;    /* 淹没截面积，m2 */

    scanf("%lf %lf %lf", &b1, &b2, &h);

    /* 梯形公式：两端值的平均 × 区间长度 */
    area = (b1 + b2) / 2.0 * h;

    printf("area = %.2f\n", area);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| `4.8 3.5 1.2` | $(4.8+3.5)/2 \times 1.2 = 4.15 \times 1.2 = 4.98$ | `area = 4.98` ✓ |
| `6.0 6.0 0.8` | $(6.0+6.0)/2 \times 0.8 = 6.0 \times 0.8 = 4.8$（矩形退化） | `area = 4.80` ✓ |
| `2.0 0.0 3.0` | $(2.0+0)/2 \times 3.0 = 3.0$（三角形退化） | `area = 3.00` ✓ |

第 2、3 行验证了梯形向矩形、三角形的退化情形——公式在特例下仍然自洽。

## 六、常见错误与讲解

**错误 1：括号遗漏导致运算顺序错误**

```c
area = b1 + b2 / 2.0 * h;      /* 错：先算 b2/2*h，再与 b1 相加 */
area = (b1 + b2) / 2.0 * h;    /* 对：先加后除再乘 */
```

用样例 1 自查：错误写法输出 $4.8 + 3.5/2 \times 1.2 = 6.9$，与 4.98 明显不符。

**错误 2：除以整数 2 引发误用**

```c
area = (b1 + b2) / 2 * h;   /* 本题恰好没问题：左边是实数，除法按实数进行 */
```

`(b1 + b2)` 是 `double`，除以整数 2 仍是实数除法。但养成写 `2.0` 的习惯更安全——一旦公式改成两个整型中间量的运算（如面积按整型像素计），`/ 2` 就会变成整数除法吞掉小数。

**错误 3：变量类型用 int**

```c
int b1, b2, h;    /* 错：宽度与吃水是连续量，读入 4.8 会丢成 4 */
```

物理实数量一律 `double`（第 2 章立的规矩）。

**错误 4：把面积公式当成"体积公式"去多乘一个方向**

本例求的是竖直面内的**截面积**（m²），不要自行扩展成三维体积。综合实验 C8 中体积是第 5 章用"沿长度方向逐段积分"再做的，现在只负责把一段算对。

## 七、与综合实验的衔接

- 实验 **C8（冰块浮力）**中，淹没体积 = 沿冰块长度方向把若干个这样的截面积"叠"起来（每段再乘段长）。本练习产出的是其中一个截面积；练习 09 会把"叠"的动作写成循环（沿时间的位移积分同理）；学到第 5 章（数组）后，各段的宽度将存入数组批量处理；学到第 4 章（函数）后，梯形公式会封装成 `double trapezoid(double y0, double y1, double w)`，被位移、体积、剂量等多个实验共用；
- **梯形公式 = 线性插值的面积版**这一联系值得记住：第 2 章用它插值，第 3 章用它求积，第 8 章的拉格朗日插值仍是它的多点推广。线性近似是整门数值计算课程的第一块基石。
