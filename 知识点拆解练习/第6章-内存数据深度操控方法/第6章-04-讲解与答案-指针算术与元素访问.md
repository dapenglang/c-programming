## 二、预备知识：指针算术的基本原理（零基础阅读）

### 1. 先画出声速表的内存

`double c[6]` 在内存中是 6 个连续的 8 字节柜子（地址为示意值）：

```
下标        0        1        2        3        4        5
地址   0061FEF0 0061FEF8 0061FF00 0061FF08 0061FF10 0061FF18
值      1448.6   1450.2   1452.1   1451.0   1449.3   1447.8
```

相邻地址相差 **8**（十六进制 `8`）——因为一个 `double` 占 8 字节。`p = c;` 后 `p` 指向下标 0。

### 2. 指针加 1，跨过一个元素而不是一个字节

对 `double *p` 做 `p + 1`，得到的是"下一个元素"的地址：数值上地址增加 8（一个元素的字节数），**不是 1**。一般地，`p + i` 的地址数值等于 `p` 的地址加 $i \times 8$：

```
p     = 0061FEF0  → c[0]
p + 1 = 0061FEF8  → c[1]   （+0x08）
p + 2 = 0061FF00  → c[2]   （+0x10）
p + 3 = 0061FF08  → c[3]   （+0x18，即十进制 24）
```

这就是"**按元素跨度移动**"：编译器知道 `p` 是 `double *`，自动把偏移量乘上元素大小 8。你表达"走几格"，编译器负责"走多远"。若 `p` 是 `int *`（4 字节），`p + 1` 就只加 4——跨度永远跟随指针类型。

### 3. `*(p + i)` 与 `p[i]` 为什么等价

C 语言规定：下标运算符 `a[i]` 就是 `*(a + i)` 的缩写。所以以下写法取的都是 `c[3]`：

```c
c[3]        *(c + 3)        p[3]        *(p + 3)      /* 此处 p == c */
```

`p[i]` 完全合法——即使 `p` 是指针变量而不是数组名，`p[3]` 也表示"从 `p` 指的地址跨过 3 个元素取值"。这正是实验 C1 中"跳到第 4 档取声速"的底层机制。

### 4. 一个经典陷阱：`*p + i`

`*` 与 `+` 的优先级不同：`*p + i` 是"先解引用取出 `c[0]`，再加 i"（本题即 $1448.6 + i$）；`*(p + i)` 才是"先跨 i 格，再取值"。**想跳档，括号必须写。**

### 5. 用地址差做实验

把 `&c[0]` 与 `&c[3]` 用 `%p` 打出来相减（十六进制），结果应为 `0x18` = 24 字节 = $3 \times 8$。这道"测量题"把第 2 点的文字结论变成了你亲眼所见的数据，值得每个初学者亲手做一次。

## 三、解题思路

1. **读入**：6 个声速用普通循环 `scanf("%lf", &c[i])` 读入（此处 `&c[i]` 与 `c + i` 等价）；
2. **第一遍输出**：`for (i = 0; i < 6; i++) printf("%.1f ", *(p + i));`——纯指针偏移写法；
3. **第二遍输出**：`for (i = 0; i < 6; i++) printf("%.1f ", p[i]);`——下标写法，输出应与第一遍逐字相同；
4. **定点访问**：`*p` 与 `*(p + 3)`，同时打印 `(void *)p` 与 `(void *)(p + 3)` 两个地址；
5. 输出地址行前后加说明文字，提醒"地址每次运行不同，以相对差 24 字节为准"。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double c[6];        /* 6 档深度对应的声速，m/s */
    double *p;          /* 遍历与跳档用指针 */
    int i;

    for (i = 0; i < 6; i++)
        scanf("%lf", &c[i]);

    p = c;              /* p 指向下标 0（数组名即首元素地址） */

    printf("*(p+i): ");
    for (i = 0; i < 6; i++)
        printf("%.1f ", *(p + i));   /* 指针加偏移后解引用 */
    printf("\n");

    printf("p[i]  : ");
    for (i = 0; i < 6; i++)
        printf("%.1f ", p[i]);       /* 下标写法，与上一行等价 */
    printf("\n");

    printf("first = %.1f\n", *p);
    printf("p[3] = %.1f addr0 = %p addr3 = %p\n",
           *(p + 3), (void *)p, (void *)(p + 3));

    return 0;
}
```

## 五、运行验证

样例 1（输入 `1448.6 1450.2 1452.1 1451.0 1449.3 1447.8`）：

| 输出行 | 验证要点 |
|---|---|
| `*(p+i): 1448.6 1450.2 1452.1 1451.0 1449.3 1447.8` | 指针偏移遍历正确 |
| `p[i]  : 1448.6 1450.2 1452.1 1451.0 1449.3 1447.8` | 与上一行逐字相同，等价性成立 |
| `first = 1448.6` | `*p` 取首元素 |
| `p[3] = 1451.0 addr0 = 0061FEF0 addr3 = 0061FF08` | 第 4 档值 1451.0；地址值每次运行不同，以相对关系为准：addr3 比 addr0 大 `0x18`（24 字节 = $3 \times 8$） |

样例 2 为等差声速序列，两行遍历输出相同，`p[3] = 1507.5`，地址差同样为 24 字节 ✓。

## 六、常见错误与讲解

**错误 1：漏写括号**

```c
printf("%.1f ", *p + i);    /* 错：输出 c[0] + i，不是 c[i] */
printf("%.1f ", *(p + i));  /* 对 */
```

`*` 优先于 `+`。这是指针算术里最常见的笔误，出错后往往"每个数都偏差一个递增量"，看到这种症状先查括号。

**错误 2：以为 `p + 1` 只加一个字节**

```c
/* 误以为 p+3 与 p 只差 3 字节，验证时发现差 24 字节就以为程序错了 */
```

差 24 字节才是正确的：`double *` 加 1 跨 8 字节，加 3 跨 24 字节。**跨度 = 元素个数 × 元素大小**。

**错误 3：对数组名做指针算术后赋回**

```c
c = c + 3;    /* 错：数组名是地址常量，不能被赋值 */
```

需要"移动"时用指针变量 `p` 承接：`p = c + 3;`。

**错误 4：越界访问**

```c
printf("%.1f", *(p + 6));   /* 错：只有 6 个元素，p+6 已越过末尾 */
```

`p + 6` 与首元素差 48 字节，已落在数组之外。指针算术允许算出这个地址（作为"末尾哨兵"比较用），但**解引用它就是越界**。

## 七、与综合实验的衔接

实验 **C1（声速剖面插值）**在查找"目标深度落在哪两档之间"时，正是让指针在声速表上按档跳动：`p + i` 定位上档、`p + i - 1` 定位下档，再对 `*p` 与 `*(p - 1)` 做插值。你以后在 C9 压力场、D4 温度场中还会遇到"行指针"在二维网格上的同类运算（练习 16 专门训练）。另外，`p[i]` 与 `*(p+i)` 的等价性也解释了第 5 章"数组作函数参数"为何写成 `double a[]` 或 `double *a` 都可以——形参里的数组名本来就是指针。
