# 第 3 章 练习 30　临界方程残差符号判定

**所属综合实验**：D10（D10-基于迭代求解与二分法的反应堆临界尺寸估算系统）

**对应章节**：3 程序控制结构（3.2 选择结构——if/else、3.5 关系与逻辑运算）

**场景来源**：综合实验 D10《基于迭代求解与二分法的反应堆临界尺寸估算系统》（核学院）——本练习是该实验中"由残差正负判断半径偏大还是偏小"环节的最小实现，也是二分法每一步的方向判据。

**建议用时**：25 分钟

## 一、应用场景

临界条件是**材料曲率等于几何曲率**：

$$
B_m^2 = B_g^2
$$

把两者相减，得到一个只与半径 $R$ 有关的量，称为**残差**：

$$
f(R) = B_m^2 - B_g^2 = \frac{k-1}{L^2} - \left(\frac{\pi}{R}\right)^2
$$

$f(R) = 0$ 时的 $R$ 就是临界半径。但怎么知道一个给定的 $R$ 是偏大还是偏小？

关键在于 $B_g^2$ **随 $R$ 单调递减**（练习 29 第 3 章的表已经证实）：$R$ 越大，$B_g^2$ 越小，$f(R)$ 越大。因此：

- 若 $f(R) > 0$，说明 $B_m^2 > B_g^2$，几何曲率还太小——**半径偏大**，要**减小** $R$；
- 若 $f(R) < 0$，说明 $B_m^2 < B_g^2$，几何曲率太大——**半径偏小**，要**增大** $R$；
- 若 $f(R) = 0$，正好临界。

**这个符号判据就是二分法每一步"往左还是往右"的方向盘。** 本题实现这一判定。

## 二、任务要求

编写一个完整程序 `residual.c`：

1. 从键盘读入两组参数：增殖因子 `k`、扩散长度 `L`（实数，**题目保证 1.05 ≤ k ≤ 1.5，2 ≤ L ≤ 10**），以及待检验的半径 `R`（实数，cm，**题目保证 30 ≤ R ≤ 150**）；
2. 程序中用**常量**存放圆周率 $\pi$（3.14159265358979）；
3. 计算材料曲率 $B_m^2$、几何曲率 $B_g^2$ 及残差 $f = B_m^2 - B_g^2$；
4. 用 **if / else if / else 选择结构**按残差符号输出判定结论与调整建议：
   - $f > 0$：输出 `R too large`，并给出建议 `decrease R`；
   - $f < 0$：输出 `R too small`，并给出建议 `increase R`；
   - 否则：输出 `critical`。
5. 先输出残差的值（保留 6 位小数，会带正负号），再输出判定结果。

## 三、输入输出格式

**输入**：一行，三个实数，依次为 k、L（cm）、R（cm），用空格分隔。

**输出**：共两行或三行——
- 第一行：`f = 残差值`（保留 6 位小数，带正负号）；
- 第二行：`R too large` 或 `R too small` 或 `critical`；
- 第三行（仅当偏大或偏小时）：`decrease R` 或 `increase R`。

## 四、样例

**样例 1**（半径偏小）

输入：
```
1.20 5.0 30.0
```
输出：
```
f = -0.002966
R too small
increase R
```

**样例 2**（半径偏大）

输入：
```
1.20 5.0 120.0
```
输出：
```
f = 0.007315
R too large
decrease R
```

**样例 3**（接近临界）

输入：
```
1.20 5.0 60.0
```
输出：
```
f = 0.005258
R too large
decrease R
```

## 五、提示

- 残差公式的代码表达：
  ```c
  Bm2 = (k - 1.0) / (L * L);
  Bg2 = (PI / R) * (PI / R);
  f   = Bm2 - Bg2;
  ```
- $B_g^2$ 的平方仍用乘法，**不能用 `^`**；
- **判断符号要小心**：$f$ 是浮点数，直接用 `if (f > 0.0)` / `else if (f < 0.0)` / `else` 三分支处理，`else` 分支覆盖 $f = 0$ 与极小误差两种情况；
- 判定逻辑不必再重算 $B_m^2$、$B_g^2$——直接用 `f` 的符号即可，**符号里已经包含了全部信息**；
- 记忆口诀：**$R$ 变大 → $B_g^2$ 变小 → $f$ 变大**。所以 $f$ 为正意味着 $R$ 已经太大；
- 验证方法：样例 1 的 $R = 30$ cm 太小，几何曲率 0.010966 超过了材料的 0.008000，所以 $f = 0.008000 - 0.010966 = -0.002966$ 为负——**负号对应"半径偏小"，符号与结论必须一致**。

**完成本练习后你将具备的能力**：把物理关系翻译成残差函数、由残差符号反推自变量的调整方向、用选择结构实现三分支判定——这些是实验 D10 中"二分法方向判据"的地基，也是整个数值求根的核心逻辑。
