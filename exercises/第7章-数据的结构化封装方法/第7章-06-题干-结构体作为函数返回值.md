# 第 7 章 练习 06　结构体作为函数返回值

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.3 结构体变量作为函数参数）

**场景来源**：综合实验 C7《冰载荷样本统计与载荷辨识系统》（水声学院）——本练习是该实验中"阻力样本三大统计量一次求出"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

载荷辨识系统（实验 C7）对一批阻力样本要同时给出**最大值、最小值、平均值**三个统计量。第 4 章的函数只能 `return` 一个数，要算三个量就得写三个函数或借助全局变量，都不够清爽。结构体提供了第三种办法：把三个统计量打包成一个"统计结果"类型，让统计函数**返回整个结构体**——调用一次，三个结果一起拿回。这是 7.3 的最后一个要点，也是实验 C7 统计模块"一次算全、整体移交"的实现方式。

## 二、任务要求

编写一个完整程序 `load_stat.c`：

1. 定义统计结果结构体类型（成员名不得改动）：

```c
struct Stat {
    double max;   /* 最大阻力（kN） */
    double min;   /* 最小阻力（kN） */
    double avg;   /* 平均阻力（kN） */
};
```

2. 编写函数 `struct Stat analyze(const double a[], int n);`：形参为阻力数组与样本数，**返回值类型是 struct Stat**，函数内部一次遍历同时求出三个统计量；
3. `main` 中读入 $n$（$1 \le n \le 20$）与 $n$ 个阻力样本（kN），调用 `analyze`，用一个 `struct Stat` 变量接住返回值；
4. 按格式输出三个统计量。

## 三、输入输出格式

**输入**：第一行一个整数 $n$（$1 \le n \le 20$）；第二行 $n$ 个实数（kN），以空格分隔。

**输出**：三行：`最大阻力 = X kN`、`最小阻力 = X kN`、`平均阻力 = X kN`，均保留 **2 位小数**。

## 四、样例

**样例 1**

输入：
```
6
12.5 8.3 15.2 9.8 11.4 13.0
```
输出：
```
最大阻力 = 15.20 kN
最小阻力 = 8.30 kN
平均阻力 = 11.70 kN
```

**样例 2**

输入：
```
4
6.5 7.2 5.9 8.0
```
输出：
```
最大阻力 = 8.00 kN
最小阻力 = 5.90 kN
平均阻力 = 6.90 kN
```

## 五、提示

- 最大值、最小值的初值取**第一个样本** `a[0]`，再从前往后逐个比较更新；
- 平均值 = 累加和 ÷ n，和用 `double sum` 累加；
- 接收返回值：`struct Stat r; r = analyze(f, n);`——结构体之间的整体赋值；
- `const double a[]` 表示函数承诺不修改数组内容（第 6 章 const 知识的复习）。

**完成本练习后你将具备的能力**：定义"结果打包"型结构体、编写返回结构体的函数、用一次调用拿到多个计算结果——实验 C7 统计模块与 C8 求解模块都会用到这一技巧。
