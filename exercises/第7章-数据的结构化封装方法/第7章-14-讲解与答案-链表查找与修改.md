## 二、预备知识：遍历查找与"改数据不改链"（零基础阅读）

### 1. 链表的查找只能是"顺序查找"

数组可以按下标直接跳到第 `i` 个元素，也可以对有序数组做二分查找；但链表的节点靠 `next` 一根根串起来，**没有下标、不能随机访问**，所以想找某个节点只能**从头顺着链一个一个比**，这叫**顺序查找**。查找一个"满足条件的节点"和上一题的"遍历统计"用的是同一副骨架，区别只在于：找到后要**做点事**。

```
head ──► [101|30.0|●] ──► [102|10.0|●] ──► [103|50.0|●] ──► NULL
           ▲ 30>20? 是 → 改成 24.0
                          ▲ 10>20? 否 → 保持
                                        ▲ 50>20? 是 → 改成 40.0
```

### 2. 节点的"数据域"和"指针域"要分清

一个节点里有两类成员，操作它们的效果完全不同：

- **数据域**（`id`、`load`）：描述这条记录的内容。改它只是"把记录的内容换一换"，**链的形状丝毫不变**；
- **指针域**（`next`）：描述"下一个节点在哪"。改它会**改变链的连接关系**（这正是头插、尾插、删除在做的事）。

本题要做的是"把异常测点的载荷折减"，属于**改数据域**。所以命中条件后只需：

```c
p->load = p->load * k;      /* 只动数据，不动链 */
```

改完这一句，节点的内容变了，但 `head → 节点1 → 节点2 → …` 的连接一根也没断。把"改数据"和"改连接"这两件事分开想，是读懂所有链表代码的关键。下图是一个节点被就地修改的前后对比：

```
修改前节点：  [103 | 50.0 | ●]        修改后节点：  [103 | 40.0 | ●]
               ▲数据  ▲指针                         ▲数据变  ▲指针不变
```

（这里 $0.8 \times 50.0 = 40.0$，指针域 `●` 指向的下一节点不变。）

### 3. 修改条件的写法与边界

题目要求"载荷**超过**阈值"的才折减，对应严格大于：$load > limit$。若写成 `>=`，恰好等于阈值的正常测点也会被误改。另外要注意：

- **修改与统计要同步**：命中条件时既要改值、又要让 `modified` 加一，两件事写在一个 `if` 里；
- **输出顺序**：必须先整条链遍历修改完，再（或边改边）输出。若先输出后修改，打印的是原值，看不出折减效果；
- **即使没有一条命中**，`modified` 也会是 `0`，程序照常输出，不需要特殊处理。

`malloc` 检查、`free` 释放、遍历三要素（起点 / 条件 / 推进）都与前两题一致。

## 三、解题思路

1. **建链**：尾插法把 `n` 条记录建成链表；
2. **读入参数**：`limit` 与 `k`；
3. **初始化计数**：`modified = 0;`；
4. **遍历修改**：`p = head` 起，对 `p->load > limit` 的节点执行 `p->load *= k; modified++;`，然后 `p = p->next;`；
5. **输出**：再次遍历，按 `%.2f` 输出修改后的载荷，最后输出 `modified`；
6. **释放链表**。

## 四、参考代码

```c
#include <stdio.h>
#include <stdlib.h>

struct IceLoad {
    int    id;
    double load;
    struct IceLoad *next;
};

int main(void)
{
    int n, i, id, modified;
    double load, limit, k;
    struct IceLoad *head = NULL, *tail = NULL, *p;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {            /* 尾插建链 */
        scanf("%d %lf", &id, &load);
        p = (struct IceLoad *)malloc(sizeof(struct IceLoad));
        if (p == NULL) { printf("malloc failed\n"); return 1; }
        p->id = id; p->load = load; p->next = NULL;
        if (head == NULL) head = tail = p;
        else { tail->next = p; tail = p; }
    }
    scanf("%lf %lf", &limit, &k);        /* 阈值与折减系数 */

    modified = 0;
    p = head;                            /* 遍历查找并修改 */
    while (p != NULL) {
        if (p->load > limit) {           /* 命中异常测点 */
            p->load = p->load * k;       /* 就地折减，只改数据域 */
            modified++;
        }
        p = p->next;
    }

    p = head;                            /* 输出修改后的链表 */
    while (p != NULL) {
        printf("%d %.2f\n", p->id, p->load);
        p = p->next;
    }
    printf("modified = %d\n", modified);

    while (head != NULL) { p = head; head = head->next; free(p); }
    return 0;
}
```

## 五、运行验证

样例 1 的链表 `101:30 → 102:10 → 103:50`，`limit = 20`、`k = 0.8`：

| 节点 | 原载荷 | 30 > 20? | 修改后 | modified |
|---|---|---|---|---|
| 101 | 30.0 | 是 | $30 \times 0.8 = 24.0$ | 1 |
| 102 | 10.0 | 否 | 10.0（不变） | 1 |
| 103 | 50.0 | 是 | $50 \times 0.8 = 40.0$ | 2 |

输出

```
101 24.00
102 10.00
103 40.00
modified = 2
```

与样例 1 一致。样例 2 中 `limit = 20`、`k = 0.5`：节点 `25` 与 `100` 超阈，分别变成 $12.50$ 与 $50.00$，其余不变，`modified = 2`，输出与样例 2 一致。注意折减后的 `25 → 12.50` 已低于阈值，但本题**不重复判断**（一遍遍历只判一次），不会连锁折减。

## 六、常见错误与讲解

**错误 1：把修改写成了改指针，破坏链表结构**

```c
p->next = p->load * k;    /* 错：把小数赋给指针，链断且类型错误 */
p->load = p->load * k;    /* 对：只修改数据域 */
```
折减载荷改的是 `p->load`，绝不能碰 `p->next`。指针域一旦被写入无意义的值，后面的节点就再也找不到了。

**错误 2：先输出后修改，看不到折减效果**

```c
while (p != NULL) { printf("%d %.2f\n", p->id, p->load); p = p->next; }
/* 之后才去修改，输出的是原值 */
```
要保证输出在修改之后。可以先遍历修改一遍，再遍历输出一遍（本参考代码采用这种做法，逻辑最清晰）。

**错误 3：查找条件用错符号**

```c
if (p->load >= limit) { … }   /* 错：等于阈值的不应折减 */
if (p->load >  limit) { … }   /* 对：题目要求"超过" */
```
读题时务必看清"超过 / 不小于 / 大于等于"的区别，它们对应 `>`、`>=`、`>=`。

**错误 4：忘记 free**

修改型程序同样要归还内存。释放仍用 `while (head != NULL) { p = head; head = head->next; free(p); }`，先存后继再释放。

## 七、与综合实验的衔接

实验 **C7《冰载荷数据辨识与统计系统》**在统计之前，往往要先做**数据清洗**：识别异常样本、按规则修正或剔除。本题的"遍历—判断—就地修改"正是清洗环节的最小模型：判据换成别的（超上限、低于下限、持续时长超限……），改法换成别的（折减、置零、标记），骨架都不用变。下一题（练习 15）会把"改数据"升级为"改连接"——从链表中**删除**一个节点，那才是真正触及链表结构的操作，也是本节后面所有难点的起点。
