# 第 4 章 练习 28　层内传播时间函数

**所属综合实验**：C8（C8-基于分层线性插值的声线传播时间计算系统）

**对应章节**：4 函数（4.1 函数定义与调用、4.2 参数传递、4.3 函数声明与原型、4.5 嵌套调用）

**场景来源**：综合实验 C8《基于分层线性插值的声线传播时间计算系统》（水声学院）——本练习是该实验中"层内传播时间计算"环节的最小实现。

**建议用时**：40 分钟

## 一、应用场景

第 3 章练习 40 用"路程 ÷ 速度"算每层时间，其实做了简化——声线在层内是**斜着走**的。声源以**掠射角** $\theta$（声线与水平面的夹角）进入一层厚 $h$ 的水层，层内声速为 $c$，则声线在该层内的斜程为 $h/\cos\theta$，传播时间为

$$t = \frac{h}{c\cos\theta}$$

同时可以算出声线在这层里的水平跨距：

$$d = h\tan\theta$$

综合实验 C8 的 M4/M5 模块反复要做这个计算——每条声线、每一层都要算一次。同一个公式要用几十上百次，最好的办法是把它**封装成函数**：写一次，处处调用。

## 二、任务要求

编写一个完整程序 `layer_time_fn.c`：

1. 自定义函数 `double layerTime(double h, double c, double thetaDeg)`：给定层厚、声速、掠射角（**角度制**），返回层内传播时间 $t = h/(c\cos\theta)$（内部先把角度转成弧度再调用 `cos`）；
2. 自定义函数 `double layerSpan(double h, double thetaDeg)`：返回层内水平跨距 $d = h\tan\theta$；
3. 主函数从键盘读入层数 `n`（**题目保证 1 ≤ n ≤ 100**），循环读入每层的 `h`、`c`、`thetaDeg`；
4. 每层调用上述两个函数，打印该层时间（保留 6 位小数）与水平跨距（保留 6 位小数）；
5. 用累加器把各层时间累加，最后打印总传播时间（保留 6 位小数）。

**知识边界提示**：本题可使用第 2、3 章全部知识，并要求使用**函数定义、函数声明、参数传值调用**；**禁用数组与指针**。三角函数使用 `<math.h>` 的 `cos`/`tan` 与 `M_PI`（或自定义 `PI = 3.14159265358979`）。

## 三、输入输出格式

**输入**：第一行一个整数 n；随后 n 行，每行三个实数 h、c、thetaDeg（thetaDeg 为角度制掠射角）。

**输出**：共 n+1 行：前 n 行每行 `第i层 时间=x 水平跨距=y`（各保留 6 位小数）；最后一行 `总传播时间=x`（保留 6 位小数）。

输入：

```
第3层 时间=0.022366 水平跨距=13.989230
第4层 时间=0.068277 水平跨距=32.491970
总传播时间=0.180603
```

**样例 2**

输入：
```
1

```
输出：
```
第1层 时间=0.066667 水平跨距=0.000000
总传播时间=0.066667
```

（样例 2 掠射角为 0°，声线水平走，斜程退化为层厚本身，水平跨距为 0——可用于自检。）

## 五、提示

- **函数声明（原型）**放在 `main` 之前，定义放在 `main` 之后或之前均可：

  ```c
  double layerTime(double h, double c, double thetaDeg);
  double layerSpan(double h, double thetaDeg);
  ```
- **角度转弧度**：C 的三角函数吃**弧度**，$\theta_{\text{rad}} = \theta_{\text{deg}} \times \pi / 180$；
- 时间公式的实现只有一行：

  ```c
  double rad = thetaDeg * PI / 180.0;
  return h / (c * cos(rad));
  ```
- 参数是**传值**的：主函数把 `h, c, thetaDeg` 的值抄一份给函数，函数里怎么改都不影响主函数的变量——本题只需要"拿进去、算出来、return 回来"，正合适；
- 想一想：`layerTime` 和 `layerSpan` 都要做"角度转弧度"，能不能把 `rad` 的计算写成一个更小的函数、让两者调用它？（函数嵌套调用，试一试。）
- 累加总时间的骨架与第 3 章练习 40 相同——变的只是"算一层时间"这件事被搬进了函数。

**完成本练习后你将具备的能力**：把公式封装成带参数的函数、写函数原型、按传值方式传参、在循环中反复调用函数并累加结果——这些是实验 C8 中"层内传播时间计算"模块的地基。
