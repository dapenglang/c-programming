## 二、预备知识：指针遍历数组的基本原理（零基础阅读）

### 1. 问题是怎么来的

要统计一个序列的和与极值，办法早就有了：`for (i = 0; i < n; i++) s += d[i];`。那为什么还要学指针写法？

两个原因。**其一**，C 语言规定"数组名在表达式中就是首元素地址"，所以 `d[i]` 的底层动作本来就是"先取地址 `d + i`，再取该地址的内容"——下标写法只是指针写法的语法糖。**其二**，综合实验 C6 中大量模块（差分、滑动窗、阈值判决）都以"一段连续内存 + 一个游标"的方式处理数据，指针遍历是与硬件/内存直觉最贴合的表达，学会它，读别人的工程代码不再吃力。

### 2. 指针算术的规则

设 `double d[5]; double *p = d;`，则：

- `p` 指向 `d[0]`；`*p` 就是 `d[0]` 的**内容**；
- `p + 1` 指向 `d[1]`——**加 1 的单位是"一个元素"**，不是 1 个字节（编译器按 `sizeof(double)` 自动折算）；
- `p++` 让指针前移一格；`*(p + i)` 等价于 `d[i]`；
- `d + n` 是"第 n 个元素的地址"，即**尾后位置**，用它做循环上界最安全：
  ```c
  for (p = d; p < d + n; p++) { ... *p ... }
  ```

### 3. 极值统计的套路

```c
mx = mn = *d;              /* 先取第一个元素做初值 */
for (p = d + 1; p < d + n; p++) {
    if (*p > mx) mx = *p;
    if (*p < mn) mn = *p;
}
```

注意从 `d + 1` 开始即可，第一个元素已当过初值。

### 4. 用本例走一遍

样例 1 的序列 `d = {12.0, 13.5, 11.0, 14.0, 12.5}`，指针游走过程：

```
内存：  d[0]   d[1]   d[2]   d[3]   d[4]
      +------+------+------+------+------+
      | 12.0 | 13.5 | 11.0 | 14.0 | 12.5 |
      +------+------+------+------+------+
         ↑p
```

| 步骤 | p 指向 | *p | 累加 s | mx | mn |
|---|---|---|---|---|---|
| 初值 | d[0] | 12.0 | 12.0 | 12.0 | 12.0 |
| 1 | d[1] | 13.5 | 25.5 | 13.5 | 12.0 |
| 2 | d[2] | 11.0 | 36.5 | 13.5 | 11.0 |
| 3 | d[3] | 14.0 | 50.5 | 14.0 | 11.0 |
| 4 | d[4] | 12.5 | 63.0 | 14.0 | 11.0 |

结果：总和 63.00，平均 63.0/5 = 12.60，最大 14.00，最小 11.00——与样例一致。

> **这个写法在综合实验中反复出现**：C6 的一阶差分、滑动平滑、阈值判决全都以 `for (p = d; p < d + n - k; p++)` 这类指针游标为核心；C7 的滑动平均、C9 的区间扫描同理。掌握指针遍历，第 6 章后面的题目水到渠成。

## 三、解题思路

1. 读入 `n` 与序列；
2. 指针 `p` 从 `d` 游到 `d + n`，一轮循环内同时累加、比最大、比最小；
3. 平均 = 总和 / n；
4. 按格式输出四个结果。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double d[100];              /* 深度序列 */
    double *p;                  /* 游标指针 */
    double s = 0.0, mx, mn, avg;
    int n;

    scanf("%d", &n);
    for (p = d; p < d + n; p++) {       /* 用指针读入 */
        scanf("%lf", p);                /* p 本身就是地址，不必加 & */
    }

    mx = mn = *d;                       /* 初值取第一个元素 */
    for (p = d; p < d + n; p++) {
        s += *p;
        if (*p > mx) mx = *p;
        if (*p < mn) mn = *p;
    }
    avg = s / n;

    printf("总和 = %.2f m\n", s);
    printf("平均 = %.2f m\n", avg);
    printf("最大 = %.2f m\n", mx);
    printf("最小 = %.2f m\n", mn);
    return 0;
}
```


| 样例 | 手算验证 | 程序输出 |
|---|---|---|
| 1 | 63.0 / 12.6 / 14.0 / 11.0 | ✓ |
| 2 | 9.8 / 9.8 / 9.8 / 9.8 | ✓ |

**反例验证**：把循环条件误写成 `p <= d + n`，游标会多走一步，读到数组外的垃圾数据（总和变大且不稳定）——说明 `p < d + n` 这一步之差就是越界。

## 六、常见错误与讲解

**错误 1：读入时写 `scanf("%lf", &p)` 或 `scanf("%lf", p + i)` 用错**

```c
scanf("%lf", &p);        /* 错：p 是指针变量自己的地址，不是元素地址 */
scanf("%lf", p);         /* 对：p 当前正指向要写入的元素 */
```

**错误 2：混淆 `p` 与 `*p`**

```c
s += p;      /* 错：把地址当数值累加，结果巨大且无意义 */
s += *p;     /* 对：*p 才是指针指向的那个 double 值 */
```

**错误 3：极值初值取 0**

```c
mx = 0.0;                /* 若全部深度为正，正确；但若是全为负的序列就错 */
mx = *d;                 /* 对：用第一个元素做初值，任何序列都安全 */
```

**错误 4：越界一步**

```c
for (p = d; p <= d + n; p++)   /* 错：最后会访问 d[n]，越界 */
for (p = d; p < d + n; p++)    /* 对：严格小于尾后地址 */
```
