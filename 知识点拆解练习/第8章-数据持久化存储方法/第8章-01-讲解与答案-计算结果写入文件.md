## 二、预备知识：文件读写的基本原理（零基础阅读）

### 1. 为什么需要文件

程序中我们定义过的所有变量、数组、结构体，都存放在**内存**里。内存有个特点：**程序一结束，里面的内容全部消失**。练习 5-01 里读入的阻力序列，练习 7-02 里建立的冰块清单，只要 `main` 一返回，统统不见了。

可现实工作恰恰要求把成果**留下来**：今天算出的载荷结果，明天还要复核；这次试验的测量数据，下次程序还要读回去继续处理。数据的"寿命"必须比程序长。解决办法就是把数据写进**磁盘上的文件**——文件里的内容不会因为程序退出而丢失，这就是"持久化存储"。本章讲的，就是 C 程序怎样和文件打交道。

### 2. 文件操作的标准四步曲

在 C 语言里操作文件，无论读还是写，都遵循同一套"四步曲"：

1. **声明文件指针**：`FILE *fp;`；
2. **打开文件**：`fp = fopen("文件名", "模式");`；
3. **读或写**：用 `fprintf`/`fscanf`/`fgets`/`fgetc`/`fread`/`fwrite` 等函数；
4. **关闭文件**：`fclose(fp);`。

**`fopen` 返回的 `FILE *` 是什么？** 你不需要知道 `FILE` 内部长什么样，只要理解：文件名交给操作系统后，操作系统会为这次访问建立一套"档案"，记录文件在哪、读到哪了、是读还是写。`fopen` 返回的指针就是这份档案的**编号牌**——后续所有读写函数只要拿到这个牌子，就知道操作的是哪个文件、当前进行到哪。这个"当前进行到哪"就是**文件位置指针**，读写会自动把它往后推。

**打开失败会怎样？** 如果文件名写错、文件不存在又没有权限新建、磁盘被写保护，`fopen` 就返回一个特殊值 `NULL`（空指针）。如果不对它判断就直接用，程序会崩溃。所以打开之后**必须**紧跟一句：

```c
if (fp == NULL) { printf("打不开文件\n"); return 1; }
```

### 3. 常用读写函数怎么选

| 函数 | 读/写单位 | 典型写法 | 适合场景 |
|---|---|---|---|
| `fprintf` | 按格式写 | `fprintf(fp, "%d %.2f\n", id, v);` | 把数字按人可读格式写进文本 |
| `fscanf` | 按格式读 | `fscanf(fp, "%d%lf", &id, &v);` | 从文本里按格式读数字 |
| `fgets` | 读一整行 | `fgets(buf, sizeof(buf), fp);` | 一行里有字符串、需要整行处理 |
| `fgetc`/`fputc` | 读/写单个字符 | `c = fgetc(fp);` | 逐字符处理（如词频统计） |
| `fread`/`fwrite` | 按字节块读写 | `fwrite(a, sizeof(double), n, fp);` | 二进制文件、批量存数组 |

本题的数据是"整数编号 + 实数载荷"，正好是"按格式的文本"，所以选 **`fprintf`** 最合适。

### 4. 打开模式的区别

| 模式 | 含义 | 文件已存在时 |
|---|---|---|
| `"r"` | 只读文本 | 从文件头开始读，不存在则失败 |
| `"w"` | 只写文本 | **清空原有内容**，从头开始写 |
| `"a"` | 追加文本 | 保留原有内容，从末尾接着写 |
| `"rb"`/`"wb"` | 二进制只读/只写 | 同上，但按二进制方式处理 |

本题要把结果保存成新台账，用 `"w"`；但要特别注意 **`"w"` 会清空同名旧文件**，若想往日志里"接着记"就得用 `"a"`（练习 09 专门练）。

### 5. 用本题的数据走一遍文件指针

输入是 `3 / 1 12.5 / 2 18.3 / 3 9.75`。`fopen(..., "w")` 成功后，文件位置指针停在开头（0 字节处）。第一次循环写下 `1 12.50` 加换行共 7 字节，指针移到第 7 字节；第二次写下 `2 18.30` 加换行，指针移到 14；第三次写下 `3 9.75` 加换行，指针移到 20。可见**每一次写都是接着上一次的末尾继续**——这就是"文件位置指针自动后移"的实际效果。`fclose` 后，磁盘上的文件内容正是这三行。

## 三、解题思路

1. **打开文件**：`fp = fopen("load_results.txt", "w")`，并**立即**检查是否为 `NULL`；
2. **读入条数**：`scanf("%d", &n)`；
3. **循环写文件**：读一组 `id`、`value`，用 `fprintf` 写一行，重复 $n$ 次；
4. **关闭文件**：`fclose(fp)`；
5. **屏幕提示**：输出 `写入完成，共 %d 条记录`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;                 /* 文件指针，代表要写入的文件 */
    int n, i, id;             /* n 为记录条数，id 为测点编号 */
    double value;             /* 冰载荷值，单位 kN */

    scanf("%d", &n);          /* 读入记录条数 */

    /* 第一步：以"写"模式打开文件 */
    fp = fopen("load_results.txt", "w");
    if (fp == NULL) {         /* 必须检查是否打开成功 */
        printf("无法打开文件 load_results.txt\n");
        return 1;
    }

    /* 第二步：循环读入并用 fprintf 写入文件 */
    for (i = 0; i < n; i++) {
        scanf("%d%lf", &id, &value);          /* 从键盘读一条记录 */
        fprintf(fp, "%d %.2f\n", id, value);  /* 写一行到文件 */
    }

    /* 第三步：关闭文件，确保数据落盘 */
    fclose(fp);

    printf("写入完成，共 %d 条记录\n", n);

    return 0;
}
```

## 五、运行验证

**样例 1：运行前** `load_results.txt` 不存在（或内容任意，因为 `"w"` 会清空它）。

屏幕输入：
```
3
1 12.5
2 18.3
3 9.75
```
屏幕输出：
```
写入完成，共 3 条记录
```
**运行后** `load_results.txt` 的内容：
```
1 12.50
2 18.30
3 9.75
```

逐行核对：`fprintf(fp, "%d %.2f\n", 1, 12.5)` 中 `%.2f` 把 12.5 输出成 `12.50`，于是第一行是 `1 12.50`；第二行 `2 18.30`；第三行 `3 9.75`（9.75 保留两位正好是 `9.75`）。与题面样例完全一致。

**样例 2：运行前** 文件里有上次的 3 行。以 `"w"` 方式打开后先被清空。

屏幕输入：
```
2
10 7.5
11 6.25
```
屏幕输出：
```
写入完成，共 2 条记录
```
**运行后** 文件内容（旧的 3 行已被覆盖，只剩新的 2 行）：
```
10 7.50
11 6.25
```

这一步同时验证了 `"w"` 的"清空重写"特性：如果误用 `"a"`，结果会变成旧的 3 行加上新的 2 行共 5 行，与本题要求不符。

## 六、常见错误与讲解

**错误 1：`fopen` 之后不检查 `NULL`**

```c
fp = fopen("load_results.txt", "w");
fprintf(fp, "1 12.50\n");   /* 错：若 fp 为 NULL，直接崩溃 */
```

文件名拼错、路径不存在又没有权限时 `fopen` 返回 `NULL`。判空是**每次打开文件后的固定动作**，不是可选项。

**错误 2：忘记 `fclose`**

```c
fprintf(fp, "%d %.2f\n", id, value);
return 0;                 /* 错：没关文件就退出 */
```

写入的数据先放在系统的缓冲区里，`fclose` 才会把它真正刷到磁盘。不关文件，可能写完却"看不见"，长时间运行还会耗尽系统可打开的文件数。

**错误 3：`fprintf` 写成了 `printf`**

```c
printf("%d %.2f\n", id, value);        /* 错：数据全打到屏幕，文件是空的 */
fprintf(fp, "%d %.2f\n", id, value);   /* 对：第一个参数是文件指针 */
```
`fprintf` 比 `printf` 多一个开头的"写到哪里"参数。检查办法：运行结束后打开 `load_results.txt`，应能看到与屏幕提示条数一致的记录行。
