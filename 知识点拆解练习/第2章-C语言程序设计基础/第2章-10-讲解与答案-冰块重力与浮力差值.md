## 二、预备知识：重力、浮力与阿基米德原理（零基础阅读）

### 1. 问题是怎么来的

一块冰漂在水上，究竟会下沉还是上浮？答案取决于它受到的**重力**和**浮力**谁大。重力来自冰自己的质量，浮力来自它排开的海水。把两者分别算出来后相减，差值就能告诉我们冰块的"净受力方向"。

### 2. 公式是怎么来的

**重力**：任何质量为 $m$ 的物体受到的重力是 $G = mg$。冰的质量 = 冰密度 × 冰的**总体积**，总体积是长宽厚三者之积：

$$
G = \rho_{\text{ice}} \times (l \times w \times t) \times g
$$

**浮力**：阿基米德原理说，物体受到的浮力等于它**排开液体所受的重力**。冰只有水下的那一段排开水，排开的水体积等于"长 × 宽 × 水下深度 $d$"：

$$
F = \rho_{\text{水}} \times (l \times w \times d) \times g
$$

**差值**：$G - F$。为正说明重力占优（冰有下沉趋势），为负说明浮力占优（冰有上浮趋势）。当 $G = F$ 时冰恰好悬浮——这正是实验 C8 用二分法要找的"平衡吃水"。

### 3. 用本例走一遍

长 2 m、宽 1.5 m、厚 0.4 m、水下 0.34 m：

- 冰的体积：$2\times1.5\times0.4 = 1.2\ \mathrm{m^3}$；
- 重力：$G = 917\times1.2\times9.8 = 1100.4\times9.8 = 10783.92$ N；
- 排开体积：$2\times1.5\times0.34 = 1.02\ \mathrm{m^3}$；
- 浮力：$F = 1025\times1.02\times9.8 = 1045.5\times9.8 = 10245.9$ N；
- 差值：$10783.92 - 10245.9 = 538.02$ N（为正，重力略大）。

### 4. 编程时怎么用它

关键是**分清两个体积**：重力用总厚度 $t$，浮力用水下深度 $d$。两者都用 `l * w` 再乘各自的高，千万不要把浮力也写成 $t$。此外，差值可能为负，C 语言里 `%f` 能正常输出负号，无需特殊处理。

## 三、解题思路

1. **备常量**：`RHO_ICE`、`RHO_WATER`、`GRAV`；
2. **备变量**：`l, w, t, d`（输入），`V`（总冰体积）、`Vsub`（排开体积）、`G, F, diff`（结果），全用 `double`；
3. **读入四个数**；
4. **算重力**：`G = RHO_ICE * l * w * t * GRAV`；
5. **算浮力**：`F = RHO_WATER * l * w * d * GRAV`；
6. **求差值并输出**：`diff = G - F`，三行各保留 4 位小数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const double RHO_ICE   = 917.0;    /* 海冰密度，kg/m^3 */
    const double RHO_WATER = 1025.0;   /* 海水密度，kg/m^3 */
    const double GRAV      = 9.8;      /* 重力加速度，m/s^2 */

    double l, w, t, d;   /* 输入：长、宽、厚、水下深度，m */
    double G;            /* 重力，N */
    double F;            /* 浮力，N */
    double diff;         /* 差值 = 重力 - 浮力，N */

    /* 读入四个尺寸参数 */
    scanf("%lf %lf %lf %lf", &l, &w, &t, &d);

    /* 重力：冰密度 * 总体积(长*宽*厚) * g */
    G = RHO_ICE * l * w * t * GRAV;

    /* 浮力：水密度 * 排开体积(长*宽*水下深度) * g */
    F = RHO_WATER * l * w * d * GRAV;

    /* 净受力（重力减浮力） */
    diff = G - F;

    /* 输出，均保留 4 位小数 */
    printf("G = %.4f N\n", G);
    printf("F = %.4f N\n", F);
    printf("diff = %.4f N\n", diff);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2 1.5 0.4 0.34 | $G=917\times1.2\times9.8=10783.92$；$F=1025\times1.02\times9.8=10245.9$；差 $538.02$ | `G=10783.9200` / `F=10245.9000` / `diff=538.0200` ✓ |
| 1 0.8 0.5 0.45 | $G=917\times0.4\times9.8=3594.64$；$F=1025\times0.36\times9.8=3616.2$；差 $-21.56$ | `G=3594.6400` / `F=3616.2000` / `diff=-21.5600` ✓ |
| 2 1.5 0.4 0.5 | $G=10783.92$；$F=1025\times1.5\times9.8=15067.5$；差 $-4283.58$ | `G=10783.9200` / `F=15067.5000` / `diff=-4283.5800` ✓ |

第 2、3 行差值为负，说明浮力已超过重力，冰会向上运动；第 1 行差值很小为正，接近悬浮状态——与平衡吃水的物理直觉一致。

## 六、常见错误与讲解

**错误 1：浮力误用了总厚度**

```c
F = RHO_WATER * l * w * t * GRAV;   /* 错：浮力取决于水下深度 d，不是总厚度 t */
F = RHO_WATER * l * w * d * GRAV;   /* 对 */
```

若 $d = t$（整块淹没），两式才相等；一般情况下必须用 $d$。

**错误 2：密度或 g 写成整数**

```c
const int GRAV = 9.8;    /* 错：9.8 是小数，不能放进 int */
const double GRAV = 9.8; /* 对 */
```

**错误 3：差值方向写反、符号搞错**

```c
diff = F - G;    /* 与题目定义的"重力 − 浮力"相反，符号会全部反过来 */
diff = G - F;    /* 对 */
```

**错误 4：scanf 漏 `&` 或变量顺序错乱**

```c
scanf("%lf %lf %lf %lf", &l, &w, &t, &d);   /* 对：注意 d 是第四个 */
scanf("%lf %lf %lf", &l, &w, &t);           /* 错：d 没读入 */
```

## 七、与综合实验的衔接

- 在实验 **C8（碎冰冰块浮力吃水计算系统）**中，本练习对应"冰块受力平衡分析"环节：正式程序会不断改变水下深度 $d$，直到重力与浮力之差为 0，那个 $d$ 就是平衡吃水——用二分法迭代求解需要循环与函数（第 3、4、7 章）；
- 本练习的"分别算、再求差"是二分法（练习 07 章、综合实验 C8/A2）的判据内核：**只要能把 f(d) = G − F 写成代码，就能用二分法或牛顿法求出它的零点**。因此本题是通往数值求解的最后一节基础课。
