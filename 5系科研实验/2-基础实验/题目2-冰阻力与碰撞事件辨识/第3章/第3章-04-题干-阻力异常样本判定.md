# 第 3 章 练习 04　阻力异常样本判定（关系运算与逻辑判断）

**对应章节**：3 结构化程序设计方法（3.1 顺序结构、3.2 选择结构、3.4 关系运算符与逻辑运算符）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"载荷样本异常检测"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰载荷测量试验中，传感器以固定时间间隔连续输出冰阻力样本（单位 kN）。现场数据偶尔会出问题：要么某一样本超过设备量程对应的物理上限（传感器饱和或受扰），要么相邻样本之间发生无物理意义的"突跳"（数据链路丢包、电磁干扰）。**任一异常都意味着这一组数据不可信，必须整组剔除**。实验 C7 在把样本写入数据库前，要由程序自动完成这道筛查：连续三个样本一组，逐条规则核对，给出"正常"或"异常"的结论。

## 二、任务要求

编写一个完整程序 `load_check.c`：

1. 从键盘读入 3 个实数，为同一组的连续三个阻力样本 `f1`、`f2`、`f3`（单位 kN）；
2. 按以下两条规则判定：
   - **上限规则**：任何一个样本超过上限阈值 $F_{max} = 850$ kN（严格大于）；
   - **突跳规则**：相邻两个样本之差的绝对值超过 $J = 60$ kN（严格大于），即 $|f_1 - f_2| > 60$ 或 $|f_2 - f_3| > 60$；
3. 两条规则任一触发即判异常；全部不触发判正常；
4. 注意：第 3 章尚未学习数学库函数，**不允许使用 `fabs()`**，差的绝对值请用"先相减、为负则取反"的方式自行实现。

## 三、输入输出格式

**输入**：一行，3 个实数，以空格分隔（单位 kN）。

**输出**：一行，`normal` 或 `abnormal`。

## 四、样例

**样例 1**

输入：
```
800 810 790
```
输出：
```
normal
```
（最大值 810 未超 850；相邻差 10、20 均未超 60）

**样例 2**

输入：
```
700 790 700
```
输出：
```
abnormal
```
（三个值都未超 850，但 $|700 - 790| = 90 > 60$，触发突跳规则）

## 五、提示

绝对值可以手动实现：

```c
d = f1 - f2;
if (d < 0.0)
    d = -d;      /* 负差取反即绝对值 */
```

多条异常规则之间是"或"的关系，用 `||` 串进同一个 if 条件即可，不需要为每条规则单独写一遍输出。

**完成本练习后你将具备的能力**：手写绝对值运算、用 `||` 组合多条异常规则、理解"严格大于"与阈值的关系——这是实验 C7 中载荷数据清洗模块的最小实现。
