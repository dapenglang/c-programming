## 二、预备知识：嵌套循环与逐格遍历（零基础阅读）

### 1. 问题是怎么来的

测点排成 3 行 4 列，要"一个不落地"处理每个格子。如果只写一个循环，它只能从头到尾走一条线，照顾不到"行"和"列"两个方向；所以需要**两层循环**：外层负责"走到哪一行"，内层负责"在这一行里走到哪一列"。这种一层套一层的写法就叫嵌套循环。

### 2. 方法是怎么想出来的

把网格上的每个格子用一个坐标 $(i, j)$ 表示，$i$ 是行号（1..3），$j$ 是列号（1..4）。要让 $(i,j)$ 取遍所有组合，可以这样做：让 $i$ 从 1 慢慢加到 3，每固定一个 $i$，就让 $j$ 从 1 跑到 4。用两重 for 表达：

```c
for (i = 1; i <= 3; i++)        /* 外层：固定一行 */
    for (j = 1; j <= 4; j++)    /* 内层：扫遍这一行 */
        /* 处理格子 (i, j) */
```

内外层一共产生 $3 \times 4 = 12$ 个 $(i,j)$ 组合，且顺序是**行优先**的：$(1,1),(1,2),(1,3),(1,4),(2,1),\dots,(3,4)$——正好和"先输入第 1 行、再第 2 行"的顺序一致。

### 3. 用本例走一遍

以样例 1 的前几个格子为例：

- $i=1, j=1$：读入 $12.5$，累加后 `sum = 12.5`，因为是第一个数据，记 `max = min = 12.5`，位置 $(1,1)$；
- $i=1, j=2$：读入 $15.3$，`sum = 27.8`；$15.3 > 12.5$ 且 $15.3 > 12.5$ 的 min，于是 `max = 15.3`，位置更新为 $(1,2)$；
- ……
- $i=2, j=2$：读入 $22.4$，比当前最大值大，`max = 22.4`，位置更新为 $(2,2)$；
- ……

内层 4 次走完一行，外层跳到下一行，直到 12 个格子全部处理，最后 `sum = 191.4`，`mean = 191.4/12 = 15.95`，最大值 22.4 在 $(2,2)$，最小值 9.8 在 $(3,1)$。

### 4. 编程时怎么用它

三个要点：**① 两个循环变量必须不同**（如 `i` 表行、`j` 表列），否则内外层共用会互相干扰；**② 边读边统计**：因为不让用数组，读到每个数就立刻累加、比较，把"需要保留的信息"压缩成几个变量（`sum`、`vmax`、`vmin` 及四个位置变量）；**③ 最值初值**：最好的办法是把**第一个读到的数**同时作为最大值和最小值的初值（用一个 `first` 标志判断），避免"初值设 0 导致全负数时出错"。记录位置时，一旦更新了最值，就要同时把当前的 `i`、`j` 存进对应的位置变量。

## 三、解题思路

1. **定义常量**：`const int ROWS = 3, COLS = 4;`，循环和均值都用它，便于修改；
2. **准备统计变量**：`sum = 0.0`、`mean`、`vmax`、`vmin`、四个位置变量，以及标志 `first = 1`；
3. **嵌套循环读入并统计**：外层 `i` 控制行、内层 `j` 控制列；每读一个数就累加，并按 `first` 分支决定"初始化最值"还是"比较更新"；
4. **算均值**：`sum / (ROWS * COLS)`，注意写成浮点除法；
5. **输出**：四行，最值行附带 `(row i, col j)`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    const int ROWS = 3, COLS = 4;      /* 网格规模 */

    double v;                          /* 当前读入的测点值 */
    double sum = 0.0;                  /* 总和 */
    double vmax = 0.0, vmin = 0.0;     /* 最大值、最小值 */
    int    rmax = 1, cmax = 1;         /* 最大值所在行、列 */
    int    rmin = 1, cmin = 1;         /* 最小值所在行、列 */
    int    first = 1;                  /* 是否读到第一个数据 */
    int    i, j;                       /* 行、列循环变量 */

    /* 嵌套循环：外层走行，内层走列，共 ROWS*COLS 个格子 */
    for (i = 1; i <= ROWS; i++) {
        for (j = 1; j <= COLS; j++) {
            scanf("%lf", &v);          /* 读入第 (i,j) 个测点 */
            sum = sum + v;             /* 累加 */

            if (first) {               /* 第一个数据同时初始化最值 */
                vmax = vmin = v;
                rmax = rmin = i;
                cmax = cmin = j;
                first = 0;
            } else {                   /* 后续数据与当前最值比较 */
                if (v > vmax) { vmax = v; rmax = i; cmax = j; }
                if (v < vmin) { vmin = v; rmin = i; cmin = j; }
            }
        }
    }

    /* 输出统计结果 */
    printf("sum = %.3f\n", sum);
    printf("mean = %.3f\n", sum / (ROWS * COLS));
    printf("max = %.3f (row %d, col %d)\n", vmax, rmax, cmax);
    printf("min = %.3f (row %d, col %d)\n", vmin, rmin, cmin);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：内外层用了同一个循环变量**

```c
for (i = 1; i <= 3; i++)
    for (i = 1; i <= 4; i++)    /* 错：外层变量被内层覆盖，只跑一趟 */
```

内外层必须用**不同**变量（常用 `i`、`j`）。

**错误 2：最值初值设为 0**

```c
double vmax = 0.0;             /* 若所有测点都是负值，max 会错误地保持 0 */
```

安全做法：把**第一个读入的数**同时作为 `vmax`、`vmin` 的初值（本题用 `first` 标志实现）。

**错误 3：忘了同步记录位置**

```c
if (v > vmax) vmax = v;        /* 只更新了值，位置仍是旧的，输出坐标会错 */
if (v > vmax) { vmax = v; rmax = i; cmax = j; }   /* 对：值 + 位置一起更新 */
```

**错误 4：均值用整数除法**

```c
mean = sum / 12;               /* 若 sum 是 double 则无碍，但写法有隐患 */
mean = sum / (ROWS * COLS);    /* 对：ROWS*COLS 是 int=12，与 double 相除仍为浮点 */
```

注意 `sum` 是 `double`，只要它参与除法，结果就是浮点；但仍建议保持分母含义清晰。
