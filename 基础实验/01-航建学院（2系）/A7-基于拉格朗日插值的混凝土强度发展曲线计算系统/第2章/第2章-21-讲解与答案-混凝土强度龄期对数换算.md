## 二、预备知识：对数换算的基本原理（零基础阅读）

### 1. 问题是怎么来的

工程师想知道"7 天龄期的混凝土强度达到了 28 天强度的几分之几"。直接做实验测 7 天强度要等 7 天、样本数量还要足够，太慢。于是规范根据大量试验数据，总结出一条**经验公式**，用龄期 $n$ 直接算出强度比 $f(n)$。

为什么公式里出现的是 $\lg n$ 而不是 $n$ 本身？因为混凝土早期强度增长快、后期增长慢：从 3 天到 7 天强度涨得很多，而从 14 天到 28 天虽然同样是 14 天，强度却只涨一点点。这种"前期猛、后期缓"的规律，正好对数函数的曲线形状（先陡后平）能描述。用数学语言说：**强度比与龄期的对数近似成线性关系**。

### 2. 公式是怎么推出来的

规范给出的拟合式是

$$
f(n) = A + B \cdot \lg n
$$

其中 $A$ 是截距，$B$ 是斜率，$\lg n$ 是"以 10 为底的对数"。对数的定义是：若 $10^{k} = n$，则 $\lg n = k$。例如：

$$
\lg 10 = 1,\quad \lg 100 = 2,\quad \lg 1 = 0
$$

对数有一个很好用的性质——把乘法变加法、把幂变倍数：

$$
\lg(a b) = \lg a + \lg b,\qquad \lg(n^k) = k \lg n
$$

本题不需要用到这些性质，只需知道 $\lg n$ 是一个可以直接计算出来的数。在 C 语言里，$\lg n$ 由数学库函数 `log10(n)` 提供（`log` 后面跟的 `10` 就是"底数 10"）。

### 3. 用本例走一遍

取 $n = 7$，$A = 0.256$，$B = 0.516$：

- 先算对数：$\lg 7 \approx 0.8451$；
- 再算斜率项：$B \cdot \lg 7 = 0.516 \times 0.8451 \approx 0.4361$；
- 加上截距：$f = 0.256 + 0.4361 = 0.6921 \approx 0.6922$（保留 4 位小数）。

再验算 $n = 28$：$\lg 28 \approx 1.4472$，$B \cdot \lg 28 = 0.516 \times 1.4472 \approx 0.7468$，$f = 0.256 + 0.7468 = 1.0028$。手算与规范值 1 非常接近，说明 28 天时强度比约为 1（正好达到 28 天强度），公式合理。

> 顺带一提：本题手算中 $n=28$ 得到约 1.0018，与 1 的小偏差来自回归系数的取整——真实规范数据的拟合值本来就允许这样的小误差。

### 4. 编程时怎么用它

三个要点：

1. **确定数据类型**：龄期和强度比都是实数量，用 `double`，不要用 `int`；
2. **调用库函数**：`log10(n)` 不是运算符，要写在表达式里，并且顶部 `#include <math.h>`；
3. **注意优先级**：乘号优先于加号，`A + B * log10(n)` 会先算乘法，符合公式。

## 三、解题思路

1. **确定数据**：回归系数 $A$、$B$ 是规范给定的常数，定义为 `const double`；
2. **确定变量**：读入的龄期 `n` 和待求的强度比 `f`，都是 `double`；
3. **套用经验公式**：`f = A + B * log10(n)`；
4. **输出**：题目要求保留 4 位小数，用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>              /* 使用 log10 需要包含数学库 */

int main(void)
{
    /* 哈尔滨地区某水泥品种的回归系数（规范值，不允许修改） */
    const double A = 0.256;    /* 截距，无量纲 */
    const double B = 0.516;    /* 斜率，无量纲 */

    double n;                  /* 混凝土龄期，天 */
    double f;                  /* 龄期 n 时的强度比，无量纲 */

    /* 读入龄期 */
    scanf("%lf", &n);

    /* 对数经验公式：f = A + B * lg(n)，C 语言中 lg 写作 log10 */
    f = A + B * log10(n);

    /* 输出，保留 4 位小数 */
    printf("f = %.4f\n", f);

    return 0;
}
```

## 六、常见错误与讲解

**错误 1：忘记包含数学库头文件**

```c
#include <stdio.h>
/* 缺 #include <math.h> */
... log10(n) ...    /* 错：编译器警告隐式声明，链接可能失败或结果错 */
```

正确写法：`#include <math.h>`。凡是调用 `sqrt`、`fabs`、`log10`、`pow` 等函数，都必须包含它。

**错误 2：把 log10 写成 log 或 ln**

```c
f = A + B * log(n);    /* 错：log 是自然对数（以 e 为底），不是常用对数 */
```

本题要的是以 10 为底的对数，写 `log10(n)`。二者数值差异很大（`log(7)≈1.9459`，`log10(7)≈0.8451`）。

**错误 3：常量写成整数**

```c
const int A = 0;       /* 错：0.256 被截断成 0，结果全错 */
```

`0.256`、`0.516` 必须用 `double` 存放，否则小数部分直接丢失。

**错误 4：忘记取地址符**

```c
scanf("%lf", n);     /* 错：程序崩溃或读不进数据 */
scanf("%lf", &n);    /* 对：scanf 需要变量的地址 */
```
