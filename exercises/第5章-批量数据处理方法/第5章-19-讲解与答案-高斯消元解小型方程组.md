## 二、预备知识：高斯消元法的基本原理（零基础阅读）

### 1. 问题的困难在哪里

一个三阶方程组长这样：

$$
\begin{cases} -2T_1 + T_2 = -100\\ T_1 - 2T_2 + T_3 = 0\\ T_2 - 2T_3 = -200 \end{cases}
$$

难点在于**未知数互相纠缠**：第一个方程同时含 $T_1$ 与 $T_2$，没法直接算出任何一个。若能把它变成"第一个方程含 3 个未知数、第二个含 2 个、第三个只剩 1 个"的形状，就能从第三个式子直接解出 $T_3$，再往回依次求出 $T_2$、$T_1$。

### 2. 消元的目的是什么

高斯消元法的核心思想就是：**利用"方程可以整体相加减"的性质，把不需要的系数主动消成 0**，把方程组整理成上三角形式。具体做法是：

- 用第一个方程去消掉第二、第三个方程里的 $T_1$；
- 再用处理后的第二个方程去消掉第三个方程里的 $T_2$。

消完之后系数矩阵变成

$$
\left[\begin{array}{ccc|c} * & * & * & *\\ 0 & * & * & *\\ 0 & 0 & * & * \end{array}\right]
$$

这种"对角线下方全为 0"的形状叫**上三角**，其好处是最后一行只剩一个未知数、可直接除出来——这就是**回代**的起点。

### 3. 主元怎么选

消第 $k$ 列时，用来"减"的那一行叫主元行，它在该列上的系数 $a_{kk}$ 叫**主元**。用主元去消它下面的元素，需要的乘数（消元乘子）是

$$
m = \frac{a_{ik}}{a_{kk}}
$$

然后令"第 $i$ 行 ← 第 $i$ 行 − $m$ × 第 $k$ 行"。这样第 $i$ 行第 $k$ 列的系数就变成 $a_{ik} - m\,a_{kk} = 0$，正好被消掉。

**关于选主元**：通用高斯消元每步会挑绝对值最大的主元并交换行，以免除以很小的数放大误差；**本题系数矩阵对角占优**（对角线 $|{-2}|$ 大于同行其他系数绝对值之和），主元天然非零、数值稳定，**无需选主元**，按对角线顺序消即可。

### 4. 回代怎么算

上三角化后，从**最后一行往上**依次求解第 $i$ 个未知数：

$$
T_i = \frac{b_i - \sum_{j=i+1}^{3} a_{ij}\,T_j}{a_{ii}}
$$

意思是：先取右边常数 $b_i$，把**已求出的未知数**（$T_{i+1}, T_{i+2}, \dots$）带系数减掉，剩下即 $a_{ii}T_i$，再除以 $a_{ii}$。最后一个方程右边无未知数、直接除；越往上已知量越多，逐一减掉即可。

### 5. 用本例手算第一步消元

把样例 1 的方程组写成增广矩阵：

$$
\left[\begin{array}{ccc|c} -2 & 1 & 0 & -100\\ 1 & -2 & 1 & 0\\ 0 & 1 & -2 & -200 \end{array}\right]
$$

**第一步：消去第 2、3 行的 $T_1$（第 0 列）。**

- 主元为 $a_{00} = -2$；
- 消第 2 行（第 1 行）的乘子：$m_{10} = a_{10}/a_{00} = 1/(-2) = -0.5$；
- 第 2 行 ← 第 2 行 − $(-0.5)$ × 第 1 行，即**加上 0.5 倍第 1 行**：

$$
(1,\ -2,\ 1,\ 0) + 0.5\times(-2,\ 1,\ 0,\ -100) = (0,\ -1.5,\ 1,\ -50)
$$

- 消第 3 行：它第 0 列本来就是 0，乘子 $m_{20} = 0/(-2) = 0$，**这一行保持不变**，仍为 $(0,\ 1,\ -2,\ -200)$。

第一步消元后得到：

$$
\left[\begin{array}{ccc|c} -2 & 1 & 0 & -100\\ 0 & -1.5 & 1 & -50\\ 0 & 1 & -2 & -200 \end{array}\right]
$$

请特别注意：**整行都要参与运算，第 4 列的常数项也要跟着变**（$-100$ 变成了 $-50$ 的由来），这是消元最容易出错的地方。

第二步用主元 $a_{11} = -1.5$ 消去第 3 行的 $T_2$，乘子 $m_{21} = 1/(-1.5) = -2/3$，第 3 行 ← 第 3 行 + $\frac{2}{3}$ × 第 2 行，得到 $(0,\ 0,\ -4/3,\ -700/3)$。至此上三角完成，回代即可：$T_3 = (-700/3)/(-4/3) = 175$，再往上求出 $T_2 = 150$、$T_1 = 125$（见"五、运行验证"）。

## 三、解题思路

1. **读增广矩阵**：双重循环读入 3 行 4 列，存入 `double a[3][4]`；
2. **前向消元**：外层 `k` 走主元列 $0 \sim 1$，内层 `i` 走被消的行 $k+1 \sim 2$，对每个 `i` 先算乘子 `m = a[i][k] / a[k][k]`，再用内层 `j` 从 $k$ 到 3 执行 `a[i][j] -= m * a[k][j]`；
3. **回代**：`i` 从 2 到 0，先令 `s = a[i][3]`，把已知的 `x[j]`（$j > i$）带系数减掉，再 `x[i] = s / a[i][i]`；
4. **输出**：循环打印 `T1`、`T2`、`T3`，保留 2 位小数；
5. 注意消元时 `j` 的起点是 `k`（前面已消成 0 的列可以不管），终点是 `N`（含常数项那一列）。

## 四、参考代码

```c
#include <stdio.h>
#define N 3

int main(void)
{
    double a[N][N + 1];            /* 增广矩阵：N 列系数 + 1 列常数项 */
    double x[N];                   /* 解向量 */
    int i, j, k;

    /* 读入 3 行 4 列增广矩阵 */
    for (i = 0; i < N; i++)
        for (j = 0; j <= N; j++)
            scanf("%lf", &a[i][j]);

    /* 前向消元：把系数矩阵化为上三角 */
    for (k = 0; k < N - 1; k++) {          /* 主元列 k = 0, 1 */
        for (i = k + 1; i < N; i++) {      /* 用主元行 k 消掉下面各行 */
            double m = a[i][k] / a[k][k];  /* 消元乘子 */
            for (j = k; j <= N; j++)
                a[i][j] -= m * a[k][j];    /* 整行一起减，常数项也要减 */
        }
    }

    /* 回代：从最后一个未知数往上求 */
    for (i = N - 1; i >= 0; i--) {
        double s = a[i][N];                /* 先取常数项 */
        for (j = i + 1; j < N; j++)
            s -= a[i][j] * x[j];           /* 减掉已求出的未知数 */
        x[i] = s / a[i][i];
    }

    /* 输出三个解 */
    for (i = 0; i < N; i++)
        printf("T%d = %.2f\n", i + 1, x[i]);

    return 0;
}
```

## 五、运行验证

**样例 1**。前向消元的中间结果（保留到分式便于核对）：

第一步（消 $T_1$）后：

$$
\left[\begin{array}{ccc|c} -2 & 1 & 0 & -100\\ 0 & -1.5 & 1 & -50\\ 0 & 1 & -2 & -200 \end{array}\right]
$$

第二步（消 $T_2$）后：

$$
\left[\begin{array}{ccc|c} -2 & 1 & 0 & -100\\ 0 & -1.5 & 1 & -50\\ 0 & 0 & -\tfrac{4}{3} & -\tfrac{700}{3} \end{array}\right]
$$

回代：

| 未知数 | 计算 | 结果 |
|---|---|---|
| $T_3$ | $\dfrac{-700/3}{-4/3} = \dfrac{700}{4}$ | 175 |
| $T_2$ | $\dfrac{-50 - 1\times 175}{-1.5} = \dfrac{-225}{-1.5}$ | 150 |
| $T_1$ | $\dfrac{-100 - 1\times 150}{-2} = \dfrac{-250}{-2}$ | 125 |

程序输出：

```
T1 = 125.00
T2 = 150.00
T3 = 175.00
```

与题干样例 1 完全一致。**物理核对**：左右端温度分别为 100 ℃ 与 200 ℃、沿 4 段均匀分布，理论上的线性温度场应为 $100, 125, 150, 175, 200$，程序求出的三个内部节点温度正好是 125、150、175，与理论值完全吻合，说明消元与回代都正确。

**样例 2** 同样核对：左右端 20 ℃ 与 140 ℃，理论上内部节点为 50、80、110，程序输出 `T1 = 50.00`、`T2 = 80.00`、`T3 = 110.00`，吻合。

## 六、常见错误与讲解

**错误 1：消元时漏乘常数项（最高发）**

`for (j = k; j < N; j++)` 只循环到系数列，**漏掉了第 N 列常数项**；应写成 `for (j = k; j <= N; j++)`，让常数项也参与整行相减。常数列是方程组的一部分，漏掉它结果必然错。

**错误 2：内层循环起点写错**

`for (j = 0; j <= N; j++)` 可行但多余——第 $k$ 列之前已被消成 0，不必再算；推荐 `for (j = k; j <= N; j++)`，从当前主元列开始。两种写法结果相同，但从 `k` 起更省事，也避免把前面已处理好的 0 又算错。

**错误 3：回代时把未知数取错**

应写 `s -= a[i][j] * x[j];`，减掉的是**已求出**的 $x_j$（$j>i$）；若误写成 `x[i]`，减的正是待求量、还没算出来。回代顺序必须**从下往上**（`i` 递减），才能保证用到 $x_j$ 时它们已解出。

**错误 4：主元为 0 时直接除**

`m = a[i][k] / a[k][k];` 在主元 `a[k][k] == 0` 时会除零出错。本题对角占优、主元非零，无需担心；通用程序应在消元前检查主元、必要时交换两行（选主元）——这是本练习刻意简化的部分。

## 七、与综合实验的衔接

- 实验 **D4（基于高斯消元的燃料棒一维稳态温度场计算系统）**正是把本练习放大：节点数从 3 个增加到几十个，系数矩阵变成**三对角矩阵**，但"读入系数 → 前向消元 → 回代"的三段式流程与本练习完全相同。求出整排节点温度后，还可以配合练习 17 的统计函数算最高温度、平均温度；
- 高斯消元是数值计算的第一块基石：结构力学、流体、传热中的离散方程都归结为解线性方程组。本练习先在最简单的 $3 \times 3$ 情形下把"消元—回代"这条主线走通，**掌握了它，后面处理更大规模的方程组只是把数字 3 换成更大的规模而已**。同时，"二维数组 + 双重循环 + 分步消除"的组合，也是本章二维数组知识的综合运用。
