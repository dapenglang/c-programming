## 二、预备知识：多分支分箱计数的基本原理（零基础阅读）

### 1. 问题是怎么来的

评估海域噪声，只报一个平均值会掩盖很多信息：同样是 70 dB 的均值，可能"一半很安静、一半很吵"，也可能"全天不咸不淡"。所以统计上要做**频数分布**：把取值范围切成几个**区间**（行话叫"分箱"），数一数每个箱子里落了几个样本。

"把一个数丢进正确的箱子"，本质是一连串**条件判断**：先问"够不够安静"，不满足再问"够不够中等"……这就是 C 语言的 **if-else if 多分支链**。

### 2. 公式（判定规则）的推导

四个区间按噪声级 $x$ 划分：

$$
\text{区间} =
\begin{cases}
1, & x < 60 \\
2, & 60 \le x < 70 \\
3, & 70 \le x < 80 \\
4, & x \ge 80
\end{cases}
$$

直接照抄这个数学写法，每个条件都要写两侧：

```c
if (x >= 60.0 && x < 70.0) cnt2++;    /* 啰嗦：每条都要写上下界 */
```

更聪明的办法是利用 **else 的语义**："走到 else if 分支，说明前面的条件都没成立"。按从小到大排列，只写上界即可：

$$
\text{判定顺序：} x < 60 \xrightarrow{\text{否}} x < 70 \xrightarrow{\text{否}} x < 80 \xrightarrow{\text{否}} \text{区间 4}
$$

走到第二个判断时，$x \ge 60$ 已经由 else 隐含保证，无需重写。这样每个条件只写一个关系表达式，边界也不容易漏。

### 3. 代入本例数值

样例 1 的 12 个样本逐个判定：

| 样本 | 判定路径 | 区间 |
|---|---|---|
| 58.3 | <60 成立 | 1 |
| 61.2 | ≥60，<70 成立 | 2 |
| 66.8 | ≥60，<70 成立 | 2 |
| 71.5 | ≥70，<80 成立 | 3 |
| 74.9 | ≥70，<80 成立 | 3 |
| 63.4 | ≥60，<70 成立 | 2 |
| 82.1 | ≥80 | 4 |
| 77.3 | ≥70，<80 成立 | 3 |
| 59.9 | <60 成立（差 0.1 也是 <60） | 1 |
| 85.6 | ≥80 | 4 |
| 70.0 | 不是 <70，而是 ≥70 且 <80 → **区间 3** | 3 |
| 64.5 | ≥60，<70 成立 | 2 |

合计：区间 1 得 2、区间 2 得 4、区间 3 得 4、区间 4 得 2。注意 **70.0 恰好压线**：因为判定写的是 `x < 70.0`，70.0 不满足，落到下一分支——这就是"左闭右开"的边界约定。

### 4. 通过编程翻译

把"逐条丢箱子"翻译成程序：样本数 n 决定循环圈数；每个计数器是**一个变量当一个小桶**，`cnt++` 就是往桶里放一颗石子；判定逻辑就是上面的 else-if 链。

> **这个思想在综合实验中反复出现**：C9 的"区间频数统计"（M3）就是本题本体；C9 的"超阈值样本占比"（M6）只是把 4 个箱子简化成 2 个（超/不超）；C6 的"阈值跳变判决"（M6）也是同一套 if-else 骨架。分箱计数是水声数据处理里最常用的统计地基。

## 三、解题思路

1. **四个计数器清零**：`int cnt1 = 0, cnt2 = 0, cnt3 = 0, cnt4 = 0;`；
2. **for 循环 n 圈**：每圈读入 x，跑一遍 else-if 链，命中的计数器 `++`；
3. **输出**：按区间 1～4 顺序打印频数。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i;
    double x;
    int cnt1 = 0, cnt2 = 0, cnt3 = 0, cnt4 = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf", &x);
        if (x < 60.0)      cnt1++;
        else if (x < 70.0) cnt2++;
        else if (x < 80.0) cnt3++;
        else               cnt4++;
    }
    printf("区间1(<60)频数=%d\n", cnt1);
    printf("区间2([60,70))频数=%d\n", cnt2);
    printf("区间3([70,80))频数=%d\n", cnt3);
    printf("区间4(>=80)频数=%d\n", cnt4);
    return 0;
}
```

## 五、运行验证

**样例 1 运行结果**（12 个样本）：

```
区间1(<60)频数=2
区间2([60,70))频数=4
区间3([70,80))频数=4
区间4(>=80)频数=2
```

**样例 2 运行结果**（单个边界值 70.0）：

```
区间1(<60)频数=0
区间2([60,70))频数=0
区间3([70,80))频数=1
区间4(>=80)频数=0
```

**核对**：样例 1 中 12 = 2+4+4+2，频数总和恰等于样本数——这是分箱统计最重要的**守恒检查**（每个样本必落且只落一个箱）；边界值 59.9、70.0 的归属已按"左闭右开"逐一人工核对，与程序输出一致。

**反例验证**：若把第二个条件误写成 `x <= 70.0`，输入 70.0 会落进区间 2，样例 2 输出变成区间 2 频数=1——说明边界写错会被这样的样例立刻暴露。

## 六、常见错误与讲解

**错误 1：条件全写上界但不用 else**

```c
if (x < 60.0) cnt1++;
if (x < 70.0) cnt2++;      /* 错：58.3 会同时进 cnt1 和 cnt2 */
if (x < 80.0) cnt3++;
```

没有 else 链，`x < 60` 的样本会命中后面所有更宽的区间，频数总和大于 n。**必须用 else-if 串起来**。

**错误 2：计数器没清零**

```c
int cnt1, cnt2, cnt3, cnt4;     /* 错：未初始化 */
```

**错误 3：边界方向写反（右闭左开）**

```c
if (x < 60.0)      cnt1++;
else if (x <= 70.0) cnt2++;     /* 错：70.0 归入区间2，与题意不符 */
```

**错误 4：读入用 `%f` 而不是 `%lf`**

```c
scanf("%f", &x);     /* 错：x 是 double，scanf 必须用 %lf */
```
