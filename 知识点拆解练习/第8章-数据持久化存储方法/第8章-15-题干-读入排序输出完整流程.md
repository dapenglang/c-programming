# 第 8 章 练习 15　读入排序输出完整流程

**对应章节**：8 数据持久化存储方法（8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）；另用到第 5 章 5.1 一维数组、5.5 排序与查找

**场景来源**：综合实验 C7《冰区载荷辨识与统计系统》（水声学院）——本练习是该实验中"阻力序列排序整理"环节的实现。

**建议用时**：30~40 分钟

## 一、应用场景

实验 C7 完成一批冰阻力样本的采集后，需要把杂乱无章的阻力序列**从小到大排序**，便于后续绘制分布图、查找分位数（如 95% 分位载荷）。排序前数据在文件里，排序结果也要落盘保存成新文件。本练习完成一条最典型的数据处理流水线：**从文件读入数组 → 排序 → 写出到文件**，并在屏幕上报告最大值与最小值。这条"文件—内存—文件"的流水线，是后续所有数据整理任务的标准作业方式。

## 二、任务要求

编写完整程序 `sortdata.c`：

1. 以 `"r"` 方式打开 `load_in.txt`，以 `"w"` 方式打开 `load_sorted.txt`，**检查两个 fopen 的返回值**，失败时输出提示并结束（返回值 1）；
2. **数据文件格式约定**：`load_in.txt` 第一行是样本个数 n（整数，n ≤ 100），第二行是 n 个阻力值（kN，空格分隔，实数）。样例数据行：第一行 `6`，第二行 `23.5 25.1 19.8 27.6 22.4 24.9`；
3. 先读入 n，再用循环把 n 个阻力值读入一维 double 数组（若 n 超过 100 或不大于 0，输出 `数据个数无效` 并结束）；
4. 用**冒泡排序**把数组按从小到大排序；
5. 把排序后的序列按每行一个、`"%.1f\n"` 的格式写入 `load_sorted.txt`；关闭两个文件，并在屏幕输出 `读入 N 个数据，已排序写入 load_sorted.txt` 以及排序后的最大值与最小值（保留 2 位小数）。

## 三、输入输出格式

**输入文件**：`load_in.txt`（第一行 n，第二行 n 个实数）。

**输出文件**：`load_sorted.txt`（每行一个实数，共 n 行，升序）。

**屏幕输出**：两行——`读入 N 个数据，已排序写入 load_sorted.txt` 与 `最大 = X.XX kN，最小 = X.XX kN`。

## 四、样例

**输入文件 load_in.txt 的内容**：

```
6
23.5 25.1 19.8 27.6 22.4 24.9
```

**程序运行后 load_sorted.txt 的内容**：

```
19.8
22.4
23.5
24.9
25.1
27.6
```

**屏幕输出**：

```
读入 6 个数据，已排序写入 load_sorted.txt
最大 = 27.60 kN，最小 = 19.80 kN
```

## 五、提示

- 排序必须**先全部读入数组**再进行——冒泡排序要反复交换任意两个元素，流式地"边读边排"对文件来说是困难的，这正体现了"数组 = 可随机访问的批量数据"的价值；
- 冒泡排序回顾：外层共进行 $n-1$ 轮，第 $i$ 轮从下标 0 扫到 $n-1-i$，相邻元素逆序则交换，每轮把当前最大值"冒泡"到末尾；
- 排好序后，最小值是 `a[0]`，最大值是 `a[n-1]`——不必再单独找一遍；
- 写文件用 `for (i = 0; i < n; i++) fprintf(fo, "%.1f\n", a[i]);`。

**完成本练习后你将具备的能力**：把"文件读入 → 数组算法 → 文件写出"三段式流水线完整走通，并学会在流水线中加入合法性检查——这是实验 C7 数据整理模块的标准流程，也是练习 20 综合流水线的直接前身。
