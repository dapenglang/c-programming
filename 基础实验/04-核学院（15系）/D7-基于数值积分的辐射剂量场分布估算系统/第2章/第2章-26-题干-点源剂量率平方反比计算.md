# 第 2 章 练习 26　点源剂量率平方反比计算

**所属综合实验**：D7（D7-基于数值积分的辐射剂量场分布估算系统）

**对应章节**：2 C 语言程序设计基础（2.1 常量与变量、2.2 数据类型、2.3 运算符、2.4 标准输入输出、2.5 数值计算——幂运算）

**场景来源**：综合实验 D7《基于数值积分的辐射剂量场分布估算系统》（核学院）——本练习是该实验中"单点源剂量率计算"环节的最小实现。

**建议用时**：20 分钟

## 一、应用场景

辐射防护中最基本的一件事，是算出一个**点源**在某处造成的**剂量率**。点源发出的射线向四面八方散开，距离越远，同样多的射线摊在越大的球面上，所以剂量率随距离**平方反比**下降：

$$
\dot{D} = \frac{S}{d^{2}}
$$

其中 $S$ 是源的**强度常数**（已经把源活度、γ 常数等并进一个系数里，单位 μSv·m²/h），$d$ 是测点到源的距离（单位 m），$\dot{D}$ 就是剂量率（单位 μSv/h）。

综合实验 D7 最终要算出一整片区域的剂量场，那片场就是由许多这样的"单点源贡献"叠加起来的。所以这道题是整个 D7 的第一块地基——**先把一个点源对一个测点的贡献算对**。

## 二、任务要求

编写一个完整程序 `point_dose.c`：

1. 程序中用**常量**存放点源强度 $S$（取 120.0，单位 μSv·m²/h）；
2. 从键盘读入测点到源的距离 `d`（单位 m，double 类型，**题目保证 d > 0**，本程序不需要判断分支）；
3. 用平方反比公式计算剂量率 `D`；
4. 按规定格式输出结果，保留 **4 位小数**。

## 三、输入输出格式

**输入**：一行，一个实数，表示测点到源的距离 d（米）。

**输出**：一行，按格式 `D = 结果` 输出，结果保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
2
```
输出：
```
D = 30.0000
```

**样例 2**

输入：
```
5
```
输出：
```
D = 4.8000
```

## 五、提示

平方反比公式：剂量率等于源强除以距离的平方。

$$
\dot{D} = \frac{S}{d^{2}}
$$

在 C 语言里，$d^{2}$ 可以写成 `d * d`（最省事、最准确），也可以写成 `pow(d, 2)`（需要 `#include <math.h>`）。因此本式写成一行：

```c
D = S / (d * d);
```

注意：分母要加括号。若写成 `S / d * d`，按从左到右的顺序会算成 $(S/d)\times d = S$，与距离无关——这是新手最容易犯的错误。
