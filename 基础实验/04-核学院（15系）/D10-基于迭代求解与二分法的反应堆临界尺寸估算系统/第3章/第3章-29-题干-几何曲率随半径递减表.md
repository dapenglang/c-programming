# 第 3 章 练习 29　几何曲率随半径递减表

**所属综合实验**：D10（D10-基于迭代求解与二分法的反应堆临界尺寸估算系统）

**对应章节**：3 程序控制结构（3.3 循环结构——for 循环、3.4 循环的嵌套、2.4 格式化输出）

**场景来源**：综合实验 D10《基于迭代求解与二分法的反应堆临界尺寸估算系统》（核学院）——本练习是该实验中"扫描半径、列出几何曲率递减表"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

材料曲率 $B_m^2 = (k-1)/L^2$ 是介质的固有属性，**几何曲率** $B_g^2$ 则完全由堆的尺寸决定。对半径为 $R$ 的球形堆芯（或按等效球形处理），单群扩散理论给出：

$$
B_g^2 = \left(\frac{\pi}{R}\right)^2 = \frac{\pi^2}{R^2}
$$

**尺寸越大、几何曲率越小**——这是理解临界的关键直觉：堆做得越大，中子泄漏的相对份额越小。

综合实验 D10 求解临界半径时，第一步就是把半径从小到大扫一遍，把对应的 $B_g^2$ 列成表格，观察它如何随 $R$ 单调递减、并找出它在哪一段"跨过"了材料的 $B_m^2$。本题实现这张递减表。

## 二、任务要求

编写一个完整程序 `bg_table.c`：

1. 程序中用**常量**存放圆周率 $\pi$（取 3.14159265358979，double）；
2. 从键盘读入扫描参数：起始半径 `R0`、终止半径 `R1`（单位 cm，**题目保证 30 ≤ R0 < R1 ≤ 150**）和步数 `m`（整数，**题目保证 1 ≤ m ≤ 40**）；
3. 用**循环**从 $R_0$ 到 $R_1$ 均匀取 `m+1` 个半径（含两端点），对每个半径算出几何曲率 $B_g^2 = (\pi/R)^2$；
4. 每行输出一个半径及其几何曲率，半径保留 1 位小数，几何曲率保留 6 位小数。

## 三、输入输出格式

**输入**：一行，两个实数和一个整数，依次为起始半径 R0、终止半径 R1、步数 m，用空格分隔。

**输出**：共 `m+1` 行，每行格式为 `R = 半径, Bg2 = 几何曲率`；半径 1 位小数，几何曲率 6 位小数。

## 四、样例

**样例 1**

输入：
```
30 150 4
```
输出：
```
R = 30.0, Bg2 = 0.010966
R = 60.0, Bg2 = 0.002742
R = 90.0, Bg2 = 0.001218
R = 120.0, Bg2 = 0.000685
R = 150.0, Bg2 = 0.000439
```

**样例 2**

输入：
```
50 70 2
```
输出：
```
R = 50.0, Bg2 = 0.003948
R = 60.0, Bg2 = 0.002742
R = 70.0, Bg2 = 0.002014
```

## 五、提示

- 步长公式：$h = (R_1 - R_0)/m$，则第 $i$ 个半径（$i = 0,1,\dots,m$）为 $R_i = R_0 + i \cdot h$。这样**恰好能取到两端点**，共 `m+1` 个值；
- 循环写成 `for (i = 0; i <= m; i++)`，**上界是 `m` 而不是 `m-1`**（因为是 m 段、m+1 个点）；
- 半径与曲率都必须声明为 `double`，中间量 $i \cdot h$ 中 `i` 是整数会自动提升；
- $\pi$ 定义为常量：`const double PI = 3.14159265358979;`；
- 曲率写成 `Bg2 = (PI / R) * (PI / R);` 或先算 `Bover = PI / R;` 再 `Bg2 = Bover * Bover;`——**仍然不能用 `^`**；
- 想一想递减规律：$R$ 从 30 到 60（翻倍），$B_g^2$ 从 0.010966 降到 0.002742（约 1/4）——**这正是平方反比：半径变为 2 倍，曲率变为 1/4。** 这个规律会在二分法中反复用到。

**完成本练习后你将具备的能力**：用 for 循环做等间距扫描、由步数算步长并按 `R0 + i*h` 取值、在循环中做公式计算并格式化输出表格、观察并解释数值的单调性与量级变化——这些是实验 D10 中"几何曲率扫描模块"的地基。
