## 二、预备知识：用递归替代循环（零基础阅读）

### 1. 问题来源

"求 $x^n$"和"求 $1+2+\dots+n$"用循环写都不难。但它们的数学定义其实都是**递推**的：

$$
x^n = x \cdot x^{n-1},\qquad S(n) = n + S(n-1)
$$

也就是说，**只要能算出"小一号"的结果，再补上这一步的组合操作**，就得到了原问题的答案。这种思路写成函数，就是递归。

### 2. 递归与循环的对照

- 循环：`s = 0; for (i = 1; i <= n; i++) s += i;`——从 1 加到 n，**自下而上**地累加；
- 递归：`sum_to(n) = n + sum_to(n-1)`——**从上往下**把问题拆小，直到基线，再**自下而上**地把结果组合回来。

两者结果相同，但思考方向相反。一般地：**能用循环写的递推关系，都能改写成递归；反之亦然**。选择哪种，取决于哪种更好读。

### 3. 基线条件

- `my_pow`：$x^0 = 1$，所以 `n == 0` 时返回 `1.0`；
- `sum_to`：$0$ 个数的和是 $0$，所以 `n == 0` 时返回 `0`。

基线都取 $n=0$，比阶乘题的 $n\le1$ 更统一，因为它让两个递推的终止点都是"零个"。

### 4. 调用栈展开：两个函数各看一遍

**求 $2^3$（即 `my_pow(2, 3)`）：**

```text
my_pow(2, 3) = 2 * my_pow(2, 2)      ── 挂起
  my_pow(2, 2) = 2 * my_pow(2, 1)    ── 挂起
    my_pow(2, 1) = 2 * my_pow(2, 0)  ── 挂起
      my_pow(2, 0)  命中基线 → 1.0      （最深处）
    my_pow(2, 1) = 2 * 1.0 = 2.0     ── 返回 2.0
  my_pow(2, 2) = 2 * 2.0 = 4.0       ── 返回 4.0
my_pow(2, 3) = 2 * 4.0 = 8.0         ── 返回 8.0
```

**求 $1+2+3+4$（即 `sum_to(4)`）：**

```text
sum_to(4) = 4 + sum_to(3)     ── 挂起
  sum_to(3) = 3 + sum_to(2)   ── 挂起
    sum_to(2) = 2 + sum_to(1) ── 挂起
      sum_to(1) = 1 + sum_to(0) ── 挂起
        sum_to(0)  命中基线 → 0    （最深处）
      sum_to(1) = 1 + 0 = 1    ── 返回 1
    sum_to(2) = 2 + 1 = 3      ── 返回 3
  sum_to(3) = 3 + 3 = 6        ── 返回 6
sum_to(4) = 4 + 6 = 10         ── 返回 10
```

两个函数的调用结构一模一样：**一路深入，触底返回，在返回的路上把"乘 x"或"加当前 n"补上**。

### 5. 编程要点

- `my_pow` 返回 `double`，基线返回 `1.0`（写成 `1` 也不错，但 `1.0` 更贴合"浮点结果"的语义）；
- `sum_to` 返回 `int`，因为和是整数；
- 主函数用 `scanf("%lf %d", &x, &n)`，注意 `%lf` 与 `%d` 分别对应 `double` 与 `int`。

## 三、解题思路

1. **定两个接口**：`my_pow`、`sum_to`，各写原型；
2. **写基线**：两个都取 `n == 0`；
3. **写递推**：`x * my_pow(x, n-1)` 与 `n + sum_to(n-1)`；
4. **主流程**：读 `x`、`n` → 两次调用 → 两行输出；
5. **校核**：$2^{10}=1024$、$1+2+\dots+10=55$。

## 四、参考代码

```c
#include <stdio.h>
/* 函数原型声明 */
double my_pow(double x, int n);   /* x 的 n 次幂 */
int    sum_to(int n);             /* 1 + 2 + ... + n */

int main(void)
{
    double x;
    int n;

    scanf("%lf %d", &x, &n);                      /* 读入底数与非负整数 n */
    printf("pow = %.4f\n", my_pow(x, n));         /* 递归求幂 */
    printf("sum = %d\n", sum_to(n));              /* 递归求和 */
    return 0;
}
/* 递归求幂：x^n = x * x^(n-1)，x^0 = 1 */
double my_pow(double x, int n)
{
    if (n == 0)                                   /* 基线条件 */
        return 1.0;
    else                                          /* 递推关系 */
        return x * my_pow(x, n - 1);
}
/* 递归求累加：S(n) = n + S(n-1)，S(0) = 0 */
int sum_to(int n)
{
    if (n == 0)                                   /* 基线条件 */
        return 0;
    else                                          /* 递推关系 */
        return n + sum_to(n - 1);
}
```

## 五、运行验证

以 `my_pow(2,3)` 与 `sum_to(4)` 为例的中间结果：

| 调用 | 表达式 | 本层结果 |
|---|---|---|
| my_pow(2, 0) | 基线 | 1.0 |
| my_pow(2, 1) | 2 × 1.0 | 2.0 |
| my_pow(2, 2) | 2 × 2.0 | 4.0 |
| my_pow(2, 3) | 2 × 4.0 | 8.0 |
| sum_to(1) | 1 + 0 | 1 |
| sum_to(2) | 2 + 1 | 3 |
| sum_to(3) | 3 + 3 | 6 |
| sum_to(4) | 4 + 6 | 10 |

多组输入的程序输出：

| 输入 x n | 手算过程 | 程序输出 |
|---|---|---|
| 2 10 | $2^{10}=1024$；$1+\dots+10=55$ | `pow = 1024.0000`、`sum = 55` ✓ |
| 1.5 3 | $1.5^3=3.375$；$1+2+3=6$ | `pow = 3.3750`、`sum = 6` ✓ |
| 3 4 | $3^4=81$；$1+2+3+4=10$ | `pow = 81.0000`、`sum = 10` ✓ |
| 2 0 | $2^0=1$；空和为 0 | `pow = 1.0000`、`sum = 0` ✓ |

## 六、常见错误与讲解

**错误 1：`my_pow` 返回类型写成 `int`，结果被截断**

```c
int my_pow(double x, int n) { ... return x * my_pow(x, n - 1); }  /* 错：1.5^3 会变成 3 */
double my_pow(double x, int n) { ... }                            /* 对 */
```

**错误 2：基线条件缺失或方向写反**

```c
return x * my_pow(x, n - 1);   /* 没有 n == 0 的出口 → 死递归 */
return x * my_pow(x, n + 1);   /* n 越来越大 → 永远到不了基线 */
```

**错误 3：把递归当成 C 标准库的 `pow`**

```c
#include <math.h>
double p = pow(x, n);          /* 这是库函数、需要 -lm；本题要求自己写 my_pow 体会递归 */
```
题目的用意是**手写递归**，而不是调用现成的幂函数。

**错误 4：`sum_to` 忘记返回、或打印格式不匹配**

```c
if (n == 0) 0;                                  /* 错：没有 return */
printf("sum = %f\n", sum_to(n));                /* 错：int 用 %f */
printf("sum = %d\n", sum_to(n));                /* 对 */
```

## 七、与综合实验的衔接

- 在实验 **C3（声传播损失估算系统）**中，"逐层累加各层损失"和"按倍率逐层相乘"就是本练习两个函数在物理背景下的应用：把每层的衰减量作为一项累加，把每层的衰减倍率作为一次乘幂；
- 更一般地，C3、D1（活度随时间的幂/指数衰减）、A10（积分累加）都体现"递推 + 组合"的结构。**掌握"用递归表达递推"，你就能在循环与递归之间自由切换**，把代码写得既正确又易读。
