# 第 7 章 练习 07　结构体指针访问

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.4 结构体指针变量）

**场景来源**：综合实验 C6《冰区航行冰块碰撞仿真系统》（水声学院）——本练习是该实验中"冰块状态按时间步更新"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

碰撞仿真的主循环里，每个时间步 $\Delta t$ 都要更新冰块的状态：冰块以速度 $(v_x, v_y)$ 匀速漂移，位置按 $x \leftarrow x + v_x \Delta t$、$y \leftarrow y + v_y \Delta t$ 推进。仿真内核拿到的是冰块的**地址**（指针），通过指针直接读写冰块本体——因为仿真要修改的就是那块真实的冰，而不是它的副本。本练习练习结构体指针的定义、取址，以及用箭头运算符 `->` 访问成员，体会"通过指针原地修改结构体"与值传递的区别。

## 二、任务要求

编写一个完整程序 `ice_move.c`：

1. 按下面的框架定义结构体类型（成员名不得改动）：

```c
struct IceBlock {
    int    id;      /* 冰块编号 */
    double x;       /* 位置 x（m） */
    double y;       /* 位置 y（m） */
    double vx;      /* 速度 vx（m/s） */
    double vy;      /* 速度 vy（m/s） */
};
```

2. `main` 中定义结构体变量并读入数据；定义结构体指针 `struct IceBlock *p = &b;`；
3. **全部后续访问必须通过指针 p 用 `->` 完成**：先输出更新前状态，再按 $x \leftarrow x + v_x \Delta t$、$y \leftarrow y + v_y \Delta t$ 更新位置，最后输出更新后状态；
4. 时间步长 $\Delta t$ 由键盘读入。

## 三、输入输出格式

**输入**：一行，6 个数据：编号（整数）、x、y、vx、vy（实数）、$\Delta t$（实数，s），以空格分隔。

**输出**：两行，格式为 `更新前：编号 号冰块位置 (x, y) m` 与 `更新后：编号 号冰块位置 (x, y) m`，坐标保留 **2 位小数**。

## 四、样例

**样例 1**

输入：
```
3 12.0 5.0 1.5 -0.8 2.0
```
输出：
```
更新前：3 号冰块位置 (12.00, 5.00) m
更新后：3 号冰块位置 (15.00, 3.40) m
```

**样例 2**

输入：
```
7 20.0 10.0 -2.0 4.0 0.5
```
输出：
```
更新前：7 号冰块位置 (20.00, 10.00) m
更新后：7 号冰块位置 (19.00, 12.00) m
```

## 五、提示

- 结构体指针定义：`struct IceBlock *p = &b;`，取结构体变量地址同样用 `&`；
- 箭头运算符：`p->x` 等价于 `(*p).x`，表示"p 指向的那个结构体的 x 成员"；
- 更新位置：`p->x += p->vx * dt; p->y += p->vy * dt;`——注意速度成员不更新；
- 输出编号也走指针：`p->id`。

**完成本练习后你将具备的能力**：定义结构体指针、取结构体地址、用 `->` 读写成员——实验 C6 的仿真内核正是通过指针在时间步循环中原地推进每块冰的状态。
