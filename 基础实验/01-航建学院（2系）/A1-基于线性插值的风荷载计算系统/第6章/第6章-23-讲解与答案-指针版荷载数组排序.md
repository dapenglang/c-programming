## 二、预备知识：排序与指针传数组的基本原理（零基础阅读）

### 1. 问题是怎么来的

一排数排成从大到小，方便看"最不利值"和"前几名"。冒泡排序是最容易理解的排序算法，适合入门。它要用到两把钥匙：**元素交换**和**指针传数组**。

### 2. 元素交换是怎么做的——为什么需要"临时柜子"

要把 `a` 和 `b` 两个柜子里的东西互换，不能直接写：

```c
a = b;
b = a;      /* 错：a 已经被改成 b 的值，b = a 等于没换 */
```

这就像要把两个杯子里的水互换：直接倒会让一杯倒空、另一杯没接住。必须借助一个**空杯子**：

$$
a \to t,\quad b \to a,\quad t \to b
$$

对应代码：

```c
t = a; a = b; b = t;    /* 三步交换 */
```

### 3. 冒泡排序是怎么走的

以降序（大在前）为例。每一轮从左到右扫描：

- 若 `a[j] < a[j+1]`（前小后大，不符合降序），就交换两者；
- 否则不动。

经过一轮，最小的元素像气泡一样被推到最右边。下一轮只需处理前 n-1 个（因为最后 1 个已就位），以此类推。共需 `n-1` 轮。

以 `[3, 1, 2]` 为例走一遍：

| 轮次 | 比较 | 结果 |
|---|---|---|
| 第 1 轮 | 3>1 不动；1<2 交换 | `[3, 2, 1]` |
| 第 2 轮 | 3>2 不动 | `[3, 2, 1]` |

排好了。

### 4. 指针参数为什么能改原数组

关键理解：**数组名就是首元素的地址**。当函数参数写成 `double *a`，调用 `sort(arr, n)` 时，传进去的是 `arr` 的地址，函数内部的 `a` 就指向主函数的那片内存。因此函数里写 `a[j] = ...` 改的就是主函数的数组元素——**和主函数里直接改一模一样**。

画一张内存图：

```
主函数 arr:  [0.85][1.20][0.60][1.55][0.95][1.10]
                 ↑
函数内 a ────────┘   （a 存着 arr 的首地址，指向同一片内存）
```

所以函数不需要 `return` 任何东西，`void sort` 就够了——改动直接落在原数组上。

### 5. `a[j]` 与 `*(a+j)` 是一回事

C 语言里，`a[j]` 会被自动翻译成 `*(a + j)`：从首地址 `a` 往后跳 `j` 个元素，再解引用。所以下面两行等价：

```c
a[j] = a[j+1];        /* 下标写法 */
*(a+j) = *(a+j+1);    /* 指针写法 */
```

本题用哪种都行，理解它们等价即可。

## 三、解题思路

1. **定义 void 函数 `sort(double *a, int n)`**；
2. **双层循环实现冒泡**：外层 `i` 控制轮数 `n-1`，内层 `j` 控制每轮的比较范围；
3. **降序判断**：`if (a[j] < a[j+1])` 时交换；
4. **主函数读入 n 与数组，调用 `sort(arr, n)`**；
5. **输出排序结果**，格式用循环控制空格。

## 四、参考代码

```c
#include <stdio.h>

/* 函数声明：指针参数接收数组，无返回值 */
void sort(double *a, int n);

int main(void)
{
    int n, i;
    double arr[30];        /* 各楼层风压强度，kN/m^2 */

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf", &arr[i]);
    }

    /* 传数组名（首地址）即可，函数会直接改原数组 */
    sort(arr, n);

    /* 输出排序结果，用空格分隔 */
    for (i = 0; i < n; i++) {
        printf("%.2f", arr[i]);
        if (i < n - 1) printf(" ");      /* 最后一个数后不加空格 */
    }
    printf("\n");

    return 0;
}

/* 冒泡排序（降序）：a 为数组首地址，n 为元素个数 */
void sort(double *a, int n)
{
    int i, j;
    double t;
    for (i = 0; i < n - 1; i++) {             /* 共 n-1 轮 */
        for (j = 0; j < n - 1 - i; j++) {     /* 每轮比较范围逐轮缩小 */
            if (a[j] < a[j + 1]) {            /* 前小后大：需交换以保持降序 */
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
}
```

## 五、运行验证

| 输入 | 手算/中间过程 | 程序输出 |
|---|---|---|
| 6 / 0.85 1.20 0.60 1.55 0.95 1.10 | 降序排列，最大 1.55，最小 0.60 | `1.55 1.20 1.10 0.95 0.85 0.60` ✓ |
| 5 / 2.10 0.30 1.80 0.75 1.20 | 降序：2.10、1.80、1.20、0.75、0.30 | `2.10 1.80 1.20 0.75 0.30` ✓ |

## 六、常见错误与讲解

**错误 1：交换写成两行**

```c
a[j] = a[j+1]; a[j+1] = a[j];     /* 错：第一行已覆盖 a[j]，两者变成相同值 */
```

必须引入临时变量 `t`，三步交换。

**错误 2：传数组时加 `&` 或写成单个元素**

```c
sort(&arr, n);      /* 多余：arr 本身即地址（虽多数情况可用，但不规范） */
sort(arr[0], n);    /* 错：传的是第一个元素的值，不是数组 */
```

正确写法：`sort(arr, n);`。

**错误 3：降序判断条件写反**

```c
if (a[j] > a[j + 1]) ...     /* 写成这样得到升序（小在前） */
if (a[j] < a[j + 1]) ...     /* 对：降序需要把"前小后大"的换过来 */
```

先想清楚要的是升序还是降序，再决定条件方向。

**错误 4：数组长度不足**

```c
double arr[30];      /* 若 n 可能超过 30 就危险 */
```

本题保证 n ≤ 30，则数组至少开 30。若不确定，宁可开大一些（如 100），避免越界。
