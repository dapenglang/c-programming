# 第 3 章 练习 06　超阈值样本计数（循环 + 判断）

**对应章节**：3 结构化程序设计方法（3.2 选择结构、3.3 循环结构——for 循环、3.4 关系运算符）

**场景来源**：综合实验 C7《冰载荷数据辨识与统计系统》（水声学院）——本练习是该实验中"超阈值事件统计"环节的实现。

**建议用时**：25 分钟

## 一、应用场景

冰载荷长期监测系统昼夜不停地输出阻力样本。结构设计人员关心的问题不是"载荷有多高"，而是"**载荷有多频繁**"：一天 24 小时里，阻力超过安全阈值 850 kN 的事件发生了多少次、占全部样本的比例是多少？这个占比（超标率）直接决定结构构件的疲劳寿命评估结论。统计程序需要在读入样本流的循环里**顺带数数**：每读到一个超过阈值的样本就把计数器加一，最后除以总数得到占比。这种"循环 + 判断 + 计数"的三件套是数据统计程序的基本功。

## 二、任务要求

编写一个完整程序 `over_count.c`：

1. 第一行读入两个数：样本个数 `n`（整数，**题目保证 $1 \le n \le 1000$**）与阈值 `T`（实数，单位 kN）；
2. 随后读入 n 个实数（阻力样本，单位 kN）；
3. 统计**严格大于**阈值 T 的样本个数 `count`（恰好等于阈值不算超标）；
4. 按格式输出 `count` 与超标占比 `ratio`（百分数，保留 2 位小数）。

## 三、输入输出格式

**输入**：第一行两个数 n 和 T，以空格分隔；第二行 n 个实数，以空格分隔。

**输出**：一行，格式为 `count = 次数, ratio = 占比%`，占比保留 2 位小数。

## 四、样例

**样例 1**

输入：
```
8 850
861.2 843.5 872.9 838.0 855.4 849.9 866.1 850.0
```
输出：
```
count = 4, ratio = 50.00%
```
（超标的 4 个：861.2、872.9、855.4、866.1；注意 849.9 与恰好 850.0 都不算）

**样例 2**

输入：
```
5 900
861.2 843.5 872.9 838.0 855.4
```
输出：
```
count = 0, ratio = 0.00%
```
（阈值提高到 900，没有一个样本超标——占比为 0 是完全正常的输出）

## 五、提示

计数器与累加器用法一致，只是加的不是样本值而是 1：

```c
if (f > t)
    count = count + 1;
```

占比要小心**整数除法**陷阱：`count / n` 若两边都是 int，结果会舍掉小数部分。先把 count 乘上 100.0 变成实数运算，或写成 `count * 100.0 / n`。

**完成本练习后你将具备的能力**：在循环中结合 if 做条件计数、正确计算百分比并避开整数除法陷阱——这是实验 C7 中超标事件统计模块的完整实现。
