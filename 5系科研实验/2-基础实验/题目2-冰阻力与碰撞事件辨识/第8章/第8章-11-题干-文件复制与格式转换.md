# 第 8 章 练习 11　文件复制与格式转换

**对应章节**：8 数据持久化存储方法（8.2 文件型指针、8.3 文件的打开与关闭、8.4 文件的读写）

**场景来源**：综合实验 C7《冰区载荷辨识与统计系统》（水声学院）——本练习是该实验中"原始阻力数据文件格式转换"环节的实现（方法取自教材 8.4 节"文件的读写"例题）。

**建议用时**：30～40 分钟

## 一、应用场景

实验 C7 采集的冰阻力原始数据文件 `resistance_raw.txt` 是测量仪器导出的**逗号分隔**格式（样本序号,阻力值），而实验后续的统计模块只接受**空格分隔**的标准格式。在把数据交给统计程序之前，必须先做一次"格式转换"：把原始文件逐行读入，转成空格分隔的新文件 `resistance.txt`，原文件保留不动。这就是工程中最常见的"文件复制 + 格式转换"操作——它看起来简单，却是任何数据处理流水线的第一步。

## 二、任务要求

编写完整程序 `convert.c`：

1. 以只读方式 `"r"` 打开 `resistance_raw.txt`，以写方式 `"w"` 打开 `resistance.txt`，**两个 fopen 的返回值都必须检查**，任一打开失败时输出错误提示并结束程序（返回值 1）；
2. 用 `fgets` 逐行读入原始文件（每行不超过 100 个字符），用 `sscanf` 按格式 `"%d,%lf"` 从该行中拆出样本序号（整数）与阻力值（kN，实数）；
3. 把每行按 `"%d %.1f\n"` 的格式写入新文件 `resistance.txt`；
4. 原始文件末尾可能有一个多余的空行（`fgets` 读到只含 `'\n'` 的行），遇到空行时直接跳过：不写入新文件、不计数；
5. 全部处理完后关闭两个文件，并在屏幕输出成功转换的行数。

**数据文件格式约定**：`resistance_raw.txt` 每行两列，逗号分隔；第 1 列为样本序号（整数），第 2 列为阻力值（kN，保留 1 位小数）。样例数据行：`1,23.5`。

## 三、输入输出格式

**输入文件**：`resistance_raw.txt`（逗号分隔文本，若干行）。

**输出文件**：`resistance.txt`（空格分隔文本，与有效行一一对应）。

**屏幕输出**：一行，格式为 `转换完成：共 N 行`（N 为成功转换的行数）。

## 四、样例

**输入文件 resistance_raw.txt 的内容**：

```
1,23.5
2,25.1
3,19.8
4,27.6
5,22.4
```

**程序运行后 resistance.txt 的内容**：

```
1 23.5
2 25.1
3 19.8
4 27.6
5 22.4
```

**屏幕输出**：

```
转换完成：共 5 行
```

## 五、提示

- `fgets` 的原型是 `fgets(str, n, fp)`：从 fp 指向的文件读入一行（包括行末的 `'\n'`，并自动补 `'\0'`），读到文件末尾返回 NULL。循环条件可写成 `while (fgets(line, sizeof(line), fin) != NULL)`；
- `sscanf` 与 `scanf` 用法完全相同，只是第一个参数换成"要解析的字符串"：`sscanf(line, "%d,%lf", &id, &f)`，格式串中的逗号要与数据行中的逗号一一对应；
- 判断空行可以用 `if (line[0] == '\n') continue;`，也可以看 `sscanf` 的返回值是否等于 2；
- 注意 `fopen` 的第二个参数：读旧文件用 `"r"`，写新文件用 `"w"`——用 `"w"` 打开一个已存在的文件会**清空**它的内容，别把目标文件名写错。

**完成本练习后你将具备的能力**：同时管理两个文件指针、`fgets` + `sscanf` 的"读一行、解析一行"组合拳、按新格式重组并写出数据行——这正是实验 C7 数据预处理模块的原型，也是后续练习 12、14、15 的基础骨架。
