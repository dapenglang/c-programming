# 第 6 章 练习 06　指针版数组查找

**对应章节**：6 内存数据深度操控方法（6.2 指针变量的定义与使用、6.3 指针与数组；为 6.5 指针与函数中"返回地址"打基础）

**场景来源**：综合实验 C6《冰区船舶与冰块碰撞模拟系统》（水声学院）——本练习是该实验中"按质量定位冰块记录并修正"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

碰撞模拟系统 C6 的冰块数据库中，每块冰的质量记录存放在一个数组里。当试验人员发现某块冰的质量记录有误时，系统先**按原质量值查找**这条记录，找到后**在原位置直接修正**。查找函数若只返回"是否找到"，主函数还须再写一遍定位逻辑；更高效的返回方式是**直接返回目标元素的地址**——拿到地址即可读、可写，一举两得。本练习就实现这个"返回地址"的查找函数：找到返回元素地址，找不到返回 `NULL`（空指针）。

## 二、任务要求

编写一个完整程序 `ice_find.c`：

1. 编写函数 `double *find(double *a, int n, double key)`：在 `a` 指向的 `n` 个元素中顺序查找 `key`，用指针遍历；找到返回该元素地址，找不到返回 `NULL`；
2. 主函数读入 6 个冰块质量（kg）存入数组，再读入待查找的原质量 `key` 与修正值 `fix`；
3. 调用 `find`：若返回非 `NULL`，输出 `found at index 下标`，并通过返回的指针把该元素修改为 `fix`，再输出修正后的 6 个质量（保留 2 位小数）；
4. 若返回 `NULL`，输出 `NOT FOUND`，不修改任何数据。

## 三、输入输出格式

**输入**：两行。
第 1 行：6 个实数，冰块质量（kg），空格分隔；
第 2 行：两个实数，`key` 与 `fix`。

**输出**：找到时两行：`found at index 下标` 与修正后的质量序列；找不到时一行：`NOT FOUND`。

## 四、样例

**样例 1**

输入：
```
105.0 88.5 120.3 76.8 95.4 110.2
88.5 92.0
```
输出：
```
found at index 1
105.00 92.00 120.30 76.80 95.40 110.20
```

**样例 2**

输入：
```
105.0 88.5 120.3 76.8 95.4 110.2
60.0 65.0
```
输出：
```
NOT FOUND
```

## 五、提示

1. 函数内的遍历与练习 03 相同：`for (p = a; p < a + n; p++)`，比较 `*p == key`；
2. 返回地址而非值：`return p;`——返回类型写成 `double *`；
3. `NULL` 是 stdio.h 中定义的"空指针"常量，表示"不指向任何有效数据"，判断写 `if (pos != NULL)`；
4. 主函数拿到地址 `pos` 后，下标可由**指针相减**得到：`pos - m` 的结果是两地址之间的元素个数（`long` 型，用 `%ld` 输出或强制转换）。

**完成本练习后你将具备的能力**：编写返回指针的函数、理解 `NULL` 的含义与判空习惯、用指针相减求下标——实验 C6 中"定位并修正记录"环节的完整实现，也是 6.5"指针与函数"的直通训练。
