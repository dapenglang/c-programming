# 第 7 章 练习 10　结构体数组统计报表

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.2 结构体数组、7.3 结构体变量作为函数参数）

**场景来源**：综合实验 C7《冰载荷样本统计与载荷辨识系统》（水声学院）——本练习是该实验中"样本统计报表生成"环节的实现。

**建议用时**：30 分钟

## 一、应用场景

载荷辨识系统（实验 C7）每完成一轮现场测量，都要生成一份统计报表：这批撞击样本共多少条？平均阻力多大？最大阻力出现在哪次撞击？超过警戒阈值的样本有几条？报表的每一行输入是一条完整记录（编号 + 阻力），每一项输出是对记录集合的整体统计。本练习把第 7 章前半段的技法收拢成一条完整流水线：**结构体数组存数据、函数做统计、main 组报表**——写完它，你就具备了独立搭建 C7 统计模块的雏形。

## 二、任务要求

编写一个完整程序 `load_report.c`：

1. 按下面的框架定义结构体类型（成员名不得改动）：

```c
struct Record {
    int    no;      /* 样本编号 */
    double force;   /* 撞击阻力（kN） */
};
```

2. 定义长度为 20 的结构体数组（题目保证 $1 \le n \le 20$），读入 $n$ 条记录与警戒阈值 `T`（kN）；
3. 编写函数 `double average(struct Record r[], int n);` 计算平均阻力（数组作参数，第 5 章 + 7.2 综合）；
4. `main` 中一次遍历统计：最大阻力及其样本编号、超过阈值 `T` 的样本数；连同平均值输出四行报表。

## 三、输入输出格式

**输入**：第一行两个数据：$n$（整数，$1 \le n \le 20$）、阈值 `T`（实数，kN）；随后 $n$ 行，每行 2 个数据：样本编号（整数）、阻力（实数，kN）。

**输出**：四行：

```
样本总数 = n
平均阻力 = X kN
最大阻力 = X kN（编号 号）
超阈值样本数 = k（阈值 T kN）
```

其中实数保留 **2 位小数**，阈值保留 **1 位小数**。

## 四、样例

**样例 1**

输入：
```
6 10.0
1 12.5
2 8.3
3 15.2
4 9.8
5 11.4
6 13.0
```
输出：
```
样本总数 = 6
平均阻力 = 11.70 kN
最大阻力 = 15.20 kN（3 号）
超阈值样本数 = 4（阈值 10.0 kN）
```

**样例 2**

输入：
```
4 8.0
11 9.5
12 7.2
13 10.1
14 6.8
```
输出：
```
样本总数 = 4
平均阻力 = 8.40 kN
最大阻力 = 10.10 kN（13 号）
超阈值样本数 = 2（阈值 8.0 kN）
```

## 五、提示

- 统计最值与计数可以在**同一次遍历**中完成：每读到一个样本就同时比对最大值、判断是否超阈值；
- 超阈值判断用严格大于：`force > T`；
- 平均值交给独立函数 `average` 计算，体会"一个函数只做一件事"；
- 最大阻力一行的格式里，编号写在括号内：`（%d 号）`。

**完成本练习后你将具备的能力**：把结构体数组、数组作参数的函数、一次遍历多统计量组织成完整报表流水线——这是实验 C7 统计报表模块的直接预演，也是第 7 章 7.1～7.4 前半段的小结。
