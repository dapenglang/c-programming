## 二、预备知识：循环累加的基本原理（零基础阅读）

### 1. 问题是怎么来的

声波在海水中走"分层"的路：每层厚度 $h_i$、声速 $c_i$，在一层里走的时间是"路程 ÷ 速度"：

$$t_i = \frac{h_i}{c_i}$$

要算从海面到海底的总时间，就是把每层的时间**逐个加起来**。数据有 n 层，层数事先不知道具体值，是运行时读进来的——这正是**计数循环**的用武之地：循环变量 `i` 从 1 数到 n，每圈处理一层。

### 2. 累加器：一个变量当"小账本"

"把 n 个数加起来"不需要 n 个变量，只需要**一个变量当账本**：

```c
double total = 0.0;            /* ① 账本清零 */
...
total = total + t;             /* ② 每来一笔，记上一笔 */
```

`total = total + t` 读作"把账本上的旧值加上 t，再写回账本"。循环 n 圈后，账本上就是全部 n 层之和。这个"①清零 → ②循环累加 → ③输出"的三步，就是 C 语言里最常用的**累加器模式**。

数学上它做的是：

$$T = ((t_1 + t_2) + t_3) + \cdots + t_n$$

从 0 出发一笔一笔加，与一次求和结果相同（在 double 精度下按从左到右顺序逐次相加）。

### 3. 代入本例数值

样例 1 的四层：

| 层 i | h (m) | c (m/s) | $t_i = h_i/c_i$ (s) |
|---|---|---|---|
| 1 | 50 | 1500 | 0.033333… |
| 2 | 80 | 1520 | 0.052631… |
| 3 | 30 | 1480 | 0.020270… |
| 4 | 100 | 1540 | 0.064935… |

逐圈记账：`total` 从 0 → 0.033333 → 0.085965 → 0.106236 → 0.171170。最终打印 `总传播时间=0.171170`（`%.6f` 舍入到 6 位小数）。

### 4. 通过编程翻译

把"逐层记账"翻译成程序：层数 n 决定循环圈数（`for (i = 1; i <= n; i++)`）；每圈读入该层 h、c，算出 t，先打印（让用户看到每层的贡献），再记入账本。循环结束后账本就是总时间。

> **这个思想在综合实验中反复出现**：C8 的"逐层累加总传播时间"（M6）、C6 的"分段统计求和"、C9 的"累积分布计算"，全部是同一个累加器模式，只是"每笔账"的含义不同——本练习掌握的是最纯粹的一笔。

## 三、解题思路

1. **读层数**：`scanf("%d", &n);`；
2. **定义累加器**：`double total = 0.0;`（必须初始化为 0）；
3. **for 循环 n 圈**：每圈读 `h, c` → 算 `t = h / c` → 打印本层 → `total += t;`；
4. **打印总时间**：`printf("总传播时间=%.6f\n", total);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    int n, i;
    double h, c, t, total;

    scanf("%d", &n);            /* 读入层数 */

    total = 0.0;                /* 累加器清零 */
    for (i = 1; i <= n; i++) {
        scanf("%lf %lf", &h, &c);       /* 读入本层厚度与声速 */
        t = h / c;                       /* 本层传播时间 = 路程/速度 */
        printf("第%d层时间=%.6f\n", i, t);
        total = total + t;               /* 累加进总时间 */
    }

    printf("总传播时间=%.6f\n", total);
    return 0;
}
```

## 五、运行验证

**样例 1 运行结果**（输入 `4` 与四层数据）：

```
第1层时间=0.033333
第2层时间=0.052632
第3层时间=0.020270
第4层时间=0.064935
总传播时间=0.171170
```

**样例 2 运行结果**（单层 100/1500）：

```
第1层时间=0.066667
总传播时间=0.066667
```

**核对**：样例 1 中 $50/1500+80/1520+30/1480+100/1540 = 0.033333+0.052632+0.020270+0.064935 = 0.171170$，与程序输出一致（数值已按 IEEE-754 double 与 `%.6f` 舍入规则复算核对）。样例 2 单层时总时间恰等于该层时间，验证了累加器在 n=1 时也正确。

**反例验证**：若把 `total = 0.0;` 删掉，`total` 的初值是内存里的随机数，输出将是一个不确定的大数——说明累加器清零不可省略。

## 六、常见错误与讲解

**错误 1：累加器忘清零**

```c
double total;               /* 错：未初始化，值不确定 */
for (i = 1; i <= n; i++) { ... total = total + t; ... }
```

**错误 2：在循环外才读数据、循环内只累加旧值**

```c
for (i = 1; i <= n; i++) { scanf(...) 放到循环外 → 只算了一层 }
```

每层的数据必须在**循环体内**读入，n 层就要读 n 次。

**错误 3：`%lf` 写成 `%f`**

```c
scanf("%f %f", &h, &c);     /* 错：double 用 scanf 要 %lf，%f 会写入错乱 */
```

printf 输出 double 用 `%f`（或 `%.6f`）没问题，但 **scanf 读 double 必须用 `%lf`**。

**错误 4：层号从 0 开始打印**

```c
for (i = 0; i < n; i++) { printf("第%d层时间=...", i, ...); }   /* 打出"第0层"，不符题意 */
```

要么循环从 `i = 1` 到 `i <= n`，要么循环仍从 0 起、打印时用 `i + 1`。
