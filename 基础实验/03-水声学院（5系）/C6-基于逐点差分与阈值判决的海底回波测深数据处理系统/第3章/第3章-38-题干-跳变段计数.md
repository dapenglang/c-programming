# 第 3 章 练习 38　跳变段计数

**所属综合实验**：C6（C6-基于逐点差分与阈值判决的海底回波测深数据处理系统）

**对应章节**：3 循环结构（while/for）、循环累计计数、3.x 关系与逻辑运算符

**场景来源**：综合实验 C6《基于逐点差分与阈值判决的海底回波测深数据处理系统》（水声学院）——本练习是该实验中"跳变段统计"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

练习 37 学会了对**一对**相邻深度做三级判决。现在把视野拉远：一条测线有 $N$ 个 ping，深度序列里可能藏着几段不同的海底地形——平坦段、斜坡段、断层。每出现一次"阶跃跳变"，就说明进入了一段**新**地形。

于是得到一个重要统计量：**跳变次数** $k$。它直接给出地形分段数：$k$ 次跳变把序列切成 $k+1$ 段。综合实验 C6 的第 8 模块"分段统计"（各段的均值、极值）就建立在这个计数之上——先把序列切对，才谈得上逐段统计。

本题读入整条深度序列（逐个读入，**不用数组**：只需记住"上一个深度"），统计超过阈值的跳变次数并推算段数。

## 二、任务要求

编写一个完整程序 `seg_count.c`：

1. 从键盘读入两个数：观测点数 `N`（int，$1 \le N \le 1000$）、判决阈值 `T`（double，m）；
2. 随后读入 $N$ 个深度（double，m）——逐个读入，**边读边处理**，不允许使用数组；
3. 对每对相邻深度计算幅度 $A = |d_i - d_{i-1}|$，若 $A > T$ 则计一次跳变；
4. 输出两行：跳变次数 `jumps = <k>` 与地形段数 `segments = <k+1>`（$N \ge 1$ 时段数恒为 $k+1$）。

## 三、输入输出格式

**输入**：第一行 `N T`；第二行 $N$ 个实数，用空格分隔。

**输出**：两行：

```
jumps = <k>
segments = <k+1>
```

## 四、样例

**样例 1**

输入：
```
8 0.5
150.0 150.2 151.0 151.1 152.6 152.5 150.8 150.9
```
输出：
```
jumps = 3
segments = 4
```
（相邻差分为 0.2、0.8、0.1、1.5、0.1、1.7、0.1，其中 0.8、1.5、1.7 超过阈值 0.5，共 3 次。）

**样例 2**

输入：
```
5 0.5
200.0 200.1 200.2 200.1 200.0
```
输出：
```
jumps = 0
segments = 1
```
（全序列平稳，整条测线只有一段地形。）

## 五、提示

- 核心骨架："记住上一个，比较当前与上一个，然后让当前变成新的上一个"：
  ```c
  scanf("%lf", &d0);                 /* 第一个深度单独读入 */
  for (i = 2; i <= n; i++) {
      scanf("%lf", &d1);             /* 读当前深度 */
      if (fabs(d1 - d0) > T) k++;    /* 幅度超阈值 → 跳变 +1 */
      d0 = d1;                       /* 当前变上一个（滚动前进） */
  }
  ```
- 只需**两个**深度变量 `d0`、`d1` 反复滚动——这是"流式处理"的基本功，也是不用数组处理序列的标准姿势；
- 计数变量 `k` 初始化为 0；
- 想一想：为什么第一个深度要放在循环**外**读？（它没有"上一个"，不参与判决，只充当起点。）

**完成本练习后你将具备的能力**：用两个滚动变量对流式序列做相邻比较与累计——这是 C6 实验"分段重建 + 分段统计"模块的第一步。
