## 二、预备知识：指针参数回传结果的基本原理（零基础阅读）

### 1. 问题是怎么来的

第 4 章我们学过"值传递"：把实参的值**复制**一份给形参。这样一来，函数内部怎么改形参，外面的实参都不受影响——就像把柜子里的东西**复印**一份交给别人，别人涂改复印件，原件不受影响。

于是出现难题：函数想同时告诉调用者两件事（最大挠度 + 它在哪里），可 `return` 一次只能带一个值。值传递帮不上忙。

**办法**：不复制东西，而是把**柜子的门牌号（地址）**交给函数，函数拿着门牌号**直接打开柜子改东西**。改的是原件，因此改动在函数外也看得见。这就是"指针参数回传结果"。

### 2. 用内存图看懂"值传递 vs 地址传递"

假设主函数里有一个变量 `pos`，它的柜子门牌号是 2000，里面初始是 0。

**值传递（错误做法）**：函数参数写 `int pos`。调用时把 0 复制给函数内的一个新柜子（比如门牌 3000）。函数里 `pos = 4;` 改的是门牌 3000 的柜子，主函数的门牌 2000 里还是 0。

```
主函数 pos(门牌2000): [0]  ←── 没变
函数内 pos(门牌3000): [4]  ←── 改了也没用
```

**地址传递（正确做法）**：函数参数写 `int *pos`。调用时把门牌号 2000 复制进去。函数里 `*pos = 4;` 意思是"打开门牌 2000 的柜子，改成 4"。

```
主函数 pos(门牌2000): [4]  ←── 变了！因为改的就是它
函数内 pos(门牌?):  [2000] ←── 纸条上记着 2000，*pos 顺藤摸瓜
```

这就是为什么主函数调用时要写 `&pos`（把 pos 的地址交出去），而函数里要写 `*pos = ...`（按地址去改）。

### 3. 本题两个结果怎么分派

函数

```c
double beam_stat(double *y, int n, int *pos);
```

有三个参数和一个返回值，各自的角色是：

| 名称 | 角色 | 传什么 |
|---|---|---|
| `double *y` | 数组首地址（只读遍历即可） | 数组名 `y` |
| `int n` | 数组有效长度 | 值 `n` |
| `int *pos` | 回传下标的通道 | 变量地址 `&pos` |
| 返回值 | 回传最大挠度 | —— |

一个结果（最大值）走返回值，另一个结果（下标）走指针参数，两个答案就都回到主函数了。

### 4. 用本例走一遍

样例 1 中 $L=6$、$n=6$、$h=1$，各点挠度（m）为：

| 下标 i | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $y_i$ | 0 | 2.847 | 6.111 | 7.031 | 6.111 | 2.847 | 0 |

函数内部：`imax=0`，逐个比较——2.847>0 更新为 1，6.111>2.847 更新为 2，7.031>6.111 更新为 3，之后都不再更新。最终 `*pos = 3`（写回主函数），`return 7.03125`。主函数输出 `max_y = 7.031`、位置 `3 × 1.00 = 3.00`。

## 三、解题思路

1. **定义函数 `beam_stat`**：遍历数组求最大下标 `imax`，`*pos = imax`，`return y[imax]`；
2. **主函数读入** L、q、E、I、n；
3. **计算数组**：`h = L/n`，循环算 n+1 个点的挠度；
4. **调用**：`double mx = beam_stat(y, n, &pos);`；
5. **输出** `mx` 与 `pos * h`。

## 四、参考代码

```c
#include <stdio.h>

/* 函数声明：返回最大挠度，经指针参数 pos 回传其下标 */
double beam_stat(double *y, int n, int *pos);

int main(void)
{
    double L, q, E, I;
    int n, i;
    double h;
    double y[51];        /* 挠度数组，最多 51 个点 */
    int pos;             /* 接收回传的下标 */
    double mx;           /* 最大挠度，m */

    scanf("%lf %lf %lf %lf", &L, &q, &E, &I);
    scanf("%d", &n);

    h = L / n;
    for (i = 0; i <= n; i++) {
        double x = i * h;
        y[i] = q * x * (L*L*L - 2*L*x*x + x*x*x) / (24 * E * I);
    }

    /* 调用：用 &pos 把变量地址交出去 */
    mx = beam_stat(y, n, &pos);

    printf("max_y = %.3f\n", mx);
    printf("x_at_max = %.2f\n", pos * h);

    return 0;
}

/* 在数组中找最大挠度：返回值传最大值，指针参数传下标 */
double beam_stat(double *y, int n, int *pos)
{
    int imax = 0;        /* 当前最大值的下标 */
    int i;

    for (i = 1; i <= n; i++) {
        if (y[i] > y[imax]) {
            imax = i;    /* 更新擂主下标 */
        }
    }

    *pos = imax;         /* 关键：按地址把下标写回主函数 */
    return y[imax];      /* 通过返回值交回最大值 */
}
```

## 五、运行验证

| 输入 | 手算/中间过程 | 程序输出 |
|---|---|---|
| 6 10 30000 0.0008 / 6 | x=3 处 $4050/576 = 7.03125$ 最大，下标 3，坐标 3.00 | `max_y = 7.031` `x_at_max = 3.00` ✓ |
| 4 10 30000 0.0008 / 4 | x=2 处 $10\times2\times40/576\approx1.389$ 最大，坐标 2.00 | `max_y = 1.389` `x_at_max = 2.00` ✓ |
| 2 10 30000 0.0008 / 2 | x=1 处 $10\times1\times(8-4+1)/576 = 50/576\approx0.0868$ | `max_y = 0.087` `x_at_max = 1.00` ✓ |

关键的验证点：`pos` 在主函数里被打印出正确值（3、2、1），说明指针参数确实把下标回传成功。

## 六、常见错误与讲解

**错误 1：调用时忘记加 `&`**

```c
mx = beam_stat(y, n, pos);      /* 错：传进去的是 pos 的值，不是地址 */
mx = beam_stat(y, n, &pos);     /* 对：传地址 */
```

不加 `&`，函数内部的 `*pos` 会把一个整数当作地址去解引用，程序极可能崩溃。**看到函数参数是 `int *`、`double *`，调用时实参就写 `&变量`。**

**错误 2：函数内写成 `pos = imax;`**

```c
void ...(int *pos) { pos = imax; }    /* 错：只改了函数内的纸条(地址)，外面没变 */
```

`pos` 是地址，`*pos` 才是它指向的柜子。回传结果必须写 `*pos = imax;`。

**错误 3：误以为数组参数需要加 `&`**

```c
mx = beam_stat(&y, n, &pos);    /* 多余：y 本身就是地址，不用再加 & */
```

数组名已经代表首地址，直接写 `y` 即可。这也是"指针参数"和"数组参数"其实是同一回事的体现。

**错误 4：函数声明与定义不一致**

```c
double beam_stat(double *y, int n, int *pos);   /* 声明 */
double beam_stat(double y[], int n, int *pos)   /* 定义写成 y[]，其实等价，可以 */
double beam_stat(double y, int n, int *pos)     /* 错：y 写成 double，类型不符 */
```

`double y[]` 和 `double *y` 作为形参是等价的，但写成 `double y` 就完全不同（是值传递）。

## 七、与综合实验的衔接

- 实验 **A2（简支梁最大挠度位置）**中，本练习对应"结果回传"模块。真实求解时，`beam_stat` 先给出最大值的粗略位置，二分法再在其附近细找精确位置——二分法本身也需要函数（挠度公式）与指针参数配合，本练习正是那一环的预演；
- "指针参数回传多个结果"是编程中的通用技巧：第 6 章后面的"指针版沉降数据字符串解析"要用它回传解析出的数值个数；将来处理矩阵运算、统计量时，往往一次要回传"最值 + 位置 + 个数"多个结果，返回值只能给一个，其余全靠指针参数。**记住这句口诀：一个结果用返回，多个结果用指针。**
