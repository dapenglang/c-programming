# 《计算思维与问题求解》C 语言综合实验题目库 · 总目录（V3 定稿版）

> 本目录对应四个学院的 30 个综合实验题目，每个题目一份独立文档，含：系统/算法说明、题目任务与专业关联、数据来源与格式、数据结构设计、功能模块拆解（含每个模块的功能简介与输入输出）、数据流与控制流、知识点对照表与超纲关键词、团队分工建议、预期成果示例、选做扩展。
>
> **选题规则**：3~4 人一组，每组选 1 题；同一题目最多 3 组选择（5 系、15 系每题最多 2 组），先到先得，额满后由教师协调改选。

## 版本说明

- V3 定稿依据：题目经郎博士三轮审阅（V1 专业关联弱 → V2 难度大 → V3 定稿），最终原则为"算法全部落在课程知识内、专业特色体现在应用场景、模块细粒度拆分以练熟 C 语言为目的"。
- 每题新增"系统/算法说明"一节：解释系统作用、解决的重要问题及支撑的关键应用。
