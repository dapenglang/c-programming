# 第 3 章 练习 44　集热器日得热量梯形积分

**所属综合实验**：A10（A10-基于数值积分的太阳能集热器日得热量计算系统）

**对应章节**：3 循环结构（3.1 for 循环、3.5 累加器模式、2.4 实数运算与格式化输出）

**场景来源**：综合实验 A10《基于数值积分的太阳能集热器日得热量计算系统》（航建学院）——本练习是该实验中"逐时段累加得热量环节"的最小实现。

**建议用时**：40 分钟

## 一、应用场景

太阳能集热器一天之中功率随日照变化：清晨从 0 缓缓升起，中午达到峰值，傍晚又回落到 0。测得的是**每隔一段时间一个功率值**（离散的点），而"日得热量"（一天总共收集了多少能量，单位 kWh）在数学上是功率曲线下的**面积**——一个定积分。

测到的只是离散点，没法精确积分，工程上最常用的近似是**梯形积分（梯形法则）**：把相邻两个测点之间的曲线段当成直线段，每一小段下的面积就是一个小**梯形**，把所有梯形面积加起来。

综合实验 A10 用梯形积分计算集热器日得热量，本题实现其中"逐时段累加"环节，只用**一个循环 + 一个累加器**。

## 二、任务要求

编写一个完整程序 `daily_gain.c`：

1. 从键盘读入时段数 `n` 与步长 `h`（`n` 为整数，**1 ≤ n ≤ 100**；`h` 为 double，单位 h，0 < h ≤ 2）；
2. 读入 `n + 1` 个功率值 `P[0] ~ P[n]`（double，单位 kW）——注意是 `n` 个时段对应 `n + 1` 个测点（好比 6 小时、每 1 小时一测，共 7 个测点）；
3. 用**梯形法则**计算日得热量：

$$Q = h \cdot \left( \frac{P_0 + P_n}{2} + \sum_{i=1}^{n-1} P_i \right)$$

4. 输出日得热量 `Q`（保留 2 位小数）；
5. **禁用数组、禁用函数**——本题练的是循环累加，读完一个功率就可以**立即累加**，不需要保存所有值（设一个"首值"变量 `p0` 和一个"末值/当前值"变量 `pcur` 即可）；
6. 题目保证输入功率均非负。

## 三、输入输出格式

**输入**：第一行两个数 n h；第二行 n+1 个实数（空格分隔）。

**输出**：`日得热量 Q = xx.xx kWh`

## 四、样例

**样例 1**

输入：
```
6 0.5
0.0 1.2 2.8 3.5 2.6 1.4 0.0
```
输出：
```
日得热量 Q = 5.75 kWh
```

**样例 2**

输入：
```
1 1.0
2.0 4.0
```
输出：
```
日得热量 Q = 3.00 kWh
```

（只有 1 个时段时，Q = h·(P0 + P1)/2 = 1×3 = 3——单独一个小梯形的面积。）

## 五、提示

- 梯形积分的循环累加写法：
  ```c
  Q = (p0 + pcur) / 2.0;          /* 首尾两个测点只算半权 */
  for (i = 1; i <= n - 1; i++) {  /* 中间测点全权 */
      scanf("%lf", &pcur);
      Q += pcur;
  }
  scanf("%lf", &pcur);            /* 最后一个测点 */
  Q = (p0 + pcur) / 2.0 + ...     /* 注意组织好读入与累加的顺序 */
  Q *= h;                         /* 最后统一乘步长 */
  ```
  （骨架里故意留了调整空间——建议先把"中间点累加"的循环写顺，再处理首尾的半权。）
- 更直接的写法：先读入 `P[0]` 存入 `p0`（首点只读一次），之后每读一个新点 `pcur`，就把**上一小段的梯形面积** `h*(p0_prev + pcur)/2` 累加进 `Q`，再让 `p0_prev = pcur`。两种写法任选其一，关键是不丢点、不重算；
- **除 2 要写 `/ 2.0`**：`(p0 + pcur) / 2` 在 C 里是整数 2——虽然这里操作数是 double 不会被截断，但写成 `/ 2.0` 是防止将来变量改成 int 时踩坑的好习惯；
- 想一想：为什么首尾两个点要"除以 2"，中间的点不用？画出 2 个时段的图，数一数每个测点被几个梯形"共享"。

**完成本练习后你将具备的能力**：用循环累加器实现梯形法则数值积分——这是实验 A10 中"日得热量计算环节"的地基，也是数值积分类实验（一维乃至二维积分）的公共起点。
