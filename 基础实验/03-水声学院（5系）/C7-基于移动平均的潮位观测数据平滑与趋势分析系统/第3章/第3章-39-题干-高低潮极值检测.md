# 第 3 章 练习 39　高低潮极值检测

**所属综合实验**：C7（C7-基于移动平均的潮位观测数据平滑与趋势分析系统）

**对应章节**：3 循环结构、选择结构、复合条件（逻辑与 &&）

**场景来源**：综合实验 C7《基于移动平均的潮位观测数据平滑与趋势分析系统》（水声学院）——本练习是该实验中"高低潮极值检测"环节的最小实现。

**建议用时**：30 分钟

## 一、应用场景

潮位曲线一起一伏：涨到最高点是**高潮**，落到最低点是**低潮**。自动找出每个高、低潮，是潮汐分析的第一步——有了它们才能算潮差、报潮时。综合实验 C7 的第 6 模块"高低潮极值检测"就是干这件事。

数学上，一个点是**局部极大**当且仅当它比左右两个邻居都大；**局部极小**当且仅当比左右邻居都小。处理序列时仍然可以不用数组：让三个变量 `a、b、c` 像**滑动窗口**一样沿序列滚动（`a` 是左邻、`b` 是窗口中心、`c` 是右邻），每滚一步做一次比较。这是练习 38"两个滚动变量"的自然升级——变成**三个**。

## 二、任务要求

编写一个完整程序 `tide_extreme.c`：

1. 从键盘读入观测点数 `N`（int，$3 \le N \le 2000$），随后读入 $N$ 个潮位值（double，m）——**边读边处理，不允许使用数组**；
2. 用滑动三变量窗口检测每个**内部点**（第 2 个到第 $N-1$ 个）：
   - 若 $b > a$ 且 $b > c$：这是一个**高潮**，输出一行 `high <b>`；
   - 若 $b < a$ 且 $b < c$：这是一个**低潮**，输出一行 `low <b>`；
   （`<b>` 为该点潮位，保留 2 位小数；高潮、低潮按出现顺序输出。）
3. 最后输出两行统计：`highs = <H>` 与 `lows = <L>`（高潮、低潮的总个数）。

注意：**平台段不判**——若 $b$ 与邻居相等（不严格大于/小于），一律不算极值。

## 三、输入输出格式

**输入**：第一行整数 `N`；第二行 $N$ 个实数，用空格分隔。

**输出**：先若干行极值记录（`high x.xx` 或 `low x.xx`，按时间顺序），最后两行统计：

```
highs = <H>
lows = <L>
```

## 四、样例

**样例 1**

输入：
```
10
2.1 2.8 3.6 3.1 2.4 2.9 3.8 3.3 2.6 3.0
```
输出：
```
high 3.60
low 2.40
high 3.80
low 2.60
highs = 2
lows = 2
```
（内部点共 8 个，其中第 3 点 3.6、第 7 点 3.8 是高潮；第 5 点 2.4、第 9 点 2.6 是低潮。）

**样例 2**（含平台段）

输入：
```
6
1.5 2.2 2.2 2.2 1.8 1.9
```
输出：
```
lows = 0
highs = 0
```
（第 2～4 点同为 2.2，"不比邻居大"也不"比邻居小"，平台段不算极值；首尾点不判。）

## 五、提示

- 滑动窗口的滚动套路（先读满前三点，之后每读一个新值滚动一次）：
  ```c
  scanf("%lf %lf", &a, &b);          /* 先读前两点 */
  for (i = 3; i <= n; i++) {
      scanf("%lf", &c);              /* 读右邻 */
      if (b > a && b > c) { ... }    /* 判高潮：中心 b */
      if (b < a && b < c) { ... }    /* 判低潮 */
      a = b;  b = c;                 /* 窗口右滚一格 */
  }
  ```
- 两个条件用 `&&`（逻辑与）连接；"严格大于/小于"保证平台段自动出局；
- 高潮与低潮**互斥**（$b$ 不可能同时比两个邻居都大又都小），但代码里仍建议用两个独立 `if` 而非 `if-else`——结构清晰，且正确性不依赖互斥假设；
- 计数器 `H`、`L` 初始化为 0，输出时整型 `%d`；
- 想一想：首尾两个点为什么永远不可能是（本题定义的）极值？（它们缺左邻或右邻，滑动窗口从第 3 个点才开始工作。）

**完成本练习后你将具备的能力**：用三变量滑动窗口检测序列的局部极值——这是 C7 实验"高低潮检测"与"潮差统计"两个模块的共同地基。
