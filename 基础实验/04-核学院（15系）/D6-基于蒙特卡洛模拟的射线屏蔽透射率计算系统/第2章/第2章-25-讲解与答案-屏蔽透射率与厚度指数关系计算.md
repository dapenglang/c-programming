## 二、预备知识：指数衰减律的基本原理（零基础阅读）

### 1. 问题是怎么来的

γ 光子穿过屏蔽板时，会和材料原子发生光电效应、康普顿散射等作用，一旦发生作用，光子就"消失"在射线束里了。**光子走的距离越长，碰上原子的机会就越多**，因此透射过去的光子越来越少。

关键规律是：在每一小段相同厚度 $\Delta x$ 里，被挡下的光子**比例**是固定的（比如每 1 mm 挡掉 5%）。这不是"每段挡掉固定的个数"，而是"每段挡掉当前剩余量的固定比例"——这种"按比例削减"的过程，其结果就是指数衰减。

### 2. 公式是怎么推出来的

设厚度为 $x$ 时射线强度为 $I(x)$。再往前走一小段 $dx$，损失的强度与"当前强度"和"走过的厚度"成正比：

$$
dI = -\mu \, I \, dx
$$

负号表示强度在减少，$\mu$ 是比例系数（就是线衰减系数）。这是最简单的微分方程，把 $I$ 移到一边、$x$ 移到另一边积分：

$$
\int \frac{dI}{I} = -\mu \int dx \quad\Longrightarrow\quad \ln I = -\mu x + C
$$

用边界条件定常数：厚度为 0 时强度就是入射强度 $I_0$，即 $I(0) = I_0$，代入得 $C = \ln I_0$。于是

$$
\ln I - \ln I_0 = -\mu x \quad\Longrightarrow\quad \ln\frac{I}{I_0} = -\mu x
$$

两边取指数函数（$e$ 的幂），就得到**窄束指数衰减律**：

$$
\frac{I}{I_0} = e^{-\mu x}
$$

### 3. 用本例走一遍

取铅 $\mu = 0.78\ \text{cm}^{-1}$，厚度 $x = 2$ cm：

- 指数上的乘积：$\mu x = 0.78 \times 2 = 1.56$；
- 取负并求指数：$T = e^{-1.56}$；
- 查指数函数值：$e^{-1.56} \approx 0.2101$。

所以 2 cm 铅板把射线削弱到原来的约 21%。再验算特殊点：$x = 0$ 时 $T = e^{0} = 1$，全部透射；$x$ 越大 $e^{-\mu x}$ 越接近 0，透射越少——与物理直觉完全一致。

顺便看一眼半值层：令 $T = 0.5$，则 $e^{-\mu x} = 0.5$，两边取对数得 $-\mu x = \ln 0.5 = -\ln 2$，所以

$$
x_{1/2} = \frac{\ln 2}{\mu} = \frac{0.6931}{0.78} \approx 0.889\ \text{cm}
$$

即铅的半值层约 0.89 cm。样例 2 的 $x = 0.9$ 正好接近半值层，输出 0.4956 略小于 0.5——厚度略大于半值层，透射率就略低于一半，两个结果互相印证。

### 4. 编程时怎么用它

公式里只有两个量：常量 $\mu$ 和输入 $x$，最后求 $T$。编程就是：**把 $\mu$ 放进常量、把 $x$ 读进变量、把 $e^{-\mu x}$ 用一个 `exp` 调用翻译成一行赋值语句**。

> **这个思想在综合实验中反复出现**：D6 射线屏蔽（μ 与 x → 透射率）、D1 放射性活度（半衰期与时间 → 活度）、D3 中子能量对数换算，全部是"物理量 → 指数/对数运算"同一个套路。学会一次，多处可用。

## 三、解题思路

1. **确定数据**：铅的线衰减系数是材料固有属性，程序运行中不改动，用 `const double MU = 0.78;` 表达最贴切；
2. **确定变量**：只有两个变量——读入的厚度 `x` 和待求的透射率 `T`，都是实数，用 `double`；
3. **套用公式**：`T = exp(-MU * x);`。注意负号写在指数里，`-MU * x` 先算乘法再变号（等价于 `-(MU*x)`），与公式 $-\mu x$ 完全一致；
4. **输出**：`exp` 需要数学库，开头加 `#include <math.h>`；题目要求保留 4 位小数，用 `%.4f`。

## 四、参考代码

```c
#include <stdio.h>
#include <math.h>              /* 使用 exp 函数需要数学库 */

int main(void)
{
    /* 铅对某能量γ射线的线衰减系数，单位 1/cm，材料固有属性用常量 */
    const double MU = 0.78;

    double x;                  /* 屏蔽板厚度，单位 cm */
    double T;                  /* 透射率 I/I0，无量纲 */

    /* 读入厚度 */
    scanf("%lf", &x);

    /* 指数衰减律：T = exp(-mu * x) 即 e 的 (-μx) 次方 */
    T = exp(-MU * x);

    /* 输出，保留 4 位小数 */
    printf("T = %.4f\n", T);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 2 | μx = 0.78×2 = 1.56，T = e^(−1.56) = 0.2101 | `T = 0.2101` ✓ |
| 0.9 | μx = 0.78×0.9 = 0.702，T = e^(−0.702) = 0.4956（略小于半值 0.5） | `T = 0.4956` ✓ |
| 0 | μx = 0，T = e^0 = 1.0000（不挡，全透射） | `T = 1.0000` ✓ |
| 0.889 | μx = 0.78×0.889 = 0.6934 ≈ ln2，T ≈ 0.5000（半值层厚度） | `T = 0.5000` ✓ |

第四个样例验证了半值层公式 $x_{1/2} = \ln 2/\mu \approx 0.889$ cm，与解析解吻合。

## 六、常见错误与讲解

**错误 1：漏写 `#include <math.h>`**

```c
#include <stdio.h>
/* 缺 #include <math.h> */
...
T = exp(-MU * x);      /* 编译告警“隐式声明函数 exp”，结果不可靠 */
```

C 语言里 `exp`、`pow`、`log`、`sqrt` 都属于数学库函数，必须在文件开头声明数学库头文件，否则编译器不认识这个函数。**纪律：凡是调用数学库函数，第一行就补上 `#include <math.h>`。**

**错误 2：常量写成整数**

```c
const int MU = 0.78;     /* 错：0.78 存进 int 变成 0，透射率恒为 1 */
const double MU = 0.78;  /* 对：物理常数一律 double */
```

$\mu$ 本质是实数，用 `int` 会把 0.78 截断为 0，导致 $T \equiv 1$——物理上完全错误。**本章纪律：凡是物理上的实数量（厚度、系数、强度、能量……），一律用 `double`。**

**错误 3：负号位置写错**

```c
T = exp(MU * x);        /* 错：少了负号，算成了 e^(+μx)，透射率大于 1 */
T = exp(-MU * x);       /* 对：指数上是 −μx */
```

忘了负号会得到 $T > 1$，物理上意味着"透射的光子比入射的还多"，一眼就能看出荒谬。**自检办法：算完想想透射率应在 0～1 之间。**

**错误 4：输出格式与类型不匹配**

```c
printf("T = %d\n", T);     /* 错：double 用 %d 输出得到乱码 */
printf("T = %f\n",  T);    /* 对但没控制位数 */
printf("T = %.4f\n", T);   /* 对：保留 4 位小数 */
```

`scanf` 与 `printf` 的格式符要和变量类型严格对应：`double` 读入用 `%lf`、输出用 `%f`（可加精度如 `%.4f`）。

## 七、与综合实验的衔接

- 实验 **D6（蒙特卡洛射线屏蔽透射率计算）**中，"理论透射率计算"模块就是本练习的放大：材料更多（铅、铁、混凝土各有不同 μ）、厚度要循环扫描。学到第 3 章（循环）后，厚度可以批量扫描；学到第 4 章（函数）后，本练习的计算会被封装进 `double trans(double mu, double x)` 反复调用；学到第 7 章（结构体）后，材料信息会打包成一个结构体数组。本练习故意规定"0 ≤ x ≤ 10"，就是为了让你**先专注于把一个指数计算写对**；
- D6 的核心是蒙特卡洛模拟：用伪随机数抽样决定每个光子的命运，统计透射比例，再用本练习的 $e^{-\mu x}$ 作对照。**模拟值应当逼近理论值**——这正是数值方法课的第一次"理论 vs 实验"对照训练。
