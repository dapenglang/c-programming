# 第 7 章 练习 12　链表尾插建立队列

**对应章节**：7 数据的结构化封装方法（7.1 结构体类型及变量、7.5 链表——尾插法建立链表、尾指针维护、链表遍历、`malloc`/`free`）

**场景来源**：综合实验 C6《冰块与结构碰撞模拟系统》（水声学院）——本练习是该实验中"按到达顺序排队管理冰块对象"环节的实现。

**建议用时**：35 分钟

## 一、应用场景

在碎冰与结构的碰撞模拟中，冰块是**随时间一个接一个进入计算域**的：先进入的先参与碰撞计算，后进入的排在后面，这就是典型的**先来先服务（队列）**顺序。程序必须严格保持冰块的到达次序，一旦顺序乱了，碰撞事件的时间线就错了。用链表存放这些冰块时，如果还像上一题那样**头插**，链表顺序会和到达顺序相反；要严格保持"先来在前"，就要用**尾插法**——每条新记录都挂到链表的末尾。本练习用尾指针把建链、入队、遍历一次做完。

## 二、任务要求

编写一个完整程序 `list_append.c`：

1. 定义节点结构体类型 `struct IceBlock`：`int id`（冰块编号）、`double mass`（质量，kg）、`struct IceBlock *next`（指向下一节点的指针）；
2. 读入整数 `n`（冰块个数），再循环读入 `n` 行，每行 `id` 与 `mass`；
3. 对每条记录用 `malloc` 申请新节点，**插入到链表尾部**（尾插）；要求用一个 `tail` 指针始终指向当前链表的最后一个节点，使每次尾插不需要从头遍历，操作时间为常数；
4. 建链完成后，从 `head` 出发遍历输出全部节点（此时输出顺序应**与输入顺序一致**），最后输出 `count = 节点数`；
5. 每次 `malloc` 都要检查返回值是否为 `NULL`；程序结束前用 `free` 释放所有节点。

## 三、输入输出格式

**输入**：

- 第一行：一个整数 `n`（`0 ≤ n ≤ 100`）；
- 接下来 `n` 行：每行两个数 `id`（整数）与 `mass`（实数，kg）。

**输出**：按链表顺序（即输入顺序）输出 `n` 行，每行 `id mass`（质量保留 2 位小数）；最后一行输出 `count = 节点数`。当 `n = 0` 时，只输出 `count = 0`。

## 四、样例

**样例 1**

输入：
```
3
1 120.5
2 88.0
3 150.2
```
输出：
```
1 120.50
2 88.00
3 150.20
count = 3
```

**样例 2**

输入：
```
4
11 60.0
12 75.5
13 90.0
14 45.3
```
输出：
```
11 60.00
12 75.50
13 90.00
14 45.30
count = 4
```

## 五、提示

- 尾插的关键是**维护一个 `tail` 指针**。空链表时 `head` 和 `tail` 都是 `NULL`；插入第一个节点时，`head` 与 `tail` 同时指向它；
- 尾插的四步：
  ```c
  p->next = NULL;              /* 新节点将成为尾节点，next 置 NULL */
  if (head == NULL)            /* 空链表：头、尾都指向它 */
      head = tail = p;
  else {                       /* 非空：挂到尾部，再更新 tail */
      tail->next = p;
      tail = p;
  }
  ```
- 新节点的 `next` **必须置为 `NULL`**，否则尾节点的"链结束"标志就不存在了；
- 遍历写法与头插完全相同：`p = head; while (p != NULL) { …; p = p->next; }`；
- 释放时仍用 `while (head != NULL)` 逐个 `free`，先存下一节点再释放。

**完成本练习后你将具备的能力**：区分头插与尾插两种建链方式、会用尾指针把插入代价降到 $O(1)$、能保持数据的原始到达顺序——这是实验 C6"冰块队列管理"模块的地基。
