# 第 3 章 练习 22　去噪效果误差累加

**所属综合实验**：B2（B2-基于滑动平均滤波的传感器数据去噪系统）

**对应章节**：3 程序流程控制（3.1 关系与逻辑运算、3.3 循环结构 for、3.4 标准输入输出）

**场景来源**：综合实验 B2《基于滑动平均滤波的传感器数据去噪系统》（人工智能学院）——本练习是该实验中"去噪效果评估"环节的最小实现。

**建议用时**：25 分钟

## 一、应用场景

传感器采集的数据里总混着噪声，滑动平均滤波就是用来"抹平"这些波动的。可滤波到底管不管用？要看**去噪前后数据差多少**：原始数据与去噪数据的差距如果很小，说明滤波没有破坏有用信息；如果差距过大，说明滤波器把真实信号也削掉了。

工程上常用**误差平方和**来量化这种差距：把每个采样点上的差值平方后累加起来。B2 系统每处理完一条序列，都要算一次这个指标，用来评价滤波窗口是否合适。

## 二、任务要求

编写一个完整程序 `denoise_error.c`：

1. 从键盘读入采样点数 `n`（整数，$1 \le n \le 20$）；
2. 依次读入 $n$ 个原始采样值（double 类型）和 $n$ 个去噪后的采样值（double 类型）；
3. 用循环逐点计算差值，累加得到**误差平方和**：

$$
S = \sum_{i=1}^{n}{(x_i - y_i)^2}
$$

（$x_i$ 为原始值，$y_i$ 为去噪值。）
4. 输出误差平方和，保留 **4 位小数**。

## 三、输入输出格式

**输入**：
第一行，一个整数 n；
第二行，n 个实数，为原始采样值；
第三行，n 个实数，为去噪后的采样值。

**输出**：一行，按格式 `SSE = 结果` 输出误差平方和，保留 4 位小数。

## 四、样例

**样例 1**

输入：
```
3
10.0 12.0 14.0
10.5 12.5 13.5
```
输出：
```
SSE = 0.7500
```

**样例 2**

输入：
```
4
1.0 2.0 3.0 4.0
1.5 2.5 3.5 4.5
```
输出：
```
SSE = 1.0000
```

## 五、提示

误差平方和的计算流程：

$$
S = \sum_{i=1}^{n}{(x_i - y_i)^2} = (x_1-y_1)^2 + (x_2-y_2)^2 + \cdots + (x_n-y_n)^2
$$

编程三步走：

1. 用一个 `double` 变量 `sse` 做累加器，**初值必须是 0.0**；
2. 为了能逐点配对，最好先把两串数据分别存进两个数组（第 5 章内容），或者用两次循环先读原始值再读去噪值；
3. 循环里执行 `sse += (x[i] - y[i]) * (x[i] - y[i]);`，每一项都要先平方再加。

平方写成 `d * d` 即可，不必用 `pow`。注意乘除优先级高于加减，`(x[i]-y[i])` 的括号不能省。

**完成本练习后你将具备的能力**：用 for 循环遍历序列、用累加器模式求和、书写含平方的算式——这些是实验 B2 中"误差评估模块"的地基。
