## 二、预备知识：形参、实参与值传递（零基础阅读）

### 1. 问题来源：为什么要有"参数"

面积公式离不开"上底、下底、高"这三个量，而这三个量每次都不相同。函数不能把具体数值写死，于是留出三个"空位"：

```c
double trap_area(double a, double b, double h)
```

这里的 `a、b、h` 就是**形参**——它们在函数定义时只是占位变量，还没有具体的值。真正调用时，主函数把三个具体数字塞进去：

```c
s = trap_area(2.0, 3.5, 1.2);
```

`2.0、3.5、1.2` 就是**实参**。

### 2. 位置一一对应

C 语言的参数传递是**按位置**对应的：第 1 个实参给第 1 个形参，第 2 个给第 2 个……所以 `trap_area(2.0, 3.5, 1.2)` 表示 $a=2.0,\ b=3.5,\ h=1.2$。如果把顺序写成 `trap_area(3.5, 2.0, 1.2)`，虽然本题因公式对 $a,b$ 对称而结果相同，但在"上底/下底"语义不同的问题里就会出错。**位置错了，函数不会报错，只会安静地算错。**

### 3. 值传递：传进去的是"复印件"

调用瞬间，实参的值被**复制**一份交给形参。也就是说，函数里的 `a` 和主函数里的 `a` 是**两个互不相干的变量**，只是初值相同。函数内部哪怕写 `a = 100;`，主函数里的 `a` 也纹丝不动。本例函数不改形参，只读取它们并计算，因此值传递用起来最自然。

### 4. 返回值：一进多出中的"一个出"

函数有 3 个入口参数，但 `return` 只能交回**一个**结果（这里是面积 `double`）。以后遇到的"计算多种中间结果"的需求，要靠第 6 章的指针才能在参数里返回——本章先把手头这一种"输入若干、输出一个"的模式练熟。

### 5. 编程翻译

把公式 $S=\dfrac{(a+b)h}{2}$ 直接翻译成一行：

```c
return (a + b) * h / 2.0;
```

注意写成 `/ 2.0` 而不是先写 `(a+b)*h/2` 也正确（因为前面是浮点运算，`2` 会被自动提升）。但**绝不可以**写成 `1/2 * (a+b) * h`，因为 `1/2` 是整数除法，结果直接得 0。

## 三、解题思路

1. **定接口**：函数名 `trap_area`，三个 `double` 形参，返回 `double`；
2. **写原型**：在 `main` 之前声明 `double trap_area(double a, double b, double h);`；
3. **写定义**：函数体只有一行 `return (a + b) * h / 2.0;`；
4. **主流程**：`scanf` 读三个数 → `s = trap_area(a, b, h);` → `printf` 输出；
5. **校核**：用退化情形（$a=b$，即矩形）验证公式。

## 四、参考代码

```c
#include <stdio.h>

/* 函数原型声明：上底 a、下底 b、高 h，返回梯形面积 */
double trap_area(double a, double b, double h);

int main(void)
{
    double a, b, h;       /* 上底、下底、高，单位 m */
    double s;             /* 梯形面积，单位 m^2 */

    scanf("%lf %lf %lf", &a, &b, &h);   /* 读入三个实数 */
    s = trap_area(a, b, h);             /* 调用函数，位置一一对应 */
    printf("area = %.4f\n", s);

    return 0;
}

/* 函数定义：一个梯形只做一件事——求面积 */
double trap_area(double a, double b, double h)
{
    return (a + b) * h / 2.0;
}
```

## 五、运行验证

| 输入 a b h | 函数内手算过程 | 程序输出 |
|---|---|---|
| 2.0 3.5 1.2 | (2.0+3.5)×1.2/2 = 5.5×1.2/2 = 3.3 | `area = 3.3000` ✓ |
| 1.6 1.6 0.8 | (1.6+1.6)×0.8/2 = 3.2×0.8/2 = 1.28 | `area = 1.2800` ✓ |
| 0.0 4.0 2.0 | (0+4)×2/2 = 4.0（退化为三角形） | `area = 4.0000` ✓ |

当 $a=b$ 时结果等于矩形面积 $bh$，当 $a=0$ 时等于三角形面积 $bh/2$，两种退化情形的结果都正确，说明公式与参数传递均无误。

## 六、常见错误与讲解

**错误 1：实参顺序与形参语义错位**

```c
s = trap_area(b, a, h);    /* a、b 互换：本题因公式对称仍对，换到"上下底"不对称的问题就错 */
```

养成习惯：**按形参定义的语义顺序填实参**，并用注释标明每个实参的含义。

**错误 2：整数除法把结果算成 0**

```c
return 1 / 2 * (a + b) * h;   /* 错：1/2 = 0，整体得 0 */
return (a + b) * h / 2;       /* 对：前面已是浮点，2 自动提升为 2.0 */
```

**错误 3：忘记函数原型**

```c
int main(void) { ... trap_area(a, b, h); ... }   /* 编译报错：未声明 */
double trap_area(double a, double b, double h) { return ...; }
```

在 `main` 之前补上 `double trap_area(double a, double b, double h);` 即可。

**错误 4：scanf 忘记取地址符或格式符不匹配**

```c
scanf("%lf %lf %lf", a, b, h);    /* 错：缺 & */
scanf("%lf %lf %lf", &a, &b, &h); /* 对：每个变量前都要 & */
```

## 七、与综合实验的衔接

- 在实验 **C8（碎冰浮力吃水计算）**中，"淹没面积积分"模块就是循环调用本函数：把冰块横截面沿高度切成若干小段，每段用 `trap_area` 求出面积再累加。本练习写好的这个函数，正是那台"面积累加机器"的单步积木；
- 更广泛地看，实验 A3（飞行器弹道梯形积分）、D5（γ 射线剂量率数值积分）都用同一套梯形法。**把"单个梯形面积"和"多段累加"分开成两个函数，是数值计算程序最常见的模块划分方式**——学会本练习，就掌握了这种划分的最小单元。
