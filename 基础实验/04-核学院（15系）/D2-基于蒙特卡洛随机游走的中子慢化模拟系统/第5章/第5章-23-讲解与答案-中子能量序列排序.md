## 二、预备知识：冒泡排序的基本原理（零基础阅读）

### 1. 问题是怎么来的

一堆数字要**按大小排队**，这是计算机最经典的任务之一。核科学里排队的对象五花八门：中子能量样本、截面数据点、核素半衰期……排序的目的是让后续统计（找中位数、划分能群、二分查找）变得容易。

### 2. 冒泡排序的推导

**核心操作：比较相邻两个数，若"前大后小"（升序要求）就交换。**

假设数组为 \([3, 1, 2]\)，走一轮：

- 比 \(a_0, a_1\)：\(3>1\)，交换 → \([1, 3, 2]\)；
- 比 \(a_1, a_2\)：\(3>2\)，交换 → \([1, 2, 3]\)。

一轮下来，**最大的数 3 被"冒"到了最后**。这就是"冒泡"名字的由来：大的数像气泡一样浮到末尾。

**为什么需要多轮？** 一轮只能把"当前最大"送到末尾，次大的数需要第二轮。对 n 个数，最多需要 \(n-1\) 轮。

**内层比较次数逐轮减少**：第 1 轮比 \(n-1\) 次，第 2 轮只需比 \(n-2\) 次（末尾已经是最大的，不用再比）……第 k 轮比 \(n-k\) 次。故双循环写作：

$$
\text{for } i=0..n-2:\quad \text{for } j=0..n-2-i:\quad \text{比较 } a_j, a_{j+1}
$$

### 3. 交换为什么需要临时变量

如果直接写 `a[j] = a[j+1]; a[j+1] = a[j];`，第一步就把 `a[j]` 的原值覆盖掉了，第二步赋回的其实是 `a[j+1]` 的值，两个数都变成 `a[j+1]`。**正确做法是先用临时变量"存一份"**：

```c
tmp = a[j];        /* 备份 a[j] */
a[j] = a[j + 1];   /* 用 a[j+1] 覆盖 a[j] */
a[j + 1] = tmp;    /* 把备份填回 a[j+1] */
```

可以想象成"两杯水交换"：必须借第三个空杯子，不能直接对倒。

### 4. 用本例走一遍

样例 2：\([100, 0.5, 50]\)，n=3。

**第 1 轮**（i=0，j 从 0 到 1）：

- j=0：比 \(100\) 与 \(0.5\)，\(100>0.5\)，交换 → \([0.5, 100, 50]\)；
- j=1：比 \(100\) 与 \(50\)，\(100>50\)，交换 → \([0.5, 50, 100]\)。

**第 2 轮**（i=1，j 只到 0）：

- j=0：比 \(0.5\) 与 \(50\)，不交换 → \([0.5, 50, 100]\)。

排序完成，输出 \(0.5, 50, 100\)，与样例一致。

### 5. 编程时怎么用它

冒泡排序是"**双重循环 + 一个判断 + 三行交换**"，是所有排序算法里最容易手写的一个。它思路直观、不易写错，缺点是效率一般（比较次数约 \(n^2/2\)），但作为入门足够，也是实验 D2 中处理几十个样本时的实用选择。

> **这个思想在综合实验中反复出现**：D2 排序能量样本、D3 按能量排序截面表（保证递增以便插值）、D1 按半衰期排序核素、D4 按温度排序节点。**排序是"让数据就位"的通用前置步骤。**

## 三、解题思路

1. **读入**：先读 `n`，再用循环读入 `n` 个能量存入数组；
2. **外层循环**：`for (i = 0; i < n - 1; i++)` 控制轮数；
3. **内层循环**：`for (j = 0; j < n - 1 - i; j++)` 控制本轮比较次数，比较 `a[j]` 与 `a[j+1]`；
4. **交换**：逆序时用 `tmp` 交换；
5. **输出**：循环逐行打印，用 `%.4e`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    double e[50];   /* 中子能量样本数组，最多 50 个，eV */
    int    n;       /* 样本个数 */
    int    i, j;
    double tmp;     /* 交换用的临时变量 */

    /* 读入个数与能量序列 */
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%lf", &e[i]);
    }

    /* 冒泡排序：升序 */
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - 1 - i; j++) {
            if (e[j] > e[j + 1]) {          /* 逆序则交换 */
                tmp       = e[j];
                e[j]      = e[j + 1];
                e[j + 1]  = tmp;
            }
        }
    }

    /* 逐行输出排序结果 */
    for (i = 0; i < n; i++) {
        printf("%.4e\n", e[i]);
    }

    return 0;
}
```

| n=3：100 0.5 50 | 升序排列为 0.5,50,100 | 3 行见样例 2 ✓ |

## 六、常见错误与讲解

**错误 1：交换时不用临时变量**

```c
e[j] = e[j + 1];        /* 错：原 e[j] 已丢失 */
e[j + 1] = e[j];
```

结果两个元素都变成原来的 `e[j+1]`，数据被破坏。**交换必借临时变量。**

**错误 2：内层循环边界写错**

```c
for (j = 0; j < n - 1 - i; j++)   /* 对：逐轮减少比较次数 */
for (j = 0; j < n; j++)           /* 错：访问 e[j+1] 时 j 可能取到 n-1，越界读 e[n] */
```

内层要访问 `e[j+1]`，所以 `j` 最大只能是 `n-2`，即上界 `< n-1 - i`。

**错误 3：外层循环次数写成 `n`**

```c
for (i = 0; i < n; i++)      /* 多跑一轮，虽无害但不必要 */
for (i = 0; i < n - 1; i++)  /* 对：n 个数最多 n-1 轮 */
```

多一轮不会出错（只是个空转），但浪费且不严谨。

**错误 4：输出格式用 `%f` 看小能量**

```c
printf("%.4f\n", e[i]);   /* 0.025 会显示成 0.0250，但 1e-8 之类会变成 0.0000 */
printf("%.4e\n", e[i]);   /* 对：科学计数法，量级清晰 */
```

核能能量跨 8 个数量级，必须用科学计数法输出。
