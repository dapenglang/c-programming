## 二、预备知识：线性插值的基本原理（零基础阅读）

### 1. 问题是怎么来的

声速剖面表只给出两个测点：深度 0 m 处 1531.0 m/s，深度 50 m 处 1524.0 m/s。**表里没有 30 m 这一档，那里的声速是多少？** 最合理的假设是：0～50 m 之间声速随深度**均匀变化**，图象是一条直线；那么任意深度的声速就在这条直线上按比例取值。这就是线性插值。

### 2. 公式是怎么推出来的

设已知点为 $(z_0, c_0)$、$(z_1, c_1)$，要求 $z$ 处（$z_0 \le z \le z_1$）的值。"均匀变化"意味着**增长量与深度增长量成正比**：

$$
\frac{c - c_0}{c_1 - c_0} = \frac{z - z_0}{z_1 - z_0}
$$

解得

$$
c = c_0 + \dfrac{(c_1 - c_0)(z - z_0)}{z_1 - z_0}
$$

用大白话读：**起点值 + 全程变化量 × 已走比例**。注意 $(c_1 - c_0)$ 可以是负数，表示声速在下降，公式同样成立。

### 3. 用本例走一遍

取 $z = 30$，代入 $(z_0, c_0) = (0,\ 1531.0)$，$(z_1, c_1) = (50,\ 1524.0)$：

- 已走比例：$(30 - 0)/(50 - 0) = 0.6$，即走完了 60%；
- 全程变化：$1524.0 - 1531.0 = -7.0$ m/s；
- 已变化：$-7.0 \times 0.6 = -4.2$ m/s；
- 结果：$c = 1531.0 - 4.2 = 1526.8$ m/s。

再验端点：$z=0$ 得 1531.0，$z=50$ 得 1524.0，与测点完全一致，说明公式正确。

### 4. 编程时怎么用它

公式里五个量：四个表格常量、一个输入 $z$。编程就是把这五个数放进变量，把公式原样翻译成一行赋值语句。**唯一要留心的是括号**：分子 $(c_1-c_0)(z-z_0)$ 要先各自算好再相乘，分母 $(z_1-z_0)$ 单独成组。

> **这个思想在综合实验中反复出现**：C1 声速剖面、A1 风荷载、D3 核截面、D4 温度场，都是"表格 + 线性插值"。本题与练习 01 是同一种方法换了一个场景，请独立完成、独立验算。

## 三、解题思路

1. **确定常量**：四个表格值 `Z0=0.0, Z1=50.0, C0=1531.0, C1=1524.0`，用 `const double`；
2. **确定变量**：深度 `z` 与声速 `c`，用 `double`；
3. **套公式**：`c = C0 + (C1 - C0) * (z - Z0) / (Z1 - Z0);`；
4. **输出**：`printf("c = %.2f m/s\n", c);`。

## 四、参考代码

```c
#include <stdio.h>

int main(void)
{
    /* 声速剖面相邻两档测点：深度(m) 与 声速(m/s) */
    const double Z0 = 0.0;      /* 下档深度 */
    const double Z1 = 50.0;     /* 上档深度 */
    const double C0 = 1531.0;   /* 下档声速 */
    const double C1 = 1524.0;   /* 上档声速（声速随深度递减） */

    double z;                   /* 待查深度，m */
    double c;                   /* 插值得到的声速，m/s */

    /* 读入深度（题目保证 0 <= z <= 50） */
    scanf("%lf", &z);

    /* 线性插值：c = c0 + (c1 - c0) * (z - z0) / (z1 - z0) */
    c = C0 + (C1 - C0) * (z - Z0) / (Z1 - Z0);

    /* 输出，保留 2 位小数 */
    printf("c = %.2f m/s\n", c);

    return 0;
}
```

## 五、运行验证

| 输入 | 手算过程 | 程序输出 |
|---|---|---|
| 30 | 1531 + (−7) × 30/50 = 1531 − 4.2 = 1526.8 | `c = 1526.80 m/s` ✓ |
| 45 | 1531 + (−7) × 45/50 = 1531 − 6.3 = 1524.7 | `c = 1524.70 m/s` ✓ |
| 0 | 1531 + (−7) × 0/50 = 1531.0（下端点） | `c = 1531.00 m/s` ✓ |
| 50 | 1531 + (−7) × 50/50 = 1524.0（上端点） | `c = 1524.00 m/s` ✓ |

端点值与测点数据完全吻合，中间值随深度线性下降，插值正确。

## 六、常见错误与讲解

**错误 1：常量写成整数**

```c
const int Z0 = 0, Z1 = 50;         /* 错：虽然此处恰好为整数，但破坏了实数语义 */
const double C0 = 1531, C1 = 1524; /* 错：声速写成整型字面量 */
```

正确写法是全部用带小数点的常量（如 `1531.0`），保证右边表达式按实数运算。

**错误 2：忘记取地址符**

```c
scanf("%lf", z);     /* 错：程序崩溃或读不进数据 */
scanf("%lf", &z);    /* 对：scanf 需要变量地址 */
```

**错误 3：输出格式与精度不符**

```c
printf("c = %d m/s\n", c);      /* 错：double 用 %d 输出乱码 */
printf("c = %f m/s\n", c);      /* 对但位数不定 */
printf("c = %.2f m/s\n", c);    /* 对：保留 2 位小数 */
```

**错误 4：公式括号写错（负斜率最容易出问题）**

```c
c = C0 + (C1 - C0) * z - Z0 / (Z1 - Z0);        /* 错：括号缺失，结果全乱 */
c = C0 + (C1 - C0) * (z - Z0) / (Z1 - Z0);      /* 对：先减、再乘、再除 */
```

本题 $(C_1 - C_0)$ 为负，若把符号算错，结果会高于 1531，明显偏离合理区间（1524～1531），凭这一点就能自查。
